## Example

Rules for roots, powers and logarithms hold on a stated range, and the classical [[mathematical fallacies|S2BW0FDHV8]] of this family use them one step outside it.
Here is the shortest one, a false proof that $1 = -1$; find the bad step first.

1. $1 = \sqrt{1}$.
2. $\sqrt{1} = \sqrt{(-1)(-1)}$, since $(-1)(-1) = 1$.
3. $\sqrt{(-1)(-1)} = \sqrt{-1} \cdot \sqrt{-1}$.
4. $\sqrt{-1} \cdot \sqrt{-1} = i \cdot i = -1$.
5. So $1 = -1$.

Here $\sqrt{t}$ is the non-negative [[square root|0F7FQS6XY6]] of a real number $t \ge 0$, and $i$ is a complex number with $i^2 = -1$.
The bad step is step 3.
It uses the product rule $\sqrt{ab} = \sqrt{a}\sqrt{b}$ with $a = b = -1$, and the rule is proved only for $a \ge 0$ and $b \ge 0$.
We check the steps and the rule.

1. Steps 1 and 2 are true: $\sqrt{1} = 1$ and $(-1)(-1) = 1$.
2. The proof of the product rule shows where the condition enters. For $a, b \ge 0$ the number $\sqrt{a}\sqrt{b}$ is non-negative and its square is $ab$, so it is the non-negative square root of $ab$.
3. For $a = b = -1$ the number $\sqrt{a}\sqrt{b} = i \cdot i = -1$ is negative, so it is not the non-negative square root of $ab = 1$.
4. Step 4 is correct arithmetic, but it starts from the false line of step 3.

The correct version keeps the rule inside its range: $\sqrt{(-1)(-1)} = \sqrt{1} = 1$, and the product $\sqrt{-1}\sqrt{-1} = -1$ is a different number.

## Remarks

### Two square roots, one symbol

Here is a second false proof, that $4 = 5$.

1. $16 - 36 = -20 = 25 - 45$.
2. Add $\frac{81}{4}$ to both sides: $16 - 36 + \frac{81}{4} = 25 - 45 + \frac{81}{4}$.
3. Both sides are squares: $\left(4 - \frac{9}{2}\right)^2 = \left(5 - \frac{9}{2}\right)^2$.
4. Take square roots: $4 - \frac{9}{2} = 5 - \frac{9}{2}$, so $4 = 5$.

Steps 1 to 3 are correct, and both sides of step 3 equal $\frac{1}{4}$.
Step 4 is the bad one: it uses "$x^2 = y^2$ gives $x = y$", which fails because [[squaring is not injective|Q07B3Q8Q5A]].
Here $x = -\frac{1}{2}$ and $y = \frac{1}{2}$.
The correct rule comes from a factorization:
$$x^2 = y^2 \iff (x - y)(x + y) = 0 \iff x = y \text{ or } x = -y.$$
In the language of the [[absolute value|0FFXKTKKQC]], $\sqrt{x^2} = |x|$, so step 4 only gives $\left|4 - \frac{9}{2}\right| = \left|5 - \frac{9}{2}\right|$, which is true.

### Complex powers

For complex $z \neq 0$ and $w$, define $z^w = e^{w \operatorname{Log} z}$, where $\operatorname{Log}$ is the principal [[complex logarithm|02QGGD5G87]], with imaginary part in $(-\pi, \pi]$.
A false proof that $e^{-2\pi} = 1$:

1. By Euler's formula, $e^{2\pi i} = \cos 2\pi + i \sin 2\pi = 1$.
2. Raise both sides to the power $i$: $\left(e^{2\pi i}\right)^i = 1^i$.
3. Use $(e^a)^b = e^{ab}$: the left side is $e^{2\pi i \cdot i} = e^{-2\pi}$.
4. The right side is $1^i = e^{i \operatorname{Log} 1} = e^0 = 1$, so $e^{-2\pi} = 1$.

The bad step is step 3.
By the definition, $(e^a)^b = e^{b \operatorname{Log}(e^a)}$, and $\operatorname{Log}(e^a) = a$ only when the imaginary part of $a$ lies in $(-\pi, \pi]$.
For $a = 2\pi i$ that fails, and in fact $\operatorname{Log}(e^{2\pi i}) = \operatorname{Log} 1 = 0$.
So the correct value is $\left(e^{2\pi i}\right)^i = e^{i \cdot 0} = 1$, while $e^{-2\pi} \approx 0.00187$.

### Logarithms

A false proof that $0 = 2\pi i$:

1. $(-1)^2 = 1$, so $\operatorname{Log}\big((-1)^2\big) = \operatorname{Log} 1 = 0$.
2. Use $\operatorname{Log}(z^2) = 2 \operatorname{Log} z$: $\operatorname{Log}\big((-1)^2\big) = 2 \operatorname{Log}(-1) = 2\pi i$.
3. So $0 = 2\pi i$.

Here $\operatorname{Log}(-1) = \pi i$ is right, because $e^{\pi i} = -1$ and $\pi$ lies in $(-\pi, \pi]$.
Step 2 is the bad one.
The rule $\operatorname{Log}(z^2) = 2 \operatorname{Log} z$ holds exactly when $2 \operatorname{Log} z$ has imaginary part in $(-\pi, \pi]$, that is, when $\arg z$ lies in $(-\frac{\pi}{2}, \frac{\pi}{2}]$.
For $z = -1$ the principal argument is $\pi$, so the rule does not apply.

### The multivalued view

Each of these rules fails because a function picks one value out of several.
The equation $w^2 = t$ has two solutions for $t > 0$, and $\sqrt{t}$ picks the non-negative one.
The equation $e^w = z$ has infinitely many solutions $w$, which differ by multiples of $2\pi i$, and $\operatorname{Log} z$ picks one of them.
If $\log z$ means the set of all solutions, then $\log 1 = \{2\pi i k : k \in \mathbb{Z}\}$ and $2 \log(-1) = \{(4k + 2)\pi i : k \in \mathbb{Z}\}$.
So $0$ and $2\pi i$ are two values of the same multivalued $\log 1$, and the "contradiction" equates two different values.
In the same way $1^i$ has the values $e^{i \cdot 2\pi i k} = e^{-2\pi k}$, and $e^{-2\pi}$ is the value with $k = 1$.

### Watch out

Inside the range, the rules are safe.
With positive numbers the product rule works: $\sqrt{4} = \sqrt{2}\sqrt{2}$.
With $a = \frac{\pi i}{2}$ in place of $2\pi i$, $\operatorname{Log}(e^{\pi i/2}) = \frac{\pi i}{2}$, and $\left(e^{\pi i/2}\right)^i = e^{-\pi/2}$ is correct.
The trap is the formula $\sqrt{x^2} = x$ in a computation where $x$ can be negative, such as $x = \cos t$ on an interval where the cosine changes sign.

### Try it

Is $\sqrt{(-4)(-9)} = \sqrt{-4}\sqrt{-9}$?
No: the left side is $\sqrt{36} = 6$, and the right side is $(2i)(3i) = -6$.

Simplify $\sqrt{x^2 y}$ for real $x$ and $y \ge 0$.
The answer is $|x|\sqrt{y}$, not $x\sqrt{y}$; for $x = -1$ and $y = 4$ the value is $2$.

## Explanations

### L1 human

Every positive number has two square roots: $9$ has the roots $3$ and $-3$.
The symbol $\sqrt{9}$ means only the positive one, $3$.
Many false proofs forget the other root.
For example, $(-3)^2 = 9$ and $3^2 = 9$, but that does not make $-3$ equal to $3$.
Taking square roots of both sides of an equation is safe only when you know the signs of both sides.

### L2 human

We find the real numbers $a$ with $\sqrt{a^2} = a$, and use the answer to repair a false step.
For $a \ge 0$, the number $a$ is non-negative and its square is $a^2$, so $\sqrt{a^2} = a$.
For $a < 0$, the number $-a$ is positive and its square is $a^2$, so $\sqrt{a^2} = -a$.
Together:
$$\sqrt{a^2} = |a| \quad \text{for every real } a.$$
So $\sqrt{a^2} = a$ holds exactly when $a \ge 0$.

Now take the false step $\sqrt{(1 - 3)^2} = 1 - 3$, which leads to $2 = -2$.
The correct value is $|1 - 3| = 2$.
Check: $(1 - 3)^2 = 4$ and $\sqrt{4} = 2$.
The rule $\sqrt{a^2} = |a|$ is the standard repair for every false proof of this kind.

### L3 human

The failures have a structural reason.
Suppose that $s$ is a square root on $\mathbb{C}^\times$ that respects products, so $s(z)^2 = z$ and $s(zw) = s(z)s(w)$.
Then $s(1) = s(1 \cdot 1) = s(1)^2$, and $s(1) \neq 0$ because $s(1)^2 = 1$, so $s(1) = 1$.
Products give $s(-1)^2 = s\big((-1)(-1)\big) = s(1) = 1$.
But $s(-1)^2 = -1$ by the definition of a square root, so $-1 = 1$, which is false.
So no square root on $\mathbb{C}^\times$ is multiplicative, and in the same way no logarithm on $\mathbb{C}^\times$ turns products into sums, since $\exp$ has the kernel $2\pi i \mathbb{Z}$.
The first false proof is this argument in disguise.
On $(0, \infty)$, squaring and $\exp$ (from $\mathbb{R}$) are bijections onto $(0, \infty)$, so $\sqrt{\ }$ and $\ln$ respect products there, and the rules hold.
The cure in complex analysis is to work with branches on cut planes, or with Riemann surfaces, where the multivalued function becomes single-valued.
