## Example

Four [[mathematical fallacies|S2BW0FDHV8]] use a rule for roots, powers or logarithms outside the range where the rule holds.
For each one we give the argument, the step that fails, and the correct rule.
Here $\sqrt{t}$ is the non-negative [[square root|0F7FQS6XY6]] of a real number $t \ge 0$, and $i$ is a complex number with $i^2 = -1$.

### A product rule for negative numbers

The argument:

1. $1 = \sqrt{1}$.
2. $\sqrt{1} = \sqrt{(-1)(-1)}$, since $(-1)(-1) = 1$.
3. $\sqrt{(-1)(-1)} = \sqrt{-1} \cdot \sqrt{-1}$.
4. $\sqrt{-1} \cdot \sqrt{-1} = i \cdot i = -1$.
5. So $1 = -1$.

The check:

1. Steps 1 and 2 are valid: $\sqrt{1} = 1$, and $(-1)(-1) = 1$.
2. Step 3 uses the rule $\sqrt{ab} = \sqrt{a}\sqrt{b}$ with $a = b = -1$. The rule is proved only for $a \ge 0$ and $b \ge 0$, so step 3 is invalid.
3. The proof of the rule shows where the condition enters. For $a, b \ge 0$, the number $\sqrt{a}\sqrt{b}$ is non-negative and its square is $ab$. So it is the non-negative square root of $ab$.
4. For $a = b = -1$, the number $\sqrt{a}\sqrt{b} = i \cdot i = -1$ is negative, so it is not the non-negative square root of $ab = 1$.

### The two square roots

The argument:

1. $-20 = -20$, so $16 - 36 = 25 - 45$.
2. Add $\frac{81}{4}$ to both sides: $16 - 36 + \frac{81}{4} = 25 - 45 + \frac{81}{4}$.
3. Both sides are squares: $\left(4 - \frac{9}{2}\right)^2 = \left(5 - \frac{9}{2}\right)^2$.
4. Take square roots: $4 - \frac{9}{2} = 5 - \frac{9}{2}$.
5. Add $\frac{9}{2}$: $4 = 5$.

The check:

1. Step 3 is valid: $\left(4 - \frac{9}{2}\right)^2 = 16 - 36 + \frac{81}{4}$ and $\left(5 - \frac{9}{2}\right)^2 = 25 - 45 + \frac{81}{4}$. Both sides equal $\frac{1}{4}$.
2. Step 4 uses the rule "$x^2 = y^2$ implies $x = y$". This rule is false, because [[squaring is not injective|Q07B3Q8Q5A]] on $\mathbb{R}$.
3. Here $x = -\frac{1}{2}$ and $y = \frac{1}{2}$. Then $x^2 = y^2 = \frac{1}{4}$, but $x \neq y$.
4. The correct rule is: $x^2 = y^2$ holds exactly when $x = y$ or $x = -y$, because $x^2 - y^2 = (x - y)(x + y)$.
5. An equivalent form is $\sqrt{x^2} = |x|$, with the [[absolute value|0FFXKTKKQC]]. So step 4 gives only $\left|4 - \frac{9}{2}\right| = \left|5 - \frac{9}{2}\right|$, which is true.

### Complex powers

Define $z^w = e^{w \operatorname{Log} z}$ for complex $z \neq 0$ and $w$, where $\operatorname{Log}$ is the principal [[complex logarithm|02QGGD5G87]], with imaginary part in $(-\pi, \pi]$.

The argument:

1. $e^{2\pi i} = \cos 2\pi + i \sin 2\pi = 1$.
2. Raise both sides to the power $i$: $\left(e^{2\pi i}\right)^i = 1^i$.
3. Use $(e^a)^b = e^{ab}$: the left side is $e^{2\pi i \cdot i} = e^{-2\pi}$.
4. The right side is $1^i = e^{i \operatorname{Log} 1} = e^0 = 1$.
5. So $e^{-2\pi} = 1$.

The check:

1. Step 1 is valid by Euler's formula $e^{i\theta} = \cos\theta + i\sin\theta$.
2. Step 2 is valid: both sides are the power $1^i$, so both equal $1$ by step 4.
3. Step 3 is invalid. By the definition, $\left(e^{a}\right)^b = e^{b \operatorname{Log}(e^a)}$, and $\operatorname{Log}(e^a) = a$ only when the imaginary part of $a$ is in $(-\pi, \pi]$.
4. Here $a = 2\pi i$, whose imaginary part $2\pi$ is not in $(-\pi, \pi]$. In fact $\operatorname{Log}(e^{2\pi i}) = \operatorname{Log} 1 = 0$, not $2\pi i$.
5. So the correct value is $\left(e^{2\pi i}\right)^i = e^{i \cdot 0} = 1$, and $e^{-2\pi} \approx 0.00187$ is a different number.

### Logarithms

The argument:

1. $(-1)^2 = 1$, so $\operatorname{Log}\left((-1)^2\right) = \operatorname{Log} 1 = 0$.
2. Use $\operatorname{Log}(z^2) = 2 \operatorname{Log} z$: $\operatorname{Log}\left((-1)^2\right) = 2 \operatorname{Log}(-1) = 2\pi i$.
3. So $0 = 2\pi i$.

The check:

1. $\operatorname{Log}(-1) = \pi i$, because $e^{\pi i} = -1$ and $\pi \in (-\pi, \pi]$.
2. The rule $\operatorname{Log}(z^2) = 2\operatorname{Log} z$ holds exactly when $2 \operatorname{Log} z$ has imaginary part in $(-\pi, \pi]$, that is, when $\arg z \in (-\pi/2, \pi/2]$.
3. For $z = -1$ the principal argument is $\pi$, which is not in $(-\pi/2, \pi/2]$. So step 2 is invalid.

## Remarks

### What the examples show

Each rule fails because a function is chosen from several possible values.
The equation $w^2 = t$ has two solutions for $t > 0$, and $\sqrt{t}$ picks the non-negative one.
The equation $e^w = z$ has infinitely many solutions $w$, which differ by multiples of $2\pi i$, and $\operatorname{Log} z$ picks one of them.
A rule such as $\sqrt{ab} = \sqrt{a}\sqrt{b}$ says that the chosen values match, and the choice does not respect products for all inputs.

### The multivalued view

If $\log z$ denotes the set of all $w$ with $e^w = z$, then $\log 1 = \{2\pi i k : k \in \mathbb{Z}\}$ and $2\log(-1) = \{(4k + 2)\pi i : k \in \mathbb{Z}\}$.
So $2\pi i$ is one of the values of $\log 1$, and the "contradiction" $0 = 2\pi i$ comes from equating two different values of one multivalued function.
In the same way, $1^i$ has the values $e^{i \cdot 2\pi i k} = e^{-2\pi k}$, and $e^{-2\pi}$ is the value with $k = 1$.

### How the examples change

If we replace $-1$ by a positive number in the first argument, every step is valid: $\sqrt{4} = \sqrt{2}\sqrt{2}$.
If we replace $2\pi i$ by $\pi i / 2$ in the third argument, then $\operatorname{Log}(e^{\pi i/2}) = \pi i/2$, and the rule of step 3 holds: $\left(e^{\pi i/2}\right)^i = e^{-\pi/2}$.

## Explanations

### L1 human

Every positive number has two square roots: $9$ has the roots $3$ and $-3$.
The symbol $\sqrt{9}$ means only the positive one, $3$.
Many false proofs forget the other root.
For example, $(-3)^2 = 9$ and $3^2 = 9$, but this does not mean that $-3 = 3$.
Taking square roots of both sides of an equation is safe only when we know the signs of both sides.

### L2 human

We decide for which real $a$ the equation $\sqrt{a^2} = a$ holds, and we use it to repair a false step.

1. For $a \ge 0$, the number $a$ is non-negative and its square is $a^2$, so $\sqrt{a^2} = a$.
2. For $a < 0$, the number $-a$ is positive and its square is $a^2$, so $\sqrt{a^2} = -a$.
3. Together: $\sqrt{a^2} = |a|$ for every real $a$, and $\sqrt{a^2} = a$ exactly when $a \ge 0$.
4. A false step "$\sqrt{(1 - 3)^2} = 1 - 3$" gives $2 = -2$. By step 3 the correct value is $|1 - 3| = 2$.

The typical use of this rule is in the simplification of roots: $\sqrt{x^2 y} = |x|\sqrt{y}$ for $y \ge 0$.
A trap is the formula $\sqrt{x^2} = x$ in a calculation where $x$ can be negative, for example $x = \cos t$ on an interval where the cosine changes sign.

### L3 human

The rules for roots and logarithms are statements about branches of multivalued functions.
The map $z \mapsto z^2$ is a surjective homomorphism of the multiplicative group $\mathbb{C}^\times$ with kernel $\{1, -1\}$, and $\exp$ is a surjective homomorphism from $(\mathbb{C}, +)$ onto $\mathbb{C}^\times$ with kernel $2\pi i\mathbb{Z}$.
A homomorphic section of $z \mapsto z^2$ would split $\mathbb{C}^\times$ as a direct product with $\{1, -1\}$ as a factor, and this is impossible because $\mathbb{C}^\times$ is divisible.
So no choice of square root on $\mathbb{C}^\times$ is multiplicative, and no choice of logarithm is additive; the fallacies are concrete witnesses of these facts.
On the positive reals, squaring on $(0, \infty)$ and $\exp$ on $\mathbb{R}$ are bijections onto $(0, \infty)$, so their inverses $\sqrt{\ }$ and $\ln$ are homomorphisms, and the rules hold there.
