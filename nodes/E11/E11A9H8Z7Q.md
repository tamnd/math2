## Statement

McNaughton's theorem lists exactly which functions the formulas of Łukasiewicz logic can compute: the continuous ones made of finitely many linear pieces with integer coefficients.

Fix $n \ge 1$.
Each formula $\varphi(p_1, \dots, p_n)$ of [[infinite-valued Łukasiewicz logic|JQ713VVD0G]] defines a function $f_\varphi \colon [0, 1]^n \to [0, 1]$, whose value at $x$ is the value of $\varphi$ under the valuation $p_i \mapsto x_i$.
A *McNaughton function* is a map $f \colon [0, 1]^n \to [0, 1]$ with two properties.

1. The map $f$ is continuous.
2. There are finitely many affine functions $g_j(x) = m_{j0} + m_{j1} x_1 + \dots + m_{jn} x_n$, with all $m_{ji} \in \mathbb{Z}$, such that for each $x$ we have $f(x) = g_j(x)$ for some $j$.

**Theorem.**
A function $f \colon [0, 1]^n \to [0, 1]$ is $f_\varphi$ for some formula $\varphi$ if and only if $f$ is a McNaughton function.

## Remarks

### A first case

Take $f(x) = \lvert 2x - 1 \rvert$ on $[0, 1]$.
It is continuous, and its pieces $2x - 1$ and $1 - 2x$ have integer coefficients, so the theorem says that some formula defines it.
[[The worked example|1PMN1CASZG]] finds one, $(p \odot p) \oplus (\neg p \odot \neg p)$.
Check at $x = 0.2$: $0.2 \odot 0.2 = 0$ and $0.8 \odot 0.8 = 0.6$, and $\lvert 0.4 - 1 \rvert = 0.6$.

### Why each condition is needed

Continuity is needed.
The function that is $0$ on $[0, \tfrac12]$ and $1$ on $(\tfrac12, 1]$ has integer pieces, but every $f_\varphi$ is continuous, so no formula defines it.

Integer coefficients are needed, and this includes the constant term $m_{j0}$.
The constant $\tfrac12$ is continuous and affine, but every $f_\varphi$ sends $(0, \dots, 0)$ into $\{0, 1\}$, because the connectives keep $\{0, 1\}$ closed.

The codomain $[0, 1]$ matters too.
The function $2x$ has integer coefficients but leaves $[0, 1]$, while its truncation $\min(1, 2x) = x \oplus x$ is definable.

### What it gives you

The truth function of a formula is made of finitely many linear pieces, so Łukasiewicz logic responds to the actual sizes of values, not only to their order.
Every McNaughton function maps rational points to rational points and maps $\{0, 1\}^n$ into $\{0, 1\}$.
With pointwise operations, the functions $f_\varphi$ form the free MV-algebra on $n$ generators; this step uses [[Chang's completeness theorem|QM0F33QE9P]].

### The converse and generalizations

The theorem is an equivalence.
The direction "definable implies McNaughton" is the easy part, an induction on formulas.
The [[proof|KANQ0PQSN4]] of the other direction is constructive: from the pieces of $f$ it builds a formula.
Adding truth constants for the rationals, as in [[rational Pavelka logic|YG62F8YC0P]], makes functions such as the constant $\tfrac12$ definable, so the integer condition is a feature of the pure language.

## History

McNaughton published the theorem in 1951.
The book of Cignoli, D'Ottaviano and Mundici uses it as a main tool for the study of free MV-algebras.

## Explanations

### L1 human

A formula of Łukasiewicz logic is a recipe that turns input values into an output value.
McNaughton's theorem lists all the recipes that formulas can produce.
They are the continuous functions made of finitely many straight pieces, each with whole-number slopes and a whole-number offset.
So $\min(1, 2x)$ is a recipe, and $x / 2$ is not.

### L2 human

To show that a function is not definable, find a point where it jumps, or a piece with a coefficient that is not an integer.
To show that a function is definable, check continuity and list its pieces; then the proof gives a formula.
Take $f(x, y) = \max(0, x - y)$ on $[0, 1]^2$.
It is continuous, and its pieces $0$ and $x - y$ have integer coefficients, so it is definable.
Indeed $\neg y \odot x$ has the value $\max(0, (1 - y) + x - 1) = \max(0, x - y)$.
Watch out: the offset must be an integer too, so $x + \tfrac12$ is not a piece, even on a small region.

### L3 human

The easy direction is an induction: $1 - f$ and $\min(1, f + g)$ are McNaughton functions when $f$ and $g$ are.
The hard direction has two parts.
First, the truncation $\max(0, \min(1, g))$ of each integer affine $g$ is definable, by induction on the coefficients.
Second, every continuous piecewise affine function on a convex set is a maximum of minima of its pieces.
Truncation commutes with $\max$ and $\min$, and both are definable, so $f$ is definable.
Together with Chang's theorem, this identifies the free MV-algebras concretely, and that link between logic and polyhedral geometry runs through the later theory of MV-algebras.
