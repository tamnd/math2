## Example

Let $f \colon \R^3 \to \R$ be the linear map $f(x, y, z) = x + y + z$, and let
$$U = \{(x, y, z) \in \R^3 : x + y + z = 0\}.$$
We show that the [[quotient space|0SVR29SV1V]] $\R^3 / U$ is isomorphic to $\R$, by the [[first isomorphism theorem|0MTBGVZ4XJ]], and we check each step by hand.

1. The map $f$ is linear, since it is given by the $1 \times 3$ matrix $\begin{pmatrix} 1 & 1 & 1 \end{pmatrix}$.
2. The [[kernel|02YFME3RGW]] of $f$ is $U$, by the definition of $U$.
3. The [[image|0JB228DCWB]] of $f$ is all of $\R$, since $f(t, 0, 0) = t$ for every $t \in \R$.
4. The theorem gives the map $\bar f \colon \R^3 / U \to \R$, $\bar f(v + U) = f(v)$, and says that it is an [[isomorphism|0XSJ25Z9M4]].
5. The map is well defined on a sample coset.
   We have $(1, 0, 0) + U = (0, 1, 0) + U$, since the difference $(1, -1, 0)$ satisfies $1 - 1 + 0 = 0$ and so lies in $U$.
   Both representatives give $f = 1$.
6. The map is injective.
   If $\bar f(v + U) = 0$, then $f(v) = 0$, so $v \in U$ and $v + U$ is the zero coset $U$.
7. The map is surjective, since $\bar f\bigl((t, 0, 0) + U\bigr) = t$ for every $t$.

So $\R^3 / U$ is a line.
Its points are the parallel planes $x + y + z = c$, and the number $c$ labels each of them.

## Remarks

The coset of $(x, y, z)$ is the plane through $(x, y, z)$ parallel to $U$, that is, the plane $x + y + z = c$ with $c = x + y + z$.
The count $\dim(\R^3 / U) = 3 - 2 = 1$ agrees with the [[dimension of a quotient space|0SXDQ6TN00]].
The line $\R(1, 1, 1)$ is a complement of $U$, and it meets the plane $x + y + z = c$ in the single point $\tfrac{c}{3}(1, 1, 1)$.
So this line gives one representative in each coset.

If we replace $f$ by $g(x, y, z) = x + 2y$, the same reasoning shows that $\R^3$ modulo the plane $x + 2y = 0$ is again a line.
Any nonzero linear map $\R^3 \to \R$ has a plane as its kernel, and the quotient by that plane is always one-dimensional.

## Explanations

### L1 human

The sum $x + y + z$ has the same value at every point of a plane parallel to $U$.
So each such plane gets a label, the common value of $x + y + z$.
Different planes get different labels, and every number is used.
So the set of planes is like a number line.

### L2 human

The isomorphism $\bar f$ turns an abstract set of planes into the concrete line $\R$.
To add the planes $x + y + z = 2$ and $x + y + z = 5$, pick a point on each, say $(2, 0, 0)$ and $(0, 5, 0)$, and add:
$$(2, 0, 0) + (0, 5, 0) = (2, 5, 0), \qquad 2 + 5 + 0 = 7.$$
So the sum is the plane $x + y + z = 7$.
Check with other points, $(1, 1, 0)$ and $(0, 0, 5)$: their sum $(1, 1, 5)$ also has coordinate sum $7$.
This is the typical use of the first isomorphism theorem: to identify $V / U$, find a surjective linear map with kernel $U$.
