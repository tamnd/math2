## Proof

We prove [[Harrop's theorem|VSYQ1AZ9G7]] for $\Lambda = \mathsf{K}\Gamma$ with $\Gamma$ finite and with the finite model property, by running two procedures $A$ and $B$ in parallel on an input $\varphi$: $A$ looks for a proof, and $B$ looks for a finite countermodel.

### Procedure A: the theorems

1. $\Lambda$ is the set of theorems of the [[Hilbert system|1MGMQX43B8]] with the rules modus ponens and necessitation.
   Its axioms are tautology instances, instances of $\mathrm{K}$ and instances of the formulas of $\Gamma$.
2. Whether a formula is a tautology instance is decidable by truth tables, after the maximal non-propositional subformulas are read as letters.
   Whether it is an instance of one of the finitely many formulas of $\mathrm{K}$ and $\Gamma$ is decidable by matching.
   This is where the finiteness of $\Gamma$ is used.
3. So we can decide whether a finite list of formulas is a derivation.
   Procedure $A$ lists all finite lists in turn and stops when it finds a derivation whose last line is $\varphi$.

### Procedure B: the finite countermodels

4. Procedure $B$ lists all pairs $(\mathfrak{F}, V)$, where $\mathfrak{F}$ is a frame with domain $\{ 1, \dots, k \}$ for some $k \geq 1$ and $V$ is a valuation of the variables of $\varphi$.
5. For each pair, $B$ first tests whether each $\gamma \in \Gamma$ is valid on $\mathfrak{F}$.
   The test is finite: there are $2^{km}$ valuations of the $m$ variables of $\gamma$, and truth at each world is computed by the clauses of Kripke semantics.
6. If $\mathfrak{F}$ passes, $B$ tests whether $\varphi$ is false at some world of $(\mathfrak{F}, V)$, and it stops if so.

### Correctness and termination

7. If $A$ stops, then $\Lambda \vdash \varphi$, by the definition of $\Lambda$.
8. If $B$ stops at $(\mathfrak{F}, V)$, then $\mathfrak{F}$ validates $\Gamma$.
   By [[soundness|E87G6ZTMTN]], $\mathfrak{F}$ validates every theorem of $\mathsf{K}\Gamma$, and $\varphi$ fails on $\mathfrak{F}$, so $\Lambda \nvdash \varphi$.
9. If $\Lambda \vdash \varphi$, a derivation exists, and $A$ finds it.
10. If $\Lambda \nvdash \varphi$, the finite model property in the frame form of [[the definition|K12PSCFX3Y]] gives a finite $\Lambda$-frame $\mathfrak{F}$ and a valuation where $\varphi$ fails.
    This is where the FMP is used.
    Such an $\mathfrak{F}$ validates $\Gamma \subseteq \Lambda$, and an isomorphic copy on $\{ 1, \dots, k \}$ occurs in the list of $B$ with a valuation that refutes $\varphi$, so $B$ stops.
11. By steps 7 to 10, exactly one of $A$ and $B$ stops, and its answer is correct.
    Running them in parallel, one step of each in turn, decides whether $\Lambda \vdash \varphi$.

## Idea

The theorems form a computably enumerable set because there are finitely many axiom schemes to match.
The non-theorems form a computably enumerable set because each has a finite witness, a finite frame of the logic.
The finite axiom set is what lets us check that a finite frame is a frame of the logic.

## Variants

For the general form, procedure $A$ uses the recursive axiom set, and procedure $B$ uses the given enumeration of finite $\Lambda$-frames instead of the test of step 5.

With a computable bound $f$ on the size of countermodels, procedure $B$ alone decides $\Lambda$.
If no frame with at most $f(\lvert \varphi \rvert)$ worlds refutes $\varphi$, then $\Lambda \vdash \varphi$.
