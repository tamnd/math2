## Example

Let $P_3$ be the real [[polynomials|0Q9EZS90GY]] of degree at most $3$, and $P_2$ those of degree at most $2$.
Let $D \colon P_3 \to P_2$ be differentiation, $D(p) = p'$, and let $W \subseteq P_3$ be the subspace of constant polynomials.
We apply the [[universal property of the quotient|0ZERJX6PH6]] to $D$ and $W$, and we show that the induced map is an isomorphism.

1. The map $D$ is linear, since $(p + q)' = p' + q'$ and $(ap)' = a p'$.
2. Every constant $c$ has $D(c) = 0$, so $W \subseteq \ker D$.
   Conversely, $D(a_0 + a_1 x + a_2 x^2 + a_3 x^3) = a_1 + 2a_2 x + 3a_3 x^2$ is zero only when $a_1 = a_2 = a_3 = 0$, so $\ker D = W$.
3. The universal property gives a linear map $\bar D \colon P_3 / W \to P_2$ with $\bar D(p + W) = p'$ and $\bar D \circ \pi = D$, where $\pi$ is the [[quotient map|0J0SK5FF4M]].
4. The map is well defined on a sample coset.
   We have $(x^3 + 2x + 5) + W = (x^3 + 2x - 1) + W$, since the difference is the constant $6$.
   Both representatives have derivative $3x^2 + 2$.
5. The map $\bar D$ is injective.
   If $\bar D(p + W) = 0$, then $p' = 0$, so $p$ is constant by step 2, and $p + W = 0 + W$.
6. The map $\bar D$ is surjective, since every $a + bx + cx^2$ in $P_2$ is a derivative:
   $$D\Bigl(ax + \frac{b}{2} x^2 + \frac{c}{3} x^3\Bigr) = a + bx + cx^2.$$
7. So $\bar D$ is an [[isomorphism|0XSJ25Z9M4]] $P_3 / W \cong P_2$.
   Check with dimensions: $\dim(P_3 / W) = 4 - 1 = 3 = \dim P_2$.

## Remarks

The inverse of $\bar D$ sends a quadratic $q$ to the coset of any antiderivative of $q$.
This is the linear algebra behind the constant of integration.
An antiderivative is defined only up to a constant, so it is really an element of $P_3 / W$, not of $P_3$.
For instance, $\bar D^{-1}(3x^2 + 2)$ is the coset $(x^3 + 2x) + W$, which contains $x^3 + 2x + c$ for every $c$.

If we divide by a smaller subspace, the induced map stops being injective.
With $W = \{0\}$, the map $\bar D$ is just $D$, and its kernel is the line of constants.
With a larger subspace, such as the polynomials of degree at most $1$, the universal property does not apply, because $D(x) = 1 \ne 0$.

## Explanations

### L1 human

Two polynomials that differ by a constant have the same derivative.
So differentiation never needs to know the constant term.
That means it is really a rule on "polynomials up to a constant", and on those it loses no information at all.

### L2 human

The step that needs care is step 4: a formula on cosets must give the same value for every representative.
Here every representative of $p + W$ has the form $p + c$ for a constant $c$, and
$$(p + c)' = p' + 0 = p',$$
so the check holds for all cosets at once.
This is the typical use of the universal property: a linear map that kills a subspace $W$ becomes a map on $V / W$, and if its kernel is exactly $W$, the new map is injective.
