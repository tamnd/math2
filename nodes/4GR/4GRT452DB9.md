## Example

In [[Zermelo-Fraenkel set theory|0HE5WDQ9FJ]] (ZF), the set $\N$ with its usual $0$, successor, addition and multiplication is a model of [[Peano arithmetic|0QFT7Z76N5]].
By the [[soundness theorem|AVD7T7J063]], a theory with a model does not prove $0 = 1$.
So ZF proves $\operatorname{Con}(\mathrm{PA})$.
We check the three results of an [[ordinal analysis|57PTMS2ADY]].

1. Notation system: the proof uses none.
2. Lower bound: the proof says nothing about which transfinite inductions PA proves.
3. Upper bound: the proof says nothing about which orders PA cannot prove well-founded.

So this proof is not an ordinal analysis of PA.

## Remarks

The proof is correct, but it uses far more than PA.
It uses the existence of the infinite set $\N$ and the truth of all arithmetic statements in it.
Gentzen's proof uses only primitive recursive reasoning and one principle of transfinite induction, and it measures exactly how much PA needs.
The same contrast holds for every model-theoretic consistency proof: it shows that a theory is consistent, but not how strong it is.

## Explanations

### L1 human

One can prove that arithmetic is free of contradictions by pointing at the natural numbers: they satisfy all the axioms, so the axioms cannot contradict each other.
This argument is correct, but it uses a much stronger theory.
It does not tell us how strong arithmetic itself is, and that is what an ordinal analysis measures.

### L2 human

We compare what the two proofs need.

1. The ZF proof needs the truth definition for all arithmetic formulas in $\N$, which PA cannot define.
2. Gentzen's proof needs PRA and quantifier-free transfinite induction along a primitive recursive order of type $\varepsilon_0$.
3. PRA is much weaker than PA, and the added induction is exactly what PA cannot prove.

So Gentzen's proof locates the strength of PA, while the ZF proof only confirms consistency.
The trap: both are "consistency proofs", but only one of them is an analysis.
