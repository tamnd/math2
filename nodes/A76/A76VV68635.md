## Example

Let $e_0, e_1$ be the standard basis of $\C^2$.
The *GHZ state* of three qubits is the unit vector
$$\psi = \frac{1}{\sqrt{2}}\big(e_0 \otimes e_0 \otimes e_0 + e_1 \otimes e_1 \otimes e_1\big)$$
in the [[tensor product|EY0X2NKA3S]] $\C^2 \otimes \C^2 \otimes \C^2$.
It is [[entangled|CHNXT8CCK7]].
Indeed, a product vector $u \otimes v \otimes w$ has coefficients $c_{ijk} = u_i v_j w_k$, so $c_{000} c_{111} = c_{001} c_{110}$.
For $\psi$ the left side is $1/2$ and the right side is $0$.
With the [[Pauli matrices|XAQCW3D4QQ]] $X$ and $Y$, one checks $(X \otimes X \otimes X)\psi = \psi$.
Since $Y e_0 = i e_1$ and $Y e_1 = -i e_0$, also $(X \otimes Y \otimes Y)\psi = (Y \otimes X \otimes Y)\psi = (Y \otimes Y \otimes X)\psi = -\psi$.

## Remarks

These four eigenvalue equations give the GHZ argument against local [[hidden-variable theories|QRW6NE1VY7]].
Suppose each qubit $k$ carries predetermined values $x_k, y_k \in \set{-1, 1}$ for the measurements of $X$ and $Y$.
The last three equations force $x_1 y_2 y_3 = y_1 x_2 y_3 = y_1 y_2 x_3 = -1$.
Multiplying them gives $x_1 x_2 x_3 = -1$, since each $y_k^2 = 1$.
The first equation forces $x_1 x_2 x_3 = 1$, a contradiction without any inequality.
For $n$ qubits the GHZ state is $(e_0^{\otimes n} + e_1^{\otimes n})/\sqrt2$.
Tracing out one qubit of the three-qubit GHZ state leaves a separable mixed state, so its entanglement is destroyed by losing one particle.

## Explanations

### L1 human

The GHZ state is three qubits that are either all $0$ or all $1$, in an equal superposition.
It is the simplest example where quantum predictions contradict local predetermined answers in every single run, not only on average.
Measuring one qubit in the standard basis fixes the other two completely.
