## Summary

Holography records a light wave with its phase, not only its intensity, and later rebuilds the same wave.
The object wave is made to interfere with a known reference wave, and the recording medium stores the resulting fringe pattern.
Lit again by the reference wave, the recorded pattern diffracts light into a copy of the original object wave.
Dennis Gabor introduced the method, and it gives three-dimensional images as well as tools for measurement and data storage.

## Explanations

### L1 human

An ordinary photograph keeps only how bright each point is, so the depth of the scene is lost.
A hologram also keeps how far the light has travelled, by mixing the light from the object with a clean beam from the same laser.
The two beams make a fine pattern of stripes, too fine to see, and this pattern is what is recorded.
When the same clean beam later shines on the pattern, the stripes bend the light so that it leaves exactly as it came from the object.
Looking through the hologram, one sees the object in three dimensions and can look around it.
