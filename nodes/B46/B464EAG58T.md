## Example

Let $\mathsf{Ver} = \mathsf{K} + \square\bot$, as in [[the trivial logic and the verum logic|5PZCVXYXDD]].
We compute its [[canonical model|TVE4F04KME]] completely, and we get a decision method from it.

### The canonical frame

Recall that $\Gamma R^c \Delta$ holds when $\square\psi \in \Gamma$ implies $\psi \in \Delta$.
Every maximal [[consistent|VM8TQ70CVJ]] set $\Gamma$ contains the axiom $\square\bot$.
So if $\Gamma R^c \Delta$, then $\bot \in \Delta$, which contradicts the consistency of $\Delta$.
So $R^c$ is empty, and the canonical frame has no arrows at all.

### Completeness

Now let $\mathsf{Ver} \nvdash \varphi$.
[[Lindenbaum's lemma|SC0BSJ3GT6]] gives a maximal consistent $\Gamma$ with $\neg\varphi \in \Gamma$, and by the [[truth lemma|NM4CB7QAYT]] $\varphi$ is false at $\Gamma$ in the canonical model.
So $\mathsf{Ver}$ is complete for the frames with empty relation.
These frames validate $\square\bot$, since $\square\psi$ is true at every world without successors.
With [[soundness|E87G6ZTMTN]], $\mathsf{Ver}$ is exactly the logic of frames with empty relation.

### A decision method
Define $\varphi^*$ by replacing each outermost subformula $\square\psi$ of $\varphi$ by $\top$, so that $\varphi^*$ has no boxes.
On a frame with empty relation, each $\square\psi$ is true at each world, so $\varphi$ and $\varphi^*$ have the same truth value everywhere.
If $\varphi^*$ is a [[tautology|05006AJ7DZ]], then $\varphi$ is valid on these frames, and $\mathsf{Ver} \vdash \varphi$ by completeness.
If $\varphi^*$ is not a tautology, a one-world model with empty relation that copies a falsifying assignment refutes $\varphi$, so $\mathsf{Ver} \nvdash \varphi$.
So $\mathsf{Ver} \vdash \varphi$ exactly when $\varphi^*$ is a tautology, and truth tables decide $\mathsf{Ver}$.

### Check

Check: take $\varphi = \square p \to (\lozenge q \to r)$, where $\lozenge q$ abbreviates $\neg\square\neg q$.
Then $\varphi^* = \top \to (\neg\top \to r)$.
Since $\neg\top$ is false, $\neg\top \to r$ is true, so $\varphi^*$ is a tautology and $\mathsf{Ver} \vdash \varphi$.

## Remarks

### A syntactic proof of the same fact

The reduction to $\varphi^*$ can also be proved inside the logic.
$\mathsf{Ver}$ proves $\square\psi \leftrightarrow \top$ for every $\psi$, since $\square\bot \to \square\psi$ follows from $\bot \to \psi$ by necessitation and axiom $\mathrm{K}$.
Replacement of equivalents then gives $\mathsf{Ver} \vdash \varphi \leftrightarrow \varphi^*$.

### How many worlds

The canonical model has one world for each assignment of truth values to the variables.
At a world without successors only the variables matter, so two maximal consistent sets that agree on all variables are equal.

### Nearby logics

For the trivial logic $\mathsf{K} + (\square p \leftrightarrow p)$ the same method works with $\square\psi$ replaced by $\psi$, and the canonical relation is the identity.
If we replace $\square\bot$ by $\square\square\bot$, the canonical relation is no longer empty, but no world starts a path of length 2.

### Watch out

The translation $\varphi^*$ replaces the boxed subformulas only.
So $\lozenge q = \neg\square\neg q$ becomes $\neg\top$, not $\top$: in this logic $\lozenge q$ is always false.

## Explanations

### L1 human

In the verum logic, "necessarily $p$" is always true, whatever $p$ says.
In a picture, this means that no world sees any other world, or itself.
So to decide whether a formula is a law, we replace every "necessarily ..." part by "true".
What remains is an ordinary formula, and a truth table decides it.
For example, "necessarily $p$, or $q$" becomes "true, or $q$", which is always true.

### L2 human

This is the one canonical model that you can write down in full.
Every step of the general method can be checked by hand here: the worlds are the assignments to the variables, the relation is empty, and the truth lemma reduces to the truth table of the box-free part.
The typical use of the example is as a first exercise with canonical models.
Try $\varphi = \lozenge p \vee q$.
Then $\varphi^* = \neg\top \vee q$, which is false when $q$ is false, so $\mathsf{Ver} \nvdash \lozenge p \vee q$.
