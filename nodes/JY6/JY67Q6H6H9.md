## Example

Let $\mathcal{N} = (\mathbb{N}, +)$ be the [[natural numbers|0MWKJ44V5A]] with addition only, and let $\varphi(x) = \exists y \, (y + y = x)$.
We show that $\varphi$ defines the set $E$ of even numbers.

1. Let $a \in \mathbb{N}$.
   By the clause for $\exists$, $\mathcal{N} \models \varphi[a]$ holds if and only if some $b \in \mathbb{N}$ gives $\mathcal{N} \models (y + y = x)[a, b]$, with $x \mapsto a$ and $y \mapsto b$.
2. By the clause for equality, this holds if and only if $b + b = a$, that is, $a = 2b$ for some $b \in \mathbb{N}$.
3. So $\mathcal{N} \models \varphi[a]$ holds if and only if $a$ is even.

So $E$ is a [[definable relation|1DQ1M6ZWS4]] of $\mathcal{N}$ without parameters.

## Remarks

The same idea defines more in $(\mathbb{N}, +)$.
The number $0$ is defined by $x + x = x$, and the order $\le$ by $\exists z \, (x + z = y)$.
Then $1$ is defined as the least nonzero element, so by adding $1$ repeatedly, every natural number is $\emptyset$-definable in $(\mathbb{N}, +)$.
Not every set is definable, though.
By the quantifier elimination for Presburger arithmetic, the definable subsets of $\mathbb{N}$ in $(\mathbb{N}, +)$ are exactly the eventually periodic sets, so the set of squares, whose gaps grow, is not definable there.

## Explanations

### L1 human

In the natural numbers with only plus, a number is even exactly when it is some number plus itself.
For example, $10 = 5 + 5$, but $3$ is not $0 + 0$, $1 + 1$ or any larger double.
That description uses only plus, so it is a formula of the language.

### L2 human

We check the formula on two inputs.
For $x \mapsto 10$, the witness $y \mapsto 5$ gives
$$5 + 5 = 10,$$
so $\varphi[10]$ holds.
For $x \mapsto 3$, the values $y = 0$ and $y = 1$ give $0$ and $2$, and every $y \ge 2$ gives at least $4$, so $\varphi[3]$ fails.
The typical use is to define arithmetic notions inside a weak structure.
Watch out: the term $2 \cdot y$ is not allowed, because neither the symbol $\cdot$ nor the constant $2$ is in the signature.
