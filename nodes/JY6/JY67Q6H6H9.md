## Example

Let $\mathcal{N} = (\N, +)$ be the [[natural numbers|0MWKJ44V5A]] with addition only.
Let $\varphi(x) = \exists y \, (y + y = x)$.
We show that $\varphi$ defines the set $E$ of even numbers.

1. Let $a \in \N$. By the clause for $\exists$, $\mathcal{N} \models \varphi[a]$ if and only if some $b \in \N$ satisfies $\mathcal{N} \models (y + y = x)[a, b]$.
2. By the clause for equality, this holds if and only if $b + b = a$, that is, $a = 2b$.
3. So $\mathcal{N} \models \varphi[a]$ if and only if $a$ is even.

So $E$ is a [[definable relation|1DQ1M6ZWS4]] of $\mathcal{N}$ without parameters.

## Remarks

In the same way, $0$ is $\emptyset$-definable by $x + x = x$, and the order is $\emptyset$-definable by $\exists z \, (x + z = y)$.
Then $1$ is definable as the least nonzero element, so every natural number is $\emptyset$-definable in $(\N, +)$.
By Presburger's theorem, the definable subsets of $\N$ in $(\N, +)$ are exactly the eventually periodic sets; so the set of squares is not definable there.

## Explanations

### L1 human

In the natural numbers with only plus, a number is even exactly when it is some number plus itself.
That sentence uses only plus, so it is a formula of the language.

### L2 human

We check the formula on two inputs.

1. For $x \mapsto 10$, the witness $y \mapsto 5$ gives $5 + 5 = 10$, so $\varphi[10]$ holds.
2. For $x \mapsto 3$, the values $y = 0, 1$ give $0$ and $2$, and every $y \geq 2$ gives at least $4$. So $\varphi[3]$ fails.

The typical use is to define arithmetic notions inside a weak structure.
A trap is to use the term $2 \cdot y$; the symbol $\cdot$ and the constant $2$ are not in the signature.
