## Summary

In mathematical logic and graph theory, an **implication graph** is a skew-symmetric, [[directed graph|0KFYGSHHF5]] $G = (V, E)$ composed of vertex set $V$ and directed edge set $E$. Each vertex in $V$ represents the truth status of a Boolean literal, and each directed edge from vertex $u$ to vertex $v$ represents the [[material implication|0NMG7W7Q11]] "If the literal $u$ is true then the literal $v$ is also true". Implication graphs were originally used for analyzing complex Boolean expressions.
