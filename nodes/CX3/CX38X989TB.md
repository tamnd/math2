## Summary

To prove a universal statement "for every $x$ in a set $X$, $P(x)$", one lets $x$ be an arbitrary element of $X$ and proves $P(x)$ for that $x$.
The word "arbitrary" means that the proof uses no property of $x$ except that $x$ belongs to $X$, and that $x$ is a new letter that occurs in no hypothesis.
Then the same proof works for each element of $X$, and the statement holds for all of them.
This is called the generic element argument, and in logic it is the rule of [[universal generalization|BKQ3YD6SVZ]].
Most theorems are universal statements, so this is the first step of most proofs.

## Motivation

A set such as the integers or the real numbers has infinitely many elements, so no one can check them one by one.
A finite list of checks also proves nothing: the polynomial $n^2 + n + 41$ is prime for $n = 0, 1, \ldots, 39$, but [[not for $n = 40$|H75AB4EJT5]].
The way out is to reason about one element with a name, $x$, and to use only what is true of every element.
Then the argument is a template, and each element of the set can be put into it.

## Notation

A universal statement is written $\forall x \in X, \ P(x)$ with the [[universal quantifier|0B88PQTJ66]].
In mathematical writing the quantifier is often implicit, as in the identity $(a + b)^2 = a^2 + 2ab + b^2$; see [[quantifiers in mathematical writing|EGTZPA6QH3]].
A proof opens with a phrase such as "Let $x \in X$.", "Let $x$ be an arbitrary element of $X$." or "Fix $x \in X$."
For a statement "for all $x$, if $P(x)$ then $Q(x)$", the opening is "Let $x$ be such that $P(x)$."
In Lean the tactic `intro x` starts such a proof of a goal `∀ x, P x`.

## Remarks

### Examples

1. [[The polynomial x^2 - 2x + 2 is positive for every real x|77SJHGNFR8]]: for arbitrary $x$, $x^2 - 2x + 2 = (x - 1)^2 + 1 \geq 1$.
2. [[The intersection of two sets is a subset of each|SAHE0068ZZ]]: two universal quantifiers, one over sets and one over elements, each opened with "let".
3. For every integer $n$, the number $n(n + 1)$ is even. Let $n$ be an arbitrary integer, and use a [[proof by cases|0WCP0PVET6]] on the parity of $n$.
4. For every real $x$, $|x| \geq 0$. Let $x$ be real; if $x \geq 0$, then $|x| = x \geq 0$, and if $x < 0$, then $|x| = -x > 0$.
5. "For all $\varepsilon > 0$ there is $\delta > 0$ such that ..." starts with "Let $\varepsilon > 0$." The proof then chooses $\delta$ depending on this $\varepsilon$.

### Non-examples

1. [[Checking cases does not prove that 2^n > n^2|3K78AT7X0R]]: the inequality holds for $n = 1$ and for $n = 5, 6, 7$, but it fails for $n = 2, 3, 4$.
2. "Let $x = 3$. Then $x^2 - 2x + 2 = 5 > 0$." This fixes a specific element. It proves the statement for $x = 3$ only.
3. "Let $n$ be an arbitrary integer. Then $n = 2k$ for some $k$." This uses a property, evenness, that an arbitrary integer does not have. The element is no longer generic.

### Basic properties

1. The generic element may not appear in an open hypothesis. If the proof assumes "$x > 0$" earlier, then a conclusion about $x$ holds only for $x > 0$.
2. Inside a universal proof, existential witnesses may depend on the generic element. In "$\forall x \, \exists y$", the $y$ can be a function of $x$, as in the choice $\delta = \varepsilon / 2$.
3. A universal statement over the empty set is true, because there is no element to check. This is [[vacuous truth|FA6YZGR2SS]] in the language of conditionals.
4. To disprove a universal statement, one [[counterexample|0ED72CTBNP]] is enough, by the [[negation of a universal statement|0P3A06QNDP]].
5. Statements about all natural numbers can also be proved by [[mathematical induction|0ASJVEFA9J]], when the generic argument does not work directly.

### History

Euclid's proofs speak of one figure, for example "let $ABC$ be a triangle", and the reader understands that the argument applies to each triangle.
Gerhard Gentzen's natural deduction of 1934 states the rule exactly: a proof of $P(x)$ gives $\forall x \, P(x)$ when $x$ does not occur in any open assumption.
This side condition is the formal meaning of the word "arbitrary".

### Common errors

1. Proving a universal statement by examples. Ten or a million checks do not prove the statement for all elements.
2. Choosing a special element and calling it arbitrary, for example a figure that is accidentally isosceles. See [[a special figure is not a generic example|4KAG9W328V]].
3. Letting the generic element depend on something chosen later. In "$\exists y \, \forall x$", the $y$ must be chosen before $x$ and may not depend on $x$; see the [[order of quantifiers|EGTZPA6QH3]].

## Explanations

### L1 human

Suppose someone claims that each whole number times the next one is even.
We cannot check every number, because there are infinitely many.
Instead we think of "some number", call it $n$, and we do not say which one.
If $n$ is even, the product $n(n + 1)$ has an even factor; if $n$ is odd, then $n + 1$ is even.
Either way the product is even.
Since we used nothing special about $n$, the argument works for $5 \cdot 6 = 30$, for $8 \cdot 9 = 72$, and for every other pair.

### L2 human

We prove: for every real $x$ and every real $y$, if $x < y$, then $x < \frac{x + y}{2} < y$.

1. Let $x$ and $y$ be arbitrary real numbers with $x < y$. This opens both quantifiers and the hypothesis.
2. Add $x$ to both sides of $x < y$: $2x < x + y$.
3. Divide by $2 > 0$: $x < \frac{x + y}{2}$.
4. Add $y$ to both sides of $x < y$: $x + y < 2y$, so $\frac{x + y}{2} < y$.
5. Steps 3 and 4 give the conclusion for these $x$ and $y$.
6. We used only $x < y$ and the rules of inequalities, so the conclusion holds for all real $x$ and $y$ with $x < y$.

The typical use: open each universal quantifier and each hypothesis at the start, then prove the remaining goal by a [[direct proof|0NTF6DMVAP]].

A trap: a picture with $x = 1$ and $y = 3$ helps to find the proof, but it is not the proof.
Each step must hold for all $x < y$, including negative numbers and numbers very close together.

### L3 human

The rule of universal generalization has a side condition: the variable must not be free in any open assumption.
Without it, from the assumption $x = 0$ one could derive $\forall x \, (x = 0)$.
In type theory a proof of $\forall x : X, \, P(x)$ is a dependent function that sends each $x$ to a proof of $P(x)$, so a generic element is a bound variable of a function.
In category theory the same idea appears as the Yoneda lemma, where a natural transformation is fixed by its value on one generic element.
In algebraic geometry, a "generic point" makes the informal idea of a generic element precise for varieties, and the topic [[almost all, generic and in general|N1XSAXCQY3]] treats the related informal use of the word.
When a generic argument is not available, [[mathematical induction|0ASJVEFA9J]] and the [[well-ordering principle|01BX15HSRR]] give other ways to prove statements about all natural numbers.
