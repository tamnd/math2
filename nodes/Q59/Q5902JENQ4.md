## Proof

We check that $A^{-1}b$ is a solution by multiplying by $A$, show that any solution equals it by multiplying by $A^{-1}$, and then treat a matrix right side one column at a time.

**Part 1.** Let $b \in F^n$ and let $x_0 = A^{-1} b$.

1. By [[associativity|073E4XC016]], $Ax_0 = A(A^{-1} b) = (AA^{-1}) b$.
2. By the [[definition of the inverse|0TWTS88TWN]], $AA^{-1} = I_n$, and $I_n b = b$ because $I_n$ is the [[identity matrix|06DW9BAWB1]]. So $Ax_0 = b$, and $x_0$ is a solution.
3. Let $x$ be any solution, so $Ax = b$.
4. Multiply on the left by $A^{-1}$: $A^{-1}(Ax) = A^{-1} b$.
5. By associativity and $A^{-1}A = I_n$, the left side is $(A^{-1}A)x = I_n x = x$. So $x = A^{-1} b = x_0$.
6. Steps 2 and 5 show that $x_0$ is a solution and that each solution equals $x_0$.

**Part 2.**

7. A matrix $X$ satisfies $AX = B$ exactly when each column $x_j$ of $X$ satisfies $Ax_j = b_j$, by the column rule of the matrix product. Here $b_j$ is column $j$ of $B$.
8. By part 1, $x_j = A^{-1} b_j$ for each $j$, and this is column $j$ of $A^{-1} B$. So $X = A^{-1} B$ is the unique solution.

## Idea

Existence and uniqueness use the two halves of the definition of the inverse.
The equation $AA^{-1} = I_n$ shows that $A^{-1}b$ works.
The equation $A^{-1}A = I_n$ shows that nothing else works, because it lets us cancel $A$ from the left of $Ax = b$.
So the inverse turns "solve the system" into "multiply once".

## Variants

Part 2 can also be proved without columns, by the same steps 1 to 6 with the matrix $B$ in place of the vector $b$.
Uniqueness can also be phrased through the homogeneous system: if $Ax = b$ and $Ay = b$, then $A(x - y) = 0$, so $x - y = A^{-1}A(x - y) = 0$.
For a square matrix each half of the definition is enough on its own, by the theorem on [[one-sided inverses|0753Y2X5K6]], but this proof uses both halves and so does not need that theorem.
