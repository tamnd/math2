## Problem

Let $E$ be a finite set, and let $M_1 = (E, \mathcal{I}_1)$ and $M_2 = (E, \mathcal{I}_2)$ be two [[matroids|PX31ZNYS3Z]] on $E$.
A *common independent set* is a set $I \subseteq E$ with $I \in \mathcal{I}_1 \cap \mathcal{I}_2$.
The *matroid intersection problem* asks for a common independent set with the largest number of elements.
In the weighted version, a weight $w \colon E \to \R$ is given, and the goal is a common independent set $I$ of largest weight $\sum_{e \in I} w(e)$.
The matroids are given by independence oracles, which answer whether a given set is independent.

## Remarks

Edmonds proved the min-max formula
$$\max \set{ \abs{I} : I \in \mathcal{I}_1 \cap \mathcal{I}_2 } = \min_{A \subseteq E} \big( r_1(A) + r_2(E \setminus A) \big),$$
where $r_1$ and $r_2$ are the [[rank functions|SYRCTH853H]] of $M_1$ and $M_2$.
Both the unweighted and the weighted versions can be solved with a polynomial number of oracle calls, by augmenting paths in an exchange graph.
Maximum [[matching|0MJ04A50QW]] in a [[bipartite graph|0ZVQKTRKVQ]] with sides $X$ and $Y$ is a special case.
Take $E$ the edge set, $M_1$ the matroid whose independent sets use each vertex of $X$ at most once, and $M_2$ the same for $Y$.
Then the common independent sets are exactly the matchings, and the formula becomes [[Kőnig's theorem|0JP0ZF57PN]].
Arborescences and common transversals are other special cases.
The intersection of three matroids is NP-hard in general, since it contains the Hamiltonian path problem in directed graphs.

## Explanations

### L1 human

A matroid is a rule that says which sets are "independent", like sets of linearly independent vectors or sets of edges without a cycle.
Matroid intersection asks for the largest set that is independent for two such rules at once.
For example, when assigning workers to jobs, one rule says no worker is used twice and the other says no job is used twice.
A set of pairs that obeys both rules is a matching, and the largest one is what we want.
Two rules can be handled efficiently, but with three rules the problem becomes hard.
