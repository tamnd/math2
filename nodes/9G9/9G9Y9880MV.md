## Example

With a triangular matrix and nonzero diagonal, each row adds exactly one new unknown, so we solve from the bottom up.
Let $U = \begin{bmatrix} 2 & 1 & -1 \\ 0 & 3 & 2 \\ 0 & 0 & 4 \end{bmatrix}$ and $b = (3, 13, 8)$ over $\mathbb{R}$.
The matrix $U$ is [[upper triangular|0N4XY7Z3NN]] with diagonal entries $2, 3, 4$, which are not $0$.
We solve $Ux = b$ by [[back substitution|0ATFVE08MW]].

1. Row 3 reads $4x_3 = 8$, so $x_3 = 2$.
2. Row 2 reads $3x_2 + 2x_3 = 13$, so $x_2 = (13 - 4) / 3 = 3$.
3. Row 1 reads $2x_1 + x_2 - x_3 = 3$, so $x_1 = (3 - 3 + 2) / 2 = 1$.
4. Check: $2 \cdot 1 + 3 - 2 = 3$, $3 \cdot 3 + 2 \cdot 2 = 13$ and $4 \cdot 2 = 8$.

So $x = (1, 3, 2)$, and it is the only solution.

## Remarks

The work was $3$ divisions, $3$ multiplications and $3$ subtractions, that is $9 = 3^2$ operations, as the count $n^2$ predicts.
Row 3 needed $1$ operation, row 2 needed $3$ and row 1 needed $5$.

## Explanations

### L1 human

The bottom equation has one unknown, so we solve it first.
Each equation above it then has only one new unknown.

### L2 human

1. Solve the last row.
2. Put the value into the row above and solve for its first unknown.
3. Repeat up to the first row.
4. Check all the equations.

Watch out: in step 3 the term $-x_3$ becomes $+2$ when we move it to the right side, and a sign error here is common.
