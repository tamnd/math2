## Summary

A **disperser** is a one-sided extractor. Where an extractor requires that every event gets the same probability under the [[uniform distribution|0AREFQ9Z65]] and the extracted distribution, only the latter is required for a disperser. So for a disperser, an event $A \subseteq \{0,1\}^{m}$ we have: $Pr_{U_{m}}[A] > 1 - \epsilon$
