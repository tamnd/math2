## Summary

A cyclic code is a [[linear code|E85KREWV60]] that is closed under the cyclic shift of coordinates.
Writing a word $(c_0, \dots, c_{n-1})$ as the polynomial $c_0 + c_1 x + \cdots + c_{n-1} x^{n-1}$ turns a cyclic code into an [[ideal|096Z9MP2ME]] of the ring $\F_q[x]/(x^n - 1)$.
So each cyclic code is described by one polynomial, its generator polynomial, which divides $x^n - 1$.
This algebraic structure gives fast encoding with shift registers and good decoding algorithms, and it includes Hamming, BCH, Reed–Solomon and Golay codes.

## Explanations

### L1 human

Write a codeword around a circle.
A code is cyclic when rotating any codeword by one step gives another codeword.
For example, the binary code $\set{000, 110, 011, 101}$ is cyclic: rotating $110$ gives $011$, rotating again gives $101$, and once more gives back $110$.
Because rotation is multiplication by $x$ in the polynomial picture, cyclic codes can be handled with polynomial algebra.
