## Definition

Linear temporal logic is the language of next and until, read on infinite words.
Let $AP$ be a set of atomic propositions.
The formulas of *linear temporal logic* over $AP$ are given by the grammar
$$\varphi ::= p \mid \neg \varphi \mid \varphi \land \varphi \mid X \varphi \mid \varphi \, U \, \varphi, \qquad p \in AP.$$
A formula is interpreted on an infinite word $w = w_0 w_1 w_2 \cdots$ with each $w_i \subseteq AP$.
For $i \ge 0$, let $w^{i} = w_i w_{i+1} \cdots$ be the suffix of $w$ from position $i$.
The relation $w \models \varphi$ is defined by induction on $\varphi$.

1. $w \models p$ if and only if $p \in w_0$.
2. $w \models \neg\varphi$ if and only if $w \not\models \varphi$, and $w \models \varphi \land \psi$ if and only if $w \models \varphi$ and $w \models \psi$.
3. $w \models X\varphi$ if and only if $w^{1} \models \varphi$.
4. $w \models \varphi \, U \, \psi$ if and only if there is a $j \ge 0$ with $w^{j} \models \psi$ and $w^{i} \models \varphi$ for all $0 \le i < j$.

Let $s$ be a state of a [[Kripke structure|RFQ8DJZNQT]] with a total transition relation and a labeling $L$ of states by subsets of $AP$.
Then $s$ satisfies $\varphi$ if the word $L(s_0) L(s_1) \cdots$ of every infinite path $s = s_0, s_1, \dots$ satisfies $\varphi$.

## Notation

We write $F\varphi = \top \, U \, \varphi$ ("eventually") and $G\varphi = \neg F \neg \varphi$ ("always"), where $\top = p \vee \neg p$ for a fixed $p$.
The other connectives of [[propositional logic|09K9MWD2QQ]] are defined as usual.
The set of infinite words over $2^{AP}$ that satisfy $\varphi$ is $\mathrm{Words}(\varphi)$.

## Remarks

### Reading the clauses

Each clause looks only at the suffix from the current position, so the truth of a formula at position $i$ depends only on $w^i$.
Clause 3 moves the reading point one step to the right, and clause 4 moves it to a witness $j$.
The until is reflexive because $j = 0$ is allowed: $\varphi \, U \, \psi$ holds as soon as $\psi$ holds at position $0$, whatever $\varphi$ is.
The definition for a state quantifies over all paths, which is what makes LTL a linear-time logic: it judges a system by the set of its runs.
Totality of the transition relation is there for a reason.
A state with no infinite path would satisfy every formula, including $\bot$, since there is no path to check.

### A word that works and one that fails

Let $AP = \{p\}$ and $w = \emptyset \, \emptyset \, \{p\} \, \{p\} \, \{p\} \cdots$.
Then $w \models FGp$, because the suffix $w^{2}$ satisfies $Gp$: every suffix of $w^2$ starts with a letter that contains $p$.
On the same word, $w \models \neg p \, U \, p$ with witness $j = 2$, and $w \models XXp$.
The word $w' = \{p\} \, \emptyset \, \{p\} \, \emptyset \cdots$ does not satisfy $FGp$.
Every suffix of $w'$ has a later position without $p$, so no suffix satisfies $Gp$.

A finite word is not a model in this definition.
Variants of LTL for finite traces exist, and there $X\varphi$ is false at the last position.
The [[concept page|RMJ56ZPA63]] uses the definition on lasso words and on the shapes of common requirements.

## Explanations

### L1 human

Picture time as a line of moments $0, 1, 2, \dots$, and at each moment some basic facts are true.
An LTL formula is a statement about the whole line, read from moment $0$.
"$G\,\mathit{safe}$" says the system is safe at every moment.
"$G(\mathit{req} \to F\,\mathit{grant})$" says that whenever a request happens, a grant happens then or later.
A system satisfies a formula when every possible run of it does.

### L2 human

We evaluate $p \, U \, q$ on $w = \{p\}\,\{p\}\,\{q\}\,\emptyset\,\emptyset \cdots$.
The witness must be a $j$ with $q \in w_j$, and the only such position is $j = 2$.
For $i = 0$ and $i = 1$ we have $p \in w_i$, so $w \models p \, U \, q$.
At position $3$ the suffix $w^3$ has no $q$ at all, so $w^3 \not\models p \, U \, q$.
Watch out: the clause for a state quantifies over all paths, so a state can satisfy neither $Fp$ nor $\neg Fp$.

### L3 human

The semantics reads formulas over the frame $(\mathbb{N}, <)$, in the style of the [[standard translation|YW6YGBMVQY]], with $U$ as a binary modality.
Clause 4 is a first-order formula in one free variable over $(\mathbb{N}, <)$, so every LTL formula is first-order definable on words.
The converse is Kamp's theorem for $\mathbb{N}$, and the translation into Büchi automata turns the clauses into states that remember which subformulas are still owed.
