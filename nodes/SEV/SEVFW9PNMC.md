## Definition

An *alphabet* is a nonempty [[finite set|0BBTH3YSZA]] $\Sigma$.
Its elements are called *symbols* or *letters*.

## Remarks

Example: $\Sigma = \set{0, 1}$ is an alphabet, since it is finite and nonempty.
Non-example: the set $\N$ of natural numbers is not an alphabet in this sense, since it is infinite.
Some authors allow infinite alphabets in combinatorics on words, and some allow the empty alphabet; most of automata theory uses the finite nonempty case.
The letter $\Sigma$ is the usual name for an alphabet, and $\Sigma^*$ is the set of strings over it.
