## Definition

Let $I \subseteq \R$ be an open interval and let $u \colon I \to \R$ be a twice differentiable utility function with $u'(w) > 0$ for all $w \in I$.
The *Arrow–Pratt coefficient of absolute risk aversion* of $u$ at $w \in I$ is
$$A(w) = -\frac{u''(w)}{u'(w)}.$$
If $I \subseteq (0, \infty)$, the *coefficient of relative risk aversion* of $u$ at $w$ is $R(w) = w\, A(w)$.

## Remarks

For $u(w) = \ln w$ on $(0, \infty)$: $u'(w) = 1/w$ and $u''(w) = -1/w^2$, so $A(w) = 1/w$ and $R(w) = 1$.
For $u(w) = -e^{-a w}$ on $\R$ with $a > 0$: $u'(w) = a e^{-a w}$ and $u''(w) = -a^2 e^{-a w}$, so $A(w) = a$ for all $w$.
The measure is not defined for $u(w) = \abs{w}$ on $\R$, since $u$ is not differentiable at $0$ and $u'$ is not positive on $(-\infty, 0)$.
The coefficient does not change when $u$ is replaced by $a u + b$ with $a > 0$, so it depends only on the preferences over lotteries.
$A \ge 0$ on $I$ if and only if $u$ is concave, that is, if and only if the agent is [[risk averse|RJG35DZXTH]].
Pratt's theorem compares two such utilities $u_1, u_2$ on $I$.
The condition $A_1(w) \ge A_2(w)$ for all $w$ holds if and only if $u_1 = \varphi \circ u_2$ for an increasing concave $\varphi$.
It also holds if and only if every lottery has a [[certainty equivalent|FZNYZWR7MY]] for $u_1$ at most its certainty equivalent for $u_2$.
For a small lottery $w + \varepsilon Z$ with $\mathbb{E}[Z] = 0$, the risk premium is $\tfrac12 \varepsilon^2 \operatorname{Var}(Z) A(w) + o(\varepsilon^2)$.
