## Example

Let $f \colon \R \to \R^3$ be $f(t) = (t, t, t)$, and let $g \colon \R^3 \to \R^2$ be $g(x, y, z) = (x - y, y - z)$.
We check that
$$0 \to \R \xrightarrow{f} \R^3 \xrightarrow{g} \R^2 \to 0$$
is a [[short exact sequence|8MCYV0P04T]], and then we split it.

1. The map $f$ is injective, because $f(t) = (0, 0, 0)$ forces $t = 0$.
2. The composite is zero: $g(t, t, t) = (t - t, t - t) = (0, 0)$.
   So $\operatorname{im} f \subseteq \ker g$.
3. For the reverse inclusion, compute the [[kernel|02YFME3RGW]] of $g$.
   The equation $g(x, y, z) = (0, 0)$ means $x = y$ and $y = z$, so $\ker g = \R(1, 1, 1)$, which is the [[image|0JB228DCWB]] of $f$.
4. The map $g$ is onto, because for every $(a, b) \in \R^2$
$$g(a + b, b, 0) = (a + b - b,\ b - 0) = (a, b).$$
5. So the sequence is exact at $\R$, at $\R^3$ and at $\R^2$.
6. To split it, let $s(a, b) = (a + b, b, 0)$.
   This map is linear, and $g \circ s = \operatorname{id}_{\R^2}$ by step 4.
7. The map $\R \oplus \R^2 \to \R^3$ given by
$$(t, (a, b)) \mapsto f(t) + s(a, b) = (t + a + b,\ t + b,\ t)$$
   is an isomorphism, with inverse $(x, y, z) \mapsto (z, (x - y, y - z))$.
   Check: $z + (x - y) + (y - z) = x$ and $z + (y - z) = y$.
8. The dimensions satisfy $1 - 3 + 2 = 0$, as the [[alternating sum formula|EFBRMNWDQM]] requires.

## Remarks

### The splitting is a choice

The image of $s$ is the plane $z = 0$, and it is a complement of $\ker g = \R(1, 1, 1)$.
Another complement gives another splitting.
For example, let
$$s'(a, b) = (a + b, b, 0) - \tfrac{a + 2b}{3}(1, 1, 1).$$
Its coordinates add up to $(a + 2b) - (a + 2b) = 0$, so its image lies in the plane $x + y + z = 0$, and $g \circ s' = g \circ s = \operatorname{id}$ because $g(1, 1, 1) = 0$.
The second splitting is the one that an inner product would pick, since $x + y + z = 0$ is the plane perpendicular to $(1, 1, 1)$.

### The left inverse

The inverse in step 7 gives the left inverse $r(x, y, z) = z$ of $f$, the first component of the inverse map.
Check: $r(f(t)) = r(t, t, t) = t$.
With the second splitting the left inverse changes to $r'(x, y, z) = \tfrac{x + y + z}{3}$, the average of the coordinates.

### What changes when $g$ changes

If we replace $g$ by $g(x, y, z) = (x - y, 0)$, then $g$ is no longer onto, and its kernel is the plane $x = y$, which is larger than $\operatorname{im} f$.
The sequence then fails to be exact at $\R^3$ and at $\R^2$, although the composite $g \circ f$ is still zero.

## Explanations

### L1 human

The line through $(1, 1, 1)$ sits inside $\R^3$.
The map $g$ records the differences $x - y$ and $y - z$, so it forgets exactly how far a point has moved along that line.
The plane $z = 0$ is a second piece that $g$ maps onto $\R^2$ one-to-one.
So $\R^3$ is the line plus the plane, and the dimensions match: $3 = 1 + 2$.

### L2 human

To check exactness in the middle you need both inclusions.
Step 2 gives $\operatorname{im} f \subseteq \ker g$ from $g \circ f = 0$, and step 3 gives $\ker g \subseteq \operatorname{im} f$ by solving $g = 0$.
Watch out: the composite $g \circ f = 0$ alone is not enough, as the changed $g$ in the remarks shows.
