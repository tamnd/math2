## Definition

Let $\mathcal{A}$ be an [[algorithm|9DMSG5HAQX]] with input set $I$, and let $\abs{x} \in \N$ be the size of an input $x \in I$.
Let $c(x)$ be the number of elementary steps of $\mathcal{A}$ on $x$ in a fixed cost model.
Let $I_n = \set{x \in I : \abs{x} = n}$ and assume each $I_n$ is finite and nonempty.

1. The *worst-case running time* of $\mathcal{A}$ is $T(n) = \max_{x \in I_n} c(x)$.
2. The *best-case running time* is $B(n) = \min_{x \in I_n} c(x)$.
3. Given a probability distribution $\Pr_n$ on each $I_n$, the *average-case running time* is $\bar{T}(n) = \sum_{x \in I_n} \Pr_n(x)\, c(x)$.

The *analysis of algorithms* is the determination of such functions, usually up to [[asymptotic order|0TGV80E6A4]] as $n \to \infty$.
The same definitions with memory use in place of $c(x)$ give the space complexity.

## Remarks

Example: linear search for a key in a list of $n$ items, counting comparisons, has $T(n) = n$ and $B(n) = 1$.
If the key is present and equally likely to be at each of the $n$ positions, then $\bar{T}(n) = \frac{1}{n}\sum_{k=1}^n k = \frac{n+1}{2}$.
In asymptotic terms, $T(n) = \Theta(n)$, $\bar{T}(n) = \Theta(n)$ and $B(n) = \Theta(1)$.

The [[time complexity|T00W8RQT8E]] of a problem is a different notion: it is the least running time of an algorithm that solves the problem.
