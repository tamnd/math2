## Example

The claim is the [[inequality of arithmetic and geometric means|0DRF0F3XC9]] for two numbers: for all real $a \ge 0$ and $b \ge 0$,
$$\frac{a + b}{2} \ge \sqrt{ab}.$$
A student hands in this text.

> $\frac{a+b}{2} \ge \sqrt{ab} \;\Rightarrow\; a + b \ge 2\sqrt{ab} \;\Rightarrow\; a - 2\sqrt{ab} + b \ge 0 \;\Rightarrow\; (\sqrt a - \sqrt b)^2 \ge 0$, which is true.
> $\blacksquare$

We check the text against the method of [[scratch work and the final proof|E97XXFW9MV]].

1. The first line is the claim. The text assumes what it must prove.
2. Each arrow goes from the claim toward a known fact. So the text shows "the claim implies $(\sqrt a - \sqrt b)^2 \ge 0$".
3. A true conclusion does not make the starting point true. So the text, read as written, proves nothing about the claim.
4. The text is good scratch work. It finds the known fact from which a proof can start.

The final proof reverses the chain and checks that each step goes forward.

> Let $a \ge 0$ and $b \ge 0$.
> Then $\sqrt a$ and $\sqrt b$ are real numbers with $(\sqrt a)^2 = a$ and $(\sqrt b)^2 = b$.
> A square is non-negative, so $(\sqrt a - \sqrt b)^2 \ge 0$.
> Expanding gives $a - 2\sqrt a \sqrt b + b \ge 0$, and $\sqrt a \sqrt b = \sqrt{ab}$ because $a, b \ge 0$.
> So $a + b \ge 2\sqrt{ab}$, by adding $2\sqrt{ab}$ to both sides.
> Dividing by $2$ gives $\frac{a + b}{2} \ge \sqrt{ab}$.
> $\square$

## Remarks

1. Here each backward step is reversible, so the reversed chain is a proof. The student's text is not wrong mathematics, but it is in the wrong order for a proof.
2. A backward chain with a step that cannot be reversed can start from a false claim and still reach a true statement. The page [[squaring both sides does not prove an identity|FGS7ZJJYRK]] shows this with $\sqrt{x^2} = x$.
3. The reversed proof uses the hypotheses $a \ge 0$ and $b \ge 0$ at two places: for $\sqrt a$ and $\sqrt b$ to exist, and for $\sqrt a \sqrt b = \sqrt{ab}$.
4. A numerical check: for $a = 1$ and $b = 9$ we get $\frac{1 + 9}{2} = 5 \ge 3 = \sqrt 9$, and $(\sqrt 1 - \sqrt 9)^2 = 4 \ge 0$.
5. A student who wants to keep the backward order can write "$\iff$" at each step and give the reason why each step is an equivalence. Then the text is a proof, but the reader must check two directions at each step.

## Explanations

### L1 human

The student starts by writing the claim and then changes it, step by step, into something true.
That is a good way to find a proof, but it is not a proof.
It is like saying "if I am right, then two plus two is four, so I am right".
A true end point does not show that the start was true.
The repair is to start from the true fact and walk forward to the claim.

### L2 human

We test the backward text on a false claim, to see why its form is not a proof.

1. False claim: for all real $a$ and $b$, $a \ge b$.
2. Backward text: "$a \ge b \Rightarrow 0 \cdot a \ge 0 \cdot b \Rightarrow 0 \ge 0$, which is true."
3. Each arrow is a correct implication, and the last line is true.
4. The claim is false: $a = 0$ and $b = 1$ give $0 \ge 1$, which is false.
5. So the form "claim, arrows, true statement" can "prove" a false claim, and it proves nothing.

The typical use of the backward search is to find the starting fact of the proof.
A trap is to reverse the chain without checking each step; multiplication by $0$ in step 2 cannot be reversed.
