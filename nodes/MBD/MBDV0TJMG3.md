## Statement

An odd prime number $p$ is defined to be regular if it does not divide the class number of the $p$th cyclotomic field $\mathbb{Q}(\zeta_p)$, where $\zeta_p$ is a primitive $p$th root of unity.

The prime number 2 is often considered regular as well.

The class number of the cyclotomic field is the number of [[ideals|096Z9MP2ME]] of the ring of integers $\mathbb{Z}(\zeta_p)$ up to equivalence.
