## Example

Łukasiewicz's three-valued logic uses the truth values $0$ (false), $\tfrac{1}{2}$ (undetermined) and $1$ (true).
Its connectives are defined by
$$\neg x = 1 - x, \qquad x \land y = \min(x, y), \qquad x \lor y = \max(x, y).$$
A formula counts as valid when it has the value $1$ under every assignment of the three values to its variables.
We show that this logic does not satisfy the [[principle of bivalence|5DYNDW9526]], and we compute $p \lor \neg p$.

1. The value $\tfrac{1}{2}$ is a truth value of the logic, and it is neither $1$ nor $0$. So a proposition with value $\tfrac{1}{2}$ is neither true nor false, and bivalence fails.
2. Give $p$ the value $\tfrac{1}{2}$. Łukasiewicz's own example of such a proposition was a statement about a future event, such as "there will be a sea battle tomorrow".
3. The [[negation|029JBBF693]] is $\neg p = 1 - \tfrac{1}{2} = \tfrac{1}{2}$.
4. The [[disjunction|0F72FK8EKB]] is $p \lor \neg p = \max(\tfrac{1}{2}, \tfrac{1}{2}) = \tfrac{1}{2}$.
5. So $p \lor \neg p$ is not valid in this logic: the [[law of excluded middle|0RYYK8PG4S]] fails together with bivalence.
6. In the same way, $p \land \neg p = \min(\tfrac{1}{2}, \tfrac{1}{2}) = \tfrac{1}{2}$, and $\neg(p \land \neg p) = \tfrac{1}{2}$. The [[law of noncontradiction|MP4R7T546Z]] is not valid either.

## Remarks

The example shows the condition that fails: the set of truth values has three elements, not two.
On the values $0$ and $1$ alone, the three formulas above agree with classical logic: for $p = 1$ or $p = 0$, the value of $p \lor \neg p$ is $1$.
So every failure of a classical law comes from the third value.

Łukasiewicz's implication is $x \to y = \min(1, 1 - x + y)$.
For $p = \tfrac{1}{2}$, it gives $p \to p = \min(1, 1) = 1$, so $p \to p$ is valid, while $\neg p \lor p$ is not.
In classical logic $p \to q$ and $\neg p \lor q$ are equivalent, so this equivalence also fails in the three-valued logic.

## Explanations

### L1 human

Imagine a third answer besides "true" and "false", namely "not decided yet".
A claim about tomorrow's weather may get this third answer today.
Then the claim "it will rain tomorrow or it will not rain tomorrow" also gets the answer "not decided yet" in this logic.
So the rule that every claim is true or false is given up here.

### L2 human

We compute the value of $p \lor (q \land \neg p)$ for $p = \tfrac{1}{2}$ and $q = 1$.

1. $\neg p = 1 - \tfrac{1}{2} = \tfrac{1}{2}$.
2. $q \land \neg p = \min(1, \tfrac{1}{2}) = \tfrac{1}{2}$.
3. $p \lor (q \land \neg p) = \max(\tfrac{1}{2}, \tfrac{1}{2}) = \tfrac{1}{2}$.

In classical logic, with $q$ true, the formula reduces to $p \lor \neg p$, which is always true.
Here it gets the value $\tfrac{1}{2}$.

The typical use of such a computation is to show that a classical law is not valid in a many-valued logic: one assignment with a value below $1$ is enough.

A trap: the value $\tfrac{1}{2}$ is not a probability.
The values of the parts determine the value of the whole by $\min$, $\max$ and $1 - x$, which probabilities do not do.
