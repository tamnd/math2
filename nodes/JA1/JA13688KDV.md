## Definition

Let $T$ be a [[complete theory|655K8Y7VS8]] in a signature $L$.

1. A formula $\varphi(x_1, \dots, x_n)$ is *complete* for $T$ if $T \cup \set{\exists \bar x \, \varphi(\bar x)}$ is satisfiable and, for every $L$-formula $\psi(\bar x)$, either $T \models \forall \bar x \, (\varphi \to \psi)$ or $T \models \forall \bar x \, (\varphi \to \neg\psi)$.
2. A complete $n$-[[type|9V71Q3SD1G]] $p(\bar x)$ of $T$ is *isolated* if it contains a complete formula. Then $p$ is the set of all $\psi$ with $T \models \forall \bar x \, (\varphi \to \psi)$.
3. A [[model|MVCH6N9SNW]] $M$ of $T$ is *atomic* if for every $n$ and every $\bar a \in M^n$, the type $\operatorname{tp}^M(\bar a)$ is isolated.

## Notation

Some books say that $\varphi$ *isolates* $p$, or that $p$ is *principal*.
Isolation in clause 2 agrees with the notion used in the [[omitting types theorem|7MFGBVDVG9]] for complete types.

## Remarks

Clause 3 asks for isolation over the empty set.
In a theory with constants, a tuple may use the constants inside the formula $\varphi$, but not other elements of $M$.
For incomplete theories, one first fixes a completion, since isolation is relative to $T$.
This is the definition of the concept [[atomic model|HSJ4F9J8SM]].

## Explanations

### L1 human

A model is atomic when each finite list of its elements can be described, completely, by one formula.
Completely means that every other property of the list follows from that one formula and the theory.

### L2 human

In the theory of an infinite set in the empty signature, the formula $x_1 \ne x_2$ is complete.
Any two pairs of distinct elements have the same type, because a bijection of the model maps one pair to the other.
In general, the type of a tuple of an infinite set is isolated by the conjunction of the equalities and inequalities among its entries.
So every infinite set is an atomic model of this theory.
