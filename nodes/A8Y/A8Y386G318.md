## Example

Take two statements that are each half true, written in [[vector logic|DJ41X602BJ]] as $u = v = \tfrac12 s + \tfrac12 n$.
Their conjunction comes out a quarter true: $s^T C (u \otimes v) = \tfrac14$.
We derive this, and the values of the other connectives, for general mixed inputs.

Let $s$ and $n$ be orthonormal truth vectors, and for $\alpha, \alpha' \in [0, 1]$ put $u = \alpha s + (1 - \alpha) n$ and $v = \alpha' s + (1 - \alpha') n$.
These are [[convex combinations|21SXYJYC59]] of $s$ and $n$.
We compute the scalar values $s^T N u$ and $s^T G (u \otimes v)$ for $G = C, D, L$.

1. By bilinearity of $\otimes$, $u \otimes v = \alpha \alpha' (s \otimes s) + \alpha (1 - \alpha')(s \otimes n) + (1 - \alpha) \alpha' (n \otimes s) + (1 - \alpha)(1 - \alpha')(n \otimes n)$.
2. $N u = \alpha n + (1 - \alpha) s$, so $s^T N u = 1 - \alpha$.
3. $C$ sends $s \otimes s$ to $s$ and the other three basic inputs to $n$, so $s^T C (u \otimes v) = \alpha \alpha'$.
4. $D$ sends only $n \otimes n$ to $n$, so $s^T D (u \otimes v) = 1 - (1 - \alpha)(1 - \alpha') = \alpha + \alpha' - \alpha \alpha'$.
5. $L$ sends only $s \otimes n$ to $n$, so $s^T L (u \otimes v) = 1 - \alpha (1 - \alpha')$.

At $\alpha = \alpha' = \tfrac12$ the values are $\tfrac12$ for negation, $\tfrac14$ for conjunction, $\tfrac34$ for disjunction and $\tfrac34$ for implication.

## Remarks

Compare with [[Łukasiewicz three-valued logic|F9NDCFY3GS]] at the value $\tfrac12$ for both inputs.
There, $\neg$ gives $\tfrac12$ and implication gives $\min(1, 1 - \tfrac12 + \tfrac12) = 1$.
The weak conjunction $\min$ gives $\tfrac12$, and the strong conjunction $\max(0, \tfrac12 + \tfrac12 - 1)$ gives $0$.
So negation agrees, but conjunction and implication differ, and the value $\tfrac14$ is not even in $\{0, \tfrac12, 1\}$.

Change the parameters to $\alpha = \tfrac34$ and $\alpha' = \tfrac13$.
Then conjunction gives $\tfrac34 \cdot \tfrac13 = \tfrac14$, disjunction gives $\tfrac34 + \tfrac13 - \tfrac14 = \tfrac56$, and implication gives $1 - \tfrac34 \cdot \tfrac23 = \tfrac12$.
The Łukasiewicz implication gives $\min(1, 1 - \tfrac34 + \tfrac13) = \tfrac{7}{12}$.
For $\alpha, \alpha' \in \{0, 1\}$ all the formulas give the classical truth tables.

The output vectors are again convex combinations of $s$ and $n$; for example $C (u \otimes v) = \alpha \alpha' s + (1 - \alpha \alpha') n$.
So the operations can be composed, and the scalar value of a composite formula is computed step by step.
These values are probabilities: $\alpha \alpha'$ is the chance that two independent events with chances $\alpha$ and $\alpha'$ both happen.

## Explanations

### L1 human

Suppose a statement is $50\%$ true, written as half of the "true" arrow and half of the "false" arrow.
"And" of two such statements comes out $25\%$ true.
This is the chance that two independent fair coins both show heads.
So these mixed truth values behave like probabilities, not like the degrees of truth of Łukasiewicz logic.

### L2 human

Expand $u \otimes v$ into the four basic inputs, with the weights $\alpha \alpha'$, $\alpha (1 - \alpha')$, $(1 - \alpha) \alpha'$ and $(1 - \alpha)(1 - \alpha')$.
For a connective $G$, add the weights of the basic inputs that $G$ sends to $s$, and the sum is $s^T G (u \otimes v)$.
For exclusive or at $\alpha = \tfrac34$, $\alpha' = \tfrac13$, the weights of $s \otimes n$ and $n \otimes s$ are $\tfrac12$ and $\tfrac{1}{12}$, so the value is $\tfrac{7}{12}$.
Watch out: the value at $(\tfrac12, \tfrac12)$ is not the Łukasiewicz value, even though both logics use $\tfrac12$ for "undetermined".
