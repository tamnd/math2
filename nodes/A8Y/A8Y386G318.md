## Example

Work in [[vector logic|DJ41X602BJ]] with orthonormal truth vectors $s$ and $n$.
For $\alpha, \alpha' \in [0, 1]$ put $u = \alpha s + (1 - \alpha) n$ and $v = \alpha' s + (1 - \alpha') n$.
These are [[convex combinations|21SXYJYC59]] of $s$ and $n$.
We compute the scalar values $s^T N u$ and $s^T G (u \otimes v)$ for $G = C, D, L$.

1. By bilinearity of $\otimes$, $u \otimes v = \alpha \alpha' (s \otimes s) + \alpha (1 - \alpha')(s \otimes n) + (1 - \alpha) \alpha' (n \otimes s) + (1 - \alpha)(1 - \alpha')(n \otimes n)$.
2. $N u = \alpha n + (1 - \alpha) s$, so $s^T N u = 1 - \alpha$.
3. $C$ sends $s \otimes s$ to $s$ and the other three basic inputs to $n$. So $s^T C (u \otimes v) = \alpha \alpha'$.
4. $D$ sends only $n \otimes n$ to $n$. So $s^T D (u \otimes v) = 1 - (1 - \alpha)(1 - \alpha') = \alpha + \alpha' - \alpha \alpha'$.
5. $L$ sends only $s \otimes n$ to $n$. So $s^T L (u \otimes v) = 1 - \alpha (1 - \alpha')$.

With numbers, take $\alpha = \alpha' = \tfrac12$.
Then the values are $\tfrac12$ for negation, $\tfrac14$ for conjunction, $\tfrac34$ for disjunction and $\tfrac34$ for implication.

## Remarks

Compare with [[Łukasiewicz's three-valued logic|F9NDCFY3GS]] at the value $\tfrac12$ for both inputs.
There, $\neg$ gives $\tfrac12$ and implication gives $\min(1, 1 - \tfrac12 + \tfrac12) = 1$.
The weak conjunction $\min$ gives $\tfrac12$, and the strong conjunction $\max(0, \tfrac12 + \tfrac12 - 1)$ gives $0$.
So negation agrees, but conjunction and implication differ.
The value $\tfrac14$ also shows that the projected values do not stay in $\set{0, \tfrac12, 1}$.

Change the parameters to $\alpha = \tfrac34$ and $\alpha' = \tfrac13$.
Then conjunction gives $\tfrac14$, disjunction gives $\tfrac56$, and implication gives $1 - \tfrac34 \cdot \tfrac23 = \tfrac12$.
The Łukasiewicz implication gives $\min(1, 1 - \tfrac34 + \tfrac13) = \tfrac{7}{12}$.
For $\alpha, \alpha' \in \set{0, 1}$, all the formulas give the classical truth tables.

The output vectors are again convex combinations of $s$ and $n$.
For example, $C (u \otimes v) = \alpha \alpha' s + (1 - \alpha \alpha') n$.
So the operations can be composed, and the scalar value of a composite is computed step by step.

## Explanations

### L1 human

Suppose a statement is $50\%$ true, written as half of the "true" arrow and half of the "false" arrow.
"And" of two such statements comes out $25\%$ true.
This is the chance that two independent fair coins both show heads.
So these mixed truth values behave like probabilities, not like the degrees of truth of Łukasiewicz.

### L2 human

1. Expand $u \otimes v$ into the four basic inputs, with weights $\alpha \alpha'$, $\alpha(1 - \alpha')$, $(1 - \alpha)\alpha'$ and $(1 - \alpha)(1 - \alpha')$.
2. For a connective $G$, add the weights of the basic inputs that $G$ sends to $s$.
3. The sum is $s^T G (u \otimes v)$.

The typical use is quick evaluation of any connective on uncertain inputs.
A trap: the answer for $(\tfrac12, \tfrac12)$ is not the Łukasiewicz value, even though both logics use $\tfrac12$ for "undetermined".
