## Problem

Two spaceships are at rest in an inertial frame $S$, one behind the other on a line, at distance $d$.
A thin string of rest length $d$ joins them and is just taut.
At the same time in $S$ both ships start to accelerate along the line with the same acceleration program.
So at every time of $S$ they have the same velocity $v$.
Does the string break?

## Remarks

The string breaks once $v$ is large enough.
Since the two ships have the same motion shifted by $d$, their distance in $S$ stays equal to $d$.
A string moving at speed $v$ that keeps its rest length $d$ would have length $d/\gamma$ in $S$ by [[length contraction|4A5MG1MJAZ]], with $\gamma$ the [[Lorentz factor|2E9AJVZS6E]].
So the string must stretch to the rest length $\gamma d > d$, and as $\gamma$ grows the stress exceeds what it can bear.
Equivalently, in the momentary rest frame of the ships the distance between them is $\gamma d$, because the two ships do not start simultaneously in the frames that move with them.
The motion of the ships is not [[Born rigid|J7FVATX80A]]; a Born rigid motion would need the front ship to have a smaller proper acceleration than the rear ship.
Dewan and Beran described the experiment in 1959; John Stewart Bell discussed it in 1976, and it then became widely known.

## Explanations

### L1 human

Two rockets tied by a string speed up in exactly the same way, so to an observer at rest their distance never changes.
Yet the string feels a pull and finally breaks.
The reason is that a moving string wants to be shorter, by length contraction, while the rockets keep the same distance.
From the rockets' own point of view, they really do drift apart.
The puzzle shows that length contraction has real physical effects on stresses.
