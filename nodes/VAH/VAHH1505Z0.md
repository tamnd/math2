## Statement

Fix a countable predicate language $\mathcal{L}$ with infinitely many predicate symbols of each arity.
Formulas are built from atomic formulas and $\overline{0}$ with $\neg$, $\to$, $\odot$, $\oplus$, $\land$, $\lor$, $\forall$ and $\exists$.

A *standard structure* $\mathfrak{M}$ has a non-empty domain $M$ and, for each $n$-ary predicate $P$, a map $P^{\mathfrak{M}} \colon M^n \to [0, 1]$.
Let $e$ assign an element of $M$ to each variable.
The value $\lVert \varphi \rVert_{\mathfrak{M}, e} \in [0, 1]$ is defined by induction on $\varphi$:

1. $\lVert P(x_1, \dots, x_n) \rVert_{\mathfrak{M}, e} = P^{\mathfrak{M}}(e(x_1), \dots, e(x_n))$, and $\lVert \overline{0} \rVert_{\mathfrak{M}, e} = 0$.
2. The connectives use the operations of [[infinite-valued Łukasiewicz logic|JQ713VVD0G]]: $\neg x = 1 - x$, $x \to y = \min(1, 1 - x + y)$, $x \odot y = \max(0, x + y - 1)$, $x \oplus y = \min(1, x + y)$, and $\land, \lor$ are $\min, \max$.
3. $\lVert \forall x \, \varphi \rVert_{\mathfrak{M}, e}$ is the infimum, and $\lVert \exists x \, \varphi \rVert_{\mathfrak{M}, e}$ is the supremum, of the values $\lVert \varphi \rVert_{\mathfrak{M}, e'}$, where $e'$ differs from $e$ at most at $x$.

A formula $\varphi$ is a *standard tautology* of first-order Łukasiewicz logic $\mathrm{Ł}\forall$ if $\lVert \varphi \rVert_{\mathfrak{M}, e} = 1$ for all standard $\mathfrak{M}$ and all $e$.
$\mathrm{Taut}$ is the set of their [[Gödel numbers|MFJXPAF0R0]].

A set $A \subseteq \mathbb{N}$ is *$\Pi^0_2$-complete* if $A$ is in the class $\Pi^0_2$ of the [[arithmetical hierarchy|7CVJCQKY41]], and every $\Pi^0_2$ set is [[many-one reducible|H5CW67CCST]] to $A$.

**Theorem.**
The set $\mathrm{Taut}$ is $\Pi^0_2$-complete.

**Corollary.**
The set $\mathrm{Taut}$ is not [[computably enumerable|TN9G24VABN]].
So no proof system with a computably enumerable set of axioms and decidable rules has exactly the standard tautologies of $\mathrm{Ł}\forall$ as its theorems.

## Remarks

The infima and suprema in the definition exist, because every subset of $[0, 1]$ has an infimum and a supremum in $[0, 1]$.
The [[proof node|EEEFJ258Q3]] proves the corollary from the theorem, and it does not prove the theorem itself.

### Why each hypothesis is needed

1. The standard semantics is needed. SEP (2016) states the general completeness theorem for $\mathrm{Ł}\forall$: provability equals validity in all suitable MV-algebras. So the general tautologies are computably enumerable, and SEP calls them $\Sigma_1$-complete.
2. The first-order language is needed. SEP (2016) states that the propositional Łukasiewicz tautologies are co-NP-complete, so they form a decidable set.
3. The Łukasiewicz operations are needed. With the Gödel operations, SEP (2016) states that the standard predicate tautologies are $\Sigma_1$-complete; see [[first-order Gödel logics|H8C323CV3T]].

### Consequences

1. $\mathrm{Ł}\forall$ has no complete axiomatization for standard validity with computably enumerable axioms. SEP (2016, section 4) states this non-axiomatizability.
2. The axioms of $\mathrm{Ł}\forall$ are still complete for the general semantics, by the general completeness theorem.
3. So some formula has value $1$ in every standard structure, and value below $1$ in some structure over a linearly ordered MV-algebra.
4. By [[Post's theorem|NYJX5QXX1T]], every $\Sigma^0_2$ set is computably enumerable relative to the halting problem. So an oracle for the halting problem lets an algorithm list the non-tautologies.

### Converse

The converse of the corollary is false.
A set that is not computably enumerable need not be $\Pi^0_2$-complete.
SEP (2016) states that the set of standard predicate tautologies of product logic is not arithmetical, so it is in no class $\Pi^0_n$.

### Generalizations

1. SEP (2016, section 8) compares three logics. The standard predicate tautologies are $\Sigma_1$-complete for Gödel logic, $\Pi_2$-complete for Łukasiewicz logic, and not arithmetical for product logic.
2. In each of these logics the general predicate tautologies are $\Sigma_1$-complete, by the general completeness theorem.

### Sources

The Fall 2016 edition of SEP calls the set $\Pi_2$-complete, and the current edition calls it $\Sigma_2$-complete, so the two editions differ.

## History

The current SEP entry attributes to Scarpellini (1962) the result that the standard tautologies of $\mathrm{Ł}\forall$ are not recursively axiomatizable.
The same entry attributes the exact class in the arithmetical hierarchy to Ragaz (1981).
The Fall 2016 edition refers to a survey by Hájek (2005) for these complexity results.

## Explanations

### L1 human

A tautology is a formula that is fully true in every situation.
For ordinary first-order logic, a computer program can list all tautologies, because a complete proof system exists.
For first-order Łukasiewicz logic with truth values in $[0, 1]$, no program can list exactly the tautologies.
Here is a small case with the formula "if $P$ holds of everything, then $P$ holds of something".
On two objects with degrees $0.3$ and $0.8$, "everything" gets $0.3$, "something" gets $0.8$, and the implication gets $1$.

### L2 human

We check that $\forall x \, P(x) \to \exists x \, P(x)$ is a standard tautology, and that the converse is not.

1. Let $\mathfrak{M}$ be a standard structure, and let $a = \inf_{m \in M} P^{\mathfrak{M}}(m)$ and $b = \sup_{m \in M} P^{\mathfrak{M}}(m)$.
2. The domain $M$ is not empty, so $a \le b$.
3. The implication has value $\min(1, 1 - a + b) = 1$, since $1 - a + b \ge 1$.
4. For the converse, take $M = \set{m_1, m_2}$ with $P(m_1) = 0.3$ and $P(m_2) = 0.8$.
5. Then $\exists x \, P(x) \to \forall x \, P(x)$ has value $\min(1, 1 - 0.8 + 0.3) = 0.5$, so it is not a tautology.

The typical use: one structure is enough to show that a formula is not a tautology.
To show that a formula is a tautology, an argument over all structures is necessary, and the theorem says that no proof system does this job completely.
A trap: the value of $\forall x \, P(x)$ is an infimum, and no element need have it.
On $M = \mathbb{N}$ with $P(n) = \tfrac{1}{n + 1}$, the value of $\forall x \, P(x)$ is $0$, while every $P(n)$ is positive.

### L3 human

Classical first-order validity is $\Sigma^0_1$-complete: it is computably enumerable by Gödel's completeness theorem, and it is undecidable.
Standard validity in $\mathrm{Ł}\forall$ lies one level higher, on the $\Pi$ side, so it is not even computably enumerable.
The cause is the continuum $[0, 1]$, with infima and suprema that need not be attained.
Over linearly ordered MV-algebras, where the semantics is general, completeness returns, and validity drops back to $\Sigma^0_1$.
The comparison of Gödel, Łukasiewicz and product logic shows how the choice of the t-norm moves standard validity through the arithmetical hierarchy.
[[Rational Pavelka logic|YG62F8YC0P]] is a related topic, where provability and truth are compared by degrees and not only at the value $1$.
