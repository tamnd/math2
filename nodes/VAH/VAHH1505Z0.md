## Statement

The first-order formulas that are fully true in every structure with truth values in $[0, 1]$ cannot be listed by any algorithm, and their set sits exactly at level $\Pi^0_2$ of the arithmetical hierarchy.

Fix a countable predicate language with infinitely many predicate symbols of each arity.
Formulas are built from atomic formulas and $\overline{0}$ with $\neg$, $\to$, $\odot$, $\oplus$, $\land$, $\lor$, $\forall$ and $\exists$.
A *standard structure* $\mathfrak{M}$ has a non-empty domain $M$ and, for each $n$-ary predicate $P$, a map $P^{\mathfrak{M}} \colon M^n \to [0, 1]$.
For an assignment $e$ of elements of $M$ to the variables, the value $\lVert \varphi \rVert_{\mathfrak{M}, e} \in [0, 1]$ is defined by induction on $\varphi$.

1. An atomic formula $P(x_1, \dots, x_n)$ gets $P^{\mathfrak{M}}(e(x_1), \dots, e(x_n))$, and $\overline{0}$ gets $0$.
2. The connectives use the operations of [[infinite-valued Łukasiewicz logic|JQ713VVD0G]], such as $x \to y = \min(1, 1 - x + y)$ and $x \odot y = \max(0, x + y - 1)$.
3. The formula $\forall x \, \varphi$ gets the infimum, and $\exists x \, \varphi$ the supremum, of the values of $\varphi$ under the assignments that differ from $e$ at most at $x$.

A *standard tautology* of first-order Łukasiewicz logic $\mathrm{Ł}\forall$ has the value $1$ in every standard structure under every assignment.
Let $\mathrm{Taut}$ be the set of their [[Gödel numbers|MFJXPAF0R0]].
A set $A \subseteq \mathbb{N}$ is *$\Pi^0_2$-complete* if it lies in the class $\Pi^0_2$ of the [[arithmetical hierarchy|7CVJCQKY41]] and every $\Pi^0_2$ set is [[many-one reducible|H5CW67CCST]] to it.

**Theorem.**
The set $\mathrm{Taut}$ is $\Pi^0_2$-complete.

**Corollary.**
The set $\mathrm{Taut}$ is not [[computably enumerable|TN9G24VABN]].
So no proof system with a computably enumerable set of axioms and decidable rules has exactly the standard tautologies of $\mathrm{Ł}\forall$ as its theorems.

## Remarks

### A first case

The formula $\forall x \, P(x) \to \exists x \, P(x)$ is a standard tautology.
In a structure, let $a$ and $b$ be the infimum and the supremum of the values of $P$.
The domain is not empty, so $a \le b$, and the implication gets $\min(1, 1 - a + b) = 1$.
The converse $\exists x \, P(x) \to \forall x \, P(x)$ is not one.
On two elements with $P$ equal to $0.3$ and $0.8$, it gets $\min(1, 1 - 0.8 + 0.3) = 0.5$.

### Why each hypothesis is needed

The standard semantics is needed.
The axioms of $\mathrm{Ł}\forall$ are complete for the general semantics over linearly ordered MV-algebras, so the general tautologies are computably enumerable, and in fact $\Sigma^0_1$-complete.

The first-order language is needed.
The propositional Łukasiewicz tautologies form a decidable set, and Mundici proved in 1987 that the set is coNP-complete.

The Łukasiewicz operations are needed.
With the Gödel operations the standard predicate tautologies are axiomatizable, so they are $\Sigma^0_1$-complete; see [[first-order Gödel logics|H8C323CV3T]].

### What it gives you

Some formula has the value $1$ in every standard structure but not in some structure over a linearly ordered MV-algebra, since the two sets of tautologies have different complexity.
The complement of $\mathrm{Taut}$ is in $\Sigma^0_2$.
By [[Post's theorem|NYJX5QXX1T]], every $\Sigma^0_2$ set is computably enumerable relative to the halting problem, so an algorithm with an oracle for the halting problem can list the non-tautologies.

### The converse

The converse of the corollary is false: a set that is not computably enumerable need not be $\Pi^0_2$-complete.
For product logic the standard predicate tautologies are not even arithmetical, so they lie in no class $\Pi^0_n$.

### Generalizations

The three main t-norm logics differ.
The standard predicate tautologies are $\Sigma^0_1$-complete for Gödel logic, $\Pi^0_2$-complete for Łukasiewicz logic, and not arithmetical for product logic.
In each of the three the general predicate tautologies are $\Sigma^0_1$-complete, by the general completeness theorem.

## History

Scarpellini proved in 1962 that the standard tautologies of $\mathrm{Ł}\forall$ are not recursively axiomatizable.
Ragaz determined the exact class in 1981, by proving that the set is $\Pi^0_2$-complete.

## Explanations

### L1 human

A tautology is a formula that is fully true in every situation.
For ordinary first-order logic a computer program can list all tautologies, because a complete proof system exists.
For first-order Łukasiewicz logic with truth values in $[0, 1]$, no program can list exactly the tautologies.
So no list of axioms and rules can prove all of them and nothing else.

### L2 human

One structure is enough to show that a formula is not a tautology, as with the two elements $0.3$ and $0.8$ above.
To show that a formula is a tautology we need an argument over all structures, and the theorem says that no proof system does this job completely.
Watch out: the value of $\forall x \, P(x)$ is an infimum, and no element needs to have it.
On $M = \mathbb{N}$ with $P(n) = \tfrac{1}{n + 1}$, the value of $\forall x \, P(x)$ is $0$, while every $P(n)$ is positive.
Here $\forall x \, P(x) \to \overline{0}$ gets the value $1$, although no single instance $P(n) \to \overline{0}$ does.

### L3 human

Classical first-order validity is $\Sigma^0_1$-complete: it is computably enumerable by Gödel's completeness theorem, and it is undecidable.
Standard validity in $\mathrm{Ł}\forall$ lies one level higher, on the $\Pi$ side, so it is not even computably enumerable.
The cause is the continuum $[0, 1]$, with infima and suprema that need not be attained.
The [[proof|EEEFJ258Q3]] derives the corollary from the theorem; the theorem itself is cited.
[[Rational Pavelka logic|YG62F8YC0P]] compares provability and truth by degrees, not only at the value $1$, and for degrees the two agree.
