## Example

Let $M$ be a countable [[non-standard model|1QWN5CV4CG]] of $\mathsf{PA}$, and let $\mathcal{K}$ be the class of all cuts of $M$.
Let $Y(a, b) = b - a$ for $a \le b$, and $Y(a, b) = 0$ for $a > b$.
We check that $Y$ is an [[indicator|JWTZ8NVVGK]] for $\mathcal{K}$.

1. $Y$ is defined by a formula of arithmetic without parameters.
2. $Y(a, b) \le b$. If $a' \le a \le b \le b'$, then $b - a \le b' - a'$, so $Y$ is monotone.
3. Let $a \le b$ with $b - a$ non-standard. Let $I$ be the set of the $x \in M$ with $x \le a + k$ for some standard $k$.
4. $I$ is closed downward. It is closed under $x \mapsto x + 1$, because $x \le a + k$ gives $x + 1 \le a + (k + 1)$.
5. $I$ contains every standard number $k \le a + k$, and $a \in I$ with $k = 0$.
6. $b \notin I$, because $b \le a + k$ would give $b - a \le k$, a standard bound. So $I$ is a cut with $a \in I < b$, and $I \ne M$.
7. Conversely, let $I$ be a cut with $a \in I < b$. Then $a + k \in I$ for each standard $k$, by closure under $x \mapsto x + 1$.
8. So $a + k < b$ for each standard $k$, because $b$ is above every element of $I$. So $b - a$ is non-standard.
9. Steps 3 to 8 show that $b - a$ is non-standard exactly when a cut separates $a$ from $b$.

## Remarks

This indicator detects every cut, so it says nothing about models of $\mathsf{PA}$.
It shows the shape of the definition with the smallest possible amount of arithmetic.

## Explanations

### L1 human

Two infinite numbers $a$ and $b$ are separated by a cut when $b$ is infinitely far above $a$.
The distance $b - a$ is then an infinite number, and conversely.
So the plain difference is an indicator for cuts.

### L2 human

The cut in step 3 is the set of numbers at a finite distance above $a$, together with everything below $a$.
The typical use of this example is as a model for the proofs of harder indicators.
The trap: the class here is all cuts, and a cut of this kind is usually not a model of $\mathsf{PA}$, because it is not closed under addition.
