## Example

The plain difference $b - a$ already detects cuts: it is infinite exactly when $b$ is infinitely far above $a$.
For a non-standard $c$, the pair $c$, $c + 5$ has difference $5$ and no cut between them, while the pair $c$, $2c$ has difference $c$ and a cut between them.

Let $M$ be a countable [[non-standard model|1QWN5CV4CG]] of $\mathsf{PA}$, and let $\mathcal{K}$ be the class of all cuts of $M$.
Let $Y(a, b) = b - a$ for $a \le b$, and $Y(a, b) = 0$ for $a > b$.
We check the three conditions for $Y$ to be an [[indicator|JWTZ8NVVGK]] for $\mathcal{K}$.

1. $Y$ is defined without parameters by the formula $(a \le b \wedge a + y = b) \vee (b < a \wedge y = 0)$.
2. $Y(a, b) \le b$ in both cases.
   If $a' \le a \le b \le b'$, then $b - a \le b' - a'$, so $Y$ is monotone.
3. Let $a \le b$ with $b - a$ non-standard.
   Let $I$ be the set of the $x \in M$ with $x \le a + k$ for some standard $k$.
4. $I$ is closed downward.
   It is closed under $x \mapsto x + 1$, because $x \le a + k$ gives $x + 1 \le a + (k + 1)$.
5. $I$ contains each standard $k$, since $k \le a + k$, and it contains $a$, with $k = 0$.
6. $b \notin I$, because $b \le a + k$ would give $b - a \le k$, a standard bound.
   So $I \ne M$, and $I$ is a cut with $a \in I < b$.
7. Conversely, let $I$ be a cut with $a \in I < b$.
   Then $a + k \in I$ for each standard $k$, by closure under $x \mapsto x + 1$.
8. So $a + k < b$ for each standard $k$, because $b$ is above every element of $I$.
   So $b - a$ is non-standard.
9. Steps 3 to 8 show that $b - a$ is non-standard exactly when a cut separates $a$ from $b$, which is condition 3.

## Remarks

The example shows the shape of the definition of an indicator with the smallest possible amount of arithmetic.
It detects every cut, so it says nothing about the cuts that are models of $\mathsf{PA}$.

The cut built in step 3 is the smallest cut that contains $a$.
It is usually not closed under addition: for $a = c$ non-standard, it contains $c$ but not $c + c$, since $c \le k$ fails for standard $k$.
So the class here is the largest possible one.
If we ask for cuts closed under doubling, the difference no longer works, and we need the [[doubling indicator|K470Y7R628]] instead: $c$ and $2c$ have non-standard difference, but no cut closed under doubling separates them.

## Explanations

### L1 human

Two infinite numbers $a$ and $b$ are separated by a cut when $b$ is infinitely far above $a$.
The distance $b - a$ is then an infinite number, and the converse also holds.
For example, an infinite number $c$ and the number $c + 5$ are close, but $c$ and $2c$ are far apart.
So the plain difference is an indicator for cuts.

### L2 human

We compute three values in a model with a non-standard element $c$.
The pair $(c, c + 5)$ gives $Y = 5$, which is standard, so no cut separates $c$ from $c + 5$.
The pair $(c, 2c)$ gives $Y = c$, which is non-standard, and the cut of the numbers below $c + k$ for some standard $k$ separates them.
The pair $(c, c^2)$ gives $Y = c^2 - c = c(c - 1)$, which is at least $c$, so the same cut separates $c$ from $c^2$.

The typical use of this example is as a model for the proofs of harder indicators.
The trap is to think that the cut it finds is a model of arithmetic.
It is not even closed under addition, as the pair $(c, 2c)$ shows.
