## Definition

Let $\Sigma$ be a finite alphabet, let $k, n, q$ be positive integers, and let $0 \le \delta < 1$ and $0 \le \varepsilon < 1/2$ be real numbers.
Let $d$ be the [[Hamming distance|EP5HNGSXFA]] on $\Sigma^n$.
A map $C \colon \set{0,1}^k \to \Sigma^n$ is a $(q, \delta, \varepsilon)$-*locally decodable code* if there is a [[randomized algorithm|2Y50S7GQTD]] $D$, the decoder, with the following properties.

1. $D$ takes an index $i \in \set{1, \dots, k}$ as input and has oracle access to a word $y \in \Sigma^n$.
2. On every input, $D$ reads at most $q$ positions of $y$.
3. For every $x \in \set{0,1}^k$, every $y \in \Sigma^n$ with $d(y, C(x)) \le \delta n$ and every $i$, the output satisfies $\Pr[D^y(i) = x_i] \ge 1 - \varepsilon$.

The number $q$ is the *query complexity* of the code.

## Remarks

Example: the binary [[Hadamard code|HSXZD57ABX]] $C(x) = (\langle x, a \rangle)_{a \in \F_2^k}$ has length $n = 2^k$.
The decoder picks $a \in \F_2^k$ uniformly at random, reads $y_a$ and $y_{a + e_i}$, and outputs $y_a + y_{a + e_i}$.
If $y = C(x)$, the output is $\langle x, e_i \rangle = x_i$.
Each of the two queried positions is uniform, so each is corrupted with probability at most $\delta$.
By the union bound the output is correct with probability at least $1 - 2\delta$, so $C$ is a $(2, \delta, 2\delta)$-locally decodable code for $\delta < 1/4$.

Non-example: the identity code $C(x) = x$ with $n = k$ and $\delta \ge 1/k$ fails clause 3 for every $q$.
Let $x'$ be $x$ with bit $i$ flipped and let $y = x'$.
Then $d(y, C(x)) = 1$ and $d(y, C(x')) = 0$, so the decoder must output both $x_i$ and $x'_i$ with probability at least $1 - \varepsilon > 1/2$, which is impossible.

Some authors require only success probability $1/2 + \varepsilon$ for binary alphabets; the two forms differ only in how the parameters are named.
