## Summary

In mathematics, especially in the area of abstract algebra that studies infinite groups, the adverb **virtually** is used to modify a property so that it need only hold for a [[subgroup|0X1JXT47GA]] of finite [[index|0DTXBQPA2S]]. Given a property P, the group *G* is said to be *virtually P* if there is a finite index subgroup $H \le G$ such that *H* has property P.
