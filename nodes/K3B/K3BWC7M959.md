## Proof

By [[linear systems as vector equations|E7SAHXQEVC]], $Ax = x_1 v_1 + \cdots + x_n v_n$ for each $x \in F^n$.

1. ("If", spanning) Let $A$ be [[invertible|0EB9N0S33C]] and $b \in F^n$. Put $x = A^{-1} b$. Then $Ax = b$, so $b$ is a combination of the columns.
2. ("If", independence) If $Ax = 0$, then $x = A^{-1}(Ax) = A^{-1} 0 = 0$. By the [[column test|76GG9B25A1]], the columns are independent.
3. So the columns form a [[basis|0VTQTPQGAV]].
4. ("Only if") Let the columns form a basis. For each $j$, the columns span, so there is $x_j \in F^n$ with $A x_j = e_j$.
5. Let $X$ be the matrix with columns $x_1, \dots, x_n$. Column $j$ of $AX$ is $A x_j = e_j$, so $AX = I$.
6. Then $A(XA - I) = (AX)A - A = A - A = 0$. So each column $y$ of $XA - I$ satisfies $Ay = 0$.
7. The columns of $A$ are independent, so $Ay = 0$ gives $y = 0$, by the column test. Hence $XA - I = 0$, and $XA = I$.
8. By steps 5 and 7, $X$ is a two-sided inverse of $A$, and $A$ is invertible.

## Idea

Spanning gives a right inverse column by column, and independence upgrades the right inverse to a two-sided inverse.
