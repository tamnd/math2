## Summary

Take the three values $0, \tfrac12, 1$ with Kleene's tables: $\neg x = 1 - x$, $\land$ is $\min$ and $\lor$ is $\max$.
Mark only $1$ as "true" and you get [[strong Kleene logic|SZHA10A9X7]]; mark both $\tfrac12$ and $1$ and you get the [[logic of paradox|BXJZG67PX3]], a different logic on the same tables.
A *logical matrix* is exactly this pair of data: the tables, which form an algebra, and the set of values that count as true.

Exactly, as in [[the definition|AJEJS6TFWP]], a logical matrix for a propositional language is a pair $M = \langle \mathbf{A}, D \rangle$, where $\mathbf{A}$ is an algebra with one operation for each connective and $D$ is a subset of its universe, the *designated values*.
A valuation is a homomorphism from the formula algebra into $\mathbf{A}$.
Then $\Gamma \models_M \varphi$ means that every valuation that designates all of $\Gamma$ designates $\varphi$.
Logical matrices are the standard semantics of [[many-valued logics|DWYCKAKXZD]], and by [[Wójcicki's theorem|VWJVAS3VE3]] every structural logic is the logic of a class of matrices.

## Motivation

A two-valued truth table already does two jobs at once: it computes values, and it says which value is "true".
With three or more values these jobs come apart, and you must give both pieces of data.
The matrix is the pair, and matrix consequence generalizes the rule that true premises give a true conclusion.

Matrices are also the standard tool for independence proofs.
To show that an axiom does not follow from the other axioms of a Hilbert system, find a matrix in which the other axioms are always designated, the rules preserve designation, and the given axiom is not always designated.
Many of the later pages use this method, for instance to show that [[Wajsberg's axiom fails in four-valued Łukasiewicz logic|BK6EPGABW8]].
In [[algebraic logic|QYA4H5Y7VR]] the matrix is the basic notion of a model of a logic.

## Notation

We write $\langle \mathbf{A}, D \rangle$ for a matrix, $\mathrm{Fm}$ for the formula algebra and $\models_M$ for matrix consequence.
For a class $\mathcal{K}$ of matrices, $\models_{\mathcal{K}}$ is the intersection of the relations $\models_M$ for $M \in \mathcal{K}$.
Some authors say "substitution-invariant" instead of "structural", since "structural" has another meaning in proof theory.
In combinatorics a "logical matrix" is a matrix with entries $0$ and $1$; that meaning is unrelated.

## Remarks

### One algebra, two logics

On Kleene's algebra, explosion $p \land \neg p \models q$ holds with $D = \{1\}$, because $\min(x, 1 - x) \le \tfrac12$ and the premise is never designated.
With $D = \{\tfrac12, 1\}$ it fails at $p = \tfrac12$, $q = 0$, because then the premise has the designated value $\tfrac12$.
Excluded middle behaves the other way round, since $\max(x, 1 - x) \ge \tfrac12$.
[[The comparison of K3 and LP|BJMXHXJ7QQ]] works out all four cases.

### Formulas as truth values

The formula algebra itself can serve as the algebra of a matrix.
For classical logic, the [[Lindenbaum matrix|ZV4GTXRRCV]] $\langle \mathrm{Fm}, \mathrm{Cn}(\emptyset) \rangle$ has formulas as values and theorems as designated values.
A valuation is then a substitution, and a formula is a tautology of this matrix exactly when all its substitution instances are theorems.
This is how [[Wójcicki's theorem|VWJVAS3VE3]] gives a matrix semantics to every structural logic.

### The rules you can use

Every relation $\models_{\mathcal{K}}$ is a [[consequence relation|J78Y1M4GND]]: reflexive and monotone at once, and closed under cut because a valuation that designates $\Gamma$ and each lemma also designates the conclusion.
It is also structural, since a valuation composed with a substitution is again a valuation.
If $\langle \mathbf{B}, E \rangle$ is a submatrix of $\langle \mathbf{A}, D \rangle$, with $E = D \cap B$, then every inference valid in the larger matrix is valid in the smaller one, because each valuation into $\mathbf{B}$ is a valuation into $\mathbf{A}$.
The consequence relation of a finite matrix is finitary, by a compactness argument over the finitely many values.

### What it is not

A probability function on formulas is not a valuation of any matrix, because no operation on $[0, 1]$ computes $P(\varphi \land \psi)$ from $P(\varphi)$ and $P(\psi)$, as [[the example on probability|EVW7FAWM68]] shows.
[[Suszko's two-valued semantics|MAYHP6P8NC]] uses two values but no matrix, because its valuations are not homomorphisms.
A Kripke model of intuitionistic logic gives truth at worlds, not values in an algebra, and becomes a matrix only after passing to the Heyting algebra of up-sets.

### Watch out

In an independence proof it is not enough to check the axioms.
Each rule must also preserve designated values, and [[a matrix that breaks modus ponens|SHCDQRD4ZK]] proves nothing.
Also, "$\varphi$ is a tautology of $M$" means that $\varphi$ is always in $D$, not that it always takes the top value.
In the logic of paradox $p \lor \neg p$ is a tautology although its value at $p = \tfrac12$ is only $\tfrac12$.

### History

Łukasiewicz and Tarski set out the notion of a logical matrix with designated values in their joint paper of 1930.
Łoś and Suszko introduced structural consequence relations in 1958.
Wójcicki proved in 1970 that every structural consequence relation is given by a class of matrices, and his book "Theory of Logical Calculi" of 1988 presents the theory.

### Try it

First, in the matrix on $\{0, \tfrac12, 1\}$ with $D = \{\tfrac12, 1\}$ and $x \to y = \max(1 - x, y)$, does modus ponens hold?
No: at $p = \tfrac12$ and $q = 0$, both $p$ and $p \to q = \max(\tfrac12, 0) = \tfrac12$ are designated, but $q$ is not.

Second, with the same tables and $D = \{1\}$, does it hold?
Yes: $p = 1$ gives $p \to q = \max(0, q) = q$, so a designated $p \to q$ forces $q = 1$.

## Explanations

### L1 human

A logical matrix is a system of truth tables together with a list of "good" values.
The tables tell you how to compute the value of a compound sentence.
The good values tell you which values count as true.
An argument is valid in the matrix when good premises always give a good conclusion.

### L2 human

We use a matrix to show that a formula is not provable in a Hilbert system for classical logic minus one axiom.
Suppose the remaining axioms all take the value $1$ in a three-valued matrix with $D = \{1\}$, and modus ponens preserves the value $1$.
Then every theorem of the smaller system takes the value $1$, by induction on the length of a proof.
If the dropped axiom takes the value $\tfrac12$ at some valuation, it is not a theorem of the smaller system, so it is independent.
This is the typical use of matrices.
Watch out: the induction step needs the rule to preserve $D$, so test the rule before you trust the result.

### L3 human

In abstract algebraic logic a matrix is a model of a logic, and the Leibniz congruence of a matrix identifies the values that no formula context can separate.
Reduced matrices, in which this congruence is the identity, give the algebraic counterpart of a logic, as studied in [[algebraic logic|QYA4H5Y7VR]].
Generalized matrices, with a family of designated sets, and non-deterministic matrices, with sets of possible values, extend the idea in two directions.
