## Example

Let $\sigma$ be a [[signature|WDVVEYD6AT]] with a constant symbol $c$ and a unary relation symbol $P$.
We show that the string $\forall c \, P(c)$ is not a [[well-formed formula|HYJ10AF6RT]] over $\sigma$.
The idea is to look at how the strings from each clause of the [[definition|2CHENV4DCC]] begin.

1. Clause 1 gives $t_1 = t_2$, which starts with the first symbol of a term: a variable, a constant symbol or a function symbol.
2. Clause 2 gives $R(t_1, \ldots, t_n)$, which starts with a relation symbol.
3. Clause 3 gives a string that starts with $\neg$, and clause 4 gives a string that starts with a left bracket.
4. Clause 5 gives $\forall x \, \varphi$ or $\exists x \, \varphi$ with $x$ a variable.
   So every formula that starts with $\forall$ has a variable as its second symbol.
5. The second symbol of $\forall c \, P(c)$ is $c$, a constant symbol, and the variables are disjoint from the symbols of $\sigma$.
6. So no clause produces $\forall c \, P(c)$, and the string is not in the smallest set closed under the clauses.

## Remarks

The string $P(c)$ is a formula by clause 2, and it says that the object named $c$ has the property $P$.
To say that every object has $P$, we write $\forall x \, P(x)$ with a variable.
A constant symbol names one fixed object in each structure, so a quantifier over it would have nothing to range over.

The same argument rejects other strings.
The string $\exists f(x) \, P(x)$ is not a formula, because $f(x)$ is a term but not a variable.
The string $\forall P \, P(x)$ is not a formula either, since $P$ is a relation symbol; [[second-order logic|G6X7SZSNC5]] allows such quantifiers over relation variables.

Watch out for the opposite mistake.
The string $\forall x \, \forall x \, P(x)$ looks wrong, but it is a formula, because clause 5 does not ask that $x$ is free in its argument.
Its outer quantifier binds nothing and has no effect.

Some proof systems use parameters or eigenvariables that behave like constants in some rules and like variables in others.
They are still kept apart from the constant symbols of the signature.

## Explanations

### L1 human

A quantifier says "for every thing" or "there is a thing", and it needs a blank to fill.
A variable is such a blank, as in "for every $\_$, $\_$ is even or odd".
A constant is a fixed name, like "Paris" or $0$.
"For every $0$, $0$ is even" makes no sense, because $0$ is not a blank.
So the rules allow $\forall x$ but not $\forall 0$ or $\forall c$.

### L2 human

The method is a general way to prove that a string is not a formula: find a property of formulas that every clause keeps, and show that the string lacks it.
Here the property is "if the first symbol is $\forall$ or $\exists$, the second symbol is a variable".
Clauses 1 to 4 never produce a string that starts with a quantifier, so they keep the property for free.
Clause 5 puts a variable right after the quantifier, so it keeps the property too.
The string $\forall c \, P(c)$ lacks the property, so it is not a formula.
