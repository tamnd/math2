## Definition

Let $s \in \set{1/2, 1, 3/2, \dots}$.
Let $\lvert 0 \rangle, \lvert 1 \rangle, \lvert 2 \rangle, \dots$ be the number basis of the one-mode boson [[Fock space|1TJ8TNH331]], with annihilation and creation operators $b \lvert n \rangle = \sqrt{n} \lvert n-1 \rangle$ and $b^\dagger \lvert n \rangle = \sqrt{n+1} \lvert n+1 \rangle$, and number operator $\hat n = b^\dagger b$.
Let $\mathcal{H}_s$ be the span of $\lvert 0 \rangle, \dots, \lvert 2s \rangle$.
The *Holstein–Primakoff transformation* defines the operators on $\mathcal{H}_s$
$$S^z = s - \hat n, \qquad S^+ = \sqrt{2s - \hat n} \, b, \qquad S^- = b^\dagger \sqrt{2s - \hat n}.$$
Here $\sqrt{2s - \hat n}$ acts on $\lvert n \rangle$ by multiplication by $\sqrt{2s - n}$, which is real for $0 \le n \le 2s$.
With $S^x = (S^+ + S^-)/2$ and $S^y = (S^+ - S^-)/(2i)$, these operators satisfy $[S^z, S^\pm] = \pm S^\pm$ and $[S^+, S^-] = 2 S^z$, and they form the spin-$s$ irreducible representation of the spin algebra.

## Remarks

Check: $S^+ \lvert n \rangle = \sqrt{n(2s - n + 1)} \lvert n-1 \rangle$ and $S^- \lvert n \rangle = \sqrt{(n+1)(2s - n)} \lvert n+1 \rangle$.
With $m = s - n$ these are the standard formulas $\sqrt{(s - m)(s + m + 1)}$ and $\sqrt{(s + m)(s - m + 1)}$ for the raising and lowering operators on the state of $S^z$-eigenvalue $m$.
Since $S^- \lvert 2s \rangle = 0$ and $S^+ \lvert 0 \rangle = 0$, the space $\mathcal{H}_s$ is invariant.
See also the [[representation theory of SU(2)|9V6PRD1Z90]].

Example: for $s = 1/2$, $\mathcal{H}_s$ is spanned by $\lvert 0 \rangle$ (spin up) and $\lvert 1 \rangle$ (spin down), and $S^+ \lvert 1 \rangle = \sqrt{1 \cdot 1} \lvert 0 \rangle = \lvert 0 \rangle$, $S^z \lvert 0 \rangle = \tfrac12 \lvert 0 \rangle$.

Non-example: dropping the square root, the operators $\sqrt{2s}\, b$, $\sqrt{2s}\, b^\dagger$ and $s - \hat n$ fail the relation $[S^+, S^-] = 2S^z$, since $[\sqrt{2s}\, b, \sqrt{2s}\, b^\dagger] = 2s$ is a constant.
They are only the leading terms of the expansion in $1/s$, which is linear spin-wave theory for a ferromagnet such as the [[quantum Heisenberg model|5QG15H8P5J]].
