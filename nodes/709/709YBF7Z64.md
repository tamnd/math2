## Definition

Let $I \subseteq \R$ be an interval of wealth levels and let $u \colon I \to \R$ be a utility function for an agent who follows the [[expected utility hypothesis|8C2N37XPJ8]].
A lottery is a random variable $W$ with finitely many values, all in $I$.
The agent is *risk averse* if $u(\mathbb{E}[W]) \ge \mathbb{E}[u(W)]$ for every lottery $W$.
The agent is *strictly risk averse* if moreover $u(\mathbb{E}[W]) > \mathbb{E}[u(W)]$ for every lottery $W$ that is not constant.
The agent is *risk neutral* if equality holds for every lottery, and *risk loving* if the reverse inequality $\le$ holds for every lottery.

## Remarks

Let $I = [0, \infty)$ and $u(w) = \sqrt{w}$, and let $W$ take the values $0$ and $100$ with probability $1/2$ each.
Then $u(\mathbb{E}[W]) = \sqrt{50} \approx 7.07$ and $\mathbb{E}[u(W)] = 5$, consistent with risk aversion; indeed $\sqrt{\cdot}$ is concave, so the inequality holds for all lotteries.
The utility $u(w) = w^2$ on $[0, \infty)$ is not risk averse: for the same $W$, $u(\mathbb{E}[W]) = 2500 < 5000 = \mathbb{E}[u(W)]$.
The agent is risk averse if and only if $u$ is a [[concave function|0GCM7B6PBK]].
Concavity gives the inequality by [[Jensen's inequality|0RWMRTPC87]], and lotteries with two values give back the definition of concavity.
In the same way, strict risk aversion is equivalent to strict concavity, and risk neutrality to $u$ being affine.
