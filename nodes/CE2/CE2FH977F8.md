## Definition

Let $G = (N, \Sigma, P, S)$ be a [[formal grammar|DP1HXZGPCM]], with $A, B \in N$, $a \in \Sigma$, and $\alpha, \beta, \gamma \in (N \cup \Sigma)^*$.
The grammar $G$ is of:

1. *type 0* always; these are the [[unrestricted grammars|4WNNN9726C]];
2. *type 1* if every rule has the form $\alpha A \beta \to \alpha \gamma \beta$ with $\gamma$ nonempty, except possibly $S \to \varepsilon$ when $S$ occurs on no right side;
3. *type 2* if every rule has the form $A \to \gamma$;
4. *type 3* if every rule has the form $A \to aB$, $A \to a$ or $A \to \varepsilon$.

A language is of type $i$ if it is generated by a grammar of type $i$.
The *Chomsky hierarchy* is the chain of the four classes of languages of types $3, 2, 1, 0$.

## Remarks

The languages of types $0, 1, 2, 3$ are the [[recursively enumerable languages|67R1A5Y54R]], the [[context-sensitive languages|NYJ7PD4025]], the [[context-free languages|Q56EWEQYE2]] and the [[regular languages|18WVBDCS38]].
They form a strictly increasing chain: type $3 \subsetneq$ type $2 \subsetneq$ type $1 \subsetneq$ type $0$.
Example: $\set{a^n b^n : n \ge 0}$ is of type 2 but not of type 3, and $\set{a^n b^n c^n : n \ge 1}$ is of type 1 but not of type 2.
Every type-1 language is decidable, so an undecidable recursively enumerable language, such as the halting problem, is of type 0 but not of type 1.
Non-example: a grammar with the rule $AB \to a$ is of type 0 but not of type 1, since the rule shortens the string.
It is not of type 2 either, since its left side has two symbols.
