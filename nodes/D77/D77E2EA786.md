## Example

For an integer $n$, let $P$ be "$4$ [[divides|096PW7Q014]] $n$", and let $Q$ be "$n$ is even".
The [[conditional statement|FA6YZGR2SS]] "if $P$, then $Q$" is true for every integer $n$.
We first check the truth value, and then we list the English forms of the same conditional.

1. Suppose $P$ is true. Then $n = 4k$ for an integer $k$.
2. So $n = 2(2k)$, and $2k$ is an integer. So $n$ is even, and $Q$ is true.
3. So no integer has $P$ true and $Q$ false, and the conditional is true for every $n$.
4. Three of the four cases occur: $n = 8$ has $P$ and $Q$ true; $n = 6$ has $P$ false and $Q$ true; $n = 7$ has $P$ and $Q$ false. The case "$P$ true, $Q$ false" never occurs.

Each of the following sentences states the same conditional, with "for every integer $n$" understood.

1. If $4$ divides $n$, then $n$ is even.
2. $4$ divides $n$ implies that $n$ is even.
3. $n$ is even if $4$ divides $n$.
4. $4$ divides $n$ only if $n$ is even.
5. $n$ is even whenever $4$ divides $n$.
6. Divisibility by $4$ is sufficient for $n$ to be even.
7. Evenness is necessary for divisibility by $4$.

## Remarks

The example shows that the hypothesis need not come first in the sentence.
In forms 3 and 5, the conclusion comes first.
In form 4, the words "only if" come before the conclusion, not before the hypothesis.

The sentences below are not forms of the same conditional.
"$n$ is even only if $4$ divides $n$" is the converse, and it is false: for $n = 2$, the number is even, but $4$ does not divide it.
"$4$ divides $n$ if and only if $n$ is even" is also false, for the same $n = 2$.
The words "necessary" and "sufficient" are explained on the page [[necessary and sufficient conditions|09BJQQB3VS]].

If we replace $4$ by $2$, then both directions hold, and the biconditional "$2$ divides $n$ if and only if $n$ is even" is true.

## Explanations

### L1 human

"If a number can be split into $4$ equal whole parts, then it is even" is true.
Here are other ways to say the same thing.
"A number is even if it can be split into $4$ equal whole parts."
"A number can be split into $4$ equal whole parts only if it is even."
"Being even is necessary for being split into $4$ equal whole parts."
All of them say: a number that splits into $4$ parts is never odd.

### L2 human

We rewrite "$n$ is a multiple of $6$ only if $n$ is a multiple of $3$" in the "if ... then" form, and we check it.

1. "$A$ only if $B$" means "if $A$, then $B$". So the statement is "if $n$ is a multiple of $6$, then $n$ is a multiple of $3$".
2. Suppose $n = 6k$ for an integer $k$. Then $n = 3(2k)$, so $n$ is a multiple of $3$.
3. So the statement is true for every integer $n$.
4. The converse, "if $n$ is a multiple of $3$, then $n$ is a multiple of $6$", is false: $n = 3$ is a counterexample.

The typical use of this rewriting is in the reading of theorems with "only if" or "necessary", before any proof starts.

A trap: the phrase "only if" sounds like a restriction on the conclusion, so many readers turn the arrow around.
The test in step 1 avoids this error.
