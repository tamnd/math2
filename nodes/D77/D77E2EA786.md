## Example

For an integer $n$, let $P$ be "$4$ [[divides|096PW7Q014]] $n$", and let $Q$ be "$n$ is even".
We check that the [[conditional statement|FA6YZGR2SS]] "if $P$, then $Q$" is true for every integer $n$, and then we list its English forms.

1. Suppose $P$ is true.
   Then $n = 4k$ for some integer $k$.
2. So $n = 2(2k)$, and $2k$ is an integer.
   So $n$ is even, and $Q$ is true.
3. So no integer has $P$ true and $Q$ false, and the conditional holds for every $n$.
4. Three of the four patterns of truth values occur.
   For $n = 8$ both $P$ and $Q$ are true, for $n = 6$ only $Q$ is true, and for $n = 7$ both are false.
   The pattern "$P$ true, $Q$ false" never occurs.

Each of the following sentences states the same conditional, with "for every integer $n$" understood.

1. If $4$ divides $n$, then $n$ is even.
2. That $4$ divides $n$ implies that $n$ is even.
3. $n$ is even if $4$ divides $n$.
4. $4$ divides $n$ only if $n$ is even.
5. $n$ is even whenever $4$ divides $n$.
6. Divisibility by $4$ is sufficient for $n$ to be even.
7. Evenness is necessary for divisibility by $4$.

## Remarks

The hypothesis need not come first in the sentence.
In forms 3 and 5 the conclusion comes first.
In form 4 the words "only if" stand before the conclusion, not before the hypothesis.

Two similar sentences say something else.
"$n$ is even only if $4$ divides $n$" is the converse, and it is false: $2$ is even, and $4$ does not divide $2$.
"$4$ divides $n$ if and only if $n$ is even" is false for the same $n = 2$.
If we replace $4$ by $2$, both directions hold, and "$2$ divides $n$ if and only if $n$ is even" is true.
The words "necessary" and "sufficient" are explained in [[necessary and sufficient conditions|09BJQQB3VS]].

## Explanations

### L1 human

"If a number can be split into $4$ equal whole parts, then it is even" is true.
Here are other ways to say the same thing.
"A number is even if it can be split into $4$ equal whole parts."
"A number can be split into $4$ equal whole parts only if it is even."
"Being even is necessary for being split into $4$ equal whole parts."
All of them say that a number that splits into $4$ equal parts is never odd.

### L2 human

Rewrite "$n$ is a multiple of $6$ only if $n$ is a multiple of $3$" in the form "if ... then", and check it.
"$A$ only if $B$" means "if $A$, then $B$", so the sentence says "if $n$ is a multiple of $6$, then $n$ is a multiple of $3$".
Suppose $n = 6k$ for an integer $k$.
Then
$$n = 3(2k),$$
so $n$ is a multiple of $3$, and the sentence is true for every integer $n$.
The converse, "if $n$ is a multiple of $3$, then $n$ is a multiple of $6$", is false, and $n = 3$ is a counterexample.

Watch out: "only if" sounds like a restriction on the conclusion, so many readers turn the arrow around.
Rewriting it as "if ... then" first is the cure, and it is the right first step with every theorem that uses "only if" or "necessary".
