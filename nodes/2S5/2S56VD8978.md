## Definition

Let persons $n = 1, \dots, N$ answer items $i = 1, \dots, I$, and let $X_{ni} \in \set{0, 1}$ be the [[random variable|0PNRKMRC55]] that equals $1$ when person $n$ answers item $i$ correctly.
The *dichotomous Rasch model* with person parameters $\beta_n \in \R$ (abilities) and item parameters $\delta_i \in \R$ (difficulties) states that:

1. the variables $X_{ni}$ are independent;
2. for all $n$ and $i$,
$$P(X_{ni} = 1) = \frac{e^{\beta_n - \delta_i}}{1 + e^{\beta_n - \delta_i}}.$$

## Remarks

Equivalently, the log-odds of a correct answer is $\ln \frac{P(X_{ni} = 1)}{P(X_{ni} = 0)} = \beta_n - \delta_i$, a [[logistic regression|JN1PJ5AJJS]] with one parameter per person and per item.
Example: $\beta_n = 1$ and $\delta_i = 1$ give probability $1/2$; $\beta_n - \delta_i = \ln 3$ gives $3/4$.
Non-example: the two-parameter logistic model $P(X_{ni} = 1) = e^{a_i(\beta_n - \delta_i)}/(1 + e^{a_i(\beta_n - \delta_i)})$ with item slopes $a_i$ not all equal is not a Rasch model once two persons have different abilities.
There the log-odds gap between two persons, $a_i(\beta_n - \beta_m)$, depends on the item, while in the Rasch model it is the same for every item.
The parameters are determined only up to a common additive constant, so one usually fixes $\sum_i \delta_i = 0$.
The raw score $\sum_i X_{ni}$ is a sufficient statistic for $\beta_n$, which allows estimating item difficulties by conditioning on the scores.
