## Example

The signature has a constant $0$, a unary function symbol $S$ and binary function symbols $+$ and $\cdot$.
[[Robinson arithmetic|3K1AKGXF8A]] $\mathsf{Q}$ is the theory axiomatized by these seven sentences.

1. $\forall x \, (S x \neq 0)$.
2. $\forall x \, \forall y \, (S x = S y \to x = y)$.
3. $\forall x \, (x \neq 0 \to \exists y \, (x = S y))$.
4. $\forall x \, (x + 0 = x)$.
5. $\forall x \, \forall y \, (x + S y = S (x + y))$.
6. $\forall x \, (x \cdot 0 = 0)$.
7. $\forall x \, \forall y \, (x \cdot S y = x \cdot y + x)$.

We check that $\mathsf{Q}$ is not a [[decidable theory|HWC687ES0Q]].

1. The set of axioms is finite, hence computable. So the set of consequences of $\mathsf{Q}$ is computably enumerable.
2. $\mathsf{Q}$ is consistent: the standard structure $(\N, 0, S, +, \cdot)$ satisfies the seven axioms.
3. $\mathsf{Q}$ is [[essentially undecidable|~c0b3bb9c]]: every consistent theory in the same signature that contains $\mathsf{Q}$ is undecidable; see [[Robinson arithmetic is essentially undecidable|~2685d084]].
4. $\mathsf{Q}$ is a consistent theory that contains $\mathsf{Q}$, so by step 3 it is undecidable.

So the condition of decidability fails: no algorithm decides, for each sentence $\sigma$, whether $\mathsf{Q} \models \sigma$.

## Remarks

The example shows that a finite set of axioms does not make a theory decidable.
The proof of decidability for complete theories does not apply, because $\mathsf{Q}$ is not complete.
For example, $\mathsf{Q}$ does not prove $\forall x \, \forall y \, (x + y = y + x)$, since a nonstandard model of $\mathsf{Q}$ violates this law.

Since $\mathsf{Q}$ is finitely axiomatized, let $\alpha$ be the conjunction of its seven axioms.
Then $\mathsf{Q} \models \sigma$ if and only if $\alpha \to \sigma$ is valid.
So a decision procedure for validity would decide $\mathsf{Q}$, and this gives a proof of [[Church's theorem|VA6BNNY2YC]].

When a parameter changes, the result changes in this way.

- If multiplication is removed, together with axioms 6 and 7, the theory of the structure $(\N, 0, S, +)$ is decidable, by [[Presburger arithmetic|~14d8268c]].
- If more axioms are added, for example the induction axioms of Peano arithmetic, the theory stays undecidable, as long as it is consistent.

## Explanations

### L1 human

Robinson arithmetic is a short list of seven basic rules about counting, adding and multiplying whole numbers.
A computer can list everything that follows from these seven rules, one result after another.
But no computer program can take any statement and decide, after finite time, whether it follows from the rules.
So a short list of rules can still produce a theory that is too complex for any algorithm.

### L2 human

We see why proof search fails on the sentence $\sigma = \forall x \, (0 + x = x)$.

1. The algorithm that lists proofs from $\mathsf{Q}$ would answer "yes" if it found a proof of $\sigma$.
2. For each numeral, $\mathsf{Q}$ proves $0 + \bar{n} = \bar{n}$, by $n$ uses of axiom 5 and one use of axiom 4.
3. But $\sigma$ itself is not provable in $\mathsf{Q}$: there are models of $\mathsf{Q}$ with extra elements $a$ where $0 + a \neq a$.
4. Its negation is not provable either, since $\sigma$ is true in $\N$.
5. So the proof search for $\sigma$ or $\neg \sigma$ runs forever.

The typical use of $\mathsf{Q}$ is as the base theory for undecidability: a theory that interprets $\mathsf{Q}$ in a suitable way is undecidable.
A trap is to think that undecidability of $\mathsf{Q}$ follows from step 5.
One sentence on which a search fails does not exclude another algorithm; the proof needs essential undecidability.
