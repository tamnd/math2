## Example

Let $\set{e}(n)$ denote the result of the $e$-th partial [[computable function|KZSB5E471K]] on input $n$, and let $\langle a, b \rangle$ be a pairing function on $\mathbb{N}$.
We write "$\set{e}(n) \in X$" for the positive formula $\exists m \, (\set{e}(n) \text{ halts with output } m \wedge X(m))$.

The operator of the first tree class is

$$A_1(X, x) \;=\; x = 0 \;\vee\; \exists y \, (x = \langle 1, y \rangle \wedge X(y)) \;\vee\; \exists e \, \big( x = \langle 2, e \rangle \wedge \forall n \, (\set{e}(n) \in X) \big).$$

The operator of the second tree class has one more clause, which branches over the first class $\mathcal{O}_1$:

$$A_2(X, Y, x) \;=\; A_1(X, x) \;\vee\; \exists e \, \big( x = \langle 3, e \rangle \wedge \forall a \, (Y(a) \to \set{e}(a) \in X) \big).$$

We check that these operators define $\mathcal{O}_1$ and $\mathcal{O}_2$ in $\mathrm{ID}_2$, in the sense of the [[definition|~cd19a8f1]].

1. The ordering. Take $\prec$ on $\set{0, 1}$ with $0 \prec 1$, a primitive recursive well-ordering of type $2$.
2. One operator for both stages. Let $A(X, Y, \mu, x)$ be $A_1(X, x)$ when $\mu = 0$, and $A_2(X, Y(0, \cdot), x)$ when $\mu = 1$. This is a single formula, by cases on $\mu$.
3. Positivity in $X$. In $A_1$, the variable $X$ occurs only under $\exists$, $\forall$, $\wedge$ and $\vee$, never under a negation. In the new clause of $A_2$, $X$ occurs in the consequent of $\to$, which is positive.
4. The predicate $Y$ occurs negatively in $A_2$, in the antecedent $Y(a)$. The definition of $\mathrm{ID}_\nu$ puts no condition on $Y$, so this is allowed.
5. So stage $0$ is $\mathcal{O}_1 = P^0_A$, and stage $1$ is $\mathcal{O}_2 = P^1_A$, the least fixed point of $A_2(\cdot, \mathcal{O}_1, \cdot)$.

In the standard model, $\mathcal{O}_1$ is the set of codes of well-founded computable trees with branching over $\mathbb{N}$.
The set $\mathcal{O}_2$ also contains trees that branch over all elements of $\mathcal{O}_1$.

## Remarks

The example shows why the stages are iterated: the clause $\forall a \, (a \in \mathcal{O}_1 \to \dots)$ uses $\mathcal{O}_1$ negatively, so it cannot be part of the same positive definition as $\mathcal{O}_1$.
In $\mathrm{ID}_2$ the class $\mathcal{O}_1$ is fixed at an earlier stage, and then it may appear anywhere.
Continuing, $\mathcal{O}_{\mu + 1}$ branches over $\mathcal{O}_\mu$, and the theory $\mathrm{ID}^i_\nu(\mathcal{O})$ has exactly these tree classes for $\mu < \nu$, over intuitionistic logic.
The class $\mathcal{O}_1$ is close to [[Kleene's O|WHAP0K600D]]: Kleene's set uses the same three kinds of codes, but it also asks that the sequence $\set{e}(0), \set{e}(1), \dots$ increase.
The trees of $\mathcal{O}_1$ are a model of the countable ordinals in constructive mathematics, often called Brouwer ordinals.
The class $\mathcal{O}_2$ plays the role of a higher number class, with branching over $\mathcal{O}_1$ instead of over $\mathbb{N}$.

## Explanations

### L1 human

A tree in $\mathcal{O}_1$ is either a single point, or a point on top of one smaller tree, or a point on top of an infinite list of smaller trees, given by a program.
Every branch of such a tree ends after finitely many steps.
A tree in $\mathcal{O}_2$ may also sit on top of a family of trees, with one tree for each tree of $\mathcal{O}_1$.
To define the second kind we must already know which trees are of the first kind, so we build the classes one after the other.

### L2 human

We check that a code for $\omega$ is in $\mathcal{O}_1$.

1. Let $s_0 = 0$ and $s_{n+1} = \langle 1, s_n \rangle$, and let $e$ be a program with $\set{e}(n) = s_n$ for every $n$.
2. The first clause of $A_1$ and the closure axiom give $s_0 \in \mathcal{O}_1$.
3. If $s_n \in \mathcal{O}_1$, the second clause and the closure axiom give $s_{n+1} \in \mathcal{O}_1$. By induction on $n$, every $s_n$ is in $\mathcal{O}_1$.
4. So $\forall n \, (\set{e}(n) \in \mathcal{O}_1)$, and the third clause gives $\langle 2, e \rangle \in \mathcal{O}_1$.

The code $s_n$ stands for the natural number $n$, and $\langle 2, e \rangle$ stands for their limit $\omega$.
The typical use of these classes is in the reduction of subsystems of analysis to theories of inductive definitions.
The trap is to put the clause with $Y$ into $A_1$ itself: then $\mathcal{O}_1$ would occur negatively in its own definition.
