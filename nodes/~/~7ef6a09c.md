## Statement

Let $K$ be a commutative ring, let $A$ be an $n \times n$ matrix over $K$, and let $c \in K$.
Let $B$ be the matrix that we get from $A$ when we multiply one row by $c$.
Then $\det B = c \det A$, where $\det$ is the [[determinant|~362fc72a]].

## Remarks

This is a special case of [[linearity in each row|~6e067c97]].
It describes the effect of the scaling [[row operation|~6bd67cbb]] on the determinant.
Scaling all $n$ rows gives $\det(cA) = c^n \det A$, see [[the determinant of a scalar multiple|~5943b179]].

## Explanations

### L1 human

If we stretch one edge of a box by the factor $c$, then its volume is multiplied by $c$.
The determinant behaves in the same way.
For example, doubling one row doubles the determinant.
