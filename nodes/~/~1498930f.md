## Example

Let $f \colon \R \to \R$ be the squaring map, $f(x) = x^2$.
Here $\R$ is a vector space over itself.
We check the conditions of a [[linear map|0RJF668P1T]].

1. Zero. $f(0) = 0$, so this test does not rule out linearity.
2. Additivity. Take $u = v = 1$. Then $f(u + v) = f(2) = 4$, but $f(u) + f(v) = 1 + 1 = 2$. So additivity fails.
3. Homogeneity. Take $a = 2$ and $v = 1$. Then $f(2 \cdot 1) = 4$, but $2 \cdot f(1) = 2$. So homogeneity fails.

So $f$ is not a linear map, although it sends $0$ to $0$.

## Remarks

The example shows that $f(0) = 0$ does not imply linearity.
In general $f(u + v) - f(u) - f(v) = 2uv$, so additivity fails for each pair with $u \ne 0$ and $v \ne 0$.
Also $f(av) = a^2 f(v)$, so homogeneity holds only for $a \in \{0, 1\}$ or $v = 0$.
The linear maps $\R \to \R$ are exactly the maps $x \mapsto cx$ for a constant $c$, by the [[theorem on matrix transformations|W6KB0J3SZZ]] with $n = m = 1$.

## Explanations

### L1 human

Squaring does not respect sums: $(1 + 2)^2 = 9$, but $1^2 + 2^2 = 5$.
So squaring is not linear.
This is a common error in algebra, where $(a + b)^2$ is wrongly written as $a^2 + b^2$.

### L2 human

To disprove linearity, one instance is enough, and here $u = v = 1$ works.
The graph of a linear map $\R \to \R$ is a line through the origin, and the graph of $x^2$ is a parabola.
The trap is to test only $f(0) = 0$, which this map passes.
