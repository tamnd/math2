## Example

Let $f_n \colon [a, b] \to \mathbb{R}$ be [[Riemann integrable|0F2QCWVFT7]] for each $n$, with $a < b$.
Suppose that $f_n \to f$ [[uniformly on $[a, b]$|08HJRTG5N7]].
We prove by an [[epsilon over three argument|~9f05a67c]] that $f$ is Riemann integrable.
For a bounded function $g$ and a partition $P$ of $[a, b]$, we write $U(g, P)$ and $L(g, P)$ for the [[upper and lower Darboux sums|0QRQVH0CRW]].

1. The function $f$ is bounded. There is $N_0$ with $\lvert f_{N_0}(x) - f(x) \rvert < 1$ for all $x$, so $\lvert f(x) \rvert < \sup \lvert f_{N_0} \rvert + 1$.
2. Let $\varepsilon > 0$. By [[Riemann's criterion|017DH8WXTE]], it is enough to find a partition $P$ with $U(f, P) - L(f, P) < \varepsilon$.
3. By uniform convergence, there is an index $N$ and a number $\eta < \frac{\varepsilon}{3(b - a)}$ with $\lvert f_N(x) - f(x) \rvert \le \eta$ for all $x \in [a, b]$. We fix this $N$.
4. The function $f_N$ is Riemann integrable. So there is a partition $P$ with $U(f_N, P) - L(f_N, P) < \varepsilon/3$.
5. Let $I$ be an interval of $P$, of length $\lvert I \rvert$. For $x \in I$ we have $f(x) \le f_N(x) + \eta \le \sup_I f_N + \eta$, so $\sup_I f \le \sup_I f_N + \eta$. In the same way $\inf_I f \ge \inf_I f_N - \eta$.
6. We multiply by $\lvert I \rvert$ and add over the intervals of $P$. The lengths add up to $b - a$, so
$$U(f, P) \le U(f_N, P) + \eta (b - a), \qquad L(f, P) \ge L(f_N, P) - \eta (b - a).$$
7. So $U(f, P) - L(f, P) \le \eta (b - a) + \big( U(f_N, P) - L(f_N, P) \big) + \eta (b - a) < \frac{\varepsilon}{3} + \frac{\varepsilon}{3} + \frac{\varepsilon}{3} = \varepsilon$.

The three terms in step 7 are the three terms of the method.
The two outer terms compare $f$ with $f_N$, and the middle term is a property of $f_N$ alone.

## Remarks

1. A concrete case: let $H(t) = 1$ for $t \ge 0$ and $H(t) = 0$ for $t < 0$, and let $f(x) = \sum_{k = 1}^{\infty} 2^{-k} H(x - \frac1k)$ on $[0, 1]$.
2. The partial sum $f_n$ is a step function with $n$ jumps, so it is Riemann integrable. The tail gives $\lvert f(x) - f_n(x) \rvert \le \sum_{k > n} 2^{-k} = 2^{-n}$ for all $x$, so the convergence is uniform.
3. By the example, $f$ is Riemann integrable, although it has a jump of size $2^{-k}$ at each point $\frac1k$, so it has infinitely many discontinuities.
4. The order of the choices is the same as in the [[uniform limit theorem|0X9XT05JVC]]: the index $N$ is fixed first, and the partition $P$ depends on $N$.
5. With [[pointwise convergence|056FSKG32J]] the result fails. Let $r_1, r_2, \ldots$ list the rational numbers of $[0, 1]$, and let $f_n$ be $1$ at $r_1, \ldots, r_n$ and $0$ elsewhere. Each $f_n$ has integral $0$, but the pointwise limit is $1$ on the rationals and $0$ on the irrationals. Each upper sum of the limit is $1$, and each lower sum is $0$.
6. The same estimate gives $\left\lvert \int_a^b f_n - \int_a^b f \right\rvert \le (b - a) \sup \lvert f_n - f \rvert$, which is the statement that [[uniform limits commute with integration|0BWGW68B66]].

## Explanations

### L1 human

The integral of a function is squeezed between an upper estimate and a lower estimate made from rectangles.
A function is Riemann integrable when the rectangles can make the two estimates as close as we like.
Suppose a nice function stays within a thin band around $f$ everywhere.
Then the rectangles for $f$ differ from those for the nice function by at most the band's width.
So we choose the band thin enough, and then rectangles that work for the nice function.
The gap for $f$ is at most the gap for the nice function plus twice the band's contribution.

### L2 human

We follow the steps for the concrete case of remark 1, with $\varepsilon = \frac14$ on $[0, 1]$.

1. Step 3 asks for $\eta < \frac{1}{12}$. Since $\lvert f - f_n \rvert \le 2^{-n}$ and $2^{-4} = \frac{1}{16} < \frac{1}{12}$, we take $N = 4$ and $\eta = \frac{1}{16}$.
2. Step 4 asks for a partition with $U(f_4, P) - L(f_4, P) < \frac{1}{12}$. The function $f_4$ jumps at $\frac14, \frac13, \frac12, 1$, with jump sizes $\frac{1}{16}, \frac18, \frac14, \frac12$, which add up to $\frac{15}{16}$.
3. We put each jump inside an interval of length $\frac{1}{20}$ of $P$, and $f_4$ is constant on each other interval of $P$. Then $U(f_4, P) - L(f_4, P) \le \frac{15}{16} \cdot \frac{1}{20} < \frac{1}{12}$.
4. So $U(f, P) - L(f, P) < \frac{1}{16} + \frac{1}{12} + \frac{1}{16} = \frac{5}{24} < \frac14$.

The typical use of the result is a function defined by a uniformly convergent series of step functions or of continuous functions.
The result shows that the function is integrable, and the series can then be integrated term by term.
A trap is to choose the partition before the index $N$: the partition must fit the jumps of the chosen $f_N$, and it changes when $N$ changes.
