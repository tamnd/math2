## Summary

Let $\Lambda$ be a consistent [[normal modal logic|~b1c67ad7]].
Its canonical model $\mathfrak{M}^\Lambda = (W^\Lambda, R^\Lambda, V^\Lambda)$ has as worlds the maximal $\Lambda$-[[consistent|VM8TQ70CVJ]] sets of formulas, the relation $\Gamma R^\Lambda \Delta$ iff $\set{\varphi : \square\varphi \in \Gamma} \subseteq \Delta$, and the valuation $V^\Lambda(p) = \set{\Gamma : p \in \Gamma}$.
The [[truth lemma|~f856785f]] says that a formula is true at $\Gamma$ exactly when it belongs to $\Gamma$, so $\mathfrak{M}^\Lambda$ refutes every non-theorem of $\Lambda$.
A logic is canonical when its canonical frame $(W^\Lambda, R^\Lambda)$ validates it.
This is the main method to prove the completeness of a normal logic for a class of [[Kripke frames|NGHWZ9Y7ZV]].

## Motivation

To prove completeness, we must turn each non-theorem $\varphi$ into a model with a world where $\varphi$ fails.
Henkin's method for first-order logic builds the model out of syntax: a maximal consistent set describes one structure.
In modal logic one maximal consistent set describes one world, and many worlds are needed at once.
So we take all maximal consistent sets as worlds, and the box formulas of a set tell which worlds it must see.
The construction is uniform in $\Lambda$, and the properties of $R^\Lambda$ reflect the axioms of $\Lambda$.

## Notation

1. $\mathfrak{F}^\Lambda = (W^\Lambda, R^\Lambda)$ is the canonical frame, and $\mathfrak{M}^\Lambda$ the canonical model.
2. For $\Gamma \in W^\Lambda$ we write $\square^{-1}\Gamma = \set{\varphi : \square\varphi \in \Gamma}$, so $\Gamma R^\Lambda \Delta$ iff $\square^{-1}\Gamma \subseteq \Delta$.
3. An equivalent form of the relation is $\Gamma R^\Lambda \Delta$ iff $\set{\lozenge\varphi : \varphi \in \Delta} \subseteq \Gamma$, see [[the truth lemma|~f856785f]].
4. Some books write $\mathrm{MCS}_\Lambda$ for $W^\Lambda$ and use $\Lambda$-MCS for its members.

## Remarks

### Examples

1. The canonical frame of $\mathsf{K}$ refutes every non-theorem of $\mathsf{K}$, so $\mathsf{K}$ is the logic of all frames, see [[the completeness theorem|~1d9447ce]].
2. The canonical frames of $\mathsf{T}$, $\mathsf{K4}$, $\mathsf{S4}$, $\mathsf{B}$ and $\mathsf{S5}$ are reflexive, transitive, preorders, reflexive symmetric and equivalence relations, see [[the completeness theorem|~1d9447ce]].
3. The logic $\mathsf{KD45}$ of belief is canonical, and its canonical frame is serial, transitive and Euclidean, see [[the KD45 example|~298e1efe]].
4. The canonical relation of $\mathsf{K} + \square\bot$ is empty, since $\square\bot$ lies in every world, see [[the verum logic example|~1d8eb538]].

### Non-examples

1. The canonical frame of $\mathsf{GL}$ is not conversely well-founded, so $\mathsf{GL}$ is not canonical, see [[the GL example|~d4a639ce]].
2. The canonical model of a consistent normal logic is never finite: it has $2^{\aleph_0}$ worlds or more.
For each set $S$ of variables, the literals $p$ for $p \in S$ and $\neg p$ for $p \notin S$ form a consistent set, by substituting $\top$ and $\bot$.
3. A Kripke incomplete logic is the logic of no class of frames, so it is not canonical. Such logics exist and are treated in [[modal model theory|SPQVNPZDTB]].

### Basic properties

1. Lindenbaum's lemma: every $\Lambda$-consistent set extends to a maximal one, as in [[Lindenbaum's lemma|SC0BSJ3GT6]] for first-order logic. The modal proof is in [[the proof of the truth lemma|~f68a7cd6]].
2. Existence lemma: if $\lozenge\varphi \in \Gamma$, then some $\Delta$ with $\Gamma R^\Lambda \Delta$ contains $\varphi$.
3. Truth lemma: $\mathfrak{M}^\Lambda, \Gamma \models \varphi$ iff $\varphi \in \Gamma$, see [[the truth lemma|~f856785f]].
4. Canonical model theorem: $\Lambda$ is strongly complete for $\mathfrak{M}^\Lambda$, so every $\Lambda$-consistent set is true at some world of $\mathfrak{M}^\Lambda$.
5. If $\Lambda$ contains $\mathrm{T}$, $\mathrm{D}$, $\mathrm{B}$, $\mathrm{4}$ or $\mathrm{5}$, then $R^\Lambda$ is reflexive, serial, symmetric, transitive or Euclidean. These facts combine, see [[the completeness theorem|~1d9447ce]].

### History

Henkin's proof of 1949 of the completeness of first-order logic built models from maximal consistent sets.
The canonical model method for normal modal logics was developed in the 1960s.
The notes of Lemmon and Scott, published in 1977, present it in the modern form.
Segerberg's An essay in classical modal logic (1971) applied it, together with filtration, to many logics.

### Common errors

1. Defining $\Gamma R^\Lambda \Delta$ by "$\Gamma \subseteq \Delta$"; the correct condition passes from $\square\varphi \in \Gamma$ to $\varphi \in \Delta$.
2. Assuming that completeness for a class needs canonicity; $\mathsf{GL}$ is complete but not canonical.
3. Forgetting that the truth lemma needs maximality; for a consistent set that is not maximal, $\varphi \notin \Gamma$ does not give $\neg\varphi \in \Gamma$.

## Explanations

### L1 human

A canonical model is a model built out of descriptions.
Each world is a complete description: for every statement, it says yes or no, and it never contradicts the logic.
One world sees another when everything that the first calls "necessary" is true in the second.
Then each description is true exactly at its own world.
So every statement that the logic cannot prove is false at some world of this model.

### L2 human

We show that the canonical relation of $\mathsf{T}$ is reflexive.

1. Let $\Gamma$ be a maximal $\mathsf{T}$-consistent set and let $\square\varphi \in \Gamma$.
2. The formula $\square\varphi \to \varphi$ is an instance of $\mathrm{T}$, so it is in $\mathsf{T} \subseteq \Gamma$.
3. A maximal consistent set is closed under modus ponens, so $\varphi \in \Gamma$.
4. As $\varphi$ was any formula with $\square\varphi \in \Gamma$, we get $\square^{-1}\Gamma \subseteq \Gamma$, that is, $\Gamma R^{\mathsf{T}} \Gamma$.

The typical use is exactly this pattern: an axiom of $\Lambda$, read inside maximal consistent sets, gives a property of $R^\Lambda$.
A trap: the canonical model of $\mathsf{S5}$ is not universal; it is an equivalence relation with many classes, and each class gives a universal model.

### L3 human

Algebraically, the canonical frame is the ultrafilter frame of the Lindenbaum algebra of $\Lambda$.
The truth lemma is the Jónsson-Tarski representation of this Boolean algebra with operator.
If the variety of modal algebras of a logic is closed under canonical extensions, the logic is canonical.
Sahlqvist's theorem gives a large syntactic class of canonical logics, see [[modal model theory|SPQVNPZDTB]].
Variants of the method use the canonical model restricted to a finite set of formulas.
This leads to [[filtration|~9960fa2c]] and to the finite canonical models used for $\mathsf{GL}$ in [[Kripke completeness of GL|1DMFNR7FZT]].
