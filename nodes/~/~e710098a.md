## Example

Define $Q \colon \R^2 \to \R$ by $Q(0, 0) = 0$ and
$$Q(x, y) = \frac{x^4}{x^2 + y^2} \qquad \text{for } (x, y) \ne (0, 0).$$
We show that $Q$ satisfies the first condition of a [[quadratic form|0HZNE5QZDJ]] but not the second.

1. Homogeneity for $a \ne 0$ and $(x, y) \ne (0, 0)$: $Q(ax, ay) = \dfrac{a^4 x^4}{a^2 (x^2 + y^2)} = a^2 Q(x, y)$.
2. Homogeneity when $a = 0$ or $(x, y) = (0, 0)$: both sides are $0$. So $Q(av) = a^2 Q(v)$ for all $a$ and $v$.
3. Let $b(u, v) = Q(u + v) - Q(u) - Q(v)$. Take $u = (1, 0)$, so $Q(u) = 1$.
4. For $v = (0, 1)$: $Q(v) = 0$ and $Q(1, 1) = \frac12$. So $b(u, v) = \frac12 - 1 - 0 = -\frac12$.
5. For $2v = (0, 2)$: $Q(2v) = 0$ and $Q(1, 2) = \frac15$. So $b(u, 2v) = \frac15 - 1 - 0 = -\frac45$.
6. A bilinear $b$ would give $b(u, 2v) = 2 b(u, v) = -1$. Since $-\frac45 \ne -1$, the map $b$ is not bilinear.
7. So the second condition fails, and $Q$ is not a quadratic form.

## Remarks

The example shows that the scaling rule $Q(av) = a^2 Q(v)$ does not define quadratic forms.
The bilinearity of the polar form is what forces $Q$ to be a polynomial of degree $2$ in the coordinates.
A function on $\R^2$ that is homogeneous of degree $2$ is fixed by its values on the unit circle.
These values can be any function of the angle.
A quadratic form allows only the functions $a \cos^2\theta + b \cos\theta \sin\theta + c \sin^2\theta$ on the circle.
Here $Q(\cos\theta, \sin\theta) = \cos^4\theta$, which is not of that type.

## Explanations

### L1 human

The function doubles its output four times when we double the input, as a square does.
But it is a fraction, not a polynomial, so it is not a quadratic form.
The test with the polar form finds the difference with the numbers $-\frac12$ and $-\frac45$.

### L2 human

To test a candidate quadratic form, check both conditions.

1. Check $Q(av) = a^2 Q(v)$.
2. Compute $b(u, v)$ for a few vectors and test $b(u, 2v) = 2b(u, v)$ and $b(u, v + w) = b(u, v) + b(u, w)$.

A trap: the second test must use specific vectors, as in steps 4 and 5; a general argument with symbols can hide the failure.
