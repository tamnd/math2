## Example

Take $\lambda = \aleph_0$ in the definition of [[Keisler's order|~889bca65]].
We show that every regular ultrafilter $\mathcal{D}$ on $\N$ saturates every complete theory $T$ in a countable language.

1. Let $\mathcal{D}$ be regular, with sets $X_n \in \mathcal{D}$ such that each $i$ lies in only finitely many $X_n$.
2. If $\mathcal{D}$ were principal, generated by $\set{i_0}$, then $i_0$ would lie in every $X_n$. So $\mathcal{D}$ is nonprincipal.
3. Conversely, a nonprincipal ultrafilter on $\N$ is regular: take $X_n = \set{i : i \ge n}$, and $i$ lies only in $X_0, \dots, X_i$.
4. A nonprincipal ultrafilter on $\N$ is countably incomplete, since the sets $X_n$ above have empty intersection.
5. Let $\mathcal{M} \models T$. By the [[saturation of ultraproducts|~bf3451a3]], part 1, $\mathcal{M}^{\N} / \mathcal{D}$ is $\aleph_1$-saturated, that is, $\aleph_0^+$-saturated.

So at $\lambda = \aleph_0$ the condition "$\mathcal{D}$ saturates $T_2$ implies $\mathcal{D}$ saturates $T_1$" holds for all $T_1, T_2$.
Every difference in Keisler's order shows up at an uncountable $\lambda$.

## Remarks

The example explains why Keisler's order quantifies over all infinite $\lambda$.
At uncountable $\lambda$ the picture changes.
By Keisler's characterization, a regular ultrafilter on $\lambda$ that is not $\lambda^+$-good fails to saturate the theories in the maximum class.
Such ultrafilters exist for some $\lambda$, since every unstable theory lies strictly above the stable ones.
The example also uses that the language is countable, as the definition requires.

## Explanations

### L1 human

On the natural numbers, every ultrafilter that the definition allows already fills all countable gaps in every theory.
So the countable case gives every theory the same rank.
To see differences one must use ultrafilters on larger sets.

### L2 human

We compare the theory $T_0$ of infinite sets and the theory $T_1$ of $(\Q, <)$ at $\lambda = \aleph_0$.

1. Let $\mathcal{D}$ be nonprincipal on $\N$.
2. By step 5, $\N^{\N} / \mathcal{D}$ and $\Q^{\N} / \mathcal{D}$ are both $\aleph_1$-saturated.
3. In $\Q^{\N} / \mathcal{D}$ this means, for instance, that every increasing sequence $a_0 < a_1 < \dots$ has an upper bound, by the type $\set{a_n < x : n \in \N}$.
4. So $\mathcal{D}$ saturates both theories, and $\lambda = \aleph_0$ does not show that $T_1$ is harder.

The typical use is as a warning when computing with the order.
The trap is to take the hyperreals or other ultrapowers over $\N$ as test cases for Keisler's order.
