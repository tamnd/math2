## Example

A binary [[sequence|0G9EKM0E15]] $s = (s(0), s(1), s(2), \ldots)$ is finitely supported if only finitely many terms $s(k)$ are $1$.
Let $E$ be the set of finitely supported binary sequences.
We list $E$, apply a [[diagonal|~7da89d71]] flip, and see that the flip gives no contradiction.

1. For $n \in \N$, let $e_n(k)$ be bit $k$ of the binary expansion of $n$. So $e_n = (e_n(0), e_n(1), \ldots)$ is in $E$.
2. Each $s \in E$ is $e_n$ for exactly one $n$, namely $n = \sum_k s(k) 2^k$. So $e_0, e_1, e_2, \ldots$ lists $E$, and $E$ is [[countable|01TQB88H4C]].
3. Define the diagonal sequence $t(n) = 1 - e_n(n)$.
4. For $n \ge 1$, we have $n < 2^n$, so bit $n$ of $n$ is $0$. Also $e_0$ is the zero sequence, so $e_0(0) = 0$.
5. So $e_n(n) = 0$ for every $n$, and $t = (1, 1, 1, \ldots)$.
6. The sequence $t$ differs from each $e_n$ at the place $n$, so $t$ is not in the list.
7. But $t$ has infinitely many terms equal to $1$, so $t \notin E$. Step 4 of the method, "the diagonal object is in the class", fails.

## Remarks

The example shows why the check that the diagonal object is in the class is a part of the method.
Without it, the same argument would "prove" that the countable set $E$ is uncountable.
In [[Cantor's diagonal argument|0XCH8QVDCQ]] the class is the set of all binary sequences, so the diagonal is always in the class.

The result changes with the class.
For the set of eventually periodic binary sequences, which is also countable, the diagonal of a list of all of them is again outside the set.
For the set of all binary sequences, the diagonal is inside, and the set is uncountable.
The first terms of the list are $e_0 = (0, 0, \ldots)$, $e_1 = (1, 0, \ldots)$, $e_2 = (0, 1, 0, \ldots)$ and $e_3 = (1, 1, 0, \ldots)$.

## Explanations

### L1 human

Take all strings of $0$ and $1$ that have only a few $1$s and then $0$s forever.
We can put them in one list, using the binary form of the numbers $0, 1, 2, \ldots$.
Now flip the diagonal: the new string is all $1$s.
It is not in the list, but it is also not a string with only a few $1$s.
So the diagonal trick does not show that the list misses one of our strings.

### L2 human

We compute the first diagonal entries of the list.

1. $e_0 = (0, 0, 0, \ldots)$, so $e_0(0) = 0$.
2. $1 = 2^0$, so $e_1 = (1, 0, 0, \ldots)$ and $e_1(1) = 0$.
3. $2 = 2^1$, so $e_2 = (0, 1, 0, \ldots)$ and $e_2(2) = 0$.
4. $3 = 2^0 + 2^1$, so $e_3 = (1, 1, 0, \ldots)$ and $e_3(3) = 0$.
5. The flipped diagonal starts $1, 1, 1, 1, \ldots$, and it continues with $1$ forever by step 4 of the example.

The typical use of this example is as a test of a diagonal proof: check the class of the diagonal object.
A trap is to think that a diagonal object outside the list is always a new member of the class.
