## Proof

Let $L$, $T_L$, $H$ and $\mathcal{M}_H$ be as in the statement of [[Hintikka's lemma|~542ddd18]].
We write $\mathcal{M}$ for $\mathcal{M}_H$, and $t^{\mathcal{M}}$ for the value of a closed term $t$ in $\mathcal{M}$.

Part A: $\mathcal{M}$ is a structure, and its terms name themselves.

1. $L$ has a constant symbol $c$, and $c \in T_L$. So the domain $T_L$ is nonempty, and $\mathcal{M}$ is an $L$-[[structure|983GZBQYT4]].
2. Each function symbol $f$ of arity $n$ gets a map $T_L^n \to T_L$, because $f(t_1, \dots, t_n)$ is a closed term when $t_1, \dots, t_n$ are closed terms.
3. Claim: $t^{\mathcal{M}} = t$ for every closed term $t$. We use [[structural induction|12MQ2NJ29A]] on $t$.
4. If $t$ is a constant symbol $c$, then $c^{\mathcal{M}} = c$ by the definition of $\mathcal{M}$.
5. If $t = f(t_1, \dots, t_n)$ and $t_i^{\mathcal{M}} = t_i$ for each $i$, then $t^{\mathcal{M}} = f^{\mathcal{M}}(t_1^{\mathcal{M}}, \dots, t_n^{\mathcal{M}}) = f^{\mathcal{M}}(t_1, \dots, t_n) = f(t_1, \dots, t_n) = t$. The first equality is the definition of the value of a term, the second is the induction hypothesis, and the third is the definition of $f^{\mathcal{M}}$.

Part B: the truth conditions in $\mathcal{M}$.

6. Atomic sentences. Let $A = R(t_1, \dots, t_n)$ be an atomic sentence. By the definition of [[satisfaction|2RBQPV02AS]], $\mathcal{M} \models A$ exactly when $(t_1^{\mathcal{M}}, \dots, t_n^{\mathcal{M}}) \in R^{\mathcal{M}}$. By step 3 this tuple is $(t_1, \dots, t_n)$. By the definition of $R^{\mathcal{M}}$, it is in $R^{\mathcal{M}}$ exactly when $R(t_1, \dots, t_n) \in H$. So $\mathcal{M} \models A$ exactly when $A \in H$.
7. Instances. Let $\varphi$ be a formula whose only free variable is $x$, and let $t \in T_L$. A closed term is substitutable for $x$ in $\varphi$, so the substitution lemma for [[substitution|NCDZ969V7X]] applies. It gives: $\mathcal{M} \models \varphi[t/x]$ exactly when $\mathcal{M} \models \varphi[s]$ for an assignment $s$ with $s(x) = t^{\mathcal{M}}$, and $t^{\mathcal{M}} = t$ by step 3.
8. Universal sentences. $\mathcal{M} \models \forall x\, \varphi$ exactly when $\mathcal{M} \models \varphi[s]$ for each assignment with $s(x) = a$, for each $a \in T_L$. Each element $a$ of the domain is a closed term, and by step 7 the condition for $a$ is $\mathcal{M} \models \varphi[a/x]$. So $\mathcal{M} \models \forall x\, \varphi$ exactly when $\mathcal{M} \models \varphi[t/x]$ for every $t \in T_L$.
9. Existential sentences. In the same way, $\mathcal{M} \models \exists x\, \varphi$ exactly when $\mathcal{M} \models \varphi[t/x]$ for some $t \in T_L$.
10. The $\alpha$ sentences. $\mathcal{M}$ makes $\varphi \wedge \psi$ true exactly when it makes $\varphi$ and $\psi$ true. It makes $\neg(\varphi \vee \psi)$ true exactly when it makes $\neg\varphi$ and $\neg\psi$ true. It makes $\neg(\varphi \to \psi)$ true exactly when it makes $\varphi$ and $\neg\psi$ true. It makes $\neg\neg\varphi$ true exactly when it makes $\varphi$ true. So in each case $\mathcal{M} \models \alpha$ exactly when $\mathcal{M} \models \alpha_1$ and $\mathcal{M} \models \alpha_2$.
11. The $\beta$ sentences. In the same way, the truth tables of $\vee$, $\wedge$ and $\to$ give: $\mathcal{M} \models \beta$ exactly when $\mathcal{M} \models \beta_1$ or $\mathcal{M} \models \beta_2$. For $\varphi \to \psi$ the components are $\neg\varphi$ and $\psi$, and the implication is true exactly when $\varphi$ is false or $\psi$ is true.
12. The $\gamma$ sentences. For $\forall x\, \varphi$, step 8 gives: $\mathcal{M} \models \gamma$ exactly when $\mathcal{M} \models \gamma(t)$ for every $t \in T_L$. For $\neg\exists x\, \varphi$, step 9 gives: it is true exactly when $\varphi[t/x]$ is false for every $t$, that is, when $\gamma(t) = \neg\varphi[t/x]$ is true for every $t$.
13. The $\delta$ sentences. For $\exists x\, \varphi$, step 9 gives: $\mathcal{M} \models \delta$ exactly when $\mathcal{M} \models \delta(t)$ for some $t \in T_L$. For $\neg\forall x\, \varphi$, step 8 gives: it is true exactly when $\varphi[t/x]$ is false for some $t$, that is, when $\delta(t) = \neg\varphi[t/x]$ is true for some $t$.

Part C: the rank and the types of sentences.

14. The rank $r(\varphi)$ of a formula is the number of occurrences of $\neg, \wedge, \vee, \to, \forall, \exists$ in it. A substitution of a term for a variable does not change the rank, so $r(\varphi[t/x]) = r(\varphi)$. Below, $a = r(\varphi)$ and $b = r(\psi)$, and $a, b \ge 0$.
15. The $\alpha$ components have smaller rank. $r(\varphi \wedge \psi) = a + b + 1$, with components of rank $a$ and $b$. $r(\neg(\varphi \vee \psi)) = a + b + 2$, with components of rank $a + 1$ and $b + 1$. $r(\neg(\varphi \to \psi)) = a + b + 2$, with components of rank $a$ and $b + 1$. $r(\neg\neg\varphi) = a + 2$, with components of rank $a$.
16. The $\beta$ components have smaller rank. $r(\varphi \vee \psi) = a + b + 1$, with components of rank $a$ and $b$. $r(\neg(\varphi \wedge \psi)) = a + b + 2$, with components of rank $a + 1$ and $b + 1$. $r(\varphi \to \psi) = a + b + 1$, with components $\neg\varphi$ of rank $a + 1$ and $\psi$ of rank $b$.
17. The instances have smaller rank. $r(\forall x\, \varphi) = r(\exists x\, \varphi) = a + 1$, and the instances $\varphi[t/x]$ have rank $a$ by step 14. $r(\neg\exists x\, \varphi) = r(\neg\forall x\, \varphi) = a + 2$, and the instances $\neg\varphi[t/x]$ have rank $a + 1$.
18. Each sentence has exactly one of six forms: atomic, the negation of an atomic sentence, $\alpha$, $\beta$, $\gamma$ or $\delta$. The main symbol decides the form: $\wedge$ gives $\alpha$, $\vee$ or $\to$ gives $\beta$, $\forall$ gives $\gamma$, and $\exists$ gives $\delta$.
19. A sentence $\neg\psi$ with $\psi$ atomic is a negated atom. Otherwise the main symbol of $\psi$ decides: $\neg$, $\vee$ or $\to$ gives $\alpha$, $\wedge$ gives $\beta$, $\exists$ gives $\gamma$, and $\forall$ gives $\delta$.

Part D: the induction.

20. Claim: for each $n \ge 0$, every sentence $\varphi \in H$ with $r(\varphi) = n$ is true in $\mathcal{M}$. We use strong [[induction|0ASJVEFA9J]] on $n$: we assume the claim for all ranks below $n$, and we prove it for $n$, by [[cases|0WCP0PVET6]] on the form of $\varphi$ (steps 18 and 19).
21. Case $\varphi$ atomic. Then $\varphi \in H$, and step 6 gives $\mathcal{M} \models \varphi$.
22. Case $\varphi = \neg A$ with $A$ atomic. Condition (1) of a [[Hintikka set|~03b04954]] gives $A \notin H$, because $\neg A \in H$. Step 6 gives $\mathcal{M} \not\models A$, so $\mathcal{M} \models \neg A$.
23. Case $\varphi$ is an $\alpha$ sentence. Condition (2) gives $\alpha_1, \alpha_2 \in H$. They have smaller rank by step 15, so they are true by the induction hypothesis. Step 10 gives $\mathcal{M} \models \varphi$.
24. Case $\varphi$ is a $\beta$ sentence. Condition (3) gives $\beta_i \in H$ for some $i \in \{1, 2\}$. It has smaller rank by step 16, so it is true by the induction hypothesis. Step 11 gives $\mathcal{M} \models \varphi$.
25. Case $\varphi$ is a $\gamma$ sentence. Condition (4) gives $\gamma(t) \in H$ for every $t \in T_L$. Each $\gamma(t)$ has smaller rank by step 17, so each is true by the induction hypothesis. Step 12 gives $\mathcal{M} \models \varphi$.
26. Case $\varphi$ is a $\delta$ sentence. Condition (5) gives $\delta(t) \in H$ for some $t \in T_L$. It has smaller rank by step 17, so it is true by the induction hypothesis. Step 13 gives $\mathcal{M} \models \varphi$.
27. Steps 21 to 26 cover all the forms of steps 18 and 19, so the claim of step 20 holds for $n$. By strong induction it holds for every $n$.

Conclusion.

28. Every sentence of $H$ has some rank $n$, so step 27 gives $\mathcal{M}_H \models \varphi$ for every $\varphi \in H$. So $\mathcal{M}_H$ is a model of $H$, and $H$ is satisfiable. $\blacksquare$

## Idea

The model takes the closed terms as its elements, so that every element has a name, and it makes an atomic sentence true exactly when the sentence is in $H$.
Because every element has a name, a quantified sentence is true exactly when the right instances are true.
The conditions of a Hintikka set then push truth from the atomic members of $H$ up to all members, by induction on the rank.
The induction uses the rank and not the subformula order, because an instance $\varphi[t/x]$ is not a subformula of $\forall x\, \varphi$.

## Variants

With the equality symbol, the same proof works on the quotient of $T_L$ by the relation $s \sim t \iff (s = t) \in H$, under the extra conditions (E1) and (E2) in the remarks of the statement; step 6 then also covers the atomic sentences $s = t$.
For propositional logic, Parts A and B reduce to the truth tables, the model is the valuation that makes a letter true exactly when it is in $H$, and the induction is on the length of formulas.
Another proof first extends $H$ to a set that contains, for each atomic sentence, the sentence or its negation, and then reads off the model; the extension is not needed, and the proof above avoids it.
