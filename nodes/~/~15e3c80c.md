## Proof

We use [[the theorem on row operations|~6410ee51]], called Theorem E below.

Part 1, equivalence relation.

1. Reflexive: the operation $R_1 \leftarrow 1 \cdot R_1$ is elementary and changes nothing, so $A \sim A$.
2. Symmetric: let $A = A_0, A_1, \dots, A_k = B$, where $A_{t}$ comes from $A_{t-1}$ by an operation $\rho_t$.
3. By Theorem E, part 1, each $\rho_t$ has an inverse elementary operation $\rho_t'$.
4. Then $\rho_1', \dots, \rho_k'$, applied in the order $\rho_k'$ first, take $B$ back to $A$. So $B \sim A$.
5. Transitive: if a sequence takes $A$ to $B$ and another takes $B$ to $C$, then the first followed by the second takes $A$ to $C$.
6. So $\sim$ is an [[equivalence relation|0G8VEZ3WTK]].

Part 2, matrix form.

7. By Theorem E, part 2, $A_t = E_t A_{t-1}$ with $E_t$ invertible.
8. So $B = E_k \cdots E_1 A$. Put $P = E_k \cdots E_1$.
9. A product of invertible matrices is invertible, with inverse $E_1^{-1} \cdots E_k^{-1}$. So $P$ is invertible.

Part 3, row space.

10. Row $i$ of $PA$ is $\sum_l p_{il} R_l$, a linear combination of the rows $R_l$ of $A$.
11. So every row of $B$ lies in the row space of $A$, which is a subspace. Hence the row space of $B$ is contained in that of $A$.
12. By symmetry, $A = P^{-1} B$, so the row space of $A$ is contained in that of $B$.
13. So the two [[row spaces|0EP73HK4C4]] are equal.

Part 4, null space.

14. If $Ax = 0$, then $Bx = PAx = P0 = 0$.
15. If $Bx = 0$, then $Ax = P^{-1}Bx = 0$.
16. So the two [[null spaces|0PQ2GGY1QV]] are equal.

Part 5, solution sets.

17. Apply Theorem E, part 3, to each step $A_{t-1} \to A_t$ of a sequence from $[A \mid b]$ to $[A' \mid b']$.
18. Each step keeps the solution set, so the first and the last systems have the same solution set.

## Idea

Elementary operations can be undone, which gives symmetry, and sequences of operations can be chained, which gives transitivity.
A sequence of operations is left multiplication by an invertible matrix $P$.
Multiplying on the left by $P$ makes new rows from combinations of old rows, and it keeps $Ax = 0$ because $P$ is invertible.

## Variants

Parts 3 and 4 can also be proved one operation at a time, without the matrix $P$.
For a single operation, each new row is a combination of the old rows, and the inverse operation gives the reverse inclusion.
