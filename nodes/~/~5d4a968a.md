## Example

Let $f \colon \mathbb{R} \to \mathbb{R}$ be the function $f(x) = 3x - 7$.
The claim is that $f$ is [[surjective|01RVCMSN5N]]: for every real $y$ there is a real $x$ with $f(x) = y$.
We find $x$ in scratch work, and then we write a final proof that does not show the search.
This is an instance of [[scratch work and the final proof|~d29be80b]].

Scratch work, which is not part of the proof:

1. We want $x$ with $3x - 7 = y$. We treat this as an equation for the unknown $x$.
2. Adding $7$ gives $3x = y + 7$, and dividing by $3$ gives $x = \frac{y + 7}{3}$.
3. This tells us which $x$ to name in the proof. The scratch work assumed that a solution exists, so it is not a proof of existence.

The final proof:

> Let $y$ be a real number.
> Let $x = \frac{y + 7}{3}$.
> This is a real number.
> Then $f(x) = 3 \cdot \frac{y + 7}{3} - 7 = (y + 7) - 7 = y$.
> Since $y$ was arbitrary, every real number is a value of $f$, so $f$ is surjective.
> $\square$

We check the final proof.

1. It starts with an arbitrary $y$, as the goal "for every $y$" requires.
2. It names $x$ by a formula that depends only on $y$. This answers the goal "there is $x$".
3. It verifies $f(x) = y$ by a calculation that a reader can check in one line.
4. It does not solve any equation. The solving belongs to the scratch work.
5. A numerical check: for $y = 5$ we get $x = 4$ and $f(4) = 12 - 7 = 5$.

## Remarks

1. The scratch work goes from the goal $f(x) = y$ to a candidate $x$. The proof goes from the candidate to the goal. This is the pattern of [[proving injectivity and surjectivity|DD2P85Y8E9]].
2. If we change $f$ to $g(x) = x^2$ on $\mathbb{R}$, the same scratch work gives $x = \pm\sqrt{y}$, which needs $y \ge 0$. So the scratch work points to the failure: $y = -1$ has no preimage, and $g$ is not surjective.
3. If we change the domain and codomain to the integers, $f(x) = 3x - 7$ is not surjective. The scratch work gives $x = \frac{y + 7}{3}$, which is not an integer for $y = 0$.
4. The final proof is shorter than the scratch work. This is common for existence proofs, where checking a candidate is easier than finding it.

## Explanations

### L1 human

Suppose a machine takes a number, multiplies it by $3$, and subtracts $7$.
We want to show that every number can come out of the machine.
To find the input for the output $5$, we run the machine backward: add $7$ to get $12$, divide by $3$ to get $4$.
In the written proof we only show that the input $\frac{y+7}{3}$ works for each output $y$.
How we found it stays in the draft.

### L2 human

We repeat the method for $h \colon \mathbb{R} \setminus \{1\} \to \mathbb{R} \setminus \{2\}$, $h(x) = \frac{2x}{x - 1}$.

1. Scratch: solve $\frac{2x}{x - 1} = y$ for $x$. This gives $2x = yx - y$, so $x(2 - y) = -y$ and $x = \frac{y}{y - 2}$.
2. Scratch: this needs $y \ne 2$, which the codomain gives. We must also check $x \ne 1$.
3. Proof: let $y \ne 2$, and let $x = \frac{y}{y - 2}$. If $x = 1$, then $y = y - 2$, which is false. So $x \ne 1$, and $x$ is in the domain.
4. Proof: $x - 1 = \frac{y - (y - 2)}{y - 2} = \frac{2}{y - 2}$, and $2x = \frac{2y}{y - 2}$.
5. Proof: so $h(x) = \frac{2y}{y - 2} \cdot \frac{y - 2}{2} = y$. Hence $h$ is surjective.

The typical use of this pattern is every proof that a function is onto, or that an equation has a solution.
A trap is to hand in the solving steps of the scratch work as the proof.
These steps start from "$h(x) = y$", which is what the proof must show.
