## Definition

Let $\mathcal{M}$ be an $L$-[[structure|983GZBQYT4]] and let $\varphi$ be an $L$-[[formula|HYJ10AF6RT]].
The formula $\varphi$ is true in $\mathcal{M}$, written $\mathcal{M} \models \varphi$, when $\mathcal{M} \models \varphi[s]$ for every variable assignment $s$ in $\mathcal{M}$, in the sense of [[satisfaction|~cf18e0d7]].
When $\varphi$ is a [[sentence|DKFGQTRYZE]], the formula $\varphi$ is false in $\mathcal{M}$ when it is not true in $\mathcal{M}$.
The theory of $\mathcal{M}$ is the set of $L$-sentences that are true in $\mathcal{M}$:
$$\operatorname{Th}(\mathcal{M}) = \set{\sigma : \sigma \text{ is an } L\text{-sentence and } \mathcal{M} \models \sigma}.$$

## Notation

$\mathcal{M} \models \sigma$ is read "$\sigma$ is true in $\mathcal{M}$" or "$\mathcal{M}$ satisfies $\sigma$".
Some books define $\mathcal{M} \models \varphi$ only for sentences; for sentences the two conventions agree.
In Mathlib, truth of a sentence is `FirstOrder.Language.Sentence.Realize`.

## Remarks

For a sentence $\sigma$, all assignments give the same answer, by the [[coincidence lemma|~7b107606]], because $\sigma$ has no free variables.
So $\mathcal{M} \models \sigma$ holds if and only if some assignment satisfies $\sigma$, and a sentence is either true or false in $\mathcal{M}$.
For a formula with free variables, the truth of $\varphi$ is the truth of its universal closure $\forall x_1 \cdots \forall x_n \, \varphi$, where $x_1, \ldots, x_n$ are the free variables of $\varphi$.
A formula such as $x < 1$ in $(\N, <)$ can be neither true nor false; see the [[example|~2c4f7e5f]].
The concept page [[truth in a structure|K7XDVK5854]] gives the properties of $\operatorname{Th}(\mathcal{M})$ and the link to elementary equivalence.

## Explanations

### L1 human

A sentence is true in a structure when it holds there, with no letters left to fill in.
For example, "every number has a bigger number" is true for the whole numbers.
For a formula with letters left over, we call it true only when it holds for every way of filling in the letters.

### L2 human

We check the definition on the formula $\varphi = (x + 0 = x)$ in $\mathcal{M} = (\Z, +, 0)$.

1. Let $s$ be any assignment, and let $a = s(x)$.
2. The value of $x + 0$ under $s$ is $a + 0 = a$, and the value of $x$ is $a$.
3. So $\mathcal{M} \models \varphi[s]$, by the clause for equality.
4. Since $s$ was arbitrary, $\mathcal{M} \models \varphi$. Equivalently, $\mathcal{M} \models \forall x \, (x + 0 = x)$.

The typical use is to state that an axiom holds in a structure.
A trap is to test only one assignment for a formula with free variables: $x + x = x$ is satisfied when $x \mapsto 0$, but it is not true in $(\Z, +, 0)$, because $1 + 1 \neq 1$.
