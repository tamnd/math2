## Example

A neighborhood frame is a pair $(W, N)$ where $N$ assigns to each world $w$ a set $N(w)$ of subsets of $W$.
In [[neighborhood semantics|CN7HK9K1B6]], $\square\varphi$ is true at $w$ when $[\![ \varphi ]\!] \in N(w)$.
Take
$$W = \set{a, b}, \quad N(a) = \set{\set{a}, \set{b}}, \quad N(b) = \varnothing, \quad V(p) = \set{a}, \quad V(q) = \varnothing.$$

1. $[\![ p ]\!] = \set{a}$ and $[\![ q ]\!] = \varnothing$, by the valuation.
2. $[\![ p \to q ]\!] = (W \setminus \set{a}) \cup \varnothing = \set{b}$.
3. $\square p$ is true at $a$, since $\set{a} \in N(a)$.
4. $\square(p \to q)$ is true at $a$, since $\set{b} \in N(a)$.
5. $\square q$ is false at $a$, since $\varnothing \notin N(a)$.
6. So axiom $\mathrm{K}$, $\square(p \to q) \to (\square p \to \square q)$, fails at $a$.
7. $\square\top$ is false at $a$, since $[\![ \top ]\!] = W \notin N(a)$. The theorem $\top$ is valid, so [[necessitation|G989VP2NGP]] fails on this frame.
8. The rule RE holds. If $\varphi \leftrightarrow \psi$ is true at every world, then $[\![ \varphi ]\!] = [\![ \psi ]\!]$, so $\square\varphi$ and $\square\psi$ have the same truth value at each world.
9. No relation gives $N(a)$. A [[Kripke frame|NGHWZ9Y7ZV]] corresponds to $N(a) = \set{X : R[a] \subseteq X}$, and this family contains $W$ and is closed under intersection.
10. Here $W \notin N(a)$, and $\set{a} \cap \set{b} = \varnothing \notin N(a)$, so both properties fail.

## Remarks

The example shows that neighborhood semantics validates fewer formulas than Kripke semantics.
Each failure matches a missing closure property of $N(a)$.
Closure under intersection and supersets would give $\mathrm{K}$, and $W \in N(a)$ would give necessitation.
The formulas valid on all neighborhood frames form the smallest classical modal logic $\mathsf{E}$.
This logic is closed under RE but is not a [[normal modal logic|~2cd45d93]].
If we let $N(a)$ and $N(b)$ both be the family of all subsets of $W$, then every $\square\varphi$ is true everywhere.
This is the model of the empty [[accessibility relation|XBCYFDPS2F]], so $\mathrm{K}$ and necessitation hold again.
If we only add $\varnothing$ and $W$ to $N(a)$, then $\mathrm{K}$ holds at $a$, but $\square\top$ still fails at $b$, since $N(b)$ is empty.

## Explanations

### L1 human

In neighborhood semantics, each world keeps a list of "necessary" sets of worlds.
A statement is necessary at a world when the set of worlds where it holds is on the list.
At world $a$ the list has the sets $\set{a}$ and $\set{b}$, but not the empty set.
So "$p$" and "if $p$ then $q$" are both necessary at $a$, while "$q$" is not.
The usual rule "necessary premises give a necessary conclusion" breaks.

### L2 human

1. Take the same frame and the formula $\square p \wedge \square\neg p$.
2. $[\![ \neg p ]\!] = \set{b} \in N(a)$, and $[\![ p ]\!] = \set{a} \in N(a)$.
3. So $\square p \wedge \square\neg p$ is true at $a$, while $\square\bot$ is false at $a$, since $\varnothing \notin N(a)$.
4. In $\mathsf{K}$, $\square p \wedge \square\neg p \to \square\bot$ is a theorem, so this is another failure of normality.

The typical use of neighborhood models is for logics where the box is not normal, for example logics of ability or of agency.
A trap: neighborhood semantics still validates RE, so it cannot separate formulas that are equivalent in classical logic.
