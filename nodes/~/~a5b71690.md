## Definition

Let $n \ge 2$.
An *$n$-valued Łukasiewicz-Moisil algebra* is a structure $(A, \lor, \land, \sim, \varphi_1, \dots, \varphi_{n - 1}, 0, 1)$ such that $(A, \lor, \land, \sim, 0, 1)$ is a [[De Morgan algebra|CDGBK86D23]] and, for all $x, y \in A$ and $1 \le i, j \le n - 1$:

1. $\varphi_i(x \lor y) = \varphi_i x \lor \varphi_i y$, $\varphi_i(x \land y) = \varphi_i x \land \varphi_i y$, $\varphi_i 0 = 0$ and $\varphi_i 1 = 1$;
2. $\varphi_i x \lor \sim \varphi_i x = 1$;
3. $\varphi_i \varphi_j x = \varphi_j x$;
4. $\varphi_i \sim x = \sim \varphi_{n - i} x$;
5. if $i \le j$, then $\varphi_i x \le \varphi_j x$;
6. determination principle: if $\varphi_i x = \varphi_i y$ for all $i$, then $x = y$.

## Notation

We write $\mathbf{LM}_n$ for the class.
The standard algebra is $L_n = \set{\tfrac{j}{n - 1} : 0 \le j \le n - 1}$ with $\max$, $\min$, $\sim x = 1 - x$, and $\varphi_i(\tfrac{j}{n - 1}) = 1$ if $i + j \ge n$, and $0$ otherwise.

## Remarks

1. Example: [[the chain $L_3$|~3359e128]].
2. Example: [[a four-element subalgebra of $L_5$|~7fd4c499]].
3. Non-example: [[the four-element De Morgan algebra with two fixed points|~3ec227c4]] fails clause 6 for every choice of the $\varphi_i$.
4. Clauses 2 and 3 say that each $\varphi_i x$ is complemented, with complement $\sim \varphi_i x$, and that $\varphi_i$ fixes the complemented elements in its image.
5. Clause 6 is a quasi-identity. In the presence of the other clauses it can be replaced by identities, and $\mathbf{LM}_n$ is a variety.
6. On $L_n$, clause 4 holds since $i + (n - 1 - j) \ge n$ iff $j < i$ iff $(n - i) + j < n$.

## Explanations

### L1 human

The operation $\varphi_i$ asks a yes or no question about the level of $x$.
The answers to all $n - 1$ questions fix $x$.
Negation turns "at least level $k$" questions into "below level $n - k$" questions.

### L2 human

1. In $L_3$, $\varphi_1$ sends $1$ to $1$ and $0, \tfrac12$ to $0$.
2. $\varphi_2$ sends $\tfrac12, 1$ to $1$ and $0$ to $0$.
3. Check clause 4 at $x = 1$, $i = 1$: $\varphi_1 \sim 1 = \varphi_1 0 = 0$, and $\sim \varphi_2 1 = \sim 1 = 0$.
4. Check clause 6: the pairs $(\varphi_1 x, \varphi_2 x)$ are $(0, 0)$, $(0, 1)$ and $(1, 1)$ for $x = 0, \tfrac12, 1$. They are distinct.

The typical use: an identity holds in $\mathbf{LM}_n$ iff it holds in $L_n$.
The trap: in clause 4 the index changes from $i$ to $n - i$.
