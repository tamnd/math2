## Summary

Let $f \colon X \to Y$ be a [[function|0EPAT51DXQ]].
To prove that $f$ is [[injective|09NWETVTNY]], we take arbitrary $a, b \in X$, assume $f(a) = f(b)$, and derive $a = b$.
To prove that $f$ is [[surjective|01RVCMSN5N]], we take an arbitrary $y \in Y$ and find an $x \in X$ with $f(x) = y$, usually by solving the equation $f(x) = y$ for $x$ and checking that the solution lies in $X$.
To prove that $f$ is [[bijective|0GG9TVW90M]], we prove both, or we give a function $g \colon Y \to X$ and check $g(f(x)) = x$ for all $x \in X$ and $f(g(y)) = y$ for all $y \in Y$.
These patterns matter because injectivity and surjectivity are the first properties of every map in algebra, analysis and combinatorics, and the [[bijection principle|0GV2573FP4]] turns a bijection into a count.

## Motivation

The definitions are short, but they have different logical forms.
Injectivity is a universal statement: for all $a$ and $b$, $f(a) = f(b)$ implies $a = b$.
Surjectivity is a universal statement with an existential part: for each $y$ there exists an $x$ with $f(x) = y$.
So the two proofs start differently.
An injectivity proof starts with two arbitrary elements and an equation, and it ends with an equation.
A surjectivity proof starts with one arbitrary element of the codomain, and it must produce an element of the domain, as in a [[constructive proof|01XM7JEKHY]].
Students often mix the two forms, for example by checking $f(x) = y$ for one chosen $y$.
A fixed pattern for each property avoids such errors.

## Notation

1. Injective functions are also called one-to-one functions or injections, and the arrow $f \colon X \hookrightarrow Y$ marks an injection in some books.
2. Surjective functions are also called onto functions or surjections, and the arrow $f \colon X \twoheadrightarrow Y$ marks a surjection in some books.
3. "One-to-one" sometimes means bijective in older texts. A reader must check which meaning the book uses.
4. In Mathlib, injectivity is `Function.Injective f`, surjectivity is `Function.Surjective f`, and bijectivity is `Function.Bijective f`. The definition of `Function.Injective f` is `∀ a b, f a = f b → a = b`, the same form as the pattern above.

## Remarks

### Examples

1. [[The function (x + 1)/(x - 1) is its own inverse|~c96bff16]]: a bijection of $\mathbb{R} \setminus \{1\}$, proved by an injectivity argument, by solving $f(x) = y$, and by an inverse.
2. [[The function x^3 + x is a bijection of the real numbers|~455d820b]]: injectivity by a factorization, and surjectivity by the [[intermediate value theorem|00KAFBR32E]] without an explicit formula for the solution.
3. The function $f \colon \mathbb{Z} \to \mathbb{Z}$, $f(n) = 2n$, is injective: $2a = 2b$ gives $a = b$ after division by $2$. It is not surjective: $1 = 2n$ has no integer solution, because $2n$ is even.
4. The function $g \colon \mathbb{R} \to [0, \infty)$, $g(x) = x^2$, is surjective: for $y \ge 0$ the number $x = \sqrt{y}$ gives $g(x) = y$. The codomain matters, because the same rule into $\mathbb{R}$ is not surjective.
5. A [[linear map|0NRYHJPQG2]] $T$ is injective if and only if $T(v) = 0$ implies $v = 0$. The proof applies the pattern: $T(a) = T(b)$ gives $T(a - b) = 0$, so $a - b = 0$. This is the statement [[a linear map is injective iff its kernel is trivial|0BJBYCGMWE]].

### Non-examples

1. [[Squaring on the real numbers is not injective|~e3eb8147]]: the step "$a^2 = b^2$, so $a = b$" is false, and $f(-1) = f(1)$ shows that no proof can exist.
2. A check that $f(1) \neq f(2)$, $f(2) \neq f(3)$ and $f(1) \neq f(3)$ is not a proof of injectivity. It tests three pairs, and the definition speaks of all pairs.
3. The claim "$f(x) = 3x$ is surjective from $\mathbb{Z}$ to $\mathbb{Z}$, because $x = y/3$" is not a valid surjectivity proof. The solution $y/3$ is not an integer when $y = 1$, so it is not an element of the domain.

### Basic properties

1. The contrapositive form of injectivity, $a \neq b \Rightarrow f(a) \neq f(b)$, is equivalent. It suits functions given by cases, or functions on finite sets.
2. A function is injective if and only if it has a [[left inverse|05SG20AMXH]] (for a non-empty domain). This is the statement [[injective iff it has a left inverse|0HYFEEZAEM]].
3. A function is surjective if and only if it has a [[right inverse|0WWRD82HD2]]. This is the statement [[surjective iff it has a right inverse|0TYQNHVB4C]], and its proof needs the axiom of choice for infinite sets.
4. A function is bijective if and only if it has a two-sided [[inverse function|0J2WAR83WP]], by the statement [[bijective iff it has a two-sided inverse|01VG2A0BHW]]. One equation $g \circ f = \mathrm{id}_X$ alone is not enough: it gives only injectivity of $f$.
5. Compositions keep both properties: [[a composition of injections is injective|01FPXMTBX1]], and [[a composition of surjections is surjective|07EH4R3RVQ]].
6. For a function between two [[finite sets|070R982G4B]] with the same number of elements, injective, surjective and bijective are equivalent. So one of the two proofs is enough. The same holds for linear maps from a finite-dimensional space to itself, by the statement [[an injective endomorphism of a finite-dimensional space is surjective|0912EEEVCT]].
7. A strictly increasing function on a subset of $\mathbb{R}$ is injective: if $a \neq b$, say $a < b$, then $f(a) < f(b)$.

### History

The words injection, surjection and bijection were introduced by the Bourbaki group in the 20th century.
Older texts use "one-to-one" and "onto", and many English textbooks still prefer these words.
Velleman treats the two proof patterns and the inverse functions in the chapter on functions.

### Common errors

1. A student proves injectivity by the converse: "if $a = b$, then $f(a) = f(b)$". This holds for every function, so it proves nothing.
2. A student solves $f(x) = y$ and forgets to check that the solution is in the domain, or that the equation was solved by reversible steps.
3. A student ignores the codomain. The rule $x \mapsto x^2$ is surjective onto $[0, \infty)$ and not surjective onto $\mathbb{R}$, so "surjective" has no meaning until the codomain is fixed.

## Explanations

### L1 human

A function is a rule that sends each input to one output.
It is injective when two different inputs never give the same output, like seat numbers in a theatre where each person has a different seat.
To show this, we suppose two inputs give the same output and show that they were the same input.
A function is surjective when every possible output is reached, like a theatre where every seat is taken.
To show this, we take any output and find an input that gives it.
For the rule "add $5$" on whole numbers, the output $12$ comes from the input $7$, and in general the output $y$ comes from $y - 5$.

### L2 human

We prove that $f \colon \mathbb{R} \to \mathbb{R}$, $f(x) = 3x + 5$, is a bijection, in three ways.

1. Injectivity. Let $a, b \in \mathbb{R}$ with $f(a) = f(b)$. Then $3a + 5 = 3b + 5$.
2. Subtract $5$ from both sides: $3a = 3b$. Divide by $3$, which is not zero: $a = b$.
3. Surjectivity. Let $y \in \mathbb{R}$. We solve $3x + 5 = y$ and get $x = (y - 5)/3$, a real number.
4. Check: $f\big((y - 5)/3\big) = 3 \cdot (y - 5)/3 + 5 = y$. So each $y$ is a value of $f$.
5. Inverse. Define $g(y) = (y - 5)/3$. Then $g(f(x)) = (3x + 5 - 5)/3 = x$ for all $x$, and $f(g(y)) = y$ by step 4.
6. Since $g$ is a two-sided inverse, $f$ is a bijection, and $f^{-1} = g$.

The typical use is the proof that a formula defines a bijection between two sets, for example to count one set by another.
A trap is to show only $g(f(x)) = x$.
For $f \colon \mathbb{R} \to \mathbb{R}^2$, $f(x) = (x, 0)$, and $g(u, v) = u$, we get $g(f(x)) = x$ for all $x$, but $f$ is not surjective, since $(0, 1)$ is not a value of $f$.

### L3 human

In category theory the two properties split into several notions.
An injective function is a monomorphism of sets: $f \circ u = f \circ v$ implies $u = v$.
A surjective function is an epimorphism of sets.
In the category of sets, monomorphisms are the injections and epimorphisms are the surjections, but in other categories these notions can differ: the inclusion $\mathbb{Z} \to \mathbb{Q}$ is an epimorphism of rings and is not surjective.
For homomorphisms of groups, rings and modules, the injectivity pattern reduces to the kernel: $f(a) = f(b)$ if and only if $f(a - b) = 0$, so it suffices to show that the kernel is trivial.
Surjectivity proofs often avoid an explicit solution and use an existence theorem instead, such as the intermediate value theorem, a fixed point theorem or a dimension count with the [[rank-nullity theorem|0W4FSW1TVB]].
For bijections, the inverse can be a different kind of object: the inverse of a smooth bijection need not be smooth, as $x \mapsto x^3$ shows at $0$.
