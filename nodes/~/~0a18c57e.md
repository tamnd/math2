## Definition

A [[topological space|~77bfcc55]] $X$ is locally compact when each point $x \in X$ has a [[neighbourhood|~192237ab]] $N$ that is [[compact|~56dabfb9]].

## Remarks

Authors use several stronger definitions, for example that each neighbourhood of $x$ contains a compact neighbourhood of $x$. For [[Hausdorff spaces|~a1fe0c25]], all the usual definitions agree.
Each compact space is locally compact. The space $\mathbb{R}^n$ is locally compact, because each closed ball is compact.
The rationals $\mathbb{Q}$ and each infinite-dimensional normed space are not locally compact.
A locally compact Hausdorff space has a Hausdorff [[one-point compactification|~79c8c402]].

## Explanations

### L1 human

A locally compact space is compact in small pieces: each point has a compact set around it.
The real line is not compact, but each closed interval in it is.
