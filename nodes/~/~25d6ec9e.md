## Example

Let $T = \operatorname{Th}(\N, 0, 1, +, \cdot, <)$, a complete extension of [[Peano arithmetic|HACXBCM7SS]], and write $p \mid x$ for the formula $\exists y \, (\underline{p} \cdot y = x)$.

1. By the [[definition|~12a18db1]], $(\N, 0, 1, +, \cdot, <)$ has a countable recursively saturated elementary extension $\mathcal{M}$.
2. $\mathcal{M}$ is nonstandard: the computable set $\set{\underline{n} < x : n \in \N}$ is finitely satisfiable, so it is realized.
3. For a set $S$ of primes let $p_S(x) = \set{p \mid x : p \in S} \cup \set{\neg (p \mid x) : p \notin S, \, p \text{ prime}}$.
4. Each $p_S$ is finitely satisfiable in $\N$: for finitely many primes $p_1, \dots, p_k$ in $S$ and $q_1, \dots, q_m$ outside $S$, the product $p_1 \cdots p_k$ is divisible by each $p_i$ and by no $q_j$.
5. So each $p_S$ is a [[type|9V71Q3SD1G]] of $T$, and $p_S$ and $p_{S'}$ contradict each other when $S \ne S'$.
6. There are $2^{\aleph_0}$ sets of primes, so $T$ has $2^{\aleph_0}$ pairwise contradictory types over $\emptyset$.
7. The countable model $\mathcal{M}$ realizes at most countably many of them, so it omits some $p_S$, and it is not [[saturated|RMTZ5J64FX]].
8. If $S$ is [[computable|PPGD5KW8JC]], then $p_S$ is computable, so $\mathcal{M}$ realizes it. So $\mathcal{M}$ is [[recursively saturated|~fc343dbc]] and omits only types $p_S$ with $S$ not computable.

## Remarks

The sets $S$ for which $p_S$ is realized in $\mathcal{M}$ depend on $\mathcal{M}$, and they always include the computable sets.
By the theorem of Barwise and Schlipf, $\mathcal{M}$ is also resplendent.
By [[Tennenbaum's theorem|W6D5ZJAY9D]], the nonstandard model $\mathcal{M}$ is not computable, although its construction uses only computable types.

## Explanations

### L1 human

A nonstandard model of arithmetic has numbers that are larger than every ordinary number.
Such a number is divisible by some primes and not by others, and this pattern is a set of primes.
A countable model has only countably many numbers, so it misses most patterns, but a recursively saturated model has a number for every pattern that a program can describe.

### L2 human

We find an element of $\mathcal{M}$ divisible by every prime.

1. The set $\set{p \mid x : p \text{ prime}}$ is computable, since a program can list the primes.
2. A finite part is satisfied by a product of finitely many primes.
3. Recursive saturation gives $b \in M$ divisible by every standard prime, and $b \ne 0$ can be added as one more formula.

The typical use is to produce nonstandard numbers with prescribed computable divisibility.
The trap is to expect the same for a non-computable set of primes.
