## Example

Let $F$ be a field and $N = J_2(0) = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}$, so $N e_1 = 0$ and $N e_2 = e_1$.
Consider the [[module|~772e5994]] $F^2_N$, with $x$ acting as $N$.

1. Define $\psi \colon F[x] \to F^2$ by $\psi(f) = f(N) e_2$. It is a homomorphism of $F[x]$-modules, since $\psi(gf) = g(N) f(N) e_2 = g \cdot \psi(f)$.
2. $\psi(1) = e_2$ and $\psi(x) = N e_2 = e_1$. So $\psi$ is surjective.
3. $\psi(x^2) = N e_1 = 0$, so $(x^2) \subseteq \ker \psi$.
4. For $f = a + bx + x^2 g$, $\psi(f) = a e_2 + b e_1$. This is $0$ only if $a = b = 0$. So $\ker \psi = (x^2)$.
5. Hence $F^2_N \cong F[x]/(x^2)$, a cyclic module with generator $e_2$.
6. The submodules of $F[x]/(x^2)$ are $0$, $(x)/(x^2)$ and the whole module. Under $\psi$ they are $0$, the line $F e_1$ and $F^2$.
7. These are exactly the [[$N$-invariant subspaces|0ACX5QT8TE]] of $F^2$, as the [[dictionary theorem|~3b7dc48a]] says: a line $F v$ is invariant only if $Nv \in Fv$, and $N(a, b) = (b, 0)$ is a multiple of $(a, b)$ only if $b = 0$.

## Remarks

The example shows a cyclic module that is not a direct sum of two smaller nonzero submodules: the only nonzero proper submodule is $F e_1$.
For $J_k(0)$, the same map gives $F^k_{J_k(0)} \cong F[x]/(x^k)$, with generator $e_k$.
For $J_k(\lambda)$, it gives $F[x]/((x - \lambda)^k)$.

## Explanations

### L1 human

The matrix $N$ sends the second basis vector to the first, and the first to zero.
Think of $x$ as "apply $N$".
Then the second basis vector plays the role of $1$, the first plays the role of $x$, and $x$ squared is zero.
So the plane with this map behaves like the polynomials in which $x$ squared counts as zero.

### L2 human

1. Compute $(3 + 2x + 5x^2) \cdot (1, 1)$ in $F^2_N$, over $\mathbb{Q}$.
2. $N(1, 1) = (1, 0)$ and $N^2 = 0$.
3. So the result is $3(1, 1) + 2(1, 0) + 0 = (5, 3)$.
4. In $\mathbb{Q}[x]/(x^2)$, the vector $(1, 1) = e_1 + e_2$ is $x + 1$, and $(3 + 2x + 5x^2)(1 + x) \equiv (3 + 2x)(1 + x) = 3 + 5x + 2x^2 \equiv 3 + 5x$ modulo $x^2$, which is $3 e_2 + 5 e_1 = (5, 3)$.

The typical use is to read off invariant subspaces from ideals.
The trap is to match $e_1$ with $1$: the generator is $e_2$, the vector that $N$ does not kill.
