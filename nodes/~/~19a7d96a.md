## Summary

*Higher-order reverse mathematics* is the part of reverse mathematics that works in the language of all finite types, not only with numbers and sets of numbers.
Ulrich Kohlenbach began it in 2005, with the base system $\mathsf{RCA}_0^\omega$.
The higher-order systems prove the same sentences of [[second-order arithmetic|DC60FYCSPM]] as the second-order systems they extend, so they keep the classification of the usual theorems.
What they add is the ability to state theorems about arbitrary functions on the reals and about uncountable families directly, without codes.

## Motivation

In [[RCA0|~58b63877]] a real number is a sequence of rationals, and a [[continuous function|0X3WGX95FE]] $f : \R \to \R$ is coded by a set of numbers that lists rational approximations.
Only continuous functions have such codes.
A discontinuous function such as the Heaviside function, a functional on [[Baire space|0ZH5AJ2ED7]], or a covering of $[0, 1]$ indexed by all reals cannot be named by a set of numbers.
So second-order arithmetic cannot even state many theorems of analysis in their usual form.
Higher types give names to these objects: a function from reals to reals is an object of type $1 \to 1$.
Then one can ask the reverse-mathematics question for such theorems as well: which axioms prove them.

## Notation

The finite types are built from type $0$, the natural numbers, by the rule that $\sigma \to \tau$ is a type when $\sigma$ and $\tau$ are.
Type $1 = 0 \to 0$ is the type of functions $\N \to \N$, and type $2 = 1 \to 0$ is the type of functionals on Baire space.
The base system $\mathsf{RCA}_0^\omega$ is Kohlenbach's $\mathsf{E}\text{-}\mathsf{PRA}^\omega + \mathsf{QF}\text{-}\mathsf{AC}^{1,0}$: [[primitive recursive arithmetic|330YAP9Y4Q]] in all finite types with extensionality, quantifier-free induction, and the axiom of choice from type $1$ to type $0$ for quantifier-free formulas.
Kleene's quantifier $(\exists^2)$ is the axiom
$$\exists \varphi^{2}\, \forall f^{1}\, \big(\varphi(f) = 0 \leftrightarrow \exists n\, f(n) = 0\big).$$
$\mathsf{ACA}_0^\omega$ denotes $\mathsf{RCA}_0^\omega + (\exists^2)$.
Kleene's $(\exists^3)$ is the analogous axiom one type higher: a functional of type $3$ that decides $\exists f^1\, Y(f) = 0$ for each $Y$ of type $2$.

## Remarks

### Examples

- Over $\mathsf{RCA}_0^\omega$, $(\exists^2)$ gives a discontinuous function $\R \to \R$. The [[example on the Heaviside function|~3407d0d6]] builds it.
- Over $\mathsf{RCA}_0^\omega$, $(\exists^2)$ proves arithmetical comprehension. The [[example on arithmetical comprehension|~53939a2d]] gives the induction on formulas.
- The statement NIN, "for every $Y : [0, 1] \to \N$ there are $x \ne y$ with $Y(x) = Y(y)$", is a form of the uncountability of $\R$. Normann and Sanders studied its strength in 2022.

### Non-examples

- The Heaviside function cannot be coded in second-order arithmetic, so the classical framework cannot even state that it exists. The [[non-example|~042da6e6]] proves this.
- A theorem about continuous functions on $[0, 1]$, such as the intermediate value theorem, needs no higher types. Higher-order reverse mathematics gives it the same strength as the classical framework, by property 1.

### Basic properties

1. $\mathsf{RCA}_0^\omega$ is conservative over $\mathsf{RCA}_0$ for sentences of second-order arithmetic (Kohlenbach, 2005). The proof interprets the higher types by the extensional continuous functionals, so that every object of higher type becomes a code that is a set of numbers.
2. Over $\mathsf{RCA}_0^\omega$, $(\exists^2)$ is equivalent to the existence of a discontinuous function $F : \R \to \R$ (Kohlenbach, 2005). One direction is the Heaviside example. The other direction uses Grilliot's trick, which recovers $(\exists^2)$ from any point of discontinuity.
3. $\mathsf{RCA}_0^\omega$ does not prove that a discontinuous function exists, so by property 2 it does not prove $(\exists^2)$. A model in which every function $\R \to \R$ is continuous comes from the interpretation in property 1.
4. $\mathsf{ACA}_0^\omega$ proves [[ACA0|~08f6623a]], and it is conservative over $\mathsf{ACA}_0$ for sentences of second-order arithmetic.
5. Normann and Sanders ("On the uncountability of $\R$", Journal of Symbolic Logic, 2022) showed that NIN is not provable in $\mathsf{Z}_2^\omega$, the union of the systems that add the comprehension functionals for $\Pi^1_k$ formulas to $\mathsf{RCA}_0^\omega$. It is provable in $\mathsf{Z}_2^\Omega = \mathsf{RCA}_0^\omega + (\exists^3)$. Both systems are conservative over $\mathsf{Z}_2$ for second-order sentences.
6. The Heine-Borel theorem for uncountable coverings of $[0, 1]$, which follows from Cousin's lemma, behaves like NIN according to work of Normann and Sanders: the comprehension functionals of $\mathsf{Z}_2^\omega$ do not suffice to prove it.

### History

Kohlenbach introduced the framework in "Higher order reverse mathematics" (2005), as part of his work on the proof theory of analysis.
Kleene's quantifier $\exists^2$ and Feferman's non-constructive $\mu$-operator, which is equivalent to it over the base system, come from the older study of computation in higher types.
Normann and Sanders later used the framework to classify theorems about uncountable objects, and they found that statements like NIN and the uncountable Heine-Borel theorem are hard to prove even though they are easy to state.

### Common errors

- Reading $(\exists^2)$ as the same axiom as arithmetical comprehension. $\mathsf{ACA}_0$ asserts one set for each formula, while $(\exists^2)$ is a single functional that answers all $\Sigma^0_1$ questions about all functions uniformly. The second-order consequences agree, by property 4, but the higher-order consequences differ.
- Treating a code of a continuous function as the function itself. A code exists only for continuous functions, so "every function $\R \to \R$" in second-order arithmetic means "every coded continuous function".
- Expecting higher-order systems to be stronger for second-order statements. The base system and $\mathsf{ACA}_0^\omega$ are conservative over their second-order versions.

## Explanations

### L1 human

Classical reverse mathematics talks only about whole numbers and sets of whole numbers.
It describes a real number or a continuous function by an infinite list of approximations.
A function with a jump, like the switch that is $0$ up to a point and $1$ after it, has no such description.
Higher-order reverse mathematics allows functions of functions as basic objects.
So it can ask which axioms are needed to prove theorems about jumps, about all functions on the reals, and about uncountable families.

### L2 human

Here is how $(\exists^2)$ turns a real number into a yes or no answer, the core of the Heaviside example.

1. Let $x$ be given by rationals $q_n$ with $\abs{q_n - x} \le 2^{-n}$.
2. Then $x > 0$ if and only if $q_n > 2^{-n+1}$ for some $n$.
3. The function $g(n) = 0$ if $q_n > 2^{-n+1}$, and $g(n) = 1$ otherwise, is computable from the $q_n$.
4. The functional $\varphi$ of $(\exists^2)$ answers whether $g$ has a zero, so it decides whether $x > 0$.

The typical use: one shows that a theorem about arbitrary functions implies $(\exists^2)$ by building a discontinuous function from it, and then applies Grilliot's trick.
The trap: a function of type $1 \to 1$ on representations must give equal outputs on equal reals; this extensionality has to be checked at each step.

### L3 human

The framework separates two kinds of strength that second-order arithmetic merges: comprehension for sets and the existence of functionals.
At the level of $\mathsf{ACA}_0$ the two agree on second-order sentences, but higher up they come apart sharply, as the results on NIN show.
Systems of finite type are also the setting of proof mining, a field Kohlenbach developed: [[the Dialectica interpretation|HZ17ES9PDY]] and related functional interpretations extract bounds from proofs in such systems.
The study of the functionals themselves, such as $\exists^2$, $\exists^3$ and the Suslin functional, belongs to higher-type computability theory.
