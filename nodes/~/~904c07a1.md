## Example

Subtraction is a [[binary operation|0M418FE7BB]] on the [[integers|0C4JS9RF5M]] $\mathbb{Z}$.
We show that it is not [[associative|0K8F7PVDMX]].

1. Take $a = 5$, $b = 3$, $c = 2$.
2. $(5 - 3) - 2 = 2 - 2 = 0$.
3. $5 - (3 - 2) = 5 - 1 = 4$.
4. Since $0 \neq 4$, the law $(a - b) - c = a - (b - c)$ fails for this triple. One triple is enough, so subtraction is not associative.

We can also find all the triples where the law holds.

5. For all $a, b, c \in \mathbb{Z}$, $(a - b) - c = a - b - c$ and $a - (b - c) = a - b + c$.
6. These are equal exactly when $-c = c$, that is, when $c = 0$.

So the law holds only for the triples with $c = 0$.

## Remarks

Subtraction on $\mathbb{Q}$, $\mathbb{R}$ and $\mathbb{C}$ fails in the same way, with the same triple.
Division on $\mathbb{Q} \setminus \{0\}$ is not associative either: $(8 / 4) / 2 = 1$, but $8 / (4 / 2) = 4$.
Because subtraction is not associative, the expression $a - b - c$ needs a convention, and the convention is $(a - b) - c$.
Subtraction can be written with addition: $a - b = a + (-b)$.
Addition is associative, so $a + (-b) + (-c)$ has one meaning, and it is the conventional value of $a - b - c$.
Subtraction is not [[commutative|099E72KTF8]] either, since $3 - 2 \neq 2 - 3$.

## Explanations

### L1 human

Take $5$ apples.
Take away $3$, then take away $2$: no apples are left.
Now first compute $3 - 2 = 1$, and take away $1$ apple from $5$: $4$ apples are left.
The brackets changed the answer, so subtraction is not associative.

### L2 human

To show that an operation is not associative, find one triple $a, b, c$ with $(a \ast b) \ast c \neq a \ast (b \ast c)$, and compute both sides.
The computation in steps 5 and 6 shows that a good choice needs $c \neq 0$.
A trap is to test with $c = 0$: for example, $(5 - 3) - 0 = 5 - (3 - 0)$, and this can give the false idea that the law holds.
The typical use of this non-example is to show that a set with a binary operation can fail the first group axiom.
