## Statement

Let $K$ be a commutative ring and let $A$ be an $n \times n$ matrix over $K$.
If one row of $A$ is zero, then $\det A = 0$, where $\det$ is the [[determinant|~362fc72a]].

## Remarks

This follows from linearity in that row: the zero row is $0$ times itself, so $\det A = 0 \cdot \det A = 0$.
The same holds for a zero column.

## Explanations

### L1 human

A zero row means that one edge of the box spanned by the rows has length zero.
Such a box has no volume.
So the determinant is zero.
