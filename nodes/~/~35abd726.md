## Example

Let $\mathrm{Th}(\N)$ be the set of [[sentences|DKFGQTRYZE]] of the language $\set{0, S, +, \cdot}$ that are true in the [[standard model|WP27CABPA4]] $\N$.
We take $\mathrm{Th}(\N)$ as a set of axioms and check that it is [[negation complete|319P85G2C1]].

1. Let $\varphi$ be a sentence. In $\N$, $\varphi$ is true or $\neg \varphi$ is true, by the definition of satisfaction.
2. If $\varphi$ is true, then $\varphi \in \mathrm{Th}(\N)$, so $\mathrm{Th}(\N) \vdash \varphi$ by a one-line proof.
3. If $\neg \varphi$ is true, then $\neg \varphi \in \mathrm{Th}(\N)$, so $\mathrm{Th}(\N) \vdash \neg \varphi$.
4. So $\mathrm{Th}(\N)$ is negation complete.
5. It is consistent, since $\N$ is a model of it.
6. It contains the axioms of [[Robinson arithmetic|3K1AKGXF8A]], since they are true in $\N$.

## Remarks

By the first incompleteness theorem, $\mathrm{Th}(\N)$ is not computably enumerable; it [[has no decidable axiom set|~a7addafc]].
The theorems of $\mathrm{Th}(\N)$ are exactly its members, since a sentence provable from true sentences is true.
The same argument shows that the theory of any structure is negation complete.

## Explanations

### L1 human

Take as axioms all true statements about whole numbers.
Every statement is true or false, so the statement or its negation is an axiom.
This list settles every question, but no computer can list it.

### L2 human

1. Each sentence is true or false in $\N$.
2. The true one, $\varphi$ or $\neg \varphi$, is an axiom.

The typical use is as the extreme case: completeness is easy when the axioms are all truths.
A trap: this does not contradict Gödel's theorem, because $\mathrm{Th}(\N)$ is not computably enumerable.
