## Example

Let $D$ be a nonempty set.
A unary quantifier on $D$ is a set $Q$ of subsets of $D$; a formula $Qx \, \varphi(x)$ is true when the set of $x$ that satisfy $\varphi$ is in $Q$.
This is the simplest case of a [[generalized quantifier|MFV98WTF4G]].
A [[permutation|05RWFKVTJ7]] $\pi$ of $D$ acts on $Q$ by $\pi[Q] = \{\pi[X] : X \in Q\}$, and $Q$ is permutation invariant when $\pi[Q] = Q$ for every $\pi$.
We show: $Q$ is permutation invariant if and only if, for all $X, Y \subseteq D$ with $|X| = |Y|$ and $|D \setminus X| = |D \setminus Y|$, we have $X \in Q$ exactly when $Y \in Q$.

1. Let $\pi$ be a permutation and $X \subseteq D$. The map $\pi$ restricts to a [[bijection|0SNQEF7Z53]] from $X$ onto $\pi[X]$, so $|\pi[X]| = |X|$.
2. The map $\pi$ also restricts to a bijection from $D \setminus X$ onto $D \setminus \pi[X]$, because $\pi$ is a bijection of $D$. So $|D \setminus \pi[X]| = |D \setminus X|$.
3. Suppose that $Q$ satisfies the cardinality condition, and let $X \in Q$. By steps 1 and 2 the set $\pi[X]$ has the same two cardinalities as $X$, so $\pi[X] \in Q$. So $\pi[Q] \subseteq Q$.
4. Step 3 applied to $\pi^{-1}$ gives $\pi^{-1}[Q] \subseteq Q$, so $Q \subseteq \pi[Q]$, and $\pi[Q] = Q$.
5. Conversely, suppose that $Q$ is invariant, and let $X, Y$ have $|X| = |Y|$ and $|D \setminus X| = |D \setminus Y|$.
6. Choose a bijection $f \colon X \to Y$ and a bijection $g \colon D \setminus X \to D \setminus Y$. Their union $\pi = f \cup g$ is a permutation of $D$ with $\pi[X] = Y$.
7. If $X \in Q$, then $Y = \pi[X] \in \pi[Q] = Q$. The same argument with $\pi^{-1}$ gives the other direction.

So the following quantifiers are permutation invariant, and they are logical by Tarski's criterion:

- $\forall$, with $Q = \{D\}$, that is, $|D \setminus X| = 0$;
- $\exists$, with $Q = \{X : |X| \geq 1\}$;
- "there are at least two", with $Q = \{X : |X| \geq 2\}$;
- "there are infinitely many", with $Q = \{X : X \text{ is infinite}\}$;
- "most", with $Q = \{X : |X| > |D \setminus X|\}$.

## Remarks

The example shows that the criterion admits many quantifiers that first-order logic cannot express.
"There are infinitely many" is not definable in first-order logic, because of the [[compactness theorem|1NR3HAWG9D]], and "most" is not definable even on finite domains.
On a finite set $D$ with $n$ elements the second cardinality is $n - |X|$, so an invariant quantifier depends only on $|X|$, and there are exactly $2^{n+1}$ invariant quantifiers, one for each set of possible sizes $0, 1, \ldots, n$.
On an infinite $D$ both cardinalities are needed: the sets of even numbers and of numbers at least $1$ in $\mathbb{N}$ both have size $\aleph_0$, but their complements have sizes $\aleph_0$ and $1$.
A quantifier such as "contains the number $0$", that is $Q = \{X : 0 \in X\}$, is not invariant, because a permutation can move $0$.

## Explanations

### L1 human

The word "some" in "some cats are black" asks only whether the set of black cats is empty or not.
The word "most" asks only whether there are more black cats than other cats.
Neither word cares which cats they are, only how many.
If we exchange one cat for another, the answers stay the same.
This is why these words count as logical: they look only at numbers of objects.

### L2 human

We take $D = \{1, 2, 3\}$ and test two quantifiers.

1. Let $Q_{\text{most}} = \{X \subseteq D : |X| \geq 2\}$, because $|X| > 3 - |X|$ means $|X| \geq 2$.
2. So $Q_{\text{most}} = \{\{1, 2\}, \{1, 3\}, \{2, 3\}, \{1, 2, 3\}\}$.
3. A permutation maps each $2$-element set to a $2$-element set and $D$ to $D$, so it maps $Q_{\text{most}}$ to itself.
4. Let $Q_1 = \{X \subseteq D : 1 \in X\}$, the quantifier "the object $1$ has the property".
5. The permutation $\sigma$ that swaps $1$ and $2$ maps $\{1\} \in Q_1$ to $\{2\}$, and $\{2\} \notin Q_1$.
6. So $Q_{\text{most}}$ is invariant and $Q_1$ is not.

The typical use of this test is in the study of natural language quantifiers, where "most", "few" and "at least three" are classified by the sizes of sets.
A trap is to forget the complement on infinite domains: on $\mathbb{N}$ the quantifier $\{X : D \setminus X \text{ is finite}\}$ ("all but finitely many") is invariant, but it does not depend on $|X|$ alone.
