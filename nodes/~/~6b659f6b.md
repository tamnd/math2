## Example

We check three pairs of structures that are [[elementarily equivalent|P3B1V182N4]] and not [[isomorphic|PZMGQMDN25]].
[[Isomorphic structures are elementarily equivalent|NDTJ2E895C]], so each pair shows that the converse fails.

1. Orders. $(\Q, <) \equiv (\R, <)$, by [[this example|TZZVG88865]]. They are not isomorphic, because an isomorphism is a bijection, and $\Q$ is countable while $\R$ is not.
2. Arithmetic: the structure. Let $L = \set{0, S, +, \cdot, <}$, let $\mathcal{N} = (\N, 0, S, +, \cdot, <)$, and let $\bar n$ be the term $S \cdots S 0$ with $n$ symbols $S$.
3. Arithmetic: the model. Add a constant $c$. Each finite part of $\mathrm{Th}(\mathcal{N}) \cup \set{\bar n < c : n \in \N}$ holds in $\mathcal{N}$ with $c$ a large number. By the [[compactness theorem|1NR3HAWG9D]] the set has a model, and with the [[Löwenheim-Skolem theorem|484M0TZ1S7]] we can take it countable. Its $L$-reduct $\mathcal{N}^*$ satisfies $\mathcal{N}^* \equiv \mathcal{N}$.
4. Arithmetic: no isomorphism. Let $h \colon \mathcal{N}^* \to \mathcal{N}$ be an isomorphism, and $m = h(c^{\mathcal{N}^*})$. Then $\mathcal{N}^* \models \bar m < c$, so $\mathcal{N} \models \bar m < \bar m$, because $h$ maps the value of the term $\bar m$ to $m$. This is false, so no isomorphism exists, although both models are countable.
5. Fields. The algebraic closure $\overline{\Q}$ of $\Q$ and the algebraic closure $K$ of the field $\Q(t)$ of rational functions are both algebraically closed of characteristic $0$. The theory of these fields is [[complete|MT8TDVPBXB]], so $\overline{\Q} \equiv K$, as in [[this example|N0VJ3FPSQ2]] for $\overline{\Q}$ and $\C$.
6. Fields: no isomorphism. An isomorphism fixes $\Q$ and preserves algebraic independence over $\Q$, so it preserves the [[transcendence degree|D7TR0YWR9H]]. $\overline{\Q}$ has transcendence degree $0$ and $K$ has $1$, so they are not isomorphic, although both are countable.

## Remarks

By [[Steinitz's theorem|CAEHMSX9RT]], the countable algebraically closed fields of characteristic $0$ are classified by their transcendence degree $0, 1, 2, \dots, \aleph_0$, so there are $\aleph_0$ of them up to isomorphism, all elementarily equivalent.

The example shows that first-order logic cannot fix a structure up to isomorphism, even among countable structures.
The size obstruction of step 1 is general: by the Löwenheim-Skolem theorem, an infinite structure in a countable signature is elementarily equivalent to structures of every infinite cardinality.
Steps 4 and 6 show that even a fixed size is not enough.
For finite structures the situation changes: [[elementarily equivalent finite structures are isomorphic|J15KTB0NH5]].
A theory whose models of one cardinality $\kappa$ are all isomorphic is called $\kappa$-categorical; the theory of $(\Q, <)$ is $\aleph_0$-categorical, and the theory of algebraically closed fields of characteristic $0$ is categorical in every uncountable cardinality.

## Explanations

### L1 human

Two structures are elementarily equivalent when every statement of first-order logic is true in one exactly when it is true in the other.
They are isomorphic when they are copies of each other.
Copies always agree on all statements, but agreement on all statements does not make two structures copies.
For example, the rational numbers and the real numbers, with their order, satisfy the same statements, but there are more real numbers than rational numbers, so they cannot be copies.

### L2 human

We check where the argument of step 4 uses the extra element $c$.

1. In $\mathcal{N}$, every element $m$ is the value of the term $\bar m$.
2. An isomorphism maps the value of each term to the value of the same term, so the values of all terms in $\mathcal{N}^*$ map onto all of $\N$.
3. In $\mathcal{N}^*$, the element $c$ is above the value of every term $\bar m$, so it is not the value of any term.
4. So an isomorphism has no element of $\N$ left for $c$.

The typical use of these pairs is to test whether a property is first-order: a property that holds in one structure of a pair and fails in the other is not expressible by a first-order sentence, as for [[the properties in this example|T1S9T0RKHJ]].
A trap is to think that the nonstandard model is "the same as $\N$ with an extra point"; it contains infinitely many elements beyond the numerals, such as $c + c$ and $c \cdot c$.
