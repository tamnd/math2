## Example

Let $f \colon X \to Y$ be a function, and let $A$ and $B$ be subsets of $X$.
The [[image|0Q3F20XB0A]] of a subset $S$ is $f(S) = \{ f(s) : s \in S \}$.
A student claims that $f(A \cap B) = f(A) \cap f(B)$ and starts a proof by [[double inclusion|~b9b86114]].

1. ($\subseteq$) Let $y \in f(A \cap B)$. Then $y = f(x)$ for some $x \in A \cap B$.
2. Since $x \in A$, we get $y = f(x) \in f(A)$. Since $x \in B$, we get $y \in f(B)$.
3. So $y \in f(A) \cap f(B)$. This half is correct, and it is the statement [[image of an intersection|0RX7DDBYCK]].
4. ($\supseteq$) Let $y \in f(A) \cap f(B)$. Then $y = f(a)$ for some $a \in A$, and $y = f(b)$ for some $b \in B$.
5. The student now writes "so $y = f(x)$ with $x \in A \cap B$". This step has no reason: the elements $a$ and $b$ can be different.
6. The half cannot be repaired, because the claim is false. Take $X = \{1, 2\}$, $Y = \{0\}$, the constant function $f(1) = f(2) = 0$, $A = \{1\}$ and $B = \{2\}$.
7. Then $A \cap B = \varnothing$, so $f(A \cap B) = \varnothing$.
8. But $f(A) = \{0\}$ and $f(B) = \{0\}$, so $f(A) \cap f(B) = \{0\}$.
9. The element $0$ lies in $f(A) \cap f(B)$ and not in $f(A \cap B)$. So the inclusion $\supseteq$ fails, and the two sets are not equal.

## Remarks

1. The example is not an instance of double inclusion, because only one inclusion is true. The method gives a proof only when both halves succeed.
2. The failed step 5 shows where the reverse inclusion needs an extra hypothesis. If $f$ is [[injective|0PVG1CRAJN]], then $f(a) = f(b)$ gives $a = b$, so $a \in A \cap B$, and the step becomes correct.
3. So for an injective $f$ the equality $f(A \cap B) = f(A) \cap f(B)$ holds by double inclusion. Conversely, if the equality holds for all $A$ and $B$, then $f$ is injective: apply it to $A = \{a\}$ and $B = \{b\}$ with $f(a) = f(b)$.
4. For unions the situation differs: $f(A \cup B) = f(A) \cup f(B)$ holds for every function, and both halves of the double inclusion succeed.
5. For [[preimages|0FGCFY1AZX]] both laws hold: $f^{-1}(C \cap D) = f^{-1}(C) \cap f^{-1}(D)$ and the same for unions.

## Explanations

### L1 human

Suppose each student of a class gets a grade.
Let $A$ be the students in the chess club and $B$ the students in the choir, and suppose no student is in both.
Then the grades of the students in both clubs form an empty list.
But Ann in the chess club and Ben in the choir can both have the grade "B".
So "B" is a grade of the chess club and a grade of the choir, but it is not the grade of anyone in both clubs.

### L2 human

We find the failure on a function of real numbers.

1. Let $f(x) = x^2$ on $\mathbb{R}$, $A = [-2, -1]$ and $B = [1, 2]$.
2. Then $A \cap B = \varnothing$, so $f(A \cap B) = \varnothing$.
3. Also $f(A) = [1, 4]$, because $x \mapsto x^2$ is continuous and decreasing on $[-2, -1]$, with values $4$ at $-2$ and $1$ at $-1$.
4. In the same way $f(B) = [1, 4]$, because $f$ is increasing on $[1, 2]$.
5. So $f(A) \cap f(B) = [1, 4]$, which is not empty.

The typical use of this example is a warning: before a proof of an equality of sets, test the reverse inclusion on a small example.
A trap is to give the two elements $a$ and $b$ of step 4 the same name $x$ by accident, which hides the gap.
