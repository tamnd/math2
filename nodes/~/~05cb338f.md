## Statement

Let $\mathcal{L}$ be a countable language that contains the [[language of arithmetic|D8SD54M5PN]], with a fixed [[Gödel numbering|MFJXPAF0R0]].
Let $\mathcal{M}$ be an $\mathcal{L}$-structure that expands the [[standard model|WP27CABPA4]] $\mathcal{N}$.
Say that a formula $\varphi(v)$ of $\mathcal{L}$ with exactly one free variable *defines* $n$ in $\mathcal{M}$ if $\mathcal{M} \models \forall v\,(\varphi(v) \leftrightarrow v = \underline{n})$.
Then there is no formula $\mathrm{Def}(x, y)$ of $\mathcal{L}$ with this property: for all $a, n \in \mathbb{N}$,
$$\mathcal{M} \models \mathrm{Def}(\underline{a}, \underline{n}) \iff a \text{ codes a formula of } \mathcal{L} \text{ with one free variable that defines } n \text{ in } \mathcal{M}.$$

## Remarks

### Why each hypothesis is needed

1. The formula $\mathrm{Def}$ must be in the same language $\mathcal{L}$ as the formulas it describes. In set theory, definability by arithmetical formulas has an explicit definition, as truth does in [[this example|~e9e7c9af]].
2. If only formulas of bounded complexity are described, the result can fail. For $\Sigma_n$ formulas, a [[partial truth predicate|Y2MF1EZAM7]] gives a formula that expresses $\Sigma_n$-definability.
3. The structure must interpret the arithmetic symbols in the standard way. The proof uses that a bounded quantifier $\forall x \le b$ ranges over $0, \ldots, b$ only.

### Consequences

1. Take $\mathcal{L}$ to be the language of arithmetic and $\mathcal{M} = \mathcal{N}$: no arithmetical formula expresses arithmetical definability in $\mathcal{N}$.
2. Take $\mathcal{L} = \mathcal{L}_{\mathrm{Def}}$ and let $\mathrm{Def}$ be the new atomic predicate. Then the [[naive definability schema|~a84aca18]] fails in every expansion of $\mathcal{N}$.
3. So the [[Berry paradox|~6cd3e1b8]] does not make arithmetic inconsistent: it shows that its definability relation is not expressible in it.

### Converse

Every number $n$ is defined by the formula $v = \underline{n}$.
So the set of definable numbers is all of $\mathbb{N}$, and the difficulty is only in expressing the relation "defines".

### Generalizations

The statement is closely related to [[Tarski's undefinability theorem|YRV6SYK2BY]].
A definability formula would give a truth formula, by $\mathrm{Tr}(\ulcorner \sigma \urcorner) :\leftrightarrow \mathrm{Def}(\ulcorner \sigma \wedge v = 0 \urcorner, \underline{0})$.
The proof by the Berry construction uses counting, and it does not use a liar sentence.

## History

Wikipedia states that Boolos (1989) used a formalized Berry paradox to prove Gödel's incompleteness theorem.
In his proof, a representable definability relation takes the place of $\mathrm{Def}$.
The same entry states that Chaitin built formal analogues of the paradox with programs or proofs of bounded length.

## Explanations

### L1 human

Every number can be described by some formula, for example "$v = 7$" describes $7$.
The statement says that a language cannot contain one formula that tells, for every formula, which number it describes.
If it could, we could write "the least number not described by any formula shorter than this one", and get a contradiction.

### L2 human

1. Suppose $\mathrm{Def}$ exists, and fix a bound $b$.
2. Only finitely many formulas have codes at most $b$, and each defines at most one number.
3. So some number is not defined by any formula with code at most $b$; let $m$ be the least one.
4. Let $\beta(y)$ say "$y$ is the least number not defined by a formula with code at most $b$". If $\beta$ has code at most $b$, it defines $m$.
5. That contradicts the choice of $m$. The diagonal lemma with parameters makes the code of this formula equal to $b$.

The typical use is as a model for incompleteness proofs by counting, as in [[Chaitin's proof|77EMTE7X9V]].
The trap is to forget that the bound must be the code of the formula itself, which needs the diagonal lemma.

### L3 human

The proposition is a form of undefinability in which the self-reference is hidden in a counting argument.
It is the logical core of the argument that [[Kolmogorov complexity|8PY3K6NCKF]] is not computable.
A short program cannot output "the first string with no short description", because it is itself a short description.
