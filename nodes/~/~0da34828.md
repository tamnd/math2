## Example

Let $U = \set{0, 1}$ and $\alpha = 2$, so $U^2$ has the four points $(0, 0), (0, 1), (1, 0), (1, 1)$.
Let $A = \mathcal{P}(U^2)$, with $16$ elements, and the set operations.
Put $c_0 X = \set{(u, s_1) : u \in U, (s_0, s_1) \in X}$, $c_1 X = \set{(s_0, u) : u \in U, (s_0, s_1) \in X}$, $d_{00} = d_{11} = U^2$ and $d_{01} = d_{10} = \set{(0, 0), (1, 1)}$.

1. Clauses 1 and 2 of [[the definition|RKCSWWVYTC]]: $c_\kappa \emptyset = \emptyset$, and $X \subseteq c_\kappa X$.
2. Clause 3: $c_0 Y$ is a union of lines along coordinate $0$, so a point of $X \cap c_0 Y$ moves along its line inside $c_0 Y$. Hence $c_0(X \cap c_0 Y) = c_0 X \cap c_0 Y$.
3. Clause 4: $c_0 c_1 X = c_1 c_0 X = U^2$ if $X \ne \emptyset$.
4. Clause 6 with $\kappa = 0$ and $\lambda = \mu = 1$: $c_0(d_{10} \cdot d_{01}) = c_0 \set{(0, 0), (1, 1)} = U^2 = d_{11}$.
5. Clause 7 with $x = \set{(0, 0)}$: $c_0(d_{01} \cdot x) = \set{(0, 0), (1, 0)}$ and $c_0(d_{01} \cdot -x) = c_0\set{(1, 1)} = \set{(0, 1), (1, 1)}$. The intersection is empty.

So $A$ is a [[cylindric algebra|1MDT9BF81H]] of dimension $2$.

## Remarks

1. For $X = \set{(0, 1)}$, $c_0 X = \set{(0, 1), (1, 1)}$: it is the set of the formula $v_1 = 1$.
2. The substitution $c_0(d_{01} \cdot X)$ sends the set of $\varphi(v_0, v_1)$ to the set of $\varphi(v_1, v_1)$.
3. The atoms of $A$ are the four points, and $c_0$ maps an atom to the line along coordinate $0$ through it.
4. This algebra is simple: $c_0 c_1 X = U^2$ for every $X \ne \emptyset$.

## Explanations

### L1 human

The four points form a two by two grid.
The first cylindrification spreads a set along the direction of coordinate $0$, and the second along the direction of coordinate $1$.
The diagonal is the set of points with equal coordinates.

### L2 human

1. Take $X = \set{(0, 1)}$.
2. $c_0 X = \set{(0, 1), (1, 1)}$ and $c_1 X = \set{(0, 0), (0, 1)}$.
3. $c_0(d_{01} \cap X) = c_0 \emptyset = \emptyset$, because $(0, 1)$ is off the diagonal: "$\varphi(v_1, v_1)$" holds nowhere.

The typical use: small set algebras let one test proposed identities by hand.
The trap: $c_0$ frees coordinate $0$, so it spreads along the direction of coordinate $0$.
