## Proof

Call a matrix a *T-product* if it is a finite product of [[transvection matrices|0NMN00FNW1]]; the empty product $I_n$ is a T-product.
We use three facts from the [[theorem on elementary matrices|~11309c07]].
Left multiplication by $T_{ij}(c)$ adds $c$ times row $j$ to row $i$.
Right multiplication by $T_{ij}(c)$ adds $c$ times column $i$ to column $j$.
The inverse of $T_{ij}(c)$ is $T_{ij}(-c)$.

We prove by induction on $n$ that there are T-products $L$ and $R$ and a [[diagonal matrix|0Q9PGXD9E4]] $D$ with $M = L D R$.

**Base case $n = 1$.**

1. Each $1 \times 1$ matrix $M = (m)$ is diagonal.
2. So $M = I_1 \, M \, I_1$, with $L = R = I_1$ the empty products.

**Induction step.** Let $n \ge 2$, and assume the result for size $n - 1$.

3. Case 1: row $n$ and column $n$ of $M$ are both zero. Then $M$ is the [[block matrix|0ASDFEQS6P]] $\operatorname{diag}(M', 0)$ with $M'$ of size $n - 1$, and we go to step 9 with $d = 0$ and no transvections used.
4. Case 2: $m_{nn} = 0$ and $m_{nk} \ne 0$ for some $k < n$. Replace $M$ by $M T_{kn}(1)$, which adds column $k$ to column $n$. The new entry $(n, n)$ is $m_{nn} + m_{nk} = m_{nk} \ne 0$.
5. Case 3: $m_{nn} = 0$, row $n$ is zero, and $m_{kn} \ne 0$ for some $k < n$. Replace $M$ by $T_{nk}(1) M$, which adds row $k$ to row $n$. The new entry $(n, n)$ is $m_{kn} \ne 0$.
6. In the remaining cases, $d = m_{nn} \ne 0$ now holds, and $M$ was multiplied by at most one transvection on one side.
7. For each $i < n$, multiply on the left by $T_{in}(-m_{in}/d)$, which subtracts $m_{in}/d$ times row $n$ from row $i$. This makes entry $(i, n)$ zero, and it does not change row $n$. After these steps column $n$ is $d\, e_n$.
8. For each $j < n$, multiply on the right by $T_{nj}(-m_{nj}/d)$, which subtracts $m_{nj}/d$ times column $n$ from column $j$. Column $n$ is $d\, e_n$, so only entry $(n, j)$ changes, and it becomes $0$.
9. By steps 3 to 8 there are T-products $P$ and $Q$ with $P M Q = \operatorname{diag}(M', d)$, for an $(n-1) \times (n-1)$ matrix $M'$ and a scalar $d$.
10. By the induction hypothesis, $M' = L' D' R'$ with T-products $L'$ and $R'$ of size $n - 1$ and a diagonal $D'$.
11. For a transvection $T_{ij}(c)$ of size $n - 1$, the block matrix $\operatorname{diag}(T_{ij}(c), 1)$ is the transvection $T_{ij}(c)$ of size $n$. By block multiplication, $\operatorname{diag}(XY, 1) = \operatorname{diag}(X, 1) \operatorname{diag}(Y, 1)$. So $\operatorname{diag}(L', 1)$ and $\operatorname{diag}(R', 1)$ are T-products of size $n$.
12. By block multiplication, $\operatorname{diag}(M', d) = \operatorname{diag}(L', 1)\, \operatorname{diag}(D', d)\, \operatorname{diag}(R', 1)$, and $\operatorname{diag}(D', d)$ is diagonal.
13. If $P = T_1 \cdots T_k$, then $P^{-1} = T_k^{-1} \cdots T_1^{-1}$, and each $T_l^{-1}$ is a transvection by the third fact above. So $P^{-1}$ and $Q^{-1}$ are T-products.
14. By steps 9 and 12, $M = P^{-1} \operatorname{diag}(L', 1)\, \operatorname{diag}(D', d)\, \operatorname{diag}(R', 1)\, Q^{-1}$.
15. Set $L = P^{-1}\operatorname{diag}(L', 1)$, $D = \operatorname{diag}(D', d)$ and $R = \operatorname{diag}(R', 1)\, Q^{-1}$. A product of T-products is a T-product, so $M = L D R$ is of the required form. This completes the induction.

## Idea

Use the last diagonal entry as a pivot.
If it is zero, one row or column addition makes it nonzero, unless row $n$ and column $n$ are already zero.
Row additions clear column $n$ and column additions clear row $n$, which splits off a block of size $n - 1$.
Induction treats that block, and the inverses of transvections are transvections.

## Variants

The proof in Mathlib follows the same plan; it reduces the last row and column and then uses induction.
The [[proof that $\mathrm{SL}_n(F)$ is generated by transvections|~5cde9a23]] uses the first entry as the pivot and makes it equal to $1$.
