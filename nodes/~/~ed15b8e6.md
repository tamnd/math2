## Example

Let $\iota \colon \R^2 \to \R^3$ be the map $\iota(x, y) = (x, y, 0)$, with the dot product on both spaces.
We check that $\iota$ is a [[linear isometry|0717XXPWM6]], and we compute its [[adjoint|0ST8QF9T3T]].

1. Linearity: $\iota\big(a(x, y) + b(x', y')\big) = (ax + bx', ay + by', 0) = a\,\iota(x, y) + b\,\iota(x', y')$.
2. Norms: $\norm{\iota(x, y)}^2 = x^2 + y^2 + 0^2 = \norm{(x, y)}^2$. So $\norm{\iota(x, y)} = \norm{(x, y)}$.
3. The matrix of $\iota$ in the standard bases is $A = \begin{pmatrix} 1 & 0 \\ 0 & 1 \\ 0 & 0 \end{pmatrix}$.
4. The standard bases are orthonormal, so the matrix of $\iota^*$ is $A^T$, by [[the matrix of the adjoint|0DBTE6HVBD]]. So $\iota^*(x, y, z) = (x, y)$.
5. $A^TA = I_2$, so $\iota^*\iota = I$, as [[the equivalent conditions|~d0f0e2fd]] say.
6. $AA^T = \begin{pmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \\ 0 & 0 & 0 \end{pmatrix} \neq I_3$. So $\iota\iota^* \neq I$.
7. The vector $(0, 0, 1)$ is not in the range of $\iota$, so $\iota$ is not surjective.

## Remarks

- The example shows that conditions 6 and 7 of the equivalent conditions need $\dim V = \dim W$.
- The map $\iota\iota^*$ is the orthogonal projection of $\R^3$ onto the plane $z = 0$. For every linear isometry $T$, the map $TT^*$ is the orthogonal projection onto the range of $T$.
- If we change the map to $(x, y) \mapsto (x, y, x)$, it is still linear and injective, but $(1, 0) \mapsto (1, 0, 1)$ has length $\sqrt{2}$. So it is not a linear isometry.

## Explanations

### L1 human

We put a flat sheet of paper into space, at height $0$.
Each point of the sheet keeps its two coordinates and gets the third coordinate $0$.
Lengths on the sheet do not change, so the map is an isometry.
But the map does not reach the points above or below the sheet.

### L2 human

Worked check for one vector:

1. Take $v = (3, 4)$, of length $5$.
2. Then $\iota(v) = (3, 4, 0)$, of length $\sqrt{9 + 16 + 0} = 5$.
3. And $\iota^*\iota(v) = \iota^*(3, 4, 0) = (3, 4) = v$.
4. But $\iota\iota^*(1, 2, 3) = \iota(1, 2) = (1, 2, 0) \neq (1, 2, 3)$.

A trap: from $\iota^*\iota = I$ we cannot conclude $\iota\iota^* = I$, because the matrices are not square.
