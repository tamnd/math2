## Example

Each application below uses the [[compactness theorem|1NR3HAWG9D]] for first-order logic.
It says that a set of [[sentences|DKFGQTRYZE]] has a [[model|MVCH6N9SNW]] if and only if every finite subset of it has a model.
All signatures below are countable, so we need compactness only for countable signatures.
A class $\mathcal{K}$ of structures of a signature $L$ is an [[elementary class|MEC3ZMC4F1]] when some set $\Phi$ of $L$-sentences has as its models exactly the structures in $\mathcal{K}$.
We then say that $\Phi$ axiomatizes $\mathcal{K}$.
As in Enderton, every structure has a nonempty universe.

Each application follows the same plan.
First, add new constant symbols when they help, and write down a set $\Gamma$ of sentences.
Second, show that every finite subset of $\Gamma$ has a model, usually a finite or a familiar structure.
Third, the compactness theorem gives a model of $\Gamma$, and we read off its properties.

Two facts are used several times.

- Fact 1 (expansions). Let $L'$ be $L$ with new constant symbols added. An $L'$-structure and its restriction to $L$ satisfy the same $L$-sentences. The reason is that the truth of a sentence depends only on the universe and on the symbols that occur in the sentence.
- Fact 2 (size). For $n \ge 2$ let $\lambda_n$ be the sentence $\exists x_1 \cdots \exists x_n \bigwedge_{1 \le i < j \le n} \neg\, x_i = x_j$. A structure satisfies $\lambda_n$ if and only if its universe has at least $n$ elements, because $\lambda_n$ asks for $n$ pairwise distinct elements.

Application A (infinite models from arbitrarily large finite models).
Let $\Sigma$ be a set of $L$-sentences.
Suppose that for every $n \ge 1$, $\Sigma$ has a finite model with at least $n$ elements.
Then $\Sigma$ has an infinite model.
As a consequence, no set of $L$-sentences has as its models exactly the finite models of $\Sigma$.

1. Let $\Gamma = \Sigma \cup \set{\lambda_n : n \ge 2}$. Let $\Gamma_0$ be a finite subset of $\Gamma$.
2. Let $N$ be the largest $n$ with $\lambda_n \in \Gamma_0$, or $N = 2$ if there is none. By hypothesis, $\Sigma$ has a finite model $\mathcal{A}$ with at least $N$ elements.
3. The structure $\mathcal{A}$ satisfies $\lambda_n$ for every $n \le N$, by Fact 2. It also satisfies every sentence of $\Sigma$. So $\mathcal{A}$ is a model of $\Gamma_0$.
4. By the compactness theorem, $\Gamma$ has a model $\mathcal{B}$. By Fact 2, $\mathcal{B}$ has at least $n$ elements for every $n$, so $\mathcal{B}$ is infinite. Since $\Sigma \subseteq \Gamma$, $\mathcal{B}$ is a model of $\Sigma$.
5. Now suppose, for a contradiction, that a set $\Phi$ of $L$-sentences has as its models exactly the finite models of $\Sigma$. Then $\Phi$ has finite models of every size that $\Sigma$ has, so steps 1 to 4 apply to $\Phi$. They give an infinite model of $\Phi$, which contradicts the choice of $\Phi$.
6. Take $\Sigma = \emptyset$. For each $n \ge 1$ there is an $L$-structure with universe $\set{1, \dots, n}$: read each constant symbol as $1$, each function symbol as the constant function with value $1$, and each relation symbol as the empty relation. So step 5 shows that the class of finite $L$-structures is not elementary.
7. Take for $\Sigma$ the three group axioms of the [[elementary theory of groups|RX9MB386C5]]. The group $\mathbb{Z}/n\mathbb{Z}$ has $n$ elements, so step 5 shows that the class of finite groups is not elementary. This is the example [[finiteness of a group is not first-order|3J825EJ81F]].

Application B (a nonstandard model of arithmetic).
Let $L_A$ be the signature with the constant $0$, the unary function symbol $S$, the binary function symbols $+$ and $\cdot$, and the binary relation symbol $<$.
Let $\mathfrak{N} = (\N, 0, S, +, \cdot, <)$ be the standard structure, and let $\operatorname{Th}(\mathfrak{N})$ be the set of $L_A$-sentences that are true in $\mathfrak{N}$.
For $n \in \N$ the numeral $\underline{n}$ is the term $S S \cdots S 0$ with $n$ copies of $S$.
Claim: some model $\mathcal{M}$ of $\operatorname{Th}(\mathfrak{N})$ is not [[isomorphic|PZMGQMDN25]] to $\mathfrak{N}$.

8. Add a new constant symbol $c$, and let $\Gamma = \operatorname{Th}(\mathfrak{N}) \cup \set{\underline{n} < c : n \in \N}$.
9. The value of $\underline{n}$ in $\mathfrak{N}$ is $n$, by induction on $n$: the value of $\underline{0}$ is $0$, and the value of $\underline{n+1} = S\underline{n}$ is $n + 1$.
10. Let $\Gamma_0$ be a finite subset of $\Gamma$. Let $N$ be the largest $n$ with $(\underline{n} < c) \in \Gamma_0$, or $N = 0$ if there is none. Expand $\mathfrak{N}$ by reading $c$ as $N + 1$.
11. In this expansion, $\underline{n} < c$ is true for every $n \le N$, by step 9. The sentences of $\operatorname{Th}(\mathfrak{N})$ stay true, by Fact 1. So $\Gamma_0$ has a model.
12. By the compactness theorem, $\Gamma$ has a model $\mathcal{M}'$. Let $\mathcal{M}$ be its restriction to $L_A$, and let $a$ be the value of $c$ in $\mathcal{M}'$. By Fact 1, $\mathcal{M}$ is a model of $\operatorname{Th}(\mathfrak{N})$.
13. Suppose, for a contradiction, that $h$ is an isomorphism from $\mathfrak{N}$ onto $\mathcal{M}$. Then $h(n) = \underline{n}^{\mathcal{M}}$ for every $n$, by induction: $h(0) = 0^{\mathcal{M}}$, and $h(n + 1) = S^{\mathcal{M}}(h(n)) = S^{\mathcal{M}}(\underline{n}^{\mathcal{M}})$, which is the value of $\underline{n+1}$.
14. The map $h$ is onto, so $a = h(m) = \underline{m}^{\mathcal{M}}$ for some $m \in \N$. The sentence $\underline{m} < c$ lies in $\Gamma$, so $\underline{m}^{\mathcal{M}} <^{\mathcal{M}} \underline{m}^{\mathcal{M}}$.
15. The sentence $\forall x \, \neg\, x < x$ is true in $\mathfrak{N}$, so it is true in $\mathcal{M}$ by step 12. This contradicts step 14, so $\mathcal{M}$ is not isomorphic to $\mathfrak{N}$.
16. The axioms of first-order [[Peano arithmetic|0QFT7Z76N5]] are true in $\mathfrak{N}$, so $\mathcal{M}$ is a [[non-standard model of arithmetic|1QWN5CV4CG]].
17. Consequence: no set $\Phi$ of $L_A$-sentences has as its models exactly the structures isomorphic to $\mathfrak{N}$. Such a $\Phi$ would be true in $\mathfrak{N}$, so $\Phi \subseteq \operatorname{Th}(\mathfrak{N})$, and $\mathcal{M}$ would be a model of $\Phi$.

Application C (torsion groups).
We use the signature $\set{\cdot, {}^{-1}, e}$ of groups, and for a term $t$ and $n \ge 1$ we write $t^n$ for the product $t \cdot t \cdots t$ with $n$ factors.
Claim: the class of [[torsion groups|JZNQTTMG58]], the groups in which every element has finite order, is not elementary.

18. Suppose, for a contradiction, that a set $\Phi$ of sentences axiomatizes the torsion groups. Add a new constant symbol $c$, and let $\Gamma = \Phi \cup \set{\neg\, c^n = e : n \ge 1}$.
19. Let $\Gamma_0$ be a finite subset of $\Gamma$. Let $N$ be the largest $n$ with $(\neg\, c^n = e) \in \Gamma_0$, or $N = 1$ if there is none.
20. Take the group $\mathbb{Z}/(N+1)\mathbb{Z}$ with addition, and read $c$ as the class of $1$. Then the value of $c^n$ is the class of $n$, which is not $0$ for $1 \le n \le N$.
21. The group $\mathbb{Z}/(N+1)\mathbb{Z}$ is finite, so each element has finite order, and it is a torsion group. So it satisfies $\Phi$, and its expansion does too by Fact 1. By step 20, the expansion is a model of $\Gamma_0$.
22. By the compactness theorem, $\Gamma$ has a model $(H, g)$, where $g$ is the value of $c$. By Fact 1, $H$ is a model of $\Phi$, so $H$ is a torsion group.
23. But $g^n \ne e$ for every $n \ge 1$, so $g$ has infinite order. This contradicts step 22, so no such $\Phi$ exists.
24. The torsion-free groups behave differently. The sentences $\tau_n = \forall x \, (x^n = e \to x = e)$ for $n \ge 2$, with the group axioms, axiomatize them. But no finite set of sentences does, by the example [[torsion-free groups need infinitely many axioms|APF4KHZ976]].

Application D (connected graphs).
We use one binary relation symbol $E$.
A graph is a model of $\forall x \, \neg E x x$ and $\forall x \forall y \, (E x y \to E y x)$.
A walk of length $k$ from $a$ to $b$ is a sequence $v_0, v_1, \dots, v_k$ of vertices with $v_0 = a$, $v_k = b$, and an edge between $v_{i-1}$ and $v_i$ for $1 \le i \le k$.
A graph is [[connected|0KWFFMDF8T]] when any two vertices are joined by a walk.
Claim: the class of connected graphs is not elementary.

25. Define formulas $\pi_k(x, y)$. Let $\pi_0$ be $x = y$, let $\pi_1$ be $E x y$, and for $k \ge 2$ let $\pi_k$ be $\exists z_1 \cdots \exists z_{k-1} \, (E x z_1 \land E z_1 z_2 \land \cdots \land E z_{k-1} y)$. In a graph, $\pi_k(a, b)$ holds if and only if there is a walk of length $k$ from $a$ to $b$.
26. Suppose, for a contradiction, that a set $\Phi$ of sentences axiomatizes the connected graphs. Add new constant symbols $c$ and $d$, and let $\Gamma = \Phi \cup \set{\neg \pi_k(c, d) : k \ge 0}$. A finite part of $\Gamma$ says that there is no walk, and so no path, of length at most some $n$ from $c$ to $d$.
27. Let $\Gamma_0$ be a finite subset of $\Gamma$. Let $N$ be the largest $k$ with $\neg \pi_k(c, d) \in \Gamma_0$, or $N = 0$ if there is none.
28. Let $P$ be the path graph with vertices $0, 1, \dots, N + 1$, with an edge between $i$ and $j$ exactly when $|i - j| = 1$. It is connected: for $i < j$ the sequence $i, i + 1, \dots, j$ is a walk. Read $c$ as $0$ and $d$ as $N + 1$.
29. Let $v_0, \dots, v_k$ be a walk in $P$ from $0$ to $N + 1$. Each step changes the vertex by $1$, so $N + 1 = |v_k - v_0| \le \sum_{i=1}^{k} |v_i - v_{i-1}| = k$.
30. So $P$ has no walk of length $k \le N$ from $c$ to $d$, and the expansion satisfies $\neg \pi_k(c, d)$ for $k \le N$. It satisfies $\Phi$ by Fact 1, because $P$ is a connected graph. So $\Gamma_0$ has a model.
31. By the compactness theorem, $\Gamma$ has a model $(G, a, b)$. By Fact 1, $G$ is a model of $\Phi$, so $G$ is a connected graph.
32. So $G$ has a walk from $a$ to $b$, of some length $k$. Then $G$ satisfies $\pi_k(c, d)$, which contradicts $\neg \pi_k(c, d) \in \Gamma$.

Application E (well-orders).
We use one binary relation symbol $<$.
A structure $(A, <)$ is a [[well-order|01CGSJ0GNQ]] (in the strict form) when $<$ is a strict total order on $A$ and every nonempty subset of $A$ has a least element.
Claim: the class of well-orders is not elementary.

33. Suppose, for a contradiction, that a set $\Phi$ of sentences axiomatizes the well-orders. Add new constant symbols $c_0, c_1, c_2, \dots$, and let $\Gamma = \Phi \cup \set{c_{n+1} < c_n : n \ge 0}$.
34. Let $\Gamma_0$ be a finite subset of $\Gamma$. Choose $N$ such that every constant $c_i$ that occurs in $\Gamma_0$ has $i \le N$.
35. Expand $(\N, <)$: read $c_i$ as $N - i$ for $i \le N$, and as $0$ for $i > N$. Each sentence $c_{n+1} < c_n$ of $\Gamma_0$ has $n + 1 \le N$, and then $N - n - 1 < N - n$.
36. Every nonempty set of natural numbers has a least element, by the [[well-ordering principle|01BX15HSRR]]. So $(\N, <)$ is a well-order, and it satisfies $\Phi$. By Fact 1 and step 35, the expansion is a model of $\Gamma_0$.
37. By the compactness theorem, $\Gamma$ has a model $(A, <, a_0, a_1, \dots)$, where $a_n$ is the value of $c_n$. By Fact 1, $(A, <)$ is a model of $\Phi$, so it is a well-order.
38. The set $\set{a_n : n \in \N}$ is nonempty. Each element $a_n$ is not least, because $a_{n+1} < a_n$. So this set has no least element, which contradicts step 37.

## Remarks

Each property in Applications A to E says that something happens after finitely many steps, with no bound on the number of steps.
A group is torsion when each element satisfies $x^1 = e$ or $x^2 = e$ or $x^3 = e$, and so on.
A graph is connected when any two vertices satisfy $\pi_0$ or $\pi_1$ or $\pi_2$, and so on.
In a well-order, each descending chain stops after finitely many steps.
Compactness shows that such an unbounded condition is not expressed by any set of first-order sentences.
When a bound is fixed, the property becomes first-order.
For example, the groups of exponent dividing $n$ are the models of the group axioms and the one sentence $\forall x \, (x^n = e)$.
In the same way, "diameter at most $n$" is one sentence $\forall x \forall y \, (\pi_0(x, y) \lor \cdots \lor \pi_n(x, y))$ about a graph.

The hypothesis of Application A cannot be weakened to "finite models of some sizes".
The sentence $\neg \lambda_{m+1}$ has models of every size from $1$ to $m$, and all its models are finite.

The complement of a class in Applications A to E can be elementary.
The infinite $L$-structures are the models of $\set{\lambda_n : n \ge 2}$.
They are not the models of one sentence $\psi$, because then $\neg \psi$ would axiomatize the finite $L$-structures, against step 6.

Application B shows that $\mathfrak{N}$ is not determined up to isomorphism by first-order sentences.
In contrast, the second-order [[Peano axioms|0QFT7Z76N5]], with induction over all subsets, determine $\mathfrak{N}$ up to isomorphism.
The proof of Application E also works with $\Phi = \operatorname{Th}(\N, <)$, and it gives a structure with the same first-order sentences as $(\N, <)$ that is not a well-order.

With uncountably many new constants $c_i$ and the sentences $\neg\, c_i = c_j$ for $i \ne j$, the same method gives large models of every theory with an infinite model.
This is the upward [[Löwenheim-Skolem theorem|484M0TZ1S7]].
For uncountable signatures, the compactness theorem needs a form of the axiom of choice.

## Explanations

### L1 human

Imagine a list of rules: "there are at least 2 things", "there are at least 3 things", and so on without end.
Any 5 rules from the list can be obeyed by a large enough finite set: if the largest of them says "at least 100 things", a set with 100 things works.
The compactness theorem says that the whole list can then be obeyed at once, and a set that obeys every rule must be infinite.
So no list of first-order rules can say "there are only finitely many things".
The same trick shows that rules cannot say "every element of the group has finite order" or "every two points of the network are connected".
In each case the rules can ask for a witness that is "farther away than any number", and only an infinite structure contains such a witness.

### L2 human

We run the key step of Application E for one finite subset.

1. Let $\Gamma_0 = \Phi_0 \cup \set{c_1 < c_0, \ c_2 < c_1, \ c_3 < c_2}$, where $\Phi_0$ is a finite part of $\Phi$.
2. The constants in $\Gamma_0$ are $c_0, c_1, c_2, c_3$, so $N = 3$.
3. In $(\N, <)$ read $c_0 = 3$, $c_1 = 2$, $c_2 = 1$ and $c_3 = 0$.
4. Then $2 < 3$, $1 < 2$ and $0 < 1$, so the three new sentences are true.
5. $(\N, <)$ is a well-order, so it satisfies $\Phi_0$.

Each finite subset needs only a finite descending chain, and $\N$ has descending chains of every finite length.
The whole set $\Gamma$ needs an infinite descending chain, which no well-order has.
The typical use of compactness is this: to show that a property is not first-order, add constants that describe a failure of the property "beyond every finite stage".
A trap is to think that the argument finds a strange model of the class itself.
The model that compactness gives is a model of $\Phi$, and the contradiction shows only that $\Phi$ did not describe the class.
Another trap is to conclude that a single structure cannot be described: a finite structure is determined up to isomorphism by one sentence that lists its elements and its operations.

### L3 human

The applications show that elementary classes are closed under constructions that pass "to the limit".
An elementary class is closed under [[ultraproducts|AX9Q86GB8M]] by [[Łoś's theorem|AGYBSTD7BG]], and a non-principal ultraproduct of the groups $\mathbb{Z}/n\mathbb{Z}$ contains an element of infinite order.
This gives a second proof of Application C, and similar ultraproducts give the other applications.
The arguments above also show that a logic that extends first-order logic and expresses finiteness, well-foundedness or connectedness cannot satisfy the compactness theorem.
[[Second-order logic|G6X7SZSNC5]] expresses all three, and it is not compact.
By [[Lindström's theorem|FYZ3CJGZYV]], first-order logic is a maximal logic with the compactness property and the downward Löwenheim-Skolem property.
Over finite structures the compactness theorem fails, yet connectedness is still not first-order; there the proof uses [[Ehrenfeucht-Fraïssé games|2RE7YAZK8R]] in place of compactness.
Application B is the starting point of the model theory of arithmetic.
