## Example

The *constant domain axiom* is $\forall x (p \lor Q(x)) \to (p \lor \forall x Q(x))$, where $x$ is not free in $p$.
We show that it has value $1$ in every $V$-structure $\mathfrak{M}$ of a [[first-order Gödel logic|~c951b605]].
Let $a$ be the value of $p$, and let $b_d$ be the value of $Q(d)$ for $d \in M$; let $b = \inf_d b_d$.

1. The value of the antecedent is $\inf_d \max(a, b_d)$, and the value of the consequent is $\max(a, b)$.
2. Case $a \ge b$: $\max(a, b_d) \ge a$ for all $d$, so the antecedent is at least $a$.
3. Let $\varepsilon > 0$; since $\inf_d b_d = b \le a$, some $d$ has $b_d < a + \varepsilon$, so $\max(a, b_d) < a + \varepsilon$.
4. So in this case the antecedent is $a = \max(a, b)$.
5. Case $a < b$: then $b_d \ge b > a$ for all $d$, so $\max(a, b_d) = b_d$.
6. So in this case the antecedent is $\inf_d b_d = b = \max(a, b)$.
7. In both cases the antecedent equals the consequent, and the Gödel implication $x \to x$ has value $1$.

Numeric check with $M = \mathbb{N}$, $a = 0.3$ and $b_n = \tfrac{1}{n+1}$:

8. $\max(0.3, \tfrac{1}{n+1})$ is $\tfrac{1}{n+1}$ for $n \le 2$ and $0.3$ for $n \ge 3$, so the infimum is $0.3$.
9. The consequent is $\max(0.3, 0) = 0.3$, and $0.3 \to 0.3 = 1$.

## Remarks

1. The proof uses only that the truth values form a chain: $\max(a, \cdot)$ commutes with infima on a chain.
2. In intuitionistic predicate logic the axiom fails: [[a Kripke model with growing domains|42GA7FHGW2]] refutes it.
3. So every first-order Gödel logic proves a sentence that intuitionistic predicate logic does not prove.
4. The two-world Kripke countermodel has a linear frame, so it validates prelinearity; hence prelinearity alone does not give the constant domain axiom.

## Explanations

### L1 human

"For every $x$, $p$ or $Q(x)$" and "$p$, or for every $x$, $Q(x)$" get the same degree in Gödel logic.
The reason is that degrees of truth form a single line.

### L2 human

1. Compare $a$ with the infimum $b$ of the values of $Q$.
2. If $a$ is larger, both sides are $a$; otherwise both sides are $b$.

A trap: the step "some $d$ has $b_d < a + \varepsilon$" needs $b \le a$, and the infimum need not be attained.
