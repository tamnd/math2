## Proof

For each t-norm $*$ and candidate $r(x, y)$, we show: $z * x \le y \iff z \le r(x, y)$ for all $x, y, z \in [0, 1]$.
This is the residuation condition of [[the definition|~a4e21349]], and a residuum is unique.

**Łukasiewicz.** Let $r(x, y) = \min(1, 1 - x + y)$.

1. Since $y \ge 0$: $\max(0, z + x - 1) \le y \iff z + x - 1 \le y \iff z \le 1 - x + y$.
2. Since $z \le 1$: $z \le 1 - x + y \iff z \le \min(1, 1 - x + y)$.

**Gödel.** Let $r(x, y) = 1$ if $x \le y$, else $y$.

3. Case $x \le y$: $\min(z, x) \le x \le y$ holds for every $z$, and $z \le 1$ holds for every $z$.
4. Case $x > y$: if $z \le y$, then $\min(z, x) \le z \le y$.
5. If $z > y$, then $\min(z, x) > y$, since both $z > y$ and $x > y$.
6. So $\min(z, x) \le y \iff z \le y$.

**Product.** Let $r(x, y) = 1$ if $x \le y$, else $y / x$.

7. Case $x \le y$: $z x \le x \le y$ for every $z \in [0, 1]$.
8. Case $x > y$: then $x > 0$, so $z x \le y \iff z \le y / x$, by division by $x$.
9. Here $y / x < 1$, so $y / x \in [0, 1]$.

**Negations.**

10. $\neg_{Ł} x = \min(1, 1 - x + 0) = 1 - x$.
11. For Gödel and product, $x \le 0$ iff $x = 0$, so $x \Rightarrow 0 = 1$ for $x = 0$.
12. For $x > 0$: Gödel gives $0$, and product gives $0 / x = 0$. $\blacksquare$

## Idea

Solve the inequality $z * x \le y$ for $z$, and take the largest solution.

## Variants

One can first prove that $x \Rightarrow y = \max \set{z : z * x \le y}$ for every left-continuous t-norm, as in [[the left-continuity statement|~42fe79f8]].
Then each residuum is a computation of a maximum.
