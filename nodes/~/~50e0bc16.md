## Example

Let $G = S_3$ be the [[symmetric group|0515A6D2Y1]] on $\{1, 2, 3\}$.
We use [[cycle notation|0ZKPH2BD1T]] and compose permutations from right to left, so $\sigma\tau$ means first $\tau$, then $\sigma$.
The three [[transpositions|0FWVRHBRWM]] of $S_3$ are $(1\,2)$, $(1\,3)$ and $(2\,3)$.
We show that they are [[conjugate|0DXD4QSZ8A]] to each other in $S_3$.
Each transposition is its own inverse, so $(2\,3)^{-1} = (2\,3)$ and $(1\,3)^{-1} = (1\,3)$.

1. We compute $(2\,3)(1\,2)(2\,3)$. The point $1$ goes to $1$, then to $2$, then to $3$. The point $3$ goes to $2$, then to $1$, then to $1$. The point $2$ goes to $3$, then to $3$, then to $2$.
2. So $(2\,3)(1\,2)(2\,3)^{-1} = (1\,3)$, and $(1\,2)$ is conjugate to $(1\,3)$.
3. We compute $(1\,3)(1\,2)(1\,3)$. The point $1$ goes to $3$, then to $3$, then to $1$. The point $2$ goes to $2$, then to $1$, then to $3$. The point $3$ goes to $1$, then to $2$, then to $2$.
4. So $(1\,3)(1\,2)(1\,3)^{-1} = (2\,3)$, and $(1\,2)$ is conjugate to $(2\,3)$.
5. Conjugacy is an equivalence relation, so $(1\,3)$ and $(2\,3)$ are also conjugate to each other.

The full table of the conjugates of $(1\,2)$ follows.

| $g$ | $g(1\,2)g^{-1}$ |
|---|---|
| $e$ | $(1\,2)$ |
| $(1\,2)$ | $(1\,2)$ |
| $(2\,3)$ | $(1\,3)$ |
| $(1\,3\,2)$ | $(1\,3)$ |
| $(1\,3)$ | $(2\,3)$ |
| $(1\,2\,3)$ | $(2\,3)$ |

So the [[conjugacy class|0DEBXAJ5SA]] of $(1\,2)$ is $\{(1\,2), (1\,3), (2\,3)\}$.

## Remarks

The computation follows a general rule: $g(a\,b)g^{-1} = (g(a)\;g(b))$ for each permutation $g$.
For example, $g = (2\,3)$ sends $1$ to $1$ and $2$ to $3$, so it sends $(1\,2)$ to $(1\,3)$.
Each value in the table appears exactly twice.
The reason is that the [[centraliser|02YYV36BFM]] of $(1\,2)$ is $\{e, (1\,2)\}$, which has $2$ elements.
In $S_n$ the same rule shows that all transpositions are conjugate.
More generally, two permutations with the same cycle type are conjugate ([[conjugacy classes of symmetric groups|0J438GAC8K]]).

## Explanations

### L1 human

A transposition swaps two of the three points and fixes the third one.
If we first rename the points, then swap, then undo the renaming, we get a swap of two other points.
So all three swaps are the same kind of move, and they form one conjugacy class.

### L2 human

The fast way to conjugate a permutation is to rename the entries of its cycles.
To find $g(1\,2)g^{-1}$, write $(1\,2)$ and replace each entry $x$ by $g(x)$.
For $g = (1\,2\,3)$ this gives $(2\,3)$, which matches the table.
A common error is to compute $g^{-1}(1\,2)g$ instead.
Both products are conjugates of $(1\,2)$, but for a fixed $g$ they can differ.
For $g = (1\,2\,3)$, the product $g^{-1}(1\,2)g$ is $(1\,3)$, and this is not $g(1\,2)g^{-1} = (2\,3)$.
