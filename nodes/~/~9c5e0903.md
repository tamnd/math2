## Summary

Let $\mathcal{I}$ be a [[structure|983GZBQYT4]] in a signature $L_0$, called the *index structure*, and let $\mathcal{M}$ be an $L$-structure with $A \subseteq M$.
A family $(a_i)_{i \in \mathcal{I}}$ of elements of $M$ is an *$\mathcal{I}$-indexed indiscernible family over $A$* if the following holds for every $n$ and all $n$-tuples $\bar{\imath}$ and $\bar{\jmath}$ from $\mathcal{I}$.
If $\bar{\imath}$ and $\bar{\jmath}$ have the same quantifier-free type in $\mathcal{I}$, then $a_{\bar{\imath}}$ and $a_{\bar{\jmath}}$ have the same [[type|9V71Q3SD1G]] over $A$ in $\mathcal{M}$.
For a linear order $\mathcal{I}$ this is an [[indiscernible sequence|~0949d8de]], and for a set with no structure it is an indiscernible set.
Other index structures, such as trees and ordered graphs, measure combinatorial patterns of a theory and characterize the dividing lines of classification theory.

## Motivation

An indiscernible sequence copies the order of its index set into a model, and nothing more.
Some properties of a theory need a richer pattern, such as a tree of formulas or a graph of formulas.
To see such a pattern without the noise of an arbitrary family, one needs a family that is as homogeneous as the pattern allows.
This is an indiscernible family indexed by the pattern itself.

## Notation

The quantifier-free type of $\bar{\imath}$ in $\mathcal{I}$ is written $\operatorname{qftp}^{\mathcal{I}}(\bar{\imath})$.
For trees one usually takes $L_0 = \set{\trianglelefteq, <_{\mathrm{lex}}, \wedge}$, with the tree order, the lexicographic order and the meet.
An index structure $\mathcal{I}$ has the *modeling property* if, for every $\mathcal{I}$-indexed family $(b_i)$ in a model of $T$, there is an $\mathcal{I}$-indexed indiscernible family $(a_i)$ that is *locally based* on $(b_i)$.
Locally based means: for each finite set $\Delta$ of formulas and each finite tuple $\bar{\imath}$, some $\bar{\jmath}$ with the same quantifier-free type as $\bar{\imath}$ has $a_{\bar{\imath}}$ and $b_{\bar{\jmath}}$ agree on $\Delta$.

## Remarks

### Examples

- A linear order $(I, <)$ as index structure: the quantifier-free type of a tuple is its order pattern, so the definition gives [[order-indiscernible sequences|~cc1977c7]].
- A set with no structure as index structure: the quantifier-free type records only equalities, so the definition gives indiscernible sets, such as a [[basis of a vector space|~5413a315]].
- $(\Q, <)$ indexed by itself: tuples with the same order pattern are moved onto each other by an automorphism; see [[this example|~7eb41167]].
- The Rado graph indexed by itself: tuples with the same quantifier-free type are moved onto each other by an automorphism, by ultrahomogeneity; see [[this example|~054605b5]].
- More generally, every [[ultrahomogeneous|H8VM37SSAX]] relational structure indexed by itself is an indiscernible family, for the same reason.

### Non-examples

- $(\Z, <)$ indexed by itself: the pairs $(0, 1)$ and $(0, 2)$ have the same order pattern, but only the second has an element between its members; see [[this example|~56ca9cc6]].
- The vertices of the Rado graph, indexed by the same set with no structure: two pairs of distinct vertices have the same equalities, but one can be an edge and the other not.
- The natural numbers in $(\N, <)$ indexed by $(\N, <)$: the elements $0$ and $1$ have the same quantifier-free type, but $\exists y \, (y < x)$ separates them; see [[this example|~a7f9e86c]].

### Basic properties

- If $\mathcal{I}'$ is an expansion of $\mathcal{I}$ with the same universe, every $\mathcal{I}$-indexed indiscernible family is $\mathcal{I}'$-indexed indiscernible, since equal quantifier-free types in $\mathcal{I}'$ give equal ones in $\mathcal{I}$.
- For a substructure $\mathcal{J} \subseteq \mathcal{I}$, the subfamily $(a_j)_{j \in \mathcal{J}}$ is $\mathcal{J}$-indexed indiscernible, since quantifier-free types do not change in a substructure.
- If $\mathcal{I}$ is ultrahomogeneous, then every automorphism $\sigma$ of $\mathcal{I}$ gives a partial elementary map $a_i \mapsto a_{\sigma(i)}$ of $\mathcal{M}$.
- Existence: for suitable countable ordered index structures whose [[age|5FKW715RGJ]] is a [[Ramsey class|8XS8FCTF8T]], the compactness argument for the [[existence of indiscernibles|~c0b513d4]] works with the Ramsey property of the age in place of Ramsey's theorem.
- [[Finite linear orders form a Ramsey class|X3K7KWH5BK]], and this is the case of ordinary indiscernible sequences.

### History

Shelah used indiscernibles indexed by trees in the development of classification theory.
Scow proved that, for a class of ordered index structures, the modeling property holds exactly when the age of the index structure is a Ramsey class.
Scow also characterized NIP theories by the collapse of indiscernibles indexed by ordered graphs to order-indiscernibles.

### Common errors

- The condition uses quantifier-free types in $\mathcal{I}$, not complete types. Two tuples of $(\N, <)$ with the same order pattern count as the same pattern, even if their types in $(\N, <)$ differ.
- An $\mathcal{I}$-indexed indiscernible family need not exist with prescribed local properties for an arbitrary $\mathcal{I}$. The modeling property is a Ramsey property of the index structure.

## Explanations

### L1 human

An indiscernible sequence is a row of elements that look alike, where only the order in the row can be seen.
A generalized indiscernible family replaces the row by another shape, such as a family tree or a network of friends.
The rule is that two groups of members that sit in the same way in the shape must look alike in the model.
For example, in a network, two pairs of friends must look alike, and two pairs of strangers must look alike.

### L2 human

We check that the vertices of the Rado graph $R$, indexed by $R$ itself, form an indiscernible family, for pairs.

1. Let $(u_1, u_2)$ and $(v_1, v_2)$ have the same quantifier-free type in $R$. Then $u_1 = u_2$ exactly when $v_1 = v_2$, and $u_1 E u_2$ exactly when $v_1 E v_2$.
2. So the map $u_k \mapsto v_k$ is an isomorphism of induced subgraphs.
3. By ultrahomogeneity, it extends to an automorphism $\sigma$ of $R$.
4. Automorphisms preserve formulas, so $(u_1, u_2)$ and $(v_1, v_2)$ have the same type in $R$.

The typical use is to fix a combinatorial pattern, such as an array of formulas, and to replace it by an indiscernible family with the same pattern.
The trap is to index by a structure that is too poor: indexed by a pure set, the vertices of $R$ are not indiscernible.

### L3 human

Generalized indiscernibles turn dividing lines into statements about collapse.
A theory is stable exactly when every order-indiscernible sequence is an indiscernible set, so the order collapses to equality.
In the same way, Scow's theorem says that a theory is NIP exactly when every indiscernible family indexed by the random ordered graph is order-indiscernible, so the graph relation is invisible.
The existence of such families is a Ramsey property of the index structure, and this links model theory with structural Ramsey theory and with the [[Kechris-Pestov-Todorcevic correspondence|96Q4P7PZVY]] for automorphism groups.
For [[NIP theories|74VCDYQDGP]] and [[stable theories|T7JW5QY6KR]] the collapse results are a main tool in later sub-areas.
