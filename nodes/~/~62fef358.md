## Description

Gödel's system T is a typed language of computable functionals of finite type, built from the [[simply typed lambda calculus|2DP940895E]] by adding the natural numbers and recursion.

*Types.*
The type $0$ is the type of natural numbers.
If $\sigma$ and $\tau$ are types, then $\sigma \to \tau$ is the type of functions from $\sigma$ to $\tau$.
We write $1$ for $0 \to 0$ and $2$ for $1 \to 0$; the arrow associates to the right.

*Terms.* Each term has a unique type, written $t : \sigma$.

1. For each type $\sigma$ there are infinitely many variables $x^\sigma : \sigma$.
2. The constants are $0 : 0$, the successor $S : 0 \to 0$, and for each type $\sigma$ the recursor $R_\sigma : \sigma \to (0 \to \sigma \to \sigma) \to 0 \to \sigma$.
3. If $t : \sigma \to \tau$ and $s : \sigma$, then the application $t\, s : \tau$.
4. If $t : \tau$ and $x$ is a variable of type $\sigma$, then the abstraction $\lambda x.\, t : \sigma \to \tau$.

*Reduction.* The one-step reduction is generated by these rules, applied to any subterm.

1. $(\lambda x.\, t)\, s \rightsquigarrow t[s/x]$, the [[beta reduction|Y9B9CVY6SJ]].
2. $R_\sigma\, a\, f\, 0 \rightsquigarrow a$.
3. $R_\sigma\, a\, f\, (S\, n) \rightsquigarrow f\, n\, (R_\sigma\, a\, f\, n)$.

So $R_\sigma$ defines a function $g$ by [[primitive recursion|5NVA2JRHPV]] with values of type $\sigma$: $g(0) = a$ and $g(n + 1) = f\, n\, g(n)$.

*The theory.*
Gödel's theory T is a quantifier-free theory of equations $s = t$ between terms of type $0$.
It has the defining equations of the reduction rules as axioms, the propositional rules, and the induction rule: from $A(0)$ and $A(x) \to A(S x)$ infer $A(t)$, for quantifier-free $A$.

*Main facts.*

1. Strong normalization: every reduction sequence of a term of T is finite. Tait proved this in 1967 by his computability method.
2. Confluence: the normal form is unique. So a closed term of type $0$ reduces to exactly one numeral $S(\cdots S(0) \cdots)$.
3. Hence every closed term $t : 1$ defines a total [[computable function|KZSB5E471K]] $n \mapsto$ the normal form of $t\, \overline{n}$.
4. The functions $\N \to \N$ defined by closed terms of type $1$ are exactly the provably recursive functions of Peano arithmetic. They are also the $\alpha$-recursive functions for $\alpha < \varepsilon_0$.
5. The terms with recursors $R_0$ only define exactly the primitive recursive functions.

## Remarks

Examples of terms:

- Addition: $\mathrm{add} = \lambda m\, n.\, R_0\, m\, (\lambda k\, a.\, S\, a)\, n$, so $\mathrm{add}\, m\, 0 = m$ and $\mathrm{add}\, m\, (S\, n) = S(\mathrm{add}\, m\, n)$.
- Iteration: $\mathrm{it} = \lambda f\, n\, b.\, R_0\, b\, (\lambda k\, a.\, f\, a)\, n$ has type $1 \to 0 \to 0 \to 0$, and $\mathrm{it}\, f\, n\, b = f^n(b)$.
- The [[Ackermann function|N470JF7ZJX]]: $\mathrm{A} = \lambda m.\, R_1\, S\, (\lambda k\, g\, n.\, \mathrm{it}\, g\, (S\, n)\, (S\, 0))\, m$ has type $0 \to 1$. Then $\mathrm{A}\, 0 = S$ and $\mathrm{A}\, (m + 1)\, n = (\mathrm{A}\, m)^{n + 1}(1)$.
- The Ackermann function is not primitive recursive, so this term needs the recursor $R_1$ at type $1$.

Non-example: the evaluation function $E$, with $E(\ulcorner t \urcorner, n)$ the value of $t\, \overline{n}$ for codes of closed terms $t : 1$, and $E(m, n) = 0$ when $m$ is not such a code.
It is computable, by normalization, but it is not defined by a term of T.
If it were, the function $n \mapsto E(n, n) + 1$ would be defined by a closed term $t$ with code $c$, and then $E(c, c) = E(c, c) + 1$.

Variants and notation:

- Some books write $\mathbb{N}$ for the type $0$ and $\mathbb{N} \to \mathbb{N}$ for the type $1$.
- Gödel used combinators instead of $\lambda$-abstraction. The two forms define the same functionals.
- Many books add a definition by cases, which is $R_\sigma\, a\, (\lambda k\, x.\, b)\, n$, and product types, which can be simulated by currying.
- Extending T by [[bar recursion|~a7df5e71]] gives a system that interprets classical analysis.

Models: the full set-theoretic model of all functions of finite type, the hereditarily recursive operations, the hereditarily effective operations and the continuous functionals of Kleene and Kreisel.

## Explanations

### L1 human

System T is a small programming language for functions on the natural numbers.
It allows functions that take other functions as inputs, such as "apply a function $n$ times".
Its main loop is a counted loop: repeat a step $n$ times, where $n$ is known before the loop starts.
For example, "apply the step 'add $2$' three times to $1$" gives $7$.
Every program in system T stops, and yet it can compute very fast-growing functions, such as the Ackermann function.

### L2 human

We compute $\mathrm{add}\, 2\, 2$ by reduction, where $2 = S(S\, 0)$.

1. $\mathrm{add}\, 2\, 2$ reduces to $R_0\, 2\, h\, (S(S\, 0))$, with $h = \lambda k\, a.\, S\, a$.
2. The recursion rule gives $h\, (S\, 0)\, (R_0\, 2\, h\, (S\, 0))$, and beta reduction gives $S(R_0\, 2\, h\, (S\, 0))$.
3. The same two rules give $S(S(R_0\, 2\, h\, 0))$.
4. The rule for $0$ gives $S(S(2)) = S(S(S(S\, 0)))$, the numeral $4$.

The typical use of system T is as the target of Gödel's [[Dialectica interpretation|HZ17ES9PDY]]: a proof in arithmetic yields a term of T for each witness.
A trap is to think that T only gives primitive recursive functions; recursion at higher types gives much more.

### L3 human

System T is the simply typed lambda calculus with a natural numbers object and its recursor, and it is the internal language of a cartesian closed category with such an object.
Through the [[Curry-Howard correspondence|A77FER1Q5H]], the recursor corresponds to the induction rule, and terms of T correspond to proofs in intuitionistic arithmetic.
Its strength is measured by ordinals: it has the same type-1 functions as PA, and normalization of T cannot be proved in PA, by [[ordinal analysis|XTTKZTYDSD]] at $\varepsilon_0$.
Extensions of T by [[bar recursion|~a7df5e71]], by fixed points (PCF) or by polymorphism (system F) give the functional analogues of stronger theories.
