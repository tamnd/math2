## Example

Let $\sigma = \set{<}$, with one binary relation symbol, and let $\varphi = \forall x \, \exists y \, (x < y)$.
We check that $\varphi$ is a [[sentence|DKFGQTRYZE]] and find its truth value in two structures.

1. $\operatorname{FV}(x < y) = \set{x, y}$, because $x < y$ is atomic.
2. $\operatorname{FV}(\exists y \, (x < y)) = \set{x, y} \setminus \set{y} = \set{x}$.
3. $\operatorname{FV}(\varphi) = \set{x} \setminus \set{x} = \emptyset$, so $\varphi$ is a sentence by the [[definition|Q85MMH5DEY]].
4. In $(\mathbb{N}, <)$ the sentence is [[true|K7XDVK5854]]: for each $n \in \mathbb{N}$, the element $n + 1$ satisfies $n < n + 1$.
5. In the finite order $(\set{0, 1, 2}, <)$ the sentence is false: for $x = 2$ no element $y$ satisfies $2 < y$.

## Remarks

The sentence says that the order has no largest element.
Each nonempty finite linear order has a largest element, so $\varphi$ is false in all of them, and true in $(\mathbb{Z}, <)$, $(\mathbb{Q}, <)$ and $(\mathbb{R}, <)$.
The truth value depends only on the structure, and not on any assignment, since $\varphi$ has no free variables.
Swapping the quantifiers gives the sentence $\exists y \, \forall x \, (x < y)$, which says that some element is above all elements, itself included.
It is false in every structure in which $<$ is irreflexive, since $x = y$ gives $y < y$.

## Explanations

### L1 human

"Every number has a larger number" is a complete claim.
For the natural numbers it is true: $7$ has the larger number $8$, and the same works for each number.
For the three numbers $0, 1, 2$ it is false, because nothing is larger than $2$.
The claim is about the whole collection of numbers, not about one chosen number.

### L2 human

We evaluate $\varphi$ in $(\mathbb{N}, <)$ from the inside out.

1. The formula $x < y$ defines the set of pairs $(a, b)$ with $a < b$.
2. The formula $\exists y \, (x < y)$ defines the set of $a$ with some $b > a$. This set is all of $\mathbb{N}$, since $b = a + 1$ works.
3. The sentence $\forall x \, \exists y \, (x < y)$ is true when this set is the whole domain, so it is true.

The typical use of such sentences is to describe classes of structures, here the orders without a largest element.
The trap is the order of the quantifiers: the $y$ may depend on $x$, and $\exists y \, \forall x$ asks for one $y$ for all $x$.
