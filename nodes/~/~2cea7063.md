## Example

Let $L_0 = \set{0, 1, +, -, <}$ and let $T = \mathrm{Th}(\Z, 0, 1, +, -, <)$, the [[theory|92SWXST1ZM]] of [[Presburger arithmetic|4W0E9G7PPV]] in this signature.
For $n \ge 2$ write $n y$ for the [[term|6D3WA7N2W4]] $y + \dots + y$ with $n$ summands.
Let $\Delta$ consist of the atomic $L_0$-formulas and the formulas $\exists y \, (t = n y)$, for $n \ge 2$ and $t$ an $L_0$-term.
We show that $T$ has elimination relative to $\Delta$.

1. Expand $\Z$ to $L = L_0 \cup \set{D_n : n \ge 2}$ by letting $D_n$ be the set $n \Z$. The expansion is a $\Z$-group: each integer is congruent to exactly one of $0, 1, \dots, n - 1$ modulo $n$.
2. Let $\varphi(\bar x)$ be an $L_0$-formula. By [[quantifier elimination for Z-groups|~0727c76f]], $\varphi$ is equivalent in every $\Z$-group, in particular in the expansion of $\Z$, to a quantifier-free $L$-formula $\psi(\bar x)$.
3. In $\psi$, replace each atomic formula $D_n(t)$ by $\exists y \, (t = n y)$. The result $\psi_0$ is a Boolean combination of formulas in $\Delta$.
4. In $\Z$, $D_n(t)$ and $\exists y \, (t = n y)$ define the same set, so $\varphi$ and $\psi_0$ define the same set in $\Z$.
5. So $\forall \bar x \, (\varphi \leftrightarrow \psi_0)$ is an $L_0$-sentence true in $\Z$. It belongs to $T$.

So every $L_0$-formula is equivalent modulo $T$ to a Boolean combination of formulas in $\Delta$.

## Remarks

The theory $T$ has no quantifier elimination in $L_0$.
In one variable, an atomic $L_0$-formula has the form $k x + m = 0$ or $k x + m < 0$ with $k, m \in \Z$, and defines a finite set or a set that contains or omits all large integers.
So every quantifier-free definable subset of $\Z$ is finite or cofinite on the positive integers, but $2 \Z$ is neither.
The elimination set cannot be made smaller in a simple way; see [[this non-example|~a2527617]].

## Explanations

### L1 human

Statements about whole numbers with addition and order can contain many "there is" phrases.
All of them can be replaced by one kind of question: "is this number divisible by $n$?".
So every such statement is a combination of equations, inequalities and divisibility conditions.

### L2 human

We see the elimination on the formula $\exists y \, (x = y + y + y + 1)$.

1. In the expansion, it says that $x - 1$ is divisible by $3$, so it is equivalent to $D_3(x - 1)$.
2. Replacing $D_3$ gives $\exists y \, (x - 1 = 3 y)$, which lies in $\Delta$.

The typical use is to describe the definable subsets of $\Z$: they are finite unions of sets of points and of arithmetic progressions cut by intervals.
A trap is to count the divisibility formulas as quantifier-free: each one has an existential quantifier.
