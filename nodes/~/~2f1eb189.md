## Example

Let $H = G_3 \sqcup \set{w}$, the [[Henson graph|TZT25G2YB3]] $G_3$ with one extra vertex $w$ joined to nothing.
We show that $H$ is universal for countable triangle-free graphs but is not [[ultrahomogeneous|~7468669e]].

1. $H$ is triangle-free, since $w$ lies on no edge.
2. Every countable triangle-free graph embeds into $G_3$, hence into $H$; so $H$ is a [[universal graph|4S189K88T3]] for this class.
3. Take a vertex $v$ of $G_3$. The map $w \mapsto v$ is an isomorphism of one-point induced subgraphs.
4. An [[automorphism|DSQ17TNW1C]] preserves degrees, and $w$ has degree $0$ while $v$ has infinite degree.
5. So the map does not extend, and $H$ is not ultrahomogeneous.

## Remarks

$H$ has the same age as $G_3$, the finite triangle-free graphs.
So $H$ is a countable structure with the right age that is not the Fraïssé limit.
Universality alone does not single out $G_3$; ultrahomogeneity, or the extension property, does.

## Explanations

### L1 human

Adding a lonely vertex to $G_3$ keeps every triangle-free graph inside.
But the lonely vertex is different from every other vertex, so the symmetry is lost.

### L2 human

We check that $v$ has infinite degree in $G_3$.

1. Apply the extension property with $U = \set{v}$ and $V$ the finite set of neighbors found so far.
2. Each step gives a new neighbor of $v$.
3. So $v$ has infinitely many neighbors.

The typical use is to separate universality from homogeneity.
A trap is to think that a structure with the right age is automatically the limit.
