## Statement

Let $\mathcal{U}$ be an [[ultrafilter|J64Y3JC0RE]] on a set $I$, and let $(\mathcal{M}_i)_{i \in I}$ be $L$-structures with nonempty domains.
Call $\mathcal{U}$ *countably incomplete* when some sets $X_0 \supseteq X_1 \supseteq \dots$ in $\mathcal{U}$ have empty intersection.
For a [[cardinal|0EBACQFAZW]] $\kappa$, call $\mathcal{U}$ *$\kappa$-good* when the following holds for every cardinal $\alpha < \kappa$.
Let $f$ map the finite subsets of $\alpha$ into $\mathcal{U}$ with $f(t) \subseteq f(s)$ whenever $s \subseteq t$.
Then there is $g$ from the finite subsets of $\alpha$ into $\mathcal{U}$ with $g(s) \subseteq f(s)$ and $g(s \cup t) = g(s) \cap g(t)$ for all $s, t$.

1. If $L$ is countable and $\mathcal{U}$ is countably incomplete, then the [[ultraproduct|AX9Q86GB8M]] $\prod_{i \in I} \mathcal{M}_i / \mathcal{U}$ is $\aleph_1$-[[saturated|RMTZ5J64FX]].
2. Let $\kappa$ be uncountable. If $\abs{L} < \kappa$ and $\mathcal{U}$ is countably incomplete and $\kappa$-good, then $\prod_{i \in I} \mathcal{M}_i / \mathcal{U}$ is $\kappa$-saturated.

Every nonprincipal ultrafilter on $\N$ is countably incomplete, so part 1 applies to every nonprincipal ultraproduct indexed by $\N$.

## Remarks

### Why each hypothesis is needed

- *Countable incompleteness.* For a principal ultrafilter the ultraproduct is a factor. The factor $(\Q, <)$ omits the [[type|9V71Q3SD1G]] $\set{n < x : n \in \N}$ over the countable set $\N$, so it is not $\aleph_1$-saturated.
- *Countable language in part 1.* The proof lists the type as $\varphi_0, \varphi_1, \dots$ in order type $\omega$. A type over countably many parameters in an uncountable language can be uncountable.
- *Goodness in part 2.* Keisler showed a converse. A regular ultrafilter $\mathcal{U}$ on $\lambda$ is $\lambda^+$-good exactly when $\mathcal{M}^{\lambda} / \mathcal{U}$ is $\lambda^+$-saturated for every structure $\mathcal{M}$ in a countable language.

### Consequences

- Assume the [[continuum hypothesis|0MN2MER9WN]]. Let $\mathcal{M} \equiv \mathcal{N}$ be countably infinite in a countable language, and let $\mathcal{U}$ be nonprincipal on $\N$.
- Then both ultrapowers have size $2^{\aleph_0} = \aleph_1$ and are $\aleph_1$-saturated, so they are saturated. Saturated models of one complete theory in one cardinality are isomorphic, so $\mathcal{M}^{\N} / \mathcal{U} \cong \mathcal{N}^{\N} / \mathcal{U}$.
- This is the special case of the [[Keisler-Shelah theorem|~4f3e3ffa]] that needs only part 1.
- In the hyperreals $\R^{\N} / \mathcal{U}$, every countable family of nonempty open intervals with the finite intersection property has a common point.

### Converse

Countable incompleteness is also necessary in part 1.
If $\mathcal{U}$ is countably complete, then it is closed under countable intersections.
A function $f : I \to \Q$ has countably many fibers, one of them lies in $\mathcal{U}$, so $f$ is equivalent to a constant.
So $(\Q, <)^I / \mathcal{U} \cong (\Q, <)$, which is not $\aleph_1$-saturated.
For the converse of part 2, see the remark on goodness above.

### Generalizations

The behavior of $\lambda^+$-saturation of ultrapowers over regular ultrafilters on $\lambda$ leads to [[Keisler's order|~889bca65]] on theories.
Ultraproducts of metric structures in continuous logic over countably incomplete ultrafilters are $\aleph_1$-saturated in the metric sense.

## History

Keisler introduced good ultrafilters and proved part 2.
He constructed countably incomplete good ultrafilters under the generalized continuum hypothesis.
Kunen proved in 1972 that for every infinite $\lambda$ there is a countably incomplete $\lambda^+$-good ultrafilter on $\lambda$, using only ZFC.

## Explanations

### L1 human

An ultraproduct glues together many structures and keeps every first-order property they share on a large set of indices.
The theorem says that it also fills every countable gap.
If countably many conditions can be met a finite number at a time, then one element of the ultraproduct meets them all.
The element is built index by index: at index $i$ we meet as many conditions as the index allows, and this number grows along the ultrafilter.

### L2 human

We find an infinite hyperreal in $\R^{\N} / \mathcal{U}$, $\mathcal{U}$ nonprincipal, along the proof of part 1.

1. The type is $\varphi_n(x) : x > n$ for $n \in \N$, in the language of ordered fields. Each finite part is met in $\R$.
2. Take $X_n = \set{i : i \ge n}$. These sets are cofinite, so they lie in $\mathcal{U}$, and their intersection is empty.
3. For $i \in \N$ the largest $n$ with $i \in X_n$ is $n = i$. So we choose $b(i)$ with $b(i) > 0, 1, \dots, i$, for example $b(i) = i + 1$.
4. For each $n$, the set $\set{i : b(i) > n}$ contains $X_n$, so it lies in $\mathcal{U}$.
5. By [[Łoś's theorem|AGYBSTD7BG]], $[b]$ satisfies every $\varphi_n$, so it is larger than every natural number.

The typical use is to get nonstandard elements on demand.
The trap is to apply part 1 to a type over uncountably many parameters, such as $\set{x > r : r \in \R}$; this needs more than $\aleph_1$-saturation.
