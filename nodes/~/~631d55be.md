## Example

Let $\mathrm{TJ}(Y) = \set{(e, x) : \Phi^Y_e(x) \text{ halts}}$ be the [[Turing jump|60P2XWY5QX]] of $Y$.
The formula "$n \in \mathrm{TJ}(Y)$" is $\Sigma^0_1$ in $Y$, so it is arithmetical.
The claim is that [[ATR0|~9f6fce13]] proves that there is a set $H$ such that $H_j = \mathrm{TJ}(H^j)$ for every $j$, where the columns use the order $(\N, <)$.
Such a set $H$ is, up to [[Turing equivalence|PA4PYQ1PZ0]], the $\omega$-th jump $\emptyset^{(\omega)}$.

1. Let $W$ be the usual order $<$ on $\N$, coded as the set of pairs $(i, j)$ with $i \le j$. This set exists by $\Delta^0_1$ comprehension.
2. $\mathsf{RCA}_0$ proves $\mathrm{WO}(W)$. Suppose that $f(k + 1) < f(k)$ for all $k$. By $\Sigma^0_1$ induction on $k$, $f(k) + k \le f(0)$ for all $k$. For $k = f(0) + 1$ this gives $f(0) + 1 \le f(0)$, which is false.
3. Apply arithmetical transfinite recursion with $\theta(n, Y) \equiv n \in \mathrm{TJ}(Y)$ along $W$. This gives a set $H$ with $H_j = \mathrm{TJ}(H^j)$ for all $j$.
4. For $j = 0$, $H^0 = \emptyset$, so $H_0 = \emptyset'$.
5. $H^{j+1}$ is $H^j$ together with column $j$, so $H^{j+1} \equiv_T H^j \oplus H_j$. Since $H^j \le_T \mathrm{TJ}(H^j) = H_j$, this gives $H^{j+1} \equiv_T H_j$.
6. Thus $H_{j+1} = \mathrm{TJ}(H^{j+1}) \equiv_T (H_j)'$. By induction on $j$, $H_j \equiv_T \emptyset^{(j+1)}$ for every $j$.
7. So the columns of $H$ are, uniformly in $j$, the finite jumps of $\emptyset$, and $H \equiv_T \emptyset^{(\omega)}$.

$\mathsf{ACA}_0$ does not prove this statement.

8. The family of [[arithmetical sets|~46cb5771]] is an $\omega$-model of $\mathsf{ACA}_0$.
9. The formula "$H$ is a hierarchy along $W$ for $\theta$" is arithmetical, so it has the same meaning in this $\omega$-model and in the true sets.
10. Suppose that a set $H$ of this kind is arithmetical. By [[Post's theorem|NYJX5QXX1T]], $H \le_T \emptyset^{(k)}$ for some $k$.
11. By step 6, $\emptyset^{(k+1)} \equiv_T H_k \le_T H \le_T \emptyset^{(k)}$. This is false, because a set never computes its own jump.
12. So the model of arithmetical sets has no such $H$, and by the [[soundness theorem|4A84VHDTHV]] $\mathsf{ACA}_0$ does not prove that $H$ exists.

## Remarks

The same proof, with a parameter $X$ in $\theta$, shows that $\mathsf{ATR}_0$ proves that $X^{(\omega)}$ exists for every $X$.
The system $\mathsf{ACA}_0^+$, which is $\mathsf{ACA}_0$ with the axiom "$X^{(\omega)}$ exists for every $X$", is thus contained in $\mathsf{ATR}_0$.

## Explanations

### L1 human

$\mathsf{ACA}_0$ can take the jump of a set any finite number of times, but it cannot collect all these jumps in one set.
$\mathsf{ATR}_0$ can collect them, because it iterates the jump along the well-ordering $\omega$.
