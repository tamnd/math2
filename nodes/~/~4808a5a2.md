## Definition

A [[topological space|~77bfcc55]] $X$ is T1 when for all points $x \neq y$ of $X$ there is an [[open set|~159c5927]] $U$ with $x \in U$ and $y \notin U$.

## Remarks

A space is T1 if and only if each set $\{x\}$ with $x \in X$ is [[closed|~dfeacff3]].
Each [[Hausdorff space|~a1fe0c25]] is T1, and each T1 space is [[T0|~5b4f8168]].
An infinite set with the [[cofinite topology|~9632ad11]] is T1 but not Hausdorff. In fact, the cofinite topology is the coarsest T1 topology on a set.

## Explanations

### L1 human

In a T1 space, for two distinct points, each point has an open set around it that does not contain the other point.
This is the same as saying that single points are closed.
