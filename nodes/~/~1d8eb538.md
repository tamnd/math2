## Example

Let $\mathsf{Ver} = \mathsf{K} + \square\bot$, as in [[the trivial logic and the verum logic|~99b8dd16]].
We compute its [[canonical model|~d626bd63]] and derive a decision method.
In the canonical model, $\Gamma R^c \Delta$ when $\square\psi \in \Gamma$ implies $\psi \in \Delta$.

1. Every maximal [[consistent|VM8TQ70CVJ]] set $\Gamma$ contains the theorem $\square\bot$.
2. If $\Gamma R^c \Delta$, then $\bot \in \Delta$ by step 1, which contradicts the consistency of $\Delta$.
3. So $R^c$ is empty: the canonical frame has no arrows.
4. Let $\mathsf{Ver} \nvdash \varphi$. [[Lindenbaum's lemma|SC0BSJ3GT6]] gives a maximal consistent $\Gamma$ with $\neg\varphi \in \Gamma$.
5. By the [[truth lemma|~f856785f]], $\varphi$ is false at $\Gamma$ in the canonical model, whose frame has the empty relation.
6. So $\mathsf{Ver}$ is complete for the frames with empty relation.
7. These frames validate $\square\bot$, since $\square\psi$ is true at every world without successors. With [[soundness|~d189ee4b]], $\mathsf{Ver}$ is the logic of these frames.
8. Define $\varphi^*$ by replacing each outermost subformula $\square\psi$ of $\varphi$ by $\top$. Then $\varphi^*$ has no boxes.
9. On a frame with empty relation, each $\square\psi$ is true at each world, so $\varphi$ and $\varphi^*$ have the same truth value at each world.
10. If $\varphi^*$ is a [[tautology|05006AJ7DZ]], it is true at every world, so $\varphi$ is valid on these frames and $\mathsf{Ver} \vdash \varphi$ by step 6.
11. If $\varphi^*$ is not a tautology, take a falsifying assignment and a one-world model with empty relation that copies it. Then $\varphi^*$ and $\varphi$ fail there, so $\mathsf{Ver} \nvdash \varphi$.
12. So $\mathsf{Ver} \vdash \varphi$ exactly when $\varphi^*$ is a tautology, and truth tables decide $\mathsf{Ver}$.

## Remarks

The example shows a canonical model that can be computed completely.
The reduction also has a syntactic proof: $\mathsf{Ver} \vdash \square\psi \leftrightarrow \top$ for each $\psi$, and replacement of equivalents gives $\mathsf{Ver} \vdash \varphi \leftrightarrow \varphi^*$.
The canonical model has one world for each assignment of truth values to the variables, since only the variables matter at a world without successors.
For the trivial logic the same method works with $\square\psi$ replaced by $\psi$, and the canonical relation is the identity.
If we replace $\square\bot$ by $\square\square\bot$, the canonical relation is no longer empty, but no world has a path of length 2.

## Explanations

### L1 human

In the verum logic, "necessarily $p$" is always true, whatever $p$ is.
In a picture, this means that no world sees any world.
So to decide if a formula is a law, we replace every "necessarily ..." part by "true".
What remains is an ordinary formula, and a truth table decides it.
For example, "necessarily $p$, or $q$" becomes "true, or $q$", which is always true.

### L2 human

1. Take $\varphi = \square p \to (\lozenge q \to r)$.
2. Recall $\lozenge q = \neg\square\neg q$. Replace the boxed parts: $\varphi^* = \top \to (\neg\top \to r)$.
3. Since $\neg\top$ is false, $\neg\top \to r$ is true, so $\varphi^*$ is a tautology.
4. So $\mathsf{Ver} \vdash \varphi$: in this logic $\lozenge q$ is always false, so an implication from it is always true.

The typical use of this example is as a first exercise with the canonical model, where every step can be checked by hand.
A trap: $\varphi^*$ must replace only the boxed subformulas, so $\neg\square\neg q$ becomes $\neg\top$, not $\top$.
