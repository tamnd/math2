## Example

Let $\mathrm{Sq} = \set{0, 1, 4, 9, 16, \dots}$ be the set of [[perfect squares|HCGCPW8ZFE]].
Let $\theta(x)$ be the formula $\exists y < x + 1 \, (y \cdot y = x)$ of $L_A$, where $x + 1$ abbreviates $x + S0$.
We check that $\theta$ is $\Delta_0$, that it defines $\mathrm{Sq}$, and that $\mathrm{Sq}$ lies in the [[linear-time hierarchy|~38fa6f6e]].

1. $\Delta_0$. The only quantifier is $\exists y < x + 1$, and $y$ does not occur in the bound. The matrix $y \cdot y = x$ is atomic. So $\theta$ is a [[$\Delta_0$ formula|GE43CSZTS9]].
2. If $n \in \mathrm{Sq}$, then $n = m^2$ for some $m$. If $m \ge 1$, then $m \le m^2 = n < n + 1$. If $m = 0$, then $m < n + 1$. So $\N \models \theta(n)$.
3. If $\N \models \theta(n)$, then some $m < n + 1$ satisfies $m \cdot m = n$, so $n \in \mathrm{Sq}$.
4. For $n = 45$: the values $m = 0, \dots, 45$ have $m^2 \ne 45$, since $6^2 = 36$ and $7^2 = 49$. So $\N \models \neg \theta(45)$.
5. For $n = 49$: the value $m = 7 < 50$ gives $7 \cdot 7 = 49$. So $\N \models \theta(49)$.
6. By steps 1 to 3 and the equality $\Delta_0 = \mathrm{LinH}$, the set $\mathrm{Sq}$ is in $\mathrm{LinH}$, with $n$ written in binary.

## Remarks

The example shows the typical shape of a $\Delta_0$ definition: a bounded guess of a witness, then an atomic check.
A witness $y$ has at most about half the binary length of $x$, so the alternating machine guesses fewer bits than the length of the input.
If the exponent $2$ is replaced by a fixed $k$, the formula $\exists y < x + 1 \, (y^k = x)$ with $y^k$ written as a product still works.
If the exponent becomes a variable, as in $\set{(x, k) : x = y^k \text{ for some } y}$, the set is still $\Delta_0$-definable, but the formula needs Bennett's $\Delta_0$ definition of exponentiation.

## Explanations

### L1 human

A perfect square is a number like $49 = 7 \cdot 7$.
To test whether a number is a square, it suffices to try all numbers up to it.
For $45$ we try $0, 1, 2, \dots$ and find that $6 \cdot 6 = 36$ is too small and $7 \cdot 7 = 49$ is too big.
So $45$ is not a square.
Because the search never goes past the number itself, the property is bounded.

### L2 human

We find the witness for $n = 144$ in binary.

1. $144 = 10010000_2$ has $8$ binary digits.
2. The witness $12 = 1100_2$ has $4$ digits, half the length.
3. The check $12 \cdot 12 = 144$ holds, so $\theta(144)$ is true.
4. A nondeterministic machine guesses the $4$ bits of $12$ and then verifies the product.

The typical use is as a first test of the correspondence: a natural set has a short $\Delta_0$ definition, so it is in $\mathrm{LinH}$.
A trap is to think that the machine must try all $145$ values; it guesses one, and the guess has only a linear number of bits.
