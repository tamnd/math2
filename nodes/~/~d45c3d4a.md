## Definition

Let $L$ be a propositional language, and $\vDash$ classical [[consequence|1HK0VYWTV7]].

1. A relation $\mathrel{|\!\sim} \subseteq L \times L$ is a *preferential consequence relation* if, for all $\alpha, \beta, \gamma \in L$, it satisfies the rules of system $\mathbf{P}$:
   - Reflexivity: $\alpha \mathrel{|\!\sim} \alpha$;
   - Left Logical Equivalence: if $\vDash \alpha \leftrightarrow \beta$ and $\alpha \mathrel{|\!\sim} \gamma$, then $\beta \mathrel{|\!\sim} \gamma$;
   - Right Weakening: if $\vDash \beta \to \gamma$ and $\alpha \mathrel{|\!\sim} \beta$, then $\alpha \mathrel{|\!\sim} \gamma$;
   - Cut: if $\alpha \land \beta \mathrel{|\!\sim} \gamma$ and $\alpha \mathrel{|\!\sim} \beta$, then $\alpha \mathrel{|\!\sim} \gamma$;
   - Or: if $\alpha \mathrel{|\!\sim} \gamma$ and $\beta \mathrel{|\!\sim} \gamma$, then $\alpha \lor \beta \mathrel{|\!\sim} \gamma$;
   - Cautious Monotony: if $\alpha \mathrel{|\!\sim} \beta$ and $\alpha \mathrel{|\!\sim} \gamma$, then $\alpha \land \beta \mathrel{|\!\sim} \gamma$.
2. It is *rational* if it also has Rational Monotony: if $\alpha \mathrel{|\!\sim} \gamma$ and not $\alpha \mathrel{|\!\sim} \neg\beta$, then $\alpha \land \beta \mathrel{|\!\sim} \gamma$.
3. A *preferential model* is $S = (\Omega, \ell, \prec)$, where $\Omega$ is a set of states, $\ell$ maps states to [[truth valuations|H31CS3HK5P]] of $L$, and $\prec$ is a [[strict partial order|60FNZ35H6R]] on $\Omega$.
   Put $\widehat{\alpha} := \set{s \in \Omega : \ell(s) \vDash \alpha}$.
   A state $s \in \widehat{\alpha}$ is *minimal* in $\widehat{\alpha}$ if no $t \in \widehat{\alpha}$ has $t \prec s$.
   It must be *smooth*: if $s \in \widehat{\alpha}$ is not minimal there, then some $t \prec s$ is minimal in $\widehat{\alpha}$.
4. Put $\alpha \mathrel{|\!\sim}_S \beta$ if $\ell(s) \vDash \beta$ for all minimal $s$ in $\widehat{\alpha}$.
5. $S$ is *ranked* if $\prec$ is modular: $s \prec t$ implies $u \prec t$ or $s \prec u$, for all $s, t, u$.

## Notation

We write $\alpha \mathrel{|\!\not\sim} \beta$ for "not $\alpha \mathrel{|\!\sim} \beta$".
We write $\min \widehat{\alpha}$ for the set of minimal states of $\widehat{\alpha}$.
A state $s$ with $\ell(s) \vDash \alpha$ is called an $\alpha$-state.

## Remarks

- A state is not the same as a valuation: two states can carry the same valuation and sit at different places in the order.
- If $\Omega$ is finite, every strict partial order on it is smooth, since a descending chain in a finite set ends.
- Rule Or uses a disjunction of premises, and Cut and Cautious Monotony together say that adding a defeasible conclusion as a premise changes nothing.
- In a ranked model, the states lie in levels that are linearly ordered, and a state is more normal than another if its level is lower.

## Explanations

### L1 human

A preferential model lists possible situations and says which ones are more normal than others.
"If $\alpha$, then normally $\beta$" holds when $\beta$ is true in the most normal situations where $\alpha$ is true.
The rules of system $\mathbf{P}$ are the rules that this reading always obeys.

### L2 human

To compute $\alpha \mathrel{|\!\sim}_S \beta$, list the $\alpha$-states, remove each one that has a more normal $\alpha$-state, and test $\beta$ on the rest.
Smoothness guarantees that every $\alpha$-state that we remove is beaten by one that we keep.
A trap is to compare an $\alpha$-state with all states; we compare it only with $\alpha$-states.

### L3 human

The rules of $\mathbf{P}$ are Horn rules on conditional assertions, so the preferential closure of a set $\mathbf{K}$ is the least relation that contains $\mathbf{K}$ and is closed under them.
Rational Monotony is not a Horn rule, since it has a negative premise, and so the rational relations that contain $\mathbf{K}$ have no least element in general.
This is the reason for the separate construction of rational closure.
