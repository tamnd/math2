## Example

Let $Q(x, y) = x^2 + xy$ on $\R^2$.
We check that $Q$ is a [[quadratic form|0HZNE5QZDJ]], we compute its polar form, and we find its symmetric matrix.

1. Homogeneity: $Q(ax, ay) = a^2 x^2 + a^2 xy = a^2 Q(x, y)$ for all $a \in \R$.
2. Polar form: for $u = (x, y)$ and $v = (x', y')$,
$$Q(u + v) - Q(u) - Q(v) = (x + x')^2 + (x + x')(y + y') - x^2 - xy - x'^2 - x'y' = 2xx' + xy' + x'y.$$
3. The result $b_Q(u, v) = 2xx' + xy' + x'y$ is linear in $u$ for fixed $v$ and linear in $v$ for fixed $u$. So it is bilinear, and $Q$ is a quadratic form.
4. Outside characteristic $2$, the associated symmetric bilinear form is $B = \frac12 b_Q$, so $B(u, v) = xx' + \frac12 xy' + \frac12 x'y$.
5. The matrix of $B$ in the standard basis has the entries $B(e_1, e_1) = 1$, $B(e_1, e_2) = B(e_2, e_1) = \frac12$ and $B(e_2, e_2) = 0$:
$$A = \begin{pmatrix} 1 & \tfrac12 \\ \tfrac12 & 0 \end{pmatrix}.$$
6. Check: $(x, y) A (x, y)^T = x^2 + \tfrac12 xy + \tfrac12 yx + 0 = x^2 + xy = Q(x, y)$.
7. The matrix $\begin{pmatrix} 1 & 1 \\ 0 & 0 \end{pmatrix}$ also gives $x^2 + xy$, but it is not [[symmetric|0N28QN4CYA]]. The symmetric matrix is unique.

## Remarks

The example shows the convention that confuses many readers.
The coefficient of a cross term $x_i x_j$ is split into two equal halves $a_{ij} = a_{ji}$.
So a form with integer coefficients can have a symmetric matrix with entries $\frac12$.
For $x^2 + c\,xy$ the off-diagonal entry is $c / 2$; it is an integer exactly when $c$ is even.
The determinant of $A$ is $-\frac14 < 0$, so the form is indefinite: $Q(1, 0) = 1 > 0$ and $Q(1, -2) = 1 - 2 = -1 < 0$.

## Explanations

### L1 human

The expression $x^2 + xy$ has one square term and one mixed term.
To write it with a symmetric table of numbers, we put half of the mixed coefficient in each of the two off-diagonal places.
So the table has $1$ and $0$ on the diagonal, and $\frac12$ twice off the diagonal.

### L2 human

The general rule for a form in two variables is
$$ax^2 + bxy + cy^2 = \begin{pmatrix} x & y \end{pmatrix} \begin{pmatrix} a & b/2 \\ b/2 & c \end{pmatrix} \begin{pmatrix} x \\ y \end{pmatrix}.$$
With $a = 1$, $b = 1$ and $c = 0$ we get the matrix of step 5.
A trap: the determinant of this matrix is $ac - b^2/4$, not $ac - b^2$, so the tests for definiteness must use $b^2 - 4ac$.
