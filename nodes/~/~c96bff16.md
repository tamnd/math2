## Example

Let $X = \mathbb{R} \setminus \{1\}$, the set of real numbers different from $1$.
Define
$$f \colon X \to X, \qquad f(x) = \frac{x + 1}{x - 1}.$$
We prove that $f$ is a bijection by the three standard patterns of [[proving injectivity and surjectivity|~250c2090]].

1. The rule makes sense on $X$: for $x \neq 1$ the denominator $x - 1$ is not zero.
2. The values lie in $X$. If $f(x) = 1$, then $x + 1 = x - 1$, so $1 = -1$, which is false. So $f(x) \neq 1$ for each $x \in X$.
3. Injectivity. Let $a, b \in X$ with $f(a) = f(b)$. Multiply both sides by $(a - 1)(b - 1)$, which is not zero: $(a + 1)(b - 1) = (b + 1)(a - 1)$.
4. Expand: $ab - a + b - 1 = ab - b + a - 1$. Cancel $ab$ and $-1$: $-a + b = -b + a$, so $2b = 2a$ and $a = b$. Hence $f$ is [[injective|09NWETVTNY]].
5. Surjectivity. Let $y \in X$, so $y \neq 1$. We solve $\frac{x + 1}{x - 1} = y$ for $x \neq 1$.
6. Multiply by $x - 1$: $x + 1 = yx - y$. Collect the terms with $x$: $x(y - 1) = y + 1$. Since $y \neq 1$, we get $x = \frac{y + 1}{y - 1}$.
7. This $x$ lies in $X$ by step 2 applied to $y$, and each step of 6 can be reversed because $x - 1 \neq 0$ and $y - 1 \neq 0$. So $f(x) = y$, and $f$ is [[surjective|01RVCMSN5N]].
8. Inverse. Step 6 shows that the solution is $x = f(y)$. So we check $f(f(x)) = x$ for each $x \in X$ directly.
9. We compute $f(x) + 1 = \frac{2x}{x - 1}$ and $f(x) - 1 = \frac{2}{x - 1}$. So $f(f(x)) = \frac{2x}{x - 1} \cdot \frac{x - 1}{2} = x$.
10. So $f \circ f = \mathrm{id}_X$, and $f$ is a two-sided [[inverse|0J2WAR83WP]] of itself. By the statement [[bijective iff it has a two-sided inverse|01VG2A0BHW]], $f$ is a bijection.

A check with numbers: $f(3) = 4/2 = 2$ and $f(2) = 3/1 = 3$, so $f(f(3)) = 3$.

## Remarks

1. Step 10 alone proves the bijectivity. Steps 3 to 7 show the same conclusion with the two separate patterns, and they agree with it.
2. A function with $f \circ f = \mathrm{id}$ is called an involution. Each involution is a bijection, because it is its own two-sided inverse.
3. The choice of the set $X$ matters. On $\mathbb{R} \setminus \{1\}$ as domain with codomain $\mathbb{R}$, the function is injective but not surjective, because the value $1$ is never reached.
4. The function is a Möbius transformation $x \mapsto \frac{ax + b}{cx + d}$ with $a = b = c = 1$ and $d = -1$. When $c \neq 0$ and $ad - bc \neq 0$, such a map is a bijection from $\mathbb{R} \setminus \{-d/c\}$ to $\mathbb{R} \setminus \{a/c\}$. Here $-d/c = 1$ and $a/c = 1$.

## Explanations

### L1 human

The rule takes a number, adds $1$, and divides by the number minus $1$.
For $3$ it gives $4 \div 2 = 2$, and for $2$ it gives $3 \div 1 = 3$.
So applying the rule twice brings $3$ back to $3$.
The proof shows that this happens for every allowed number.
A rule that undoes itself can never send two numbers to the same place, and it reaches every allowed number.

### L2 human

We see why the number $1$ must be removed from both sides.

1. The input $1$ is not allowed, because the denominator $x - 1$ is zero there.
2. The output $1$ is never reached, by step 2 of the example.
3. If we kept $1$ in the codomain, the equation $f(x) = 1$ would have no solution, and $f$ would not be surjective.
4. So the clean statement is: $f$ is a bijection from $\mathbb{R} \setminus \{1\}$ to $\mathbb{R} \setminus \{1\}$.

The typical use of the inverse pattern is a rational or linear change of variables, where the inverse has a formula.
A trap is to multiply by $x - 1$ without the condition $x \neq 1$, which can add a false solution.
