## Example

Let $\mathrm{M}$ be the McKinsey formula $\square\lozenge p \to \lozenge\square p$.
We run the search of [[Harrop's theorem|~8e9dee58]] for a finite frame of [[S4|~b4d2786a]] that refutes $\mathrm{M}$.
The frames of $\mathsf{S4}$ are the preorders, the [[reflexive|0X8NMST0J2]] and [[transitive|0GJZW9JFZQ]] frames.
We list them by size, up to isomorphism, and check every valuation of $p$.

1. Size 1. The only preorder is one reflexive point $w$.
2. At $w$ the only successor is $w$, so $\lozenge p$ and $\square p$ both have the truth value of $p$.
3. So $\square\lozenge p$ and $\lozenge\square p$ both have the value of $p$, and $\mathrm{M}$ is true at $w$ for both valuations.
4. Size 2. There are three preorders on $\set{a, b}$ up to isomorphism: two separate reflexive points, the chain $a \le b$, and the cluster where each point sees both.
5. Separate points. Each point sees only itself, so step 2 applies at each point, and $\mathrm{M}$ is true everywhere.
6. The chain. Here $a$ sees $a$ and $b$, and $b$ sees only $b$.
7. At $b$, step 2 applies again, so $\mathrm{M}$ is true at $b$.
8. At $a$, $\square\lozenge p$ needs $\lozenge p$ at $b$, which is $p$ at $b$.
9. If $p$ is true at $b$, then $\square p$ is true at $b$, so $\lozenge\square p$ is true at $a$.
10. So in the chain, whenever the antecedent holds at $a$, the consequent holds at $a$, and $\mathrm{M}$ is valid on the chain.
11. The cluster. Take $V(p) = \set{a}$.
12. Each point sees $a$, and $p$ is true at $a$, so $\lozenge p$ is true at $a$ and at $b$.
13. So $\square\lozenge p$ is true at $a$.
14. Each point sees $b$, and $p$ is false at $b$, so $\square p$ is false at $a$ and at $b$.
15. So $\lozenge\square p$ is false at $a$, and $\mathrm{M}$ fails at $a$.
16. The cluster is a preorder, so it validates $\mathsf{S4}$, and by [[soundness|~d189ee4b]] $\mathsf{S4} \nvdash \mathrm{M}$.

## Remarks

The search stops at size 2, and steps 1 to 3 show that no smaller countermodel exists.
With $\lozenge$ counted as primitive, $\Sigma = \operatorname{Sub}(\mathrm{M})$ has the 6 members $p$, $\lozenge p$, $\square p$, $\square\lozenge p$, $\lozenge\square p$ and $\mathrm{M}$.
The [[finite model property theorem|~4d501751]] bounds the search by $2^{6} = 64$ worlds, so the search was certain to end.
The other half of Harrop's procedure enumerates the proofs of $\mathsf{S4}$; it never finds a proof of $\mathrm{M}$, by step 16.
Adding $\mathrm{M}$ to $\mathsf{S4}$ gives the logic $\mathsf{S4.1}$, and the cluster shows that this extension is proper.
In $\mathsf{S5}$ every frame is a union of clusters, so the same cluster shows $\mathsf{S5} \nvdash \mathrm{M}$.

## Explanations

### L1 human

The procedure looks for a small picture where the formula is false.
It tries every picture with one world, then every picture with two worlds.
With one world, nothing can go wrong.
With two worlds that see each other, and $p$ true at only one of them, the formula fails.
So the formula is not a law of $\mathsf{S4}$.

### L2 human

1. Take two worlds $a$ and $b$ that see each other and themselves.
2. Make $p$ true at $a$ only.
3. Every world can reach a $p$-world, so "always eventually $p$" holds.
4. No world has $p$ at all its successors, so "eventually always $p$" fails.

The typical use of the example is to see that a finite model property turns non-provability into a finite search.
A trap: a countermodel on a frame that is not a preorder, such as an irreflexive point, proves nothing about $\mathsf{S4}$.

### L3 human

Over $\mathsf{K}$, the McKinsey formula defines no first-order class of frames, a result of Goldblatt treated in [[modal model theory|SPQVNPZDTB]].
Harrop's method gives decidability, but the naive search through all frames below the bound is very slow.
The [[complexity theorem|~c5e1a419]] gives the optimal PSPACE bound for $\mathsf{S4}$.
