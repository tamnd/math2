## Definition

A [[graph|~3f82cef4]] $G$ is connected if its vertex set is nonempty and any two vertices of $G$ are [[reachable|~fb98409f]] from each other.

## Remarks

The empty graph, with no vertices, is not connected under this convention. Some authors call it connected.
A graph is connected if and only if it has exactly one [[connected component|~b47736e3]].
The [[cycle graphs|~19143ce5]], the [[path graphs|~c147bff4]] and the [[trees|~29e53124]] are connected.

## Explanations

### L1 human

A graph is connected when it is in one piece.
From any vertex you can reach any other vertex along edges.
