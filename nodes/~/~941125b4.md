## Example

Each class below is not an [[elementary class|MEC3ZMC4F1]]: no set $T$ of first-order sentences has exactly its members as models.
The method is the same each time: suppose $T$ exists, add new constants and infinitely many sentences that each finite part of $T$ can satisfy, and apply the [[compactness theorem|1NR3HAWG9D]] to get a model of $T$ outside the class.

1. *Finite sets.* Add "there are at least $n$ elements" for each $n$. A large finite set satisfies each finite part; a model of the whole is infinite.
2. *[[Torsion groups|JZNQTTMG58]].* Add a constant $c$ and $c^n \ne e$ for $n \ge 1$. The group $\Z/m\Z$ with $c = 1$ and $m$ large satisfies each finite part; in a model of the whole, $c$ has infinite order.
3. *[[Well-orders|01CGSJ0GNQ]].* Add constants $c_0, c_1, \dots$ and $c_{n+1} < c_n$. The order $(\N, <)$ with $c_i = N - i$ satisfies each finite part; a model of the whole has an infinite descending chain.
4. *[[Connected graphs|0KWFFMDF8T]].* Add constants $a, b$ and, for each $n$, "there is no path of length at most $n$ from $a$ to $b$". A long path with $a$, $b$ at its ends satisfies each finite part; in a model of the whole, $a$ and $b$ lie in different components.
5. *[[Archimedean ordered fields|0XH79S06J3]].* Add a constant $c$ and $c > n \cdot 1$ for each $n$. The field $\R$ with $c$ large satisfies each finite part; in a model of the whole, $c$ is infinitely large.

So none of these five classes is elementary.

## Remarks

### Simple groups

The class of [[simple groups|0YMYMNQ0QZ]] is not elementary either.
Add constants $a, b$, the sentence $a \ne e$, and for each $k$ the sentence "$b$ is not a product of at most $k$ conjugates of $a$ and $a^{-1}$".
For a finite part with bound $K$, take the simple [[alternating group|0Z5905Q73D]] $A_m$ with $m \ge \max(5, 3K + 3)$, $a = (1\,2\,3)$ and $b$ a product of $K + 1$ disjoint $3$-cycles.
A conjugate of $a^{\pm 1}$ is a $3$-cycle, a product of $j \le K$ of them moves at most $3j$ points, and $b$ moves $3K + 3$ points.
In a model of the whole, $a \ne e$ and $b$ is not in the normal subgroup generated by $a$, so the group is not simple.

### Games and natural language

Among finite linear orders, "the number of elements is even" is not first-order: the orders with $2^k$ and $2^k + 1$ elements agree on sentences of quantifier depth $k$, by the [[Ehrenfeucht-Fraïssé game|2RE7YAZK8R]].
Compactness does not apply here, since the class of finite orders is itself not elementary.
In natural language, the [[Geach-Kaplan sentence|655T2GTWNV]] and the quantifier [[most|1C6CGH1G6A]] are standard examples of statements that have no first-order paraphrase.

## Explanations

### L1 human

First-order sentences talk about elements, not about sets of elements or about "finitely many".
So properties like "finite", "every element has finite order" or "you can walk from any point to any other" escape them.
Compactness turns each of these into a proof: any first-order description that fits all finite cases also fits an infinite, strange case.

### L2 human

We check the finite part in item 4 for $n \le 3$.

1. Let the graph be the path with vertices $v_0, \dots, v_4$ and edges $v_i v_{i+1}$ for $i < 4$, with $a = v_0$ and $b = v_4$.
2. Every path from $v_0$ to $v_4$ in this graph passes through $v_1, v_2, v_3$, so it has length at least $4$.
3. So "there is no path of length at most $n$ from $a$ to $b$" holds for $n = 1, 2, 3$, and the graph is connected.

The typical use of the method is to show that a natural class needs second-order or infinitary logic.
A trap is to conclude that a property is not first-order because one natural attempt fails.
