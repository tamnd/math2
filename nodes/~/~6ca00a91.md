## Example

Let $H = \set{0, \tfrac12, 1}$ with the usual order, $\land = \min$, $\lor = \max$.
Put $a \to b = 1$ if $a \le b$, and $a \to b = b$ otherwise, and $\neg a = a \to 0$.
We check that $H$ is a [[Heyting algebra|BND6A96S3D]], that it is not a Boolean algebra, and that classical laws fail in it.

1. Residuation: $c \land a \le b$ iff $c \le a \to b$.
   If $a \le b$, both sides hold for every $c$.
   If $a > b$, the left side means $\min(c, a) \le b$, that is $c \le b$, since $a > b$.
2. So $H$ is a Heyting algebra, and $\neg 0 = 1$, $\neg \tfrac12 = 0$, $\neg 1 = 0$.
3. No complement: $\tfrac12 \land x = 0$ forces $x = 0$, and then $\tfrac12 \lor 0 = \tfrac12 \ne 1$.
4. [[Excluded middle|0RYYK8PG4S]] fails: at $p = \tfrac12$, $p \lor \neg p = \max(\tfrac12, 0) = \tfrac12$.
5. Double negation fails: $\neg \neg \tfrac12 = \neg 0 = 1 \ne \tfrac12$.
6. [[Peirce's law|GMSZ75D5WE]] fails at $p = \tfrac12$, $q = 0$: $p \to q = 0$, then $(p \to q) \to p = 1$, then $1 \to \tfrac12 = \tfrac12$.

So $H$ is not a Boolean algebra, and it refutes three classical theorems.

## Remarks

1. The chain is a model of intuitionistic logic, so it shows that excluded middle is not an intuitionistic theorem.
2. The two-element subchain $\set{0, 1}$ is Boolean; the extra middle element breaks complementation.
3. Every finite Heyting chain with at least three elements refutes $p \lor \neg p$ at any element strictly between $0$ and $1$.
4. Valuations in $H$ satisfy the Gödel-Dummett law $(p \to q) \lor (q \to p)$, because $H$ is a chain.

## Explanations

### L1 human

Here there are three truth values: false, "not yet decided" and true.
The value "not yet decided" has no opposite value in the list.
So "$p$ or not $p$" can come out as "not yet decided", not as true.
This is why a three-valued chain is not a model of ordinary logic.

### L2 human

1. Set $p = \tfrac12$.
2. Then $\neg p = \tfrac12 \to 0$; since $\tfrac12 > 0$, this is $0$.
3. So $p \lor \neg p = \max(\tfrac12, 0) = \tfrac12$.
4. The value is not $1$, so excluded middle is not valid in $H$.

The typical use: small Heyting chains are the first countermodels for classical laws in intuitionistic logic.
The trap: $\neg \tfrac12 = 0$, not $\tfrac12$; the Heyting negation is not $1 - x$.
