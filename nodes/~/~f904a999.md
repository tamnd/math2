## Example

In [[affine logic|~963ba4ac]], the formula $A \otimes B \multimap A$ is derivable for all formulas $A$ and $B$.
In one-sided form it is $A^{\perp} \mathbin{\wp} B^{\perp} \mathbin{\wp} A$, since $(A \otimes B)^{\perp} = A^{\perp} \mathbin{\wp} B^{\perp}$.

1. $\vdash A^{\perp}, A$ is an axiom.
2. Weakening adds $B^{\perp}$: $\vdash A^{\perp}, B^{\perp}, A$.
3. The rule $\mathbin{\wp}$ gives $\vdash A^{\perp} \mathbin{\wp} B^{\perp}, A$.
4. The rule $\mathbin{\wp}$ again gives $\vdash (A^{\perp} \mathbin{\wp} B^{\perp}) \mathbin{\wp} A$.

## Remarks

In MALL, the sequent $\vdash p^{\perp} \mathbin{\wp} q^{\perp}, p$ is not derivable, for atoms $p$ and $q$.
By [[cut admissibility for MALL|~3257a7fb]], a derivation could be taken cut-free.
The last rule of a cut-free derivation must be $\mathbin{\wp}$, since no other rule has this conclusion, and it leaves $\vdash p^{\perp}, q^{\perp}, p$.
That sequent has three atomic formulas and no connective, so no rule other than the axiom applies, and the axiom needs exactly two formulas.
So weakening is needed: $A \otimes B \multimap A$ separates affine logic from linear logic.

## Explanations

### L1 human

From "$A$ and $B$ together" we may conclude "$A$", if we may throw $B$ away.
Affine logic allows this; linear logic does not.

### L2 human

We derive the other projection $A \otimes B \multimap B$.

1. $\vdash B^{\perp}, B$ is an axiom.
2. Weakening adds $A^{\perp}$: $\vdash A^{\perp}, B^{\perp}, B$.
3. Two uses of $\mathbin{\wp}$ give $\vdash (A^{\perp} \mathbin{\wp} B^{\perp}) \mathbin{\wp} B$.

The typical use of these projections is to discard part of a resource.
A trap: $A \mathbin{\&} B \multimap A$ is derivable already in linear logic, by the rule for $\oplus$, so it does not need weakening.
