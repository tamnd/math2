## Example

Let $T$ be the theory of [[dense linear orders|2W4S2H4VYA]] without endpoints, and let $\lambda = \beth_\omega = \sup_n \beth_n$, a [[beth number|SS6WMEN6KX]].

1. The cardinal $\lambda$ is a strong limit: if $\mu < \lambda$, then $\mu < \beth_n$ for some $n$, so $2^\mu \le 2^{\beth_n} = \beth_{n+1} < \lambda$.
2. The language has one symbol, so $\lambda > \abs{L} + \aleph_0$.
3. Build the links $\mathcal{M}_\mu$ for cardinals $\aleph_0 \le \mu < \lambda$ by recursion. Let $\mathcal{M}'$ be the union of the earlier links, or $(\Q, <)$ at the start, and let $\mathcal{M}_\mu$ be a $\mu^+$-saturated elementary extension of $\mathcal{M}'$ of size at most $(\abs{M'} + 2)^{\mu}$, by part 1 of [[existence of saturated models|~b797b7c8]].
4. By induction, $\abs{M_\mu} \le 2^\mu < \lambda$: there are at most $\mu$ earlier links, each of size at most $2^\mu$, and $(2^\mu)^\mu = 2^\mu$.
5. Each $\mathcal{M}_\mu$ has size at least $\mu^+$, since the type $\set{x \ne a : a \in A}$ over a set $A$ of size $\mu$ is realized in it.
6. So the union $\mathcal{M}$ has size exactly $\lambda$, and it is a [[special model|~82e5b5a7]] of $T$.
7. The [[cofinality|BAWHE1W6MH]] of $\lambda$ is $\aleph_0$, since $\lambda$ is the limit of the sequence $\beth_n$. So $\lambda$ is singular.
8. By part 5 of existence of saturated models, no dense linear order of singular size is saturated. So $\mathcal{M}$ is not [[saturated|RMTZ5J64FX]].

## Remarks

The proof of step 8 finds an increasing sequence $(a_n)_{n \in \N}$ that is cofinal in $\mathcal{M}$, using sets $X_n$ of size less than $\lambda$ that cover $M$; here the sets $M_{\beth_n}$ can serve.
The type over $\set{a_n : n \in \N}$ of an element above every $a_n$ is consistent and omitted.
So $\mathcal{M}$ is not even $\aleph_1$-saturated, although each link is far more saturated.
Every finite set lies in one link, so $\mathcal{M}$ is still $\aleph_0$-saturated.

## Explanations

### L1 human

The model is built as a growing union of better and better saturated orders.
The union has countably many stages that matter, and a countable increasing sequence can climb through all of them.
No element lies above such a sequence, so the union fails to be saturated, although it is special.

### L2 human

The test that separates special from saturated is the regularity of the size.

1. For regular $\lambda$, a special model of size $\lambda$ is saturated.
2. For singular $\lambda$, a special model of size $\lambda$ may omit a type over a set of size $\operatorname{cf}(\lambda)$.

The typical use is as a substitute for a saturated model in size $\beth_\omega$, where the back-and-forth arguments still work.
The trap is to apply saturation to a countable parameter set in such a model.
