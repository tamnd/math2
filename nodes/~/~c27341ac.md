## Proof

We prove [[the complexity theorem|~a0f550e4]].
The upper bounds use [[the translation theorem|~6369ab54]], [[Savitch's theorem|PFKWV5SFF5]] and the lasso lemma of step 1.
The lower bound is the reduction of Sistla and Clarke; we give its construction and cite their correctness check.

1. Lasso lemma. A Büchi automaton with an accepting run has a path from an initial state to an accepting state $q$, and a cycle through $q$.
2. Proof of step 1. An accepting run visits some accepting state $q$ infinitely often, since there are finitely many states. Two visits to $q$ give the cycle. Conversely, the path followed by the cycle forever is an accepting run.
3. Bounded lengths. If $\mathcal{A}$ has $n$ states, the path and the cycle of step 1 can be chosen of length at most $n$, by removing repeated states.
4. Satisfiability in NPSPACE. Let $\mathcal{A}_\varphi$ be the automaton of the translation theorem, with $n = 2^{O(\lvert\varphi\rvert)}$ states. The algorithm guesses $q$, then guesses the path and the cycle one state at a time.
5. At each moment it stores the current state, the previous one, $q$ and a step counter up to $n$. Each takes $O(\lvert\varphi\rvert)$ bits, by part 3 of the translation theorem.
6. Each guessed step is checked against the rules of $\mathcal{A}_\varphi$ in polynomial time, without building $\mathcal{A}_\varphi$. So satisfiability is in NPSPACE.
7. By Savitch's theorem, NPSPACE equals PSPACE. This gives the upper bound of part 1.
8. Model checking, reduction. A state $s$ fails $\varphi$ if and only if some path from $s$ has a label word satisfying $\neg\varphi$.
9. Form the product of $M$ with $\mathcal{A}_{\neg\varphi}$. Its states are pairs $(m, B)$, and $(m, B) \to (m', B')$ when $m \to m'$ in $M$ and $\mathcal{A}_{\neg\varphi}$ moves from $B$ to $B'$ on the label of $m$.
10. A product state is accepting when $B$ is. Its accepting runs from $(s, B_0)$, with $B_0$ initial, correspond to paths from $s$ whose label words satisfy $\neg\varphi$.
11. Model checking in PSPACE. Apply steps 4 to 7 to the product. A state needs $O(\log\lvert M \rvert + \lvert\varphi\rvert)$ bits, so "$s$ fails $\varphi$" is in PSPACE, and so is its complement.
12. Time bound. The product has $\lvert M \rvert \cdot 2^{O(\lvert\varphi\rvert)}$ states and edges. A reachable accepting state on a cycle is found in linear time with [[strongly connected components|5XY87RKYJ4]]. This gives part 3.
13. Lower bound, the machine. Let $T$ be a deterministic Turing machine that runs in space $N = p(\lvert x \rvert)$ on input $x$. Assume that $T$ repeats its accepting configuration forever once it accepts.
14. Every language in PSPACE is decided by such a machine $T$. For fixed $T$, we build from $x$ in polynomial time a formula $\varphi_{T,x}$. It is satisfiable exactly when $T$ accepts $x$.
15. Letters. For each tape symbol $a$ and each pair (state, symbol) there is one atomic proposition, plus one for the separator $\#$. A word codes the configurations of $T$ in blocks of length $N + 1$, each ended by $\#$.
16. The formula is a conjunction. One conjunct says $G$ ("exactly one letter proposition is true"). One says that the first block is the initial configuration on $x$, using $X^i$ for $i \le N$.
17. The window conjunct. The content of a cell in the next configuration is a function $f$ of the three cells around it now. For all letters $a, b, c$ it states $G\big((a \wedge Xb \wedge X^2 c) \to X^{N+2} f(a, b, c)\big)$.
18. Here $X^{N+2}$ moves from the middle cell to the same cell of the next block. This conjunct has $O(N)$ symbols for each triple, so the formula has polynomial size.
19. The last conjunct is $F\,\mathit{acc}$, where $\mathit{acc}$ is the disjunction of the letters with an accepting state.
20. Correctness, cited. Sistla and Clarke check that the models of $\varphi_{T,x}$ are exactly the codes of the accepting computations of $T$ on $x$. So satisfiability is PSPACE-hard, which completes part 1.
21. Model checking hardness. Let $M_T$ have one state for each letter, all edges between them, and a start state $s$ with an empty label and edges to all letter states.
22. The label words of paths from $s$ are $\emptyset$ followed by any word with exactly one letter per position. So $s$ fails $\neg X\varphi_{T,x}$ if and only if $\varphi_{T,x}$ is satisfiable.
23. $M_T$ has polynomial size, so the complement of model checking is PSPACE-hard. Since PSPACE is closed under complement, model checking is PSPACE-hard. This completes part 2.

## Idea

An LTL formula is equivalent to an exponential automaton whose states are small, so a nondeterministic search can walk through it in polynomial space.
For hardness, the operator $X$ iterated $N + 2$ times links each tape cell to the same cell one configuration later.

## Variants

1. The upper bound can also be proved without automata. One guesses an ultimately periodic model one position at a time, storing only the set of subformulas true there.
