## Statement

The theory ZFC, that is [[Zermelo-Fraenkel set theory|0HE5WDQ9FJ]] with choice, is given by the following ten axioms about [[sets|0SJ3RX9TXA]].

1. Extensionality ([[axiom of extensionality|0TB16T2C97]]): sets are equal exactly when they have the same elements.
2. Empty set: some set $\emptyset$ has no elements.
3. Pairing: for sets $x$ and $y$ there is a set whose only elements are $x$ and $y$. It is written $\{x,y\}$, and $\{x\}$ when $x=y$.
4. Union: for every set $x$ there is a set $y$ whose elements are exactly the elements of the elements of $x$.
5. Infinity: there is a set $x$ with $\emptyset\in x$ such that $\{y,\{y\}\}\in x$ whenever $y\in x$.
6. Power set: for every set $x$ there is a set $y$ whose elements are exactly the subsets of $x$.
7. Regularity ([[axiom of regularity|NFQ9FVCP31]]): every non-empty set $x$ has an element $y$ such that $x$ and $y$ are disjoint.
8. Separation (subset axiom): for each set and each property $P(x)$, there is a subset of that set whose elements are exactly those $x$ with $P(x)$.
9. Replacement ([[axiom schema of replacement|D96K8S8R61]]): if $P(x,y)$ is functional, meaning $P(x,y_1)$ and $P(x,y_2)$ give $y_1=y_2$, then for each set there is a set holding exactly the images of its elements.
10. Choice ([[axiom of choice|0HTGB13FE2]]): for each collection of pairwise disjoint non-empty sets, some set meets each of them in exactly one element.
