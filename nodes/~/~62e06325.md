## Statement

Let $X$ be the set of [[real numbers|08J2M1JYAG]] $x$ with $0 < x < 1$. No function from the set of positive integers to $X$ is a [[surjection|01RVCMSN5N]].

## Remarks

Equivalently, no list $x_1, x_2, x_3, \dots$ of numbers in $X$ contains every number of $X$. So $X$ cannot be counted.
