## Example

Let $f(x) = 1$ for every real $x$.
The true limit is $\lim_{x \to 0} f(x) = 1$.
We show an argument that "proves" $\lim_{x \to 0} f(x) = 0$, and we find its error.

The false argument:

1. Let $\varepsilon > 0$, and let $\delta = \frac{\lvert x \rvert}{2}$.
2. Let $x$ satisfy $0 < \lvert x - 0 \rvert < \delta$, that is, $0 < \lvert x \rvert < \frac{\lvert x \rvert}{2}$.
3. No real $x$ satisfies this condition, because $\lvert x \rvert < \frac{\lvert x \rvert}{2}$ gives $\lvert x \rvert < 0$.
4. So the implication "$0 < \lvert x \rvert < \delta$ implies $\lvert f(x) - 0 \rvert < \varepsilon$" holds for every $x$, because its hypothesis is false.
5. So $\lim_{x \to 0} f(x) = 0$, the argument concludes.

The check against the [[epsilon-delta definition of a limit|0GBZDAFPX8]]:

1. The definition has the [[quantifier|EGTZPA6QH3]] order $\forall \varepsilon > 0 \; \exists \delta > 0 \; \forall x$. The number $\delta$ is chosen after $\varepsilon$ and before $x$.
2. So $\delta$ may depend on $\varepsilon$, and on the point $0$, but not on $x$.
3. In step 1 of the argument, $\delta = \lvert x \rvert / 2$ uses a variable $x$ that is not yet chosen. So step 1 does not define a number.
4. The argument is not an instance of [[writing epsilon-delta proofs|~925b8c9e]], and its conclusion is false.
5. The definition shows that the claim is false. Take $\varepsilon = \frac12$. For each $\delta > 0$, the point $x = \delta/2$ satisfies $0 < \lvert x \rvert < \delta$, and $\lvert f(x) - 0 \rvert = 1 \ge \frac12$. So no $\delta$ works for this $\varepsilon$.

## Remarks

1. A less extreme form of the error appears in the proof of $\lim_{x \to 2} x^2 = 4$. The scratch work gives $\lvert x^2 - 4 \rvert = \lvert x - 2 \rvert \cdot \lvert x + 2 \rvert$, and a student writes $\delta = \varepsilon / \lvert x + 2 \rvert$.
2. That choice also depends on $x$, so it is not a $\delta$. The correct proof removes $x$ with a bound: on $\lvert x - 2 \rvert < 1$ we have $\lvert x + 2 \rvert < 5$, and $\delta = \min(1, \varepsilon/5)$ works, as in [[the limit of x^2 at 2|~4bda664f]].
3. In the example above the error makes the condition on $x$ impossible, so every limit would follow. This shows that the quantifier order is not a formality.
4. The order $\forall \varepsilon \, \forall x \, \exists \delta$ would allow $\delta$ to depend on $x$, and it gives a statement that is true for every function and every claimed limit, by the argument above.

## Explanations

### L1 human

In the game of the limit, the first player names a tolerance, then the second player names a distance, and only then is the point $x$ chosen.
The second player may not wait to see $x$.
The false argument cheats: it picks a distance that depends on $x$, and in fact so small that no $x$ fits.
With this cheat, the second player "wins" every game, even for the false claim that the constant $1$ tends to $0$.

### L2 human

We test the order of the quantifiers on the claim $\lim_{x \to 0} f(x) = 0$ for the constant $f(x) = 1$.

1. The correct statement is: there is $\delta > 0$ such that, for all $x$ with $0 < \lvert x \rvert < \delta$, $\lvert 1 - 0 \rvert < \varepsilon$.
2. For $\varepsilon = \frac12$ the inner condition is $1 < \frac12$, which is false for every $x$.
3. So the statement asks for a $\delta$ such that no $x$ satisfies $0 < \lvert x \rvert < \delta$.
4. Each $\delta > 0$ has such points, for example $x = \delta/2$. So no $\delta$ exists, and the limit is not $0$.

The typical use of this check is the review of a written epsilon-delta proof.
We find the line where $\delta$ is defined, and we make sure that only $\varepsilon$ and the fixed point appear in it.
A trap is a $\delta$ written with a hidden $x$, for example $\delta = \varepsilon / (x + 2)$, where $x$ is used before the line that introduces it.
