## Proof

We treat invertible $A$ first, and then singular $A$.
Let $Q = [0, 1]^n$, so $\lambda(Q) = 1$, and let $E_{ij}$ be the matrix unit.

1. Let $A$ be invertible. Then $A(S)$ is the preimage of $S$ under the continuous map $A^{-1}$, so $A(S)$ is Borel.
2. Define $\mu(S) = \lambda(A(S))$ for Borel $S$. $A$ is a bijection, so $\mu$ is a measure.
3. $A(S + x) = A(S) + A x$, and [[Lebesgue measure|2Z2QVWZ262]] is translation invariant. So $\mu$ is translation invariant.
4. $\mu$ is the image of $\lambda$ under the homeomorphism $A^{-1}$, so $\mu$ is a Radon measure.
5. $\mu(A^{-1}(Q)) = \lambda(Q) = 1$, so $\mu \ne 0$.
6. By the [[uniqueness of Haar measure|WSW3B6KNW1]] on $(\mathbb{R}^n, +)$, $\mu = c(A) \lambda$ for a constant $c(A) > 0$.
7. Evaluation at $Q$ gives $c(A) = \lambda(A(Q))$. In particular $c(I_n) = 1$.
8. For invertible $A, B$: $c(AB) \lambda(S) = \lambda(A(B(S))) = c(A) c(B) \lambda(S)$. With $S = Q$, $c(AB) = c(A) c(B)$.
9. Let $D = \operatorname{diag}(d_1, \dots, d_n)$ be invertible. Then $D(Q)$ is a box with sides $\lvert d_1 \rvert, \dots, \lvert d_n \rvert$.
10. So $c(D) = \lvert d_1 \cdots d_n \rvert = \lvert \det D \rvert$, by the [[triangular rule|0K1KKMFHYH]].
11. Let $T_{ij}(t) = I_n + t E_{ij}$ with $i \ne j$, a [[transvection|0NMN00FNW1]]. Let $t \ne 0$.
12. Let $S_t$ be the diagonal matrix with $t$ at position $i$ and $1$ elsewhere. Then $S_t T_{ij}(1) S_t^{-1} = T_{ij}(t)$.
13. By steps 8 and 7, $c(T_{ij}(t)) = c(S_t) c(T_{ij}(1)) c(S_t^{-1}) = c(T_{ij}(1))$.
14. $E_{ij}^2 = 0$ for $i \ne j$, so $T_{ij}(1)^2 = T_{ij}(2)$.
15. By steps 8 and 13, $c(T_{ij}(1))^2 = c(T_{ij}(2)) = c(T_{ij}(1))$. As $c > 0$, $c(T_{ij}(1)) = 1$.
16. So $c(T_{ij}(t)) = 1$ for all $t$, and $\det T_{ij}(t) = 1$ by the triangular rule.
17. By the [[generation theorem|YSS4XNY9RC]], $A = T_1 \cdots T_k \, D$ with transvections $T_m$ and $D = \operatorname{diag}(1, \dots, 1, \det A)$.
18. By steps 8, 10 and 16 and the [[product rule|04CPJ6AF00]], $c(A) = \lvert \det A \rvert$. This proves part 1 for invertible $A$.
19. Now let $A$ be singular. Then $\det A = 0$ by the [[invertibility criterion|03Q7RE2HXR]].
20. The column space $W = A(\mathbb{R}^n)$ has dimension $r < n$.
21. [[Extend|0M4SXE5WW3]] a basis $w_1, \dots, w_r$ of $W$ to a basis $w_1, \dots, w_n$ of $\mathbb{R}^n$. Let $P$ have columns $w_1, \dots, w_n$.
22. Let $H = \{ x : x_n = 0 \}$. Then $P(H)$ is the span of $w_1, \dots, w_{n-1}$.
23. Since $r \le n - 1$, this span contains $W$, so $W \subseteq P(H)$.
24. $H$ is the union of the boxes $[-k, k]^{n-1} \times [0, 0]$ for $k \ge 1$, each of volume $0$. So $\lambda(H) = 0$.
25. By the invertible case for $P$, $\lambda(P(H)) = \lvert \det P \rvert \cdot 0 = 0$.
26. So $A(S) \subseteq P(H)$ lies in a null set. Lebesgue measure is complete, so $A(S)$ is measurable with $\lambda(A(S)) = 0$.
27. This equals $\lvert \det A \rvert \lambda(S) = 0$, with $0 \cdot \infty = 0$. This proves part 1 for singular $A$.
28. For part 2, $P = A(Q)$. The set $Q$ is a Borel set with $\lambda(Q) = 1$, so part 1 gives $\lambda(P) = \lvert \det A \rvert$.

## Idea

The map $S \mapsto \lambda(A(S))$ is again translation invariant, so it is $\lambda$ times a constant $c(A)$.
The constant is multiplicative, it is $1$ on transvections, and it is $\lvert \det D \rvert$ on diagonal matrices.
Elementary matrices generate $\mathrm{GL}_n(\mathbb{R})$, so $c(A) = \lvert \det A \rvert$.
A singular matrix maps everything into a hyperplane, which is a null set.

## Variants

A proof without Haar measure checks the formula on boxes for each type of elementary matrix.
For a shear, the image of a box has the same volume by [[Fubini's theorem|0R0T1VWH5X]], since each slice is only translated.
A third proof uses $A = QR$ with $Q$ orthogonal and $R$ upper triangular, and the invariance of $\lambda$ under orthogonal maps.
