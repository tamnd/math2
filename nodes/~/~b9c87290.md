## Definition

Let $L$ be a signature, let $T$ be a complete $L$-[[theory|92SWXST1ZM]], and let $M \models T$.
Let $\mathcal{E}$ be the set of $L$-formulas $E(\bar x, \bar y)$, with $\bar x$ and $\bar y$ of the same length $n_E \ge 1$, such that $T$ says that $E$ is an [[equivalence relation|0G8VEZ3WTK]].

1. The signature $L^{\mathrm{eq}}$ is the [[many-sorted signature|7TDHDN8P96]] with one sort $S_E$ for each $E \in \mathcal{E}$, the symbols of $L$ on the sort $S_=$, and a function symbol $\pi_E : S_=^{n_E} \to S_E$ for each $E$.
2. The $L^{\mathrm{eq}}$-[[structure|983GZBQYT4]] $M^{\mathrm{eq}}$ has $M$ as its sort $S_=$, with the $L$-structure of $M$, and the quotient $M^{n_E} / E$ as its sort $S_E$. The symbol $\pi_E$ maps $\bar a$ to its class $\bar a / E$.
3. The elements of the sorts $S_E$ are the *imaginary elements* of $M$, and the elements of $S_=$ are the *real elements*.
4. $T^{\mathrm{eq}}$ is the theory of $M^{\mathrm{eq}}$. It does not depend on the choice of $M \models T$.

Let $X = \varphi(M, \bar b)$ be a [[definable set|CY1TXHF6KQ]], with $\varphi(\bar x, \bar y)$ an $L$-formula.
Let $E_\varphi(\bar y, \bar y')$ be the formula $\forall \bar x \, (\varphi(\bar x, \bar y) \leftrightarrow \varphi(\bar x, \bar y'))$, which is in $\mathcal{E}$.
The *canonical parameter* of $X$ for $\varphi$ is the imaginary $\ulcorner X \urcorner = \bar b / E_\varphi$.

## Notation

One writes $a, b, e$ for imaginaries as well as for real elements, and $\operatorname{dcl}^{\mathrm{eq}}$ and $\operatorname{acl}^{\mathrm{eq}}$ for [[definable and algebraic closure|DKAGC639W9]] computed in $M^{\mathrm{eq}}$.
The canonical parameter is also called the *code* of $X$, and some books write $\ulcorner \varphi(\bar x, \bar b) \urcorner$.
It depends on $\varphi$ only up to interdefinability: two formulas that define $X$ give two codes, each in the definable closure of the other.

## Remarks

$T^{\mathrm{eq}}$ is axiomatized by $T$ on $S_=$ and, for each $E \in \mathcal{E}$, the axioms that $\pi_E$ is onto $S_E$ and that $\pi_E(\bar x) = \pi_E(\bar y) \leftrightarrow E(\bar x, \bar y)$.
Each model of $T^{\mathrm{eq}}$ is isomorphic to $N^{\mathrm{eq}}$ for a model $N$ of $T$.

Example: in the theory of an equivalence relation with infinitely many infinite classes, each class is an imaginary element; see [[this example|~daf6ca13]].

Non-example: the classes of the relation "infinitely close" in a non-archimedean real closed field are not imaginaries, because the relation is not definable; see [[this example|~99697a21]].

## Explanations

### L1 human

Sometimes the objects we care about are groups of elements, not single elements.
For example, among the points of the plane, a line is a set of points.
Imaginary elements turn such a set into a single new element, the "name" of the set.
The name of a line can be its equation, up to multiplying the whole equation by a nonzero number.

### L2 human

We find the canonical parameter of the circle $X$ of radius $2$ around $(1, 0)$ in $\mathbb{R}^2$.

1. Take $\varphi(x_1, x_2; y_1, y_2, y_3)$ to be $(x_1 - y_1)^2 + (x_2 - y_2)^2 = y_3$, and $\bar b = (1, 0, 4)$.
2. Two parameter tuples define the same set when they give the same center and the same $y_3 \ge 0$, or when both have $y_3 < 0$, giving the empty set.
3. So the class of $\bar b$ under $E_\varphi$ is $\set{(1, 0, 4)}$, and $\ulcorner X \urcorner$ is interdefinable with the real tuple $(1, 0, 4)$.

The typical use is to treat a definable set as an element, and to ask which automorphisms fix it.
A trap is to forget the degenerate parameters: for $y_3 = 0$ the set is a point, and for $y_3 < 0$ all tuples give the same empty set.
