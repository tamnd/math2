## Proof

Let $v$ be the valuation with $v(p) = \tfrac12$ for every variable $p$.
We write $v(\varphi)$ for the value of $\varphi$ in the [[strong Kleene matrix|~e50e75c5]].

1. Claim: $v(\varphi) = \tfrac12$ for every formula $\varphi$. We use [[structural induction|12MQ2NJ29A]] on $\varphi$.
2. Base case: if $\varphi$ is a variable $p$, then $v(p) = \tfrac12$ by the choice of $v$.
3. Negation: if $v(\psi) = \tfrac12$, then $v(\neg \psi) = 1 - \tfrac12 = \tfrac12$.
4. Conjunction: if $v(\psi) = v(\chi) = \tfrac12$, then $v(\psi \land \chi) = \min(\tfrac12, \tfrac12) = \tfrac12$.
5. Disjunction: under the same hypothesis, $v(\psi \lor \chi) = \max(\tfrac12, \tfrac12) = \tfrac12$.
6. Implication is the abbreviation $\neg \psi \lor \chi$, so steps 3 and 5 cover it.
7. This proves the claim, which is item 1.
8. Item 2: the only designated value is $1$, and $v(\varphi) = \tfrac12 \ne 1$. So $v$ refutes $\varphi$.
9. Item 3: if $\Gamma = \emptyset$, then $\Gamma \models \varphi$ would mean that $\varphi$ is a tautology, which step 8 excludes.

## Idea

The value $\tfrac12$ is a fixed point of every connective.
So a formula cannot leave $\tfrac12$ when all its inputs are $\tfrac12$.

## Variants

1. The same proof works for every set of connectives that maps $(\tfrac12, \dots, \tfrac12)$ to $\tfrac12$.
2. In algebraic terms, $\set{\tfrac12}$ is a subalgebra, and term functions preserve subalgebras.
