## Example

Let $\sigma = \set{<, 3}$ with a binary relation symbol and a constant symbol.
We show that the string $\varepsilon x \, (3 < x)$ of the [[epsilon calculus|~41c81e04]] is not a $\sigma$-[[term|6D3WA7N2W4]].

1. A $\sigma$-term is a variable, the constant $3$, or $f(t_1, \dots, t_n)$ for a function symbol $f$ of $\sigma$. Here $\sigma$ has no function symbols.
2. So every $\sigma$-term is a variable or the constant $3$, a string of length $1$.
3. The string $\varepsilon x \, (3 < x)$ has length greater than $1$. So it is not a $\sigma$-term.
4. Adding symbols does not help. A term over any signature contains no relation symbol, by induction on terms, while $\varepsilon x \, (3 < x)$ contains $<$.
5. In $\varepsilon x \, (3 < x)$ the variable $x$ is bound. In a first-order term every variable occurrence is [[free|~2fd0cd75]], because only quantifiers bind.

So $\varepsilon$-terms need a new formation rule, which makes terms and formulas mutually recursive.

## Remarks

In the epsilon calculus, terms and formulas are defined together: if $A$ is a formula and $x$ a variable, then $\varepsilon x \, A$ is a term.
The [[definite description|PD2R4XT79Q]] operator $\iota x \, A$ and the set-builder $\set{x \mid A}$ are other term-forming binders of this kind.
In first-order logic they are eliminated in favour of formulas, for example by Russell's analysis of descriptions.

## Explanations

### L1 human

First-order terms are names built from symbols such as $0$, $+$ and variables.
They never contain a sentence inside.
The expression "some $x$ bigger than $3$" contains the statement "$3 < x$", so it is a new kind of name.

### L2 human

We see why the mutual recursion matters.

1. In first-order logic, terms are built first, and formulas are built from terms.
2. With $\varepsilon$, the formula $3 < x$ gives the term $\varepsilon x \, (3 < x)$, which gives the formula $3 < \varepsilon x \, (3 < x)$, and so on.
3. So unique readability and recursion on syntax must be proved for terms and formulas at once.

The typical use of this non-example is to locate the epsilon calculus outside first-order syntax, with a conservative translation back.
A trap: a term may look like an $\varepsilon$-term in a book that writes $\varepsilon$ for a constant, such as an infinitesimal.
The test is whether a formula and a bound variable occur inside.
