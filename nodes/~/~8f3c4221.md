## Example

Let $L$ be the empty signature, so an $L$-[[structure|983GZBQYT4]] is a nonempty set.
Let $A$ and $B$ be infinite sets, of any [[cardinalities|0EBACQFAZW]].
Let $I$ be the set of all injective maps from a [[finite|070R982G4B]] subset of $A$ into $B$.
We check that $I$ is a [[back-and-forth system|~95b1c1d3]].

1. $I$ is not empty: it contains the empty map.
2. Each $p \in I$ is a partial isomorphism: it is injective, and $L$ has no relation symbols to preserve.
3. Forth: let $p \in I$ and $a \in A$. If $a \in \operatorname{dom} p$, take $q = p$. Otherwise the range of $p$ is finite and $B$ is infinite, so some $b \in B$ is outside the range. Then $q = p \cup \set{(a, b)}$ is injective, so $q \in I$.
4. Back: let $p \in I$ and $b \in B$. If $b \in \operatorname{ran} p$, take $q = p$. Otherwise $\operatorname{dom} p$ is finite and $A$ is infinite, so some $a \in A$ is outside it, and $p \cup \set{(a, b)} \in I$.
5. So $A \cong_p B$, for example for $A = \N$ and $B = \R$.

## Remarks

By [[Karp's theorem|~ca02717b]], any two infinite sets satisfy the same sentences of $L_{\infty\omega}$.
So in the empty signature no sentence of $L_{\infty\omega}$ says "the domain is countable", although the sentence $\bigvee_{n \ge 1} \exists x_1 \cdots \exists x_n \, \forall y \, \bigvee_{i} (y = x_i)$ says "the domain is finite".
When $A$ and $B$ are both countable, the back-and-forth method turns $I$ into a bijection, which is an isomorphism in the empty signature.

The example fails when one set is finite.
Let $A = \set{1, \dots, n}$ and $B$ be infinite, and let $p \in I$ have domain $A$.
Back for a point $b$ outside the range of $p$ needs a new point of $A$, and there is none.
The structures still agree on all sentences of quantifier rank at most $n$; see [[the game on finite sets|~544e1961]].

## Explanations

### L1 human

Take two bags of marbles with no colors or labels, each bag with infinitely many marbles.
Whatever finite number of marbles we have paired so far, we can pair one more, from either bag, because both bags still have unpaired marbles.
So the bags look the same to any test that pairs marbles one at a time, even if one bag has far more marbles than the other.

### L2 human

We run three steps between $A = \N$ and $B = \R$.

1. Start with $p_0 = \emptyset$.
2. Forth with $a = 5$: the range is empty, so take $b = \pi$, and $p_1 = \set{(5, \pi)}$.
3. Back with $b = \pi$: it is already in the range, so $p_2 = p_1$.
4. Back with $b = \sqrt{2}$: the domain is $\set{5}$, so take $a = 0$, and $p_3 = \set{(5, \pi), (0, \sqrt{2})}$.

The typical use of the example is to show that $L_{\infty\omega}$ cannot tell infinite cardinalities apart in the empty signature.
A trap is to conclude that $\N$ and $\R$ are isomorphic: the system exists, but the back-and-forth method needs both sets to be countable.
