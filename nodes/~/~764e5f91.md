## Example

Let $L_A = \set{0, S, +, \cdot}$, with a constant symbol, a unary function symbol and two binary function symbols.
First-order Peano arithmetic $\mathsf{PA}$ is the first-order form of the [[Peano axioms|0QFT7Z76N5]].
Its axioms are the six sentences
$$\forall x \, \neg\, S x = 0, \quad \forall x \forall y \, (S x = S y \to x = y), \quad \forall x \, (x + 0 = x),$$
$$\forall x \forall y \, (x + S y = S(x + y)), \quad \forall x \, (x \cdot 0 = 0), \quad \forall x \forall y \, (x \cdot S y = (x \cdot y) + x),$$
and every induction axiom.
For a formula $\varphi$ whose free variables are among $x, y_1, \dots, y_m$, the induction axiom of $\varphi$ and $x$ is the sentence
$$\forall y_1 \cdots \forall y_m \, \big( (\varphi^x_0 \land \forall x \, (\varphi \to \varphi^x_{S x})) \to \forall x \, \varphi \big).$$
The terms $0$ and $S x$ are always substitutable for $x$ in $\varphi$, because $0$ has no variables and a free occurrence of $x$ is never in the scope of a quantifier $\forall x$.
We check that the axiom set of $\mathsf{PA}$ is decidable, so that $\mathsf{PA}$ is a [[recursively axiomatizable theory|3ANXZC3BEG]].

1. Code the symbols of $L_A$, the logical symbols and the variables by natural numbers. The sets of formulas and of sentences are then decidable, by a parsing program.
2. Let $\tau$ be a string. If $\tau$ is not a sentence, it is not an axiom. If $\tau$ is one of the six basic axioms, which we test by comparison, it is an axiom.
3. Otherwise $\tau$ begins with some number $k \ge 0$ of universal quantifiers. For each $m \le k$, remove the first $m$ quantifiers $\forall y_1 \cdots \forall y_m$, and call the rest $\rho$. There are $k + 1$ choices.
4. By unique readability, $\rho$ has at most one decomposition of the form $((\alpha \land \forall x \, \beta) \to \forall x' \, \gamma)$. In $H$ the conjunction $\alpha \land \beta'$ is spelled $\neg (\alpha \to \neg \beta')$, and the parser reads $\alpha$, $x$, $\beta$, $x'$ and $\gamma$ from $\rho$, or finds that there is no such decomposition.
5. Test whether $x' = x$, whether $\beta$ is the string $(\gamma \to \gamma^x_{S x})$, and whether $\alpha$ is the string $\gamma^x_0$. The substitutions are computed by replacing each free occurrence of $x$ in $\gamma$.
6. If the tests of step 5 succeed for some $m$, then $\tau$ is the induction axiom of $\varphi = \gamma$ and $x$. The free variables of $\gamma$ are among $x, y_1, \dots, y_m$, because $\tau$ is a sentence. If the tests fail for every $m$, then $\tau$ is not an induction axiom.
7. Each step stops after finitely many operations, so the program always answers. So the axiom set of $\mathsf{PA}$ is a [[computable set|PPGD5KW8JC]], and $\mathsf{PA}$ is recursively axiomatizable.
8. By property 3 of the main page, the set $\operatorname{Thm}(\mathsf{PA})$ is [[computably enumerable|TN9G24VABN]].
9. Every axiom of $\mathsf{PA}$ is true in $\N$, so $\mathsf{PA}$ is consistent, and it proves the axioms of [[Robinson arithmetic|3K1AKGXF8A]]. By step 7 and the first of [[Gödel's incompleteness theorems|X9WYNYE29C]], $\mathsf{PA}$ is not complete. So property 5 of the main page does not apply.

## Remarks

The example shows that an infinite axiom set can be recursive: what matters is a test of membership, not the size of the set.
The induction schema is the reason why the set is infinite.
Robinson arithmetic, which drops the induction schema, has a finite set of axioms, and it is recursively axiomatizable by property 1 of the main page.

The set of theorems of $\mathsf{PA}$ is computably enumerable but not decidable.
So $\mathsf{PA}$ is recursively axiomatizable and undecidable, like the [[theory of groups|~379a857f]].
If we replace the axioms of $\mathsf{PA}$ by all sentences true in $\N$, the theory becomes complete but loses its recursive axiomatization: see [[true arithmetic is not recursively axiomatizable|~10f45dc4]].

## Explanations

### L1 human

Peano arithmetic has infinitely many axioms, so a computer cannot store them in a list.
But a computer can still test whether a given sentence is an axiom.
The induction axioms all have one fixed shape: "if the property holds for 0, and it passes from each number to the next, then it holds for all numbers".
The computer checks this shape, just as a teacher checks that a proof by induction has a base case and an induction step.
So proofs in Peano arithmetic can be checked by a machine.

### L2 human

We test two strings with the program of the Example.

1. Take $\tau_1 = ((0 = 0 \land \forall x \, (x = x \to S x = S x)) \to \forall x \, x = x)$. There are no leading quantifiers, so $m = 0$ and $\rho = \tau_1$.
2. The parser gives $\alpha = (0 = 0)$, $x$, $\beta = (x = x \to S x = S x)$, $x' = x$ and $\gamma = (x = x)$.
3. Then $\gamma^x_{S x} = (S x = S x)$, so $\beta = (\gamma \to \gamma^x_{S x})$, and $\gamma^x_0 = (0 = 0) = \alpha$. So $\tau_1$ is the induction axiom of $x = x$.
4. Take $\tau_2 = ((0 = 0 \land \forall x \, (x = x \to S x = S x)) \to \forall x \, S x = S x)$. Here $\gamma = (S x = S x)$, and $\gamma^x_0 = (S 0 = S 0)$, which is not $\alpha$.
5. So $\tau_2$ is not an induction axiom, although it is a valid sentence and a theorem of $\mathsf{PA}$.

The typical use of this check is in the proof of Gödel's incompleteness theorems, which need a theory with a decidable set of axioms.
The trap is to think that a decidable set of axioms gives a decidable set of theorems; for $\mathsf{PA}$ it does not.
