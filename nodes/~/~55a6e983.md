## Example

Let $A = \operatorname{diag}(1, 2)$ over $\R$.
Its [[eigenspaces|0AYEPBQMAW]] are $E_1 = \operatorname{span}\{e_1\}$ and $E_2 = \operatorname{span}\{e_2\}$.

1. $Ae_1 = e_1$ and $Ae_2 = 2e_2$. So $e_1 \in E_1$ and $e_2 \in E_2$.
2. Let $U = E_1 \cup E_2$, the set of all [[eigenvectors|0B5H4208Z9]] of $A$ together with $0$.
3. $e_1 + e_2 = (1, 1)$, and $A(1, 1) = (1, 2)$.
4. $(1, 2)$ is not a multiple of $(1, 1)$. So $(1, 1)$ is not an eigenvector, and $(1, 1) \notin U$.
5. So $U$ is not closed under addition, and $U$ is not a subspace of $\R^2$.

## Remarks

- Each single eigenspace $E_\lambda = \ker(A - \lambda I)$ is a subspace.
- The sum $E_1 + E_2$ is a subspace, here all of $\R^2$. It is direct, because eigenvectors with distinct eigenvalues are linearly independent.

## Explanations

### L1 human

The eigenvectors for $1$ lie on one axis, and those for $2$ lie on the other axis.
Adding one vector from each axis gives a vector off both axes.
That vector is not an eigenvector.

### L2 human

The typical lesson is to use the sum of eigenspaces, not their union.
A trap is to call the set of all eigenvectors "the eigenspace" of a matrix with several eigenvalues.
