## Example

Let $D$ be the map $A \mapsto \neg \neg A$ on formulas of first-order logic, and let $A = \forall x\, (P(x) \vee \neg P(x))$.
We show that $A$ is classically provable but $D(A) = \neg \neg A$ is not intuitionistically provable.
So $D$ is not a [[double-negation translation|HGJVM49PA4]] for predicate logic.

We use a [[Kripke model|NGHWZ9Y7ZV]] for first-order [[intuitionistic logic|Q11N8X99FK]].
Its nodes are $w_0 \le w_1 \le w_2 \le \cdots$, and the domain of $w_n$ is $\set{0, 1, \dots, n}$.
The node $w_m$ forces $P(k)$ if and only if $k < m$.
Forcing is defined by the usual clauses: $w \Vdash \neg B$ if no $v \ge w$ forces $B$.
Also $w \Vdash B \vee C$ if $w$ forces $B$ or $C$, and $w \Vdash \forall x\, B$ if every $v \ge w$ forces $B(d)$ for every $d$ in the domain of $v$.

1. The model is monotone: domains grow along $\le$, and if $w_m$ forces $P(k)$, then $k < m \le m'$, so $w_{m'}$ forces $P(k)$.
2. $A$ is classically provable: excluded middle gives $P(x) \vee \neg P(x)$, and ${\forall}\mathrm{I}$ gives $A$.
3. Fix $m$. The element $m$ is in the domain of $w_m$, and $w_m$ does not force $P(m)$, since $m < m$ is false.
4. The node $w_{m+1} \ge w_m$ forces $P(m)$, so $w_m$ does not force $\neg P(m)$.
5. By steps 3 and 4, $w_m$ does not force $P(m) \vee \neg P(m)$, so $w_m$ does not force $A$.
6. Step 5 holds for every $m$, so no node forces $A$. Hence $w_0$ forces $\neg A$.
7. Then $w_0$ does not force $\neg \neg A$, because $w_0 \ge w_0$ forces $\neg A$.
8. Intuitionistic logic is sound for Kripke models: every provable formula is forced at every node. So $\nvdash_i \neg \neg A$.

So $D$ fails the condition "$\vdash_c B$ implies $\vdash_i D(B)$" at $B = A$.

## Remarks

The map $D$ is a double-negation translation for propositional logic, by Glivenko's theorem.
The example shows that this fails as soon as a universal quantifier occurs.
The same model forces $\forall x\, \neg \neg (P(x) \vee \neg P(x))$ at every node, since this formula is intuitionistically provable.
So the model refutes the double negation shift $\forall x\, \neg \neg B(x) \to \neg \neg \forall x\, B(x)$.
This shift is the principle that [[bar recursion|~a7df5e71]] interprets, and it is the reason why the Kuroda translation puts $\neg \neg$ after each $\forall$.
With a finite chain of nodes the argument fails: the last node $w_n$ forces $\neg P(n)$, so the infinite chain is needed.

## Explanations

### L1 human

For statements without "for all", it is enough to put "it is impossible that not" in front of a classical truth to make it intuitionistically acceptable.
This example shows that this simple trick breaks with "for all".
Picture a growing collection of objects $0, 1, 2, \dots$, and knowledge that grows over time.
At each time, the newest object is not yet known to have $P$, but it will be known to have $P$ later.
So at no time is every object decided, and so "it is impossible that not every object is decided" is false at the start.

### L2 human

We check steps 3 to 7 at the node $w_2$, with domain $\set{0, 1, 2}$.

1. $w_2$ forces $P(0)$ and $P(1)$, since $0 < 2$ and $1 < 2$.
2. $w_2$ does not force $P(2)$, since $2 < 2$ is false.
3. $w_3$ forces $P(2)$, so $w_2$ does not force $\neg P(2)$.
4. So $w_2$ does not force $P(2) \vee \neg P(2)$, and so it does not force $A$.

The typical use of such a model is to show that a principle is not intuitionistically provable.
A trap is to use a finite chain: its last node forces $A$, and then every node forces $\neg \neg A$.
