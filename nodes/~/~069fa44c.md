## Proof

Let $T$ be complete with infinite models in a countable signature.
We prove $(2) \Leftrightarrow (3)$, $(2) \Leftrightarrow (4)$, $(1) \Leftrightarrow (4)$ and $(2) \Leftrightarrow (5)$.

### Separating formulas

Let $q_1, \dots, q_m$ be distinct complete $n$-types.
For $i \ne j$ choose $\psi_{ij} \in q_i$ with $\neg\psi_{ij} \in q_j$, and let $\theta_i = \bigwedge_{j \ne i} \psi_{ij}$.
Then $\theta_i \in q_i$ and $\theta_i \notin q_j$ for $j \ne i$.

### Clauses 2, 3 and 4

1. $(2) \Rightarrow (4)$. Let $S_n(T) = \set{q_1, \dots, q_m}$. A complete type containing $\theta_i$ is not $q_j$ for $j \ne i$, so it is $q_i$. So $\theta_i$ isolates $q_i$.
2. $(2) \Rightarrow (3)$. With $\theta_i$ as in step 1, every tuple in every model satisfies exactly one $\theta_i$. So each formula $\varphi$ is equivalent modulo $T$ to the disjunction of the $\theta_i$ with $\varphi \in q_i$. There are at most $2^m$ such disjunctions.
3. $(3) \Rightarrow (2)$. A complete type is fixed by the classes of formulas it contains. With $k$ classes there are at most $2^k$ types.
4. $(4) \Rightarrow (2)$. For each type $p$ choose a formula $\theta_p$ isolating it. The set $\set{\neg\theta_p : p \in S_n(T)}$ is realized by no tuple, since the type of the tuple contains its own $\theta_p$. By [[compactness|1NR3HAWG9D]], $T \models \theta_{p_1} \vee \dots \vee \theta_{p_k}$ for some $p_1, \dots, p_k$. Every type contains some $\theta_{p_i}$, so it equals $p_i$.

### Clauses 1 and 4

1. $(4) \Rightarrow (1)$. If all types are isolated, every countable model is [[atomic|~fbef995e]]. Two countable atomic models are isomorphic by [[this theorem|~ddda0a28]].
2. $(1) \Rightarrow (4)$. Suppose that $p$ is not isolated. The [[omitting types theorem|7MFGBVDVG9]] gives a countable model $M$ that omits $p$.
3. By compactness, $T$ has a model realizing $p$, and by the [[Löwenheim-Skolem theorem|484M0TZ1S7]] a countable one, $N$.
4. $N$ realizes $p$ and $M$ does not, so $M \not\cong N$, and $T$ is not $\aleph_0$-categorical.

### Clauses 2 and 5

1. $(2) \Rightarrow (5)$. Let $M$ be a countable model. It is atomic by $(2) \Rightarrow (4)$. The back-and-forth proof in [[this theorem|~ddda0a28]], run from $M$ to itself, shows that two tuples of $M$ with the same type are mapped to each other by an [[automorphism|0K1SCPBNKJ]]. So the orbits on $M^n$ are at most $\abs{S_n(T)}$ in number.
2. $(5) \Rightarrow (2)$. An automorphism keeps types, so all tuples in one orbit have the same type. So $M$ realizes finitely many $n$-types $q_1, \dots, q_m$, at most one per orbit. Take $\theta_i$ as above.
3. A tuple of $M$ that satisfies $\theta_i$ has type $q_i$. So for $\varphi \in q_i$, $M \models \forall \bar x \, (\theta_i \to \varphi)$, and this sentence is in $T$. So $\theta_i$ isolates $q_i$ in $T$.
4. Also $M \models \forall \bar x \, (\theta_1 \vee \dots \vee \theta_m)$, so this sentence is in $T$. Every $p \in S_n(T)$ contains some $\theta_i$, so $p = q_i$.

## Idea

Finitely many types means that each type is cut out by one formula, and these formulas cover everything.
Then every countable model is atomic, and atomic countable models are unique.
A non-isolated type breaks categoricity, because one countable model omits it and another realizes it.
In a countable model, types and orbits correspond, by a back-and-forth argument.

## Variants

Clause 3 can be phrased with the [[Lindenbaum-Tarski algebra|QC9M3Q8B8Q]]: each algebra $B_n(T)$ is finite.
Then $S_n(T)$, its Stone space, is finite, which is clause 2.
