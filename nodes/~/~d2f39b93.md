## Example

Let $v$ be a truth assignment, and define $f : \mathrm{Form} \to \set{0, 1}$ by $f(\varphi) = 1$ when some variable that occurs in $\varphi$ has the value $1$ under $v$, and $f(\varphi) = 0$ otherwise.
Take $v(p) = 1$ and $v(q) = 0$.
We show that $f$ agrees with $v$ on variables but is not a [[truth valuation|~41f42e3d]].

1. For a variable $s$, the only variable that occurs in $s$ is $s$, so $f(s) = v(s)$; so $f$ extends $v$.
2. The formula $p \land q$ contains $p$ and $v(p) = 1$, so $f(p \land q) = 1$.
3. The clause for $\land$ in the [[definition|~1bd7b4b2]] asks for $f(p \land q) = \min(f(p), f(q)) = \min(1, 0) = 0$.
4. Steps 2 and 3 disagree, so $f$ breaks the clause for $\land$.
5. Also $f(\neg p) = 1$, since $p$ occurs in $\neg p$, but the clause for $\neg$ asks for $1 - f(p) = 0$.
6. So $f$ is not a truth valuation, and $f \neq \bar v$.

## Remarks

The example shows that "agrees with $v$ on variables" is not enough: a valuation must follow the clauses at every connective.
By the extension theorem, $\bar v$ is the only truth valuation that agrees with $v$ on variables, and here $\bar v(p \land q) = 0$.
The map $f$ does satisfy the clause for $\lor$: $f(\varphi \lor \psi) = 1$ exactly when $f(\varphi) = 1$ or $f(\psi) = 1$.
So $f$ and $\bar v$ agree on all formulas built from variables with $\lor$ only.
If $v$ gives the value $1$ to every variable, then $f$ is constant $1$, and it breaks the clause for $\neg$ at every formula $\neg \varphi$.

## Explanations

### L1 human

Here is a wrong rule for truth: "a formula is true when at least one of its letters is true".
With $p$ true and $q$ false, the rule calls "$p$ and $q$" true.
But "$p$ and $q$" is false, since $q$ is false.
The rule also calls "not $p$" true, but it is false.
So the rule does not follow the tables of the connectives.

### L2 human

We test a proposed map $g$ on formulas against the definition of a truth valuation.

1. Check the variables: $g(s)$ must be $0$ or $1$ for each variable $s$.
2. Check each clause on small formulas, such as $\neg p$, $p \land q$, $p \lor q$, $p \to q$ and $p \leftrightarrow q$, in each row.
3. One failure, as in step 4 above, shows that $g$ is not a valuation.
4. To show that $g$ is a valuation, check each clause for all formulas, by an argument and not by a list.

The typical use is to rule out a false semantics quickly.
A trap is to test the clauses only on variables; the clauses are about compound formulas.
