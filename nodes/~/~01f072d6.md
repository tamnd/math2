## Example

Let $T \colon \R^2 \to \R^2$ be the map $T(v) = 2v$, with the dot product on $\R^2$.
We check the conditions of a [[linear isometry|0717XXPWM6]].

1. Linearity holds: $T(au + bv) = 2au + 2bv = aT(u) + bT(v)$.
2. Norms: $\norm{T(1, 0)} = \norm{(2, 0)} = 2$, but $\norm{(1, 0)} = 1$. So the norm condition fails.
3. In general, $\norm{Tv} = 2\norm{v}$, so the condition fails for every $v \neq 0$.
4. Inner products: $\ip{Tu}{Tv} = 4\ip{u}{v}$. So $T^*T = 4I \neq I$.

## Remarks

- $T$ keeps angles and right angles: $\ip{Tu}{Tv} = 0$ exactly when $\ip{u}{v} = 0$. So keeping orthogonality is not enough for an isometry.
- The scaling $v \mapsto cv$ is a linear isometry exactly when $\abs{c} = 1$. Over $\R$, this means $c = 1$ or $c = -1$.
- The inverse $v \mapsto \frac{1}{2}v$ halves every length, so it is not a linear isometry either.

## Explanations

### L1 human

A photo copier that doubles the size of a picture keeps the shape, but not the size.
A segment of length $3$ becomes a segment of length $6$.
An isometry must keep sizes, so doubling is not an isometry.

### L2 human

Worked check:

1. Take $v = (3, 4)$, of length $5$.
2. Then $Tv = (6, 8)$, of length $\sqrt{36 + 64} = 10$.
3. So $\norm{Tv} \neq \norm{v}$, and $T$ is not a linear isometry.

A trap: the matrix $2I$ has orthogonal columns $(2, 0)$ and $(0, 2)$, but they are not unit vectors.
