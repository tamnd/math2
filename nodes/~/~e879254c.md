## Example

Two agents $a$ and $b$ and four worlds $w_1, w_2, w_3, w_4$.
Each relation is an [[equivalence relation|0G8VEZ3WTK]], given by its classes:

- agent $a$: $\set{w_1, w_2}$, $\set{w_3}$, $\set{w_4}$;
- agent $b$: $\set{w_1}$, $\set{w_2, w_3}$, $\set{w_4}$.

The atom $p$ is true at $w_1, w_2, w_3$, and the atom $q$ is true at $w_1, w_2$.
Let $G = \set{a, b}$, and evaluate at $w_1$.

1. From $w_1$, agent $a$ reaches $w_2$, and from $w_2$, agent $b$ reaches $w_3$.
2. No class containing $w_1$, $w_2$ or $w_3$ contains $w_4$. So the worlds reachable from $w_1$ in one or more steps are $w_1, w_2, w_3$.
3. $p$ is true at all three, so $C_G p$ is true at $w_1$, by [[the reachability clause|~2e0d432a]].
4. $q$ is false at $w_3$, which is reachable, so $C_G q$ is false at $w_1$.
5. Still $E_G q$ is true at $w_1$: $q$ holds on $a$'s class $\set{w_1, w_2}$ and on $b$'s class $\set{w_1}$.
6. $E_G^2 q$ is false at $w_1$. It needs $E_G q$ at $w_2$, hence $K_b q$ at $w_2$, but $b$'s class $\set{w_2, w_3}$ contains $w_3$.
7. At $w_4$ the only reachable world is $w_4$. So $C_G \neg p$ is true at $w_4$.

So at $w_1$, $q$ is known by everyone but is not common knowledge, while $p$ is common knowledge.

## Remarks

The reachable sets are the classes of the [[transitive closure|05J9NWX07X]] of $R_a \cup R_b$: here $\set{w_1, w_2, w_3}$ and $\set{w_4}$.
They are the blocks of the meet of the two partitions, as in [[the partition form of the definition|RRRHWH9F6Y]].
Common knowledge is constant on each block, so $C_G\varphi$ has the same value at $w_1$, $w_2$ and $w_3$.
The level at which "everyone knows" breaks is the distance from $w_1$ to the nearest world without $q$: here two steps.

## Explanations

### L1 human

Draw the four worlds and connect two of them when some agent cannot tell them apart.
A fact is common knowledge when it holds everywhere in the connected piece containing the actual world.
The atom $p$ holds on the whole piece, so it is common knowledge.
The atom $q$ fails at the end of the piece, so it is not, even though both agents know it.

### L2 human

We find the first $k$ with $E_G^k q$ false at $w_1$ by distances.

1. $E_G^k q$ holds at $w_1$ iff $q$ holds at every world exactly $k$ steps away.
2. Since each relation is reflexive, worlds within $k$ steps are also exactly $k$ steps away.
3. $w_3$ is two steps away, so $E_G^2 q$ fails at $w_1$, and $E_G q$ holds since $w_3$ is not one step away.

The typical use is to read the depth of mutual knowledge from a picture.
A trap: step 2 needs reflexivity; without it, "within $k$ steps" and "exactly $k$ steps" differ.

### L3 human

Checking $C_G$ in a finite model is a connected component computation, linear in the size of the model.
For $\mathsf{S5}$ models the components are the blocks of the meet partition, which is why Aumann's partition definition matches the modal one.
