## Example

Let $\sigma$ be the sentence $\forall x \, \exists y \, (x < y)$ in the signature $\set{<}$.
We show that $\sigma$ is [[true|~58a589d1]] in $\mathcal{N} = (\N, <)$ and false in $\mathcal{F} = (\set{0, 1, 2}, <)$, both with the usual order.

Truth in $\mathcal{N}$:

1. Let $s$ be any assignment in $\mathcal{N}$. By the clause for $\forall x$ of [[satisfaction|~cf18e0d7]], we must show $\mathcal{N} \models \exists y \, (x < y)[s[x \mapsto n]]$ for every $n \in \N$.
2. Let $n \in \N$. The number $n + 1$ is a natural number.
3. Under the assignment that sends $x$ to $n$ and $y$ to $n + 1$, the atomic formula $x < y$ is satisfied, because $n < n + 1$.
4. By the clause for $\exists y$, step 3 gives $\mathcal{N} \models \exists y \, (x < y)[s[x \mapsto n]]$.
5. Since $n$ and $s$ were arbitrary, $\mathcal{N} \models \sigma$.

Falsity in $\mathcal{F}$:

1. Let $s$ be any assignment in $\mathcal{F}$, and consider the variant $s[x \mapsto 2]$.
2. The candidates for $y$ are $0$, $1$ and $2$. The pairs $(2, 0)$, $(2, 1)$ and $(2, 2)$ are not in the order relation, because $2$ is not less than $0$, $1$ or $2$.
3. So $\mathcal{F} \not\models \exists y \, (x < y)[s[x \mapsto 2]]$, by the clause for $\exists y$.
4. By the clause for $\forall x$, $\mathcal{F} \not\models \sigma[s]$. Since $s$ was arbitrary, $\sigma$ is false in $\mathcal{F}$, and $\mathcal{F} \models \neg \sigma$.

## Remarks

The example shows that the truth value of one sentence depends on the structure.
So $\sigma \in \operatorname{Th}(\mathcal{N})$ and $\neg \sigma \in \operatorname{Th}(\mathcal{F})$.
The sentence $\sigma$ is true in every linear order without a greatest element, such as $(\Z, <)$ and $(\Q, <)$.
It is false in every nonempty finite linear order, because the greatest element has no larger element.
If we reverse the quantifiers, the sentence $\exists y \, \forall x \, (x < y)$ is false in $\mathcal{N}$ and in $\mathcal{F}$, because no $y$ satisfies $y < y$.

## Explanations

### L1 human

The sentence says "for every number there is a bigger number".
For the numbers $0, 1, 2, 3, \ldots$ it is true: the number after $n$ is bigger than $n$.
For the numbers $0, 1, 2$ only, it is false: nothing in the list is bigger than $2$.
So the same sentence is true in one world and false in another.

### L2 human

We show that the reversed sentence $\exists y \, \forall x \, (x < y)$ is false in every structure in which $<$ is irreflexive.

1. Suppose some value $b$ of $y$ satisfies $\forall x \, (x < y)$.
2. Then the variant $x \mapsto b$ must satisfy $x < y$, so $b < b$.
3. This contradicts irreflexivity, so no witness $b$ exists, and the sentence is false.

The typical use is to separate finite and infinite linear orders by a sentence.
A trap is to read $\forall x \, \exists y$ as $\exists y \, \forall x$; the first allows $y$ to depend on $x$, the second does not.
