## Example

The claim is: every integer $n \ge 2$ has a [[prime|0SN0MAEKYX]] factor.
A student writes this argument.

1. Let $n \ge 2$, and let $p$ be the [[smallest prime factor|0VMWPGGG3C]] of $n$.
2. Then $p$ is prime and $p$ divides $n$.
3. So $n$ has a prime factor.

We check the argument.

1. Step 1 introduces "the smallest prime factor of $n$". This object exists only if the set of prime factors of $n$ is nonempty.
2. That set is nonempty exactly when $n$ has a prime factor, which is the claim.
3. So step 1 assumes the claim, and the argument is [[circular|~a3747f47]]. Steps 2 and 3 only restate step 1.

A correct proof uses the smallest divisor greater than $1$, whose existence does not need the claim.

1. Let $D$ be the set of divisors $d$ of $n$ with $d \ge 2$. The set $D$ is nonempty, because $n \in D$.
2. By the [[well-ordering principle|01BX15HSRR]], $D$ has a least element $q$.
3. Suppose that $q$ is not prime. Then $q = ab$ with $2 \le a < q$.
4. Then $a$ divides $q$, and $q$ divides $n$, so $a$ divides $n$. So $a \in D$ and $a < q$, which contradicts the choice of $q$.
5. So $q$ is prime, and $q$ divides $n$. This proves the claim.

## Remarks

The difference between the two proofs is the set from which we choose the least element.
The set $D$ of step 1 is nonempty for a reason that we can check, $n \in D$, while the set of prime factors is nonempty only by the claim.
The correct proof shows afterwards that $q$ is the smallest prime factor of $n$: every prime factor of $n$ lies in $D$, so it is at least $q$.
The same error occurs with every definite description: "the least element of $S$", "the limit of $(a_n)$" or "the solution of the equation" needs a proof of existence first.

## Explanations

### L1 human

Imagine a proof that a box contains a red ball which starts with "take the smallest red ball in the box".
That first sentence already assumes that a red ball is there.
The argument never looks inside the box.
A correct argument must first show that a red ball is there, and only then talk about the smallest one.

### L2 human

We apply the correct proof to $n = 91$.

1. The divisors of $91$ that are at least $2$ are $7$, $13$ and $91$, so $D = \{7, 13, 91\}$.
2. The least element is $q = 7$.
3. The number $7$ has no divisor $a$ with $2 \le a < 7$, so $7$ is prime.
4. So $91$ has the prime factor $7$, and $91 = 7 \cdot 13$.

The typical use of this proof shape is any claim "every object has a part with property $P$": take a least part with a weaker property that is easy to see, and prove that it has $P$.
A trap is to write "let $x$ be the least element with property $P$" before any element with property $P$ is known.
