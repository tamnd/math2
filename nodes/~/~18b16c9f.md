## Definition

Let $(X, \tau_X)$ and $(Y, \tau_Y)$ be [[topological spaces|~77bfcc55]] and let $f \colon X \to Y$ be a function.
The function $f$ is continuous when for each [[open set|~159c5927]] $V \in \tau_Y$, the [[preimage|0FGCFY1AZX]] $f^{-1}(V)$ is in $\tau_X$.

## Remarks

Equivalently, $f$ is continuous if and only if preimages of closed sets are closed, as in [[continuity via closed sets|~30e373fc]].
For metric spaces, this is the same as the epsilon-delta condition, by [[continuity via open sets|~6031a7b1]].
A function is continuous if and only if it is [[continuous at each point|~73d0eb71]].
Constant maps and identity maps are continuous, and the [[composition of continuous maps is continuous|~01184641]].

## Explanations

### L1 human

A continuous map does not tear the space apart: the points that go into an open set come from an open set.
This definition uses only open sets, so it works in each topological space.
