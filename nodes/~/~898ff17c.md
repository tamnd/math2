## Example

Let $L = \set{+, -, \cdot, 0, 1}$ and $\mathcal{M} = \mathcal{N} = (\C, +, -, \cdot, 0, 1)$.
Let $f \colon \set{i} \to \C$ be the map $f(i) = -i$.
We check that $f$ is a [[partial elementary map|~7e54c18a]].

1. Let $\sigma(a + bi) = a - bi$ be complex conjugation. It is a bijection of $\C$, and it is its own inverse.
2. $\sigma(z + w) = \sigma(z) + \sigma(w)$ and $\sigma(z w) = \sigma(z) \sigma(w)$ for all $z, w$, by direct computation with $i^2 = -1$. Also $\sigma(0) = 0$, $\sigma(1) = 1$ and $\sigma(-z) = -\sigma(z)$.
3. So $\sigma$ is an [[automorphism|XY6CJMDY5M]] of $\mathcal{M}$, and $\sigma(i) = -i = f(i)$.
4. Let $\varphi(x)$ be a formula. [[Automorphisms preserve formulas|NDTJ2E895C]], so $\C \models \varphi(i)$ iff $\C \models \varphi(\sigma(i))$ iff $\C \models \varphi(-i)$.
5. The domain of $f$ has one element, so formulas $\varphi(x_1, \dots, x_k)$ with all $x_j$ sent to $i$ reduce to formulas in one variable. So $f$ is partial elementary.

## Remarks

The example shows that $i$ and $-i$ have the same type in the complex field: no formula without parameters separates them.
The same holds for the two roots of any irreducible polynomial over $\Q$, for example $\sqrt{2}$ and $-\sqrt{2}$, because an isomorphism of the fields they generate extends to an automorphism of $\C$; see [[the model theory of algebraically closed fields|MT8TDVPBXB]].
In the real field, the map $\sqrt{2} \mapsto -\sqrt{2}$ is not partial elementary, because $\sqrt{2}$ is a square and $-\sqrt{2}$ is not.
So whether a map is partial elementary depends on the ambient structure.
If a constant symbol for $i$ is added to the signature, the map is no longer partial elementary, because the formula $x = i$ separates $i$ from $-i$.

## Explanations

### L1 human

The two square roots of $-1$ are $i$ and $-i$.
Swapping them everywhere is complex conjugation, and it keeps every sum and product correct: for example $(1 + i)(1 - i) = 2$, and after the swap $(1 - i)(1 + i) = 2$.
So any statement about $i$ written with addition and multiplication stays true when $i$ is replaced by $-i$.
For example, "$i$ times itself is $-1$" becomes "$-i$ times itself is $-1$", and both are true.

### L2 human

We check one formula with a quantifier.

1. Let $\varphi(x) = \exists z \, (z \cdot z = x)$, "$x$ has a square root".
2. $\varphi(i)$ holds: $z = \frac{1 + i}{\sqrt{2}}$ has $z^2 = \frac{1 + 2i + i^2}{2} = i$.
3. Then $\sigma(z) = \frac{1 - i}{\sqrt{2}}$ satisfies $\sigma(z)^2 = \frac{1 - 2i + i^2}{2} = -i$. So $\varphi(-i)$ holds too, as step 4 predicts.

The typical use is to show that two elements are indistinguishable by producing an automorphism that exchanges them.
A trap is to use an automorphism that moves a parameter of the formula; then the conclusion is about the moved parameter, not the original one.
