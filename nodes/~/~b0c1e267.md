## Example

Let $S_3$ be the [[symmetric group|0515A6D2Y1]] on $\{1, 2, 3\}$, of order $6$.
We compute its [[exponent|0ZDW0H0VX4]] from the [[orders|0WE2NHZJ7B]] of its elements.

1. The identity $e$ has order $1$.
2. The three transpositions $(1\,2)$, $(1\,3)$ and $(2\,3)$ have order $2$: each one is not $e$, and its square swaps two points twice, which gives $e$.
3. The two $3$-cycles $(1\,2\,3)$ and $(1\,3\,2)$ have order $3$. For $\sigma = (1\,2\,3)$, the power $\sigma^2 = (1\,3\,2)$ is not $e$, and $\sigma^3$ moves each point three steps around the cycle $1 \to 2 \to 3 \to 1$, so $\sigma^3 = e$. The same holds for $(1\,3\,2) = \sigma^{-1}$.
4. Steps 1 to 3 list all $1 + 3 + 2 = 6$ elements of $S_3$. So the element orders are $1, 2, 3$.
5. By [[the divisibility criterion|0F5QC101Q7]], $g^n = e$ for all $g \in S_3$ exactly when $1$, $2$ and $3$ divide $n$, that is, when $6 \mid n$.
6. So the least such positive $n$ is $\operatorname{lcm}(1, 2, 3) = 6$, and $\exp(S_3) = 6$.

## Remarks

The exponent $6$ equals the order $|S_3| = 6$, but $S_3$ is not cyclic, because no element has order $6$.
So the theorem that [[a finite abelian group with exponent equal to its order is cyclic|0MC0AQZSHE]] needs the abelian hypothesis.
The largest element order in $S_3$ is $3$, which is smaller than the exponent.
In a finite abelian group, the largest element order always equals the exponent, so $S_3$ also shows that this fails for non-abelian groups.
For every $n \geq 1$, the exponent of $S_n$ is $\operatorname{lcm}(1, 2, \ldots, n)$.
The reason is that a $k$-cycle has order $k$ for each $k \leq n$, and the order of every permutation is the lcm of its cycle lengths.
For example, $\exp(S_4) = \operatorname{lcm}(1, 2, 3, 4) = 12$.

## Explanations

### L1 human

The group $S_3$ is the set of the six ways to rearrange three objects.
Three of them swap two objects, and doing a swap twice gives back the start.
Two of them rotate the three objects, and doing a rotation three times gives back the start.
To bring every rearrangement back to the start with the same number of repetitions, we need a number that is a multiple of both $2$ and $3$.
The smallest such number is $6$.

### L2 human

We check the identity $g^6 = e$ on one element of each type.

1. For $\tau = (1\,2)$, we have $\tau^6 = (\tau^2)^3 = e^3 = e$.
2. For $\sigma = (1\,2\,3)$, we have $\sigma^6 = (\sigma^3)^2 = e^2 = e$.
3. The number $3$ does not work, since $\tau^3 = \tau \neq e$. The number $2$ does not work, since $\sigma^2 \neq e$.

The typical use of this example is as a counterexample: it separates "exponent equals order" from "cyclic" when the group is not abelian.
A trap: the exponent is not always the order of some element, and $S_3$ is the smallest group where this fails.
