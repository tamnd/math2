## Example

Let $\varphi = (p \lor q) \land \neg (p \land q)$, with the variables $p$ and $q$.
We compute the [[Boolean function|0X05GS525E]] $F_\varphi : \set{0,1}^2 \to \set{0,1}$, with $F_\varphi(a, b) = \bar v(\varphi)$ for an assignment $v$ with $v(p) = a$ and $v(q) = b$.

1. Row $(0, 0)$: $\bar v(p \lor q) = 0$, so $\bar v(\varphi) = \min(0, \cdot) = 0$.
2. Row $(0, 1)$: $\bar v(p \lor q) = 1$, $\bar v(p \land q) = 0$, $\bar v(\neg (p \land q)) = 1$, so $\bar v(\varphi) = 1$.
3. Row $(1, 0)$: in the same way, $\bar v(p \lor q) = 1$ and $\bar v(\neg (p \land q)) = 1$, so $\bar v(\varphi) = 1$.
4. Row $(1, 1)$: $\bar v(p \land q) = 1$, so $\bar v(\neg (p \land q)) = 0$ and $\bar v(\varphi) = 0$.
5. So $F_\varphi(a, b) = 1$ exactly when $a \neq b$: this is the function "exclusive or", also written $a \oplus b$.
6. Let $r$ be a third variable, and let $v$ and $w$ agree on $p$ and $q$. Since $r$ does not occur in $\varphi$, $\bar v(\varphi) = \bar w(\varphi)$, so the value of $r$ has no effect.

## Remarks

The example shows how a formula defines a function on $\set{0,1}^n$, one value for each row of its truth table.
The formula $\neg (p \leftrightarrow q)$ has the same table, so it is [[logically equivalent|0JMR2HM2N2]] to $\varphi$.
The formula $(p \land \neg q) \lor (\neg p \land q)$, the disjunctive normal form read from the rows $(1, 0)$ and $(0, 1)$, also has the same table.
There are $2^{2^2} = 16$ Boolean functions of two arguments, and exclusive or is one of them.
If we drop $\neg (p \land q)$, the formula $p \lor q$ has the value $1$ also in the row $(1, 1)$, so it defines inclusive or.

## Explanations

### L1 human

"Exclusive or" means "one or the other, but not both".
The formula says "$p$ or $q$, and not both $p$ and $q$".
We test it in the four cases.
When both letters are false, it is false.
When exactly one letter is true, it is true.
When both letters are true, "not both" fails, so it is false.

### L2 human

We read off a formula from a table, and we check it.

1. The table of exclusive or has the value $1$ in the rows $(1, 0)$ and $(0, 1)$.
2. The row $(1, 0)$ gives the conjunction $p \land \neg q$, and the row $(0, 1)$ gives $\neg p \land q$.
3. Their disjunction $\psi = (p \land \neg q) \lor (\neg p \land q)$ has the value $1$ exactly in these two rows.
4. So $F_\psi = F_\varphi$, and $\psi$ and $\varphi$ are equivalent.

The typical use is in circuit design: exclusive or adds two bits without the carry.
A trap is to read the English word "or" as exclusive; in logic, $\lor$ is inclusive and gives $1$ in the row $(1, 1)$.
