## Example

The claim is: the sum of two odd numbers is even.
A class of eight-year-olds knows that a number is even if its counters can be put in pairs with none left over, and odd if one counter is left over.
A student argues with counters.

1. The student lays out $7$ counters in pairs: three pairs and one single counter.
2. The student lays out $5$ counters in pairs: two pairs and one single counter.
3. The student pushes the two sets together. The pairs stay pairs, and the two single counters form a new pair.
4. Now all counters are in pairs, with none left over, so $7 + 5 = 12$ is even.
5. The student says: "Every odd number is pairs and one more. When you put two together, the two extra ones make a pair."

We check that the argument is a [[pre-formal proof|~66a80e3a]] by action.

6. Step 5 states the general structure: each odd number is "pairs and one". This is the class's definition of odd.
7. The action in step 3 does not depend on the number of pairs. It works for any two odd numbers.
8. The conclusion follows from the class's definition of even.

So the argument is an action proof, and it is a valid proof for the class.

## Remarks

The action proof matches the symbolic proof line by line.
"Pairs and one" is $2a + 1$; pushing together is $(2a + 1) + (2b + 1)$; the two single counters making a pair is $1 + 1 = 2$; and "all in pairs" is $2(a + b + 1)$.
The number of counters, $7$ and $5$, plays no role in the steps, which is what makes the action generic.

## Explanations

### L1 human

An odd number of counters can be put in pairs with one left over.
If two children each have an odd number of counters and they put them together, the two left-over counters make a pair.
So the total can be put in pairs with nothing left over, which means it is even.
This works no matter how many counters each child has.

### L2 human

1. Fix the class's definitions: even is "all in pairs", odd is "pairs and one".
2. Perform the action on one case, and say what happens to the pairs and to the single counters.
3. State why the action works for any odd numbers.
4. Translate, if the class is ready, into $(2a + 1) + (2b + 1) = 2(a + b + 1)$.

A trap is to stop after step 2.
Without step 3, the action is a check of one case, $7 + 5$, and not a proof.
