## Example

Let $t \colon \R^2 \to \R^2$ be the [[translation|087VJM5Q77]] by the vector $(1, 0)$, so $t(x, y) = (x + 1, y)$.
We check the two conditions of a [[linear map|0RJF668P1T]] and the property $T(0) = 0$.

1. Zero. $t(0, 0) = (1, 0) \ne (0, 0)$. A linear map sends $0$ to $0$, by the [[lemma on zero|~c10ad39e]], so $t$ is not linear.
2. Additivity. Take $u = v = (0, 0)$. Then $t(u + v) = (1, 0)$, but $t(u) + t(v) = (1, 0) + (1, 0) = (2, 0)$. So additivity fails.
3. Homogeneity. Take $a = 2$ and $v = (1, 1)$. Then $t(2v) = t(2, 2) = (3, 2)$, but $2\,t(v) = 2\,(2, 1) = (4, 2)$. So homogeneity fails.

Each condition fails, so $t$ is not a linear map.

## Remarks

The translation by a vector $w_0$ is linear only when $w_0 = 0$, since $t(0) = w_0$.
A translation keeps lengths and angles, so it is an isometry of the plane, but it is an [[affine map|0JF0TVYGWT]] and not a linear map.
Every affine map of $\R^n$ is a linear map followed by a translation, $x \mapsto Ax + b$.
In school algebra, $y = 2x + 1$ is called a "linear function"; in linear algebra it is affine, for the same reason as here.

## Explanations

### L1 human

Sliding every point of the plane one step to the right is a translation.
It moves the origin, and a linear map never moves the origin.
So a slide is not linear, even though it does not bend or stretch anything.

### L2 human

The quickest test for linearity is the image of $0$.
Here $t(0, 0) = (1, 0)$, so the test fails at once.
The trap is the other direction: a map that fixes $0$ can still fail to be linear, as the [[squaring map|~1498930f]] shows.
