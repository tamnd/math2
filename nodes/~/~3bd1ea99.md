## Example

We define a function $\psi'$ like the [[collapsing function|~766739ea]] $\psi$, but without $\Omega$.
Let $C'_0(\alpha) = \set{0, 1, \omega}$.
Let $C'_{n+1}(\alpha)$ add to $C'_n(\alpha)$ the sums, products and powers of its elements, and the values $\psi'(\xi)$ with $\xi \in C'_n(\alpha)$ and $\xi < \alpha$.
Let $C'(\alpha) = \bigcup_n C'_n(\alpha)$, and let $\psi'(\alpha)$ be the least ordinal not in $C'(\alpha)$.
We show that $\psi'(\alpha) = \varepsilon_\alpha$ for $\alpha \le \zeta_0$, and $\psi'(\alpha) = \zeta_0$ for every $\alpha \ge \zeta_0$.

1. For $\alpha \le \zeta_0$, the proof of part (a) of the [[small values|~19a7c469]] works without change. The alternative "at least $\Omega$" in the upper bound never occurs, because no element of $C'(\alpha)$ is uncountable.
2. So $\psi'(\alpha) = \varepsilon_\alpha$ for $\alpha \le \zeta_0$, and in particular $\psi'(\zeta_0) = \zeta_0$.
3. Let $\alpha \ge \zeta_0$. Every $\beta < \zeta_0$ is in $C'(\zeta_0)$, and $C'(\zeta_0) \subseteq C'(\alpha)$. So $\psi'(\alpha) \ge \zeta_0$.
4. We show by induction on $n$ that every element of $C'_n(\alpha)$ is below $\zeta_0$. The generators $0, 1, \omega$ are below $\zeta_0$.
5. The ordinal $\zeta_0$ is an [[epsilon number|PQSHBKCE7V]], so it is closed under sums, products and powers.
6. A new value $\psi'(\xi)$ has $\xi \in C'_n(\alpha)$, so $\xi < \zeta_0$ by the induction hypothesis. Then $\psi'(\xi) = \varepsilon_\xi < \zeta_0$ by step 2.
7. So $\zeta_0 \notin C'(\alpha)$, and $\psi'(\alpha) = \zeta_0$.

The function $\psi'$ is not a collapsing function: it has no uncountable generator, and its values never pass $\zeta_0$, however large the argument is.

## Remarks

The example shows why the uncountable generator is needed.
Without $\Omega$, the closure sets contain only countable ordinals below $\zeta_0$, and the large arguments of $\psi'$ cannot be named inside $C'(\alpha)$.
So the large arguments have no effect.
With $\Omega$ as a generator, the term $\psi(\Omega)$ names $\zeta_0$, and the function passes $\zeta_0$ at the argument $\Omega + 1$.
If we add $\zeta_0$ itself as a generator instead of $\Omega$, the function stops at the next fixed point $\zeta_1$, by the same proof.
So no countable set of generators avoids the problem: each one gives a new stopping point.

## Explanations

### L1 human

Imagine a machine that names ordinals and is allowed to use its own earlier answers.
Without a huge helper number, the machine gets stuck at one ordinal, $\zeta_0$.
It cannot name $\zeta_0$, and every later step only uses names below $\zeta_0$.
So feeding it larger inputs does not help.
The huge number $\Omega$ is what lets the real collapsing function escape this trap.

### L2 human

We compare $\psi'(\zeta_0 + 1)$ and $\psi(\zeta_0 + 1)$.

1. For $\psi'$, the argument $\zeta_0$ is not in $C'(\zeta_0 + 1)$, by step 4. So $\psi'(\zeta_0)$ is not available, and $\psi'(\zeta_0 + 1) = \zeta_0$.
2. For $\psi$, the argument $\zeta_0$ is also not in $C(\zeta_0 + 1)$, and $\psi(\zeta_0 + 1) = \zeta_0$ by the small values.
3. For $\psi$, the argument $\Omega + 1$ is in $C(\Omega + 1)$, and $\psi(\Omega + 1) = \varepsilon_{\zeta_0 + 1}$.
4. For $\psi'$, no argument gives a value above $\zeta_0$.

The typical use of this example is to explain the role of $\Omega$ in a first course on ordinal notations.
The trap is to think that a large argument alone makes a large value: the argument must also be nameable in the closure set.
