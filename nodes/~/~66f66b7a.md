## Example

Let $\mathcal{L}_T$ be the language of arithmetic with a unary predicate $T$.
The [[diagonal lemma|3PRW76471J]] applied to $T(x)$ gives a sentence $\tau$ with $\mathsf{Q} \vdash \tau \leftrightarrow T(\ulcorner \tau \urcorner)$.
We take the sentence $\tau := \exists y\,(D(\underline{k}, y) \wedge T(y))$ built in the [[proof of the diagonal lemma|SFPSB6JPTC]].
This $\tau$ is a *truth-teller*: it says of itself that it is true.
We check that it is consistent either way, and that it is a [[truth-value gap|4CBCWZQZ12]] in the least Kripke fixed point.

1. *Classical model with $\tau$ true.* Let $E := \{\ulcorner \tau \urcorner\}$, and expand the [[standard model|WP27CABPA4]] to $(\mathcal{N}, E)$, with $E$ as the extension of $T$.
2. $(\mathcal{N}, E)$ is a model of $\mathsf{Q}$ in $\mathcal{L}_T$, so it satisfies $\tau \leftrightarrow T(\ulcorner \tau \urcorner)$. Since $\ulcorner \tau \urcorner \in E$, it satisfies $T(\ulcorner \tau \urcorner)$, and hence $\tau$.
3. So $(\mathcal{N}, E)$ satisfies the instance $T(\ulcorner \tau \urcorner) \leftrightarrow \tau$ of the [[naive truth schema|~34d21c75]], with both sides true.
4. *Classical model with $\tau$ false.* Let $E := \emptyset$. As in step 2, $(\mathcal{N}, \emptyset)$ satisfies $\neg T(\ulcorner \tau \urcorner)$ and $\neg \tau$.
5. So $(\mathcal{N}, \emptyset)$ also satisfies the instance for $\tau$, with both sides false.
6. Both structures satisfy all axioms of $\mathsf{PA}$ with induction for $\mathcal{L}_T$, since induction holds in every expansion of $\mathcal{N}$. So both $\tau$ and $\neg \tau$ are consistent with $\mathsf{PA}$ plus the T-sentence for $\tau$.
7. *Kripke's theory.* With this form of $\tau$, the strong Kleene values of $\tau$ and $T(\ulcorner \tau \urcorner)$ agree in every partial model. The reason is that $D(\underline{k}, m)$ is true only for $m = \ulcorner \tau \urcorner$.
8. In [[Kripke's construction|~1dd87a57]] from the empty interpretation, step 7 shows that $\tau$ never gets a value. So $\tau$ is ungrounded, and it is a gap in the least fixed point.
9. *Other fixed points.* There are fixed points in which $\tau$ is true and fixed points in which $\tau$ is false. The [[proof of Kripke's theorem|~d1bbd010]] constructs them.

## Remarks

The truth-teller is the opposite of the [[liar paradox|~005ac188]].
The liar has no consistent classical value, while the truth-teller has two.
In Kripke's theory both are gaps in the least fixed point, but for different reasons.
The liar is a gap in every fixed point, and the truth-teller only in some.
The SEP entry on revision theory states that Kripke's semantics has three acceptable interpretations for the truth-teller: true, false and neither.
In the [[revision theory|~721e1cff]], the truth-teller keeps the value of the initial hypothesis forever; see [[its revision sequences|~860cb113]].
So it is neither categorically true nor categorically false, and the SEP entry stresses that this differs from saying it is neither true nor false.
If we replace $T(x)$ by $T(x) \vee \neg T(x)$, the new sentence is still ungrounded.
But it is true in every fixed point in which it has a value.

## Explanations

### L1 human

The sentence "This sentence is true" is the truth-teller.
If we call it true, then it says something correct, so nothing goes wrong.
If we call it false, then it says something wrong, so again nothing goes wrong.
Both choices are consistent, and nothing in the world decides between them.
So many logicians say that the sentence is not grounded: its truth does not come from any fact outside the sentence.

### L2 human

1. Suppose $T$ is interpreted by $E = \{\ulcorner \tau \urcorner\}$. Then $T(\ulcorner \tau \urcorner)$ is true.
2. The diagonal lemma gives $\tau \leftrightarrow T(\ulcorner \tau \urcorner)$, so $\tau$ is true.
3. So $\ulcorner \tau \urcorner \in E$ agrees with the truth of $\tau$: the choice is stable.
4. The same check with $E = \emptyset$ gives a stable choice in which $\tau$ is false.
5. For the liar $\lambda \leftrightarrow \neg T(\ulcorner \lambda \urcorner)$, neither choice is stable: with $\ulcorner \lambda \urcorner \in E$, the sentence $\lambda$ is false, and with $\ulcorner \lambda \urcorner \notin E$, it is true.

The typical use of the truth-teller is to test a theory of truth: a good theory must say why this sentence has no determined value.
The trap is to think that only paradoxical sentences are a problem.
The truth-teller is consistent, but it shows that the facts alone do not determine its truth.
