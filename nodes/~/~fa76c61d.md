## Example

The [[intermediate value theorem|00KAFBR32E]] says: if $f \colon [a, b] \to \mathbb{R}$ is continuous and $y$ lies between $f(a)$ and $f(b)$, then $f(c) = y$ for some $c \in [a, b]$.
The picture argument says: the graph is an unbroken curve from one height to another, so it must pass through each height in between.
We show that this argument is not [[rigorous|~cc99a1f7]], and we locate the property that a rigorous proof must use.

1. We repeat the picture argument with the rational numbers $\mathbb{Q}$ in place of $\mathbb{R}$. Let $g(x) = x^2 - 2$ for rational $x$ with $1 \le x \le 2$.
2. The function $g$ is continuous on these rational numbers, because it is a polynomial, and the epsilon-delta proof for polynomials uses only the arithmetic of the numbers.
3. We compute the end values: $g(1) = 1 - 2 = -1 < 0$ and $g(2) = 4 - 2 = 2 > 0$.
4. Suppose that $g(c) = 0$ for a rational $c$. Then $c^2 = 2$, so $c = \sqrt{2}$ or $c = -\sqrt{2}$.
5. The number $\sqrt{2}$ is [[irrational|0DZGSDHD92]], and so is $-\sqrt{2}$. This contradicts step 4, so $g$ has no rational zero.
6. So the statement "a continuous function that changes sign has a zero" fails over $\mathbb{Q}$. The picture of step 1 looks the same over $\mathbb{Q}$ and over $\mathbb{R}$, so the picture cannot be the reason that the theorem holds over $\mathbb{R}$.
7. The difference between $\mathbb{Q}$ and $\mathbb{R}$ is the [[completeness axiom|0AXWET80YW]]: each nonempty set of real numbers with an upper bound has a least upper bound. The set $\{x \in \mathbb{Q} : x^2 < 2\}$ has upper bounds in $\mathbb{Q}$, but no least one.
8. [[The rigorous proof|P54346XMQQ]] takes $c$ as the least upper bound of the set of points where $f(x) < y$. It uses completeness at this one step, and it uses continuity to show $f(c) \ge y$ and $f(c) \le y$.

## Remarks

The example shows the main use of rigour: it finds the hypothesis on which a result depends.
The picture hides the completeness of $\mathbb{R}$, and the rigorous proof names it.
This is also why the theorem fails for functions on $\mathbb{Q}$, and why it holds for real functions on any interval.

The example also shows a change in the standard of proof.
Earlier authors took the result as evident and gave no proof.
Bernard Bolzano gave a proof in 1817, and Augustin-Louis Cauchy gave the modern statement and a proof in 1821.
A complete account of the real numbers, with completeness as a theorem or an axiom, came later in the 19th century, for example with [[Dedekind cuts|0G3RRM41X9]].

If we change the function to $h(x) = x^2 - 4$ on the rational interval $[1, 3]$, the zero $x = 2$ is rational, and the conclusion holds.
So one rational example can satisfy the conclusion by chance, and only a proof shows which functions must satisfy it.

## Explanations

### L1 human

Draw a line from a point below a river to a point above it without lifting the pen.
It seems that the line must cross the river.
Mathematicians wanted to know why this is true, and not only that it looks true.
They found that it depends on the number line having no holes.
On a number line made only of fractions there are holes, for example at the square root of $2$.
A curve can jump over such a hole without any break that we can see, so the crossing can fail.
The rigorous proof uses exactly the fact that the real number line has no holes.

### L2 human

We check the fact of step 7 for the set $A = \{x \in \mathbb{Q} : x > 0 \text{ and } x^2 < 2\}$.

1. The set $A$ is nonempty, since $1 \in A$, and $2$ is an upper bound, since $x \ge 2$ gives $x^2 \ge 4$.
2. Let $u$ be a rational upper bound of $A$. Then $u \ge 1 > 0$, since $1 \in A$, and $u^2 \neq 2$, because $\sqrt{2}$ is irrational.
3. Suppose $u^2 < 2$. The rational number $v = (2u + 2)/(u + 2)$ satisfies $v - u = (2 - u^2)/(u + 2) > 0$.
4. We compute $v^2 - 2 = \big((2u + 2)^2 - 2(u + 2)^2\big)/(u + 2)^2 = 2(u^2 - 2)/(u + 2)^2 < 0$. So $v \in A$ and $v > u$, which contradicts that $u$ is an upper bound.
5. So $u^2 > 2$. Then the same $v$ satisfies $v < u$ and $v^2 > 2$, by the formulas of steps 3 and 4 with the signs reversed.
6. Each $x \in A$ has $x^2 < 2 < v^2$, so $x < v$. Thus $v$ is a smaller rational upper bound, and $A$ has no least rational upper bound.

The typical use of this check is to show that a theorem of analysis needs completeness.
A trap is to think that the theorem fails over $\mathbb{Q}$ because $g$ is "not continuous" there; it is continuous, and the failure comes from the holes in $\mathbb{Q}$.
