## Summary

*Phase semantics* interprets the formulas of [[linear logic|2P2184B6HE]] as subsets of a commutative [[monoid|0N6R902FG1]], called *facts*; see [[the definition|~09c29208]].
A *phase space* is a commutative monoid $M$ with a chosen subset $\bot$, and the negation of a set $X$ is the set $X^{\perp}$ of the elements that send all of $X$ into $\bot$.
Linear logic is [[sound and complete|~3257a7fb]] for phase semantics.
The completeness proof uses only cut-free derivations, so it also proves that cut is admissible.

## Motivation

A formula is read as the set of its "proofs" or "phases", and the monoid product combines two of them into one.
The tensor $A \otimes B$ is then the closure of the set of products $a b$ with $a$ in $A$ and $b$ in $B$.
Since the monoid need not satisfy $m m = m$, a phase of $A$ need not give a phase of $A \otimes A$, and contraction fails.
Phase models give short proofs that a sequent is not derivable.

## Notation

We write the monoid product as $m n$ or $m + n$ and the unit as $1$ or $0$, as fits the example.
For subsets $X$ and $Y$ of $M$, $X Y = \set{x y \mid x \in X, y \in Y}$.
$A^*$ is the fact that interprets the formula $A$.

## Remarks

### Examples

1. The group $\mathbb{Z}/2$ with $\bot = \set{0}$ is a [[phase space in which contraction fails|~d55f75f4]].
2. The one-point monoid with $\bot = \emptyset$ gives the [[two-valued truth tables|~a7b7e75a]].
3. The monoid $(\mathbb{N}, +)$ with $\bot = \set{1}$ has a [[subset that is not a fact|~dc8ad7b9]].
4. The *syntactic phase space* is the monoid of finite multisets of formulas, with $\bot$ the set of cut-free derivable sequents.

### Non-examples

A Kripke model of intuitionistic logic is not a phase space: its sets of worlds are closed under a preorder, not under a product.
A set $X \subseteq M$ with $X \neq X^{\perp\perp}$ cannot be the value of a formula.

### Basic properties

1. $X \subseteq X^{\perp\perp}$, and $X \subseteq Y$ implies $Y^{\perp} \subseteq X^{\perp}$.
2. $X^{\perp\perp\perp} = X^{\perp}$, so every set $X^{\perp}$ is a fact.
3. The intersection of facts is a fact, so the facts form a complete lattice.
4. A sequent $\vdash A^{\perp}, B$ is valid in a phase model if and only if $A^* \subseteq B^*$.

### History

The SEP entry on linear logic states that phase semantics is due to Girard, in the 1987 paper cited here.
The same entry states that Okada used phase semantics to give semantic proofs of cut elimination for first-order and higher-order linear logic.

### Common errors

The value of $A \otimes B$ is $(A^* B^*)^{\perp\perp}$, not $A^* B^*$; the product of two facts need not be a fact.
The value of $A \oplus B$ is $(A^* \cup B^*)^{\perp\perp}$, not $A^* \cup B^*$.

## Explanations

### L1 human

Think of a set of moves that can be combined, such as numbers under addition.
Each formula becomes a set of moves, and "and" combines a move for $A$ with a move for $B$.
A set $\bot$ of "bad" results decides which moves fit together.

### L2 human

We compute in $M = \mathbb{Z}/2$ with $\bot = \set{0}$.

1. $\set{0}^{\perp} = \set{m \mid m + 0 = 0} = \set{0}$, and $\set{1}^{\perp} = \set{m \mid m + 1 = 0} = \set{1}$.
2. $\emptyset^{\perp} = M$ and $M^{\perp} = \emptyset$, so all four subsets are facts.
3. With $p^* = \set{1}$, the value of $p \otimes p$ is $\set{1 + 1}^{\perp\perp} = \set{0}$.
4. Since $p^* \not\subseteq (p \otimes p)^*$, the sequent $p \vdash p \otimes p$ is not valid.

The typical use of phase semantics is to show that a sequent is not derivable, by a small model.
A trap: $\set{0}$ here is the value of the constant $\bot$, which is a fact; it is not the empty fact $0^* = M^{\perp} = \emptyset$.

### L3 human

Phase semantics is an instance of the residuated lattice semantics of substructural logics.
The facts of a phase space form a commutative residuated lattice with an involutive negation, and every bounded lattice of this kind gives a model of MALL.
Okada's method turns completeness into a proof of cut admissibility: the syntactic phase space is built from cut-free derivations only.
