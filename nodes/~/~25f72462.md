## Example

A [[normal function|ERTAM0SFVB]] is a function $f$ on ordinals that is strictly increasing and continuous: $f(\lambda) = \sup_{\xi < \lambda} f(\xi)$ for limit ordinals $\lambda$.
We show that [[Buchholz's function|E7WEFRMQTB]] $\psi_0$ is not a normal function.

1. By the [[small values|~7c91f19c]], $\psi_0(\varepsilon_0) = \omega^{\varepsilon_0} = \varepsilon_0$.
2. By the same node, $\psi_0(\Omega) = \varepsilon_0$.
3. We have $\varepsilon_0 < \Omega$, because $\varepsilon_0$ is countable and $\Omega$ is the first uncountable ordinal.
4. So $\psi_0(\varepsilon_0) = \psi_0(\Omega)$ although $\varepsilon_0 < \Omega$, and $\psi_0$ is not strictly increasing.
5. A second failure: $\psi_0(\varepsilon_0 + 1) = \varepsilon_0$, also by the small values, while a strictly increasing function $f$ has $f(\alpha + 1) > f(\alpha)$.

So the condition of a normal function that fails is strict monotonicity.

## Remarks

The function $\psi_0$ is weakly increasing, and it is continuous at many limits, for example $\psi_0(\omega) = \omega^\omega = \sup_n \psi_0(n)$.
On the arguments $\alpha$ with $\alpha \in C_0(\alpha)$, Buchholz's function is strictly increasing, and these are the arguments used in notations.
The restriction $\alpha \mapsto \omega^\alpha$ to $\alpha \le \varepsilon_0$ is a normal function on that interval, so the failure only starts at arguments that cannot be named.
The same failure occurs for every [[collapsing function|~766739ea]], because each one maps an uncountable set of arguments into countable ordinals.

## Explanations

### L1 human

A normal function is one that always goes up when its input goes up, and has no jumps at limits.
Buchholz's function $\psi_0$ goes up at first, giving $1$, $\omega$, $\omega^2$, and so on.
But between $\varepsilon_0$ and the huge ordinal $\Omega$ it stays at the same value $\varepsilon_0$.
So it does not always go up, and it is not a normal function.

### L2 human

We find the first argument where strict monotonicity fails.

1. For $\alpha < \varepsilon_0$ we have $\psi_0(\alpha) = \omega^\alpha$, and $\alpha \mapsto \omega^\alpha$ is strictly increasing.
2. At $\alpha = \varepsilon_0$ we get $\psi_0(\varepsilon_0) = \varepsilon_0$.
3. At $\alpha = \varepsilon_0 + 1$ we get $\psi_0(\varepsilon_0 + 1) = \varepsilon_0$ again.
4. So the first failure is the pair $\varepsilon_0 < \varepsilon_0 + 1$.

The typical use of this fact is in the comparison of terms: one may conclude $\psi_0(\alpha) < \psi_0(\beta)$ from $\alpha < \beta$ only when both arguments are in normal form.
The trap is to apply the rule to arguments such as $\varepsilon_0 + 1$, which are not in $C_0(\varepsilon_0 + 1)$.
