## Example

The [[Ackermann function|N470JF7ZJX]] $A : \N \times \N \to \N$ is given by
$$A(0, n) = n + 1, \qquad A(m + 1, 0) = A(m, 1), \qquad A(m + 1, n + 1) = A(m, A(m + 1, n)).$$
We show that no term $t(x, y)$ of [[primitive recursive arithmetic|~ca566935]] has the value $A(m, n)$ at $x = m$, $y = n$ for all $m$ and $n$.
Here the value of a term in $\mathfrak{N}$ is computed with the defining equations of its function symbols.

1. Every function symbol of the [[definition|~c6872ee7]] denotes a [[primitive recursive function|5NVA2JRHPV]]. We use [[structural induction|12MQ2NJ29A]] on the clauses that generate the symbols: $0$, $S$ and $\pi^n_i$ denote initial functions, and $\mathrm{Comp}$ and $\mathrm{Rec}$ denote composition and primitive recursion of the functions that their parts denote.
2. Every term $t(x_1, \ldots, x_k)$ denotes a primitive recursive function of $x_1, \ldots, x_k$. We use induction on terms: a variable $x_i$ denotes the projection $\pi^k_i$, and $f(t_1, \ldots, t_m)$ denotes the composition of the function of $f$ with the functions of $t_1, \ldots, t_m$.
3. The Ackermann function is not primitive recursive, by the [[theorem on the Ackermann function|97QF3KHSBY]].
4. Suppose some term $t(x, y)$ had the value $A(m, n)$ for all $m$ and $n$. By step 2, $A$ would be primitive recursive, which contradicts step 3.

So $\mathsf{PRA}$ has no term for the Ackermann function, although $A$ is computable.

## Remarks

The relation "$s$ codes a correct finite table of values of $A$ that ends with $A(m, n) = v$" is primitive recursive.
So $\mathsf{PRA}$ can state, for each fixed $m$, $n$ and $v$, that $A(m, n) = v$, and it proves this statement when it is true, by checking the table.
What $\mathsf{PRA}$ cannot do is state that $A$ is total: the sentence $\forall m \, \forall n \, \exists v \, \exists s \, (\ldots)$ has an unbounded $\exists$, and its free-variable form needs a term for the witness $v$ as a function of $m$ and $n$.
The same holds for $\mathsf{I}\Sigma_1$: its provably total functions are exactly the primitive recursive functions, so it does not prove that $A$ is total.
[[Peano arithmetic|~b3b2d1f3]] proves that $A$ is total, by induction on $m$ of a formula with a $\forall n \, \exists v$ inside; $\mathsf{I}\Sigma_2$ already suffices.
On [[Tait's thesis|~ca566935]], this places the Ackermann function outside finitist mathematics.
If we replace $A$ by any one row $n \mapsto A(m, n)$ with $m$ fixed, the answer changes: each row is primitive recursive, so each row has a term in $\mathsf{PRA}$.

## Explanations

### L1 human

The Ackermann function is a rule for computing numbers that grow faster than any tower of powers.
For example, $A(1, n) = n + 2$, $A(2, n) = 2n + 3$, and $A(4, 2)$ already has nearly twenty thousand digits.
Every rule of primitive recursive arithmetic is built by "do this step $n$ times", with a number of repetitions fixed in advance.
The Ackermann function cannot be built in this way, so the system has no name for it.

### L2 human

We check that each row of $A$ is primitive recursive, for the first three rows.

1. $A(0, n) = n + 1 = S(n)$, the successor.
2. $A(1, 0) = A(0, 1) = 2$, and $A(1, n + 1) = A(0, A(1, n)) = A(1, n) + 1$. By induction on $n$, $A(1, n) = n + 2$.
3. $A(2, 0) = A(1, 1) = 3$, and $A(2, n + 1) = A(1, A(2, n)) = A(2, n) + 2$. By induction on $n$, $A(2, n) = 2n + 3$.
4. In general, row $m + 1$ is defined from row $m$ by primitive recursion on $n$, so each row has a function symbol of $\mathsf{PRA}$.

The typical use of this example is as the test case for any claimed characterization of finitist or provably total functions.
A trap is to conclude from step 4 that $A$ is primitive recursive: the definition of row $m + 1$ depends on $m$, and no single definition covers all rows.
