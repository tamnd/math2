## Example

Let $B$ be a set.
We show that the [[empty set|0ECVK59Y03]] $\varnothing$ is a [[subset|0FE8Q5S42Y]] of $B$, and we show that the statement is a [[vacuous truth|0V4QXPGJQK]].

1. By the definition of a subset, $\varnothing \subseteq B$ means $\forall x \, (x \in \varnothing \to x \in B)$.
2. Let $x$ be any object. The empty set has no elements, so the statement $x \in \varnothing$ is false.
3. An [[implication|0ZNX6DQ3EJ]] with a false antecedent is true. So $x \in \varnothing \to x \in B$ is true for this $x$.
4. Step 3 holds for every object $x$, so $\forall x \, (x \in \varnothing \to x \in B)$ is true.
5. So $\varnothing \subseteq B$. The truth of step 4 does not depend on $B$: the consequent $x \in B$ is never checked, and this is what makes the truth vacuous.

The same fact has a proof by counterexample search.
A counterexample to $\varnothing \subseteq B$ would be an element $x \in \varnothing$ with $x \notin B$.
There is no element of $\varnothing$, so there is no counterexample.

## Remarks

The example shows how the definition of a subset, with the implication inside the universal quantifier, decides the case of the empty set without a separate rule.

Three consequences follow.

- With $B = \varnothing$, we get $\varnothing \subseteq \varnothing$.
- The empty set is the only set that is a subset of every set. If $E \subseteq B$ for every set $B$, then $E \subseteq \varnothing$, so $E$ has no elements, and $E = \varnothing$.
- A set with $n$ elements has $2^n$ subsets, and $\varnothing$ is one of them. For $\{1, 2\}$ the four subsets are $\varnothing$, $\{1\}$, $\{2\}$ and $\{1, 2\}$.

If we replace $\varnothing$ by a nonempty set $A$, then step 2 fails: for $x \in A$ the antecedent is true, and $x \in B$ must be checked.
For example, $\{1\} \subseteq B$ holds exactly when $1 \in B$.

## Explanations

### L1 human

A set $A$ is inside a set $B$ when every member of $A$ is also a member of $B$.
The empty set has no members at all.
So there is no member of the empty set that could fail to be in $B$.
That is why the empty set is inside every set, even inside the set $\{7\}$ and inside itself.

### L2 human

We check $\varnothing \subseteq \{1, 2, 3\}$ and $\{0\} \not\subseteq \{1, 2, 3\}$ with the same definition.

1. For $\varnothing$: each instance $x \in \varnothing \to x \in \{1, 2, 3\}$ has a false antecedent, so it is true. So $\varnothing \subseteq \{1, 2, 3\}$.
2. For $\{0\}$: the instance $x = 0$ has the true antecedent $0 \in \{0\}$ and the false consequent $0 \in \{1, 2, 3\}$. So this instance is false, and $\{0\} \not\subseteq \{1, 2, 3\}$.

The typical use of this fact is in proofs about all subsets of a set, such as the count $2^n$, where the empty subset must be included.
A trap is to confuse $\varnothing \subseteq B$ with $\varnothing \in B$: the first is always true, and the second holds only when the empty set is an element of $B$, as in $B = \{\varnothing\}$.
