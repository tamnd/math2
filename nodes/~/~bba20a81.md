## Definition

Let $T$ be a complete theory with [[monster model|EYTTQZ0E1S]] $\mathbb{M}$, and let $\alpha$ be a small ordinal, finite or infinite.

1. A *$\emptyset$-type-definable equivalence relation* on $\alpha$-tuples is an [[equivalence relation|0G8VEZ3WTK]] $E$ on $\mathbb{M}^\alpha$ that is the set of realizations of a partial [[type|9V71Q3SD1G]] $\pi(\bar x, \bar y)$ over $\emptyset$.
2. A *hyperimaginary* is a class $e = \bar a / E$ of such a relation $E$, for some $\bar a \in \mathbb{M}^\alpha$.
3. An [[automorphism|DSQ17TNW1C]] $\sigma$ of $\mathbb{M}$ acts by $\sigma(\bar a / E) = \sigma(\bar a) / E$. This is well defined because $\pi$ has no parameters.
4. The hyperimaginary $e$ is *in the definable closure* of a set $A$ if every automorphism fixing $A$ pointwise fixes $e$. Two hyperimaginaries, or a hyperimaginary and a set, are *interdefinable* if each is in the definable closure of the other.
5. The hyperimaginary $e$ is *eliminable* if it is interdefinable with a sequence of [[imaginary elements|~b9c87290]]. The theory $T$ *eliminates hyperimaginaries* if every hyperimaginary is eliminable.
6. The relation $E$ is *bounded* if it has fewer than $|\mathbb{M}|$ classes. A hyperimaginary of a bounded relation is a *bounded hyperimaginary*.

## Notation

Hyperimaginaries are written $e, d, \dots$, and $\operatorname{dcl}(e)$ and $\operatorname{bdd}(e)$ denote their definable and bounded closures.
When $\alpha$ is finite and $E$ is given by one formula, $e$ is an imaginary, so imaginaries are hyperimaginaries.

## Remarks

A bounded relation $E$ on $\alpha$-tuples has at most $2^{|T| + |\alpha|}$ classes, since the class of $\bar a$ is then determined by the type of $\bar a$ over any small model.
So boundedness does not depend on the monster model.

Example: the intersection of a decreasing chain of definable equivalence relations, each splitting every class into two, gives an eliminable bounded hyperimaginary; see [[this example|~fc1ebceb]].

Non-example: in a real closed field, "at finite distance" is an equivalence relation that is not type-definable, so its classes are not hyperimaginaries; see [[this example|~decee435]].

## Explanations

### L1 human

Imaginary elements are names for classes of a rule given by one formula.
Hyperimaginaries are names for classes of a rule given by infinitely many formulas at once.
For example, two numbers are "infinitely close" if they differ by less than $1$, less than $\tfrac12$, less than $\tfrac13$, and so on for every fraction $1/n$.
Each condition is one formula, and the rule is the list of all of them together.

### L2 human

We check that "infinitely close" in a non-archimedean real closed field is a $\emptyset$-type-definable equivalence relation.

1. Take $\pi(x, y) = \set{-1/n < x - y < 1/n : n \ge 1}$, with each $1/n$ a $\emptyset$-definable element.
2. Reflexivity and symmetry hold, since $|x - x| = 0$ and $|x - y| = |y - x|$.
3. For transitivity, use the formula for $2 n$ twice: $|x - z| \le |x - y| + |y - z| < 1/n$.
4. So $\pi$ defines an equivalence relation, and its classes are hyperimaginaries.

The typical use is to name the class of a tuple for a relation that only compactness produces.
A trap is to expect the class to be coded by one imaginary: here, the relation is not definable.
