## Proof

Throughout, "increasing tuple" means a tuple $(i_1, \dots, i_n)$ with $i_1 < \dots < i_n$, and subsets of an ordered set are listed in increasing order.

### Step 1: a finite part of part 1

Let $\mathcal{M}$ and $(b_n)_{n \in \N}$ be as in part 1, and let $I$ be an infinite linear order.
Let $L^+$ be $L$ with new constants $c_m$ for $m \in M$ and $d_i$ for $i \in I$.
Let $\Sigma$ be the set of these $L^+$-sentences:

- the elementary diagram of $\mathcal{M}$, so that a model is an elementary extension of $\mathcal{M}$ by the [[diagram lemmas|EP5E317TNW]];
- $d_i \ne d_j$ for $i \ne j$ in $I$;
- $\varphi(d_{\bar{\imath}}) \leftrightarrow \varphi(d_{\bar{\jmath}})$ for each $L$-formula $\varphi(x_1, \dots, x_n)$ and increasing $\bar{\imath}, \bar{\jmath}$ in $I$;
- $\varphi(d_{\bar{\imath}})$ for each $L$-formula $\varphi$ true at all increasing tuples of $(b_n)$, and increasing $\bar{\imath}$.

Let $\Sigma_0 \subseteq \Sigma$ be finite.
It mentions finitely many formulas $\varphi_1, \dots, \varphi_t$ in the third group, each with at most $r$ free variables $x_1, \dots, x_r$, and finitely many $d_i$, say for $i$ in a set $I_0$ with $N$ elements.

### Step 2: the Ramsey argument

1. Color each $r$-element set $\set{n_1 < \dots < n_r} \subseteq \N$ by the vector of truth values in $\mathcal{M}$ of $\varphi_l(b_{n_1}, \dots, b_{n_{s_l}})$, for $l = 1, \dots, t$, where $s_l$ is the number of variables of $\varphi_l$. There are at most $2^t$ colors.
2. By [[Ramsey's theorem for s-subsets|YSZ82MRXT8]], applied to $\set{1, \dots, R}$ with $R$ large, some $H \subseteq \N$ with $N + r$ elements has all its $r$-sets of one color.
3. Let $h_1 < \dots < h_N$ be the first $N$ elements of $H$. Each increasing $s_l$-tuple from them extends to an $r$-set in $H$ by elements above $h_N$.
4. The color of that $r$-set fixes the truth value of $\varphi_l$ at the tuple. So $\varphi_l$ has one truth value at all increasing $s_l$-tuples from $h_1, \dots, h_N$.
5. Interpret $c_m$ as $m$, and $d_i$ for $i \in I_0$ as $b_{h_k}$, where $i$ is the $k$-th element of $I_0$. Interpret the other $d_i$ arbitrarily.
6. This structure satisfies $\Sigma_0$: the diagram holds in $\mathcal{M}$, the $b_n$ are distinct, step 4 gives the third group, and the fourth group holds because each $b_{h_k}$ is a member of $(b_n)$.

### Step 3: compactness and part 2

By the [[compactness theorem|1NR3HAWG9D]], $\Sigma$ has a model.
Its reduct to $L$ is an elementary extension $\mathcal{N}$ of $\mathcal{M}$, so $\mathcal{N} \equiv \mathcal{M}$.
The elements $a_i := d_i^{\mathcal{N}}$ form an injective [[indiscernible sequence|~cc1977c7]] by the second and third groups, and the fourth group gives the last claim of part 1.
For part 2, take an infinite model $\mathcal{M}$ of $T$ and any injective sequence in it.

### Step 4: the invariant of part 3

Let $\Gamma$ be a set of $L$-formulas, each with free variables among $x_1, \dots, x_n$ for some $n$.
Call an ordered set $Y \subseteq X_\beta$ *$\Gamma$-good* if every $\varphi(x_1, \dots, x_n) \in \Gamma$ holds in $\mathcal{M}_\beta$ at every increasing $n$-tuple of $Y$.
Call $\Gamma$ *large* if for every $\alpha < \omega_1$ there are $\beta < \omega_1$ and a $\Gamma$-good $Y \subseteq X_\beta$ with $\abs{Y} \ge \beth_\alpha$.
The empty set is large, with $Y = X_\alpha$.

Claim: let $\Gamma$ be large, and let $\Theta = \set{\theta_j(x_1, \dots, x_m) : j \in \N}$ be a set of formulas such that every increasing $m$-tuple of every $X_\beta$ satisfies some $\theta_j$.
Then $\Gamma \cup \set{\theta_j}$ is large for some $j$.

### Step 5: proof of the claim

1. We may assume $m \ge 1$, by adding a dummy variable. Fix $\alpha < \omega_1$. As $\Gamma$ is large, there is a $\Gamma$-good $Y \subseteq X_\beta$ with $\abs{Y} \ge \beth_{\alpha + m}$.
2. Color each $m$-element subset of $Y$ by the least $j$ such that $\theta_j$ holds at it, as an increasing tuple. There are at most $\aleph_0 \le \beth_\alpha$ colors.
3. By the [[beth numbers|ZC4BHVHWE9]], $\beth_{\alpha + m} = 2^{\beth_{m-1}(\beth_\alpha)}$, and this is at least $\beth_{m-1}(\beth_\alpha)^+$.
4. The [[Erdős-Rado theorem|S1BHE358VX]] gives $\beth_{m-1}(\beth_\alpha)^+ \to (\beth_\alpha^+)^m_{\beth_\alpha}$. So some $H \subseteq Y$ of size $\beth_\alpha^+$ has all $m$-sets of one color $j_\alpha$.
5. Then $H$ is good for $\Gamma \cup \set{\theta_{j_\alpha}}$, since subsets of a good set are good.
6. The map $\alpha \mapsto j_\alpha$ goes from $\omega_1$ to $\N$. The [[first uncountable ordinal|Z92S2GVCX9]] is [[regular|13ZV2F8JAR]], so some $j$ has $j_\alpha = j$ for unboundedly many $\alpha$.
7. For each $\alpha$ pick $\alpha' \ge \alpha$ with $j_{\alpha'} = j$. Item 5 for $\alpha'$ gives a good set of size $\beth_{\alpha'}^+ \ge \beth_\alpha$. So $\Gamma \cup \set{\theta_j}$ is large.

### Step 6: the construction of part 3

1. List the $L$-formulas in the variables $x_1, x_2, \dots$ as $\chi_0, \chi_1, \dots$, which is possible since $L$ is countable.
2. Put $\Gamma_0 = \emptyset$. At step $2s$ apply the claim to $\Theta = \set{\chi_s, \neg \chi_s}$. At step $2s + 1$ apply it to $\Theta = \Psi_s$, which is allowed by the hypothesis of part 3.
3. This gives large sets $\Gamma_0 \subseteq \Gamma_1 \subseteq \cdots$, and $\Gamma_\omega = \bigcup_s \Gamma_s$ contains $\chi_s$ or $\neg \chi_s$ for each $s$, and some $\psi_{k,j}$ for each $k$.
4. The formula $x_1 = x_2$ is not in $\Gamma_\omega$: it fails at every increasing pair of a set $X_\beta$, so a good set for it has at most one element.

### Step 7: the model of part 3

Let $\Sigma'$ be $T$ together with $d_i \ne d_j$ for $i \ne j$ and $\varphi(d_{\bar{\imath}})$ for $\varphi \in \Gamma_\omega$ and increasing $\bar{\imath}$ in $I$.
A finite part of $\Sigma'$ uses finitely many formulas, all in some large $\Gamma_s$, and finitely many $d_i$, say $N$ of them.
A $\Gamma_s$-good set $Y \subseteq X_\beta$ with $\abs{Y} \ge \beth_0 = \aleph_0$ has $N$ increasing elements, and they interpret these $d_i$ in $\mathcal{M}_\beta$.
By compactness $\Sigma'$ has a model $\mathcal{N}$.
The elements $a_i = d_i^{\mathcal{N}}$ are distinct, and they are indiscernible because $\Gamma_\omega$ decides each $\chi_s$.
For each $k$ some $\psi_{k,j} \in \Gamma_\omega$ holds at all increasing tuples, which proves part 3.

## Idea

Indiscernibility is a homogeneity condition, so partition theorems produce it.
For one model and finitely many formulas, the finite Ramsey theorem gives a homogeneous finite piece, and compactness glues the pieces.
Part 3 keeps a property of the elements of the given models, such as the omission of a type.
For this the proof never leaves those models: it decides one formula at a time and keeps large homogeneous sets.
There the Erdős-Rado theorem takes the place of Ramsey's theorem.

## Variants

Part 1 also follows from the infinite [[Ramsey theorem|00TQV3F5S4]]: an infinite homogeneous subsequence for finitely many formulas exists in $\mathcal{M}$ itself, and compactness finishes as before.
In a monster model, a variant applies the Erdős-Rado theorem to a long enough sequence and obtains an indiscernible sequence over a set $A$ of parameters.
Each finite tuple of the new sequence then has the type over $A$ of some increasing tuple of the original sequence.
Part 3 is often stated in the special case where each $\mathcal{M}_\alpha$ omits a countable set of types, which is the case used for the [[Hanf number|~506bb18e]].
