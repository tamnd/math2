## Example

The [[exclusive or|~777e424f]] $p \oplus q$ is true when exactly one of $p$, $q$ is true.
We show that $\oplus$ alone is not [[functionally complete|TDZVCWYJ9F]]: no formula built from variables with $\oplus$ alone has the truth table of $\neg p$.
So $\oplus$ does not share the property of the [[Sheffer stroke|1NNYWRN6B8]].

1. Fix the assignment that makes every variable false.
2. Claim: every formula built from variables with $\oplus$ alone is false under this assignment.
3. A variable is false under the assignment, so the claim holds for variables.
4. Suppose $\varphi$ and $\psi$ are built with $\oplus$ alone and are both false under the assignment. Then $\varphi \oplus \psi$ has the value $\mathsf{F} \oplus \mathsf{F} = \mathsf{F}$.
5. By steps 3 and 4 and induction on the construction of formulas, the claim of step 2 holds for every such formula.
6. The formula $\neg p$ is true at $p = \mathsf{F}$, so by step 2 no formula built with $\oplus$ alone has the truth table of $\neg p$.

So $\oplus$ alone is not functionally complete.

## Remarks

The example shows the main obstacle to completeness: a connective that preserves a truth value cannot produce a negation.
Here $\oplus$ preserves $\mathsf{F}$, because $\mathsf{F} \oplus \mathsf{F} = \mathsf{F}$.
In the same way, $\land$, $\lor$, $\to$ and $\leftrightarrow$ preserve $\mathsf{T}$: each gives $\mathsf{T}$ on the input $\mathsf{T}\mathsf{T}$, so none of them alone can express $\neg p$.
The Sheffer stroke and the Peirce arrow escape both obstacles, because $\mathsf{T} \uparrow \mathsf{T} = \mathsf{F}$ and $\mathsf{F} \downarrow \mathsf{F} = \mathsf{T}$.

If we add the constant $\top$ to $\oplus$, then $\neg p \equiv p \oplus \top$, so negation becomes expressible.
The set $\set{\oplus, \top}$ is still not functionally complete.
With $\mathsf{T}$ as $1$ and $\mathsf{F}$ as $0$, every formula in it computes a sum modulo $2$ of variables and constants.
The function $p \land q$ is not such a sum.
The set $\set{\oplus, \land, \top}$ is functionally complete, and its formulas are the polynomials of a [[Boolean ring|0RCV1ZFP8G]].

## Explanations

### L1 human

The exclusive or says "exactly one of the two".
If every input is false, then no input is true, so "exactly one" is false.
Combining false results with exclusive or again gives false.
So a formula of exclusive ors can never be true when all its inputs are false.
But "not $p$" is true when $p$ is false, so exclusive or alone can never say "not".

### L2 human

We show in the same way that $\set{\land, \lor}$ is not functionally complete.

1. Fix the assignment that makes every variable true.
2. A variable is true under it.
3. If $\varphi$ and $\psi$ are true, then $\varphi \land \psi$ and $\varphi \lor \psi$ are true.
4. By induction, every formula built with $\land$ and $\lor$ is true under this assignment.
5. The formula $\neg p$ is false at $p = \mathsf{T}$, so it is not expressible.

The typical use of this argument is to prove that a set of connectives is not complete: find a property that all of them keep and that $\neg$ or another connective breaks.
A trap: the argument proves incompleteness, but it gives no help in proving completeness, which needs explicit formulas as on the page of the [[stroke|~9608def4]].
