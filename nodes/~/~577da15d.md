## Definition

Let $X$ be a [[topological space|~77bfcc55]] and let $A \subseteq X$.
The set $A$ is nowhere dense in $X$ when the [[interior|~51ce20fc]] of its [[closure|~8d5f2dc5]] is empty, that is, $\operatorname{int} \overline{A} = \emptyset$.

## Remarks

The set $\mathbb{Z}$ is nowhere dense in $\mathbb{R}$. So is each finite subset of $\mathbb{R}$.
The [[Cantor set|~903cc646]] is nowhere dense in $\mathbb{R}$, though it is uncountable.
The set $\mathbb{Q}$ is not nowhere dense in $\mathbb{R}$, because its closure is $\mathbb{R}$.
A closed set is nowhere dense if and only if its complement is open and [[dense|~337095db]].

## Explanations

### L1 human

A nowhere dense set is thin everywhere: inside each open set, you can find a smaller open set that misses it completely.
The integers on the real line are an example, since there are gaps between them.
