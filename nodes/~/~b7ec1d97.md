## Proof

We prove [[Harrop's theorem|~8e9dee58]] for $\Lambda = \mathsf{K}\Gamma$ with $\Gamma$ finite and with the finite model property.
We give two procedures, $A$ and $B$, that run in parallel on an input $\varphi$.

1. Procedure $A$ lists the theorems. $\Lambda$ is the set of theorems of the [[Hilbert system|1MGMQX43B8]] with the rules modus ponens and necessitation. Its axioms are tautology instances, instances of $\mathrm{K}$ and instances of the formulas of $\Gamma$.
2. Whether a formula is a tautology instance is decidable by truth tables, after the maximal non-propositional subformulas are read as letters. Whether it is an instance of one of the finitely many formulas of $\mathrm{K}$ and $\Gamma$ is decidable by matching. Here the finiteness of $\Gamma$ is used.
3. So we can decide whether a finite list of formulas is a derivation. Procedure $A$ lists all finite lists in turn and stops when it finds a derivation whose last line is $\varphi$.
4. Procedure $B$ lists the finite countermodels. It lists all pairs $(\mathfrak{F}, V)$. In each pair, $\mathfrak{F}$ is a frame with domain $\set{1, \dots, k}$ for some $k \ge 1$, and $V$ is a valuation of the variables of $\varphi$.
5. For each pair, $B$ first tests whether $\mathfrak{F} \models \gamma$ for each $\gamma \in \Gamma$. This test is finite: there are $2^{km}$ valuations of the $m$ variables of $\gamma$. Truth at each world is computed by the clauses of Kripke semantics.
6. If $\mathfrak{F}$ passes, $B$ tests whether $\varphi$ is false at some world of $(\mathfrak{F}, V)$, and stops if it is.
7. Correctness of $A$. If $A$ stops, then $\Lambda \vdash \varphi$, by the definition of $\Lambda$.
8. Correctness of $B$. If $B$ stops at $(\mathfrak{F}, V)$, then $\mathfrak{F}$ validates $\Gamma$. By [[soundness|~d189ee4b]], $\mathfrak{F}$ validates every theorem of $\mathsf{K}\Gamma$. As $\varphi$ fails on $\mathfrak{F}$, $\Lambda \nvdash \varphi$.
9. Termination. If $\Lambda \vdash \varphi$, a derivation exists, and $A$ finds it. If $\Lambda \nvdash \varphi$, the finite model property in the frame form of [[the definition|~d85c3662]] gives a finite $\Lambda$-frame $\mathfrak{F}$ and a valuation where $\varphi$ fails. Here the FMP is used.
10. Such an $\mathfrak{F}$ validates $\Gamma \subseteq \Lambda$, and an isomorphic copy on $\set{1, \dots, k}$ occurs in the list of $B$, with a valuation that refutes $\varphi$. So $B$ stops.
11. Exactly one of $A$ and $B$ stops, by steps 7 to 10, and its answer is correct. Running them in parallel, one step of each in turn, decides $\Lambda \vdash \varphi$.

## Idea

The theorems form a computably enumerable set because the axioms are finite in number.
The non-theorems form a computably enumerable set because each one has a finite witness, a finite frame of the logic.
A finite axiom set lets us check that a finite frame is a frame of the logic.

## Variants

1. For the general form, procedure $A$ uses the recursive axiom set. Procedure $B$ uses the given enumeration of finite $\Lambda$-frames instead of the test of step 5.
2. With a computable bound $f$ on the size of countermodels, procedure $B$ alone decides $\Lambda$. If no frame with at most $f(|\varphi|)$ worlds refutes $\varphi$, then $\Lambda \vdash \varphi$.
