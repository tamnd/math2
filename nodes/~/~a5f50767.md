## Statement

Let $X$ be a set with $m$ elements, and let $n$ be a positive integer with $n \le m$.
Call a string over $X$ a permutation if no letter occurs twice in it.
Then the number of such strings of length $n$ is $P(m,n) = m(m-1)\cdots(m-n+1)$.

## Remarks

Here $P(m,n)$ is the [[falling factorial|0N5M924N3P]] $(m)_n$, which equals $m!/(m-n)!$.
A string of length $n$ with distinct letters is the same as an injective function from $\{1,\dots,n\}$ to $X$.
So the count is a special case of the [[number of injections|0X0N833FF8]].
