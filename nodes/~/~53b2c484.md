## Proof

Throughout, "elementary map" means a [[partial elementary map|XTNYY0WRQ5]] of $\mathcal{A} | L$ into itself.
Since $\mathcal{A}$ is saturated of size $\kappa$, so is $\mathcal{A} | L$, and types in finitely many variables over fewer than $\kappa$ parameters are realized, one variable at a time.

**Part 1, (a) implies (b) implies (c).**
If $\varphi(\mathcal{A}) = \psi(\mathcal{A}, \bar b)$, then $\alpha(\varphi(\mathcal{A})) = \psi(\mathcal{A}, \alpha(\bar b))$, so $\nu \le \lvert A^{<\omega} \rvert = \kappa < 2^\kappa$.

**Part 1, (c) implies (a).** Assume (a) fails.

1. Claim: for every $B \subseteq A$ with $\lvert B \rvert < \kappa$, there are $\bar a, \bar b$ with the same $L$-type over $B$ and $\mathcal{A} \models \varphi(\bar a) \wedge \neg \varphi(\bar b)$.
2. Otherwise the set $\set{\varphi(\bar x), \neg \varphi(\bar y)} \cup \set{\psi(\bar x, \bar e) \leftrightarrow \psi(\bar y, \bar e) : \psi \in L, \ \bar e \in B}$ is not realized in $\mathcal{A}$. By saturation it is not finitely satisfiable, so finitely many $\psi_j(\bar x, \bar e_j)$ have the property that tuples agreeing on all of them agree on $\varphi$.
3. Then $\varphi(\mathcal{A})$ is a finite union of Boolean cells of the $\psi_j(\bar x, \bar e_j)$, which is definable with parameters, against our assumption.
4. Enumerate $A = \set{a_\xi : \xi < \kappa}$. By induction on the length of $s \in 2^{<\kappa}$, build elementary maps $f_s$ with $f_s \subseteq f_t$ for $s \subseteq t$, and with $\lvert \operatorname{dom} f_s \rvert < \kappa$.
5. Let $f_\emptyset = \emptyset$, and at a limit length $\delta$ let $f_s = \bigcup_{\xi < \delta} f_{s | \xi}$. Each step adds finitely many elements, so $\lvert \operatorname{dom} f_s \rvert \le \lvert \delta \rvert + \aleph_0$, which is below $\kappa$ when $\delta \ge \omega$, and finite otherwise.
6. Successor step from $f_s$ with $s$ of length $\xi$: let $B = \operatorname{dom} f_s$, and take $\bar a, \bar b$ as in step 1. Let $\bar c$ realize the image under $f_s$ of the $L$-type of $\bar a$ over $B$.
7. Then $g_0 = f_s \cup \set{\bar a \mapsto \bar c}$ and $g_1 = f_s \cup \set{\bar b \mapsto \bar c}$ are elementary, since $\bar a$ and $\bar b$ have the same type over $B$.
8. Extend each $g_i$ by one forth step and one back step, using saturation, so that $a_\xi$ lies in its domain and its range. Call the results $f_{s 0}$ and $f_{s 1}$.
9. For $\eta \in 2^\kappa$, let $\alpha_\eta = \bigcup_{\xi < \kappa} f_{\eta | \xi}$. It is defined on every $a_\xi$, onto $A$, and elementary, so it is an automorphism of $\mathcal{A} | L$.
10. Let $\eta \ne \eta'$, first differing after $s$, with $s 0 \subseteq \eta$ and $s 1 \subseteq \eta'$, and let $\bar a, \bar b, \bar c$ be as at the node $s$. Then $\alpha_\eta(\bar a) = \bar c = \alpha_{\eta'}(\bar b)$.
11. Since $\varphi(\bar a)$ holds and $\varphi(\bar b)$ fails, $\bar c \in \alpha_\eta(\varphi(\mathcal{A}))$ and $\bar c \notin \alpha_{\eta'}(\varphi(\mathcal{A}))$.
12. So the $2^\kappa$ automorphisms $\alpha_\eta$ give $2^\kappa$ distinct images, and (c) fails.

**Part 2.**
(a) implies (b) as in part 1, in each model separately.
For the converse, assume (a) fails, and let $\Theta = T \cup \set{\neg \exists \bar y \, \forall \bar x \, (\varphi \leftrightarrow \psi(\bar x, \bar y)) : \psi \text{ an } L\text{-formula}}$.

13. If $\Theta$ were inconsistent, [[compactness|1NR3HAWG9D]] would give finitely many $\psi_i$ as in (a). So $\Theta$ has a model, with complete theory $T'$.
14. $T'$ has only infinite models, since in a finite model every set is definable with parameters by listing its tuples.
15. By [[the existence theorem|GSQ833HAZT]], $T'$ has a saturated model $\mathcal{A}$ of size $\kappa$, and $\varphi(\mathcal{A})$ is not definable with parameters, because $\mathcal{A} \models \Theta$.
16. By part 1, $\nu(\varphi, \mathcal{A}) = 2^\kappa > \kappa = \lvert A \rvert$, so (b) fails.

**Part 3.** Each image $\alpha(P^{\mathcal{A}})$ is a set $Q$ with $(\mathcal{A} | L, Q) \models T$, so the hypothesis gives (b) of part 2 for $\varphi = P(\bar x)$.

## Idea

If a set is not definable with parameters, then over every small set of parameters two tuples look alike to $L$ but differ on the set.
Sending both to one common tuple splits the construction into two branches whose automorphisms disagree about the set.
Repeating the split at every level of a tree of height $\kappa$ produces $2^\kappa$ different images.

## Variants

- When the images are counted as expansions $(\mathcal{A} | L, Q)$ that satisfy $T$, the same proof applies, as in part 3.
- With $\nu = 1$ in place of $\nu \le \kappa$, the same splitting at the root alone gives the saturated form of [[Svenonius's theorem|~8495e2be]].
