## Example

We show that $\forall x\, Px \to Pt$ is not valid in [[free logic|~5d51b6ee]], with the negative semantics and with the positive dual-domain semantics.

Negative semantics.

1. Let the [[structure|983GZBQYT4]] have domain $D = \set{a}$ and $P = \set{a}$, and let the constant $t$ have no denotation.
2. $\forall x\, Px$ is true, since the only object $a$ is in $P$.
3. In negative semantics, an atom with a non-denoting term is false. So $Pt$ is false.
4. Hence $\forall x\, Px \to Pt$ is false in this structure.

Positive (dual-domain) semantics.

5. Let the inner domain be $D_i = \set{a}$ and the outer domain $D_o = \set{a, o}$, with $P = \set{a}$ and $t$ denoting $o$.
6. The quantifier ranges over $D_i$, so $\forall x\, Px$ is true.
7. $Pt$ is false, since $o \notin P$.
8. So the formula is false in this structure too.

In both structures, the [[existence predicate|XK9WZW5B68]] $E!t$ is false.
The free form $\forall x\, Px \to (E!t \to Pt)$ is true in both, because its inner antecedent $E!t$ is false.

## Remarks

Read $P$ as "is a physical object" and $t$ as "Pegasus".
Every existing object is physical, but Pegasus is not, because Pegasus does not exist.
The free specification axiom adds exactly the missing premise.
In classical logic, step 1 is impossible, because every constant must denote an object of the domain.

## Explanations

### L1 human

"Everything is physical" may be true of everything that exists.
But "Pegasus is physical" is not true, since Pegasus does not exist.
So we cannot always move from "everything" to a particular name.
Free logic requires first that the name refers to something that exists.

### L2 human

The counterexample needs a name outside the range of the quantifier.
In negative semantics, the name denotes nothing; in positive semantics, it denotes an object of the outer domain.
A trap is to put the denotation of $t$ in the inner domain; then $E!t$ is true and specification holds.
