## Example

We outline the proof in [[ZFC|0HE5WDQ9FJ]] of the [[consistency statement|~3f19fcb2]] $\mathrm{Con}(\mathsf{PA})$, read in $\mathsf{ZFC}$ through the natural numbers $\omega$.
Each step is a theorem of $\mathsf{ZFC}$.

1. The set $\omega$ exists, by the axiom of infinity. With the successor map $n \mapsto n \cup \set{n}$ and addition and multiplication defined by recursion on $\omega$, it forms a structure $\mathcal{N}$ for the language $\set{0, S, +, \cdot}$.
2. Satisfaction in a set-sized structure is defined by recursion on formulas, so "$\mathcal{N} \models \varphi$" is a formula of set theory in the code of $\varphi$.
3. $\mathcal{N}$ satisfies the axioms of $\mathsf{Q}$, by the recursion equations of step 1.
4. For each formula $\varphi(x, \vec{y})$, the set $\set{n \in \omega : \mathcal{N} \models \varphi(n, \vec{b})}$ exists by separation. If it contains $0$ and is closed under successor, it equals $\omega$, by induction on $\omega$. So $\mathcal{N}$ satisfies every induction axiom.
5. $\mathsf{ZFC}$ proves the [[soundness theorem|4A84VHDTHV]]: every formula with a proof from axioms true in $\mathcal{N}$ is true in $\mathcal{N}$. The proof is induction on the length of proofs.
6. $\mathcal{N} \not\models 0 = S0$, since $0 = \varnothing$ and $S0 = \set{\varnothing}$ differ.
7. By steps 4 to 6, no proof of $0 = S0$ from the axioms of [[Peano arithmetic|MPSCREYC3M]] exists. This is $\mathrm{Con}(\mathsf{PA})$, read through $\omega$.

## Remarks

The proof uses the full scheme of induction on $\omega$ for all formulas at once, which $\mathsf{PA}$ cannot state, through the satisfaction relation of step 2.
By the second incompleteness theorem, $\mathsf{ZFC}$ does not prove its own consistency statement $\mathrm{Con}(\mathsf{ZFC})$, if $\mathsf{ZFC}$ is consistent.
Weaker theories also prove $\mathrm{Con}(\mathsf{PA})$, for example second-order arithmetic.

## Explanations

### L1 human

Set theory can build the whole set of natural numbers as one object.
It can then check that every axiom of arithmetic holds in this object, and that proofs preserve truth.
So it proves that arithmetic never proves $0 = 1$.

### L2 human

1. Build the model $\omega$ inside $\mathsf{ZFC}$.
2. Check every axiom of $\mathsf{PA}$ in it, induction included.
3. Apply soundness to get $\mathrm{Con}(\mathsf{PA})$.

The typical use is the method "a theory proves the consistency of another theory by building a model of it".
A trap: the argument needs a truth definition for $\omega$, which is why $\mathsf{PA}$ cannot run it about itself.
