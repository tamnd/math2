## Definition

Let $a < b$ and let $f \colon [a, b] \to \mathbb{R}$ be a function.
The function $f$ is Riemann integrable on $[a, b]$ if there is a real number $I$ with the following property.
For each $\varepsilon > 0$ there is $\delta > 0$ such that $|S(f, P, t) - I| < \varepsilon$ for each tagged partition $(P, t)$ of $[a, b]$ with [[mesh|~c4b15e64]] $\| P \| < \delta$.
Here $S(f, P, t)$ is the [[Riemann sum|~3a724e5e]] of $f$ for $(P, t)$.

## Remarks

The number $I$ is unique. It is the [[Riemann integral|~d843dc28]] of $f$.
A Riemann integrable function is bounded.
[[Continuous functions|~a84a5268]] and [[monotone functions|~7c09e9fb]] on $[a, b]$ are Riemann integrable. The [[Dirichlet function|~0b7f418d]] is not.

## Explanations

### L1 human

A function is Riemann integrable if its Riemann sums settle down to one number as the partitions get finer.
It does not matter which tags we choose in the pieces.
