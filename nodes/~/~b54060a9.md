## Example

Let $L = \set{0, s, P}$, with $0$ a constant, $s$ unary and $P$ a unary relation symbol.
The [[Herbrand universe|~171f8802]] is $\set{s^n(0) : n \in \N}$, and the Herbrand base is $\set{P(s^n(0)) : n \in \N}$.
Let $\Sigma = \set{P(0), \ \forall x \, (P(x) \to P(s(s(x))))}$.
We determine all [[Herbrand models|~d1167ab6]] $\mathcal{H}_I$ of $\Sigma$, where $I$ is a set of ground atoms.

1. $\mathcal{H}_I \models P(0)$ if and only if $P(0) \in I$.
2. In $\mathcal{H}_I$, the term $s(s(x))$ under $x \mapsto s^n(0)$ has the value $s^{n+2}(0)$. So the second sentence holds if and only if, for all $n$, $P(s^n(0)) \in I$ implies $P(s^{n+2}(0)) \in I$, by the clauses for $\forall$ and $\to$ of [[satisfaction|~cf18e0d7]].
3. Let $E = \set{P(s^{2k}(0)) : k \in \N}$. If $\mathcal{H}_I \models \Sigma$, then $E \subseteq I$, by step 1 and induction on $k$ with step 2.
4. Conversely, $\mathcal{H}_E \models \Sigma$: $P(0) \in E$, and if $n$ is even, then $n + 2$ is even.
5. Let $I \supseteq E$. Then $\mathcal{H}_I \models \Sigma$ if and only if $I$ is closed under $P(s^n(0)) \mapsto P(s^{n+2}(0))$.

So the Herbrand models of $\Sigma$ are the sets $I \supseteq E$ that are closed under adding $2$ to the exponent, and the least one is $E$.
Examples are $E$ itself, the whole base $B(L)$, and $E \cup \set{P(s^n(0)) : n \geq 7}$.

## Remarks

The example shows that a set of definite clauses has a least Herbrand model, here the "even numbers".
In logic programming, $\Sigma$ is the program `p(0). p(s(s(X))) :- p(X).`, and its meaning is the least Herbrand model $E$.
The query $P(s^3(0))$ fails, because $P(s^3(0)) \notin E$, although $P(s^3(0))$ is true in other Herbrand models, such as $B(L)$.
So "true in the least Herbrand model" is different from "true in every model", but for ground atoms the two agree: $P(s^n(0))$ is a consequence of $\Sigma$ if and only if $n$ is even.

## Explanations

### L1 human

The rules say: $0$ has property $P$, and whenever $x$ has $P$, so does the number two steps later.
The smallest choice that obeys the rules gives $P$ to $0, 2, 4, 6, \ldots$ and nothing else.
Larger choices are allowed too, but every choice must contain the even numbers.

### L2 human

We check that $I = E \cup \set{P(s(0))}$ is not a Herbrand model of $\Sigma$.

1. Take $x \mapsto s(0)$. Then $P(x)$ holds, because $P(s(0)) \in I$.
2. Then $P(s(s(x)))$ must hold, so $P(s^3(0)) \in I$ is needed. It is not in $I$.
3. So the second sentence fails, and $\mathcal{H}_I$ is not a model.

Adding all odd atoms, as in $B(L)$, repairs this.
The typical use is to compute the meaning of a recursive logic program.
A trap is to think that the least Herbrand model is the only model; it is the intersection of all Herbrand models.
