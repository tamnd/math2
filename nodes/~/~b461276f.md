## Statement

Let $F$ be a [[finite field|0ZXZ82FTX2]] with $q$ elements, let $A$ be an $m \times n$ matrix over $F$, and let $b \in F^m$.
Let $r = \operatorname{rank} A$.
Then the [[system|0GT4WWGWH2]] $Ax = b$ has either no solution or exactly $q^{\,n - r}$ solutions.
The homogeneous system $Ax = 0$ always has exactly $q^{\,n - r}$ solutions.

## Remarks

### Why each hypothesis is needed

1. The field must be finite, so that counting makes sense; over $\R$ the same system has infinitely many solutions when $r < n$.
2. The coefficients must lie in a field: over the ring $\mathbb{Z}/4$, the equation $2x = 0$ has the $2$ solutions $0$ and $2$, and $2$ is not a power of $4$.

### Consequences

1. The number of solutions of a consistent system over $\mathbb{F}_2$ is a power of $2$.
2. Over $F$ with $q$ elements, exactly $q^r$ of the $q^m$ right-hand sides $b$ give a consistent system, because the column space has dimension $r$.
3. When $r = m$, every $b$ gives exactly $q^{n - m}$ solutions.

### Converse

Every power $q^d$ with $0 \le d \le n$ occurs as a count: take $A$ to be the first $n - d$ rows of the identity matrix $I_n$, padded with zero rows if needed, and $b = 0$.

### Generalizations

For a linear map $T \colon V \to W$ between finite-dimensional spaces over $\mathbb{F}_q$, every nonempty fibre $T^{-1}(w)$ has $q^{\dim \ker T}$ elements.

### History

Linear algebra over $\mathbb{F}_2$ is used for linear codes: a binary linear code is the null space of a check matrix $H$ of rank $r$, so it has $2^{n - r}$ codewords.
It also solves puzzles such as Lights Out, see [[the Lights Out example|~1680847d]].

## Explanations

### L1 human

Over a finite field there are only finitely many possible solutions.
Each free variable can take $q$ values, and the other unknowns are then fixed.
So with $k$ free variables there are $q^k$ solutions, if there is any solution at all.

### L2 human

We count the solutions of $x + y + z = 1$ over $\mathbb{F}_3$.

1. The matrix $A = (1, 1, 1)$ has rank $r = 1$, and $n = 3$.
2. The system is consistent, since $(1, 0, 0)$ is a solution.
3. So it has $3^{3 - 1} = 9$ solutions.
4. Directly: choose $y$ and $z$ in $3 \cdot 3 = 9$ ways, and put $x = 1 - y - z$; check with $y = z = 2$: $x = 1 - 4 = -3 = 0$, and $0 + 2 + 2 = 4 = 1$ in $\mathbb{F}_3$.

The typical use is to count solutions in coding theory, cryptography and puzzles.
A trap: the integers modulo $n$ form a field only for $n$ prime; for other $n$ the count can fail.

### L3 human

The solution set is a coset of the kernel, and the kernel is an $\mathbb{F}_q$-vector space of dimension $n - r$, so it is in bijection with $\mathbb{F}_q^{\,n - r}$.
The count $q^{n-r}$ then follows from $|\mathbb{F}_q^{\,d}| = q^d$.
