## Example

Let $G = (\mathbb{Q}^\times, \cdot)$ be the nonzero [[rational numbers|0NCJ5WXN6Z]] under multiplication.
Let $P = \{2^k : k \geq 0\} = \{1, 2, 4, 8, \ldots\}$ be the set of nonnegative powers of $2$.
We check that $P$ is not the [[cyclic subgroup|08ABT85339]] $\langle 2 \rangle = \{2^k : k \in \mathbb{Z}\}$.

1. Identity: $1 = 2^0 \in P$. This condition holds.
2. Closure: $2^a \cdot 2^b = 2^{a+b}$, and $a + b \geq 0$ when $a, b \geq 0$. This condition holds.
3. Inverses: $2 \in P$, but its inverse $\tfrac{1}{2}$ is not in $P$, because each element of $P$ is an integer $\geq 1$. This condition fails.
4. So $P$ is not a [[subgroup|0X1JXT47GA]] of $G$.
5. The set $\langle 2 \rangle$ is a subgroup, so $P \neq \langle 2 \rangle$. Concretely, $\tfrac{1}{2} = 2^{-1}$ lies in $\langle 2 \rangle$ but not in $P$.

## Remarks

The set $P$ is the submonoid generated by $2$: the smallest subset that contains $1$ and $2$ and is closed under products.
In a group, the subgroup generated by an element must also contain the inverse, and so all the negative powers.
In a finite group the difference disappears: if $g$ has order $n \geq 1$, then $g^{-1} = g^{n-1}$ is a nonnegative power.
For example, in $\mathbb{C}^\times$ the nonnegative powers of $i$ are $1, i, -1, -i$, which is already [[the subgroup $\langle i \rangle$|~2bdc2622]].
The set $P$ is the multiplicative form of the non-subgroup $\mathbb{N} = \{0, 1, 2, \ldots\}$ of $(\mathbb{Z}, +)$, through $k \mapsto 2^k$.

## Explanations

### L1 human

Doubling $1$ again and again gives $1, 2, 4, 8, \ldots$.
These numbers are closed under multiplication: $4 \cdot 8 = 32$ is again in the list.
But the list has no number that undoes $2$, because $\tfrac{1}{2}$ is not in it.
A subgroup must contain the inverse of each of its elements, so this list is not a subgroup.

### L2 human

We compare $P$ with the full subgroup.

1. $\langle 2 \rangle$ contains $2^{-3} = \tfrac{1}{8}$, and $P$ does not.
2. Each element of $P$ is a positive integer, and $\langle 2 \rangle$ contains numbers between $0$ and $1$.

The typical use of this non-example is a warning in infinite groups: always include the negative powers.
A trap: in a finite group the positive powers are enough, so a student who checks only finite groups does not see the problem.
