## Example

Let $T$ be the theory of [[dense linear orders without endpoints|2W4S2H4VYA]], and let $\mathcal{U}$ be the principal ultrafilter on $\N$ generated by $\set{0}$.
We show that $\aleph_1$-saturation of $\mathcal{M}^{\N} / \mathcal{U}$ depends on the choice of $\mathcal{M} \models T$, so $\mathcal{U}$ cannot be used in [[Keisler's order|~889bca65]].

1. By the [[diagonal embedding theorem|~50eaa729]], part 3, $\mathcal{M}^{\N} / \mathcal{U} \cong \mathcal{M}$ for every $\mathcal{M}$.
2. Take $\mathcal{M}_1 = (\Q, <)$. The type $\set{n < x : n \in \N}$ over the countable set $\N$ is finitely satisfiable and not realized, so $\mathcal{M}_1^{\N} / \mathcal{U}$ is not $\aleph_1$-saturated.
3. Take $\mathcal{M}_2 = (\Q, <)^{\N} / \mathcal{V}$ for a nonprincipal $\mathcal{V}$ on $\N$. By the [[saturation of ultraproducts|~bf3451a3]], it is $\aleph_1$-saturated, and $\mathcal{M}_2 \equiv \mathcal{M}_1$.
4. By step 1, $\mathcal{M}_2^{\N} / \mathcal{U} \cong \mathcal{M}_2$ is $\aleph_1$-saturated.

So "$\mathcal{U}$ saturates $T$" has no meaning: the answer is no for $\mathcal{M}_1$ and yes for $\mathcal{M}_2$.

## Remarks

The principal ultrafilter fails the regularity condition: the index $0$ lies in every member of $\mathcal{U}$.
For regular ultrafilters, Keisler showed that the answer depends only on the theory, and this is what makes the order a relation between theories.
The same problem appears for any countably complete ultrafilter, since then the ultrapower of a countable structure is isomorphic to the structure.

## Explanations

### L1 human

A principal ultrafilter just picks one coordinate, so the ultrapower is a copy of the original model.
Whether it has gaps then depends on which model we started with, not on the theory.
Keisler's order needs ultrafilters that really mix the coordinates.

### L2 human

We check step 2 for $(\Q, <)$.

1. Each finite part $\set{n < x : n \le k}$ is satisfied by $x = k + 1$.
2. Every rational $q$ is below some natural number $n$, so $q$ fails $n < x$.
3. So no rational realizes the type.

The typical use is to justify the regularity condition in the definition.
The trap is to think that saturation is a property of a theory for every ultrafilter.
