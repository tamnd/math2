## Proof

All families of scalars below are finitely supported, so all sums are finite.

1. ("Only if", existence) Let $(b_i)$ be a basis and $v \in V$. The family [[spans|0BJKVF90Z6]] $V$, so $v = \sum_i a_i b_i$ for some scalars $a_i$.
2. ("Only if", uniqueness) Assume $v = \sum_i a_i b_i = \sum_i a'_i b_i$.
3. Subtract, using the axioms of the [[definition|05EGHEQZAW]]: $\sum_i (a_i - a'_i) b_i = 0$. Only finitely many terms are nonzero.
4. The family is [[independent|0EVHJFTG9Z]], so $a_i - a'_i = 0$ for all $i$. Hence $a_i = a'_i$, and the coordinates are unique.
5. ("If", spanning) Assume that each $v$ has exactly one expression. In particular, each $v$ has at least one, so the family spans $V$.
6. ("If", independence) Let $\sum_i c_i b_i = 0$. The trivial combination $\sum_i 0 b_i$ is also equal to $0$.
7. By uniqueness of the expression for the vector $0$, we get $c_i = 0$ for all $i$. So the family is independent.
8. By steps 5 and 7, the family is a [[basis|0VTQTPQGAV]].

## Idea

Two expressions for the same vector differ by an expression for $0$.
Independence says that the only expression for $0$ is trivial, so the two expressions agree.
