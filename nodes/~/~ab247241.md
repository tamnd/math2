## Example

Let $\sigma$ be a [[signature|WDVVEYD6AT]] with a constant symbol $c$ and a unary relation symbol $P$.
We show that the string $\forall c \, P(c)$ is not a [[well-formed formula|HYJ10AF6RT]] over $\sigma$.
We look at the first symbol of the strings that each clause of the [[definition|2CHENV4DCC]] produces.

1. Clause 1 gives $t_1 = t_2$, which starts with the first symbol of a term: a variable, a constant symbol or a function symbol.
2. Clause 2 gives $R(t_1, \ldots, t_n)$, which starts with a relation symbol.
3. Clause 3 gives a string that starts with $\neg$, and clause 4 gives a string that starts with a bracket.
4. Clause 5 gives $\forall x \, \varphi$ or $\exists x \, \varphi$, where $x$ is a variable. So a string that starts with $\forall$ has a variable as its second symbol.
5. The second symbol of $\forall c \, P(c)$ is $c$. It is a constant symbol, and the variables are disjoint from the symbols of $\sigma$.
6. So no clause produces $\forall c \, P(c)$, and the string is not in the smallest set closed under the clauses.

## Remarks

The string $P(c)$ is a formula, by clause 2, and it says that the object named $c$ has the property $P$.
To say that every object has $P$, we write $\forall x \, P(x)$ with a variable.
A constant symbol names one fixed object in each structure, so a quantifier over it would have nothing to range over.
Some proof systems use parameters or eigenvariables, which behave like constants in some rules and like variables in others.
They are still kept apart from the constant symbols of the signature.

## Explanations

### L1 human

A quantifier says "for every thing" or "there is a thing", and it needs a placeholder to fill.
A variable is such a placeholder, like the blank in "for every $\_$, $\_$ is even or odd".
A constant is a fixed name, like "Paris" or $0$.
"For every $0$, $0$ is even" makes no sense, because $0$ is not a blank.
So the rules allow $\forall x$ but not $\forall 0$ or $\forall c$.

### L2 human

The same check rejects other wrong strings.

1. The string $\exists f(x) \, P(x)$ is not a formula, because $f(x)$ is a term but not a variable.
2. The string $\forall P \, P(x)$ is not a formula, because $P$ is a relation symbol. In [[second-order logic|G6X7SZSNC5]] such quantifiers are allowed, with relation variables.
3. The string $\forall x \, \forall x \, P(x)$ is a formula: clause 5 does not ask that $x$ is free in its argument.

The typical use of this argument is a proof that a string is not a formula: find a property of the first symbols that every clause keeps.
The trap is case 3: a strange string can still be a formula, and its outer quantifier then has no effect.
