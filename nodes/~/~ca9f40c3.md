## Example

Statement: if $f : \mathbb{R} \to \mathbb{R}$ is [[differentiable|0K57YG3BB8]], $f' = f$ and $f(0) = 1$, then $f(x) = e^x$ for every real $x$.
The [[exponential function|0J0FCWV32D]] $e^x$ has these properties, so it exists.
We prove uniqueness in the second form: any $f$ with the properties equals the known solution.

1. Let $f$ be such a function, and define $g(x) = f(x) e^{-x}$.
2. By the product rule and the chain rule, $g'(x) = f'(x) e^{-x} - f(x) e^{-x}$.
3. Since $f' = f$, this is $g'(x) = 0$ for every $x$.
4. A function with zero derivative on $\mathbb{R}$ is constant; see [[zero derivative implies constant|003QDZ4T16]]. So $g(x) = g(0) = f(0) e^0 = 1$.
5. Hence $f(x) e^{-x} = 1$, and $f(x) = e^x$ for every $x$.

## Remarks

The comparison function $g$ is the quotient $\frac{f}{e^x}$, written as a product to avoid dividing.
This is a common device: to show that $f$ equals a known $h$, show that $\frac{f}{h}$ or $f - h$ is constant, and compute the constant at one point.

Both conditions are needed.
Without $f(0) = 1$, every function $c e^x$ satisfies $f' = f$, so uniqueness fails.
Without $f' = f$, many functions satisfy $f(0) = 1$.

## Explanations

### L1 human

Imagine an amount of money that grows at a rate equal to its current size, starting from $1$.
The exponential function $e^x$ describes such growth.
The proof shows that no other growth curve with the same rule and the same start is possible.
If two curves followed the same rule from the same start, their ratio would never change, so it would stay equal to $1$ forever.

### L2 human

We use the same method to show: if $f$ is differentiable, $f' = 2f$ and $f(0) = 3$, then $f(x) = 3 e^{2x}$.

1. Let $g(x) = f(x) e^{-2x}$.
2. Then $g'(x) = f'(x) e^{-2x} - 2 f(x) e^{-2x} = 2f(x) e^{-2x} - 2f(x) e^{-2x} = 0$.
3. So $g$ is constant, and $g(x) = g(0) = f(0) = 3$.
4. Hence $f(x) = 3 e^{2x}$.

The typical use: multiply by the reciprocal of the expected solution, and show that the derivative of the product is $0$.

A trap: step 3 needs the domain to be an interval.
On a domain made of two separate intervals, a function with zero derivative can take a different constant on each piece.
