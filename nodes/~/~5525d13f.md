## Example

We write numbers in dyadic notation, with $s_1(m) = 2m + 1$ and $s_2(m) = 2m + 2$, as in [[Cook's theory PV|~98af8889]].
The successor $\mathrm{succ}(y) = y + 1$ is introduced by limited recursion on notation with the equations
$$\mathrm{succ}(0) = s_1(0), \qquad \mathrm{succ}(s_1(y)) = s_2(y), \qquad \mathrm{succ}(s_2(y)) = s_1(\mathrm{succ}(y)).$$
We check that this is a legal definition in $\mathsf{PV}$, so that $\mathrm{succ}$ and its equations form part of a [[feasibly constructive proof|~3d1b2721]].

1. Form. The equations have the form $f(0) = g$ and $f(s_i(y)) = h_i(y, f(y))$, with $g = s_1(0)$, $h_1(y, z) = s_2(y)$ and $h_2(y, z) = s_1(z)$. Each of $g$, $h_1$, $h_2$ is a composition of initial functions.
2. Bound for $h_1$. Take $l_1(y) = s_2(y)$. The value $s_2(y)$ is a final segment of the dyadic string $z \frown s_2(y)$, so it is bounded by this concatenation.
3. Bound for $h_2$. Take $l_2(y) = s_1(0)$, the one-digit string $1$. Then $h_2(y, z) = s_1(z)$ is exactly the concatenation $z \frown 1$.
4. Correctness for $s_1$. In $\N$, $s_1(y) + 1 = 2y + 2 = s_2(y)$.
5. Correctness for $s_2$. In $\N$, $s_2(y) + 1 = 2y + 3 = 2(y + 1) + 1 = s_1(y + 1)$.
6. Correctness at $0$. $0 + 1 = 1 = s_1(0)$.
7. Running time. Each equation removes one dyadic digit of $y$, so $\mathrm{succ}(y)$ uses at most $\abs{y} + 1$ applications of the equations.

So $\mathrm{succ}$ is a $\mathsf{PV}$ symbol, and steps 4 to 6 show that it computes $y \mapsto y + 1$.

## Remarks

The example shows how a carry is handled by recursion on notation: the digit $2$ becomes $1$ and the carry moves to the rest of the string.
In binary notation the same definition reads $\mathrm{succ}(2y) = 2y + 1$ and $\mathrm{succ}(2y + 1) = 2 \, \mathrm{succ}(y)$, with a separate case for $y = 0$.
Addition and multiplication are defined in the same way, by recursion on the digits of one argument, with bounds of the same kind.

## Explanations

### L1 human

Adding $1$ to a number written in digits is done from the right.
If the last digit can grow, it grows, and the work is done.
If not, it resets and $1$ is carried to the next place.
The number of steps is at most the number of digits, so it is fast even for very long numbers.

### L2 human

We compute $\mathrm{succ}(10)$ in dyadic notation.

1. $10 = s_2(4)$, since $2 \cdot 4 + 2 = 10$.
2. So $\mathrm{succ}(10) = s_1(\mathrm{succ}(4))$.
3. $4 = s_2(1)$, since $2 \cdot 1 + 2 = 4$.
4. So $\mathrm{succ}(4) = s_1(\mathrm{succ}(1))$, and $1 = s_1(0)$ gives $\mathrm{succ}(1) = s_2(0) = 2$.
5. Then $\mathrm{succ}(4) = s_1(2) = 5$, and $\mathrm{succ}(10) = s_1(5) = 11$.

The typical use is as a building block: almost every later $\mathsf{PV}$ definition uses the successor.
A trap is to look for a digit $0$: dyadic notation has only the digits $1$ and $2$, and an even number $n \ge 2$ ends in $2$.
