## Proof

All three constructions are elementary chains, in which each link realizes the types over small subsets of the previous link.
The tool for one link is [[realizing types|~17fa6973]]: a family of $\mu$ types over subsets of $\mathcal{M}$ is realized in an elementary extension of size at most $\abs{M} + \abs{L} + \mu + \aleph_0$.

### Part 1

1. Let $\mu = (\abs{M} + 2^{\abs{L}})^{\kappa}$. Then $\mu^{\kappa} = \mu$, $\mu \ge \abs{M}$, $\mu \ge 2^{\abs{L}} > \abs{L}$ and $\mu \ge 2^{\kappa} \ge \kappa^+$.
2. By [[transfinite recursion|0ZHQMQ2C1N]], build $\mathcal{M}_\alpha$ for $\alpha \le \kappa^+$ with $\mathcal{M}_0 = \mathcal{M}$, $\mathcal{M}_\beta \preceq \mathcal{M}_\alpha$ for $\beta < \alpha$, and $\abs{M_\alpha} \le \mu$.
3. At a successor, consider all complete $1$-types over sets $A \subseteq M_\alpha$ with $\abs{A} \le \kappa$. There are at most $\mu^{\kappa} = \mu$ such sets, and at most $2^{\abs{L} + \kappa} \le \mu$ types over each.
4. Realizing types gives $\mathcal{M}_{\alpha+1} \succeq \mathcal{M}_\alpha$ that realizes all these types, of size at most $\mu + \abs{L} + \mu \cdot \mu + \aleph_0 = \mu$.
5. At a limit $\alpha$, let $\mathcal{M}_\alpha$ be the union. It is an elementary extension of each earlier link by the [[elementary chain theorem|NHCRZ74JHH]], and its size is at most $\abs{\alpha} \cdot \mu = \mu$.
6. Let $\mathcal{N} = \mathcal{M}_{\kappa^+}$, let $A \subseteq N$ with $\abs{A} < \kappa^+$, and let $p \in S_1^{\mathcal{N}}(A)$.
7. Each $a \in A$ lies in some $M_{\alpha_a}$ with $\alpha_a < \kappa^+$. The cardinal $\kappa^+$ is [[regular|13ZV2F8JAR]], so $\beta = \sup_{a \in A} \alpha_a < \kappa^+$ and $A \subseteq M_\beta$.
8. Since $\mathcal{M}_\beta \preceq \mathcal{N}$, both structures satisfy the same $L_A$-sentences, so $p$ is a complete type over $A$ in $\mathcal{M}_\beta$.
9. By step 3, some $b \in M_{\beta+1}$ realizes $p$. Since $\mathcal{M}_{\beta+1} \preceq \mathcal{N}$, the element $b$ realizes $p$ in $\mathcal{N}$, so $\mathcal{N}$ is $\kappa^+$-saturated.

### Part 2

10. The cardinal $\kappa$ is regular. If its [[cofinality|BAWHE1W6MH]] were $\theta < \kappa$, then König's theorem would give $\kappa^{\theta} > \kappa$, while $\kappa^{\theta} \le \kappa^{<\kappa} = \kappa$.
11. By the [[Löwenheim-Skolem theorem|484M0TZ1S7]], $T$ has a model $\mathcal{M}_0$ of size $\kappa$, since $\kappa \ge \abs{L} + \aleph_0$.
12. Build an elementary chain $\mathcal{M}_\alpha$, $\alpha \le \kappa$, of models of size $\kappa$ as in steps 2 to 5, now realizing the types over sets $A \subseteq M_\alpha$ with $\abs{A} < \kappa$.
13. There are at most $\kappa^{<\kappa} = \kappa$ such sets. Over each, there are at most $2^{\abs{A} + \abs{L} + \aleph_0}$ types, and $\abs{A} + \abs{L} + \aleph_0 < \kappa$ because $\kappa$ is uncountable. So there are at most $2^{<\kappa} \le \kappa^{<\kappa} = \kappa$ types over each.
14. So each successor link has size $\kappa$, and each limit link has size at most $\abs{\alpha} \cdot \kappa = \kappa$.
15. Steps 6 to 9 with $\kappa$ in place of $\kappa^+$, using step 10, show that $\mathcal{M}_\kappa$ is saturated. It has size $\kappa$ by steps 11 and 14.

### Part 3

16. Start with a model $\mathcal{M}_0$ of size $\lambda$, by the Löwenheim-Skolem theorem.
17. Given $\mathcal{M}_\alpha$ of size $\lambda$, stability gives $\abs{S_1(M_\alpha)} \le \lambda$. Realize all these types in $\mathcal{M}_{\alpha+1}$ of size $\lambda$, and take unions at limits.
18. Let $A \subseteq M_\lambda$ with $\abs{A} < \lambda$ and $p \in S_1(A)$. As in step 7, regularity of $\lambda$ gives $\beta < \lambda$ with $A \subseteq M_\beta$.
19. The set $p \cup \operatorname{Th}_{M_\beta}(\mathcal{M}_\beta)$ is finitely satisfiable in $\mathcal{M}_\beta$, since a finite part of $p$ is realized there. By [[Lindenbaum's lemma|SC0BSJ3GT6]] it extends to some $q \in S_1(M_\beta)$.
20. An element of $M_{\beta+1}$ that realizes $q$ realizes $p$. So $\mathcal{M}_\lambda$ is saturated, of size $\lambda$.

### Part 4

21. If the continuum hypothesis holds, part 2 applies with $\kappa = \aleph_1$, since $\aleph_1^{\aleph_0} = 2^{\aleph_0} = \aleph_1$ and the language is finite.
22. Conversely, let $\mathcal{M}$ be a saturated dense linear order of size $\aleph_1$. It contains a copy $Q$ of $(\Q, <)$, since every countable [[dense linear order|2W4S2H4VYA]] embeds into it by the forth half of the back-and-forth argument.
23. For each irrational $r$, the set $\set{q < x : q \in Q, \, q < r} \cup \set{x < q : q \in Q, \, q > r}$ is finitely satisfiable by density, and it has countably many parameters. Saturation gives $m_r \in M$ that realizes it.
24. If $r < s$ are irrational, then some $q \in Q$ has $r < q < s$, so $m_r < q < m_s$. So $r \mapsto m_r$ is injective, and $2^{\aleph_0} \le \aleph_1$.

### Part 5

25. Let $\mathcal{M}$ be a dense linear order without endpoints of singular size $\kappa$, with cofinality $\theta < \kappa$. Write $M = \bigcup_{i < \theta} X_i$ with $\abs{X_i} < \kappa$.
26. Suppose that $\mathcal{M}$ is saturated, for a contradiction. By recursion on $i < \theta$, choose $a_i$ above every element of $X_i \cup \set{a_j : j < i}$.
27. This is possible: the set $X_i \cup \set{a_j : j < i}$ has size less than $\kappa$, and the type that says that $x$ lies above all its elements is finitely satisfiable, since $\mathcal{M}$ has no greatest element.
28. In the same way, the type that says $a_i < x$ for all $i < \theta$ has fewer than $\kappa$ parameters, so some $b \in M$ realizes it.
29. Then $b \in X_i$ for some $i$, so $b < a_i$ by step 26, which contradicts $a_i < b$.

## Idea

To realize all types over small sets, one realizes them over the small subsets of a model and repeats this along a chain.
The chain must be so long, and the cardinal so regular, that every small subset of the union appears in an earlier link.
The difficulty is only the counting, which is where $\kappa^{<\kappa} = \kappa$ or stability enters.
