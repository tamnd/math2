## Summary

Let $L \subseteq L^+$ be [[signatures|WDVVEYD6AT]].
A class $\mathcal{K}$ of $L$-structures is a *basic pseudo-elementary class*, or $\mathrm{PC}$ class, if it is the class of [[reducts|EY20BF96SJ]] to $L$ of the models of one $L^+$-[[sentence|DKFGQTRYZE]].
It is a *pseudo-elementary class*, or $\mathrm{PC}_\Delta$ class, if it is the class of reducts to $L$ of the models of an $L^+$-[[theory|92SWXST1ZM]].
So pseudo-elementary classes are the shadows of [[elementary classes|MEC3ZMC4F1]] after some symbols are forgotten.
They are closed under isomorphisms and [[ultraproducts|AX9Q86GB8M]], but not in general under elementary equivalence.
The formal definition is [[this definition|~7fafe2f2]].

## Motivation

Many natural properties say that some extra structure exists.
A linear order is not a well-order when some nonempty subset has no least element; a set is infinite when it has an injective map into itself that is not onto.
Neither property is first-order in the original signature, but each becomes first-order once a symbol for the extra structure is added and then forgotten.
Pseudo-elementary classes capture exactly this "there exists a relation such that" pattern, which is the existential fragment of second-order logic.

## Notation

$\mathrm{EC}$ and $\mathrm{EC}_\Delta$ denote the classes of models of one sentence and of a theory.
$\mathrm{PC}$ and $\mathrm{PC}_\Delta$ denote their classes of reducts, as above.
Some authors use "pseudo-elementary" for $\mathrm{PC}$ only, and some allow the expansion to add new sorts; this page follows the one-sorted convention.

## Remarks

### Examples

- Every elementary class is pseudo-elementary, with $L^+ = L$.
- [[Linear orders that are not well-ordered|~3343cdb5]] form a $\mathrm{PC}$ class that is not elementary.
- [[Infinite sets|~62519d74]] form a $\mathrm{PC}$ class that is not basic elementary.
- With one unary symbol $P$, the structures in which $P$ and its complement have the same cardinality form a $\mathrm{PC}$ class: add a function $f$ that is a bijection and maps $P$ onto its complement and back.

### Non-examples

- [[Finite sets|~af99cced]] form no $\mathrm{PC}_\Delta$ class, by compactness.
- Well-orders form no $\mathrm{PC}_\Delta$ class: an ultrapower of an expansion of $(\mathbb{N}, <)$ by a nonprincipal ultrafilter has a reduct that is not well-ordered.

### Basic properties

- $\mathrm{PC}$ and $\mathrm{PC}_\Delta$ classes are closed under ultraproducts: an ultraproduct of reducts is the reduct of the ultraproduct of the expansions.
- Finite unions and intersections of $\mathrm{PC}$ classes are $\mathrm{PC}$, after renaming the new symbols apart.
- If $\mathcal{K}$ and its complement among $L$-structures are both $\mathrm{PC}$, then $\mathcal{K}$ is basic elementary. An interpolant, by [[Craig's theorem|E2CBFNAVZY]], of the two defining sentences gives the axiom.

### History

A classical example comes from algebraic logic.
In the many-sorted version of the definition, the representable relation algebras form a pseudo-elementary class, and Tarski showed in 1955 that this class is even a variety.

### Common errors

- A pseudo-elementary class need not be closed under elementary equivalence: $(\mathbb{N}, <)$ and $(\mathbb{N}, <) + (\mathbb{Z}, <)$ are elementarily equivalent, and only the second lies in the $\mathrm{PC}$ class of non-well-ordered linear orders.
- Forgetting symbols is not the same as forgetting axioms: the reduct of a model of $T$ satisfies only the $L$-consequences of $T$, but a model of those consequences need not expand to a model of $T$.

## Explanations

### L1 human

Sometimes a property says "there is some hidden extra structure", like "there is a way to pair up these things".
We cannot always state such a property directly in the original language.
We can state it if we add a name for the hidden structure, write the rules, and then forget the name.
The classes obtained this way are the pseudo-elementary classes.

### L2 human

We show that the class of structures $(A, P)$ in which $P$ and $A \setminus P$ have the same size is $\mathrm{PC}$.

1. Add a unary function symbol $f$, and let $\sigma$ say that $f$ is a bijection with $f(f(x)) = x$, and that $P(x) \leftrightarrow \neg P(f(x))$ for all $x$.
2. If $(A, P, f) \models \sigma$, then $f$ maps $P$ bijectively onto $A \setminus P$.
3. Conversely, a bijection $g \colon P \to A \setminus P$ gives $f = g \cup g^{-1}$, which satisfies $\sigma$.

So the class is the class of reducts of models of $\sigma$.
A trap is to think that this class is elementary.
A structure with $P$ countably infinite and $A \setminus P$ uncountable satisfies the same sentences as one with both parts countably infinite.
The reason is that a sentence in the signature $\set{P}$ can only count the elements of each part up to a finite bound.

### L3 human

A $\mathrm{PC}$ class is the class of models of an existential second-order sentence $\exists R_1 \cdots \exists R_k \, \sigma$ with $\sigma$ first-order.
On finite structures, [[Fagin's theorem|BG8Q0BYSQ3]] identifies these classes with the properties decidable in nondeterministic polynomial time.
In infinite model theory, the separation of disjoint $\mathrm{PC}$ classes by an elementary class is a form of [[Craig interpolation|E2CBFNAVZY]].
