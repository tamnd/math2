## Proof

We prove the cycle $1 \Rightarrow 2 \Rightarrow 3 \Rightarrow 4 \Rightarrow 1$, then the claims on eigenvalues.

1. Assume condition 1, with $T^k = 0$. Let $K_j = \ker T^j$, so $K_0 = 0$ and $K_j \subseteq K_{j+1}$.
2. Assume $K_j = K_{j+1}$, and let $T^{j+2} v = 0$. Then $T v \in K_{j+1} = K_j$, so $T^{j+1} v = 0$.
3. So once two terms of the chain are equal, all later terms are equal.
4. Before that, each step adds at least one dimension. So the chain is constant from some index $m \le n$ on.
5. $K_k = V$, since $T^k = 0$. The chain is constant from $m$ on, so $K_n = K_{\max(k, n)} = V$. So $T^n = 0$, which is condition 2.
6. Assume condition 2. Then $0 = K_0 \subseteq K_1 \subseteq \cdots \subseteq K_n = V$.
7. Choose a basis of $K_1$, extend it to a basis of $K_2$, and so on up to $K_n = V$.
8. If $T^j v = 0$, then $T^{j-1}(T v) = 0$. So $T(K_j) \subseteq K_{j-1}$ for each $j \ge 1$.
9. Let $b$ be a basis vector added at level $j$. By step 8, $T b \in K_{j-1}$.
10. $K_{j-1}$ is spanned by the basis vectors added before $b$. So column $b$ has nonzero entries only above the diagonal.
11. So the matrix is strictly upper triangular, which is condition 3.
12. Assume condition 3, with strictly upper triangular matrix $A$. Then $t I - A$ is upper triangular with diagonal entries $t$.
13. By the [[triangular determinant|0K1KKMFHYH]], $\det(t I - A) = t^n$. By [[basis independence|0TYMASG33Y]], $p_T = t^n$. This is condition 4.
14. Assume condition 4. By [[Cayley-Hamilton|0QEM68Y0DE]], $T^n = p_T(T) = 0$. So $T$ is nilpotent, which is condition 1.
15. Now assume the conditions hold. By condition 4 and [[eigenvalues as roots|053QVHF6N7]], the eigenvalues are the roots of $t^n$.
16. The only root of $t^n$ is $0$, and $n \ge 1$. So $0$ is an eigenvalue, and it is the only one.
17. Let $F$ be algebraically closed, and assume condition 5. Then $p_T$ splits into $n$ linear factors $t - \mu_i$.
18. Each $\mu_i$ is a root of $p_T$, so it is an eigenvalue, as in step 15. So each $\mu_i = 0$.
19. So $p_T = t^n$, which is condition 4.

## Idea

The kernels of the powers of $T$ grow by at least one dimension until they stop, so they reach $V$ by step $n$.
A basis adapted to these kernels makes $T$ strictly upper triangular, because $T$ moves each kernel into the previous one.
The triangular determinant gives $t^n$, and Cayley-Hamilton closes the cycle.

## Variants

Without Cayley-Hamilton, $4 \Rightarrow 1$ follows over the algebraic closure from triangularization and the [[strictly triangular power argument|AW5RBMW7RK]].
For $1 \Rightarrow 2$, one can also use the minimal polynomial: it divides $t^k$, so it is $t^j$, and it divides $p_T$, which has degree $n$.
