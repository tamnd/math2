## Summary

Let $\mathcal{M}$ be an $L$-[[structure|983GZBQYT4]] and let $\varphi(x_1, \dots, x_n, y)$ be an $L$-[[formula|HYJ10AF6RT]].
A *Skolem function* for $\varphi$ in $\mathcal{M}$ is a function $f \colon M^n \to M$ such that $\mathcal{M} \models \exists y \, \varphi(\bar a, y)$ implies $\mathcal{M} \models \varphi(\bar a, f(\bar a))$ for all $\bar a \in M^n$; for $n = 0$ it is an element.
An $L$-theory $T$ is a *Skolem theory* when for every formula $\varphi(\bar x, y)$ there is a function symbol $f$ of $L$ with $T \models \forall \bar x \, (\exists y \, \varphi(\bar x, y) \to \varphi(\bar x, f(\bar x)))$.
If $\mathcal{M}$ is a model of a Skolem theory and $A \subseteq M$, the *Skolem hull* of $A$ is the [[substructure|676H7EGTKJ]] of $\mathcal{M}$ generated by $A$.
Skolem hulls are [[elementary substructures|8WZF9SBP39]] of a controlled size, and they are the standard way to build small elementary substructures.

## Motivation

The [[Tarski-Vaught test|60SA99BER7]] says that a subset is elementary when it contains a witness for each existential formula with parameters in it.
Closing a set under witnesses requires a choice of witnesses, and a function that makes this choice is a Skolem function.
When these functions are symbols of the signature, closure under witnesses becomes closure under the operations of the structure.
Then elementary substructures are the substructures, and the algebra of generated substructures applies.

## Notation

The Skolem hull of $A$ is written $\mathrm{Sk}(A)$, $\mathrm{Hull}(A)$ or $H(A)$.
The Skolem expansion of $L$ is written $L^{\mathrm{Sk}}$ or $L^*$, and the corresponding theory $T^{\mathrm{Sk}}$.
Some books write $f_\varphi$ for the Skolem function of $\varphi$; other books call a theory with built-in Skolem functions a theory "with Skolem functions".

## Remarks

### Examples

- In $(\Q, <)$ with Skolem functions that choose midpoints and the neighbors $x - 1$ and $x + 1$, the Skolem hull of $\emptyset$ is the set of dyadic rationals; see [[this example|~f06ac29b]].
- In the real field, the formula $y \cdot y = x$ has the Skolem function $x \mapsto \sqrt{x}$ for $x \ge 0$ and $x \mapsto 0$ otherwise, and it is $0$-definable; see [[this example|~aee599ed]].
- In a group, the inverse map is a Skolem function for $x \cdot y = e$; see [[Skolem functions for the group axioms|WPZWBJ8FN4]].
- In $(\N, <)$ the map "the least witness, or $0$ if there is none" is a $0$-definable Skolem function for each formula, because $\N$ is well ordered. The hull of $\emptyset$ is all of $\N$.

### Non-examples

- In the complex field there is no $0$-definable Skolem function for $y \cdot y = x$: complex conjugation would have to fix the value at $-1$. See [[this non-example|~ad253bd2]].
- In $(\C, +, -, \cdot, 0, 1)$ the substructure generated by $\emptyset$ is $\Z$, and it is not elementary, because $\exists y \, (y + y = 1)$ holds in $\C$ and fails in $\Z$. The operations of $L$ alone are not Skolem functions.
- A function that picks witnesses only for quantifier-free formulas does not give elementary hulls: closing a subset of $(\Z, <)$ under "a point above $x$" and "a point below $x$" can give $2\Z$, which is not elementary in $\Z$.

### Basic properties

- Skolemization: with the [[axiom of choice|0HTGB13FE2]], every $L$-theory $T$ extends to a Skolem theory $T^{\mathrm{Sk}}$ in a signature $L^{\mathrm{Sk}} \supseteq L$ with $\abs{L^{\mathrm{Sk}}} = \abs{L} + \aleph_0$. Every model of $T$ [[expands|EY20BF96SJ]] to a model of $T^{\mathrm{Sk}}$.
- In a model of a Skolem theory, every substructure is an elementary substructure, by the Tarski-Vaught test.
- So the Skolem hull $\mathrm{Sk}(A)$ satisfies $A \subseteq \mathrm{Sk}(A) \preceq \mathcal{M}$ and $\abs{\mathrm{Sk}(A)} \le \abs{A} + \abs{L} + \aleph_0$.
- This gives the downward [[Löwenheim-Skolem theorem|484M0TZ1S7]]; see [[the proof by Skolem hulls|~44c2d2c2]].
- The [[Skolem normal form|Q5H7C57VNH]] replaces existential quantifiers in one sentence by new function symbols, with the same idea.

### History

Thoralf Skolem used functions of this kind in his 1920 proof of the Löwenheim-Skolem theorem, which relies on the axiom of choice.
The functions and the Skolem normal form carry his name.

### Common errors

- The Skolem hull is the closure under the Skolem functions, not the $L$-substructure generated by $A$.
- Skolem functions are not unique, so the hull depends on the chosen expansion. Two Skolem expansions can give different hulls of the same set.
- The theory $T^{\mathrm{Sk}}$ is not equivalent to $T$. It is a conservative extension: it proves the same $L$-sentences.

## Explanations

### L1 human

Many statements say "there is something with a property", for example "for every number $x \ge 0$ there is a number $y$ with $y \cdot y = x$".
A Skolem function is a rule that picks one such thing each time, here the rule $x \mapsto \sqrt{x}$.
Start with a few elements and apply all such rules again and again.
The result is a collection that already contains an answer to every question of this kind about its own elements.
For example, starting from $4$ in the real numbers, the square root rule adds $2$, then $\sqrt{2}$, then $\sqrt[4]{2}$, and so on.

### L2 human

We compute part of a Skolem hull in the field $\R$.

1. Let $f$ be the square root Skolem function of the second example, and let $A = \set{2}$.
2. The field operations and $f$ produce $\sqrt{2}$, $1 + \sqrt{2}$, $\sqrt{1 + \sqrt{2}}$, and so on.
3. Each of these numbers is algebraic over $\Q$, because the algebraic numbers form a field closed under square roots.
4. A full Skolem hull also closes under Skolem functions for other formulas, for example "a root of an odd degree polynomial with these coefficients".
5. Every such witness can be chosen algebraic, and with these choices the hull of $\set{2}$ is the field of [[real algebraic numbers|~76723848]].

The typical use is to produce an elementary substructure that contains a given set and has the smallest possible size.
A trap is to forget the choices: with a Skolem function that picks a transcendental number when there is a choice, the hull of $\set{2}$ can contain $\pi$.

### L3 human

Skolem functions turn the existential quantifier into an operation, so the class of models of a Skolem theory is closed under substructures, and elementary substructures become algebraic objects.
This is the setting of the Ehrenfeucht-Mostowski construction, in the sub-area on [[indiscernibles|W9CHA4PD9H]]: the Skolem hull of a sequence of indiscernibles is a model whose automorphisms come from order automorphisms of the sequence.
A theory has definable Skolem functions when the Skolem functions can be chosen $0$-definable in each model; real closed fields and, more generally, o-minimal expansions of ordered groups have this property, and then no choice is needed.
In set theory, Skolem hulls of sets of ordinals in models of the form $L_\alpha$ are the basic tool of fine structure theory, where the definable well order of $L$ gives canonical Skolem functions.
