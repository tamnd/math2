## Example

Let $R$ be a new binary relation symbol, and let $A(x) := (\forall u \le x)(\exists v \le x) R(u, v)$.
The formula $A(x)$ is a [[$\Delta_0(R)$ formula|GE43CSZTS9]].
It says that $R$ is total on $\set{0, \dots, x}$.
We compute its [[Paris-Wilkie translation|~c9c38d6d]] at $x = n$, with one variable $p_{i, j}$ for each atom $R(i, j)$.

1. The instance is $A(n) = (\forall u \le n)(\exists v \le n) R(u, v)$. The bound $n$ is a closed term with the value $n$.
2. The universal quantifier becomes a conjunction: $A(n)^{\mathrm{PW}} = \bigwedge_{i = 0}^{n} \big((\exists v \le n) R(i, v)\big)^{\mathrm{PW}}$.
3. Each existential quantifier becomes a disjunction: $\big((\exists v \le n) R(i, v)\big)^{\mathrm{PW}} = \bigvee_{j = 0}^{n} R(i, j)^{\mathrm{PW}}$.
4. The atom $R(i, j)$ has the closed terms $i$ and $j$, so it becomes $p_{i, j}$.
5. So $A(n)^{\mathrm{PW}} = \bigwedge_{i = 0}^{n} \bigvee_{j = 0}^{n} p_{i, j}$, a formula in conjunctive normal form.
6. Size: there are $n + 1$ clauses with $n + 1$ variables each, so $(n + 1)^2$ occurrences of variables. Depth: $2$.
7. For $n = 1$ the translation is $(p_{0,0} \lor p_{0,1}) \land (p_{1,0} \lor p_{1,1})$.
8. Truth: an assignment is a relation $X \subseteq \set{0, \dots, n}^2$. The formula is true if and only if every $i \le n$ has some $j \le n$ with $(i, j) \in X$, as $A(n)$ says.

## Remarks

The example shows the pattern of the translation: each bounded quantifier gives one level of $\bigwedge$ or $\bigvee$, and each atom with $R$ gives one variable.
The formula $A(n)^{\mathrm{PW}}$ is not a [[tautology|05006AJ7DZ]]: the assignment with all variables false makes it false.
This matches the fact that $\forall x \, A(x)$ fails when $R$ is empty, so the Paris-Wilkie theorem does not apply.
If the quantifiers are exchanged, $(\exists v \le n)(\forall u \le n) R(u, v)$ translates to $\bigvee_{j} \bigwedge_{i} p_{i, j}$, a formula in disjunctive normal form.
If the bound $n$ is replaced by $n \cdot n$, the size grows to $(n^2 + 1)^2$, which is still polynomial in $n$.

## Explanations

### L1 human

Take three people $0$, $1$, $2$, and the statement "each person likes somebody among the three".
Written out in full, it says: "$0$ likes $0$, $1$ or $2$; and $1$ likes $0$, $1$ or $2$; and $2$ likes $0$, $1$ or $2$".
Each part "$i$ likes $j$" is a switch that is on or off, so there are $9$ switches.
The written-out statement is true exactly when each of the three groups has a switch that is on.

### L2 human

We translate the same formula at $n = 2$ and test two assignments.

1. The translation is $(p_{0,0} \lor p_{0,1} \lor p_{0,2}) \land (p_{1,0} \lor p_{1,1} \lor p_{1,2}) \land (p_{2,0} \lor p_{2,1} \lor p_{2,2})$.
2. Take $X = \set{(0, 1), (1, 1), (2, 0)}$. The variables $p_{0,1}$, $p_{1,1}$ and $p_{2,0}$ are true, one in each clause, so the formula is true.
3. Take $X = \set{(0, 1), (1, 2)}$. The third clause has no true variable, so the formula is false.
4. In $\N$ with $R$ read as the second $X$, the number $2$ has no $v \le 2$ with $R(2, v)$, so $A(2)$ is false, as the translation says.

The typical use is to read off the depth and the size of translations before one applies a lower bound for constant-depth proofs.
A trap is to give $p_{i, j}$ and $p_{j, i}$ the same name: the atoms $R(i, j)$ and $R(j, i)$ are different.
