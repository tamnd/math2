## Example

A student writes "define $\varphi \colon \mathbb{Z}/6\mathbb{Z} \to \mathbb{Z}$ by $\varphi([a]) = a$".
We show that this rule does not define a [[function|0EPAT51DXQ]].

1. The class $[0]$ in $\mathbb{Z}/6\mathbb{Z}$ is $\{\ldots, -6, 0, 6, 12, \ldots\}$, so $[0] = [6]$.
2. The rule gives $\varphi([0]) = 0$ and $\varphi([6]) = 6$.
3. A function assigns one value to each input, but here one input gets the two values $0$ and $6$, and $0 \ne 6$.
4. So $\varphi$ is not well defined, and the formula $\varphi([a]) = a$ names no function.
5. The short form "$\varphi(a) = a$" is not an [[abuse of notation|~6c049b35]], because no exact form of it is correct.

## Remarks

The example marks the limit of the abuse "a class is named by a member".
The abuse is safe for addition and multiplication, because their results do not depend on the member.
A formula for a map out of $\mathbb{Z}/6\mathbb{Z}$ must give the same value for every member of a class.
A correct version picks one member: $\psi([a]) = $ the remainder of $a$ on division by $6$, which lies in $\{0, 1, \ldots, 5\}$.
Then $\psi([0]) = \psi([6]) = 0$, and $\psi$ is a function, though it does not respect addition, since $\psi([3] + [3]) = 0 \ne 6 = \psi([3]) + \psi([3])$.

## Explanations

### L1 human

On a clock with $6$ hours, the hour $0$ and the hour $6$ are the same hour.
Suppose a rule says "turn the hour into the number you see".
Then the same hour could give $0$ or $6$, depending on how we wrote it.
A rule that gives two answers for one input is not a function.

### L2 human

We test a second rule, $\chi \colon \mathbb{Z}/6\mathbb{Z} \to \mathbb{Z}/3\mathbb{Z}$ with $\chi([a]_6) = [a]_3$, and show that it is well defined.

1. Suppose $[a]_6 = [b]_6$. Then $6$ divides $a - b$.
2. Since $3$ divides $6$, $3$ also divides $a - b$, so $[a]_3 = [b]_3$.
3. So the value of $\chi$ does not depend on the member, and $\chi$ is a function.
4. The reverse rule from $\mathbb{Z}/3\mathbb{Z}$ to $\mathbb{Z}/6\mathbb{Z}$ fails: $[0]_3 = [3]_3$, but $[0]_6 \ne [3]_6$.

The typical use of this check is the definition of a homomorphism out of a quotient group.
A trap: a formula that looks natural can still depend on the member; the check of step 1 and step 2 is always needed.
