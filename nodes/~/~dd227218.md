## Statement

Let $F$ be a field, let $n \ge 1$, and let $p = x^n + c_{n-1} x^{n-1} + \cdots + c_0 \in F[x]$ be monic.
Let $C = C(p)$ be its [[companion matrix|0VH1TC1PWF]] in the column version.
Then:

1. $C^{i-1} e_1 = e_i$ for $1 \le i \le n$, so $e_1$ is a cyclic vector of $C$;
2. the [[minimal polynomial|03NDVCSHSB]] of $C$ is $p$;
3. the [[characteristic polynomial|039HF58KQ5]] $\det(xI - C)$ of $C$ is $p$.

The same holds for the row version $C^{\mathsf T}$.

## Remarks

### Why each hypothesis is needed

The polynomial must be monic, since minimal and characteristic polynomials are monic.
For a polynomial $a p$ with $a \ne 0, 1$, first divide by $a$.
The result holds over every field, and over every commutative ring for part 3.

### Consequences

- Every monic polynomial of degree $n \ge 1$ is the characteristic polynomial of some $n \times n$ matrix.
- $C(p)$ is diagonalizable over $F$ if and only if $p$ splits over $F$ into distinct linear factors.
- If $p = (x - \lambda)^n$, then $C(p)$ is [[similar|027KDW2K72]] to the [[Jordan block|07PH4RX0X5]] $J_n(\lambda)$, since both are cyclic with the same characteristic polynomial.
- The roots of $p$ in $F$ are exactly the eigenvalues of $C(p)$ in $F$.

### Converse

A matrix whose minimal and characteristic polynomials are both $p$ need not be equal to $C(p)$.
But it is similar to $C(p)$, by the [[criterion for cyclic maps|~55322f5b]].

### Generalizations

Over a commutative ring $R$, $\det(xI - C(p)) = p$ still holds, by the same cofactor expansion.
The block companion matrix of a monic matrix polynomial $x^k I + A_{k-1} x^{k-1} + \cdots + A_0$ has characteristic polynomial $\det(x^k I + \cdots + A_0)$.

## Explanations

### L1 human

The companion matrix of a polynomial is built so that its characteristic polynomial is that polynomial.
The theorem also says that no shorter polynomial kills the matrix.
For example, the matrix with columns $0, 1$ and $-1, 0$ is a quarter turn of the plane.
Turning twice gives minus the identity, so $x$ squared plus one kills it, and nothing shorter does.

### L2 human

Let $p = x^3 - 1$ over $\mathbb{Q}$, so $C = C(p)$ has columns $e_2$, $e_3$, $e_1$.

1. $C e_1 = e_2$ and $C^2 e_1 = e_3$, as part 1 says.
2. $C^3 e_1 = C e_3 = e_1$. So $(C^3 - I) e_1 = 0$.
3. Every $e_i$ is $C^{i-1} e_1$, so $(C^3 - I) e_i = C^{i-1} (C^3 - I) e_1 = 0$. So $C^3 = I$.
4. A nonzero polynomial $a_0 + a_1 x + a_2 x^2$ gives $(a_0 I + a_1 C + a_2 C^2) e_1 = (a_0, a_1, a_2) \ne 0$. So $m_C = x^3 - 1$.

The typical use is to produce a matrix with a prescribed characteristic polynomial.
The trap is to think that $C(p)$ is diagonalizable when $p$ has distinct roots in some larger field.
Over $\mathbb{Q}$, $x^3 - 1$ has the factor $x^2 + x + 1$ with no rational roots, so $C$ is not diagonalizable over $\mathbb{Q}$.

### L3 human

The matrix $C(p)$ is the matrix of multiplication by $x$ on the $F[x]$-module $F[x]/(p)$ in the basis $1, x, \dots, x^{n-1}$.
The annihilator of this module is the ideal $(p)$, which gives part 2 at once.
The [[rational canonical form|042JWAR3Q0]] writes every matrix as a block diagonal matrix of companion matrices, and so reduces all of similarity theory to this one example.
