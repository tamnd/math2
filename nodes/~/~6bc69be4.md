## Description

The natural numbers are the numbers $0, 1, 2, 3, \dots$ that count the elements of a finite set.
We write $\mathbb{N} = \{0, 1, 2, 3, \dots\}$ for the set of natural numbers.
Each natural number $n$ has a next natural number $n + 1$, its successor.
The [[Peano axioms|~85dcaa42]] describe $\mathbb{N}$ with the number $0$ and the [[successor function|~849ef9dc]].
The [[addition|~e45f9549]], the [[multiplication|~8a70c676]] and the [[order|~120f06ca]] of $\mathbb{N}$ come from $0$ and the successor function.

## Remarks

Some authors start the natural numbers at $1$. They then write $\mathbb{N}_0$ or $\mathbb{Z}_{\ge 0}$ for the set $\{0, 1, 2, \dots\}$.
Every nonempty set of natural numbers has a least element. This is the [[well-ordering principle|~e843d518]].
The [[integers|~3fed16db]] contain the natural numbers as the integers that are not negative.

## Explanations

### L1 human

The natural numbers are the numbers that you use to count: zero, one, two, three, and so on.
There is no largest natural number, because you can always add one more.
All the other number systems of this course, such as the integers and the real numbers, start from the natural numbers.
