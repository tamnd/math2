## Example

Let $\mathbb{P}$ be the set of [[prime numbers|01826KMG2H]].
We show that almost all primes are odd, in the cofinite sense of [[almost all|N1XSAXCQY3]]: the set of primes that are not odd is finite.

1. Let $p$ be a prime that is not odd. Then $p$ is even, so $2$ [[divides|0PG2H7WKGG]] $p$.
2. A prime has exactly two positive divisors, $1$ and itself. Since $2$ is a positive divisor of $p$ and $2 \neq 1$, we get $2 = p$.
3. The number $2$ is prime and even. So the set of exceptions is exactly $\{2\}$.
4. The set $\{2\}$ has one element, so it is finite.
5. The set $\mathbb{P}$ is infinite, by [[Euclid's theorem|0292EPPPT0]]. So the statement is about an infinite set, and the cofinite sense applies to it with content.
6. So all primes except finitely many are odd, which is the claim.

## Remarks

The example shows the simplest sense of "almost all": all but finitely many.
On an infinite set, a finite set of exceptions is also of density zero among the primes, so the statement holds in the density sense too.
Step 5 matters: on a finite set every property holds for all but finitely many elements, so the cofinite sense says nothing there.
If we change "odd" to "at least $1000$", the statement stays true, with the $168$ primes below $1000$ as exceptions.
If we change "odd" to "of the form $4k + 1$", the statement becomes false: the primes of the form $4k + 3$, such as $3, 7, 11, 19$, form an infinite set by [[Dirichlet's theorem on arithmetic progressions|0GNVN3CA2P]].

## Explanations

### L1 human

The prime numbers are $2, 3, 5, 7, 11, 13, \ldots$, and only the first one is even.
Every other even number has $2$ as a factor, and so it is not prime.
So the list of primes contains exactly one even number and infinitely many odd numbers.
Mathematicians say that almost all primes are odd: the exceptions are so few that we can count them on one finger.

### L2 human

We check the claim and its use in a proof.

1. Let $p$ and $q$ be primes with $p + q$ odd. One of $p, q$ is even, since the sum of two odd numbers is even.
2. By steps 1 to 3, an even prime equals $2$. So one of $p, q$ is $2$.
3. For example, $p + q = 15$ forces $\{p, q\} = \{2, 13\}$, and $p + q = 27$ has no solution, because $27 - 2 = 25$ is not prime.

The typical use of the example is the phrase "let $p$ be an odd prime", which removes the single exception $2$ at the start of a proof.
A trap: "almost all primes are odd" is not a reason to ignore $p = 2$ in a proof about all primes; the case $p = 2$ must be checked on its own.
