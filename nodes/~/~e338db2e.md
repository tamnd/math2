## Example

Consider the claim "a group of order $4$ is unique up to isomorphism".
We show that it is false, with two groups.

- $\mathbb{Z}/4\mathbb{Z} = \{[0], [1], [2], [3]\}$ with addition modulo $4$, see [[integers modulo $n$|03VFZ2WETT]].
- The [[Klein four-group|0PMRQJVTME]] $V = \{(0,0), (1,0), (0,1), (1,1)\}$ with addition modulo $2$ in each coordinate.

1. Both groups have $4$ elements.
2. In $\mathbb{Z}/4\mathbb{Z}$, the element $[1]$ has [[order|0WE2NHZJ7B]] $4$: the multiples $[1], [2], [3]$ are nonzero, and $4 \cdot [1] = [0]$.
3. In $V$, each element $v$ satisfies $v + v = (0, 0)$. So each element has order $1$ or $2$.
4. A [[group isomorphism|08MG7H8JW5]] $\varphi$ preserves orders: $k\varphi(g) = \varphi(kg)$, and $\varphi$ is injective, so $kg = 0$ exactly when $k\varphi(g) = 0$.
5. So an isomorphism $\mathbb{Z}/4\mathbb{Z} \to V$ would map $[1]$ to an element of order $4$, and $V$ has none.
6. So the two groups are not isomorphic, and "the group of order $4$" is not legal, even [[up to|~2311cd14]] isomorphism.

## Remarks

1. Each group of order $4$ is isomorphic to one of these two groups. So the groups of order $4$ form exactly two isomorphism classes.
2. For each prime $p$, the groups of order $p$ form one class: each is cyclic by Lagrange's theorem. So "the group of order $p$" is legal up to isomorphism.
3. The proof finds an invariant, here "has an element of order $4$", that isomorphisms preserve and that the two groups do not share. This is the standard way to disprove an isomorphism.

## Explanations

### L1 human

Think of a rectangular card that is not a square, lying in a frame on a table.
It fits the frame in four ways: the start, a half turn, a flip across the long side, and a flip across the short side.
Each of these moves, done twice, brings the card back to the start.
Now think of a square card and quarter turns: it takes four quarter turns to come back.
Both have four moves, but they behave differently.
So the number of moves does not tell us how the moves combine.

### L2 human

We use an invariant to decide whether $\mathbb{Z}/2\mathbb{Z} \times \mathbb{Z}/2\mathbb{Z}$ is isomorphic to the group of units of $\mathbb{Z}/8\mathbb{Z}$.

1. The units modulo $8$ are $[1], [3], [5], [7]$, so the group has order $4$.
2. Check squares: $3^2 = 9$, $5^2 = 25$ and $7^2 = 49$, and each is $1$ modulo $8$.
3. So each element has order $1$ or $2$, and no element has order $4$.
4. By remark 1, a group of order $4$ with no element of order $4$ is isomorphic to $V$. So the units modulo $8$ form a copy of $V$.

The typical use: count elements of each order to separate or to identify small groups.
A trap is to stop at the order of the group, which does not determine the group.
