## Example

Let $\mathsf{RT}^3_2$ be the statement: for every colouring $c$ of the three-element subsets of $\N$ with colours $0$ and $1$, there is an infinite set $H$ such that $c$ is constant on the three-element subsets of $H$.
We show that $\mathsf{RT}^3_2$ implies [[ACA0|~08f6623a]] over [[RCA0|~58b63877]].
We use the following lemma about $\mathsf{ACA}_0$, which we cite: over $\mathsf{RCA}_0$, arithmetical comprehension follows from the statement "every [[one-to-one function|09NWETVTNY]] $f : \N \to \N$ has a range", that is, a set $R$ with $n \in R \iff \exists i\, f(i) = n$.
We argue in $\mathsf{RCA}_0 + \mathsf{RT}^3_2$, and we fix a one-to-one function $f : \N \to \N$.

1. For $x < y < z$, put $c(\set{x, y, z}) = 1$ if some $i$ with $y \le i < z$ has $f(i) < x$, and $c(\set{x, y, z}) = 0$ otherwise. The quantifier on $i$ is bounded by $z$, so $c$ exists by $\Delta^0_1$ comprehension.
2. By $\mathsf{RT}^3_2$ there is an infinite set $H$ on whose triples $c$ is constant. Let $h_0 < h_1 < h_2 < \cdots$ be the elements of $H$ in increasing order.
3. Suppose the constant colour is $1$. Put $x = h_0$ and look at the $x + 1$ intervals $[h_j, h_{j+1})$ for $j = 1, \dots, x + 1$.
4. For each such $j$, the triple $\set{x, h_j, h_{j+1}}$ has colour $1$, so some $i_j$ with $h_j \le i_j < h_{j+1}$ has $f(i_j) < x$.
5. The intervals are disjoint, so the numbers $i_1, \dots, i_{x+1}$ are distinct. Since $f$ is one-to-one, the $x + 1$ values $f(i_j)$ are distinct and all lie in $\set{0, \dots, x - 1}$.
6. This contradicts the finite [[pigeonhole principle|0HGVCWQGY3]], which $\mathsf{RCA}_0$ proves. So the constant colour is $0$.
7. Let $x < y$ be in $H$ and let $n < x$. We claim: $n$ is in the range of $f$ if and only if $f(i) = n$ for some $i < y$.
8. The direction from right to left holds by definition. For the other direction, let $f(i) = n$ with $i \ge y$. Choose $z \in H$ with $z > i$, which exists because $H$ is infinite.
9. Then $y \le i < z$ and $f(i) = n < x$, so $c(\set{x, y, z}) = 1$. This contradicts step 6, so no such $i$ exists, and the claim holds.
10. For each $n$, let $k(n)$ be the least $k$ with $h_k > n$. Define $R$ by: $n \in R$ if and only if $f(i) = n$ for some $i < h_{k(n) + 1}$.
11. The definition of $R$ uses only the function $k \mapsto h_k$, which $\mathsf{RCA}_0$ proves to exist, and bounded quantifiers. So $R$ exists by $\Delta^0_1$ comprehension.
12. By step 7 with $x = h_{k(n)}$ and $y = h_{k(n)+1}$, the set $R$ is exactly the range of $f$.
13. So every one-to-one function has a range, and the cited lemma gives $\mathsf{ACA}_0$.

Conversely, $\mathsf{ACA}_0$ proves $\mathsf{RT}^3_2$, and indeed Ramsey's theorem for $n$-element sets and $k$ colours for each fixed $n$ and $k$.
So $\mathsf{RT}^3_2$ is equivalent to $\mathsf{ACA}_0$ over $\mathsf{RCA}_0$.

## Remarks

This shows that $\mathsf{RT}^3_2$ is not a member of the [[reverse mathematics zoo|~00f7bd45]]: its strength is exactly one of the Big Five.
The step from triples to pairs changes everything: for pairs, step 1 has no room for the bound $x$, and Seetapun showed that $\mathsf{RT}^2_2$ does not imply $\mathsf{ACA}_0$.
Ramsey's theorem for all $n$ at once, $\forall n\, \mathsf{RT}^n_2$, is stronger than $\mathsf{ACA}_0$, and the Wikipedia article on [[Ramsey's theorem|00TQV3F5S4]] notes that it proves the Paris-Harrington theorem.

## Explanations

### L1 human

The range of a function is the set of all its values.
For a general function on the natural numbers, finding the range needs an infinite search, and this is what arithmetical comprehension provides.
Ramsey's theorem for triples gives a special infinite set $H$ of "checkpoints".
Between two checkpoints $x < y$, every value smaller than $x$ that the function ever takes has already appeared before position $y$.
So the infinite search becomes a finite one, and the range can be computed from $H$.

### L2 human

Take $f(i) = i + 1$, so that the range of $f$ is $\set{1, 2, 3, \dots}$.

1. For $x < y < z$, some $i \in [y, z)$ has $i + 1 < x$ only if $y + 1 < x$, which fails since $y > x$. So every triple has colour $0$, and $H = \N$ is homogeneous.
2. For $n = 3$, we have $k(3) = 4$ and $h_{k(3)+1} = 5$. The search for $i < 5$ with $i + 1 = 3$ finds $i = 2$, so $3 \in R$.
3. For $n = 0$, the search for $i < 2$ with $i + 1 = 0$ fails, so $0 \notin R$.

The typical use of this argument is to show that a combinatorial principle reaches $\mathsf{ACA}_0$: one codes the jump into the colouring.
The trap: the bound $x$ of step 1 must be the smallest element of the triple; with the bound on the wrong element, step 3 does not get $x + 1$ disjoint intervals.
