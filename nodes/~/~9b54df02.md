## Definition

Let $L_A$ be the [[language of arithmetic|~8c012030]].
For a formula $\varphi(x, y_1, \ldots, y_k)$ of $L_A$, whose free variables are among $x, y_1, \ldots, y_k$, the induction axiom $\mathrm{Ind}_\varphi$ is the sentence
$$\forall y_1 \cdots \forall y_k\, \Bigl( \bigl( \varphi(0, \vec{y}) \land \forall x\, (\varphi(x, \vec{y}) \to \varphi(S x, \vec{y})) \bigr) \to \forall x\, \varphi(x, \vec{y}) \Bigr).$$
*Peano arithmetic* $\mathsf{PA}$ is the first-order [[theory|FZRMYTQFRR]] in $L_A$ whose axioms are:

1. the eight axioms $\mathsf{Q}1$ to $\mathsf{Q}8$ of [[Robinson arithmetic|TT8MXRTVBM]];
2. the axiom $\mathrm{Ind}_\varphi$ for every formula $\varphi$ of $L_A$.

## Notation

The variables $y_1, \ldots, y_k$ are the parameters of the induction axiom, and $x$ is the induction variable.
The set of axioms in item 2 is the [[induction schema|~59894b26]].
For a class $\Gamma$ of formulas, $\mathsf{I}\Gamma$ is the theory with item 2 restricted to $\varphi \in \Gamma$.

## Remarks

Axiom $\mathsf{Q}3$ is redundant: $\mathsf{PA}$ proves it from the other axioms by induction on $\varphi(x) := x = 0 \lor \exists y\,(x = S y)$.
Many books therefore list only $\mathsf{Q}1$, $\mathsf{Q}2$ and $\mathsf{Q}4$ to $\mathsf{Q}7$ with the schema, and define $<$ separately.
For the full schema the parameters can be removed.
Parameter-free induction on $x$ for $\forall \vec{y}\,\bigl((\varphi(0, \vec{y}) \land \forall u\,(\varphi(u, \vec{y}) \to \varphi(S u, \vec{y}))) \to \varphi(x, \vec{y})\bigr)$ gives $\mathrm{Ind}_\varphi$.
For a restricted class $\Gamma$ this trick raises the complexity of the formula, and parameter-free $\Gamma$-induction can be weaker.
The set of axioms is infinite but decidable, since one can check by an algorithm whether a string is an instance of the schema.
The [[concept page|~b3b2d1f3]] describes what $\mathsf{PA}$ proves and its models.

## Explanations

### L1 human

Peano arithmetic is Robinson arithmetic plus one induction rule for each property that a formula can express.
The rule for a property says: if $0$ has it, and each number that has it passes it to the next number, then all numbers have it.
The extra letters $y_1, \ldots, y_k$ let the property depend on other fixed numbers.

### L2 human

We write out the induction axiom for $\varphi(x, y) := x + y = y + x$.

1. The parameter is $y$, and the induction variable is $x$.
2. $\varphi(0, y)$ is $0 + y = y + 0$.
3. $\varphi(S x, y)$ is $S x + y = y + S x$.
4. So $\mathrm{Ind}_\varphi$ is $\forall y\,\bigl((0 + y = y + 0 \land \forall x\,(x + y = y + x \to S x + y = y + S x)) \to \forall x\,(x + y = y + x)\bigr)$.

The typical use of the definition is to check that a proof in $\mathsf{PA}$ uses only instances of the schema.
A trap is to substitute $S x$ for $x$ where $x$ is bound inside $\varphi$; the substitution acts on free occurrences only.
