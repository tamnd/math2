## Example

We show that $(\Z, <)$ is not [[ultrahomogeneous|~7468669e]].

1. The map $p$ with $p(0) = 0$ and $p(1) = 2$ is an order isomorphism from $\set{0, 1}$ onto $\set{0, 2}$.
2. Suppose $\sigma$ is an order [[automorphism|DSQ17TNW1C]] of $\Z$ that extends $p$.
3. The set $\set{x : 0 < x < 1}$ is empty, so its image $\set{y : 0 < y < 2}$ under $\sigma$ is empty.
4. But $1$ lies strictly between $0$ and $2$, a contradiction.

## Remarks

The automorphisms of $(\Z, <)$ are the translations $x \mapsto x + k$.
So an automorphism preserves the distance $\lvert x - y \rvert$, while an isomorphism of finite substructures need not.
The age of $(\Z, <)$ equals the age of $(\Q, <)$, so $(\Z, <)$ is a structure with the right age that is not the Fraïssé limit.
The weak homogeneity also fails: the embedding $\set{0 < 1} \to \Z$ given by the identity does not extend to $\set{0 < \frac12 < 1}$.

## Explanations

### L1 human

In the integers, $0$ and $1$ are neighbors, while $0$ and $2$ have a point between them.
A symmetry of the integers keeps neighbors as neighbors.
So it cannot send the pair $0, 1$ onto the pair $0, 2$.

### L2 human

We list the automorphisms of $(\Z, <)$.

1. Let $\sigma$ be an order automorphism, and let $k = \sigma(0)$.
2. The successor $1$ of $0$ must go to the successor of $k$, so $\sigma(1) = k + 1$.
3. By induction in both directions, $\sigma(x) = x + k$ for all $x$.

The typical use is to separate "same age" from "same structure".
A trap is to think that $\Z$ fails only because it is discrete; a dense order with endpoints, like $\Q \cap [0, 1]$, also fails.
