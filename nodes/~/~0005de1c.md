## Example

Let $\mathcal{R} = (\R, 0, 1, +, \cdot)$, the field of real numbers without a symbol for the order, and let $\sigma$ be an [[automorphism|DSQ17TNW1C]] of $\mathcal{R}$.

1. In $\R$, $x \ge 0$ holds exactly when $x = y \cdot y$ for some $y$. So the order of the [[ordered field|0P3VCBDEE2]] $\R$ is definable in the field language.
2. If $x = y \cdot y$, then $\sigma(x) = \sigma(y) \cdot \sigma(y)$. So $\sigma$ maps nonnegative reals to nonnegative reals, and $\sigma$ preserves the order.
3. The automorphism fixes $1$, hence every integer, and hence every rational number $m/n$, since $\sigma(m/n) \cdot \sigma(n) = \sigma(m)$.
4. Suppose $\sigma(r) \ne r$, say $\sigma(r) < r$. By the [[Archimedean property|0A74SX55QP]], some rational $q$ has $\sigma(r) < q < r$.
5. From $q < r$ and step 2, $q = \sigma(q) < \sigma(r)$, which contradicts $\sigma(r) < q$. The case $r < \sigma(r)$ is the same.
6. So $\sigma$ is the identity, and $\mathcal{R}$ is [[rigid|~18c508c5]].

## Remarks

The number $\pi$ is fixed by every automorphism of $\mathcal{R}$, but it is not in $\operatorname{dcl}(\emptyset)$: the definable closure of $\emptyset$ in $\R$ is the field of real algebraic numbers.
So rigidity does not imply that every element is definable; see [[algebraic and definable closure|~07008141]].
An elementary extension of $\mathcal{R}$ that is saturated is not rigid.

## Explanations

### L1 human

A symmetry of the real numbers that respects addition and multiplication must keep squares as squares, so it keeps the order.
It also keeps every fraction in place.
An order-preserving map that fixes every fraction fixes every real number, since reals are squeezed between fractions.

### L2 human

The proof has three steps that work for many ordered structures.

1. Show that the order is definable, so automorphisms preserve it.
2. Show that a dense set of elements is fixed.
3. Conclude that every element is fixed, by squeezing.

The typical use is to prove rigidity of Archimedean ordered structures.
The trap is to forget step 1: the field $\C$ has no definable order, and it has many automorphisms.
