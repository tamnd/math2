## Statement

Let $x$, $y$ and $z$ be [[integers|0C4JS9RF5M]].
Adding the same integer $z$ to both sides keeps the [[order|07J9ZJFECP]] of $x$ and $y$.

1. If $x \le y$, then $x + z \le y + z$.
2. If $x < y$, then $x + z < y + z$.

## Remarks

The law holds for every $z$, whether $z$ is positive, zero or negative.
Adding $-z$ to both sides of the conclusion gives back the hypothesis, so each part is also an equivalence.
