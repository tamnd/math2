## Example

A group of students computes $f(n) = n^2 + n + 41$ for $n = 0, 1, 2, 3, 4, 5$ and gets $41, 43, 47, 53, 61, 71$.
They check that each value is prime.
A student says: "So $n^2 + n + 41$ is probably prime for all $n$, unless we find a value where it is not."
We lay out this argument in the [[Toulmin model|~889806ec]].

1. Claim $C$: for each natural number $n$, the number $n^2 + n + 41$ is prime.
2. Data $D$: the six values above, each checked to be prime. For example, $71$ has no prime divisor $p$ with $p^2 \leq 71$, that is, none of $2, 3, 5, 7$.
3. Warrant $W$: a pattern that holds in all checked cases probably holds in general. This warrant is inductive.
4. Backing $B$: experience that patterns in small cases often continue.
5. Qualifier $Q$: "probably". The student states it.
6. Rebuttal $R$: "unless we find a value where it is not". The student states it too.
7. The rebuttal applies: $f(40) = 1600 + 40 + 41 = 1681 = 41^2$, which is not prime. So the claim is false.

## Remarks

The example shows all six parts of the model, including the qualifier and the rebuttal, which a deductive proof does not need.
The student's argument is a good [[conjecture|WMEMMHZ3BH]] with an honest qualifier, and the model records that the student did not claim certainty.
The page [[forty prime values of n^2 + n + 41 do not prove a statement|H75AB4EJT5]] gives the full computation for $n = 0$ to $39$.
With the rebuttal found, the class can make a new claim with a deductive warrant: "$f(41) = 41 \cdot 43$ is not prime, since $41^2 + 41 + 41 = 41(41 + 1 + 1)$."
A second case follows: $f(41) = 1763 = 41 \cdot 43$.

## Explanations

### L1 human

The students try six numbers and get a prime number each time.
They guess that this always happens, and they say "probably", which is honest.
They also say what would prove them wrong: one number where the result is not prime.
Such a number exists: for $n = 40$ the result is $1681 = 41 \cdot 41$.
The Toulmin model has a place for "probably" and for "unless", so it describes this argument well.

### L2 human

1. Claim: all values are prime.
2. Data: six prime values.
3. Warrant: an inductive rule, "what holds in the cases checked holds always".
4. Qualifier and rebuttal: stated by the student.
5. Test of the rebuttal: $n = 40$ gives $41^2$.

A trap is to call the student's argument a wrong proof.
The student did not claim a proof, and the model shows that the argument was a conjecture with a correct qualifier.
