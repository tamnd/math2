## Example

Let $L = \set{\cdot, {}^{-1}, e}$ be the signature of groups, with a binary function symbol, a unary function symbol and a constant symbol.
Let $T_{\mathrm{grp}}$ be the set of the three group axioms of the [[elementary theory of groups|RX9MB386C5]]:
$$\forall x \forall y \forall z \, ((x \cdot y) \cdot z = x \cdot (y \cdot z)), \quad \forall x \, (x \cdot e = x \land e \cdot x = x), \quad \forall x \, (x \cdot x^{-1} = e \land x^{-1} \cdot x = e).$$
We check that $T_{\mathrm{grp}}$ is a [[recursively axiomatizable theory|3ANXZC3BEG]], and we look at what this gives.

1. The signature is finite. Code its three symbols, the logical symbols and the variables $v_0, v_1, \dots$ by natural numbers, so that each string has a Gödel number.
2. The axiom set is $T_{\mathrm{grp}}$ itself. It has three members, so a program decides membership: it compares a given string with the three axioms, symbol by symbol. So $T_{\mathrm{grp}}$ is a [[computable set|PPGD5KW8JC]] of sentences.
3. By steps 1 and 2, $T_{\mathrm{grp}}$ is a recursive axiomatization of itself.
4. By property 3 of the main page, the set $\operatorname{Thm}(T_{\mathrm{grp}})$ is [[computably enumerable|TN9G24VABN]]: a program lists all derivations from $T_{\mathrm{grp}}$ and outputs their last lines.
5. By [[Gödel's completeness theorem|WQ1ZE255SF]] and soundness, $\operatorname{Thm}(T_{\mathrm{grp}})$ is the set of sentences true in every group. So the elementary theory of groups is computably enumerable.
6. The theory is not complete. Let $\sigma$ be $\forall x \forall y \, (x \cdot y = y \cdot x)$. The group $(\mathbb{Z}, +)$ satisfies $\sigma$.
7. In the symmetric group $S_3$, composing from right to left, $(1\,2)(1\,3) = (1\,3\,2)$ and $(1\,3)(1\,2) = (1\,2\,3)$. These differ, so $S_3$ does not satisfy $\sigma$.
8. By soundness, $T_{\mathrm{grp}} \nvdash \neg \sigma$ because of step 6, and $T_{\mathrm{grp}} \nvdash \sigma$ because of step 7. So property 5 of the main page does not apply.

## Remarks

The example shows that a recursive axiomatization gives a list of the theorems, not a test for them.
The set $\operatorname{Thm}(T_{\mathrm{grp}})$ is in fact not decidable, by a theorem of Tarski that is described in the [[elementary theory of groups|RX9MB386C5]].

The example changes when we change the axioms.

- Add $\sigma$: the axioms of abelian groups are still finite, and this theory is decidable by [[Szmielew's theorem|Y0753DF5R9]]. It is still not complete: $\exists x \, (\neg\, x = e \land x \cdot x = e)$ holds in $\mathbb{Z}/2\mathbb{Z}$ and fails in $(\mathbb{Z}, +)$.
- Add the infinitely many sentences $\tau_n = \forall x \, (x^n = e \to x = e)$ for $n \ge 2$: the axioms of torsion-free groups. This set is still decidable, by a test of the shape of a sentence, but it cannot be replaced by a finite set, as the example [[torsion-free groups need infinitely many axioms|APF4KHZ976]] shows.
- Try to axiomatize the torsion groups: no set of sentences at all does this, by Application C of [[applications of first-order compactness|~23a8e9a5]].

## Explanations

### L1 human

The rules of a group are three short sentences.
A computer can check whether a given sentence is one of these three rules by comparing letters.
So a computer can check any proof written from these rules, and it can list every theorem about all groups, one by one.
But the list does not settle every question.
The sentence "any two elements commute" is true in some groups and false in others, so it is not a theorem, and its negation is not a theorem either.

### L2 human

We decide membership in the set of torsion-free axioms $\set{\tau_n : n \ge 2}$, the second change in the Remarks.
We fix the spelling of $x^n$ with brackets to the left: $x^2 = (x \cdot x)$ and $x^{n+1} = (x^n \cdot x)$.

1. Take the string $\tau = \forall x \, (((x \cdot x) \cdot x) = e \to x = e)$.
2. The program checks that $\tau$ starts with $\forall x$ and that the rest has the form $(t = e \to x = e)$ for a term $t$. Here $t = ((x \cdot x) \cdot x)$.
3. The program counts the occurrences of $x$ in $t$: there are $n = 3$.
4. The program builds $x^3 = ((x \cdot x) \cdot x)$ and compares it with $t$. They agree, and $3 \ge 2$, so $\tau = \tau_3$ is an axiom.
5. For the string $\forall x \, ((x \cdot (x \cdot x)) = e \to x = e)$, step 4 fails, so the answer is "no". In every group this string says the same as $\tau_3$, but it is a different string.

The typical use is the first step of any undecidability or incompleteness proof: one checks that the axioms of the theory form a decidable set.
The trap is to think that finitely many axioms give a decidable theory; for groups they do not.
