## Proof

We use the notation of the [[statement|~62799b98]].
A string $u$ is an *initial segment* of a string $w$ when $w = u v$ for some string $v$.
We write $\abs{w}$ for the length of $w$.

1. Every term and every formula is a nonempty string. Reason: each clause of the definitions produces a nonempty string.
2. A term contains no $=$, no relation symbol, no connective and no quantifier. Reason: no clause for terms introduces these symbols, by induction on terms.
3. The first symbol of a term is a variable, a constant symbol or a function symbol, and it fixes the clause. Reason: a variable or a constant symbol alone is a term of length $1$, and the clause for $f(t_1, \dots, t_n)$ starts with $f$.
4. The first symbol of a formula is a term symbol, a relation symbol, $\neg$, a left bracket, $\forall$ or $\exists$. These six cases are disjoint, and they match the five forms of part 2 of the statement in order, with $\forall$ and $\exists$ together. Reason: each clause of the definition of formulas starts with one of these symbols, and the symbols are pairwise distinct.
5. Prefix lemma for terms: if $s$ and $t$ are terms and $s$ is an initial segment of $t$, then $s = t$. We prove this by strong induction on $\abs{t}$. Steps 6 to 8 give the proof.
6. If $t$ is a variable or a constant symbol, then $\abs{t} = 1$. By step 1, $s$ is nonempty, so $s = t$.
7. Let $t = f(t_1, \dots, t_n)$. Then $s$ starts with $f$, so by step 3, $s = f(s_1, \dots, s_n)$ with the same $n = \operatorname{ar}(f)$. Both $t_1$ and $s_1$ start right after "$f($", so one of them is an initial segment of the other. The longer of the two has length less than $\abs{t}$: indeed $\abs{t_1} < \abs{t}$, and $\abs{s_1} < \abs{s} \le \abs{t}$. The induction hypothesis for the longer one gives $s_1 = t_1$.
8. The next symbol is a comma in both strings, or the closing bracket when $n = 1$. So $t_2$ and $s_2$ start at the same place, and the argument of step 7 gives $s_2 = t_2$. Repeating it gives $s_i = t_i$ for all $i \le n$. Then the closing bracket follows in both, so $s = t$.
9. Part 1 of the statement. By step 3, the first symbol fixes the form. If $t = f(t_1, \dots, t_n) = f(s_1, \dots, s_n)$, then $t_1$ and $s_1$ start at the same place, and steps 7 and 8 with the prefix lemma give $t_i = s_i$ for all $i$.
10. Prefix lemma for formulas: if $\psi$ and $\varphi$ are formulas and $\psi$ is an initial segment of $\varphi$, then $\psi = \varphi$. We prove this by strong induction on $\abs{\varphi}$, with cases by the first symbol, which $\psi$ and $\varphi$ share. Steps 11 to 16 give the cases.
11. First symbol a term symbol. By step 4, $\varphi$ is $t_1 = t_2$ and $\psi$ is $s_1 = s_2$. The terms $t_1$ and $s_1$ start at the first place, so one is an initial segment of the other, and the prefix lemma for terms gives $s_1 = t_1$. The symbol $=$ follows in both, and the same argument gives $s_2 = t_2$. So $\psi = \varphi$.
12. First symbol a relation symbol $R$. Then $\varphi = R(t_1, \dots, t_n)$ and $\psi = R(s_1, \dots, s_n)$ with $n = \operatorname{ar}(R)$. Steps 7 and 8, with the prefix lemma for terms, give $s_i = t_i$ for all $i$, and so $\psi = \varphi$.
13. First symbol $\neg$. Then $\varphi = \neg \varphi'$ and $\psi = \neg \psi'$, and $\psi'$ is an initial segment of $\varphi'$. Since $\abs{\varphi'} < \abs{\varphi}$, the induction hypothesis gives $\psi' = \varphi'$, so $\psi = \varphi$.
14. First symbol $\forall$ or $\exists$. Then $\varphi = Q x \, \varphi'$ and $\psi = Q y \, \psi'$. The second symbol gives $x = y$, and the argument of step 13 gives $\psi' = \varphi'$.
15. First symbol a left bracket. Then $\varphi = (\varphi_1 \circ \varphi_2)$ and $\psi = (\psi_1 \ast \psi_2)$. The formulas $\varphi_1$ and $\psi_1$ start at the second place, so one is an initial segment of the other. The longer one has length less than $\abs{\varphi}$, as in step 7, and the induction hypothesis gives $\psi_1 = \varphi_1$.
16. In the same case, the next symbol gives $\ast = \circ$. Then $\varphi_2$ and $\psi_2$ start at the same place, and the argument of step 15 gives $\psi_2 = \varphi_2$. The closing bracket follows, so $\psi = \varphi$.
17. Part 2 of the statement. By step 4, the first symbol fixes the form. Two decompositions of the same formula of the same form agree, by the argument of steps 11 to 16 applied with $\psi = \varphi$: the first parts start at the same place, so they are equal by the prefix lemmas, and then each later part is equal in turn.

This proves both parts of the statement.

## Idea

Read the string from left to right.
The first symbol tells which clause built it.
The only difficulty is where the first argument ends, and the prefix lemma says that a term or a formula cannot properly extend another one.
So two decompositions that start at the same place must end at the same place.

## Variants

1. Bracket counting: every nonempty proper initial segment of a formula $(\varphi_1 \circ \varphi_2)$ has more left than right brackets. Every binary connective inside $\varphi_1$ or $\varphi_2$ lies inside its own brackets, so $\circ$ is the only binary connective with exactly one open bracket before it.
2. Weight counting for prefix notation: give each symbol of arity $n$ the weight $1 - n$. A string is a term exactly when its total weight is $1$ and each proper initial segment has weight less than $1$.
3. Parsing algorithm: the proof gives a left-to-right parser, which reads a term or formula and returns its formation tree in linear time.
