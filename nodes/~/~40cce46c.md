## Example

We show that the strings $(p \land \land q)$, $(p \land q$ and $)p \land q($ are not [[propositional formulas|~7139c138]].
A failed search for a formation sequence is not a proof, so we use properties that every formula has.

1. Property B: a formula has as many left brackets as right brackets, and it has twice as many brackets as connectives.
2. We prove B by [[induction on formulas|EDRV3N0SA3]]: a variable has $0$ brackets and $0$ connectives.
3. If $\varphi$ has B, then $(\neg \varphi)$ has one more left bracket, one more right bracket and one more connective, so it has B.
4. If $\varphi$ and $\psi$ have B, then $(\varphi \circ \psi)$ adds one left bracket, one right bracket and one connective to their totals, so it has B.
5. The string $(p \land \land q)$ has $2$ brackets and $2$ connectives, and $2 \neq 2 \cdot 2$, so it fails B and is not a formula.
6. The string $(p \land q$ has $1$ left bracket and $0$ right brackets, so it fails B and is not a formula.
7. Property F: the first symbol of a formula is a variable or a left bracket.
8. We prove F by induction: a variable starts with itself, and $(\neg \varphi)$ and $(\varphi \circ \psi)$ start with a left bracket.
9. The string $)p \land q($ starts with a right bracket, so it fails F and is not a formula.

## Remarks

The string $)p \land q($ has B: it has $1$ left bracket, $1$ right bracket and $1$ connective.
So property B alone does not decide whether a string is a formula; each property of this kind gives only a necessary condition.
A full test is the parsing algorithm that the [[unique readability theorem|~26f00b05]] supports: find the main connective by the bracket count, then test the parts.
The string $(p)$ fails B, since it has $2$ brackets and $0$ connectives.
The string $(p \land q)$, with one $\land$ removed from the first string, passes the test and is a formula.

## Explanations

### L1 human

Not every string of logic symbols is a formula.
In "$(p$ and and $q)$" the word "and" appears twice in a row, with nothing between the two.
In "$(p$ and $q$" a bracket is opened and never closed.
To prove that such a string is not a formula, we find a rule that every formula obeys, for example "brackets come in pairs", and we show that the string breaks the rule.

### L2 human

We decide whether the string $((p \to q)(\neg r))$ is a formula.

1. Count the symbols: $3$ left brackets, $3$ right brackets, and $2$ connectives ($\to$ and $\neg$).
2. Property B asks for $2 \cdot 2 = 4$ brackets, but the string has $6$.
3. So the string fails B, and it is not a formula.
4. The reason is a missing binary connective between $(p \to q)$ and $(\neg r)$.

The typical use of an invariant like B is a quick check before a full parse.
A trap is to think that a string that passes B is a formula; the string $)p \land q($ passes B and is not a formula.
