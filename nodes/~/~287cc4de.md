## Example

Let $C_0 = [0, 1]$, and let $C_{n+1}$ be the set that we get from $C_n$ when we remove the open middle third of each of its closed intervals.
The [[Cantor set|0BXNDZFQME]] is $C = \bigcap_{n \ge 0} C_n$.
We check two properties that together defeat the intuition that a "large" set must take up some length.

1. The set $C_n$ is a union of $2^n$ closed intervals, each of length $3^{-n}$. So the total length of $C_n$ is $(2/3)^n$.
2. Since $C \subseteq C_n$ for every $n$, and $(2/3)^n \to 0$, the set $C$ has length $0$. In the language of measure, $C$ is a [[null set|VQQM4Y550T]].
3. A number $x \in [0, 1]$ lies in $C$ exactly when it has a base $3$ expansion $x = \sum_{n \ge 1} d_n 3^{-n}$ with every digit $d_n \in \{0, 2\}$. For example, $\tfrac{1}{4} = 0.0202\ldots_3$, so $\tfrac{1}{4} \in C$.
4. The map $\sum d_n 3^{-n} \mapsto \sum (d_n/2) 2^{-n}$ sends $C$ onto $[0, 1]$, since every number in $[0, 1]$ has a base $2$ expansion. So $C$ has at least as many points as $[0, 1]$.
5. So $C$ is [[uncountable|0W7FBYS1F1]], by [[Cantor's diagonal argument|0XCH8QVDCQ]] for $[0, 1]$.

The set $C$ is as large as $[0, 1]$ in cardinality and as small as a point in length, so it is a standard pathological set.

## Remarks

Each interval of $C_n$ has length $3^{-n}$, and $C \subseteq C_n$.
So $C$ contains no interval of positive length.
The set $C$ is pathological only as a subset of the real line.
In topology, $C$ is a standard model: every nonempty compact metric space is a continuous image of it.

## Explanations

### L1 human

Start with a line segment and remove its middle third.
Then remove the middle third of each of the two pieces that remain, and continue for ever.
The total length that remains goes to $0$.
But infinitely many points remain, and there are as many of them as points in the whole segment.
This surprises most people, so mathematicians call the Cantor set pathological.

### L2 human

To check that a point is in $C$, write it in base $3$.

1. The point $\tfrac{1}{4}$ has base $3$ expansion $0.020202\ldots_3$, because $\sum_{k \ge 1} 2 \cdot 9^{-k} = 2/8 = 1/4$.
2. Every digit is $0$ or $2$, so $\tfrac{1}{4} \in C$.
3. The point $\tfrac{1}{2} = 0.111\ldots_3$ has only the digit $1$, and it lies in the first removed interval $(\tfrac{1}{3}, \tfrac{2}{3})$, so $\tfrac{1}{2} \notin C$.

A trap: the point $\tfrac{1}{4}$ is not an end point of any removed interval, so $C$ contains more than the end points.
Another trap: $\tfrac{1}{3} = 0.1_3 = 0.0222\ldots_3$ has two expansions, and $\tfrac{1}{3} \in C$ because one expansion uses only $0$ and $2$.
