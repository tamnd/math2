## Example

We use the partial models and the jump $\mathcal{J}$ of [[Kripke's theory of truth|~1dd87a57]].
Let $\lambda := \exists y\,(D(\underline{k}, y) \wedge \neg T(y))$ be the liar from the [[proof of the diagonal lemma|SFPSB6JPTC]].
Here $D(\underline{k}, m)$ is true in $\mathcal{N}$ only for $m = \ulcorner \lambda \urcorner$.
Let $(E, A)$ be any fixed point.

1. In [[strong Kleene logic|SZHA10A9X7]], $\|\lambda\|_{(E, A)} = \|\neg T(\ulcorner \lambda \urcorner)\|_{(E, A)}$. The only witness that is not false is $y = \ulcorner \lambda \urcorner$.
2. Since $(E, A)$ is a fixed point, $\ulcorner \lambda \urcorner \in E$ if and only if $\|\lambda\| = 1$.
3. Also $\ulcorner \lambda \urcorner \in A$ if and only if $\|\lambda\| = 0$, since $\ulcorner \lambda \urcorner$ is the code of a sentence.
4. Suppose $\ulcorner \lambda \urcorner \in E$. Then $\|\lambda\| = 1$ by step 2, so $\|T(\ulcorner \lambda \urcorner)\| = 0$ by step 1.
5. So $\ulcorner \lambda \urcorner \in A$, by the clause for $T$. This contradicts $E \cap A = \emptyset$.
6. Suppose $\ulcorner \lambda \urcorner \in A$. Then $\|\lambda\| = 0$ by step 3, so $\|T(\ulcorner \lambda \urcorner)\| = 1$ by step 1.
7. So $\ulcorner \lambda \urcorner \in E$, which again contradicts disjointness.
8. Hence $\ulcorner \lambda \urcorner \notin E \cup A$, and $\|\lambda\|_{(E, A)} = \mathrm{u}$.
9. So $\lambda$ is a [[truth-value gap|4CBCWZQZ12]] in $(E, A)$. It is not a glut, since no code is in both $E$ and $A$.

## Remarks

Step 1 is where the form of $\lambda$ matters.
With this form, the strong Kleene value of $\lambda$ equals that of $\neg T(\ulcorner \lambda \urcorner)$ in every partial model, and not only in fixed points.
The argument uses only that $(E, A)$ is a fixed point.
So the liar is a gap in the least, the maximal and the intrinsic fixed points.
The [[truth-teller|~66f66b7a]] behaves differently: the same argument gives no contradiction for it.
In a glut semantics, $E$ and $A$ may overlap and must cover all sentences.
There the same steps put the liar in both sets; see [[this example|~bba62832]].

## Explanations

### L1 human

Kripke builds the truth predicate step by step, and he never forces a value.
If the liar were put on the "true" list, it would also have to go on the "false" list.
If it were put on the "false" list, it would also have to go on the "true" list.
Since no sentence is on both lists, the liar stays off both lists.

### L2 human

1. The value of $\lambda$ is the value of $\neg T(\ulcorner \lambda \urcorner)$.
2. In a fixed point, the value of $T(\ulcorner \lambda \urcorner)$ is the value of $\lambda$.
3. So the value $v$ of $\lambda$ satisfies $v = \neg v$ in strong Kleene logic.
4. Only $\mathrm{u}$ satisfies $\mathrm{u} = \neg \mathrm{u}$.

The typical use is the first test of a gap theory: it must make the liar a gap.
The trap is to think that this proves "the liar is not true" inside the theory; that sentence also has value $\mathrm{u}$.
