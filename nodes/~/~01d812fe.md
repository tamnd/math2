## Example

Let $P = \{(a, b) : a, b \in \mathbb{Z},\ b \neq 0\}$ be the set of pairs of [[integers|0C4JS9RF5M]] with a nonzero second entry.
Define a relation on $P$ by
$$(a, b) \sim (c, d) \iff ad = bc.$$
A [[rational number|0NCJ5WXN6Z]] is an [[equivalence class|0W95W33CMP]] of this relation, and $\mathbb{Q} := P/{\sim}$ is the [[quotient set|0011MTQMR6]].
We write $\tfrac{a}{b}$ for the class of $(a, b)$.
This is a definition by abstraction, one of the [[kinds of definitions|~917f5106]].
Its first obligation is to show that $\sim$ is an [[equivalence relation|0G8VEZ3WTK]].

1. Reflexive. For $(a, b) \in P$, we have $ab = ba$, so $(a, b) \sim (a, b)$.
2. Symmetric. If $ad = bc$, then $cb = da$, so $(c, d) \sim (a, b)$.
3. Transitive. Suppose $(a, b) \sim (c, d)$ and $(c, d) \sim (e, f)$, that is, $ad = bc$ and $cf = de$.
4. Multiply the first equation by $f$: $adf = bcf$.
5. By the second equation, $bcf = b(cf) = bde$. So $adf = bde$, that is, $d(af - be) = 0$.
6. The integer $d$ is not $0$, because $(c, d) \in P$. A product of two integers is $0$ only when a factor is $0$, so $af - be = 0$.
7. So $af = be$, and $(a, b) \sim (e, f)$.

Now the definition decides equalities by a calculation.

1. $\tfrac{1}{2} = \tfrac{2}{4}$, because $1 \cdot 4 = 2 \cdot 2$.
2. $\tfrac{1}{2} = \tfrac{-3}{-6}$, because $1 \cdot (-6) = 2 \cdot (-3)$.
3. $\tfrac{1}{2} \neq \tfrac{2}{3}$, because $1 \cdot 3 = 3$ and $2 \cdot 2 = 4$.

## Remarks

1. The definition makes "equal fractions" into equal objects. Before it, $(1, 2)$ and $(2, 4)$ are different pairs. After it, they name the same element of $\mathbb{Q}$.
2. Step 6 uses that $\mathbb{Z}$ has no zero divisors. The same construction works for each integral domain and gives its [[field of fractions|0F2PTGX1A2]].
3. If we allow $b = 0$, transitivity fails: $(1, 1) \sim (0, 0)$ and $(0, 0) \sim (2, 1)$, but $(1, 1) \not\sim (2, 1)$. So the condition $b \neq 0$ is needed.
4. Addition is defined by $\tfrac{a}{b} + \tfrac{c}{d} := \tfrac{ad + bc}{bd}$. This formula uses representatives, so it must be shown [[well defined|~a33d83e5]]. The rule [[that adds numerators and denominators|~247f4857]] fails this test.
5. The same pattern defines the integers from pairs of natural numbers, see the [[construction of the integers|0NS58JP68E]].

## Explanations

### L1 human

The fractions one half, two quarters and three sixths are written differently, but they name the same amount.
A definition by abstraction makes this exact.
It says: two fractions name the same number when their cross products are equal.
For one half and two quarters, $1 \times 4$ and $2 \times 2$ are both $4$, so they are the same number.
A rational number is then the whole family of fractions that name it.

### L2 human

We use the definition to show that $\tfrac{a}{b} = \tfrac{ka}{kb}$ for each nonzero integer $k$.

1. By the definition of $\sim$, we must check $a \cdot (kb) = b \cdot (ka)$.
2. Both sides equal $kab$, by the commutative and associative laws.
3. The pair $(ka, kb)$ is in $P$, because $kb \neq 0$ when $k \neq 0$ and $b \neq 0$.
4. So $(a, b) \sim (ka, kb)$, and the two classes are equal.

The typical use: an equality of rational numbers becomes an equality of integers, which we can check by calculation.
A trap is to treat $\tfrac{a}{b}$ as the pair $(a, b)$ itself, and then to define functions by the numerator alone.
The map $\tfrac{a}{b} \mapsto a$ is not a function on $\mathbb{Q}$, because $\tfrac12 = \tfrac24$ but $1 \neq 2$.
