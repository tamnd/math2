## Example

Let $m(x, y) = (x + y) / 2$ on $[0, 1]$.
We check the four axioms of a [[t-norm|~a4e21349]].

1. Commutativity holds: $(x + y)/2 = (y + x)/2$.
2. Monotonicity holds: if $x \le x'$ and $y \le y'$, then $x + y \le x' + y'$.
3. The unit axiom fails: $m(0.4, 1) = 0.7 \neq 0.4$.
4. Associativity fails: $m(m(0, 0), 1) = \tfrac12$, but $m(0, m(0, 1)) = \tfrac14$.
5. The null property $x * 0 = 0$ of t-norms fails too: $m(1, 0) = \tfrac12$.

So $m$ is not a t-norm.

## Remarks

1. As a conjunction, $m$ gives "true and false" the value $\tfrac12$, which breaks the classical behavior on $\set{0, 1}$.
2. Every t-norm satisfies $x * y \le \min(x, y)$, and $m(0.4, 1) = 0.7 > 0.4$ violates this bound.
3. The mean is an aggregation operator, used for averaging scores; it is not a candidate for logical conjunction.

## Explanations

### L1 human

Averaging two degrees sounds like a fair "and", but it fails a basic test.
"$A$ and a fully true statement" should be exactly as true as $A$, and the average changes it.

### L2 human

1. Test the unit axiom first, with $y = 1$.
2. Then test associativity on the values $0$ and $1$.

A trap: commutativity and monotonicity alone do not make a t-norm.
