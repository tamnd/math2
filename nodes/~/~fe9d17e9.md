## Statement

S1S is the monadic second-order theory of the [[natural numbers|0MWKJ44V5A]] with the successor relation $S = \set{(i, i+1) : i \in \N}$.
Its formulas are built as in [[monadic second-order logic on words|~f98304ff]]: first-order variables range over $\N$, set variables range over all subsets of $\N$, and the atomic formulas are $S(x, y)$, $x = y$ and $x \in X$.
For a finite alphabet $\Sigma$, an infinite word $\alpha = a_0 a_1 a_2 \cdots \in \Sigma^\omega$ is the structure $(\N, S, (P_a)_{a \in \Sigma})$ with $P_a = \set{i : a_i = a}$.

A (nondeterministic) [[Büchi automaton|92DM43HQZT]] is $A = (Q, \Sigma, \Delta, I, F)$ with a finite set $Q$ of states, transitions $\Delta \subseteq Q \times \Sigma \times Q$, initial states $I \subseteq Q$ and accepting states $F \subseteq Q$.
A run of $A$ on $\alpha$ is a sequence $r_0 r_1 r_2 \cdots$ with $r_0 \in I$ and $(r_i, a_i, r_{i+1}) \in \Delta$ for all $i$.
The run is accepting when some state of $F$ occurs in it infinitely often, and $L(A)$ is the set of infinite words with an accepting run.

**Theorem (Büchi).**

1. A language $L \subseteq \Sigma^\omega$ is definable by an MSO sentence over $(\N, S, (P_a)_{a \in \Sigma})$ if and only if $L = L(A)$ for some Büchi automaton $A$, that is, if and only if $L$ is [[omega-regular|G6WP8B6NGD]]. Both translations are effective.
2. Complementation: for every Büchi automaton $A$ over $\Sigma$ there is a Büchi automaton $B$, computable from $A$, with $L(B) = \Sigma^\omega \setminus L(A)$.
3. Emptiness: $L(A) \ne \emptyset$ if and only if some accepting state is reachable from an initial state and lies on a cycle. This is decidable.
4. S1S is [[decidable|HWC687ES0Q]].
5. S1S is not [[elementary recursive|RJ3MCAAZSV]]: no decision procedure for it runs in time bounded by a fixed tower of exponentials.

## Remarks

### About the proof

The [[proof|~2b2fce64]] proves parts 1 to 5, with complementation proved in full by Büchi's argument with Ramsey's theorem; part 5 is reduced to Meyer's lower bound for WS1S, which is cited.

### Why each hypothesis is needed

- Monadic. Full second-order logic over $(\N, S)$ can quantify over ternary relations and define addition and multiplication by their recursion equations. So its theory contains true arithmetic, which is undecidable by [[Gödel's incompleteness theorems|X9WYNYE29C]].
- Nondeterminism. Deterministic Büchi automata are strictly weaker. The language of words over $\set{a, b}$ with only finitely many $a$ is recognized by a nondeterministic Büchi automaton, but by no deterministic one. So complementation cannot be done by exchanging accepting and rejecting states, as for finite automata.
- The acceptance condition. Reading "some accepting state occurs at least once" instead of "infinitely often" gives a weaker class, which is not closed under complement.

### Consequences

1. The monadic second-order theory of $(\N, <)$ is decidable, because $x < y$ is S1S-definable: $x \ne y$ and every set that contains $x$ and is closed under successor contains $y$.
2. WS1S reduces to S1S, because "$X$ is finite" is S1S-definable: $\exists y \, \forall z \, (z \in X \to z < y)$.
3. Satisfiability of [[linear temporal logic|RMJ56ZPA63]] is decidable, because each formula translates into an S1S formula whose free set variables stand for the atomic propositions; in practice one builds a Büchi automaton for the formula directly.
4. Every nonempty omega-regular language contains an ultimately periodic word $u v^\omega$, by part 3: take the path to the accepting state and the cycle through it.

### Converse

Part 1 is an equivalence.
The omega-regular languages are also exactly the finite unions of sets $U V^\omega$ with $U$ and $V$ regular languages of finite words; this is a by-product of the proof of complementation.

### Generalizations

1. McNaughton's theorem (1966): every omega-regular language is recognized by a deterministic automaton with a Muller acceptance condition. Safra (1988) gave a determinization with $2^{O(n \log n)}$ states for $n$-state Büchi automata.
2. Infinite trees: the monadic theory of two successors, S2S, is decidable by [[Rabin's tree theorem|~5d6edbff]].
3. Elgot and Rabin (1966) showed that S1S remains decidable when a unary predicate for the set of powers of $2$ is added.

## History

Julius Richard Büchi proved the theorem in a paper presented at the 1960 International Congress for Logic, Methodology and Philosophy of Science, published in 1962.
He introduced the automata now named after him for this purpose, and he proved complementation with Ramsey's theorem.
Robert McNaughton proved the determinization theorem in 1966, and Shmuel Safra gave an optimal determinization in 1988.

## Explanations

### L1 human

Imagine a machine that reads an endless sequence of letters, such as $a b a b a b \ldots$, and never stops.
It cannot wait for the end, so it accepts when it passes through a "good" state again and again forever.
Büchi showed that the properties of endless sequences that one can write in a simple logic of positions and sets of positions are exactly the properties such machines check.
For example "the letter $a$ appears infinitely often" is one such property.
Because a machine can be inspected, every sentence of this logic can be decided true or false.

### L2 human

We check the property "infinitely many $a$" over $\set{a, b}$ in both forms.

1. In S1S with $<$ (see consequence 1) the sentence is $\forall x \, \exists y \, (x < y \wedge P_a(y))$.
2. The Büchi automaton has states $q_a$ and $q_b$, both initial, with $q_a$ accepting. Each letter $c$ leads from any state to $q_c$.
3. On $\alpha = (ab)^\omega$ the run is $q_a q_a q_b q_a q_b \cdots$ (the first state is any initial state), and $q_a$ occurs infinitely often. So $\alpha$ is accepted, and the sentence is true in $\alpha$.
4. On $\alpha = a b^\omega$ the run eventually stays in $q_b$, so $q_a$ occurs finitely often. The word is rejected, and the sentence is false in it.

The typical use is a decision procedure for specifications of non-terminating systems, written in temporal logic or S1S.
A trap is to complement a Büchi automaton by exchanging accepting and non-accepting states; on $(ab)^\omega$ the automaton above and its "swap" both accept.

### L3 human

Büchi's theorem extends the [[Büchi-Elgot-Trakhtenbrot theorem|~f98304ff]] from finite to infinite words, and the only new difficulty is complementation.
Büchi's proof uses Ramsey's theorem to factor every infinite word into a prefix and infinitely many blocks of the same type; modern proofs use determinization (McNaughton, Safra) or ranking functions on run graphs.
The same scheme, with games replacing Ramsey's theorem, gives [[Rabin's tree theorem|~5d6edbff]], and it is the theoretical base of automata-based model checking.
