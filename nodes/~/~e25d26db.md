## Description

A rational number is a number of the form $a / b$, where $a$ and $b$ are [[integers|~3fed16db]] and $b \neq 0$.
We write $\mathbb{Q}$ for the set of rational numbers.
Two fractions $a / b$ and $c / d$ are the same rational number when $a d = b c$.
With addition and multiplication, $\mathbb{Q}$ is a [[field|~e2ba06d4]], and with its usual order it is an [[ordered field|~85165fa9]].
The set $\mathbb{Q}$ contains $\mathbb{Z}$, because each integer $a$ is the fraction $a / 1$.

## Remarks

Each rational number has exactly one [[representation in lowest terms|~7fd5ec4b]] $a / b$ with $b > 0$.
The set $\mathbb{Q}$ is countable.
Not every real number is rational: $\sqrt{2}$ is [[irrational|~07cf1fcf]].

## Explanations

### L1 human

The rational numbers are the fractions, such as $1/2$, $-3/4$ and $7 = 7/1$.
Many fractions name the same number: $1/2$, $2/4$ and $3/6$ are all equal.
In $\mathbb{Q}$, you can divide by any number except $0$.
