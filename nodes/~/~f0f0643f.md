## Example

Let $S = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}$ over $\mathbb{R}$.
This is a non-example: $S$ has no Pfaffian.

1. The [[definition|C9JJD2AVJR]] needs $a_{21} = -a_{12}$.
2. Here $a_{21} = 1$ and $-a_{12} = -1$, so $S$ is not alternating over $\mathbb{R}$.
3. Check: $\det S = -1$, and $-1$ is not the square of a real number.
4. So no real number $p$ can play the role of the Pfaffian with $p^2 = \det S$.
5. Over $\mathbb{F}_2$, $1 = -1$, so $S$ is alternating there, with $\operatorname{pf}(S) = 1$ and $\det S = -1 = 1 = 1^2$.

## Remarks

The formula $a_{12}$ for a $2 \times 2$ Pfaffian can be applied to any matrix, but then it has no link to the determinant.
For $S$ it gives $1$, while $\det S = -1 \ne 1^2$.
The definition requires the alternating property so that $\operatorname{pf}(A)^2 = \det A$ holds.

## Explanations

### L1 human

The Pfaffian is defined only for matrices with $a_{ji} = -a_{ij}$ and zeros on the diagonal.
This symmetric matrix has $a_{21} = a_{12}$, so it has no Pfaffian.
Its determinant $-1$ is negative, so it is not a square of a real number.

### L2 human

Step 5 shows that the answer depends on the ring: in characteristic $2$, symmetric and skew-symmetric agree.
A trap: do not apply the matching formula to a matrix that is not alternating.
