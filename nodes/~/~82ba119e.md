## Example

Consider the false claim: every positive [[rational number|0NCJ5WXN6Z]] $q$ satisfies $q \ge 1$.
Here is an argument that looks like a [[minimal counterexample|~f8c099da]].

> Suppose that the claim is false, and let $q$ be the least positive rational with $q < 1$.
> Then $q/2$ is a positive rational, and $q/2 < q < 1$.
> So $q/2$ is a smaller counterexample, which contradicts the choice of $q$.

We check where the argument fails.

1. The claim is false: $q = \tfrac12$ is a positive rational with $q < 1$.
2. So the set $C = \{q \in \mathbb{Q} : 0 < q < 1\}$ of counterexamples is not empty.
3. The set $C$ has no least element. For each $q$ in $C$, the number $q/2$ is in $C$, and $q/2 < q$.
4. So the sentence "let $q$ be the least counterexample" names an object that does not exist.
5. The [[well-ordering principle|01BX15HSRR]] gives a least element only for nonempty sets of natural numbers, and $C$ is not such a set.
6. The method needs a size function with values in $\mathbb{N}$. Here the size is $q$ itself, with values in the positive rationals.

The argument is not an instance of the minimal counterexample method, because its first step has no justification.

## Remarks

1. The argument does prove a true statement: the set $C$ has no least element. Steps 3 and 4 are that proof.
2. The same failure occurs over the integers. The false claim "every integer is at least $0$" has the counterexamples $-1, -2, -3, \ldots$, and this set has no least element.
3. The argument becomes valid when the size is moved into $\mathbb{N}$. For example, a least positive denominator exists for each nonempty set of fractions, and the proof of the [[irrationality of the square root of 2|0DZGSDHD92]] uses this.
4. In each correct use, the proof must say why a least counterexample exists. Over $\mathbb{N}$ the reason is the well-ordering principle.

## Explanations

### L1 human

Among the whole numbers there is always a smallest one with a given property.
Among the fractions there is not.
The fractions between $0$ and $1$ go down as $\tfrac12$, $\tfrac14$, $\tfrac18$, and they never reach a smallest one.
So "take the smallest fraction below $1$" is not allowed, and the argument above proves nothing about the claim.

### L2 human

We compare a valid and an invalid use of a least element.

1. Valid: the set $\{n \in \mathbb{N} : n^2 > 50\}$ is a nonempty set of natural numbers. Its least element is $8$, because $7^2 = 49$ and $8^2 = 64$.
2. Invalid: the set $\{q \in \mathbb{Q} : q^2 > 2, q > 0\}$ is a nonempty set of positive rationals. It has no least element.
3. For step 2, let $q > 0$ with $q^2 > 2$. The number $r = q - (q^2 - 2)/(2q) = (q^2 + 2)/(2q)$ is rational, and $0 < r < q$ because $q^2 - 2 > 0$.
4. Also $r^2 = q^2 - (q^2 - 2) + \left((q^2 - 2)/(2q)\right)^2 = 2 + \left((q^2 - 2)/(2q)\right)^2 > 2$.
5. So $r$ is a smaller element of the set, and the set has no least element.

The typical use of this non-example is a check of each minimal counterexample proof: name the set in which the least element is taken.
A trap is to think that every set bounded below has a least element; the greatest lower bound $\sqrt{2}$ of the set in step 2 is not rational, so it is not in the set.
