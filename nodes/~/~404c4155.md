## Example

Both logics use the values $0, \tfrac12, 1$, the designated set $\set{1}$, $\neg x = 1 - x$, $\min$ and $\max$.
The [[strong Kleene implication|~e50e75c5]] is $x \to_K y = \max(1 - x, y)$.
The [[Łukasiewicz implication|~09f1e8d9]] is $x \to_{Ł} y = \min(1, 1 - x + y)$.

1. If $x = 0$, both give $1$.
2. If $x = 1$, both give $y$.
3. If $x = \tfrac12$ and $y = 0$, both give $\tfrac12$.
4. If $x = \tfrac12$ and $y = 1$, both give $1$.
5. If $x = y = \tfrac12$, then $\to_K$ gives $\tfrac12$ and $\to_{Ł}$ gives $1$.
6. So $p \to p$ is a tautology of $\mathrm{Ł}_3$ and not of $\mathsf{K}_3$, and the two logics are different.

## Remarks

1. One differing entry of nine changes the set of tautologies from empty to infinite.
2. The difference is not a matter of notation: by [[the non-definability theorem|~61164531]], no Kleene formula defines $\to_{Ł}$.
3. For formulas in $\neg$, $\land$, $\lor$ only, the two logics have the same valid inferences, since these tables agree.

## Explanations

### L1 human

Two three-valued logics can look the same and still differ.
They disagree only on "if undefined, then undefined".
Łukasiewicz says this is true; Kleene says it is undefined.

### L2 human

1. Write both implication tables.
2. Compare the nine entries.
3. Find a formula that uses the differing entry, here $p \to p$ at $p = \tfrac12$.

The typical use is to separate two matrices on the same set of values by one formula.
A trap: equal tables for $\neg$, $\land$, $\lor$ do not make two logics equal once $\to$ is primitive in one of them.
