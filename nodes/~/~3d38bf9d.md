## Summary

Let $\mathcal{M}$ be a structure, let $A \subseteq M$, and let $\operatorname{Aut}(\mathcal{M}/A)$ be the group of [[automorphisms|DSQ17TNW1C]] of $\mathcal{M}$ that fix $A$ pointwise.
Tuples in the same orbit of $\operatorname{Aut}(\mathcal{M}/A)$ always have the same [[type|9V71Q3SD1G]] over $A$.
*Types are orbits* in $\mathcal{M}$ over $A$ when the converse holds: any two tuples with the same type over $A$ are mapped to each other by an automorphism over $A$.
This holds when $\mathcal{M}$ is strongly $\kappa$-[[homogeneous|~ee122c2b]] and $\abs{A} < \kappa$, in particular in saturated models and in the [[monster model|~84f3dbc1]].
Outside first-order logic, the orbits themselves are taken as the definition of types, the Galois types of abstract elementary classes.

## Motivation

In Galois theory, two roots of an irreducible polynomial over a field $k$ are exchanged by an automorphism of the algebraic closure that fixes $k$.
So the roots that "look the same" over $k$ are the roots in one orbit of the Galois group.
Types generalize "being a root of the same irreducible polynomial", and homogeneity generalizes the extension of field isomorphisms.
In a homogeneous structure, the syntactic notion of type and the symmetric notion of orbit agree, and each can be used to study the other.

## Notation

The orbit of $\bar{a}$ under $\operatorname{Aut}(\mathcal{M}/A)$ is $\set{\sigma(\bar{a}) : \sigma \in \operatorname{Aut}(\mathcal{M}/A)}$.
The Galois type of $\bar{a}$ over a model $\mathcal{N}$ in an abstract elementary class is written $\operatorname{ga\text{-}tp}(\bar{a}/\mathcal{N})$ or $\operatorname{gtp}(\bar{a}/\mathcal{N})$.

## Remarks

### Examples

- In the field $\C$, two numbers have the same type over $\emptyset$ exactly when they are conjugate or both transcendental, and then an automorphism maps one to the other; see [[conjugate complex numbers|~c542d56a]].
- In $(\Q, <)$, two $n$-tuples with the same order pattern are in the same orbit; see [[the rational order is saturated|~c8f8cf10]].
- In a monster model of dense linear orders, the elements in one cut of a small set form one orbit over it; see [[a monster model of dense linear orders|~73f50538]].
- In a monster model of algebraically closed fields, the elements transcendental over a small set form one orbit over it; see [[a monster model of algebraically closed fields|~9bcdd68f]].

### Non-examples

- In the rational order with increasing constants $c_n \to 1$, the elements $1$ and $2$ have the same type over $\emptyset$ and lie in different orbits; see [[an order whose types are not orbits|~eb3dc704]].
- In $(\R, <)$, the elements $0$ and $-1$ have the same type over $\Q_{>0}$, while every automorphism that fixes $\Q_{>0}$ fixes $0$; see [[the real order is not special|~a1ead269]].

### Basic properties

- An automorphism over $A$ preserves every formula with parameters in $A$, so each orbit lies inside the set of realizations of one type.
- If $\mathcal{M}$ is strongly $\kappa$-homogeneous and $\abs{A} < \kappa$, then for $\operatorname{tp}(\bar{a}/A) = \operatorname{tp}(\bar{b}/A)$ the map that fixes $A$ and sends $\bar{a}$ to $\bar{b}$ is partial elementary, so it extends to an automorphism.
- For the countable model of an $\aleph_0$-categorical countable theory, the automorphism group has finitely many orbits on $n$-tuples for each $n$, since the model is saturated and $S_n(T)$ is finite; see [[Ryll-Nardzewski theorem|1513J40TKA]].
- In an abstract elementary class with amalgamation, joint embedding and arbitrarily large models, Galois types over a model are the orbits of the automorphisms of a monster model that fix the model.

### History

Galois types are the basic notion of type in the theory of abstract elementary classes, where no syntax of formulas is available.
The parallel between types and Galois orbits comes from the model theory of fields.

### Common errors

- Expecting types to be orbits in every model: it fails in non-homogeneous models, and the parameter set must be small.
- Confusing the orbit of a tuple with the orbits of its coordinates: two tuples can have coordinates in the same orbits and still lie in different orbits, as $(0, 1)$ and $(1, 0)$ in $(\Q, <)$.

## Explanations

### L1 human

A type describes an element by what formulas say about it, and an orbit describes it by where the symmetries of the structure can move it.
A symmetry never changes what formulas say, so an orbit lies inside a type.
In a homogeneous structure, the two descriptions agree.

### L2 human

We compute the orbits of $\operatorname{Aut}(\Q, <)$ on pairs.

1. An automorphism preserves the order, so it preserves which of $a_1 < a_2$, $a_1 = a_2$ and $a_2 < a_1$ holds.
2. Two pairs with the same pattern are mapped to each other by a piecewise linear automorphism.
3. So there are exactly three orbits on pairs, matching the three complete $2$-types; see [[the 2-types of dense linear orders|~decb0203]].

The typical use is to count types by counting orbits, or the other way around.
The trap is to forget the parameters: over $\set{0}$, the pairs split into more orbits, according to their positions relative to $0$.

### L3 human

In a [[monster model|~84f3dbc1]], types over small sets are orbits, so model theory becomes the study of the automorphism group acting on small configurations.
This view leads to Galois theory for definable sets and to the study of oligomorphic permutation groups for $\aleph_0$-categorical structures.
For classes that are not first-order axiomatizable, such as those of [[infinitary logic|VBYC17XY83]], Galois types replace syntactic types, and stability theory is developed for them.
