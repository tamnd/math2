## Example

Consider the expression $x^2 + 1$, with $x$ ranging over $D = \mathbb{Z}$.
We show that it is not a [[predicate|0T3DPBG981]] on $D$.

1. A predicate on $D$ must give a [[proposition|0ZGC7ZESYN]] for each value of its free variable.
2. Substitute $x = 2$. The result is $2^2 + 1$, which is the number $5$.
3. The number $5$ is not true or false, so it is not a proposition.
4. So the second condition of the definition fails at $x = 2$, and $x^2 + 1$ is not a predicate.

The expression $x^2 + 1$ is a term: it names an object for each value of $x$.
A predicate needs a relation between terms, for example the equation $x^2 + 1 = 5$.

5. For the predicate $x^2 + 1 = 5$ on $\mathbb{Z}$, the substitution $x = 2$ gives "$5 = 5$", which is true, and $x = 0$ gives "$1 = 5$", which is false.
6. Its truth set is $\{-2, 2\}$, because $x^2 + 1 = 5$ means $x^2 = 4$.

## Remarks

The example shows the difference between the two kinds of expressions with variables: terms, whose values are objects, and formulas, whose values are truth values.
In first-order logic, terms are built from variables, constants and function symbols, and predicates are applied to terms to give formulas.
The same holds for other terms: $\sin x$, $f(x)$ and $\{x\}$ are terms, while $\sin x = 0$, $f(x) > 0$ and $x \in A$ are predicates.

## Explanations

### L1 human

"$x^2 + 1$" is like a machine that turns a number into a number: $2$ becomes $5$.
A predicate is a sentence that becomes true or false.
"$x^2 + 1 = 5$" is such a sentence: it is true for $x = 2$ and false for $x = 0$.
So the equals sign, or another relation, turns the number machine into a predicate.

### L2 human

We sort four expressions with the free variable $n$ on $\mathbb{N}$.

1. $2n + 1$: the value at $n = 3$ is $7$, a number. So it is a term.
2. $2n + 1 > 6$: the value at $n = 3$ is "$7 > 6$", a true proposition. So it is a predicate.
3. $\gcd(n, 6)$: the value at $n = 4$ is $2$. So it is a term.
4. $\gcd(n, 6) = 1$: the value at $n = 4$ is "$2 = 1$", false. So it is a predicate, with the truth set of the numbers coprime to $6$.

The typical use of this test is in reading a definition: the defined notion must be a predicate, such as "$n$ is coprime to $6$", and not a term.
A trap is to write "$f(x) = x^2$ is true" when $f$ is being defined: that line defines a term, and it is not a claim with a truth value.
