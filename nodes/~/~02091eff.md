## Example

For an index $e$, let $R_e = \set{(i, j) : \Phi_e((i, j)) = 1}$.
Let $\varphi(e)$ be the conjunction of these three conditions.

- (a) $\Phi_e$ is total with values in $\set{0, 1}$, so $R_e$ is a [[computable set|PPGD5KW8JC]] of pairs.
- (b) $R_e$ is a linear order on its field.
- (c) For every set $F$, if $F$ is the graph of a function $f \colon \N \to \N$, then there is a $k$ with $(f(k), f(k + 1)) \in R_e$.

So $\varphi(e)$ says that $R_e$ is a computable [[well-ordering|01CGSJ0GNQ]]: condition (c) says that there is no descending sequence $f(0) >_{R_e} f(1) >_{R_e} \cdots$.

1. Conditions (a) and (b) use only quantifiers over numbers and the relation "$\Phi_e(x)$ halts with output $y$", which is $\Sigma^0_1$. So (a) and (b) together are arithmetical.
2. Condition (c) has the form $\forall F\, \psi(e, F)$ with $\psi$ arithmetical.
3. So $\varphi(e)$ is equivalent to $\forall F\, \big((a) \wedge (b) \wedge \psi(e, F)\big)$, which is a $\Pi^1_1$ formula.
4. By $\Pi^1_1$ comprehension in [[Π¹₁-CA0|~999ea337]], there is a set $W$ with $\forall e\, (e \in W \leftrightarrow \varphi(e))$.

In the full model $(\N, \mathcal{P}(\N))$, the set $W$ is the true set of indices of computable well-orderings.

5. This set is many-one equivalent to [[Kleene's O|WHAP0K600D]]. This fact is cited without proof.
6. Kleene's O is not [[hyperarithmetical|NS1HWGTD8E]], so $W$ is not hyperarithmetical, and in particular $W$ is not arithmetical.

## Remarks

The same method, with a set parameter $X$ in $\Phi^X_e$, shows that $\Pi^1_1\text{-}\mathsf{CA}_0$ proves that the hyperjump of $X$ exists for every $X$.
A countable linear order with no descending sequence in a model may still have a descending sequence outside the model.
So in a model that is not a [[β-model|J0Z2GNJZ2W]], the set given by step 4 can differ from the true set.

## Explanations

### L1 human

The property "this computable order is a well-ordering" refers to all infinite sequences.
$\Pi^1_1$ comprehension still collects the indices with this property into one set.
