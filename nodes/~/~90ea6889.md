## Example

Take a first-order language with equality and no constants or function symbols, and allow [[structures|983GZBQYT4]] with the empty domain.
In the empty structure, $\forall x\, A$ is true and $\exists x\, A$ is false for every formula $A$ with at most $x$ free.

1. In classical [[first-order logic|086QKPF0A6]], $\exists x\,(x = x)$ is valid: every structure has an element $a$, and $a = a$.
2. In the empty structure, there is no element, so $\exists x\,(x = x)$ is false.
3. So $\exists x\,(x = x)$ is not valid in inclusive logic.
4. Similarly, $\forall x\, Px \to \exists x\, Px$ is classically valid, and false in the empty structure, since its antecedent is true and its consequent is false.

The language has no singular terms, so no term fails to denote.
So this inclusive logic is not a [[free logic|~5d51b6ee]]: it changes the assumption on domains, not on terms.

## Remarks

The SEP entry gives Hailperin's empty logic as the standard case of an inclusive logic that is not free.
Conversely, a free logic can keep the nonempty domain, by a rule that introduces $E!t$ for a fresh $t$.
The two changes are orthogonal; a logic can make both, one, or neither.

## Explanations

### L1 human

Classical logic assumes that at least one thing exists, so "something is equal to itself" is a law.
Inclusive logic allows a world with nothing in it.
In that world, "something is equal to itself" is false.
This is about empty worlds, not about empty names, so it is different from free logic.

### L2 human

The empty structure makes every universal sentence true and every existential sentence false.
So any classical law of the form "if all, then some" fails there.
A trap is to say that inclusive logic is free logic; it has no names that fail to denote.
