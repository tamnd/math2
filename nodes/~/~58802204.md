## Problem

Find an [[algorithm|9DMSG5HAQX]] that takes as input an arbitrary sentence $\sigma$ of [[first-order logic|086QKPF0A6]] and outputs "yes" if $\sigma$ is [[valid|5SDS9T8E7J]] and "no" otherwise.
Here $\sigma$ may use any finite signature of relation, function and constant symbols, and valid means true in every structure for that signature.
The problem asks for one algorithm that works for all sentences and that always stops.

Three forms of the problem are equivalent.

1. Validity: decide whether $\models \sigma$.
2. Satisfiability: decide whether $\sigma$ has a model. This is equivalent to form 1, because $\sigma$ is satisfiable if and only if $\neg \sigma$ is not valid.
3. Provability: decide whether $\vdash \sigma$ in a standard proof calculus. This is equivalent to form 1 by soundness and [[Gödel's completeness theorem|WQ1ZE255SF]].

The answer is negative: no such algorithm exists.
This is [[Church's theorem|VA6BNNY2YC]], proved independently by Church and by Turing in 1936.

## Remarks

### Why the problem needed a definition of algorithm

A positive answer only needs one algorithm, and every mathematician can recognize an algorithm when one is written down.
A negative answer is a statement about all possible algorithms.
To prove it, one needs a precise mathematical class that contains every algorithm.
In 1936 Church proposed the functions definable in the [[lambda calculus|BD756KR8FM]], and Turing proposed the functions computed by [[Turing machines|758EYCN27B]].
The two classes turned out to be the same.
The claim that they contain every intuitive algorithm is the [[Church-Turing thesis|RWRNBS3Z7B]].
With the thesis, "no Turing machine decides validity" becomes "no algorithm decides validity".

### The negative answers

Turing proved that the [[halting problem|Z7TN2B35B0]] is undecidable.
He then built from each machine $M$ a first-order sentence that is valid exactly when $M$ halts.
A decision procedure for validity would therefore decide the halting problem, which is impossible.
Church proved the same result with the lambda calculus and with the undecidability of an arithmetic theory.
The proofs are on the page of [[Church's theorem|VA6BNNY2YC]].

### What survives of the problem

Validity is semi-decidable: an algorithm that lists all proofs eventually confirms every valid sentence.
So the set of valid sentences is [[computably enumerable|TN9G24VABN]] but not [[computable|PPGD5KW8JC]].
The problem has positive answers for many fragments of first-order logic, which are the subject of the topic [[decidability of logics and theories|E4AVTNWE9E]].

- The [[monadic predicate calculus|SERN6CRVWW]], where all relation symbols are unary, is decidable.
- Several classes of prenex sentences, defined by their quantifier prefix, are decidable.
- Some theories, such as [[Presburger arithmetic|~14d8268c]], have a decidable set of consequences.

### Related decision problems

The problem of finite validity, truth in every finite structure, is even harder: it is not computably enumerable, by [[Trakhtenbrot's theorem|~3e65890a]].
[[Hilbert's tenth problem|X8TVJSVTD4]] asks for an algorithm that decides whether a polynomial equation with integer coefficients has an integer solution; it also has a negative answer.

## History

Hilbert and Ackermann stated the problem in their book Grundzüge der theoretischen Logik in 1928 and called it the main problem of mathematical logic.
The problem was part of the program of Hilbert, which asked for finitary methods to settle mathematical questions; see [[Hilbert's program|P1RW6JWX73]].
Before 1936, several special cases were solved in the positive.
Löwenheim treated the monadic case in 1915.
Bernays and Schönfinkel, and Ackermann, solved prefix classes in 1928.
Gödel proved the completeness theorem in 1929, so validity and provability became the same question.
In 1936 Church published "A note on the Entscheidungsproblem", and Turing published "On computable numbers, with an application to the Entscheidungsproblem".

## Explanations

### L1 human

Hilbert hoped for a machine-like method that could judge every statement of logic as "always true" or "not always true".
Such a method would settle many mathematical questions by calculation alone.
In 1936 Church and Turing showed that no such method can exist.
Turing first described exactly what a mechanical method is, with his machines.
Then he showed that a method for logic would also predict whether any machine stops, and that this prediction is impossible.
For small parts of logic, a method does exist, for example when every property talks about one object at a time.

### L2 human

We decide one sentence by hand, with the method for the monadic fragment.
Let $\sigma$ be $\forall x \, P(x) \to \exists x \, P(x)$, with one unary symbol $P$.

1. The sentence $\sigma$ is valid if and only if $\neg \sigma$ has no model. Here $\neg \sigma$ is equivalent to $\forall x \, P(x) \wedge \neg \exists x \, P(x)$.
2. The sentence $\neg \sigma$ is monadic with $k = 1$ predicate and quantifier rank $q = 1$. By the [[finite model property of the monadic predicate calculus|~2f4e10fc]], if it has a model, it has one with at most $q \cdot 2^k = 2$ elements.
3. A structure with one element $a$ has $P = \emptyset$ or $P = \set{a}$. In the first case $\forall x \, P(x)$ fails; in the second case $\neg \exists x \, P(x)$ fails.
4. A structure with two elements $a, b$ has four choices of $P$. If $P$ is not all of $\set{a, b}$, then $\forall x \, P(x)$ fails; if $P = \set{a, b}$, then $\neg \exists x \, P(x)$ fails.
5. So $\neg \sigma$ has no model, and $\sigma$ is valid.

The typical use of the Entscheidungsproblem is as the model of a negative result: to show that a question has no algorithm, reduce the halting problem to it.
A trap is to read "undecidable" as "some sentences can never be settled".
Each single sentence is valid or not; undecidability says only that no single algorithm settles all of them.

### L3 human

The set of valid sentences in a signature with a binary relation symbol is a complete computably enumerable set: it is computably enumerable, and the halting set reduces to it by a computable map.
So the Entscheidungsproblem has exactly the difficulty of the halting problem.
The finite version is harder in a different direction: finite satisfiability is computably enumerable and undecidable, so finite validity is co-c.e. and not c.e., by Trakhtenbrot's theorem.
The classical decision problem, in the sense of Börger, Grädel and Gurevich, is the program of sorting the fragments of first-order logic into decidable and undecidable ones, by quantifier prefix, by number of variables, or by guards.
The same question for theories, rather than for pure logic, leads to the decidable theories of Presburger, Tarski and Rabin, and to the essentially undecidable theories of Tarski, Mostowski and Robinson.
