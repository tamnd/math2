## Definition

Let $U \subseteq \mathbb{C}$ be an open set and let $f : U \to \mathbb{C}$ be [[holomorphic|~1a187203]] on $U$.
A zero of $f$ is a point $z_0 \in U$ with $f(z_0) = 0$.

## Remarks

The zeros of $\sin$ are the numbers $k\pi$ with $k \in \mathbb{Z}$. The [[complex exponential|~aa66b863]] has no zeros.
Each zero has an [[order|~ace80a9a]], a positive integer or $\infty$.
If $f$ is not the zero function on a [[domain|~6387ec34]], its zeros are [[isolated|~4c4550bd]].

## Explanations

### L1 human

A zero of a function is a point where the function takes the value $0$, as for real functions.
For example, $z^2 + 1$ has the zeros $i$ and $-i$.
