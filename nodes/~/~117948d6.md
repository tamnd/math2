## Example

Consider the [[polynomial|N2EY1EVPRB]] $p(n) = n^2 + n + 41$.
A student computes $p(0) = 41$, $p(1) = 43$, $p(2) = 47$, $p(3) = 53$ and $p(4) = 61$, and all five are [[prime numbers|01826KMG2H]].
The student then writes: "So $p(n)$ is `obviously` prime for every natural number $n$."
We show that this is not a correct use of the word "obvious" from [[trivial, obvious and clearly|~f4ece120]].

1. "Obvious" claims that a short check from the definitions proves the statement. So the statement must at least be true.
2. Take $n = 40$. Then $p(40) = 1600 + 40 + 41 = 1681$.
3. We have $41^2 = 1681$. So $p(40) = 41 \cdot 41$ is a [[composite number|008BH74D7R]], and it is not prime.
4. So the statement is false, and no check can prove it.

The values $p(0), p(1), \ldots, p(39)$ are all prime, so a check of many cases does not find the error.
A correct sentence is: "$p(n)$ is prime for $n = 0, 1, \ldots, 39$, and $p(40) = 41^2$ is not prime."

## Remarks

The example shows that "obvious" is a claim about a proof, not about examples.
A pattern in many cases is evidence, but it is not a proof.
The value $n = 41$ also fails, by a direct factorization: $p(41) = 41^2 + 41 + 41 = 41 \cdot 43$.
In fact no polynomial in one variable with integer coefficients that is not constant takes only prime values at all natural numbers.
Leonhard Euler noticed in 1772 that this polynomial is prime for the $40$ values $n = 0, 1, \ldots, 39$.

## Explanations

### L1 human

The rule "square the number, add the number, add $41$" gives prime numbers for $0, 1, 2$ and many more.
It gives primes for all the numbers from $0$ to $39$.
At $40$, it gives $1681$, which is $41 \times 41$, so it is not prime.
Many good examples do not prove that a rule always works, and calling the rule obvious does not make it true.

### L2 human

We test an "obvious" claim before we accept it.

1. Look for a value where the claim could break. Here $p(n) = n(n + 1) + 41$, so if $n$ or $n + 1$ is a multiple of $41$, then $41$ divides $p(n)$.
2. At $n = 41$: $p(41) = 41 \cdot 42 + 41 = 41 \cdot 43$, so $p(41)$ is not prime.
3. At $n = 40$: $p(40) = 40 \cdot 41 + 41 = 41 \cdot 41$, so $p(40)$ is not prime.

The typical use of this test is to look at the structure of a formula for a value that makes it factor.
A trap: a long list of checked cases makes a claim feel obvious, but one counterexample is enough to refute it.
