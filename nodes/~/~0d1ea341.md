## Example

True arithmetic is $\mathsf{TA} = \operatorname{Th}(\N, 0, S, +, \cdot)$, the set of sentences in $L_A = \set{0, S, +, \cdot}$ that are true in the standard structure.
We check that $\mathsf{TA}$ is [[essentially undecidable|~c0b3bb9c]] and hereditarily undecidable.

1. $\mathsf{TA}$ is consistent, because $\N$ is a model.
2. $\mathsf{TA}$ is [[complete|655K8Y7VS8]]: for each sentence $\sigma$, either $\sigma$ or $\neg \sigma$ is true in $\N$.
3. The seven axioms of [[Robinson arithmetic|3K1AKGXF8A]] $\mathsf{Q}$ are true in $\N$, so $\mathsf{Q} \subseteq \mathsf{TA}$.
4. Let $T'$ be a consistent $L_A$-theory with $\mathsf{TA} \subseteq T'$. If $\sigma \in T'$ and $\sigma \notin \mathsf{TA}$, then $\neg \sigma \in \mathsf{TA} \subseteq T'$ by step 2, and $T'$ is inconsistent.
5. So $T' = \mathsf{TA}$, and $\mathsf{TA}$ is a consistent extension of $\mathsf{Q}$. By the theorem that [[Robinson arithmetic is essentially undecidable|~2685d084]], $T'$ is undecidable.
6. Let $T''$ be an $L_A$-theory with $T'' \subseteq \mathsf{TA}$. Then $T''$ is true in $\N$.
7. $\mathsf{Q}$ is finitely axiomatized and interpretable in $\N$ by the identity interpretation. By part 2 of the [[transfer theorem|~e4c9e250]], $T''$ is undecidable.

So $\mathsf{TA}$ is essentially undecidable and hereditarily undecidable.

## Remarks

The example shows that essential undecidability of a complete theory is the same as its undecidability, since a complete consistent theory has no other consistent extension in its signature.
Step 7 with $T'' = \operatorname{Cn}(\emptyset)$ gives [[Church's theorem|VA6BNNY2YC]] for the signature of arithmetic.
Since $\mathsf{TA}$ is complete and undecidable, it is not axiomatizable, by the theorem on [[complete axiomatizable theories|~269dc6e7]]: this is Gödel's first incompleteness theorem for true axioms.
In fact $\mathsf{TA}$ is not even definable in $\N$, by [[Tarski's undefinability theorem|YRV6SYK2BY]].
If the signature changes, the picture changes: $\operatorname{Th}(\N, 0, 1, +)$ is decidable by [[Presburger arithmetic|~14d8268c]], and $\operatorname{Th}(\N, \cdot)$ is decidable by [[Skolem arithmetic|~c0c01fe2]].

## Explanations

### L1 human

True arithmetic is the collection of all true statements about whole numbers with "plus one", addition and multiplication.
No computer can sort every such statement into true and false.
Also, no smaller collection of these true statements can be sorted by a computer, even the collection of statements that are true in every structure.

### L2 human

We compare true arithmetic with Presburger arithmetic.

1. Both theories are complete, since each is the theory of one structure.
2. Presburger arithmetic has quantifier elimination with divisibility predicates, and so a decision procedure.
3. True arithmetic contains $\mathsf{Q}$, so it is undecidable by steps 3 to 5.
4. The difference lies in multiplication: with it, the theory can represent every computable set, and the diagonal argument applies.

The typical use of the example is as the target of reductions: a decision procedure for a theory into which $\mathsf{TA}$ translates would decide $\mathsf{TA}$.
A trap is to think that $\mathsf{TA}$ is a theory with axioms that one can write down; it has no computable set of axioms.
