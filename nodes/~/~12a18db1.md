## Definition

Let $L$ be a signature whose symbols are coded by natural numbers so that the set of codes of $L$-[[formulas|HYJ10AF6RT]] is computable, and let $\mathcal{M}$ be an $L$-[[structure|983GZBQYT4]] with domain $M$.

1. $\mathcal{M}$ is *recursively saturated* if for every $n$, every tuple $\bar{a} \in M^n$ and every [[computable|PPGD5KW8JC]] set $p(x, y_1, \dots, y_n)$ of $L$-formulas, if every finite subset of $p(x, \bar{a})$ is satisfied by an element of $M$, then some $b \in M$ satisfies every formula of $p(x, \bar{a})$.
2. $\mathcal{M}$ is *resplendent* if for every $n$, every tuple $\bar{a} \in M^n$, every finite set $L'$ of new symbols and every $(L \cup L' \cup \set{c_1, \dots, c_n})$-sentence $\theta$ such that $\theta$ is consistent with the theory of $(\mathcal{M}, \bar{a})$, there is an expansion $\mathcal{M}'$ of $\mathcal{M}$ to $L \cup L'$ with $(\mathcal{M}', \bar{a}) \models \theta$.

Here the theory of $(\mathcal{M}, \bar{a})$ is the set of $(L \cup \set{c_1, \dots, c_n})$-sentences true in $\mathcal{M}$ when each $c_i$ names $a_i$.

## Notation

Some authors say *computably saturated*.

## Remarks

The main page of the idea is [[recursively saturated model|~fc343dbc]].
We prove that every $\mathcal{M}$ has a recursively saturated elementary extension of size $\abs{M} + \aleph_0$, when $L$ is countable.

1. There are $\abs{M} + \aleph_0$ pairs $(\bar{a}, p)$ of a finite tuple and a computable set of formulas, since there are countably many programs.
2. By [[realizing types|~17fa6973]], $\mathcal{M}_0 = \mathcal{M}$ has an elementary extension $\mathcal{M}_1$ of size $\abs{M} + \aleph_0$ that realizes every $p(x, \bar{a})$ finitely satisfiable in $\mathcal{M}_0$.
3. Repeat to get an [[elementary chain|NHCRZ74JHH]] $\mathcal{M}_0 \preceq \mathcal{M}_1 \preceq \cdots$, and let $\mathcal{N}$ be its union, of size $\abs{M} + \aleph_0$.
4. A tuple $\bar{a}$ of $\mathcal{N}$ lies in some $\mathcal{M}_k$. If $p(x, \bar{a})$ is finitely satisfiable in $\mathcal{N}$, then it is finitely satisfiable in $\mathcal{M}_k \preceq \mathcal{N}$, and it is realized in $\mathcal{M}_{k+1}$, hence in $\mathcal{N}$.

Example: $(\Q, <)$ is recursively saturated, since it realizes every type over a finite set.

Non-example: the standard model $(\N, 0, 1, +, \cdot, <)$ is not recursively saturated, since it omits the computable type $\set{\underline{n} < x : n \in \N}$.

## Explanations

### L1 human

Recursive saturation asks for a realization of each consistent computable list of properties with finitely many parameters.
Resplendence asks that each consistent way of adding new relations, described by one sentence, is possible on the structure itself.

### L2 human

We check that $\overline{\Q}$ is not recursively saturated.

1. The list $p(x) = \set{f(x) \ne 0 : f \in \Z[x], \, f \ne 0}$ is computable, with no parameters.
2. A finite part of $p$ excludes finitely many roots, so it is satisfied in the infinite field $\overline{\Q}$.
3. Every algebraic number is a root of some $f$, so no element satisfies all of $p$.

The trap is to allow infinitely many parameters: the definition gives no control over types over infinite sets.
