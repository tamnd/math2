## Example

Let $(a_n)$ be a nonincreasing sequence of real numbers in $[0, 1]$.
The [[monotone convergence theorem|0FM6N4R0VB]] says that $(a_n)$ converges.
We extract a rate of metastability from its proof, as in [[proof mining|~7cf2af55]].
For $g : \N \to \N$ let $\tilde g(n) = n + g(n)$, and let $K = \lceil 1 / \varepsilon \rceil$ for $\varepsilon > 0$.

**Claim.** For every $\varepsilon > 0$ and every $g$ there is $n \le \tilde g^{(K)}(0)$ with $|a_i - a_j| \le \varepsilon$ for all $i, j \in [n, n + g(n)]$.

1. Let $n_0 = 0$ and $n_{k + 1} = \tilde g(n_k)$. Then $n_0 \le n_1 \le \cdots$ and $n_k = \tilde g^{(k)}(0)$.
2. For each $k$, the sequence is nonincreasing on $[n_k, n_{k + 1}]$, so $|a_i - a_j| \le a_{n_k} - a_{n_{k + 1}}$ for $i, j$ in this interval.
3. Suppose the claim fails for $n = n_0, \ldots, n_{K - 1}$. Then $a_{n_k} - a_{n_{k + 1}} > \varepsilon$ for each $k < K$, by step 2.
4. Summing over $k < K$ gives $a_{n_0} - a_{n_K} > K \varepsilon \ge 1$.
5. But $a_{n_0} \le 1$ and $a_{n_K} \ge 0$, so $a_{n_0} - a_{n_K} \le 1$, a contradiction.
6. So some $n_k$ with $k < K$ satisfies the claim, and $n_k \le n_K = \tilde g^{(K)}(0)$.

So $\Phi(\varepsilon, g) = \tilde g^{(K)}(0)$ is a rate of metastability.

## Remarks

The rate depends only on $\varepsilon$ and $g$, not on the sequence: it is uniform for all nonincreasing sequences in $[0, 1]$.
The proof is a finite form of the classical proof, with the [[no-counterexample interpretation|~42908449]] of the Cauchy property in place of the Cauchy property.
No computable [[rate of convergence|YWZQC5E54B]] exists in general, by the [[Specker sequence|~e5c2714e]].
For $g(n) = 0$ the claim says nothing, since $[n, n]$ has one point; the content grows with $g$.

## Explanations

### L1 human

A decreasing sequence in $[0, 1]$ converges, but no formula says when it gets close to its limit.
Metastability asks a weaker question: given a window size rule $g$, find a starting point $n$ where the sequence stays within $\varepsilon$ on the window from $n$ to $n + g(n)$.
Jump from window to window; each jump where the sequence moves more than $\varepsilon$ uses up $\varepsilon$ of the total drop of at most $1$.
So after at most $1 / \varepsilon$ windows a quiet window appears.

### L2 human

We compute the rate for $\varepsilon = 1/2$ and $g(n) = n + 1$.

1. $K = 2$, and $\tilde g(n) = 2n + 1$.
2. $n_0 = 0$, $n_1 = 1$, $n_2 = 3$.
3. So some $n \in \set{0, 1}$ satisfies $|a_i - a_j| \le 1/2$ on $[n, 2n + 1]$, and $\Phi = 3$.
4. For $a = 1, 0.4, 0.3, 0.3, \ldots$: on $[0, 1]$ the drop is $0.6$, so $n = 0$ fails; on $[1, 3]$ the drop is $0.1$, so $n = 1$ works.

The typical use is as the model case for metastability results in fixed point and ergodic theory.
A trap is to read the claim as a rate of convergence: the window size $g$ is part of the input.
