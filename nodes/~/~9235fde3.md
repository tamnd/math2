## Statement

Let $G$ be a set with an [[associative|0K8F7PVDMX]] [[binary operation|0M418FE7BB]], written $ab$.

1. Suppose that there is an element $e \in G$ with $ea = a$ for all $a \in G$, and that for each $a \in G$ there is an element $b \in G$ with $ba = e$. Then $G$ is a [[group|G5S1M9]] with identity $e$, and the element $b$ is the inverse of $a$.
2. Suppose that there is an element $e \in G$ with $ae = a$ for all $a \in G$, and that for each $a \in G$ there is an element $b \in G$ with $ab = e$. Then $G$ is a group with identity $e$, and the element $b$ is the inverse of $a$.

In words: a left [[identity|07WYQPB8E3]] together with left [[inverses|0ZNZH0EXFX]] is enough, and a right identity together with right inverses is enough.

## Remarks

### Why each hypothesis is needed

1. The sides must match. Take a set $G$ with at least two elements and the operation $a \ast b = b$. It is associative, because $(a \ast b) \ast c = c$ and $a \ast (b \ast c) = b \ast c = c$. Fix an element $e$. Then $e \ast a = a$ for all $a$, so $e$ is a left identity. Also $a \ast e = e$, so $e$ is a right inverse of each $a$.
2. But this $G$ has no identity. If $f$ were an identity, then for an element $a \neq f$ we get $a = a \ast f = f$, a contradiction. So a left identity with right inverses does not give a group.
3. In the same way, the operation $a \ast b = a$ on a set with at least two elements is associative, it has a right identity, and each element has a left inverse, but it has no identity.
4. Associativity is needed. Let $G = \{e, a\}$ with $e \ast e = e$, $e \ast a = a$, $a \ast e = e$ and $a \ast a = e$. Then $e$ is a left identity, and each element $x$ has the left inverse $x$, because $e \ast e = e$ and $a \ast a = e$. 
5. But this $G$ has no identity. The element $e$ is not a right identity, because $a \ast e = e \neq a$. The other element $a$ is not a left identity, because $a \ast a = e \neq a$, so $G$ has no identity. The operation is not associative: $(a \ast a) \ast a = e \ast a = a$, but $a \ast (a \ast a) = a \ast e = e$.

### Consequences

1. To show that a structure is a group, it is enough to check associativity, a left identity and left inverses. We then check only one equation for the identity and one equation for each inverse.
2. In a group, if $ba = e$ then also $ab = e$. So one of the two equations is enough to recognize an inverse. See [[uniqueness of identity and inverses|0D9NDGE9KP]].
3. The class `Group` of Mathlib asks for a two-sided identity and only the left inverse law $a^{-1} a = 1$, and the right inverse law is then a theorem.

### Converse

Each group satisfies the hypotheses of parts 1 and 2, because a two-sided identity is a left and a right identity, and a two-sided inverse is a left and a right inverse.

### Generalizations

1. Part 2 follows from part 1 applied to the [[opposite structure|D33V8HE0KY]] $a \ast^{\mathrm{op}} b = ba$, because a right identity for $\ast$ is a left identity for $\ast^{\mathrm{op}}$.
2. A nonempty associative structure is a group if and only if, for all $a$ and $b$, the equations $ax = b$ and $ya = b$ have solutions $x$ and $y$ in $G$.

## Explanations

### L1 human

The definition of a group asks that the identity works from both sides and that each inverse works from both sides.
This result says that one side is enough, if we choose the same side for both.
If an element does nothing when we put it on the left, and each element can be undone from the left, then everything also works from the right.
The grouping rule (associativity) makes this possible.

### L2 human

We use the result to check that a structure is a group with less work.
Let $G$ be the set of real numbers other than $-1$, with $a \ast b = a + b + ab$.
This is a binary operation on $G$, because $a \ast b + 1 = (a + 1)(b + 1) \neq 0$.

1. Associativity. Both $(a \ast b) \ast c$ and $a \ast (b \ast c)$ are equal to $a + b + c + ab + ac + bc + abc$.
2. Left identity. We have $0 \ast a = 0 + a + 0 = a$ for all $a \in G$.
3. Left inverses. For $a \in G$, put $b = -a/(1 + a)$. Then $b + 1 = 1/(1 + a) \neq 0$, so $b \in G$, and $b \ast a + 1 = (b + 1)(a + 1) = 1$, so $b \ast a = 0$.

By part 1, $G$ is a group with identity $0$, and we did not need to check $a \ast 0$ or $a \ast b$.
A trap is to mix the sides: a left identity with right inverses is not enough, as the operation $a \ast b = b$ shows.

### L3 human

The result shows that the group axioms can be weakened in a controlled way.
Other minimal systems also exist: a nonempty semigroup in which each equation $ax = b$ and $ya = b$ has a solution is a group.
A finite nonempty semigroup with both cancellation laws is a group, but the finite condition is needed, because $(\mathbb{N}, +)$ has both cancellation laws.
In 1952 Graham Higman and Bernhard Neumann showed that groups can be defined by a single equation in the operation $(a, b) \mapsto a b^{-1}$.
