## Example

The formula $p \to p$ is a classical [[tautology|05006AJ7DZ]].
In the [[strong Kleene matrix|~e50e75c5]], $p \to p$ abbreviates $\neg p \lor p$, with value $\max(1 - x, x)$ at $p = x$.

1. At $p = 0$: $\max(1, 0) = 1$.
2. At $p = 1$: $\max(0, 1) = 1$.
3. At $p = \tfrac12$: $\max(\tfrac12, \tfrac12) = \tfrac12$.
4. The value $\tfrac12$ is not designated, so step 3 refutes $p \to p$.

So $p \to p$ is not a tautology of $\mathsf{K}_3$, although the inference $p \models_{\mathsf{K}_3} p$ is valid.

## Remarks

1. The same valuation refutes $p \lor \neg p$ and $\neg(p \land \neg p)$; each has the value $\tfrac12$.
2. In [[Łukasiewicz's three-valued logic|~d7a9d81e]], $\tfrac12 \to \tfrac12 = 1$, so $p \to p$ is a tautology there.
3. The example shows the failure of the deduction theorem in $\mathsf{K}_3$: $p \models p$, but $\not\models p \to p$.

## Explanations

### L1 human

"If $p$ then $p$" sounds always true.
In strong Kleene logic it is "not $p$, or $p$".
When $p$ is undefined, both parts are undefined, so the whole is undefined.

### L2 human

1. Rewrite $\to$ with $\neg$ and $\lor$.
2. Try the value $\tfrac12$ for every variable.
3. Read off the value; if it is not $1$, the formula is not a tautology.

The typical use is a fast test: every formula fails at the all-$\tfrac12$ valuation.
A trap: in $\mathsf{K}_3$ the implication is not the Łukasiewicz implication, even though both logics use the same three values.
