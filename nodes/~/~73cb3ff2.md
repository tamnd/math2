## Proof

Let $h \colon M \to N$ be an [[embedding|SCRB74SWQN]] of $\mathcal{M}$ into $\mathcal{N}$.
We use the clauses of [[satisfaction|1WTCZB4DVB]] and prove the four parts in order.

Part 1, by [[structural induction|12MQ2NJ29A]] on the [[term|6D3WA7N2W4]] $t$.

1. If $t$ is the variable $x_i$, then $h(t^{\mathcal{M}}(\bar{a})) = h(a_i) = t^{\mathcal{N}}(h(\bar{a}))$.
2. If $t$ is a constant symbol $c$, then $h(c^{\mathcal{M}}) = c^{\mathcal{N}}$, because an embedding preserves constants.
3. If $t = f(t_1, \dots, t_k)$, then $h(t^{\mathcal{M}}(\bar{a})) = h(f^{\mathcal{M}}(t_1^{\mathcal{M}}(\bar{a}), \dots, t_k^{\mathcal{M}}(\bar{a})))$ by the definition of the value of a term.
4. Since $h$ preserves $f$, this equals $f^{\mathcal{N}}(h(t_1^{\mathcal{M}}(\bar{a})), \dots, h(t_k^{\mathcal{M}}(\bar{a})))$.
5. By the induction hypothesis for $t_1, \dots, t_k$, this equals $f^{\mathcal{N}}(t_1^{\mathcal{N}}(h(\bar{a})), \dots, t_k^{\mathcal{N}}(h(\bar{a}))) = t^{\mathcal{N}}(h(\bar{a}))$.

Part 2, by structural induction on the quantifier-free formula $\varphi$.

6. Let $\varphi$ be $t_1 = t_2$. Then $\mathcal{M} \models \varphi(\bar{a})$ means $t_1^{\mathcal{M}}(\bar{a}) = t_2^{\mathcal{M}}(\bar{a})$.
7. Since $h$ is injective, this holds if and only if $h(t_1^{\mathcal{M}}(\bar{a})) = h(t_2^{\mathcal{M}}(\bar{a}))$.
8. By part 1, this holds if and only if $t_1^{\mathcal{N}}(h(\bar{a})) = t_2^{\mathcal{N}}(h(\bar{a}))$, that is, $\mathcal{N} \models \varphi(h(\bar{a}))$.
9. Let $\varphi$ be $R(t_1, \dots, t_k)$. Write $b_j = t_j^{\mathcal{M}}(\bar{a})$. Then $\mathcal{M} \models \varphi(\bar{a})$ means $(b_1, \dots, b_k) \in R^{\mathcal{M}}$.
10. Since $h$ preserves and reflects $R$, this holds if and only if $(h(b_1), \dots, h(b_k)) \in R^{\mathcal{N}}$.
11. By part 1, $h(b_j) = t_j^{\mathcal{N}}(h(\bar{a}))$, so this holds if and only if $\mathcal{N} \models \varphi(h(\bar{a}))$.
12. Let $\varphi = \neg\psi$. By the induction hypothesis $\mathcal{M} \models \psi(\bar{a}) \iff \mathcal{N} \models \psi(h(\bar{a}))$, and negating both sides gives the claim for $\varphi$.
13. Let $\varphi = \psi \land \chi$. Both sides of $\psi$ and both sides of $\chi$ agree by the induction hypothesis, so both sides of the conjunction agree. The connectives $\lor$, $\to$ and $\leftrightarrow$ are handled in the same way.

Part 3.

14. Let $\varphi = \exists y_1 \cdots \exists y_k \, \psi(\bar{x}, \bar{y})$ with $\psi$ quantifier-free, and suppose $\mathcal{M} \models \varphi(\bar{a})$.
15. Then there are $b_1, \dots, b_k \in M$ with $\mathcal{M} \models \psi(\bar{a}, \bar{b})$, by the clause for $\exists$.
16. By part 2, $\mathcal{N} \models \psi(h(\bar{a}), h(\bar{b}))$.
17. So the elements $h(b_1), \dots, h(b_k)$ are witnesses in $N$, and $\mathcal{N} \models \varphi(h(\bar{a}))$.

Part 4.

18. Let $\varphi = \forall \bar{y} \, \psi$ with $\psi$ quantifier-free, and suppose $\mathcal{N} \models \varphi(h(\bar{a}))$. Assume for a contradiction that $\mathcal{M} \not\models \varphi(\bar{a})$.
19. Then $\mathcal{M} \models \exists \bar{y} \, \neg\psi(\bar{a}, \bar{y})$, and $\neg\psi$ is quantifier-free, so this formula is existential.
20. By part 3, $\mathcal{N} \models \exists \bar{y} \, \neg\psi(h(\bar{a}), \bar{y})$, which contradicts $\mathcal{N} \models \varphi(h(\bar{a}))$.

This proves parts 1 to 4.
For a substructure $\mathcal{M} \subseteq \mathcal{N}$, the inclusion map is an embedding, which gives the last claim of the statement.

## Idea

An embedding commutes with the evaluation of terms, because it commutes with each function and constant.
Injectivity handles equations, and the two-sided condition on relations handles relation symbols.
Connectives keep the equivalence, and a witness in $M$ is sent to a witness in $N$, which gives the existential case; the universal case is its negation.

## Variants

One can prove part 2 only for atomic formulas and then note that the set of formulas for which the equivalence holds is closed under Boolean connectives.
For an isomorphism the same induction also passes through every quantifier, because every element of $N$ is an image $h(b)$; this is the proof of [[isomorphism invariance of truth|X3XGDVSANT]].
