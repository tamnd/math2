## Summary

The absolute value of a number is its distance from $0$. We write $|x|$ for the absolute value of $x$.
For a real number, $|x|$ is $x$ without its sign, for example $|-3| = |3| = 3$.
For a complex number $a + b i$, the absolute value is the [[modulus|~a255a1b0]] $\sqrt{a^2 + b^2}$.
