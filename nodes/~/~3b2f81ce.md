## Example

We define [[binary trees|02A8EMC83C]] inductively.
The empty tree $\varnothing$ is a binary tree, and if $L$ and $R$ are binary trees, then $\operatorname{node}(L, R)$ is a binary tree.
Let $n(t)$ be the number of nodes of $t$ and $e(t)$ the number of empty subtrees of $t$, given by the rules
$$n(\varnothing) = 0, \quad n(\operatorname{node}(L, R)) = n(L) + n(R) + 1, \qquad e(\varnothing) = 1, \quad e(\operatorname{node}(L, R)) = e(L) + e(R).$$
We prove $e(t) = n(t) + 1$ for every binary tree $t$, by [[structural induction|~f9cfa40d]] on $t$.

1. Case $\varnothing$: $e(\varnothing) = 1$ and $n(\varnothing) + 1 = 0 + 1 = 1$. So the claim holds.
2. Case $\operatorname{node}(L, R)$: the induction hypotheses are $e(L) = n(L) + 1$ and $e(R) = n(R) + 1$.
3. By the rule for $e$ and the two hypotheses, $e(\operatorname{node}(L, R)) = e(L) + e(R) = n(L) + n(R) + 2$.
4. By the rule for $n$, $n(\operatorname{node}(L, R)) + 1 = n(L) + n(R) + 1 + 1 = n(L) + n(R) + 2$.
5. Steps 3 and 4 give $e(\operatorname{node}(L, R)) = n(\operatorname{node}(L, R)) + 1$. This completes the step.
6. By structural induction, $e(t) = n(t) + 1$ for every binary tree $t$.

Some small trees agree with the result.

| $t$ | $n(t)$ | $e(t)$ |
|---|---|---|
| $\varnothing$ | $0$ | $1$ |
| $\operatorname{node}(\varnothing, \varnothing)$ | $1$ | $2$ |
| $\operatorname{node}(\operatorname{node}(\varnothing, \varnothing), \varnothing)$ | $2$ | $3$ |
| $\operatorname{node}(\operatorname{node}(\varnothing, \varnothing), \operatorname{node}(\varnothing, \varnothing))$ | $3$ | $4$ |

## Remarks

1. The step uses two hypotheses, one for each part. This is typical of a constructor with two parts.
2. If we draw each empty subtree as a leaf, every tree becomes a full binary tree: each inner node has exactly two children. The result then says that a full binary tree has one more leaf than inner nodes.
3. A count gives the same result for $n(t) \ge 1$. Each node has $2$ child positions, so there are $2n(t)$ positions. Each node except the root fills one position, and each empty subtree fills one, so $2n(t) = (n(t) - 1) + e(t)$.
4. Another proof of remark 2 takes a smallest counterexample and deletes a leaf and its parent, which gives a smaller counterexample. Structural induction gives a direct proof with no contradiction.

## Explanations

### L1 human

A binary tree is either empty, or it is a node with a left tree and a right tree below it.
In a drawing, every node has two places below it, and each place holds a node or nothing.
We count the places that hold nothing, and we find one more of them than there are nodes.
For a single node, there are $2$ empty places and $1$ node.
The proof shows that putting two trees under a new node keeps this rule true.

### L2 human

We follow the proof for $t = \operatorname{node}(\operatorname{node}(\varnothing, \varnothing), \varnothing)$, with $L = \operatorname{node}(\varnothing, \varnothing)$ and $R = \varnothing$.

1. For $R = \varnothing$, the base case gives $e(R) = 1 = n(R) + 1$.
2. For $L$, the step with two empty parts gives $e(L) = 1 + 1 = 2$ and $n(L) = 0 + 0 + 1 = 1$.
3. For $t$, the step gives $e(t) = e(L) + e(R) = 2 + 1 = 3$.
4. The rule for $n$ gives $n(t) = 1 + 0 + 1 = 2$, so $e(t) = n(t) + 1$.

The typical use of this pattern is a relation between two counts that are both defined by recursion on the same structure.
A trap is to use only one hypothesis, for example only for $L$, which leaves the term $e(R)$ unknown.
