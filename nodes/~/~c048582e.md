## Example

Let $T$ be the theory in the language of pure equality, with no non-logical symbols, whose only axiom is $\forall x \, \forall y \, (x = y)$.
We check that $T$ is [[negation complete|319P85G2C1]].

1. A model of $T$ is a set with exactly one element; structures have non-empty domains.
2. Any two one-element sets are isomorphic, by the unique bijection between them.
3. Isomorphic structures satisfy the same [[sentences|DKFGQTRYZE]]. So for every sentence $\varphi$, either all models of $T$ satisfy $\varphi$, or all models satisfy $\neg \varphi$.
4. In the first case $T \models \varphi$, and $T \vdash \varphi$ by the [[completeness theorem|WQ1ZE255SF]]. In the second case $T \vdash \neg \varphi$.
5. So $T$ is negation complete.

For instance, $T \vdash \exists x \, \forall y \, (x = y)$, and $T \vdash \neg \exists x \, \exists y \, \neg (x = y)$.

## Remarks

The same argument shows that the theory "there are exactly $n$ elements" is negation complete for each $n \ge 1$.
The empty theory in the same language is not negation complete: it decides neither $\forall x \, \forall y \, (x = y)$ nor its negation.

## Explanations

### L1 human

If the rules say "there is exactly one thing", every question about which things are equal has one answer.
So the rules settle every question in their language.

### L2 human

1. All models are isomorphic, so they agree on every sentence.
2. By the completeness theorem, a sentence true in all models is provable.

The typical use is as a first example of a complete theory, proved through models instead of proofs.
A trap: the argument needs the completeness theorem to pass from "true in all models" to "provable".
