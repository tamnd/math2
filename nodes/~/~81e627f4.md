## Example

Consider the system $x^2 + y = 3$, $x - y = 1$ over $\R$.

1. The term $x^2$ is not a constant times $x$, so the first equation is not a [[linear equation|0Q3ZT8J05R]].
2. A student writes the array $\left[\begin{array}{cc|c} 1 & 1 & 3 \\ 1 & -1 & 1 \end{array}\right]$, treating $x^2$ as $x$.
3. Reducing it: $R_2 \leftarrow R_2 - R_1$ gives $(0, -2 \mid -2)$, so $y = 1$ and $x = 2$.
4. Check $(2, 1)$ in the true system: $4 + 1 = 5 \ne 3$. So $(2, 1)$ is not a solution.
5. The true solutions: $y = x - 1$, so $x^2 + x - 4 = 0$, and $x = \tfrac{-1 \pm \sqrt{17}}{2}$.
6. So the array is not an [[augmented matrix|0YCDZ7N8VD]] of this system.

## Remarks

Only linear systems have augmented matrices.
The true system has two solutions, which no linear system over $\R$ can have.

## Explanations

### L1 human

The table method works only when every unknown appears plainly, multiplied by a number.
A square of an unknown breaks it.

### L2 human

1. Check that each equation is linear before you build the table.
2. If one is not, use substitution or other methods for nonlinear equations.

A trap: the method still produces an answer, so only a check in the original equations shows the mistake.
