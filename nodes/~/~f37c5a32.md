## Example

We give a [[preferential model|~d45c3d4a]] whose relation fails Rational Monotony.
Use two atoms $p$ and $q$, and three states $x, y, z$ with these labels:

| state | $p$ | $q$ |
| --- | --- | --- |
| $x$ | true | false |
| $y$ | false | true |
| $z$ | true | true |

The order has the single pair $x \prec y$.
It is a strict partial order on a finite set, so the model is smooth.
By [[soundness of system P|~2b4be2dd]], its relation $\mathrel{|\!\sim}$ is a [[preferential consequence relation|~5ba6fe6b]].

1. All three states satisfy $\top$, and $y$ is beaten by $x$. So $\min \widehat{\top} = \set{x, z}$.
2. Both $x$ and $z$ satisfy $p$, so $\top \mathrel{|\!\sim} p$.
3. The state $z$ satisfies $q$, so $\top \mathrel{|\!\not\sim} \neg q$.
4. Rational Monotony would now give $\top \land q \mathrel{|\!\sim} p$.
5. The $q$-states are $y$ and $z$. The only state below $y$ is $x$, which is not a $q$-state. So $\min \widehat{q} = \set{y, z}$.
6. The state $y$ does not satisfy $p$, so $\top \land q \mathrel{|\!\not\sim} p$.

So Rational Monotony fails, and the relation is preferential but not rational.

## Remarks

The order is not modular: $x \prec y$, but neither $z \prec y$ nor $x \prec z$.
Put $z$ in the same level as $x$, so that also $z \prec y$; then $y$ is no longer minimal among the $q$-states, and $q \mathrel{|\!\sim} p$ holds.
This matches the fact that ranked models give rational relations.

## Explanations

### L1 human

Normally $p$ holds, and it is possible that $q$ holds.
Rational Monotony says that learning $q$ should then not destroy the conclusion $p$.
In this model it does, because learning $q$ brings back a state $y$ that was hidden only by a state without $q$.

### L2 human

The state $y$ is beaten only by $x$, and $x$ disappears when we restrict to $q$-states.
So $y$ becomes minimal, and it violates $p$.
A trap is to expect a single "most normal" level; in a non-ranked model, states can be incomparable.
