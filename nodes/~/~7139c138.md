## Summary

Fix a set $P$ of [[propositional variables|AC4HD34AXX]] and the alphabet that consists of the variables, the [[connectives|QS0XVAN9BG]] $\neg$, $\land$, $\lor$, $\to$, $\leftrightarrow$ and the two brackets $($ and $)$.
The set of propositional formulas over $P$ is the smallest set $\mathrm{Form}$ of finite [[strings|1P6EP01HZF]] over this alphabet with two properties.
First, each variable $p \in P$, as a string of length $1$, belongs to $\mathrm{Form}$.
Second, if $\varphi$ and $\psi$ belong to $\mathrm{Form}$, then the strings $(\neg \varphi)$, $(\varphi \land \psi)$, $(\varphi \lor \psi)$, $(\varphi \to \psi)$ and $(\varphi \leftrightarrow \psi)$ belong to $\mathrm{Form}$.
The [[definition node|~6bf5df7c]] states this in full.
Formulas are the sentences of the [[propositional calculus|09K9MWD2QQ]]: truth values, proofs and normal forms are all defined on them.

## Motivation

In ordinary language the sentence "it rains and it is cold or it is windy" has two readings.
In the first reading the "and" groups first, and in the second reading the "or" groups first.
The two readings can have different truth values, so a logic needs a language without this problem.
We also want to define functions on all sentences, such as the truth value, by giving one rule for each way of building a sentence.
And we want to prove facts about all sentences by one argument for each way of building them.
The inductive definition of formulas, with a pair of brackets for each connective, gives all three things.

## Notation

Greek letters $\varphi$, $\psi$, $\chi$ denote formulas; they are symbols of the metalanguage, not of the formulas.
In practice we drop the outer brackets and use the precedence $\neg$, then $\land$, then $\lor$, then $\to$, then $\leftrightarrow$; the arrow $\to$ groups to the right.
So $p \land q \to \neg r$ abbreviates the official formula $((p \land q) \to (\neg r))$.
Some books also allow the constants $\top$ (true) and $\bot$ (false) as formulas of length $1$.
Some books use fewer connectives, for example only $\neg$ and $\to$ in the [[Hilbert system|1MGMQX43B8]] $L$.
Other names are well-formed formula, wff, sentence and sentential formula; the general notion is the [[well-formed formula|HYJ10AF6RT]].
In Polish notation a formula is written in prefix form without brackets, for example $Cpq$ for $p \to q$.

## Remarks

### Formation sequences

A formation sequence is a finite list $\varphi_1, \ldots, \varphi_n$ of strings in which each $\varphi_k$ is a variable, or $(\neg \varphi_i)$ with $i < k$, or $(\varphi_i \circ \varphi_j)$ with $i, j < k$ and $\circ$ a binary connective.
A string is a formula if and only if it is the last member of some formation sequence.
The [[definition node|~6bf5df7c]] proves this.
So the "smallest set" of the definition is the set of strings that can be built in finitely many steps.

### Structural induction

The smallest-set definition gives a method of proof, called [[induction on formulas|EDRV3N0SA3]], an instance of [[structural induction|12MQ2NJ29A]].
Let $A$ be a property of strings.
Suppose that each variable has $A$, that $(\neg \varphi)$ has $A$ when $\varphi$ has $A$, and that $(\varphi \circ \psi)$ has $A$ when $\varphi$ and $\psi$ have $A$.
Then every formula has $A$.
The proof uses only minimality: the set of formulas with $A$ contains the variables and is closed under the formation rules, so it contains the smallest such set, which is $\mathrm{Form}$.
For example, every formula has as many left brackets as right brackets, and its number of brackets is twice its number of connectives.
For a variable both numbers are $0$, and each formation rule adds one connective and two brackets.

### Definitions by recursion

We also define functions on formulas by one clause for each formation rule.
The set $\mathrm{Sub}(\varphi)$ of subformulas of $\varphi$ is defined by
$$\mathrm{Sub}(p) = \set{p}, \quad \mathrm{Sub}((\neg \varphi)) = \set{(\neg \varphi)} \cup \mathrm{Sub}(\varphi), \quad \mathrm{Sub}((\varphi \circ \psi)) = \set{(\varphi \circ \psi)} \cup \mathrm{Sub}(\varphi) \cup \mathrm{Sub}(\psi).$$
In the same way we define the set $\mathrm{Var}(\varphi)$ of variables that occur in $\varphi$, the number of connectives, and the depth.
Such a definition gives a well-defined function only because each formula is built in exactly one way.
This is the [[unique readability theorem|~26f00b05]].
The most important recursive definition is the [[truth valuation|~41f42e3d]].

### Parse trees

The parse tree of a formula is a finite [[rooted tree|0Y0JGC2K9T]].
The tree of a variable $p$ is one node labelled $p$.
The tree of $(\neg \varphi)$ has a root labelled $\neg$ with the tree of $\varphi$ below it.
The tree of $(\varphi \circ \psi)$ has a root labelled $\circ$ with the tree of $\varphi$ on the left and the tree of $\psi$ on the right.
The subformulas are the formulas of the subtrees, and the label of the root is the main connective.
The leaves carry the variables, and the brackets do not appear in the tree.

### Examples

- Each variable, such as $p$, is a formula by the first rule.
- The string $((p \land q) \to (\neg r))$ is a formula with $6$ subformulas and $3$ connectives; [[this example|~b3114ae1]] gives its formation sequence and its tree.
- The string $(\neg (\neg p))$ is a formula: $p$ is a formula, so $(\neg p)$ is one, so $(\neg (\neg p))$ is one.
- The axiom $(p \to (q \to p))$ of the system $L$ is a formula, built from $p$ and $(q \to p)$.
- In Polish notation the string $CCpqCNqNp$ is a formula; [[this example|~97d38925]] reads it with a counter.

### Non-examples

- The strings $(p \land \land q)$ and $(p \land q$ are not formulas; [[this non-example|~40cce46c]] shows it with the bracket count.
- The string $(p)$ is not a formula: it has $2$ brackets and $0$ connectives, but each formula has twice as many brackets as connectives.
- The string $p \land q$ is not an official formula, since a binary connective always comes with a pair of brackets; it is an abbreviation of $(p \land q)$.

### Basic properties

- Each formula is a nonempty string, and its first symbol is a variable or a left bracket.
- Each formula has equal numbers of left and right brackets, and twice as many brackets as connectives.
- No proper initial segment of a formula is a formula, and each formula has exactly one reading ([[unique readability|~26f00b05]]).
- Each formula has finitely many subformulas and finitely many variables.
- If $P$ is [[countable|01TQB88H4C]], then $\mathrm{Form}$ is countable, because it is a subset of the set of finite strings over a countable alphabet.
- Even with one variable there are infinitely many formulas: $p$, $(\neg p)$, $(\neg (\neg p))$ and so on.

### History

Frege's Begriffsschrift of 1879 wrote formulas in a two-dimensional notation of lines and strokes.
Whitehead and Russell's Principia Mathematica grouped formulas with dots instead of brackets.
Jan Łukasiewicz introduced his bracket-free prefix notation in 1924; it is now called Polish notation.

### Common errors

- To treat $p \land q \lor r$ as a formula without a precedence rule. It has two readings, and they can have different truth values.
- To confuse a formula with its truth value. The formula $p \to q$ is a string; its value is defined only after we give values to $p$ and $q$.
- To think that $\varphi$ is a variable of the formula. The letter $\varphi$ is a name in the metalanguage for some formula, and the variables of the formula are elements of $P$.

## Explanations

### L1 human

A propositional formula is a sentence of logic built by fixed rules.
We start with letters such as $p$ and $q$, which stand for simple statements.
We combine them with "not", "and", "or", "if ... then" and "if and only if", and we put brackets around each new combination.
For example, $(p \land q)$ means "$p$ and $q$", and $((p \land q) \to r)$ means "if $p$ and $q$, then $r$".
The brackets tell us which part is built first, as brackets do in $(2 + 3) \times 4$.
Each formula is a finite string of symbols, built in finitely many steps.

### L2 human

We build a formula, find its subformulas and check the bracket rule.

1. Start with the variables $p$ and $q$.
2. Apply the rule for $\neg$ to $q$: $(\neg q)$ is a formula.
3. Apply the rule for $\lor$ to $p$ and $(\neg q)$: $(p \lor (\neg q))$ is a formula.
4. Apply the rule for $\to$ to $q$ and the formula of step 3: $\varphi = (q \to (p \lor (\neg q)))$ is a formula.
5. The subformulas are $p$, $q$, $(\neg q)$, $(p \lor (\neg q))$ and $\varphi$, so there are $5$ of them.
6. The formula $\varphi$ has $3$ connectives ($\to$, $\lor$, $\neg$) and $6$ brackets, so the brackets number twice the connectives.

The typical use of the inductive definition is a proof by induction on formulas: check the variables, then check that each rule keeps the property.
A trap is to count the variable $q$ twice as a subformula.
Subformulas form a set, so $q$ counts once, although it occurs twice in $\varphi$.

### L3 human

The set $\mathrm{Form}$ with the operations $\varphi \mapsto (\neg \varphi)$ and $(\varphi, \psi) \mapsto (\varphi \circ \psi)$ is an algebra with one unary and four binary operations.
By unique readability it is the absolutely free algebra, or term algebra, of this signature over the set $P$.
Definition by recursion is then the universal property of the free algebra: each map from $P$ to an algebra of the same signature extends to exactly one homomorphism.
The smallest-set definition is the [[least fixed point|CH9B4RZPMW]] of a monotone operator on sets of strings, the same pattern that defines the terms and formulas of [[first-order logic|086QKPF0A6]].
In computer science the same object is an abstract syntax tree, and the official bracketed strings are one way to write such trees in a line.
