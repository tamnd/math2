## Example

Let $V = \{1, 3, 5, 7\}$ with multiplication modulo $8$.
We compute the products: each element times itself is $1$, because $9$, $25$ and $49$ are $1$ modulo $8$.
Also $3 \cdot 5 = 15 = 7$, $3 \cdot 7 = 21 = 5$ and $5 \cdot 7 = 35 = 3$ modulo $8$.
The [[Cayley table|0YB2NRP0T5]] is as follows.

| $\cdot$ | $1$ | $3$ | $5$ | $7$ |
|---|---|---|---|---|
| $1$ | $1$ | $3$ | $5$ | $7$ |
| $3$ | $3$ | $1$ | $7$ | $5$ |
| $5$ | $5$ | $7$ | $1$ | $3$ |
| $7$ | $7$ | $5$ | $3$ | $1$ |

The table shows that multiplication is a binary operation on $V$, that $1$ is the identity, and that each element is its own inverse.
Multiplication modulo $8$ is associative, so $V$ is a [[group|G5S1M9]] with $4$ elements.
With the names $e = 1$, $a = 3$, $b = 5$ and $c = 7$, this is the table of the [[Klein four-group|0PMRQJVTME]].

## Remarks

The table is a Latin square: each element occurs one time in each row and in each column.
The table is symmetric about the main diagonal, so $V$ is [[abelian|082GHNPJ53]].
The main diagonal contains only the identity, so $x^2 = e$ for each $x$.
For this reason the Klein four-group is not the cyclic group $\mathbb{Z}/4\mathbb{Z}$, whose table has the entry $1 + 1 = 2$ on its main diagonal.
The same table also describes the symmetries of a rectangle that is not a square: the identity, the half turn, and the two reflections in the lines through the midpoints of opposite sides.
See also [[the Klein four-group is abelian but not cyclic|DX6X1D21FE]].

## Explanations

### L1 human

Take the numbers $1, 3, 5, 7$ and multiply them, but keep only the remainder after division by $8$.
For example, $3 \cdot 5 = 15$, and $15$ leaves the remainder $7$.
The table shows all sixteen results.
Each number times itself gives $1$, so each number undoes itself.

### L2 human

We use the table to compute a longer product, for example $3 \cdot 5 \cdot 7$.

1. Row $3$, column $5$ gives $3 \cdot 5 = 7$.
2. Row $7$, column $7$ gives $7 \cdot 7 = 1$.
3. So $3 \cdot 5 \cdot 7 = 1$.

The product of the three elements other than the identity is the identity.
A trap is to think that two groups with $4$ elements must have the same table: the diagonal of this table differs from the diagonal of $\mathbb{Z}/4\mathbb{Z}$.
