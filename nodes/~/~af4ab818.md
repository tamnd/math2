## Example

On $\R^2$ let $B(x, y) = x_1 y_1 + x_2$.
We check the two conditions of a [[bilinear form|0P799D6AMN]].

1. Fix $y$. The map $x \mapsto y_1 x_1 + x_2$ is linear in $x$, because it is a linear combination of the coordinates of $x$.
2. Fix $x = (0, 1)$. Then $B(x, y) = 1$ for every $y$.
3. A linear map sends $0$ to $0$, but $B(x, 0) = 1$. So $y \mapsto B(x, y)$ is not linear.
4. In the same way, $B(x, 2y) = 2y_1 \cdot 0 + 1 = 1$ and $2B(x, y) = 2$ for $x = (0, 1)$ and any $y$.
5. So $B$ is linear in the first slot but not in the second slot, and $B$ is not a bilinear form.

## Remarks

The example shows that linearity in one slot does not give linearity in the other slot.
The term $x_2$ does not contain $y$, and every term of a bilinear form must contain one coordinate of $x$ and one coordinate of $y$.
If we remove the term $x_2$, we get $x_1 y_1$, which is bilinear.
If we change it to $x_2 y_2$, we get the [[dot product|0S52TNNTH9]].

## Explanations

### L1 human

A bilinear rule must double its answer when we double either input.
Here, the second input does not change the term $x_2$.
With $x = (0, 1)$ the rule gives $1$ for every second input, also for the zero vector.
So doubling the second input does not double the answer.

### L2 human

A fast test for bilinearity of a polynomial formula in the coordinates:

1. Write the formula as a sum of monomials.
2. Check that each monomial has degree $1$ in the coordinates of $x$ and degree $1$ in the coordinates of $y$.
3. Here the monomial $x_2$ has degree $0$ in $y$, so the test fails.

A trap: linearity in the first slot is not enough.
We must check both slots.
