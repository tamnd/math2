## Example

A real sequence $(a_n)$ is [[bounded|0A8JNBGT2Z]] if there is $M > 0$ such that $|a_n| \leq M$ for all $n$.
The definition has two bounded [[quantifiers|~aec76a22]]: "there is $M > 0$" and "for all $n \in \mathbb{N}$".
We write it with symbols and apply it to $a_n = (-1)^n$.

1. In symbols, the definition is $\exists M > 0 \; \forall n \in \mathbb{N} \; |a_n| \leq M$.
2. The bounded quantifier "$\exists M > 0$" abbreviates "there is a real $M$ such that $M > 0$ and". The bounded quantifier "$\forall n \in \mathbb{N}$" abbreviates "for every $n$, if $n \in \mathbb{N}$, then".
3. The existential quantifier comes first. So one number $M$ must work for all $n$ at once.
4. For $a_n = (-1)^n$, take $M = 1$. For every $n$, $|a_n| = |(-1)^n| = 1 \leq 1$.
5. So $M = 1$ satisfies the condition, and the sequence $(-1)^n$ is bounded.

## Remarks

The [[order of quantifiers|0FYQMKFE77]] matters here.
The statement with the quantifiers swapped is "for every $n$, there is $M > 0$ with $|a_n| \leq M$".
This weaker statement is true for every real sequence: for each $n$, take $M = |a_n| + 1$.
So the swapped statement holds for $a_n = n$, which is not bounded.

The negation follows the rules for quantifiers: $(a_n)$ is unbounded if for every $M > 0$ there is $n$ with $|a_n| > M$.
For $a_n = n$, given $M > 0$, any integer $n > M$ works.
The domain of a bounded quantifier also matters.
If we drop "$M > 0$" and allow every real $M$, the definition does not change, but if we restrict to $M < 1$, the sequence $(-1)^n$ is no longer bounded in that sense.

## Explanations

### L1 human

A list of numbers is bounded if one fence keeps every number in the list between $-M$ and $M$.
The list $-1, 1, -1, 1, \ldots$ is bounded: the fence at $1$ works for all of them.
The list $1, 2, 3, 4, \ldots$ is not bounded: every fence is passed by some later number.
The words "one fence for every number" carry the two quantifiers.

### L2 human

We check whether $a_n = \dfrac{n}{n + 1}$ is bounded, and we follow the quantifiers.

1. The goal is "$\exists M > 0 \; \forall n \in \mathbb{N} \; |a_n| \leq M$". So we must name one $M$ first.
2. Try $M = 1$. Now let $n \in \mathbb{N}$ be arbitrary, as the universal quantifier asks.
3. Since $0 \leq n < n + 1$, we get $0 \leq \dfrac{n}{n + 1} < 1$. So $|a_n| \leq 1$.
4. The $n$ in step 2 was arbitrary, so $M = 1$ works for all $n$, and the sequence is bounded.

The typical use is in proofs: an existential quantifier asks for a specific object, and a universal quantifier asks for an arbitrary one.

A trap: a student chooses $M$ after $n$, for example $M = |a_n|$.
This proves only the swapped statement, which every sequence satisfies.
