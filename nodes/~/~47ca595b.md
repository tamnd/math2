## Example

Let
$$N = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}.$$

1. The entry $n_{12} = 1$ is not $0$, so $N$ is not the [[zero matrix|~d9ded4cd]].
2. The entry $(i, j)$ of $N^2$ is $n_{i1} n_{1j} + n_{i2} n_{2j}$. The second row of $N$ is zero, so $n_{2j} = 0$, and the first column is zero, so $n_{i1} = 0$.
3. So every entry of $N^2$ is $0$, and $N^2 = 0$.
4. Thus $N$ is a [[nilpotent matrix|0419GJC84P]] of index 2.
5. As a map, $N$ sends $e_2$ to $e_1$ and $e_1$ to $0$, so $N^2$ sends both to $0$.

## Remarks

For real numbers, $x^2 = 0$ implies $x = 0$.
The example shows that the matrix equation $X^2 = 0$ has nonzero solutions.
Every matrix $\begin{pmatrix} a & b \\ c & -a \end{pmatrix}$ with $a^2 + bc = 0$ also has square zero.

## Explanations

### L1 human

This matrix is not the zero matrix, because it has a $1$ in the top right corner.
When we multiply it by itself, the $1$ meets only zeros, and we get the zero matrix.

### L2 human

The map $N$ moves the second basis vector to the first, and the first to zero.
Applied twice, it kills every vector, so $N^2 = 0$.
