## Proof

We prove the equivalences 1.1 if and only if 1.2, 1.1 if and only if 1.3, and 1.3 if and only if 1.4, and then part 2.

1. (1.1 and 1.2) By part 3 of the [[dependence lemma|~ddec9473]], the columns are dependent if and only if some $v_j$ lies in the span of the other columns. Negating both sides gives 1.1 if and only if 1.2.
2. (1.1 and 1.3) By [[linear systems as vector equations|E7SAHXQEVC]], $Ax = x_1 v_1 + \cdots + x_n v_n$ for $x = (x_1, \dots, x_n)$.
3. So a nonzero $x$ with $Ax = 0$ is the same as coefficients $x_1, \dots, x_n$, not all $0$, with $\sum_j x_j v_j = 0$.
4. By the [[definition of independence|0EVHJFTG9Z]], such coefficients exist exactly when the columns are dependent. So 1.1 holds if and only if 1.3 holds.
5. (1.3 and 1.4) By [[the pivot criterion for homogeneous systems|JPW6KVS70A]], $Ax = 0$ has a nonzero solution if and only if some column of $A$ has no pivot. Negating both sides gives 1.3 if and only if 1.4.
6. (Part 2) Each pivot lies in a different row, so $A$ has at most $m$ pivots.
7. If $n > m$, then at most $m < n$ columns have a pivot, so some column has no pivot.
8. By step 5, $Ax = 0$ has a nonzero solution, and by step 4 the columns are dependent.

## Idea

The matrix-vector product turns a dependence relation into a nonzero solution of $Ax = 0$.
Row reduction finds such a solution exactly when a free variable exists, which is a column without a pivot.
