## Example

Let $\sigma = \set{+, \cdot, -, 0, 1, <}$ be the [[signature|WDVVEYD6AT]] of [[ordered fields|0P3VCBDEE2]].
Let $\mathrm{Sq}$ be the string
$$\forall x \, \big(0 < x \to \exists y \, (y \cdot y = x)\big).$$
We check that $\mathrm{Sq}$ is a first-order [[sentence|DKFGQTRYZE]], that it is true in $\mathbb{R}$, and that it is false in $\mathbb{Q}$.

1. The strings $0 < x$ and $y \cdot y = x$ are atomic formulas: $<$ is a binary relation symbol, $=$ is the equality symbol, and $0$, $x$, $y \cdot y$ are terms.
2. The quantifier $\exists y$ applied to $y \cdot y = x$ gives a formula, and $\to$ joins it to $0 < x$.
3. The quantifier $\forall x$ applied to the whole gives a formula. Both quantifiers range over elements of the domain, so the formula is first-order.
4. The variable $y$ is bound by $\exists y$, and $x$ is bound by $\forall x$. No variable is free, so $\mathrm{Sq}$ is a sentence.
5. In $\mathbb{R}$, let $a > 0$. The number $b = \sqrt{a}$ is a real number with $b \cdot b = a$. So $\mathbb{R}$ satisfies $\mathrm{Sq}$.
6. In $\mathbb{Q}$, take $x = 2$. Then $0 < 2$ holds. Suppose that $(p/q)^2 = 2$ with integers $p, q$, $q \neq 0$, and $\gcd(p, q) = 1$. Then $p^2 = 2q^2$, so $p$ is even, say $p = 2k$. Then $2k^2 = q^2$, so $q$ is even too, against $\gcd(p, q) = 1$.
7. So no rational $y$ satisfies $y \cdot y = 2$, and $\mathbb{Q}$ does not satisfy $\mathrm{Sq}$.

So one first-order sentence separates the ordered fields $\mathbb{R}$ and $\mathbb{Q}$.

## Remarks

The hypothesis $0 < x$ cannot be dropped: the sentence $\forall x \, \exists y \, (y \cdot y = x)$ is false in $\mathbb{R}$, because $y \cdot y = -1$ has no real solution.
It is true in $\mathbb{C}$, but $\mathbb{C}$ is not an ordered field, so the signature then has no $<$.
The proof of step 5 uses the completeness of $\mathbb{R}$, for example through the intermediate value theorem for $y \mapsto y^2$.
The sentence itself does not mention completeness.
It is one of the axioms of [[real closed fields|DDY3Q3PJ6W]], together with one sentence for each odd degree $n$: every polynomial of degree $n$ has a root.
Those axioms are first-order, and they hold in $\mathbb{R}$ and also in the countable field of real algebraic numbers.

## Explanations

### L1 human

The sentence says: "every positive number has a square root".
It talks only about numbers, so it is a first-order sentence.
It is true for the real numbers: the square root of $2$ is about $1.414$.
It is false for the fractions: no fraction times itself gives exactly $2$.
So the same sentence can be true in one number system and false in another.

### L2 human

We read the sentence in the ordered field $\mathbb{Q}(\sqrt{2})$ of the numbers $a + b\sqrt{2}$ with $a, b \in \mathbb{Q}$.

1. The number $2$ now has a square root, $\sqrt{2}$.
2. The number $3$ is positive. Suppose $(a + b\sqrt{2})^2 = 3$. Then $a^2 + 2b^2 = 3$ and $2ab = 0$.
3. If $b = 0$, then $a^2 = 3$, which has no rational solution, by the argument of step 6 with the prime $3$.
4. If $a = 0$, then $2b^2 = 3$, so $(2b)^2 = 6$, which has no rational solution, by the same argument with the prime $2$.
5. So $\mathrm{Sq}$ is false in $\mathbb{Q}(\sqrt{2})$, with the witness $x = 3$.

The typical use of such a sentence is to show that two structures are not elementarily equivalent.
A trap: the truth of a sentence depends on the structure, so "$\mathrm{Sq}$ is true" has no meaning until the structure is fixed.
