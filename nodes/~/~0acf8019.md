## Definition

Let $L$ and $L'$ be [[signatures|WDVVEYD6AT]], let $M$ be an $L$-[[structure|983GZBQYT4]] with domain $M$, let $N$ be an $L'$-structure, and let $A \subseteq M$.
Let $n \ge 1$, and write $\bar x, \bar x_1, \bar x_2, \dots$ for $n$-tuples of variables.
An *$n$-dimensional interpretation $\Gamma$ of $N$ in $M$ over $A$* consists of the following data.

1. An $L_A$-[[formula|HYJ10AF6RT]] $\partial(\bar x)$, the *domain formula*.
2. An $L_A$-formula $\varepsilon(\bar x_1, \bar x_2)$.
3. For each relation symbol $R$ of $L'$ of arity $k$, an $L_A$-formula $\varphi_R(\bar x_1, \dots, \bar x_k)$.
4. For each function symbol $F$ of $L'$ of arity $k$, an $L_A$-formula $\varphi_F(\bar x_1, \dots, \bar x_k, \bar x_{k+1})$. Constant symbols count as function symbols of arity $0$.
5. A surjective map $f : \partial(M^n) \to N$, the *coordinate map*.

The data must satisfy these conditions, for all tuples $\bar a, \bar b, \bar a_1, \dots, \bar a_{k+1}$ in $\partial(M^n)$.

- (Equality) $f(\bar a) = f(\bar b)$ if and only if $M \models \varepsilon(\bar a, \bar b)$.
- (Relations) $N \models R(f \bar a_1, \dots, f \bar a_k)$ if and only if $M \models \varphi_R(\bar a_1, \dots, \bar a_k)$.
- (Functions) $F^N(f \bar a_1, \dots, f \bar a_k) = f(\bar a_{k+1})$ if and only if $M \models \varphi_F(\bar a_1, \dots, \bar a_{k+1})$.

The structure $N$ is *interpretable in $M$ over $A$* if such an interpretation exists.
It is *interpretable without parameters* if this holds with $A = \emptyset$.
It is *definable in $M$* if this holds with $\varepsilon(\bar x_1, \bar x_2)$ the formula $\bar x_1 = \bar x_2$, so that $f$ is a bijection from the [[definable set|CY1TXHF6KQ]] $\partial(M^n)$ onto $N$.

## Notation

The conditions force $\varepsilon$ to define an [[equivalence relation|0G8VEZ3WTK]] on $\partial(M^n)$, and they force each $\varphi_R$ to be invariant under it.
So $N$ is isomorphic to the quotient $\partial(M^n) / \varepsilon$ with the induced relations and functions.
Books that omit the coordinate map call this quotient structure the interpreted structure, and say that $N$ is interpretable when it is isomorphic to it.
Some authors also allow the domain to be a finite union of definable sets of different lengths, which is the same as an interpretation in $M^{\mathrm{eq}}$.

## Remarks

The coordinate map is not determined by the formulas.
If $\alpha$ is an automorphism of $N$, then $\alpha \circ f$ is another coordinate map for the same formulas.
This is why Hodges keeps $f$ as a part of the data: the automorphism group of $N$ then acts on the set of interpretations with given formulas.

Example: the [[rational field in the ring of integers|~53eefcc8]] is a $2$-dimensional interpretation without parameters, with a nontrivial $\varepsilon$.

Non-example: the same formulas with domain $\Z^2$ give a formula $\varepsilon$ that is not transitive, so no coordinate map exists; see [[this non-example|~fd8862db]].

## Explanations

### L1 human

To interpret one structure in another, we say three things in the language of the old structure.
We say which lists of old elements are allowed, when two allowed lists name the same new element, and how the operations act on the lists.
The coordinate map then tells which new element each list names.
For fractions, the allowed lists are pairs $(a, b)$ of integers with $b$ not zero, and $(a, b)$ names $a / b$.

### L2 human

We check the equality condition for $\Q$ in $\Z$ on two pairs.

1. Take $\partial(x_1, x_2)$ to be $x_2 \neq 0$ and $\varepsilon(x_1, x_2, y_1, y_2)$ to be $x_1 \cdot y_2 = y_1 \cdot x_2$.
2. Take $f(a, b) = a / b$.
3. For $(2, 6)$ and $(-1, -3)$ we get $2 \cdot (-3) = -6 = (-1) \cdot 6$, so $\varepsilon$ holds.
4. Indeed $f(2, 6) = 1/3 = f(-1, -3)$, as the equality condition asks.

The typical use of the definition is to check each condition for given formulas, one symbol of $L'$ at a time.
A trap is to forget the domain formula: the pair $(1, 0)$ is not in the domain, and without this restriction the equality condition fails.
