## Example

Take the [[Kripke model|NGHWZ9Y7ZV]] $\mathfrak{M}$ with $W = \N$, $R = \set{(n, n + 1) : n \in \N}$ and $V(p) = \set{n : n \text{ even}}$.
Take $\Sigma = \set{p, \square p}$, which is closed under subformulas.
We build two [[filtrations|~9960fa2c]] of $\mathfrak{M}$ through $\Sigma$.

1. $\square p$ is true at $n$ exactly when $n + 1$ is even, that is, when $n$ is odd.
2. So the even numbers make $p$ true and $\square p$ false, and the odd numbers make $p$ false and $\square p$ true.
3. Two worlds are identified when they agree on $\Sigma$, so there are two classes: $E$, the even numbers, and $O$, the odd numbers.
4. The valuation of the quotient is $V^f(p) = \set{E}$, since $p$ is true on $E$ and false on $O$.
5. The smallest filtration has $[w] R^s [v]$ when some $w' \sim w$ and $v' \sim v$ have $w' R v'$. The arrows $n \to n + 1$ give $R^s = \set{(E, O), (O, E)}$.
6. The largest filtration has $[w] R^l [v]$ when, for every $\square\varphi \in \Sigma$, $w \models \square\varphi$ implies $v \models \varphi$. The only such formula is $\square p$.
7. $E$ makes $\square p$ false, so the condition is empty, and $E R^l E$ and $E R^l O$ hold.
8. $O$ makes $\square p$ true, so $O R^l [v]$ needs $p$ at $v$. So $O R^l E$ holds and $O R^l O$ fails.
9. So $R^l = \set{(E, E), (E, O), (O, E)}$.
10. Filtration lemma for $\square p$ in $R^s$: $E$ sees only $O$, where $p$ is false, so $\square p$ is false at $E$. $O$ sees only $E$, so $\square p$ is true at $O$. Both match step 2.
11. Filtration lemma for $\square p$ in $R^l$: $E$ sees $O$, so $\square p$ is false at $E$; $O$ sees only $E$, so $\square p$ is true at $O$. Both match step 2.
12. So the infinite model collapses to 2 worlds, below the bound $2^{|\Sigma|} = 4$.

## Remarks

The example shows that a filtration keeps exactly the information about $\Sigma$, and it can turn an infinite model into a finite one.
The two filtrations differ by the loop $(E, E)$, and both satisfy the [[filtration theorem|~889ee92a]].
The quotient of $\mathfrak{M}$ is not a copy of $\mathfrak{M}$.
In $R^s$, the world $E$ is on a cycle of length 2, while $\N$ has no cycles.
Formulas outside $\Sigma$ can change their truth value: $\square\square p$ is true at $0$ in $\mathfrak{M}$, since $\square p$ is true at $1$.
With $R^l$, the formula $\square\square p$ is false at $E$, since $E R^l E$ and $\square p$ is false at $E$.
If we take $V(p) = \N$, then all worlds agree on $\Sigma$, the quotient has one world, and the smallest filtration has a loop.

## Explanations

### L1 human

Picture the days $0, 1, 2, \dots$, with rain on even days.
We only care about two questions: "does it rain today" and "does it rain tomorrow".
Every even day gives the answers "yes, no", and every odd day gives "no, yes".
So we merge all even days into one day and all odd days into another day.
The result is a picture with two days that take turns, and it answers both questions correctly.

### L2 human

1. Take the world $3$ of $\mathfrak{M}$, which is odd, so $[3] = O$.
2. In $\mathfrak{M}$, $\square p$ is true at $3$, since $4$ is even.
3. In both filtrations, $O$ sees only $E$, where $p$ is true, so $\square p$ is true at $O$.
4. So the truth value of $\square p$ is the same at $3$ and at $[3]$, as the filtration theorem says.

The typical use of filtration is to prove the finite model property: a formula that fails in some model fails in a finite model.
A trap: the filtration theorem holds only for formulas in $\Sigma$, so a check outside $\Sigma$ can fail.
