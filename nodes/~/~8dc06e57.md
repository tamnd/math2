## Example

Let $L' = \set{+, \cdot}$ and $\mathcal{Q} = (\Q, +, \cdot)$.
Let $L = \set{+}$ and $\mathcal{Z} = (\Z, +)$.
We check that $\mathcal{Z}$ is not the [[reduct|~ad0fa7f2]] of $\mathcal{Q}$ to $L$, and that $\mathcal{Q}$ is not an expansion of $\mathcal{Z}$.

1. The reduct $\mathcal{Q} \restriction L$ has the same domain as $\mathcal{Q}$, namely $\Q$.
2. The domain of $\mathcal{Z}$ is $\Z$, and $\Z \ne \Q$, since $1/2 \in \Q \setminus \Z$.
3. So $\mathcal{Z} \ne \mathcal{Q} \restriction L$, and $\mathcal{Z}$ is not a reduct of $\mathcal{Q}$.
4. The reduct of $\mathcal{Q}$ to $L$ is $(\Q, +)$, and $\mathcal{Z}$ is a [[substructure|676H7EGTKJ]] of it.

So $\mathcal{Z}$ is obtained from $\mathcal{Q}$ by two moves: first a reduct (forget $\cdot$), then a substructure (keep only $\Z$).

## Remarks

A second kind of failure concerns definitional expansions.
The structure $(\Z, +, <)$ is an expansion of $(\Z, +)$, but it is not a definitional expansion.

5. The map $\nu(x) = -x$ is an [[automorphism|DSQ17TNW1C]] of $(\Z, +)$: it is a bijection and $-(x + y) = (-x) + (-y)$.
6. An automorphism preserves every relation that is [[definable|CY1TXHF6KQ]] without parameters.
7. $\nu$ does not preserve $<$: $0 < 1$, but $\nu(0) = 0 > -1 = \nu(1)$.
8. So $<$ is not $\emptyset$-definable in $(\Z, +)$, and the expansion adds a genuinely new relation.

With $<$ the set $\N = \set{x : \neg(x < 0)}$ becomes definable, where $0$ is defined by $x + x = x$.
In $(\Z, +)$ the set $\N$ is not $\emptyset$-definable, because $\nu(\N) = \set{0, -1, -2, \dots} \ne \N$.

## Explanations

### L1 human

A reduct keeps every element and forgets some operations.
The fractions with addition and multiplication have the reduct "fractions with addition".
The whole numbers with addition are a smaller part of it, with fewer elements.
So they come from the fractions by forgetting multiplication and then throwing away elements, and that is not a reduct.

### L2 human

We test whether $(2\Z, +)$ is a reduct of $(\Z, +, \cdot)$.

1. A reduct of $(\Z, +, \cdot)$ has domain $\Z$.
2. The domain $2\Z$ does not contain $1$, so it is not $\Z$.
3. So $(2\Z, +)$ is not a reduct; it is a substructure of the reduct $(\Z, +)$.

The typical use of the distinction is in proofs that change the language and the domain in two separate steps.
A trap is to say "the reduct of $\Q$ to the integers", which mixes the two moves.
