## Example

The formula $\bot \to p$, the principle of [[explosion|TTKZGJEEK7]], is not a theorem of [[minimal logic|~2f9e5781]].

1. Take the minimal Kripke model with one world $w$, with $\bot$ true at $w$ and $p$ false at $w$.
2. The set $\set{w}$ is an up-set, so $\bot$ may be true there.
3. $\bot \to p$ is true at $w$ only if every world above $w$ that forces $\bot$ also forces $p$.
4. The world $w$ forces $\bot$ and does not force $p$. So $\bot \to p$ fails at $w$.
5. Each axiom of $\mathsf{ML}$ holds at every world of every minimal Kripke model, and modus ponens preserves this. So $\mathsf{ML} \nvdash \bot \to p$.

## Remarks

The one-world model is a two-valued truth table in which $\bot$ gets the value true.
Every axiom of $\mathsf{ML}$ is a classical tautology for every value of $\bot$, so this table is sound for $\mathsf{ML}$.
If we require $\bot$ to be false at every world, the model becomes an intuitionistic Kripke model, and $\bot \to p$ holds.
So the only difference between $\mathsf{ML}$ and $\mathsf{IPC}$ is whether worlds may force $\bot$.

## Explanations

### L1 human

Treat $\bot$ as an ordinary statement that happens to be true, and let $p$ be false.
Then "if $\bot$ then $p$" is false, like "if it is Monday then it is raining" on a dry Monday.
Minimal logic allows this reading of $\bot$, so it can not prove "if $\bot$ then $p$".

### L2 human

1. Use the truth table of classical logic, with $\bot$ treated as a variable.
2. Axiom 1 with $\varphi = \bot$, $\psi = p$ is $\bot \to (p \to \bot)$. With $\bot = 1$ and $p = 0$, it is $1 \to (0 \to 1) = 1$.
3. The formula $\bot \to p$ with $\bot = 1$ and $p = 0$ is $1 \to 0 = 0$.
4. So the table separates the axioms of $\mathsf{ML}$ from $\bot \to p$.

The typical use of such a table is a quick test for non-theorems of minimal logic.
A trap: the test only shows non-derivability; a formula can pass every two-valued test and still fail in $\mathsf{ML}$, as Peirce's law $((p \to q) \to p) \to p$ does.
