## Example

Let $<$ be a binary relation symbol, and let $\varphi = \forall y \, (x < y)$.
We show that the occurrence of $x$ in $\varphi$ is not a bound occurrence, although it lies inside a quantifier.

1. The only quantifier in $\varphi$ is $\forall y$, and its scope is $x < y$.
2. The occurrence of $x$ lies in this scope.
3. A bound occurrence of $x$ must lie in the scope of a quantifier $\forall x$ or $\exists x$, by item 5 of the [[definition|~e71c5bb3]]. The quantifier $\forall y$ is not on $x$, and $\varphi$ has no other quantifier.
4. So the occurrence of $x$ is free.
5. The recursion agrees: $\operatorname{FV}(x < y) = \set{x, y}$, and $\forall y$ removes $y$ only, so $\operatorname{FV}(\varphi) = \set{x}$.

## Remarks

The occurrence of $y$ in $\varphi$ is bound by $\forall y$, so $\operatorname{BV}(\varphi) = \set{y}$.
Since $x$ is free, $\varphi$ is not a [[sentence|DKFGQTRYZE]].
Its truth depends on the value of $x$: in $(\mathbb{Z}, <)$ it is false for every value of $x$, and in the structure $(\set{0, 1}, \le)$, where the symbol $<$ is read as $\le$, it is true exactly for $x = 0$.
If we add a quantifier, $\exists x \, \forall y \, (x < y)$ is a sentence, and $x$ becomes bound.
This example is also the start of the standard capture example: substituting $y$ for the free $x$ gives $\forall y \, (y < y)$, where the new $y$ is bound by the old quantifier.

## Explanations

### L1 human

The claim "every number $y$ is larger than $x$" is about one unknown number $x$.
The words "every number" cover only the letter $y$.
So the claim cannot be judged until we know $x$.
In the integers it is false for every $x$, because $y = x$ itself is not larger than $x$.

### L2 human

We test the claim in the structure $(\set{0, 1}, \le)$, reading $<$ as $\le$.

1. For $x = 0$: we have $0 \le 0$ and $0 \le 1$, so $\forall y \, (x \le y)$ is true.
2. For $x = 1$: we have $1 \le 0$ false, so $\forall y \, (x \le y)$ is false.
3. So the truth value changes with the value of $x$, which confirms that $x$ is free.

The typical use of this test is a quick check that a formula is not a sentence: find two values of a variable with different truth values.
The trap: the converse fails, because a free variable can have no effect on the truth value, as $x$ in $x = x$.
