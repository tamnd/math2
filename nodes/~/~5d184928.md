## Definition

Let $L$ be a signature.

1. For an $L$-[[structure|983GZBQYT4]] $\mathcal{M}$, the *theory of $\mathcal{M}$* is the set $\operatorname{Th}(\mathcal{M})$ of all $L$-[[sentences|DKFGQTRYZE]] $\sigma$ with $\mathcal{M} \models \sigma$.
2. For a class $K$ of $L$-structures, the *theory of $K$* is $\operatorname{Th}(K) = \set{\sigma : \mathcal{M} \models \sigma \text{ for every } \mathcal{M} \in K}$. If $K$ is empty, $\operatorname{Th}(K)$ is the set of all $L$-sentences.
3. For a set $T$ of $L$-sentences, $\operatorname{Mod}(T)$ is the class of all $L$-structures $\mathcal{M}$ with $\mathcal{M} \models \sigma$ for every $\sigma \in T$, that is, the class of [[models|MVCH6N9SNW]] of $T$.

## Notation

When the signature must be shown, one writes $\operatorname{Th}_L(\mathcal{M})$ and $\operatorname{Mod}_L(T)$.
The class $\operatorname{Mod}(T)$ is a proper class in general, so statements about it are statements about all $L$-structures.

## Remarks

Example: $\operatorname{Th}(\Z, <)$ contains $\forall x \, \exists y \, (x < y)$ and the negation of $\exists x \, \forall y \, \neg(y < x)$.

Non-example: the set of group axioms is not $\operatorname{Th}(\mathcal{G})$ for any group $\mathcal{G}$, because $\operatorname{Th}(\mathcal{G})$ contains $\forall x \, \forall y \, (xy = yx)$ or its negation, and the group axioms prove neither.

For a single structure, $\operatorname{Th}(\set{\mathcal{M}}) = \operatorname{Th}(\mathcal{M})$, and for a class, $\operatorname{Th}(K) = \bigcap_{\mathcal{M} \in K} \operatorname{Th}(\mathcal{M})$.
Both operators reverse inclusion: $K_1 \subseteq K_2$ gives $\operatorname{Th}(K_2) \subseteq \operatorname{Th}(K_1)$, and $T_1 \subseteq T_2$ gives $\operatorname{Mod}(T_2) \subseteq \operatorname{Mod}(T_1)$.

## Explanations

### L1 human

The theory of a structure collects every sentence that is true in it.
The models of a set of sentences are all the structures in which every one of those sentences is true.

### L2 human

We compute $\operatorname{Mod}(T)$ for $T = \set{\forall x \, \forall y \, (x = y)}$ in the empty signature.

1. A structure in the empty signature is a nonempty set $M$.
2. $M \models \forall x \, \forall y \, (x = y)$ exactly when any two elements of $M$ are equal.
3. So $\operatorname{Mod}(T)$ is the class of one-element sets.

A trap is to forget that structures are nonempty; with empty structures allowed, the empty set would also be a model.
