## Example

Let $L_0 = \set{0, 1, +, -, <}$ and $T = \mathrm{Th}(\Z, 0, 1, +, -, <)$, the [[theory|92SWXST1ZM]] of [[Presburger arithmetic|4W0E9G7PPV]] in this signature.
Let $\Delta_2$ consist of the atomic $L_0$-formulas and the formulas $\exists y \, (t = y + y)$, for $L_0$-[[terms|6D3WA7N2W4]] $t$.
We show that $T$ has no elimination relative to $\Delta_2$.

1. A term in one variable $x$ equals $k x + m$ in $\Z$, for some $k, m \in \Z$.
2. An atomic formula in $x$ is equivalent to $k x + m = 0$ or $k x + m < 0$. If $k \neq 0$, its truth value is the same for all $x > \abs{m}$. If $k = 0$, it does not depend on $x$.
3. The formula $\exists y \, (k x + m = y + y)$ holds if and only if $k x + m$ is even. Its truth value depends only on the parity of $x$.
4. Let $\psi(x)$ be a Boolean combination of formulas in $\Delta_2$, and let $N$ exceed all numbers $\abs{m}$ that occur in its atomic formulas. By steps 2 and 3, for $x > N$ the truth of $\psi(x)$ depends only on the parity of $x$. So $\psi(a) \leftrightarrow \psi(a + 2)$ holds for all $a > N$.
5. Let $\varphi(x)$ be $\exists y \, (x = y + y + y)$. Choose a multiple $a = 3 j$ of $3$ with $a > N$. Then $\varphi(a)$ holds and $\varphi(a + 2)$ fails, since $a + 2 \equiv 2 \pmod 3$.
6. So $\varphi$ and $\psi$ differ on $a$ or on $a + 2$, and $\varphi$ is not equivalent in $\Z$, hence not modulo $T$, to any Boolean combination of formulas in $\Delta_2$.

## Remarks

The same argument shows that a set of divisibility formulas $\exists y \, (t = n y)$, for $n$ dividing a fixed $M$, is not enough.
Boolean combinations of them and of atomic formulas define sets that are eventually periodic with period $M$, while the multiples of a prime not dividing $M$ are not.
So the elimination set of [[this example|~2cea7063]] needs divisibility by every $n$.

## Explanations

### L1 human

If one may only ask "is this number even?", together with equations and inequalities, then for large numbers one only learns their parity.
But "is this number a multiple of $3$?" is not determined by parity, so it cannot be expressed this way.

### L2 human

We see step 4 on the formula $\psi(x)$ given by $x > 5 \land \exists y \, (x + 1 = y + y)$.
For $x > 5$ it says that $x$ is odd, so it holds at $7, 9, 11, \dots$, a set with period $2$.
The multiples of $3$, namely $6, 9, 12, \dots$, are not periodic with period $2$, since $6$ is in the set and $8$ is not.
The typical use of this argument is to show that an elimination set must contain enough formulas.
A trap is to forget the constants $m$ in the terms: they only shift the point $N$ after which the pattern is periodic.
