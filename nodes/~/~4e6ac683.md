## Proof

By [[the existence theorem|~d9e684c6]], $A$ is row equivalent to some matrix in [[reduced row echelon form|0NNR68BFRY]].
If $R$ and $S$ are two such matrices, then $R \sim S$, by symmetry and transitivity, see [[the theorem on row equivalence|~e3949f1c]].
So it suffices to prove: if $R \sim S$ are $m \times n$ and in reduced row echelon form, then $R = S$.
We use induction on $n$.

Lemma: deleting the last column of a matrix in reduced row echelon form gives a matrix in reduced row echelon form.

1. A row whose leading entry is in column $n$ has zeros before it. Such a row is the last nonzero row, by the staircase condition.
2. After deleting column $n$, that row becomes zero, and it is still below all other nonzero rows. Zero rows stay zero.
3. The other rows keep their leading entries, with value $1$, in the same columns, and those columns are unchanged. So the three conditions still hold.

Base case $n = 1$.

4. An $m \times 1$ matrix in reduced row echelon form is either $0$ or $e_1$.
5. Every row operation maps the zero matrix to itself. So $R = 0$ if and only if $S = 0$, and hence $R = S$.

Induction step, $n \ge 2$.

6. Let $R'$ and $S'$ be $R$ and $S$ with column $n$ deleted. A row operation acts on each column separately, so the same operations take $R'$ to $S'$.
7. By the lemma, $R'$ and $S'$ are in reduced row echelon form. By the induction hypothesis, $R' = S'$.
8. So $R$ and $S$ can differ only in column $n$. Suppose, for a contradiction, that $R \ne S$.
9. Let $x \in F^n$ with $Rx = 0$. By [[the theorem on row equivalence|~e3949f1c]], part 4, also $Sx = 0$.
10. So $(R - S)x = 0$. The first $n - 1$ columns of $R - S$ are zero, so $(R - S)x = x_n u$, where $u \ne 0$ is column $n$ of $R - S$.
11. Hence $x_n = 0$ for every solution $x$ of $Rx = 0$.
12. If column $n$ of $R$ had no leading entry, $x_n$ would be free. The matrix $[R \mid 0]$ is in reduced form, since a zero column has no leading entry.
13. So by [[the lemma on systems in RREF|~e45eea91]], some solution of $Rx = 0$ has $x_n = 1$.
14. This contradicts step 11. So column $n$ of $R$ contains a leading entry, and by the same argument so does column $n$ of $S$.
15. Let $r$ be the number of nonzero rows of $R' = S'$. Their leading entries lie in rows $1, \dots, r$.
16. The leading entry of column $n$ of $R$ lies in a row that is zero in $R'$, so in a row $i \ge r + 1$. By the zero-row condition, $i = r + 1$.
17. By conditions 2 and 3 of the reduced form, column $n$ of $R$ is the unit vector $e_{r+1}$. In the same way, column $n$ of $S$ is $e_{r+1}$.
18. So column $n$ of $R$ equals column $n$ of $S$, and $R = S$. This contradicts step 8.
19. Hence $R = S$, which proves the theorem.

## Idea

Delete the last column; by induction the rest of the two matrices agree.
If the last columns differ, the null space forces $x_n = 0$, so the last column must be a pivot column in both matrices.
But a pivot column in this position is the same unit vector in both, so the last columns agree after all.

## Variants

A second proof uses the [[row space|069MCGX635]].
Row equivalent matrices have the same row space $W$, and the nonzero rows of a matrix in reduced row echelon form are a basis of $W$.
The pivot columns are the indices $j$ such that some vector of $W$ has its first nonzero entry in position $j$; this set depends only on $W$.
For each pivot column $p_i$, the row of the RREF with its leading $1$ there is the unique vector of $W$ with entry $1$ at $p_i$ and $0$ at the other pivot columns.
So the RREF is determined by $W$, and two row equivalent matrices in RREF are equal.
