## Example

We show that every rule admissible in classical propositional logic $\mathsf{CPC}$ is derivable; see [[admissible rules|~41ee4c18]].
By conjunction of premises, consider a rule $A / B$.

1. Suppose $A / B$ is not derivable, so $A \nvdash_{\mathsf{CPC}} B$.
2. By completeness of $\mathsf{CPC}$, there is a valuation $v$ with $v(A) = 1$ and $v(B) = 0$.
3. Define $\sigma$ by $\sigma p = \top$ if $v(p) = 1$, and $\sigma p = \bot$ if $v(p) = 0$.
4. For every formula $C$, $\sigma C$ has no variables, and its truth value is $v(C)$, by induction on $C$.
5. So $\sigma A$ is a variable-free formula with value $1$, which is a [[tautology|05006AJ7DZ]], and a theorem.
6. Also $\sigma B$ has value $0$, so $\sigma B$ is not a theorem.
7. Hence $A / B$ is not admissible. By contraposition, every admissible rule is derivable.

## Remarks

The argument uses that every truth value has a name in the language, namely $\top$ or $\bot$.
The same argument works for a many-valued logic complete for a single finite matrix whose elements all have names.
For $\mathsf{IPC}$ the argument fails, since $\mathsf{IPC}$ has no finite characteristic matrix.
Classical logic is even hereditarily structurally complete, since it is [[Post complete|R1122T076S]].
Its only proper extension is the inconsistent logic, in which every rule is derivable.

## Explanations

### L1 human

In classical logic, a rule that is not provable has a counterexample row in a truth table.
Replacing each variable by "true" or "false" as in that row turns the premise into a theorem and the conclusion into a false sentence.
So every safe rule of classical logic is already provable.

### L2 human

1. Take the rule $p \vee q / p$.
2. The valuation $p = 0$, $q = 1$ makes the premise true and the conclusion false.
3. The substitution $p \mapsto \bot$, $q \mapsto \top$ gives the theorem $\bot \vee \top$ and the non-theorem $\bot$.

The typical use is as the base case of structural completeness, to contrast with $\mathsf{IPC}$.
A trap: the substitution must send variables to formulas, so the constants $\top$ and $\bot$ are essential.
