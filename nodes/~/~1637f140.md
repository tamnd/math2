## Example

Let $L = \set{R}$ with one binary relation symbol $R$, and let $T_{<}$ be the theory of [[strict linear orders|P33CMYHJW9]]:

- $\forall x \, \neg R(x, x)$ (irreflexivity);
- $\forall x \, \forall y \, \forall z \, (R(x, y) \wedge R(y, z) \to R(x, z))$ (transitivity);
- $\forall x \, \forall y \, (R(x, y) \vee x = y \vee R(y, x))$ (connectedness).

Let $\mathcal{N}$ be the $L$-structure with domain $\N$ and $R^{\mathcal{N}} = \set{(m, n) : m \le n}$.
We show that $\mathcal{N}$ is not a [[model|CWQV9PTCB3]] of $T_{<}$.

1. Take the assignment $x \mapsto 0$.
2. The pair $(0, 0)$ is in $R^{\mathcal{N}}$, because $0 \le 0$. So $R(x, x)$ holds, and $\neg R(x, x)$ fails.
3. By the clause for $\forall$ of [[satisfaction|~cf18e0d7]], the irreflexivity axiom is false in $\mathcal{N}$.
4. A model must make every axiom true, so $\mathcal{N} \not\models T_{<}$.

The other two axioms are true in $\mathcal{N}$: $\le$ is transitive, and any two natural numbers are comparable.
So exactly one axiom fails, and it fails at every element, not only at $0$.

## Remarks

The example shows that the same set $\N$ can carry a model and a non-model of a theory: $(\N, <)$ is a model of $T_{<}$.
The structure $\mathcal{N}$ is a model of the theory of non-strict linear orders, which has reflexivity and antisymmetry in place of irreflexivity.
The repair is to read $R$ as $<$, or to change the theory.

## Explanations

### L1 human

The rules of a strict order say that no number is "before" itself.
If we read "before" as "less than or equal to", then $0$ is before $0$, so the rule breaks.
One broken rule is enough: the structure is not a model of the rules.

### L2 human

We check the transitivity axiom in $\mathcal{N}$, to see that the failure is only at irreflexivity.

1. Let $x \mapsto a$, $y \mapsto b$ and $z \mapsto c$, with $a, b, c \in \N$.
2. If $a \le b$ and $b \le c$, then $a \le c$. So the implication holds when the antecedent holds.
3. If the antecedent fails, the implication holds by the clause for $\to$.

A trap is to read the symbol $R$ as $<$ by habit; the structure fixes its meaning, and here it means $\le$.
