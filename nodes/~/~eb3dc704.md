## Example

Let $L = \set{<} \cup \set{c_n : n \in \N}$ and let $\mathcal{M} = (\Q, <, c_n)_{n \in \N}$ with $c_n = 1 - 1/(n+1)$.
The constants increase, and their least upper bound in $\Q$ is $1$.

1. The theory of a [[dense linear order|2W4S2H4VYA]] without endpoints with constants has [[quantifier elimination|7FDDXV3JK7]]. So the [[type|9V71Q3SD1G]] of $a$ over $\emptyset$ is fixed by the formulas $x < c_n$, $x = c_n$ and $c_n < x$ that $a$ satisfies.
2. Both $1$ and $2$ lie above every $c_n$, so $\operatorname{tp}(1) = \operatorname{tp}(2)$.
3. An [[automorphism|DSQ17TNW1C]] $\sigma$ of $\mathcal{M}$ fixes each $c_n$. If $\sigma(1) = 2$, then $\sigma^{-1}(3/2)$ would be an element below $1$ and above every $c_n$.
4. No rational number lies below $1$ and above every $c_n$, since $c_n$ tends to $1$. So no automorphism maps $1$ to $2$, and the orbits of $\operatorname{Aut}(\mathcal{M})$ are not the [[sets of realizations of types|~3d38bf9d]].
5. The map $f = \set{2 \mapsto 1}$ is a [[partial elementary map|XTNYY0WRQ5]] by step 2.
6. An extension $g$ of $f$ with $3/2$ in its domain would need $g(3/2)$ below $g(2) = 1$ and above every $c_n$, which is impossible by step 4.
7. So $\mathcal{M}$ is not $\aleph_0$-[[homogeneous|~ee122c2b]].

## Remarks

The structure $\mathcal{M}$ is not $\aleph_0$-saturated either: over $\set{1}$ it omits the type of an element above every $c_n$ and below $1$.
In a homogeneous elementary extension, such as a saturated one, this type is realized, and an automorphism maps $1$ to $2$.
The failure of homogeneity is a failure of richness here, while the order $(\Z, <)$ is homogeneous without being rich.

## Explanations

### L1 human

The numbers $1$ and $2$ look the same to the language, since both are above all the named points.
Still, $1$ is the first point above the named points, in the sense that nothing lies between them and $1$, while many points lie between them and $2$.
First-order formulas cannot express this difference, but automorphisms must respect it.

### L2 human

The test for "types are orbits" fails when two tuples of the same type are not exchanged by any automorphism.

1. Find two tuples with the same type, here by quantifier elimination.
2. Find a property that an automorphism preserves and that separates them, here the emptiness of the gap between the constants and the element.

The trap is to assume that the second property is first-order: it involves all the constants at once.
