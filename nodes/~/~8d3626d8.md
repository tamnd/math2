## Example

Let $\varphi = (p \to (q \land \neg r)) \leftrightarrow (\neg p \lor q)$, and let $v$ be the truth assignment with $v(p) = v(q) = v(r) = 1$.
We compute $\bar v(\varphi)$ by the clauses of the [[definition|~1bd7b4b2]], from the variables up to the main connective $\leftrightarrow$.

1. $\bar v(\neg r) = 1 - v(r) = 1 - 1 = 0$.
2. $\bar v(q \land \neg r) = \min(1, 0) = 0$.
3. $\bar v(p \to (q \land \neg r)) = \max(1 - 1, 0) = 0$.
4. $\bar v(\neg p) = 1 - 1 = 0$.
5. $\bar v(\neg p \lor q) = \max(0, 1) = 1$.
6. The two sides of $\leftrightarrow$ have the values $0$ and $1$, which differ, so $\bar v(\varphi) = 0$.

Now let $w$ be the assignment with $w(p) = w(q) = 1$ and $w(r) = 0$.

7. $\bar w(\neg r) = 1$, so $\bar w(q \land \neg r) = \min(1, 1) = 1$ and $\bar w(p \to (q \land \neg r)) = \max(0, 1) = 1$.
8. $\bar w(\neg p \lor q) = \max(0, 1) = 1$, as in step 5.
9. Both sides have the value $1$, so $\bar w(\varphi) = 1$.

## Remarks

The example shows that the computation follows the parse tree from the leaves to the root, one clause at each node.
The assignments $v$ and $w$ differ only at $r$, and $\varphi$ changes its value; so the value of $\varphi$ depends on $r$.
If $u(p) = 0$, then $\bar u(p \to (q \land \neg r)) = 1$ and $\bar u(\neg p \lor q) = 1$, so $\bar u(\varphi) = 1$ for each choice of $u(q)$ and $u(r)$.
So $\varphi$ is satisfiable but not a [[tautology|05006AJ7DZ]].
A valuation of a variable that does not occur in $\varphi$, such as $s$, has no effect on $\bar v(\varphi)$.

## Explanations

### L1 human

We have a formula with three letters, and all three letters are true.
We work from the inside out.
"Not $r$" is false, so "$q$ and not $r$" is false.
"If $p$ then ($q$ and not $r$)" is then false, since $p$ is true.
On the other side, "not $p$ or $q$" is true, since $q$ is true.
The two sides differ, so the "if and only if" is false.

### L2 human

We compute the whole truth table of $\varphi$ in a short way.

1. Write $A = p \to (q \land \neg r)$ and $B = \neg p \lor q$.
2. If $p = 0$, then $A = 1$ and $B = 1$, so $\varphi = 1$; these are $4$ rows.
3. If $p = 1$, then $A = \min(q, 1 - r)$ and $B = q$.
4. In the row $p = 1$, $q = 0$, both $A$ and $B$ are $0$, so $\varphi = 1$; these are $2$ rows.
5. In the row $p = 1$, $q = 1$, we get $A = 1 - r$ and $B = 1$, so $\varphi = 1$ exactly when $r = 0$.
6. So $\varphi$ is false in exactly one of the $8$ rows: $p = q = r = 1$.

The typical use of this computation is to find whether a formula is a tautology or satisfiable.
A trap is to stop at the first true row: one true row shows satisfiable, but a tautology needs all rows.
