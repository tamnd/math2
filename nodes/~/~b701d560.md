## Statement

Let $A$ be a matrix. Then there is exactly one matrix in [[reduced row echelon form|0WF5AQYTW6]] that is [[row equivalent|095DDGZF16]] to $A$.

## Remarks

Existence comes from row reduction. The content of the result is that two different reduced row echelon matrices are never row equivalent to the same matrix. So the reduced row echelon form of $A$ is well defined, and two matrices are row equivalent exactly when they have the same one.
