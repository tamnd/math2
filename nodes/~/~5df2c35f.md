## Definition

A group is a pair $(G, \cdot)$ of a set $G$ and a [[binary operation|0M418FE7BB]] $\cdot \colon G \times G \to G$ that satisfies the three axioms below.
We write $ab$ for $a \cdot b$.

1. Associativity: $(ab)c = a(bc)$ for all $a, b, c \in G$.
2. Identity: there is an element $e \in G$ such that $ea = a$ and $ae = a$ for all $a \in G$.
3. Inverses: for each $a \in G$ there is an element $b \in G$ such that $ab = e$ and $ba = e$.

## Notation

The element $e$ of axiom 2 is the identity element of $G$, and it is also written $1$ or $1_G$.
The element $b$ of axiom 3 is the inverse of $a$, written $a^{-1}$.
These notations are correct because $e$ and $a^{-1}$ are unique, by [[uniqueness of identity and inverses|0D9NDGE9KP]].
In additive notation, for [[abelian groups|082GHNPJ53]], we write $a + b$, $0$ and $-a$.

## Remarks

Closure, the condition that $ab \in G$ for all $a, b \in G$, is a part of the statement that $\cdot$ is a binary operation on $G$.
Some books list closure as a fourth axiom.
Axiom 3 uses the element $e$ of axiom 2, so the order of the axioms matters.
The [[one-sided group axioms|~9235fde3]] give an equivalent definition: an associative operation with a left identity and left inverses defines a group.
The class `Group` of Mathlib uses a definition of this kind: it asks for a two-sided identity and only the left inverse law $a^{-1} a = 1$.
The concept page [[group|G5S1M9]] gives the examples, the non-examples and the first properties.

## Explanations

### L1 human

A group is a set with a way to combine two elements into a third element of the set.
The way of combining must not depend on the grouping of three elements.
One element must change nothing, and each element must have a partner that brings it back to that element.
The whole numbers with addition form a group: $0$ changes nothing, and $-3$ brings $3$ back to $0$.

### L2 human

To show that $(G, \cdot)$ is a group, we check four conditions in order.

1. The operation is a binary operation on $G$: each product $ab$ is defined and lies in $G$.
2. The operation is associative.
3. There is an identity element $e$.
4. Each element has an inverse with respect to this $e$.

For example, let $G = \{1, -1\}$ with multiplication.
The products $1 \cdot 1 = 1$, $1 \cdot (-1) = -1$, $(-1) \cdot 1 = -1$ and $(-1)(-1) = 1$ are in $G$, so step 1 holds.
Multiplication of integers is associative, so step 2 holds.
The element $1$ is an identity, so step 3 holds.
Each element is its own inverse, so step 4 holds, and $G$ is a group.
A trap is to find an identity for each element separately: one element $e$ must work for all elements at the same time.
