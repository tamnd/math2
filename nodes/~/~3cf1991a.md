## Example

Let $\mathsf{Q}$ be [[Robinson arithmetic|TT8MXRTVBM]], with a Hilbert-style proof system whose rule is modus ponens.
Let $\mathrm{Prov}_{\mathsf{Q}}(x) := \exists y \, \mathrm{Prf}_{\mathsf{Q}}(y, x)$ be its [[provability predicate|NB2BCZR40F]].
We show that $\mathsf{Q} \vdash \mathrm{Prov}_{\mathsf{Q}}(\ulcorner 0 + 0 = 0 \urcorner)$.

1. Line 1 is $\forall x \, (x + 0 = x)$. It is axiom 4 of $\mathsf{Q}$.
2. Line 2 is $\forall x \, (x + 0 = x) \to 0 + 0 = 0$. It is a logical axiom, an instance of $\forall x \, \psi(x) \to \psi(t)$ with the closed term $t = 0$.
3. Line 3 is $0 + 0 = 0$. It follows from lines 1 and 2 by modus ponens.
4. Let $p = 2^{a_1} 3^{a_2} 5^{a_3}$, where $a_i$ is the code of line $i$. Then $p$ codes a proof in $\mathsf{Q}$ of $0 + 0 = 0$, by steps 1 to 3.
5. The relation "$p$ codes a proof of the formula with code $x$" is decidable, by [[arithmetization of syntax|~f1d9d517]]. It holds for $p$ and $x = \#(0 + 0 = 0)$.
6. The formula $\mathrm{Prf}_{\mathsf{Q}}$ represents this relation in $\mathsf{Q}$. So $\mathsf{Q} \vdash \mathrm{Prf}_{\mathsf{Q}}(\underline{p}, \ulcorner 0 + 0 = 0 \urcorner)$.
7. By the logical rule from $\psi(t)$ to $\exists y \, \psi(y)$, $\mathsf{Q} \vdash \exists y \, \mathrm{Prf}_{\mathsf{Q}}(y, \ulcorner 0 + 0 = 0 \urcorner)$, which is $\mathrm{Prov}_{\mathsf{Q}}(\ulcorner 0 + 0 = 0 \urcorner)$.

## Remarks

The example is one instance of the first [[derivability condition|~abdd9e6a]]: a proof in $T$ gives a proof in $T$ that $\mathrm{Prov}_T$ holds.
The number $p$ is huge, and the numeral $\underline{p}$ is a term with $p$ symbols $S$, so the proof in step 6 is very long, but it exists.
If the sentence is replaced by $\forall x \, (0 + x = x)$, the method fails: $\mathsf{Q}$ does not prove this sentence, so no $p$ exists, and $\mathrm{Prov}_{\mathsf{Q}}$ of its code is false in $\N$.

## Explanations

### L1 human

The statement "zero plus zero is zero" has a three-line proof from the axioms.
That proof is a finite object, and it has a code number $p$.
Robinson arithmetic can check the claim "$p$ codes a proof of zero plus zero is zero" by calculation.
So Robinson arithmetic proves "there is a proof of zero plus zero is zero".

### L2 human

1. Write the proof: axiom 4, the instance of the axiom at $x = 0$, then modus ponens.
2. Code the three lines and the proof.
3. Representability turns the true statement "$p$ is a proof" into a theorem of $\mathsf{Q}$.
4. The $\exists$ rule removes the explicit number $p$.

The typical use is the first derivability condition in the proofs of the second incompleteness theorem and Löb's theorem.
A trap: the step goes from a real proof to a formal statement, not back; a formal statement $\mathrm{Prov}_T(\ulcorner \varphi \urcorner)$ need not come from a real proof.
