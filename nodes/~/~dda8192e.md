## Example

Let $f \colon \R^2 \to \R^2$ be $f(x) = x + (1, 0)$, that is, $f(x, y) = (x + 1,\ y)$.

1. Every [[linear map|0RJF668P1T]] $T$ satisfies $T(0) = T(0 + 0) = T(0) + T(0)$, so $T(0) = 0$.
2. But $f(0, 0) = (1, 0) \ne (0, 0)$. So $f$ is not linear.
3. The [[linear map of a matrix|009892PZ30]] is linear. So $f$ is not the linear map of any $2 \times 2$ matrix, in any bases.
4. A naive attempt fails: $f(e_1) = (2, 0)$ and $f(e_2) = (1, 1)$ give the matrix $M = \begin{pmatrix} 2 & 1 \\ 0 & 1 \end{pmatrix}$.
5. But $M(1, 1) = (3, 1)$, and $f(1, 1) = (2, 1)$. So $M$ does not compute $f$.

## Remarks

- The map $f$ is affine: $f(x) = Ax + b$ with $A = I$ and $b = (1, 0)$.
- An affine map of $\R^n$ is the restriction of a linear map of $\R^{n+1}$ to the plane $x_{n+1} = 1$. Here the matrix is $\begin{pmatrix} 1 & 0 & 1 \\ 0 & 1 & 0 \\ 0 & 0 & 1 \end{pmatrix}$, in homogeneous coordinates.

## Explanations

### L1 human

A shift of the plane moves the origin, so it is not linear.
No matrix can describe it, because a matrix map always fixes the origin.

### L2 human

The test $f(0) = 0$ excludes every map with a constant term.
Step 5 shows what happens when one builds a matrix from the images of basis vectors anyway: the matrix and the map disagree.
Homogeneous coordinates turn affine maps into linear maps in one more dimension.
