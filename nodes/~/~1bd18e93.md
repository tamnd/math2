## Example

We use the spaces $\mathbf{Bool}$ and $\mathbf{Bool} \mathbin{\&} \mathbf{Bool}$ of the [[flat space example|~4e599afd]].
The *left-sequential and* $F$ from $\mathbf{Bool} \mathbin{\&} \mathbf{Bool}$ to $\mathbf{Bool}$ reads its first argument first.

1. $F(c) = \set{f}$ if $f_1 \in c$.
2. $F(c) = \set{t}$ if $t_1 \in c$ and $t_2 \in c$.
3. $F(c) = \set{f}$ if $t_1 \in c$ and $f_2 \in c$.
4. $F(c) = \emptyset$ in all other cases.

The three cases that give a value exclude each other, since a clique does not contain both $t_1$ and $f_1$.
So $F(c)$ is always a clique of $\mathbf{Bool}$.

The [[trace|~2e816c07]] of $F$ is $\set{(\set{f_1}, f), (\set{t_1, t_2}, t), (\set{t_1, f_2}, f)}$.

1. $(\set{f_1}, f)$ is in the trace: $f \in F(\set{f_1})$ and $F(\emptyset) = \emptyset$.
2. $(\set{t_1, t_2}, t)$ is in the trace: $t \in F(\set{t_1, t_2})$, and $F(\set{t_1}) = F(\set{t_2}) = \emptyset$.
3. $(\set{t_1, f_2}, f)$ is in the trace for the same reason.
4. No other pair is in the trace: each other clique $c$ with $F(c) \neq \emptyset$ contains one of these three sets as a proper subset.

$F$ is stable.

1. For a clique $c$ and a token $\beta \in F(c)$, exactly one set $a$ from the trace with output $\beta$ lies in $c$.
   The two sets for $f$ contain $f_1$ and $t_1$, which no clique contains together.
2. Let $c \cup c'$ be a clique and $\beta \in F(c) \cap F(c')$.
   The set $a$ for $\beta$ in $c$ and the set for $\beta$ in $c'$ lie in the clique $c \cup c'$, so they are equal by step 1.
3. So $a \subseteq c \cap c'$, and $\beta \in F(c \cap c')$.
   The other inclusion holds by monotonicity.

## Remarks

$F$ is not linear, since $\set{t_1, t_2}$ in its trace has two tokens.
This matches the program: to answer "true", it must read both arguments.
The *right-sequential and*, which reads the second argument first, has the trace $\set{(\set{f_2}, f), (\set{t_1, t_2}, t), (\set{f_1, t_2}, f)}$, which is a different stable function.

## Explanations

### L1 human

The program asks the first question first.
If the answer is "false", it stops and says "false".
If the answer is "true", it asks the second question and repeats that answer.
The trace lists these three runs, each with the answers it needed.

### L2 human

We compute $F$ from the trace on the clique $c = \set{t_1, f_2}$.

1. The trace pairs whose first set lies in $c$: only $(\set{t_1, f_2}, f)$, since $f_1 \notin c$ and $t_2 \notin c$.
2. So $F(c) = \set{f}$.
3. On $c' = \set{t_1}$, no first set of the trace lies in $c'$, so $F(c') = \emptyset$.
4. On $c'' = \set{f_1, t_2}$, the pair $(\set{f_1}, f)$ applies, so $F(c'') = \set{f}$ before the second argument matters.

The typical use of the trace is to write a stable function as a clique of the space $!A \multimap B$.
A trap: the trace pairs record minimal inputs, so $(\set{f_1, t_2}, f)$ is not in the trace though $f \in F(\set{f_1, t_2})$.
