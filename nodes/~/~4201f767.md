## Example

Let $p$ be an atom.
The sequent $p \Rightarrow p \wedge p$ is derivable in LJ, so $p \to p \wedge p$ is valid in [[intuitionistic logic|Q11N8X99FK]].
Its linear version $p \vdash p \otimes p$, that is $\vdash p^{\perp}, p \otimes p$, is not derivable in [[linear logic|H408H4WHBA]].
So linear logic does not have [[contraction|~54d8cf2f]] for arbitrary formulas.

1. In LJ, two copies of the axiom $p \Rightarrow p$ give $p \Rightarrow p \wedge p$ by the right rule for $\wedge$, which shares the context.
2. In linear logic, by [[cut elimination|~ac5cd644]] it suffices to show that $\vdash p^{\perp}, p \otimes p$ has no cut-free derivation.
3. The sequent has two formulas but is not an axiom, since $p \otimes p$ is not $p$.
4. The formula $p^{\perp}$ is the dual of an atom, so no rule makes it.
   The last rule must be $\otimes$ on $p \otimes p$.
5. The rule $\otimes$ splits the context $\set{p^{\perp}}$: one premise is $\vdash p^{\perp}, p$, and the other is $\vdash p$.
6. The sequent $\vdash p$ is not derivable: it is not an axiom, and no rule ends in a single atom.
7. So no cut-free derivation exists, and the sequent is not derivable.

## Remarks

A semantic check gives the same result, with the [[phase space|~09c29208]] $M = \mathbb{Z}/2$ (written additively, with unit $0$) and $\bot = \set{0}$.

1. For $X \subseteq M$, $X^{\perp} = \set{m \mid m + x \in \bot \text{ for all } x \in X}$.
   So $\set{1}^{\perp} = \set{1}$ and $\set{1}^{\perp\perp} = \set{1}$, and $\set{1}$ is a fact.
2. Put $p = \set{1}$.
   Then $p \otimes p = (p + p)^{\perp\perp} = \set{0}^{\perp\perp} = \set{0}$, since $\set{0}^{\perp} = \set{0}$.
3. The sequent $p \vdash p \otimes p$ is valid only if $p \subseteq p \otimes p$, that is, $\set{1} \subseteq \set{0}$, which is false.
4. By the soundness of phase semantics, the sequent is not derivable.

The sequent becomes derivable when $p$ is replaced by $!p$; see [[controlled contraction|~a81dbb98]].
With the additive conjunction, $\vdash p^{\perp}, p \mathbin{\&} p$ is derivable, since the rule for $\mathbin{\&}$ shares the context.

## Explanations

### L1 human

In ordinary logic, from "it rains" we get "it rains and it rains".
In linear logic, from one coin we cannot get two coins.
The rules of linear logic do not let us copy a hypothesis, and the proof checks every rule that could make two coins from one.

### L2 human

We compare the two calculi rule by rule.

1. LJ: the right rule for $\wedge$ gives both premises the same context $p$, so $p$ is used twice.
2. Linear logic: the rule for $\otimes$ gives each premise a part of the context, so $p$ goes to one premise only.
3. The other premise must prove $p$ from nothing, which fails.
4. The rule for $\mathbin{\&}$ behaves like the LJ rule, and it proves $p \vdash p \mathbin{\&} p$.

The typical use of this example is to show that intuitionistic conjunction splits into two linear conjunctions.
A trap: the failure is for $\otimes$, not for $\mathbin{\&}$, so "linear logic cannot prove $p \to p \wedge p$" is true only for the tensor reading.
