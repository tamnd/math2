## Example

Let $\Gamma = \set{p \lor q, \; \neg p \lor r, \; \neg q}$.
We find an assignment that satisfies $\Gamma$, and we show that it is the only one on $p$, $q$, $r$.

1. The member $\neg q$ is true only when $v(q) = 0$.
2. With $v(q) = 0$, the member $p \lor q$ is true only when $v(p) = 1$, by the truth table of [[disjunction|0F72FK8EKB]].
3. With $v(p) = 1$, the disjunct $\neg p$ has value 0, so the member $\neg p \lor r$ is true only when $v(r) = 1$.
4. Take $v(p) = 1$, $v(q) = 0$, $v(r) = 1$. Then $\bar v(p \lor q) = 1$, $\bar v(\neg p \lor r) = 0 \lor 1 = 1$, and $\bar v(\neg q) = 1$.
5. So $v$ satisfies $\Gamma$, and $\Gamma$ is satisfiable.
6. Steps 1 to 3 show that every satisfying assignment has these three values, so this assignment is the only one on $p$, $q$, $r$.

## Remarks

Each step above uses a member that has only one literal left that can still be true, and forces that literal.
This is unit propagation, the basic step of the [[DPLL algorithm|K7R9D390SP]].
The three members are clauses, so $\Gamma$ is a formula in [[conjunctive normal form|0B3D4C8YF2]].
If we add the member $\neg r$, the set becomes unsatisfiable, since step 3 forces $v(r) = 1$.
If we remove the member $\neg q$, the set has more satisfying assignments, for example $v(p) = 0$, $v(q) = 1$ with any value of $r$.

## Explanations

### L1 human

Three friends plan a party.
Paul or Quinn must bring food.
If Paul brings food, Rita brings drinks.
Quinn cannot bring food.
Then Paul brings food, and so Rita brings drinks, and every wish is met.

### L2 human

We check the same set with the satisfiability test for consequence.

1. Step 6 of the example shows that every assignment satisfying $\Gamma$ has $v(r) = 1$.
2. So $\Gamma \models r$.
3. By the reduction of consequence to satisfiability, $\Gamma \cup \set{\neg r}$ is unsatisfiable.

The typical use: one satisfying assignment proves satisfiability, and we do not need the full truth table with eight rows.
A trap: proving unsatisfiability needs an argument about all assignments, so one failed guess proves nothing.
