## Example

Consider the underdetermined system
$$x_1 + x_2 = 2, \qquad x_2 + x_3 = 2, \qquad A = \begin{pmatrix} 1 & 1 & 0 \\ 0 & 1 & 1 \end{pmatrix}, \quad b = \begin{pmatrix} 2 \\ 2 \end{pmatrix}.$$
The two rows are independent, so $A$ has rank $2$, and we can use the formula of the [[minimum-norm theorem|~6f828050]].

1. $A A^{\mathsf{T}} = \begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}$, with determinant $3$, so $(A A^{\mathsf{T}})^{-1} = \frac{1}{3} \begin{pmatrix} 2 & -1 \\ -1 & 2 \end{pmatrix}$.
2. $y = (A A^{\mathsf{T}})^{-1} b = \frac{1}{3} (4 - 2, -2 + 4) = (2/3, 2/3)$.
3. $x_0 = A^{\mathsf{T}} y = \frac{2}{3} (1, 1, 0) + \frac{2}{3} (0, 1, 1) = (2/3, 4/3, 2/3)$.
4. Check: $A x_0 = (2/3 + 4/3, 4/3 + 2/3) = (2, 2) = b$.
5. $\norm{x_0}^2 = (4 + 16 + 4)/9 = 8/3$.
6. The [[null space|0PQ2GGY1QV]] of $A$: $x_1 = -x_2$ and $x_3 = -x_2$, so $\operatorname{Nul}(A) = \R (1, -1, 1)$.
7. $x_0 \cdot (1, -1, 1) = (2 - 4 + 2)/3 = 0$. So $x_0$ is orthogonal to the null space, that is, it lies in the [[row space|0EP73HK4C4]].
8. Every solution is $x_0 + t (1, -1, 1)$ with $t \in \R$, and $\norm{x_0 + t (1, -1, 1)}^2 = 8/3 + 3 t^2$.
9. For $t = 4/3$ we get the solution $(2, 0, 2)$, with $\norm{(2, 0, 2)}^2 = 8 = 8/3 + 16/3$. For $t = -2/3$ we get $(0, 2, 0)$, with $\norm{(0, 2, 0)}^2 = 4 = 8/3 + 4/3$.
10. Both are longer than $x_0$, as step 8 predicts.

## Remarks

Setting the free variable to $0$ in row reduction gives $x_3 = 0$ and the solution $(0, 2, 0)$.
This is a valid solution, but it is not the minimum-norm solution: it has a component $-\frac{2}{3} (1, -1, 1)$ in the null space.
For a single equation $x_1 + 2 x_2 + 2 x_3 = 9$, the formula gives $x_0 = \frac{9}{9} (1, 2, 2) = (1, 2, 2)$, with norm $3$.
This is the point of the plane closest to the origin; the solution $(9, 0, 0)$ has norm $9$.

## Explanations

### L1 human

The two equations describe a line of solutions in space.
The minimum-norm solution is the point of this line that is closest to the origin.
Here it is $(2/3, 4/3, 2/3)$.

### L2 human

The method is: solve $A A^{\mathsf{T}} y = b$, then put $x_0 = A^{\mathsf{T}} y$.
The check is that $x_0$ solves the system and is orthogonal to the null space.
The typical use is to choose one solution of an underdetermined system in a way that does not depend on which variable we call free.
The trap is to think that the solution from row reduction with free variables set to $0$ is the shortest one.
