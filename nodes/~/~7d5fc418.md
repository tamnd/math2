## Example

Let $K$ be a [[field|04C5ZBG1WT]], as a structure in the signature $\set{+, \cdot, 0, 1}$.
Let $\varphi(x_1, x_2; y_1, y_2, y_3)$ be the formula $y_1 x_1 + y_2 x_2 = y_3 \wedge \neg (y_1 = 0 \wedge y_2 = 0)$.
For $(a, b) \neq (0, 0)$, the set $X = \varphi(K^2; a, b, c)$ is the line $a x_1 + b x_2 = c$.
We compute its [[canonical parameter|~b9c87290]] and show that it is interdefinable with a real triple.

1. The relation $E_\varphi$. For $(a, b) \neq (0, 0)$, two equations $a x_1 + b x_2 = c$ and $a' x_1 + b' x_2 = c'$ define the same line exactly when $(a', b', c') = \lambda (a, b, c)$ for some $\lambda \neq 0$. All triples with $(a, b) = (0, 0)$ define the empty set, and they form one more class.
2. The code. $\ulcorner X \urcorner$ is the class of $(a, b, c)$ under proportionality.
3. A real code. Define $g(a, b, c) = (0, a / b, c / b)$ if $b \neq 0$, and $g(a, b, c) = (1, 0, c / a)$ if $b = 0$.
4. $g$ is constant on classes. Replacing $(a, b, c)$ by $\lambda (a, b, c)$ does not change $b = 0$ or the quotients $a / b$, $c / b$ and $c / a$.
5. $g$ separates classes. If $b \neq 0$, the line is $x_2 = -(a / b) x_1 + c / b$, which $g$ determines. If $b = 0$, the line is $x_1 = c / a$, which $g$ also determines. The first entry tells the two cases apart.
6. So the $\emptyset$-definable map $g$ induces a bijection from the lines onto a $\emptyset$-definable set of triples, and $\ulcorner X \urcorner$ and $g(a, b, c)$ are interdefinable.

So the imaginary $\ulcorner X \urcorner$ is coded by a real tuple, as elimination of imaginaries predicts for algebraically closed fields.

## Remarks

The example works in every field, because it uses only the division by a nonzero coefficient.
It gives the usual chart of the projective line of directions: the line has slope $-a / b$ when $b \neq 0$, and it is vertical when $b = 0$.

The code depends on the choice of a normal form, and other normal forms give interdefinable codes.
For example, the triple $(a / c, b / c, 1)$ works for lines that do not pass through the origin.

For curves of higher degree the same idea needs more care.
A finite set of points is coded by the coefficients of a polynomial whose roots are the points, and this is the main step of the proof of [[elimination of imaginaries in algebraically closed fields|~f002ea16]].

## Explanations

### L1 human

A straight line in the plane has many equations: $x + 2 y = 3$ and $2 x + 4 y = 6$ give the same line.
To name the line by one list of numbers, we divide by the coefficient of $y$, and get $y = -\tfrac12 x + \tfrac32$.
The pair of numbers $-\tfrac12$ and $\tfrac32$ now names the line, and two lines with the same name are the same line.

### L2 human

We compute the code of the line $X$ given by $3 x_1 + 6 x_2 = 9$ over $\mathbb{Q}$.

1. Here $(a, b, c) = (3, 6, 9)$, and $b \neq 0$.
2. So $g(3, 6, 9) = (0, 3/6, 9/6) = (0, 1/2, 3/2)$.
3. The equation $1 x_1 + 2 x_2 = 3$ defines the same line, and $g(1, 2, 3) = (0, 1/2, 3/2)$ as well.
4. The point $(1, 1)$ is on $X$, since $3 + 6 = 9$, and indeed $1 = -\tfrac12 \cdot 1 + \tfrac32$.

The typical use is to see a family of definable sets as a definable set of elements, here the lines as a set of triples.
A trap is to use the triple $(a / b, 1, c / b)$ for all lines: it is undefined for vertical lines, where $b = 0$.
