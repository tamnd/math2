## Example

Use the lower limit logic CLuN and the abnormalities $A \land \neg A$, as in the [[dynamic proof example|~b12a4bd2]].
Take the premises $\Gamma = \set{p, \neg p \lor q}$.

| line | formula | justification | condition |
|---|---|---|---|
| 1 | $p$ | premise | $\emptyset$ |
| 2 | $\neg p \lor q$ | premise | $\emptyset$ |
| 3 | $q$ | 1, 2, conditional DS | $\set{p \land \neg p}$ |

1. The classical valuation $v(p) = v(q) = 1$, with $v(\neg B) = 1 - v(B)$ for every formula $B$, is a CLuN model of $\Gamma$ in which no abnormality is true.
2. So no Dab-formula is a CLuN consequence of $\Gamma$, and no formula is unreliable.
3. Line 3 is never marked, and $q$ is finally derived.

So the [[adaptive logic|~132437fd]] validates [[disjunctive syllogism|6EFJF9NAYX]] for these premises.

## Remarks

The argument works for every premise set with a classical model: then no Dab-formula follows, nothing is marked, and every conditional classical step stands.
So, for consistent premises, the adaptive logic gives the classical consequences.
This is the upper limit logic applied where it is safe.
If we add the premise $\neg p$, then $p \land \neg p$ follows, and line 3 is marked: the logic is nonmonotonic.

## Explanations

### L1 human

When the facts do not conflict, the adaptive logic reasons like classical logic.
Here "$p$" and "not $p$ or $q$" give $q$.
The step is safe because there is no sign that $p$ is contradictory.

### L2 human

The condition of line 3 is $\set{p \land \neg p}$.
A condition causes trouble only if one of its members appears in a minimal Dab-formula.
A consistent premise set has a model with no abnormalities, so it has no Dab-consequences.
A trap is to confuse "no Dab-formula is derived yet" with "no Dab-formula is derivable"; the second is what matters, and the classical model proves it.
