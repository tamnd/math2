## Example

The formula $p \rightarrow (q \rightarrow p)$ is a classical tautology, but it is not a theorem of the relevance logic $\mathbf{R}$.
We use the [[two-point Routley-Meyer model|~06edf471]], in which every theorem of $\mathbf{R}$ holds at the base point $0$.

1. The model has $W = \set{0, 1}$, $0^* = 1$, $1^* = 0$, and $Rabc$ for all triples except $(0, 0, 1)$.
2. Put $p$ true at $0$ only, and $q$ true at $0$ and $1$.
   Both sets are hereditary, by the [[definition|~212d1096]].
3. $R011$ holds, $q$ is true at $1$, and $p$ is false at $1$.
4. So $q \rightarrow p$ is false at $0$, by the truth condition for $\rightarrow$ with $b = c = 1$.
5. $R000$ holds, $p$ is true at $0$, and $q \rightarrow p$ is false at $0$.
6. So $p \rightarrow (q \rightarrow p)$ is false at $0$, with $b = c = 0$.
7. So $p \rightarrow (q \rightarrow p)$ is not a theorem of $\mathbf{R}$.

## Remarks

The formula passes the variable sharing test, since $p$ occurs on both sides of the main arrow.
So variable sharing alone does not exclude it, and we need a model.
In the natural deduction system of Anderson and Belnap, the proof attempt fails because the hypothesis $q$ is discharged without being used.
The Wikipedia article gives the frame condition "$Rabc$ implies $b \leq c$" for the axiom $A \rightarrow (B \rightarrow A)$, where $a \leq b$ means $R0ab$.
This model breaks that condition: $R101$ holds, but $0 \leq 1$ fails since $R001$ fails.

## Explanations

### L1 human

Classical logic says: if $p$ is true, then "$q$ implies $p$" is true for every $q$.
Relevance logic rejects this, since $q$ plays no part in getting $p$.
A small model with two points shows that $\mathbf{R}$ does not prove it.

### L2 human

We also check that the related formula $p \rightarrow (q \rightarrow q)$ fails, with $p$ true at $0$ and $1$ and $q$ true at $0$ only.

1. $R101$ holds, $q$ is true at $0$, and $q$ is false at $1$.
   So $q \rightarrow q$ is false at $1$.
2. At $0$, the only $b$ with $q$ true is $b = 0$, and $R00c$ forces $c = 0$.
   So $q \rightarrow q$ is true at $0$.
3. $R011$ holds, $p$ is true at $1$, and $q \rightarrow q$ is false at $1$.
4. So $p \rightarrow (q \rightarrow q)$ is false at $0$, and it is not a theorem of $\mathbf{R}$.

The typical use of such a model is to show that a formula is not a theorem, which a failed proof search alone cannot show.
A trap: $q \rightarrow q$ is a theorem of $\mathbf{R}$, so it holds at $0$, but it need not hold at the other point $1$.
