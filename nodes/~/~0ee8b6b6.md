## Proof

In an $\omega$-structure $(\N, \mathcal{S})$, a formula without set quantifiers, with parameters from $\N$ and $\mathcal{S}$, is true exactly when it is true of the actual sets and numbers.
We use this fact (A) throughout.

1. ($\Rightarrow$) Let $(\N, \mathcal{S})$ be a model of $\mathsf{RCA}_0$. Let $X, Y \in \mathcal{S}$.
2. The formula $\exists m \le n\, \big( (n = 2m \wedge m \in X) \vee (n = 2m + 1 \wedge m \in Y) \big)$ is $\Sigma^0_0$. $\Delta^0_1$ comprehension gives a set $Z \in \mathcal{S}$ that it defines.
3. By (A), $Z = X \oplus Y$. So $\mathcal{S}$ is closed under join.
4. Let $Y \le_T X$ with $X \in \mathcal{S}$, by a program $e$ that computes the characteristic function of $Y$ with oracle $X$.
5. Let $\varphi(n)$ say "there is a halting computation of program $e$ with oracle $X$ on input $n$ with output $1$". It is $\Sigma^0_1$, with parameter $X$.
6. Let $\psi(n)$ say "no halting computation of program $e$ with oracle $X$ on input $n$ has output $0$". It is $\Pi^0_1$.
7. The program halts on every input with output $0$ or $1$. So $\varphi(n) \leftrightarrow \psi(n)$ holds for every $n$, and by (A) it holds in $(\N, \mathcal{S})$.
8. $\Delta^0_1$ comprehension gives a set in $\mathcal{S}$ defined by $\varphi$, and by (A) it is $Y$. So $\mathcal{S}$ is closed downward under $\le_T$.
9. So $\mathcal{S}$ is a Turing ideal.
10. ($\Leftarrow$) Let $\mathcal{S}$ be a Turing ideal. The basic axioms hold in $(\N, \mathcal{S})$, since the number part is standard.
11. Induction holds for every formula $\varphi(n)$. If the set $\set{n : (\N, \mathcal{S}) \models \neg\varphi(n)}$ were nonempty, its least element $n_0$ would give a contradiction with $\varphi(0)$ or with $\varphi(n_0 - 1) \to \varphi(n_0)$.
12. Let $\varphi(n)$ be $\Sigma^0_1$ and $\psi(n)$ be $\Pi^0_1$, with set parameters $X_1, \ldots, X_k \in \mathcal{S}$, and assume $\forall n\, (\varphi(n) \leftrightarrow \psi(n))$ in $(\N, \mathcal{S})$.
13. Let $X = X_1 \oplus \cdots \oplus X_k$. By closure under join, $X \in \mathcal{S}$, and each $X_i \le_T X$.
14. By (A), $A = \set{n : \varphi(n)}$ is [[computably enumerable|TN9G24VABN]] relative to $X$. Its complement $\set{n : \neg \psi(n)}$ is also computably enumerable relative to $X$.
15. A set that is computably enumerable relative to $X$ and has a complement computably enumerable relative to $X$ is computable from $X$: run both enumerations until $n$ appears. So $A \le_T X$.
16. By closure downward, $A \in \mathcal{S}$, and $A$ witnesses the instance of $\Delta^0_1$ comprehension.
17. So $(\N, \mathcal{S})$ is a model of $\mathsf{RCA}_0$.

## Idea

Comprehension for $\Delta^0_1$ formulas makes exactly the sets that are computable from finitely many given sets.
In an $\omega$-model, arithmetical formulas mean what they say, so the axioms turn into closure conditions.

## Variants

The same method shows that the $\omega$-models of $\mathsf{ACA}_0$ are the Turing ideals closed under the jump: an arithmetical formula with parameter $X$ defines a set computable from $X^{(n)}$ for some $n$, by Post's theorem.
