## Example

Let $L = \set{P}$ with $P$ a unary relation symbol, and let $\mathcal{M}$ be the $L$-structure with domain $\set{0, 1}$ and $P^{\mathcal{M}} = \set{1}$.
Let $\sigma$ be the conjunction of the two sentences
$$\exists x \, \exists y \, (x \ne y \land \forall z \, (z = x \lor z = y)), \qquad \exists x \, (P(x) \land \forall y \, (P(y) \to y = x)).$$
The first says "there are exactly two elements", the second "exactly one element is in $P$".
We check that $\operatorname{Th}(\mathcal{M})$ is the set of consequences of $\sigma$, so that the [[theory of $\mathcal{M}$|~305c87e7]] is axiomatized by one sentence.

1. $\mathcal{M} \models \sigma$: $0 \ne 1$ are the only elements, and $1$ is the only element of $P$.
2. Let $\mathcal{N} \models \sigma$. Then $\mathcal{N}$ has two elements $a \ne b$, and exactly one of them, say $b$, is in $P^{\mathcal{N}}$.
3. The map $h(0) = a$, $h(1) = b$ is a bijection with $x \in P^{\mathcal{M}} \iff h(x) \in P^{\mathcal{N}}$. So $h$ is an [[isomorphism|PZMGQMDN25]] and $\mathcal{N} \cong \mathcal{M}$.
4. [[Isomorphic structures satisfy the same sentences|NDTJ2E895C]]. So for every sentence $\tau \in \operatorname{Th}(\mathcal{M})$ and every model $\mathcal{N}$ of $\sigma$, we have $\mathcal{N} \models \tau$. That is, $\sigma \models \tau$.
5. Conversely, if $\sigma \models \tau$, then $\mathcal{M} \models \tau$ by step 1, so $\tau \in \operatorname{Th}(\mathcal{M})$.

So $\operatorname{Th}(\mathcal{M}) = \set{\tau : \sigma \models \tau}$.

## Remarks

The same argument works for every finite structure in a finite signature: one sentence describes it up to isomorphism, and its theory is the set of consequences of that sentence.
For a finite structure in an infinite signature, the theory need not be finitely axiomatizable, but it still determines the structure up to isomorphism; see [[the finite case of elementary equivalence|~906b905e]].
The sentence $\sigma$ alone is [[complete|655K8Y7VS8]], since all its models are isomorphic.
If we drop the second conjunct, the theory of two-element sets with a unary relation is not complete: it does not decide $\exists x \, P(x)$.

## Explanations

### L1 human

The structure is two points, one of them painted.
The sentence "there are two points and exactly one is painted" describes it completely: any structure that satisfies it is a copy of the original.
So every true statement about the two points follows from this one sentence.

### L2 human

We check that $\tau = \exists x \, \neg P(x)$ follows from $\sigma$.

1. Let $\mathcal{N} \models \sigma$, with two elements $a \ne b$ and $P^{\mathcal{N}} = \set{b}$.
2. Then $a \notin P^{\mathcal{N}}$, since $b$ is the only element of $P^{\mathcal{N}}$ and $a \ne b$.
3. So $\mathcal{N} \models \neg P(a)$, and $\mathcal{N} \models \tau$.

The typical use of such a sentence is to show that a finite structure is pinned down by first-order logic.
A trap is to expect the same for infinite structures; no set of sentences pins down $(\N, <)$ up to isomorphism.
