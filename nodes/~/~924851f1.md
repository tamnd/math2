## Example

In the *Rényi-Ulam game*, a questioner must find an unknown element $x$ of a finite set $U$ with $n$ elements.
Each question is a subset $Q \subseteq U$, read as "is $x \in Q$?".
The answerer replies yes or no, and at most one answer in the whole game is a lie.
We take $n = 2^m$, and we ask for the least number $q$ of questions that always find $x$.

**The states as Ł3-valued functions.**
After some answers, give each $y \in U$ the value $1$ if $y$ is consistent with all answers, $\tfrac12$ if it is inconsistent with exactly one, and $0$ otherwise.
This is a map $\sigma \colon U \to \set{0, \tfrac12, 1}$, and at the start $\sigma(y) = 1$ for all $y$.

1. An answer to $Q$ defines $a \colon U \to \set{\tfrac12, 1}$: $a(y) = 1$ if $y$ agrees with the answer, and $a(y) = \tfrac12$ if not.
2. The new state is $\sigma \odot a$, computed at each $y$ with the [[Łukasiewicz conjunction|~09f1e8d9]] $u \odot v = \max(0, u + v - 1)$.
3. Check: $1 \odot 1 = 1$, $1 \odot \tfrac12 = \tfrac12$, $\tfrac12 \odot 1 = \tfrac12$ and $\tfrac12 \odot \tfrac12 = 0$. So $\odot$ adds one inconsistency, and two inconsistencies give $0$.
4. The secret $x$ never reaches $0$, because at most one answer is a lie.
5. So the questioner has found $x$ exactly when one element has a value above $0$.

**The volume bound.**
With $r$ questions still to ask, give the state the weight
$$W_r(\sigma) = (r + 1) \cdot \#\set{y : \sigma(y) = 1} + \#\set{y : \sigma(y) = \tfrac12}.$$

6. Let the state be $\sigma$, and ask any $Q$. Let $\sigma_{\mathrm{yes}}$ and $\sigma_{\mathrm{no}}$ be the two next states.
7. An element $y$ with $\sigma(y) = 1$ keeps value $1$ under one answer and gets $\tfrac12$ under the other. It adds $r + 1$ to $W_{r-1}(\sigma_{\mathrm{yes}}) + W_{r-1}(\sigma_{\mathrm{no}})$, the same as to $W_r(\sigma)$.
8. An element with $\sigma(y) = \tfrac12$ keeps $\tfrac12$ under one answer and gets $0$ under the other. It adds $1 + 0 = 1$ to both sides.
9. So $W_{r-1}(\sigma_{\mathrm{yes}}) + W_{r-1}(\sigma_{\mathrm{no}}) = W_r(\sigma)$ for every question.
10. Let the answerer always give the answer with the larger next weight. Then the weight at least halves at each step.
11. The answerer commits to no $x$ in advance. At the end, any $y$ with value above $0$ is a legal secret, since its answers contain at most one lie.
12. After $q$ questions the weight is at least $W_q(\text{start}) / 2^q = n (q + 1) / 2^q$.
13. With $r = 0$ the weight is the number of elements with value above $0$. If $n (q + 1) > 2^q$, at least $2$ remain, and the questioner can not name $x$.
14. So every winning strategy has $2^q \ge 2^m (q + 1)$.

For $m = 2$ the bound gives $q \ge 5$: $q = 4$ fails, since $2^4 = 16 < 4 \cdot 5 = 20$, and $q = 5$ passes, since $32 \ge 24$.

**A strategy with five questions for four elements.**
Let $U = \set{1, 2, 3, 4}$, and give the elements the code words $00000$, $11100$, $00111$ and $11011$.
Question $i$ asks whether bit $i$ of the code word of $x$ is $1$.
So the questions are $Q_1 = Q_2 = \set{2, 4}$, $Q_3 = \set{2, 3}$ and $Q_4 = Q_5 = \set{3, 4}$, and they are fixed in advance.

15. The [[Hamming distances|EP5HNGSXFA]] between the code words are $3, 3, 4, 4, 3, 3$, so any two code words differ in at least $3$ places.
16. The answers of $x$ form its code word with at most one bit changed.
17. That word differs from the code word of $x$ in at most $1$ place, and from each other code word in at least $3 - 1 = 2$ places.
18. So in the final state only $x$ has a value above $0$, and the questioner finds $x$.

A run: the secret is $x = 3$, and the answer to $Q_2$ is a lie.
The answers are no, yes, yes, yes, yes.
The states $(\sigma(1), \sigma(2), \sigma(3), \sigma(4))$ after each answer are $(1, \tfrac12, 1, \tfrac12)$, $(\tfrac12, \tfrac12, \tfrac12, \tfrac12)$, $(0, \tfrac12, \tfrac12, 0)$, $(0, 0, \tfrac12, 0)$ and $(0, 0, \tfrac12, 0)$.
Only element $3$ remains, with value $\tfrac12$, which records the one lie.
A short Python computation checked all $4 \cdot 6 = 24$ cases of a secret and a lie position, including no lie.

## Remarks

The example shows that the bookkeeping of a game with one lie is the arithmetic of [[Łukasiewicz three-valued logic|~d7a9d81e]].
With up to $e$ lies, the same bookkeeping uses the values $0, \tfrac{1}{e+1}, \dots, 1$, and the step $\tfrac{e}{e+1}$ replaces $\tfrac12$.
These values form a finite subalgebra of [[infinite-valued Łukasiewicz logic|~3e406741]].

The bound changes with $m$.
For $m = 1$ it gives $q \ge 3$, and three equal questions with a majority vote reach it.
For $m = 3$ it gives $q \ge 6$, and for $m = 20$, about one million elements, it gives $q \ge 25$.
The bound is only a lower bound, and this example does not show that it is reached for every $m$.

For strategies fixed in advance, the bound is the [[Hamming bound|RZEGDKR7C7]] for [[codes|TAE6K8NQ46]] that correct one error.
Adaptive questions can use earlier answers, but by step 14 they can not beat the same count.

Wikipedia states that Rényi introduced the game in 1961 and that Ulam found it again, with one million objects and one lie.

## Explanations

### L1 human

One player thinks of a number from 1 to 4, and the other asks yes or no questions.
The first player may lie once.
Four questions are not enough.
There are 4 numbers, and 5 cases for the lie: no lie, or a lie in one of the 4 answers.
That makes 20 cases, but 4 answers give only 16 patterns.
Five questions are enough, with the questions of the example.
The game is a model of error-correcting codes, where a lie is a bit that noise changed.

### L2 human

1. Write the state as a list of values in $\set{0, \tfrac12, 1}$, one for each candidate.
2. After each answer, lower each inconsistent candidate by $\tfrac12$, and stop at $0$.
3. Compute the weight $W_r$ with $r$ questions left, and check that the two possible answers split it into two parts with the sum $W_r$.
4. A good question splits the weight as evenly as possible.

For eight elements and six questions, the start weight is $8 \cdot 7 = 56 \le 64 = 2^6$, so the bound allows six questions.
A trap: the weight bound is necessary but it is not a proof that a strategy exists.
Each case needs a strategy, as in the five-question example above.
