## Example

Let $T = \mathrm{PA} + \neg\operatorname{Con}(\mathrm{PA})$, where $\operatorname{Con}(\mathrm{PA})$ is the [[consistency|VM8TQ70CVJ]] sentence built from the [[provability predicate|NB2BCZR40F]].
Let $\operatorname{Prf}(z, y)$ be the primitive recursive relation "$z$ codes a PA-proof of the formula with code $y$".
Let $B(x)$ be $\exists z \le x \, \operatorname{Prf}(z, \ulcorner 0 = 1 \urcorner)$, a [[primitive recursive relation|QQQRJA90EP]].
Define $x \triangleleft y$ by

$$(\neg B(x) \wedge \neg B(y) \wedge y < x) \vee (B(x) \wedge B(y) \wedge x < y) \vee (\neg B(x) \wedge B(y)).$$

1. $T$ is consistent. If it were not, PA would prove $\operatorname{Con}(\mathrm{PA})$, which [[Gödel's second incompleteness theorem|4PZM5GJTR5]] rules out.
2. $\triangleleft$ is primitive recursive, since $B$ and $<$ are.
3. In $\N$, PA is consistent, so $B(x)$ is false for every $x$. Then $x \triangleleft y$ holds exactly when $y < x$.
4. So $0, 1, 2, \ldots$ is an infinite descending sequence: $n + 1 \triangleleft n$ for every $n$. The order $\triangleleft$ is not well-founded.
5. Inside $T$, let $p$ be the least $z$ with $\operatorname{Prf}(z, \ulcorner 0 = 1 \urcorner)$; it exists by $\neg\operatorname{Con}(\mathrm{PA})$ and the least number principle. Then $B(x)$ holds exactly when $x \ge p$.
6. So inside $T$ the order lists $p - 1, p - 2, \ldots, 0$ first and then $p, p + 1, p + 2, \ldots$ in the usual order. Its order type is $p + \omega$.
7. $T$ proves $\operatorname{TI}(\triangleleft, X)$. Assume $X$ is progressive, and use induction on $k \le p$ to show $X(x)$ for $p - k \le x < p$. The elements below $p - k - 1$ are exactly the numbers from $p - k$ to $p - 1$.
8. Then strong induction on $x \ge p$ shows $X(x)$, since below $x$ lie the numbers less than $p$ and the numbers from $p$ to $x - 1$.
9. So $T$ proves transfinite induction along $\triangleleft$, but $\triangleleft$ is not a well-order.

## Remarks

The example shows why the definition of the [[proof-theoretic ordinal|C19Z3B6V4P]] takes the supremum only over true well-orders, and why the bound $\abs{T} < \omega_1^{\mathrm{CK}}$ assumes $\Pi^1_1$-soundness.
$T$ proves the false $\Sigma_1$ sentence $\neg\operatorname{Con}(\mathrm{PA})$, so it is not even $\Sigma_1$-sound.
The order is [[the artificial notation system|~ca1a6d69]] turned around.
There, PA cannot prove induction along a true well-order of type $\omega$.
Here, $T$ proves induction along an order that is not well-founded.

## Explanations

### L1 human

A theory can be free of contradictions and still believe false things.
The theory here believes that arithmetic is inconsistent, which is false.
We build an ordering of the numbers that looks well-behaved if arithmetic is inconsistent, but in fact runs downward forever.
The theory proves that induction works along this ordering, so its trust in an ordering says nothing about the ordering unless the theory is sound.

### L2 human

We test the order on the first few numbers.

1. In the standard model $\N$, no $x$ codes a proof of $0 = 1$, so $B$ is always false.
2. Then $3 \triangleleft 2 \triangleleft 1 \triangleleft 0$, and the list continues downward without end.
3. Inside $T$, suppose the least proof of $0 = 1$ had code $p = 3$.
4. Then the order is $2, 1, 0, 3, 4, 5, \ldots$, a well-order of type $3 + \omega = \omega$.

The typical use is to explain the soundness hypothesis in results about proof-theoretic ordinals.
The trap: the consistency of $T$ is not enough; the theory must also prove only true $\Pi^1_1$ sentences.
