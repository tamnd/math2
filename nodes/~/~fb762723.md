## Example

Let $T_0$ be the [[theory of infinite sets|KFWXHKBHYT]] in the empty language; it is [[complete|N0T7CAMYQ1]].
Let $\mathcal{D}$ be a regular ultrafilter on an infinite cardinal $\lambda$, witnessed by sets $X_\alpha \in \mathcal{D}$, $\alpha < \lambda$, and let $M$ be an infinite set.
We show that $N = M^\lambda / \mathcal{D}$ is $\lambda^+$-saturated, so $\mathcal{D}$ saturates $T_0$.

1. Let $A \subseteq N$ with $\abs{A} \le \lambda$, and list $A$ as $[f_\alpha]$, $\alpha < \lambda$, with repetitions if needed.
2. A complete $1$-type over $A$ in the empty language says, for each $a \in A$, whether $x = a$. If it contains $x = a$, then $a$ realizes it.
3. Otherwise the type is $\set{x \neq a : a \in A}$, and we need an element of $N$ outside $A$.
4. For $i \in \lambda$ the set $s(i) = \set{\alpha : i \in X_\alpha}$ is finite. Since $M$ is infinite, choose $g(i) \in M$ different from $f_\alpha(i)$ for all $\alpha \in s(i)$.
5. For each $\alpha$, the set $\set{i : g(i) \neq f_\alpha(i)}$ contains $X_\alpha \in \mathcal{D}$. So $[g] \neq [f_\alpha]$.
6. Hence $[g] \notin A$ realizes the type, and $N$ is $\lambda^+$-saturated.

Since every regular ultrafilter saturates $T_0$, the implication in the definition holds for every $T_2$, and $T_0 \trianglelefteq T_2$.
So $T_0$ lies in the minimum class of [[Keisler's order|~889bca65]].

## Remarks

Step 2 uses that in the empty language a formula in one variable over $A$ is a Boolean combination of equations $x = a$; this follows from quantifier elimination for $T_0$.
Steps 4 and 5 are a diagonal argument, and regularity is exactly what makes $s(i)$ finite.
The argument shows more: $\abs{N} > \lambda$, so a regular ultrapower of an infinite set is larger than its index set.
For a countably incomplete ultrafilter that is not regular, step 4 can fail, since some index may lie in infinitely many $X_\alpha$.

## Explanations

### L1 human

In a set with no structure, a gap is only a request for a new element, different from a given list.
A regular ultrafilter always provides a new element: at each index only finitely many entries of the list must be avoided.
So the theory of infinite sets is the easiest theory to saturate.

### L2 human

We run steps 4 and 5 for $\lambda = \aleph_0$, $M = \N$, and $X_n = \set{i : i \ge n}$, so $s(i) = \set{0, 1, \dots, i}$.

1. Let $f_n$ be the constant function with value $n$, so $A$ is the set of standard elements.
2. Step 4 asks for $g(i) \notin \set{0, 1, \dots, i}$, so take $g(i) = i + 1$.
3. For each $n$, $g(i) \neq n$ for all $i \ge n$, so $[g] \neq [f_n]$.

The typical use is as the base case: a theory is compared with $T_0$ first.
The trap is to forget regularity in step 4, where the finiteness of $s(i)$ is used.
