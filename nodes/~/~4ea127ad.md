## Example

Let $\sigma = \set{+, \cdot, -, 0, 1, <}$ be the signature of [[ordered fields|0P3VCBDEE2]].
The least upper bound property of an ordered field $F$ says: every nonempty subset of $F$ that is bounded above has a [[supremum|0R3H5PANRQ]] in $F$.
We show that this property is not first-order in two senses.

1. Its natural form begins with "for every subset $A$ of $F$". This quantifier ranges over subsets of the domain, not over elements, so it is a quantifier of [[second-order logic|G6X7SZSNC5]].
2. A first-order formula of $\sigma$ can only quantify over elements. So the natural form is not a first-order sentence.
3. A stronger claim holds: no set $\Sigma$ of first-order $\sigma$-sentences has as its models exactly the ordered fields with the least upper bound property.
4. Suppose, for a contradiction, that such a set $\Sigma$ exists.
5. Every ordered field with the least upper bound property is isomorphic to $\mathbb{R}$. So the models of $\Sigma$ are exactly the ordered fields isomorphic to $\mathbb{R}$.
6. The signature $\sigma$ is finite, so there are only [[countably many|01TQB88H4C]] $\sigma$-sentences, and $\Sigma$ is countable.
7. The set $\Sigma$ has the infinite model $\mathbb{R}$. By the downward [[Löwenheim-Skolem theorem|484M0TZ1S7]], $\Sigma$ has a countable model $\mathcal{M}$.
8. By step 5, $\mathcal{M}$ is isomorphic to $\mathbb{R}$. But $\mathbb{R}$ is uncountable, and an isomorphism is a bijection. This is a contradiction.

So the least upper bound property is not expressible by any set of first-order sentences in the language of ordered fields.

## Remarks

The second-order sentence is
$$\forall A \, \big( (\exists x \, A(x) \land \exists b \, \forall x \, (A(x) \to x \le b)) \to \exists s \, \forall c \, (\forall x \, (A(x) \to x \le c) \leftrightarrow s \le c) \big),$$
where $A$ is a variable for unary relations, and $u \le w$ abbreviates $u < w \lor u = w$.
The proof above uses only that $\sigma$ is countable and that $\mathbb{R}$ is uncountable.
The same argument shows that no first-order theory in a countable signature characterizes any uncountable structure up to isomorphism.
In set theory the property becomes first-order again, because subsets of $\mathbb{R}$ are elements of the universe of sets.
That move changes the domain: the variables then range over all sets, not over real numbers.

## Explanations

### L1 human

The least upper bound property says that every bounded set of real numbers has a smallest upper bound.
It talks about all sets of numbers, not only about numbers.
First-order logic can say "for every number" but not "for every set of numbers".
So the property cannot be written as a first-order sentence about numbers.
For example, the set of fractions $x$ with $x^2 < 2$ has no smallest upper bound among the fractions, but it has one among the real numbers, namely $\sqrt{2}$.

### L2 human

We see why the natural first-order attempt fails.

1. The attempt replaces "every subset" by "every subset defined by a formula": for each formula $\varphi(x)$, one axiom says that if $\varphi$ defines a nonempty set bounded above, then that set has a supremum.
2. These infinitely many axioms are first-order, one for each $\varphi$.
3. They hold in $\mathbb{R}$, because every subset of $\mathbb{R}$, defined or not, has the property.
4. By steps 6 and 7 of the example, they also hold in some countable ordered field, which is not isomorphic to $\mathbb{R}$.
5. A concrete such field is the field $\mathbb{R}_{\mathrm{alg}}$ of real algebraic numbers. By Tarski's theorem, it satisfies the same first-order sentences as $\mathbb{R}$, and it is countable.

The typical use of this example is as a warning: a first-order axiom schema is weaker than one second-order axiom.
A trap is to think that the schema "for every formula" is the same as "for every subset": a countable language has countably many formulas, but $\mathbb{R}$ has uncountably many subsets.
