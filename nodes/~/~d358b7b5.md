## Example

The $2 \times 2$ [[matrix units|~2c685e2c]] are $E_{11} = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}$, $E_{12} = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}$, $E_{21} = \begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix}$ and $E_{22} = \begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix}$.

1. $E_{12} E_{21} = \begin{pmatrix} 0 \cdot 0 + 1 \cdot 1 & 0 \cdot 0 + 1 \cdot 0 \\ 0 \cdot 0 + 0 \cdot 1 & 0 \cdot 0 + 0 \cdot 0 \end{pmatrix} = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix} = E_{11}$. The rule gives $\delta_{22} E_{11} = E_{11}$.
2. $E_{21} E_{12} = \begin{pmatrix} 0 \cdot 0 + 0 \cdot 0 & 0 \cdot 1 + 0 \cdot 0 \\ 1 \cdot 0 + 0 \cdot 0 & 1 \cdot 1 + 0 \cdot 0 \end{pmatrix} = \begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix} = E_{22}$. The rule gives $\delta_{11} E_{22} = E_{22}$.
3. $E_{12} E_{12} = \begin{pmatrix} 0 \cdot 0 + 1 \cdot 0 & 0 \cdot 1 + 1 \cdot 0 \\ 0 & 0 \end{pmatrix} = 0$. The rule gives $\delta_{21} E_{12} = 0$.
4. $E_{11} E_{12} = \begin{pmatrix} 1 \cdot 0 + 0 \cdot 0 & 1 \cdot 1 + 0 \cdot 0 \\ 0 & 0 \end{pmatrix} = E_{12}$. The rule gives $\delta_{11} E_{12} = E_{12}$.
5. $E_{12} E_{11} = \begin{pmatrix} 0 \cdot 1 + 1 \cdot 0 & 0 \cdot 0 + 1 \cdot 0 \\ 0 & 0 \end{pmatrix} = 0$. The rule gives $\delta_{21} E_{11} = 0$.

## Remarks

The [[product rule|~eda9ba19]] gives all $16$ products of two $2 \times 2$ matrix units without computation.
Steps 1 and 2 show that $E_{12}$ and $E_{21}$ do not commute.
Steps 4 and 5 show that $E_{11}$ and $E_{12}$ do not commute.

## Explanations

### L1 human

Two matrix units multiply to a matrix unit when the inner indices match, and to zero otherwise.

### L2 human

Step 3 shows a nonzero matrix with square zero.
Steps 1 and 2 show that $E_{12} E_{21} - E_{21} E_{12} = E_{11} - E_{22}$, which has trace $0$, as every commutator does.
