## Example

Add two constants $a$ and $b$ to the language of [[quantified modal logic|D2H3S12V7X]], and let a constant be interpreted world by world.
So a structure gives each constant $c$ and each world $u$ an object $c^u$.
Let:

- $W = \{w, v\}$ and $R = W \times W$;
- $D(w) = D(v) = \{1, 2\}$;
- $a^w = a^v = 1$, so $a$ denotes the same object at both worlds;
- $b^w = 1$ and $b^v = 2$, so $b$ denotes different objects at the two worlds.

We check that $a = b \to \square (a = b)$ fails at $w$.

1. At $w$: $a^w = 1$ and $b^w = 1$, so $w \models a = b$.
2. At $v$: $a^v = 1$ and $b^v = 2$, so $v \not\models a = b$.
3. Since $w R v$, step 2 gives $w \not\models \square (a = b)$.
4. By steps 1 and 3, the antecedent is true and the consequent is false at $w$, so the implication fails at $w$.

We check which condition of the semantics fails.

5. The semantics of the main page has no world-dependent terms: the only terms are variables, and their values do not depend on the world.
6. The constant $b$ has two values, $1$ at $w$ and $2$ at $v$. So $b$ is not rigid, and the structure is not a model of the kind that the main page defines.

## Remarks

The example shows that rigidity is exactly what the proof of [[the necessity of identity|~2aa4fdf6]] uses.
In that proof, the step "the assignment is the same at $v$ as at $w$" fails for $b$.
A name that denotes the same object at every world is a [[rigid designator|HGR6C3KA34]].
If we change $b^v$ to $1$, then $b$ becomes rigid, and the implication holds at both worlds.
Definite descriptions such as "the number of planets" behave like $b$: they can pick out different objects at different worlds.

## Explanations

### L1 human

The phrase "the winner of the race" names a person, but which person depends on how the race went.
In our world it names Ana, and in another possible world it names Ben.
So "Ana is the winner" is true here, but it is not necessary.
A proper name like "Ana" names Ana in every world, and that is why identities between proper names are necessary.

### L2 human

We check that the necessity of identity holds for the rigid constant $a$ and a variable $x$.

1. Let $\sigma(x) = 1$. At $w$, $a^w = 1 = \sigma(x)$, so $w \models_\sigma a = x$.
2. At $v$, $a^v = 1 = \sigma(x)$, so $v \models_\sigma a = x$.
3. At $w$ itself the identity also holds, so $w \models_\sigma \square (a = x)$ because $w$ sees only $w$ and $v$.
4. So $a = x \to \square (a = x)$ holds at $w$ under $\sigma$.

The typical use of the non-rigid structure is to model descriptions and contingent identities.
A trap: the failure comes from the term $b$, not from the logic $\mathsf{S5}$ of the frame.
