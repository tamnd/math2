## Summary

A proposition is a statement that is either true or false.
In classical logic, each proposition has exactly one of the two truth values, true or false.
For example, "$2 + 2 = 4$" is a true proposition, and "$7$ is even" is a false proposition.
A question or a command is not a proposition, because it has no truth value.

## Remarks

Letters such as $p$, $q$ and $r$ usually denote propositions.
An open sentence such as "$x > 3$" is not a proposition until $x$ has a value. It is a [[predicate|~6043077c]].
The connectives [[negation|~01664468]], [[conjunction|~5a3dd005]] and [[disjunction|~4f3617aa]] make new propositions from given propositions.

## Explanations

### L1 human

A proposition is a sentence that you can mark with "true" or "false".
"It rains in Paris now" is a proposition, because it is true or false at a given time.
"Close the door" is not a proposition, because it is neither true nor false.
