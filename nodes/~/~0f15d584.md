## Statement

Let $a < b$ and let $f \colon [a, b] \to \mathbb{R}$ be bounded.
Then $f$ is [[Riemann integrable|~29258b78]] if and only if the set of points where $f$ is not [[continuous|~61d30733]] has Lebesgue measure zero.

## Remarks

A set $E \subseteq \mathbb{R}$ has measure zero if for each $\varepsilon > 0$ it is covered by countably many open intervals of total length less than $\varepsilon$.
Countable sets have measure zero. So [[Thomae's function|~a0dd379a]] is integrable, and so is each monotone function.
The [[Dirichlet function|~0b7f418d]] is discontinuous everywhere, so it is not integrable.
Giuseppe Vitali and Henri Lebesgue proved the criterion independently, in 1907.

## Explanations

### L1 human

A bounded function is Riemann integrable exactly when it is continuous at almost all points.
The bad points must form a set of total length zero.
