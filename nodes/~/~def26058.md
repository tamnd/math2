## Definition

We work in the language of [[second-order arithmetic|DC60FYCSPM]].
Let $2^{<\N}$ be the set of finite binary strings, coded by natural numbers, and write $\abs{\sigma}$ for the length of $\sigma$ and $\tau \preceq \sigma$ when $\tau$ is an initial segment of $\sigma$.

1. A *tree* is a set $T \subseteq 2^{<\N}$ such that $\sigma \in T$ and $\tau \preceq \sigma$ imply $\tau \in T$.
2. For a tree $T$ and $n \in \N$, let $T_n = \set{\sigma \in T : \abs{\sigma} = n}$. This is a finite set, and $\mathsf{RCA}_0$ proves that its number of elements $\abs{T_n}$ exists.
3. A tree $T$ has *positive measure* if there is a rational number $q > 0$ such that $\abs{T_n} / 2^n \ge q$ for all $n$.
4. A *path* of $T$ is a function $f : \N \to \set{0, 1}$ such that the string $f \upharpoonright n = \langle f(0), \dots, f(n-1) \rangle$ is in $T$ for every $n$.
5. *Weak weak König's lemma*, $\mathsf{WWKL}$, is the sentence: every tree of positive measure has a path.
6. $\mathsf{WWKL}_0$ is the system $\mathsf{RCA}_0 + \mathsf{WWKL}$. Its axioms are the basic axioms of arithmetic, the induction axiom for $\Sigma^0_1$ formulas, the comprehension axiom for $\Delta^0_1$ formulas, and $\mathsf{WWKL}$.

## Notation

The name "weak weak König's lemma" and the abbreviation $\mathsf{WWKL}$ go back to Yu and Simpson (1990).
Some texts call a tree of positive measure a *fat* tree.
The subscript $0$ in $\mathsf{WWKL}_0$ means, as for [[RCA0|~58b63877]], that induction is restricted to $\Sigma^0_1$ formulas.
In an $\omega$-model $(\N, \mathcal{S})$ with $\mathcal{S} \subseteq \mathcal{P}(\N)$, a tree of positive measure is a tree $T \in \mathcal{S}$ whose set of paths has positive Lebesgue measure in [[Cantor space|W9VYJRBF9N]].

## Remarks

### Why the rational bound

Each string of $T_{n+1}$ has its initial segment of length $n$ in $T_n$, and each string of $T_n$ has at most two extensions of length $n + 1$.
So $\abs{T_{n+1}} \le 2 \abs{T_n}$, and the ratio $\abs{T_n} / 2^n$ is non-increasing in $n$.
Its limit is the measure of the set of paths of $T$.
$\mathsf{RCA}_0$ does not prove that this limit exists as a real number, because the limit of a computable non-increasing sequence of rationals can be a non-computable real.
The rational bound $q$ in clause 3 states "the limit is positive" without using the limit.
Because the ratio is non-increasing, it is enough to ask $\abs{T_n} / 2^n \ge q$ for infinitely many $n$.

### Place among the subsystems

A tree of positive measure has $\abs{T_n} \ge q 2^n > 0$ for every $n$, so it is infinite.
So [[weak König's lemma|~e7c6fa0e]] gives it a path, and $\mathsf{WKL}_0$ proves $\mathsf{WWKL}$.
Yu and Simpson showed that $\mathsf{WWKL}_0$ is strictly weaker than $\mathsf{WKL}_0$.
$\mathsf{RCA}_0$ does not prove $\mathsf{WWKL}$, as the [[computable tree with no computable path|~fd0e454c]] shows.
The concept page [[weak weak König's lemma|~7de8ca26]] gives the equivalents in measure theory and the link with randomness.

## Explanations

### L1 human

A binary tree is a family of finite strings of $0$ and $1$, closed under cutting off the end of a string.
At each length $n$ there are $2^n$ strings, and the tree keeps some of them.
The tree has positive measure if it always keeps at least a fixed fraction, for example at least one half, at every length.
The axiom $\mathsf{WWKL}$ says that such a tree has an infinite branch.
For example, the tree of strings that do not start with $1, 1$ keeps $3$ of the $4$ strings of length $2$, and the branch $0, 0, 0, \dots$ runs through it.

### L2 human

We check that the tree $T$ of strings that do not begin with $11$ has positive measure.

1. $T_0$ and $T_1$ contain all strings, so the ratio is $1$ for $n = 0, 1$.
2. For $n \ge 2$, a string of length $n$ is outside $T$ exactly when it begins with $11$. There are $2^{n-2}$ such strings.
3. So $\abs{T_n} = 2^n - 2^{n-2} = \tfrac{3}{4} 2^n$, and $q = \tfrac{3}{4}$ works.

The typical use of $\mathsf{WWKL}$: a theorem of measure theory says that some set of positive measure is not empty, and the proof codes that set as the paths of a tree.
The trap: it is not enough that each $\abs{T_n}$ is positive; the fraction must stay above one fixed $q$, or the axiom becomes the stronger $\mathsf{WKL}$.

### L3 human

In topological terms, $\mathsf{WKL}$ says that a closed subset of Cantor space that is coded by an infinite tree is not empty, and $\mathsf{WWKL}$ says the same only for closed sets of positive measure.
So $\mathsf{WKL}$ is about compactness and $\mathsf{WWKL}$ is about measure.
The computability-theoretic content is randomness: the $\omega$-models of $\mathsf{WWKL}_0$ are the Turing ideals that contain, for each $X$, a set that is [[Martin-Löf random|X5KD3X3VJ3]] relative to $X$.
The [[Lebesgue measure|2Z2QVWZ262]] of the set of paths is the bridge between the two readings.
A tree of positive measure is a closed set of positive measure.
By a lemma of Kučera, a set that is random relative to the tree has a final segment that is a path of the tree.
In constructive mathematics, forms of the fan theorem play the part that $\mathsf{WKL}$ plays here; this belongs to [[constructive reverse mathematics|3XFMHSCVYZ]].
