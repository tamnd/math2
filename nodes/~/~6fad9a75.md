## Proof

Let $P$ be any set of variables, and let $\Sigma$ be a finitely satisfiable set of formulas.
Give $\set{0, 1}$ the discrete topology, and let $X = \set{0, 1}^P$ have the [[product topology|0GBG8B49AA]].
A point of $X$ is a map $v : P \to \set{0, 1}$, that is, a [[truth assignment|~41f42e3d]].

1. The space $\set{0, 1}$ is finite, so it is compact. By [[Tychonoff's theorem|0JTRSJKCFB]], $X$ is [[compact|0QPHW703PV]].
2. For a formula $\varphi$, put $M(\varphi) = \set{v \in X : v(\varphi) = 1}$, the set of models of $\varphi$.
3. Let $q_1, \dots, q_k$ be the variables of $\varphi$. For $s \in \set{0, 1}^k$ put $U_s = \set{v \in X : v(q_i) = s_i \text{ for } i = 1, \dots, k}$.
4. Each $U_s$ is open. It is the intersection of the $k$ sets $\pi_{q_i}^{-1}(\set{s_i})$, where $\pi_q(v) = v(q)$ is a projection, and each $\set{s_i}$ is open in the discrete space.
5. The value $v(\varphi)$ depends only on $v(q_1), \dots, v(q_k)$, by the coincidence property of the valuation. So $M(\varphi)$ is the union of the sets $U_s$ over those $s$ that make $\varphi$ true.
6. This is a finite union of open sets, so $M(\varphi)$ is open.
7. The complement of $M(\varphi)$ in $X$ is $M(\neg \varphi)$, because $v(\neg \varphi) = 1 - v(\varphi)$. Step 6 for $\neg \varphi$ shows that it is open. So $M(\varphi)$ is closed, and it is a [[clopen set|DQ4E55T3BW]].
8. For a finite set $\set{\varphi_1, \dots, \varphi_n} \subseteq \Sigma$, a model is a point of $M(\varphi_1) \cap \cdots \cap M(\varphi_n)$. Finite satisfiability says that this intersection is never empty.
9. So the closed sets $M(\varphi)$, $\varphi \in \Sigma$, have the [[finite intersection property|00BWV5CKCF]].
10. In a compact space, a family of closed sets with the finite intersection property has a nonempty intersection. Choose $v$ in $\bigcap_{\varphi \in \Sigma} M(\varphi)$.
11. Then $v(\varphi) = 1$ for every $\varphi \in \Sigma$, so $\Sigma$ is [[satisfiable|QN7M1JCGT9]]. (If $\Sigma$ is empty, every point of the nonempty space $X$ works.)

## Idea

Truth assignments are the points of a product of two-point spaces, which is compact by Tychonoff's theorem.
Each formula depends on finitely many coordinates, so its set of models is clopen.
Finite satisfiability is then the finite intersection property, and compactness gives a common point, which is a model.

## Variants

- Choice: Tychonoff's theorem for arbitrary products is equivalent to the axiom of choice. This proof only needs it for products of compact Hausdorff spaces, which is equivalent to the Boolean prime ideal theorem.
- Countably infinite $P$: then $X$ is the Cantor space, whose compactness needs no choice, and the [[direct proof|~fb8216fd]] is the same argument without topology.
- Ultrafilters: let $I$ be the set of finite subsets of $\Sigma$, and choose a model $v_F$ of each $F \in I$. Take an ultrafilter $U$ on $I$ that contains every set $\set{F \in I : \varphi \in F}$, and put $v(p) = 1$ when $\set{F : v_F(p) = 1} \in U$. Induction on formulas shows that $v(\varphi) = 1$ exactly when $\set{F : v_F(\varphi) = 1} \in U$, so $v$ is a model of $\Sigma$.
- From completeness: the strong [[completeness theorem|~e697b103]] and the [[soundness theorem|~7a1817da]] give compactness. If $\Sigma$ has no model, then $\Sigma \models \neg (p_0 \to p_0)$, so $\Sigma \vdash \neg (p_0 \to p_0)$. A derivation uses a finite $\Sigma_0 \subseteq \Sigma$, and soundness gives $\Sigma_0 \models \neg (p_0 \to p_0)$, so $\Sigma_0$ has no model.
