## Example

Statement: for every [[real number|08J2M1JYAG]] $x$, $x^2 - 2x + 2 > 0$.
We [[prove the universal statement|~ad3ff00f]] with a generic element.

1. Let $x$ be an arbitrary real number. We assume nothing else about $x$.
2. [[Complete the square|XNCV97HTZ8]]: $x^2 - 2x + 2 = (x^2 - 2x + 1) + 1 = (x - 1)^2 + 1$.
3. The square of a real number is never negative, so $(x - 1)^2 \geq 0$.
4. Add $1$ to both sides: $(x - 1)^2 + 1 \geq 1$.
5. By steps 2 and 4, $x^2 - 2x + 2 \geq 1 > 0$.
6. Step 1 put no condition on $x$, so steps 2 to 5 hold for each real number. This proves the statement for all real $x$.

## Remarks

The proof gives more than the statement: the value is at least $1$, and it equals $1$ exactly when $x = 1$.
So the bound $x^2 - 2x + 2 \geq 1$ is sharp, and the minimum of the polynomial is $1$ at $x = 1$.

A change of the constant term changes the answer.
For $x^2 - 2x + c$, the same computation gives $(x - 1)^2 + (c - 1)$.
The polynomial is positive for every real $x$ exactly when $c > 1$.
For $c = 1$ it is $0$ at $x = 1$, and for $c < 1$ it is negative at $x = 1$.
A check of the values at $x = 0, 2, 3$ cannot see this: for $c = 0.5$ these values are $0.5$, $0.5$ and $3.5$, all positive, but the value at $x = 1$ is $-0.5$.

## Explanations

### L1 human

The claim is that $x^2 - 2x + 2$ is a positive number, whatever number $x$ is.
Try $x = 0$: the value is $2$.
Try $x = 1$: the value is $1$.
Try $x = 5$: the value is $17$.
These tries do not cover all numbers.
The proof rewrites the expression as "a square plus $1$", and a square is never negative, so the sum is at least $1$ for every $x$.

### L2 human

We use the same method for a polynomial in two variables: for all real $x$ and $y$, $x^2 + xy + y^2 \geq 0$.

1. Let $x$ and $y$ be arbitrary real numbers.
2. Complete the square in $x$: $x^2 + xy + y^2 = \left(x + \frac{y}{2}\right)^2 + \frac{3}{4} y^2$.
3. Check by expanding: $\left(x + \frac{y}{2}\right)^2 = x^2 + xy + \frac{1}{4} y^2$, and $\frac{1}{4} y^2 + \frac{3}{4} y^2 = y^2$.
4. Both terms in step 2 are at least $0$, so the sum is at least $0$.

The typical use: an expression that is a sum of squares is non-negative for all values of its variables.

A trap: writing "for $x = y = 1$ the value is $3 > 0$" proves nothing about all $x$ and $y$.
