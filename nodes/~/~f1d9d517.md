## Summary

Arithmetization of syntax is the method that turns the syntax of a theory $T$ into arithmetic, in three stages.
First, a [[Gödel numbering|MFJXPAF0R0]] codes symbols, formulas and proofs by numbers.
Second, the syntactic relations, such as "$x$ codes a formula" and "$y$ codes a proof of $x$", become [[primitive recursive|5NVA2JRHPV]] relations of codes, provided the axioms of $T$ form a decidable set.
Third, every such relation is represented in [[Robinson arithmetic|3K1AKGXF8A]] $\mathsf{Q}$ by a formula, which gives the proof predicate $\mathrm{Prf}_T(y, x)$.
The method lets a theory of arithmetic reason about its own proofs, and it underlies every incompleteness theorem.

## Motivation

The incompleteness theorems need a sentence that speaks about its own provability.
A theory of arithmetic speaks only about numbers.
So we must show that "$y$ is a proof of $x$ in $T$" is a property of numbers that a formula can express, and that $T$ proves the true instances of it.
Arithmetization of syntax does this work once, for every theory with a decidable set of axioms.

## Notation

We use the language $\set{0, S, +, \cdot}$, numerals $\underline{n}$ and the code $\# \varphi$ with its numeral $\ulcorner \varphi \urcorner$.

1. $\mathrm{Form}(x)$, $\mathrm{Sent}(x)$: $x$ codes a formula, a sentence.
2. $\mathrm{num}(n) = \# \underline{n}$, and $\mathrm{sub}(x, n)$ is the code of the result of putting $\underline{n}$ for the free variable $v_0$ in the formula with code $x$.
3. $\mathrm{Ax}_T(x)$: $x$ codes an axiom of $T$.
4. $\mathrm{Prf}_T(y, x)$: $y$ codes a proof in $T$ of the formula with code $x$. We use the same symbol for the relation and for a formula that represents it.
5. A formula is $\Delta_0$ when all its quantifiers are bounded, as in $\forall z \le t$ or $\exists z \le t$. It is $\Sigma_1$ when it has the form $\exists \vec{x} \, \delta$ with $\delta$ in $\Delta_0$.
6. In $\mathsf{Q}$ we read $x \le y$ as $\exists z \, (z + x = y)$.

## Remarks

### Examples

1. [[Concatenation of codes is primitive recursive|~e699b64b]]: the code of the string $vw$ is computed from the codes of $v$ and $w$ by bounded operations.
2. [[The proof predicate of Peano arithmetic is decidable|~be5e3117]]: the induction axioms form a decidable set, so proofs in $\mathsf{PA}$ can be checked by a program.
3. The relation $\mathrm{Form}(x)$ is primitive recursive: a string is a formula when it is built from shorter formulas, and the shorter parts have smaller codes.
4. The function $\mathrm{num}$ is primitive recursive, by $\mathrm{num}(0) = \# 0$ and $\mathrm{num}(n + 1) = $ the code of $S$ followed by the string with code $\mathrm{num}(n)$.
5. The diagonal function $d(n) = \mathrm{sub}(n, n)$, used in the [[diagonal lemma|3PRW76471J]], is primitive recursive as a composition.

### Non-examples

1. [[True arithmetic has no decidable axiom set|~a7addafc]]: the method cannot give a proof predicate for the theory of all true sentences of $\N$.
2. A theory whose axioms form a set that is computably enumerable but not decidable still has a decidable proof relation after Craig's trick. So this is not a real limit, but the trick must be applied first.
3. A coding that is not computable, as in [[coding sentences by their truth value|~291b20d9]], gives no primitive recursive syntactic relations.

### Basic properties

1. If $\mathrm{Ax}_T$ is decidable, then $\mathrm{Prf}_T$ is decidable. If $\mathrm{Ax}_T$ is primitive recursive, then $\mathrm{Prf}_T$ is primitive recursive.
2. Representability theorem. For each [[computable|KZSB5E471K]] relation $R \subseteq \N^k$ there is a formula $\varphi_R(\vec{x})$ such that, for all $\vec{n}$, $R(\vec{n})$ implies $\mathsf{Q} \vdash \varphi_R(\underline{\vec{n}})$, and $\neg R(\vec{n})$ implies $\mathsf{Q} \vdash \neg \varphi_R(\underline{\vec{n}})$.
3. For each computable total function $f \colon \N^k \to \N$ there is a formula $\varphi_f(\vec{x}, y)$ with $\mathsf{Q} \vdash \forall y \, (\varphi_f(\underline{\vec{n}}, y) \leftrightarrow y = \underline{f(\vec{n})})$ for all $\vec{n}$.
4. $\Sigma_1$-completeness of $\mathsf{Q}$: every $\Sigma_1$ sentence that is true in $\N$ is provable in $\mathsf{Q}$.
5. For a primitive recursive relation, the formula in property 2 can be chosen $\Sigma_1$, and its negation is also equivalent in $\N$ to a $\Sigma_1$ formula.
6. Every extension of $\mathsf{Q}$ in the same language keeps properties 2 to 4, because it proves everything that $\mathsf{Q}$ proves.

The proof of properties 2 and 3 is an induction on the definition of $f$ as a recursive function.
It is long, and the sub-area on formal arithmetic and the textbooks give it in full; here is its outline.

1. The zero function, the successor and the projections are represented by $y = 0$, $y = S x$ and $y = x_i$.
2. A composition $f(\vec{x}) = h(g_1(\vec{x}), \ldots, g_m(\vec{x}))$ is represented by $\exists \vec{z} \, (\bigwedge_i \varphi_{g_i}(\vec{x}, z_i) \wedge \varphi_h(\vec{z}, y))$.
3. A minimization $f(\vec{x}) = \mu z \, (g(\vec{x}, z) = 0)$ is represented by $\varphi_g(\vec{x}, y, 0) \wedge \forall z \, (z < y \to \neg \varphi_g(\vec{x}, z, 0))$. The proof uses two facts, $\mathsf{Q} \vdash \forall z \, (z \le \underline{n} \to z = 0 \vee \cdots \vee z = \underline{n})$ and $\mathsf{Q} \vdash \forall z \, (z \le \underline{n} \vee \underline{n} \le z)$, which are proved as Q-a and Q-b in [[the proof of Rosser's theorem|~8501ccc0]].
4. Primitive recursion needs finite sequences inside arithmetic. [[Gödel's β-function lemma|BM6P0C2AC2]] codes them with addition and multiplication only, so primitive recursion reduces to composition and minimization.
5. Property 4 follows by induction on $\Sigma_1$ formulas. The base case is that $\mathsf{Q}$ proves the true atomic sentences and the negations of the false ones. Bounded quantifiers use the fact in step 3.

### History

Gödel arithmetized syntax in his 1931 paper, with prime-power codes and a long list of primitive recursive definitions, ending with the proof relation.
His β-function let him define the recursive functions in the language of addition and multiplication alone.
Robinson arithmetic $\mathsf{Q}$ was introduced by Raphael Robinson in 1950 as a finite theory in which all computable functions are representable.

### Common errors

1. A student forgets that the axioms must form a decidable set. Without it, the proof relation need not be decidable, and the method does not apply.
2. A student thinks that representability needs induction. It holds already in $\mathsf{Q}$, which has no induction axioms.
3. A student confuses "the relation is represented by $\varphi$" with "$\varphi$ defines the relation in $\N$". Representability asks for proofs in $\mathsf{Q}$ of each true instance and each false instance.

## Explanations

### L1 human

A checker can verify a written proof line by line, like a computer program.
Arithmetization shows that this checking is arithmetic: it uses only adding, multiplying and comparing numbers.
For example, after coding, "this list of formulas is a proof of $0 = 0$" becomes a statement about two numbers.
Then arithmetic itself can state facts about proofs, and the theory can talk about what it can prove.

### L2 human

1. Code the proof $\varphi_1, \ldots, \varphi_k$ by $y = 2^{\# \varphi_1} 3^{\# \varphi_2} \cdots p_k^{\# \varphi_k}$.
2. The number of lines $k$ is the number of primes that divide $y$, found by a search below $y$.
3. For each $i \le k$, compute $\# \varphi_i$ as the exponent of $p_i$ in $y$.
4. Check that each $\varphi_i$ is an axiom, by the decidable test $\mathrm{Ax}_T$, or follows from earlier lines by a rule.
5. Check that the last line has code $x$. All checks are bounded searches, so $\mathrm{Prf}_T(y, x)$ is decidable.

The typical use is to prove that $\mathrm{Prov}_T(x) := \exists y \, \mathrm{Prf}_T(y, x)$ is a $\Sigma_1$ formula, the [[provability predicate|NB2BCZR40F]].
A trap: decidable in $\N$ is not the same as provable in $T$; the representability theorem is what moves from the first to the second.

### L3 human

Arithmetization says that $\N$ with addition and multiplication can simulate any finite combinatorial structure, such as strings, trees and finite sequences.
The same simulation shows that the theory of $(\N, +, \cdot)$ is undecidable, while the theory of $(\N, +)$, Presburger arithmetic, is decidable, because addition alone cannot code sequences.
In computability theory, the same idea gives the Kleene $T$ predicate, which codes the computations of a machine.
Weak theories such as $\mathsf{I}\Delta_0$ and Buss's bounded arithmetic carry out arithmetization with polynomial bounds on the codes.
