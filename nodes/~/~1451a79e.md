## Example

We prove the comparison rule for the [[Veblen function|6QFEVWKE25]] and apply it.
Rule: $\varphi_\alpha(\beta) < \varphi_\gamma(\delta)$ holds exactly in these three cases.

- (a) $\alpha = \gamma$ and $\beta < \delta$.
- (b) $\alpha < \gamma$ and $\beta < \varphi_\gamma(\delta)$.
- (c) $\alpha > \gamma$ and $\varphi_\alpha(\beta) < \delta$.

The same cases with $=$ in place of the last $<$ give the rule for equality.

1. Each $\varphi_\alpha$ is strictly increasing, so $\varphi_\alpha(x) < \varphi_\alpha(y)$ holds exactly when $x < y$.
2. Case $\alpha = \gamma$: step 1 gives (a).
3. Case $\alpha < \gamma$: $\varphi_\gamma(\delta)$ is a fixed point of $\varphi_\alpha$, by the definition. So $\varphi_\alpha(\beta) < \varphi_\gamma(\delta) = \varphi_\alpha(\varphi_\gamma(\delta))$, and step 1 turns this into $\beta < \varphi_\gamma(\delta)$.
4. Case $\alpha > \gamma$: $\varphi_\alpha(\beta)$ is a fixed point of $\varphi_\gamma$. So the inequality is $\varphi_\gamma(\varphi_\alpha(\beta)) < \varphi_\gamma(\delta)$, and step 1 turns this into $\varphi_\alpha(\beta) < \delta$.

We now compare four pairs.

5. $\varphi_1(\varepsilon_0 + 1)$ and $\varphi_2(0)$: case (b) with $1 < 2$. Since $\varepsilon_0 + 1 < \zeta_0 = \varphi_2(0)$, we get $\varepsilon_{\varepsilon_0 + 1} < \zeta_0$.
6. $\varphi_2(0)$ and $\varphi_1(\varphi_2(0) + 1)$: case (c) with $2 > 1$. Since $\varphi_2(0) < \varphi_2(0) + 1$, we get $\zeta_0 < \varepsilon_{\zeta_0 + 1}$.
7. $\varphi_0(\varphi_1(0))$ and $\varphi_1(0)$: case (b) with equality. The argument $\varphi_1(0)$ equals $\varphi_1(0)$, so $\omega^{\varepsilon_0} = \varepsilon_0$.
8. $\varphi_\omega(0)$ and $\varphi_3(\varphi_\omega(0))$: case (c) with equality. So $\varphi_3(\varphi_\omega(0)) = \varphi_\omega(0)$, a fixed point of $\varphi_3$.

## Remarks

The rule reduces a comparison of two Veblen terms to comparisons of smaller terms, so it can be run as a recursive algorithm on finite terms.
Together with the [[comparison of Cantor normal forms|~bfea1a9a]] for sums, it gives a decidable order on the terms built from $0$, $+$ and $\varphi$.
This order is the [[notation system|~f8083877]] for the ordinals below $\Gamma_0$.
To make the terms unique, one requires $\beta < \varphi_\alpha(\beta)$ in each term $\varphi_\alpha(\beta)$; step 7 shows why, since $\varphi_0(\varepsilon_0)$ and $\varphi_1(0)$ name the same ordinal.

## Explanations

### L1 human

To compare two Veblen values, first compare the lower indices.
If they are equal, compare the arguments.
If one index is smaller, its function cannot move the value of the other one, and that turns the question into a smaller comparison.
For example, $\varepsilon_{\varepsilon_0 + 1}$ is still below $\zeta_0$, because $\varepsilon_0 + 1$ is below $\zeta_0$.

### L2 human

We decide whether $\varphi_1(\varphi_2(0)) < \varphi_2(1)$.

1. The indices are $1 < 2$, so case (b) applies: compare $\varphi_2(0)$ with $\varphi_2(1)$.
2. These have the same index, so case (a) applies: compare $0$ with $1$.
3. $0 < 1$, so $\varphi_2(0) < \varphi_2(1)$, and so $\varepsilon_{\zeta_0} < \zeta_1$.

Note that $\varepsilon_{\zeta_0} = \zeta_0$, since $\zeta_0$ is a fixed point of $\alpha \mapsto \varepsilon_\alpha$.
The typical use is to decide the order of a notation system by recursion on terms.
The trap: comparing only the indices gives wrong answers, since $\varphi_1(\varphi_2(1)) = \varphi_2(1)$ has the smaller index $1$ but equals a term with index $2$.
