## Summary

Let $\mathcal{M}$ be an $L$-[[structure|983GZBQYT4]] with domain $M$ and let $A \subseteq M$.
An element $b \in M$ is *algebraic over $A$* when some $L_A$-formula $\varphi(x)$ holds at $b$ and has only finitely many solutions in $\mathcal{M}$.
It is *definable over $A$* when some $L_A$-formula $\varphi(x)$ has $b$ as its only solution.
The *algebraic closure* $\operatorname{acl}(A)$ is the set of elements algebraic over $A$, and the *definable closure* $\operatorname{dcl}(A)$ is the set of elements definable over $A$.
A complete [[type|9V71Q3SD1G]] $p \in S_1(A)$ is *algebraic* when it contains a formula with finitely many solutions.
These closures measure which elements a set of parameters pins down, and they give the dimension theory of strongly minimal structures.

## Motivation

In a field, the elements algebraic over a subfield $k$ are the roots of nonzero polynomials over $k$, and each such polynomial has finitely many roots.
A first-order formula over $A$ with finitely many solutions plays the role of the polynomial in any structure.
So the field notion extends to every structure, and it agrees with the field notion in algebraically closed fields.
Definable closure is the stricter version: the elements that $A$ names exactly, as $\Q(A)$ is named by the field operations from $A$.

## Notation

The closures are written $\operatorname{acl}(A)$ and $\operatorname{dcl}(A)$, or $\operatorname{acl}^{\mathcal{M}}(A)$ and $\operatorname{dcl}^{\mathcal{M}}(A)$ when the structure must be named.
Some authors write $\operatorname{cl}(A)$ for $\operatorname{acl}(A)$ in a strongly minimal structure.
In stability theory one also uses the closures $\operatorname{acl}^{\mathrm{eq}}$ and $\operatorname{dcl}^{\mathrm{eq}}$ in the structure with imaginary elements.

## Remarks

### Examples

- In an algebraically closed field, $\operatorname{acl}(A)$ is the field-theoretic [[algebraic closure|0X6AB5P3G1]] of the subfield generated by $A$; see [[algebraic closure in algebraically closed fields|~1cfca11d]].
- In a dense linear order, $\operatorname{acl}(A) = \operatorname{dcl}(A) = A$; see [[closure in dense linear orders|~be5ac796]].
- In $(\Z, <)$, $\operatorname{dcl}(\emptyset) = \emptyset$, since $n \mapsto n + 1$ is an automorphism with no fixed point, while $\operatorname{dcl}(\set{0}) = \Z$, since each $n$ is the $n$-th successor or predecessor of $0$.
- In a vector space over an infinite field $F$, in the language with a function for each scalar, both closures of $A$ are the linear span of $A$.

### Non-examples

- In the field $\C$ the number $\pi$ is not in $\operatorname{acl}(\emptyset)$, and $\sqrt{2}$ is in $\operatorname{acl}(\emptyset)$ but not in $\operatorname{dcl}(\emptyset)$; see [[algebraic but not definable elements in the complex field|~6a94f005]].
- In an infinite set with no structure, $\operatorname{acl}(A) = A$, so no element outside $A$ is algebraic over $A$.

### Basic properties

- $A \subseteq \operatorname{dcl}(A) \subseteq \operatorname{acl}(A)$, using the formula $x = a$ for $a \in A$.
- Monotonicity: $A \subseteq B$ implies $\operatorname{acl}(A) \subseteq \operatorname{acl}(B)$ and $\operatorname{dcl}(A) \subseteq \operatorname{dcl}(B)$.
- Finite character: $b \in \operatorname{acl}(A)$ exactly when $b \in \operatorname{acl}(A_0)$ for a finite $A_0 \subseteq A$, since a formula uses finitely many parameters; the same holds for $\operatorname{dcl}$.
- Idempotence: $\operatorname{acl}(\operatorname{acl}(A)) = \operatorname{acl}(A)$ and $\operatorname{dcl}(\operatorname{dcl}(A)) = \operatorname{dcl}(A)$; the proof is in the [[definition|~5546131c]].
- An [[automorphism|DSQ17TNW1C]] of $\mathcal{M}$ that fixes $A$ pointwise fixes $\operatorname{dcl}(A)$ pointwise and maps $\operatorname{acl}(A)$ onto itself.
- If $\mathcal{M} \preceq \mathcal{N}$, then the closures of $A$ in $\mathcal{M}$ and in $\mathcal{N}$ are equal, since "exactly $k$ solutions" is first-order.
- The type $\operatorname{tp}(b/A)$ is algebraic exactly when $b \in \operatorname{acl}(A)$; then it has at most $k$ realizations in every elementary extension, where $k$ is the number of solutions of the formula.
- $\abs{\operatorname{acl}(A)} \le \abs{A} + \abs{L} + \aleph_0$, since there are that many $L_A$-formulas.

### History

The model-theoretic closures generalize the algebraic closure of fields.
Baldwin and Lachlan used algebraic closure as a dimension theory for strongly minimal structures in 1971.

### Common errors

- Confusing $\operatorname{acl}$ with $\operatorname{dcl}$: a finite set of solutions is enough for $\operatorname{acl}$, and a single solution is needed for $\operatorname{dcl}$.
- Forgetting the structure: in the field $\C$, $\operatorname{dcl}(\emptyset) = \Q$, while in the ordered field $\R$ the number $\sqrt{2}$ is definable over $\emptyset$ as the positive square root of $2$.
- Thinking that $\operatorname{acl}(A)$ in a field is always algebraically closed: in the field $\R$ the closure of $\emptyset$ is the set of real algebraic numbers, which is not algebraically closed.

## Explanations

### L1 human

An element is algebraic over some given elements when a property that uses them has only finitely many solutions, and the element is one of them.
In the complex numbers, $\sqrt{2}$ is one of the two solutions of $x^2 = 2$, so it is algebraic over nothing at all.
It is not definable, because nothing tells $\sqrt{2}$ apart from $-\sqrt{2}$ with the field operations alone.
The number $1/2$ is definable, as the unique solution of $2x = 1$.

### L2 human

We compute $\operatorname{acl}(\set{0})$ in $(\Z, <)$.

1. The formula "$0 < x$ and no element lies between $0$ and $x$" has the unique solution $1$.
2. In the same way, each $n \in \Z$ is the unique solution of a formula with the parameter $0$.
3. So $\operatorname{dcl}(\set{0}) = \Z$ and $\operatorname{acl}(\set{0}) = \Z$.

The typical use is to find the elements that are tied to a set of parameters.
The trap is to compute the closure in the wrong structure: in an elementary extension of $(\Z, <)$ the closure of $\set{0}$ is still the copy of $\Z$, and the new elements are not in it.

### L3 human

In a strongly minimal structure, $\operatorname{acl}$ satisfies the exchange property, so it is a pregeometry, a [[matroid|PX31ZNYS3Z]], and the dimension of a model over its prime part determines the model; see [[strongly minimal theory|PNGY60EBDJ]].
In algebraically closed fields this dimension is the [[transcendence degree|D7TR0YWR9H]], and in vector spaces it is the linear dimension.
In a saturated or [[monster model|~84f3dbc1]], $b \in \operatorname{dcl}(A)$ exactly when every automorphism over $A$ fixes $b$, and $b \in \operatorname{acl}(A)$ exactly when $b$ has finitely many images under these automorphisms; this is the model-theoretic Galois correspondence.
