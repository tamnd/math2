## Example

Use $\delta(A) = \lvert A \rvert - \lvert E(A) \rvert$ on finite [[graphs|00C0BR7D7H]], with $\mathcal{K}_0$ the graphs on which $\delta \ge 0$ for all subsets.
We show that free amalgamation over a set that is not self-sufficient can leave $\mathcal{K}_0$.

1. Let $A = \set{a, b}$ with no edge, so $\delta(A) = 2$.
2. Let $B$ be the [[cycle|0QQ0F12962]] $a - x - b - y - a$. Then $\delta(B) = 4 - 4 = 0$, and every proper subset has $\delta \ge 1$, so $B \in \mathcal{K}_0$.
3. $A \not\le B$, since $\delta(B) = 0 < 2$.
4. Let $C$ be the path $a - z - b$. Then $C \in \mathcal{K}_0$ and $A \le C$.
5. The [[free amalgam|~dade84ce]] $D$ has vertices $a, b, x, y, z$ and $6$ edges.
6. So $\delta(D) = 5 - 6 = -1 < 0$, and $D \notin \mathcal{K}_0$.

## Remarks

Here a different amalgam exists: identifying $z$ with $x$ gives $B$ itself, which contains $C$.
So the failure is of free amalgamation, which is the canonical amalgam used in the construction.
Restricting to self-sufficient bases, as in [[Hrushovski amalgamation|~b9f4e93f]], removes this problem.

## Explanations

### L1 human

The $4$-cycle already uses up all the freedom of its two opposite corners.
Adding another path between the corners, without merging anything, uses more freedom than exists.
So the glued graph breaks the rule of the class.

### L2 human

We count the edges of $D$.

1. From $B$: $ax$, $xb$, $by$, $ya$.
2. From $C$: $az$, $zb$.
3. Free amalgamation adds nothing else, so there are $6$ edges on $5$ vertices.

The typical use is to see why the construction uses $\le$ instead of $\subseteq$.
A trap is to amalgamate over a base that looks independent, with no edges, without checking it is self-sufficient.
