## Definition

Let $f \colon A \to B$ be a [[function|~d103e2ff]].
The codomain of $f$ is the set $B$.

## Remarks

Each value $f(a)$ is in the codomain, but not every element of the codomain needs to be a value.
The set of values is the [[range|~54a6afbb]] of $f$. It is a subset of the codomain.
The function $f$ is [[surjective|~beb187ef]] when its range is the whole codomain.

## Explanations

### L1 human

For $f \colon \mathbb{R} \to \mathbb{R}$ with $f(x) = x^2$, the codomain is $\mathbb{R}$.
The value $-1$ is in the codomain, but no input gives it.
