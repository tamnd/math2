## Example

Let $\varphi$ be the formula $(p \land q) \to r$, with the three propositional variables $p$, $q$ and $r$.
We use the [[principle of bivalence|~e6dead3d]] to list all cases for $\varphi$, and we compute its [[truth table|05RSK4Q657]].

1. By bivalence, each of $p$, $q$, $r$ has exactly one of the values T and F.
2. The choices are independent, so there are $2 \cdot 2 \cdot 2 = 2^3 = 8$ valuations. In the standard order they are TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF.
3. In each row we compute the [[conjunction|025YZN3VJW]] $p \land q$ first, and then the [[implication|0NMG7W7Q11]] $(p \land q) \to r$, which is F only when $p \land q$ is T and $r$ is F.

| $p$ | $q$ | $r$ | $p \land q$ | $(p \land q) \to r$ |
|---|---|---|---|---|
| T | T | T | T | T |
| T | T | F | T | F |
| T | F | T | F | T |
| T | F | F | F | T |
| F | T | T | F | T |
| F | T | F | F | T |
| F | F | T | F | T |
| F | F | F | F | T |

4. The formula $\varphi$ is false in exactly one row, the row TTF.
5. Bivalence guarantees that the $8$ rows cover every case, so $\varphi$ is false exactly when $p$ and $q$ are true and $r$ is false.

## Remarks

The example shows the role of bivalence in the truth-table method: it fixes the list of cases.
Without bivalence, step 5 would not follow, because a case outside the table could exist.

If we change the number of variables to $n$, the same count gives $2^n$ rows: $16$ rows for $4$ variables and $1024$ rows for $10$ variables.
If we allow three truth values, as in a three-valued logic, then three variables give $3^3 = 27$ rows, and the connectives need new tables for the third value.

## Explanations

### L1 human

Each of three switches can be on or off.
The first switch has $2$ positions, each of them combines with $2$ positions of the second, and so on.
So there are $2 \times 2 \times 2 = 8$ ways to set the three switches.
A truth table with three letters lists these $8$ ways, because each letter is either true or false.

### L2 human

We count the rows for the formula $(p \lor q) \land \neg(r \land s)$ and check one row.

1. The formula has the $4$ variables $p$, $q$, $r$, $s$, so it needs $2^4 = 16$ rows.
2. Take the row $p = $ F, $q = $ T, $r = $ T, $s = $ T.
3. Then $p \lor q$ is T, because $q$ is T.
4. $r \land s$ is T, so $\neg(r \land s)$ is F.
5. So the whole formula is F in this row, because its second part is F.

The typical use of the count $2^n$ is to check that a truth table is complete before reading off a result.

A trap: the variable $q$ in a formula counts once, even if it occurs several times.
The formula $(p \land q) \lor (\neg q \land p)$ has $2$ variables and needs $4$ rows, not $16$.
