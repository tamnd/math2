## Example

Take the frame $(\N, <)$: the worlds are the natural numbers, and $m R n$ means $m < n$.
We check the frame properties of this [[accessibility relation|XBCYFDPS2F]] and test the axioms of [[common modal axiom schemata|FDFQFWPM4X]].

1. Serial: every $n$ has the successor $n + 1$, since $n < n + 1$.
2. [[Transitive|0GJZW9JFZQ]]: $l < m$ and $m < n$ give $l < n$.
3. Not [[reflexive|0X8NMST0J2]]: $0 < 0$ fails.
4. Not [[symmetric|061J5VGSPT]]: $0 < 1$ holds and $1 < 0$ fails.
5. Not Euclidean: $0 < 1$ and $0 < 2$ hold, but $2 < 1$ fails.
6. So $\mathrm{D}$ and $\mathrm{4}$ are valid on $(\N, <)$, by the correspondences for serial and transitive frames.
7. $\mathrm{T}$ fails with $V(p) = \set{n : n \geq 1}$. At $0$, every successor has $p$, so $\square p$ is true, while $p$ is false.
8. $\mathrm{B}$ fails with $V(p) = \set{0}$. At $1$, all successors are at least $2$ and lack $p$, so $\lozenge p$ is false at $1$. Then $\square\lozenge p$ is false at $0$, while $p$ is true at $0$.
9. $\mathrm{5}$ fails with $V(p) = \set{2}$. At $1$, the successor $2$ has $p$, so $\lozenge p$ is true. At $2$, all successors exceed $2$, so $\lozenge p$ is false, and $\square\lozenge p$ is false at $1$.
10. Temporal reading: $\square p$ means "$p$ at all later times". Take $V(p) = \set{n : n \text{ even}}$.
11. $[\![ \lozenge p ]\!] = \N$, since after each $n$ there is a later even number.
12. $[\![ \square p ]\!] = \varnothing$, since $n + 1$ or $n + 2$ is odd.
13. $[\![ \square\lozenge p ]\!] = \N$, since $\lozenge p$ holds everywhere: $p$ holds infinitely often.

## Remarks

The example shows a frame for the logic $\mathsf{KD4}$ on which $\mathrm{T}$, $\mathrm{B}$ and $\mathrm{5}$ fail.
In the temporal reading, $\square\lozenge p$ says "$p$ holds infinitely often", and $\lozenge\square p$ says "from some time on, $p$ holds forever".
With $V(p)$ the even numbers, $\lozenge\square p$ is false everywhere, so the two notions differ.
If we replace $<$ by $\leq$, the frame becomes reflexive, so $\mathrm{T}$ becomes valid.
The order $\leq$ is still not symmetric, and $\mathrm{B}$ still fails with $V(p) = \set{0}$ at $0$, since $1$ sees no $p$-world.
If we replace $\N$ by a finite chain $\set{0, \dots, k}$ with $<$, the last world has no successor, and $\mathrm{D}$ fails there.

## Explanations

### L1 human

Read the numbers $0, 1, 2, \dots$ as days, and "box $p$" as "$p$ on every later day".
"Diamond $p$" means "$p$ on some later day".
If it rains on every even day, then on each day there is a later rainy day.
But on no day is it true that it rains on all later days.
Every day has a next day, so "box $p$" always implies "diamond $p$".

### L2 human

1. Take $V(p) = \set{3, 4, 5, \dots}$.
2. At $n \geq 2$, every later day is at least $3$, so $\square p$ is true.
3. At $0$ and $1$, the later day $2$ lacks $p$, so $\square p$ is false.
4. So $[\![ \square p ]\!] = \set{2, 3, \dots}$ and $[\![ \lozenge\square p ]\!] = \N$.

The typical use of $(\N, <)$ is as a frame for the logic of the strict future, and as an infinite test frame for $\mathsf{KD4}$.
A trap: the frame is transitive and irreflexive, but it does not validate [[Löb's axiom|QQ6PZFGGB3]], because it has an infinite increasing chain.
