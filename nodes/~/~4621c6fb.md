## Example

Classical propositional logic $\mathsf{CPC}$ is an [[intermediate logic|~57af80cc]], and every consistent superintuitionistic logic $L$ satisfies $L \subseteq \mathsf{CPC}$.

1. $\mathsf{CPC}$ contains $\mathsf{IPC}$, since every axiom of [[the Hilbert system for IPC|52XCYMK0WW]] is a [[tautology|05006AJ7DZ]].
2. Tautologies are closed under modus ponens and substitution. So $\mathsf{CPC}$ is a superintuitionistic logic, and it is consistent.
3. Now let $L$ be superintuitionistic, and let $\varphi \in L$ be a formula that is not a tautology.
4. Choose a valuation $v$ with $v(\varphi) = 0$. Let $\sigma p = \bot \to \bot$ if $v(p) = 1$, and $\sigma p = \bot$ if $v(p) = 0$.
5. Claim: for every $\psi$, $\mathsf{IPC} \vdash \sigma \psi \leftrightarrow (\bot \to \bot)$ if $v(\psi) = 1$, and $\mathsf{IPC} \vdash \sigma \psi \leftrightarrow \bot$ if $v(\psi) = 0$.
6. The claim holds for variables and $\bot$. For the inductive step, $\mathsf{IPC}$ proves the classical tables of $\wedge$, $\vee$ and $\to$ on the two constants, for example $((\bot \to \bot) \to \bot) \leftrightarrow \bot$.
7. So $\mathsf{IPC} \vdash \sigma \varphi \leftrightarrow \bot$. Since $\sigma \varphi \in L$, we get $\bot \in L$ by modus ponens.
8. By the axiom $\bot \to \psi$, every formula $\psi$ is in $L$, so $L$ is inconsistent.

## Remarks

The proof shows a dichotomy: a superintuitionistic logic is either contained in $\mathsf{CPC}$ or is the set of all formulas.
So "consistent superintuitionistic logic" and "intermediate logic" mean the same thing.
$\mathsf{CPC}$ is a coatom of the lattice of superintuitionistic logics: its only proper extension is the inconsistent logic.

## Explanations

### L1 human

Any logic that contains intuitionistic logic and proves a classically false formula proves everything.
The reason is that we can replace every letter by "true" or "false" to make the formula an outright falsehood.
So classical logic is the strongest logic that is still consistent.

### L2 human

1. Take $L = \mathsf{IPC} + (p \to q)$, which proves a non-tautology.
2. Substitute $p \mapsto \bot \to \bot$ and $q \mapsto \bot$.
3. Then $L$ proves $(\bot \to \bot) \to \bot$, hence $\bot$, hence everything.

The typical use is to show that an axiom that is not classically valid makes a logic inconsistent.
A trap: the argument uses closure under substitution, so it fails for theories, which need not be closed under it.
