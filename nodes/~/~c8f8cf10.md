## Example

Let $\mathcal{Q} = (\Q, <)$, a countable [[dense linear order|2W4S2H4VYA]] without endpoints.
We check that $\mathcal{Q}$ is saturated, homogeneous, universal and recursively saturated, and that its types are orbits.

1. Since $\abs{\Q} = \aleph_0$, [[saturation|RMTZ5J64FX]] means: every complete $1$-type over a finite set $A$ is realized.
2. Write $A = \set{a_1 < \dots < a_k}$. By [[quantifier elimination|7FDDXV3JK7]], a complete type $p(x)$ over $A$ is fixed by the position of $x$: $x = a_i$, $a_i < x < a_{i+1}$, $x < a_1$ or $a_k < x$.
3. Each position is filled in $\Q$: by $a_i$, by $(a_i + a_{i+1})/2$, by $a_1 - 1$ or by $a_k + 1$. So $\mathcal{Q}$ is saturated.
4. Homogeneity: an order-preserving map $f$ between finite subsets of $\Q$ is partial elementary by quantifier elimination. A piecewise linear map through the points $(a, f(a))$ extends it to an automorphism, so $\mathcal{Q}$ is [[strongly homogeneous|~ee122c2b]].
5. Universality: a countable model of the theory is isomorphic to $\mathcal{Q}$ by [[Cantor's isomorphism theorem|ABN5PTXEHY]], so it embeds elementarily, and $\mathcal{Q}$ is [[universal|~40536de0]].
6. Recursive saturation: every type over a finite set is realized by step 3, in particular every computable one, so $\mathcal{Q}$ is [[recursively saturated|~fc343dbc]].
7. Orbits: two $n$-tuples have the same type over $\emptyset$ exactly when their coordinates are in the same order with the same ties. Step 4 gives an automorphism that maps one to the other, so [[types are orbits|~3d38bf9d]].

## Remarks

The rational order is also universal for countable linear orders in the weaker sense of order embeddings; see [[every countable linear order embeds into the rational order|A14V9CHSZF]].
It is not $\aleph_1$-saturated, since it omits the type of $\sqrt{2}$ over $\Q$.
The real order $(\R, <)$ is $\aleph_0$-saturated as well, but it is not saturated, since $\abs{\R} = 2^{\aleph_0}$ and it omits types over countable sets.

## Explanations

### L1 human

Pick finitely many fractions and any position relative to them: below all, between two of them, above all, or equal to one.
Some fraction always fills that position, because between two fractions there is always a third, and there is no smallest or largest fraction.
This is exactly what saturation asks for in a countable structure.

### L2 human

We realize the type over $A = \set{0, 1, 3}$ that says $1 < x < 3$.

1. The type contains $1 < x$, $x < 3$, $0 < x$ and $x \ne 0, 1, 3$.
2. The number $2$ satisfies these formulas, so it realizes the type.

The typical use is to recognize a countable saturated model by checking types over finite sets.
The trap is to check the whole set $\Q$ as parameters: the type of an element just above $0$ over $\Q$ is not realized, and it does not have to be.
