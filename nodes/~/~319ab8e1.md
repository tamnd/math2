## Summary

Let $\mathcal{M}$ be an $L$-structure, let $A$ be a subset of its domain, and let $n \ge 1$.
Let $S_n(A)$ be the set of complete $n$-[[types|9V71Q3SD1G]] over $A$.
For an $L_A$-formula $\varphi(x_1, \dots, x_n)$ put $[\varphi] = \set{p \in S_n(A) : \varphi \in p}$.
The *Stone topology* on $S_n(A)$ is the topology with the sets $[\varphi]$ as a basis.
With it, $S_n(A)$ is [[compact|0TVJZYB6SH]], [[Hausdorff|0S1FJ8VEX9]] and [[totally disconnected|0RJSBR9GW1]], that is, a [[Stone space|ZV38HA5PAQ]], and the sets $[\varphi]$ are exactly its [[clopen sets|DQ4E55T3BW]].
This space is the *Stone space of $n$-types over $A$*.
It turns the compactness theorem into the compactness of a space, and it lets topology count and classify the types of a theory.

## Motivation

A formula $\varphi(\bar{x})$ cuts the set of complete types into the types that contain $\varphi$ and the types that contain $\neg \varphi$.
It is natural to call these two pieces open, and then the formulas give a topology.
The [[compactness theorem|1NR3HAWG9D]] says that a set of formulas is consistent when each finite part is consistent.
In the topology this becomes: closed sets with the finite intersection property have a common point.
So the logic of types becomes the topology of one compact space, and topological ideas such as isolated points, density and rank get a logical meaning.

## Notation

The space is written $S_n(A)$, $S_n^{\mathcal{M}}(A)$ or $S_n(T)$ for a theory $T$.
The basic clopen set of $\varphi$ is written $[\varphi]$, $\langle \varphi \rangle$ or $U_\varphi$.
For a set $p$ of formulas, $[p] = \bigcap_{\varphi \in p} [\varphi]$ is the closed set of complete types that contain $p$.

## Remarks

### Examples

- For the theory of [[dense linear orders|2W4S2H4VYA]], $S_2(\emptyset)$ has three points, each one isolated; see [[the 2-types of dense linear orders|~decb0203]].
- For algebraically closed fields of characteristic $0$, $S_1(\emptyset)$ is a countable discrete set of algebraic types plus one limit point, the transcendental type; see [[the type space of algebraically closed fields|~4b7c25db]].
- For $(\R, <)$ and $A = \Q$, the space $S_1(\Q)$ has $2^{\aleph_0}$ points; see [[types of reals over the rationals|~6aa706c0]].
- For the theory of infinitely many unary predicates $P_0, P_1, \dots$ that are independent, a $1$-type over $\emptyset$ is a choice of $P_i(x)$ or $\neg P_i(x)$ for each $i$, and $S_1(\emptyset)$ is homeomorphic to the [[Cantor space|W9VYJRBF9N]].

### Non-examples

- The set of types over $\emptyset$ that the field $\overline{\Q}$ realizes, with the subspace topology, is an infinite discrete space and so not compact; see [[the types realized in the algebraic numbers|~10f17097]].
- The set $S_n(A)$ with the discrete topology is not compact when it is infinite, so it is not the Stone space of types.

### Basic properties

- The sets $[\varphi]$ form a basis: $[\varphi] \cap [\psi] = [\varphi \wedge \psi]$, and $[x_1 = x_1] = S_n(A)$.
- Each $[\varphi]$ is clopen, since its complement is $[\neg \varphi]$, because a complete type contains exactly one of $\varphi$ and $\neg \varphi$.
- The space is Hausdorff: two different types $p \ne q$ differ at some $\varphi \in p$ with $\neg \varphi \in q$, and $[\varphi]$, $[\neg \varphi]$ separate them.
- The space is compact: if the sets $[\varphi_i]$ cover it with no finite subcover, then $\set{\neg \varphi_i}$ is finitely satisfiable, and a complete type that contains it lies in no $[\varphi_i]$.
- Every clopen set is a finite union of basic sets, by compactness, so it equals $[\varphi_1 \vee \dots \vee \varphi_k]$.
- The space is the Stone space of the [[Lindenbaum-Tarski algebra|QC9M3Q8B8Q]] of $L_A$-formulas modulo $\operatorname{Th}_A(\mathcal{M})$, and a type is an ultrafilter of this algebra; see [[Stone duality|B9T33D5MJK]].
- For $A \subseteq B$, restriction $p \mapsto p \cap L_A$ is a continuous surjection $S_n(B) \to S_n(A)$.
- The [[isolated points|0A1YXSKB48]] of $S_n(A)$ are the [[isolated types|~ecb9582c]].

### Counting types

The space $S_n(A)$ has at most $2^{\abs{L} + \abs{A} + \aleph_0}$ points, since a type is a set of formulas.
When $L$ and $A$ are countable, the space has a countable basis, so it is a compact metrizable space.
Then the Cantor-Bendixson analysis gives a dichotomy: $S_n(A)$ is countable, or it contains a [[perfect set|628242KN0T]] and has exactly $2^{\aleph_0}$ points.
This dichotomy is the base of the study of countable models and of [[stability|T7JW5QY6KR]].

### History

Stone proved the representation theorem for Boolean algebras in 1936.
Morley used the Stone spaces of types and the Cantor-Bendixson rank of their points in his 1965 proof of the categoricity theorem.

### Common errors

- Reading $[\varphi]$ as the set of tuples that satisfy $\varphi$: it is a set of types, not a set of tuples.
- Thinking that a realized type is an isolated point: in $(\R, <)$ the type of $\sqrt{2}$ over $\Q$ is realized, but every formula in it holds on an interval, which contains other irrationals.
- Forgetting that $[\varphi] = [\psi]$ when $\varphi$ and $\psi$ are equivalent modulo $\operatorname{Th}_A(\mathcal{M})$.

## Explanations

### L1 human

Think of each complete type as a point.
Each formula splits the points into two groups: the types that say yes to the formula and the types that say no.
These groups play the role of the open sets of a map of all possible kinds of elements.
For the field of complex numbers, every algebraic number such as $\sqrt{2}$ gives a point that sits alone, while the transcendental numbers give one more point that all the other points crowd towards.

### L2 human

We compute $S_2(\emptyset)$ for the theory of dense linear orders.

1. A complete $2$-type contains exactly one of $x_1 < x_2$, $x_1 = x_2$ and $x_2 < x_1$.
2. By quantifier elimination, this choice decides every formula in $x_1, x_2$.
3. So there are three types, and each one is the only point of the clopen set of its formula.
4. So $S_2(\emptyset)$ is a discrete space with three points.

The typical use is to read a property of the theory from the space: here every type is isolated, as the Ryll-Nardzewski theorem predicts for an $\aleph_0$-categorical theory.
The trap is to expect the same for $S_1(\Q)$ in $(\R, <)$, which has $2^{\aleph_0}$ points and many limit points.

### L3 human

The map $\varphi \mapsto [\varphi]$ is the Stone duality between the Boolean algebra of formulas and the type space, so type spaces are the dual objects of theories.
For algebraically closed fields, a complete $n$-type over a field $K$ is fixed by the prime ideal of the polynomials in $K[x_1, \dots, x_n]$ that it makes zero, so $S_n(K)$ is the spectrum of $K[x_1, \dots, x_n]$ with the constructible topology.
The Cantor-Bendixson rank of a type in $S_n(A)$ is the start of [[Morley rank|WN43DRPNBX]], and the count of types over sets of each size defines the [[stability spectrum|5D9DC20519]].
In continuous logic the type spaces are compact Hausdorff spaces that need not be totally disconnected.
