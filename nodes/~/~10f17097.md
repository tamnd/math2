## Example

Let $\overline{\Q}$ be the field of [[algebraic numbers|0H628RSGWX]], a model of $\mathrm{ACF}_0$.
Let $R \subseteq S_1(\emptyset)$ be the set of complete $1$-types over $\emptyset$ that $\overline{\Q}$ realizes, with the subspace topology.
We show that $R$ is not a compact space, so it is not a Stone space of types.

1. By [[the type space of algebraically closed fields|~4b7c25db]], $S_1(\emptyset)$ consists of the types $p_g$ for irreducible $g \in \Z[x]$ and the transcendental type $p_\infty$.
2. Every element of $\overline{\Q}$ is a root of an irreducible $g$, so it realizes $p_g$; and every $g$ has a root in $\overline{\Q}$.
3. So $R = \set{p_g : g \text{ irreducible}}$, and $p_\infty \notin R$.
4. Each set $[g(x) = 0] \cap R = \set{p_g}$ is open in $R$, so $R$ is discrete.
5. $R$ is infinite, since the polynomials $x - k$ for $k \in \Z$ are irreducible and pairwise different.
6. The cover of $R$ by the open sets $\set{p_g}$ has no finite subcover, so $R$ is not [[compact|0TVJZYB6SH]].

## Remarks

The set $R$ is not closed in $S_1(\emptyset)$: its closure adds the point $p_\infty$, and then the space becomes compact.
For the field $\C$ the set of realized types is all of $S_1(\emptyset)$.
In general, a model of a complete theory realizes every isolated type, so its set of realized types is dense whenever the isolated types are dense.

## Explanations

### L1 human

The algebraic numbers contain a root of every polynomial equation, but they contain no transcendental number.
So one kind of element is missing.
The missing kind is the one that the other kinds approach, and without it the collection of kinds has a hole.

### L2 human

The test for compactness is a cover with no finite subcover.

1. Cover $R$ by the sets $\set{p_g}$, one for each irreducible $g$.
2. A finite subcover would use finitely many $g$, but there are infinitely many types $p_g$.

The trap is to think that every subset of a compact space is compact: only the closed subsets are.
