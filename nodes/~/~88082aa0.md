## Example

We modify the [[propositional institution|~60ee66bb]] by adding one sentence whose meaning depends on the whole signature.

- Signatures and morphisms: sets of propositional variables and functions between them, as before.
- Sentences: $\mathrm{Sen}(\Sigma)$ is the set of formulas built with $\neg$ and $\wedge$ from the variables in $\Sigma$ and one extra constant $\mathsf{ALL}$. A morphism $\sigma$ replaces each variable $p$ by $\sigma(p)$ and leaves $\mathsf{ALL}$ unchanged.
- Models and reducts: valuations $v \colon \Sigma \to \set{0, 1}$, with $v'|_\sigma = v' \circ \sigma$.
- Satisfaction: as in propositional logic, where $\mathsf{ALL}$ gets the value $1$ under $v$ exactly when $v(p) = 1$ for every $p \in \Sigma$.

$\mathrm{Sen}$ and $\mathrm{Mod}$ are functors, as in the propositional institution.
We show that the satisfaction condition fails, so the data are not an institution in the sense of [[abstract logical systems|~b4428343]].

1. Let $\Sigma = \set{p}$, $\Sigma' = \set{p, q}$, and let $\sigma \colon \Sigma \to \Sigma'$ be the inclusion.
2. Let $v'$ be the $\Sigma'$-valuation with $v'(p) = 1$ and $v'(q) = 0$.
3. The reduct $v'|_\sigma$ is the $\Sigma$-valuation $p \mapsto 1$. Every variable of $\Sigma$ is true under it, so $v'|_\sigma \models_\Sigma \mathsf{ALL}$.
4. The translation $\sigma(\mathsf{ALL})$ is $\mathsf{ALL}$ over $\Sigma'$. Since $v'(q) = 0$, $v' \not\models_{\Sigma'} \mathsf{ALL}$.
5. So $v' \models_{\Sigma'} \sigma(\mathsf{ALL})$ fails while $v'|_\sigma \models_\Sigma \mathsf{ALL}$ holds, and the satisfaction condition fails for $\sigma$, $v'$ and $\mathsf{ALL}$.

The failure has a consequence for logical consequence.

6. Over $\Sigma = \set{p}$, the only valuation that makes $p$ true is $p \mapsto 1$, and it makes $\mathsf{ALL}$ true. So $\set{p} \models_\Sigma \mathsf{ALL}$.
7. Over $\Sigma'$, the valuation $v'$ of step 2 makes $p$ true and $\mathsf{ALL}$ false. So $\set{p} \not\models_{\Sigma'} \mathsf{ALL}$.
8. Translation along $\sigma$ does not preserve consequence, although it does in every institution.

## Remarks

The defect is that $\mathsf{ALL}$ speaks about all symbols of the current signature, so its meaning changes when the signature grows.
In first-order logic the analogous sentence would say "every relation symbol of the signature holds of every element", and it fails for the same reason.
Sentences that mention only the symbols they contain, in a way that commutes with renaming, satisfy the condition; this is why ordinary propositional and first-order logic are institutions.

## Explanations

### L1 human

The sentence "everything in this list is true" depends on the list.
If the list contains one true statement, the sentence is true.
If we add a false statement to the list, the same sentence becomes false, although nothing about the first statement changed.
Institutions forbid such sentences, because renaming or extending the vocabulary must not change the meaning of old sentences.

### L2 human

We test the satisfaction condition for a renaming that is a bijection, where it does hold.

1. Let $\Sigma = \set{p}$, $\Sigma' = \set{r}$, and $\sigma(p) = r$.
2. For $v'(r) = 1$, the reduct is $p \mapsto 1$, and $\mathsf{ALL}$ is true on both sides.
3. For $v'(r) = 0$, the reduct is $p \mapsto 0$, and $\mathsf{ALL}$ is false on both sides.

So a bijective renaming does not reveal the defect, and only a morphism that adds a variable does.
The typical use of this example is to show why the satisfaction condition is stated for all morphisms, not only for bijections.
A trap is to check the condition for renamings only and to conclude that the data form an institution.
