## Example

Let $V = \R_{>0}$ be the set of positive [[real numbers|08J2M1JYAG]].
Define a new addition and a new scalar multiplication, with scalars in $\R$:
$$x \oplus y = xy, \qquad a \odot x = x^a \qquad (x, y \in V,\ a \in \R).$$
We check that $V$ is a real [[vector space|000AYPA9AJ]], axiom by axiom, as numbered in the [[definition|05EGHEQZAW]].

1. Closure: for $x, y > 0$ and $a \in \R$, the numbers $xy$ and $x^a$ are positive. So both operations map into $V$.
2. Axiom 1: $x \oplus (y \oplus z) = x(yz) = (xy)z = (x \oplus y) \oplus z$.
3. Axiom 2: $x \oplus y = xy = yx = y \oplus x$.
4. Axiom 3: the number $1$ is the zero vector, since $x \oplus 1 = x \cdot 1 = x$.
5. Axiom 4: the negative of $x$ is $1/x$, which is positive, and $x \oplus (1/x) = 1$, the zero vector.
6. Axiom 5: $a \odot (b \odot x) = (x^b)^a = x^{ab} = (ab) \odot x$.
7. Axiom 6: $1 \odot x = x^1 = x$.
8. Axiom 7: $a \odot (x \oplus y) = (xy)^a = x^a y^a = (a \odot x) \oplus (a \odot y)$.
9. Axiom 8: $(a + b) \odot x = x^{a + b} = x^a x^b = (a \odot x) \oplus (b \odot x)$.

All eight axioms hold, so $V$ is a real vector space.

## Remarks

The example shows that the zero vector need not be the number $0$: here it is $1$, and the negative of $2$ is $\tfrac12$.
The rule $0v = 0$ reads $0 \odot x = x^0 = 1$ here, and the rule $(-1)v = -v$ reads $(-1) \odot x = 1/x$.
The natural logarithm turns $\oplus$ into $+$ and $\odot$ into ordinary multiplication: $\ln(xy) = \ln x + \ln y$ and $\ln(x^a) = a \ln x$.
So $\ln$ is a [[linear isomorphism|0B8T10CE7N]] from $V$ to $\R$, and $V$ has [[dimension|03GSZ8RTZJ]] $1$.
Any $x \ne 1$, for example $x = e$, is a basis: each $y > 0$ equals $(\ln y) \odot e$.
If we allow $x = 0$, the axioms fail: $0$ has no negative, because $0 \cdot y = 1$ has no solution.

## Explanations

### L1 human

Here the "vectors" are positive numbers, "adding" means multiplying, and "scaling by $a$" means raising to the power $a$.
These strange rules still obey all the laws of a vector space.
For example, "$2 + 3$" is $6$, and "$2$ times the vector $3$" is $3^2 = 9$.
The number $1$ plays the role of zero, because multiplying by $1$ changes nothing.

### L2 human

We test the axiom $a \odot (x \oplus y) = (a \odot x) \oplus (a \odot y)$ with $a = 2$, $x = 3$ and $y = 5$.

1. $x \oplus y = 15$, so $2 \odot 15 = 225$.
2. $2 \odot 3 = 9$ and $2 \odot 5 = 25$, so their sum is $9 \cdot 25 = 225$.
3. Both sides are $225$.

The example is a standard test of whether a student checks the axioms from the definitions instead of from habit.
A trap: the zero vector is not $0$, and $0$ is not even in $V$.
