## Example

We show that $\mathsf{IOpen}$, the [[fragment|~1d4194bd]] of $\mathsf{PA}$ with induction for quantifier-free formulas, proves $\forall x \, \forall y \, (x + y = y + x)$.
We use the axioms $\mathsf{Q}4$, $x + 0 = x$, and $\mathsf{Q}5$, $x + Sy = S(x + y)$, of [[Robinson arithmetic|3K1AKGXF8A]].
Each induction below is on an equation, possibly with a parameter, so each is an axiom of $\mathsf{IOpen}$.

1. Lemma A: $0 + x = x$. Induct on $x$ in the formula $0 + x = x$. The base $0 + 0 = 0$ is $\mathsf{Q}4$. If $0 + x = x$, then $0 + Sx = S(0 + x) = Sx$ by $\mathsf{Q}5$.
2. Lemma B: $Sy + x = S(y + x)$. Induct on $x$ with parameter $y$. The base is $Sy + 0 = Sy = S(y + 0)$, by $\mathsf{Q}4$ twice.
3. Step of Lemma B. If $Sy + x = S(y + x)$, then $Sy + Sx = S(Sy + x) = SS(y + x) = S(y + Sx)$, by $\mathsf{Q}5$, the hypothesis and $\mathsf{Q}5$.
4. Commutativity. Induct on $y$ in $x + y = y + x$, with parameter $x$. The base $x + 0 = x = 0 + x$ holds by $\mathsf{Q}4$ and Lemma A.
5. Step. If $x + y = y + x$, then $x + Sy = S(x + y) = S(y + x) = Sy + x$, by $\mathsf{Q}5$, the hypothesis and Lemma B.

So $\mathsf{IOpen} \vdash \forall x \, \forall y \, (x + y = y + x)$, and the proof uses three instances of open induction.

## Remarks

The informal argument is the [[usual proof by induction|4EQPCHKEBH]]; the example checks that each induction is on a quantifier-free formula.
[[Robinson arithmetic|3K1AKGXF8A]] does not prove the law: [[this model of Q|~1e15aa46]] has elements $a$ and $b$ with $a + b \ne b + a$.
So the law separates $\mathsf{Q}$ from $\mathsf{IOpen}$.
Associativity of $+$, commutativity and associativity of $\cdot$, and distributivity also follow by open induction in the same way.
The same is not true of all simple number theory: $\mathsf{IOpen}$ does not prove the irrationality of $\sqrt 2$, by Shepherdson's theorem.

## Explanations

### L1 human

Commutativity says that $x + y = y + x$, for example $2 + 5 = 5 + 2$.
The starting rules only say how to add $0$ or a successor on the right.
Three short inductions move the successor from the right to the left.
Each induction is about a plain equation, so the weakest induction principle already suffices.

### L2 human

We check Lemma B for $y = 1$ and $x = 2$ by unfolding the equations.

1. $S1 + 2 = S(S1 + 1) = SS(S1 + 0) = SS(S1) = 4$.
2. $S(1 + 2) = S(S(1 + 1)) = SSS(1 + 0) = SSS1 = 4$.
3. Both sides equal $4$, as Lemma B predicts.

The typical use of this example is as the first step in showing that every model of $\mathsf{IOpen}$ is a commutative discretely ordered semiring.
A trap is to do the inductions in a different order: the step of commutativity needs Lemma B, and the base needs Lemma A.
