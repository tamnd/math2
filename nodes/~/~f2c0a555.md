## Example

Let $\mathrm{REC}$ be the family of [[computable sets|PPGD5KW8JC]], and let $\varphi_e$ be the $e$-th partial computable function.
We check that $(\N, \mathrm{REC})$ is the least $\omega$-model of [[RCA0|~58b63877]], that it is not a model of [[WKL0|~b501e994]], and that it is not a [[β-model|J0Z2GNJZ2W]].

1. $\mathrm{REC}$ contains $\emptyset$. The join of two computable sets is computable, and a set [[Turing reducible|PA4PYQ1PZ0]] to a computable set is computable.
2. So $\mathrm{REC}$ is a Turing ideal, and it is an $\omega$-model of $\mathsf{RCA}_0$ by the [[characterization of ω-models|~d06d0faa]].
3. Every $\omega$-model of $\mathsf{RCA}_0$ is a Turing ideal, so it contains $\emptyset$ and every set computable from $\emptyset$. So $\mathrm{REC}$ is the least one.
4. Let $A = \set{e : \varphi_e(e) = 0}$ and $B = \set{e : \varphi_e(e) = 1}$. They are disjoint.
5. No computable $C$ has $A \subseteq C$ and $C \cap B = \emptyset$. For such $C$, take $e$ with $\varphi_e(x) = 1$ for $x \in C$ and $\varphi_e(x) = 0$ for $x \notin C$.
6. If $e \in C$, then $\varphi_e(e) = 1$, so $e \in B$, which is disjoint from $C$. If $e \notin C$, then $\varphi_e(e) = 0$, so $e \in A \subseteq C$. Both cases are impossible.
7. Let $T$ be the set of $\sigma \in 2^{<\N}$ such that for all $e < \abs{\sigma}$: if $\varphi_e(e)$ halts in at most $\abs{\sigma}$ steps with output $0$, then $\sigma(e) = 1$, and with output $1$, then $\sigma(e) = 0$.
8. $T$ is computable and closed under initial segments. For each $n$ it has an element of length $n$, so $T$ is an infinite binary tree in $\mathrm{REC}$.
9. Let $P$ be a path through $T$. If $\varphi_e(e) = 0$ in $s$ steps, then $P {\restriction} n \in T$ for $n > \max(e, s)$ gives $P(e) = 1$. Likewise $\varphi_e(e) = 1$ gives $P(e) = 0$.
10. So $\set{e : P(e) = 1}$ separates $A$ from $B$, and by step 5 it is not computable. So $T$ has no path in $\mathrm{REC}$, and weak König's lemma fails in $(\N, \mathrm{REC})$.
11. The $\Sigma^1_1$ sentence "$T$ has a path" is true in $(\N, \mathcal{P}(\N))$, since every infinite binary tree has a path. It is false in $(\N, \mathrm{REC})$, so this model is not a $\beta$-model.

## Remarks

The tree $T$ of step 7 is often called a Kleene tree.
The example explains why $\mathsf{RCA}_0$ is called the theory of computable mathematics: its least $\omega$-model contains only computable sets.
Any theorem that has a computable instance with no computable solution is not provable in $\mathsf{RCA}_0$, by the same argument.

## Explanations

### L1 human

If one keeps only the sets that a computer can decide, then all the axioms of $\mathsf{RCA}_0$ still hold.
Some infinite binary trees that a computer can decide have no path that a computer can find.
So weak König's lemma is false in this world of computable sets.

### L2 human

Steps 4 to 10 build a computable instance of weak König's lemma with no computable solution.
This is the standard way to show that a principle is not provable in $\mathsf{RCA}_0$.
A trap is to think that $T$ has no paths at all: it has paths, and each of them separates $A$ from $B$, but no path is computable.
