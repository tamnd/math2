## Summary

Let $L$ be a [[first-order|086QKPF0A6]] language without the equality symbol that has at least one constant symbol, with the connectives $\neg, \wedge, \vee, \to$ and the quantifiers $\forall, \exists$, and use the $\alpha, \beta, \gamma, \delta$ types of [[semantic tableaux|~78632a29]].
A set $H$ of [[sentences|DKFGQTRYZE]] of $L$ is a Hintikka set for $L$ (also a downward saturated set) when it satisfies five conditions.
(1) No atomic sentence $A$ has both $A \in H$ and $\neg A \in H$.
(2) If $\alpha \in H$, then $\alpha_1 \in H$ and $\alpha_2 \in H$.
(3) If $\beta \in H$, then $\beta_1 \in H$ or $\beta_2 \in H$.
(4) If $\gamma \in H$, then $\gamma(t) \in H$ for every closed [[term|6D3WA7N2W4]] $t$ of $L$.
(5) If $\delta \in H$, then $\delta(t) \in H$ for at least one closed term $t$ of $L$.
[[Hintikka's lemma|~542ddd18]] says that each Hintikka set is [[satisfiable|QN7M1JCGT9]], and this is the step from syntax to a model in the completeness proofs for tableaux and related systems.

## Motivation

A completeness proof must build a [[structure|983GZBQYT4]] from syntactic data alone.
For a single sentence, the natural candidate is a set of sentences that says enough to fix a model.
Such a set must contain a reason for the truth of each of its complex members, in the form of simpler members.
For $\varphi \wedge \psi$ the reason is $\varphi$ and $\psi$; for $\varphi \vee \psi$ it is one of them; for $\exists x\, \varphi$ it is a named witness $\varphi[t/x]$; for $\forall x\, \varphi$ it is every instance $\varphi[t/x]$.
If the reasons go all the way down to atomic sentences and do not clash there, then the atomic sentences fix a structure, and the reasons carry truth back up.
A Hintikka set is exactly a set with this downward closure.

An open branch of a fair tableau has this closure, because the tableau rules add the reasons one by one.
So Hintikka sets connect the tableau method to models.
They are different from the maximal consistent sets of Henkin's proof of the [[model existence theorem|G0DTR159RN]]: a Hintikka set can be small, and it is defined without a notion of proof.

## Notation

We write $H$ for a Hintikka set and $T_L$ for the set of closed terms of $L$.
The condition "for every closed term of $L$" in (4) depends on $L$, so we say "Hintikka set for $L$" when the language matters.
In tableau proofs $L$ is the language $L^{+}$ with the parameters, or the language of the symbols on one branch.

Hintikka called these sets model sets, and Smullyan's book First-Order Logic calls them Hintikka sets.
Some books state condition (1) for all sentences, add the constants $\top$ and $\bot$, or let (4) range over the parameters only.
These variants change the details of the proofs and not the idea.
Signed versions use the signs $T$ and $F$ in place of the negation sign.

## Remarks

### Examples

- The empty set is a Hintikka set, because each condition is about members of $H$.
- A set of atomic and negated atomic sentences with no pair $A, \neg A$, such as $\{P(c), \neg Q(c)\}$, is a Hintikka set: conditions (2) to (5) have no cases.
- [[A finite Hintikka set with all four rule types|~a1b05f21]]: $\{\forall x(P(x) \vee Q(x)), \exists x(P(x) \wedge \neg Q(x)), \dots\}$ in a language with one constant.
- [[An infinite Hintikka set over the terms 0, s(0), s(s(0)), …|~e0196c91]]: a function symbol makes the instances of a $\gamma$ sentence infinite.
- Let $\mathcal{M}$ be an $L$-structure in which each element is the value of a closed term. Then the set of all $L$-sentences true in $\mathcal{M}$ is a Hintikka set. Condition (5) holds because each witness of $\exists x\, \varphi$ has a name $t$, and then $\varphi[t/x]$ is true.
- The set of sentences on an open branch of a systematic tableau is a Hintikka set for $L^{+}$; see [[semantic tableaux|~78632a29]].

### Non-examples

- [[A satisfiable set that is not a Hintikka set|~2d814afe]]: $\{\exists x\, P(x), \forall x\, \neg Q(x)\}$ fails conditions (4) and (5).
- $\{P(c), \neg P(c)\}$ fails condition (1), and it is not satisfiable.
- $\{P(c) \vee Q(c)\}$ fails condition (3), because neither $P(c)$ nor $Q(c)$ is in the set.
- In a language with the constant $c$ and a unary function symbol $f$, the set $\{\forall x\, P(x), P(c)\}$ fails condition (4), because $P(f(c))$ is missing.

### Basic properties

- [[Hintikka's lemma|~542ddd18]]: each Hintikka set $H$ for $L$ has a model whose domain is the set $T_L$ of closed terms. This model is a [[Herbrand structure|HKW429DSDK]].
- A Hintikka set contains no pair $\chi, \neg\chi$ for any sentence $\chi$, atomic or not. The reason: a model of $H$ would make both true.
- A Hintikka set need not be complete: $\{P(c)\}$ contains neither $Q(c)$ nor $\neg Q(c)$. The model of the lemma then makes $Q(c)$ false.
- A Hintikka set need not be closed under logical consequence: $\{P(c)\}$ does not contain $P(c) \vee Q(c)$.
- The union of a chain of Hintikka sets for $L$ is a Hintikka set for $L$. Each condition is about one or two members, and they lie in one set of the chain.
- The intersection of two Hintikka sets need not be a Hintikka set: $\{P(c) \vee Q(c), P(c)\} \cap \{P(c) \vee Q(c), Q(c)\} = \{P(c) \vee Q(c)\}$ fails (3).
- Use in tableau completeness: if a fair tableau for $\Gamma$ has an open branch, then the branch is a Hintikka set that contains $\Gamma$, so $\Gamma$ is satisfiable.
- With the equality symbol, two more closure conditions are needed; see the remarks of [[Hintikka's lemma|~542ddd18]].

### History

Jaakko Hintikka introduced model sets in 1955.
Evert Willem Beth introduced semantic tableaux in the same year, independently.
Raymond Smullyan's book First-Order Logic (1968) used the name Hintikka set, and it proved Hintikka's lemma in the uniform notation.

### Common errors

1. Closure in the wrong direction. A Hintikka set is closed downward (from a sentence to its components), not upward. It does not have to contain $\varphi \vee \psi$ when it contains $\varphi$.
2. Forgetting terms in condition (4). With a function symbol, the closed terms are infinite, and a Hintikka set that contains a $\gamma$ sentence is then infinite.
3. Reading condition (1) as "consistent". Condition (1) is a check on atomic sentences only, and Hintikka's lemma is what turns it into satisfiability.

## Explanations

### L1 human

Imagine a list of facts about a small world, for example "every ball is red or blue" and "some ball is red and not blue".
The list is a Hintikka set when every complicated fact comes with simple facts that explain it.
For "some ball is red and not blue", the list must name a ball, say ball $c$, and say "ball $c$ is red" and "ball $c$ is not blue".
For "every ball is red or blue", the list must say "ball $c$ is red or blue" for each named ball, and then one of the two parts.
At the bottom, the simple facts must not contradict each other.
Then we can build the world from the simple facts, and every fact on the list is true in it.

### L2 human

We check that $H = \{P(c) \wedge \neg P(d),\ P(c),\ \neg P(d),\ \exists x\, \neg P(x)\}$ is a Hintikka set for the language with the constants $c, d$ and the unary symbol $P$.

1. Condition (1): the atomic sentences in $H$ are $P(c)$, and the negated ones are $\neg P(d)$. The atom $P(d)$ is not in $H$, so there is no clash.
2. Condition (2): the only $\alpha$ sentence is $P(c) \wedge \neg P(d)$, and both $P(c)$ and $\neg P(d)$ are in $H$.
3. Condition (3): $H$ has no $\beta$ sentence.
4. Condition (4): $H$ has no $\gamma$ sentence.
5. Condition (5): the $\delta$ sentence $\exists x\, \neg P(x)$ has the instance $\neg P(d) \in H$ with $t = d$.

The model of Hintikka's lemma has the domain $\{c, d\}$ and $P = \{c\}$, and each member of $H$ is true in it.

The typical use is the last step of a completeness proof: the proof builds a Hintikka set that contains the given set, and Hintikka's lemma gives the model.
The trap is condition (4): adding the sentence $\forall x\, P(x)$ to $H$ would require $P(c)$ and $P(d)$, and $P(d)$ clashes with $\neg P(d)$, so no Hintikka set contains the larger set.

### L3 human

Hintikka sets are the semantic half of the analytic proof systems.
A proof system has a cut-free completeness proof when each failed proof search produces a Hintikka set.
This pattern works for tableaux, cut-free [[sequent calculus|W72CA3R9MP]] and many modal and intuitionistic systems.
In the modal and intuitionistic cases, the Hintikka sets become the worlds of a Kripke model.
In model theory the same idea appears as the term model and as the Henkin construction, and the model of Hintikka's lemma is a [[Herbrand structure|HKW429DSDK]], the basis of [[Herbrand's theorem|VZ21F10WRS]].
With the equality symbol, the term model must be divided by a [[congruence relation|DCSXXT4SER]], which leads to the treatment of equality in the [[rules for equality|~65701c23]].
