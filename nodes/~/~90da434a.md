## Example

Let $\mathrm{ACA}_0$ be the subsystem of [[second-order arithmetic|DC60FYCSPM]] with arithmetical comprehension and the induction axiom for sets, as in [[ACA0 is conservative over PA|HPA6HX3114]].
For a primitive recursive order $\prec$, let $\mathrm{WF}(\prec)$ be the sentence $\forall X \, (\operatorname{Prog}(X) \to \forall x \, (x \in X))$.
We check the three results of an [[ordinal analysis|57PTMS2ADY]] with $\alpha = \varepsilon_0$.

1. Notation system: the Cantor normal forms below $\varepsilon_0$, as for PA.
2. Lower bound for a fixed notation $a$. The jump proof of [[transfinite induction in arithmetic|~e065bc19]] uses induction for the formulas $\varphi^+$, which are arithmetical in $X$. In $\mathrm{ACA}_0$, arithmetical comprehension turns each such formula into a set for the set induction axiom, so $\mathrm{ACA}_0$ proves $\mathrm{WF}(\prec_a)$.
3. Upper bound (cited). $\mathrm{ACA}_0$ is conservative over $\mathrm{PA}(X)$, Peano arithmetic with a new predicate $X$ in the induction schema, for formulas with a free set variable. The proof is the conservativity proof over PA, read with a parameter.
4. So if $\mathrm{ACA}_0 \vdash \mathrm{WF}(\lhd)$, then $\mathrm{PA}(X) \vdash \operatorname{Prog}(X) \to \forall x \, X(x)$ along $\lhd$. The upper bound of [[the analysis of PA|~633a5219]] holds for $\mathrm{PA}(X)$, so the order type of $\lhd$ is below $\varepsilon_0$.
5. So $\abs{\mathrm{ACA}_0} = \varepsilon_0$.

## Remarks

Two theories with different languages have the same ordinal here, and the reason is conservativity.
The full system $\mathrm{ACA}$, with induction for all second-order formulas, proves more: its ordinal is $\varepsilon_{\varepsilon_0}$.
The step from $\mathrm{ACA}_0$ to $\mathrm{ACA}$ adds induction, not comprehension, and the ordinal grows by a full level of epsilon numbers.

## Explanations

### L1 human

The system ACA0 adds sets of numbers to Peano arithmetic, but only sets that arithmetic can already describe.
Such sets do not let it prove any new facts about numbers.
So its ordinal is the same as for Peano arithmetic, namely $\varepsilon_0$.

### L2 human

We compare $\mathrm{ACA}_0$ and $\mathrm{ACA}$ on one induction.

1. In $\mathrm{ACA}_0$, induction is an axiom about sets, so it applies only to properties that define a set.
2. Arithmetical comprehension gives sets for arithmetical properties, so arithmetical induction holds, as in PA.
3. In $\mathrm{ACA}$, induction holds for all second-order formulas, for example for "$\prec_x$ is well-founded", which has a set quantifier.
4. Induction on this formula proves well-foundedness for longer orders, up to each ordinal below $\varepsilon_{\varepsilon_0}$.

The typical use is to read the ordinal of a subsystem of second-order arithmetic from a conservation result.
The trap: the subscript $0$ in $\mathrm{ACA}_0$ marks restricted induction, and it changes the ordinal.
