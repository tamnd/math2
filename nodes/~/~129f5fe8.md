## Example

Let $g : \N \to \N$ be a function.
The minimum principle $A = \exists n\, \forall m\, (g(n) \le g(m))$ says that $g$ takes a smallest value.
It follows from the [[well-ordering principle|J2P9FWBP3Q]], and PA proves it for each function given by a formula.
Its [[no-counterexample interpretation|~42908449]] asks for a functional $X(g, f)$ with $g(X) \le g(f(X))$ for every $f : \N \to \N$.

Construction of $X$.

1. Define $n_0 = 0$ and $n_{k + 1} = f(n_k)$, for all $k$.
2. Let $X(g, f) = n_k$ for the least $k$ with $g(n_k) \le g(f(n_k))$.

Proof that $X$ is defined and correct.

3. Suppose $g(n_j) > g(f(n_j)) = g(n_{j + 1})$ for all $j < k$.
4. Then $g(n_k) \le g(n_0) - k = g(0) - k$, by induction on $k$, since each step lowers the value by at least $1$.
5. Values are natural numbers, so $k \le g(0)$.
6. Hence the least $k$ of step 2 exists, and $k \le g(0)$.
7. By the choice of $k$, $g(X) \le g(f(X))$ with $X = n_k$.

So $X$ satisfies the n.c.i., and it is computed by at most $g(0) + 1$ evaluations of $f$ and $g$.

## Remarks

The witness for $A$ itself, the place of the minimum of $g$, is not a [[computable function|KZSB5E471K]] of $g$.
Given finitely many values $g(0), \ldots, g(N)$, the value $g(N + 1)$ can still be smaller than all of them.
So no algorithm with access to $g$ finds the minimum.
The functional $X$ avoids this: it uses $f$ to decide which values of $g$ to inspect.
The bound $k \le g(0)$ is the same bound as in the [[infinite descent example|~a0317708]] for the A-translation.
In PA, with $g$ a definable function, the same functional is primitive recursive in $g$ and $f$.

## Explanations

### L1 human

The claim "the function $g$ has a smallest value" is true, but a computer cannot find the smallest value, because it can never look at all values.
The no-counterexample interpretation changes the task.
An opponent claims that every number $n$ is beaten by a number $f(n)$ with a smaller value.
The program follows the claim: $0$, then $f(0)$, then $f(f(0))$, and so on.
The values go down at every step, so after at most $g(0)$ steps a claim fails, and the program has caught the opponent.

### L2 human

We run $X$ on $g(m) = |m - 5| + 2$ and $f(n) = n + 1$.

1. $n_0 = 0$ with $g(0) = 7$; $f(0) = 1$ with $g(1) = 6 < 7$, so we continue.
2. $n_1 = 1$, $n_2 = 2$, $n_3 = 3$, $n_4 = 4$, with values $6, 5, 4, 3$.
3. $n_5 = 5$ with $g(5) = 2$, and $f(5) = 6$ with $g(6) = 3 \ge 2$. So $X = 5$.

Here $X$ is the true minimum, but only because $f$ moved toward it.
For $f(n) = 0$ the functional stops at once with $X = 0$, since $g(0) \le g(f(0))$, and $0$ is not the minimum.
The typical use is to show what finite information a classical existence proof contains.
A trap is to expect $X$ to find the true minimum: it only refutes the given $f$.
