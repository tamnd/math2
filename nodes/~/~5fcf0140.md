## Proof

We use the conventions on Turing machines of the [[encoding proof of Church's theorem|~083e3c03]].
So $M$ is a [[universal Turing machine|TC69PEHAX7]] with states $q_0, \ldots, q_m$ and symbols $a_0, \ldots, a_k$, where $a_0$ is the blank, and the set of words on which $M$ halts is not computable.
For an input $w = b_0 \cdots b_{n-1}$ with $n \ge 1$, let $q_t$, $h_t$ and $c_t(y)$ be the state, the head position and the symbol in cell $y$ after $t$ steps.
The head moves at most one cell in each step and starts at cell $0$, so $h_t \le t$.

The signature $L$ has a binary relation symbol $<$ and binary relation symbols $Q_q$ and $C_a$ for each state $q$ and each symbol $a$.
In a structure, the same elements serve as cells and as times.
We use these abbreviations.

- $\operatorname{succ}(x, y)$ is $x < y \wedge \neg \exists z \, (x < z \wedge z < y)$.
- $\operatorname{first}(x)$ is $\neg \exists z \, (z < x)$.
- $\delta_0(x)$ is $\operatorname{first}(x)$, and $\delta_{i+1}(x)$ is $\exists y \, (\delta_i(y) \wedge \operatorname{succ}(y, x))$.
- $F(x, t, s)$ is $\forall y \, (y \neq x \to \bigwedge_c (C_c(y, t) \to C_c(y, s)))$.

Let $\psi_w$ be the conjunction of the following sentences.

- $\lambda$: the three axioms of a strict linear order: irreflexivity, transitivity, and $\forall x \, \forall y \, (x < y \vee x = y \vee y < x)$.
- $\iota_w$: the sentence $\exists x \, \delta_{n-1}(x)$, and the sentence $\forall t \, (\operatorname{first}(t) \to \theta(t))$, where $\theta(t)$ is the conjunction of $Q_{q_0}(t, t)$, of $\forall x \, (\delta_i(x) \to C_{b_i}(x, t))$ for each $i < n$, and of $\forall x \, (\bigwedge_{i < n} \neg \delta_i(x) \to C_{a_0}(x, t))$.
- For each instruction $\delta(q, a) = (r, b, \mathrm{R})$, the axiom $\forall x \, \forall t \, (Q_q(x, t) \wedge C_a(x, t) \to \exists s \, \exists u \, (\operatorname{succ}(t, s) \wedge \operatorname{succ}(x, u) \wedge Q_r(u, s) \wedge C_b(x, s) \wedge F(x, t, s)))$.
- For each instruction $\delta(q, a) = (r, b, \mathrm{L})$, the axiom $\forall x \, \forall t \, (Q_q(x, t) \wedge C_a(x, t) \to \exists s \, (\operatorname{succ}(t, s) \wedge C_b(x, s) \wedge F(x, t, s) \wedge \mu))$, where $\mu$ is $(\operatorname{first}(x) \wedge Q_r(x, s)) \vee \exists u \, (\operatorname{succ}(u, x) \wedge Q_r(u, s))$.

The map $w \mapsto \psi_w$ is computable.

Step A: a lemma on finite linear orders.

1. Let $e_0 < e_1 < \cdots < e_N$ be a finite strict linear order. Then $\operatorname{succ}(x, y)$ holds exactly when $x = e_i$ and $y = e_{i+1}$ for some $i < N$, since no element lies strictly between $e_i$ and $e_{i+1}$.
2. $\operatorname{first}(x)$ holds exactly for $x = e_0$, the least element.
3. By induction on $i$, $\delta_i(x)$ holds exactly for $x = e_i$ when $i \le N$, and for no $x$ when $i > N$. The step uses item 1.

Step B: if $M$ halts on $w$, then $\psi_w$ has a finite model.

4. Let $T$ be the step at which $M$ halts, and let $N = \max(T, n)$. Let $\mathcal{A}$ have domain $\set{0, 1, \ldots, N}$ with the usual order.
5. Let $Q_q(x, t)$ hold when $t \le T$, $q_t = q$ and $h_t = x$. Let $C_a(x, t)$ hold when $t \le T$ and $c_t(x) = a$.
6. $\mathcal{A} \models \lambda$, since the usual order is a strict linear order.
7. $\mathcal{A} \models \iota_w$. By step 3, $\delta_i$ defines $i$, and $n - 1 \le N$. At time $0$ the head is at cell $0$ in state $q_0$, cell $i < n$ holds $b_i$, and the other cells are blank.
8. For the instruction axioms, assume $Q_q(x, t) \wedge C_a(x, t)$ with an instruction $\delta(q, a)$. By step 5, $t \le T$, $x = h_t$ and $a = c_t(h_t)$. Since $\delta(q_t, c_t(h_t))$ is defined, $M$ does not halt at step $t$, so $t < T$.
9. Then $s = t + 1 \le N$ is the successor of $t$, and the step of $M$ at time $t$ makes $Q_r$, $C_b$ and $F$ true at time $s$, as in the encoding proof of Church's theorem.
10. For a right move, the new head position $h_t + 1 = h_{t+1} \le t + 1 \le N$ is in the domain, so $u = h_t + 1$ exists. For a left move, $\mu$ holds with $x = 0$ if $h_t = 0$, and with $u = h_t - 1$ otherwise.
11. So $\mathcal{A} \models \psi_w$, and $\mathcal{A}$ is finite.

Step C: if $\psi_w$ has a finite model, then $M$ halts on $w$.

12. Let $\mathcal{A}$ be a finite model of $\psi_w$. By $\lambda$, its elements form a strict linear order $e_0 < \cdots < e_N$.
13. Assume, for a contradiction, that $M$ never halts on $w$.
14. By $\iota_w$ and step 3, $n - 1 \le N$. We prove by induction on $t \le N$ the claim $P(t)$: $h_t \le N$, $\mathcal{A} \models Q_{q_t}(e_{h_t}, e_t)$, and $\mathcal{A} \models C_{c_t(y)}(e_y, e_t)$ for every $y \le N$.
15. $P(0)$ holds. By step 2, $e_0$ is the only first element, so $\iota_w$ gives $Q_{q_0}(e_0, e_0)$. By step 3, $\iota_w$ puts $b_i$ in $e_i$ for $i < n$ and the blank in $e_y$ for $n \le y \le N$.
16. Assume $P(t)$ with $t < N$. Since $M$ does not halt, $\delta(q_t, c_t(h_t)) = (r, b, D)$ is defined, and the axiom for it applies at $x = e_{h_t}$ and time $e_t$.
17. The axiom gives $s$ with $\operatorname{succ}(e_t, s)$, so $s = e_{t+1}$ by step 1. It also gives $C_b(e_{h_t}, e_{t+1})$, and $F$ keeps the symbol of every other cell $e_y$.
18. Case $D = \mathrm{R}$. The axiom gives $u$ with $\operatorname{succ}(e_{h_t}, u)$ and $Q_r(u, e_{t+1})$. By step 1, $u = e_{h_t + 1}$, so $h_{t+1} = h_t + 1 \le N$.
19. Case $D = \mathrm{L}$ and $h_t = 0$. The element $e_0$ is first and has no predecessor, so $\mu$ gives $Q_r(e_0, e_{t+1})$, and $h_{t+1} = 0$.
20. Case $D = \mathrm{L}$ and $h_t \ge 1$. The element $e_{h_t}$ is not first, so $\mu$ gives $u$ with $\operatorname{succ}(u, e_{h_t})$, that is, $u = e_{h_t - 1} = e_{h_{t+1}}$.
21. Steps 17 to 20 prove $P(t + 1)$.
22. By $P(N)$, and since $M$ does not halt at step $N$, the axiom for $\delta(q_N, c_N(h_N))$ applies at $x = e_{h_N}$ and time $e_N$.
23. That axiom gives $s$ with $\operatorname{succ}(e_N, s)$. By step 1, $e_N$ has no successor, which is a contradiction.
24. So $M$ halts on $w$.

Step D: conclusion.

25. By steps B and C, $w \mapsto \psi_w$ is a computable [[many-one reduction|JTAH37JTHD]] of the halting set of $M$ to the set of finitely satisfiable $L$-sentences. So this set is not computable.
26. The set of finitely satisfiable $L$-sentences is [[computably enumerable|TN9G24VABN]]. An algorithm lists all $L$-structures with domain $\set{0, \ldots, N}$ for $N = 0, 1, 2, \ldots$, and evaluates the sentence in each one by checking all values of the quantified variables. This proves property 1.
27. An $L$-sentence $\sigma$ is finitely satisfiable if and only if $\neg \sigma$ is not finitely valid.
28. Suppose that the set of finitely valid sentences were computably enumerable. By step 27, the set of sentences that are not finitely satisfiable would be computably enumerable as well.
29. A set that is computably enumerable and has a computably enumerable complement is computable. With step 26, finite satisfiability would be computable, which contradicts step 25.
30. So the set of finitely valid $L$-sentences is not computably enumerable. This proves property 2.

## Idea

A finite structure that obeys the axioms must contain the run of the machine step by step, because each step demands a next time point.
A finite linear order has a last element, so the run must reach a halting configuration before the times run out.
Conversely, a halting run fits into a finite structure whose size is the length of the run.
So halting reduces to finite satisfiability, and the complement argument handles finite validity.

## Variants

- Here the axioms demand a successor time, whereas in the proof of Church's theorem the conclusion $\eta$ asserts a halting configuration. Both versions work for both theorems, with small changes.
- The relations can be coded into one binary relation symbol, which gives the theorem for every signature with a binary relation symbol.
- A stronger form says that the set of sentences with a finite model and the set of sentences with no model at all cannot be separated by a computable set. These two sets are disjoint, and the proof uses a pair of computably inseparable sets in place of the halting set.
