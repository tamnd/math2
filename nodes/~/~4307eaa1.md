## Summary

A Hamiltonian system is a dynamical system given by Hamilton's equations $q' = \partial H / \partial p$, $p' = -\partial H / \partial q$ for a function $H$ of positions and momenta.
Such systems model mechanical systems without friction, such as planetary systems. See the [[definition|~8edd4c55]].

## Remarks

The name honours William Rowan Hamilton.
