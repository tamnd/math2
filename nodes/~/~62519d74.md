## Example

Let $L = \emptyset$, so that $L$-structures are nonempty sets, and let $\mathcal{K}$ be the class of infinite sets.

1. $\mathcal{K}$ is a basic [[pseudo-elementary class|~d3135277]]: with one new unary function symbol $f$, it is the class of reducts of the models of "$f$ is injective and not onto", as checked in [[the definition|~7fafe2f2]].
2. $\mathcal{K}$ is an [[elementary class|MEC3ZMC4F1]], axiomatized by the [[sentences|DKFGQTRYZE]] $\exists^{\ge n} x \, (x = x)$ for $n \ge 1$, each of which says that there are at least $n$ elements.
3. $\mathcal{K}$ is not basic elementary. Suppose that one $L$-sentence $\sigma$ had exactly the infinite sets as models.
4. Then every finite set satisfies $\neg \sigma$, so each finite subset of $\set{\neg \sigma} \cup \set{\exists^{\ge n} x \, (x = x) : n \ge 1}$ has a model.
5. By [[compactness|1NR3HAWG9D]], the whole set has a model, which is infinite and satisfies $\neg \sigma$, a contradiction.

So $\mathcal{K}$ is both $\mathrm{PC}$ and elementary, but it is not basic elementary: one new symbol does what no single $L$-sentence can.

## Remarks

The same compactness argument shows that the class of [[finite sets|~af99cced]] is not pseudo-elementary at all.
The defining sentence in step 1 is Dedekind's definition of an infinite set.
The converse direction, that every infinite set has such a map, uses a countable sequence of distinct elements, and so needs a weak form of the axiom of choice.

## Explanations

### L1 human

A set is infinite if it never runs out.
We cannot say this with one rule about the bare set, but we can if we add a map that moves every element to a new place without collisions and misses at least one element.

### L2 human

On $\mathbb{N}$, take $f(n) = n + 1$: it is injective and misses $0$, so $(\mathbb{N}, f)$ satisfies the defining sentence.
On a finite set $\set{1, \ldots, k}$, an injective map is a permutation, so it is onto, and no expansion works.
A trap is to use "$f$ has no fixed point" instead of "$f$ is not onto": the swap of two elements has no fixed point on a two-element set.
