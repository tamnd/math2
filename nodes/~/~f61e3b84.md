## Example

Let $L = \set{P_i : i \in \N}$ with $P_i$ unary.
Let $M$ be the disjoint union of pairs $\set{a_i, b_i}$, with $P_i^M = \set{a_i, b_i}$.
We show that $M$ fails the [[small index property|~22edb57f]].

1. An automorphism preserves each $P_i$, so it either fixes or swaps each pair. Hence $G = \operatorname{Aut}(M) \cong (\Z/2\Z)^{\N}$.
2. A basic open subgroup is $U_N = \set{g : g \text{ fixes each pair } i < N}$.
3. View $G$ as a vector space over $\mathbb{F}_2$, with $e_N$ the swap of pair $N$ only.
4. The finitely supported vectors form a subspace $W$, and the coordinate sum $s$ is a linear map $W \to \mathbb{F}_2$.
5. Extend $s$ to a linear map $\lambda \colon G \to \mathbb{F}_2$, using a basis of $G$ that extends one of $W$.
6. The kernel $K$ of $\lambda$ has [[index|04QEBF8S49]] $2$.
7. Each $U_N$ contains $e_N$, and $\lambda(e_N) = 1$, so $U_N \not\subseteq K$.
8. So $K$ contains no basic open subgroup, and $K$ is not [[open|4K9RYSNPG3]].

## Remarks

Step 5 uses the axiom of choice, through the existence of a basis; see [[non-constructive existence|JZQVJ9XT63]].
In fact $G$ has $2^{2^{\aleph_0}}$ subgroups of index $2$, while only countably many of them are open.
The structure $M$ is ultrahomogeneous, so homogeneity does not imply SIP.

## Explanations

### L1 human

The symmetries of $M$ are independent swaps of infinitely many pairs.
An index-$2$ subgroup can be built that does not depend on any finite set of pairs.
Such a subgroup is large but not open, so the small index property fails.

### L2 human

We see why the open subgroups of index $2$ are countable in number.

1. An open subgroup $H$ of index $2$ contains some $U_N$.
2. Then $H$ is determined by its image in $G / U_N \cong (\Z/2\Z)^N$, a finite group.
3. There are countably many $N$ and finitely many subgroups for each.

The typical use is as the standard counterexample to SIP.
A trap is to try to write $K$ down explicitly; without choice, it may not exist.
