## Example

Fix $m \geq 1$, a shared variable $p$ and private variables $q_1, \dots, q_m$ of $A$.
Let $A_m = \set{q_1, \dots, q_m, \ \neg q_1 \vee \cdots \vee \neg q_m \vee p}$ and $B = \set{\neg p}$.
[[Craig's theorem|TRS2HY57EG]] gives the interpolant $E_m(p) = \bigvee_{c} A_m(p, c)$, where $c$ runs over all $2^m$ assignments of $q_1, \dots, q_m$.
We check that this method of interpolation is not feasible.

1. **A short refutation.** Resolve the long clause with $q_1$, then the result with $q_2$, and so on up to $q_m$. This gives the clause $p$, and one more step with $\neg p$ gives $\square$. The refutation has $m + 2$ axioms and $m + 1$ resolvents, so $L = 2m + 3$ clauses.
2. **The elimination interpolant is correct.** For every $a$, $E_m(a) = 1$ exactly when $A_m(a, q)$ is satisfiable. If $E_m(a) = 0$, then $A_m(a, q)$ is unsatisfiable. If $E_m(a) = 1$, then $A_m(a, q)$ is satisfiable, so $a = 1$, and $B(1) = \set{\neg 1}$ is unsatisfiable.
3. **Its cost.** Written out, $E_m$ has $2^m$ disjuncts. Evaluating it at $a$ by trying all $c$ takes $2^m$ evaluations of $A_m$. This is exponential in $L$.
4. **A feasible interpolant exists.** The [[interpolation theorem for resolution|~902cba69]] applied to the refutation of step 1 gives a circuit with at most $4L = 8m + 12$ gates. It computes $p$.

So the elimination procedure gives an interpolant, but not one of size polynomial in the refutation.
It is not an instance of feasible interpolation.

## Remarks

The example separates two questions.
Craig's theorem answers "is there an interpolant?", and the answer is always yes.
Feasible interpolation answers "is there an interpolant of size polynomial in a given proof?".

Here only the assignment $c = (1, \dots, 1)$ satisfies the unit clauses $q_1, \dots, q_m$, so $E_m$ is equivalent to $p$.
The elimination formula is large even though the interpolant $p$, a single variable, exists.

If $m$ is fixed, the elimination costs a constant factor $2^m$, and it is feasible for this fixed $m$.
The failure is in the growth with $m$.

## Explanations

### L1 human

One way to find which side fails is to try every value of the private switches of $A$.
With $m$ private switches there are $2^m$ settings to try.
The proof of the conflict has only about $2m$ lines.
So this way takes far more work than the size of the proof, and it does not use the proof at all.

### L2 human

We compare the two methods for $m = 3$.

1. The refutation has $2 \cdot 3 + 3 = 9$ clauses.
2. Elimination tries the $8$ assignments of $q_1, q_2, q_3$.
3. For $m = 30$, the refutation has $63$ clauses, while elimination tries $2^{30}$, more than $10^9$, assignments.

The typical use of the comparison is to explain why feasible interpolation is a property of the proof system, and not of the formulas.
A trap is to think that a large interpolant formula means that no small interpolant exists.
