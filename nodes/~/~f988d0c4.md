## Example

Let $C \colon \C^n \to \C^n$ apply [[complex conjugation|0FTH2E9TAS]] to each coordinate:
$$C(z_1, \dots, z_n) = (\bar z_1, \dots, \bar z_n).$$

1. Additivity: $\overline{z_k + w_k} = \bar z_k + \bar w_k$ for each $k$. So $C(z + w) = C(z) + C(w)$.
2. Twisted homogeneity: $\overline{\lambda z_k} = \bar\lambda\, \bar z_k$ for each $k$. So $C(\lambda z) = \bar\lambda\, C(z)$.
3. By steps 1 and 2, $C$ is [[antilinear|~8c967182]], with $\sigma$ the conjugation of $\C$.
4. $C$ is not $\C$-[[linear|0RJF668P1T]]. With $e_1 = (1, 0, \dots, 0)$, $C(i e_1) = -i e_1$, while $i\,C(e_1) = i e_1$.
5. $C \circ C = \id$, since $\bar{\bar z} = z$. So $C$ is bijective, and the composite of the two antilinear maps is linear.
6. Numerical check in $\C^2$: $C((1 + i)(2, i)) = C(2 + 2i,\ -1 + i) = (2 - 2i,\ -1 - i)$, and $(1 - i)(2, -i) = (2 - 2i,\ -1 - i)$.

## Remarks

- $C$ is linear over $\R$: $C(rz) = r\,C(z)$ for $r \in \R$, since $\bar r = r$.
- Every antilinear map $\C^n \to \C^m$ has the form $z \mapsto A \bar z$ for a unique complex $m \times n$ matrix $A$. Here $A = I$.
- The fixed points of $C$ form $\R^n$, a real subspace that is not a complex subspace.

## Explanations

### L1 human

Conjugation flips the sign of each imaginary part.
It respects sums, but it turns the scalar $i$ into $-i$.
So it is linear over the real numbers but antilinear over the complex numbers.

### L2 human

To recognise an antilinear map, test it on $i v$: an antilinear map gives $-i\,T(v)$.
Conjugation passes this test, and applying it twice gives the identity.
The trap is to call conjugation a linear isomorphism of $\C^n$; it is a real isomorphism, but not a complex one.
