## Example

Suppose that $\square$ is read by a unary truth function $f : \set{0, 1} \to \set{0, 1}$, so that the value of $\square\varphi$ is $f$ of the value of $\varphi$.
Call a formula $f$-valid when it gets value 1 under every assignment of values to the variables.
We show that for no $f$ is the set of $f$-valid formulas equal to the logic $\mathsf{K}$ of [[normal modal logic K|~b1c67ad7]].

1. There are 4 functions $f$: the constant 0, the constant 1, the identity, and the negation.
2. $\mathsf{K} \vdash \square\top$, by [[necessitation|G989VP2NGP]] from the [[tautology|05006AJ7DZ]] $\top$. The value of $\top$ is 1, so $\square\top$ is $f$-valid only when $f(1) = 1$.
3. So the constant 0 and the negation fail: under them $\square\top$ gets value 0, although it is a theorem of $\mathsf{K}$.
4. Under the identity, $\square p \to p$ gets the value of $p \to p$, which is 1. So $\square p \to p$ is $f$-valid.
5. But $\mathsf{K} \nvdash \square p \to p$. On one world without successors and with $V(p) = \varnothing$, $\square p$ is true and $p$ is false, and [[soundness|~d189ee4b]] applies.
6. Under the constant 1, $\square\bot$ gets value 1, so $\square\bot$ is $f$-valid.
7. But $\mathsf{K} \nvdash \square\bot$. On one world $w$ with $w R w$, the formula $\square\bot$ is false at $w$.
8. So each of the 4 choices either misses a theorem of $\mathsf{K}$ or adds a non-theorem.

## Remarks

The example shows that the box of $\mathsf{K}$ is not truth-functional.
[[Kripke semantics|NGHWZ9Y7ZV]] solves this: the value of $\square\varphi$ at $w$ depends on the values of $\varphi$ at other worlds, the successors of $w$.
[[Neighborhood semantics|CN7HK9K1B6]] also makes the value depend on the whole truth set of $\varphi$, not on one truth value.
The identity gives exactly the trivial logic, in which the box is deleted.
The constant 1 gives exactly the verum logic; see [[the trivial logic and the verum logic|~99b8dd16]].
So the two truth tables that respect necessitation describe the two one-world frames.
Dugundji proved in 1940 that none of Lewis's systems $\mathsf{S1}$ to $\mathsf{S5}$ is characterized by a finite matrix.
So for these systems, finitely many truth values do not suffice either.

## Explanations

### L1 human

For "and" and "not", the truth of the whole is fixed by the truth of the parts.
For "necessarily", this is not so.
"Two plus two is four" and "it rains today" may both be true.
The first is necessary and the second is not.
So one cannot compute "necessarily $p$" from the truth value of $p$ alone.

### L2 human

1. Try $f$ equal to the identity on the formula $p \to \square p$.
2. Its value is that of $p \to p$, so it is $f$-valid.
3. On the frame $W = \set{1, 2}$, $R = \set{(1, 2)}$ with $V(p) = \set{1}$, it fails at $1$.
4. So the identity adds the non-theorem $p \to \square p$ as well.

The typical use of this argument is to motivate possible worlds: a non-truth-functional operator needs more than one point of evaluation.
A trap: a truth function can be sound for $\mathsf{K}$, as the identity is, without being complete for it.
