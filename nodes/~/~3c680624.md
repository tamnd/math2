## Statement

Let $M = (S, R, L)$ be a finite [[Kripke structure|RFQ8DJZNQT]] with total transition relation $R$, and let $\varphi$ be a formula of [[CTL|1DA0Y6KDF8]].
The set $[\![\varphi]\!]_M = \set{s \in S : M, s \models \varphi}$ can be computed in time $O(\lvert\varphi\rvert \cdot (\lvert S \rvert + \lvert R \rvert))$.
Here $\lvert\varphi\rvert$ is the number of subformulas of $\varphi$.
In particular, the CTL [[model checking|VNY0VXVZ53]] problem "does $s$ satisfy $\varphi$?" is decidable in polynomial time.

## Remarks

### Why each hypothesis is needed

1. $M$ is finite, so that the sets of states can be stored and the searches terminate.
2. $R$ is total. Otherwise a state without successors has no infinite path, and the clause for $EG$ must be changed. The bound still holds after the change, but the algorithm for $EG$ is different.
3. Each operator is a path quantifier followed by one temporal operator. This makes every subformula a set of states and allows the bottom-up computation. For [[CTL*|~2b6e0b85]] model checking is PSPACE-complete, so no such bound is expected there.

### Consequences

1. Model checking CTL is in P, while model checking LTL is PSPACE-complete, see [[the LTL theorem|~a0f550e4]].
2. When the property fails, the same search gives a witness path or a counterexample path for the outermost operator.
3. The bound is linear in $\lvert S \rvert$, but $\lvert S \rvert$ is often exponential in the size of a program. This is the state explosion problem, attacked with symbolic methods.

### Generalizations

1. Fairness constraints, given as sets of states that a path must visit infinitely often, can be added. The time is then $O(\lvert\varphi\rvert \cdot (\lvert S \rvert + \lvert R \rvert) \cdot k)$ for $k$ constraints.
2. Symbolic model checking, by Burch, Clarke, McMillan, Dill and Hwang (1990), computes the same fixpoints on binary decision diagrams.
3. The modal [[mu-calculus|MZ0M2KR9S0]] has the same bottom-up method, with one fixpoint iteration per fixpoint operator.

## History

Clarke and Emerson gave a polynomial-time algorithm for CTL in 1981.
Clarke, Emerson and Sistla gave the algorithm with time linear in $\lvert M \rvert \cdot \lvert\varphi\rvert$ in ACM TOPLAS in 1986.

## Explanations

### L1 human

To check a CTL formula, a computer labels each state with the parts of the formula that hold there.
It starts with the smallest parts and works outward.
Each part needs one pass over the states and the moves.
So the work grows like the size of the system times the size of the formula.

### L2 human

To compute $[\![ E[p \, U \, q] ]\!]$:

1. Mark all $q$-states.
2. Repeatedly mark each $p$-state that has an edge into a marked state.
3. Stop when nothing changes. Each edge is looked at once, if we follow the edges backwards from the newly marked states.

A trap: the bound counts edges as well as states, so a dense structure with $\lvert S \rvert^2$ edges costs $\lvert S \rvert^2$ per subformula.

### L3 human

The algorithm computes the least fixpoint for $EU$ by backward reachability, and the greatest fixpoint for $EG$ through strongly connected components.
In the [[mu-calculus|MZ0M2KR9S0]], CTL lies in the alternation-free fragment, and that fragment has linear-time model checking.
