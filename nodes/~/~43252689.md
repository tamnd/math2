## Example

A real number is [[algebraic|0MNF0BYFQC]] if it is a root of a nonzero [[polynomial|N2EY1EVPRB]] with integer coefficients.
A real number that is not algebraic is [[transcendental|0VTQXTCR2G]].
We prove by a [[counting argument|~0ba16916]] that a real transcendental number exists.

1. Let $p(x) = a_0 + a_1 x + \cdots + a_d x^d$ have integer coefficients, degree $d \ge 1$ and $a_d \ne 0$.
2. Define the height of $p$ as $h(p) = d + \abs{a_0} + \abs{a_1} + \cdots + \abs{a_d}$. It is a positive integer.
3. For a fixed integer $N$, a polynomial of height $N$ has $d \le N$ and $\abs{a_i} \le N$ for each $i$. So there are only finitely many polynomials of height $N$.
4. Each such polynomial has at most $d$ real roots. Let $A_N$ be the finite set of all real roots of the polynomials of height $N$.
5. Every real algebraic number lies in some $A_N$, because its polynomial has some height. So the set $A$ of real algebraic numbers is $A_2 \cup A_3 \cup A_4 \cup \cdots$.
6. List the elements of $A_2$, then the new elements of $A_3$, then the new elements of $A_4$, and so on. Each algebraic number appears in this list at a finite position, so $A$ is countable.
7. The real numbers are [[uncountable|0518MM6BE1]]. So $A \ne \R$, and some real number is not algebraic.

We check the first sets of the list.

1. Height $2$: only $x$ and $-x$. So $A_2 = \set{0}$.
2. Height $3$: the $8$ polynomials $\pm 2x$, $\pm x \pm 1$ and $\pm x^2$. So $A_3 = \set{-1, 0, 1}$.
3. Height $4$: $22$ polynomials, for example $2x - 1$, $x + 2$ and $x^2 - 1$. Their real roots give $A_4 = \set{-2, -1, -\tfrac{1}{2}, 0, \tfrac{1}{2}, 1, 2}$.
4. The number $\sqrt{2}$ is a root of $x^2 - 2$, which has height $2 + 2 + 0 + 1 = 5$. So $\sqrt{2}$ first appears in $A_5$.

## Remarks

The example shows the main feature of a counting argument: it proves existence and names no transcendental number.
It proves more than existence.
Since $A$ is countable and $\R$ is uncountable, the set $\R \setminus A$ is uncountable, so most real numbers are transcendental.

Step 6 is an explicit list, so the proof needs no choice principle.
The general fact that a [[countable union of countable sets|0Z8FM54P86]] is countable uses the axiom of countable choice, but here the height gives the order directly.
A proof that a specific number such as $e$ or $\pi$ is transcendental needs analysis, and it is much harder.

## Explanations

### L1 human

Some numbers, like $\sqrt{2}$, are solutions of simple equations with whole-number coefficients.
We can write all these equations in one long list, in order of their size.
So we can also list all their solutions, one after another.
But Cantor proved that the real numbers cannot be put in one list.
So some real number is missing from the list, and it is not the solution of any such equation.

### L2 human

We find the position of $\tfrac{1}{3}$ in the list of algebraic numbers.

1. The number $\tfrac{1}{3}$ is a root of $3x - 1$, which has height $1 + 1 + 3 = 5$.
2. By Gauss's lemma, an integer polynomial $p$ with root $\tfrac{1}{3}$ is $(3x - 1)q(x)$ for an integer polynomial $q$. So the leading coefficient of $p$ is a multiple of $3$.
3. The polynomial $p$ also has a second nonzero coefficient, because a single term $a x^d$ has only the root $0$. So $h(p) \ge 1 + 3 + 1 = 5$.
4. So $\tfrac{1}{3}$ is not in $A_2$, $A_3$ or $A_4$, and it first appears in $A_5$.

The typical use is the comparison "countable set inside an uncountable set".
A trap is to think that the argument finds a transcendental number.
It shows only that the list of algebraic numbers cannot contain every real number.
