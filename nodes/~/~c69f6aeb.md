## Definition

A [[set|~bd92ceee]] $A$ is countably infinite when there is a [[bijective function|~14a2ca3d]] $f \colon \mathbb{N} \to A$.

## Remarks

Another name is denumerable. Its cardinality is [[aleph-null|~154686c0]].
Examples are $\mathbb{N}$, $\mathbb{Z}$ and $\mathbb{Q}$, and also the set of primes.
A set is countably infinite exactly when it is [[countable|~589c0629]] and [[infinite|~f9aa0fb0]].

## Explanations

### L1 human

A countably infinite set can be listed as $a_0, a_1, a_2, \dots$ without end, and each element appears exactly one time.
The integers have such a list: $0, 1, -1, 2, -2, \dots$.
