## Example

We give an explicit tree of positive measure, in the sense of [[WWKL0|~def26058]], and compute its levels.
Split $\N$ into consecutive blocks $B_1, B_2, B_3, \dots$, where $B_i$ has $i + 1$ elements and starts at $(i - 1)(i + 2)/2$.
So $B_1 = \set{0, 1}$, $B_2 = \set{2, 3, 4}$, $B_3 = \set{5, 6, 7, 8}$, and $B_4$ starts at $9$.
Let $T$ be the set of strings $\sigma$ such that no block $B_i \subseteq \set{0, \dots, \abs{\sigma} - 1}$ has $\sigma(j) = 1$ for all $j \in B_i$.

1. $T$ is computable, since for a given $\sigma$ only the finitely many blocks inside $\set{0, \dots, \abs{\sigma} - 1}$ need checking.
2. $T$ is a tree. If $\rho \preceq \sigma$, every block inside $\set{0, \dots, \abs{\rho} - 1}$ is also inside $\set{0, \dots, \abs{\sigma} - 1}$, and $\rho$ and $\sigma$ agree on it. So a forbidden block in $\rho$ is also a forbidden block in $\sigma$.
3. Fix $n$ and let $B_1, \dots, B_m$ be the blocks inside $\set{0, \dots, n - 1}$. A string of length $n$ is in $T$ if and only if, on each $B_i$ with $i \le m$, it takes one of the $2^{i+1} - 1$ values other than all ones. The other positions are free.
4. So $\abs{T_n} / 2^n = \prod_{i=1}^{m} (1 - 2^{-(i+1)})$.
5. For example, $\abs{T_2} = 3$, $\abs{T_5} = 3 \cdot 7 = 21$, and $\abs{T_9} = 3 \cdot 7 \cdot 15 = 315$, so the ratios are $\tfrac{3}{4}$, $\tfrac{21}{32}$ and $\tfrac{315}{512} \approx 0.615$.
6. For numbers $a_1, \dots, a_m$ in $[0, 1]$, induction on $m$ gives $\prod_{i=1}^{m} (1 - a_i) \ge 1 - \sum_{i=1}^{m} a_i$.
7. With $a_i = 2^{-(i+1)}$, the sum is less than $\sum_{i \ge 1} 2^{-(i+1)} = \tfrac{1}{2}$. So $\abs{T_n} / 2^n \ge \tfrac{1}{2}$ for every $n$.
8. So $T$ has positive measure with $q = \tfrac{1}{2}$, and it is an instance of the hypothesis of [[weak weak König's lemma|~7de8ca26]].
9. The sequence $0, 0, 0, \dots$ is a path: no block of it is all ones.

## Remarks

The measure of the set of paths is the infinite product $\prod_{k \ge 2} (1 - 2^{-k}) \approx 0.5776$.
Here $\mathsf{RCA}_0$ already proves that $T$ has a path, because the path of step 9 is computable.
The tree is a model case for the reversals of measure theory: each block is a small open set to avoid, and the sum of their measures stays below $1$.
Positive measure follows from the bound on the sum alone, in step 7, without the exact product.

## Explanations

### L1 human

Flip a coin forever, and group the flips into blocks of $2$, $3$, $4$, $\dots$ flips.
A sequence loses if some block comes up all heads.
The chance to lose on block $i$ is $2^{-(i+1)}$, and these chances add up to $\tfrac{1}{2}$.
So the chance to survive is at least one half, and the tree of surviving starts has positive measure.
The sequence of all tails survives.

### L2 human

We check step 3 at length $n = 5$.

1. The blocks inside $\set{0, 1, 2, 3, 4}$ are $B_1 = \set{0, 1}$ and $B_2 = \set{2, 3, 4}$.
2. On $B_1$ the string may take $00$, $01$ or $10$, which is $3$ choices.
3. On $B_2$ it may take any of the $8$ values except $111$, which is $7$ choices.
4. So $\abs{T_5} = 21$ and $\abs{T_5} / 2^5 = \tfrac{21}{32} \ge \tfrac{1}{2}$.

The typical use: trees of this kind come from a sequence of intervals of small total length, as in the reversal of countable additivity.
The trap: if the blocks had length $1$, the losing chances would add up to infinity, and the ratio $\abs{T_n} / 2^n$ would tend to $0$.

### L3 human

The set of paths is a closed subset of Cantor space, the complement of the union of the open sets $\set{X : X(j) = 1 \text{ for all } j \in B_i}$.
Steps 6 and 7 are the subadditivity of measure in a finite form, which $\mathsf{RCA}_0$ proves.
The reversals that reach $\mathsf{WWKL}_0$ run this argument backwards: a tree of positive measure is turned into a sequence of open sets of small total measure.
