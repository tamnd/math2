## Example

Let $\mathfrak{M} = (W, R, V)$ with $W = \{0, 1, 2, 3, 4\}$,
$$R = \{(0, 1), (1, 0), (0, 2), (2, 3), (3, 4), (4, 4)\},$$
and $V(p) = \{0, 1, 2, 3\}$.
We compute $\|\nu X . (p \wedge \lozenge X)\|$ in the [[modal mu-calculus|MZ0M2KR9S0]].
Write $g(T) = V(p) \cap \mathrm{pre}(T)$, where $\mathrm{pre}(T) = \set{w : w R v \text{ for some } v \in T}$.
By the [[definition|5BXYE8REDN]], the formula denotes the greatest fixed point of $g$, and on a finite model we reach it by iteration from $W$.

1. $T_0 = W = \{0, 1, 2, 3, 4\}$.
2. Every world has a successor, so $\mathrm{pre}(W) = W$, and $T_1 = V(p) \cap W = \{0, 1, 2, 3\}$.
3. $\mathrm{pre}(\{0, 1, 2, 3\}) = \{0, 1, 2\}$: $0 R 1$, $1 R 0$, $2 R 3$, while the only successor of $3$ is $4$ and the only successor of $4$ is $4$. So $T_2 = \{0, 1, 2\}$.
4. $\mathrm{pre}(\{0, 1, 2\}) = \{0, 1\}$: $0 R 1$ and $1 R 0$, while the only successor of $2$ is $3$. So $T_3 = \{0, 1\}$.
5. $\mathrm{pre}(\{0, 1\}) = \{0, 1\}$, so $T_4 = \{0, 1\} = T_3$, and $\{0, 1\}$ is a fixed point.
6. It is the greatest one: if $g(T) = T$, then $T = g(T) \subseteq g(W) = T_1$, and by monotonicity of $g$ we get $T \subseteq T_k$ for every $k$, so $T \subseteq T_3$.

So $\|\nu X . (p \wedge \lozenge X)\| = \{0, 1\}$.
These are exactly the worlds where an infinite path through $p$-worlds starts: the path $0, 1, 0, 1, \dots$ and the path $1, 0, 1, 0, \dots$.

## Remarks

World $2$ has the $p$-path $2, 3$, but every continuation goes to $4$, where $p$ is false.
World $3$ has an infinite path $3, 4, 4, \dots$, but it leaves the $p$-worlds at once.
The least fixed point of the same map is empty: $g(\emptyset) = \emptyset$, since no world has a successor in $\emptyset$.
So the choice of $\nu$ is what makes the formula speak about infinite behaviour.
If we remove the pair $(1, 0)$ from $R$, world $1$ has no successor, and the greatest fixed point becomes empty.

## Explanations

### L1 human

Here $p$ means "the machine is safe", and the arrows are the possible next steps.
The formula asks for a way to run forever and stay safe at every step.
From worlds $0$ and $1$ the machine can go back and forth between $0$ and $1$ forever, and both are safe.
From world $2$ every run reaches world $4$, which is unsafe.

### L2 human

We check that $\{0, 1\}$ is a post-fixed point, $T \subseteq g(T)$, which is what the definition of $\nu$ needs.

1. World $0$: $p$ is true at $0$, and $0 R 1$ with $1 \in T$, so $0 \in g(T)$.
2. World $1$: $p$ is true at $1$, and $1 R 0$ with $0 \in T$, so $1 \in g(T)$.
3. So $T \subseteq g(T)$, and $T$ lies in the greatest fixed point, the union of all post-fixed points.

The typical use of this formula is the property "$p$ holds forever along some path", written $\mathrm{EG}\, p$ in computation tree logic.
A trap: to show that a world is in a greatest fixed point, it is enough to find one post-fixed point that contains it.
To show that a world is not in it, one must run the iteration or give another argument.
