## Definition

Let $P$ be a set of propositional variables, and let $\mathrm{Form}$ be the set of [[propositional formulas|~7139c138]] over $P$.

1. A truth assignment is a function $v : P \to \set{0, 1}$.
2. A truth valuation is a function $V : \mathrm{Form} \to \set{0, 1}$ such that, for all formulas $\varphi$ and $\psi$:
   - $V((\neg \varphi)) = 1 - V(\varphi)$;
   - $V((\varphi \land \psi)) = \min(V(\varphi), V(\psi))$;
   - $V((\varphi \lor \psi)) = \max(V(\varphi), V(\psi))$;
   - $V((\varphi \to \psi)) = \max(1 - V(\varphi), V(\psi))$;
   - $V((\varphi \leftrightarrow \psi)) = 1$ if $V(\varphi) = V(\psi)$, and $V((\varphi \leftrightarrow \psi)) = 0$ otherwise.
3. If the formulas include the constants $\top$ and $\bot$, a truth valuation also satisfies $V(\top) = 1$ and $V(\bot) = 0$.
4. For a truth assignment $v$, the valuation $\bar v$ is the unique truth valuation with $\bar v(p) = v(p)$ for each $p \in P$, and $\bar v(\varphi)$ is the truth value of $\varphi$ under $v$.

## Notation

The five clauses are the [[truth tables|05RSK4Q657]] of the connectives, written as arithmetic on $\set{0, 1}$.
For example, the clause for $\to$ gives the value $0$ only for $V(\varphi) = 1$ and $V(\psi) = 0$.
After the extension theorem we write $v(\varphi)$ for $\bar v(\varphi)$, and $v \models \varphi$ for $v(\varphi) = 1$.

## Remarks

Item 4 is correct as a definition only because each assignment has exactly one extension.
The [[concept page|~41f42e3d]] proves this extension theorem in numbered steps, with the [[unique readability theorem|~26f00b05]].
Item 2 defines valuations without any assignment; the extension theorem then shows that the map $V \mapsto V|_P$ is a bijection from truth valuations to truth assignments.
In the system $L$, with only $\neg$ and $\to$ as primitive connectives, only the first and the fourth clauses are needed, and the other connectives get their values through their definitions.
For example, $\varphi \lor \psi$ abbreviates $\neg \varphi \to \psi$, and $\max(1 - (1 - a), b) = \max(a, b)$ is the table of $\lor$.

## Explanations

### L1 human

A truth assignment says which letters are true.
A truth valuation says which formulas are true, and it must follow the tables of the connectives.
For example, if a valuation makes $p$ true, it must make "not $p$" false.

### L2 human

We check the clause for $\to$ against the truth table.

1. If $V(\varphi) = 1$ and $V(\psi) = 1$, then $\max(0, 1) = 1$.
2. If $V(\varphi) = 1$ and $V(\psi) = 0$, then $\max(0, 0) = 0$.
3. If $V(\varphi) = 0$ and $V(\psi) = 1$, then $\max(1, 1) = 1$.
4. If $V(\varphi) = 0$ and $V(\psi) = 0$, then $\max(1, 0) = 1$.

These are the four rows of the table of implication: false only from true to false.
A trap is to forget that the clauses must hold for all formulas $\varphi$ and $\psi$, not only for variables.
