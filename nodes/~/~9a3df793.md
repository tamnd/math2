## Example

Let $\mathcal{N} = (\N, \mathcal{P}(\N))$ be the $L_2$-structure whose numbers are the natural numbers with the usual $0, 1, +, \cdot, <$, and whose sets are all subsets of $\N$.
We check that $\mathcal{N}$ is a model of [[second-order arithmetic|DC60FYCSPM]], with the axioms of the [[definition|Y92NXGEQBD]].

1. The basic axioms are true statements about the natural numbers. For example, $n + 1 \ne 0$ holds because $0$ is not a successor in $\N$.
2. The axiom $m < n + 1 \leftrightarrow (m < n \vee m = n)$ holds, because no natural number lies strictly between $n$ and $n + 1$.
3. The induction axiom holds. Let $X \subseteq \N$ contain $0$ and be closed under $n \mapsto n + 1$.
4. If $X \ne \N$, then $\N \setminus X$ has a least element $n_0$. Then $n_0 \ne 0$, so $n_0 = m + 1$ with $m \in X$, and closure gives $n_0 \in X$. This is a contradiction, so $X = \N$.
5. The comprehension scheme holds. Let $\varphi(n)$ be any $L_2$-formula, with parameters in $\N$ and in $\mathcal{P}(\N)$.
6. The set $A = \set{n \in \N : \mathcal{N} \models \varphi(n)}$ is a subset of $\N$, so $A \in \mathcal{P}(\N)$.
7. So $A$ witnesses $\exists X\, \forall n\, (n \in X \leftrightarrow \varphi(n))$ in $\mathcal{N}$.
8. Every axiom is true in $\mathcal{N}$, and its number part is standard, so $\mathcal{N}$ is an $\omega$-model of $\mathsf{Z}_2$.
9. Each subsystem, such as [[ATR0|~ff80e550]] or [[Π¹₁-CA0|~0d0109c9]], has only axioms of $\mathsf{Z}_2$, so $\mathcal{N}$ is also a model of each subsystem.
10. A $\Sigma^1_1$ formula with parameters in $\mathcal{P}(\N)$ has the same truth value in $\mathcal{N}$ and in the true sets, because the sets of $\mathcal{N}$ are all the true sets. So $\mathcal{N}$ is a [[β-model|J0Z2GNJZ2W]].

## Remarks

$\mathcal{N}$ is the intended model of $\mathsf{Z}_2$, and it is the largest $\omega$-model: every $\omega$-model has a family $\mathcal{S} \subseteq \mathcal{P}(\N)$.
Step 6 uses that the set domain is the full power set, so the set quantifiers inside $\varphi$ cause no problem.
In a structure with fewer sets, step 6 can fail; the structure of computable sets is such a case.
The set of sentences true in $\mathcal{N}$ is not arithmetical, and by the incompleteness theorems no recursively axiomatized theory proves all of them.

## Explanations

### L1 human

Here every set of natural numbers is allowed.
So every property that the theory can express gives a set, and that set is there.
Induction holds because the natural numbers have no gaps: each number is reached from $0$ by adding $1$.

### L2 human

The proof of step 4 uses the least number principle in the metatheory.
Step 6 needs no work, but it hides a definition by recursion on formulas: truth in $\mathcal{N}$ of a formula with set quantifiers refers to all subsets of $\N$.
A typical use is to show that $\mathsf{Z}_2$ and all its subsystems are consistent, under the assumption that $\mathcal{P}(\N)$ exists.
A trap is to take $\mathcal{N}$ as the only model: by the compactness theorem, $\mathsf{Z}_2$ also has models with non-standard numbers.
