## Example

Let $\operatorname{Prf}(z, y)$ be the [[primitive recursive relation|QQQRJA90EP]] "$z$ codes a PA-proof of the formula with code $y$", and let $A(x)$ be $\neg \operatorname{Prf}(x, \ulcorner 0 = 1 \urcorner)$.
Then $\forall x \, A(x)$ is the [[consistency|VM8TQ70CVJ]] sentence $\operatorname{Con}(\mathrm{PA})$.

1. PA is consistent, so no $n$ codes a PA-proof of $0 = 1$, and each sentence $A(\bar n)$ is true.
2. Each $A(\bar n)$ is a closed instance of a primitive recursive relation. [[Peano arithmetic|0QFT7Z76N5]] proves every true closed instance of a primitive recursive relation, by computing its value.
3. So PA proves $A(\bar 0)$, $A(\bar 1)$, $A(\bar 2)$, and so on.
4. PA does not prove $\forall x \, A(x)$, by [[Gödel's second incompleteness theorem|X9WYNYE29C]].
5. So the premises of one application of the [[ω-rule|~e0034cfd]] are PA-theorems, and its conclusion is not.

## Remarks

The theory $\mathrm{PA} + \neg\operatorname{Con}(\mathrm{PA})$ is consistent but proves $\exists x \, \neg A(x)$ while it also proves every $A(\bar n)$; such a theory is called ω-inconsistent.
Closing PA under the ω-rule gives all true arithmetic sentences, which is not a recursively axiomatized theory.
The example is why the ω-rule is used as a tool for analysing PA from outside, not as a rule of PA.

## Explanations

### L1 human

For each number $n$, Peano arithmetic can check that $n$ is not the code of a proof of a contradiction.
It cannot prove the single statement that no number is such a code, by Gödel's theorem.
So "true for each number separately" does not give "true for all numbers" in Peano arithmetic, and that step is exactly the ω-rule.

### L2 human

We follow one instance.

1. Take a number $n$. Since PA is consistent, $n$ does not code a PA-proof of $0 = 1$.
2. PA evaluates $\operatorname{Prf}(\bar n, \ulcorner 0 = 1 \urcorner)$ to false in finitely many steps, so it proves $A(\bar n)$.
3. The same works for every $n$, but each $n$ needs its own proof, and the proofs get longer as $n$ grows.

The typical use is to show that a formal theory cannot contain the ω-rule if it is recursively axiomatized and consistent.
The trap: the infinitely many proofs in step 3 do not combine into one proof, since a proof is finite and must cover all $n$ by one argument.
