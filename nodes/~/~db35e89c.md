## Definition

Fix a propositional or first-order language, and let $\mathrm{Cn}(S)$ be the set of sentences that are classical [[consequences|1HK0VYWTV7]] of $S$.

1. A *default* is an expression $(\gamma : \theta)/\tau$, where $\gamma$, $\theta$ and $\tau$ are sentences.
2. A *default theory* is a pair $T = (W, D)$, where $W$ is a set of sentences and $D$ is a set of defaults.
3. For a set $E$ of sentences, $\Gamma_T(E)$ is the smallest set $S$ of sentences with these three properties:
   - $W \subseteq S$;
   - $\mathrm{Cn}(S) = S$;
   - for every $(\gamma : \theta)/\tau \in D$, if $\gamma \in S$ and $\neg\theta \notin E$, then $\tau \in S$.
4. A set $E$ is an *extension* of $T$ if $\Gamma_T(E) = E$.
5. A sentence $\varphi$ is a *skeptical consequence* of $T$ if it belongs to every extension, and a *credulous consequence* if it belongs to some extension.

## Notation

$\mathrm{Ext}(T)$ is the set of extensions of $T$.
We say that a default $(\gamma : \theta)/\tau$ is *blocked* by $E$ if $\neg\theta \in E$.
Reiter's original definition allows several justifications $\theta_1, \ldots, \theta_n$; the default is blocked if some $\neg\theta_i \in E$.

## Remarks

- $\Gamma_T(E)$ exists: the intersection of all sets with the three properties has them again, because $E$ is fixed in the third property.
- Equivalently, $E$ is an extension if and only if $E = \bigcup_{i} E_i$, where $E_0 = W$ and $E_{i+1} = \mathrm{Cn}(E_i) \cup \set{\tau : (\gamma : \theta)/\tau \in D,\ \gamma \in E_i,\ \neg\theta \notin E}$.
  The set $E$ occurs on the right side, so this is a [[fixed-point|R6QVS6P21N]] condition, not a recursive construction.
- $\Gamma_T$ is antitone: if $E \subseteq E'$, then $\Gamma_T(E') \subseteq \Gamma_T(E)$.
  The set $\Gamma_T(E)$ has the three properties for $E'$, since $\neg\theta \notin E'$ implies $\neg\theta \notin E$.
- Extensions are minimal: if $E \subseteq E'$ are extensions, then $E' = \Gamma_T(E') \subseteq \Gamma_T(E) = E$.
- An extension $E$ is inconsistent if and only if $W$ is inconsistent.
  If $E$ is inconsistent, every default is blocked, so $E = \Gamma_T(E) = \mathrm{Cn}(W)$.
  If $W$ is inconsistent, every extension contains $\mathrm{Cn}(W)$, the set of all sentences.
- The test $\neg\theta \notin E$ says that $\theta$ is consistent with $E$, because $E$ is deductively closed; see [[consistency|VM8TQ70CVJ]] and [[deductive closure|CT4FZ84V45]].

## Explanations

### L1 human

An extension is a set of beliefs that is stable under the rules of thumb.
We guess a set of beliefs, use it to see which rules are blocked, and apply the other rules to the facts.
If we get back exactly the guess, the guess is an extension.

### L2 human

The definition has two roles for $E$: it decides which defaults are blocked, and it must equal the result.
To check a candidate, compute $\Gamma_T(E)$ in two steps: list the defaults not blocked by $E$, then close $W$ under logic and those defaults.
A trap is to check consistency against $W$ or against a partial result; the check uses the candidate $E$.

### L3 human

Since $\Gamma_T$ is antitone, $\Gamma_T \circ \Gamma_T$ is monotone, and every extension lies between its least and its greatest fixed point.
Every extension $E$ equals $\mathrm{Cn}(W \cup \set{\tau_d : d \in D'})$, where $\tau_d$ is the conclusion of $d$ and $D'$ is the set of defaults that $E$ applies.
So for finite $D$, a search over the subsets of $D$ finds all extensions.
