## Description

The fast-growing hierarchy is a family of functions $f_\alpha : \N \to \N$, one for each ordinal $\alpha \le \varepsilon_0$.
It needs a [[fundamental sequence|VB6YXF761M]] $\lambda[0] < \lambda[1] < \cdots$ with supremum $\lambda$ for each limit ordinal $\lambda \le \varepsilon_0$.

**The standard fundamental sequences.**
Every ordinal $\alpha < \varepsilon_0$ has a [[Cantor normal form|6GD30FGYDZ]] $\alpha = \omega^{\alpha_1} + \cdots + \omega^{\alpha_k}$ with $\alpha_1 \ge \cdots \ge \alpha_k$.
Then $\alpha$ is a limit ordinal exactly when $k \ge 1$ and $\alpha_k > 0$.
For such $\alpha$ and $x \in \N$, write $\gamma = \omega^{\alpha_1} + \cdots + \omega^{\alpha_{k-1}}$, and define $\alpha[x]$ as follows.

1. If $\alpha_k = \beta + 1$, then $\alpha[x] = \gamma + \omega^\beta \cdot x$.
2. If $\alpha_k$ is a limit ordinal, then $\alpha[x] = \gamma + \omega^{\alpha_k[x]}$.
3. For [[epsilon nought|KT50SMH3EC]], $\varepsilon_0[0] = 0$ and $\varepsilon_0[x+1] = \omega^{\varepsilon_0[x]}$.

So $\omega[x] = x$, $\omega^2[x] = \omega \cdot x$, $\omega^\omega[x] = \omega^x$, and $\varepsilon_0[1] = 1$, $\varepsilon_0[2] = \omega$, $\varepsilon_0[3] = \omega^\omega$.

**The functions.**
Write $g^x$ for the $x$-fold iterate of $g$, with $g^0(x) = x$.

- $f_0(x) = x + 1$.
- $f_{\alpha + 1}(x) = f_\alpha^x(x)$.
- $f_\lambda(x) = f_{\lambda[x]}(x)$ for a limit ordinal $\lambda$.

This is a definition by transfinite recursion on $\alpha$, because $\lambda[x] < \lambda$.
With the sequences above it is called the *Wainer hierarchy*.

## Remarks

### First values

Each line is a direct calculation from the definition.

- $f_1(x) = f_0^x(x) = x + x = 2x$, because each application of $f_0$ adds $1$.
- $f_2(x) = f_1^x(x) = 2^x \cdot x$, because each application of $f_1$ doubles. So $f_2(0), \dots, f_2(4)$ are $0, 2, 8, 24, 64$.
- $f_3(2) = f_2(f_2(2)) = f_2(8) = 2^8 \cdot 8 = 2048$.
- $f_\omega(x) = f_{\omega[x]}(x) = f_x(x)$. So $f_\omega(0) = f_0(0) = 1$, $f_\omega(1) = f_1(1) = 2$ and $f_\omega(2) = f_2(2) = 8$.
- $f_{\varepsilon_0}(0) = f_0(0) = 1$, $f_{\varepsilon_0}(1) = f_1(1) = 2$ and $f_{\varepsilon_0}(2) = f_\omega(2) = 8$.
- $f_{\varepsilon_0}(3) = f_{\omega^\omega}(3) = f_{\omega^3}(3)$, a number far too large to write down.

### Growth

The Wikipedia article lists these facts for the Wainer hierarchy.

- Every $f_\alpha$ is total and [[computable|KZSB5E471K]].
- If $\alpha < \beta$, then $f_\beta$ eventually dominates $f_\alpha$: $f_\alpha(x) < f_\beta(x)$ for all large enough $x$.
- Every [[primitive recursive function|5NVA2JRHPV]] is dominated by some $f_n$ with $n < \omega$. So $f_\omega$ dominates them all, and it is a variant of the [[Ackermann function|N470JF7ZJX]].
- Every $f_\alpha$ with $\alpha < \varepsilon_0$ is [[provably total|~25aedb3b]] in [[Peano arithmetic|MPSCREYC3M]] $\mathsf{PA}$.
- Every function that $\mathsf{PA}$ proves total is dominated by some $f_\alpha$ with $\alpha < \varepsilon_0$. So $f_{\varepsilon_0}$ is [[not provably total in PA|~4e374acd]].

### The theory and the stronger theory

$\mathsf{PA}$ does not prove that $f_{\varepsilon_0}$ is total, but $\mathsf{ZFC}$ proves it by transfinite recursion on $\alpha$.
$\mathsf{PA}$ with [[transfinite induction|0ZHQMQ2C1N]] up to $\varepsilon_0$ also proves it.
The induction is on $\alpha \le \varepsilon_0$ for the formula "$f_\alpha$ is total", with an ordinary induction on the number of iterations at successor steps.

### Relation to other hierarchies

- The [[Hardy hierarchy|~ec594377]] satisfies $f_\alpha = H_{\omega^\alpha}$ for every $\alpha < \varepsilon_0$, and it measures the length of Goodstein sequences and hydra battles.
- The [[slow-growing hierarchy|~073644c1]] grows much more slowly: $g_{\varepsilon_0}$ is of the order of $f_3$ only.

### Dependence on the fundamental sequences

The values depend on the choice of the sequences.
Some authors take $\varepsilon_0[0] = 1$ and $\varepsilon_0[x+1] = \omega^{\varepsilon_0[x]}$.
Then $\varepsilon_0[2] = \omega^\omega$, and $f_{\varepsilon_0}(2) = f_{\omega^\omega}(2) = f_{\omega + 2}(2)$, which is larger than $f_8(8)$.
Other authors use $\omega^{\beta+1}[x] = \omega^\beta \cdot (x + 1)$.
The domination facts above are stated for the standard sequences.

### History

The hierarchy is also called the Schwichtenberg-Wainer hierarchy, after Helmut Schwichtenberg and Stanley Wainer.
Its finite levels $f_n$ correspond to the levels of the Grzegorczyk hierarchy of primitive recursive functions.

### Common errors

- "$f_{\varepsilon_0}$ is not provably total in $\mathsf{PA}$" does not mean that $f_{\varepsilon_0}$ is not computable. It is computable, and $\mathsf{ZFC}$ proves that it is total.
- The small values say nothing about growth: $f_{\varepsilon_0}(2) = f_2(2) = 8$. Domination is a statement about all large arguments.

## Explanations

### L1 human

The fast-growing hierarchy is a ladder of functions, and each rung grows much faster than the one below.
The first rung adds one, the next rung doubles, and the next one roughly takes powers of two.
For example the third rung sends $2$ to $2048$.
After all the finite rungs come rungs labelled by infinite ordinals, which mix the earlier rungs.
The rung labelled $\varepsilon_0$ grows so fast that ordinary arithmetic cannot prove that it always gives an answer.

### L2 human

A worked calculation of $f_3(2)$ and $f_{\varepsilon_0}(2)$.

1. $f_1(x) = 2x$, since $f_1(x)$ applies $x \mapsto x + 1$ exactly $x$ times to $x$.
2. $f_2(x) = 2^x \cdot x$, since $f_2(x)$ doubles $x$ exactly $x$ times. So $f_2(2) = 8$.
3. $f_3(2) = f_2(f_2(2)) = f_2(8) = 256 \cdot 8 = 2048$.
4. $\varepsilon_0[2] = \omega^{\varepsilon_0[1]} = \omega^1 = \omega$, so $f_{\varepsilon_0}(2) = f_\omega(2)$.
5. $\omega[2] = 2$, so $f_\omega(2) = f_2(2) = 8$.

The typical use is as a ruler: to show that a theory does not prove "$\forall x\, \exists y\, \varphi(x, y)$", show that the least $y$ grows faster than every $f_\alpha$ with $\alpha$ below the ordinal of the theory.
The trap: the hierarchy depends on the fundamental sequences, so a value such as $f_{\varepsilon_0}(2)$ is only meaningful with a stated choice.

### L3 human

The hierarchy turns ordinals into growth rates.
For a theory with an [[ordinal analysis|C5E5TG8PGP]], the provably total functions are usually those dominated by some $f_\alpha$ with $\alpha$ below its [[proof-theoretic ordinal|C72RBH0CDR]].
For $\mathsf{PA}$ this ordinal is $\varepsilon_0$, which is the boundary in the [[Paris-Harrington theorem|509ZWA0R26]] and in [[Goodstein's theorem|XQMNJF241J]].
Beyond $\varepsilon_0$ the fundamental sequences come from ordinal notations such as the [[Veblen function|6QFEVWKE25]], and the Wikipedia article states that the function $\mathrm{TREE}$ of [[Friedman's finite form of Kruskal's theorem|~0c69c0b2]] dominates $f_{\Gamma_0}$.
