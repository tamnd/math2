## Summary

A *first-order Gödel logic* is the set of first-order sentences that get the value $1$ in every structure with truth values in a set $V \subseteq [0, 1]$.
The connectives are those of [[Gödel-Dummett logic|474SGS2N0X]]: $\min$, $\max$, the Gödel implication, and $\neg x = x \to 0$.
The quantifiers $\forall$ and $\exists$ are the infimum and supremum over the domain.
For $V = [0, 1]$ this is the first-order Gödel logic $\mathrm{G}\forall$, which Horn axiomatized in 1969.
Unlike the propositional case, the first-order logic depends on $V$, and not only on whether $V$ is finite.

## Motivation

In Gödel logic the value of a propositional formula depends only on the order of the values of its variables, as SEP states.
So all infinite subsets of $[0, 1]$ that contain $0$ and $1$ give the same propositional logic.
Quantifiers compute infima and suprema, and these depend on the order type of $V$: whether a set of values has a least element, and whether $0$ is a limit.
So first-order Gödel logics separate truth value sets that propositional logic cannot separate.

## Notation

Let $V \subseteq [0, 1]$ be closed, with $0, 1 \in V$.
A *$V$-structure* $\mathfrak{M}$ has a non-empty domain $M$ and, for each $n$-ary predicate $P$, a map $P^{\mathfrak{M}} \colon M^n \to V$.
Values of formulas are computed as in Mostowski's semantics, with the Gödel operations on $V$ and with $\inf$ and $\sup$ for $\forall$ and $\exists$.
$\mathrm{G}_V$ is the set of sentences with value $1$ in every $V$-structure.
The closedness of $V$ makes all infima and suprema of subsets of $V$ lie in $V$.

## Remarks

### Examples

1. [[The constant domain axiom is valid in every first-order Gödel logic|~98782e35]]: $\forall x (p \lor Q(x)) \to (p \lor \forall x Q(x))$ has value $1$ for every $V$.
2. [[A sentence that separates truth value sets|~429872cb]]: $\exists x (P(x) \to \forall y P(y))$ is in $\mathrm{G}_V$ iff every non-empty subset of $V$ has a least element.
3. SEP notes that $\neg \neg \forall x P(x) \to \forall x \neg \neg P(x)$ and $\forall x (P(x) \to \exists y P(y))$ are valid in first-order Gödel logic.
4. [[The Gödel chain on the unit interval|BHR2YXEQZT]] is the propositional part of $\mathrm{G}_{[0, 1]}$.

### Non-examples

1. [[Intuitionistic predicate logic is not a Gödel logic|~035eafc2]]: it refutes prelinearity and the constant domain axiom.
2. Classical first-order logic is not $\mathrm{G}_{[0, 1]}$: SEP notes that $\forall x \neg \neg P(x) \to \neg \neg \forall x P(x)$ is classically valid and not valid over $[0, 1]$.
   With $P(n) = \tfrac{1}{n+1}$ on $\mathbb{N}$, the antecedent is $1$ and the consequent is $\neg \neg 0 = 0$.

### Basic properties

1. Every first-order Gödel logic extends [[intuitionistic predicate logic|MW0RVDRFTA]] with prelinearity and the constant domain axiom.
2. SEP (many-valued logic) states that $\mathrm{G}_{[0, 1]}$ has a finite axiomatization due to Horn (1969).
3. SEP (fuzzy logic) states that the Hilbert system for first-order Gödel-Dummett logic is strongly complete for its semantics.
4. SEP states that almost no logic of a class of continuous t-norms is recursively axiomatizable at the first-order level, and that Gödel logic is the sole exception.
5. If $V$ is finite with $n$ elements, $\mathrm{G}_V$ is the first-order logic of the $n$-element Gödel chain, and it contains $\exists x (P(x) \to \forall y P(y))$.

### History

SEP reports that Mostowski proposed the lattice-valued semantics of quantifiers in 1961, and that Horn gave a finite axiomatization of first-order Gödel logic in 1969.
SEP also cites the survey of Gödel-Dummett logics by Baaz and Preining (2011) in the Handbook of Mathematical Fuzzy Logic.

### Common errors

1. Assuming that every infinite $V$ gives the same first-order logic, as in the propositional case. [[The separating sentence|~429872cb]] refutes this.
2. Reading $\forall$ as a minimum. Over an infinite domain the infimum need not be attained, and this is the source of the dependence on $V$.
3. Identifying first-order Gödel logic with intuitionistic logic plus prelinearity. The constant domain axiom is an extra law.

## Explanations

### L1 human

Gödel logic measures truth by degrees, and it cares only about which statement is truer.
"For all $x$" takes the lowest degree over all $x$, and "there is an $x$" takes the highest.
With infinitely many objects, the lowest degree may only be approached and never reached.
Then the choice of allowed degrees changes which sentences are always true.

### L2 human

To test a sentence in $\mathrm{G}_V$, build a structure whose atomic values form a set without a least element, if $V$ allows one.
A decreasing sequence such as $\tfrac{1}{n+1}$, approaching $0$, is the typical tool.
A trap: in $V = \set{1 - \tfrac1n : n \ge 1} \cup \set{1}$ there is no strictly decreasing sequence, so this tool is not available there.

### L3 human

A $V$-structure is a model over the complete Heyting chain $V$, so intuitionistic predicate logic is sound for it.
If $V$ and $V'$ are order isomorphic, then $\mathrm{G}_V = \mathrm{G}_{V'}$, since the Gödel operations, $\inf$ and $\sup$ are defined from the order alone.
