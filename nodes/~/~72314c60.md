## Proof

Let $\mathcal{P} = \prod_{i \in I} \mathcal{M}_i / \mathcal{U}$, let $A \subseteq P$, and let $p(x)$ be a [[type|9V71Q3SD1G]] over $A$, so every finite part of $p$ is satisfied in $\mathcal{P}$.
Fix a representative $a(i)$ for each parameter, and fix $X_0 \supseteq X_1 \supseteq \dots$ in $\mathcal{U}$ with $X_0 = I$ and empty intersection.
For a finite set $\Phi$ of formulas let $E(\Phi) = \set{i \in I : \mathcal{M}_i \models \exists x \bigwedge \Phi}$, with parameters read at $i$.
Since $\mathcal{P} \models \exists x \bigwedge \Phi$, [[Łoś's theorem|AGYBSTD7BG]] gives $E(\Phi) \in \mathcal{U}$.

1. *Part 1.* Now $L$ and $A$ are countable, so $p$ is countable; list it as $\varphi_0, \varphi_1, \dots$, repeating a formula if $p$ is finite.
2. Let $Z_n = X_n \cap E(\set{\varphi_0, \dots, \varphi_n})$. Then $Z_n \in \mathcal{U}$, the sets $Z_n$ decrease, and their intersection is empty.
3. For $i \in Z_0$ let $n(i)$ be the largest $n$ with $i \in Z_n$; it exists because $i$ leaves some $X_n$. Choose $b(i)$ satisfying $\varphi_0, \dots, \varphi_{n(i)}$ in $\mathcal{M}_i$, which is possible since $i \in E(\set{\varphi_0, \dots, \varphi_{n(i)}})$.
4. For $i \notin Z_0$ let $b(i)$ be any element. These choices use the [[axiom of choice|0HTGB13FE2]].
5. Fix $k$. If $i \in Z_k$, then $n(i) \ge k$, so $\mathcal{M}_i \models \varphi_k(b(i))$. The truth set of $\varphi_k$ contains $Z_k \in \mathcal{U}$.
6. By Łoś's theorem, $[b]$ satisfies every $\varphi_k$, so it realizes $p$.
7. *Part 2.* Now $\abs{A} < \kappa$ and $\abs{L} < \kappa$ with $\kappa$ uncountable, so $p$ has $\alpha < \kappa$ formulas; list them as $\varphi_\beta$, $\beta < \alpha$.
8. For a finite $s \subseteq \alpha$ let $f(s) = X_{\abs{s}} \cap E(\set{\varphi_\beta : \beta \in s})$. It lies in $\mathcal{U}$, and $s \subseteq t$ gives $f(t) \subseteq f(s)$.
9. Goodness gives $g \le f$ into $\mathcal{U}$ with $g(s \cup t) = g(s) \cap g(t)$. For $i \in I$ let $s(i) = \set{\beta < \alpha : i \in g(\set{\beta})}$.
10. If $t \subseteq s(i)$ is finite and nonempty, then $i \in g(t) \subseteq f(t) \subseteq X_{\abs{t}}$. Since $i \notin X_m$ for some $m$, every such $t$ has fewer than $m$ elements, so $s(i)$ is finite.
11. If $s(i) \neq \emptyset$, step 10 with $t = s(i)$ gives $i \in E(\set{\varphi_\beta : \beta \in s(i)})$. Choose $b(i)$ satisfying all $\varphi_\beta$ with $\beta \in s(i)$; otherwise choose any $b(i)$.
12. Fix $\beta < \alpha$. If $i \in g(\set{\beta})$, then $\beta \in s(i)$, so $\mathcal{M}_i \models \varphi_\beta(b(i))$. The truth set contains $g(\set{\beta}) \in \mathcal{U}$.
13. By Łoś's theorem, $[b]$ realizes $p$, and $\mathcal{P}$ is $\kappa$-saturated.

## Idea

Each index $i$ can only promise finitely many formulas of the type, and countable incompleteness lets this number grow to infinity along $\mathcal{U}$.
In part 1 the formulas come in a list, so "the first $n(i)$ formulas" is a good choice at index $i$.
In part 2 there is no such list, and goodness replaces it: the multiplicative $g$ decides at each index a finite set $s(i)$ of formulas, consistently for all of them.

## Variants

For part 1 one can also derive the result from part 2: every countably incomplete ultrafilter is $\aleph_1$-good, since a multiplicative refinement of a function on finite subsets of a countable set can be built by hand.
Both parts use countable incompleteness only to bound the finite sets $s(i)$; without it, step 10 fails and the theorem fails, as a principal ultrafilter shows.
