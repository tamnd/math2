## Example

Let PA be first-order [[Peano arithmetic|0QFT7Z76N5]] in the language with $0$, $S$, $+$ and $\cdot$.
Its axioms are the following sentences, and the schema (Ind) has one axiom for each formula $A(x, \bar y)$.

- (P1) $\forall x \, \lnot(S(x) = 0)$.
- (P2) $\forall x \, \forall y \, (S(x) = S(y) \to x = y)$.
- (P3) $\forall x \, (x + 0 = x)$ and (P4) $\forall x \, \forall y \, (x + S(y) = S(x + y))$.
- (P5) $\forall x \, (x \cdot 0 = 0)$ and (P6) $\forall x \, \forall y \, (x \cdot S(y) = x \cdot y + x)$.
- (Ind) $\forall \bar y \, \big(A(0, \bar y) \land \forall x \, (A(x, \bar y) \to A(S(x), \bar y)) \to \forall x \, A(x, \bar y)\big)$.

We give an [[interpretation|~95e26594]] $I$ of PA in [[Zermelo-Fraenkel set theory|0HE5WDQ9FJ]] ZF.
A set is *inductive* when it contains $\emptyset$ and contains $x \cup \{x\}$ for each of its elements $x$.
By the [[axiom of infinity|X0B4YT5FA7]] an inductive set exists, and by Separation the intersection $\omega$ of all inductive sets is a set.
So $\omega$ is the least inductive set, and ZF proves that $\omega$ exists and is unique.

The interpretation $I$ consists of the following formulas of set theory.

- The domain: $\delta(x) := x \in \omega$.
- The constant $0$: $\varphi_0(y) := \forall z \, (z \notin y)$, so $0$ is the empty set.
- The successor: $\varphi_S(x, y) := \forall z \, (z \in y \leftrightarrow (z \in x \lor z = x))$, so $S(x)$ is $x \cup \{x\}$.
- Addition: $\varphi_+(x_1, x_2, y)$ says "$a(x_1, x_2) = y$", where $a \colon \omega \times \omega \to \omega$ is the unique function with $a(m, \emptyset) = m$ and $a(m, n \cup \{n\}) = a(m, n) \cup \{a(m, n)\}$.
- Multiplication: $\varphi_\cdot(x_1, x_2, y)$ says "$g(x_1, x_2) = y$", where $g \colon \omega \times \omega \to \omega$ is the unique function with $g(m, \emptyset) = \emptyset$ and $g(m, n \cup \{n\}) = a(g(m, n), m)$.

The functions $a$ and $g$ exist and are unique by the recursion theorem on $\omega$, a theorem of ZF; see [[definition by recursion|0DSHAVH45F]].
Let $B$ be the set of functions from $\omega$ to $\omega$.
For $a$, the recursion theorem gives $H \colon \omega \to B$ with $H(\emptyset) = (m \mapsto m)$ and $H(n \cup \{n\}) = (m \mapsto H(n)(m) \cup \{H(n)(m)\})$, and we put $a(m, n) := H(n)(m)$.
For $g$, it gives $G \colon \omega \to B$ with $G(\emptyset) = (m \mapsto \emptyset)$ and $G(n \cup \{n\}) = (m \mapsto a(G(n)(m), m))$, and we put $g(m, n) := G(n)(m)$.
Uniqueness follows by induction on $n$, as in step 9 below.

We check the conditions of an interpretation, one step for each condition.
Each step is an argument in ZF.

1. The domain is not empty: $\emptyset \in \omega$, because $\omega$ is inductive.
2. The constant $0$: the empty set exists and is unique by Extensionality, and it lies in $\omega$ by step 1.
3. The successor is a total function on $\omega$: for $x \in \omega$ the set $x \cup \{x\}$ exists by Pairing and Union, it is unique by Extensionality, and it lies in $\omega$ because $\omega$ is inductive.
4. Addition and multiplication are total functions on $\omega$: for $x_1, x_2 \in \omega$ the values $a(x_1, x_2)$ and $g(x_1, x_2)$ exist, are unique and lie in $\omega$, by the recursion theorem.
5. (P1): $x \in x \cup \{x\}$, so $x \cup \{x\}$ is not empty, and it is different from $\emptyset$.
6. (P2): let $x, y \in \omega$ with $x \cup \{x\} = y \cup \{y\}$, and suppose $x \neq y$. Then $x \in y \cup \{y\}$ and $x \neq y$ give $x \in y$. In the same way $y \in x$. So the set $\{x, y\}$ has no $\in$-minimal element, against the [[axiom of foundation|NFQ9FVCP31]]. Hence $x = y$.
7. (P3) and (P4): these are the equations $a(m, \emptyset) = m$ and $a(m, n \cup \{n\}) = a(m, n) \cup \{a(m, n)\}$ that define $a$. The translation of (P4) first unnests the terms $S(y)$, $x + S(y)$ and $x + y$, and by steps 3 and 4 each of these terms has exactly one value in $\omega$.
8. (P5) and (P6): these are the equations $g(m, \emptyset) = \emptyset$ and $g(m, n \cup \{n\}) = a(g(m, n), m)$ that define $g$.
9. (Ind): fix parameters $\bar y$ in $\omega$ and assume the translated hypotheses: $A^I(\emptyset, \bar y)$, and $A^I(x, \bar y) \to A^I(x \cup \{x\}, \bar y)$ for each $x \in \omega$. By Separation, $X = \{n \in \omega : A^I(n, \bar y)\}$ is a set. By the hypotheses, $X$ contains $\emptyset$ and is closed under $x \mapsto x \cup \{x\}$, so $X$ is inductive. Since $\omega$ is the least inductive set, $\omega \subseteq X$, so $A^I(n, \bar y)$ holds for each $n \in \omega$.

So $I$ is an interpretation, and $\mathsf{ZF} \rhd \mathsf{PA}$.

## Remarks

The example shows the standard pattern of an interpretation: a domain, explicit definitions of the symbols, and a proof in $S$ of each translated axiom.
The induction schema becomes an instance of Separation together with the minimality of $\omega$, one instance for each formula $A$.
As a consequence, if ZF is consistent, then PA is consistent.

The proof uses only Extensionality, Empty set, Pairing, Union, Power set (for the set of functions $\omega \to \omega$), Infinity, Separation and Foundation.
So Zermelo set theory with the axiom of foundation also interprets PA, and Replacement is not needed.
If we change the successor to $x \mapsto \{x\}$ and the domain to the least set that contains $\emptyset$ and is closed under $x \mapsto \{x\}$, we get Zermelo's numerals, and the same steps give a second interpretation.

ZF proves more than the axioms of PA in this interpretation: it proves that $\omega$ is a model of PA, and hence it proves the translation of $\mathrm{Con}(\mathsf{PA})$.
So ZF also interprets $\mathsf{PA} + \mathrm{Con}(\mathsf{PA})$.
Interpretability is a weaker relation than "proves the consistency of": PA does not prove $\mathrm{Con}(\mathsf{PA})$, but PA interprets PA.

## Explanations

### L1 human

Set theory knows only sets and the relation "is an element of".
It can still speak about numbers.
The number $0$ is the empty set, $1$ is the set $\{0\}$, $2$ is the set $\{0, 1\}$, and $3$ is the set $\{0, 1, 2\}$.
The next number after $n$ is the set that has the elements of $n$ and also $n$ itself.
Each rule of arithmetic, for example "$0$ is not the next number of any number", becomes a fact about sets that set theory can prove.

### L2 human

We compute $1 + 1$ and $2 \cdot 2$ in the interpretation, to see that the definitions give the usual values.

1. $0 = \emptyset$, $1 = \{\emptyset\}$, $2 = \{\emptyset, \{\emptyset\}\}$, $3 = 2 \cup \{2\}$ and $4 = 3 \cup \{3\}$.
2. $a(1, 0) = 1$ by the first equation for $a$.
3. $a(1, 1) = a(1, 0 \cup \{0\}) = a(1, 0) \cup \{a(1, 0)\} = 1 \cup \{1\} = 2$.
4. $g(2, 1) = a(g(2, 0), 2) = a(0, 2)$, and $a(0, 2) = 2$ by two uses of the second equation for $a$.
5. $a(2, 1) = a(2, 0) \cup \{a(2, 0)\} = 2 \cup \{2\} = 3$.
6. $g(2, 2) = a(g(2, 1), 2) = a(2, 2) = a(2, 1) \cup \{a(2, 1)\} = 3 \cup \{3\} = 4$.

The typical use is a relative consistency proof, and the construction is the first step of the arithmetic inside set theory.
A trap is to prove the induction schema with one set $X$ for all formulas at once; Separation gives one set for each formula $A$, and that is all that the schema needs.
