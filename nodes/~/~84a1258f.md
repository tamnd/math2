## Example

Let $\Sigma = \set{a_1, \ldots, a_k}$ be a finite alphabet with $k \ge 2$ symbols.
For the language of arithmetic we can take the $12$ symbols $\neg, \to, \forall, =, (, ), 0, S, +, \cdot, v, '$ and write the variable $v_i$ as $v$ followed by $i$ primes.
Define $\#(a_{d_1} a_{d_2} \cdots a_{d_n}) = d_1 k^{n-1} + d_2 k^{n-2} + \cdots + d_n$, with each digit $d_j \in \set{1, \ldots, k}$, and $\#(\text{empty string}) = 0$.
We check that $\#$ is a [[Gödel numbering|MFJXPAF0R0]] whose set of codes is all of $\N$.

1. Computability: the sum is computed from the digits by $n$ multiplications and additions, so $\#$ is [[computable|KZSB5E471K]].
2. The last digit is determined: $\#(w a_d) = k \cdot \#(w) + d$ with $1 \le d \le k$, so $d$ is the unique number in $\set{1, \ldots, k}$ with $d \equiv \#(w a_d) \pmod k$.
3. Decoding: for $m \ge 1$, let $d$ be as in step 2 and set $m' = (m - d)/k$. Then $0 \le m' < m$.
4. Repeating step 3 ends at $0$ after finitely many steps, because the numbers decrease. The digits found, read backwards, give a string $w$ with $\#(w) = m$.
5. Surjectivity: step 4 gives a string for every $m \in \N$, so every number is a code, and the set of codes $\N$ is decidable.
6. Injectivity: by step 2, two strings with the same code have the same last digit and the same code without it. Induction on the length gives equal strings.
7. Steps 3 and 4 compute the inverse map, so all three conditions hold.

## Remarks

For $k = 2$ and $\Sigma = \set{a, b}$, the order of the codes is $\varepsilon, a, b, aa, ab, ba, bb, aaa$ with codes $0$ to $7$.
This is the length-lexicographic order: shorter strings first, and strings of the same length in dictionary order.
Unlike the prime-power numbering, this numbering is a bijection, and its codes grow only exponentially in the length.
With digits from $0$ to $k - 1$ instead, the strings $a_0$ and $a_0 a_0$ would both get the code $0$, so the shift to the digits $1$ to $k$ is needed.

## Explanations

### L1 human

Write the symbols as the digits $1$ and $2$, and read a string as a number in a special base $2$.
The string $ab$ becomes $1 \cdot 2 + 2 = 4$.
The string $ba$ becomes $2 \cdot 2 + 1 = 5$.
Every whole number comes from exactly one string, so nothing is wasted.

### L2 human

1. Take $k = 2$, $c(a) = 1$, $c(b) = 2$, and the number $m = 11$.
2. Since $11$ is odd, its last digit is $1$, the symbol $a$, and $(11 - 1)/2 = 5$.
3. Since $5$ is odd, the next digit is $1$, the symbol $a$, and $(5 - 1)/2 = 2$.
4. Since $2$ is even, the next digit is $2$, the symbol $b$, and $(2 - 2)/2 = 0$.
5. Reading backwards gives $baa$, and $2 \cdot 4 + 1 \cdot 2 + 1 = 11$ checks the result.

The typical use is a numbering that is onto $\N$, so that every number names a string.
A trap: in ordinary base $k$, leading zeros break injectivity.
