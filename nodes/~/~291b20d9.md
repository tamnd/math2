## Example

Let $g$ be the prime-power [[Gödel numbering|MFJXPAF0R0]] of the strings of the language $\set{0, S, +, \cdot}$.
Define a map $h$ on strings by $h(w) = 2 g(w)$ when $w$ is a sentence true in $\N$, and $h(w) = 2 g(w) + 1$ otherwise.
We check which conditions of a Gödel numbering hold.

1. Injectivity holds. If $h(w) = h(w')$, then $h(w)$ and $h(w')$ have the same parity. Dividing by $2$ and rounding down gives $g(w) = g(w')$, so $w = w'$.
2. Computability fails. Suppose $h$ were computable.
3. Then the set of true sentences would be a [[computable set|PPGD5KW8JC]]: compute $h(w)$ and check whether it is even.
4. Every computable set of numbers is definable in $\N$ by a formula of arithmetic, by the representability of computable relations.
5. So the set of codes of true sentences would be definable in $\N$. This contradicts [[Tarski's undefinability theorem|YRV6SYK2BY]], so $h$ is not computable.
6. The set of codes fails to be decidable. A number $m$ is a code exactly when $\lfloor m/2 \rfloor$ is a code of $g$ and the parity of $m$ matches the truth value. Deciding this would decide truth, as in step 3.

## Remarks

The map $h$ carries the same information as $g$ plus one bit, the truth value, and the extra bit is not computable.
So the example shows that injectivity alone is not enough: the numbering must be computable for arithmetic to describe syntax.
If "true in $\N$" is replaced by "provable in Peano arithmetic", step 2 still fails, now by the undecidability of provability.
If it is replaced by "is a sentence", the map becomes computable, since the set of sentences is decidable, and $h$ is a Gödel numbering.

## Explanations

### L1 human

Imagine a code for statements that is even for true statements and odd for false ones.
Different statements still get different numbers.
But to compute the code, one must first know whether the statement is true.
No machine can do that for all statements of arithmetic, so this code cannot be computed.

### L2 human

1. The sentence $0 = 0$ is true, so its value is $2 g(0 = 0)$, an even number.
2. The sentence $0 = S0$ is false, so its value is $2 g(0 = S0) + 1$, an odd number.
3. For a sentence such as the Goldbach conjecture, nobody knows today which parity to use.

The typical use of this example is to separate the conditions of a Gödel numbering.
A trap: a map defined by cases on a property is computable only when the property is decidable.
