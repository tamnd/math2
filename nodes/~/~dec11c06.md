## Example

Let $x_0, \dots, x_{n-1}$ and $y_0, \dots, y_{n-1}$ be the bits of two numbers, with $x_0$ and $y_0$ the lowest bits.
The carry $c_i$ into position $i$ satisfies $c_0 = 0$ and $c_{i+1} = \mathrm{MAJ}(x_i, y_i, c_i)$, where
$$\mathrm{MAJ}(u, v, w) = (u \land v) \lor (u \land w) \lor (v \land w).$$

*Unfolded formulas.*
Define formulas $C_i$ in the variables $x, y$ by $C_1 = x_0 \land y_0$ and $C_{i+1} = (x_i \land y_i) \lor (x_i \land C_i) \lor (y_i \land C_i)$.
Count variables and connectives as symbols.

1. $\abs{C_1} = 3$.
2. $C_{i+1}$ contains two copies of $C_i$ and $9$ other symbols, so $\abs{C_{i+1}} = 2 \abs{C_i} + 9$.
3. By induction on $i$, $\abs{C_i} = 12 \cdot 2^{i-1} - 9 \ge 2^i$.

*Extension variables.*
An [[extended Frege|~6925f591]] proof can introduce the extension axioms
$$q_1 \leftrightarrow (x_0 \land y_0), \qquad q_{i+1} \leftrightarrow (x_i \land y_i) \lor (x_i \land q_i) \lor (y_i \land q_i)$$
for $i = 1, \dots, n-1$, in this order.
Each $q_{i+1}$ is new when it is introduced, and its definition uses only $x_i$, $y_i$ and the earlier $q_i$.
Each axiom has at most $13$ symbols, so all $n$ axioms together have at most $13 n$ symbols.
For $i \ge 1$, the sum bit at position $i$ is then the short formula $x_i \oplus y_i \oplus q_i$.

## Remarks

The extension variables $q_i$ are the gates of a [[Boolean circuit|NDPRFZGZ9M]] for addition.
So EF-proofs can reason with circuits of size $O(n)$, where the unfolded formulas $C_i$ have size $2^i$ or more.

The example does not separate Frege systems from EF.
The carry also has the *carry-lookahead* formula
$$c_i = \bigvee_{j < i} \Bigl( x_j \land y_j \land \bigwedge_{j < k < i} (x_k \lor y_k) \Bigr),$$
of size $O(i^2)$: a carry into position $i$ exists exactly when some position $j < i$ generates one and every position between them passes it on.
Frege proofs about addition use formulas of this kind.

## Explanations

### L1 human

When we add two numbers by hand, we write each carry once above the column.
A formula cannot do this: each time it needs a carry, it must write the whole expression for it again.
The expression for the next carry contains the previous one twice, so its length doubles at each column.
Extended Frege lets the proof write each carry once and give it a name.

### L2 human

We compute $\abs{C_3}$.

1. $\abs{C_1} = 3$, for $x_0 \land y_0$.
2. $\abs{C_2} = 2 \cdot 3 + 9 = 15$.
3. $\abs{C_3} = 2 \cdot 15 + 9 = 39$.
4. The formula $12 \cdot 2^{2} - 9 = 39$ agrees.

With extension variables, the third carry is $q_3$, of size $1$, with a definition of $13$ symbols.
The typical use is to translate polynomial-time computations into EF-proofs.
A trap: a long unfolded formula does not prove that every formula for the same function is long.
