## Example

Let $T$ be a [[first-order theory|92SWXST1ZM]] with [[finite|070R982G4B]] models of every size above any bound.
So for each $n \in \N$ there is a finite model $\mathcal{M}_n \models T$ with at least $n$ elements.
Let $\mathcal{U}$ be a nonprincipal ultrafilter on $\N$, and let $\mathcal{M} = \prod_{n \in \N} \mathcal{M}_n / \mathcal{U}$.
We check that $\mathcal{M}$ is an infinite model of $T$.

1. Each sentence of $T$ holds in every $\mathcal{M}_n$, so its truth set is $\N \in \mathcal{U}$. By [[Łoś's theorem|AGYBSTD7BG]], $\mathcal{M} \models T$.
2. For $k \ge 1$, let $\lambda_k$ be the sentence $\exists x_1 \dots \exists x_k \bigwedge_{j < l} x_j \neq x_l$, which says "at least $k$ elements".
3. $\lambda_k$ holds in $\mathcal{M}_n$ for all $n \ge k$. This set is cofinite, so it lies in the nonprincipal $\mathcal{U}$.
4. By Łoś's theorem $\mathcal{M} \models \lambda_k$ for every $k$, so $\mathcal{M}$ is infinite.

## Remarks

The example is the [[ultraproduct method|~0aa1297f]] with the index set $\N$ in place of the finite subsets of $T \cup \set{\lambda_k : k \ge 1}$.
This works because the finite parts are linearly ordered by size: $\mathcal{M}_n$ satisfies $T$ and $\lambda_1, \dots, \lambda_n$.
It shows that the class of finite models of $T$ is not elementary: any theory with the same finite models also has an infinite model.
So the classes of finite groups, finite fields and finite graphs are not axiomatizable in first-order logic.
If $\mathcal{U}$ is principal at $n_0$, then $\mathcal{M} \cong \mathcal{M}_{n_0}$ is finite, and the argument fails at step 3.
If the sizes of the $\mathcal{M}_n$ are bounded by $N$, then $\lambda_{N+1}$ fails in every factor, and the ultraproduct is finite.

## Explanations

### L1 human

Suppose a set of rules has finite examples of every size, as groups do.
We glue one example of each size into one structure by an ultraproduct.
For any number, such as $1000$, most of the examples have more than $1000$ elements.
So the glued structure has more than $1000$ elements, and the same holds for every number.
So it is infinite, and it still follows all the rules.

### L2 human

Let $\mathcal{M}_n = \Z / n\Z$ for $n \ge 1$, as groups, and let $G = \prod_{n} \mathcal{M}_n / \mathcal{U}$ for a nonprincipal $\mathcal{U}$.

1. The group axioms hold in each factor, so $G$ is an abelian group.
2. Let $g = [(1, 1, 1, \dots)]$, and fix $k \ge 1$.
3. $k \cdot 1 = 0$ in $\Z / n\Z$ exactly when $n$ divides $k$, which happens for finitely many $n$.
4. So the truth set of $k \cdot g = 0$ is finite and not in $\mathcal{U}$, and $k \cdot g \neq 0$ in $G$.
5. So $g$ has infinite order, although every element of every factor has finite order.

The typical use is to show that a property of finite structures is not first-order.
The trap is to think that $G$ is finite or torsion: "every element has finite order" is an infinite disjunction, not a first-order sentence.
