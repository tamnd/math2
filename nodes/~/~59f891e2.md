## Definition

$\mathsf{RCA}_0$ is the subsystem of [[second-order arithmetic|DC60FYCSPM]] whose axioms are the following.

1. The basic axioms of $\mathsf{Z}_2$, as in the [[definition of second-order arithmetic|Y92NXGEQBD]].
2. $\Sigma^0_1$ induction: for every $\Sigma^0_1$ formula $\varphi(n)$ of $L_2$, with any parameters, the universal closure of
$$\big(\varphi(0) \wedge \forall n\, (\varphi(n) \to \varphi(n + 1))\big) \to \forall n\, \varphi(n).$$
3. $\Delta^0_1$ comprehension: for every $\Sigma^0_1$ formula $\varphi(n)$ and every $\Pi^0_1$ formula $\psi(n)$, with any parameters, in which $X$ is not free, the universal closure of
$$\forall n\, \big(\varphi(n) \leftrightarrow \psi(n)\big) \to \exists X\, \forall n\, \big(n \in X \leftrightarrow \varphi(n)\big).$$

Here $\Sigma^0_1$ and $\Pi^0_1$ are the classes of the [[arithmetical hierarchy|GE43CSZTS9]] for $L_2$: a $\Sigma^0_1$ formula has the form $\exists k\, \theta$ with $\theta$ built from atomic formulas, including $t \in X$, with bounded number quantifiers only.

## Notation

The name stands for "recursive comprehension axiom", and the subscript $0$ marks the restriction of induction.
The set induction axiom of $\mathsf{Z}_2$ is the instance of clause 2 for the formula $n \in X$, so $\mathsf{RCA}_0$ contains it.
Some authors write $\mathsf{RCA}$ for the system with the full [[induction scheme|1QD0KDDGYJ]].

## Remarks

Example: the family of computable sets satisfies clause 3, because a set that is computably enumerable and has a computably enumerable complement is computable.

Non-example: the family of computable sets together with the halting set $K$ fails clause 3: the complement of $K$ is defined from $K$ by a formula that is both $\Sigma^0_1$ and $\Pi^0_1$, but it is not in the family.

Clause 3 does not ask that $\mathsf{RCA}_0$ prove the equivalence $\varphi \leftrightarrow \psi$; the instance has the equivalence as hypothesis, and so the axiom applies inside a model whenever the equivalence holds there.

## Explanations

### L1 human

$\mathsf{RCA}_0$ allows a set to exist when a computer, with the given sets as oracles, can decide membership in it.
It allows induction for statements of the form "there is a number $k$ such that a checkable condition holds".

### L2 human

To use clause 3, one gives two descriptions of a set: one of the form "some witness exists", and one of the form "every candidate passes a test".
For example, if $f$ is a function, then $\set{n : \exists k\, f(k) = n}$ need not exist in $\mathsf{RCA}_0$, since only the first form is available.
If $f$ is strictly increasing, then $f(k) \ge k$ for all $k$, and $n$ is in the range exactly when $\exists k \le n\, f(k) = n$, which is bounded, so the set exists.
