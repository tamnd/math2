## Example

Let $L = \set{+, -, \cdot, 0, 1, <}$ be the signature of ordered rings, and let $\R_{\mathrm{alg}} = \set{r \in \R : r \text{ is algebraic over } \Q}$.
We check that $(\R_{\mathrm{alg}}, +, -, \cdot, 0, 1, <) \preceq (\R, +, -, \cdot, 0, 1, <)$.

1. [[The algebraic numbers form a field|0QFTETCHKB]], and $\R$ is a field, so $\R_{\mathrm{alg}}$ is a subfield of $\R$. With the restricted order it is a substructure of $\R$.
2. Let $a \in \R_{\mathrm{alg}}$ with $a > 0$. Then $\sqrt{a} \in \R$ is a root of $x^2 - a$, so it is algebraic over $\Q(a)$, hence over $\Q$. So $\sqrt{a} \in \R_{\mathrm{alg}}$.
3. Let $p$ be a polynomial of odd degree with coefficients in $\R_{\mathrm{alg}}$. It takes values of both signs on $\R$, so it has a real root $r$ by the [[intermediate value theorem|00KAFBR32E]].
4. The root $r$ is algebraic over the field generated by the coefficients, which is a finite extension of $\Q$. So $r$ is algebraic over $\Q$, and $r \in \R_{\mathrm{alg}}$.
5. By steps 2 and 3 to 4, $\R_{\mathrm{alg}}$ is a [[real closed field|DDY3Q3PJ6W]], and so is $\R$.
6. The theory $\mathrm{RCF}$ has [[quantifier elimination|FSJ9NGRRPA]]. So for each formula $\varphi(\bar x)$ there is a quantifier-free $\psi(\bar x)$ that is equivalent to it in every real closed field.
7. For $\bar a$ in $\R_{\mathrm{alg}}$: $\R_{\mathrm{alg}} \models \varphi(\bar a)$ iff $\R_{\mathrm{alg}} \models \psi(\bar a)$ iff $\R \models \psi(\bar a)$ iff $\R \models \varphi(\bar a)$. The middle step holds because [[embeddings preserve quantifier-free formulas|C9494XYEMN]].
8. So $\R_{\mathrm{alg}} \preceq \R$.

## Remarks

The example gives a countable elementary substructure of $\R$ that is not built by the [[Löwenheim-Skolem theorem|484M0TZ1S7]] but found in nature.
$\R_{\mathrm{alg}}$ is countable, because there are countably many polynomials with rational coefficients and each has finitely many roots.
A consequence: a system of polynomial equations and inequalities with real algebraic coefficients that has a real solution has a real algebraic solution.
If we replace $\R_{\mathrm{alg}}$ by $\Q$, the conclusion fails, since $\exists y \, (y \cdot y = 1 + 1)$ holds in $\R$ and fails in $\Q$.
If we drop the order from the signature, the inclusion is still elementary, because the order of a real closed field is definable: $x \le y$ if and only if $\exists z \, (y - x = z \cdot z)$.
The same argument with algebraically closed fields gives $\overline{\Q} \preceq \C$; see [[this example|~4bfe8f6c]].

## Explanations

### L1 human

The real algebraic numbers are the real numbers that solve a polynomial equation with whole-number coefficients, such as $\sqrt{2}$ or $\sqrt[3]{5}$.
The number $\pi$ is not one of them.
Every question about adding, multiplying and comparing numbers, asked about some real algebraic numbers, has the same answer in the real algebraic numbers and in all real numbers.
For example, "is there a number $y$ with $y^3 = 2$ and $y > 1$" is true in both, with $y = \sqrt[3]{2}$.

### L2 human

We check the consequence on one system: $x^2 + y^2 = 4$ and $y = x^3$.

1. The system says that the curve $y = x^3$ meets the circle of radius $2$.
2. The function $g(x) = x^2 + x^6 - 4$ has $g(0) = -4$ and $g(2) = 64$, so it has a root $x_0$ between $0$ and $2$.
3. Then $(x_0, x_0^3)$ is a real solution.
4. The number $x_0$ is a root of $x^6 + x^2 - 4$, a polynomial with integer coefficients, so $x_0 \in \R_{\mathrm{alg}}$, and the solution is real algebraic.

The typical use is to move a real solution of a semialgebraic problem to the countable field $\R_{\mathrm{alg}}$, or the reverse.
A trap is to apply the transfer to statements about all subsets of $\R$, such as the least upper bound property; they are not first-order, and they fail in $\R_{\mathrm{alg}}$.
