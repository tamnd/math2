## Example

Let $X = \set{a, b}$ with the open sets $\emptyset$, $\set{a}$, $X$; this is the [[Sierpiński space|NTCD3724BB]].
Let $B$ be the power set of $X$, and let $Ix$ be the interior of $x$.
The table of $I$ is $I\emptyset = \emptyset$, $I\set{a} = \set{a}$, $I\set{b} = \emptyset$, $IX = X$.
We check the four axioms of an [[interior algebra|7X1HGZ6FK0]].

1. $IX = X$, so $I1 = 1$.
2. $Ix \le x$ holds in each of the four rows of the table.
3. $Ix$ is one of $\emptyset$, $\set{a}$, $X$, and $I$ fixes these three sets, so $IIx = Ix$.
4. For $I(x \land y) = Ix \land Iy$: if $x \le y$, both sides equal $Ix$, because $I$ is monotone in the table.
   The only pair that is not comparable is $\set{a}$, $\set{b}$; then $I\emptyset = \emptyset = \set{a} \land \emptyset$.

So $(B, I)$ is an interior algebra.
Its open elements are $\emptyset < \set{a} < X$, a three-element chain.

## Remarks

1. By [[the open elements theorem|~960c7881]], the chain is a Heyting algebra, with $\neg \set{a} = I\set{b} = \emptyset$.
2. So $\set{a} \lor \neg \set{a} = \set{a} \ne X$: excluded middle fails in the open elements.
3. In $B$ itself, $\set{a} \lor \neg \set{a} = X$; the failure comes from replacing $\neg$ by $I \neg$.
4. With the discrete topology on $X$, every set is open, and the open elements form the Boolean algebra $B$.

## Explanations

### L1 human

The space has two points, $a$ and $b$.
Only $a$ has room around it: the set $\set{a}$ is open, and $\set{b}$ is not.
So the inside of $\set{b}$ is empty.
The open sets are "nothing", "just $a$" and "everything".
They form a chain of three steps, like false, unknown and true.

### L2 human

1. Compute $\set{a} \Rightarrow \emptyset = I(\set{b} \cup \emptyset) = I\set{b} = \emptyset$.
2. Compute $X \Rightarrow \set{a} = I(\emptyset \cup \set{a}) = \set{a}$.
3. Compute $\set{a} \Rightarrow X = I(\set{b} \cup X) = X$.
4. Check residuation at $z = \set{a}$, $x = X$, $y = \set{a}$: $z \land x = \set{a} \le y$, and $z \le X \Rightarrow \set{a} = \set{a}$.

The typical use: the Sierpiński space is the smallest space whose open sets are not Boolean.
The trap: $\set{b}$ is closed and not open, so $\set{b}$ is not an element of the Heyting algebra.
