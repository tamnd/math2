## Statement

Let $I$ be an open interval and let $f \colon I \to \mathbb{R}$ be differentiable.
Then $f$ is [[convex|~aaa9779c]] if and only if $f'$ is increasing on $I$.

## Remarks

If $f$ is convex, the [[slope inequalities|~b1c3ba4d]] give $f'(x) \le f'(y)$ for $x < y$.
If $f'$ is increasing, the [[mean value theorem|~9bd25708]] on $[x, y]$ and $[y, z]$ gives the slope inequalities.
Then the graph lies above each tangent line: $f(y) \ge f(x) + f'(x)(y - x)$.
Mathlib states the converse direction as `MonotoneOn.convexOn_of_deriv`.

## Explanations

### L1 human

A differentiable function is convex when its slope keeps growing.
The graph then turns to the left as we move along it to the right.
