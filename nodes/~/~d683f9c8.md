## Example

Let $L = \set{a_1 < a_2 < \dots < a_n}$ be a finite [[linear order|0FRXBVVR03]] with $n \ge 2$.
We show that $L$ is not [[homogeneous|~7468669e]].

1. Let $\sigma$ be an order [[automorphism|DSQ17TNW1C]] of $L$.
2. $\sigma$ maps the least element to the least element, so $\sigma(a_1) = a_1$.
3. Removing $a_1$ leaves a smaller linear order, and $\sigma$ restricts to an automorphism of it.
4. By [[induction on size|B2D8PTFNN1]], $\sigma$ is the identity.
5. The map $a_1 \mapsto a_2$ is an isomorphism of one-point substructures, and it does not extend.

## Remarks

A finite linear order is rigid: its automorphism group is trivial.
So among finite tournaments, the transitive ones with at least $2$ vertices are not homogeneous.
Among linear orders, the only countable homogeneous ones are the empty order, the one-point order and $(\Q, <)$.

## Explanations

### L1 human

In a finite chain, the first element is special: nothing comes before it.
No symmetry can move it.
So the chain is not as symmetric as homogeneity asks.

### L2 human

We test the chain $1 < 2 < 3$.

1. An automorphism fixes $1$, the least element.
2. It then fixes $2$, the least of the rest, and then $3$.
3. So the map $1 \mapsto 2$ does not extend.

The typical use is to see why Lachlan's list of homogeneous tournaments has so few finite entries.
A trap is to forget the empty order and the one-point order, which are homogeneous.
