## Definition

The formulas are built from atoms $p, q, \ldots$ by the connectives $\wedge$, $\vee$ and $\to$.
Let $G$ be one of the ordered [[abelian groups|082GHNPJ53]] $\mathbb{Z}$, $\mathbb{Q}$ or $\mathbb{R}$.
A *$G$-valuation* $v$ gives each atom an element of $G$, and it extends to all formulas by
$$v(A \wedge B) = \min(v(A), v(B)), \quad v(A \vee B) = \max(v(A), v(B)), \quad v(A \to B) = v(B) - v(A).$$
A formula $A$ is *valid in $G$* if $v(A) \geq 0$ for every $G$-valuation $v$.
*Abelian logic* is the set of formulas valid in $\mathbb{R}$.

## Notation

The SEP entry on many-valued logic writes the implication as $a \rightarrow b := -a + b$, and it calls the non-negative numbers the designated values.
We write $a, b, c$ for the values of $A, B, C$ when the valuation is fixed.

## Remarks

1. *The same logic for $\mathbb{Z}$, $\mathbb{Q}$ and $\mathbb{R}$.* A formula is valid in $\mathbb{Z}$ if and only if it is valid in $\mathbb{R}$, and the same holds for $\mathbb{Q}$.
   1. $\mathbb{Z} \subseteq \mathbb{Q} \subseteq \mathbb{R}$, and each is closed under $\min$, $\max$ and subtraction.
   2. So validity in $\mathbb{R}$ gives validity in $\mathbb{Q}$, and validity in $\mathbb{Q}$ gives validity in $\mathbb{Z}$.
   3. For an integer $k > 0$, multiplying all atom values by $k$ multiplies $v(A)$ by $k$, by induction on $A$.
   4. The induction step holds, since $\min$, $\max$ and subtraction commute with multiplication by $k > 0$.
   5. Let $A$ be valid in $\mathbb{Z}$, and let $v$ be a $\mathbb{Q}$-valuation.
   6. Let $k > 0$ be a common denominator of the values of the atoms of $A$.
   7. Then $kv$ is a $\mathbb{Z}$-valuation on these atoms, so $k \, v(A) \geq 0$ by step 3, and $v(A) \geq 0$.
   8. Now let $A$ be valid in $\mathbb{Q}$, and let $v$ be an $\mathbb{R}$-valuation.
   9. $v(A)$ is a continuous function of the atom values, since $\min$, $\max$ and subtraction are continuous.
   10. Rational points are dense, so $v(A)$ is a limit of values $\geq 0$, and $v(A) \geq 0$.
2. *The implication fragment.* Let $A$ contain only $\to$, with atoms $p_1, \ldots, p_m$.
   1. By induction on $A$, $v(A) = \sum_i n_i v(p_i)$ with integers $n_i$ that depend on $A$ but not on $v$.
   2. If every $n_i$ is $0$, then $v(A) = 0$ for every $v$, so $A$ is valid.
   3. If $n_j \neq 0$, put $v(p_j) = -n_j$ and $v(p_i) = 0$ for $i \neq j$.
   4. Then $v(A) = -n_j^2 < 0$, so $A$ is not valid.

## Explanations

### L1 human

Each formula gets a number, and implication is the difference of two numbers.
A formula is valid if its number is never negative.

### L2 human

We compute the coefficients $n_i$ of remark 2 for $p \to (q \to p)$.

1. $v(q \to p) = v(p) - v(q)$.
2. $v(p \to (q \to p)) = (v(p) - v(q)) - v(p) = -v(q)$.
3. So $n_p = 0$ and $n_q = -1$.
4. With $v(q) = 1$, the value is $-1$, so the formula is not valid.

The typical use of remark 2 is to decide a formula with $\to$ alone by counting the occurrences of each atom with signs.
A trap: remark 2 needs $\to$ alone; with $\wedge$ or $\vee$, the value is a piecewise linear function, not a linear one.
