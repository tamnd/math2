## Definition

A [[set|~bd92ceee]] $A$ is countable when there is an [[injective function|~3e705960]] $f \colon A \to \mathbb{N}$.

## Remarks

Equivalently, $A$ is [[finite|~5b198354]] or [[countably infinite|~c69f6aeb]].
A nonempty set is countable exactly when there is a [[surjection|~beb187ef]] from $\mathbb{N}$ to it.
Some authors use "countable" only for countably infinite sets, and "at most countable" for this notion.
Subsets of countable sets are countable.

## Explanations

### L1 human

A countable set is one that you can list: first element, second element, and so on.
The list may stop, or it may go on forever, but each element appears at some finite position.
