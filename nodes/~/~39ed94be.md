## Example

Consider the system $x + y = 1$, $x - y = 0$ over $\R$.

1. The constant term of the first equation is $1 \ne 0$, so the system is not [[homogeneous|04KGXJG1A2]].
2. $R_2 \leftarrow R_2 - R_1$ gives $-2y = -1$, so $y = \tfrac12$, and then $x = \tfrac12$.
3. Check: $\tfrac12 + \tfrac12 = 1$ and $\tfrac12 - \tfrac12 = 0$.
4. Double the solution: $(1, 1)$ gives $1 + 1 = 2 \ne 1$, so $(1, 1)$ is not a solution.
5. The zero vector $(0, 0)$ gives $0 \ne 1$, so it is not a solution either.
6. So the solution set $\set{(\tfrac12, \tfrac12)}$ is not a [[linear subspace|00YC1D652K]].

## Remarks

The associated homogeneous system $x + y = 0$, $x - y = 0$ has only the solution $(0, 0)$.
So the solution set is $(\tfrac12, \tfrac12) + \set{0}$, as [[the structure theorem|~a01a76ca]] predicts.

## Explanations

### L1 human

A subspace must contain zero, and it must stay closed under doubling.
The single point $(\tfrac12, \tfrac12)$ fails both tests.

### L2 human

Quick test: a system $Ax = b$ has a subspace as its solution set only when $b = 0$.

1. If $b \ne 0$, then $A0 = 0 \ne b$, so $0$ is not a solution.
2. A subspace always contains $0$.

A trap: the solution set of a non-homogeneous system is still flat, but it is a shifted copy of a subspace, not a subspace.
