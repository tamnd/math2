## Definition

Let $G$ be a [[graph|~3f82cef4]].
An independent set in $G$ is a set $S$ of vertices of $G$ such that no two vertices of $S$ are adjacent.

## Remarks

A set is independent in $G$ if and only if it is a [[clique|~d6405616]] in the [[complement graph|~7c02eda7]].
A set $S$ is independent if and only if its complement in the vertex set is a [[vertex cover|~1935d630]].
The largest size of an independent set is the independence number $\alpha(G)$. Each colour class of a [[colouring|~ed132083]] is an independent set.

## Explanations

### L1 human

An independent set is a set of vertices with no edge between any two of them.
In a conflict graph, it is a set of tasks that can all happen at the same time.
