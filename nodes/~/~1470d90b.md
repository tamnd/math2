## Summary

*Default logic* is a [[nonmonotonic logic|~37275fd2]] introduced by Reiter in 1980.
Its basic object is a *default* $(\gamma : \theta)/\tau$, read "if $\gamma$ is known and $\theta$ is consistent with what we believe, infer $\tau$".
A *default theory* is a pair $(W, D)$ of a set $W$ of facts and a set $D$ of defaults.
Its acceptable belief sets are its *extensions*, defined as [[fixed points|R6QVS6P21N]] of an operator.
A default theory can have no extension, exactly one, or several.

## Motivation

Much knowledge is general but has exceptions: birds fly, unless they are penguins, ostriches or injured.
To list all exceptions in a classical axiom is impossible in practice.
A default states the rule together with a consistency condition, so exceptions block it without being listed in advance.
The consistency condition refers to the final belief set, so extensions must be defined by a fixed-point equation, not by an iteration from below.

## Notation

For a default $d = (\gamma : \theta)/\tau$, we call $\gamma$ the *prerequisite*, $\theta$ the *justification* and $\tau$ the *conclusion*.
A default $(\gamma : \tau)/\tau$ is *normal*.
We write $\mathrm{Cn}$ for classical [[deductive closure|CT4FZ84V45]], $\Gamma_T$ for the operator of the theory $T$, and $\mathrm{Ext}(T)$ for its set of extensions.
$T \mathrel{|\!\sim}_{\mathrm{sk}} \varphi$ means that $\varphi$ is in every extension, and $T \mathrel{|\!\sim}_{\mathrm{cr}} \varphi$ that it is in some extension.

## Remarks

### Examples

- [[Tweety in default logic|~e3291b56]]: one default gives "Tweety flies", and the fact "Tweety is a penguin" blocks it.
- [[The Nixon diamond|~a28dd2ae]]: two conflicting defaults give two extensions.
- [[A default theory with no extension|~050bfb32]]: the default $(\top : \theta)/\neg\theta$ defeats itself.

### Non-examples

- A default theory with $D = \emptyset$ has exactly one extension, $\mathrm{Cn}(W)$; it is classical logic in disguise.
- The closed-world assumption is not a default theory as such, but each atom $p$ gives the default $(\top : \neg p)/\neg p$, which expresses it.

### Basic properties

- An extension $E$ of $(W, D)$ contains $W$ and is deductively closed.
- An extension is inconsistent if and only if $W$ is inconsistent.
- Extensions are minimal: if $E \subseteq E'$ are both extensions, then $E = E'$.
- Every normal default theory has an extension, and two different extensions of a normal theory are inconsistent with each other.
- Skeptical consequence fails Cautious Monotony, by an example of Makinson; see [[Skeptical default consequence fails Cautious Monotony|~8f44dab0]].
- For finite propositional theories, Gottlob (1992) showed these complexity results, as reported in the Wikipedia article:
  deciding whether an extension exists is $\Sigma_2^{\mathrm{P}}$-complete;
  credulous consequence is $\Sigma_2^{\mathrm{P}}$-complete;
  skeptical consequence is $\Pi_2^{\mathrm{P}}$-complete.
  These classes are on the second level of the [[polynomial hierarchy|8W2MGKP4ZR]].
- For first-order default theories, skeptical consequence is not even semi-decidable, because a default applies only after a [[consistency|VM8TQ70CVJ]] check.

### History

Reiter introduced default logic in "A logic for default reasoning" (1980), in the special issue of Artificial Intelligence on nonmonotonic reasoning.
Lukaszewicz (1988) gave a variant in which every theory has an extension.
Konolige (1988) translated default logic into a strongly grounded form of autoepistemic logic.
Horty (2007) studied defaults with priorities.

### Common errors

- To test the justification against the facts only. The test $\neg\theta \notin E$ uses the final extension $E$.
- To build an extension by applying defaults in some order and to stop. An order can produce a set that is not a fixed point, and a fixed point may not exist.
- To take the union of all extensions as the set of conclusions. That set is in general not consistent.

## Explanations

### L1 human

A default is a rule of thumb: "if something is a bird, and nothing says it cannot fly, then it flies".
Default logic collects all the rules of thumb that we can use together without contradiction.
Each such collection gives a possible picture of the world, called an extension.

### L2 human

To check that a set $E$ is an extension, we use $E$ to decide which defaults are blocked.
Then we close the facts under logic and under the defaults that are not blocked.
If the result is $E$ again, then $E$ is an extension.
A trap is to forget the last step: a guess that blocks too few or too many defaults gives a different set.

### L3 human

The operator $\Gamma_T$ is antitone: a larger guess blocks more defaults and gives a smaller result.
So the Knaster-Tarski theorem does not give a fixed point, and indeed some theories have none.
Every extension is generated by its applied defaults: $E = \mathrm{Cn}(W \cup \set{\tau_d : d \in D'})$, where $\tau_d$ is the conclusion of $d$ and $D'$ is the set of defaults whose prerequisite is in $E$ and which $E$ does not block.
The default $(\gamma : \theta)/\tau$ corresponds to the autoepistemic formula $(\mathsf{B}\gamma \land \neg\mathsf{B}\neg\theta) \supset \tau$, in Konolige's translation.
