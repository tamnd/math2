## Summary

A random experiment is a procedure that we can repeat as often as we like and that has a well-defined set of possible results.
The set of these results is the [[sample space|~5c034e59]] of the experiment.
The experiment is random when it has more than one possible result, and deterministic when it has exactly one.

## Remarks

Each repetition of the experiment is a trial. Each trial gives exactly one [[outcome|~f70869fd]].
A toss of a coin and a roll of a die are random experiments.

## Explanations

### L1 human

A random experiment is an action whose result you cannot predict, but whose possible results you know in advance.
When you roll a die, you do not know the number that you will get, but you know that it is one of $1, 2, 3, 4, 5, 6$.
