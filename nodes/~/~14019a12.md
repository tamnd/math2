## Example

Let $f \colon \mathbb{R} \to \mathbb{R}$ be continuous, and assume that
$$f(x) = 1 + \int_0^x t\, f(t)\, dt \qquad \text{for each } x \in \mathbb{R}.$$
We prove by a regularity [[bootstrap|~57b93b38]] that $f$ is [[smooth|0V33BNKZ9S]], that is $f \in C^\infty$.
Then we find $f$.

1. The integrand $g(t) = t f(t)$ is continuous, as a product of two continuous functions.
2. By the [[fundamental theorem of calculus|0NHGY0N0JB]], $x \mapsto \int_0^x g(t)\, dt$ is differentiable with derivative $g(x)$.
3. So $f$ is differentiable, and $f'(x) = x f(x)$ for each $x$. The right side is continuous, so $f \in C^1$. This is the first gain: from $C^0$ to $C^1$.
4. Induction hypothesis: $f \in C^k$ for some $k \ge 1$. Then $x \mapsto x f(x)$ is in $C^k$, as a product of a polynomial and a $C^k$ function.
5. By step 3, $f' = x f$, so $f' \in C^k$. A function whose derivative is in $C^k$ is in $C^{k+1}$. So $f \in C^{k+1}$.
6. By [[mathematical induction|0ASJVEFA9J]] on $k$, with base case step 3, $f \in C^k$ for every $k$. So $f \in C^\infty$.
7. To find $f$, let $h(x) = f(x) e^{-x^2/2}$. Then $h'(x) = f'(x) e^{-x^2/2} - x f(x) e^{-x^2/2} = 0$, by step 3.
8. So $h$ is constant on $\mathbb{R}$, with $h(0) = f(0) = 1$, because the integral from $0$ to $0$ is $0$.
9. Hence $f(x) = e^{x^2/2}$.

A check of step 9: $1 + \int_0^x t\, e^{t^2/2}\, dt = 1 + \left[ e^{t^2/2} \right]_0^x = 1 + e^{x^2/2} - 1 = e^{x^2/2}$.

## Remarks

1. The equation gives one derivative more than it receives. The integral raises the regularity by one, and this gain drives the induction.
2. The bootstrap can start even lower. If $f$ is only Riemann integrable on each bounded interval, then the right side is continuous in $x$, so $f$ is continuous, and step 1 applies.
3. The step from $C^k$ to $C^{k+1}$ also gives formulas: $f'' = f + x f' = (1 + x^2) f$, and in general $f^{(k)} = p_k f$ with polynomials $p_k$ given by $p_0 = 1$ and $p_{k+1} = p_k' + x p_k$.
4. The example does not prove that $f$ is real analytic. That is true here, because $f$ is an [[exponential|0J0FCWV32D]] of a polynomial, but a regularity bootstrap alone stops at $C^\infty$.
5. The same scheme proves that solutions of $y' = F(x, y)$ with a smooth $F$ are smooth: $y \in C^k$ gives $F(x, y(x)) \in C^k$, so $y \in C^{k+1}$.

## Explanations

### L1 human

The equation says that $f$ at $x$ is $1$ plus an area under a curve built from $f$.
An area under a curve changes smoothly as we move its right edge, even when the curve itself has corners.
So $f$ is smoother than we assumed.
But then the curve under the area is smoother too, so $f$ is smoother again.
Repeating this, $f$ is as smooth as we like.

### L2 human

We compute the first derivatives of $f = e^{x^2/2}$ from remark 3 and check them.

1. $p_0 = 1$, so $f^{(0)} = f$.
2. $p_1 = p_0' + x p_0 = x$, so $f' = x f$. Direct differentiation gives $f' = x e^{x^2/2}$, which agrees.
3. $p_2 = p_1' + x p_1 = 1 + x^2$, so $f'' = (1 + x^2) f$.
4. Direct differentiation: $f'' = e^{x^2/2} + x \cdot x e^{x^2/2} = (1 + x^2) e^{x^2/2}$, which agrees.
5. $p_3 = 2x + x(1 + x^2) = 3x + x^3$, so $f'''(0) = 0$ and $f'''(1) = 4 e^{1/2}$.

The typical use of a regularity bootstrap is to show that a weak or continuous solution of a differential or integral equation is smooth.
A trap is to differentiate the equation before knowing that $f$ is differentiable.
Step 3 must come first, and it uses only the continuity of $f$.
