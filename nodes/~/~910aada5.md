## Example

For a formula $A$, let $B \mapsto B[A/\bot]$ replace each occurrence of $\bot$ in $B$ by $A$, and keep all other atomic formulas.
We show that this map does not have the main property of the [[A-translation|~10a427f4]]: it does not preserve provability in [[Heyting arithmetic|RXHJPVMPJH]].

1. Let $B = \bot \to 0 = 1$. HA proves $B$ by the rule ${\bot}\mathrm{E}$ of [[natural deduction|PAQ4ZX2TX1]], followed by ${\to}\mathrm{I}$.
2. Let $A = (0 = 0)$. Then $B[A/\bot] = (0 = 0 \to 0 = 1)$.
3. HA proves $0 = 0$, so if HA proved $B[A/\bot]$, it would prove $0 = 1$.
4. HA does not prove $0 = 1$, since every theorem of HA is true in $\N$.
5. So HA proves $B$ but not $B[A/\bot]$.

With the A-translation, $B^A = (\bot \vee A) \to (0 = 1 \vee A)$, and HA proves it by cases.

## Remarks

The example shows why the A-translation adds $A$ to every atomic formula and not only to $\bot$.
The added disjunct $A$ makes the translated atoms follow from $A$, and this repairs ex falso.
In minimal logic there is no rule ${\bot}\mathrm{E}$, and there the map $B \mapsto B[A/\bot]$ preserves provability, because $\bot$ is then an ordinary propositional symbol.
The negative translation of a classical proof can be carried out in minimal logic, and this gives the refined A-translation.

## Explanations

### L1 human

A proof may use the rule "from a contradiction, anything follows".
If we replace "contradiction" by some statement $A$ that is not a contradiction, this rule becomes "from $A$, anything follows", which is false.
For example, from "$0 = 0$" we cannot conclude "$0 = 1$".
Friedman's translation avoids this problem by also weakening every basic statement $P$ to "$P$ or $A$".

### L2 human

We compare the two maps on the formula $\neg \neg (0 = 0)$, which is $((0 = 0 \to \bot) \to \bot)$.

1. HA proves it: from $0 = 0 \to \bot$ and $0 = 0$ we get $\bot$.
2. With $A = (0 = 1)$, replacing only $\bot$ gives $(0 = 0 \to 0 = 1) \to 0 = 1$, and HA proves this by the same steps.
3. With $A = (0 = 1)$ and $B = \bot \to 0 = 0$, replacing only $\bot$ gives $0 = 1 \to 0 = 0$, which HA proves too.
4. The failure appears only when ex falso produces an atom that does not follow from $A$, as in the main example.

The typical use of the comparison is to decide which translation fits a given logic.
A trap is to test the map only on formulas without ex falso, where it looks correct.
