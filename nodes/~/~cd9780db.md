## Example

Let $\theta(e, s, X)$ be a $\Sigma^0_0$ formula that expresses "the oracle program $e$ with oracle $X$ halts on input $e$ within $s$ steps", built from the [[Kleene T predicate|S9DK13K5PS]] relativized to $X$.
Let $\mathrm{TJ}$ be the sentence
$$\forall X\, \exists Y\, \forall e\, \big( e \in Y \leftrightarrow \exists s\, \theta(e, s, X) \big),$$
which says that every set has a [[Turing jump|60P2XWY5QX]] $X'$.
We check that $\mathrm{TJ}$ is equivalent to $\mathsf{ACA}_0$ over $\mathsf{RCA}_0$, in the sense of [[reverse mathematics|TQTDKMBJ0F]].

1. $\mathsf{ACA}_0$ proves $\mathrm{TJ}$. The formula $\exists s\, \theta(e, s, X)$ has no set quantifiers, so [[arithmetical comprehension|~bffbe3ad]] gives $Y$.
2. For the reversal, work in [[RCA0|~59f891e2]] plus $\mathrm{TJ}$. Let $\varphi(n)$ be a $\Sigma^0_1$ formula, with set parameters coded into one set $X$.
3. Cited without proof: the enumeration theorem, formalized in $\mathsf{RCA}_0$, gives a primitive recursive function $g$ such that $\varphi(n) \leftrightarrow g(n) \in X'$ for all $n$.
4. $\mathrm{TJ}$ gives the set $X'$. The set $\set{n : g(n) \in X'}$ is $\Delta^0_1$ in $X'$, so $\Delta^0_1$ comprehension gives it.
5. So $\mathsf{RCA}_0 + \mathrm{TJ}$ proves $\Sigma^0_1$ comprehension.
6. $\Sigma^0_1$ comprehension proves comprehension for all arithmetical formulas, by the argument of the [[range lemma|~78eb94fe]]. So $\mathsf{RCA}_0 + \mathrm{TJ}$ proves every axiom of $\mathsf{ACA}_0$.

## Remarks

The example shows the computability content of $\mathsf{ACA}_0$.
An $\omega$-model of $\mathsf{RCA}_0$ satisfies $\mathsf{ACA}_0$ exactly when it is closed under the Turing jump.
Step 3 is the formal version of the fact that $X'$ is complete among sets that are computably enumerable in $X$.

## Explanations

### L1 human

The jump of a set $X$ is the halting problem for programs that may ask questions about $X$.
Arithmetical comprehension proves that the jump exists, since the jump is described without set quantifiers.
Conversely, once every jump exists, every arithmetically described set can be computed from finitely many jumps, so it exists.

### L2 human

The reversal uses $\mathrm{TJ}$ only for $\Sigma^0_1$ formulas, and then climbs the arithmetical hierarchy one quantifier at a time.
The typical use is to show that a theorem implies $\mathsf{ACA}_0$: one shows that it computes the jump of each set.
A trap is to apply $\mathrm{TJ}$ $n$ times for a variable $n$: the sequence $X, X', X'', \ldots$ as one set does not exist in $\mathsf{ACA}_0$.
