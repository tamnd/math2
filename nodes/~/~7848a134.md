## Example

We compute a circumscription, McCarthy's minimal-model approach to [[nonmonotonic logic|~37275fd2]].
The language has a constant $t$ and unary predicates $\mathit{Bird}$, $\mathit{Pen}$, $\mathit{Flies}$ and $\mathit{Ab}$ ("abnormal").
For predicates $P$ and $Q$, write $Q \leq P$ for $\forall x\,(Qx \to Px)$, and $Q < P$ for $Q \leq P \land \neg(P \leq Q)$.
Let
$$A(\mathit{Ab}, \mathit{Flies}) := \forall x\,\big((\mathit{Bird}\,x \land \neg\mathit{Ab}\,x) \to \mathit{Flies}\,x\big) \land \mathit{Bird}\,t.$$
The circumscription of $\mathit{Ab}$ in $A$, with $\mathit{Flies}$ allowed to vary, is the [[second-order|G6X7SZSNC5]] sentence
$$A^\star := A(\mathit{Ab}, \mathit{Flies}) \land \neg\exists Q\,\exists F\,\big(A(Q, F) \land Q < \mathit{Ab}\big).$$

Claim 1: $A^\star \vDash \mathit{Flies}\,t$.

1. Let $\mathcal{M}$ be a [[structure|983GZBQYT4]] with $\mathcal{M} \vDash A^\star$, and suppose that $\mathit{Ab}^{\mathcal{M}} \neq \emptyset$.
2. Put $Q := \emptyset$ and $F :=$ the whole domain. Then $A(Q, F)$ holds, since $F$ contains every object and $\mathit{Bird}\,t$ holds in $\mathcal{M}$.
3. Also $Q < \mathit{Ab}$, since $\emptyset \subseteq \mathit{Ab}^{\mathcal{M}}$ and $\mathit{Ab}^{\mathcal{M}} \not\subseteq \emptyset$.
4. This contradicts the second conjunct of $A^\star$. So $\mathit{Ab}^{\mathcal{M}} = \emptyset$.
5. Then $\mathit{Bird}\,t \land \neg\mathit{Ab}\,t$ holds, and the first conjunct of $A$ gives $\mathit{Flies}\,t$.

Claim 2: after we add a penguin, the conclusion fails.
Let $A'(\mathit{Ab}, \mathit{Flies}) := A(\mathit{Ab}, \mathit{Flies}) \land \mathit{Pen}\,t \land \forall x\,(\mathit{Pen}\,x \to \neg\mathit{Flies}\,x)$, and let $A'^\star$ be its circumscription in the same way.

6. Let $\mathcal{N}$ have domain $\set{t}$, with $\mathit{Bird} = \mathit{Pen} = \mathit{Ab} = \set{t}$ and $\mathit{Flies} = \emptyset$. Then $\mathcal{N} \vDash A'$.
7. The only $Q < \mathit{Ab}$ is $Q = \emptyset$. Then $A'(\emptyset, F)$ needs $F\,t$ from the first conjunct, and $\neg F\,t$ from the last one. So no such $F$ exists.
8. So $\mathcal{N} \vDash A'^\star$, and $\mathcal{N} \nvDash \mathit{Flies}\,t$.

So $A^\star \vDash \mathit{Flies}\,t$, while $A'^\star \nvDash \mathit{Flies}\,t$, although $A'$ classically implies $A$.

## Remarks

The variation of $\mathit{Flies}$ is necessary for Claim 1.
If $\mathit{Flies}$ is fixed, the structure with domain $\set{t}$, $\mathit{Bird} = \mathit{Ab} = \set{t}$ and $\mathit{Flies} = \emptyset$ satisfies the circumscription.
Its only candidate $Q = \emptyset$ fails $A(Q, \mathit{Flies})$, because $\mathit{Bird}\,t \to \mathit{Flies}\,t$ is false; and in it $\mathit{Flies}\,t$ is false.
Circumscription uses second-order logic, which has no complete proof system, so its consequence relation is not effectively enumerable in general.

## Explanations

### L1 human

Circumscription assumes that things are as normal as possible.
If we know only that Tweety is a bird, we assume that no bird is abnormal, and so Tweety flies.
If we also know that Tweety is a penguin and penguins do not fly, Tweety must be abnormal, and the conclusion goes away.

### L2 human

The circumscription axiom says that no smaller extension of $\mathit{Ab}$ would also satisfy the axioms.
In Claim 1, the empty extension works, so $\mathit{Ab}$ must be empty.
In Claim 2, the penguin axiom makes the empty extension impossible.
A trap is to keep $\mathit{Flies}$ fixed while minimizing; then a nonflying bird can be "minimally" abnormal.
