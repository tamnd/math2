## Example

The definition reads as follows.
Let $n$ be an [[integer|0C4JS9RF5M]].
We say that $n$ is *even* if there is an integer $k$ with $n = 2k$.
We say that $n$ is *odd* if there is an integer $k$ with $n = 2k + 1$.
We check that this text is a [[mathematical definition|~d1d36166]], and we use it to decide some cases.

1. The definiendum is the word "even", and the definiens is the condition "there is an integer $k$ with $n = 2k$".
2. The definiens uses only known terms: integers, multiplication by $2$, equality and the phrase "there is". It does not use the word "even", so it is not circular.
3. The "if" is read as "if and only if". So an even integer $n$ has the form $n = 2k$, and we can use this form in proofs.
4. The number $0$ is even, because $0 = 2 \cdot 0$ and $0$ is an integer.
5. The number $-6$ is even, because $-6 = 2 \cdot (-3)$ and $-3$ is an integer.
6. The number $7$ is not even. Suppose that $7 = 2k$ with an integer $k$. If $k \leq 3$, then $2k \leq 6$. If $k \geq 4$, then $2k \geq 8$. So $2k \neq 7$ for each integer $k$.
7. The number $7$ is odd, because $7 = 2 \cdot 3 + 1$.

## Remarks

1. The definition decides the borderline cases $0$ and the negative integers. Everyday language often leaves them open, but the definition does not.
2. The definitions of "even" and "odd" do not say that each integer is exactly one of the two. That is a theorem, and it follows from the [[division algorithm|0CHQKZFK5S]] with divisor $2$.
3. The domain of $k$ is part of the definiens. If we let $k$ range over the rational numbers, then each rational number $q$ is "even", because $q = 2 \cdot (q/2)$. So the words "integer $k$" carry the whole meaning.
4. If we replace $2$ by an integer $m$, the same form defines "$n$ is a multiple of $m$". For $m = 1$ each integer is a multiple, and for $m = 0$ only $0$ is a multiple.
5. Mathlib defines an element $a$ to be even when $a = r + r$ for some $r$. This is equivalent, because $r + r = 2r$.

## Explanations

### L1 human

A number is even when it splits into two equal whole parts.
For example, $10$ is even, because it is $5$ and $5$.
The definition also covers $0$, because $0$ is $0$ and $0$.
It also covers $-4$, because $-4$ is $-2$ and $-2$.
The number $9$ is not even: $4$ and $4$ make $8$, and $5$ and $5$ make $10$, so no whole number fits.

### L2 human

We prove from the definition that the square of an even integer is even.

1. Let $n$ be an even integer.
2. By the definition, there is an integer $k$ with $n = 2k$.
3. Then $n^2 = 4k^2 = 2 \cdot (2k^2)$.
4. The number $2k^2$ is an integer, because products of integers are integers.
5. So $n^2$ is two times an integer, and $n^2$ is even by the definition.

The typical use is this: unfold "even" into "$2k$", calculate, and fold the result back into "even".
A trap is the converse statement "if $n^2$ is even, then $n$ is even".
It is true, but this unfolding does not prove it, because $n^2 = 2j$ gives no formula for $n$.
A proof by contrapositive works: if $n = 2k + 1$, then $n^2 = 2(2k^2 + 2k) + 1$ is odd.
