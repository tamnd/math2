## Proof

This is an outline: the ordinal part needs Buchholz's collapsing functions, and we cite three lemmas without proof.
We use the rules 1 to 4 of the page [[Buchholz hydra|~bf22387c]].

**The hydras with labels $0$ only.**

1. If every node other than the root has the label $0$, only rules 1 and 2 apply.
2. These are the rules of the [[Kirby-Paris hydra|~360e5faf]], with $n$ copies at step $n$.
3. So the [[proof by ordinal assignment|~100c3bb3]] below $\varepsilon_0$ proves part 1 for these hydras in full.

**The ordinal of a general hydra.**

1. Buchholz's functions $\psi_\nu$, for $\nu \le \omega$, map ordinals to ordinals below $\Omega_{\nu+1}$, with $\psi_\nu(0) = \Omega_\nu$ for $\nu > 0$ and $\psi_0(0) = 1$. Here $\Omega_\nu = \aleph_\nu$ for $\nu > 0$.
2. To a node with label $\nu$ and children of values $\alpha_1, \dots, \alpha_j$ assign the value $\psi_\nu(\alpha_1 + \cdots + \alpha_j)$. The root gets the sum $\alpha_1 + \cdots + \alpha_j$.
3. For example $+(0)$ has value $\psi_0(0) = 1$, $+(0(0))$ has value $\psi_0(1) = \omega$, and $+(0(1))$ has value $\psi_0(\Omega_1) = \varepsilon_0$.
4. Every hydra has a value below the [[Takeuti-Feferman-Buchholz ordinal|S5FTQGHVKC]] $\psi_0(\varepsilon_{\Omega_\omega + 1})$. The path $R_x$ has the value $\psi_0(\psi_\omega(\psi_\omega(\cdots)))$, and these values tend to this ordinal.

**Part 1: termination.**

1. **Cited lemma 1** (Buchholz 1987). Read with suitable normal forms, the value of a hydra strictly decreases at every step, for every choice of the head and of $n$.
2. Rule 4 replaces $\psi_\omega$ by $\psi_{n+1}$, rule 3 goes to an element of a fundamental sequence, and rule 2 is the step of the Kirby-Paris hydra. Lemma 1 checks that each of these lowers the value.
3. Suppose a battle never ends. Then the values form an infinite strictly decreasing sequence of ordinals, by lemma 1.
4. This contradicts the [[well-ordering|0F1D6PK9RZ]] of the ordinals. So every battle ends, which is part 1.

**Part 3: a proof in $\mathsf{ZFC}$.**

1. The functions $\psi_\nu$ and the cardinals $\aleph_\nu$ are defined in $\mathsf{ZFC}$.
2. The ordinals are well-ordered in $\mathsf{ZFC}$. With lemma 1, the argument of Part 1 is a proof in $\mathsf{ZFC}$.

**Part 2: unprovability in $(\Pi^1_1\text{-}\mathsf{CA}) + \mathsf{BI}$.**

1. Code the terms built from $0$, $+$ and $\psi_\nu$ ($\nu \le \omega$) by numbers. Their order is decidable, and it is a well-order of type $\psi_0(\varepsilon_{\Omega_\omega + 1})$ on the terms in normal form.
2. **Cited lemma 2** (Buchholz 1987). The rules of the game follow the fundamental sequences of these terms. From this, $(\Pi^1_1\text{-}\mathsf{CA}) + \mathsf{BI}$ plus statement 1 proves [[transfinite induction|0ZHQMQ2C1N]] along the whole notation system.
3. **Cited lemma 3** (ordinal analysis). The [[proof-theoretic ordinal|C72RBH0CDR]] of $(\Pi^1_1\text{-}\mathsf{CA}) + \mathsf{BI}$ is $\psi_0(\varepsilon_{\Omega_\omega + 1})$. So this system does not prove transfinite induction along the whole notation system.
4. Suppose that $(\Pi^1_1\text{-}\mathsf{CA}) + \mathsf{BI}$ proves statement 1. Then lemma 2 gives a proof of transfinite induction along the whole notation system.
5. This contradicts lemma 3. So the system does not prove statement 1, which is part 2.

## Idea

Each hydra is the tree of an ordinal term built with Buchholz's collapsing functions, and each rule of the game moves to a smaller term.
The terms are well-ordered, so every battle ends.
The order type of the terms is the proof-theoretic ordinal of $(\Pi^1_1\text{-}\mathsf{CA}) + \mathsf{BI}$, and this system cannot prove the well-foundedness of its own ordinal.

## Variants

- The Wikipedia article cites a direct independence proof by Hamano and Okada for finite labelled trees.
- The same scheme, with ordinals below $\varepsilon_0$ in place of the collapsing functions, is the [[proof for the Kirby-Paris hydra|~100c3bb3]].
