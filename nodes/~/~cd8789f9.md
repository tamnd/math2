## Example

Let $\mathbb{C}^\times$ be the nonzero complex numbers under multiplication.
Define $\varphi \colon (\mathbb{Z}, +) \to \mathbb{C}^\times$ by $\varphi(n) = i^n$.

1. The map is a [[homomorphism|0JYTG5K9Y4]], because $i^{m+n} = i^m i^n$ by the [[laws of exponents|00DRK90Z6K]].
2. The first values are $i^0 = 1$, $i^1 = i$, $i^2 = -1$, $i^3 = -i$ and $i^4 = 1$.
3. Since $i^4 = 1$, each $n = 4q + r$ with $0 \le r \le 3$ gives $i^n = (i^4)^q i^r = i^r$.
4. So the [[image|0S21GNW9ZB]] is $\{1, i, -1, -i\}$, the group of [[fourth roots of unity|0WX11EA3F3]].
5. The element $i$ has order $4$, so $i^n = 1$ exactly when $4$ divides $n$ ([[the divisibility criterion|0F5QC101Q7]]). So the [[kernel|0W88CEGQP1]] is $4\mathbb{Z}$.
6. By the [[first isomorphism theorem|0CXXJNG5B6]], $\mathbb{Z}/4\mathbb{Z} \cong \{1, i, -1, -i\}$.

## Remarks

The example shows that an infinite group can have a finite image.
The image is a subgroup of $\mathbb{C}^\times$ with $4$ elements, although $\mathbb{C}^\times$ is infinite.
If $i$ is replaced by $e^{2\pi i/n}$, the image is the group of $n$th roots of unity and the kernel is $n\mathbb{Z}$.
If $i$ is replaced by $-1$, the image is $\{1, -1\}$ and the kernel is $2\mathbb{Z}$.
If $i$ is replaced by $2$, the image $\{2^n : n \in \mathbb{Z}\}$ is infinite, the kernel is $\{0\}$, and the map is injective.

## Explanations

### L1 human

Multiplying by $i$ turns a point of the complex plane by a quarter turn about $0$.
Four quarter turns bring each point back to its start.
So the powers of $i$ take only four values: $1$, $i$, $-1$ and $-i$.
These four values form the image, and the multiples of $4$ are the exponents that give a full turn.

### L2 human

We compute $\varphi(-6)$ and $\varphi(2023)$.

1. $-6 = 4 \cdot (-2) + 2$, so $i^{-6} = i^2 = -1$.
2. $2023 = 4 \cdot 505 + 3$, so $i^{2023} = i^3 = -i$.
3. As a check of the homomorphism rule, $\varphi(-6 + 2023) = \varphi(2017)$, and $2017 = 4 \cdot 504 + 1$ gives $i$.
4. The product is $(-1)(-i) = i$, so both ways agree.

The typical use is to reduce a large exponent modulo the order of the base.
The trap is a negative exponent: write it as $4q + r$ with $0 \le r \le 3$, so $-6$ gives $r = 2$, not $r = -2$.
