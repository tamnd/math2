## Definition

Let $L$ be a signature, let $T$ be a complete $L$-theory, and let $\lambda$ be a [[cardinal|0EBACQFAZW]] with $\lambda > \abs{L} + \aleph_0$.
A [[model|MVCH6N9SNW]] $\mathcal{M}$ of $T$ with $\abs{M} = \lambda$ is *special* if there are models $\mathcal{M}_\mu$ of $T$, one for each cardinal $\mu$ with $\abs{L} + \aleph_0 \le \mu < \lambda$, such that:

1. $\mathcal{M}_\mu \preceq \mathcal{M}_\nu$ whenever $\mu \le \nu$, so that the models form an [[elementary chain|NHCRZ74JHH]];
2. each $\mathcal{M}_\mu$ is $\mu^+$-[[saturated|RMTZ5J64FX]];
3. $M = \bigcup_\mu M_\mu$.

The family $(\mathcal{M}_\mu)$ is a *specializing chain* for $\mathcal{M}$.

## Notation

The index set is the set of cardinals in the interval $[\abs{L} + \aleph_0, \lambda)$.

## Remarks

The main page of the idea is [[special model|~82e5b5a7]].

Example: if $\mathcal{M}$ is saturated and $\abs{M} > \abs{L} + \aleph_0$, then the constant family $\mathcal{M}_\mu = \mathcal{M}$ is a specializing chain, since $\mu^+ \le \abs{M}$ for every index $\mu$.

Non-example: no specializing chain exists for $(\R, <)$; see [[the real order is not special|~a1ead269]].

## Explanations

### L1 human

A special model is a union of a growing family of models, one for each cardinal below its size, where the model at the cardinal $\mu$ is saturated for parameter sets of size $\mu$.

### L2 human

We check the example for a saturated $\mathcal{M}$ of size $\aleph_2$ in a countable language.

1. The indices are $\aleph_0$ and $\aleph_1$, and both links are $\mathcal{M}$.
2. A model is an elementary substructure of itself, and the union of the links is $M$.
3. The link at $\aleph_1$ must be $\aleph_2$-saturated, which is saturation of $\mathcal{M}$, and the link at $\aleph_0$ must be $\aleph_1$-saturated, which follows from it.

The trap is to require the link at $\mu$ to have size $\mu$: a $\mu^+$-saturated infinite model has size at least $\mu^+$.
