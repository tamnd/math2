## Proof

We use the notation of the [[statement|~f98304ff]].
Part A proves that regular languages are MSO-definable, part B the converse, part C part 3 and part D the decidability of WS1S.

**Part A: From an automaton to a sentence.**

1. Let $L \subseteq \Sigma^+$ be regular. Then a [[deterministic finite automaton|W65B6BKZRY]] $A = (Q, \Sigma, \delta, q_{\mathrm{in}}, F)$ recognizes $L$.
2. Write $\operatorname{first}(x)$ for $\neg \exists z \, (z < x)$, $\operatorname{last}(x)$ for $\neg \exists z \, (x < z)$, and $S(x, y)$ for $x < y \wedge \neg \exists z \, (x < z \wedge z < y)$. These say "first position", "last position" and "$y = x + 1$".
3. Take one set variable $X_q$ for each $q \in Q$, read as "the state after reading the letter at this position is $q$". Let $\varphi_A$ be $\exists (X_q)_{q \in Q} \, (\mathrm{Part} \wedge \mathrm{Init} \wedge \mathrm{Trans} \wedge \mathrm{Acc})$, where:
4. $\mathrm{Part}$ says that every position lies in exactly one $X_q$: $\forall x \, \bigl( \bigvee_q x \in X_q \wedge \bigwedge_{q \ne q'} \neg(x \in X_q \wedge x \in X_{q'}) \bigr)$.
5. $\mathrm{Init}$ is $\forall x \, \bigl( \operatorname{first}(x) \to \bigwedge_{a \in \Sigma} (P_a(x) \to x \in X_{\delta(q_{\mathrm{in}}, a)}) \bigr)$.
6. $\mathrm{Trans}$ is $\forall x \, \forall y \, \bigl( S(x, y) \to \bigwedge_{q \in Q, \, a \in \Sigma} ((x \in X_q \wedge P_a(y)) \to y \in X_{\delta(q, a)}) \bigr)$.
7. $\mathrm{Acc}$ is $\forall x \, \bigl( \operatorname{last}(x) \to \bigvee_{q \in F} x \in X_q \bigr)$.
8. Let $w = a_0 \cdots a_{n-1}$ and let $r_0 = q_{\mathrm{in}}$, $r_{i+1} = \delta(r_i, a_i)$ be the run of $A$ on $w$. Then $w \in L$ if and only if $r_n \in F$.
9. Suppose $r_n \in F$. Put $X_q = \set{i : r_{i+1} = q}$. Each position $i$ lies only in $X_{r_{i+1}}$, so $\mathrm{Part}$ holds. $\mathrm{Init}$ and $\mathrm{Trans}$ hold by the definition of the run. $\mathrm{Acc}$ holds because $n - 1 \in X_{r_n}$ and $r_n \in F$. So $\underline{w} \models \varphi_A$.
10. Conversely, let sets $X_q$ satisfy the four conjuncts. We show $i \in X_{r_{i+1}}$ by [[induction|0ASJVEFA9J]] on $i$. For $i = 0$ this is $\mathrm{Init}$ with $a = a_0$. If $i \in X_{r_{i+1}}$, then $\mathrm{Trans}$ with $q = r_{i+1}$ and $a = a_{i+1}$ gives $i + 1 \in X_{r_{i+2}}$.
11. By $\mathrm{Part}$, position $n - 1$ lies in $X_{r_n}$ and in no other $X_q$. By $\mathrm{Acc}$, it lies in some $X_q$ with $q \in F$. So $r_n \in F$ and $w \in L$.
12. Hence $\varphi_A$ defines $L$, and $\varphi_A$ is computed from $A$.

**Part B: From a formula to an automaton.**

13. Set formulas. Let $\mathrm{MSO}_0$ have only set variables and the atomic formulas $\operatorname{Sing}(X)$ ("$X$ has exactly one element"), $X \subseteq Y$, $X \subseteq P_a$, and $X \prec Y$ ("some element of $X$ is smaller than some element of $Y$").
14. Translate each MSO formula $\psi$ into $\psi^*$ in $\mathrm{MSO}_0$. Replace each first-order variable $x$ by a new set variable $X_x$. Put $(x < y)^* = X_x \prec X_y$, $(x = y)^* = X_x \subseteq X_y \wedge X_y \subseteq X_x$, $P_a(x)^* = X_x \subseteq P_a$, and $(x \in Y)^* = X_x \subseteq Y$. Let $*$ commute with the connectives and with $\exists Y$, and put $(\exists x \, \psi)^* = \exists X_x \, (\operatorname{Sing}(X_x) \wedge \psi^*)$.
15. For an assignment $s$, let $s^*$ send $X_x$ to $\set{s(x)}$ and keep the set variables. We claim $\underline{w} \models \psi[s]$ if and only if $\underline{w} \models \psi^*[s^*]$. The proof is a [[structural induction|12MQ2NJ29A]] on $\psi$.
16. Atomic cases: $\set{i} \prec \set{j}$ holds if and only if $i < j$; $\set{i}$ and $\set{j}$ include each other if and only if $i = j$; $\set{i} \subseteq P_a$ if and only if $a_i = a$; $\set{i} \subseteq Y$ if and only if $i \in Y$.
17. The connectives and $\exists Y$ pass through the induction unchanged. For $\exists x \, \psi$, the set variable $X_x$ ranges over singletons $\set{i}$ exactly as $x$ ranges over positions $i$, so the induction hypothesis gives the claim.
18. Coding. Fix a sentence $\varphi$, rename bound variables apart, and list the set variables $X_1, \ldots, X_m$ of $\varphi^*$. A word over $\Gamma = \Sigma \times \set{0,1}^m$ is a word $w$ over $\Sigma$ together with sets $U_1, \ldots, U_m$ of positions: $U_j$ is the set of positions where the $j$-th bit is $1$. This is a bijection between $\Gamma^+$ and such tuples.
19. For a subformula $\psi$ of $\varphi^*$, let $L_\psi$ be the set of $u \in \Gamma^+$ whose tuple $(w, U_1, \ldots, U_m)$ satisfies $\underline{w} \models \psi[X_j \mapsto U_j]$. We show by structural induction that each $L_\psi$ is regular.
20. $\operatorname{Sing}(X_j)$: two states $0$ and $1$ count the bits $1$ on track $j$; a second bit $1$ has no transition; the accepting state is $1$.
21. $X_i \subseteq X_j$: one accepting state, and no transition on letters with bit $i$ equal to $1$ and bit $j$ equal to $0$. The automaton for $X_i \subseteq P_a$ is the same, with "bit $j$ equal to $0$" replaced by "letter different from $a$".
22. $X_i \prec X_j$: states $0, 1, 2$, with $2$ accepting. Every letter loops on each state; a letter with bit $i$ equal to $1$ may also go from $0$ to $1$, and a letter with bit $j$ equal to $1$ may go from $1$ to $2$. An accepting run makes these two moves at positions $p < q$ with $p \in U_i$ and $q \in U_j$, and such positions give an accepting run.
23. Negation and conjunction. By step 18 every word of $\Gamma^+$ codes exactly one tuple, so $L_{\neg \psi} = \Gamma^+ \setminus L_\psi$ and $L_{\psi \wedge \chi} = L_\psi \cap L_\chi$. These are regular by the [[closure properties|446KZ8HJ5F]], using the [[powerset construction|DDVYP8RNG8]] for the complement.
24. Quantifier. Let $g_j$ set bit $j$ of a letter to $0$. Then $L_{\exists X_j \, \psi} = g_j^{-1}(g_j(L_\psi))$: a word lies in this set exactly when changing track $j$ gives a word of $L_\psi$, that is, when some set $U_j$ of positions is a witness. The positions are those of $w$, so no padding is needed.
25. The image $g_j(L_\psi)$ is regular: relabel the transitions of a [[nondeterministic automaton|SFMYM96C1B]]. The preimage is regular: let a deterministic automaton read $g_j(c)$ for each letter $c$.
26. The truth of the sentence $\varphi^*$ does not depend on the sets. Let $e(a) = (a, 0, \ldots, 0)$. Then $\set{w \in \Sigma^+ : \underline{w} \models \varphi} = e^{-1}(L_{\varphi^*})$ by step 15, and this language is regular. Each step is a construction, so the automaton is computed from $\varphi$.

**Part C: Satisfiability and validity over finite words.**

27. Let $\varphi$ be an MSO sentence and let $A$ be the automaton of step 26. Then $\varphi$ is true in some nonempty word if and only if $L(A) \ne \emptyset$, and true in every nonempty word if and only if $\Sigma^+ \setminus L(A) = \emptyset$.
28. Emptiness of a finite automaton is decided by a search for a path from the start state to an accepting state. So both sets of part 3 are decidable.

**Part D: WS1S.**

29. Use the translation of step 14 with $S(x, y)^* = \operatorname{Succ}(X_x, X_y)$, where $\operatorname{Succ}(X, Y)$ says $X = \set{p}$ and $Y = \set{p+1}$ for some $p$. Step 15 holds in $(\N, S)$ with finite sets, by the same induction, since singletons are finite.
30. Code a tuple of finite sets $U_1, \ldots, U_m \subseteq \N$ by any word $u$ over $\set{0,1}^m$ whose length $L$ satisfies $U_j \subseteq \set{0, \ldots, L-1}$ for all $j$. Every word codes exactly one tuple, and every tuple has the codes $u \bar 0^r$, where $\bar 0$ is the zero column.
31. Let $L_\psi$ be the set of all words whose tuple satisfies $\psi$ in $(\N, S)$. The automata of steps 20 and 21 work without change. For $\operatorname{Succ}(X_i, X_j)$ use states $0, 1, 2$ with $2$ accepting: letters with bits $(0,0)$ on tracks $i, j$ loop on $0$ and on $2$; bits $(1,0)$ go from $0$ to $1$; bits $(0,1)$ go from $1$ to $2$.
32. Negation and conjunction work as in step 23, now with $(\set{0,1}^m)^*$ in place of $\Gamma^+$, because every word codes exactly one tuple.
33. For $\exists X_j \, \psi$, a finite witness may contain positions beyond the length of the word. Let $M = g_j^{-1}(g_j(L_\psi))$. We claim $L_{\exists X_j \psi} = \set{u : u \bar 0^r \in M \text{ for some } r \ge 0}$.
34. If a finite witness $U_j$ exists, choose $r$ so that $U_j \subseteq \set{0, \ldots, |u| + r - 1}$; writing $U_j$ on track $j$ of $u \bar 0^r$ gives a word of $L_\psi$, so $u \bar 0^r \in M$. Conversely, a word of $L_\psi$ that agrees with $u \bar 0^r$ off track $j$ gives a finite witness, since $u$ and $u \bar 0^r$ code the same sets.
35. The right side of step 33 is regular: in an automaton for $M$, declare accepting every state from which an accepting state is reachable by reading zero columns only. This set of states is found by a graph search.
36. For a sentence $\varphi$, the language $L_{\varphi^*}$ is either all words or empty, according to the truth of $\varphi$ in $(\N, S)$. A sentence has at least one variable, because every atomic formula has one, so $m \ge 1$. The emptiness test of step 28 decides which case holds.

Parts A and B prove part 1, their constructions prove part 2, and parts C and D prove parts 3 and 4.

## Idea

An automaton becomes a sentence by guessing its run: one set of positions for each state, with local checks of the transitions.
A sentence becomes an automaton by induction: the free variables become extra tracks of the alphabet, negation is complement, conjunction is intersection, and an existential set quantifier is the projection that forgets a track.
First-order variables are first replaced by singleton set variables, so only one kind of variable remains.
For WS1S the sets live in $\N$, and the projection must also allow extra zero columns at the end.

## Variants

One can keep first-order variables and use the alphabet $\Sigma \times \set{0,1}^m$ with the condition that the tracks of first-order variables have exactly one bit $1$; this is the same construction without the translation of step 14.
An algebraic proof replaces automata by finite monoids and uses the composition method of Feferman, Vaught and Shelah, which works by splitting a word into two parts and combining the MSO types of the parts.
An Ehrenfeucht-Fraïssé game for MSO shows that the MSO types of quantifier depth $q$ form a finite congruence on words, which gives regularity by the Myhill-Nerode theorem.
