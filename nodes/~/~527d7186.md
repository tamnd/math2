## Example

Let $T$ be the [[theory of an equivalence relation with infinitely many infinite classes|N232QBKCAA]].
Fix an uncountable cardinal $\kappa$, and let $\mathbb{M} = \kappa \times \kappa$, where $E$ holds between two pairs with the same first entry.
Then $\mathbb{M}$ has $\kappa$ classes with $\kappa$ elements each, and by quantifier elimination for $T$ it is [[saturated|RMTZ5J64FX]], so we use it as a [[monster model|EYTTQZ0E1S]].
Let $D = S_E$ be the sort of $E$-classes in $\mathbb{M}^{\mathrm{eq}}$; see [[imaginary elements|~b9c87290]].
We show that $D$ is [[stably embedded|~2e4defde]], and that every trace on $D$ is defined by a formula that uses only equality and parameters from $D$.

### Automorphisms

1. Sizes. All classes of $\mathbb{M}$ have the same cardinality $\kappa$.
2. Parameters. Let $X = \varphi(\mathbb{M}^{\mathrm{eq}}, \bar b) \cap D^n$. Replacing imaginary parameters by representatives, we may take $\bar b$ real. Let $C \subseteq D$ be the finite set of classes of the entries of $\bar b$.
3. Automorphisms. Let $\pi$ be a permutation of $D$ that fixes $C$ pointwise. For each class $Q \notin C$, choose a bijection from $Q$ onto $\pi(Q)$, by step 1, and use the identity on the classes in $C$.
4. These bijections together form a permutation of $\mathbb{M}$ that preserves $E$. So it is an [[automorphism|DSQ17TNW1C]] of $\mathbb{M}$, it fixes $\bar b$, and it induces $\pi$ on $D$.

### Invariance and definability

5. Equality types. Say that $\bar u, \bar v \in D^n$ have the same equality type over $C$ if $u_i = u_j \leftrightarrow v_i = v_j$ and $u_i = c \leftrightarrow v_i = c$ for all $i, j$ and $c \in C$.
6. Invariance. If $\bar u$ and $\bar v$ have the same equality type over $C$, some $\pi$ as in step 3 maps $\bar u$ to $\bar v$. The automorphism of step 4 fixes $\bar b$, so $\bar u \in X$ exactly when $\bar v \in X$.
7. Definability. There are finitely many equality types over $C$, and each is defined by a conjunction of formulas $u_i = u_j$, $u_i = c$ and their negations. By step 6, $X$ is the finite union of the equality types it contains.

So every trace on $D$ is definable with parameters from $D$, and the induced structure on $D$ is the pure set: each $\emptyset$-definable subset of $D^n$ is defined by equalities alone.

## Remarks

The example contrasts with [[this example|~daf6ca13]], where the same classes are imaginaries that no real tuple codes.
The sort $D$ has its own model theory, the theory of an infinite set, and stable embeddedness says that nothing from the home sort is visible on $D$.
This also follows from the general fact, since $T$ is stable.

If the classes had different sizes, the bijections of step 3 might not exist.
That is why the proof uses a model whose classes all have the same size.

## Explanations

### L1 human

Think of the teams in a large crowd, each team with infinitely many members.
Pick a few people and ask which teams have some property described with the help of those people.
The answer can only depend on which teams contain the chosen people, since everything else can be shuffled.
So the property is described by the teams alone, and naming people gives nothing new about teams.

### L2 human

We compute one trace on $D$.

1. Fix $b \in \mathbb{M}$, with class $c = b / E$.
2. Let $\varphi(u, b)$ say that some element of the class $u$ is $E$-equivalent to $b$: $\exists x \, (\pi_E(x) = u \wedge E(x, b))$.
3. Then $\varphi(\mathbb{M}^{\mathrm{eq}}, b) \cap D = \set{c}$.
4. This trace is defined by $u = c$, with the parameter $c \in D$.

The typical use is to study a quotient sort by itself, through its induced structure.
A trap is to think that the trace needs the real parameter $b$: the class $c$ is enough.
