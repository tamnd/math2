## Example

Let $P = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}$.

1. The entries $p_{12} = p_{21} = 1$ are off the diagonal and not $0$, so $P$ is not [[diagonal|0Q9PGXD9E4]].
2. Its diagonal entries are $0$, so a diagonal matrix with the same diagonal would be the zero matrix.
3. By the [[product rule|076JGP6R3T]], $P^2 = \begin{pmatrix} 0 + 1 & 0 + 0 \\ 0 + 0 & 1 + 0 \end{pmatrix} = I$.
4. The diagonal of $P^2$ is $(1, 1)$, which is not the square $(0, 0)$ of the diagonal of $P$.
5. So the rule "square the diagonal" holds for diagonal matrices only.

## Remarks

The matrix $P$ swaps the two coordinates, and it is an [[involutory matrix|~c8443172]].
It is [[diagonalisable|07SQCNV233]]: in the basis $(1, 1)^{\mathsf{T}}$, $(1, -1)^{\mathsf{T}}$ it becomes $\operatorname{diag}(1, -1)$.
So a matrix can fail to be diagonal and still be diagonal in another basis.

## Explanations

### L1 human

This matrix has its ones off the diagonal, so it is not diagonal.
It exchanges the two coordinates of a vector, and exchanging twice changes nothing.

### L2 human

Being diagonal depends on the basis, and being diagonalisable does not.
The matrix $P$ is diagonalisable but not diagonal.
