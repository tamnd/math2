## Example

The claim is: for all integers $a$, $b$, $c$, if $a \mid b$ and $b \mid c$, then $a \mid c$.
The claim contains one defined term, "divides", three times.
We apply the method of [[unpacking definitions|~2deb01cc]]: we replace each use of the term by its definition, and then the proof is a calculation.

The definition of [[divisibility|0PG2H7WKGG]]: for integers $x$ and $y$, $x \mid y$ means that there is an integer $q$ with $y = xq$.

We unpack each part of the claim.

1. The given $a \mid b$ becomes: there is an integer $s$ with $b = as$.
2. The given $b \mid c$ becomes: there is an integer $u$ with $c = bu$. The letter is new, because the two quotients can differ.
3. The goal $a \mid c$ becomes: there is an integer $t$ with $c = at$. So the task is to find $t$.
4. The words "integer", "product" and "equals" are not unpacked further. The rules of algebra for [[integers|0C4JS9RF5M]] are known, and the proof needs only them.

Now the proof is a substitution.

> Let $a$, $b$, $c$ be integers with $a \mid b$ and $b \mid c$.
> By the definition of divisibility, there are integers $s$ and $u$ with $b = as$ and $c = bu$.
> Substituting the first equation into the second gives $c = (as)u = a(su)$.
> The number $t = su$ is an integer, as a product of integers.
> So $c = at$ with an integer $t$, and hence $a \mid c$.
> $\square$

We check the result on numbers.
For $a = 2$, $b = 6$, $c = 18$ we have $s = 3$, $u = 3$ and $t = 9$, and indeed $18 = 2 \cdot 9$.

## Remarks

1. Before unpacking, the claim looks like a fact about a relation. After unpacking, it is a fact about two equations, and the proof is one line of algebra.
2. The goal unpacks to an existential statement. So the proof must name the witness $t$, here $t = su$, as the page [[proof strategies by logical form|~17497e4b]] says.
3. If we change $\mid$ to "divides with an odd quotient", the same unpacking works. The extra step is that a product of two odd integers is odd.
4. Unpacking also shows when a similar claim fails. Let "$a$ properly divides $b$" mean "$a \mid b$ and $a \ne b$". This relation is not transitive.
5. The counterexample is $a = 2$, $b = -2$, $c = 2$. Then $2$ properly divides $-2$ and $-2$ properly divides $2$, but the goal "$2 \mid 2$ and $2 \ne 2$" fails in its second part.

## Explanations

### L1 human

"$3$ divides $12$" means that $12$ is $3$ times a whole number, namely $4$.
To show that "$a$ divides $b$" and "$b$ divides $c$" give "$a$ divides $c$", we write out what each phrase means.
For example, $2$ divides $6$ because $6 = 2 \times 3$, and $6$ divides $18$ because $18 = 6 \times 3$.
Putting the two together, $18 = 2 \times 3 \times 3 = 2 \times 9$.
So $2$ divides $18$, and the same steps work for any numbers.

### L2 human

We unpack and prove: if $a \mid b$ and $a \mid c$, then $a \mid bx + cy$ for all integers $x$ and $y$.

1. Unpack the givens: $b = as$ and $c = at$ for integers $s$ and $t$.
2. Unpack the goal: we need an integer $q$ with $bx + cy = aq$.
3. Substitute: $bx + cy = asx + aty = a(sx + ty)$.
4. The number $q = sx + ty$ is an integer, so $a \mid bx + cy$.
5. Check: $a = 3$, $b = 6$, $c = 9$, $x = 2$, $y = -1$ give $bx + cy = 3 = 3 \cdot 1$, and $q = 2 \cdot 2 + 3 \cdot (-1) = 1$.

The typical use of this pattern is every exercise on divisibility, parity and congruences.
A trap is to reuse a letter, as in "$b = as$ and $c = as$"; each existential statement needs its own witness.
