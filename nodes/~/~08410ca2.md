## Example

For $n \ge 1$ let $\mathcal{M}_n$ be the set $\set{1, \dots, n}$ in the empty signature, and let $\mathcal{U}$ be a nonprincipal ultrafilter on $\N$.
Let $\mathcal{M} = \prod_n \mathcal{M}_n / \mathcal{U}$, and let $\sigma$ be the second-order sentence $\forall f \, (f \text{ injective} \to f \text{ surjective})$, where $f$ ranges over all functions from the domain to itself.
We check that $\sigma$ holds in every factor and fails in $\mathcal{M}$.

1. In a [[finite set|070R982G4B]], an injective map to itself is surjective, by counting. So $\sigma$ holds in each $\mathcal{M}_n$.
2. For each $k$, the first-order sentence "at least $k$ elements" holds in $\mathcal{M}_n$ for $n \ge k$, a cofinite set. By [[Łoś's theorem|AGYBSTD7BG]], $\mathcal{M}$ is an [[infinite set|0PWE3BCHVJ]].
3. An infinite set contains a sequence $e_0, e_1, \dots$ of distinct elements. The map $e_m \mapsto e_{m+1}$, identity elsewhere, is injective and misses $e_0$.
4. So $\sigma$ fails in $\mathcal{M}$, although its truth set is all of $\N$.

## Remarks

The example shows that Łoś's theorem is special to first-order logic, so the [[ultraproduct method|~0aa1297f]] does not transfer second-order sentences.
A second similar failure: the second-order sentence "every nonempty subset has a least element" holds in $(\N, <)$.
In a nonprincipal ultrapower of $(\N, <)$, the set of elements above all standard numbers is nonempty and has no least element.
The reason is in the quantifier step of the proof: a second-order quantifier ranges over subsets or functions of the ultraproduct, and most of them are not classes of sequences of subsets of the factors.
Łoś's theorem also fails for weak second-order logic and for $L_{\omega_1\omega}$, since both can say "the domain is finite".
If $\mathcal{U}$ is principal, every sentence of any logic is kept, since the ultraproduct is a copy of one factor.

## Explanations

### L1 human

Each finite set has a property that infinite sets lack: we cannot fit it into itself after removing an element.
An ultraproduct of larger and larger finite sets is infinite.
So it loses this property, although every piece has it.
The property speaks about all functions, not only about elements, and Łoś's theorem does not cover such statements.

### L2 human

We check step 3 for the ultraproduct $\mathcal{M}$ above.

1. Let $e_m = [(m + 1, m + 1, m + 1, \dots)]$, with the convention that the entry is $1$ when $m + 1 > n$ at index $n$.
2. For $m \neq m'$, the entries of $e_m$ and $e_{m'}$ differ at all $n > \max(m, m') + 1$, a cofinite set. So the $e_m$ are distinct.
3. The map $e_m \mapsto e_{m+1}$, identity elsewhere, is injective and does not take the value $e_0$.

The typical use of the example is as a warning before applying Łoś's theorem.
The trap is to apply the theorem to "finite", "well ordered", "complete" or "Archimedean"; none of these is first-order.
