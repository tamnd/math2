## Example

Let $M = \set{0, a, b, 1}$ with $0 < a, b < 1$ and $a, b$ incomparable, and with $\sim 0 = 1$, $\sim a = a$, $\sim b = b$.
This is a [[De Morgan algebra|5Q53XWV0QN]].
Suppose $\varphi_1, \dots, \varphi_{n - 1}$ satisfy [[the definition|~a5b71690]].

1. Values. By clause 2, $\varphi_i a \lor \sim \varphi_i a = 1$. In $M$ only $0$ and $1$ satisfy $z \lor \sim z = 1$, so $\varphi_i a \in \set{0, 1}$.
2. Chain. By clause 5, the sequence $\varphi_1 a, \dots, \varphi_{n - 1} a$ is $0, \dots, 0, 1, \dots, 1$, with $k$ zeros.
3. Symmetry. By clause 4 and $\sim a = a$, $\varphi_i a = \sim \varphi_{n - i} a$. So $\varphi_i a = 0$ iff $\varphi_{n - i} a = 1$.
4. So $i \le k$ iff $n - i > k$, for all $i$. This forces $k = \tfrac{n - 1}{2}$; for even $n$ no $k$ exists, and the axioms already fail.
5. The same holds for $b$. So $\varphi_i a = \varphi_i b$ for all $i$, and clause 6 gives $a = b$, a contradiction.

So $M$ is not a [[Łukasiewicz-Moisil algebra|~4569fbbc]] for any $n$, with any choice of operators.

## Remarks

1. $M$ is the algebra of Belnap's four values for [[first-degree entailment|KXTP4P3GHT]].
2. The argument shows more: in an $\mathbf{LM}_n$ algebra, the negation has at most one fixed point.
3. In $L_n$, the negation $1 - x$ has a fixed point iff $n$ is odd, and it is $\tfrac12$.

## Explanations

### L1 human

The Moisil questions about a value must be answered yes or no in this algebra.
A value equal to its own negation must give a symmetric pattern of answers.
There is only one such pattern, so two different self-negating values cannot be told apart.

### L2 human

1. Take $n = 3$. The allowed patterns $(\varphi_1 x, \varphi_2 x)$ are $(0, 0)$, $(0, 1)$, $(1, 1)$.
2. For $x = a$, symmetry gives $\varphi_1 a = \sim \varphi_2 a$, so the pattern is $(0, 1)$.
3. The same holds for $b$, so $a$ and $b$ get the same pattern.

The typical use: the example separates De Morgan algebras from $\mathbf{LM}_n$ algebras.
The trap: $M$ is a perfectly good De Morgan algebra; the failure comes only from the Moisil axioms.
