## Definition

Let $n \ge 1$.
The *special orthogonal group* is the set
$$SO(n) = \set{Q \in M_n(\R) : Q^TQ = I_n \text{ and } \det Q = 1}$$
of real [[orthogonal matrices|0QRBVFJ50X]] with [[determinant|0C3CFHDN6R]] $1$, with matrix multiplication as the group operation.
An element of $SO(n)$ is a *rotation* of $\R^n$.

## Notation

- Books write $SO(n)$, $SO_n(\R)$ or $SO(n, \R)$.
- Mathlib writes `Matrix.specialOrthogonalGroup n ℝ` for an index type `n`. It is defined as the matrices in `Matrix.orthogonalGroup n ℝ` with determinant `1`.

## Remarks

- $SO(n)$ is closed under products and inverses, because $\det(PQ) = \det P \det Q$ and $\det(Q^{-1}) = (\det Q)^{-1}$. So it is a group.
- For a real inner product space $V$ of finite dimension, $SO(V)$ is the group of linear isometries of $V$ with determinant $1$.
- Examples and non-examples are in the node on the [[concept|~5781ca68]].

## Explanations

### L1 human

A rotation matrix is an orthogonal matrix that does not make mirror images.
The determinant tells the two kinds apart.
It is $1$ for rotations and $-1$ for mirror images.

### L2 human

Worked check for $Q = \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}$:

1. $Q^TQ = \begin{pmatrix} 0 & 1 \\ -1 & 0 \end{pmatrix}\begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix} = I_2$, so $Q$ is orthogonal.
2. $\det Q = 0 \cdot 0 - (-1) \cdot 1 = 1$.
3. So $Q \in SO(2)$. It is the rotation by $\frac{\pi}{2}$.

A trap: $\begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}$ is orthogonal, but its determinant is $-1$, so it is not in $SO(2)$.
