## Example

For a positive integer $k$, let $d(k)$ be the [[number of divisors|0VV3ZMRF88]] of $k$.
Let $n$ be a positive integer, and let $H_n = 1 + \frac{1}{2} + \cdots + \frac{1}{n}$ be the $n$-th [[harmonic number|0NANDX7V02]].
We prove by an [[averaging argument|~f5987d03]] that some $k$ with $1 \le k \le n$ has $d(k) \ge H_n - 1$.

1. The family is the set $\set{1, \ldots, n}$, and the score of $k$ is $d(k)$.
2. The sum $\sum_{k=1}^{n} d(k)$ counts the pairs $(j, k)$ with $1 \le j, k \le n$ and $j \mid k$.
3. We count the same pairs by $j$, which is [[double counting|0F8YBHF2W3]]. For a fixed $j$, the multiples $k$ of $j$ with $k \le n$ are $j, 2j, \ldots, \lfloor n/j \rfloor j$. There are $\lfloor n/j \rfloor$ of them.
4. So $\sum_{k=1}^{n} d(k) = \sum_{j=1}^{n} \lfloor n/j \rfloor$, with the [[floor function|08GR54CKEA]].
5. For each $j$, we have $\lfloor n/j \rfloor > n/j - 1$, by the definition of the floor function.
6. So $\sum_{j=1}^{n} \lfloor n/j \rfloor > \sum_{j=1}^{n} (n/j - 1) = n H_n - n$.
7. Divide by $n$: the average of $d(k)$ over $1 \le k \le n$ is greater than $H_n - 1$.
8. By the averaging argument, some $k \le n$ has $d(k) \ge$ the average, so $d(k) > H_n - 1$.

We check the case $n = 12$.

1. The values of $d(1), \ldots, d(12)$ are $1, 2, 2, 3, 2, 4, 2, 4, 3, 4, 2, 6$. Their sum is $35$.
2. The values of $\lfloor 12/j \rfloor$ for $j = 1, \ldots, 12$ are $12, 6, 4, 3, 2, 2, 1, 1, 1, 1, 1, 1$. Their sum is also $35$, as step 4 says.
3. The average is $35/12 \approx 2.92$, and $H_{12} - 1 \approx 2.10$. So the average is greater than $H_{12} - 1$, as step 7 says.
4. Some $k \le 12$ has $d(k) \ge 35/12$, so $d(k) \ge 3$. Indeed $d(4) = 3$, and $d(12) = 6$ is larger.

## Remarks

The example shows how an average can be computed exactly when single values are irregular.
The values $d(k)$ jump up and down: $d(k) = 2$ for each prime $k$.
Their sum is a smooth function of $n$, because the count by $j$ replaces the irregular values by the regular values $\lfloor n/j \rfloor$.

The bound grows with $n$.
Since $H_n > \ln n$, the average number of divisors up to $n$ is greater than $\ln n - 1$.
For $n = 100$, the sum is $482$, the average is $4.82$, and $H_{100} - 1 \approx 4.19$.
The largest value up to $100$ is $12$, at $k = 60$, for example, so the average is far below the maximum.

## Explanations

### L1 human

The number $12$ has six divisors: $1, 2, 3, 4, 6, 12$.
The number $7$ has only two: $1$ and $7$.
If we list the divisors of every number from $1$ to $12$, we write $35$ divisors in total.
So the numbers have about three divisors each on average.
Then at least one of them must have three divisors or more.
The nice point is that we can find the total $35$ without listing the divisors: $12$ numbers are multiples of $1$, $6$ are multiples of $2$, $4$ are multiples of $3$, and so on.

### L2 human

We compute the average number of divisors up to $n = 10$ by the method of the example.

1. The values of $\lfloor 10/j \rfloor$ for $j = 1, \ldots, 10$ are $10, 5, 3, 2, 2, 1, 1, 1, 1, 1$.
2. Their sum is $27$. So $\sum_{k=1}^{10} d(k) = 27$.
3. The average is $27/10 = 2.7$, so some $k \le 10$ has $d(k) \ge 3$.
4. A check: $d(1), \ldots, d(10)$ are $1, 2, 2, 3, 2, 4, 2, 4, 3, 4$, with sum $27$.

The typical use of this count is the estimate of an average order in number theory: the average of $d(k)$ up to $n$ is close to $\ln n$.
A trap is to read the average as a typical value.
For large $n$, most integers up to $n$ have fewer than $\ln n$ divisors, and a few integers with many divisors raise the average.
The [[Hardy-Ramanujan theorem|ZJNW10PZKK]] makes the idea of a typical integer precise for the number of prime factors.
