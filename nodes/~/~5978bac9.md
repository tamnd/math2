## Example

Let $B = \{0, 1\}$ be the two-element [[Boolean algebra|0XADJKM699]], with $0 < 1$, $\neg 0 = 1$ and $\neg 1 = 0$.
Define $\square x = 1$ for both elements $x \in B$.
We check the three properties of the [[definition of a Magari algebra|~f637853d]].

1. Property 1, $\square 1 = 1$: this is the definition of $\square$ at $x = 1$.
2. Property 2, $\square(x \wedge y) = \square x \wedge \square y$: the left side is $1$ by the definition of $\square$, and the right side is $1 \wedge 1 = 1$.
3. Property 3, $\square(\square x \to x) = \square x$: the left side is $\square$ of some element, so it is $1$, and the right side is $\square x = 1$.

All three properties hold for all $x, y \in B$, so $(B, \square)$ is a [[Magari algebra|~90876855]].

## Remarks

The example shows that the operation of a Magari algebra need not satisfy $\square x \le x$: here $\square 0 = 1$ and $1 \not\le 0$.
So the formula $\square p \to p$ takes the value $\square 0 \to 0 = \neg 1 \vee 0 = 0$ under $p \mapsto 0$, and by soundness $\mathsf{GL}$ does not prove $\square p \to p$.
The algebra is the power set algebra of a frame with one point $w$ and no arrows: there $\square X = \{w\}$ for every $X$, because $w$ has no successors.
The algebra also appears in arithmetic.
Let $M$ be a model of $\mathsf{PA} + \square \bot$, where $\square \bot$ is the sentence $\neg \mathrm{Con}(\mathsf{PA})$.
Send the class of a sentence $\sigma$ in the Magari algebra of $\mathsf{PA}$ to its truth value in $M$.
This map preserves the Boolean operations, and it sends every $\square[\sigma]$ to $1$, because $\mathsf{PA} \vdash \square \bot \to \square \sigma$, so $M$ satisfies $\square \sigma$ for every $\sigma$.
The algebra also validates $\square \bot$, which is not a theorem of $\mathsf{GL}$, so this one algebra is not enough for the completeness of $\mathsf{GL}$.

If we change $\square$ to the identity map, $\square x = x$, property 3 fails at $x = 0$; see [[the identity operator is not a Magari operator|~18e74582]].
If we change $\square$ to the constant map $\square x = 0$, property 1 fails, since $\square 1 = 0$.

## Explanations

### L1 human

The algebra has only two values, "false" and "true".
We decide that "it is provable" always gives "true", whatever we put in.
Then every rule of a Magari algebra has "true" on both sides, so every rule holds.
This is what happens in a theory that proves everything, including false statements.

### L2 human

We compute the formula $\square(\square p \to p) \to \square p$ (Löb's axiom) at $p \mapsto 0$ step by step.

1. $\square p = \square 0 = 1$.
2. $\square p \to p = \neg 1 \vee 0 = 0$.
3. $\square(\square p \to p) = \square 0 = 1$.
4. The whole formula is $1 \to 1 = \neg 1 \vee 1 = 1$.

So Löb's axiom takes the value $1$, as it must in every Magari algebra.
The typical use of this small algebra is to show that a formula is not a theorem of $\mathsf{GL}$, as with $\square p \to p$ above.
A trap: an algebra in which a formula takes the value $1$ does not prove that $\mathsf{GL}$ proves the formula; $\square \bot$ is an example.
