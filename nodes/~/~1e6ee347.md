## Proof

Let $V = F^n$, viewed as an [[$F[x]$-module|~772e5994]] by $f \cdot v = f(A) v$.
For monic nonconstant $a \in F[x]$, write $\bar f$ for the class of $f$ in $F[x]/(a)$.

1. Part 1. If $X$ and $Y$ commute with $A$, then so do $X + Y$, $cX$ for $c \in F$, and $XY$, since $XYA = XAY = AXY$. The identity commutes with $A$. So $\mathcal{C}(A)$ is a subalgebra, and it contains every power $A^k$, hence $F[A]$.
2. The map $F[x] \to M_n(F)$, $f \mapsto f(A)$, is linear with image $F[A]$. By the definition of the [[minimal polynomial|03NDVCSHSB]], its kernel is $(\mu_A)$. So $F[A] \cong F[x]/(\mu_A)$, of dimension $\deg \mu_A$.
3. By the [[cyclic decomposition theorem|~168ae65b]], $\mu_A = d_r$ and $\chi_A = d_1 \cdots d_r$. So $\dim F[A] = m_r$, which proves part 1.
4. Module form. A linear map $X \colon V \to V$ is $F[x]$-linear if and only if $X(Av) = A(Xv)$ for all $v$, that is, if and only if $XA = AX$. So $\mathcal{C}(A)$ is the space of $F[x]$-module endomorphisms of $V$.
5. By the cyclic decomposition theorem, $V = Z_1 \oplus \cdots \oplus Z_r$ with $Z_i$ the [[cyclic subspace|~33677c91]] of a vector $v_i$ with annihilator $d_i$. The map $F[x] \to Z_i$, $f \mapsto f(A) v_i$, is $F[x]$-linear and onto, with kernel $(d_i)$. So $Z_i \cong F[x]/(d_i)$ as $F[x]$-modules.
6. Let $\iota_j \colon Z_j \to V$ be the inclusions and $\pi_i \colon V \to Z_i$ the projections of the direct sum. They are $F[x]$-linear, since each $Z_i$ is $A$-invariant. The map $X \mapsto (\pi_i X \iota_j)_{i,j}$ is an $F$-linear bijection from $\mathcal{C}(A)$ onto $\bigoplus_{i,j} \operatorname{Hom}_{F[x]}(Z_j, Z_i)$, with inverse $(\varphi_{ij}) \mapsto \sum_{i,j} \iota_i \varphi_{ij} \pi_j$.
7. Lemma. Let $a, b \in F[x]$ be monic and nonconstant, and $g = \gcd(a, b)$. A module map $\varphi \colon F[x]/(a) \to F[x]/(b)$ is fixed by $c = \varphi(\bar 1)$, since $\varphi(\bar f) = f \cdot \varphi(\bar 1)$.
8. Since $a \cdot \bar 1 = 0$ in $F[x]/(a)$, the class $c$ satisfies $a c = 0$ in $F[x]/(b)$. Conversely, if $c = \bar h$ with $b \mid a h$, the rule $\bar f \mapsto \overline{f h}$ is well defined, because $f \equiv f' \pmod a$ gives $f h - f' h \in (a h) \subseteq (b)$. So $\varphi \mapsto \varphi(\bar 1)$ is a linear bijection onto $K = \{\bar h \in F[x]/(b) : b \mid a h\}$.
9. Write $a = g a'$ and $b = g b'$. The [[greatest common divisor|0C8WYW4KYQ]] of $a'$ and $b'$ is $1$. Then $b \mid a h$ if and only if $b' \mid a' h$.
10. If $b' \mid a' h$, take $u, w$ with $u a' + w b' = 1$ by [[Bézout's identity|0VY3WPP9Y3]] in $F[x]$. Then $h = u a' h + w b' h$, and $b'$ divides both terms, so $b' \mid h$. The converse is direct. So $K = \{\overline{b' s} : s \in F[x]\}$.
11. The linear map $F[x] \to K$, $s \mapsto \overline{b' s}$, is onto. Its kernel is the set of $s$ with $g b' \mid b' s$, that is, $g \mid s$. So $K \cong F[x]/(g)$, and $\dim_F \operatorname{Hom}(F[x]/(a), F[x]/(b)) = \deg g$.
12. Apply the lemma with $a = d_j$ and $b = d_i$, using step 5. Since $d_1 \mid \cdots \mid d_r$, $\gcd(d_i, d_j) = d_{\min(i, j)}$, of degree $m_{\min(i, j)}$. By step 6, $\dim \mathcal{C}(A) = \sum_{i,j} m_{\min(i, j)}$, the first formula of part 2.
13. For fixed $k$, the ordered pairs $(i, j)$ with $\min(i, j) = k$ are the pairs in $\{k, \dots, r\}^2$ that are not in $\{k + 1, \dots, r\}^2$. There are $(r - k + 1)^2 - (r - k)^2 = 2r - 2k + 1$ of them. This gives the second formula of part 2.
14. Part 3. Since $n \ge 1$, we have $r \ge 1$. By part 2, $\dim \mathcal{C}(A) - n = \sum_i (2r - 2i) m_i \ge 0$. Each $m_i \ge 1$, so equality holds if and only if $r - i = 0$ for every $i$, that is, $r = 1$.
15. By step 3, $r = 1$ if and only if $\mu_A = d_1 = \chi_A$. By the [[cyclicity criterion|~55322f5b]], this holds if and only if $A$ is cyclic.
16. Part 4. If $A$ is cyclic, then $F[A] \subseteq \mathcal{C}(A)$ by step 1, and both have dimension $n$ by steps 3 and 14 ($m_1 = n$). So $F[A] = \mathcal{C}(A)$.
17. If $\mathcal{C}(A) = F[A]$, then $n \le \dim \mathcal{C}(A) = m_r \le n$ by part 3 and step 3. So $\dim \mathcal{C}(A) = n$, and $A$ is cyclic by part 3.

## Idea

The [[matrices that commute with $A$|8G3X8MPG7E]] are the module endomorphisms of $F^n_A$.
Split the module into cyclic pieces $F[x]/(d_i)$ and count the maps between each pair of pieces.
A map out of $F[x]/(a)$ is fixed by the image of $\bar 1$, and the possible images form a copy of $F[x]/(\gcd(a, b))$.

## Variants

For a cyclic $A$ there is a direct proof of part 4.
Let $v$ be a cyclic vector, and let $X$ commute with $A$.
Write $Xv = f(A) v$ for some $f \in F[x]$, which is possible since $v, Av, \dots, A^{n-1} v$ span $F^n$.
Then $X A^k v = A^k X v = f(A) A^k v$ for all $k$, so $X$ and $f(A)$ agree on a spanning set, and $X = f(A)$.
