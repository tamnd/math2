## Example

Let $F$ have the clauses $\set{p, q}$, $\set{p, \neg q}$, $\set{\neg p, r}$, $\set{\neg p, \neg r}$.
A run of the [[DPLL algorithm|K7R9D390SP]] without unit propagation splits on $p$, and then on $q$ or $r$.
Each node of the search tree carries a partial assignment $\rho$.
At each leaf some clause of $F$ is false under $\rho$.

- Leaf $p = 0, q = 0$: the clause $\set{p, q}$ is false.
- Leaf $p = 0, q = 1$: the clause $\set{p, \neg q}$ is false.
- Leaf $p = 1, r = 0$: the clause $\set{\neg p, r}$ is false.
- Leaf $p = 1, r = 1$: the clause $\set{\neg p, \neg r}$ is false.

Now label the tree from the leaves to the root.

1. Label each leaf with its false clause.
2. The node $p = 0$ splits on $q$. Its children carry $\set{p, q}$ and $\set{p, \neg q}$. Resolve on $q$ and label the node $\set{p}$, which is false under $p = 0$.
3. The node $p = 1$ splits on $r$. Resolve $\set{\neg p, r}$ and $\set{\neg p, \neg r}$ on $r$, and label it $\set{\neg p}$, which is false under $p = 1$.
4. The root splits on $p$. Resolve $\set{p}$ and $\set{\neg p}$ on $p$, and label it $\square$.

The labels form a tree-like [[resolution refutation|~586b5042]] with $7$ clauses, one for each node of the search tree.

## Remarks

The same labelling works for every unsatisfiable run.
Claim: each node with partial assignment $\rho$ gets a clause $C$ that is false under $\rho$.
The proof is by induction from the leaves.
At a leaf, the claim holds by the choice of the clause.
At a node that splits on $x$, let $C_0$ and $C_1$ be the clauses of the children for $x = 0$ and $x = 1$.
If $x \notin C_0$, then $C_0$ is already false under $\rho$, so the node gets $C_0$, and the subtree of $C_1$ is dropped.
If $\neg x \notin C_1$, the node gets $C_1$ in the same way.
Otherwise $x \in C_0$ and $\neg x \in C_1$, and the node gets the resolvent on $x$, which is false under $\rho$.
At the root, $\rho$ is empty, and the only clause false under the empty assignment is $\square$.

Unit propagation is a split in which one child is a leaf at once, so the claim covers it too.
Hence the number of nodes of a DPLL search tree is at least $S_T(F \vdash \square)$, and lower bounds for tree-like resolution are lower bounds for the running time of DPLL.

## Explanations

### L1 human

A DPLL solver tries the values of the variables one by one and backs up when a clause fails.
For this formula, it tries $p = 0$ and fails in both cases for $q$, then $p = 1$ and fails in both cases for $r$.
The record of these failures is a resolution proof: each failure is a clause, and each backtrack combines two clauses into one.

### L2 human

We check step 2 against the claim.

1. The node has $\rho = \set{p = 0}$, and it splits on $q$.
2. The child $q = 0$ has $C_0 = \set{p, q}$, and $q \in C_0$.
3. The child $q = 1$ has $C_1 = \set{p, \neg q}$, and $\neg q \in C_1$.
4. So the node gets the resolvent $\set{p}$, which is false under $p = 0$.

The typical use is to turn a lower bound for tree-like resolution into a lower bound on DPLL running time.
A trap: CDCL solvers learn clauses and reuse them, so their runs give dag-like refutations, and tree-like bounds do not apply to them.
