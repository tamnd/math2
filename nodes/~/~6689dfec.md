## Summary

Fix a positive integer $p$. A subspace of $\mathbb{R}^p$ is any subset $W \subseteq \mathbb{R}^p$ for which there is some collection $S$ of vectors in $\mathbb{R}^p$ with $W$ equal to the [[linear span|0DTY8B9HMS]] of $S$.

In this approach, a set counts as a subspace exactly when it can be built by taking all linear combinations of some chosen vectors. This is the definition used in the course text. It agrees with the usual notion of a [[linear subspace|00YC1D652K]] of $\mathbb{R}^p$.
