## Statement

Let $\cong$ be the relation on ordered pairs of [[natural numbers|0MWKJ44V5A]] in the [[construction of the integers|0NS58JP68E]], where $(a,b) \cong (c,d)$ means $a + d = b + c$.

Then $\cong$ is a [[transitive relation|0GJZW9JFZQ]]. That is, if $(a,b) \cong (c,d)$ and $(c,d) \cong (e,f)$, then $(a,b) \cong (e,f)$.

## Remarks

Add the two given equations $a + d = b + c$ and $c + f = d + e$. This gives $a + f + c + d = b + e + c + d$. Cancel $c + d$ to get $a + f = b + e$.

This is one of three steps that show the relation is an equivalence relation.
