## Counterexample

The *McKinsey formula* is $\mathrm{M} = \square \lozenge p \to \lozenge \square p$.
**Claim.** No first-order sentence $\alpha$ in the language with one binary symbol $R$ satisfies $\mathfrak{F} \models \mathrm{M} \iff \mathfrak{F} \models \alpha$ for every Kripke frame $\mathfrak{F}$.
So $\mathrm{M}$ is a modal formula without a first-order frame [[correspondent|~c216e98c]].

The frame $\mathfrak{F} = (W, R)$ has the following worlds and arrows.

- A root $w$, worlds $v_n$ and $v_n^0, v_n^1$ for $n \in \N$, and a world $z_f$ for every function $f \colon \N \to \set{0, 1}$.
- $w R v_n$ and $w R z_f$; $v_n R v_n^0$ and $v_n R v_n^1$; $v_n^i R v_n^i$; and $z_f R v_n^{f(n)}$ for every $n$.

1. Each $v_n^i$ sees only itself. So at $v_n^i$, both $\square \lozenge p$ and $\lozenge \square p$ are equivalent to $p$, and $\mathrm{M}$ holds.
2. At $v_n$ or $z_f$, all successors are of the form $v_m^i$. If $\square \lozenge p$ holds there, every successor satisfies $p$, and so also $\square p$. So $\lozenge \square p$ holds.
3. At $w$, let $\square \lozenge p$ hold under some valuation. Then each $v_n$ has a successor $v_n^{f(n)}$ with $p$, for some function $f$.
4. Then every successor of $z_f$ satisfies $p$, so $z_f \models \square p$, and $w \models \lozenge \square p$. With steps 1 to 3, $\mathfrak{F} \models \mathrm{M}$.
5. The language has one binary symbol, so it is countable. By the downward [[Löwenheim-Skolem theorem|484M0TZ1S7]], $\mathfrak{F}$ has a countable [[elementary substructure|8WZF9SBP39]] $\mathfrak{F}'$ that contains $w$ and all $v_n$, $v_n^i$.
6. $\mathfrak{F}'$ contains only countably many worlds $z_f$. List them as $z_{f_0}, z_{f_1}, \ldots$, with repetitions if needed. If there is none, the next steps hold with no $z$-worlds.
7. Define $h \colon \N \to \set{0, 1}$ by $h(2k) = 1 - f_k(2k)$ and $h(2k + 1) = f_k(2k + 1)$. On $\mathfrak{F}'$, let $V(p) = \set{v_n^{h(n)} : n \in \N}$.
8. Each $v_n$ sees $v_n^{h(n)}$, where $p$ holds, and $v_n^{1 - h(n)}$, where $p$ fails. So $v_n \models \lozenge p$ and $v_n \not\models \square p$.
9. Each $z_{f_k}$ sees $v_{2k+1}^{f_k(2k+1)}$, where $p$ holds by step 7. It also sees $v_{2k}^{f_k(2k)}$, where $p$ fails since $f_k(2k) \neq h(2k)$. So $z_{f_k} \models \lozenge p$ and $z_{f_k} \not\models \square p$.
10. The successors of $w$ in $\mathfrak{F}'$ are the $v_n$ and the $z_{f_k}$. By steps 8 and 9, $w \models \square \lozenge p$ and $w \not\models \lozenge \square p$. So $\mathfrak{F}' \not\models \mathrm{M}$.
11. If $\alpha$ corresponded to $\mathrm{M}$, then $\mathfrak{F} \models \alpha$ by step 4. Elementary substructures satisfy the same sentences, so $\mathfrak{F}' \models \alpha$ and $\mathfrak{F}' \models \mathrm{M}$. This contradicts step 10.

## Remarks

The argument uses only one property of first-order classes: closure under elementary substructures.
Frame validity of $\mathrm{M}$ is not preserved by passing to a countable elementary substructure, because the substructure loses most of the choice worlds $z_f$.
Robert Goldblatt and Johan van Benthem proved independently in 1975 that $\mathrm{M}$ is not first-order definable.
The logic $\mathsf{S4.1}$ is $\mathsf{S4} \oplus \mathrm{M}$; see [[common modal axiom schemata|FDFQFWPM4X]].
The canonicity of $\mathrm{M}$ was a long open question.
The logic $\mathsf{K4} \oplus \mathrm{M}$ is canonical, but Goldblatt proved in 1991 that $\mathsf{K} \oplus \mathrm{M}$ is not canonical.
$\mathrm{M}$ is not a [[Sahlqvist formula|~c09fa1e0]], since its antecedent $\square \lozenge p$ has a diamond under a box.
Like every modally definable class, $\mathrm{Fr}(\mathrm{M})$ is closed under bounded morphic images, generated subframes and disjoint unions, and it reflects ultrafilter extensions; see the [[Goldblatt-Thomason theorem|~4509d116]].
It is not closed under elementary equivalence.

## Explanations

### L1 human

The McKinsey axiom says: if every next step can reach a true point, then some next step stays true forever after.
The example frame makes the axiom true by offering one path for every possible choice among infinitely many pairs.
There are uncountably many choices, so a smaller copy of the frame that keeps only countably many of them misses one.
The axiom fails in the smaller copy, though first-order logic cannot see the difference between the two frames.

### L2 human

1. Take a finite version: $w$ sees $v_0$ and $v_1$, each $v_n$ sees $v_n^0$ and $v_n^1$, and these see only themselves.
2. Add $z_f$ for all four functions $f \colon \set{0, 1} \to \set{0, 1}$, with $z_f$ seeing $v_0^{f(0)}$ and $v_1^{f(1)}$.
3. Let $p$ be true exactly at $v_0^1$ and $v_1^0$. The world $z_f$ with $f(0) = 1$ and $f(1) = 0$ has $\square p$, so $\lozenge \square p$ holds at $w$.
4. Delete that world and the world $z_g$ with $g(0) = 0$ and $g(1) = 1$. The two remaining $z_f$ each see one $p$-world and one world without $p$.
5. Now $\square \lozenge p$ is true and $\lozenge \square p$ is false at $w$, so $\mathrm{M}$ fails.

In the infinite frame, step 7 chooses $h$ so that no $z$-world of $\mathfrak{F}'$ has $f = h$ or $f = 1 - h$.

The typical use of $\mathrm{M}$ is as the standard example of a non-first-order axiom that is still simple.
A trap: "not first-order definable" is a claim about frames; on a fixed model, $\mathrm{M}$ is a first-order condition through the standard translation.
