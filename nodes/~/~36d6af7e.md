## Proof

Write $Q = (q_{lm})$, so the column $q_j$ has the entries $q_{1j}, \dots, q_{nj}$.

1. Part 1. By the definition of the [[conjugate transpose|0DXKE10PHF]], $(Q^*)_{il} = \overline{q_{li}}$.
2. So $(Q^* Q)_{ij} = \sum_{l=1}^{n} \overline{q_{li}}\, q_{lj}$, by the rule for matrix products.
3. By the [[standard inner product|~a4d9ba49]], this sum is $\ip{q_j}{q_i}$. This proves part 1.
4. Part 2. $Q^* Q = I_k$ means $\ip{q_j}{q_i} = \delta_{ij}$ for all $i, j$, by part 1.
5. Since $\delta_{ij} = \delta_{ji}$, this is the condition of an [[orthonormal family|09VYHEF2VT]]. This proves part 2.
6. Part 3, first equivalence. If the columns form an [[orthonormal basis|0FWJ0VW561]], they are orthonormal, so $Q^* Q = I_n$ by part 2.
7. Conversely, if $Q^* Q = I_n$, the $n$ columns are orthonormal, so they are [[linearly independent|0JWM6GJNQW]].
8. Then $n$ independent vectors in $\mathbb{K}^n$ form a basis, by the [[right-size criterion|096V7H13H9]]. So they form an orthonormal basis.
9. Part 3, second equivalence. If $Q^* Q = I_n$, then $Q^*$ is a left inverse of the square matrix $Q$.
10. By the [[invertible matrix theorem|ACDFDABVQK]], $Q$ is invertible, and its inverse is $Q^*$. So $Q Q^* = I_n$.
11. In the same way, $Q Q^* = I_n$ makes $Q^*$ a right inverse, and the same theorem gives $Q^* Q = I_n$.
12. Part 3, third equivalence. Let $r_i = (q_{i1}, \dots, q_{in})$ be the $i$-th row, as a vector of $\mathbb{K}^n$.
13. Then $(Q Q^*)_{ij} = \sum_{l} q_{il}\, \overline{q_{jl}} = \ip{r_i}{r_j}$. So $Q Q^* = I_n$ holds exactly when the rows are orthonormal.
14. Part 4. Steps 9 and 10 show that $Q$ is invertible with $Q^{-1} = Q^*$.

## Idea

The entry $(i, j)$ of $Q^* Q$ is the inner product of column $j$ with column $i$.
So $Q^* Q = I$ is a compact way to write all the conditions $\ip{q_j}{q_i} = \delta_{ij}$ at once.
For square matrices, a one-sided inverse is a two-sided inverse, and this moves the condition from the columns to the rows.

## Variants

- Over $\mathbb{R}$ every conjugate does nothing, and the proof shows that $Q^\top Q = I$ exactly when the columns are orthonormal for the dot product.
- Instead of the invertible matrix theorem, one can use that $Q^* Q = I_n$ makes $Q$ injective, so $Q$ is bijective by the rank-nullity theorem.
