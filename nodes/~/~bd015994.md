## Statement

Let $[0, 1]$ be the real unit interval, with $x \oplus y = \min(1, x + y)$ and $\neg x = 1 - x$.

**Theorem.** $([0, 1], \oplus, \neg, 0)$ is an [[MV-algebra|QVWHWDJ5X1]].
For each $n \ge 1$, the set $L_n = \set{0, \tfrac1n, \dots, \tfrac{n-1}{n}, 1}$ is a subalgebra, so it is an MV-algebra too.
In $[0, 1]$ the derived order is the usual order, and $x \odot y = \max(0, x + y - 1)$.

## Remarks

### Why each hypothesis is needed

1. The cut at $1$ is needed: with $x \oplus y = x + y$ on $[0, 2]$, the sum leaves the set.
2. The negation must be $1 - x$: with $\neg x = x$, the law $x \oplus \neg 0 = \neg 0$ reads $x = 0$.
3. The step $\tfrac1n$ must divide $1$: $\set{0, 0.4, 1}$ is not closed, since $\neg 0.4 = 0.6$.

### Consequences

1. Some MV-algebras are not Boolean: $\tfrac12 \oplus \tfrac12 = 1 \ne \tfrac12$.
2. [[The three-element MV-algebra|~593aaada]] is $L_2$.
3. With [[Chang's completeness theorem|QM0F33QE9P]], every MV-identity is true iff it is true in $[0, 1]$.

### Converse

Not every MV-algebra embeds in $[0, 1]$: [[Chang's algebra|~28156fb0]] has an element $\varepsilon > 0$ with $n \varepsilon < 1$ for all $n$.
The MV-chains that embed in $[0, 1]$ are the archimedean ones; see Cignoli, D'Ottaviano and Mundici.

### Generalizations

1. For a totally ordered abelian group $G$ and $u > 0$, the segment $[0, u]$ with $x \oplus y = \min(u, x + y)$ and $\neg x = u - x$ is an MV-algebra.
2. For lattice-ordered groups, replace $\min$ by the lattice meet; this is [[the $\Gamma$ construction|~41795275]].

## Explanations

### L1 human

The rules of an MV-algebra were chosen to describe the numbers from $0$ to $1$ with capped addition.
This theorem checks that these numbers really obey the rules.

### L2 human

1. The hard rule is the last one: $\neg(\neg x \oplus y) \oplus y = \neg(\neg y \oplus x) \oplus x$.
2. Both sides turn out to be $\max(x, y)$.
3. So the rule says that the maximum is symmetric.

The typical use: one proves an identity in all MV-algebras by checking it on real numbers, with Chang's theorem.
The trap: that shortcut needs Chang's theorem; this statement alone gives only one direction.

### L3 human

The finite subalgebras $L_n$ are the finite MV-chains, and they give the semantics of the $(n+1)$-valued Łukasiewicz logics.
The proof is a case check, but it fixes the meaning of the last axiom: it is the symmetry of the join.
