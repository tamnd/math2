## Example

Let $X$ be a set, and let $X^X$ be the set of all [[functions|0EPAT51DXQ]] $X \to X$, with [[composition|0THBK9V825]] as the operation.
The [[identity function|0PSKT5W817]] $\mathrm{id}_X \colon X \to X$ is given by $\mathrm{id}_X(x) = x$.
We check that $\mathrm{id}_X$ is an [[identity element|07WYQPB8E3]] for composition.
Let $f \in X^X$ and $x \in X$.

1. $(f \circ \mathrm{id}_X)(x) = f(\mathrm{id}_X(x)) = f(x)$. Since this holds for each $x$, $f \circ \mathrm{id}_X = f$.
2. $(\mathrm{id}_X \circ f)(x) = \mathrm{id}_X(f(x)) = f(x)$. Since this holds for each $x$, $\mathrm{id}_X \circ f = f$.
3. By steps 1 and 2, $\mathrm{id}_X$ is a right identity and a left identity, so it is an identity element.

A concrete case: let $X = \mathbb{R}$ and $f(x) = x^2$.

4. $(f \circ \mathrm{id}_\mathbb{R})(3) = f(3) = 9$, and $(\mathrm{id}_\mathbb{R} \circ f)(3) = \mathrm{id}_\mathbb{R}(9) = 9$.

## Remarks

Since composition is also associative, $(X^X, \circ)$ is a [[monoid|0N6R902FG1]].
The identity function is a permutation, so it is also the identity of the [[symmetric group|0515A6D2Y1]] on $X$.
For functions between different sets, $f \colon X \to Y$, there are two identities: $f \circ \mathrm{id}_X = f$ and $\mathrm{id}_Y \circ f = f$.
This is the form that the identity law takes in a category.

## Explanations

### L1 human

The identity function does nothing: it sends each point to itself.
If we do a function $f$ and then do nothing, the result is $f$.
If we do nothing and then do $f$, the result is also $f$.

### L2 human

To show that two functions are equal, show that they have the same value at each point.
Here the values are both $f(x)$, so the proof is one line on each side.
The typical use is in a group of maps, such as the rotations of a square: the rotation by $0^\circ$ is the identity function and so the identity of the group.
A trap is the case of functions between different sets, where the identities on the left and on the right are different functions.
