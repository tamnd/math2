## Example

Let $P$ be a decidable property of natural numbers.
The [[drinker formula|8BMQTZZEWB]] $D = \exists x\, \forall y\, (P(x) \to P(y))$ is valid in classical logic.
Its [[no-counterexample interpretation|~42908449]] asks for a functional $X(f)$ with $P(X(f)) \to P(f(X(f)))$ for every $f : \N \to \N$.

1. Define $X(f) = 0$ if $P(f(0))$ holds, and $X(f) = f(0)$ otherwise.
2. Case $P(f(0))$: then $X = 0$, and $P(0) \to P(f(0))$ holds because its conclusion holds.
3. Case $\neg P(f(0))$: then $X = f(0)$, and $P(f(0)) \to P(f(f(0)))$ holds because its premise fails.
4. $P$ is decidable, so the two cases cover all $f$.

So $X$ satisfies the n.c.i. of $D$, with one evaluation of $P$ and at most two evaluations of $f$.

## Remarks

The two candidates $0$ and $f(0)$ form a Herbrand disjunction: $(P(0) \to P(f(0))) \vee (P(f(0)) \to P(f(f(0))))$ is a propositional tautology.
This is the shape that [[Herbrand's theorem|VZ21F10WRS]] gives for a valid formula of pure logic: finitely many terms in $f$ and a case distinction.
No computable functional of $P$ gives a witness of $D$ itself.
Suppose $F$ computes from $P$ a witness, and run it on $P$ true everywhere, with result $x_0$.
The computation reads finitely many values of $P$; make $P$ false at one point not read and different from $x_0$.
Then $F$ still returns $x_0$, but now $P(x_0)$ holds and $orall y\, P(y)$ fails, so $x_0$ is not a witness.

## Explanations

### L1 human

The drinker formula says: in a nonempty bar, there is a person such that, if that person drinks, everyone drinks.
Its classical proof does not say who the person is.
The no-counterexample interpretation lets an opponent name, for each person $x$, someone $f(x)$ who might not drink.
Then the answer is easy: ask whether $f(0)$ drinks.
If yes, person $0$ is fine for this test; if no, person $f(0)$ is fine, since that person does not drink.

### L2 human

We run $X$ with $P(n) = (n \text{ is even})$.

1. For $f(n) = n + 1$: $f(0) = 1$ is odd, so $X = 1$. The test is $P(1) \to P(2)$, true since $1$ is odd.
2. For $f(n) = 2n + 4$: $f(0) = 4$ is even, so $X = 0$. The test is $P(0) \to P(4)$, true.

The typical use is to see the n.c.i. of a valid formula of pure logic as a finite case distinction.
A trap is to think that the answer $X$ is a drinker for every test: it passes only the test $f(X)$ chosen by the opponent.
