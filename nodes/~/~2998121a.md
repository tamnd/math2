## Example

Let $A = (a_{ij})$ be the [[matrix|0VD9ZSWWJG]] with $2$ rows and $3$ columns whose entries are given by the rule $a_{ij} = 10i + j$.
We write out $A$ and read the subscripts.

1. The first subscript $i$ is the row, and it takes the values $1$ and $2$.
2. The second subscript $j$ is the column, and it takes the values $1$, $2$ and $3$.
3. Row $1$ has $a_{11} = 11$, $a_{12} = 12$, $a_{13} = 13$, and row $2$ has $a_{21} = 21$, $a_{22} = 22$, $a_{23} = 23$. So
$$A = \begin{pmatrix} 11 & 12 & 13 \\ 21 & 22 & 23 \end{pmatrix}.$$
4. The order of the subscripts matters: $a_{12} = 12$ but $a_{21} = 21$.
5. The entry $a_{31}$ does not exist, because $A$ has no third row.
6. The [[transpose|09DXWYRD43]] $A^{\mathsf{T}}$ has entries $b_{ij} = a_{ji}$, so it is a $3 \times 2$ matrix with $b_{12} = a_{21} = 21$.

## Remarks

The example shows how two subscripts name each entry of a rectangular array by its row and its column.
The rule $a_{ij} = 10i + j$ makes the convention visible, since the tens digit is the row and the units digit is the column.
For a matrix with $10$ or more columns this rule fails, because the entry $a_{1,10}$ would equal $20$, the same as $a_{21}$.
A comma between the subscripts, as in $a_{1,10}$, is needed once a subscript has two digits.

## Explanations

### L1 human

A matrix is a table of numbers.
To point at one number, we give its row and its column, as in a seat number "row 2, seat 3".
In the matrix above, the number in row $2$ and column $3$ is $23$, and we write $a_{23} = 23$.
The row always comes first.

### L2 human

We compute one entry of a product to see the subscripts at work.

1. Let $B = A^{\mathsf{T}}$, the $3 \times 2$ matrix with $b_{ij} = a_{ji}$.
2. The product $C = AB$ is $2 \times 2$, with $c_{ij} = \sum_{k=1}^{3} a_{ik} b_{kj}$.
3. For $i = j = 1$ this gives $c_{11} = a_{11} a_{11} + a_{12} a_{12} + a_{13} a_{13} = 121 + 144 + 169 = 434$.
4. The repeated index $k$ is bound by the sum, and the free indices $i$ and $j$ name the entry of $C$.

The typical use of index notation is to prove identities such as $(AB)^{\mathsf{T}} = B^{\mathsf{T}} A^{\mathsf{T}}$ entry by entry.
A trap: some books, and some programming languages, number rows and columns from $0$, so their $a_{00}$ is our $a_{11}$.
