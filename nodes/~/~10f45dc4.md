## Example

Let $L_A = \set{0, S, +, \cdot}$ be the signature of arithmetic, and let $\mathfrak{N} = (\N, 0, S, +, \cdot)$ be the standard structure.
True arithmetic is the theory $\mathrm{TA} = \operatorname{Th}(\mathfrak{N})$, the set of all $L_A$-sentences that are true in $\mathfrak{N}$.
We show that $\mathrm{TA}$ is not a [[recursively axiomatizable theory|3ANXZC3BEG]]: no decidable set $\Sigma$ of sentences satisfies $\operatorname{Thm}(\Sigma) = \operatorname{Thm}(\mathrm{TA})$.

1. $\mathrm{TA}$ is closed under derivation. If $\mathrm{TA} \vdash \sigma$, then $\sigma$ is true in the model $\mathfrak{N}$ of $\mathrm{TA}$, by the [[soundness theorem|~331f6430]]. So $\operatorname{Thm}(\mathrm{TA}) = \mathrm{TA}$.
2. $\mathrm{TA}$ is [[complete|655K8Y7VS8]]. For each sentence $\sigma$, either $\sigma$ or $\neg \sigma$ is true in $\mathfrak{N}$, so one of them lies in $\mathrm{TA}$.
3. Suppose, for a contradiction, that $\Sigma$ is a decidable set of sentences with $\operatorname{Thm}(\Sigma) = \mathrm{TA}$.
4. $\Sigma$ is consistent. Its theorems are true in $\mathfrak{N}$, so no sentence $\sigma$ has both $\Sigma \vdash \sigma$ and $\Sigma \vdash \neg \sigma$.
5. $\Sigma$ is [[computably enumerable|TN9G24VABN]], because every [[computable set|PPGD5KW8JC]] is computably enumerable.
6. $\Sigma$ proves every axiom of [[Robinson arithmetic|3K1AKGXF8A]] $\mathsf{Q}$. Each such axiom is true in $\mathfrak{N}$, so it lies in $\mathrm{TA} = \operatorname{Thm}(\Sigma)$.
7. By steps 4, 5 and 6, the first of [[Gödel's incompleteness theorems|X9WYNYE29C]] applies to the theory with axioms $\Sigma$. It gives a sentence $G$ with $\Sigma \nvdash G$ and $\Sigma \nvdash \neg G$.
8. By step 2, $G$ or $\neg G$ lies in $\mathrm{TA} = \operatorname{Thm}(\Sigma)$. So $\Sigma \vdash G$ or $\Sigma \vdash \neg G$, which contradicts step 7.
9. So no such $\Sigma$ exists, and $\mathrm{TA}$ is not recursively axiomatizable.

## Remarks

The example shows that completeness alone does not give a decidable theory.
Property 5 of the main page needs a recursive axiomatization, and $\mathrm{TA}$ has none.

$\mathrm{TA}$ is not even computably enumerable.
If it were, then by [[Craig's theorem on axiomatizability|~3da5e788]] it would have a decidable set of axioms, against step 9.
By [[Tarski's undefinability theorem|YRV6SYK2BY]], $\mathrm{TA}$ is not even definable by a formula of $L_A$.

The example changes when we remove multiplication.
The theory of $(\N, 0, 1, +)$ is [[Presburger arithmetic|B66JYY3K58]], which is complete, recursively axiomatizable and decidable.
The first incompleteness theorem does not apply there, because the axioms of $\mathsf{Q}$ mention multiplication.

The example [[true arithmetic taken as a set of axioms|9BW1F5B5GA]] uses the same argument to show that $\mathrm{TA}$ itself is not a decidable set of axioms.
Here we show more: no decidable set of axioms at all has the same theorems as $\mathrm{TA}$.

## Explanations

### L1 human

True arithmetic is the collection of all true statements about whole numbers with addition and multiplication.
It answers every question: for each statement, the statement or its opposite is true.
One might hope to find a list of axioms, checkable by a computer, from which exactly these true statements follow.
Gödel's theorem says that this is impossible.
Every checkable list that proves only true statements leaves some true statement unproved.

### L2 human

We compare the argument with the [[Peano axioms|0QFT7Z76N5]].

1. The axioms of $\mathsf{PA}$ are true in $\mathfrak{N}$, so $\operatorname{Thm}(\mathsf{PA}) \subseteq \mathrm{TA}$.
2. The axioms of $\mathsf{PA}$ form a decidable set, so steps 4 to 7 apply to $\Sigma = \mathsf{PA}$. They give a sentence $G$ that $\mathsf{PA}$ neither proves nor refutes.
3. One of $G$ and $\neg G$ is true in $\mathfrak{N}$, so it lies in $\mathrm{TA}$ but not in $\operatorname{Thm}(\mathsf{PA})$.
4. So $\operatorname{Thm}(\mathsf{PA})$ is a proper subset of $\mathrm{TA}$.

Adding the missing sentence to $\mathsf{PA}$ gives a new decidable set of axioms, and the argument starts again with a new sentence.
The typical use of this example is to separate two properties of a theory: completeness and recursive axiomatizability.
A trap is to read the result as "some true sentences have no proof"; each sentence of $\mathrm{TA}$ has a proof from $\mathrm{TA}$, but $\mathrm{TA}$ is not a decidable set of axioms.
