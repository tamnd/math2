## Example

Wikipedia describes a fan controller with rules such as "IF temperature IS warm THEN fan_speed is moderate".
We take a small version with two rules and compute its output.

Temperatures $t$ are in degrees Celsius.
The [[fuzzy sets|GV9NVFFFXF]] "warm" and "hot" have membership functions $w(t) = \max(0, 1 - |t - 20| / 10)$ and $h(t) = \min(1, \max(0, (t - 20) / 10))$.
Rule 1: IF temperature IS warm THEN fan_speed IS moderate, with representative speed $50$.
Rule 2: IF temperature IS hot THEN fan_speed IS high, with representative speed $100$.
In place of the center-of-weight step, we use the weighted average of the representative speeds.

1. Fuzzification at $t = 25$: $w(25) = 0.5$ and $h(25) = 0.5$.
2. Each rule fires with the degree of its condition: $0.5$ and $0.5$.
3. Defuzzification: $(0.5 \cdot 50 + 0.5 \cdot 100) / (0.5 + 0.5) = 75$.
4. At $t = 28$: $w = 0.2$, $h = 0.8$, and the output is $(0.2 \cdot 50 + 0.8 \cdot 100) / 1 = 90$.
5. The controller is a function from temperatures to speeds: $t \mapsto$ speed.
6. No set of formulas, no consequence relation and no notion of tautology occurs in steps 1 to 4.

So this is "fuzzy logic" only in the broad, engineering sense.
It is not a logic in the sense of [[mathematical fuzzy logic|~b4bfdbf0]], where one asks which formulas follow from which premises.

## Remarks

1. SEP separates the two senses: the broad sense, used in fuzzy control and soft computing, aims at efficient computation; the narrow sense is a branch of mathematical logic.
2. The rule "IF warm THEN moderate" is not read as an implication with a truth value; the degree of the condition is copied to the output, as Wikipedia states.
3. The same controller can be described with t-norms and t-conorms, but this does not turn it into a consequence relation.

## Explanations

### L1 human

A fuzzy fan controller reads a temperature and sets a fan speed.
It uses words like "warm" and "hot" with degrees.
It does not prove anything; it only computes a number.

### L2 human

1. Compute the degree of each condition from the input.
2. Fire each rule with that degree.
3. Combine the outputs into one number.

A trap: the word "logic" in "fuzzy logic controller" does not mean that the device has a consequence relation.
When a question asks about completeness or tautologies, it is about the narrow sense.
