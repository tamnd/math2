## Example

We show that $\mathsf{CAC}$ implies $\mathsf{ADS}$ over [[RCA0|~58b63877]], an arrow of the [[reverse mathematics zoo|~00f7bd45]] found by Hirschfeldt and Shore.
Let $(L, \prec)$ be a [[linear order|0FRXBVVR03]] with $L \subseteq \N$ infinite, and write $x \preceq y$ for "$x \prec y$ or $x = y$".
An *ascending sequence* is an infinite set $S \subseteq L$ such that $x \prec y$ for all $x < y$ in $S$.
A *descending sequence* is an infinite set $S \subseteq L$ such that $y \prec x$ for all $x < y$ in $S$.
$\mathsf{ADS}$ says that every such $(L, \prec)$ has an ascending or a descending sequence.
We argue in $\mathsf{RCA}_0 + \mathsf{CAC}$.

1. Define a relation $\trianglelefteq$ on $L$ by $x \trianglelefteq y$ if and only if $x \le y$ and $x \preceq y$. It exists by $\Delta^0_1$ comprehension, since its definition has no unbounded quantifier.
2. $\trianglelefteq$ is reflexive, because $x \le x$ and $x \preceq x$.
3. $\trianglelefteq$ is antisymmetric: $x \trianglelefteq y$ and $y \trianglelefteq x$ give $x \le y \le x$, so $x = y$.
4. $\trianglelefteq$ is transitive, because both $\le$ and $\preceq$ are transitive. So $(L, \trianglelefteq)$ is an infinite [[partial order|0QV2JS9RJ3]].
5. By $\mathsf{CAC}$ there is an infinite set $C \subseteq L$ that is a chain or an [[antichain|03HF498P1J]] for $\trianglelefteq$.
6. Let $C$ be a chain and let $x < y$ be in $C$. Then $x \trianglelefteq y$ or $y \trianglelefteq x$. The second fails, because it needs $y \le x$. So $x \preceq y$, and $x \prec y$ since $x \ne y$. So $C$ is an ascending sequence.
7. Let $C$ be an antichain and let $x < y$ be in $C$. Then $x \trianglelefteq y$ fails. Since $x \le y$ holds, $x \preceq y$ fails. As $\prec$ is linear, $y \prec x$. So $C$ is a descending sequence.
8. Steps 6 and 7 cover both cases, so $(L, \prec)$ has an ascending or a descending sequence. This is $\mathsf{ADS}$.

## Remarks

The relation of step 1 is the intersection of two linear orders, the order of the numbers and the order $\prec$.
A chain is a set where the two orders agree, and an antichain is a set where they disagree.
Whether $\mathsf{ADS}$ implies $\mathsf{CAC}$ was asked by Hirschfeldt and Shore, and Lerman, Solomon and Towsner showed that it does not.
A partial order with $n^2 + 1$ elements has a chain or an antichain with $n + 1$ elements, by Dilworth's theorem.
With this finite form in place of $\mathsf{CAC}$, the same proof gives the Erdős-Szekeres theorem: a list of $n^2 + 1$ distinct numbers has an increasing or a decreasing sub-list of length $n + 1$.

## Explanations

### L1 human

Write a list of different numbers in some order, for example $5, 2, 8, 1, 9, 3$.
Two positions agree when the later number is larger, and disagree when it is smaller.
A set of positions that all agree gives a sub-list that goes up, such as $5, 8, 9$.
A set of positions that all disagree gives a sub-list that goes down, such as $5, 2, 1$.
The chain-antichain principle finds an endless set of one of the two kinds.

### L2 human

Take $L = \N$ with the order $\prec$ given by $x \prec y$ if $x$ is even and $y$ is odd, or if $x, y$ are both even with $x < y$, or both odd with $x > y$.
So the order is $0 \prec 2 \prec 4 \prec \cdots \prec \cdots \prec 5 \prec 3 \prec 1$.

1. The even numbers form a chain for $\trianglelefteq$: for even $x < y$ we have $x \prec y$.
2. The odd numbers form an antichain for $\trianglelefteq$: for odd $x < y$ we have $y \prec x$.
3. So the even numbers give an ascending sequence, and the odd numbers give a descending sequence.

The typical use: to show that a principle about linear orders is no stronger than a principle about partial orders.
The trap: the antichain case needs that $\prec$ is linear, in step 7; for a partial order $\prec$ the incomparable pairs would give neither direction.
