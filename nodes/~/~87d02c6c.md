## Example

The drastic [[t-norm|~a4e21349]] is $x *_D y = y$ if $x = 1$, $x$ if $y = 1$, and $0$ otherwise.
Wikipedia states that it is the pointwise smallest t-norm, and that it is right-continuous.

1. Fix $x = 0.5$ and $y = 0$, and let $Z = \set{z : z *_D 0.5 \le 0}$.
2. For $z < 1$: $z \neq 1$ and $0.5 \neq 1$, so $z *_D 0.5 = 0 \le 0$, and $z \in Z$.
3. For $z = 1$: $1 *_D 0.5 = 0.5 > 0$, so $1 \notin Z$.
4. So $Z = [0, 1)$, which has no greatest element.
5. A residuum would give $Z = \set{z : z \le 0.5 \Rightarrow 0} = [0, r]$ with $r = 0.5 \Rightarrow 0$.
6. $[0, 1) \neq [0, r]$ for every $r$, so no residuum exists.
7. Left-continuity fails at the same place: $z_n = 1 - \tfrac1n \uparrow 1$, but $z_n *_D 0.5 = 0 \not\to 0.5 = 1 *_D 0.5$.

This agrees with [[the left-continuity statement|~42fe79f8]].

## Remarks

1. The semantics of MTL uses left-continuous t-norms, so the drastic t-norm is not one of its standard models.
2. The drastic t-norm is a lower bound for all t-norms, but it gives no implication and so no fuzzy logic in the sense of residuated t-norm logics.

## Explanations

### L1 human

The drastic "and" is zero unless one input is fully true.
Then there is no best value for "if $0.5$ then $0$": every value below $1$ works, and $1$ fails.

### L2 human

1. Fix $x$ and $y$.
2. Find the set of $z$ with $z * x \le y$.
3. If the set has no maximum, there is no residuum.

A trap: the drastic t-norm is still a t-norm; it fails only left-continuity.
