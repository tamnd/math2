## Definition

Let $U$ be an open subset of $\mathbb{R}^n$ and let $f : U \to \mathbb{R}^n$ be a function.
A first integral of the [[autonomous system|~b82910c9]] $x' = f(x)$ is a continuously differentiable function $H : U \to \mathbb{R}$ such that
$$\nabla H(x) \cdot f(x) = 0 \quad \text{for each } x \in U,$$
and such that $H$ is not constant on any non-empty open subset of $U$.

## Remarks

The condition means that $\frac{d}{dt} H(\gamma(t)) = 0$ for each [[solution|~31ca077a]] $\gamma$. So $H$ is constant along each solution.
Each [[trajectory|~8ab688bc]] lies in a level set $\{x : H(x) = c\}$. In the plane, the level curves of $H$ give the phase portrait.
For the [[harmonic oscillator|~f0623e61]] $x' = y$, $y' = -x$, the function $H(x, y) = x^2 + y^2$ is a first integral.
The Hamiltonian of a time-independent [[Hamiltonian system|~8edd4c55]] is a first integral.

## Explanations

### L1 human

A first integral is a quantity that does not change while the system moves, such as the energy of a system without friction.
Knowing it tells us that each motion stays on one level set of this quantity.
