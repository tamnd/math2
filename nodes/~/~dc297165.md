## Summary

The parametric form of the solution set of a consistent [[linear system|0GT4WWGWH2]] $Ax = b$ over a field $F$ writes every solution as
$$x = p + t_1 v_1 + \dots + t_k v_k, \qquad t_1, \dots, t_k \in F,$$
where $k$ is the number of [[free variables|0J0BBCMJ5W]].
We find it from the [[reduced row echelon form|0WF5AQYTW6]] of $[A \mid b]$: each free variable becomes a parameter $t_l$, and each row gives one basic variable in terms of the parameters.
The vector $p$ is the solution with all parameters $0$, and $v_l$ is the coefficient vector of $t_l$.
Every choice of $(t_1, \dots, t_k)$ gives exactly one solution, and every solution comes from exactly one choice, by [[the lemma on systems in RREF|~e45eea91]].
The parametric form matters because it describes an infinite solution set with finitely many vectors and shows its shape.

## Motivation

A system with free variables has many solutions over $\R$, so we cannot list them.
The parametric form lists a starting point and a few directions instead.
Over $\R^n$ this shows the geometry: the solution set is a point, a line, a plane, or a flat of higher dimension.

## Notation

1. The scalar form gives each variable separately, for example $x_1 = 3 - 2t$, $x_2 = 1 + t$, $x_3 = t$.
2. The vector form groups the same data as $x = (3, 1, 0) + t(-2, 1, 1)$; Lay calls this the parametric vector form.
3. Some books call the parametric form the general solution of the system.

## Remarks

### Examples

1. In [[two planes meeting in a line|~f4f0e07b]] the solution set is $(2, 1, 0) + t(-2, 1, 1)$, a line in $\R^3$.
2. In [[a linear equation whose solutions form a plane|~a1d8c718]] one equation in three unknowns gives two parameters, a plane.
3. In [[a homogeneous system with two free variables|~1916a6fe]] we get $p = 0$ and two direction vectors.
4. In [[a system solved by Gauss-Jordan elimination|~68d3db07]] the solution set is a line in $\R^4$.
5. A system with a unique solution has $k = 0$, and its parametric form is the single point $p$.

### Non-examples

1. [[Redundant parameters for a line|~3dd1af28]] describes the right set with two parameters, but different parameter values give the same point.
2. An inconsistent system, such as $x + y = 1$, $x + y = 2$, has no parametric form, since there is no point $p$.
3. The description $\set{(x, y) : x + y = 1}$ is an implicit form by an equation, not a parametric form.

### Basic properties

1. The vector $p$ is one particular solution of $Ax = b$.
2. Each $v_l$ is a solution of the homogeneous system $Ax = 0$.
3. The vectors $v_1, \dots, v_k$ are linearly independent: entry $f_l$ of $v_l$ is $1$, and entry $f_l$ of every other $v_j$ is $0$, where $f_l$ is the column of the $l$-th free variable.
4. So $v_1, \dots, v_k$ form a basis of the null space of $A$, and $k = n - \operatorname{rank} A$, see [[the structure of the solution set|~a01a76ca]].
5. Over a field with $q$ elements the solution set has $q^k$ elements, see [[the theorem on finite fields|~b461276f]].

### History

The parametric vector form, and the picture of the solution set as a translated span, is the theme of Lay, Section 1.5.

### Common errors

1. Taking a basic variable as a parameter; the parameters must be the free variables, or else some choices give no solution.
2. Reading the parametric form from an echelon form that is not reduced, without back substitution.
3. Forgetting the entry $1$ of $v_l$ in the position of its own free variable.

## Explanations

### L1 human

When a system has many solutions, we describe them all with a formula.
We choose the free unknowns as we like, and we give each one a letter such as $t$.
The other unknowns are then fixed by the equations.
For example, for $x + y = 2$ the solutions are $x = 2 - t$, $y = t$, that is, $(2, 0) + t(-1, 1)$.

### L2 human

We find the parametric form of the solutions of $x_1 + 2x_2 - x_3 = 1$, $x_3 = 2$ over $\R$.

1. The augmented matrix $\left[\begin{array}{rrr|r} 1 & 2 & -1 & 1 \\ 0 & 0 & 1 & 2 \end{array}\right]$ is in echelon form.
2. $R_1 \leftarrow R_1 + R_2$ gives the RREF row $(1, 2, 0 \mid 3)$.
3. The pivots are in columns 1 and 3, so $x_2$ is free; put $x_2 = t$.
4. The rows give $x_1 = 3 - 2t$ and $x_3 = 2$.
5. So $x = (3, 0, 2) + t(-2, 1, 0)$, a line in $\R^3$.
6. Check: $(3 - 2t) + 2t - 2 = 1$ and $x_3 = 2$, for every $t$.

The typical use is to describe the general solution of a system with free variables.
A trap: the parametric form is not unique; another particular solution, or another basis of the null space, gives the same set.

### L3 human

The parametric form is a bijection $F^k \to S$, $t \mapsto p + Vt$, where $V$ is the $n \times k$ matrix with columns $v_l$.
It is an affine isomorphism of $F^k$ onto the affine subspace $S$, see [[affine subspace|0PYW26VNT6]].
In geometry this is the same as the [[vector equation of a line|0399QFDFS8]] for $k = 1$, and the parametric equation of a [[plane|07SDJ5DNE4]] for $k = 2$.
