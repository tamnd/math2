## Description

The empty set is the [[set|~bd92ceee]] that has no [[elements|~6dec28e3]].
It is written $\varnothing$ or $\{\}$.
For each object $x$, $x \notin \varnothing$.
By the [[axiom of extensionality|~4ca8988d]], there is only one empty set.

## Remarks

The empty set is a [[subset|~a9b9ba7e]] of every set. This is a case of [[vacuous truth|~26fa0ba2]].
Its [[cardinality|~ec7b0a04]] is $0$.
The set $\{\varnothing\}$ is not empty: it has one element.

## Explanations

### L1 human

The empty set is an empty bag.
For example, the set of real numbers $x$ with $x^2 = -1$ is empty.
It is useful in the same way that the number $0$ is useful.
