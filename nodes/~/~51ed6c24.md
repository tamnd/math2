## Example

Let $M$ have states $s_0, s_1, s_2$ with edges $s_0 \to s_0$, $s_0 \to s_1$, $s_1 \to s_2$, $s_2 \to s_2$.
Let $L(s_0) = L(s_2) = \set{p}$ and $L(s_1) = \emptyset$.
We compare the [[LTL|8S64VZ6A1S]] formula $FGp$, read on all paths, with the [[CTL|1DA0Y6KDF8]] formula $AF\,AG\,p$.

1. The paths from $s_0$ are $s_0^\omega$ and $s_0^n s_1 s_2^\omega$ for $n \ge 1$.
2. On $s_0^\omega$, $p$ holds everywhere, so $FGp$ holds.
3. On $s_0^n s_1 s_2^\omega$, $p$ holds from position $n + 1$ on, so $FGp$ holds.
4. So every path from $s_0$ satisfies $FGp$, and $s_0$ satisfies $FGp$ in the LTL sense.
5. Now $[\![ AG\,p ]\!] = \set{s_2}$: from $s_0$ the state $s_1$ is reachable, and $s_1$ fails $p$.
6. $AF\,AG\,p$ at $s_0$ needs every path to reach $s_2$. The path $s_0^\omega$ never does.
7. So $s_0 \not\models AF\,AG\,p$, although $s_0$ satisfies $FGp$ on all paths.

## Remarks

Every state that satisfies $AF\,AG\,p$ satisfies $FGp$ on all paths, so the CTL formula is strictly stronger.
On the path $s_0^\omega$, each state still has the option to leave through $s_1$, so no point of the path satisfies $AG\,p$.
Emerson and Halpern showed that no CTL formula is equivalent to $FGp$ on all paths.
With [[the LTL non-example|~4085e024]], this shows that LTL and CTL are incomparable, and [[CTL*|~2b6e0b85]] contains both.

## Explanations

### L1 human

A light is on, and at any moment it may flicker off once and then stay on forever.
On every run, the light is in the end on for good.
But at no moment while it waits can we say "from now on it is on for good", because the flicker is still possible.

### L2 human

1. List the paths and check $FGp$ on each.
2. Compute $[\![ AG\,p ]\!]$ as a set of states.
3. Check whether every path reaches that set.

A trap: CTL quantifies over paths again at each state, so "eventually always" in CTL is about the whole future tree at a point, not about the rest of one path.
