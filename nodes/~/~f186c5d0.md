## Example

Let $G = \mathbb{Z}/6 = \{0, 1, 2, 3, 4, 5\}$ be the [[integers modulo $6$|03VFZ2WETT]] under addition modulo $6$.
In additive notation, the [[subgroup generated|0RP7VWQ0YN]] by $a$ and $b$ is $\langle a, b \rangle = \{xa + yb : x, y \in \mathbb{Z}\}$, with the sums taken modulo $6$.
A [[generating set|0MBV2VHMXA]] $S$ of $G$ is minimal when no proper subset of $S$ generates $G$.
We show that $\{1\}$ and $\{2, 3\}$ are both minimal generating sets.

1. The set $\{1\}$ generates $G$: each $k \in G$ is $k \cdot 1$.
2. The set $\{1\}$ is minimal: its only proper subset is $\emptyset$, and $\langle \emptyset \rangle = \{0\} \neq G$.
3. The set $\{2, 3\}$ generates $G$: $1 = 3 - 2 \in \langle 2, 3 \rangle$, so $\langle 1 \rangle = G$ lies in $\langle 2, 3 \rangle$.
4. The subset $\{2\}$ does not generate $G$: the multiples of $2$ modulo $6$ are $2, 4, 0$, so $\langle 2 \rangle = \{0, 2, 4\}$.
5. The subset $\{3\}$ does not generate $G$: the multiples of $3$ modulo $6$ are $3, 0$, so $\langle 3 \rangle = \{0, 3\}$.
6. The subset $\emptyset$ generates only $\{0\}$. By steps 4 to 6, no proper subset of $\{2, 3\}$ generates $G$, so $\{2, 3\}$ is minimal.

So $G$ has a minimal generating set with $1$ element and a minimal generating set with $2$ elements.
The smallest size is $d(\mathbb{Z}/6) = 1$.

## Remarks

The example shows that the minimal generating sets of a group need not have the same size.
In a vector space this cannot happen: each minimal spanning set is a basis, and all bases have the same size.

The orders of the elements $0, 1, 2, 3, 4, 5$ are $1, 6, 3, 2, 3, 6$.
The minimal generating sets of $\mathbb{Z}/6$ are exactly $\{1\}$, $\{5\}$, $\{2, 3\}$ and $\{3, 4\}$.
In each set of size $2$, one element has order $2$ and the other has order $3$.
This reflects the fact that $\mathbb{Z}/6$ is the direct product of its subgroups $\{0, 3\}$ of order $2$ and $\{0, 2, 4\}$ of order $3$.

The same idea works for $\mathbb{Z}/pq$ with distinct primes $p$ and $q$: the set $\{p, q\}$ generates, because $\gcd(p, q) = 1$.
It is minimal, because $\gcd(p, pq) = p \neq 1$ and $\gcd(q, pq) = q \neq 1$, so neither $p$ nor $q$ generates $\mathbb{Z}/pq$ alone.
For a prime power $p^k$, it does not work.
The subgroups of $\mathbb{Z}/p^k$ form a chain, so a set generates $\mathbb{Z}/p^k$ only when it contains a generator.
So every minimal generating set of $\mathbb{Z}/p^k$ has exactly one element.

## Explanations

### L1 human

Think of a clock with $6$ hours, numbered $0$ to $5$.
A step of $1$ hour reaches every hour, so the set $\{1\}$ is enough.
Steps of $2$ hours reach only $0, 2, 4$, and steps of $3$ hours reach only $0, 3$.
But with steps of $2$ and $3$ hours, forward and back, we can make a step of $1$ hour: $3$ forward and $2$ back.
So $\{2, 3\}$ is also enough, and neither of its two steps is enough alone.

### L2 human

We check the claim for the set $\{3, 4\}$, the other minimal generating set of size $2$.

1. $\langle 3 \rangle = \{0, 3\}$, because $3 + 3 = 6 \equiv 0$.
2. $\langle 4 \rangle = \{0, 4, 2\}$, because $4 + 4 = 8 \equiv 2$ and $2 + 4 = 6 \equiv 0$.
3. Neither subgroup is $G$, so neither $\{3\}$ nor $\{4\}$ generates $G$.
4. $4 - 3 = 1$, so $1 \in \langle 3, 4 \rangle$ and $\langle 3, 4 \rangle = G$.
5. So $\{3, 4\}$ is a minimal generating set with $2$ elements.

The typical use of this example is a warning about the word "minimal".
A minimal generating set cannot be made smaller by removing elements, but a different generating set can be smaller.

A trap: the set $\{2, 4\}$ has two elements, but it does not generate $G$.
Both elements lie in the subgroup $\{0, 2, 4\}$, so $\langle 2, 4 \rangle = \{0, 2, 4\}$.
