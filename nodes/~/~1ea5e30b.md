## Example

Consider the statement "some element of the empty set is even", that is, $\exists x \in \varnothing \; (x \text{ is even})$.
By the restricted form of the [[existential quantifier|0JW2FHW7G3]], it means $\exists x \, (x \in \varnothing \land x \text{ is even})$.
We show that it is false, so it is not a [[vacuous truth|0V4QXPGJQK]].

1. The existential statement is true exactly when at least one object $x$ makes $x \in \varnothing \land x \text{ is even}$ true.
2. For each object $x$, the statement $x \in \varnothing$ is false, because the [[empty set|0ECVK59Y03]] has no elements.
3. A conjunction with a false part is false. So $x \in \varnothing \land x \text{ is even}$ is false for each $x$.
4. So no object makes the formula of step 1 true, and the existential statement is false.
5. The universal statement $\forall x \in \varnothing \; (x \text{ is even})$ is true by vacuous truth. So the two quantifiers give different truth values over the empty set, and vacuous truth applies only to the universal one.

## Remarks

The example shows that vacuous truth is a property of implications and of universal statements, not of every statement about an empty set.
The restricted universal form uses $\to$, and an implication with a false antecedent is true.
The restricted existential form uses $\land$, and a conjunction with a false part is false.

Over a nonempty set the picture changes.
"Some element of $\{2\}$ is even" is true with the witness $2$, and "some element of $\{3\}$ is even" is false, because $3$ is odd.

## Explanations

### L1 human

"Every unicorn in this room is blue" is true in a room without unicorns, because nobody can show a unicorn that is not blue.
"Some unicorn in this room is blue" is false in the same room.
To make it true, someone would have to show a blue unicorn, and there is none.
So "every" over nothing is true, and "some" over nothing is false.

### L2 human

Let $S = \{x \in \mathbb{R} \mid x^2 < 0\}$.
We find the truth values of $\forall x \in S \; (x > 0)$ and $\exists x \in S \; (x > 0)$.

1. For each real $x$, $x^2 \ge 0$, so $S = \varnothing$.
2. The universal statement means $\forall x \, (x \in S \to x > 0)$. Each antecedent is false, so it is true.
3. The existential statement means $\exists x \, (x \in S \land x > 0)$. Each conjunction has the false part $x \in S$, so it is false.

The typical use of this contrast is the check of a claim of the form "every element of $S$ has property $P$, so $S$ has an element with property $P$": it fails exactly when $S$ is empty.
A trap is to write the restricted existential with $\to$; then $\exists x \, (x \in \varnothing \to x \text{ is even})$ is true, and the formula no longer says what the sentence says.
