## Example

Let $L = \set{P_0, P_1, P_2, \dots}$ with each $P_i$ unary.
For disjoint finite sets $I, J \subseteq \N$, let $\sigma_{I,J}$ say that there are infinitely many $x$ with $P_i(x)$ for all $i \in I$ and $\neg P_j(x)$ for all $j \in J$, written as one sentence "at least $m$ such $x$" for each $m$.
Let $T$ be the set of all these sentences.
We show that $T$ is complete, has no isolated $1$-types, and so has no [[atomic|~fbef995e]] or [[prime model|S8W40PYNHX]], and is not [[small|~166b8a9e]].

### Checks

1. Let $T_k$ be the part of $T$ that uses only $P_0, \dots, P_{k-1}$. A model of $T_k$ splits into $2^k$ cells by the values of $P_0, \dots, P_{k-1}$, and each cell is infinite.
2. Two countable models of $T_k$ have all cells of size $\aleph_0$, so a bijection cell by cell is an isomorphism. By the [[Łoś-Vaught test|ZR7Y5C235P]], $T_k$ is complete.
3. A sentence of $L$ uses finitely many $P_i$, so it is decided by some $T_k$. So $T$ is [[complete|655K8Y7VS8]].
4. For $S \subseteq \N$, let $p_S(x) = \set{P_i(x) : i \in S} \cup \set{\neg P_j(x) : j \notin S}$. Each finite part is satisfied in a model of $T$, so by [[compactness|1NR3HAWG9D]] each $p_S$ is consistent. It decides every $P_i(x)$.
5. Let $\varphi(x)$ be a formula, and let $k$ exceed every index in $\varphi$. Let $a, b$ in a model $M$ agree on $P_0, \dots, P_{k-1}$. A permutation of $M$ that swaps $a$ and $b$ and fixes the rest is an automorphism of the reduct to $P_0, \dots, P_{k-1}$. So $M \models \varphi(a) \leftrightarrow \varphi(b)$.
6. Any two complete $1$-types of $T$ are realized in one model, by compactness. So by step 5, a complete $1$-type is fixed by the sets $S$ with $p_S$ contained in it. So the complete $1$-types are exactly the completions of the $p_S$, one for each $S$, and there are $2^{\aleph_0}$ of them.
7. A formula $\varphi(x)$ in a type $p$ is also in the type that differs from $p$ only at $P_k$, by step 6. So $\varphi$ does not isolate $p$, and no $1$-type is isolated.
8. Every element of a model realizes a $1$-type that is not isolated. So $T$ has no atomic model, and by [[this theorem|~ddda0a28]] no prime model.

## Remarks

By step 6, $T$ has $2^{\aleph_0}$ complete $1$-types, so $T$ is not small.
The space $S_1(T)$ is homeomorphic to the Cantor space $2^{\N}$, which has no isolated points.
The theory still has a countable model, by the Löwenheim-Skolem theorem; it just has no smallest one.

## Explanations

### L1 human

Each element answers infinitely many yes-or-no questions: is it in $P_0$, in $P_1$, and so on.
Any formula asks only finitely many of these questions.
So no formula can describe an element completely, and every element has optional features.
That is why there is no smallest model.

### L2 human

We check step 7 for $\varphi(x) = P_0(x) \wedge \neg P_1(x)$ and $k = 2$.

1. Let $p$ contain $P_0(x)$, $\neg P_1(x)$ and $P_2(x)$.
2. Let $p'$ be the type with the same answers except $\neg P_2(x)$.
3. $\varphi$ belongs to both $p$ and $p'$, so it does not isolate $p$.

The typical use is as a counterexample to the existence of prime models.
A trap is to think that a complete theory with a countable model always has a prime model.
