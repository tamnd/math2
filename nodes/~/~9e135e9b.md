## Proof

1. Let $R = \operatorname{rref}[A \mid C]$. By [[the theorem on row equivalence|~e3949f1c]], part 2, $R = P[A \mid C]$ for an invertible $m \times m$ matrix $P$.
2. By the rule for multiplying block matrices, $P[A \mid C] = [PA \mid PC]$. So the first $n$ columns of $R$ form the matrix $PA$.
3. A matrix in [[reduced row echelon form|0NNR68BFRY]] stays in reduced row echelon form when its last column is deleted. This is the lemma in [[the proof of uniqueness|~4e6ac683]].
4. Apply step 3 $k$ times. So $PA$ is in reduced row echelon form.
5. $PA$ comes from $A$ by the same sequence of row operations as $R$ comes from $[A \mid C]$, so $PA$ is row equivalent to $A$.
6. By the [[uniqueness of the RREF|BF9SMZMJZE]], $PA = \operatorname{rref}(A)$.
7. So $R = [\operatorname{rref}(A) \mid D]$ with $D = PC$.

## Idea

Row operations act on all columns at once, so they act on the left block as if it were alone.
The left block of a reduced matrix is reduced, and the reduced form of $A$ is unique.

## Variants

One can also run [[Gauss-Jordan elimination|098D6FQN3N]] on $[A \mid C]$ column by column: the operations chosen for the first $n$ columns depend only on those columns, so they are the operations that reduce $A$.
This argument shows the result for one algorithm; the proof above shows it for every sequence of operations.
