## Example

Define $f \colon \mathbb{R} \to \mathbb{R}$ by $f(x) = x^2$.
A student writes the following "proof" that $f$ is [[injective|09NWETVTNY]].

> Let $f(a) = f(b)$.
> Then $a^2 = b^2$.
> Taking square roots, $a = b$.
> So $f$ is injective.

We locate the error and show that no correct proof exists.

1. The first step follows the pattern of [[proving injectivity and surjectivity|~250c2090]]: it assumes $f(a) = f(b)$ for arbitrary $a$ and $b$.
2. The step "taking square roots" is the error. The square root of $a^2$ is $\lvert a \rvert$, not $a$, by the definition of the [[absolute value|0FFXKTKKQC]]. So $a^2 = b^2$ gives only $\lvert a \rvert = \lvert b \rvert$.
3. The correct consequence is $a^2 - b^2 = (a - b)(a + b) = 0$, so $a = b$ or $a = -b$. The second case is not excluded.
4. A [[counterexample|0ED72CTBNP]] confirms that the claim is false: $f(-1) = 1 = f(1)$, but $-1 \neq 1$.
5. So $f$ is not injective, and the "proof" above cannot be repaired.

## Remarks

1. The example is a non-example of the method: the method gives a proof only when the step from $f(a) = f(b)$ to $a = b$ is valid for all $a$ and $b$.
2. Step 3 shows where the method can succeed after a change of domain. On $[0, \infty)$ the case $a = -b$ forces $a = b = 0$, so the restriction of $f$ to $[0, \infty)$ is injective.
3. The function $f$ is also not surjective onto $\mathbb{R}$: the equation $x^2 = -1$ has no real solution, because $x^2 \ge 0$ for each real $x$.
4. With domain and codomain $[0, \infty)$ the function is a bijection, and its inverse is the square root function.
5. To disprove injectivity, one pair $a \neq b$ with $f(a) = f(b)$ is enough. To disprove surjectivity, one $y$ with no solution is enough.

## Explanations

### L1 human

The rule "multiply the number by itself" sends $3$ to $9$ and also sends $-3$ to $9$.
So two different numbers give the same answer.
This means the rule is not injective.
The student's proof went wrong when it "undid" the squaring: from $9$ we cannot tell whether we started at $3$ or at $-3$.

### L2 human

We repeat the analysis for $h(x) = x^2 - 4x$ on $\mathbb{R}$.

1. Assume $h(a) = h(b)$. Then $a^2 - 4a = b^2 - 4b$, so $a^2 - b^2 - 4(a - b) = 0$.
2. Factor: $(a - b)(a + b - 4) = 0$. So $a = b$ or $a + b = 4$.
3. The second case gives a counterexample: $a = 1$ and $b = 3$ give $h(1) = -3 = h(3)$.
4. So $h$ is not injective on $\mathbb{R}$. It is injective on $[2, \infty)$, because there $a + b = 4$ forces $a = b = 2$.

The typical use of this analysis is to find the largest interval on which a function is injective, so that it has an inverse there.
A trap is to divide by $a - b$ in step 2 without the case $a = b$, or to forget the second factor.
