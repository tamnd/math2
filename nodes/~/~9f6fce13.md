## Definition

Work in $L_2$ with the codes of the [[definition of second-order arithmetic|Y92NXGEQBD]].
A *countable linear order* is a set $W$ of pairs such that $\le_W = \set{(i, j) : (i, j) \in W}$ is a linear order on its field $\mathrm{field}(W) = \set{i : (i, i) \in W}$.
$W$ is a *countable [[well-ordering|01CGSJ0GNQ]]*, written $\mathrm{WO}(W)$, if also there is no function $f \colon \N \to \mathrm{field}(W)$ with $f(k + 1) <_W f(k)$ for all $k$.

For a set $H$ of pairs, let $H_j = \set{n : (n, j) \in H}$ and $H^j = \set{(n, i) \in H : i <_W j}$.
For an arithmetical formula $\theta(n, Y)$, a *hierarchy along $W$ for $\theta$* is a set $H$ with
$$\forall j \in \mathrm{field}(W)\; \forall n\, \big(n \in H_j \leftrightarrow \theta(n, H^j)\big).$$

*Arithmetical transfinite recursion* is the scheme: for every arithmetical formula $\theta(n, Y)$, with any parameters, and every $W$ with $\mathrm{WO}(W)$, there is a hierarchy along $W$ for $\theta$.
$\mathsf{ATR}_0$ is the subsystem of second-order arithmetic whose axioms are those of [[ACA0|~bffbe3ad]] together with arithmetical transfinite recursion.

## Notation

The name abbreviates "arithmetical transfinite recursion".
$\mathrm{WO}(W)$ is a $\Pi^1_1$ formula, so the hypothesis of the scheme quantifies over all functions.

## Remarks

Example: for $W = (\N, <)$ and $\theta(n, Y)$ saying "$n$ is in the [[Turing jump|60P2XWY5QX]] of $Y$", a hierarchy is one set whose columns are, up to Turing equivalence, $\emptyset', \emptyset'', \emptyset''', \ldots$.

Example: for $W$ with one element and any $\theta$, a hierarchy is just the set $\set{n : \theta(n, \emptyset)}$ in column $0$, which exists by arithmetical comprehension.

Non-example: a recursion whose step is "$n$ is in the hyperjump of $Y$" is not an instance of the scheme, because this step is a $\Pi^1_1$ formula and not an arithmetical formula.
Non-example: the scheme gives no hierarchy along a linear order that is not a well-ordering, such as the order of the negative integers.

## Explanations

### L1 human

Arithmetical transfinite recursion allows one to repeat an arithmetical construction along any well-ordering.
At each stage the construction may use the results of all earlier stages.

### L2 human

To use the scheme, one fixes the step $\theta$ and the well-ordering $W$, and gets all stages at once as columns of one set.
The typical step is the Turing jump, so $\mathsf{ATR}_0$ proves that the jump can be iterated along any countable well-ordering.
A trap is to apply the scheme to a linear order without proving that it is a well-ordering inside the system.
