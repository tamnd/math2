## Example

The signature has one binary relation symbol $<$.
Let $\mathcal{E}$ be the class of finite [[linear orders|0FRXBVVR03]] with an even number of elements, including the empty order.
We show that $\mathcal{E}$ is not the [[age|~41dc9926]] of any structure.

1. Every age has the hereditary property: a substructure of a substructure of $M$ is a substructure of $M$.
2. The order $A = \set{0 < 1}$ has $2$ elements, so $A \in \mathcal{E}$.
3. The subset $\set{0}$ with the induced order is a substructure of $A$, and it has $1$ element.
4. So $\set{0} \notin \mathcal{E}$, and $\mathcal{E}$ fails the hereditary property.
5. By step 1, $\mathcal{E}$ is not an age.

## Remarks

The class $\mathcal{E}$ has the joint embedding property: two even orders embed into one even order, by putting one above the other.
So only the hereditary property fails.
The smallest age that contains $\mathcal{E}$ is the class of all finite linear orders, the age of $(\Q, <)$.
The class of finite linear orders of size at most $4$ is hereditary, and it is the age of a $4$-element order.

## Explanations

### L1 human

An age must contain every piece of every piece.
A chain with two elements has a piece with one element.
One is odd, so a list of only even chains leaves out a piece that it must contain.

### L2 human

We check the joint embedding property for $\mathcal{E}$ on a small case.

1. Let $A = \set{a_1 < a_2}$ and $B = \set{b_1 < b_2 < b_3 < b_4}$.
2. Let $C = \set{1 < 2 < 3 < 4 < 5 < 6}$, of size $6$, so $C \in \mathcal{E}$.
3. Embed $A$ by $a_i \mapsto i$ and $B$ by $b_j \mapsto j + 2$. Both maps preserve and reflect the order.

The typical use of this example is to show that the conditions of Fraïssé's theorem are independent.
A trap is to test only the joint embedding property and forget closure under substructures.
