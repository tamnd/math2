## Statement

Let $\mathcal{L}_{\mathrm{Def}}$ be the [[language of arithmetic|D8SD54M5PN]] with a new binary predicate $\mathrm{Def}(x, y)$, read "the formula with code $x$ defines the number $y$".
Fix a [[Gödel numbering|MFJXPAF0R0]].
The *naive definability schema* is the set of all sentences
$$\forall y\,\bigl(\mathrm{Def}(\ulcorner \varphi \urcorner, y) \leftrightarrow \forall v\,(\varphi(v) \leftrightarrow v = y)\bigr),$$
where $\varphi(v)$ is any [[formula|HYJ10AF6RT]] of $\mathcal{L}_{\mathrm{Def}}$ with exactly one free variable $v$, including formulas that contain $\mathrm{Def}$.
Add the clause that $\mathrm{Def}(x, y)$ is false when $x$ does not code such a formula.
Then the schema says that $\mathrm{Def}$ is the relation "$x$ [[defines|CY1TXHF6KQ]] $y$" for all of $\mathcal{L}_{\mathrm{Def}}$.

## Remarks

### Why each hypothesis is needed

1. If $\varphi$ ranges only over formulas without $\mathrm{Def}$, the schema is consistent with $\mathsf{PA}$. A model is the standard model with $\mathrm{Def}$ read as definability by arithmetical formulas, which is a relation outside arithmetic.
2. The phrase "for the whole language" is the source of the trouble: the [[Berry paradox|~6cd3e1b8]] uses a formula that contains $\mathrm{Def}$.

### Consequences

1. The schema for all formulas has no model that expands the standard model; this is the proposition on [[definability in the standard model|~05cb338f]].
2. The [[Berry paradox|~6cd3e1b8]] is the informal form of this failure.

### Converse

The schema restricted to formulas without $\mathrm{Def}$ is true in the standard model with the intended reading.
So the restriction is the exact analogue of the typed T-sentences of the [[Tarskian hierarchy|Z6MCGB0ZFX]].

### Generalizations

The [[naive truth schema|~34d21c75]] and the [[naive satisfaction schema|~8614bcb6]] are the analogous principles for truth and for satisfaction.

## Explanations

### L1 human

A formula "defines" a number if that number is the only one that fits it.
For example, "$v + v = 6$" defines the number $3$.
The naive definability schema says that a single predicate can describe this relation for every formula, even formulas that use the predicate itself.
The Berry paradox shows that this is impossible.

### L2 human

1. Take $\varphi(v) := (v + v = \underline{6})$.
2. In the standard model, $\forall v\,(v + v = 6 \leftrightarrow v = 3)$ holds.
3. The schema then requires $\mathrm{Def}(\ulcorner \varphi \urcorner, 3)$ and $\neg \mathrm{Def}(\ulcorner \varphi \urcorner, n)$ for $n \neq 3$.

The schema is the intended meaning of "definable", stated for one language that speaks about its own definitions.
The trap is to think that a formula that uses $\mathrm{Def}$ cannot define anything: it can, and the Berry formula is such a formula.

### L3 human

The schema is the definability analogue of naive comprehension.
Its failure is like the failure of the naive truth schema.
Both show that a semantic relation of a language cannot be fully expressed in the same language.
Restricted to a fixed language, definability is a well-behaved relation in a stronger metalanguage, as in model theory.
