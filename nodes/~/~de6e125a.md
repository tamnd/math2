## Example

Fix a [[Gödel numbering|MFJXPAF0R0]] of the sentences of arithmetic with the predicates $T_0, T_1$.
Let $\mathcal{L}_0 = \{0, S, +, \cdot\}$, $\mathcal{L}_1 = \mathcal{L}_0 \cup \{T_0\}$ and $\mathcal{L}_2 = \mathcal{L}_1 \cup \{T_1\}$.
Let $\mathcal{N}_0$ be the [[standard model|WP27CABPA4]].
Let $\mathcal{N}_1 = (\mathcal{N}_0, E_0)$, where $E_0$ is the set of codes of sentences of $\mathcal{L}_0$ [[true|K7XDVK5854]] in $\mathcal{N}_0$.
Let $\mathcal{N}_2 = (\mathcal{N}_1, E_1)$, where $E_1$ is the set of codes of sentences of $\mathcal{L}_1$ true in $\mathcal{N}_1$.
We check that these are the first three levels of a [[Tarskian hierarchy|Z6MCGB0ZFX]], and compute some values.

1. *Each level is well defined.* $E_0$ uses only truth in $\mathcal{N}_0$, and $E_1$ uses only truth in $\mathcal{N}_1$, which is defined once $E_0$ is.
2. *Convention T at level 0.* For a sentence $\varphi$ of $\mathcal{L}_0$, $\mathcal{N}_1 \models T_0(\ulcorner \varphi \urcorner)$ iff $\ulcorner \varphi \urcorner \in E_0$ iff $\mathcal{N}_0 \models \varphi$ iff $\mathcal{N}_1 \models \varphi$. The last step holds because $\varphi$ does not contain $T_0$.
3. *Convention T at level 1.* The same argument with $E_1$ gives $\mathcal{N}_2 \models T_1(\ulcorner \psi \urcorner) \leftrightarrow \psi$ for each sentence $\psi$ of $\mathcal{L}_1$.
4. *A computation.* $2 + 2 = 4$ is true in $\mathcal{N}_0$, so $\mathcal{N}_1 \models T_0(\ulcorner 2 + 2 = 4 \urcorner)$ by step 2.
5. *Iterated truth.* $T_0(\ulcorner 2 + 2 = 4 \urcorner)$ is a sentence of $\mathcal{L}_1$ true in $\mathcal{N}_1$, so $\mathcal{N}_2 \models T_1(\ulcorner T_0(\ulcorner 2 + 2 = 4 \urcorner) \urcorner)$.
6. *A lower predicate on a higher sentence.* $T_0(\ulcorner 2 + 2 = 4 \urcorner)$ is not a sentence of $\mathcal{L}_0$, so its code is not in $E_0$. Hence $\mathcal{N}_1 \models \neg T_0(\ulcorner T_0(\ulcorner 2 + 2 = 4 \urcorner) \urcorner)$.
7. *A false sentence.* $\mathcal{N}_0 \models \neg (1 = 0)$, so $\ulcorner 1 = 0 \urcorner \notin E_0$, and $\mathcal{N}_1 \models \neg T_0(\ulcorner 1 = 0 \urcorner)$.

## Remarks

Steps 5 and 6 show the typical feature of the hierarchy.
The sentence "it is true that it is true that $2 + 2 = 4$" holds only when the outer predicate has a higher index than the inner one.
If we use $T_0$ twice, the result is false in the intended model, although the inner claim is true.
If we add a level $\mathcal{L}_3$ with $T_2$, the same pattern continues: $T_2$ applies to every sentence of $\mathcal{L}_2$, and $T_1$ still does not.

## Explanations

### L1 human

At level 0 we only talk about numbers.
At level 1 we have a word "true-0" for level-0 sentences, and "$2 + 2 = 4$ is true-0" holds.
At level 2 we have "true-1" for level-1 sentences, so "'$2 + 2 = 4$ is true-0' is true-1" holds.
But "'$2 + 2 = 4$ is true-0' is true-0" is false, because true-0 only covers level-0 sentences.

### L2 human

1. Take $\psi := T_0(\ulcorner 0 = 0 \urcorner) \wedge \neg T_0(\ulcorner 0 = 1 \urcorner)$, a sentence of $\mathcal{L}_1$.
2. $0 = 0$ is true and $0 = 1$ is false in $\mathcal{N}_0$, so both conjuncts are true in $\mathcal{N}_1$.
3. So $\psi$ is true in $\mathcal{N}_1$, and $\ulcorner \psi \urcorner \in E_1$.
4. So $\mathcal{N}_2 \models T_1(\ulcorner \psi \urcorner)$, in agreement with step 3 of the example.

The typical use is to reason classically about the truth of sentences that themselves mention truth, one level at a time.
The trap is to write $T_0$ where the sentence needs $T_1$: the formula is well formed, but it says something false.
