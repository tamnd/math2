## Counterexample

The claim refuted is the [[naive definability schema|~a84aca18]].
It says that one predicate $\mathrm{Def}$ gives, for every formula of its own language, the number that the formula defines.

*Informal form.* Consider the phrase
"the least number not definable in fewer than twelve words".

1. Count the words of the phrase: the, least, number, not, definable, in, fewer, than, twelve, words. There are $10$ words.
2. English has finitely many words, so only finitely many phrases have fewer than $12$ words.
3. Each phrase defines at most one number. So only finitely many numbers are definable in fewer than $12$ words.
4. There are infinitely many natural numbers. So some number is not definable in fewer than $12$ words.
5. The natural numbers are well ordered, so there is a least such number; call it $m$.
6. The phrase defines $m$, by step 5, and it has $10$ words, by step 1. Since $10 < 12$, $m$ is definable in fewer than $12$ words.
7. Steps 5 and 6 contradict each other.

*Formal form.* Let $\mathcal{L}_{\mathrm{Def}}$ be arithmetic with a binary predicate $\mathrm{Def}$, and let $(\mathcal{N}, E)$ be any expansion of the standard model.
Replace "phrase with fewer than $12$ words" by "formula with code at most $b$".
Replace the phrase by a formula $\beta(y)$ whose own code is $b$; the diagonal lemma with parameters gives it.
Then the steps above become the [[proof by the Berry construction|~afa8185c]].
It shows that $E$ cannot satisfy the naive definability schema, so the schema has no model that expands $\mathcal{N}$.

## Remarks

### The counted bound

The bound in the phrase must exceed the length of the phrase.
Wikipedia uses the phrase "The smallest positive integer not definable in under sixty letters", which has $57$ letters, and $57 < 60$.
With "fewer than ten words", the phrase above would not be paradoxical, because $10$ is not less than $10$.
In the formal form, the diagonal lemma removes this counting step.
The bound is equal to the code of the formula, and the formula has that code.

### Where the reasoning fails

In the informal form, the word "definable" refers to a relation that includes the phrase itself.
The [[proposition on definability|~05cb338f]] shows that no language can express its own definability relation.
So the formal Berry argument does not refute arithmetic: it refutes the assumption that $\mathrm{Def}$ is expressible.
This is the same pattern as the [[liar paradox|~005ac188]] and [[Tarski's undefinability theorem|YRV6SYK2BY]].

### Formal analogues

Wikipedia reports that Boolos (1989) used a formalized version of the paradox for a new proof of Gödel's incompleteness theorem.
It also reports that Chaitin built formal analogues with programs or proofs of bounded length.
These analogues do not give a contradiction, but they prove impossibility results.
An example is [[Chaitin's incompleteness proof|77EMTE7X9V]], which uses [[Kolmogorov complexity|8PY3K6NCKF]].

### Related paradoxes

The Berry paradox is a [[paradox of denotation|DKZP9329YZ]], like the paradoxes of König and Richard.
Wikipedia reports that Russell first discussed the paradox in print and attributed it to Berry.
The SEP entry on self-reference calls the Berry description impredicative, because it refers to all descriptions, including itself.

## Explanations

### L1 human

Think of all English phrases with fewer than twelve words.
There are many of them, but only finitely many, so they can name only finitely many numbers.
So some numbers have no short name, and one of them is the smallest.
But "the least number not definable in fewer than twelve words" is a short name for it, with ten words.
So the smallest number with no short name has a short name.

### L2 human

1. The step that uses only counting (steps 2 to 4) is correct mathematics.
2. The step that takes the least element (step 5) is correct for any nonempty set of natural numbers.
3. The step that fails is step 6: it assumes that "definable" is a word of the same language.
4. In arithmetic, step 6 needs a formula $\mathrm{Def}$, and the [[Berry proof|~afa8185c]] shows that no such formula exists.

The typical use is as a proof idea: assume a description relation, then build "the first object with no short description".
The trap is to count wrongly: the bound must be larger than the length of the phrase itself.

### L3 human

The Berry argument is the counting form of diagonalization.
In computability it shows that Kolmogorov complexity is not computable.
In proof theory it gives incompleteness proofs, as in Boolos's proof.
