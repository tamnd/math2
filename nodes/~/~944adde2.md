## Example

Book I of [[Euclid's Elements|83WHDAV68J]] opens with a list of definitions.
The first one says, in a common English translation, that a point is that which has no part.
We check this sentence against the conditions of a [[mathematical definition|~d1d36166]].

1. A definition must state its definiens in known terms. The definiens here uses the word "part", and the *Elements* never defines "part" for geometric figures.
2. A definition must let us decide, for a given object, whether it has the defined property. The sentence gives no test that decides whether a given object is a point.
3. A definition must be usable in proofs: we must be able to replace the term by the definiens. The proofs of the *Elements* never use the sentence. They use the postulates, the common notions and earlier propositions.

So the sentence is a description that helps the reader's intuition, not a mathematical definition.

## Remarks

1. The same holds for the next definitions of Book I, which describe a line as length without breadth. The word "breadth" is not defined either.
2. In 1899 Hilbert took "point" and "line" as [[primitive notions|~d06afda5]]. He gave them no definition, and his axioms fix how proofs may use them.
3. Euclid's descriptions are still useful: they tell the reader what picture to have in mind. The lesson is that a picture and a definition have different jobs.
4. Many of Euclid's other definitions are mathematical definitions in the modern sense. For example, a circle is defined from a center and equal distances, and proofs do use this.

## Explanations

### L1 human

Euclid wrote that a point is something with no parts.
This sentence helps us imagine a point as a tiny dot.
But it gives no way to check anything, because Euclid never says what a "part" is.
In his proofs, Euclid never uses this sentence.
So mathematicians today call it a description, and they treat "point" as a word that is not defined at all.

### L2 human

Compare the two sentences "a point has no part" and "a circle is the set of points at a fixed distance $r > 0$ from a fixed point $O$".

1. The second sentence uses only known terms: point, distance, and a number $r$.
2. The second sentence gives a test: a point $P$ is on the circle exactly when the distance from $O$ to $P$ is $r$.
3. Proofs use this test. For example, if $A$ and $B$ are on the circle, then $OA = OB$, so the triangle $OAB$ is isosceles.
4. The first sentence gives no test and no equation, so no proof step can use it.

A trap is to think that a term without a definition is a gap in the theory.
Each theory must start from some undefined terms, and the axioms then do the work of a definition.
