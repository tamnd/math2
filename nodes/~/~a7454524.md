## Example

Consider the statement $2^{10} = 1024$.
We check that it is not [[deep|~1ac18cfd]] in the sense of mathematical jargon.

1. The statement uses the integers $2$, $10$ and $1024$, and the power $2^{10}$, which means $2$ multiplied by itself $10$ times.
2. The proof is a computation: $2^5 = 32$, and $2^{10} = 32 \cdot 32 = 1024$.
3. The proof uses only multiplication of integers, which the statement already needs.

A result is deep only if its proof needs concepts beyond those of its statement, so this result is not deep.

## Remarks

The result is a computation, so most mathematicians would call it [[trivial|~f4ece120]].
Contrast it with [[Fermat's last theorem|0Y5X3SDBCZ]], whose statement also uses only integers and powers, but whose proof needs elliptic curves and modular forms.
Depth is a property of the gap between statement and proof, not of the size of the numbers.
A statement about very large numbers, such as the value of $2^{1000}$, is still not deep, because the same computation proves it.

## Explanations

### L1 human

We can check $2^{10} = 1024$ by doubling $2$ ten times.
We need only multiplication, the same idea that the statement uses.
So the result is not deep.
A deep result is one that needs much more mathematics in its proof than in its statement.

### L2 human

To test whether a result is deep, compare two lists.

1. List the concepts of the statement: here, integers and powers.
2. List the concepts of the shortest known proof: here, integers and multiplication.
3. The second list adds nothing new to the first, so the result is not deep.

A trap: the test uses the known proofs, so the judgment can change when a new proof appears.
