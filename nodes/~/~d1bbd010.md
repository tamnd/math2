## Proof

We use the notation of the [[statement|~1dd87a57]], and write $P \le Q$ for pairs. "Stage $\alpha$" means $(E_\alpha, A_\alpha)$.

*Part 1: monotonicity.* Let $(E, A) \le (E_1, A_1)$.

1. We use [[induction on the number of logical symbols|EDRV3N0SA3]] of $\varphi$. Each instance $\varphi(\underline{n})$ has fewer logical symbols than $\forall x\, \varphi(x)$.
2. An arithmetical atomic sentence has the same classical value under both pairs.
3. If $\|T(t)\|_{(E, A)} = 1$, the value of $t$ is in $E \subseteq E_1$. So $\|T(t)\|_{(E_1, A_1)} = 1$. The case $0$ uses $A \subseteq A_1$.
4. If $\|\neg \varphi\| \neq \mathrm{u}$, then $\|\varphi\| \neq \mathrm{u}$. By induction it does not change, so $\|\neg \varphi\|$ does not change.
5. If $\|\varphi \wedge \psi\| = 1$, both conjuncts are $1$ and stay $1$. If it is $0$, some conjunct is $0$ and stays $0$.
6. If $\|\forall x\, \varphi\| = 1$, every instance is $1$ and stays $1$. If it is $0$, some instance is $0$ and stays $0$.
7. Disjunction and the existential quantifier are dual, with the same argument.
8. So $\mathcal{J}$ is monotone: by steps 1 to 7, $\mathcal{J}(E, A) \le \mathcal{J}(E_1, A_1)$. The non-sentence part of $A'$ is the same.
9. $\mathcal{J}$ maps pairs to pairs: no sentence has two values, and non-sentences are not codes of sentences. So $E' \cap A' = \emptyset$.

*Iteration lemma.* Call a pair $P$ *sound* if $P \le \mathcal{J}(P)$.
Iterate $\mathcal{J}$ from $P$, with unions at limits.

10. We use [[transfinite induction|0ZHQMQ2C1N]] on $\alpha$ to show that the iterate $P_\alpha$ is a disjoint pair with $P_\alpha \le P_{\alpha + 1}$.
11. For $\alpha = 0$: $P_0 = P$ is a pair, and $P \le \mathcal{J}(P) = P_1$ by soundness.
12. For $\alpha = \delta + 1$: $P_\alpha$ is a pair by step 9. Step 8 applied to $P_\delta \le P_\alpha$ gives $P_\alpha \le P_{\alpha + 1}$.
13. Before a limit $\alpha$, the iterates form an increasing chain of disjoint pairs, by induction. So their union $P_\alpha$ is a disjoint pair.
14. For $\delta < \alpha$, step 8 applied to $P_\delta \le P_\alpha$ gives $P_\delta \le P_{\delta + 1} \le P_{\alpha + 1}$. So $P_\alpha \le P_{\alpha + 1}$.
15. Induction on $\beta'$ now gives $P_\beta \le P_{\beta'}$ for all $\beta \le \beta'$.
16. Assume $P_\alpha \neq P_{\alpha + 1}$ for all countable $\alpha$. Pick $n_\alpha \in (E_{\alpha + 1} \cup A_{\alpha + 1}) \setminus (E_\alpha \cup A_\alpha)$, using disjointness.
17. For $\alpha < \beta$, $n_\alpha \in E_\beta \cup A_\beta$ and $n_\beta \notin E_\beta \cup A_\beta$, by step 15. This injects the [[first uncountable ordinal|Z92S2GVCX9]] into $\mathbb{N}$.
18. So some countable $\gamma$ has $P_\gamma = P_{\gamma + 1} = \mathcal{J}(P_\gamma)$. This fixed point is above $P = P_0$.

*Part 2: least fixed point.*

19. The pair $(\emptyset, \emptyset)$ is sound. So steps 10 to 18 give a countable $\gamma$ with stage $\gamma$ a fixed point.
20. Let $F$ be a fixed point. Then stage $0 \le F$.
21. If stage $\alpha \le F$, then stage $\alpha + 1 = \mathcal{J}(\text{stage } \alpha) \le \mathcal{J}(F) = F$, by step 8.
22. If every stage below a limit is below $F$, so is their union. So every stage, including $\gamma$, is below $F$.

*Part 3: semantic T-schema.* Let $(E, A)$ be a fixed point and $\varphi$ a sentence.

23. $\|T(\ulcorner \varphi \urcorner)\| = 1$ iff $\ulcorner \varphi \urcorner \in E$. Since $E$ is the first part of $\mathcal{J}(E, A)$, this holds iff $\|\varphi\| = 1$.
24. In the same way, $\|T(\ulcorner \varphi \urcorner)\| = 0$ iff $\|\varphi\| = 0$, since $\ulcorner \varphi \urcorner$ is a sentence code.
25. In the remaining case both values are $\mathrm{u}$.

*Part 4: maximal fixed points.* Fix a fixed point $F_0$.
Let $\mathcal{S}$ be the set of fixed points above it.

26. Let $C$ be a nonempty chain in $\mathcal{S}$, and $U$ its componentwise union. $U$ is a disjoint pair, since $C$ is a chain. The empty chain has the bound $F_0$.
27. Each $F \in C$ satisfies $F = \mathcal{J}(F) \le \mathcal{J}(U)$, by step 8. So $U$ is sound.
28. Steps 10 to 18 give a fixed point above $U$. It is an upper bound for $C$ in $\mathcal{S}$.
29. [[Zorn's lemma|04RXTQA5ZA]] gives a maximal $M \in \mathcal{S}$. A fixed point above $M$ is in $\mathcal{S}$, so it equals $M$.

*Part 5: largest intrinsic fixed point.*

30. Let $X$ be the set of sound pairs that are compatible with every fixed point. $(\emptyset, \emptyset) \in X$.
31. Let $U$ be the componentwise union of all members of $X$. Suppose $n \in E_P \cap A_Q$ with $P, Q \in X$.
32. Steps 10 to 18 give a fixed point $F \ge P$. Then $n \in E_F \cap A_Q$, so $Q$ is not compatible with $F$.
33. This contradicts $Q \in X$. So $U$ is a disjoint pair.
34. For $P \in X$, $P \le \mathcal{J}(P) \le \mathcal{J}(U)$, by step 8. So $U \le \mathcal{J}(U)$.
35. Each member of $X$ is compatible with every fixed point, so $U$ is too. So $U$ is the largest element of $X$.
36. Let $F$ be a fixed point. By step 35, the componentwise union $U \vee F$ is a disjoint pair.
37. By step 8, $\mathcal{J}(U) \le \mathcal{J}(U \vee F)$ and $F = \mathcal{J}(F) \le \mathcal{J}(U \vee F)$.
38. $\mathcal{J}(U \vee F)$ is a disjoint pair, by step 9. So $\mathcal{J}(U)$ is compatible with $F$.
39. By steps 34 and 8, $\mathcal{J}(U)$ is sound. With step 38, $\mathcal{J}(U) \in X$. So $\mathcal{J}(U) \le U$, by step 35.
40. Steps 34 and 39 give $U = \mathcal{J}(U)$. So $U$ is an intrinsic fixed point.
41. Every intrinsic fixed point is sound and is in $X$. So it is below $U$, by step 35.

*Part 6: examples.* Steps 53 to the end treat the sentence $\sigma$ of the Remarks of the statement.

42. By the [[proof of the diagonal lemma|SFPSB6JPTC]], $\lambda = \exists y\,(D(\underline{k}, y) \wedge \neg T(y))$, and $D(\underline{k}, \underline{m})$ is true only for $m = \ulcorner \lambda \urcorner$.
43. So under every pair, all disjuncts of $\lambda$ but one have value $0$. Hence $\|\lambda\| = \|\neg T(\ulcorner \lambda \urcorner)\|$.
44. In the same way, $\|\tau\| = \|T(\ulcorner \tau \urcorner)\|$ and $\|\sigma\| = \|T(\ulcorner \sigma \urcorner) \vee \neg T(\ulcorner \sigma \urcorner)\|$ under every pair.
45. In a fixed point, step 43 and part 3 give $\|\lambda\| = \|\neg \lambda\|$. Only $\mathrm{u}$ equals its own negation.
46. Under $(\{\ulcorner \tau \urcorner\}, \emptyset)$, $\tau$ has value $1$, so this pair is sound. Step 18 gives a fixed point $F_1$ above it.
47. In $F_1$, $\|\tau\| = \|T(\ulcorner \tau \urcorner)\| = 1$, by step 44.
48. Under $(\emptyset, \{\ulcorner \tau \urcorner\})$, $\tau$ has value $0$. As in steps 46 and 47, some fixed point $F_0$ gives $\tau$ value $0$.
49. Stage $0$ does not contain $\ulcorner \tau \urcorner$. If stage $\alpha$ does not, then $\|\tau\|_\alpha = \mathrm{u}$, so stage $\alpha + 1$ does not.
50. Unions at limits keep this. So $\tau$ has value $\mathrm{u}$ in the least fixed point.
51. If $\ulcorner \tau \urcorner \in E_U$, then $U$ is not compatible with $F_0$. If $\ulcorner \tau \urcorner \in A_U$, it is not compatible with $F_1$.
52. So $\tau$ has value $\mathrm{u}$ in the largest intrinsic fixed point $U$.
53. By step 44, $\|\sigma\| = 0$ would need $\|T(\ulcorner \sigma \urcorner)\| = 0$ and $= 1$. So $\sigma$ never has value $0$.
54. As in steps 49 and 50, $\sigma$ has value $\mathrm{u}$ in the least fixed point.
55. Let $Q := (\{\ulcorner \sigma \urcorner\}, \emptyset)$. Under $Q$, $\sigma$ has value $1$, so $Q$ is sound.
56. In a fixed point $F$, $\ulcorner \sigma \urcorner \in A_F$ would mean $\|\sigma\|_F = 0$. By step 53, $Q$ is compatible with $F$.
57. So $Q \in X$ and $Q \le U$. By step 44, $\|\sigma\|_U = \|T(\ulcorner \sigma \urcorner)\|_U = 1$.

## Idea

The jump is monotone, because strong Kleene values never change once they are $1$ or $0$.
So iterating it from the empty pair increases until it stops, and a counting argument shows that it stops at a countable stage.
Compatibility with all fixed points is preserved by the jump, which gives the largest intrinsic fixed point.
The examples reduce to the equation $\|\varphi\| = \|T(\ulcorner \varphi \urcorner)\|$ at fixed points.

## Variants

1. The least fixed point is also the intersection of all fixed points, by part 2.
2. In part 2, one can apply the [[Knaster-Tarski theorem|RHXP3HA64M]] to the set of disjoint pairs. It has least upper bounds of chains but is not a complete lattice, so the iteration is the direct route.
