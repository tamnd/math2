## Example

Let $S_3$ be the [[symmetric group|0515A6D2Y1]] on $\{1, 2, 3\}$, with $6$ elements.
The product $xy$ means "first $y$, then $x$".
Let $c = (1\,2\,3)$, the permutation that sends $1 \mapsto 2$, $2 \mapsto 3$ and $3 \mapsto 1$.
We show that $\{c\}$ is not a [[generating set|0MBV2VHMXA]] of $S_3$.
For a single element, $\langle c \rangle$ is the [[cyclic subgroup|08ABT85339]] of all integer powers of $c$.

1. $c^2 = (1\,3\,2)$: it sends $1 \mapsto 2 \mapsto 3$, $2 \mapsto 3 \mapsto 1$ and $3 \mapsto 1 \mapsto 2$.
2. $c^3 = e$: each number returns to itself after three steps. So $c$ has [[order|0WE2NHZJ7B]] $3$.
3. Each integer power of $c$ is one of $e, c, c^2$, because $c^{3q + t} = (c^3)^q c^t = c^t$ for $0 \leq t \leq 2$.
4. So $\langle c \rangle = \{e, (1\,2\,3), (1\,3\,2)\}$, with $3$ elements.
5. $S_3$ has $6$ elements, so $\langle c \rangle \neq S_3$. For example, $(1\,2) \notin \langle c \rangle$.

So $\{c\}$ does not generate $S_3$.

## Remarks

The subgroup $\langle c \rangle$ is the [[alternating group|0Z5905Q73D]] $A_3$, the group of the even permutations of $\{1, 2, 3\}$.
No set of even permutations generates $S_3$, because products and inverses of even permutations are even.

No single element generates $S_3$.
The elements of $S_3$ have orders $1$, $2$ and $3$, and a generator of a group of order $6$ needs order $6$.
So $S_3$ is not cyclic, and $d(S_3) \geq 2$.

If we add one transposition, we get a generating set.
For example, [[the set $\{(1\,2), (1\,2\,3)\}$ generates $S_3$|~4a65c4a8]].
For $n \geq 3$, the same argument shows that the $3$-cycles of $S_n$ generate a subgroup of $A_n$, which has index $2$ in $S_n$.
In fact [[the alternating group is generated by three-cycles|0KFZ0QX83G]].

## Explanations

### L1 human

Put three cards in a row, numbered $1$, $2$, $3$.
A cyclic shift moves card $1$ to place $2$, card $2$ to place $3$, and card $3$ to place $1$.
If we repeat the shift, we get only three orders of the cards, and the third shift gives back the start.
But three cards can lie in six orders.
A swap of two cards, for example, never comes from shifts.
So the shift alone does not produce all the rearrangements.

### L2 human

We show again that $(1\,2) \notin \langle (1\,2\,3) \rangle$, now with a sign argument.

1. A $3$-cycle is a product of two transpositions: $(1\,2\,3) = (1\,3)(1\,2)$. So it is an even permutation.
2. The even permutations form a subgroup $A_3$ of $S_3$.
3. So every power of $(1\,2\,3)$ is even.
4. The transposition $(1\,2)$ is odd, so it is not a power of $(1\,2\,3)$.

The typical use of this argument is a proof that a set does not generate a group.
We find a proper subgroup that contains the whole set, here $A_3$.

A trap: a set can fail to generate a group even when it contains elements of the largest order.
In $S_3$, the element $(1\,2\,3)$ has the largest order, $3$, but it generates only half of the group.
