## Example

Let $L = \set{c, P}$, with a constant symbol $c$ and a unary relation symbol $P$.
Let $\Sigma = \set{\exists x \, P(x), \ \neg P(c)}$.
We show that $\Sigma$ has a model but no [[Herbrand model|~d1167ab6]].

1. Let $\mathcal{M}$ have domain $\set{0, 1}$, $c^{\mathcal{M}} = 0$ and $P^{\mathcal{M}} = \set{1}$.
2. The witness $x \mapsto 1$ satisfies $P(x)$, so $\mathcal{M} \models \exists x \, P(x)$, by the clause for $\exists$ of [[satisfaction|~cf18e0d7]].
3. The value of $c$ is $0 \notin P^{\mathcal{M}}$, so $\mathcal{M} \models \neg P(c)$. So $\mathcal{M}$ is a model of $\Sigma$.
4. The Herbrand universe of $L$ is $\set{c}$, because $L$ has no function symbols.
5. A Herbrand structure $\mathcal{H}$ has domain $\set{c}$. If $\mathcal{H} \models \neg P(c)$, then $P^{\mathcal{H}} = \emptyset$.
6. Then no element satisfies $P(x)$, and $\mathcal{H} \not\models \exists x \, P(x)$.
7. So no Herbrand structure is a model of $\Sigma$.

The condition that fails is that every sentence of $\Sigma$ is universal, which the [[theorem on Herbrand models|~c158f2c6]] requires.

## Remarks

The example shows that the hypothesis "universal" in the theorem cannot be dropped.
The witness $1$ of $\exists x \, P(x)$ in $\mathcal{M}$ is not the value of a closed term, so the Herbrand universe cannot copy it.
Skolemization repairs the situation: replace $\exists x \, P(x)$ by $P(d)$ for a new constant $d$.
Then $\set{P(d), \neg P(c)}$ is universal, and the Herbrand structure on $\set{c, d}$ with $P = \set{d}$ is a model.
A second failure comes from equality: $\set{c = d}$ has a one-element model, but no Herbrand model, because distinct terms are distinct elements.

## Explanations

### L1 human

The rules say "something has $P$" and "the thing called $c$ does not have $P$".
A world of names that only knows the name $c$ cannot satisfy both rules.
A world with an extra, unnamed object can.

### L2 human

We check the Skolemized set $\set{P(d), \neg P(c)}$ in all four Herbrand structures on $\set{c, d}$.

1. $P = \emptyset$ and $P = \set{c}$ fail $P(d)$.
2. $P = \set{c, d}$ fails $\neg P(c)$.
3. $P = \set{d}$ satisfies both, so it is the only Herbrand model.

The typical use is to explain why theorem provers first Skolemize existential quantifiers.
A trap is to think that Skolemization preserves equivalence; it preserves satisfiability only.
