## Example

The [[Ramsey number|0K9QVPJYJF]] $R(k,k)$ is the least $n$ such that every colouring of the edges of the complete graph $K_n$ in red and blue contains a $K_k$ with all edges of one colour.
Paul Erdős proved in 1947 that $R(k,k) > \lfloor 2^{k/2} \rfloor$ for $k \geq 3$.
His argument uses random colourings, and we check that it is a proof and not a [[heuristic argument|~722bccf4]].

1. The random object. Let $n = \lfloor 2^{k/2} \rfloor$. Colour each edge of $K_n$ red or blue by an independent fair coin toss.
2. One set. A fixed set of $k$ vertices spans $\binom{k}{2}$ edges. It is monochromatic with probability $2 \cdot 2^{-\binom{k}{2}} = 2^{1 - \binom{k}{2}}$.
3. The expectation. By linearity of expectation, the expected number of monochromatic $k$-sets is $\binom{n}{k}\, 2^{1 - \binom{k}{2}}$.
4. The estimate. $\binom{n}{k} < n^k/k! \leq 2^{k^2/2}/k!$. So the expectation is less than $2^{1 + k/2}/k!$, which is less than $1$ for $k \geq 3$.
5. The conclusion. A random variable with values in $\{0, 1, 2, \ldots\}$ and expectation below $1$ takes the value $0$ with positive probability. So some colouring of $K_n$ has no monochromatic $K_k$, and $R(k,k) > n$.

Every step is a theorem about a finite probability space, which is a finite sum over the $2^{\binom{n}{2}}$ colourings.
No step assumes that a deterministic object behaves like a random one.
So the argument is a proof by the [[probabilistic method|3B55HNS754]], with a certain conclusion, and not a heuristic.

## Remarks

A heuristic and a probabilistic proof often use the same words.
The difference is in what is random.
In the Cramér model of the primes, the primes are fixed, and the model assumes that they behave like random numbers; this assumption is not proved.
In Erdős's argument, the colouring is chosen at random from a set that the argument controls, and the conclusion is about the existence of one good colouring.
The page [[probabilistic lower bound for diagonal Ramsey numbers|SAZNT80CG5]] states a sharper form of the bound.

The proof gives no explicit colouring.
Explicit constructions of colourings without large monochromatic sets are much harder, and none matches the bound $2^{k/2}$.

## Explanations

### L1 human

Colour each line between $n$ points red or blue by tossing a coin.
Count how many groups of $k$ points are expected to have all their lines of one colour.
If this expected number is less than $1$, then some colouring must have no such group at all.
This argument uses chance, but its conclusion is certain: such a colouring exists.
That is the difference between a proof that uses probability and a guess based on probability.

### L2 human

We check step 4 for $k = 10$.

1. $n = \lfloor 2^5 \rfloor = 32$.
2. $\binom{32}{10} = 64512240$ and $\binom{10}{2} = 45$.
3. The expectation is $64512240 \cdot 2^{-44} \approx 3.7 \cdot 10^{-6}$, far below $1$.
4. So some colouring of $K_{32}$ has no monochromatic $K_{10}$, and $R(10,10) > 32$.

The typical use: an expectation below $1$ proves that an object with no bad configuration exists.
A trap: the existence proof does not tell how to find the colouring.
