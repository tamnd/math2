## Definition

A *Beth frame* is a rooted [[tree|062D9KXJB1]] $(T, \leq)$: a partial order with a least element in which the predecessors of each node form a finite chain.
A *path* is a maximal chain of $T$.
For a node $w$, a set $B$ of nodes is a *bar* for $w$ if every node of $B$ lies above $w$ and every path through $w$ meets $B$.

A *Beth model* is a triple $(T, \leq, V)$, where $V$ assigns to each variable $p$ a set $V(p)$ of nodes with two properties.

1. $V(p)$ is an [[up-set|ETCE287E2R]].
2. $V(p)$ is *barred*: if some bar for $w$ lies inside $V(p)$, then $w \in V(p)$.

Forcing is defined by induction on formulas.

1. $w \Vdash p$ if and only if $w \in V(p)$.
2. $w \nVdash \bot$.
3. $w \Vdash \varphi \wedge \psi$ if and only if $w \Vdash \varphi$ and $w \Vdash \psi$.
4. $w \Vdash \varphi \vee \psi$ if and only if there is a bar $B$ for $w$ such that each $b \in B$ forces $\varphi$ or forces $\psi$.
5. $w \Vdash \varphi \to \psi$ if and only if, for every $v \geq w$, $v \Vdash \varphi$ implies $v \Vdash \psi$.

A formula is valid in a Beth model if the root forces it.

## Notation

$N_w$ is the set of paths through $w$.
Some authors put $\bot$ into the valuation and allow "exploding" nodes; here no node forces $\bot$.

## Remarks

1. The only difference from [[Kripke semantics|~11b532e9]] is the clause for $\vee$: a disjunction is forced when every way of going on eventually decides one disjunct.
2. A path through a node contains all predecessors of that node, since the predecessors form a chain. So a path through $v$ with $v \geq w$ is a path through $w$.
3. Every node lies on some path, by Zorn's lemma or by choosing successors one by one. So the empty set is never a bar.
4. $\set{w}$ is a bar for $w$. If $B$ is a bar for $w$ and each $b \in B$ has a bar $B_b$, then $\bigcup_b B_b$ is a bar for $w$.
5. Example: on the tree with root $r$ and two leaves $a$, $b$, with $p$ true at $a$ and $q$ at $b$, the root forces $p \vee q$; see [[a Beth model of a disjunction|~c507c2cb]].
6. Non-example: a valuation that is an up-set but not barred is not allowed; see [[a valuation that is not barred|~ee92a072]].

## Explanations

### L1 human

A Beth model is a tree of possible futures, where each branch is one way the future may go.
A fact is known now if it becomes known on every branch, sooner or later.
"$A$ or $B$" is known now if every branch eventually decides one of the two.
Different branches may decide differently.

### L2 human

We check that $\set{a, b}$ is a bar for the root $r$ of the tree with two leaves $a$ and $b$.

1. The paths of the tree are $\set{r, a}$ and $\set{r, b}$.
2. Both pass through $r$, and they meet $\set{a, b}$ at $a$ and at $b$.
3. So $\set{a, b}$ is a bar for $r$, while $\set{a}$ is not.

The typical use of bars is to express "eventually, on every branch".
A trap: in a tree with infinite paths, a bar must meet every infinite path, and an infinite set of nodes may fail to do so.
