## Definition

In a given context, fix a [[set|~bd92ceee]] $U$ such that all the sets under discussion are [[subsets|~a9b9ba7e]] of $U$.
The set $U$ is then the universal set, or the universe of discourse, of the context.

## Remarks

In elementary number theory, $U$ can be the set $\mathbb{Z}$ of integers.
The [[complement|~ef45614e]] of a set is taken relative to the universal set.
In [[Zermelo–Fraenkel set theory|~e09c717c]], no set contains all sets. This is a consequence of [[Russell's paradox|~3590b1eb]].

## Explanations

### L1 human

The universal set is the "whole world" of a problem.
In a problem about real numbers, it is $\mathbb{R}$.
In a [[Venn diagram|~164195f9]], it is the rectangle that contains all the circles.
