## Example

Let $M = (\Z, +, \cdot, 0, 1)$.
Take the formulas of the [[interpretation of the rationals in the integers|~53eefcc8]], but with the domain formula $\partial(x_1, x_2)$ equal to $x_1 = x_1$, so that the domain is all of $\Z^2$.
The formula for equality is still $\varepsilon(x_1, x_2, y_1, y_2)$: $x_1 \cdot y_2 = y_1 \cdot x_2$.
We show that no coordinate map $f : \Z^2 \to N$, into any structure $N$, satisfies the equality condition of the [[definition|~0acf8019]].

1. The equality condition asks $f(\bar a) = f(\bar b)$ exactly when $M \models \varepsilon(\bar a, \bar b)$. Equality of values of $f$ is an [[equivalence relation|0G8VEZ3WTK]], so $\varepsilon$ would have to define an equivalence relation on $\Z^2$.
2. Take $\bar a = (1, 2)$, $\bar b = (0, 0)$ and $\bar c = (3, 5)$.
3. $\varepsilon(\bar a, \bar b)$ holds, since $1 \cdot 0 = 0 = 0 \cdot 2$.
4. $\varepsilon(\bar b, \bar c)$ holds, since $0 \cdot 5 = 0 = 3 \cdot 0$.
5. $\varepsilon(\bar a, \bar c)$ fails, since $1 \cdot 5 = 5$ and $3 \cdot 2 = 6$.
6. So $\varepsilon$ is not transitive on $\Z^2$, and step 1 gives a contradiction.

Hence these formulas, with this domain, are not an interpretation of any structure in $M$.
Only the equality condition fails: the problem is the pair $(0, 0)$, which is $\varepsilon$-related to every pair.

## Remarks

The example shows why the domain formula is a part of an interpretation.
With $\partial(x_1, x_2)$ equal to $\neg\, x_2 = 0$, the pair $(0, 0)$ and all pairs $(a, 0)$ leave the domain, and transitivity holds because $\Z$ has no zero divisors.

The pairs $(a, 0)$ with $a \neq 0$ alone do not break transitivity.
On the set $\set{(a, b) : (a, b) \neq (0, 0)}$, the formula $\varepsilon$ is an equivalence relation, whose classes are the lines through the origin in $\Z^2$.
The class of $(1, 0)$ then plays the role of a point at infinity, and the quotient is the projective line over $\Q$, not the field $\Q$.

The same failure happens in every integral domain, with the same three pairs.

## Explanations

### L1 human

A fraction cannot have zero at the bottom.
If we allow the pair $(0, 0)$, the cross-multiplication test says that it equals every other pair.
Then $(1, 2)$ "equals" $(0, 0)$, and $(0, 0)$ "equals" $(3, 5)$, but $(1, 2)$ does not equal $(3, 5)$.
A rule for "naming the same thing" cannot behave like this.

### L2 human

We find all pairs $\bar b$ that are $\varepsilon$-related to every pair of $\Z^2$.

1. Let $\bar b = (b_1, b_2)$, and suppose $\varepsilon(\bar a, \bar b)$ for all $\bar a$.
2. For $\bar a = (1, 0)$ the condition is $1 \cdot b_2 = b_1 \cdot 0$, so $b_2 = 0$.
3. For $\bar a = (0, 1)$ the condition is $0 \cdot b_2 = b_1 \cdot 1$, so $b_1 = 0$.
4. So $\bar b = (0, 0)$, and conversely $(0, 0)$ is related to every pair.

The typical use of this check is to find the tuples that must leave the domain.
A trap is to remove only the pairs $(a, 0)$ with $a \neq 0$: then $(0, 0)$ is still in the domain, and transitivity still fails.
