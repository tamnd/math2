## Proof

We use the notation of the [[statement|WGBR7JHBV4]].
Write $[F]$ for the [[clone|PTKR703G6A]] generated by $F$: the set of truth functions of formulas built from variables with the functions of $F$ as connectives.
So $[F]$ contains every projection $(x_1, \ldots, x_n) \mapsto x_i$, and it is closed under composition: if $f \in [F]$ is $k$-ary and $g_1, \ldots, g_k \in [F]$ are $n$-ary, then $f(g_1, \ldots, g_k) \in [F]$.
For $a, b \in \set{0,1}^n$, write $\neg a = (\neg a_1, \ldots, \neg a_n)$, and $a \leq b$ when $a_i \leq b_i$ for each $i$.

**Part 1: a complete set lies in none of the classes.**
We prove the contrapositive: if $F \subseteq K$ for one of the five classes $K$, then $F$ is not complete.

1. Each projection $x_i$ is in all five classes: it sends $(0, \ldots, 0)$ to $0$ and $(1, \ldots, 1)$ to $1$; $a \leq b$ gives $a_i \leq b_i$; $x_i(\neg a) = \neg a_i$; and $x_i = 0 \oplus x_i$ is affine.
2. Let $f$ be $k$-ary, let $g_1, \ldots, g_k$ be $n$-ary, and let $h = f(g_1, \ldots, g_k)$. Write $g(a) = (g_1(a), \ldots, g_k(a))$, so that $h(a) = f(g(a))$.
3. $T_0$ is closed under composition: if $f, g_j \in T_0$, then $g(0, \ldots, 0) = (0, \ldots, 0)$, so $h(0, \ldots, 0) = f(0, \ldots, 0) = 0$. The same argument works for $T_1$.
4. $M$ is closed under composition: if $f, g_j \in M$ and $a \leq b$, then $g_j(a) \leq g_j(b)$ for each $j$, so $g(a) \leq g(b)$ and $h(a) = f(g(a)) \leq f(g(b)) = h(b)$.
5. $S$ is closed under composition: if $f, g_j \in S$, then $g(\neg a) = \neg g(a)$, so $h(\neg a) = f(\neg g(a)) = \neg f(g(a)) = \neg h(a)$.
6. $A$ is closed under composition: if $f = d_0 \oplus \bigoplus_j d_j y_j$ and $g_j = c_{j0} \oplus \bigoplus_i c_{ji} x_i$, then $h = d_0 \oplus \bigoplus_j d_j c_{j0} \oplus \bigoplus_i \big(\bigoplus_j d_j c_{ji}\big) x_i$, which is affine.
7. By steps 1 to 6 and [[structural induction|12MQ2NJ29A]] on formulas, $F \subseteq K$ implies $[F] \subseteq K$.
8. Each class misses some function. Negation $\neg$ is not in $T_0$, $T_1$ or $M$, since $\neg 0 = 1$, $\neg 1 = 0$ and $0 \leq 1$ but $\neg 0 > \neg 1$. The unary constant $0$ is not in $S$: at the input $0$, self-duality would need its value at $\neg 0 = 1$ to be $\neg 0 = 1$, but this value is $0$.
9. Conjunction is not in $A$: if $x \land y = c_0 \oplus c_1 x \oplus c_2 y$, then the input $(0,0)$ gives $c_0 = 0$, the inputs $(1,0)$ and $(0,1)$ give $c_1 = c_2 = 0$, and then $1 \land 1 = 0$, which is false.
10. So $[F] \subseteq K$ is not the set of all Boolean functions, and $F$ is not complete.

**Part 2: a set outside each class is complete.**
Let $f_0 \notin T_0$, $f_1 \notin T_1$, $f_m \notin M$, $f_s \notin S$ and $f_a \notin A$ be functions in $F$, not necessarily different.
We show that $[F]$ contains $\neg$, the unary constants $0$ and $1$, and $\land$.

11. Let $g(x) = f_0(x, \ldots, x)$. Then $g \in [F]$ by composition with projections, and $g(0) = f_0(0, \ldots, 0) = 1$. So $g = \neg$ when $g(1) = 0$, and $g$ is the constant $1$ when $g(1) = 1$.
12. Let $h(x) = f_1(x, \ldots, x)$. Then $h \in [F]$ and $h(1) = 0$. So $h = \neg$ when $h(0) = 1$, and $h$ is the constant $0$ when $h(0) = 0$.
13. Case I: $g = \neg$ or $h = \neg$, so $\neg \in [F]$. Since $f_s \notin S$, some $a \in \set{0,1}^n$ has $f_s(\neg a) \neq \neg f_s(a)$, that is, $f_s(\neg a) = f_s(a)$.
14. In Case I, for $x \in \set{0,1}$ let $x^{1} = x$ and $x^{0} = \neg x$, and let $k(x) = f_s(x^{a_1}, \ldots, x^{a_n})$. Then $k \in [F]$, because each $x^{a_i}$ is $x$ or $\neg x$.
15. In Case I, $1^{a_i} = a_i$ and $0^{a_i} = \neg a_i$ for each $i$. So $k(1) = f_s(a)$ and $k(0) = f_s(\neg a)$, and these are equal by step 13. So $k$ is a constant $c$, and $\neg k$ is the constant $\neg c$. Both constants are in $[F]$.
16. Case II: by steps 11 and 12, the remaining case is that $g$ is the constant $1$ and $h$ is the constant $0$. Both constants are in $[F]$. Since $f_m \notin M$, there are $a \leq b$ with $f_m(a) = 1$ and $f_m(b) = 0$.
17. In Case II, $a \neq b$, so the set $I = \set{i : a_i = 0, b_i = 1}$ is not empty; let $I = \set{i_1, \ldots, i_r}$. Let $c^0 = a$, and let $c^j$ be $c^{j-1}$ with coordinate $i_j$ changed from $0$ to $1$. Then $c^r = b$.
18. In Case II, $f_m(c^0) = 1$ and $f_m(c^r) = 0$. Let $j$ be the least index with $f_m(c^j) = 0$. Then $j \geq 1$ and $f_m(c^{j-1}) = 1$. The points $c^{j-1}$ and $c^j$ differ only in coordinate $i = i_j$.
19. In Case II, let $\nu(x) = f_m(y_1, \ldots, y_n)$, where $y_i = x$ and $y_t$ is the constant $c^j_t$ for $t \neq i$. Then $\nu \in [F]$, since the constants are in $[F]$. Also $\nu(0) = f_m(c^{j-1}) = 1$ and $\nu(1) = f_m(c^j) = 0$, so $\nu = \neg$.
20. In both cases, $[F]$ contains $\neg$ and the constants $0$ and $1$.
21. Every Boolean function $f$ of $n$ variables is a sum modulo $2$ of distinct monomials $\prod_{i \in T} x_i$ with $T \subseteq \set{1, \ldots, n}$, where the empty product is $1$. This is its algebraic normal form; steps 31 to 34 prove that it exists.
22. If each monomial in this sum for $f_a$ had at most one variable, $f_a$ would be affine. So some monomial has at least two variables. Renumber the variables so that it contains $x_1$ and $x_2$.
23. Among the monomials of $f_a$ that contain both $x_1$ and $x_2$, choose one, $x_1 x_2 \prod_{k \in Q} x_k$, with $Q$ as small as possible.
24. In $f_a$, set $x_k = 1$ for $k \in Q$ and $x_k = 0$ for each other $k \geq 3$. This uses the constants of step 20, so the result $p(x_1, x_2)$ is in $[F]$.
25. A monomial that contains some $x_k$ set to $0$ becomes $0$. A monomial that contains $x_1$ and $x_2$ and survives has the form $x_1 x_2 \prod_{k \in Q'} x_k$ with $Q' \subseteq Q$; by step 23, $Q' = Q$, so exactly one surviving monomial becomes $x_1 x_2$. Every other surviving monomial becomes $x_1$, $x_2$ or $1$.
26. So $p(x, y) = xy \oplus \alpha x \oplus \beta y \oplus \gamma$ for some $\alpha, \beta, \gamma \in \set{0,1}$.
27. Let $q(x, y) = p(x \oplus \beta, y \oplus \alpha)$. Here $x \oplus \beta$ is $x$ or $\neg x$, so $q \in [F]$. Multiplying out, $q(x, y) = xy \oplus \alpha x \oplus \beta y \oplus \alpha\beta \oplus \alpha x \oplus \alpha\beta \oplus \beta y \oplus \alpha\beta \oplus \gamma = xy \oplus \alpha\beta \oplus \gamma$.
28. If $\alpha\beta \oplus \gamma = 0$, then $q = x \land y$. Otherwise $\neg q = x \land y$. In both cases $\land \in [F]$.
29. The set $\set{\neg, \land}$ is [[functionally complete|TDZVCWYJ9F]], and $\neg, \land \in [F]$. Since $[F]$ is closed under composition, $[F]$ contains every Boolean function of arity at least $1$.
30. So $F$ is functionally complete. With Part 1, this proves the theorem.

**The algebraic normal form (step 21).**

31. If $f$ is the constant $0$, it is the empty sum. Otherwise, $f$ is the disjunction of the minterms $m_a$ with $f(a) = 1$, by the full [[disjunctive normal form|0GVDFAY4KW]].
32. At each point at most one minterm is true, so the disjunction of the minterms equals their sum modulo $2$.
33. In each minterm, write $\neg x_i$ as $1 \oplus x_i$, and multiply out with the distributive law $u(v \oplus w) = uv \oplus uw$ and with $x_i x_i = x_i$. The result is a sum modulo $2$ of monomials.
34. A monomial that occurs twice cancels, by $u \oplus u = 0$. After all cancellations, the monomials are distinct.

## Idea

Part 1 shows that each of the five classes is a clone that misses some function, so it traps every set inside it.
Part 2 builds the basic connectives from the five witnesses: the witnesses for $T_0$ and $T_1$, applied to a repeated variable, give either negation or both constants.
With negation, the non-self-dual witness gives the constants; with the constants, the non-monotone witness gives negation.
Finally, a monomial of degree at least $2$ in the polynomial of the non-affine witness, after substituting constants, gives conjunction.

## Variants

A second proof uses [[Post's lattice|MA20X7JCET]]: Post determined all clones on $\set{0,1}$, and one reads off that the five classes are the only maximal ones.
This proof is much longer, but it gives more: for example, it describes which functions a given incomplete set generates.
A third approach uses the Galois connection between clones and relations: each maximal clone is the set of functions that preserve one relation, and the proof finds the relations that give maximal clones.
This is the method that extends to finite sets with more than two elements in [[Rosenberg's classification|GF1RK91VED]].
