## Example

Problem: how many triples $(x, y, z)$ of nonnegative integers satisfy $x + y + z = 10$?
Listing the triples by hand is long and error-prone.
We replace the problem by an equivalent [[auxiliary problem|~a5a06d23]].

1. Represent a triple by a row of $10$ stars and $2$ bars: $x$ stars, a bar, $y$ stars, a bar, $z$ stars. For example, $(3, 0, 7)$ is `***||*******`.
2. Each triple gives a row of $12$ symbols with exactly $2$ bars.
3. Each row of $12$ symbols with exactly $2$ bars gives a triple: count the stars before the first bar, between the bars and after the second bar. The three counts are nonnegative and add up to $10$.
4. The maps of steps 2 and 3 are inverse to each other, so they are bijections. By the [[bijection principle|0GV2573FP4]], the two sets have the same size.
5. Auxiliary problem: in how many ways can we choose the $2$ places of the bars among $12$ places? The answer is $\binom{12}{2} = \frac{12 \cdot 11}{2} = 66$.
6. So there are $66$ triples.

A check on a small case: for $x + y + z = 2$, the formula gives $\binom{4}{2} = 6$, and the triples are $(2,0,0)$, $(0,2,0)$, $(0,0,2)$, $(1,1,0)$, $(1,0,1)$ and $(0,1,1)$.

## Remarks

The auxiliary problem is equivalent to the original problem, because the bijection keeps all information.
This is the strongest kind of auxiliary problem: its answer is the answer of the original problem.
The general result is [[stars and bars|009TEMTQKH]]: the equation $x_1 + \cdots + x_k = n$ has $\binom{n + k - 1}{k - 1}$ solutions in nonnegative integers.

When the variables must be positive, a second auxiliary problem helps: put $x = x' + 1$, $y = y' + 1$, $z = z' + 1$.
Then $x' + y' + z' = 7$ with $x', y', z' \geq 0$, and the count is $\binom{9}{2} = 36$.

## Explanations

### L1 human

We want to share $10$ sweets among $3$ children, where a child may get none.
Put the $10$ sweets in a row and place $2$ sticks to cut the row into three parts.
Each way to place the sticks is one way to share the sweets.
So we only need to count the ways to choose $2$ places out of $12$ for the sticks.
There are $66$ ways.

### L2 human

We count the nonnegative integer solutions of $x + y + z + w = 5$ in the same way.

1. A solution is a row of $5$ stars and $3$ bars, which has $8$ symbols.
2. The bijection is the same as before: count the stars between the bars.
3. The number of rows is the number of ways to choose $3$ places of $8$: $\binom{8}{3} = 56$.
4. So the equation has $56$ solutions.

The typical use: an equivalent problem from a bijection turns a count with conditions into a count of subsets.

A trap: the auxiliary problem is equivalent only if the map is a bijection; if two rows gave the same triple, the count $66$ would be too large.
