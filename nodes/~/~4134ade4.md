## Summary

This node fixes the algebraic vocabulary used in several complex variables. It starts from an explicit list of axioms and then adds four related notions.

A commutative ring is a set $R$ with an addition and a multiplication, both closed on $R$, such that the following hold. Addition is commutative and associative. There is an element $0$ with $0 + x = x$ for all $x$. Every $x$ has an additive inverse $-x$ with $x + (-x) = 0$. Multiplication is commutative and associative. There is an element $1$ with $1x = x$ for all $x$, and $1 \neq 0$. Multiplication distributes over addition: $x(y+z) = xy + xz$.

So a ring here always has an identity, it is always commutative, and it is never the zero ring. This is a [[ring|0894J980RK]] whose multiplication is commutative, with $1 \neq 0$ required.

An integral domain is a commutative ring in which $xy = 0$ forces $x = 0$ or $y = 0$.

A [[field|0QA8CHH8MG]] is a commutative ring in which each nonzero $x$ has an element $1/x$ with $x \cdot (1/x) = 1$.

In a commutative ring, a unit is an element that has a multiplicative inverse in the ring.

Let $R$ and $S$ be rings. A ring homomorphism $f \colon R \to S$ is a map with $f(a+b) = f(a) + f(b)$, $f(ab) = f(a)f(b)$ and $f(1) = 1$. A ring isomorphism is a ring homomorphism that is bijective.
