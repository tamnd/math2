## Example

Let $G = (\mathbb{Z}, +)$ be the [[integers|0C4JS9RF5M]] with addition, and let $n \ge 1$.
Let $H = n\mathbb{Z}$ be the [[subgroup|0X1JXT47GA]] of multiples of $n$.
Its [[cosets|03DEH43F4H]] are the sets $r + n\mathbb{Z}$, and two integers lie in the same coset exactly when they have the same remainder modulo $n$.
We show that $T = \{0, 1, \ldots, n - 1\}$ is a [[transversal|~f92388d9]] of $H$.

1. Let $a \in \mathbb{Z}$. By the [[division algorithm|0CHQKZFK5S]], $a = qn + r$ with unique $q \in \mathbb{Z}$ and $r \in T$.
2. Thus the coset $a + n\mathbb{Z}$ contains the element $r$ of $T$.
3. Two different elements of $T$ differ by a number from $1$ to $n - 1$. This difference is not in $n\mathbb{Z}$.
4. Thus each coset contains exactly one element of $T$.

So $T$ is a transversal, and it has $n = [\mathbb{Z} : n\mathbb{Z}]$ elements, the [[index|0DTXBQPA2S]].

## Remarks

Other transversals of $n\mathbb{Z}$ are easy to find.
The set $\{1, 2, \ldots, n\}$ is one, because $n$ takes the place of $0$.
Each set of $n$ consecutive integers is one.
A set need not be consecutive: for $n = 3$, the set $\{0, 4, 8\}$ is a transversal, because $4 \equiv 1$ and $8 \equiv 2$ modulo $3$.
In general, a set of $n$ integers is a transversal exactly when its elements have different remainders modulo $n$.

The group $\mathbb{Z}$ is [[abelian|082GHNPJ53]], so each left coset is a right coset.
Thus each transversal of $n\mathbb{Z}$ is a common transversal.

For $n \ge 2$, no transversal of $n\mathbb{Z}$ is a subgroup.
A transversal has $n$ elements, but the only finite subgroup of $\mathbb{Z}$ is $\{0\}$.
So $n\mathbb{Z}$ has no complement in $\mathbb{Z}$.

## Explanations

### L1 human

Sort the integers by their remainder after division by $4$.
There are four classes.
The numbers $0, 1, 2, 3$ have the four different remainders, so they name the four classes.
The numbers $8, 5, 2, 11$ also have the four different remainders, so they also work.
Each such set of names is a transversal.

### L2 human

We decide whether $\{3, 7, 10, 20\}$ is a transversal of $4\mathbb{Z}$.

1. The remainders modulo $4$ are $3$, $3$, $2$ and $0$.
2. The numbers $3$ and $7$ have the same remainder, so they lie in the same coset.
3. No number has remainder $1$, so the coset $1 + 4\mathbb{Z}$ has no element of the set.
4. Thus the set is not a transversal.

The typical use is the choice of a standard name for each residue class, as in modular arithmetic.
A trap is to count only the elements.
A set with $4$ elements is not always a transversal of $4\mathbb{Z}$.
