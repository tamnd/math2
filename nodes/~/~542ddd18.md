## Statement

Let $L$ be a first-order language without the equality symbol, with at least one constant symbol, the connectives $\neg, \wedge, \vee, \to$ and the quantifiers $\forall, \exists$.
Let $T_L$ be the set of closed [[terms|6D3WA7N2W4]] of $L$.
Let $H$ be a [[Hintikka set|~03b04954]] for $L$.
Define the $L$-[[structure|983GZBQYT4]] $\mathcal{M}_H$ as follows.

- The domain is $T_L$.
- Each constant symbol $c$ is interpreted as the term $c$ itself.
- Each $n$-ary function symbol $f$ is interpreted as the map that sends $(t_1, \dots, t_n)$ to the term $f(t_1, \dots, t_n)$.
- Each $n$-ary relation symbol $R$ is interpreted as the set of tuples $(t_1, \dots, t_n)$ with $R(t_1, \dots, t_n) \in H$.

Then $\mathcal{M}_H \models \varphi$ for every sentence $\varphi \in H$.
In particular, every Hintikka set is [[satisfiable|QN7M1JCGT9]].

## Remarks

The structure $\mathcal{M}_H$ is the [[Herbrand structure|HKW429DSDK]] of $L$ in which the true atomic sentences are exactly the atomic members of $H$.
Atomic sentences that are not in $H$ are false in $\mathcal{M}_H$, even when $H$ does not contain their negation.

### Why each hypothesis is needed

Each failure below is a set that satisfies all the other hypotheses and has no model.
The examples use a language with one constant $c$ and unary relation symbols $P, Q$, unless they say otherwise.

- Without condition (1): $\{P(c), \neg P(c)\}$ satisfies (2) to (5), because it has only literals, and it is unsatisfiable.
- Without condition (2): $\{P(c) \wedge Q(c), \neg P(c)\}$ satisfies (1), (3), (4) and (5), and it is unsatisfiable.
- Without condition (3): $\{P(c) \vee Q(c), \neg P(c), \neg Q(c)\}$ satisfies the other conditions, and it is unsatisfiable.
- Without condition (4): $\{\forall x\, P(x), \neg P(c)\}$ satisfies the other conditions, and it is unsatisfiable.
- Without condition (5): $\{\exists x\, P(x), \forall x\, \neg P(x), \neg P(c)\}$ satisfies (4) because $\neg P(c)$ is the only instance, and it is unsatisfiable.
- Without a constant symbol: in the language with only $P$, the set $\{\forall x\, P(x), \forall x\, \neg P(x)\}$ satisfies (4) vacuously, since there are no closed terms. It has no model, because a structure has a nonempty domain.
- Without the restriction to languages without equality: the set $\{\neg(c = c)\}$ satisfies (1) to (5), because $c = c$ is not in it, and no structure makes it true. The set $\{c = d, P(c), \neg P(d)\}$ is another such case.

### With equality

When $L$ has the equality symbol, we add two closure conditions to the definition of a Hintikka set.

- (E1) $(t = t) \in H$ for each closed term $t$.
- (E2) If $(s = t) \in H$, $\varphi$ is an atomic formula whose only free variable is $x$, and $\varphi[s/x] \in H$, then $\varphi[t/x] \in H$.

Define $s \sim t$ when $(s = t) \in H$.
(E1) makes $\sim$ reflexive.
(E2) with $\varphi = (x = s)$ makes it symmetric, and (E2) with $\varphi = (r = x)$ makes it transitive.
(E2) with $\varphi = (f(t_1, \dots, x, \dots, t_n) = f(t_1, \dots, t_i, \dots, t_n))$ and with $\varphi = R(t_1, \dots, x, \dots, t_n)$ shows that $\sim$ is a [[congruence relation|DCSXXT4SER]] that respects the relations given by $H$.
The new model has the classes $[t]$ as elements, $f([t_1], \dots, [t_n]) = [f(t_1, \dots, t_n)]$, and $R$ true of $([t_1], \dots, [t_n])$ when $R(t_1, \dots, t_n) \in H$.
Then $s = t$ is true exactly when $(s = t) \in H$, and the induction of the proof goes through with $[t]$ in place of $t$.
For $\neg(s = t) \in H$, condition (1) gives $(s = t) \notin H$, so $[s] \neq [t]$.

### Consequences

- Completeness of tableaux: an open branch of a fair systematic tableau is a Hintikka set for $L^{+}$, so the set at its root is satisfiable; see [[semantic tableaux|~78632a29]].
- The model has the domain $T_L$, so it is countable when $L$ is countable. Through the tableau proof this gives a countable model for each satisfiable countable set, a case of the [[Löwenheim-Skolem theorem|484M0TZ1S7]].
- A Hintikka set contains no pair $\chi, \neg\chi$, for any sentence $\chi$.
- Combined with a construction of Hintikka sets, the lemma gives the [[model existence theorem|G0DTR159RN]] and [[Gödel's completeness theorem|WQ1ZE255SF]].

### Converse

The converse "every satisfiable set is a Hintikka set" is false.
The set $\{\exists x\, P(x)\}$ is satisfiable, and it fails condition (5); see [[a satisfiable set that is not a Hintikka set|~2d814afe]].
A weaker converse is true.
Let $\Gamma$ have a model $\mathcal{M}$, and add to $L$ a new constant $\underline{a}$ for each element $a \in M$.
Then the set of sentences of the larger language that are true in $\mathcal{M}$, with $\underline{a}$ interpreted as $a$, is a Hintikka set, and it contains $\Gamma$.
So a set is satisfiable exactly when it is a subset of a Hintikka set for some language.

### Generalizations

The propositional version takes $H$ to be a set of propositional formulas with conditions (1) to (3), and the model is the valuation that makes a letter true exactly when it is in $H$.
The same lemma holds for many-sorted languages and, with Kripke models in place of structures, for modal and intuitionistic logics.

## History

Jaakko Hintikka introduced model sets in 1955, as sets of sentences that describe a model.
Raymond Smullyan's book First-Order Logic (1968) gave the lemma in the uniform $\alpha, \beta, \gamma, \delta$ notation and used it for the completeness of analytic tableaux.

## Explanations

### L1 human

A Hintikka set is a list of facts in which each complicated fact is backed by simpler facts on the list.
The lemma says that such a list always describes a possible world.
To build the world, we take the names on the list as the objects.
Then we make each basic fact on the list true and every other basic fact false.
For example, the list "$P(c)$ and not $Q(c)$; $P(c)$; not $Q(c)$" gives the world with one object $c$ that has $P$ and lacks $Q$.
The backing of each fact by simpler facts then makes every fact on the list true.

### L2 human

We apply the lemma to $H = \{\exists x\, Q(x),\ Q(c),\ \forall x(Q(x) \to P(x)),\ Q(c) \to P(c),\ P(c)\}$ in the language with the constant $c$ and the unary symbols $P, Q$.

1. $H$ is a Hintikka set: there are no negated atoms, so (1) holds; the $\beta$ sentence $Q(c) \to P(c)$ has the component $P(c) \in H$; the $\gamma$ sentence has the instance for the only closed term $c$; the $\delta$ sentence has the instance $Q(c)$.
2. The closed terms are $T_L = \{c\}$, so $\mathcal{M}_H$ has one element $c$.
3. $P^{\mathcal{M}_H} = \{c\}$ because $P(c) \in H$, and $Q^{\mathcal{M}_H} = \{c\}$ because $Q(c) \in H$.
4. We check from the short sentences up: $P(c)$ and $Q(c)$ are true; $Q(c) \to P(c)$ is true; $\forall x(Q(x) \to P(x))$ is true because its only instance is true; $\exists x\, Q(x)$ is true with the witness $c$.

The typical use is the last step of a completeness proof for a tableau or sequent system.
The trap is equality: with $=$ in the language, the structure $\mathcal{M}_H$ interprets $=$ as identity of terms, so $c = d \in H$ is false in it, and the quotient of the remarks is needed.

### L3 human

The lemma is a cut-free form of model existence: the model is read off from a set that is only closed downward, and it needs no maximal consistent extension.
The model is a [[Herbrand structure|HKW429DSDK]], and Herbrand's theorem is the finite form of the same idea.
The proof is an induction on a measure that the instances $\gamma(t)$ and $\delta(t)$ decrease, even though they are not subformulas.
The same pattern, an induction that carries truth up from the atomic level, appears in the truth lemma for canonical models in modal logic.
