## Statement

Let $V$ be a vector space of finite dimension $n \ge 1$ over a field $F$, and let $T \colon V \to V$ be linear.
Let $m_T$ be its [[minimal polynomial|03NDVCSHSB]] and $\chi_T$ its [[characteristic polynomial|0J5EMJRRFM]].
Then $T$ is [[cyclic|~33677c91]], that is, $V = Z(v; T)$ for some $v \in V$, if and only if $m_T = \chi_T$.
In this case $T$ has the matrix $C(\chi_T)$ in the basis $v, Tv, \dots, T^{n-1} v$, for each cyclic vector $v$.

## Remarks

### Why each hypothesis is needed

Finite dimension is needed for $\chi_T$ to exist.
The condition is $m_T = \chi_T$, not only "same roots": $I_2$ and $J_2(1)$ both have only the root $1$ in both polynomials, but only $J_2(1)$ is cyclic.

### Consequences

- If $\chi_T$ has $n$ distinct roots in $F$, then $m_T = \chi_T$, since every root of $\chi_T$ is a root of $m_T$ and $m_T \mid \chi_T$. So $T$ is cyclic.
- A matrix $A$ is cyclic if and only if it is similar to the [[companion matrix|0ZCWPNZTQ3]] $C(\chi_A)$.
- Two cyclic matrices are similar if and only if they have the same characteristic polynomial.
- A [[Jordan block|07PH4RX0X5]] $J_n(\lambda)$ is cyclic, since $m = \chi = (x - \lambda)^n$.

### Converse

The statement is an equivalence, so each direction is the converse of the other.
In general $m_T \mid \chi_T$ by the [[Cayley-Hamilton theorem|0F765KFC2J]], and the theorem says that equality holds exactly for the cyclic maps.

### Generalizations

The rank of $V_T$ as an $F[x]$-module, the least number of generators, is the number of invariant factors of $T$.
The theorem is the case of one generator.
Over an algebraically closed field, $T$ is cyclic if and only if each eigenvalue has a single Jordan block, that is, geometric multiplicity $1$.

## Explanations

### L1 human

The characteristic polynomial of a map on an $n$-dimensional space always has degree $n$.
The minimal polynomial can be shorter.
The theorem says that the two are equal exactly when one vector, pushed again and again by the map, reaches every direction of the space.
For the map that doubles the second coordinate of a point in the plane, both polynomials are $(x - 1)(x - 2)$, and the point one, one does the job.

### L2 human

Let $A = \begin{pmatrix} 2 & 1 & 0 \\ 0 & 2 & 0 \\ 0 & 0 & 3 \end{pmatrix}$ over $\mathbb{Q}$.

1. $\chi_A = (x - 2)^2 (x - 3)$, since $A$ is upper triangular.
2. $(A - 2I)(A - 3I)$ has entry $(1, 2)$ equal to $1 \cdot (-1) = -1$, so $(x - 2)(x - 3)$ does not annihilate $A$.
3. So $m_A = (x - 2)^2 (x - 3) = \chi_A$, and $A$ is cyclic.
4. A cyclic vector is $v = e_2 + e_3$: $Av = (1, 2, 3)$ and $A^2 v = (4, 4, 9)$.
5. The determinant of the matrix with columns $v, Av, A^2 v$ is $-1 \ne 0$, so these vectors form a basis.

The typical use is a quick test for a companion form: compare $m_A$ with $\chi_A$.
The trap is $A = \operatorname{diag}(2, 2, 3)$, which has the same characteristic polynomial but $m_A = (x - 2)(x - 3)$, so it is not cyclic.

### L3 human

For the $F[x]$-module $V_T$, the theorem says that $V_T$ is cyclic if and only if its annihilator ideal $(m_T)$ has the same "size" as the whole module, measured by $\dim_F$.
Over $\overline{F}$, the cyclic matrices are the regular elements of the Lie algebra $\mathfrak{gl}_n$, those whose centralizer has the least possible dimension $n$.
See the [[theorem on centralizers|~0a19e561]] for this link.
