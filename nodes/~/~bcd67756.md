## Example

Statement: for every real number $x$, if $x \neq 0$, then $x^2 > 0$.
A student proposes $x = 0$ as a [[counterexample|0ED72CTBNP]], since $0^2 = 0$ is not greater than $0$.
We check the conditions of a counterexample.

1. A counterexample must be a real number. The number $0$ is real, so this condition holds.
2. A counterexample must satisfy the hypothesis $x \neq 0$. The number $0$ does not, so this condition fails.
3. A counterexample must fail the conclusion. $0^2 = 0$ is not greater than $0$, so this condition holds.

Condition 2 fails, so $0$ is not a counterexample.
In fact the statement is true and has no counterexample: if $x > 0$, then $x^2 = x \cdot x > 0$, and if $x < 0$, then $x^2 = (-x)(-x) > 0$.

## Remarks

The student's number is a counterexample to a different statement, "for every real number $x$, $x^2 > 0$", which drops the hypothesis.
That shows that the hypothesis $x \neq 0$ is needed.
So the proposed number is useful, but not for the purpose the student had in mind.

Changing the set of allowed values also changes the answer.
For complex numbers, $x = i$ satisfies $x \neq 0$ and $x^2 = -1$, which is not greater than $0$.
So the statement fails over $\mathbb{C}$, where there is no order compatible with multiplication at all.

## Explanations

### L1 human

The rule says: square any number except zero, and the result is positive.
The student squared zero and got zero, which is not positive.
But the rule never talked about zero; it left zero out on purpose.
So zero cannot break the rule.
To break it, one would need a number other than zero with a square that is not positive, and there is no such real number.

### L2 human

We test two proposed counterexamples to the statement "for every real $x > 1$, $x^2 > x$".

1. Proposal $x = \frac{1}{2}$: the hypothesis $x > 1$ fails, so it is not a counterexample, even though $\frac{1}{4} < \frac{1}{2}$.
2. Proposal $x = 1$: the hypothesis $x > 1$ fails again, since $1 > 1$ is false.
3. In fact, for $x > 1$, multiplying $x > 1$ by $x > 0$ gives $x^2 > x$. So the statement is true.

The typical use: before checking the conclusion, check that the proposed object satisfies every hypothesis.

A trap: a boundary value such as $x = 1$ is a common candidate, and strict and non-strict inequalities in the hypothesis decide whether it is allowed.
