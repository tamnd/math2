## Example

The monadic second-order sentence $\sigma = \exists X \, \forall x \, \neg X x$ says that there is an empty set of elements.
We show that $\sigma$ is valid in [[second-order logic|G6X7SZSNC5]] with full semantics, but that its direct reading as a [[plural quantification|~8cf214d8]] is refutable.
So $\sigma$ is not a plural statement, and the empty case needs a separate clause in Boolos's translation.

1. In full semantics, $X$ ranges over all subsets of the domain $M$, including the [[empty set|0ECVK59Y03]]. With $X = \emptyset$, the formula $\forall x \, \neg Xx$ is true. So $\sigma$ is true in every structure.
2. The direct plural reading of $\sigma$ is $\sigma_p = \exists xx \, \forall x \, \neg (x \prec xx)$: there are some things such that nothing is one of them.
3. Plural logic has the axiom $\forall xx \, \exists y \, (y \prec xx)$: any things include at least one thing.
4. Let $xx$ be some things. By step 3 there is $y$ with $y \prec xx$, so $\forall x \, \neg (x \prec xx)$ fails for $xx$. So $\neg \sigma_p$ is provable.
5. Boolos's translation of $\exists X \, \psi$ is $\psi[\emptyset] \lor \exists xx \, \psi[xx]$. For $\psi = \forall x \, \neg Xx$, the first disjunct is $\forall x \, \neg (x \neq x)$, which is valid.
6. So the correct translation of $\sigma$ is valid, as $\sigma$ is. It is true because of the first disjunct alone, which contains no plural quantifier.

## Remarks

The example shows the one point where monadic second-order logic and plural logic differ: sets can be empty, and pluralities cannot.
Ordinary language agrees: "there are some critics who ..." is false when there are no such critics.
Plural comprehension carries the matching hypothesis $\exists y \, \varphi(y)$; without it, the instance for $\varphi(y) = y \neq y$ would give an empty plurality.
The difference is harmless for expressive power.
A second-order formula can exclude the empty set with $\exists x \, Xx$, and the first disjunct of Boolos's translation brings the empty set back.
For the sentence $\exists X \, \exists x \, Xx$ the situation reverses: the empty case is false, and only the plural disjunct matters.

## Explanations

### L1 human

In mathematics, the empty set is a set like any other: it is the set with no members.
In ordinary speech, "some things" always means at least one thing.
"There are some apples on the table" is false if the table is empty.
So the statement "there is a set with no members" is true.
But "there are some things, and none of them is anything" makes no sense.
When we read sets as "some things", we must treat the empty set separately.

### L2 human

We translate $\tau = \exists X \, (\forall x \, \neg Xx \land \exists y \, \neg Xy)$ with Boolos's rule.

1. Here $\psi = \forall x \, \neg Xx \land \exists y \, \neg Xy$.
2. The first disjunct $\psi[\emptyset]$ is $\forall x \, \neg (x \neq x) \land \exists y \, \neg (y \neq y)$, which is true in every nonempty domain.
3. The second disjunct $\exists xx \, \psi[xx]$ is refutable, because its first conjunct says that nothing is one of $xx$.
4. So the translation of $\tau$ is valid, as $\tau$ is: the empty set misses some element.

The typical use of the rule is to translate a second-order formula correctly into plural logic.
A trap is to drop the first disjunct, which turns valid second-order sentences such as $\tau$ into refutable plural ones.
