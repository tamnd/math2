## Statement

Let $(a_n)$ be a real sequence with $a_n \ge 0$ for all $n$.
Then the series $\sum a_n$ converges if and only if its [[partial sums|~50195ca2]] $s_N = \sum_{n=0}^{N} a_n$ are bounded above.
In this case, $\sum_{n=0}^{\infty} a_n = \sup_N s_N$.

## Remarks

The partial sums increase, since $s_{N+1} - s_N = a_{N+1} \ge 0$. The result is then the [[monotone convergence theorem|~471ab2b3]].
If the partial sums are not bounded, they tend to $+\infty$, and one writes $\sum a_n = +\infty$.
The [[comparison test|~f5595543]], the [[integral test|~2af9eb66]] and the [[Cauchy condensation test|~7ee8b747]] all rest on this fact.

## Explanations

### L1 human

When all terms are nonnegative, the running total can only go up.
So it either stays below some ceiling and converges, or it grows past every bound.
