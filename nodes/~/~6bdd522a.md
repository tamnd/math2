## Example

Given: a triangle $ABC$ with $AB = AC$, and the [[midpoint|0S706JBZBG]] $M$ of $BC$.

Prove: the segment $AM$ is perpendicular to $BC$.

A student hands in this table.

| # | Statements | Reasons |
|---|---|---|
| 1 | $AB = AC$ | given |
| 2 | $BM = CM$ | definition of midpoint |
| 3 | $\angle AMB = \angle AMC$ | from the diagram |
| 4 | $\angle AMB + \angle AMC = 180^\circ$ | angles on a straight line |
| 5 | $\angle AMB = 90^\circ$ | rows 3 and 4 |
| 6 | $AM$ is perpendicular to $BC$ | definition of perpendicular lines |

Every statement in the table is true, but the table is not a [[two-column proof|~fa2bcb65]].
We check each reason.

1. Rows 1, 2, 4, 5 and 6 have reasons of the allowed kinds. They are a given fact, a definition, a postulate on straight angles, and arithmetic on earlier rows.
2. Row 3 has the reason "from the diagram". A diagram is one drawing, and it can look the same for a triangle in which the statement is false.
3. Row 3 is also the only row that needs the hypothesis $AB = AC$. The table never uses row 1, so it would "prove" the claim for every triangle.
4. The claim is false without $AB = AC$. Take $A = (1, 3)$, $B = (0, 0)$, $C = (4, 0)$, so $M = (2, 0)$. The vectors $\vec{MA} = (-1, 3)$ and $\vec{MC} = (2, 0)$ have dot product $-2 \ne 0$, so $AM$ is not perpendicular to $BC$.

The repair replaces row 3 by three rows.

| # | Statements | Reasons |
|---|---|---|
| 3a | $AM = AM$ | a segment is equal to itself |
| 3b | triangle $ABM$ is congruent to triangle $ACM$, with $A \mapsto A$, $B \mapsto C$, $M \mapsto M$ | side-side-side (1, 2, 3a) |
| 3c | $\angle AMB = \angle AMC$ | corresponding parts of congruent triangles are equal (3b) |

Now row 3c uses row 1, through the side-side-side criterion of the [[congruence criteria for triangles|5NEJPXA6N4]].
Rows 4 to 6 stay the same, and the table is a two-column proof.

## Remarks

1. The example shows the condition that a two-column proof adds to a list of true facts. Each reason must be a given fact, a definition, a postulate or a theorem.
2. A check that each hypothesis is used is a quick test of a two-column proof. A hypothesis that no row uses signals a gap, or a hypothesis that the theorem does not need.
3. In the triangle $A = (1, 3)$, $B = (0, 0)$, $C = (4, 0)$ the angle $\angle AMB$ has cosine $\frac{\vec{MA} \cdot \vec{MB}}{\lvert \vec{MA} \rvert \lvert \vec{MB} \rvert} = \frac{2}{\sqrt{10} \cdot 2} = \frac{1}{\sqrt{10}}$. So $\angle AMB$ is about $71.6^\circ$, and $\angle AMC$ is about $108.4^\circ$.
4. A diagram is still useful in a proof. It suggests which facts to prove and which triangles to compare, but each fact needs a reason that holds for every figure.

## Explanations

### L1 human

A drawing can fool the eye.
Two angles can look equal in a picture and differ by a few degrees.
In this example the student wrote "from the diagram" as the reason why two angles are equal.
The table never used the fact that two sides of the triangle are equal.
So the same table would work for any triangle, and for some triangles the claim is false.
The repair uses congruent triangles to give a real reason.

### L2 human

We check the claim and the repair on the isosceles triangle $A = (0, 4)$, $B = (-3, 0)$, $C = (3, 0)$.

1. The midpoint of $BC$ is $M = (0, 0)$.
2. Row 3b: $AB = 5$, $AC = 5$, $BM = 3$, $CM = 3$, and $AM = 4$. So the triangles $ABM$ and $ACM$ have the same three sides.
3. Row 3c: both angles at $M$ are angles between the vector $(0, 4)$ and a horizontal vector, so both are $90^\circ$.
4. Row 6: $AM$ is the line $x = 0$, and $BC$ is the line $y = 0$, so they are perpendicular.

The typical use of this check is to read each reason of a table.
For each reason, ask whether it would hold for every figure that meets the "Given" line.
A trap is to accept a reason because the statement in its row is true.
A true statement with a false or missing reason is still a gap in the proof.
