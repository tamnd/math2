## Statement

Let $V$ be a finite-dimensional real vector space with $V \ne 0$, and let $T \colon V \to V$ be a linear map.

1. $T$ has an [[invariant subspace|0ACX5QT8TE]] $U$ with $\dim U = 1$ or $\dim U = 2$.
2. If $\dim V$ is odd, then $T$ has a real [[eigenvalue|0BQAA2BK3Q]], so $T$ has an invariant subspace of dimension $1$.

The same holds for every real $n \times n$ matrix with $n \ge 1$, acting on $\R^n$.

## Remarks

This theorem is the real replacement for the [[existence of an eigenvalue over an algebraically closed field|08CJB2NQ92]].
The proof is in [[the proof by factoring a real polynomial|~78849fe0]].

### Why each hypothesis is needed

- Dimension $2$ can be necessary. The [[rotation of the plane by an angle that is not a multiple of pi|~805e3c17]] has no real eigenvalue, so its only invariant subspaces are $0$ and $\R^2$.
- Part 2 needs odd dimension. The rotation by $90$ degrees on $\R^2$ has no real eigenvalue, and the block diagonal sum of two such rotations on $\R^4$ has none either.
- $V$ must be finite-dimensional. The right shift on real sequences has no eigenvalue, and the [[shift operators|~56ecd655]] show other failures.

### Consequences

- Every real square matrix is orthogonally similar to a block upper triangular matrix with diagonal blocks of size $1$ or $2$. This is the real Schur form.
- Every real $3 \times 3$ matrix has a real eigenvector. So every rotation of $\R^3$ fixes an axis.

### Converse

The converse fails: an invariant subspace of dimension $2$ need not contain an eigenvector.
For the rotation of $\R^2$ by $90$ degrees, $\R^2$ itself is invariant of dimension $2$, but there is no real eigenvector.

### Generalizations

Over a real closed field the same statement holds with the same proof.
Over a general field $F$, the proof gives an invariant subspace of dimension at most $d$, where $d$ is the largest degree of an irreducible factor of a polynomial that kills a vector.

## History

The determinant-free form of this result is from the book "Linear Algebra Done Right" by Axler.
The odd-dimension case is a classical consequence of the intermediate value theorem.

## Explanations

### L1 human

A real matrix need not have a real eigenvector.
But it always has a line or a plane that it maps into itself.
On that plane, the matrix acts like a rotation combined with a stretch.

### L2 human

We find an invariant plane for $A = \begin{pmatrix} 0 & 0 & -1 \\ 1 & 0 & 0 \\ 0 & 1 & 0 \end{pmatrix}$ on $\R^3$.

1. $A e_1 = e_2$, $A e_2 = e_3$, and $A e_3 = -e_1$. So $A^3 e_1 = -e_1$, and $p(x) = x^3 + 1$ kills $e_1$.
2. In $\R[x]$, $x^3 + 1 = (x + 1)(x^2 - x + 1)$, and $x^2 - x + 1$ has discriminant $-3 < 0$.
3. The vector $w = (A + I)e_1 = e_1 + e_2$ satisfies $(A^2 - A + I)w = (A^3 + I)e_1 = 0$.
4. So $U = \operatorname{span}\{w, Aw\}$ is invariant, with $w = (1, 1, 0)^{\mathsf{T}}$ and $Aw = (0, 1, 1)^{\mathsf{T}}$.
5. Check: $A(Aw) = (-1, 0, 1)^{\mathsf{T}} = Aw - w$, which is in $U$.
6. The dimension is odd, so there is also a real eigenvalue: $v = (1, -1, 1)^{\mathsf{T}}$ gives $Av = (-1, 1, -1)^{\mathsf{T}} = -v$.

The typical use is to start an induction for real matrices, where an eigenvector need not exist.
A trap: the invariant plane is not unique, and it does not come from one eigenvector.

### L3 human

The theorem says that a nonzero finite-dimensional $\R[x]$-module has a simple submodule.
A simple $\R[x]$-module is $\R[x]/(q)$ with $q$ irreducible, so its dimension is $\deg q \in \{1, 2\}$.
