## Example

Let $\sigma$ be the [[signature|WDVVEYD6AT]] of [[ordered fields|0P3VCBDEE2]] with one more unary function symbol $f$:
$$\sigma = \set{+, \cdot, -, 0, 1, <, f},$$
with arities $2, 2, 1, 0, 0, 2, 1$, where $<$ is the only relation symbol.
We write $u - w$ for the term $u + (-w)$.
Let $\mathrm{Cont}(a)$ be the formula
$$\forall \varepsilon \, \big(0 < \varepsilon \to \exists \delta \, (0 < \delta \land \forall x \, ((-\delta < x - a \land x - a < \delta) \to (-\varepsilon < f(x) - f(a) \land f(x) - f(a) < \varepsilon)))\big).$$
We check that $\mathrm{Cont}(a)$ is a first-order formula and that it expresses continuity at $a$.

1. The letters $\varepsilon$, $\delta$, $x$ and $a$ are variables. Each one stands for an element of the domain, that is, a real number.
2. The expressions $x - a$, $f(x) - f(a)$, $-\delta$ and $-\varepsilon$ are [[terms|6D3WA7N2W4]]: they are built from variables with the function symbols $+$, $-$ and $f$, each with the right number of arguments.
3. Each expression $u < w$ with terms $u$ and $w$ is an atomic formula, because $<$ is a binary relation symbol.
4. The connectives $\land$ and $\to$ and the quantifiers $\forall \varepsilon$, $\exists \delta$ and $\forall x$ then build a [[formula|HYJ10AF6RT]].
5. Each quantifier binds a variable for one element, so the formula is first-order.
6. The variables $\varepsilon$, $\delta$ and $x$ are bound, and $a$ is free. So $\mathrm{Cont}(a)$ is a property of the element $a$.
7. The absolute value is not a symbol of $\sigma$. The formula replaces $|x - a| < \delta$ by the equivalent pair $-\delta < x - a$ and $x - a < \delta$.
8. Let $g \colon \mathbb{R} \to \mathbb{R}$ be a function, and interpret $f$ as $g$ in the ordered field $\mathbb{R}$. By the clauses of satisfaction, $\mathrm{Cont}(a)$ holds for the real number $a$ exactly when for each $\varepsilon > 0$ there is a $\delta > 0$ with $|g(x) - g(a)| < \varepsilon$ whenever $|x - a| < \delta$. This is the definition of continuity of $g$ at $a$.

So "the function $f$ is continuous" is the first-order sentence $\forall a \, \mathrm{Cont}(a)$.

## Remarks

Uniform continuity comes from a change in the order of the quantifiers.
Move $\forall a$ inside, after $\exists \delta$: $\forall \varepsilon \, (0 < \varepsilon \to \exists \delta \, (0 < \delta \land \forall a \, \forall x \, (\dots)))$.
Then one $\delta$ must work for all $a$, which is the definition of uniform continuity.
The same formula makes sense in every ordered field with a unary function, for example in $\mathbb{Q}$.
In $\mathbb{Q}$ the function $g(x) = 1$ for $x^2 > 2$ and $g(x) = 0$ for $x^2 < 2$ satisfies $\forall a \, \mathrm{Cont}(a)$, because no rational number has square $2$.
So the first-order sentence keeps its meaning, but the intermediate value theorem fails in $\mathbb{Q}$.
The intermediate value theorem needs the completeness of $\mathbb{R}$, and completeness is [[not a first-order property|~4ea127ad]].

## Explanations

### L1 human

A function is continuous at a point when small changes of the input give small changes of the output.
The precise version says: for each allowed error $\varepsilon$ there is a tolerance $\delta$.
All the words "for each" and "there is" here talk about numbers.
So the definition can be written with variables for numbers, the symbols $+$, $-$ and $<$, and a symbol $f$ for the function.
For example, for $g(x) = 2x$ and the error $\varepsilon = 0.1$, the tolerance $\delta = 0.05$ works at every point.

### L2 human

We check $\mathrm{Cont}(a)$ for $g(x) = 2x$ at every $a$.

1. Let $\varepsilon > 0$ be given. We must find $\delta > 0$.
2. Take $\delta = \varepsilon / 2$. Then $0 < \delta$.
3. Let $x$ satisfy $-\delta < x - a < \delta$.
4. Then $g(x) - g(a) = 2(x - a)$, so $-2\delta < g(x) - g(a) < 2\delta$.
5. Since $2\delta = \varepsilon$, we get $-\varepsilon < g(x) - g(a) < \varepsilon$.

The typical use of the first-order form is to negate it mechanically: $g$ is discontinuous at $a$ when $\exists \varepsilon \, (0 < \varepsilon \land \forall \delta \, (0 < \delta \to \exists x \, (\dots \land \neg \dots)))$.
A trap: "$|x - a| < \delta$" cannot be written with $\lvert \cdot \rvert$ unless the signature has a symbol for it, so the formula uses two inequalities.
