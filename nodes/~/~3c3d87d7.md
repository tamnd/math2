## Example

Let $\mathcal{N} = (\N, +, \cdot, 0, 1, <)$ be the standard model of the [[natural numbers|0MWKJ44V5A]], and let $\mathcal{U}$ be a nonprincipal ultrafilter on $\N$.
Let ${}^*\mathcal{N} = \mathcal{N}^{\N} / \mathcal{U}$ be the [[ultrapower|~93a646cd]], with diagonal embedding $d$.
We check that ${}^*\mathcal{N}$ is a model of [[true arithmetic|DX0KPMH4QZ]] with an element above every $d(n)$.

1. By the theorem that the [[diagonal embedding is elementary|~50eaa729]], ${}^*\mathcal{N} \equiv \mathcal{N}$. So ${}^*\mathcal{N}$ satisfies every sentence true in $\N$, in particular the axioms of [[Peano arithmetic|0QFT7Z76N5]].
2. Let $\omega = [\mathrm{id}]$, the class of $i \mapsto i$.
3. For $n \in \N$, $\set{i : i > n}$ is cofinite. A nonprincipal ultrafilter contains every cofinite set, so $\omega > d(n)$ by the definition of $<$ in the ultrapower.
4. So $\omega$ is not of the form $d(n)$, and ${}^*\mathcal{N}$ is a nonstandard model.

## Remarks

The example builds a nonstandard model of arithmetic concretely, without the compactness theorem.
The nonstandard elements include $\omega$, $\omega + 1$, $2\omega$, $\omega^2$ and $[i \mapsto 2^i]$, and also $\omega - 1 = [i \mapsto \max(i - 1, 0)]$.
So the nonstandard part has no least element, and ${}^*\mathcal{N}$ is not well ordered, although $\N$ is; well-ordering is a second-order property.
Whether $\omega$ is even depends on $\mathcal{U}$: it is even exactly when the set of even numbers lies in $\mathcal{U}$.
By the [[non-example of countable models|~79bdadc7]], ${}^*\mathcal{N}$ has $2^{\aleph_0}$ elements; countable nonstandard models need another construction, such as compactness with the downward Löwenheim-Skolem theorem.
If $\mathcal{U}$ is principal, ${}^*\mathcal{N} \cong \mathcal{N}$.

## Explanations

### L1 human

We build new "natural numbers" as infinite lists of ordinary natural numbers.
The list $0, 1, 2, 3, \dots$ is larger than $5$, because it is larger than $5$ at all but six positions.
In the same way it is larger than every ordinary number.
Still, every rule of arithmetic, such as $x + y = y + x$, holds for the new numbers.

### L2 human

We check that $\omega = [\mathrm{id}]$ is either even or odd, but not both, in ${}^*\mathcal{N}$.

1. The sentence $\forall x \, \exists y \, (x = y + y \lor x = y + y + 1)$ holds in $\N$, so it holds in ${}^*\mathcal{N}$ by step 1.
2. Let $E$ be the set of even numbers. If $E \in \mathcal{U}$, put $h(i) = \lfloor i / 2 \rfloor$. Then $\mathrm{id} = h + h$ on $E$, so $\omega = [h] + [h]$.
3. If $E \notin \mathcal{U}$, then the odd numbers lie in $\mathcal{U}$, and $\omega = [h] + [h] + 1$ in the same way.
4. "No $x$ is both of the form $y + y$ and of the form $y + y + 1$" holds in $\N$, so it holds in ${}^*\mathcal{N}$.

The typical use is to compute in ${}^*\mathcal{N}$ by computing coordinatewise on a set in $\mathcal{U}$.
The trap is to think that the parity of $\omega$ is determined by the construction alone; it depends on the choice of $\mathcal{U}$.
