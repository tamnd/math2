## Statement

Take a [[system of linear equations|0GT4WWGWH2]] and its [[coefficient matrix|0HQFZAP3ND]].

Suppose that each row of the coefficient matrix contains a [[pivot|0J0BBCMJ5W]] position.

Then the system is [[consistent|04JAAVHDDM]], so it has at least one solution.

## Remarks

The condition concerns only the coefficient matrix, not the augmented matrix.

The converse fails: a consistent system can have a row of the coefficient matrix with no pivot.
