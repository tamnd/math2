## Example

The signature has one binary relation symbol $<$.
Let $\mathcal{K}$ be the class of finite [[linear orders|0FRXBVVR03]], including the empty order.
We show that the [[age|~41dc9926]] of $(\Q, <)$ is $\mathcal{K}$, and that the age of $(\Z, <)$ is also $\mathcal{K}$.

1. The signature has no function or constant symbols, so a finitely generated substructure is a finite subset with the induced order.
2. A finite subset of $\Q$ with the induced order is a linear order, so every member of $\operatorname{Age}(\Q, <)$ is in $\mathcal{K}$.
3. Conversely, let $A = \set{a_1 < a_2 < \dots < a_n}$ be in $\mathcal{K}$. The map $a_i \mapsto i$ is injective and order-preserving, and it reflects the order.
4. So $a_i \mapsto i$ is an [[embedding|SCRB74SWQN]] of $A$ into $(\Q, <)$, and $A \in \operatorname{Age}(\Q, <)$.
5. The same map lands in $\Z$, and step 2 works for $\Z$ in the same way, so $\operatorname{Age}(\Z, <) = \mathcal{K}$ too.

## Remarks

The two orders have the same age, but they are not isomorphic: $\Q$ is [[dense|K4D3S1MBZH]] and $\Z$ is not.
So the age alone does not determine a countable structure.
Among countable structures with age $\mathcal{K}$, only $(\Q, <)$ is ultrahomogeneous, and it is the Fraïssé limit of $\mathcal{K}$.
If we add a constant symbol for $0$, the age of $(\Q, <, 0)$ becomes the class of finite linear orders with a marked element.

## Explanations

### L1 human

Take any finite set of rational numbers, such as $\frac12, 3, -1$.
Put in increasing order, they form a chain $-1 < \frac12 < 3$ with three elements.
Every finite chain arises in this way, and nothing else does.
The integers give exactly the same chains, so the integers and the rationals have the same age.

### L2 human

We embed the order $A = \set{p < q < r < s}$ into $\Q$ above a given rational $x$.

1. Put $p \mapsto x + 1$, $q \mapsto x + 2$, $r \mapsto x + 3$, $s \mapsto x + 4$.
2. The map is injective, and $p < q$ in $A$ if and only if $x + 1 < x + 2$, and so on for each pair.
3. So the map is an embedding, and its image lies above $x$.

The typical use is to check the first hypothesis of Fraïssé's theorem: the class is the age of something.
A trap is to forget the empty order when the signature has no constants; it belongs to the age as the substructure generated by the empty set.
