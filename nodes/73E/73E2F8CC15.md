## Proof

**Part 1.**

1. For $Q \in O(n)$, $\det Q \in \set{1, -1}$, by [[the determinant theorem|QDZJMFATRW]]. So the map $\det \colon O(n) \to \set{1, -1}$ is defined.
2. For $P, Q \in O(n)$, $\det(PQ) = \det P \det Q$, by [[multiplicativity of the determinant|04CPJ6AF00]]. So $\det$ is a group homomorphism.
3. The matrix $D = \operatorname{diag}(-1, 1, \dots, 1)$ has orthonormal columns $-e_1, e_2, \dots, e_n$. So $D \in O(n)$, and $\det D = -1$.
4. Also $\det I_n = 1$. So $\det$ takes both values, and it is surjective.
5. The [[kernel|0Z424HK8CQ]] is $\set{Q \in O(n) : \det Q = 1}$, which is $SO(n)$ by definition.

**Part 2.**

6. A kernel of a homomorphism is a normal subgroup. So $SO(n)$ is normal in $O(n)$.
7. By the [[first isomorphism theorem|0CXXJNG5B6]] and step 4, $O(n)/SO(n) \cong \set{1, -1}$, a group of order $2$. So the index of $SO(n)$ is $2$.
8. Let $Q \in O(n)$ with $\det Q = -1$. Then $\det(DQ) = (-1)(-1) = 1$, so $DQ \in SO(n)$.
9. $D^2 = I_n$, so $Q = D(DQ) \in D \cdot SO(n)$.
10. Conversely, each element $DP$ with $P \in SO(n)$ has $\det(DP) = -1$, by step 2. So $D \cdot SO(n)$ is exactly the set of elements with determinant $-1$.

**Part 3.**

11. Let $z = a + ic$ with $a^2 + c^2 = 1$. The columns $(a, c)$ and $(-c, a)$ of $\phi(z)$ have length $1$, and their dot product is $-ac + ca = 0$. So $\phi(z)$ is orthogonal, by [[the equivalent conditions|F7M8ZXB4P7]].
12. $\det \phi(z) = a^2 + c^2 = 1$. So $\phi(z) \in SO(2)$.
13. Let $w = b + id$. Then $zw = (ab - cd) + i(ad + bc)$.
14. Direct multiplication gives $\phi(z)\phi(w) = \begin{pmatrix} ab - cd & -(ad + bc) \\ ad + bc & ab - cd \end{pmatrix} = \phi(zw)$. So $\phi$ is a homomorphism.
15. $\phi(z) = I_2$ forces $a = 1$ and $c = 0$, so $z = 1$. So $\phi$ is injective.
16. For surjectivity, let $Q = \begin{pmatrix} a & b \\ c & d \end{pmatrix} \in SO(2)$. Its first column $(a, c)$ has length $1$.
17. The second column is a unit vector orthogonal to $(a, c)$. In $\R^2$, the only such vectors are $(-c, a)$ and $(c, -a)$.
18. For $(b, d) = (c, -a)$, $\det Q = -a^2 - c^2 = -1$, which is false. So $(b, d) = (-c, a)$.
19. So $Q = \phi(a + ic)$, and $\abs{a + ic} = 1$. Hence $\phi$ is an isomorphism onto $SO(2)$.
20. Each $z$ in the circle group is $e^{i\theta} = \cos\theta + i\sin\theta$ for some $\theta \in \R$. So $SO(2) = \set{R(\theta) : \theta \in \R}$. $\blacksquare$

## Idea

The determinant is a homomorphism onto a group of order $2$, and its kernel is $SO(n)$.
In dimension $2$, the first column of a rotation fixes the second column up to a sign, and the determinant fixes the sign.

## Variants

- Instead of the first isomorphism theorem, count cosets directly: steps 8 to 10 show that the cosets are $SO(n)$ and $D \cdot SO(n)$.
- Part 3 also follows from [[the classification of O(2)|C97Z06HHB2]], which lists all of $O(2)$ at once.
