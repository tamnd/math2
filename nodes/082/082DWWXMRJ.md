## Summary

A [[group|G5S1M9]] $G$ is finitely generated when it has a finite [[generating set|0MBV2VHMXA]].
That is, there are elements $g_1, \ldots, g_n \in G$ with $G = \langle g_1, \ldots, g_n \rangle$.
Then each element of $G$ is a finite product of the elements $g_i$ and their inverses.
Finitely generated groups include all finite groups and the integers, and the condition lets us study an infinite group through a finite list of its elements.

## Motivation

A finite group has a finite generating set: the set of all its elements.
For an infinite group, we cannot list the elements, so we look for a finite list of generators.
The integers under addition need only the generator $1$.
The plane lattice $\mathbb{Z} \times \mathbb{Z}$ needs two generators.
The rational numbers under addition need infinitely many, because no finite set of fractions produces all fractions.
The condition "finitely generated" separates these cases.
It plays the part for groups that a finite spanning set plays for vector spaces.
It is the starting hypothesis of the [[structure theorem for finitely generated abelian groups|0RY0B72XAS]] and of geometric group theory.

## Notation

There is no special symbol.
Some books write "f.g. group" for "finitely generated group".
The least size of a generating set is $d(G)$, so $G$ is finitely generated exactly when $d(G)$ is finite.

## Remarks

### Examples

1. Each finite group is finitely generated: the set $G$ itself is a finite generating set.
2. The [[additive group of integers|0BSCJA5G53]] is generated by $1$. More generally, the group $\mathbb{Z}^n$ is generated by the $n$ standard basis vectors. The case $n = 2$ is [[the group $\mathbb{Z} \times \mathbb{Z}$|~fac25186]], which is finitely generated but not cyclic.
3. The [[free group|0KTW26C80J]] $F_2$ on two letters $a$ and $b$ is generated by $\{a, b\}$.
4. The maps $x \mapsto 2x$ and $x \mapsto x + 1$ of the real line generate [[an infinite group of affine maps|~343e55ba]]. This group is finitely generated, but it has a subgroup that is not.
5. Each [[cyclic group|0KVGH0J5B3]] is finitely generated, with one generator. A [[direct product|00HF4RJ5QN]] of two finitely generated groups is finitely generated: the pairs $(g_i, e)$ and $(e, h_j)$ generate it.

### Non-examples

1. The group $(\mathbb{Q}, +)$ is not finitely generated: a finite set of fractions has a common denominator $b$, and it generates only fractions with denominator $b$ (see [[the additive group of rational numbers|~b8d64d52]]).
2. The [[Prüfer group|F0XAMM2PPS]] $\mathbb{Z}(p^\infty)$ is not finitely generated. A finite set of its elements lies in the finite subgroup $\{m/p^k + \mathbb{Z} : m \in \mathbb{Z}\}$ for a large $k$, and this subgroup is proper.
3. The direct sum $\bigoplus_{n \geq 1} \mathbb{Z}$ of countably many copies of $\mathbb{Z}$ is not finitely generated. A finite set uses only finitely many coordinates, and the generated subgroup has $0$ in all other coordinates.
4. The group $(\mathbb{R}, +)$ is not finitely generated, because it is uncountable (basic property 1).

### Basic properties

1. A finitely generated group is [[countable|01TQB88H4C]]. For each $k$, there are finitely many products of length $k$ in the generators and their inverses, and each element is such a product.
2. A [[quotient group|0KYX2N69J0]] of a finitely generated group is finitely generated. If $g_1, \ldots, g_n$ generate $G$, then the cosets $g_1 N, \ldots, g_n N$ generate $G/N$.
3. Let $N$ be a [[normal subgroup|0CB0DX5BVV]] of $G$ with $N = \langle T \rangle$ and $G/N = \langle g_1 N, \ldots, g_m N \rangle$, where $T$ is finite. Then $T \cup \{g_1, \ldots, g_m\}$ generates $G$. Each $g \in G$ has $gN = wN$ for a product $w$ of the $g_i^{\pm 1}$, so $g = wn$ with $n \in N$.
4. A subgroup of a finitely generated group need not be finitely generated. The proof for $F_2$ is below.
5. A subgroup of finite [[index|0DTXBQPA2S]] in a finitely generated group is finitely generated. The proof is below.
6. Each subgroup of a [[finitely generated abelian group|RQNAAJF6XY]] is finitely generated. So an example for property 4 must be a non-abelian group.
7. A finitely generated group that is [[locally cyclic|RXWA8TF2RM]] is cyclic, because it is one of its own finitely generated subgroups.

### Subgroups of finitely generated groups

We show that the [[free group|0KTW26C80J]] $F_2 = \langle a, b \rangle$ has a subgroup that is not finitely generated.
The elements of $F_2$ are the [[reduced words|0KBTP8Q2FS]] in $a, a^{-1}, b, b^{-1}$, and two reduced words are equal only when they are the same string.
For $n \in \mathbb{Z}$, let $x_n = a^n b a^{-n}$, and let $H = \langle x_n : n \in \mathbb{Z} \rangle$.

1. Let $T$ be a finite subset of $H$. Each element of $T$ is a product of finitely many elements $x_n^{\pm 1}$. So there is an integer $N \geq 0$ with $T \subseteq H_N = \langle x_n : \abs{n} \leq N \rangle$.
2. Each element of $H_N$ other than $e$ is a product $x_{n_1}^{c_1} x_{n_2}^{c_2} \cdots x_{n_k}^{c_k}$ with $k \geq 1$, $\abs{n_i} \leq N$, $c_i \neq 0$ and $n_i \neq n_{i+1}$. We get this form when we combine equal neighbors, because $x_n^c x_n^{c'} = x_n^{c + c'}$, and we drop the factors with exponent $0$.
3. We have $x_n^c = a^n b^c a^{-n}$. So the product in step 2 is the word $a^{n_1} b^{c_1} a^{n_2 - n_1} b^{c_2} \cdots a^{n_k - n_{k-1}} b^{c_k} a^{-n_k}$.
4. This word is reduced: the exponents $c_i$ and $n_{i+1} - n_i$ are not $0$, so no letter stands next to its inverse.
5. The reduced word of $x_{N+1}$ is $a^{N+1} b a^{-(N+1)}$. It has one block of $b$ letters, so a word as in step 3 can equal it only when $k = 1$.
6. For $k = 1$, the word $a^{n_1} b^{c_1} a^{-n_1}$ equals $a^{N+1} b a^{-(N+1)}$ only when $n_1 = N + 1$. This contradicts $\abs{n_1} \leq N$.
7. So $x_{N+1} \notin H_N$, and $T$ does not generate $H$. Since $T$ was an arbitrary finite subset, $H$ is not finitely generated.

Next we show that a subgroup $H$ of finite index in a finitely generated group $G$ is finitely generated.
This is Schreier's lemma.
We use the [[right cosets|0NE1DK7H4T]] $Hg$ of $H$.

1. Let $G = \langle S \rangle$ with $S$ finite. Add the inverses of the elements of $S$ to $S$. Then each $g \in G$ is a product $s_1 s_2 \cdots s_k$ with $s_i \in S$.
2. The index of $H$ is finite, so there are finitely many right cosets. Choose one element from each coset, and choose $e$ from the coset $H$. Let $R$ be the finite set of the chosen elements.
3. For $g \in G$, write $\bar g$ for the element of $R$ in the coset $Hg$. Then $g \bar g^{-1} \in H$.
4. For $t \in R$ and $s \in S$, put $h_{t, s} = ts \, (\overline{ts})^{-1}$. By step 3, $h_{t, s} \in H$. There are at most $\abs{R} \cdot \abs{S}$ such elements.
5. Let $h \in H$, and write $h = s_1 \cdots s_k$ as in step 1. Put $t_0 = e$ and $t_i = \overline{t_{i-1} s_i}$ for $i = 1, \ldots, k$.
6. By the definition in step 4, $t_{i-1} s_i = h_{t_{i-1}, s_i} \, t_i$ for each $i$.
7. We use step 6 $k$ times, from the left: $h = t_0 s_1 s_2 \cdots s_k = h_{t_0, s_1} t_1 s_2 \cdots s_k = \cdots = h_{t_0, s_1} h_{t_1, s_2} \cdots h_{t_{k-1}, s_k} \, t_k$.
8. By step 3, $Ht_i = Ht_{i-1}s_i$ for each $i$. By induction on $i$, $Ht_i = Hs_1 \cdots s_i$. For $i = k$ we get $Ht_k = Hh = H$, because $h \in H$.
9. The only element of $R$ in the coset $H$ is $e$. So $t_k = e$, and $h$ is a product of elements $h_{t, s}$.
10. So the finite set $\{h_{t, s} : t \in R, \ s \in S\}$ generates $H$.

The two results fit together.
The subgroup $H$ of $F_2$ in the first proof has infinite index in $F_2$.

### History

William Burnside asked in 1902 whether a finitely generated group in which each element has finite order must be finite.
This is the [[Burnside problem|XWEMJ7T2XV]].
Evgeny Golod gave a negative answer in 1964.
Max Dehn posed the [[word problem|PBGTTAVMMT]] for finitely presented groups in 1911.

### Common errors

1. A student thinks that "finitely generated" means "finite". The group $\mathbb{Z}$ is infinite, but $1$ generates it.
2. A student thinks that subgroups of finitely generated groups are finitely generated. This is true for abelian groups and for finite index, but false in $F_2$.
3. A student shows that $\mathbb{Q}$ is not finitely generated by saying that $\mathbb{Q}$ is infinite. This reason is wrong, because $\mathbb{Z}$ is also infinite. The correct reason is the common denominator.

## Explanations

### L1 human

The integers under addition come from one number: we add $1$ again and again, or take it away.
So one building block is enough for an infinite group.
A group is finitely generated when a finite list of building blocks is enough.
Fractions under addition are different.
Any finite list of fractions has a common denominator, for example $6$ for $\tfrac{1}{2}$ and $\tfrac{2}{3}$.
Sums and differences of these fractions also have denominator $6$, so we never reach $\tfrac{1}{12}$.
So no finite list of fractions is enough.

### L2 human

We show that the group $(\mathbb{Z}[\tfrac{1}{2}], +)$ of fractions $m / 2^j$, with $m \in \mathbb{Z}$ and $j \geq 0$, is not finitely generated.

1. Let $q_1, \ldots, q_n$ be finitely many elements. Write $q_i = m_i / 2^{j_i}$, and let $J$ be the largest $j_i$.
2. Then $q_i = (m_i 2^{J - j_i}) / 2^J$, so each $q_i$ lies in the set $\tfrac{1}{2^J}\mathbb{Z}$ of integer multiples of $1/2^J$.
3. The set $\tfrac{1}{2^J}\mathbb{Z}$ is a subgroup, because the difference of two multiples of $1/2^J$ is a multiple of $1/2^J$. So $\langle q_1, \ldots, q_n \rangle \subseteq \tfrac{1}{2^J}\mathbb{Z}$.
4. If $1/2^{J+1} = c/2^J$ with $c \in \mathbb{Z}$, then $1 = 2c$, which is impossible. So $1/2^{J+1} \notin \langle q_1, \ldots, q_n \rangle$.
5. So no finite set generates $\mathbb{Z}[\tfrac{1}{2}]$.

The typical use of this argument is a proof that a group is not finitely generated.
We find an increasing chain of proper subgroups whose union is the whole group.
A finite set lies in one subgroup of the chain, so it cannot generate the group.

A trap: the property does not pass to subgroups.
The group $\mathbb{Z}[\tfrac{1}{2}]$ above is isomorphic to a subgroup of [[the group generated by $x \mapsto 2x$ and $x \mapsto x + 1$|~343e55ba]], which is finitely generated.

### L3 human

Finitely generated groups are the objects of geometric group theory.
A finite generating set $S$ gives the word length $\abs{g}_S$, the length of a shortest product of elements of $S^{\pm 1}$ that equals $g$.
The [[Cayley graph|0GYQK9NDJF]] of $(G, S)$ is a metric space, and a change of the finite set $S$ changes the metric only up to quasi-isometry.
A [[finitely presented group|TJKANTKASZ]] has finitely many generators and finitely many relations, and this is the setting of Dehn's word problem.

The failure of property 4 means that the subgroups of a finitely generated group need not satisfy the ascending chain condition.
The groups in which every subgroup is finitely generated are exactly the groups with the ascending chain condition on subgroups.
They are the analogue of [[Noetherian modules|AK1ZRCXR32]], and the [[polycyclic groups|9RBA56NXX3]] are examples.
For free groups, the [[Nielsen-Schreier theorem|W97X7WX5G8]] says that each subgroup is free, and a subgroup of index $k$ in a free group of rank $n$ is free of rank $k(n - 1) + 1$.
A finitely generated group has only finitely many subgroups of each finite index $k$, because such a subgroup comes from an action on $k$ cosets, and the action is determined by the images of the generators in $S_k$.
