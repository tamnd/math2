## Summary

In mathematics, especially in order theory, a **maximal element** of a [[subset|0BJR9QR08E]] $S$ of some preordered set is an element of $S$ that is not smaller than any other element in $S$. A **minimal element** of a subset $S$ of some preordered set is defined dually as an element of $S$ that is not greater than any other element in $S$.
