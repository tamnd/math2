## Summary

A related notation for crystal structures given a letter and index: - ! Symbol ! Meaning

Some structure designation share the same space groups. For example, space group 225 is A${}_{1}$, B${}_{1}$, and C${}_{1}$. Space group 221 is A${}_{h}$, and B${}_{2}$. However, crystallographers would not use Strukturbericht notation to describe the space group, rather it would be used to describe a specific crystal structure (e.g. space group + atomic arrangement (motif)).
