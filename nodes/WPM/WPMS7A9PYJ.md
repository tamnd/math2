## Definition

Let $q$ be a prime power and let $L \ge 1$.
Let $(s_j)_{j \ge 0}$ be a sequence over $\F_q$ generated by a [[linear-feedback shift register|WHX90SGEJ5]] of length $L$ over $\F_q$.
The sequence is a *maximum length sequence* (or *m-sequence*) if it is [[periodic|Q3B6K9HYRG]] with least period $q^L - 1$.

## Remarks

A nonzero sequence from a register of length $L$ has period at most $q^L - 1$, since the register runs through nonzero states only.
So an m-sequence visits every nonzero state exactly once per period.
Let a register have connection polynomial $C(x)$ of degree $L$ and a nonzero initial state.
Its output is an m-sequence if and only if $C(x)$ is a [[primitive polynomial|HQ7KMZYPSQ]] over $\F_q$.
In one period of a binary m-sequence there are $2^{L-1}$ ones and $2^{L-1} - 1$ zeros.
Its $\pm 1$ form $a_j = (-1)^{s_j}$ has periodic autocorrelation $\sum_{j=0}^{N-1} a_j a_{j+\tau} = -1$ for every shift $\tau \not\equiv 0 \pmod N$, where $N = 2^L - 1$.

Example: over $\F_2$ take $L = 3$ and $C(x) = 1 + x^2 + x^3$, that is, $s_j = s_{j-2} + s_{j-3}$, with initial state $(1, 0, 0)$.
The output is $1, 0, 0, 1, 0, 1, 1$ followed by $1, 0, 0, \dots$, so the least period is $7 = 2^3 - 1$, and the sequence is an m-sequence.
The polynomial $1 + x^2 + x^3$ is indeed primitive: its roots in $\F_8$ have multiplicative order $7$.

Non-example: with $L = 3$ and $C(x) = 1 + x^3$, that is, $s_j = s_{j-3}$, every sequence has period dividing $3$, which is less than $7$.
The polynomial $1 + x^3 = (1 + x)(1 + x + x^2)$ is not primitive.
