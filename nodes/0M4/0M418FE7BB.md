## Summary

Let $S$ be a [[set|0BSJ7RQ9BW]].
A binary operation on $S$ is a [[function|0EPAT51DXQ]] $\ast \colon S \times S \to S$ from the [[Cartesian product|09CEDJYBKP]] $S \times S$ to $S$.
Thus the operation assigns to each [[ordered pair|0WFCNG0MZC]] $(a, b)$ of elements of $S$ exactly one element $a \ast b$ of $S$.
The requirement that $a \ast b$ is an element of $S$ for all $a, b \in S$ is called closure: the set $S$ is closed under $\ast$.
Binary operations are the starting point of algebra, because a group, a ring and a vector space are each a set with binary operations that obey some laws.

## Motivation

Addition of numbers takes two numbers and gives one number.
Multiplication of numbers, composition of functions and multiplication of square matrices have the same form.
In each case, two inputs from a set give one output in the same set.
We give this common form a name, so that we can study the laws that such operations obey without a reference to one particular operation.
The [[associativity|0K8F7PVDMX]], [[commutativity|099E72KTF8]], [[identity element|07WYQPB8E3]] and [[inverse element|0ZNZH0EXFX]] are such laws, and a [[group|G5S1M9]] is a set with a binary operation that obeys three of them.

## Notation

Most books write the operation between its two inputs: $a \ast b$, $a \cdot b$, $a \circ b$ or $ab$.
This is infix notation, and it means the same as the function notation $\ast(a, b)$.
The symbol $+$ is used by convention only for operations that are [[commutative|099E72KTF8]].
When the operation is understood, many books write $ab$ for $a \ast b$.
A set with one binary operation is called a [[magma|9689SFPVE9]].
Some older books call it a groupoid, but today the word [[groupoid|FH3C0T643F]] usually means a different structure.

## Remarks

### Examples

1. Addition on the [[natural numbers|0MWKJ44V5A]] $\mathbb{N} = \{0, 1, 2, \ldots\}$ is a binary operation, because the sum of two natural numbers is a natural number.
2. Subtraction on the [[integers|0C4JS9RF5M]] $\mathbb{Z}$ is a binary operation, because the difference of two integers is an integer.
3. Multiplication on the [[rational numbers|0NCJ5WXN6Z]] $\mathbb{Q}$ is a binary operation, because the product of two fractions is a fraction.
4. [[Matrix multiplication is a binary operation on the square matrices of one size|~9e5e78c9]], because the product of two $n \times n$ matrices is an $n \times n$ matrix.
5. [[Composition is a binary operation on the functions from a set to itself|~552407f5]], because $f \circ g$ is again a function from the set to itself.
6. The rule $a \ast b = \max(a, b)$ is a binary operation on the [[real numbers|08J2M1JYAG]] $\mathbb{R}$, because the larger of two real numbers is a real number.

### Non-examples

1. [[Subtraction is not a binary operation on the natural numbers|~36b81b64]]: closure fails, because $1 - 2 = -1$ is not in $\mathbb{N}$.
2. Division is not a binary operation on $\mathbb{Q}$: the quotient $a / 0$ is not defined, so the rule does not give a value for each pair. Division is a binary operation on $\mathbb{Q} \setminus \{0\}$.
3. The dot product of vectors in $\mathbb{R}^3$ is not a binary operation on $\mathbb{R}^3$: its value is a real number, not a vector of $\mathbb{R}^3$.
4. Addition on the set $\{\text{odd integers}\}$ is not a binary operation on that set: closure fails, because $1 + 1 = 2$ is even.

### Basic properties

1. A binary operation on a finite set $S = \{s_1, \ldots, s_n\}$ is completely given by an $n \times n$ table, the [[Cayley table|0YB2NRP0T5]], with the entry $s_i \ast s_j$ in row $i$ and column $j$.
2. A set with $n$ elements has exactly $n^{n^2}$ binary operations, because the set $S \times S$ has $n^2$ elements and each of them can go to any of the $n$ elements of $S$. For $n = 2$ this gives $2^4 = 16$ operations.
3. When a subset $T \subseteq S$ is closed under $\ast$, the restriction of $\ast$ to $T \times T$ is a binary operation on $T$. For example, addition on $\mathbb{Z}$ restricts to the even integers.
4. The order of the inputs matters: $a \ast b$ and $b \ast a$ can be different. For subtraction on $\mathbb{Z}$, $3 - 1 = 2$ but $1 - 3 = -2$.

### History

Addition and multiplication of numbers are much older than algebra as a subject.
In 1854 Arthur Cayley described a finite group by the table of all products of its symbols, and so he treated the operation as an abstract rule.
The present definition, as a function from $S \times S$ to $S$, uses the language of sets and functions.

### Common errors

1. Closure is not checked. Before a reader calls $\ast$ a binary operation on $S$, the reader must show that $a \ast b$ is in $S$ for all $a, b \in S$, as the odd integers show.
2. The rule is not defined for some pairs. A binary operation on $S$ must give a value for every pair, also for the pairs $(a, a)$ and for the pairs that contain $0$.
3. The order is ignored. The pair $(a, b)$ is ordered, so a binary operation need not satisfy $a \ast b = b \ast a$.

## Explanations

### L1 human

A binary operation is a rule that takes two things from a collection and gives back one thing from the same collection.
Addition of whole numbers is the best known example: from $2$ and $3$ it gives $5$.
The word "binary" means that the rule takes two inputs.
The rule must work for every choice of two inputs.
The answer must also stay in the collection.
For example, take away is not a binary operation on the numbers $0, 1, 2, \ldots$, because $1$ take away $2$ is not one of these numbers.
The order of the two inputs can matter: $5$ take away $2$ is $3$, but $2$ take away $5$ is not $3$.

### L2 human

We check that a rule is a binary operation in two steps: the rule gives a value for each pair, and the value is in the set.
Here is a worked example.
Let $S = \mathbb{Z} \setminus \{-1\}$, the integers other than $-1$, and define $a \ast b = a + b + ab$.

1. For all integers $a$ and $b$, the number $a + b + ab$ is an integer. Thus the rule gives a value for each pair.
2. We must show that $a \ast b \ne -1$ when $a \ne -1$ and $b \ne -1$. We have $a + b + ab + 1 = (a + 1)(b + 1)$.
3. Since $a \ne -1$ and $b \ne -1$, both factors $a + 1$ and $b + 1$ are nonzero integers.
4. A product of two nonzero integers is nonzero, so $(a + 1)(b + 1) \ne 0$.
5. Thus $a \ast b + 1 \ne 0$, that is, $a \ast b \ne -1$. So $a \ast b \in S$.
6. By steps 1 and 5, the rule $\ast$ is a binary operation on $S$.

The typical use comes before a test of the group axioms: a structure can only be a group when its rule is first a binary operation on the set.
The same rule $a + b + ab$ is not a binary operation on the set $\{-1, 0, 1\}$, because $1 \ast 1 = 3$.
A trap is to check closure only on a few pairs.
One pair that leaves the set is enough to show that the rule is not a binary operation, but no finite list of good pairs proves closure for an infinite set.

### L3 human

A binary operation is the case $n = 2$ of an $n$-ary operation, a function $S^n \to S$.
Universal algebra studies sets with a family of such operations, and a group is then a set with a binary operation, a unary operation $a \mapsto a^{-1}$ and a nullary operation (a constant) $e$.
Some operations of mathematics are not binary operations in this strict sense.
Scalar multiplication $K \times V \to V$ of a vector space takes inputs from two different sets, and it is called an external operation.
Composition of morphisms in a category is defined only for some pairs, so it is a partial operation.
In a category with finite products, a binary operation on an object $S$ is a morphism $S \times S \to S$, and this view leads to group objects.
Later sub-areas of group theory study only operations that satisfy the group axioms, and the area of magmas and [[quasigroups|ZJD31SPPFP]] studies the operations that satisfy fewer laws.
