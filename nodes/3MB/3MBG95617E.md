## Summary

*Minimal logic* $\mathsf{ML}$ is the propositional logic derived by the [[Hilbert system|1MGMQX43B8]] of [[intuitionistic logic|52XCYMK0WW]] without the axiom $\bot \to \varphi$, with $\neg\varphi := \varphi \to \bot$; see [[the definition|V7MTF4P01E]].
In minimal logic, $\bot$ has no special rule, so it behaves like one more propositional variable.
Minimal logic keeps all the rules for negation that come from the rules for implication, and drops the principle of [[explosion|TTKZGJEEK7]].
It is the logic of natural deduction for $\wedge$, $\vee$, $\to$ alone, and it shows which uses of negation in a proof depend on ex falso.

## Motivation

Many intuitionistic proofs with negation never use the rule "from $\bot$ infer $\varphi$".
For example, $p \to \neg\neg p$ and contraposition only use the rules for $\to$.
Johansson isolated these proofs: he kept the intuitionistic rules and dropped ex falso.
In type theory, the same restriction gives the simply typed lambda calculus with an empty type that has no eliminator.
So minimal logic is the base logic of negation as "implies a fixed absurdity", without any assumption on that absurdity.

## Notation

$\mathsf{ML}$, $\mathsf{MPC}$ and $\mathsf{J}$ are common names, and $\vdash_{\mathsf{m}}$ is derivability.
Some authors write $f$ for the constant $\bot$ of minimal logic, to stress that it is an ordinary constant.

## Remarks

### Examples

1. $\mathsf{ML} \vdash p \to \neg\neg p$ and $\mathsf{ML} \vdash \neg\neg\neg p \to \neg p$; see [[intuitionistic derivations with negation|WB61HZMN2B]].
2. $\mathsf{ML} \vdash (p \to q) \to (\neg q \to \neg p)$, $\mathsf{ML} \vdash \neg(p \wedge \neg p)$ and $\mathsf{ML} \vdash \bot \to \neg p$; see [[negation laws of minimal logic|ME1W9BR7VZ]].
3. $\mathsf{ML} \vdash \neg\neg(p \vee \neg p)$; see [[the double negation of excluded middle|XA3YR52RWC]].
4. $\mathsf{ML} \vdash (p \vee q) \wedge \neg p \to \neg\neg q$, a weak disjunctive syllogism; see [[disjunctive syllogism in minimal logic|27MDC84G8Q]].

### Non-examples

1. $\bot \to p$ is not a theorem: a one-world model with $\bot$ true and $p$ false refutes it; see [[ex falso is not a theorem of minimal logic|T2SXPH67RQ]].
2. $(p \vee q) \wedge \neg p \to q$ is a theorem of $\mathsf{IPC}$ but not of $\mathsf{ML}$, by the same kind of model.
3. $\neg p \to (p \to q)$ is not a theorem, since with $p$ and $\bot$ true it reduces to $q$.

### Basic properties

1. $\mathsf{ML} \subseteq \mathsf{IPC}$, and the inclusion is proper, since $\bot \to p$ is in $\mathsf{IPC}$.
2. $\mathsf{ML} \vdash \varphi$ if and only if positive intuitionistic logic proves $\varphi[f/\bot]$, with $f$ a new variable. The reason is that the Hilbert system of $\mathsf{ML}$ is the positive one, with $\bot$ read as an atom.
3. $\mathsf{IPC} \vdash \varphi$ if and only if $\mathsf{ML} \vdash X_\varphi \to \varphi$, where $X_\varphi$ is the conjunction of $\bot \to p$ over the variables $p$ of $\varphi$.
4. On negative formulas, built from $\bot$ and negated variables $\neg p$ with $\wedge$ and $\to$, the logics $\mathsf{ML}$ and $\mathsf{IPC}$ have the same theorems.
5. Kripke semantics: $\mathsf{ML}$ is sound and complete for intuitionistic Kripke models in which $\bot$ is true on an arbitrary up-set.
6. $\mathsf{ML}$ is paraconsistent in a weak sense: from $p$ and $\neg p$ it derives $\bot$ and every negation $\neg q$, but not every formula.

### History

Johansson introduced minimal logic in 1937, in the paper "Der Minimalkalkül, ein reduzierter intuitionistischer Formalismus".
The name refers to the minimal set of rules for negation.

### Common errors

1. Assuming that every intuitionistic law of negation holds in $\mathsf{ML}$. The law $\neg p \to (p \to q)$ fails, because it is a form of ex falso.
2. Reading $\bot$ in minimal logic as "false in every model". In a Kripke model for $\mathsf{ML}$, $\bot$ may be true at some worlds.

## Explanations

### L1 human

Minimal logic is intuitionistic logic without one rule: "from a contradiction, anything follows".
A contradiction is still a special statement, and "not $A$" still means "$A$ leads to a contradiction".
For example, minimal logic proves "if $A$, then not not $A$", since that uses only "if ... then" reasoning.
But it does not prove "if a contradiction holds, then $2 + 2 = 5$".

### L2 human

We prove item 3 of the basic properties in one direction, from right to left.

1. Assume $\mathsf{ML} \vdash X_\varphi \to \varphi$.
2. $\mathsf{IPC}$ contains $\mathsf{ML}$, so $\mathsf{IPC} \vdash X_\varphi \to \varphi$.
3. Each conjunct $\bot \to p$ of $X_\varphi$ is an instance of the axiom $\bot \to \varphi$ of $\mathsf{IPC}$.
4. So $\mathsf{IPC} \vdash X_\varphi$, and modus ponens gives $\mathsf{IPC} \vdash \varphi$.

The other direction replaces each use of $\bot \to \chi$ by a derivation from the hypotheses $\bot \to p$; see [[the definition|V7MTF4P01E]].
The typical use of minimal logic is to check that a negation argument does not use ex falso.
A trap: $\bot \to \neg p$ is a theorem of $\mathsf{ML}$, since it is an instance of $\varphi \to (\psi \to \varphi)$, so not every formula of the form $\bot \to \psi$ fails.

### L3 human

Minimal logic is positive intuitionistic logic in a language with one extra constant.
So its algebraic models are Heyting algebras with one distinguished element $f$, and $\neg x := x \to f$; when $f = 0$ the model is an intuitionistic one.
The extensions of $\mathsf{ML}$ include $\mathsf{IPC}$ and a classical minimal logic with Peirce's law, which still lacks ex falso.
Minimal logic is a basic example for the later sub-areas on paraconsistent and substructural logics: it keeps the structural rules but changes the meaning of negation.
