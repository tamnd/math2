## Example

Let $L = \{R\}$ with one binary relation symbol $R$, and let $T_{<}$ be the theory of [[strict linear orders|P33CMYHJW9]], with three axioms:

1. irreflexivity, $\forall x \, \neg R(x, x)$;
2. transitivity, $\forall x \, \forall y \, \forall z \, (R(x, y) \wedge R(y, z) \to R(x, z))$;
3. connectedness, $\forall x \, \forall y \, (R(x, y) \vee x = y \vee R(y, x))$.

Let $\mathcal{N}$ be the $L$-structure with domain $\mathbb{N}$ and $R^{\mathcal{N}} = \{ (m, n) \in \mathbb{N}^2 : m \leq n \}$.
We show that $\mathcal{N}$ is not a [[model|CWQV9PTCB3]] of $T_{<}$.

1. Take the assignment $x \mapsto 0$.
2. The pair $(0, 0)$ is in $R^{\mathcal{N}}$, because $0 \leq 0$, so $R(x, x)$ holds and $\neg R(x, x)$ fails.
3. By the clause for $\forall$ of [[satisfaction|1WTCZB4DVB]], the irreflexivity axiom is false in $\mathcal{N}$.
4. A model must make every axiom true, so $\mathcal{N} \not\models T_{<}$.

The other two axioms are true in $\mathcal{N}$, because $\leq$ is transitive and any two natural numbers are comparable.
So exactly one axiom fails, and it fails at every element, not only at $0$.

## Remarks

The same set $\mathbb{N}$ carries both a model and a non-model of $T_{<}$, since $(\mathbb{N}, <)$ is a model.
The structure $\mathcal{N}$ is a model of a different theory, the theory of non-strict linear orders, which has reflexivity and antisymmetry in place of irreflexivity.
There are two repairs: read $R$ as $<$, or change the theory.

## Explanations

### L1 human

The rules of a strict order say that no number comes before itself.
If we read "comes before" as "is less than or equal to", then $0$ comes before $0$, so the rule breaks.
One broken rule is enough, and the structure is not a model of the rules.

### L2 human

We check the transitivity axiom in $\mathcal{N}$, to see that the failure lies only in irreflexivity.
Let $x \mapsto a$, $y \mapsto b$ and $z \mapsto c$, with $a, b, c \in \mathbb{N}$.
If the hypothesis holds, then
$$a \leq b \quad \text{and} \quad b \leq c \quad \text{give} \quad a \leq c,$$
so the conclusion holds.
If the hypothesis fails, the implication holds by the clause for $\to$.
Watch out: do not read $R$ as $<$ by habit, because the structure fixes its meaning, and here it means $\leq$.
