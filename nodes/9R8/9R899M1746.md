## Definition

Let $F$ be a [[field|04C5ZBG1WT]].
Let $A$ be an $m \times n$ matrix over $F$ and let $b \in F^m$.
The [[system of linear equations|0GT4WWGWH2]] $Ax = b$ in the unknown $x \in F^n$ is *overdetermined* if $m > n$, that is, if it has more equations than unknowns.
It is *underdetermined* if $m < n$, that is, if it has fewer equations than unknowns.

## Notation

1. The numbers $m$ and $n$ are the numbers of rows and columns of $A$, so the definition depends only on the shape of $A$.
2. Some authors, in numerical analysis, use the words for the rank: overdetermined then means that $\rank A = n < m$.

## Remarks

Example: the system $x = 1$, $y = 2$, $x + y = 3$ over $\R$ has $m = 3$ equations and $n = 2$ unknowns, so it is overdetermined; it is consistent, with the solution $(x, y) = (1, 2)$.
Non-example: the system $x + y = 1$, $x - y = 0$ has $m = n = 2$, so it is neither overdetermined nor underdetermined.
If $m > n$, then the [[column space|03AJKXH1AV]] of $A$ has dimension at most $n < m$, so it is a proper subspace of $F^m$.
Hence there are right-hand sides $b$ for which the system is [[inconsistent|0X6V9B1V10]].
Over $\R$, the consistent right-hand sides form a proper subspace of $\R^m$, so a randomly chosen $b$ almost never gives a consistent system.
Over $\R$, the [[least squares|0BYTQ4X1HC]] solutions are the solutions of the normal equations $A^{T} A x = A^{T} b$, which are always consistent.
If $m < n$, a consistent system has a free variable, so it has more than one solution.

## Explanations

### L1 human

A system is overdetermined when it has more equations than unknowns.
It is underdetermined when it has fewer equations than unknowns.

### L2 human

1. The system $x + y = 2$, $x - y = 0$, $x + 2y = 4$ has $3$ equations and $2$ unknowns, so it is overdetermined.
2. The first two equations give $x = y = 1$, and the third then reads $3 = 4$, so it is inconsistent.
3. The single equation $x + y + z = 1$ has $1$ equation and $3$ unknowns, so it is underdetermined.
4. Its solutions $(1 - s - t, s, t)$ form a plane; check: $(1 - s - t) + s + t = 1$.

The typical use is to describe the shape of a system before solving it.
A trap: the words describe the counts, not the solutions; an overdetermined system can be consistent.
