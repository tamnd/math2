## Summary

A formal language over an [[alphabet|RABRP2KG81]] $\Sigma$ is any set of [[strings|1P6EP01HZF]] over $\Sigma$.
Formal languages describe the syntax of programming languages and of logic, and they model [[decision problems|YAVW1XHNFH]].
They are classified by the machines or grammars that describe them, from regular languages up to [[recursively enumerable languages|67R1A5Y54R]].
Operations such as union, concatenation and [[Kleene star|ZW1M7XG8V4]] build new languages from old ones.

## Explanations

### L1 human

A formal language is a set of allowed strings, chosen by some rule.
Over the letters $a$ and $b$, the strings with as many $a$s as $b$s form a language.
So do the strings that start with $a$, and so does the set of all strings.
Unlike a natural language, a formal language has no meaning attached: only membership matters.
