## Definition

Let $A$ and $B$ be [[sets|0SJ3RX9TXA]].
The set $A$ is a subset of $B$, written $A \subseteq B$, when each [[element|0EZ758XE73]] of $A$ is an element of $B$:
$$\forall x \, (x \in A \to x \in B).$$
Then $B$ is a superset of $A$.
The set $A$ is a proper subset of $B$, written $A \subsetneq B$, when $A \subseteq B$ and $A \neq B$.

## Remarks

Some authors write $A \subset B$ for $A \subseteq B$, and others write it for a proper subset.
Two sets are equal if and only if each is a subset of the other. This follows from the [[axiom of extensionality|0TB16T2C97]].
The [[empty set|0ECVK59Y03]] is a subset of every set, and every set is a subset of itself.

## Explanations

### L1 human

$A \subseteq B$ means that $A$ fits inside $B$.
The set of even numbers is a subset of the set of integers.
To prove $A \subseteq B$, take an arbitrary $x \in A$ and show $x \in B$.
