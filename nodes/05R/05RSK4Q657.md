## Summary

Let $\varphi$ be a formula of propositional logic with the variables $p_1, \dots, p_n$.
Its truth table has one row for each of the $2^n$ assignments of truth values to $p_1, \dots, p_n$.
Its last column gives the value of $\varphi$ in each row.
The value in each row is computed from the inside out: first the variables, then each subformula, one [[logical connective|QS0XVAN9BG]] at a time, up to $\varphi$ itself.
The tables of [[negation|0XR7A7RSXB]], [[conjunction|0M28ASWG8T]], [[disjunction|0H5GKDTB01]], [[material implication|0ZNX6DQ3EJ]] and the [[biconditional|0V6GAWTBYW]] define these connectives, and the table of a compound formula is built from them.
The method decides in a finite number of steps whether a formula is a [[tautology|05006AJ7DZ]], whether two formulas are [[logically equivalent|0JMR2HM2N2]], and whether an argument is valid.
It is the first algorithm of logic, and it proves most laws of this topic.

## Motivation

The truth value of a compound [[proposition|0ZGC7ZESYN]] depends only on the truth values of its parts.
A formula with $n$ variables can therefore be true or false only in finitely many ways, one for each assignment of values to the variables.
So the question whether $\varphi$ is true for all values of $p$, $q$ and $r$ can be answered by listing all cases.
A truth table is this list, written in a fixed order so that no case is lost or counted twice.

## Notation

The rows follow the standard order.
For two variables: $\mathsf{T}\mathsf{T}$, $\mathsf{T}\mathsf{F}$, $\mathsf{F}\mathsf{T}$, $\mathsf{F}\mathsf{F}$.
For three variables: $\mathsf{T}\mathsf{T}\mathsf{T}$, $\mathsf{T}\mathsf{T}\mathsf{F}$, $\mathsf{T}\mathsf{F}\mathsf{T}$, $\mathsf{T}\mathsf{F}\mathsf{F}$, $\mathsf{F}\mathsf{T}\mathsf{T}$, $\mathsf{F}\mathsf{T}\mathsf{F}$, $\mathsf{F}\mathsf{F}\mathsf{T}$, $\mathsf{F}\mathsf{F}\mathsf{F}$.
In general, the first variable changes every $2^{n-1}$ rows, the second every $2^{n-2}$ rows, and the last in every row.
Many books, and most books of computer science, write $1$ and $0$ for $\mathsf{T}$ and $\mathsf{F}$ and start with the row $0 \cdots 0$.
The metalanguage writes $\models \varphi$ for "$\varphi$ is a tautology", $\varphi \equiv \psi$ for "$\varphi$ and $\psi$ are logically equivalent", and $\varphi_1, \dots, \varphi_k \models \psi$ for "the argument is valid".

## Remarks

### The method

To build the truth table of a formula $\varphi$ with $n$ variables:

1. List the variables in a fixed order, and write the $2^n$ rows in the standard order.
2. List the subformulas of $\varphi$ from the smallest to the largest, ending with $\varphi$. Each one gets a column.
3. Fill each column, row by row, from the columns of its immediate parts and the table of its main connective.
4. Read the answer in the last column.

The table answers three questions.

1. Tautology: $\varphi$ is a tautology exactly when its column has $\mathsf{T}$ in every row. It is a contradiction when the column has $\mathsf{F}$ in every row, and a contingency otherwise.
2. Equivalence: $\varphi \equiv \psi$ exactly when the columns of $\varphi$ and $\psi$ agree in every row of a common table. Equivalently, $\varphi \leftrightarrow \psi$ is a tautology.
3. Validity: an argument with premises $\varphi_1, \dots, \varphi_k$ and conclusion $\psi$ is valid exactly when no row makes all premises true and $\psi$ false. Equivalently, $(\varphi_1 \land \dots \land \varphi_k) \to \psi$ is a tautology.

### Short-cut methods

A full table has $2^n$ rows, which is $1024$ rows for $n = 10$.
Three short cuts save work.

1. The assume-false method (a form of reductio). To show that $\varphi$ is a tautology, assume a row makes $\varphi$ false, and work out the values that this forces on the parts. If the forced values contradict each other, then no such row exists, and $\varphi$ is a tautology. If they are consistent, then they give a row where $\varphi$ is false.
2. Rows of the conclusion. To test an argument, examine only the rows where the conclusion is false, and check whether a premise is false in each of them.
3. Early stopping. An implication with a false antecedent is true, and a conjunction with a false part is false. A disjunction with a true part is true. So many cells need no further work.

### Examples

1. [[The truth table of $((p \to q) \land (q \to r)) \to (p \to r)$|~c9f3fceb]]: an $8$-row table whose last column is all $\mathsf{T}$, so the formula is a tautology.
2. [[Checking the validity of an argument by a truth table|~9565a398]]: the argument from $p \lor q$, $p \to r$ and $q \to r$ to $r$ is valid, and the argument from $p \to r$ and $r$ to $p$ is not.
3. [[Peirce's law by the assume-false method|~e5d7cc0b]]: the short cut proves $((p \to q) \to p) \to p$ in a few lines, and it finds a falsifying row for $((p \to q) \to q) \to q$.
4. The [[proof of the law of excluded middle by a truth table|ZNQN1JW1V3]] and the [[proof of De Morgan's laws by truth tables|68VBVMFJSW]] use the method for a tautology and for an equivalence.
5. The [[proof that an implication is equivalent to its contrapositive|SWH5EJP8PS]] compares two columns of one table.

### Non-examples

1. [[A table of cases does not decide a quantified statement|~fd181d37]]: the values of "$n^2 + n + 41$ is prime" for $n = 0, \dots, 39$ are all true, yet the statement fails at $n = 40$.
2. A table with fewer than $2^n$ rows is not a truth table. For example, a table of $p \lor q \to p$ with only the rows $\mathsf{T}\mathsf{T}$ and $\mathsf{T}\mathsf{F}$ suggests a tautology, but the row $\mathsf{F}\mathsf{T}$ gives $\mathsf{F}$.
3. A table of values of a modal formula $\Box p$ is not a truth table, because $\Box$ has no truth function.

### Basic properties

1. A formula with $n$ variables has $2^n$ rows, because each variable takes one of $2$ values independently.
2. The number of columns is the number of distinct subformulas, which is at most the number of symbols of the formula.
3. Two formulas with the same variables are logically equivalent exactly when they have the same last column.
4. A formula is a tautology exactly when its negation is a contradiction.
5. The method always terminates, so the set of tautologies of propositional logic is decidable.

### History

Ludwig Wittgenstein, in the Tractatus of 1921, and Emil Post, in his paper of 1921, used truth tables to describe all truth functions.
Post used them to prove that the tautologies are exactly the theorems of the propositional calculus of Principia Mathematica.

### Common errors

1. A student lists fewer than $2^n$ rows, or lists a row twice. The standard order prevents both errors.
2. A student fills the column of a compound formula before the columns of its parts. Each column must use only columns to its left.
3. A student concludes "tautology" from the rows that were checked. One row with $\mathsf{F}$ is enough to refute a tautology, so every row must be checked, or the assume-false method must be used.

## Explanations

### L1 human

A truth table lists every possible case of a statement built from simple parts.
With two parts $p$ and $q$, there are $4$ cases: both true, only $p$ true, only $q$ true, both false.
For "$p$ or $q$" the table gives true, true, true and false.
A statement that comes out true in every case is a law of logic.
"$p$ or not $p$" is such a law: when $p$ is true, the first part is true, and when $p$ is false, the second part is true.

### L2 human

We test whether $p \to (q \to r)$ and $(p \land q) \to r$ are logically equivalent.

1. There are $3$ variables, so there are $2^3 = 8$ rows.
2. The formula $(p \land q) \to r$ is false only when $p \land q$ is true and $r$ is false, that is, in the row $\mathsf{T}\mathsf{T}\mathsf{F}$.
3. The formula $p \to (q \to r)$ is false only when $p$ is true and $q \to r$ is false, that is, when $p$, $q$ are true and $r$ is false: again only the row $\mathsf{T}\mathsf{T}\mathsf{F}$.
4. Both formulas are false in the same single row and true in the other $7$, so they are logically equivalent.

Steps 2 and 3 use the short cut of looking only for the rows where an implication is false.
The typical use of this equivalence is in proofs: to prove "if $P$ and $Q$, then $R$", we may assume $P$, then assume $Q$, and derive $R$.
A trap: $(p \to q) \to r$ is not equivalent to these two formulas; it is false in the row $\mathsf{F}\mathsf{T}\mathsf{F}$, where both are true.

### L3 human

A truth table computes the function $\set{\mathsf{T}, \mathsf{F}}^n \to \set{\mathsf{T}, \mathsf{F}}$ that a formula defines, so it is the semantics of propositional logic in its most concrete form.
The number of rows grows as $2^n$, and no method is known that decides tautologies in time polynomial in the size of the formula.
Deciding tautologies is complete for the class [[co-NP|NBSD5FG7NY]], and deciding [[satisfiability|QN7M1JCGT9]] is the complementary problem.

The assume-false method grows into the method of semantic tableaux and into resolution, which search for a falsifying row in a structured way.
Truth tables do not extend to [[predicate logic|086QKPF0A6]], where a universal statement over an infinite domain has infinitely many instances.
For [[many-valued logic|DWYCKAKXZD]] the tables have $k^n$ rows for $k$ truth values.
In [[intuitionistic logic|Q11N8X99FK]] no finite table is enough: there is no finite many-valued table that gives exactly the intuitionistic tautologies.
