## Summary

The minimum distance of a [[block code|EFGYF9P0PN]] is the least [[Hamming distance|EP5HNGSXFA]] between two different codewords.
It measures how robust the code is: a code of minimum distance $d$ detects up to $d - 1$ errors and corrects up to $\floor{(d-1)/2}$ errors.
For a linear code it equals the least [[Hamming weight|K8ZHAQAK2B]] of a nonzero codeword.
Bounds on codes, such as the Singleton and Hamming bounds, relate it to the length and the number of codewords.

## Explanations

### L1 human

Think of the codewords as points spread in space, and of errors as small moves.
If any two codewords are at least $d$ steps apart, a word received after fewer than $d$ errors can never be another codeword.
If the errors are fewer than half of $d$, the received word is still nearest to the codeword that was sent.
The repetition code $\set{000, 111}$ has minimum distance $3$, so it corrects one error.
