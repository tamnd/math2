## Definition

Let $T$ be an infinite set, let $f \colon \R^n \to \R$ and let $g \colon \R^n \times T \to \R$.
The *semi-infinite program* with these data is the [[optimization problem|NS0Q42Y3FX]]: minimise $f(x)$ over $x \in \R^n$ subject to
$$g(x, t) \le 0 \quad \text{for all } t \in T.$$
*Semi-infinite programming* is the study and solution of such problems.

## Remarks

In most of the theory $T$ is a compact subset of some $\R^k$ and $g$ is continuous.
In a *generalized* semi-infinite program the index set $T(x)$ depends on $x$.

Example: best uniform approximation of $s^2$ on $[0, 1]$ by affine functions.
Take $x = (a, b, t) \in \R^3$, $f(x) = t$, $T = [0, 1] \times \set{-1, 1}$ and $g(x, (s, \sigma)) = \sigma\,(s^2 - a - b s) - t$.
The constraints say $\abs{s^2 - a - b s} \le t$ for all $s \in [0, 1]$, so the optimal value is the smallest uniform error; it is $1/8$, reached by $a = -1/8$, $b = 1$.

Non-example: a problem with the constraints $g(x, t) \le 0$ only for $t$ in a finite set $\set{t_1, \dots, t_m}$ is an ordinary nonlinear program, not semi-infinite, since the index set is finite.
