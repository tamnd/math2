## Description

Gödel's system T is a small typed programming language in which every program stops, yet functions may take functions as inputs and loops may run over functions.
It is the [[simply typed lambda calculus|2DP940895E]] with the natural numbers and one recursor for each type, and it is the target language of the [[Dialectica interpretation|HZ17ES9PDY]].

*Types.*
The type $\mathbb{N}$ is the type of natural numbers.
If $\sigma$ and $\tau$ are types, then $\sigma \to \tau$ is the type of functions from $\sigma$ to $\tau$, and the arrow associates to the right.

*Terms.*
Each term has a unique type, written $t : \sigma$.

1. For each type $\sigma$ there are infinitely many variables $x^\sigma : \sigma$.
2. The constants are $0 : \mathbb{N}$, the successor $S : \mathbb{N} \to \mathbb{N}$, and for each type $\sigma$ the recursor $R_\sigma : \sigma \to (\mathbb{N} \to \sigma \to \sigma) \to \mathbb{N} \to \sigma$.
3. If $t : \sigma \to \tau$ and $s : \sigma$, then the application $t\, s$ has type $\tau$.
4. If $t : \tau$ and $x$ is a variable of type $\sigma$, then the abstraction $\lambda x.\, t$ has type $\sigma \to \tau$.

*Reduction.*
One-step reduction is generated by three rules, applied to any subterm:
$$(\lambda x.\, t)\, s \rightsquigarrow t[s/x], \qquad R_\sigma\, a\, f\, 0 \rightsquigarrow a, \qquad R_\sigma\, a\, f\, (S\, n) \rightsquigarrow f\, n\, (R_\sigma\, a\, f\, n).$$
The first rule is [[beta reduction|Y9B9CVY6SJ]].
The other two say that $g = R_\sigma\, a\, f$ is defined by [[primitive recursion|5NVA2JRHPV]] with values of type $\sigma$: $g(0) = a$ and $g(n + 1) = f\, n\, g(n)$.

## Remarks

### A first computation

Addition is the term $\mathrm{add} = \lambda m\, n.\, R_{\mathbb{N}}\, m\, h\, n$ with $h = \lambda k\, a.\, S\, a$.
We compute $\mathrm{add}\, 2\, 2$, where $2$ is the numeral $S(S\, 0)$.
The recursion rule and then beta reduction give the first step:
$$R_{\mathbb{N}}\, 2\, h\, (S(S\, 0)) \rightsquigarrow h\, (S\, 0)\, (R_{\mathbb{N}}\, 2\, h\, (S\, 0)) \rightsquigarrow S(R_{\mathbb{N}}\, 2\, h\, (S\, 0)).$$
The same two rules give $S(S(R_{\mathbb{N}}\, 2\, h\, 0))$, and the rule for $0$ gives $S(S(2))$.
Check: $S(S(S(S\, 0)))$ is the numeral $4$.

### Recursion at higher types

The recursor $R_{\mathbb{N}}$ alone gives the [[primitive recursive functions|5NVA2JRHPV]].
Recursion at type $\mathbb{N} \to \mathbb{N}$ goes further, because the loop then builds a new function at each step.
Let $\mathrm{it} = \lambda f\, n\, b.\, R_{\mathbb{N}}\, b\, (\lambda k\, a.\, f\, a)\, n$, so that $\mathrm{it}\, f\, n\, b = f^n(b)$.
The [[Ackermann function|N470JF7ZJX]] is the following term of type $\mathbb{N} \to (\mathbb{N} \to \mathbb{N})$:
$$\mathrm{A} = \lambda m.\, R_{\mathbb{N} \to \mathbb{N}}\, S\, (\lambda k\, g\, n.\, \mathrm{it}\, g\, (S\, n)\, (S\, 0))\, m.$$
So $\mathrm{A}\, 0 = S$ and $\mathrm{A}\, (m + 1)\, n = (\mathrm{A}\, m)^{n + 1}(1)$.
For example, $\mathrm{A}\, 1\, n = S^{n + 1}(1) = n + 2$, and $\mathrm{A}\, 2\, n = (\mathrm{A}\, 1)^{n + 1}(1) = 2n + 3$, so $\mathrm{A}\, 2\, 1 = 5$.
The Ackermann function is not primitive recursive, so this term really needs the recursor at type $\mathbb{N} \to \mathbb{N}$.

### The main facts

Gödel's theory T is a quantifier-free theory of equations $s = t$ between terms of type $\mathbb{N}$.
Its axioms are the equations of the reduction rules, it has the propositional rules, and it has the induction rule: from $A(0)$ and $A(x) \to A(S x)$ infer $A(t)$, for quantifier-free $A$.

Tait proved in 1967, with his computability method, that every term of T normalizes.
In fact T is strongly normalizing: every reduction sequence of a term is finite.
The normal form is unique, so a closed term of type $\mathbb{N}$ reduces to exactly one numeral.
Hence every closed term $t : \mathbb{N} \to \mathbb{N}$ defines a total [[computable function|KZSB5E471K]], the map from $n$ to the normal form of $t\, \overline{n}$.

The functions defined in this way are exactly the provably total functions of Peano arithmetic.
They are also exactly the $\alpha$-recursive functions for $\alpha < \varepsilon_0$.
One direction is the Dialectica interpretation of PA, and the other is a definition in T of each such function.

### What T cannot define

Let $E(c, n)$ be the value of $t\, \overline{n}$ when $c$ is the code of a closed term $t : \mathbb{N} \to \mathbb{N}$, and $E(c, n) = 0$ for other $c$.
By normalization $E$ is computable, but no term of T defines it.
If one did, then $n \mapsto E(n, n) + 1$ would be defined by a closed term $t$ with some code $c$, and then $E(c, c) = E(c, c) + 1$.
This is the usual diagonal argument, and it shows that a language in which every program stops cannot contain its own interpreter.

### Notation and variants

Many books write $0$ for the type $\mathbb{N}$, $1$ for $\mathbb{N} \to \mathbb{N}$ and $2$ for $(\mathbb{N} \to \mathbb{N}) \to \mathbb{N}$.
Some books use combinators instead of $\lambda$-abstraction, and the two forms define the same functionals.
Many books add product types and a definition by cases, which is $R_\sigma\, a\, (\lambda k\, x.\, b)\, n$ and gives $a$ for $n = 0$ and $b$ otherwise.
The main models are the full set-theoretic model of all functionals of finite type, the hereditarily recursive operations, the hereditarily effective operations and the continuous functionals of Kleene and Kreisel.

### Watch out

A common slip is to think that T computes only primitive recursive functions, because each loop is a counted loop.
The Ackermann term above shows the error: the count is fixed, but the loop body is a function, and iterating functions grows fast.
Another slip is to read the type $0$ of older books as the number zero; it is the type $\mathbb{N}$.

### Try it

First, compute $\mathrm{it}\, (\lambda a.\, a + 2)\, 3\, 1$.
The function adds $2$ and is applied $3$ times to $1$, so the value is $7$.

Second, compute $\mathrm{A}\, 2\, 2$ with the formula above.
It is $2 \cdot 2 + 3 = 7$, which agrees with the Ackermann function $A(2, 2) = 7$.

## Explanations

### L1 human

System T is a small programming language for functions on the natural numbers.
It allows functions that take other functions as inputs, such as "apply a function $n$ times".
Its only loop is a counted loop: repeat a step $n$ times, where $n$ is known before the loop starts.
For example, "apply the step 'add $2$' three times to $1$" gives $7$.
Every program in system T stops, and yet it can compute very fast-growing functions, such as the Ackermann function.

### L2 human

We compute $\mathrm{A}\, 1\, 1$ by reduction, to see a loop that produces a function.
Write $h = \lambda k\, g\, n.\, \mathrm{it}\, g\, (S\, n)\, (S\, 0)$.
The recursion rules give $\mathrm{A}\, 1 = R\, S\, h\, (S\, 0) \rightsquigarrow h\, 0\, (R\, S\, h\, 0) \rightsquigarrow h\, 0\, S$.
Beta reduction turns this into the function $\lambda n.\, \mathrm{it}\, S\, (S\, n)\, (S\, 0)$.
Applied to $1$ it gives $\mathrm{it}\, S\, 2\, 1 = S(S(1)) = 3$.
Check: the formula $\mathrm{A}\, 1\, n = n + 2$ gives $3$ for $n = 1$.

The typical use of system T is as the target of Gödel's [[Dialectica interpretation|HZ17ES9PDY]], where each witness of a theorem of arithmetic becomes a term.
Watch out: a term that looks small may hide a recursor at a high type, and its values may be very large.

### L3 human

System T is the simply typed lambda calculus with a natural numbers object and its recursor, and it is the internal language of a cartesian closed category with such an object.
Through the [[Curry-Howard correspondence|A77FER1Q5H]], the recursor corresponds to the induction rule, and terms of T correspond to proofs in intuitionistic arithmetic of finite types.
Its strength is measured by ordinals: it has the same type-1 functions as PA, and the normalization of all terms of T cannot be proved in PA, which matches the [[ordinal analysis|XTTKZTYDSD]] of PA at $\varepsilon_0$.
Extensions of T by [[bar recursion|8CCG6F2FAT]], by fixed points as in PCF, or by polymorphism as in system F give the functional analogues of stronger theories.
