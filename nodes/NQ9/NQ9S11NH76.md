## Definition

Fix a [[model of computation|YFHEG4GYHW]], usually the deterministic [[multitape Turing machine|YK3HD56R3G]].
Fix a resource, usually the number of steps (time) or the number of tape cells visited (space).
Let $M$ be a machine that halts on every input.
Let $f_M(n)$ be the largest amount of the resource that $M$ uses on an input of length $n$.
A [[decision problem|YAVW1XHNFH]] $L$ is *solvable within* a bound $g \colon \N \to \N$ if some machine $M$ decides $L$ with $f_M(n) = O(g(n))$, in [[big O notation|0TGV80E6A4]].
*Computational complexity theory* is the study of these bounds.
For each problem it asks which bounds it is solvable within and which it is not, and it compares problems by efficient reductions.

## Remarks

Example: deciding whether a binary string is a palindrome is solvable within time $O(n)$ on a two-tape machine.
The machine copies the input to its second tape and compares it with the input read backwards.
The measure $f_M$ is a worst case over all inputs of length $n$; average-case complexity uses an expected value instead.
The class of problems solvable within a bound depends on the model only up to moderate changes.
For example, a multitape [[Turing machine|758EYCN27B]] running in time $t(n) \ge n$ can be simulated by a single-tape machine in time $O(t(n)^2)$.
So classes defined by polynomial bounds do not depend on the choice among usual deterministic models.
