## Definition

Let $\Sigma$ be an alphabet and let $L \subseteq \Sigma^*$ be a [[formal language|5VRS8PJEFT]].
A [[Turing machine|W6ESDYBF8Z]] $M$ with input alphabet $\Sigma$, an accepting halting state and a rejecting halting state *decides* $L$ if both conditions hold.

1. $M$ halts on every input $w \in \Sigma^*$.
2. $M$ halts in the accepting state exactly when $w \in L$.

The language $L$ is *decidable*, or *recursive*, if some Turing machine decides it.

## Remarks

Example: $L = \set{a^n b^n : n \ge 0}$ over $\set{a, b}$ is decidable.
A machine first rejects strings not of the form $a^i b^j$.
Then it repeatedly crosses out the first $a$ and the last $b$, and rejects if one kind runs out before the other.
Each round shortens the remaining string, so the machine halts on every input, and it accepts exactly the strings in $L$.
Non-example: the halting language $H = \set{\langle M, w \rangle : M \text{ halts on } w}$ is not decidable, by the undecidability of the [[halting problem|Z7TN2B35B0]].
A machine that simulates $M$ on $w$ satisfies clause 2 but not clause 1, since it runs forever when $M$ does.
Decidable languages are closed under complement, union, intersection, concatenation and Kleene star.
Under a computable bijection between $\Sigma^*$ and $\N$, they correspond to the [[computable sets|PPGD5KW8JC]].
