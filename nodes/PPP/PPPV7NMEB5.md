## Proof

Let $G$ be a finite [[abelian group|082GHNPJ53]] with identity $e$, and write $\operatorname{ord}(x)$ for the [[order|0WE2NHZJ7B]] of $x \in G$.
We use two facts about orders.
By [[the divisibility criterion|0F5QC101Q7]], $x^k = e$ if and only if $\operatorname{ord}(x) \mid k$.
By [[the formula for the order of a power|0VVPQNVM8S]], $\operatorname{ord}(x^k) = \operatorname{ord}(x) / \gcd(\operatorname{ord}(x), k)$.

Lemma A.
If $x, y \in G$ have orders $a$ and $b$ with $\gcd(a, b) = 1$, then $\operatorname{ord}(xy) = ab$.

1. Since $G$ is abelian, $(xy)^{ab} = x^{ab} y^{ab} = (x^a)^b (y^b)^a = e$. Put $k = \operatorname{ord}(xy)$. By the divisibility criterion, $k \mid ab$.
2. From $(xy)^k = x^k y^k = e$ we get $z = x^k = y^{-k}$.
3. Then $z^a = (x^a)^k = e$ and $z^b = (y^b)^{-k} = e$. So $\operatorname{ord}(z)$ divides both $a$ and $b$, and hence it divides $\gcd(a, b) = 1$. So $z = e$.
4. So $x^k = e$ and $y^k = e$, and the divisibility criterion gives $a \mid k$ and $b \mid k$.
5. By step 4, write $k = ak'$ with $k' \in \mathbb{Z}$. Then $b \mid ak'$ and $\gcd(a, b) = 1$, so $b \mid k'$ by [[Euclid's lemma|03BAREW1Z5]]. Hence $ab \mid k$. With step 1, $k = ab$.

Lemma B.
If $x \in G$ has the largest order $m$ of an element of $G$, then $\operatorname{ord}(y) \mid m$ for every $y \in G$.

6. The set of element orders is a finite nonempty set of positive integers, so a largest order $m$ exists. Fix $x$ with $\operatorname{ord}(x) = m$.
7. Suppose, for a contradiction, that $y \in G$ has order $n$ with $n \nmid m$.
8. By the [[fundamental theorem of arithmetic|084HH1NDCB]], if the power of each prime in the factorization of $n$ were at most its power in $m$, then $n$ would divide $m$. So there is a prime $p$ with $n = p^a n'$ and $m = p^b m'$, where $p \nmid n'$, $p \nmid m'$ and $a > b \geq 0$.
9. Put $x' = x^{p^b}$. Since $p^b \mid m$, the order of $x'$ is $m / p^b = m'$.
10. Put $y' = y^{n'}$. Since $n' \mid n$, the order of $y'$ is $n / n' = p^a$.
11. The orders $m'$ and $p^a$ are coprime, because $p \nmid m'$. By Lemma A, $\operatorname{ord}(x' y') = m' p^a$.
12. Since $a > b$, we have $m' p^a = m p^{a - b} \geq m p > m$. This contradicts the choice of $m$ as the largest order.
13. So $\operatorname{ord}(y) \mid m$ for every $y \in G$.

Part 1 of the theorem.

14. By [[the power of the group order|0ZEPNS9BXK]], $g^{|G|} = e$ for every $g \in G$. So the [[exponent|0ZDW0H0VX4]] $\exp(G)$ is finite.
15. By Lemma B and the divisibility criterion, $y^m = e$ for every $y \in G$. So $\exp(G) \leq m$.
16. Since $x^{\exp(G)} = e$, the divisibility criterion gives $m \mid \exp(G)$, so $m \leq \exp(G)$.
17. By steps 15 and 16, $\exp(G) = m = \operatorname{ord}(x)$. Every element order divides it by Lemma B.

Part 2 of the theorem.

18. Suppose that $G$ is [[cyclic|0KVGH0J5B3]], generated by $g$. By [[the order of a cyclic subgroup|031M8HX7DA]], $\operatorname{ord}(g) = |\langle g \rangle| = |G|$.
19. Since $g^{\exp(G)} = e$, the divisibility criterion gives $|G| \mid \exp(G)$. By step 14, $\exp(G) \leq |G|$. So $\exp(G) = |G|$.
20. Conversely, suppose that $\exp(G) = |G|$. By step 17, the element $x$ has order $|G|$.
21. By the order of a cyclic subgroup, $|\langle x \rangle| = |G|$. The subgroup $\langle x \rangle$ is a subset of $G$ with the same finite number of elements, so $\langle x \rangle = G$, and $G$ is cyclic. $\blacksquare$

## Idea

In an abelian group, two elements of coprime orders combine to an element whose order is the product.
So if some order $n$ does not divide the largest order $m$, a prime $p$ appears to a higher power in $n$ than in $m$.
Replace the $p$-part of $m$ by the larger $p$-part of $n$, and we get an element of order larger than $m$, which is impossible.
So the largest order is a common multiple of all orders, and it equals the exponent.
If the exponent is $|G|$, then the element of the largest order generates $G$.

## Variants

Proof with the classification.
This proof is shorter, but it uses the [[classification of finite abelian groups|07CQR9BW3R]], which is a much deeper theorem.

1. If $G$ is cyclic, steps 18 and 19 above give $\exp(G) = |G|$.
2. Conversely, suppose $\exp(G) = |G|$. If $G = \{e\}$, then $G = \langle e \rangle$ is cyclic. So let $G \neq \{e\}$. By the classification, $G \cong A = \mathbb{Z}/k_1\mathbb{Z} \times \cdots \times \mathbb{Z}/k_u\mathbb{Z}$ with $u \geq 1$ and $1 < k_1 \mid k_2 \mid \cdots \mid k_u$.
3. An isomorphism preserves products and the identity, so $\exp(A) = \exp(G)$ and $|A| = |G|$. So $\exp(A) = |A| = k_1 \cdots k_u$.
4. For $(a_1, \ldots, a_u) \in A$, each $k_i$ divides $k_u$, so $k_u a_i = 0$ in $\mathbb{Z}/k_i\mathbb{Z}$. So $\exp(A) \leq k_u$.
5. If $u \geq 2$, then $|A| \geq k_1 k_u \geq 2 k_u > k_u \geq \exp(A)$, which contradicts step 3. So $u = 1$, and $A = \mathbb{Z}/k_1\mathbb{Z}$ is cyclic.
6. The isomorphism sends a generator of $A$ to a generator of $G$, so $G$ is cyclic.
7. The same argument proves part 1: the element $(0, \ldots, 0, 1)$ of $A$ has order $k_u = \exp(A)$.
