## Summary

Let $G$ be a [[group|G5S1M9]] and let $S$ be a subset of $G$.
The set $S$ is a generating set of $G$, or $S$ generates $G$, when the [[subgroup generated by $S$|0RP7VWQ0YN]] is all of $G$.
Equivalently, each element of $G$ is a finite product $s_1^{\varepsilon_1} s_2^{\varepsilon_2} \cdots s_k^{\varepsilon_k}$ with $k \geq 0$, $s_i \in S$ and $\varepsilon_i \in \{1, -1\}$.
The empty product ($k = 0$) is the identity $e$.
The elements of $S$ are the generators of $G$.
A generating set is minimal when no proper subset of it generates $G$.
The smallest size of a generating set is written $d(G)$.
A small generating set gives a short description of a large group, and many proofs about all elements reduce to a check on the generators.

## Motivation

A group can have many elements, and a list of all products is often too long to write.
But the integers under addition come from the single number $1$, and the eight symmetries of a square come from one rotation and one reflection.
In linear algebra, a few vectors span a whole space, and we work with a basis in place of all vectors.
A generating set plays the same part for a group.
A [[group homomorphism|0JYTG5K9Y4]] is determined by its values on a generating set.
So we can define and compare homomorphisms with a small amount of data.
Generators also lead to [[presentations|0JGEQXQ4AC]] and to [[Cayley graphs|0GYQK9NDJF]], which describe infinite groups with finite data.

## Notation

We write $G = \langle S \rangle$ when $S$ generates $G$.
For a finite set we drop the braces: $G = \langle a, b \rangle$ means $G = \langle \{a, b\} \rangle$.
In additive notation, $\langle a_1, \ldots, a_n \rangle$ in an [[abelian group|082GHNPJ53]] is the set of sums $c_1 a_1 + \cdots + c_n a_n$ with $c_i \in \mathbb{Z}$.
The number $d(G)$ is the minimal number of generators.
Some books call $d(G)$ the rank of $G$.
This is not the [[rank of an abelian group|EMCTDD3HZ1]], which is a different number: for example, $\mathbb{Z}/6$ has $d = 1$ and rank $0$.

## Remarks

### Examples

1. The set $\{1\}$ generates $(\mathbb{Z}, +)$, because each integer $n$ is $n \cdot 1$. The set $\{2, 3\}$ also generates $\mathbb{Z}$, because $1 = 3 - 2$.
2. In the cyclic group [[$\mathbb{Z}/n$|03VFZ2WETT]], the class of $k$ generates $\mathbb{Z}/n$ exactly when $1 \in \langle k \rangle$, that is, when $ak \equiv 1 \pmod n$ for some integer $a$. By [[Bézout's identity|0DQVHMYAGA]], this happens exactly when $\gcd(k, n) = 1$.
3. The group [[$\mathbb{Z}/6$ has minimal generating sets of sizes $1$ and $2$|~f186c5d0]]: the sets $\{1\}$ and $\{2, 3\}$.
4. [[The symmetries of a square are generated by a rotation and a reflection|~301ad9e6]]. The same holds for the [[dihedral group|0JZ27DMJ5D]] $D_n$ for each $n \geq 3$.
5. The [[symmetric group|0515A6D2Y1]] $S_n$ is [[generated by its transpositions|0AQNX7G443]], and the [[alternating group|0Z5905Q73D]] $A_n$ is [[generated by its $3$-cycles|0KFZ0QX83G]]. For $S_3$, [[a transposition and a $3$-cycle are enough|~4a65c4a8]].
6. Each group $G$ is generated by the set of all its elements. This generating set is usually far from minimal.

### Non-examples

1. [[The $3$-cycle $(1\,2\,3)$ does not generate $S_3$|~ade7cd47]]. Its powers give only the three even permutations.
2. The set $\{4, 6\}$ does not generate $\mathbb{Z}$: [[the subgroup that it generates is $2\mathbb{Z}$|~58909262]].
3. No single element generates the [[Klein four-group|0PMRQJVTME]], because each of its elements has order at most $2$. So the Klein four-group [[is not cyclic|DX6X1D21FE]]. Any two different elements other than $e$ generate it, so $d = 2$ for it.
4. No finite set generates the group $(\mathbb{Q}, +)$ of rational numbers. The proof is in [[the example of $\mathbb{Q}$|~b8d64d52]].

### Basic properties

1. The set $S$ generates $G$ if and only if no proper subgroup of $G$ contains $S$. This holds because $\langle S \rangle$ is the smallest subgroup that contains $S$.
2. If $S$ generates $G$ and $S \subseteq T \subseteq G$, then $T$ generates $G$.
3. Let $f, g \colon G \to H$ be homomorphisms with $f(s) = g(s)$ for each $s \in S$, and let $G = \langle S \rangle$. Then $f = g$. The set $E = \{x \in G : f(x) = g(x)\}$ contains $S$. It is a subgroup: $f(e) = e = g(e)$; if $x, y \in E$, then $f(xy) = f(x)f(y) = g(x)g(y) = g(xy)$; and $f(x^{-1}) = f(x)^{-1} = g(x)^{-1} = g(x^{-1})$. So $E \supseteq \langle S \rangle = G$.
4. Let $f \colon G \to H$ be a surjective homomorphism, and let $S$ generate $G$. Then $f(S)$ generates $H$. So $d(H) \leq d(G)$.
5. Minimal generating sets of one group can have different sizes. This is different from bases of a vector space, which all have the same size.
6. If $G$ is finite, then $d(G) \leq \log_2 |G|$. Put $H_0 = \{e\}$, and while $H_i \neq G$, choose $s_{i+1} \notin H_i$ and put $H_{i+1} = \langle H_i, s_{i+1} \rangle$. By [[Lagrange's theorem|3C53TD]], $|H_{i+1}| \geq 2|H_i|$, so the process stops after at most $\log_2 |G|$ steps.
7. A group with $d(G) = 1$ is a [[cyclic group|0KVGH0J5B3]] other than $\{e\}$, and $d(\{e\}) = 0$, because the empty set generates $\{e\}$.

### History

Arthur Cayley described a group by a set of generators and drew it as a graph in 1878.
This graph is now called the Cayley graph.
Walther von Dyck studied groups given by generators and relations in 1882.

### Common errors

1. A student forgets the inverses. In $\mathbb{Z}$, the sums of copies of $1$ are only the positive integers, and we also need $-1$ to get all of $\mathbb{Z}$. In a finite group the inverses come for free, because $g^{-1} = g^{m-1}$ when $g^m = e$.
2. A student thinks that each minimal generating set has $d(G)$ elements. The group $\mathbb{Z}/6$ has the minimal generating set $\{2, 3\}$ with two elements, but $d(\mathbb{Z}/6) = 1$.
3. A student thinks that a subgroup needs at most $d(G)$ generators. The group $S_6$ is not abelian and is generated by $(1\,2)$ and $(1\,2\,3\,4\,5\,6)$, so $d(S_6) = 2$. Its subgroup $H = \langle (1\,2), (3\,4), (5\,6) \rangle$ has $8$ elements, but two elements of $H$ generate at most $4$, because the elements of $H$ commute and have order at most $2$.

## Explanations

### L1 human

Generators are the building blocks of a group.
We start from a few elements, and we combine them and undo them again and again.
If we reach every element of the group in this way, the starting elements generate the group.
For the integers under addition, the number $1$ is enough: $5 = 1 + 1 + 1 + 1 + 1$ and $-2 = -1 - 1$.
For the symmetries of a square, a quarter turn and one flip are enough to get all eight symmetries.
A small set of generators is a short description of a big group.

### L2 human

We find all the single elements that generate the cyclic group $\mathbb{Z}/8 = \{0, 1, \ldots, 7\}$ under addition modulo $8$.

1. The multiples of $1$ are $1, 2, \ldots, 7, 0$, so $\langle 1 \rangle = \mathbb{Z}/8$.
2. The multiples of $3$ are $3, 6, 9 \equiv 1, \ldots$. Since $1 \in \langle 3 \rangle$, also $\langle 3 \rangle = \mathbb{Z}/8$.
3. In the same way, $5 \cdot 5 = 25 \equiv 1$ and $7 \cdot 7 = 49 \equiv 1$, so $5$ and $7$ generate $\mathbb{Z}/8$.
4. The multiples of $2$ are $0, 2, 4, 6$, and the multiples of $4$ are $0, 4$. The multiples of $6$ are $6, 4, 2, 0$. These are proper subgroups.
5. So the generators of $\mathbb{Z}/8$ are $1, 3, 5, 7$, the classes $k$ with $\gcd(k, 8) = 1$.

The typical use of a generating set is a proof that checks a property only on the generators.
For example, to show that two homomorphisms from $\mathbb{Z}/8$ are equal, it is enough to compare their values at $1$.

A trap: a minimal generating set need not be as small as possible.
In $\mathbb{Z}/6$, neither $2$ nor $3$ generates the group, so $\{2, 3\}$ is minimal, but $\{1\}$ is smaller.

### L3 human

A generating set $S$ of $G$ is the same as a surjective homomorphism onto $G$ from the [[free group|0KTW26C80J]] on $S$.
The kernel of this map is the set of relations, and a choice of generators and relations is a presentation of $G$.
With a finite generating set, the [[Cayley graph|0GYQK9NDJF]] turns $G$ into a metric space, and the shape of this space at large scale does not depend on the choice of the finite set.
This is the starting point of geometric group theory, and it uses the [[finitely generated groups|082DWWXMRJ]].

The number $d(G)$ behaves in a different way from the dimension of a vector space.
Minimal generating sets have different sizes, and a subgroup can need more generators than the group.
For an [[elementary abelian group|DZSZ8ZS554]] of order $p^n$, the generating sets are the spanning sets of a vector space over $\mathbb{F}_p$, so all minimal generating sets have $n$ elements.
For finite $p$-groups, the Burnside basis theorem reduces $d(G)$ to this linear case through the [[Frattini subgroup|KXJG5VV340]].
Every finite simple group is generated by two elements, and the proof uses the classification of the finite simple groups.
