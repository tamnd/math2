## Definition

Let $X$ be a set and let $\succsim$ be a [[preference relation|JGP0Q56FRY]] on $X$.
A *utility function* for $\succsim$ is a function $u \colon X \to \R$ such that, for all $x, y \in X$,
$$x \succsim y \iff u(x) \ge u(y).$$
One also says that $u$ represents $\succsim$.

## Remarks

On $X = \R^2_{\ge 0}$ let $x \succsim y$ when $\min(x_1, x_2) \ge \min(y_1, y_2)$.
Then $u(x) = \min(x_1, x_2)$ represents $\succsim$, directly from the definition.
The function $u(x) = x_1$ does not represent this relation: $u(2, 0) > u(1, 1)$, but $(1, 1) \succ (2, 0)$ since $\min(1, 1) = 1 > 0$.
If $u$ represents $\succsim$ and $f \colon \R \to \R$ is [[strictly increasing|011EJQWWJS]], then $f \circ u$ also represents $\succsim$.
Any relation represented by a utility function is complete and transitive.
The converse fails on uncountable sets: the lexicographic order on $\R^2$ is a preference relation with no utility function.
Every preference relation on a countable set has a utility function.
