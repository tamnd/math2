## Example

Peano arithmetic has infinitely many axioms, yet a program can still decide whether a given sentence is one of them.
Let $L_A = \{ 0, S, +, \cdot \}$, with a constant symbol, a unary function symbol and two binary function symbols.
First-order Peano arithmetic $\mathsf{PA}$ is the first-order form of the [[Peano axioms|0QFT7Z76N5]].
Its axioms are six basic sentences and every induction axiom.
The six basic sentences are these:
$$\forall x \, \neg\, S x = 0, \quad \forall x \forall y \, (S x = S y \to x = y), \quad \forall x \, (x + 0 = x),$$
$$\forall x \forall y \, (x + S y = S(x + y)), \quad \forall x \, (x \cdot 0 = 0), \quad \forall x \forall y \, (x \cdot S y = (x \cdot y) + x).$$
For a formula $\varphi$ whose free variables are among $x, y_1, \dots, y_m$, the induction axiom of $\varphi$ and $x$ is this sentence:
$$\forall y_1 \cdots \forall y_m \, \big( (\varphi^x_0 \land \forall x \, (\varphi \to \varphi^x_{S x})) \to \forall x \, \varphi \big).$$
The terms $0$ and $S x$ are always substitutable for $x$ in $\varphi$, because $0$ has no variables and a free occurrence of $x$ is never in the scope of a quantifier $\forall x$.
We check that the axiom set of $\mathsf{PA}$ is decidable, so that $\mathsf{PA}$ is a [[recursively axiomatizable theory|3ANXZC3BEG]].

1. Code the symbols of $L_A$, the logical symbols and the variables by natural numbers.
   A parsing program then decides whether a string is a formula and whether it is a sentence.
2. Let $\tau$ be a string.
   If $\tau$ is not a sentence, it is not an axiom.
   If $\tau$ equals one of the six basic sentences, which we test by comparison, it is an axiom.
3. Otherwise $\tau$ begins with some number $k \ge 0$ of universal quantifiers.
   For each $m \le k$, remove the first $m$ quantifiers $\forall y_1 \cdots \forall y_m$ and call the rest $\rho$; there are $k + 1$ choices.
4. By unique readability, $\rho$ has at most one decomposition of the form $((\alpha \land \forall x \, \beta) \to \forall x' \, \gamma)$.
   The parser reads $\alpha$, $x$, $\beta$, $x'$ and $\gamma$ from $\rho$, or finds that there is no such decomposition.
5. Test whether $x' = x$, whether $\beta$ is the string $(\gamma \to \gamma^x_{S x})$, and whether $\alpha$ is the string $\gamma^x_0$.
   The substitutions are computed by replacing each free occurrence of $x$ in $\gamma$.
6. If the tests of step 5 succeed for some $m$, then $\tau$ is the induction axiom of $\gamma$ and $x$.
   If they fail for every $m$, then $\tau$ is not an induction axiom.
7. Each step stops after finitely many operations, so the program always answers.
   So the axiom set of $\mathsf{PA}$ is a [[computable set|PPGD5KW8JC]], and $\mathsf{PA}$ is recursively axiomatizable.
8. A program that lists all derivations from this axiom set prints every theorem, so $\operatorname{Thm}(\mathsf{PA})$ is [[computably enumerable|TN9G24VABN]].
9. Every axiom of $\mathsf{PA}$ is true in $\mathbb{N}$, so $\mathsf{PA}$ is consistent, and it proves the axioms of [[Robinson arithmetic|3K1AKGXF8A]].
   By step 7 and the [[first incompleteness theorem|X9WYNYE29C]], $\mathsf{PA}$ is not complete.

## Remarks

An infinite axiom set can be decidable: what matters is a test of membership, not the size of the set.
The induction schema is what makes the set infinite.
Robinson arithmetic drops the schema and has finitely many axioms, so it is recursively axiomatizable by comparison alone.

The set of theorems of $\mathsf{PA}$ is computably enumerable but not decidable, so $\mathsf{PA}$ is recursively axiomatizable and undecidable, like the [[theory of groups|WHW13HJB3F]].
If we replace the axioms of $\mathsf{PA}$ by all sentences true in $\mathbb{N}$, the theory becomes complete but loses every recursive axiomatization, as [[true arithmetic is not recursively axiomatizable|YSC90EM2M7]] shows.

## Explanations

### L1 human

Peano arithmetic has infinitely many axioms, so a computer cannot store them all in a list.
But a computer can still test whether a given sentence is an axiom.
The induction axioms all have one shape: "if the property holds for 0, and it passes from each number to the next, then it holds for all numbers".
The computer checks this shape, just as a teacher checks that a proof by induction has a base case and an induction step.
So proofs in Peano arithmetic can be checked by a machine.

### L2 human

We test two strings with the program of the Example.
Take the first string.
$$\tau_1 = ((0 = 0 \land \forall x \, (x = x \to S x = S x)) \to \forall x \, x = x)$$
There are no leading quantifiers, so $m = 0$ and $\rho = \tau_1$.
The parser gives $\alpha = (0 = 0)$, $\beta = (x = x \to S x = S x)$, $x' = x$ and $\gamma = (x = x)$.
Then $\gamma^x_{S x} = (S x = S x)$, so $\beta = (\gamma \to \gamma^x_{S x})$, and $\gamma^x_0 = (0 = 0) = \alpha$.
So $\tau_1$ is the induction axiom of $x = x$.

Now change only the last part.
$$\tau_2 = ((0 = 0 \land \forall x \, (x = x \to S x = S x)) \to \forall x \, S x = S x)$$
Here $\gamma = (S x = S x)$ and $\gamma^x_0 = (S 0 = S 0)$, which is not $\alpha$.
So $\tau_2$ is not an induction axiom, although it is valid and so a theorem of $\mathsf{PA}$.

The typical use of this check is in the proof of Gödel's incompleteness theorems, which need a theory with a decidable set of axioms.
Watch out: a decidable set of axioms does not give a decidable set of theorems, and for $\mathsf{PA}$ it does not.
