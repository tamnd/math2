## Statement

The gate set $\{ \land, \neg \}$ can build every truth table, and the gate set $\{ \land, \lor \}$ cannot.
Post's theorem decides every question of this kind with five tests.

Let $F$ be a set of [[Boolean functions|0X05GS525E]] $f : \{ 0, 1 \}^n \to \{ 0, 1 \}$, each of arity $n \geq 1$.
Define five classes of Boolean functions.

- $T_0$: the functions that preserve $0$, that is, $f(0, \ldots, 0) = 0$.
- $T_1$: the functions that preserve $1$, that is, $f(1, \ldots, 1) = 1$.
- $M$: the [[monotone|0A7KV2WB7A]] functions, that is, $a \leq b$ coordinatewise implies $f(a) \leq f(b)$.
- $S$: the self-dual functions, that is, $f(\neg a_1, \ldots, \neg a_n) = \neg f(a_1, \ldots, a_n)$ for all $a$.
- $A$: the affine functions, that is, $f(x_1, \ldots, x_n) = c_0 \oplus c_1 x_1 \oplus \cdots \oplus c_n x_n$ for some $c_0, \ldots, c_n \in \{ 0, 1 \}$, where $\oplus$ is addition modulo $2$.

Then $F$ is [[functionally complete|TDZVCWYJ9F]] if and only if $F$ is contained in none of the five classes.
In other words, $F$ is complete exactly when it contains a function outside $T_0$, a function outside $T_1$, a non-monotone function, a function that is not self-dual and a function that is not affine.
These may be the same function.

## Remarks

### The five tests on NAND

The [[Sheffer stroke|1NNYWRN6B8]] $x \uparrow y = \neg(x \land y)$ fails all five tests.
It is not in $T_0$, since $0 \uparrow 0 = 1$, and not in $T_1$, since $1 \uparrow 1 = 0$.
It is not monotone, since $(0, 0) \leq (1, 1)$ but the value drops from $1$ to $0$.
It is not self-dual, since $0 \uparrow 1 = 1$ and $1 \uparrow 0 = 1$, while self-duality needs these two values to differ.
It is not affine, since $x \uparrow y = 1 \oplus xy$ has a term of degree $2$.
So $\{ \uparrow \}$ is complete.

Here "functionally complete" means that every Boolean function of arity at least $1$ is in the [[clone|PTKR703G6A]] generated by $F$.
That is, it is the truth function of a formula built from variables with the functions of $F$ as connectives.
The [[proof|PXQQ6DBJ55]] builds negation, the two constants and conjunction from the five witnesses.

### Why each test is needed

For each class there is a set $F$ inside that class and outside the other four.
Such a set passes four of the tests and is not complete, so none of the five conditions can be dropped.

For $T_0$, take $\{ \land, \oplus \}$.
Both functions preserve $0$, while $\oplus$ does not preserve $1$ and is not monotone, and $\land$ is not self-dual and not affine.
For $T_1$, take $\{ \lor, \leftrightarrow \}$.
Both preserve $1$, while $\leftrightarrow$ does not preserve $0$ and is not monotone, and $\lor$ is not self-dual and not affine.
For $M$, take $\{ \land, \lor, 0, 1 \}$, with the constants as unary functions.
All four are monotone, the constant $1$ does not preserve $0$, the constant $0$ does not preserve $1$, and $\land$ is not self-dual and not affine.
For $S$, take $\{ \neg, \operatorname{maj} \}$, where $\operatorname{maj}$ is the majority of three variables.
Both are self-dual, $\neg$ fails $T_0$, $T_1$ and $M$, and $\operatorname{maj}$ is not affine.
For $A$, take $\{ \neg, \oplus \}$.
Both are affine, $\neg$ fails $T_0$, $T_1$ and $M$, and $\oplus$ is not self-dual, since $\neg x \oplus \neg y = x \oplus y$.

### Single functions and small complete sets

A single function $f$ is complete alone exactly when $f(0, \ldots, 0) = 1$, $f(1, \ldots, 1) = 0$ and $f$ is not self-dual.
The first two conditions make $f$ non-monotone.
If such an $f$ were affine, it would be $1 \oplus x_{i_1} \oplus \cdots \oplus x_{i_k}$ with $k$ odd, and then it would be self-dual.
So a non-self-dual $f$ of this kind is also non-affine.

Every complete set $F$ contains a complete subset with at most four functions.
Take $f_0 \in F$ outside $T_0$, so $f_0(0, \ldots, 0) = 1$.
If $f_0$ is self-dual, then $f_0(1, \ldots, 1) = 0$, so $f_0 \notin T_1$.
If $f_0$ is not self-dual, then $f_0 \notin S$.
Either way $f_0$ is a witness for two classes, and three more functions cover the rest.

The set $\{ \to, 0 \}$ is complete, with the constant $0$ as a unary function.
The connective $\to$ fails $T_0$, $M$, $S$ and $A$, since $x \to y = 1 \oplus x \oplus xy$, and the constant $0$ fails $T_1$.

When the constants $0$ and $1$ are given for free, $F$ is complete exactly when it contains a non-monotone function and a non-affine function.
The constants already fail $T_0$, $T_1$ and $S$.

### The easy direction and the general setting

The direction "complete implies outside each class" is the easy one.
Each class contains the projections, is closed under composition, and misses some function, so a set inside one class generates only functions of that class.
The direction "outside each class implies complete" is the content of the theorem.

The five classes are the maximal clones on $\{ 0, 1 \}$, the coatoms of [[Post's lattice|MA20X7JCET]].
So the theorem says that a set is complete exactly when it lies in no maximal clone.
For a finite set with $k \geq 3$ elements the same statement holds, and [[Rosenberg's classification|GF1RK91VED]] lists the maximal clones in six families.
Every finite set has single operations that are complete alone, the [[Sheffer functions|1K829SJG3K]].

### Watch out

The affine test needs care.
A formula may look nonlinear and still define an affine function: $(x \land \neg y) \lor (\neg x \land y) = x \oplus y$.
Write the function as a sum modulo $2$ of products of variables before you decide.

The constants are not free.
The set $\{ \to \}$ alone lies in $T_1$, so it is not complete, although $\{ \to, 0 \}$ is.

### Try it

Is $\{ \land, \oplus, \leftrightarrow \}$ complete?
Yes.
The function $\leftrightarrow$ fails $T_0$, since $0 \leftrightarrow 0 = 1$.
The function $\oplus$ fails $T_1$, since $1 \oplus 1 = 0$, and it is not monotone.
The function $\land$ is not self-dual and not affine.

Is $\{ \lor, \leftrightarrow \}$ complete?
No: both functions take the value $1$ at $(1, 1)$, so the set lies in $T_1$.

## History

Emil Post published the criterion in his 1941 monograph *The Two-Valued Iterative Systems of Mathematical Logic*, in which he also described all clones on $\{ 0, 1 \}$.
The question of single complete connectives is older.
Charles Sanders Peirce knew around 1880 that NAND and NOR are each complete alone, and Henry Sheffer published this in 1913.

## Explanations

### L1 human

The theorem gives five simple tests for a set of logic gates.
The gates can build every truth table exactly when, for each test, at least one gate fails it.
The tests ask whether a gate keeps all-zeros at zero, keeps all-ones at one, never turns a larger input into a smaller output, commutes with negation, or is a sum modulo $2$.
NAND fails all five tests, so NAND alone builds everything.

### L2 human

We test the set $\{ \lor, \oplus, 1 \}$, where $1$ is the constant.

1. $T_0$: the constant $1$ does not preserve $0$.
2. $T_1$: $\oplus$ does not preserve $1$, since $1 \oplus 1 = 0$.
3. $M$: $\oplus$ is not monotone, since $(0, 1) \leq (1, 1)$ but $0 \oplus 1 = 1 > 0 = 1 \oplus 1$.
4. $S$: $\lor$ is not self-dual, since $0 \lor 1 = 1$ and $\neg 0 \lor \neg 1 = 1 \neq \neg 1$.
5. $A$: $\lor$ is not affine, since $x \lor y = x \oplus y \oplus xy$ has a term of degree $2$.
6. So the set is complete.
   For example, $\neg x = x \oplus 1$ and $x \land y = \neg(\neg x \lor \neg y)$.

The typical use is a quick test of a proposed gate set.

### L3 human

In the language of universal algebra, the clone generated by $F$ is the set of term operations of the algebra $(\{ 0, 1 \}; F)$.
The theorem identifies the five maximal subclones of the clone of all operations.
Each maximal clone is the set of functions that preserve one relation: $\{ 0 \}$, $\{ 1 \}$, the order $\leq$, the graph of $\neg$, and the relation $x \oplus y = z \oplus w$.
This Galois connection between clones and relations is the general tool behind Rosenberg's classification.
