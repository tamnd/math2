## Statement

Let $\vdash \Gamma$ be a sequent of MALL, the multiplicative-additive fragment of [[linear logic|H408H4WHBA]] with units.

1. Soundness: if $\vdash \Gamma$ is derivable, with or without cut, then it is valid in every [[phase model|5M4Z5EE88F]].
2. Completeness: if $\vdash \Gamma$ is valid in every phase model, then it has a derivation without the [[cut rule|DAMGTSY6VV]].
3. As a consequence, every sequent derivable in MALL has a cut-free derivation.

## Remarks

### Why each hypothesis is needed

The statement is for MALL because the phase models of the [[definition|5M4Z5EE88F]] do not interpret the exponentials.
The SEP entry states that phase semantics also gives semantic proofs of cut elimination for first-order and higher-order linear logic.
The monoid is commutative, so every phase model validates exchange, which MALL has.

### Consequences

1. A sequent is not derivable if one phase model makes it invalid.
   [[Contraction fails|25NVD1AHHE]] by a model on $\mathbb{Z}/2$.
2. Every MALL-derivable sequent is valid in the [[one-point model|EHMRNDEFAV]], so it is a classical tautology when $\otimes$, $\mathbin{\&}$ read as "and" and $\mathbin{\wp}$, $\oplus$ read as "or".
3. Part 3 is cut elimination for MALL, proved without a syntactic reduction of cuts.

## History

The SEP entry on linear logic states that phase semantics is due to Girard in 1987, and that Okada used it for semantic proofs of cut elimination.
The proof in this node follows the method of the cited paper of Okada.

## Explanations

### L1 human

Soundness says: what the rules prove is true in every phase model.
Completeness says: what is true in every phase model has a proof.
The completeness proof builds one special model from proofs without cut, so it also shows that cut is never needed.

### L2 human

We use soundness to show that $\vdash p^{\perp}, q^{\perp}, p$ is not derivable, so linear logic has no weakening.

1. Take $M = \mathbb{Z}/2$ with $\bot = \set{0}$, and $p^* = q^* = \set{1}$.
2. The sequent is $p \otimes q \vdash p$, so it is valid only if $(p \otimes q)^* \subseteq p^*$.
3. $(p \otimes q)^* = \set{1 + 1}^{\perp\perp} = \set{0}^{\perp\perp} = \set{0}$.
4. $\set{0} \not\subseteq \set{1}$, so the sequent is not valid, and by soundness it is not derivable.

The typical use of soundness is this kind of proof of non-derivability.
A trap: completeness needs all phase models, so validity in one model, such as $\mathbb{Z}/2$, does not prove derivability.
