## Definition

Let $q$ be a prime power, let $\F_q$ be the [[finite field|0ZXZ82FTX2]] with $q$ elements, and let $n$ be a positive integer.
A *linear code* of length $n$ over $\F_q$ is a [[linear subspace|00YC1D652K]] $C$ of the vector space $\F_q^n$.
Its elements are the codewords, and its [[dimension|03GSZ8RTZJ]] $k = \dim C$ is the dimension of the code.
If $C \ne \set{0}$ has [[minimum distance|M2X88AXM17]] $d$, then $C$ is called an $[n, k, d]$ code, or an $[n, k, d]_q$ code when the field matters.

## Remarks

A linear code is a [[block code|EFGYF9P0PN]] with $q^k$ codewords.
Its minimum distance equals the least [[Hamming weight|K8ZHAQAK2B]] $\mathrm{wt}(c)$ of a nonzero codeword $c$, since $d(x, y) = \mathrm{wt}(x - y)$ and $x - y \in C$ for $x, y \in C$.
Example: $C = \set{000, 011, 101, 110} \subseteq \F_2^3$ is closed under addition and contains $0$, so it is a subspace; it has dimension $2$ and minimum weight $2$, so it is a $[3, 2, 2]$ code.
Non-example: $C = \set{000, 011, 101}$ is not linear, because $011 + 101 = 110$ is not in $C$.
The ratio $k / n$ is the rate of the code.
