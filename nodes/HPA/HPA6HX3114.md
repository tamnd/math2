## Example

The language $L_2$ of [[second-order arithmetic|DC60FYCSPM]] has number variables $m, n, \ldots$, set variables $X, Y, \ldots$, the symbols $0, 1, +, \cdot, <$ and the relation $n \in X$.
A formula of $L_2$ is arithmetical when it has no set quantifiers; it may have free set variables as parameters.
The system ACA0 has three groups of axioms:

- the basic axioms of an ordered commutative semiring with $0$ and $1$, as in Peano arithmetic;
- the induction axiom $\forall X \, \big( (0 \in X \land \forall n \, (n \in X \to n + 1 \in X)) \to \forall n \, (n \in X) \big)$;
- arithmetical comprehension: $\exists X \, \forall n \, (n \in X \leftrightarrow \varphi(n))$ for each arithmetical formula $\varphi$ in which $X$ is not free.

Let PA be [[Peano arithmetic|0QFT7Z76N5]] in the first-order language $L_1$ with $0, 1, +, \cdot, <$, with the induction schema for all $L_1$-formulas.
We show that ACA0 is a [[conservative extension|N238J43XNE]] of PA: for every $L_1$-sentence $\sigma$, $\mathsf{ACA}_0 \vdash \sigma$ exactly when $\mathsf{PA} \vdash \sigma$.

1. ACA0 proves each basic axiom of PA, since it contains them.
2. ACA0 proves each instance of the induction schema of PA. For an $L_1$-formula $\psi(n)$ with parameters, comprehension gives $X$ with $n \in X \leftrightarrow \psi(n)$, and the induction axiom for $X$ gives the instance for $\psi$.
3. So ACA0 extends PA. For the converse, let $M$ be a model of PA.
4. Let $\mathcal{S}_M$ be the family of subsets of $M$ that are [[definable|CY1TXHF6KQ]] in $M$ by an $L_1$-formula with parameters from $M$.
5. Consider the $L_2$-structure $(M, \mathcal{S}_M)$, whose numbers are $M$ and whose sets are $\mathcal{S}_M$. The basic axioms hold, because they hold in $M$.
6. The induction axiom holds. A set $X \in \mathcal{S}_M$ is defined by some $\psi(n, \bar a)$, and the induction axiom for $X$ is the instance of the PA schema for $\psi$, which is true in $M$.
7. Arithmetical comprehension holds. Let $\varphi(n)$ be arithmetical with set parameters $X_1, \ldots, X_k \in \mathcal{S}_M$, where $X_i$ is defined by $\psi_i(n, \bar a_i)$.
8. Replace each atomic formula $t \in X_i$ in $\varphi$ by $\psi_i(t, \bar a_i)$. The result is an $L_1$-formula $\varphi^*(n)$ with parameters, and $\varphi$ and $\varphi^*$ hold of the same elements of $M$, because the number quantifiers of $\varphi$ range over $M$.
9. So $\set{n \in M : \varphi(n)}$ is defined by $\varphi^*$, and it belongs to $\mathcal{S}_M$. Thus $(M, \mathcal{S}_M)$ is a model of ACA0.
10. Let $\mathsf{ACA}_0 \vdash \sigma$ with $\sigma$ an $L_1$-sentence. By soundness $\sigma$ is true in $(M, \mathcal{S}_M)$, and its truth there depends only on $M$, so $M \models \sigma$.
11. This holds for every model $M$ of PA, so [[Gödel's completeness theorem|WQ1ZE255SF]] gives $\mathsf{PA} \vdash \sigma$.

## Remarks

ACA0 is a two-sorted first-order theory, so soundness and completeness apply to its structures $(M, \mathcal{S})$ with any family $\mathcal{S}$ of subsets of $M$.
The proof uses the restriction to arithmetical comprehension in step 8: a set quantifier in $\varphi$ would range over $\mathcal{S}_M$, and the replacement would not give an $L_1$-formula.
It also uses the restriction of induction to the single set axiom in step 6.
With comprehension for all $L_2$-formulas the system becomes full second-order arithmetic $\mathsf{Z}_2$, and the proof above does not apply.
The example shows that sets of numbers, used in the style of ACA0, add convenience but no new arithmetic theorems.

## Explanations

### L1 human

Peano arithmetic talks only about whole numbers.
ACA0 also talks about sets of whole numbers, but only about sets that can be described in the language of numbers.
Every such set is a shorthand for its description.
So any fact about numbers that ACA0 proves with sets can be proved without them, by writing out the descriptions.

### L2 human

We follow the proof for one set.

1. Let $M = \N$ and let $E$ be the set of even numbers, defined by $\psi(n) = \exists k \, (k + k = n)$.
2. The formula $\varphi(n) = (n \in E \land n + 1 \notin E)$ is arithmetical with parameter $E$.
3. Step 8 replaces it by $\varphi^*(n) = \exists k \, (k + k = n) \land \lnot \exists k \, (k + k = n + 1)$, an $L_1$-formula.
4. In $\N$ both define the set of even numbers, so comprehension for $\varphi$ is satisfied in $(\N, \mathcal{S}_\N)$.

The typical use of this result is to prove an arithmetic theorem with set-theoretic language in ACA0, and then to conclude that PA proves it.
A trap is to apply the same proof to ACA, which has induction for all $L_2$-formulas.
Step 6 fails there, because a formula with set quantifiers does not reduce to an instance of the PA schema.
