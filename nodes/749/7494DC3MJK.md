## Definition

Let $A \in \R^{n \times n}$ and $B \in \R^{n \times m}$, and consider the linear [[control system|ZPDTVZQN5K]] $x' = Ax + Bu$.
A *(linear) full state feedback* is a control law
$$u(t) = -K x(t) + v(t),$$
where $K \in \R^{m \times n}$ is a constant matrix, the *gain*, and $v$ is an external reference input.
The resulting *closed-loop system* is
$$x' = (A - BK) x + B v.$$

## Remarks

The closed-loop dynamics are governed by the matrix $A - BK$, and its [[characteristic polynomial|0VSSPAFM2C]] $\det(sI - (A - BK))$ is the closed-loop characteristic polynomial.
The law is a [[feedback|7NYES2D0Z4]] that uses the whole state, as opposed to output feedback $u = -Fy$ with $y = Cx$, which corresponds to the restricted gain $K = FC$.

Example: for the double integrator $A = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}$, $B = \begin{pmatrix} 0 \\ 1 \end{pmatrix}$ and $K = (k_1, k_2)$,
$$A - BK = \begin{pmatrix} 0 & 1 \\ -k_1 & -k_2 \end{pmatrix}, \qquad \det(sI - (A - BK)) = s^2 + k_2 s + k_1.$$
The gain $K = (1, 2)$ gives $(s + 1)^2$, so both closed-loop eigenvalues are $-1$ and the state tends to $0$ when $v = 0$.

Non-example: the law $u(t) = -\int_0^t x_1(\tau)\, d\tau$ is a feedback but not a full state feedback in this sense, since $u(t)$ is not a constant matrix times $x(t)$.
It is a dynamic controller with its own state.

Nonlinear systems use full state feedback laws $u = k(x)$ with a map $k \colon \R^n \to \R^m$.
