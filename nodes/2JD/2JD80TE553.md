## Summary

Elementary function arithmetic is the weak theory of bounded induction together with one extra axiom: every power $2^x$ exists.
The extra axiom is needed because exponentiation is easy to describe but hard to prove total.
There is a [[$\Delta_0$ formula|GE43CSZTS9]] $\mathrm{Exp}(x, y)$, with only bounded quantifiers, that holds in $\mathfrak{N}$ exactly when $y = 2^x$.
For example, $\mathrm{Exp}(3, 8)$ is true and $\mathrm{Exp}(3, 9)$ is false, and checking this needs only a search below $8$ or $9$.
The theory $\mathsf{I}\Delta_0$ proves each true instance, such as $\exists y \, \mathrm{Exp}(\overline{3}, y)$, but it does not prove $\forall x \, \exists y \, \mathrm{Exp}(x, y)$.

Exactly, $\mathsf{I}\Delta_0$ is [[Robinson arithmetic|3K1AKGXF8A]] $\mathsf{Q}$ together with the [[induction schema|1QD0KDDGYJ]] for all $\Delta_0$ formulas.
Elementary function arithmetic is the theory
$$\mathsf{EFA} = \mathsf{I}\Delta_0 + \forall x \, \exists y \, \mathrm{Exp}(x, y).$$
An equivalent form adds a function symbol $x^y$ with the axioms $x^0 = S0$ and $x^{Sy} = x^y \cdot x$, and allows it in the formulas of the induction schema; the [[definition|SXYZP1DNJJ]] gives both forms.
The functions that $\mathsf{EFA}$ proves total are exactly the [[elementary recursive functions|RJ3MCAAZSV]].

## Motivation

[[Peano arithmetic|HACXBCM7SS]] has far more induction than ordinary number theory uses.
A proof about primes, divisibility or polynomials usually needs induction only on bounded statements, such as "every $d \le n$ with $d \mid n$ has a property".
The theory $\mathsf{I}\Delta_0$ gives exactly that.
But without $2^x$ it cannot code a set of numbers below $x$, or a sequence of length $x$ of numbers below $x$.
One axiom repairs this, and then finite sets, finite sequences and proofs can all be coded.

The result is strong enough to carry out syntax and finite combinatorics, and weak enough to have a small class of provably total functions.
That is why $\mathsf{EFA}$ is a common base theory for the [[incompleteness theorems|HXHHWY3328]] and for weak systems of reverse mathematics.
Many logicians believe it proves most theorems of ordinary number theory, and Friedman's grand conjecture states this belief in a sharp form.

## Notation

We write $\mathsf{EFA}$; other names are $\mathsf{I}\Delta_0 + \mathsf{exp}$, $\mathsf{I}\Delta_0(\mathsf{exp})$, elementary arithmetic and exponential function arithmetic.
The axiom $\forall x \, \exists y \, \mathrm{Exp}(x, y)$ is called $\mathsf{exp}$, and $\mathrm{Exp}(x, y)$ is often written $2^x = y$.
Do not confuse $\mathsf{EFA}$ with elementary recursive arithmetic $\mathsf{ERA}$.
That is a quantifier-free system like [[primitive recursive arithmetic|WCXH72T8D8]], but with function symbols only for the elementary functions.

## Remarks

### Definable but not provably total

Why can $\mathsf{I}\Delta_0$ describe $2^x$ but not prove that it always exists?
The answer is Parikh's theorem.
If $\mathsf{I}\Delta_0$ proves $\forall x \, \exists y \, \varphi(x, y)$ with $\varphi$ in $\Delta_0$, then it proves $\forall x \, \exists y \le t(x) \, \varphi(x, y)$ for some term $t$.
A term of the language of arithmetic is a polynomial, so every provably total function of $\mathsf{I}\Delta_0$ is bounded by a polynomial.

The function $2^x$ is not.
Compare it with $x^3$:
$$2^{9} = 512 < 729 = 9^3, \qquad 2^{10} = 1024 > 1000 = 10^3,$$
and from then on $2^x$ stays ahead, because doubling beats the factor $((x + 1)/x)^3 < 2$.
The same happens for every polynomial, so $\mathsf{I}\Delta_0$ does not prove $\mathsf{exp}$, and $\mathsf{I}\Delta_0$ is strictly weaker than $\mathsf{EFA}$.
[[Parikh's theorem|YPQPC1WJMV]] belongs to [[bounded arithmetic|RA380RWEC0]], where it is used again.

### What one axiom buys

$\mathsf{EFA}$ proves that $x \mapsto 2^{2^x}$ is total, by two uses of $\mathsf{exp}$; [[double exponentiation|FFAWTY9TBE]] checks it.
For $x = 2$ the two uses give $2^2 = 4$ and then $2^4 = 16$.

$\mathsf{EFA}$ proves that there are infinitely many primes, in the form: for each $a$ there is a prime $p$ with $a < p \le a^a + 1$.
[[The proof in EFA|88PS05WWG7]] builds a common multiple $m \le a^a$ of $1, \ldots, a$ by bounded induction and takes a prime factor of $m + 1$.
For $a = 3$ it gives $m = 6$ and the prime $7$, and $3 < 7 \le 28$.

$\mathsf{EFA}$ proves that every finite sequence of length $n$ with entries below $b$ has a code, because $(b + 1)^{n + 1}$ exists.
So it proves the basic facts of syntax: a formula has a unique parse, the set of proofs is $\Delta_0$-definable, and substitution is a total function.

### What it still cannot do

The superexponential function, with $s(0) = 1$ and $s(x + 1) = 2^{s(x)}$, is not provably total in $\mathsf{EFA}$.
It outgrows every tower of twos of fixed height, and every elementary function stays below such a tower; [[the superexponential non-example|7T8J7ZM3RC]] gives the details.
Each fixed tower is provable, one at a time, but the tower of variable height is not.

So $\mathsf{EFA}$ is strictly weaker than the fragment $\mathsf{I}\Sigma_1$, which proves that $s$ is total.
In the other direction, $\mathsf{I}\Delta_0$ is not $\mathsf{EFA}$, as Parikh's theorem showed above.
Together:
$$\mathsf{I}\Delta_0 \subsetneq \mathsf{EFA} \subsetneq \mathsf{I}\Sigma_1,$$
where each inclusion means that every theorem of the smaller theory is a theorem of the larger one.

### Where it sits

A function is provably total in $\mathsf{EFA}$ when a $\Sigma_1$ formula $\varphi(x, y)$ defines its graph and $\mathsf{EFA}$ proves $\forall x \, \exists! y \, \varphi(x, y)$.
These functions are exactly the elementary recursive functions, the level $\mathcal{E}^3$ of the Grzegorczyk hierarchy.
On the quantifier-free side, $\mathsf{ERA}$ is strictly weaker than $\mathsf{PRA}$.
The proof-theoretic ordinal of $\mathsf{EFA}$ is $\omega^3$, compared with $\omega^2$ for $\mathsf{I}\Delta_0$ and $\omega^\omega$ for $\mathsf{PRA}$ and $\mathsf{I}\Sigma_1$.
The usual arithmetization of syntax works in $\mathsf{EFA}$, so the [[second incompleteness theorem|4PZM5GJTR5]] holds for $\mathsf{EFA}$ and its consistent recursively axiomatized extensions.

### Friedman's grand conjecture

Harvey Friedman conjectured that every theorem published in the Annals of Mathematics whose statement is arithmetical can be proved in $\mathsf{EFA}$.
The conjecture is open.
It is a claim about the practice of mathematics, not a precise mathematical statement, because "published in the Annals" is not a mathematical property.
For arithmetical sentences in general it fails.
$\mathrm{Con}(\mathsf{EFA})$ is true and not provable in $\mathsf{EFA}$, and the [[Paris-Harrington theorem|509ZWA0R26]] is not even provable in $\mathsf{PA}$.
The conjecture says that such statements do not occur among the published theorems of ordinary mathematics.

### History

László Kalmár introduced the elementary functions, and they give the theory its name.
Rohit Parikh proved his theorem on bounded witnesses in 1971.
Friedman stated the grand conjecture in a post to a mailing list on the foundations of mathematics.

### Watch out

$\mathsf{EFA}$ proves the totality of each tower of fixed height, such as $2^{2^{2^x}}$, but not of the tower $s(x)$ of variable height.
A proof of the second would need $x$ uses of $\mathsf{exp}$, and that is induction on a formula with an unbounded $\exists$.

Do not confuse provable totality with the truth of each instance.
Each true instance $\exists y \, \mathrm{Exp}(\overline{n}, y)$ is a true $\Sigma_1$ sentence, so even $\mathsf{Q}$ proves it by [[Σ1-completeness|69234Z1V00]].
Totality is the single uniform statement $\forall x \, \exists y \, \mathrm{Exp}(x, y)$, and that is much stronger.

### Try it

Is $x \mapsto x!$ provably total in $\mathsf{EFA}$?
Yes: the entries of the sequence $0!, 1!, \ldots, x!$ are at most $x^x$, so $\mathsf{exp}$ gives a bound for a code of the sequence.
Bounded induction on $x$ then shows that such a code exists, and its last entry is $x!$.

Find the least $x \ge 1$ from which $2^x > x^2$ holds for good.
At $x = 4$ the two are equal, and $2^5 = 32 > 25$, so the answer is $x = 5$.

## Explanations

### L1 human

Elementary function arithmetic is a small set of rules for whole numbers.
It allows addition, multiplication and powers such as $2^{10} = 1024$.
It allows proofs by induction, but only about statements that look at numbers below a given bound.
Its rules show that each number $x$ has a power $2^x$, and so a power of a power such as $2^{2^3} = 256$.
They cannot show that every tower $2^{2^{\cdots}}$ of any height exists.
Many logicians believe that almost all of number theory can be done with these rules.

### L2 human

We see how $\mathsf{exp}$ gives codes of finite sets.
A set $X \subseteq \{ 0, 1, \ldots, n - 1 \}$ is coded by the sum of the powers $2^i$ for $i \in X$.
For $X = \{ 0, 2, 3 \}$ and $n = 4$ the code is
$$c = 2^0 + 2^2 + 2^3 = 1 + 4 + 8 = 13 < 16 = 2^4.$$
Membership $i \in X$ says that the binary digit of $c$ at place $i$ is $1$.
It is a $\Delta_0$ statement, since it uses only quotients and remainders of $c$ by numbers at most $c$.
Check: $13 = 1101$ in binary, with ones at places $0$, $2$ and $3$.

In $\mathsf{I}\Delta_0$ alone, the code $2^n - 1$ of the whole set $\{ 0, \ldots, n - 1 \}$ need not exist.
In $\mathsf{EFA}$, the axiom $\mathsf{exp}$ gives $2^n$, and bounded induction on $n$ shows that every $\Delta_0$-definable subset has a code below $2^n$.
So in $\mathsf{EFA}$ we can quantify over the subsets of $\{ 0, \ldots, n - 1 \}$ with the bounded quantifier $\exists c < 2^n$.
Watch out: that quantifier is not available in $\mathsf{I}\Delta_0$, where the bound $2^n$ may fail to exist.

### L3 human

$\mathsf{EFA}$ is the natural base theory of weak arithmetic.
Below it lie $\mathsf{I}\Delta_0$ and the theories of bounded arithmetic, which match feasible computation; above it lie $\mathsf{PRA}$, $\mathsf{I}\Sigma_1$ and the other [[fragments of Peano arithmetic|T70PYM1F36]].
In reverse mathematics, $\mathsf{RCA}_0^*$ and $\mathsf{WKL}_0^*$ prove the same $\Pi^0_2$ sentences as $\mathsf{EFA}$.
So they play for $\mathsf{EFA}$ the role that $\mathsf{RCA}_0$ and $\mathsf{WKL}_0$ play for $\mathsf{PRA}$.
The provably total functions form the level $\mathcal{E}^3$ of the Grzegorczyk hierarchy, and the step from $\mathsf{EFA}$ to $\mathsf{PRA}$ adds all the levels $\mathcal{E}^n$ with $n \ge 4$.
The grand conjecture is a claim about the logical strength of mathematical practice, in the same spirit as the observation of reverse mathematics that many theorems of analysis are equivalent to one of five systems.
