## Example

Let $f \colon X \to Y$ be a function, and let $A$ and $B$ be subsets of $X$.
The [[image|0Q3F20XB0A]] of a subset $S$ is $f(S) = \{ f(s) : s \in S \}$.
A student claims that $f(A \cap B) = f(A) \cap f(B)$ and starts a proof by [[double inclusion|MKHVRNW68H]].

1. ($\subseteq$) Let $y \in f(A \cap B)$, so $y = f(x)$ for some $x \in A \cap B$.
2. Since $x \in A$, we get $y \in f(A)$, and since $x \in B$, we get $y \in f(B)$.
   So $y \in f(A) \cap f(B)$; this half is correct, and it is the statement on the [[image of an intersection|0RX7DDBYCK]].
3. ($\supseteq$) Let $y \in f(A) \cap f(B)$, so $y = f(a)$ for some $a \in A$ and $y = f(b)$ for some $b \in B$.
4. The student now writes "so $y = f(x)$ with $x \in A \cap B$".
   This step has no reason, because $a$ and $b$ can be different points.
5. The step cannot be repaired, because the claim is false.
   Take $X = \{1, 2\}$, $Y = \{0\}$, the constant function $f(1) = f(2) = 0$, $A = \{1\}$ and $B = \{2\}$.
6. Then $A \cap B = \varnothing$, so $f(A \cap B) = \varnothing$.
7. But $f(A) = \{0\}$ and $f(B) = \{0\}$, so $f(A) \cap f(B) = \{0\}$.
8. The element $0$ lies in $f(A) \cap f(B)$ and not in $f(A \cap B)$, so the inclusion $\supseteq$ fails and the sets differ.

## Remarks

The example is not an instance of double inclusion, because only one of the two inclusions is true, and the method proves equality only when both halves succeed.
The failed step 4 shows the extra hypothesis that would save it.
If $f$ is [[injective|0PVG1CRAJN]], then $f(a) = f(b)$ gives $a = b$, so this point lies in $A \cap B$, and the equality $f(A \cap B) = f(A) \cap f(B)$ follows.
Conversely, if the equality holds for all $A$ and $B$, then $f$ is injective: if $f(a) = f(b)$ with $a \ne b$, the sets $\{a\}$ and $\{b\}$ give $\varnothing$ on the left and $\{f(a)\}$ on the right.

Change the operation and the picture changes.
For unions, $f(A \cup B) = f(A) \cup f(B)$ holds for every function, and both halves of the double inclusion go through.
For [[preimages|0FGCFY1AZX]], both $f^{-1}(C \cap D) = f^{-1}(C) \cap f^{-1}(D)$ and the same law for unions hold for every function.

## Explanations

### L1 human

Every student in a class gets a grade.
Let $A$ be the chess club and $B$ the choir, and suppose that no student is in both.
The grades of students in both clubs form an empty list.
But Ann in the chess club and Ben in the choir can both have the grade B.
So B is a grade of the chess club and a grade of the choir, and yet nobody in both clubs has it.

### L2 human

We find the same failure with a function of real numbers.

1. Let $f(x) = x^2$ on $\mathbb{R}$, with $A = [-2, -1]$ and $B = [1, 2]$.
2. These intervals do not meet, so $f(A \cap B) = f(\varnothing) = \varnothing$.
3. On $[-2, -1]$ the function is continuous and decreasing, from $4$ at $-2$ to $1$ at $-1$, so $f(A) = [1, 4]$.
4. On $[1, 2]$ it is increasing from $1$ to $4$, so $f(B) = [1, 4]$ as well.
5. So $f(A) \cap f(B) = [1, 4]$, which is not empty, and the equality fails.

Before you try to prove an equality of sets, test the harder inclusion on a small case.
Watch out for a quiet slip: if you call both points of step 3 of the main example by the same name $x$, the gap disappears from view.
