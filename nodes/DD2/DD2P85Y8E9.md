## Summary

Injectivity and surjectivity have fixed proof shapes.
For injectivity you assume that two inputs give the same output and show that the inputs are equal; for surjectivity you take any output and produce an input that gives it.

Here is both on one goal: $f \colon \mathbb{R} \to \mathbb{R}$, $f(x) = 2x + 3$, is a bijection.
Suppose $f(a) = f(b)$, so $2a + 3 = 2b + 3$; subtract $3$ and divide by $2$ to get $a = b$.
Now take any $y \in \mathbb{R}$ and solve $2x + 3 = y$, which gives $x = (y - 3)/2$, a real number with
$$f\left(\frac{y - 3}{2}\right) = (y - 3) + 3 = y.$$
So $f$ is injective and surjective.

In general, let $f \colon X \to Y$ be a [[function|0EPAT51DXQ]].
It is [[injective|09NWETVTNY]] when $f(a) = f(b)$ implies $a = b$ for all $a, b \in X$, and [[surjective|01RVCMSN5N]] when every $y \in Y$ equals $f(x)$ for some $x \in X$.
It is [[bijective|0GG9TVW90M]] when both hold, and that happens exactly when there is a $g \colon Y \to X$ with $g(f(x)) = x$ for all $x \in X$ and $f(g(y)) = y$ for all $y \in Y$.

## Motivation

The two definitions are short, but they have different logical forms, so their proofs start differently.
Injectivity says "for all $a$ and $b$, if $f(a) = f(b)$ then $a = b$", so the proof starts with two arbitrary elements and an equation and ends with an equation.
Surjectivity says "for every $y$ there is an $x$", so the proof starts with one arbitrary $y$ and must produce an element of the domain, as in a [[constructive proof|01XM7JEKHY]].
Mixing the two forms is the source of most errors, and a fixed template for each avoids them.

The goal comes up constantly.
A bijection between two finite sets shows that they have the same size, by the [[bijection principle|0GV2573FP4]].
In algebra the first question about a homomorphism is whether it is injective or surjective, and in analysis an inverse function exists only for a bijection.
The element chasing is the same as in [[set equality by double inclusion|MKHVRNW68H]], and the inverse route returns in the [[inverse function|0J2WAR83WP]] pages.

## Notation

Injective functions are also called one-to-one functions or injections, and surjective functions are called onto functions or surjections.
Some books mark an injection with $X \hookrightarrow Y$ and a surjection with $X \twoheadrightarrow Y$.
In some older texts "one-to-one" means bijective, so check the meaning in each book.
In Lean's Mathlib, `Function.Injective f` is defined as `∀ a b, f a = f b → a = b`, the same shape as the template, and `Function.Surjective f` and `Function.Bijective f` are the other two properties.
The theorem `Function.bijective_iff_has_inverse` states the inverse criterion.

## Remarks

### Three routes to a bijection

You can prove a bijection by the two templates, or by writing down an inverse and checking both compositions.
The inverse route is often shortest when the inverse has a formula.
For $f(x) = 2x + 3$, the inverse is $g(y) = (y - 3)/2$, and
$$g(f(x)) = \frac{2x + 3 - 3}{2} = x, \qquad f(g(y)) = 2 \cdot \frac{y - 3}{2} + 3 = y.$$
The function $x \mapsto \frac{x + 1}{x - 1}$ on $\mathbb{R} \setminus \{1\}$ is [[its own inverse|46QE04NET3]], and that one computation proves that it is a bijection.

The third route proves surjectivity without solving.
For $x \mapsto x^3 + x$ on $\mathbb{R}$ there is no simple formula for the solution of $x^3 + x = y$, but the [[intermediate value theorem|00KAFBR32E]] gives a solution, and a factorization gives injectivity; the [[worked example|3PFKY6RKTQ]] carries this out.

### The codomain is part of the question

The rule $x \mapsto x^2$ from $\mathbb{R}$ to $[0, \infty)$ is surjective, since $x = \sqrt{y}$ works for every $y \ge 0$.
The same rule from $\mathbb{R}$ to $\mathbb{R}$ is not, since $x^2 = -1$ has no real solution.
So "surjective" has no meaning until the codomain is fixed.
The domain matters in the same way: $n \mapsto 3n$ from $\mathbb{Z}$ to $\mathbb{Z}$ is not surjective, because the candidate $y/3$ is not an integer when $y = 1$.
A surjectivity proof must check that the solution it finds lies in the domain.

### Facts that shorten the work

The contrapositive form, $a \ne b$ implies $f(a) \ne f(b)$, is equivalent, and it suits functions given by cases.
A strictly increasing function on a subset of $\mathbb{R}$ is injective, because $a < b$ gives $f(a) < f(b)$.
For a [[linear map|0NRYHJPQG2]], $T(a) = T(b)$ is the same as $T(a - b) = 0$, so [[injectivity reduces to a trivial kernel|0BJBYCGMWE]].
Compositions keep both properties: [[injections compose to injections|01FPXMTBX1]] and [[surjections compose to surjections|07EH4R3RVQ]].
For a map between finite sets of the same size, injective, surjective and bijective are equivalent, so one template is enough, and [[the same holds for a linear map of a finite-dimensional space to itself|0912EEEVCT]].

### One-sided inverses

A function with a non-empty domain is injective exactly when it has a [[left inverse|05SG20AMXH]], by the statement [[injective iff it has a left inverse|0HYFEEZAEM]].
It is surjective exactly when it has a [[right inverse|0WWRD82HD2]], by [[surjective iff it has a right inverse|0TYQNHVB4C]], and for infinite sets that proof uses the axiom of choice.
A two-sided inverse gives a bijection, by [[bijective iff it has a two-sided inverse|01VG2A0BHW]].
One composition alone is not enough: $f(x) = (x, 0)$ from $\mathbb{R}$ to $\mathbb{R}^2$ and $g(u, v) = u$ satisfy $g(f(x)) = x$, but $(0, 1)$ is not a value of $f$.

### Watch out

The most common slip proves the converse: "if $a = b$, then $f(a) = f(b)$".
That holds for every function, so it proves nothing.
A second slip is a false cancellation, as in "$a^2 = b^2$, so $a = b$"; [[squaring is not injective|Q07B3Q8Q5A]] on $\mathbb{R}$, since $(-1)^2 = 1^2$.
A third slip checks a few pairs, such as $f(1) \ne f(2)$ and $f(2) \ne f(3)$, while the definition speaks of all pairs.
To disprove injectivity, one pair $a \ne b$ with $f(a) = f(b)$ is enough, and to disprove surjectivity, one unreached $y$ is enough.

### History

The words injection, surjection and bijection come from the Bourbaki group.
Many English textbooks still use the older words "one-to-one" and "onto".

### Try it

Is $f \colon \mathbb{Z} \to \mathbb{Z}$, $f(n) = 2n$, injective, and is it surjective?
It is injective, since $2a = 2b$ gives $a = b$, and it is not surjective, since $2n$ is even and never equals $1$.

Show that $h(x) = x^2 - 4x$ is not injective on $\mathbb{R}$.
$h(1) = -3 = h(3)$, so two different inputs give the same output.

## Explanations

### L1 human

A function is a rule that sends each input to one output.
It is injective when two different inputs never share an output, like a theater where no two people sit in the same seat.
To show this, suppose two inputs give the same output and show that they were the same input.
It is surjective when every possible output is reached, like a theater with every seat taken.
To show this, take any output and find an input for it.
For the rule "add $5$" on whole numbers, the output $12$ comes from $7$, and the output $y$ comes from $y - 5$.

### L2 human

We prove that $f \colon \mathbb{R} \to \mathbb{R}$, $f(x) = 3x + 5$, is a bijection.

1. Let $f(a) = f(b)$, so $3a + 5 = 3b + 5$.
   Subtract $5$ and divide by $3$, which is not zero, to get $a = b$.
2. Let $y \in \mathbb{R}$ and solve $3x + 5 = y$, which gives $x = (y - 5)/3$, a real number.
3. Check: $f\big((y - 5)/3\big) = (y - 5) + 5 = y$, so every $y$ is a value of $f$.
4. Steps 1 and 3 show that $f$ is a bijection, and its inverse is $f^{-1}(y) = (y - 5)/3$.

The same template proves that a formula matches one set with another, which is how bijective counting works.
Watch out in step 2: solving gives a candidate, and step 3 is the check that the candidate lies in the domain and really works.

### L3 human

In the language of categories, an injective function is a monomorphism of sets, $f \circ u = f \circ v$ implies $u = v$, and a surjective function is an epimorphism.
In other categories the notions part ways: the inclusion of rings $\mathbb{Z} \to \mathbb{Q}$ is an epimorphism and is not surjective.
For homomorphisms of groups, rings and modules, injectivity reduces to a trivial kernel, and surjectivity often comes from a dimension count such as the [[rank-nullity theorem|0W4FSW1TVB]] or from an existence theorem.
An inverse can be a worse object than the map: $x \mapsto x^3$ is a smooth bijection of $\mathbb{R}$, but its inverse $y \mapsto y^{1/3}$ has no derivative at $0$.
