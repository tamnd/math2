## Summary

A *non-classical logic* is a formal logic whose [[consequence relation|1HK0VYWTV7]] differs from that of classical [[propositional|09K9MWD2QQ]] or [[first-order logic|086QKPF0A6]].
There are two main kinds.
A *deviation* (or *rival*) keeps the classical vocabulary but gives some [[logical connectives|QS0XVAN9BG]] a new meaning, so some classical inferences fail.
An *extension* adds new logical constants, such as the box $\Box$ of modal logic, and keeps all classical inferences in the old vocabulary.
A logic is non-classical in the strict sense when it is a deviation, and in the wide sense when it is a deviation or an extension.
The idea matters because many tasks need a notion of consequence that classical logic does not give: reasoning with contradictions, gaps, defaults, resources or computation.

## Motivation

Classical logic makes several strong assumptions at the same time.
Every sentence is true or false, and not both.
Every name denotes an object, and the domain is not empty.
A contradiction implies every sentence.
New premises never remove an old conclusion.
The conditional "if $A$ then $B$" is true whenever $A$ is false.
Each assumption is useful in mathematics, but each one fails for some kind of reasoning.
A database can hold conflicting entries, a story can mention a person who does not exist, and a default rule ("birds fly") can be withdrawn.
Non-classical logics drop or change one assumption at a time, so that each change can be studied with exact methods.

## Notation

We write $\vdash_{\mathrm{L}}$ or $\vDash_{\mathrm{L}}$ for the consequence relation of a logic $\mathrm{L}$, and $\mathrm{CL}$ for classical logic.
The classification uses three words.
A *deviant* logic has the same formulas as $\mathrm{CL}$ and a different set of valid inferences.
An *extended* logic has more formulas, and it agrees with $\mathrm{CL}$ on the classical formulas.
A *variant* (or *variation*) differs from $\mathrm{CL}$ only in notation.
Other authors use *anti-classical* for deviant and *extra-classical* for extended.

## Remarks

### Examples

- [[Intuitionistic logic|Q11N8X99FK]] is a deviation: excluded middle $p \lor \neg p$ is not valid, as the [[two-world Kripke model|426FBFPS56]] shows.
- Modal logic is an extension: the [[modal logic K|QPN30HZPSM]] adds $\Box$ and proves exactly the tautologies among the box-free formulas.
- [[Paraconsistent logics|C7YWCR87QJ]] such as the [[logic of paradox|BXJZG67PX3]] are deviations: the [[principle of explosion|K33VPAPJQG]] fails.
- [[Non-monotonic logics|BKDFH4PKRP]] such as [[default logic|K4AYFFKY2D]] are deviations at the level of consequence: monotonicity fails.
- [[Free logic|Y0CNMRXHVJ]] changes the quantifier rules, so that names need not denote.
- [[Quantum logic|2E9DMB7A6Q]] replaces the Boolean algebra of propositions by a lattice of subspaces in which distributivity fails.

### Non-examples

- Classical logic written with the [[Sheffer stroke|1NNYWRN6B8]] as the only connective is a variant, not a non-classical logic: [[the translation preserves consequence|CWX983Y0DY]].
- Many-sorted first-order logic is a variant of first-order logic, because it reduces to one-sorted logic with predicates for the sorts.

### Basic properties

- A deviant logic in the language of $\mathrm{CL}$ that has a sound and complete semantics need not be weaker than $\mathrm{CL}$. [[Connexive logic|NQFYY76BSM]] proves some classical non-theorems.
- Classical propositional logic is Post-complete: if we add a non-theorem as a new axiom schema, every formula becomes provable. So a deviant logic with a classical non-theorem must lose some classical theorems.
- The classification is not exclusive: a logic can be both a deviation and an extension. Relevance logics change $\to$ and are often studied with new connectives.
- The classification ignores translations. Gödel's translation embeds intuitionistic logic into the modal logic S4, an extension of $\mathrm{CL}$.

### History

Haack, in *Deviant Logic* (1974), divided non-classical logics into deviant, quasi-deviant and extended logics.
Burgess uses the terms anti-classical and extra-classical for a similar division.
The view that more than one logic can be correct is called logical pluralism, and Beall and Restall defended a version of it in 2006.

### Common errors

- To think that "non-classical" means "weaker than classical". Connexive logics and extensions prove formulas that classical logic does not prove.
- To think that a non-classical logic rejects classical mathematics. Most of these logics are studied with classical metamathematics.
- To confuse a property of a consequence relation with a philosophical position. Paraconsistency is a property of $\vdash$; [[dialetheism|3P0FM0AQF3]] is a view about truth.

## Explanations

### L1 human

Classical logic is the logic of school mathematics: every statement is true or false, and arguments follow fixed rules.
Some kinds of reasoning do not fit these rules.
Suppose a weather service says "it will rain tomorrow" and a second service says "it will not rain tomorrow".
Classical logic says that from these two reports anything at all follows, even "the moon is green".
A non-classical logic changes one rule so that the two reports give only sensible conclusions.
Other non-classical logics handle words like "necessarily", or rules with exceptions, like "birds fly, but penguins do not".

### L2 human

We check that excluded middle separates intuitionistic logic from classical logic.

1. In classical logic, the truth table of $p \lor \neg p$ has two rows. In the row $p = \mathrm{T}$ the formula is T, and in the row $p = \mathrm{F}$ the part $\neg p$ is T. So $p \lor \neg p$ is a tautology.
2. In intuitionistic Kripke semantics, take two worlds $w_0 \le w_1$ with $p$ true only at $w_1$.
3. At $w_0$, $p$ is not true. And $\neg p$ is not true at $w_0$, because $p$ is true at the later world $w_1$.
4. So $p \lor \neg p$ fails at $w_0$, and intuitionistic logic is a deviation from classical logic.

The typical use of the classification is to say exactly which classical principle a logic gives up.
A trap is to count a change of notation as a new logic: the Sheffer stroke gives a variant of classical logic with the same consequences.

### L3 human

From a structural view, a propositional logic is a structural consequence relation on a term algebra, and two logics can be compared by translations between their languages.
Abstract algebraic logic classifies logics by their algebraic counterparts, so Boolean, Heyting, De Morgan and orthomodular algebras each give a family of logics; this is the subject of [[algebraic logic|QYA4H5Y7VR]].
The families in this topic each drop one classical property.
Paraconsistent logics drop explosion, paracomplete and [[partial logics|F5SP7HQFFS]] drop excluded middle, non-monotonic logics drop monotonicity, free logics drop existential import for names, and connexive logics change the conditional.
[[Combining logics|HP1N0MBTDJ]] studies how two such systems can be joined, and [[multiple-conclusion logic|3AJTDAP93H]] changes the form of consequence itself.
The [[many-valued|WZP584JQ06]], [[substructural|98QF5J4W16]], [[modal|SKY7AQFG1V]] and [[intuitionistic|38EQ20GR7M]] families are treated in their own topics.
