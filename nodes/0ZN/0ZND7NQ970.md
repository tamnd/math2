## Definition

An eigenvalue is a scalar by which a linear map multiplies some nonzero vector.
Let $F$ be a field, let $V$ be a vector space over $F$, and let $T \colon V \to V$ be an [[endomorphism|0J7H0YBFDJ]].
A scalar $\lambda \in F$ is an *eigenvalue* of $T$ when there is a vector $v \in V$ with $v \ne 0$ and
$$T(v) = \lambda v.$$
An eigenvalue of an $n \times n$ matrix $A$ over $F$ is an eigenvalue of the map $F^n \to F^n$, $x \mapsto Ax$.

## Notation

Mathlib states the definition as $\ker(T - \lambda \id_V) \ne 0$, in `Module.End.HasEigenvalue T λ`.
This is the same condition, because $T(v) = \lambda v$ means exactly that $v \in \ker(T - \lambda \id_V)$.

## Remarks

The definition has three parts, and each one matters.
The scalar $\lambda$ must lie in the field $F$ of the space.
So the rotation of $\mathbb{R}^2$ by a right angle has no eigenvalue as a real map, although its matrix has the eigenvalues $\pm i$ over $\mathbb{C}$.
The map must go from $V$ to $V$, because $T(v)$ and $\lambda v$ must lie in the same space to be compared.
The vector $v$ must be nonzero, because $T(0) = 0 = \lambda \cdot 0$ for every $\lambda$, and without this condition every scalar would be an eigenvalue.

A small example: for $A = \begin{pmatrix} 2 & 0 \\ 0 & 3 \end{pmatrix}$, the standard basis vectors give $A e_1 = 2 e_1$ and $A e_2 = 3 e_2$, so $2$ and $3$ are eigenvalues.
The scalar $5$ is not an eigenvalue, because $(A - 5I)v = (-3 v_1, -2 v_2)$ is zero only for $v = 0$.

By the theorem on [[injectivity and the kernel|0BJBYCGMWE]], $\lambda$ is an eigenvalue of $T$ if and only if $T - \lambda \id_V$ is not injective.
In finite dimension this holds if and only if $\det(T - \lambda \id_V) = 0$.
The definition itself needs no basis and no finite dimension, so it also applies to maps on spaces of functions.
The [[concept of an eigenvalue|0BQAA2BK3Q]] collects the examples and the first properties.

## Explanations

### L1 human

Most vectors change direction when a linear map acts on them.
An eigenvalue is a stretch factor $\lambda$ such that some nonzero vector only gets multiplied by $\lambda$ and stays on its own line.
For the matrix that doubles the first coordinate and triples the second, the stretch factors are $2$ and $3$.

### L2 human

We test whether $\lambda = 2$ is an eigenvalue of $A = \begin{pmatrix} 1 & 1 \\ 0 & 2 \end{pmatrix}$.

1. We must solve $(A - 2I)v = 0$, and $A - 2I$ has the rows $(-1, 1)$ and $(0, 0)$.
   So the system is $-v_1 + v_2 = 0$.
2. The vector $v = (1, 1)^{\mathsf{T}}$ is a nonzero solution.
3. Check: $Av = (1 + 1, 0 + 2)^{\mathsf{T}} = (2, 2)^{\mathsf{T}} = 2v$.
4. So $2$ is an eigenvalue of $A$.

This is the typical use of the definition: a scalar is an eigenvalue when a homogeneous linear system has a nonzero solution.
Watch out: the zero solution always exists, so it proves nothing.
