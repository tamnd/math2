## Definition

Let $F$ be a field, let $V$ be a vector space over $F$, and let $T \colon V \to V$ be an [[endomorphism|0J7H0YBFDJ]].
A scalar $\lambda \in F$ is an *eigenvalue* of $T$ when there is a vector $v \in V$ with $v \ne 0$ and
$$T(v) = \lambda v.$$
An eigenvalue of an $n \times n$ matrix $A$ over $F$ is an eigenvalue of the map $F^n \to F^n$, $x \mapsto Ax$.

## Notation

Mathlib states the definition as $\ker(T - \lambda \id_V) \ne 0$, in `Module.End.HasEigenvalue T λ`.
This is the same condition, because $T(v) = \lambda v$ means $v \in \ker(T - \lambda \id_V)$.

## Remarks

So $\lambda$ is an eigenvalue of $T$ if and only if $T - \lambda \id_V$ is not injective, by the theorem on [[injectivity and the kernel|0BJBYCGMWE]].
In finite dimension, this holds if and only if $\det(T - \lambda \id_V) = 0$.
The eigenvalues of the diagonal matrix $\begin{pmatrix} 2 & 0 \\ 0 & 3 \end{pmatrix}$ are $2$ and $3$.
The rotation of $\R^2$ by $90$ degrees has no real eigenvalue.
The definition needs no finite dimension and no basis.

## Explanations

### L1 human

Most vectors change direction when a linear map acts on them.
An eigenvalue is a scaling factor $\lambda$ such that some nonzero vector only gets stretched by $\lambda$, without a change of its line.
These special directions often reveal the structure of the map.

### L2 human

We test whether $\lambda = 2$ is an eigenvalue of $A = \begin{pmatrix} 1 & 1 \\ 0 & 2 \end{pmatrix}$.

1. Solve $(A - 2I)v = 0$, that is, $-v_1 + v_2 = 0$ and $0 = 0$.
2. The vector $v = (1, 1)^{\mathsf{T}}$ is a nonzero solution.
3. Check: $Av = (1 + 1, 2)^{\mathsf{T}} = (2, 2)^{\mathsf{T}} = 2v$.
4. So $2$ is an eigenvalue of $A$.

The typical use of the definition is this test: an eigenvalue is a scalar for which a homogeneous system has a nonzero solution.
A trap: the zero solution always exists, so it proves nothing.
