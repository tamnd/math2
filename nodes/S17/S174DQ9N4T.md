## Example

Consider the argument: all squares are rhombuses, all rectangles are parallelograms, so all squares are parallelograms.
Each sentence is a true A proposition.
We show that the argument is not a categorical syllogism, has no figure, and has an invalid form, although its conclusion is true.

1. The terms are "squares", "rhombuses", "rectangles" and "parallelograms".
   There are four, and a categorical syllogism has exactly three [[terms|KSJ9W29KXQ]].
2. The first premise uses "squares" and "rhombuses", and the second uses "rectangles" and "parallelograms", so no term occurs in both premises and there is no middle term.
3. The [[figure|S4BTTGFR6J]] of a syllogism is the position of its middle term, so the argument has no figure.
4. Its form is "all $A$ are $B$, all $C$ are $D$, so all $A$ are $D$".
5. Another instance of the form: all squares are rhombuses, all triangles are three-sided polygons, so all squares are three-sided polygons.
6. In step 5 both premises are true and the conclusion is false, because a square has four sides, so the form is invalid.

The conclusion of the first instance is true for a reason that is not among the premises: every square is a rectangle.

## Remarks

True premises and a true conclusion do not make an argument valid.
The premises must share a term, because that shared term carries the information from one premise to the other.
Replace the first premise by "all squares are rectangles" and "rectangles" becomes a middle term: the argument turns into [[Barbara|AC6XQ4KRNT]], which is valid.

The fallacy of four terms often hides in a word with two meanings.
"Every square is a rectangle, $9$ is a square, so $9$ is a rectangle" shows three words for the classes, but "square" means a figure in the first premise and a number $n^2$ in the second.
So the argument has four classes: square figures, rectangles, square numbers and the number $9$.

## Explanations

### L1 human

The two premises talk about different things: one about squares and rhombuses, the other about rectangles and parallelograms.
Nothing connects them, so they cannot lead to a conclusion together.
The conclusion "all squares are parallelograms" happens to be true, but not because of these premises.
Keep the pattern and change the words, and you can get true premises and a false conclusion.

### L2 human

We take apart the argument with the ambiguous word "square".

1. The first premise is "every square is a rectangle", where a square is a quadrilateral with four equal sides and four right angles.
2. The second premise is "$9$ is a square", where a square is a number of the form $n^2$, here $9 = 3^2$.
3. So "square" names two different classes, and the argument has four terms.
4. The conclusion "$9$ is a rectangle" is not even meaningful, since a number is not a quadrilateral.

The test is to check that each term keeps one meaning through the whole argument.
The trap is to count words instead of classes: three words can name four classes.
