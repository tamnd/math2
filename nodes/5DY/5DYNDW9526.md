## Summary

Classical logic assumes that every claim is settled: it is true or it is false, even when nobody knows which.
The principle of bivalence states this assumption: every [[proposition|0ZGC7ZESYN]] has exactly one of the two truth values T (true) and F (false).
It is a claim about truth values, so it belongs to the semantics of logic, not to its formulas.
It is the reason why a [[truth table|05RSK4Q657]] lists only the values T and F for each variable.

## Motivation

Take the claim "$2^{67} - 1$ is prime".
For a long time nobody knew its truth value, yet mathematicians worked on it as if the answer existed and only had to be found.
That attitude is bivalence, and every mathematician who attacks an open problem uses it.

Bivalence also makes the truth-table method work.
A truth table lists all cases for the parts of a compound proposition, and it needs a fixed, finite list of values for each part.
With two values, $n$ variables give exactly $2^n$ cases, and the table can check them all.
Stating the assumption openly lets us ask what happens without it, which is the starting point of [[many-valued logics|DWYCKAKXZD]].

## Notation

The set of truth values is $\{T, F\}$, also written $\{1, 0\}$ or $\{\top, \bot\}$; it is the [[Boolean domain|37G9TMXT19]].
A valuation is a function $v$ from the propositional variables to $\{T, F\}$, and $v(\varphi)$ is the truth value of a formula $\varphi$ under $v$.
With the values $1$ and $0$, the connectives become arithmetic: $\neg p$ is $1 - p$, $p \land q$ is $pq$, and $p \lor q$ is $\max(p, q)$.

## Remarks

### Settled values that nobody knew

[[The truth value of "$2^{67} - 1$ is prime"|D61ZTVC8DN]] shows bivalence at work.
Frank Nelson Cole found the factorization
$$2^{67} - 1 = 147573952589676412927 = 193707721 \cdot 761838257287$$
in 1903, and the product was the same number before 1903, so the claim was false all along.
Goldbach's conjecture, "every even number greater than $2$ is a sum of two primes", is in the same position today: by bivalence it is true or false, and [[nobody knows which|2H9FT1ZV4J]].
For a statement such as "$x^2 \ge 0$ for every real $x$", bivalence gives one value to the statement and the other to its [[negation|029JBBF693]].

### Counting the cases

With bivalence, each variable has $2$ values, and the choices for different variables are independent.
So $n$ variables give $2^n$ valuations, and [[bivalence gives a truth table with $2^n$ rows|55ED55D48B]] works this out for $(p \land q) \to r$ with $8$ rows.
In the same way, a connective with $n$ inputs is a function from $\{T, F\}^n$ to $\{T, F\}$, so there are $2^{2^n}$ of them, and for $n = 2$ that is $16$.

### Bivalence is not excluded middle

The [[law of excluded middle|0RYYK8PG4S]] is the formula $p \lor \neg p$, or the claim that each instance of it is a [[tautology|05006AJ7DZ]].
Bivalence is a claim about the values that propositions take.
In classical semantics bivalence gives the law by two cases.
If $p$ is T, then $p \lor \neg p$ is T; if $p$ is F, then $\neg p$ is T, so $p \lor \neg p$ is T again.
The two can still come apart.
[[Supervaluational semantics|QQPVKJSAX1]] lets some propositions lack a value but makes every instance of $p \lor \neg p$ true.
[[Łukasiewicz's three-valued logic|6S872VHF67]] drops both: it gives $p \lor \neg p$ the value $\tfrac{1}{2}$ when $p$ has the value $\tfrac{1}{2}$.

### Logics without bivalence

Many-valued logics use three or more truth values.
Łukasiewicz's and Kleene's three-valued logics add a value for "undetermined" or "undefined", as in the [[Kleene connectives|B7KATP4SEA]], and fuzzy logics use every real number from $0$ to $1$.
Some [[paraconsistent logics|C7YWCR87QJ]] let a proposition be both true and false, so they drop the "not both" half of bivalence.
[[Intuitionistic logic|Q11N8X99FK]] goes another way: it reads truth as provability and does not assert $p \lor \neg p$, but it adds no third value, and $\neg\neg(p \lor \neg p)$ is provable there.
Gödel showed in 1932 that no finite set of truth values gives exactly the intuitionistic tautologies.

### What is not a failure of bivalence

The [[liar sentence|KBYY281V8T]] "this sentence is false" cannot take either value without contradiction, and some theories of truth give it a [[truth-value gap|4CBCWZQZ12]].
In [[Aristotle's sea battle|A4F57C4ZDA]], "there will be a sea battle tomorrow" is, on one reading, neither true nor false today.
These are real challenges to bivalence.
The open sentence "$x > 3$" is not one: it has no truth value because it is not a proposition, and each instance, such as "$5 > 3$", has exactly one value.

### Watch out

Bivalence does not say that we know the truth value, only that it exists.
It is also not the same as excluded middle, as the supervaluational case shows.
Finally, a proof by cases "either $p$ is T or $p$ is F" uses bivalence: in a logic with a third value it misses a case, and its conclusion can fail.

### History

In On Interpretation, Aristotle asked whether "there will be a sea battle tomorrow" is already true or false today.
George Boole used the values $1$ and $0$ in his algebra of logic of 1847 and 1854.
Jan Łukasiewicz built a three-valued logic in 1920 to give such statements about the future a third value.
Brouwer rejected the law of excluded middle for infinite collections, and his intuitionism led to a logic that does not rely on bivalence.

### Try it

How many rows has the truth table of $(p \lor q) \land \neg(r \land s)$?
There are $4$ variables, so $2^4 = 16$ rows.

In Łukasiewicz's logic, with $x \land y = \min(x, y)$ and $\neg x = 1 - x$, what is $p \land \neg p$ for $p = \tfrac{1}{2}$?
It is $\min(\tfrac{1}{2}, \tfrac{1}{2}) = \tfrac{1}{2}$, so $p \land \neg p$ is not simply false there.

## Explanations

### L1 human

Bivalence says that every claim is either true or false, and never both.
"$3 + 4 = 7$" is true, and "$3 + 4 = 8$" is false.
There is no third option such as "half true".
Even for a hard claim that nobody can check yet, the answer is already one of the two.
Our not knowing the answer does not create a third value.

### L2 human

Here is how bivalence enters a proof that $p \lor \neg p$ is always true.
By bivalence, $p$ is T or $p$ is F, so there are two cases.
If $p$ is T, the first part of $p \lor \neg p$ is T, so the whole is T.
If $p$ is F, then $\neg p$ is T, so the whole is T again.

Now allow a third value $\tfrac{1}{2}$, with $\neg x = 1 - x$ and $x \lor y = \max(x, y)$, as Łukasiewicz did.
For $p = \tfrac{1}{2}$ we get
$$p \lor \neg p = \max\left(\tfrac{1}{2}, 1 - \tfrac{1}{2}\right) = \tfrac{1}{2},$$
which is not $1$.
The two-case proof misses this third case.
So every truth-table proof of a classical law uses bivalence, even when it does not say so.

### L3 human

Algebraically, bivalence says that the semantics of classical propositional logic is the [[two-element Boolean algebra|0WG43AC0EV]].
Every [[Boolean algebra|0XADJKM699]] satisfies all classical laws, and a [[Heyting algebra|NG943XNQWH]] gives intuitionistic logic.
So the laws of classical logic do not need bivalence; bivalence only picks out the algebra with two elements.
In this sense excluded middle is a law of the logic, while bivalence is a property of a chosen semantics.
Michael Dummett used acceptance of bivalence as the mark of realism about a subject matter.
In model theory, every sentence is true or false in a given structure, so bivalence holds relative to a structure, while a sentence can be true in one model and false in another.
