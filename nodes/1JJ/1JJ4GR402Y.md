## Example

Conditional excluded middle is the following schema.
$$(\varphi > \psi) \vee (\varphi > \neg\psi)$$
We show that it is valid in Stalnaker's semantics and invalid in Lewis's sphere semantics of [[conditional logic|ZGYG7WN7EC]].

A Stalnaker model has a set $W$ of worlds, an absurd world $\lambda$ where every formula is true, and a selection function $f$.
For each $\varphi$ and $w \in W$, the world $f(\varphi, w)$ is a $\varphi$-world, or $\lambda$ when there is no $\varphi$-world, and $f(\varphi, w) = w$ when $w$ is itself a $\varphi$-world.

1. Fix $w$ and put $z = f(\varphi, w)$.
2. If $z = \lambda$, then $\psi$ is true at $z$, so $\varphi > \psi$ is true at $w$.
3. If $z \neq \lambda$, then $z$ is a single world, and exactly one of $\psi$ and $\neg\psi$ is true at $z$.
4. In the first case $\varphi > \psi$ holds at $w$, and in the second case $\varphi > \neg\psi$ holds at $w$.
5. So the schema is true at every world of every Stalnaker model.

Now take the sphere model with worlds $w, u, v$ and spheres $\$_w = \{\{w\}, \{w, u, v\}\}$.
Let $p$ be true at $u$ and $v$ only, and $q$ at $u$ only.

6. The smallest sphere with a $p$-world is $\{w, u, v\}$.
7. At $v$, $p$ is true and $q$ is false, so $p > q$ is false at $w$.
8. At $u$, $p$ is true and $\neg q$ is false, so $p > \neg q$ is false at $w$.
9. So $(p > q) \vee (p > \neg q)$ is false at $w$, and the schema is not valid in $\mathsf{VC}$.

## Remarks

The difference is a tie.
In the sphere model, $u$ and $v$ are equally close $p$-worlds, and they disagree on $q$.
A Stalnaker selection function must break every tie, because it chooses one closest world.
If we split the outer sphere by adding $\{w, u\}$, the tie is gone, $p > q$ becomes true, and the schema holds at $w$.

Stalnaker's logic $\mathsf{C2}$ is $\mathsf{VC}$ plus conditional excluded middle.
The schema makes "might" and "would" coincide.
With it, $\neg(\varphi > \neg\psi)$ gives $\varphi > \psi$, so "it might be that $\psi$" already says "it would be that $\psi$".
Watch out: the schema is not the law $\varphi > (\psi \vee \neg\psi)$, which holds in both semantics.

## Explanations

### L1 human

Ask: "If this coin had been tossed, would it have landed heads?"
Stalnaker says that there is one nearest situation where it is tossed, so the answer is yes or no.
Lewis says that there can be several equally near situations, some with heads and some with tails.
Then neither "it would have landed heads" nor "it would have landed tails" is true.
The schema says that one of the two is always true, so Lewis rejects it.

### L2 human

In Stalnaker's semantics we compute $f(p, w)$, which is one world, and read off $q$ there.
That value decides between $p > q$ and $p > \neg q$, so one of them is true.
In Lewis's semantics we compute the first sphere that meets $p$.
It can contain $p$-worlds with $q$ and $p$-worlds without $q$, and then both conditionals fail.
The typical use of the schema is to choose between the two semantics for an application, for example the analysis of chance under a counterfactual.
