## Example

Define $f \colon \mathbb{R} \to \mathbb{R}$ by $f(x) = x^2$.
A student writes this "proof" that $f$ is [[injective|09NWETVTNY]]: "Let $f(a) = f(b)$.
Then $a^2 = b^2$.
Taking square roots, $a = b$."
We find the error and show that no correct proof exists.

1. The first line follows the template of [[proving injectivity and surjectivity|DD2P85Y8E9]], since it assumes $f(a) = f(b)$ for arbitrary $a$ and $b$.
2. The step "taking square roots" is the error.
   The square root of $a^2$ is $\lvert a \rvert$, the [[absolute value|0FFXKTKKQC]] of $a$, so $a^2 = b^2$ gives only $\lvert a \rvert = \lvert b \rvert$.
3. The correct consequence comes from factoring:
   $$a^2 - b^2 = (a - b)(a + b) = 0, \quad \text{so } a = b \text{ or } a = -b.$$
4. Nothing rules out the second case, and a [[counterexample|0ED72CTBNP]] shows that it happens: $f(-1) = 1 = f(1)$ with $-1 \ne 1$.
5. So $f$ is not injective, and no repair of the "proof" can exist.

## Remarks

The example fails the method because the step from $f(a) = f(b)$ to $a = b$ must hold for every pair, and here it fails for $a = -b \ne 0$.
Step 3 also shows how to rescue injectivity by changing the domain.
On $[0, \infty)$ the case $a = -b$ forces $a = b = 0$, so the restriction of $f$ to $[0, \infty)$ is injective.

The function is not surjective onto $\mathbb{R}$ either, since $x^2 \ge 0$ for every real $x$ and so $x^2 = -1$ has no solution.
With domain and codomain both equal to $[0, \infty)$ it becomes a bijection, and its inverse is the square root.
To disprove injectivity one pair is enough, and to disprove surjectivity one unreached value is enough.

## Explanations

### L1 human

The rule "multiply the number by itself" sends $3$ to $9$ and also sends $-3$ to $9$.
Two different numbers give the same answer, so the rule is not injective.
The student's proof went wrong when it tried to undo the squaring.
From the answer $9$ you cannot tell whether you started at $3$ or at $-3$.

### L2 human

We run the same analysis for $h(x) = x^2 - 4x$ on $\mathbb{R}$.

1. Assume $h(a) = h(b)$, so $a^2 - 4a = b^2 - 4b$ and $a^2 - b^2 - 4(a - b) = 0$.
2. Factor out $a - b$:
   $$(a - b)(a + b - 4) = 0, \quad \text{so } a = b \text{ or } a + b = 4.$$
3. The second case gives a counterexample: $h(1) = 1 - 4 = -3$ and $h(3) = 9 - 12 = -3$.
4. So $h$ is not injective on $\mathbb{R}$.
   On $[2, \infty)$ it is injective, because there $a + b = 4$ forces $a = b = 2$.

This analysis finds the largest interval on which a function has an inverse.
Watch out: dividing by $a - b$ in step 2 without treating the case $a = b$ separately, or dropping the second factor, hides exactly the information you need.
