## Example

Take the frame $\mathfrak{F} = (W, R)$ given by a path of length two:
$$W = \{ 1, 2, 3 \}, \quad R = \{ (1, 2), (2, 3) \}.$$
We compare the truth of the axiom $\mathrm{4}$, the formula $\square p \to \square\square p$, in two [[Kripke models|NGHWZ9Y7ZV]] on $\mathfrak{F}$.

1. The relation is not [[transitive|0GJZW9JFZQ]], because $1 R 2$ and $2 R 3$ hold but $1 R 3$ fails.
2. The successor sets are $R[1] = \{ 2 \}$, $R[2] = \{ 3 \}$ and $R[3] = \varnothing$.
3. In the first model, $V(p) = W$.
   Then $p$ is true everywhere, so $\square p$ is true everywhere, and so is $\square\square p$.
4. So $\square p \to \square\square p$ is true at every world of the first model.
5. In the second model, $V'(p) = \{ 2 \} = R[1]$.
   Then $\square p$ is true at $1$, since the only successor $2$ has $p$.
6. $\square p$ is false at $2$, since the successor $3$ lacks $p$.
7. $\square\square p$ is false at $1$, since the successor $2$ makes $\square p$ false.
8. So the axiom $\mathrm{4}$ fails at $1$ in the second model, and it is not valid on $\mathfrak{F}$.

## Remarks

The example separates truth in a model from validity on a frame.
The axiom $\mathrm{4}$ is valid on a frame exactly when the frame is transitive, by [[common modal axiom schemata|FDFQFWPM4X]].
That correspondence is about frames, and one model can make $\mathrm{4}$ true on a frame that is not transitive.

The set of formulas true in the first model is not closed under uniform substitution.
Add a variable $q$ with $V(q) = \{ 2 \}$ to the first model.
Then $\square p \to \square\square p$ is true in the model, but its instance $\square q \to \square\square q$ fails at $1$, by steps 5 to 7.

The choice $V'(p) = R[1]$ is the general method.
It makes $\square p$ true at $1$ with the smallest possible truth set, so it gives $\square\square p$ the best chance to fail.
If we add the pair $(1, 3)$, the frame becomes transitive, and the axiom $\mathrm{4}$ holds under every valuation.

## Explanations

### L1 human

Picture three stations on a line: from station 1 a train goes to station 2, and from station 2 a train goes to station 3.
There is no direct train from 1 to 3.
If every station has a flag, then every check of the form "all next stations have a flag" succeeds.
If only station 2 has a flag, then from station 1 all next stations have a flag, but two steps ahead there is none.
So the rule "one step implies two steps" can hold by luck, and still fail for some choice of flags.

### L2 human

We compute the truth sets in the second model, $V'(p) = \{ 2 \}$.
World $1$ sees only $2$, and world $3$ has no successors, so $[\![ \square p ]\!] = \{ 1, 3 \}$.
World $2$ sees only $3 \in [\![ \square p ]\!]$, world $1$ sees $2 \notin [\![ \square p ]\!]$, and world $3$ sees nothing, so $[\![ \square\square p ]\!] = \{ 2, 3 \}$.
The implication fails where the first set holds and the second does not:
$$[\![ \square p \to \square\square p ]\!] = W \setminus (\{ 1, 3 \} \setminus \{ 2, 3 \}) = W \setminus \{ 1 \} = \{ 2, 3 \}.$$
The typical use is a test of frame validity: try the valuation $V(p) = R[w]$ first.
Watch out: one valuation that makes a formula true proves nothing about frame validity.
