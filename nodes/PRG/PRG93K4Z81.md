## Example

The syllogism Barbara says: every $G$ is $H$, every $H$ is $D$, so every $G$ is $D$.
In first-order logic it is the sentence
$$\beta = \forall x \, (G(x) \to H(x)) \wedge \forall x \, (H(x) \to D(x)) \to \forall x \, (G(x) \to D(x)).$$
We check that $\beta$ belongs to the [[monadic predicate calculus|SERN6CRVWW]] and that it is [[valid|5SDS9T8E7J]].

1. The relation symbols $G$, $H$ and $D$ are unary, and $\beta$ has no function symbols, no constants and no equality. So $\beta$ is a monadic sentence with $k = 3$.
2. $\beta$ is valid if and only if $\neg \beta$ has no model. The sentence $\neg \beta$ is equivalent to $\forall x \, (G(x) \to H(x)) \wedge \forall x \, (H(x) \to D(x)) \wedge \exists x \, (G(x) \wedge \neg D(x))$.
3. By the [[finite model property|AS0NHQMAKA]], if $\neg \beta$ has a model, it has one with at most $2^3 = 8$ elements, one for each type. So a finite search decides the question.
4. We do the search by types. A witness $a$ of the third conjunct has $G(a)$ and not $D(a)$.
5. The first conjunct at $a$ gives $H(a)$, and the second conjunct at $a$ gives $D(a)$.
6. This contradicts step 4. So no element can witness the third conjunct, and $\neg \beta$ has no model of any size.
7. Hence $\beta$ is valid.

## Remarks

The example shows that the traditional syllogisms are monadic sentences, and that the decision procedure of the monadic fragment checks them.
If the conclusion is changed to "every $D$ is $G$", the sentence $\forall x \, (G(x) \to H(x)) \wedge \forall x \, (H(x) \to D(x)) \to \forall x \, (D(x) \to G(x))$ is not valid.
A countermodel has one element $a$ with $D(a)$, not $H(a)$ and not $G(a)$: both premises hold, and the conclusion fails at $a$.
The search for this countermodel stops at size $1$, well below the bound $8$.

## Explanations

### L1 human

The rule "every cat is a mammal, every mammal is an animal, so every cat is an animal" is always correct.
Logic writes it with three properties: being a cat, being a mammal and being an animal.
To check it, we ask whether any object could be a cat but not an animal while the two rules hold.
Such an object would be a mammal by the first rule, and then an animal by the second rule, so it cannot exist.

### L2 human

We find the eight types for $\beta$ and see which of them the premises allow.

1. A type is a choice of yes or no for $G$, $H$ and $D$, so there are $2^3 = 8$ types.
2. The premise $\forall x \, (G(x) \to H(x))$ excludes the two types with $G$ yes and $H$ no.
3. The premise $\forall x \, (H(x) \to D(x))$ excludes the two types with $H$ yes and $D$ no.
4. The allowed types are $(G, H, D) = $ (no, no, no), (no, no, yes), (no, yes, yes) and (yes, yes, yes).
5. In each allowed type, $G$ yes implies $D$ yes, so the conclusion $\forall x \, (G(x) \to D(x))$ holds in every model of the premises.

The typical use is to check an argument in words by translating it into monadic logic and counting types.
A trap is the syllogism "some $G$ is $H$, some $H$ is $D$, so some $G$ is $D$": it is not valid, since the two witnesses can be different elements.
