## Example

Over a field $F$, let
$$N_1 = J_3(0) \oplus J_3(0) \oplus J_1(0), \qquad N_2 = J_3(0) \oplus J_2(0) \oplus J_2(0),$$
two $7 \times 7$ sums of nilpotent [[Jordan blocks|0PBFS92AJP]].

1. Both matrices are upper triangular with zero diagonal, so $\chi_{N_1} = \chi_{N_2} = x^7$.
2. The largest block in both is $J_3(0)$, so $N_1^3 = N_2^3 = 0$ and $N_1^2 \ne 0 \ne N_2^2$. Hence both [[minimal polynomials|03NDVCSHSB]] are $x^3$.
3. $\operatorname{rank} J_k(0) = k - 1$, and ranks add over blocks. So $\operatorname{rank} N_1 = 2 + 2 + 0 = 4$ and $\operatorname{rank} N_2 = 2 + 1 + 1 = 4$.
4. So $\dim \ker N_1 = \dim \ker N_2 = 3$, and both have $3$ Jordan blocks.
5. $\operatorname{rank} J_k(0)^2 = \max(k - 2, 0)$. So $\operatorname{rank} N_1^2 = 1 + 1 + 0 = 2$ and $\operatorname{rank} N_2^2 = 1 + 0 + 0 = 1$.
6. [[Similar|027KDW2K72]] matrices have similar squares, and so equal ranks of squares. So $N_1$ and $N_2$ are not similar.

## Remarks

The characteristic polynomial, the minimal polynomial, the rank and the number of Jordan blocks are all similarity invariants, but even together they do not decide similarity.
A complete set of invariants is the list of ranks of $(A - \lambda I)^k$ for all eigenvalues $\lambda$ and all $k$, by the uniqueness part of the [[Jordan normal form|085HQ5G5TE]].
For nilpotent matrices of size at most $3$, the characteristic and minimal polynomials do decide similarity.

## Explanations

### L1 human

Two matrices can agree in several numbers and still not be similar.
Here the squares of the two matrices have different ranks.

### L2 human

The Jordan partitions are $(3, 3, 1)$ and $(3, 2, 2)$.
They have the same sum $7$, the same largest part $3$, and the same number of parts $3$.
These are exactly the data of $\chi$, $\mu$ and the rank, so these data cannot tell the two partitions apart.
