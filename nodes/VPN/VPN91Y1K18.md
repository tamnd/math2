## Example

Dropping a coordinate is linear, but it lands in a different space, so it is not an endomorphism.
Let $P \colon \R^3 \to \R^2$ be the map $P(x, y, z) = (x, y)$.

1. The map $P$ is [[linear|0RJF668P1T]], since it is $v \mapsto Bv$ for the $2 \times 3$ matrix $B = \begin{pmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \end{pmatrix}$.
2. The source of $P$ is $\R^3$ and its target is $\R^2$, and these spaces differ, so $P$ is not an [[endomorphism|0PTF1PTJK0]].
3. The composite $P \circ P$ is not defined, since $P(v) \in \R^2$ is not in the source $\R^3$.
4. In matrix terms, $B$ is not square, so $B^2$ is not defined.

## Remarks

If we change the target, the related map $Q \colon \R^3 \to \R^3$, $Q(x, y, z) = (x, y, 0)$, is an endomorphism.
It is a [[projection|033DA1WE8Y]], with $Q^2 = Q$.
The maps $P$ and $Q$ agree in the first two coordinates, and only the target differs, but the target decides whether a map is an endomorphism.
A linear map between two different spaces of the same dimension, such as $P_2 \to \R^3$, is not an endomorphism either.

## Explanations

### L1 human

Dropping the third coordinate sends space to the plane.
The result lives in a different space, so the map cannot be applied a second time.
That is why it is not an endomorphism.

### L2 human

To decide whether $T$ is an endomorphism, compare its source and its target, not its formula.
Writing the same rule as $(x, y, z) \mapsto (x, y, 0)$ with target $\R^3$ gives an endomorphism of $\R^3$.
Watch out: when a map is given only by a formula, check which target is meant.
