## Summary

The nucleus of a [[nonassociative algebra|60W3THKGA7]] is the set of elements that associate with all other elements, in every position of a triple product.
In terms of the [[associator|RT4YV20367]], it consists of the elements $n$ with $(n, x, y) = (x, n, y) = (x, y, n) = 0$ for all $x, y$.
It is an associative subalgebra, and it equals the whole algebra exactly when the algebra is associative.
So its size measures how much associativity is left in the algebra.

## Explanations

### L1 human

In a nonassociative algebra some elements may still behave well with respect to brackets.
An element is in the nucleus if moving brackets around it never changes a product of three factors.
In the octonions only the real multiples of $1$ have this property.
In an associative algebra every element does.
