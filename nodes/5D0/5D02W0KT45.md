## Example

The *logic of paradox* LP of Graham Priest is a [[many-valued logic|66NMTCQNQV]] with three truth values.
They are $\mathsf{T}$ (true only), $\mathsf{B}$ (both true and false) and $\mathsf{F}$ (false only), ordered as $\mathsf{F} < \mathsf{B} < \mathsf{T}$.
A valuation $v$ gives each variable one of the three values, and it extends to all formulas by two rules.
Negation swaps $\mathsf{T}$ and $\mathsf{F}$ and keeps $\mathsf{B}$.
A conjunction gets the smaller of the two values, and a disjunction gets the larger.

The values $\mathsf{T}$ and $\mathsf{B}$ are *designated*.
A set $\Gamma$ derives $\varphi$ in LP, written $\Gamma \vDash_{\mathrm{LP}} \varphi$, when every valuation that designates all members of $\Gamma$ also designates $\varphi$.
LP is given by this semantics, so here "derives" means $\vDash_{\mathrm{LP}}$.

Let $\Gamma = \{ p, \lnot p \}$.
We show that $\Gamma$ is inconsistent in the simple sense but [[Post consistent|WK2P0E82B4]].

1. $\Gamma \vDash_{\mathrm{LP}} p$ and $\Gamma \vDash_{\mathrm{LP}} \lnot p$, because $p$ and $\lnot p$ are members of $\Gamma$.
   So $\Gamma$ derives a formula and its negation, and $\Gamma$ is not [[consistent|VM8TQ70CVJ]] in the simple sense.
2. A valuation designates $p$ and $\lnot p$ only when $v(p) = \mathsf{B}$.
   If $v(p) = \mathsf{T}$, then $v(\lnot p) = \mathsf{F}$, and if $v(p) = \mathsf{F}$, then $p$ is not designated.
3. Let $q$ be another variable, and take the valuation $v(p) = \mathsf{B}$, $v(q) = \mathsf{F}$.
4. Then $v(p) = \mathsf{B}$ and $v(\lnot p) = \mathsf{B}$ are designated, so $v$ designates all of $\Gamma$.
5. But $v(q) = \mathsf{F}$ is not designated, so $\Gamma \not\vDash_{\mathrm{LP}} q$.
6. So some formula is not derivable from $\Gamma$, and $\Gamma$ is Post consistent.

## Remarks

The equivalence of "consistent" and "not every formula is derivable" depends on [[explosion|TTKZGJEEK7]], the rule from $\varphi$ and $\lnot\varphi$ to any $\psi$.
LP is a [[paraconsistent logic|C7YWCR87QJ]]: by steps 3 to 5, explosion fails in it.

The theory still derives some formulas outside $\Gamma$.
Every valuation that designates $p$ designates $p \lor q$, so $\Gamma \vDash_{\mathrm{LP}} p \lor q$.
It also derives $p \land \lnot p$, because every valuation that designates $\Gamma$ has $v(p) = \mathsf{B}$, and then $v(p \land \lnot p) = \mathsf{B}$.

If we replace LP by classical logic, which uses only the values $\mathsf{T}$ and $\mathsf{F}$, then no valuation designates both $p$ and $\lnot p$.
So in classical logic $\Gamma$ derives every formula.
The step that changes is step 3, since the value $\mathsf{B}$ is not available.

## Explanations

### L1 human

Imagine a database that has stored both "the door is open" and "the door is not open" by mistake.
A careless reasoner would conclude anything at all from it, for example that the moon is made of cheese.
The logic of paradox allows a third value, "both", for such a statement.
With this value, the two stored claims are both accepted, but an unrelated claim such as "the light is on" does not follow.
So the database is contradictory but not useless.

### L2 human

We check that $\Gamma = \{ p, \lnot p \}$ does not derive $\lnot q$ either.

1. Take $v(p) = \mathsf{B}$ and $v(q) = \mathsf{T}$.
2. Then $v(\lnot p) = \mathsf{B}$, so both members of $\Gamma$ are designated.
3. And $v(\lnot q) = \mathsf{F}$, which is not designated.
4. So $\Gamma \not\vDash_{\mathrm{LP}} \lnot q$.

The typical use of LP is to reason with inconsistent data without collapse.
A trap is to think that LP changes only the conclusions drawn from a contradiction.
It also loses disjunctive syllogism: $\{ p, \lnot p \lor q \}$ does not derive $q$.
The valuation $v(p) = \mathsf{B}$, $v(q) = \mathsf{F}$ shows this, since then $v(\lnot p \lor q) = \mathsf{B}$.
