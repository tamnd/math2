## Example

Let $\mathrm{REC}$ be the family of [[computable sets|PPGD5KW8JC]] of natural numbers, and let $\mathcal{R} = (\mathbb{N}, \mathrm{REC})$ be the $\omega$-structure whose sets are the computable sets.
We check which axioms of [[second-order arithmetic|DC60FYCSPM]] hold in $\mathcal{R}$, and we find one comprehension instance that fails.

1. The basic axioms hold in $\mathcal{R}$, because its number part is the standard structure $\mathbb{N}$.
2. The induction axiom holds in $\mathcal{R}$.
   It is true for every subset of $\mathbb{N}$, so in particular for every computable set.
3. Let $T(e, x, s)$ be the [[Kleene T predicate|S9DK13K5PS]].
   It is primitive recursive, so it is defined by a formula $\theta(e, x, s)$ of $L_2$ with only bounded quantifiers and no set variables.
4. Take the formula $\varphi(e) := \exists s \, \theta(e, e, s)$.
   It is $\Sigma^0_1$, and it has no set quantifiers and no set parameters.
5. Since the number part is standard, $\varphi(e)$ holds in $\mathcal{R}$ exactly when program $e$ halts on input $e$.
6. The comprehension instance for $\varphi$ asks for a set $X \in \mathrm{REC}$ with $e \in X \leftrightarrow \varphi(e)$ for all $e$.
   The only such subset of $\mathbb{N}$ is the halting set $K = \{ e : \text{program } e \text{ halts on input } e \}$.
7. $K$ is not computable, by the [[undecidability of the halting problem|Z7TN2B35B0]], so $K \notin \mathrm{REC}$.

So the comprehension scheme fails in $\mathcal{R}$, and $\mathcal{R}$ is not a model of $\mathsf{Z}_2$.

## Remarks

The failure comes from one unbounded number quantifier.
If $\varphi$ is $\Sigma^0_1$ and $\mathcal{R}$ also satisfies a $\Pi^0_1$ formula equivalent to $\varphi$, then the set that $\varphi$ defines is computable.
The reason is that we can search for a witness of $\varphi$ and a witness of its negation at the same time, and one of the two searches ends.
So $\mathcal{R}$ satisfies comprehension for $\Delta^0_1$ formulas, and it is a model of the base system [[RCA0|XQENB067R3]].
It is even the [[least ω-model of RCA0|F5T3F7E0H1]].

The failing instance uses an arithmetical formula, so $\mathcal{R}$ is not a model of the subsystem $\mathsf{ACA}_0$ either.
Adding $K$ alone does not repair the structure: the family $\mathrm{REC} \cup \{K\}$ is [[not a model of RCA0|ZMVX86T0XK]], because it is not closed under joins.

## Explanations

### L1 human

Keep only the sets that a computer can decide.
Then the theory can still describe the set of programs that halt when they are given their own number.
No computer decides this set, so the set is missing from the family.
So the rule "each property gives a set" fails.

### L2 human

The check isolates the axiom that fails.
The basic axioms and the set induction axiom survive in every $\omega$-structure, and only comprehension breaks.
This is the general pattern: two $\omega$-models differ only in which sets they contain, so they differ only in comprehension instances.

Watch out: it is wrong to say that $\mathcal{R}$ fails induction.
The single set induction axiom is true in every $\omega$-structure.
Even the induction scheme for every $L_2$ formula is true in $\mathcal{R}$, because its numbers are the standard numbers.
Induction can fail only in models with non-standard numbers.
