## Example

Let $\mathrm{REC}$ be the family of [[computable sets|PPGD5KW8JC]] of natural numbers.
Let $\mathcal{R} = (\N, \mathrm{REC})$ be the $\omega$-structure whose sets are the computable sets.
We check that $\mathcal{R}$ is not a model of [[second-order arithmetic|DC60FYCSPM]].

1. The basic axioms hold in $\mathcal{R}$, since its number part is the standard structure $\N$.
2. The induction axiom holds in $\mathcal{R}$. It holds for every subset of $\N$, so it holds for each computable set.
3. Let $T(e, x, s)$ be the [[Kleene T predicate|S9DK13K5PS]]. It is primitive recursive, so it is defined by a $\Sigma^0_1$ formula $\theta(e, x, s)$ of $L_2$ without set variables.
4. Take $\varphi(e) := \exists s\, \theta(e, e, s)$. It has no set quantifiers and no set parameters.
5. In $\mathcal{R}$, $\varphi(e)$ holds exactly when program $e$ halts on input $e$, because the number part is standard.
6. An instance of comprehension asks for $X \in \mathrm{REC}$ with $e \in X \leftrightarrow \varphi(e)$ for all $e$.
7. That $X$ is the set $K = \set{e : \text{program } e \text{ halts on input } e}$.
8. $K$ is not computable, by the [[undecidability of the halting problem|Z7TN2B35B0]]. So no such $X$ exists in $\mathrm{REC}$.
9. So the comprehension scheme fails in $\mathcal{R}$, and $\mathcal{R}$ is not a model of $\mathsf{Z}_2$.

## Remarks

The failure comes from one unbounded number quantifier.
If $\varphi$ is $\Sigma^0_1$ and its negation is equivalent in $\mathcal{R}$ to a $\Sigma^0_1$ formula, then the set it defines is computable.
So $\mathcal{R}$ satisfies comprehension for $\Delta^0_1$ formulas, and $\mathcal{R}$ is a model of the subsystem $\mathsf{RCA}_0$.
It is the least $\omega$-model of $\mathsf{RCA}_0$.

## Explanations

### L1 human

Take only the sets that a computer can decide.
Then the theory can describe the set of programs that halt on their own number.
No computer decides this set, so the set is missing.
So the rule "each property gives a set" fails.

### L2 human

The argument isolates which axiom fails: the basic axioms and the set induction axiom survive, and only comprehension breaks.
The failing instance uses a $\Sigma^0_1$ formula, so $\mathcal{R}$ is not a model of the subsystem $\mathsf{ACA}_0$ either.
A trap is to say that $\mathcal{R}$ fails induction: the single set induction axiom is true in every $\omega$-structure.
