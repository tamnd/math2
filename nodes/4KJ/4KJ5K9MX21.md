## Example

A real sequence $(a_n)$ is [[bounded|0A8JNBGT2Z]] if there is $M > 0$ such that $|a_n| \le M$ for all $n$.
The definition has two bounded [[quantifiers|EGTZPA6QH3]], "there is $M > 0$" and "for all $n \in \mathbb{N}$".
We write it with symbols and apply it to $a_n = (-1)^n$.

1. In symbols the definition is
   $$\exists M > 0 \;\; \forall n \in \mathbb{N} \;\; |a_n| \le M.$$
2. The quantifier "$\exists M > 0$" is short for "there is a real $M$ such that $M > 0$ and".
   The quantifier "$\forall n \in \mathbb{N}$" is short for "for every $n$, if $n \in \mathbb{N}$, then".
3. The existential quantifier comes first, so one number $M$ must work for all $n$ at once.
4. For $a_n = (-1)^n$ take $M = 1$.
   For every $n$ we have $|a_n| = |(-1)^n| = 1 \le 1$.
5. So $M = 1$ meets the condition, and the sequence $(-1)^n$ is bounded.

## Remarks

The [[order of quantifiers|0FYQMKFE77]] matters here.
With the quantifiers swapped, the statement reads "for every $n$ there is $M > 0$ with $|a_n| \le M$".
This statement is true for every real sequence: for each $n$ take $M = |a_n| + 1$.
So it holds even for $a_n = n$, which is not bounded.

The negation follows the rules for quantifiers: $(a_n)$ is unbounded if for every $M > 0$ there is $n$ with $|a_n| > M$.
For $a_n = n$ and a given $M > 0$, any integer $n > M$ works.
The domain of the bounded quantifier also matters.
Dropping "$M > 0$" and allowing every real $M$ changes nothing, since a negative $M$ never works.
Restricting to $M < 1$ would change the definition, and then $(-1)^n$ would not count as bounded.

## Explanations

### L1 human

A list of numbers is bounded if one fence keeps every number of the list between $-M$ and $M$.
The list $-1, 1, -1, 1, \ldots$ is bounded, because the fence at $1$ works for all of them.
The list $1, 2, 3, 4, \ldots$ is not bounded, because every fence is passed by some later number.
The words "one fence for every number" carry the two quantifiers.

### L2 human

Check whether $a_n = \dfrac{n}{n + 1}$ is bounded, and let the quantifiers guide the proof.
The goal starts with "$\exists M > 0$", so we must name one $M$ first; try $M = 1$.
Next comes "$\forall n$", so let $n \in \mathbb{N}$ be arbitrary.
Since $0 \le n < n + 1$, dividing by $n + 1 > 0$ gives
$$0 \le \frac{n}{n + 1} < 1,$$
so $|a_n| \le 1$.
The $n$ was arbitrary, so $M = 1$ works for all $n$, and the sequence is bounded.

An existential quantifier asks for a specific object, and a universal quantifier asks for an arbitrary one, in the order in which they appear.
Watch out: a student who chooses $M$ after $n$, for example $M = |a_n|$, proves only the swapped statement, which every sequence satisfies.
