## Definition

Let $C$ be a [[linear code|E85KREWV60]] of length $n$ over the finite field $\F_q$.
The code $C$ is *cyclic* if for every codeword $(c_0, c_1, \dots, c_{n-1}) \in C$ the cyclic shift $(c_{n-1}, c_0, \dots, c_{n-2})$ is also in $C$.

## Remarks

Identify the word $(c_0, \dots, c_{n-1})$ with the class of $c_0 + c_1 x + \cdots + c_{n-1} x^{n-1}$ in the [[quotient ring|0076HWHGHQ]] $R_n = \F_q[x]/(x^n - 1)$ of the [[polynomial ring|0SDC934R52]].
The cyclic shift becomes multiplication by $x$, because $x^n = 1$ in $R_n$.
So a linear code is cyclic if and only if it is an [[ideal|096Z9MP2ME]] of $R_n$.
Each ideal of $R_n$ is [[principal|0SVYSP8HCG]], generated by a unique monic polynomial $g(x)$ dividing $x^n - 1$, the generator polynomial, and then $\dim C = n - \deg g$.
Example: over $\F_2$, $g(x) = 1 + x + x^3$ divides $x^7 - 1$, and the cyclic code it generates is a $[7, 4, 3]$ Hamming code.
For a direct check of the definition, the even-weight code $\set{000, 110, 011, 101}$ is cyclic, since a shift does not change the weight; it is generated by $g(x) = 1 + x$.
Non-example: the linear code $\set{000, 100}$ is not cyclic, since the shift of $100$ is $010$, which is not in the code.
