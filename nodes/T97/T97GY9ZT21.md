## Example

Russell's paradox shows that the sets that are not members of themselves do not form a set.
Plural logic can still speak about all of them together, and no contradiction follows.

We work in [[plural logic|DZVEFDYYZX]] over the domain of all sets of [[Zermelo–Fraenkel set theory|0HE5WDQ9FJ]], with the membership relation $\in$.
Plural comprehension gives, for each formula $\varphi(y)$ in which $xx$ is not free, this axiom:
$$\exists y \, \varphi(y) \to \exists xx \, \forall y \, \big( y \prec xx \leftrightarrow \varphi(y) \big).$$
We apply it to $\varphi(y) = (y \notin y)$, the formula of [[Russell's paradox|0HESMMSYEG]].

1. The empty set has no members, so $\emptyset \notin \emptyset$.
   So $\exists y \, (y \notin y)$ is true.
2. By comprehension there are some sets $rr$ with $\forall y \, (y \prec rr \leftrightarrow y \notin y)$.
   They are exactly the sets that are not members of themselves.
3. By the [[axiom of regularity|NFQ9FVCP31]], no set is a member of itself.
   So every set is one of $rr$.
4. Suppose that some set $r$ has exactly $rr$ as its members, that is, $\forall y \, (y \in r \leftrightarrow y \prec rr)$.
5. Step 4 with $y = r$, and then step 2 with $y = r$, give this chain:
   $$r \in r \iff r \prec rr \iff r \notin r.$$
   This is a contradiction.
6. So there are some sets that are exactly the sets that are not members of themselves, and no set has exactly them as members.

Check: step 5 uses only steps 2 and 4.
So the contradiction refutes the set $r$ of step 4, not the plurality $rr$ of step 2.

## Remarks

The example shows how plural logic avoids Russell's paradox.
Comprehension gives some things, and no axiom gives an object whose members are exactly these things.
Russell's argument in step 5 needs such an object, and it proves only that none exists.
The formula $rr \prec rr$ is not even well formed, because the left place of $\prec$ takes a singular term.

In naive set theory, the move from step 2 to an object is the unrestricted comprehension axiom, and that axiom is what fails.
The plurality $rr$ is what [[von Neumann–Bernays–Gödel set theory|JTPZ1HZ9KK]] treats as a proper class, but here there is no class object.
If we replace $\varphi(y)$ by $y \notin y \land y \in a$ for a set $a$, the separation axiom gives a set with these members.
The argument then shows only that this set is not a member of $a$.

## Explanations

### L1 human

Some collections are too large to be a single set, such as "all sets that are not members of themselves".
Russell showed that if we treat this collection as one set, we get a contradiction.
Plural logic still lets us talk about these sets together: "there are some sets that are exactly the sets not members of themselves".
The sentence is about many sets at once, and it does not claim that they form one new set.
So the contradiction does not arise.

### L2 human

We run the same argument for $\varphi(y) = (y \notin y \land y \in a)$ with $a = \set{ \emptyset, \set{\emptyset} }$.

1. Neither member of $a$ is a member of itself, so the sets that satisfy $\varphi$ are $\emptyset$ and $\set{\emptyset}$.
2. Comprehension gives some sets $xx$ that are exactly $\emptyset$ and $\set{\emptyset}$.
3. Here a set with exactly these members exists, namely $a$ itself.
4. Russell's argument with $r = a$ gives this equivalence:
   $$a \in a \iff (a \notin a \land a \in a).$$
5. Since $a \notin a$, both sides are false, and there is no contradiction.

The typical use of the example is the plural reading of proper classes in set theory.
Watch out: plural comprehension is not set comprehension in disguise, because it never says that a set or a class exists.
