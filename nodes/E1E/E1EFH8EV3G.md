## Example

Let $\mathbb{Q}$ be the [[rational numbers|0NCJ5WXN6Z]] under addition.
In an abelian group written additively, the [[subgroup generated|0RP7VWQ0YN]] by $q_1, \ldots, q_n$ is
$$\langle q_1, \ldots, q_n \rangle = \{c_1 q_1 + \cdots + c_n q_n : c_1, \ldots, c_n \in \mathbb{Z}\}.$$
For a positive integer $b$, let $\tfrac{1}{b}\mathbb{Z} = \{c / b : c \in \mathbb{Z}\}$ be the set of integer multiples of $1/b$.
It is the cyclic subgroup $\langle 1/b \rangle$ of $\mathbb{Q}$.
We check three properties.

1. Common denominator: let $q_1, \ldots, q_n \in \mathbb{Q}$. Write $q_i = a_i / b_i$ with $a_i, b_i \in \mathbb{Z}$ and $b_i \geq 1$, and put $b = b_1 b_2 \cdots b_n$. Then $q_i = (a_i b / b_i) / b$, and $b / b_i$ is an integer, so $q_i \in \tfrac{1}{b}\mathbb{Z}$.
2. The subgroup $\tfrac{1}{b}\mathbb{Z}$ contains each $q_i$, so it contains $\langle q_1, \ldots, q_n \rangle$.
3. Not [[finitely generated|082DWWXMRJ]]: suppose $1/(2b) \in \tfrac{1}{b}\mathbb{Z}$. Then $1/(2b) = c/b$ for an integer $c$, so $1 = 2c$, which is impossible. So $1/(2b) \notin \langle q_1, \ldots, q_n \rangle$, and no finite set generates $\mathbb{Q}$.
4. Not [[cyclic|0KVGH0J5B3]]: a cyclic group is generated by one element, so it is finitely generated. By step 3, $\mathbb{Q}$ is not cyclic.
5. [[Locally cyclic|RXWA8TF2RM]]: a group is locally cyclic when each finitely generated subgroup is cyclic. By step 2, $\langle q_1, \ldots, q_n \rangle$ is a subgroup of the cyclic group $\langle 1/b \rangle$. [[Each subgroup of a cyclic group is cyclic|0KB1ND7XDS]], so $\langle q_1, \ldots, q_n \rangle$ is cyclic.

So $\mathbb{Q}$ is locally cyclic, but it is not finitely generated and not cyclic.

## Remarks

The example shows that "locally cyclic" is weaker than "cyclic".
For a finitely generated group, the two conditions agree: the group is one of its own finitely generated subgroups.
So each locally cyclic group that is not cyclic is not finitely generated, like $\mathbb{Q}$.

Step 5 can be made explicit.
With the common denominator $b$, write $q_i = m_i / b$ with $m_i \in \mathbb{Z}$, and let $g = \gcd(m_1, \ldots, m_n)$.
By [[Bézout's identity|0DQVHMYAGA]], $g = c_1 m_1 + \cdots + c_n m_n$ for some integers $c_i$.
So $g/b = c_1 q_1 + \cdots + c_n q_n$ lies in $\langle q_1, \ldots, q_n \rangle$.
Also each $q_i = (m_i/g) \cdot (g/b)$ is an integer multiple of $g/b$.
So $\langle q_1, \ldots, q_n \rangle = \langle g / b \rangle$.
For example, $\langle \tfrac{1}{2}, \tfrac{1}{3} \rangle = \langle \tfrac{3}{6}, \tfrac{2}{6} \rangle = \langle \tfrac{1}{6} \rangle$, because $\tfrac{1}{2} - \tfrac{1}{3} = \tfrac{1}{6}$.

Each subgroup of $\mathbb{Q}$ is locally cyclic, and so is each quotient, for example $\mathbb{Q}/\mathbb{Z}$.
The multiplicative group $\mathbb{Q}_{>0}$ of positive rationals behaves in a different way.
The subgroup $\langle 2, 3 \rangle$ is not cyclic: by unique factorization, $2^x 3^y = 1$ only when $x = y = 0$, so $\langle 2, 3 \rangle \cong \mathbb{Z} \times \mathbb{Z}$.
So $(\mathbb{Q}_{>0}, \cdot)$ is not locally cyclic.

## Explanations

### L1 human

Take any two fractions, for example $\tfrac{1}{2}$ and $\tfrac{1}{3}$.
Their difference is $\tfrac{1}{6}$, and both fractions are whole multiples of $\tfrac{1}{6}$.
So the fractions that we can make from $\tfrac{1}{2}$ and $\tfrac{1}{3}$ with sums and differences are the multiples of the single fraction $\tfrac{1}{6}$.
This works for any finite list of fractions: one fraction is enough to make all of them.
But no finite list makes all fractions.
The multiples of $\tfrac{1}{6}$ never give $\tfrac{1}{12}$.

### L2 human

We find a single generator of $H = \langle \tfrac{3}{4}, \tfrac{5}{6} \rangle$.

1. The common denominator is $12$: $\tfrac{3}{4} = \tfrac{9}{12}$ and $\tfrac{5}{6} = \tfrac{10}{12}$.
2. $\gcd(9, 10) = 1$, and $10 - 9 = 1$.
3. So $\tfrac{5}{6} - \tfrac{3}{4} = \tfrac{1}{12} \in H$.
4. Both generators are multiples of $\tfrac{1}{12}$, so $H = \langle \tfrac{1}{12} \rangle$, a cyclic group.
5. The number $\tfrac{1}{24}$ is not in $H$, because $\tfrac{1}{24} = \tfrac{c}{12}$ gives $c = \tfrac{1}{2}$.

The typical use of this example is to separate two conditions that agree for finitely generated groups.
The group $\mathbb{Q}$ is the standard example of a locally cyclic group that is not cyclic.

A trap: $\mathbb{Q}$ is generated by the infinite set $\{1/n : n \geq 1\}$, and each finite part of this set generates a cyclic group.
This does not make $\mathbb{Q}$ cyclic.
A union of an increasing chain of cyclic groups need not be cyclic.
