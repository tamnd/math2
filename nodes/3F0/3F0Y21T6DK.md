## Example

A theorem of the form "for every $n$ there is $m$" proved with infinite sets in $\mathsf{WKL}_0$ comes with a primitive recursive program that finds $m$.
We follow this for the infinitude of the primes.
Let $\theta(n, p)$ be the following $\Delta^0_0$ formula, whose quantifiers are all bounded, as in the [[arithmetical hierarchy|GE43CSZTS9]].
$$p > n \wedge p > 1 \wedge \forall a \le p\, \forall b \le p\, (a \cdot b = p \rightarrow a = 1 \vee b = 1)$$
So $\forall n\, \exists p\, \theta(n, p)$ says that there are infinitely many primes.

1. [[WKL0|K5YPW1NTHZ]] proves $\forall n\, \exists p\, \theta(n, p)$.
   Euclid's proof already works in $\mathsf{RCA}_0$: the least divisor $p > 1$ of $n! + 1$ is prime, and it is larger than $n$, since no number among $2, \ldots, n$ divides $n! + 1$.
2. The sentence is $\Pi^0_2$ with a $\Delta^0_0$ matrix, so the [[conservation theorem|V609D9SZ05]] applies.
3. It gives a primitive recursive function $f$ with $\mathsf{PRA} \vdash \theta(n, f(n))$.
4. In this case one such $f$ is visible: $f(n)$ is the least $p$ with $1 < p \le n! + 1$ and $p \mid n! + 1$.
   It is primitive recursive, because the search is bounded by the primitive recursive function $n! + 1$.
5. [[Primitive recursive arithmetic|330YAP9Y4Q]] proves $\theta(n, f(n))$ by the argument of step 1, with $f(n)$ in place of the least divisor.

## Remarks

The point of the theorem is that step 3 holds for every $\Pi^0_2$ theorem of $\mathsf{WKL}_0$.
It holds even when the proof uses a path through an infinite binary tree, which no primitive recursive function can compute in general.
The ideal proof still yields a primitive recursive witness function and a finitistic proof of each instance.
Watch out: the witness from the conservation theorem need not be the least witness, or the one a mathematician would pick.
It is only some primitive recursive function that $\mathsf{PRA}$ can verify.

## Explanations

### L1 human

The statement "for every $n$ there is a prime above $n$" has a proof in $\mathsf{WKL}_0$.
The conservation theorem promises a simple program that finds such a prime.
Here the program is: search the divisors of $n! + 1$, and return the smallest one above $1$.

### L2 human

Compute $f(n)$ for small $n$.

1. For $n = 3$, $3! + 1 = 7$, and the least divisor above $1$ is $7$, so $f(3) = 7$.
2. For $n = 4$, $4! + 1 = 25 = 5 \cdot 5$, so $f(4) = 5$.
3. For $n = 5$, $5! + 1 = 121 = 11 \cdot 11$, so $f(5) = 11$.

Check: $7 > 3$, $5 > 4$ and $11 > 5$, and each value is prime.
The typical use of the conservation theorem is to extract such bounds and programs from proofs that use compactness.
The trap: $f(n)$ need not be the next prime after $n$, since $f(5) = 11$ skips $7$.
