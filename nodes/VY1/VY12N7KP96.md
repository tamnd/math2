## Example

Let $d$ and $t$ be the maps of the real line with $d(x) = 2x$ and $t(x) = x + 1$.
Both are bijections, so they lie in the group of all bijections $\mathbb{R} \to \mathbb{R}$ under composition, where $fg$ means "first $g$, then $f$".
Let $G = \langle d, t \rangle$.
Let $\mathbb{Z}[\tfrac{1}{2}] = \{m / 2^j : m \in \mathbb{Z}, \ j \geq 0\}$ be the set of dyadic rationals, a subgroup of $(\mathbb{Q}, +)$.
For $r \in \mathbb{R}$, let $\tau_r$ be the translation $x \mapsto x + r$.
We show that $G$ is a [[finitely generated group|082DWWXMRJ]] with a subgroup that is not finitely generated.

1. Finitely generated: $G$ is generated by the finite set $\{d, t\}$, by its definition.
2. Let $A$ be the set of maps $x \mapsto 2^k x + r$ with $k \in \mathbb{Z}$ and $r \in \mathbb{Z}[\tfrac{1}{2}]$. The composition of $x \mapsto 2^k x + r$ after $x \mapsto 2^l x + u$ is $x \mapsto 2^{k + l} x + (2^k u + r)$, and $2^k u + r \in \mathbb{Z}[\tfrac{1}{2}]$.
3. The inverse of $x \mapsto 2^k x + r$ is $x \mapsto 2^{-k} x - 2^{-k} r$, and $2^{-k} r \in \mathbb{Z}[\tfrac{1}{2}]$. With step 2 and the identity map $x \mapsto 2^0 x + 0$, this shows that $A$ is a group.
4. $A$ contains $d$ and $t$, so $G \subseteq A$.
5. Conversely, let $m \in \mathbb{Z}$ and $j \geq 0$. Then $d^{-j} t^m d^j (x) = 2^{-j}(2^j x + m) = x + m / 2^j$. So $\tau_r \in G$ for each $r \in \mathbb{Z}[\tfrac{1}{2}]$.
6. The map $x \mapsto 2^k x + r$ equals $\tau_r d^k$, so it lies in $G$. By steps 4 and 5, $G = A$.
7. Let $T = \{\tau_r : r \in \mathbb{Z}[\tfrac{1}{2}]\}$. By step 5, $T \subseteq G$, and $\tau_r \tau_u = \tau_{r + u}$ and $\tau_r^{-1} = \tau_{-r}$. So $T$ is a subgroup of $G$, and $\tau_r \mapsto r$ is an isomorphism from $T$ to $(\mathbb{Z}[\tfrac{1}{2}], +)$.
8. $T$ is not finitely generated. Let $\tau_{r_1}, \ldots, \tau_{r_n} \in T$, and choose $J$ with $2^J r_i \in \mathbb{Z}$ for all $i$. Each element of $\langle \tau_{r_1}, \ldots, \tau_{r_n} \rangle$ is $\tau_r$ with $r$ an integer multiple of $1/2^J$.
9. If $1/2^{J+1} = c / 2^J$ with $c \in \mathbb{Z}$, then $1 = 2c$, which is impossible. So $\tau_{1/2^{J+1}}$ is not in the subgroup of step 8, and the finite set does not generate $T$.

So $G$ is finitely generated, and its subgroup $T$ is not.

## Remarks

The example shows that "finitely generated" does not pass to subgroups, even for a small group with two generators.
Here $G$ is not abelian: $dt(x) = 2x + 2$, but $td(x) = 2x + 1$.
For abelian groups this cannot happen, because each subgroup of a [[finitely generated abelian group|RQNAAJF6XY]] is finitely generated.

The subgroup $T$ is [[normal|0CB0DX5BVV]] in $G$.
The map $(x \mapsto 2^k x + r) \mapsto k$ is a homomorphism from $G$ onto $(\mathbb{Z}, +)$, by step 2, and its kernel is $T$.
So $G/T \cong \mathbb{Z}$, and $T$ has infinite index in $G$.
This agrees with the fact that a subgroup of finite index in a finitely generated group is finitely generated.

The group $G$ is a subgroup of the [[affine group|G6GMSEZDB1]] of the real line.
The generators satisfy $d t d^{-1} = t^2$, because $d t d^{-1}(x) = 2(x/2 + 1) = x + 2$.
This relation gives a presentation of $G$, and $G$ is the [[Baumslag-Solitar group|429JJ5ZNBY]] $BS(1, 2)$.
If we replace $2$ by an integer $n \geq 2$, the same steps give the group $BS(1, n)$ with the subgroup $\mathbb{Z}[\tfrac{1}{n}]$, which is again not finitely generated.

## Explanations

### L1 human

We use two moves on the number line: "double the number" and "add $1$".
We can also undo them: "halve the number" and "subtract $1$".
If we halve, then add $1$, then double, the total effect is "add $2$".
If we double, add $1$ and halve, the total effect is "add $\tfrac{1}{2}$".
In the same way we can add $\tfrac{1}{4}$, $\tfrac{1}{8}$ and every fraction with a power of $2$ below the line.
So two moves give infinitely many shifts, and no finite list of shifts gives all of them.

### L2 human

We find the moves that give the shift by $\tfrac{3}{4}$, with $j = 2$ and $m = 3$ in step 5.

1. $d^2(x) = 4x$.
2. $t^3 d^2 (x) = 4x + 3$.
3. $d^{-2} t^3 d^2(x) = (4x + 3)/4 = x + \tfrac{3}{4}$.
4. So $\tau_{3/4} = d^{-2} t^3 d^2$, a product of $7$ generators and inverses of generators.

The typical use of this example is as a counterexample.
When a proof needs "a subgroup of a finitely generated group is finitely generated", this group shows that an extra hypothesis is necessary, for example finite index or commutativity.

A trap: each translation $\tau_r$ is a product of the two generators $d$ and $t$, but this does not make $T$ finitely generated.
The products use $d$, which is not in $T$.
A finite set of translations generates only the translations by the multiples of one number $1/2^J$.
