## Summary

An **amenable number** is a positive [[integer|0C4JS9RF5M]] for which there exists a [[multiset|MYJ8Y050J0]] of as many integers as the original number that both add up to the original number and when multiplied together give the original number. To put it algebraically, for a positive integer *n*, there is a multiset of *n* integers {*a*<sub>1</sub>, ..., *a<sub>n</sub>*}, for which the equalities

$$n = \sum_{i=1}^n a_i = \prod_{i=1}^n a_i$$

hold.
