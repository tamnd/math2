## Definition

Let $D \colon [0, \infty) \to \R$ be a demand function and $S \colon [0, \infty) \to \R$ a supply function.
The *cobweb model* is the price dynamics in discrete time $t = 1, 2, \dots$ given by
$$q_t = S(p_{t-1}), \qquad D(p_t) = q_t,$$
with an initial price $p_0$.
So producers choose the quantity $q_t$ from the previous price, and the price $p_t$ clears the market.
In the linear case $D(p) = a - bp$ and $S(p) = c + dp$ with $b, d > 0$ and $a > c$, it is the [[recurrence relation|0FYX44GP92]]
$$p_t = \frac{a - c}{b} - \frac{d}{b} p_{t-1}.$$

## Remarks

The [[equilibrium|D62PEKHRV5]] of the linear model is $p^* = (a - c)/(b + d)$, where supply equals demand.
The solution is $p_t - p^* = (-d/b)^t (p_0 - p^*)$.
So the price oscillates around $p^*$, and it converges to $p^*$ exactly when $d < b$.
This is the [[stability|CHEQ235HW9]] condition: the quantity supplied must react less to the price than the quantity demanded.
If $d = b$ the oscillation keeps a constant size, and if $d > b$ it grows.

Example: $a = 10$, $b = 2$, $c = 1$, $d = 1$.
Then $p_t = (9 - p_{t-1})/2$ and $p^* = 3$.
Starting from $p_0 = 5$ gives $p_1 = 2$, $p_2 = 3.5$, $p_3 = 2.75$, which approach $3$.

Non-example: if producers react to the current price, $q_t = S(p_t)$, there is no lag, and the market sits at $p^*$ at every date.

The path can be drawn as a [[cobweb plot|B0K8MDA7CJ]] of the map $p \mapsto ((a - c) - d p)/b$.
