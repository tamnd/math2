## Summary

A *Sheffer function* on a finite set $A$ with at least two elements is a single operation on $A$ that is [[functionally complete|TDZVCWYJ9F]] by itself; see [[the definition|6KFS240R42]].
Every operation on $A$ is then a composition of copies of it.
On $\set{0, 1}$ the binary Sheffer functions are NAND and NOR.
On $m$ values, [[Webb's function|~02b9134b]] $\max(x, y) + 1 \bmod m$ is a Sheffer function, so one binary connective can carry the whole expressive power of an $m$-valued logic.

## Motivation

A functionally complete set of connectives lets a logic express every truth table.
Fewer primitive connectives mean fewer cases in proofs by induction on formulas and fewer kinds of gates in a circuit.
The extreme case is one connective, as with NAND in classical logic.
For many-valued logics, the question is whether one binary operation can still do everything; Webb answered yes in 1935.

## Notation

A Sheffer function is often written as a stroke $x \mid y$; Webb used this symbol for his function.
We use the labels $V = \set{0, 1, \dots, m - 1}$ and the shift $S x = x + 1 \bmod m$.

## Remarks

### Examples

1. NAND and NOR on $\set{0, 1}$; see [[the Sheffer stroke|1NNYWRN6B8]].
2. [[Webb's function on three values|~66984f94]], with explicit terms for $S$ and $\max$.
3. For every $m \ge 2$, $w(x, y) = S(\max(x, y))$ is a Sheffer function; for $m = 2$ it is NOR.

### Non-examples

1. [[Maximum is not a Sheffer function|~dc3a6ee8]]: every term in $\max$ satisfies $t(x, \dots, x) = x$.
2. Every unary operation fails, since it generates only operations that depend on one variable.
3. Łukasiewicz implication on three values fails, since it preserves $\set{0, 1}$.

### Basic properties

1. An operation $f$ is a Sheffer function iff the [[clone|PTKR703G6A]] generated by $f$ is the clone of all operations on $A$.
2. To prove that $f$ is a Sheffer function, it is enough to define from $f$ a known complete set, such as [[Post's connectives|~fbe0fcc9]].
3. Słupecki's criterion. Let $|A| \ge 3$ and let $F$ contain all unary operations on $A$. Then $F$ is complete iff it contains an operation that depends on at least two variables and takes all values of $A$.
4. A set $F$ of operations is complete iff it lies in no maximal clone; Rosenberg's theorem lists the maximal clones, see [[Rosenberg's classification|GF1RK91VED]].

### History

Sheffer described the stroke and its functional completeness for two values in 1913.
Webb described a one-operation generator of any $n$-valued logic in 1935, so the function is also called the Webb operation.
SEP credits Słupecki (1939) with general criteria for functional completeness of $m$-valued operations.

### Common errors

1. Thinking that a Sheffer function must be binary. Arity $2$ is the smallest possible, but higher arities are allowed.
2. Forgetting constants. A Sheffer function must also generate the constant functions, so it cannot be idempotent.
3. Taking Webb's function for $\max(x, y) + 1$ without "mod $m$"; the wrap-around from $m - 1$ to $0$ is needed.

## Explanations

### L1 human

The NAND gate outputs $0$ only when both inputs are $1$.
Chips can be built from NAND gates alone, because NAND can imitate every other gate.
For example, $\neg x$ is $x \uparrow x$, and $x \wedge y$ is $(x \uparrow y) \uparrow (x \uparrow y)$.
An operation with this "one gate does everything" property is called a Sheffer function.
For three or more values, Webb's function plays the role of NOR.

### L2 human

To check that $f$ is a Sheffer function, define from $f$ a set that you already know is complete.
For Webb's function, $w(x, x)$ is the shift, and the shift applied $m - 1$ more times undoes the "$+1$".
A trap: an operation that maps each constant tuple $(a, \dots, a)$ to $a$ cannot be a Sheffer function.

### L3 human

By Rosenberg's theorem, $f$ is a Sheffer function iff $f$ preserves none of the finitely many maximal relations of the classification.
For $|A| \ge 3$ there are uncountably many clones, but the completeness question reduces to this finite list.
Słupecki's criterion is a special case for sets that already contain all unary operations.
