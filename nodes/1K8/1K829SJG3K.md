## Summary

On the values $0, 1, 2$, let $w(x, y)$ be the larger of $x$ and $y$, moved one step up, with $2$ wrapping around to $0$.
So $w(1, 1) = 2$, $w(0, 1) = 2$ and $w(2, 0) = 0$.
This single operation can build every operation on three values, and an operation with that property is a Sheffer function.

Exactly, a *Sheffer function* on a finite set $A$ with at least two elements is one operation $f$ on $A$ such that $\{f\}$ is [[functionally complete|TDZVCWYJ9F]]; see [[the definition|6KFS240R42]].
Every operation on $A$ is then a composition of copies of $f$ and projections.
On $\{0, 1\}$ the binary Sheffer functions are NAND and NOR.
On $m$ values, [[Webb's function|EPSBDVPKJP]] $w(x, y) = \max(x, y) + 1 \bmod m$ is a Sheffer function.

## Motivation

A functionally complete set of connectives lets a logic express every truth table.
Fewer primitive connectives mean fewer cases in proofs by induction on formulas, and fewer kinds of gate in a circuit.
The extreme case is one connective, as with NAND in classical logic, and chips built from NAND gates alone use this fact.

For [[Post's many-valued logics|YHYSGRE7JV]] the same question arises: can one binary operation carry the whole expressive power of an $m$-valued logic?
Webb answered yes in 1935.
The question then turns into a study of [[clones|PTKR703G6A]], the sets of operations closed under composition, and of the largest clones short of all operations.

## Notation

A Sheffer function is often written as a stroke, $x \mid y$, and Webb used this symbol for his function.
Two-valued NAND is also written $x \uparrow y$ and NOR $x \downarrow y$.
We label the values $V = \{0, 1, \dots, m - 1\}$ and write the shift as $S x = x + 1 \bmod m$, so that $w(x, y) = S(\max(x, y))$.

## Remarks

### A first computation

On three values, put the same input into $w$ twice:
$$w(0, 0) = 1, \qquad w(1, 1) = 2, \qquad w(2, 2) = 0.$$
So $w(x, x)$ is the shift $S$.
Now apply the shift twice more to $w(x, y)$, which undoes the step up, since $S^3$ is the identity.
At $(1, 0)$ we get $w(1, 0) = 2$, then $S(2) = 0$, then $S(0) = 1$, and $1 = \max(1, 0)$.
So $\max$ is a term in $w$, and so is Post's negation $\neg x = S^2 x$.
[[Webb's function on three values|AR2E4BF627]] gives the full table and these checks.

### Why one function is enough

[[Post's theorem|8P3Y6T0RZS]] says that $\neg$ and $\max$ already express every function.
So any operation that defines both is a Sheffer function, and this is the standard way to prove the property.
The [[proof for Webb's function|P1FJ5TEFBX]] takes four lines after this reduction.
For $m = 2$, $w(x, y) = 1 - \max(x, y)$ is NOR, so Webb's function extends the two-valued case.

### What it is not

[[Maximum is not a Sheffer function|3WGZ1AR5E0]], because every term in $\max$ sends $(a, \dots, a)$ to $a$, so no term moves $0$ to $1$.
A unary operation is never a Sheffer function, since its compositions depend on one variable only.
Łukasiewicz implication on three values is not one either, since it keeps $\{0, 1\}$ closed and so never produces $\tfrac12$ from $0$ and $1$.

### The tests you can use

An operation $f$ is a Sheffer function exactly when the clone that $f$ generates is the clone of all operations on $A$.
To prove that $f$ is not one, find a property that $f$ has, that composition keeps, and that some operation lacks.
Słupecki's criterion covers sets that contain all unary operations.
For $|A| \ge 3$, such a set is complete exactly when it also contains an operation that depends on at least two variables and takes all values.
In general, a set is complete exactly when it lies in no maximal clone, and [[Rosenberg's classification|GF1RK91VED]] lists the maximal clones.

### Watch out

A Sheffer function need not be binary, but arity $2$ is the smallest possible.
It must generate the constants too, so it cannot be idempotent: $\max$ fails for that reason alone.
And do not drop "mod $m$" from Webb's function.
Without it, $\max(2, 2) + 1 = 3$ lies outside $\{0, 1, 2\}$, so the formula is not an operation on $V$ at all.

### History

Sheffer described the stroke and its functional completeness for two values in 1913.
Webb published a single binary operation that generates every $m$-valued function in 1935, and it is now called the Webb operation.
Słupecki published his completeness criterion in 1939.

### Try it

First, on $\{0, 1, 2\}$, compute $w(w(0, 0), 2)$.
We have $w(0, 0) = 1$ and $w(1, 2) = S(2) = 0$, so the answer is $0$.

Second, is $\min$ a Sheffer function on $\{0, 1\}$?
No: every term in $\min$ sends $(0, \dots, 0)$ to $0$, so negation is not a term.

## Explanations

### L1 human

The NAND gate outputs $0$ only when both inputs are $1$.
Chips can be built from NAND gates alone, because NAND can imitate every other gate.
For example, $\neg x$ is $x \uparrow x$, and $x \wedge y$ is $(x \uparrow y) \uparrow (x \uparrow y)$.
An operation with this "one gate does everything" property is a Sheffer function, and for three or more values Webb's function plays the part of NOR.

### L2 human

We show that Webb's function on four values generates $\max$.
The diagonal gives the shift, $w(x, x) = S x$ with $S x = x + 1 \bmod 4$.
Since $S^4$ is the identity, three more shifts undo the step up:
$$S^3(w(x, y)) = S^4(\max(x, y)) = \max(x, y).$$
Check at $(3, 1)$: $w(3, 1) = 0$, then $S$ three times gives $1, 2, 3$, and $\max(3, 1) = 3$.
Post's negation is $S^3$ as well, so both of Post's connectives are terms, and Post's theorem finishes the proof.
This is the typical pattern: reduce to a set already known to be complete.

### L3 human

By Rosenberg's theorem, $f$ is a Sheffer function exactly when it preserves none of the relations that define the maximal clones.
For $|A| \ge 3$ there are uncountably many clones, but the completeness question reduces to this finite list.
Słupecki's criterion is the special case for sets that already contain all unary operations.
The same clone theory, applied to two values, gives Post's lattice and the classical completeness criterion of [[functional completeness|TDZVCWYJ9F]].
