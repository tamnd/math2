## Definition

Let $P$ and $C$ be the [[transfer functions|86JKV3TRFD]] of a plant and a controller, real [[rational functions|0XDK9CGYKJ]].
They form a single-input single-output unity negative [[feedback|7NYES2D0Z4]] loop.
Let $L = PC$ be the loop transfer function, and assume that $1 + L$ is not identically $0$.

1. The *sensitivity function* of the loop is $S = \dfrac{1}{1 + L}$.
2. The *complementary sensitivity function* of the loop is $T = \dfrac{L}{1 + L}$.

## Remarks

The two functions satisfy $S + T = 1$.
The function $T$ is the [[closed-loop transfer function|RYTSV821V8]] from the reference to the output.
If $P$ changes to $P + \Delta P$, the closed-loop function $T$ changes so that $(\Delta T / T) / (\Delta P / P) \to S$ as $\Delta P \to 0$; this is the origin of the name.
For multivariable loops one writes $S = (I + L)^{-1}$ and $T = L(I + L)^{-1}$.

Example: for $P(s) = 1/s$ and $C = 1$, $L(s) = 1/s$, so $S(s) = s/(s + 1)$ and $T(s) = 1/(s + 1)$, and indeed $S + T = 1$.

Non-example: $L/(1 - L)$ is the closed-loop function of a positive feedback loop.
It is not the complementary sensitivity function of the negative feedback loop, and its sum with $S$ is not $1$ in general.
