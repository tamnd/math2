## Summary

The elementary amenable groups are the groups that can be built from finite groups and abelian groups by taking subgroups, quotients, extensions and directed unions.
Each of these operations preserves amenability, so every elementary amenable group is [[amenable|CEAT9BESKK]].
The class contains all solvable groups and all virtually solvable groups.
There are amenable groups that are not elementary amenable, such as the [[Grigorchuk group|M0WAT1VQZH]], so the class is strictly smaller.

## Explanations

### L1 human

Some groups are amenable for simple reasons: they are finite, or abelian.
Amenability survives when one passes to a subgroup or a quotient, glues two amenable groups in an extension, or takes a growing union.
The elementary amenable groups are exactly those one reaches from finite and abelian groups by these steps.
For example, take the symmetries of the integer line, generated by a shift and a reflection.
This group has the shifts $\Z$ as a normal subgroup with quotient $\Z/2$, so it is elementary amenable.
