## Example

No graph has both a $k$-clique and a proper coloring with $k - 1$ colors, since two vertices of the clique would get the same color.
We show that every resolution refutation of this fact, written as a CNF, has exponentially many clauses.

### The two CNFs

Fix $n$ and $2 \leq k \leq n$.
The shared variables are $p_{uv}$ for $1 \leq u < v \leq n$, with $p_{vu} = p_{uv}$, and an assignment $a$ is the graph $G_a$ on $\{1, \dots, n\}$ with the edges $uv$ for which $a_{uv} = 1$.
The CNF $\mathrm{Clique}(p, q)$ has variables $q_{i,u}$, read as "the $i$-th vertex of the clique is $u$", for $i \leq k$ and $u \leq n$, and these clauses.

1. $q_{i,1} \vee \cdots \vee q_{i,n}$ for each $i \leq k$.
2. $\neg q_{i,u} \vee \neg q_{j,u}$ for all $i < j$ and all $u$.
3. $\neg q_{i,u} \vee \neg q_{j,v} \vee p_{uv}$ for all $i \neq j$ and all $u \neq v$.

The CNF $\mathrm{Color}(p, r)$ has variables $r_{u,c}$, read as "vertex $u$ has color $c$", for $u \leq n$ and $c \leq k - 1$, and these clauses.

4. $r_{u,1} \vee \cdots \vee r_{u,k-1}$ for each $u$.
5. $\neg r_{u,c} \vee \neg r_{v,c} \vee \neg p_{uv}$ for all $u < v$ and all $c$.

### The lower bound

We check the hypotheses of the [[interpolation theorem for resolution|YHGCN7BBEP]], part 2, and then draw the conclusion.

1. The private variables are disjoint: the $q_{i,u}$ occur only in $\mathrm{Clique}$, and the $r_{u,c}$ only in $\mathrm{Color}$.
2. The variables $p_{uv}$ occur in $\mathrm{Clique}$ only in clauses of type 3, and there they are positive, so the sign condition holds.
3. $\mathrm{Clique}(a, q)$ is satisfiable exactly when $G_a$ has a [[clique|0BYX1D7C2E]] with $k$ vertices.
   Given a clique $\{u_1, \dots, u_k\}$, set $q_{i, u_i} = 1$ and all other $q$ to $0$.
   Conversely, pick for each $i$ some $u_i$ with $q_{i, u_i} = 1$; clauses 2 make the $u_i$ distinct, and clauses 3 make them pairwise adjacent.
4. $\mathrm{Color}(a, r)$ is satisfiable exactly when $G_a$ has a proper [[coloring|0NCPXH194Y]] with $k - 1$ colors: give $u$ some color $c$ with $r_{u,c} = 1$.
5. Let $\pi$ be a [[resolution refutation|6JSH907W5R]] of $\mathrm{Clique} \wedge \mathrm{Color}$ with $L$ clauses.
   The theorem gives a monotone circuit $I$ with at most $4L$ gates.
   If $G_a$ has a $k$-clique, then $\mathrm{Clique}(a, q)$ is satisfiable, so $I(a) = 1$.
   If $G_a$ is $(k-1)$-colorable, then $\mathrm{Color}(a, r)$ is satisfiable, so $I(a) = 0$.
6. A monotone Boolean circuit is a monotone real circuit, with AND as minimum and OR as maximum.
   Take $k = \lfloor (n / \log_2 n)^{2/3} / 8 \rfloor$ with $n$ large.
   Part 1 of [[Pudlák's theorem|5RYPXFF0G2]] says that $I$ has $2^{\Omega((n / \log n)^{1/3})}$ gates.
7. So $4L \geq 2^{\Omega((n / \log n)^{1/3})}$, and every resolution refutation of $\mathrm{Clique} \wedge \mathrm{Color}$ has $2^{\Omega((n / \log n)^{1/3})}$ clauses.

## Remarks

The measure is the number of clauses of a resolution refutation.
The CNF has $N$ variables with $n(n-1)/2 \leq N \leq 3n^2$, so in terms of $N$ the bound is $2^{\Omega((N^{1/2} / \log N)^{1/3})}$.

The interpolant need not compute the clique function.
It must answer $1$ on graphs with a $k$-clique and $0$ on $(k-1)$-colorable graphs, and it may answer either way on other graphs.
So the lower bound must hold for every monotone function that separates the two classes.
The approximation method of [[Razborov|2XH5VDJ426]], in the form of Alon and Boppana, gives exactly this, since it tests the circuit only on single $k$-cliques and on complete $(k-1)$-partite graphs.

What changes for a stronger system?
For [[cutting planes|KKCX2HQP2K]], Pudlák's part 2 gives the same bound on the number of lines, but the circuits there are real circuits.
For [[extended Frege|5YSE04SHFH]] the route is blocked under cryptographic assumptions.
So the bound above is a lower bound for resolution only, and it says nothing about stronger systems.

## Explanations

### L1 human

One side says "this graph has a group of $k$ vertices that are all joined", and the other says "this graph can be colored with $k - 1$ colors".
Both cannot be true, and a resolution proof shows this.
From the proof one can build a small machine with AND and OR gates that tells which claim fails for a given graph.
Such machines are known to be huge, so the proof must be huge too.

### L2 human

The argument has three moves.
The theorem turns a refutation with $L$ clauses into a monotone circuit with at most $4L$ gates.
The circuit separates the graphs with a $k$-clique from the $(k-1)$-colorable graphs.
Every monotone circuit that separates them has $2^{\Omega((n / \log n)^{1/3})}$ gates, for the value of $k$ above, so $L$ is at least that large up to a factor $4$.
The same pattern works for every system with monotone feasible interpolation.
Watch out: if the edge variables occurred negatively on the clique side, the sign condition would fail, and the theorem would give no monotone circuit.
