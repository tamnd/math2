## Summary

Let $\mathcal{M}$ be an $L$-[[structure|983GZBQYT4]] with domain $M$, let $A \subseteq M$, and let $L_A$ be $L$ with a new constant for each element of $A$.
Write $\operatorname{Th}_A(\mathcal{M})$ for the set of $L_A$-sentences true in $\mathcal{M}$ when each new constant names its element.
An *$n$-type over $A$* is a set $p(x_1, \dots, x_n)$ of $L_A$-[[formulas|HYJ10AF6RT]] in the free variables $x_1, \dots, x_n$ such that $\operatorname{Th}_A(\mathcal{M}) \cup p$ is satisfiable.
It is *complete* when, for every $L_A$-formula $\varphi(\bar{x})$, either $\varphi \in p$ or $\neg \varphi \in p$.
A tuple $\bar{b}$ of $M$ *realizes* $p$ when $\mathcal{M} \models \varphi(\bar{b})$ for all $\varphi \in p$, and $\mathcal{M}$ *omits* $p$ when no tuple realizes it.
The *type of $\bar{a}$ over $A$*, written $\operatorname{tp}(\bar{a}/A)$, is the set of all $L_A$-formulas that $\bar{a}$ satisfies, and it is a complete type.
Types are the first-order descriptions of tuples, and the models of a theory differ by the types that they realize.

## Motivation

Two elements can look the same to first-order logic even when they are different.
In $(\Q, <)$ the elements $0$ and $1$ satisfy the same formulas without parameters, because the map $x \mapsto x + 1$ is an automorphism.
Over the parameter set $\set{1/2}$ they differ, since the formula $x < 1/2$ holds of $0$ and fails for $1$.
A type collects exactly the information that formulas with the given parameters can see about a tuple.
Comparing models then becomes a question about types.
The rational order omits the type of $\sqrt{2}$ over $\Q$, and the real order realizes it.
A model that realizes many types is rich, and a model that omits many types is small.
This leads to [[saturated models|RMTZ5J64FX]], which realize all types over small sets, and to the [[omitting types theorem|7MFGBVDVG9]].

## Notation

The type of $\bar{a}$ over $A$ is written $\operatorname{tp}(\bar{a}/A)$, or $\operatorname{tp}^{\mathcal{M}}(\bar{a}/A)$ when the structure must be named, and $\operatorname{tp}(\bar{a})$ when $A = \emptyset$.
The set of complete $n$-types over $A$ is $S_n^{\mathcal{M}}(A)$, or $S_n(A)$ when $\mathcal{M}$ is fixed.
For a [[theory|92SWXST1ZM]] $T$, an $n$-type of $T$ is a set $p$ of $L$-formulas with $T \cup p$ satisfiable, and $S_n(T)$ is the set of complete ones.
Some authors say "partial type" for a type and "type" for a complete type.
Mathlib formalizes complete types as `FirstOrder.Language.Theory.CompleteType`, as maximal consistent sets of sentences with new constants for the variables.

## Remarks

### Examples

- In $(\R, <)$, the type of $\sqrt{2}$ over $\Q$ is fixed by the cut $\set{q \in \Q : q < \sqrt{2}}$; see [[types of reals over the rationals|~6aa706c0]].
- In the theory of $(\N, 0, 1, +, \cdot, <)$, the set $\set{x > \underline{k} : k \in \N}$ is a type, realized by the [[infinite elements of nonstandard models|~a176ff80]].
- In the field $\C$, the complete $1$-types over $\emptyset$ are the types of the roots of each irreducible polynomial over $\Q$ and one type of a transcendental number; see [[the type space of algebraically closed fields|~4b7c25db]].
- In a [[dense linear order|2W4S2H4VYA]] there are exactly three complete $2$-types over $\emptyset$, given by $x_1 < x_2$, $x_1 = x_2$ and $x_2 < x_1$; see [[the 2-types of dense linear orders|~decb0203]].

### Non-examples

- In the theory of fields, $\set{x = 0, \; x \cdot x = 1}$ is not a type, since $x = 0$ gives $x \cdot x = 0 \ne 1$.
- In $(\Z, <)$, the set $\set{0 < x, \; x < 1}$ is not a type over $\set{0, 1}$, although the same set is a type over $\set{0, 1}$ in $(\Q, <)$; see [[a set that is a type in one order and not in another|~a202ede7]].

### Basic properties

- A set $p$ of $L_A$-formulas is a type over $A$ exactly when every finite subset of $p$ is realized in $\mathcal{M}$, by the [[compactness theorem|1NR3HAWG9D]].
- Every type over $A$ is contained in a complete type over $A$, by [[Lindenbaum's lemma|SC0BSJ3GT6]] applied to $\operatorname{Th}_A(\mathcal{M}) \cup p(\bar{c})$ with new constants $\bar{c}$.
- Every type over $A$ is realized in some elementary extension of $\mathcal{M}$; see [[realizing types|~17fa6973]].
- If $\mathcal{M} \preceq \mathcal{N}$, then types over $A$ in $\mathcal{M}$ and in $\mathcal{N}$ are the same, and $\operatorname{tp}^{\mathcal{M}}(\bar{a}/A) = \operatorname{tp}^{\mathcal{N}}(\bar{a}/A)$.
- An [[automorphism|DSQ17TNW1C]] that fixes $A$ pointwise preserves $\operatorname{tp}(\bar{a}/A)$; the converse holds in homogeneous models; see [[types as orbits|~3d38bf9d]].
- The set $S_n(A)$ carries a compact Hausdorff topology; see [[the Stone space of types|~319ab8e1]].

### History

Types were used in the study of countable models around 1960, in the omitting types theorem and in the Ryll-Nardzewski theorem.
Morley and Vaught introduced saturated models in 1962, and Morley used the Stone spaces of types in his 1965 proof of the categoricity theorem.
Later, Shelah built stability theory on counting types.

### Common errors

- Forgetting the parameters: a type over $A$ must be consistent with $\operatorname{Th}_A(\mathcal{M})$, which knows the order and the relations between the elements of $A$, and not only with the theory $T$.
- Expecting every type to be realized in $\mathcal{M}$: a type is only consistent, and it may be realized only in an elementary extension.
- Treating a type as a single formula: most interesting types are infinite and are not implied by any one of their formulas.

## Explanations

### L1 human

A type is a list of properties that an element could have, written in the language of the structure.
Take the rational numbers with their order, and the list "$x > 1$, $x > 2$, $x > 3$, and so on".
Every finite part of the list is met by some rational number, such as $100$ for the first $99$ properties.
No rational number meets the whole list, so the rationals omit this type.
A larger ordered set with an element above all integers realizes it.
So types record which kinds of elements a structure has and which kinds it is missing.

### L2 human

We find all complete $1$-types over $A = \set{0, 1}$ in $(\Q, <)$.

1. A complete type over $A$ contains, for each $a \in A$, exactly one of $x < a$, $x = a$ and $a < x$, since these three cases are exclusive and exhaustive.
2. The theory of dense linear orders has [[quantifier elimination|7FDDXV3JK7]], so these atomic choices fix every formula of the type.
3. The consistent choices are $x < 0$, $x = 0$, $0 < x < 1$, $x = 1$ and $1 < x$, because $0 < 1$ holds in $\operatorname{Th}_A(\Q, <)$.
4. Each choice is realized, for example by $-1$, $0$, $1/2$, $1$ and $2$.

So $S_1(A)$ has five points, and $(\Q, <)$ realizes all of them.
The typical use is to describe an element up to everything that formulas can say about it.
The trap is to forget the formulas without quantifier elimination: in $(\Z, <)$ over $\set{0}$, the formula "there are exactly $k$ elements between $0$ and $x$" separates infinitely many types with $0 < x$.

### L3 human

The complete $n$-types over $A$ are the ultrafilters of the Boolean algebra of $L_A$-formulas in $n$ variables modulo $\operatorname{Th}_A(\mathcal{M})$.
With the Stone topology they form a compact totally disconnected space, and the isolated points are the [[isolated types|~ecb9582c]].
Counting types over sets of a given size is the start of [[stability theory|T7JW5QY6KR]], and the rank of points in this space gives [[Morley rank|WN43DRPNBX]].
Outside first-order logic, types are replaced by orbits of automorphisms, the Galois types of abstract elementary classes.
