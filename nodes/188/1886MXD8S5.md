## Example

The signature $L$ is empty, so the only atomic formulas are equations $x = y$ between variables.
For $n \ge 2$, let $\lambda_n$ be the sentence $\exists x_1 \cdots \exists x_n \bigwedge_{1 \le i < j \le n} x_i \neq x_j$, which says "there are at least $n$ elements".
Let $A = \set{\lambda_n : n \ge 2}$ and $T = \operatorname{Cn}(A)$, the theory of infinite sets.
The models of $T$ are exactly the infinite sets.
We check that $T$ is a [[decidable theory|HWC687ES0Q]].

1. The set $A$ is computable. Given a sentence, we check whether it has the form of $\lambda_n$ for its own number $n$ of quantifiers, which is a finite comparison of strings.
2. $T$ has a model, for example the set $\N$ of natural numbers.
3. $T$ has no finite model, since a set with $m$ elements does not satisfy $\lambda_{m+1}$.
4. $T$ is $\aleph_0$-categorical. Two countably infinite sets have a bijection between them, and in the empty signature a bijection is an isomorphism.
5. By the [[Łoś-Vaught test|ZR7Y5C235P]] with $\kappa = \aleph_0$, steps 2 to 4 show that $T$ is [[complete|655K8Y7VS8]].
6. By the theorem that [[a complete axiomatizable theory is decidable|HZ7A7B2ERA]], steps 1 and 5 show that $T$ is decidable.

## Remarks

The example shows the standard route to decidability: a computable set of axioms, then completeness by a model-theoretic argument.

A faster algorithm exists.
For sentences of quantifier rank at most $q$, two sets with at least $q$ elements each satisfy the same sentences.
This follows from an [[Ehrenfeucht-Fraïssé game|2RE7YAZK8R]], since in $q$ rounds only $q$ elements are chosen.
So for $q \ge 1$, a sentence $\sigma$ of rank $q$ is in $T$ if and only if $\sigma$ is true in the set $\set{1, \ldots, q}$, and this is a finite check.

$T$ is not finitely axiomatizable.
Suppose that $T = \operatorname{Cn}(\set{\varphi})$ for one sentence $\varphi$.
Then $A \models \varphi$, so by the [[compactness theorem|1NR3HAWG9D]] some finite subset of $A$ implies $\varphi$, and so $\lambda_N \models \varphi$ for some $N$.
A set with exactly $N$ elements satisfies $\lambda_N$, hence $\varphi$, hence all of $T$, but it is finite.
This contradicts step 3.

When a parameter changes, the result changes in this way.

- The theory of sets with exactly $n$ elements is also complete and decidable, since it is the theory of one finite structure.
- The theory of all sets, $\operatorname{Cn}(\emptyset)$ in the empty signature, is decidable but not complete. A sentence of rank $q \ge 1$ is valid if and only if it is true in the sets of sizes $1$ to $q$.

## Explanations

### L1 human

Here the only thing a statement can say is whether two objects are the same or different.
In an infinite collection, every statement of this kind is either always true or always false.
For example, "there are at least five different objects" is always true.
A computer can decide each statement: it checks the statement in a small finite collection whose size is the number of quantifiers.

### L2 human

We decide the sentence $\sigma = \forall x \, \exists y \, (x \neq y)$ with the faster algorithm.

1. The quantifier rank of $\sigma$ is $q = 2$.
2. We check $\sigma$ in the set $\set{1, 2}$. For $x = 1$ we take $y = 2$, and for $x = 2$ we take $y = 1$.
3. So $\sigma$ is true in $\set{1, 2}$, and by the remark, $\sigma \in T$.
4. As a check, $\sigma$ is true in every set with at least $2$ elements, and every model of $T$ is infinite.

The typical use of this example is as a first test case for a decision method.
A trap is to check $\sigma$ in a set that is too small: $\sigma$ is false in the set $\set{1}$, and that set is not a model of $T$.
