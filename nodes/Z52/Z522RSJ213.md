## Example

Define a [[binary operation|0M418FE7BB]] $\ast$ on the [[integers|0C4JS9RF5M]] $\mathbb{Z}$ by $a \ast b = a + b + ab$.
We check that $\ast$ is [[associative|0K8F7PVDMX]].
Let $a, b, c \in \mathbb{Z}$.

1. By the definition, $(a \ast b) \ast c = (a + b + ab) + c + (a + b + ab)c$.
2. We expand the last product: $(a + b + ab)c = ac + bc + abc$. So $(a \ast b) \ast c = a + b + c + ab + ac + bc + abc$.
3. By the definition, $a \ast (b \ast c) = a + (b + c + bc) + a(b + c + bc)$.
4. We expand the last product: $a(b + c + bc) = ab + ac + abc$. So $a \ast (b \ast c) = a + b + c + ab + ac + bc + abc$.
5. The results of steps 2 and 4 are equal. Thus $(a \ast b) \ast c = a \ast (b \ast c)$ for all $a, b, c \in \mathbb{Z}$.

A numerical check with $a = 1$, $b = 2$, $c = 3$:

6. $1 \ast 2 = 1 + 2 + 2 = 5$, and $5 \ast 3 = 5 + 3 + 15 = 23$.
7. $2 \ast 3 = 2 + 3 + 6 = 11$, and $1 \ast 11 = 1 + 11 + 11 = 23$.

## Remarks

The identity $a \ast b + 1 = (a + 1)(b + 1)$ explains the result.
Put $\phi(x) = x + 1$.
Then $\phi(a \ast b) = \phi(a)\phi(b)$, and $\phi$ is a bijection from $\mathbb{Z}$ to $\mathbb{Z}$.
So $\ast$ is ordinary multiplication after a change of names, and multiplication is associative.
The check $(1 + 1)(2 + 1)(3 + 1) - 1 = 24 - 1 = 23$ agrees with steps 6 and 7.
The operation is also [[commutative|099E72KTF8]], and $0$ is an [[identity element|07WYQPB8E3]], because $a \ast 0 = a + 0 + 0 = a$.
So $(\mathbb{Z}, \ast)$ is a commutative [[monoid|0N6R902FG1]].
It is not a [[group|G5S1M9]].
An element $a$ has an [[inverse|0ZNZH0EXFX]] $b$ exactly when $a \ast b = 0$, that is, $(a + 1)(b + 1) = 1$.
This needs $a + 1 = \pm 1$, so only $a = 0$ and $a = -2$ have inverses.
For example, $1$ has no inverse.

## Explanations

### L1 human

The rule says: add the two numbers, then add their product.
For three numbers, we can do the first two first, or the last two first.
Both ways give the same number, so the brackets do not matter.

### L2 human

To check associativity of a rule given by a formula, compute both groupings as formulas in $a$, $b$, $c$, expand, and compare.
A numerical test with one triple can find an error, but only the computation with letters proves the law for all triples.
The typical use is an exercise that asks whether a new operation gives a group.
A trap is the set $\mathbb{Z}$: the operation is associative and has an identity, but the inverses fail.
On the set $\mathbb{Q} \setminus \{-1\}$ the inverses exist, because $b = -a/(a + 1)$ gives $a \ast b = 0$.
