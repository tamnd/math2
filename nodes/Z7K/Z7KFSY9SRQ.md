## Summary

In set theory, **$\in$-induction**, also called **epsilon-induction** or **set-induction**, is a principle that can be used to prove that all [[sets|0BSJ7RQ9BW]] satisfy a given property. Considered as an axiomatic principle, it is called the **axiom schema of set induction**.
