## Example

The trivial group is the set $\{e\}$ with one element $e$ and the operation $e \cdot e = e$.
We check that it is a [[group|G5S1M9]], and then we find all [[homomorphisms|0JYTG5K9Y4]] to it and from it.

1. Binary operation. The only pair is $(e, e)$, and its product $e$ is in $\{e\}$.
2. Associativity. The only case is $(ee)e = ee = e$ and $e(ee) = ee = e$, so the two sides are equal.
3. Identity. The element $e$ satisfies $ee = e$, so $ex = xe = x$ for the only element $x = e$.
4. Inverse. Since $ee = e$, the element $e$ is its own inverse.
5. Commutativity. The only pair is $(e, e)$, so $ab = ba$ for all $a, b$. Thus the trivial group is [[abelian|082GHNPJ53]].

Now let $G$ be a group with identity $e_G$.

6. Each homomorphism $f$ sends an identity to an identity. Indeed $f(e) = f(ee) = f(e) f(e)$, and [[cancellation|0VSNX4P2Q0]] of $f(e)$ gives $e_G = f(e)$.
7. Maps from $\{e\}$ to $G$. By step 6, each homomorphism $f \colon \{e\} \to G$ has $f(e) = e_G$. Conversely, the map $e \mapsto e_G$ is a homomorphism, because $f(ee) = e_G = e_G e_G = f(e) f(e)$. So there is exactly one homomorphism $\{e\} \to G$.
8. Maps from $G$ to $\{e\}$. There is exactly one map $c \colon G \to \{e\}$, with $c(g) = e$ for each $g$. It is a homomorphism, because $c(gh) = e = ee = c(g) c(h)$. So there is exactly one homomorphism $G \to \{e\}$.
9. Uniqueness. Let $\{e'\}$ be another group with one element. The only map $\{e\} \to \{e'\}$ is $e \mapsto e'$. By step 7 it is a homomorphism, and it is a bijection. So it is an [[isomorphism|08MG7H8JW5]], and it is the only isomorphism $\{e\} \to \{e'\}$.

## Remarks

Steps 7 and 8 say that the trivial group is an [[initial and terminal object|EK85VSSRMR]] of the [[category of groups|2CX7RPPXA9]].
An object that is both initial and terminal is a [[zero object|AQET9YHH6F]].
For this reason the trivial group is also called the zero group.
Step 9 says that the trivial group is unique up to a unique isomorphism, so we speak of the trivial group.
In additive notation, the trivial group is written $0$ or $\{0\}$.
Each group $G$ has the subgroup $\{e_G\}$, the trivial subgroup, and it is a trivial group.
For groups $G$ and $H$, the map $g \mapsto e_H$ is a homomorphism, the trivial homomorphism; it is the composite of the maps $G \to \{e\}$ of step 8 and $\{e\} \to H$ of step 7.
The empty set is not a group, because a group must contain an identity element.
So the trivial group is the smallest group, with [[order|0B85S2V2DR]] $1$.
It is also [[cyclic|0KVGH0J5B3]], generated by $e$.

## Explanations

### L1 human

The trivial group is the smallest possible group: it has only the identity element.
Combining the identity with itself gives the identity again.
It follows all the group rules, because there is only one case to check for each rule.
It is often an edge case in theorems, for example when a theorem asks for a group that is not trivial.

### L2 human

We see the trivial group as the kernel of an injective homomorphism.
Take the homomorphism $f \colon (\mathbb{Z}, +) \to (\mathbb{Z}, +)$ with $f(n) = 2n$.

1. $f$ is a homomorphism, because $f(m + n) = 2m + 2n = f(m) + f(n)$.
2. $f(n) = 0$ only for $n = 0$, so the [[kernel|0W88CEGQP1]] of $f$ is $\{0\}$, the trivial group.
3. $f$ is injective: if $2m = 2n$, then $m = n$.

In general, a homomorphism is injective exactly when its kernel is trivial.
The typical use of the trivial group is as such a kernel, or as the image of the trivial homomorphism.
A trap is to confuse the trivial group $\{e\}$ with the empty set, which is not a group.
