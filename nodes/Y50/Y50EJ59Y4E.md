## Definition

Let $f \colon \R^n \to \R$.
The *Nelder–Mead method* keeps $n + 1$ points $x_1, \dots, x_{n+1} \in \R^n$, the vertices of a [[simplex|YX1DJK2QAG]].
It uses the standard coefficients $\alpha = 1$ (reflection), $\gamma = 2$ (expansion), $\rho = 1/2$ (contraction) and $\sigma = 1/2$ (shrink).
One iteration does the following.

1. Relabel the points so that $f(x_1) \le f(x_2) \le \cdots \le f(x_{n+1})$, and let $x_o = \frac1n \sum_{i=1}^{n} x_i$ be the centroid of all points but the worst.
2. Compute the reflected point $x_r = x_o + \alpha (x_o - x_{n+1})$. If $f(x_1) \le f(x_r) < f(x_n)$, replace $x_{n+1}$ by $x_r$ and end the iteration.
3. If $f(x_r) < f(x_1)$, compute the expanded point $x_e = x_o + \gamma (x_r - x_o)$. Replace $x_{n+1}$ by $x_e$ if $f(x_e) < f(x_r)$, and by $x_r$ otherwise, and end the iteration.
4. Otherwise $f(x_r) \ge f(x_n)$. Compute the contracted point $x_c = x_o + \rho (x_{n+1} - x_o)$. If $f(x_c) < f(x_{n+1})$, replace $x_{n+1}$ by $x_c$ and end the iteration.
5. Otherwise shrink: replace $x_i$ by $x_1 + \sigma (x_i - x_1)$ for $i = 2, \dots, n + 1$.

The method repeats iterations until the simplex is small or the values $f(x_i)$ are close to each other.

## Remarks

Many implementations use an outside contraction toward $x_r$ when $f(x_n) \le f(x_r) < f(x_{n+1})$, and the inside contraction of clause 4 otherwise.

Example: $n = 1$, $f(x) = x^2$, points $x_1 = 1$ and $x_2 = 2$.
Then $x_o = 1$ and $x_r = 1 + (1 - 2) = 0$, with $f(0) = 0 < f(x_1) = 1$.
Clause 3 gives $x_e = 1 + 2(0 - 1) = -1$, with $f(-1) = 1 \not< f(x_r) = 0$.
So $x_2$ is replaced by $x_r = 0$, and the new simplex is $\set{0, 1}$, which contains the minimizer.

Non-example: compass search, which tests the points $x \pm h e_i$ along the coordinate axes, uses no simplex and no reflection step.
It fails clauses 1 and 2, although it is also a derivative-free method.
