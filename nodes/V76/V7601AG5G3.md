## Example

This is the most famous false proof in school mathematics.
It "proves" that $2 = 1$; try to find the bad step before you read the check.

1. Let $a$ and $b$ be real numbers with $a = b$ and $b \neq 0$.
2. Multiply both sides by $a$: $a^2 = ab$.
3. Subtract $b^2$ from both sides: $a^2 - b^2 = ab - b^2$.
4. Factor both sides: $(a + b)(a - b) = b(a - b)$.
5. Cancel the common factor $a - b$: $a + b = b$.
6. Replace $a$ by $b$: $2b = b$.
7. Divide by $b$, which is not zero: $2 = 1$.

The error is in step 5, and it is a division by zero.
Since $a = b$, the factor $a - b$ equals $0$, and step 5 divides both sides by it.
The other steps are sound, and we check them one by one.

1. Steps 2 and 3 do the same thing to both sides of a true equation, so they keep it true.
2. Step 4 is the distributive law: $(a + b)(a - b) = a^2 - b^2$ and $b(a - b) = ab - b^2$.
3. Step 5 uses [[cancellation|0GJM24EXP9]]: if $xc = yc$ and $c \neq 0$, then $x = y$. Here $c = a - b = 0$, so the condition fails.
4. Without its condition the rule is false, since $1 \cdot 0 = 2 \cdot 0$ while $1 \neq 2$.
5. Step 7 is valid, because $b \neq 0$ by step 1.

The correct version of step 5 keeps both cases.
For real numbers, $xc = yc$ holds exactly when $(x - y)c = 0$, that is, when $x = y$ or $c = 0$.
In step 4 the case $c = a - b = 0$ holds, so the equation is true and says nothing about $a + b$ and $b$.
So this is a [[mathematical fallacy|S2BW0FDHV8]] of the simplest kind: one rule used without its one condition.

## Remarks

### Losing solutions by cancelling

The same move does quieter damage when we solve equations: it loses solutions.
Solve $x^2 = 3x$ over $\mathbb{R}$.
Dividing by $x$ gives $x = 3$, but that step needs $x \neq 0$, which we do not know.
The correct method moves everything to one side and factors:
$$x^2 - 3x = 0 \quad \Longleftrightarrow \quad x(x - 3) = 0 \quad \Longleftrightarrow \quad x = 0 \text{ or } x = 3.$$
Check: $0^2 = 3 \cdot 0$ and $3^2 = 3 \cdot 3$.
So the division threw away the solution $x = 0$.
The [[non-reversible steps in solving equations|641ZP4RA5S]] show the opposite error, where squaring adds false solutions.

### Where the zero hides

The divisor is rarely written as $0$.
In the false proof it is $a - b$, and it is zero because of a hypothesis stated four lines earlier.
The step $\frac{x}{x} = 1$ hides the condition $x \neq 0$.
Cancelling $\sin x$ in $\sin x \cos x = \sin x$ leaves $\cos x = 1$, so only $x = 2k\pi$ with $k \in \mathbb{Z}$, and it loses the solutions $x = (2k + 1)\pi$, where $\sin x = 0$ but $\cos x = -1$.
The safe rule is short: before you cancel a factor, prove that it is not zero, or treat the case where it is zero on its own.

### No choice of numbers repairs it

The false proof needs $a = b$ twice: in step 2, to turn $a = b$ into $a^2 = ab$, and in step 6.
The same hypothesis makes the divisor in step 5 equal to $0$.
So the argument cannot be saved: when $a \neq b$, step 2 does not follow, and when $a = b$, step 5 divides by $0$.

### Try it

Find the bad step: "Let $x = 3$. Then $x^2 - 9 = 0 = x - 3$, so $(x - 3)(x + 3) = x - 3$, so $x + 3 = 1$, so $3 = -2$."
The step from $(x - 3)(x + 3) = x - 3$ to $x + 3 = 1$ cancels $x - 3$, which is $0$ when $x = 3$.

Solve $x^3 = x$ without losing a solution.
Write $x^3 - x = x(x - 1)(x + 1) = 0$, so $x = 0$, $1$ or $-1$; dividing by $x$ first would lose $x = 0$.

## Explanations

### L1 human

Start with two equal numbers, both equal to $3$.
After a few correct lines, the trick reaches $(3 + 3) \times 0 = 3 \times 0$, which is true, because both sides are $0$.
Then it "cancels" the $0$ and gets $3 + 3 = 3$, which is false.
The cancelling is the bad move: anything times $0$ is $0$, so the equation says nothing about $6$ and $3$.

### L2 human

Here is a second false proof, with the zero hidden better.

1. Let $x$ be a solution of $x - 2 = 0$.
2. Multiply both sides by $x + 2$: $x^2 - 4 = 0$.
3. Both sides of steps 1 and 2 are $0$, so $x^2 - 4 = x - 2$.
4. Factor: $(x - 2)(x + 2) = x - 2$.
5. Cancel $x - 2$: $x + 2 = 1$, so $x = -1$.
6. But $x = 2$ by step 1, so "$2 = -1$".

Step 5 divides by $x - 2$, which is $0$ by step 1.
The correct reading of step 4 is "$x - 2 = 0$ or $x + 2 = 1$", and the first case is just the hypothesis.
Check: with $x = 2$, step 4 reads $0 \cdot 4 = 0$, which is true and gives no information.
The typical use of this habit is in solving equations, where each division by an expression must come with a reason why the expression is not zero.
Watch out for a divisor that is zero only because of a line far above it.
