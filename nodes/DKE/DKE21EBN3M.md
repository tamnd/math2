## Example

Let $T = \mathrm{ACF}_0$.
We show that $T$ is [[small|W6XM5NVNRP]]: for each $n$, $T$ has countably many complete $n$-types.

1. By [[quantifier elimination|7FDDXV3JK7]], the type of a tuple $\bar a$ in a model $K$ is fixed by $I(\bar a) = \set{f \in \Q[x_1, \dots, x_n] : f(\bar a) = 0}$; see [[this page|MT8TDVPBXB]].
2. $I(\bar a)$ is a [[prime ideal|06HC6HK0Z8]], since $\Q[\bar x] / I(\bar a)$ embeds in the field $K$.
3. So the map $p \mapsto I_p$, where $I_p$ is the ideal of a realization of $p$, is injective from $S_n(T)$ into the set of prime ideals of $\Q[\bar x]$.
4. By [[Hilbert's basis theorem|0YKA9J3XEE]], each ideal of $\Q[\bar x]$ is generated by a finite set of polynomials.
5. There are countably many polynomials over $\Q$, so countably many finite sets of them, so countably many ideals.
6. By steps 3 and 5, $\abs{S_n(T)} \le \aleph_0$.

## Remarks

The map in step 3 is also onto: every prime ideal $P$ is the ideal of the tuple $\bar x + P$ in an algebraic closure of the fraction field of $\Q[\bar x] / P$.
The same argument over a countable subfield $k$ of a model shows that there are countably many types over $k$, so $T$ is $\omega$-stable.
$T$ has exactly $\aleph_0$ countable models, of transcendence degree $0, 1, 2, \dots, \aleph_0$, which agrees with smallness.
The same proof works for $\mathrm{ACF}_p$ with $\mathbb{F}_p$ in place of $\Q$.

## Explanations

### L1 human

In an algebraically closed field, everything about a list of elements is decided by which polynomial equations they satisfy.
The equations that a list satisfies are generated by finitely many of them.
There are only countably many finite lists of polynomials, so there are only countably many ways a list of elements can behave.

### L2 human

We list the $1$-types of $T$ by step 3.

1. The prime ideals of $\Q[x]$ are $\set{0}$ and the ideals $(f)$ with $f$ irreducible.
2. The ideal $\set{0}$ gives the type of a transcendental element.
3. Each irreducible $f$ gives the type of a root of $f$, and all roots of $f$ have this type.
4. So $S_1(T)$ is countably infinite, with one non-isolated point, the transcendental type.

The typical use is to see small theories with infinitely many types.
A trap is to think that small means finitely many types; that stronger condition is $\aleph_0$-categoricity.
