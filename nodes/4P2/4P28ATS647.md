## Definition

Let $\norm{\cdot}$ be the Euclidean [[norm|0V2WP9B1MF]].
Let $f \in \R^n$, and for $i = 1, \dots, m$ let $A_i$ be a real $n_i \times n$ matrix, $b_i \in \R^{n_i}$, $c_i \in \R^n$ and $d_i \in \R$.
Let $F$ be a real $p \times n$ matrix and $g \in \R^p$.
The *second-order cone program* with these data is: minimise $f^T x$ over $x \in \R^n$ subject to
$$\norm{A_i x + b_i} \le c_i^T x + d_i \quad (i = 1, \dots, m) \quad \text{and} \quad F x = g.$$

## Remarks

The *second-order cone* of dimension $k + 1$ is $L^{k+1} = \set{(u, t) \in \R^k \times \R : \norm{u} \le t}$, a closed [[convex cone|6VE4KA12VD]].
Each constraint says $(A_i x + b_i, c_i^T x + d_i) \in L^{n_i + 1}$, so the problem is a [[conic optimization|PAPN0JNEKN]] problem over a product of such cones.

Example: with $n_i = 0$ each constraint becomes $0 \le c_i^T x + d_i$, a linear inequality, so every linear program is a second-order cone program.

Non-example: the constraint $\norm{x} \ge 1$ is not of this form, since it bounds a norm from below; its feasible set is not convex.

A convex quadratic constraint $x^T P^T P x + q^T x + r \le 0$ can be written as $\norm{(2 P x, 1 + q^T x + r)} \le 1 - q^T x - r$.
