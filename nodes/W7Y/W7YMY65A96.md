## Summary

An $\varepsilon$-NFA is a [[nondeterministic finite automaton|SFMYM96C1B]] that may also change state without reading any input symbol, by an $\varepsilon$-move.
These free moves make it easy to glue automata together, which is why they appear in the standard translation of [[regular expressions|4DMYF2PR4Q]] into automata.
Every $\varepsilon$-NFA can be turned into an NFA without $\varepsilon$-moves, and then into a [[DFA|W65B6BKZRY]], that accepts the same language.
So $\varepsilon$-NFAs accept exactly the [[regular languages|18WVBDCS38]].

## Explanations

### L1 human

An $\varepsilon$-NFA is an NFA with some arrows labelled $\varepsilon$, the empty word.
The machine may follow such an arrow at any time without using up a letter.
For example, to accept words of the form $a^m$ or $b^n$, start with two $\varepsilon$-arrows: one into a loop on $a$ and one into a loop on $b$.
The machine guesses which branch to take before reading anything.
