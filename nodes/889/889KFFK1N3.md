## Example

Let $F$ have the four clauses $\{p, q\}$, $\{p, \neg q\}$, $\{\neg p, r\}$ and $\{\neg p, \neg r\}$.
A run of the [[DPLL algorithm|K7R9D390SP]] without unit propagation splits on $p$ first.
Under $p = 0$ it splits on $q$, and under $p = 1$ it splits on $r$.
Each node of the search tree carries the partial assignment $\rho$ on the path to it, and at each of the four leaves some clause of $F$ is false under $\rho$.
At $p = 0, q = 0$ the clause $\{p, q\}$ is false, and at $p = 0, q = 1$ the clause $\{p, \neg q\}$ is false.
At $p = 1, r = 0$ the clause $\{\neg p, r\}$ is false, and at $p = 1, r = 1$ the clause $\{\neg p, \neg r\}$ is false.

We now label the tree from the leaves up to the root, and each label will be a clause that is false under the assignment of its node.

1. Each leaf gets the clause that it falsifies.
2. The node $p = 0$ split on $q$, and its children carry $\{p, q\}$ and $\{p, \neg q\}$.
   Resolve them on $q$, and label the node $\{p\}$, which is false under $p = 0$.
3. The node $p = 1$ split on $r$.
   Resolve $\{\neg p, r\}$ and $\{\neg p, \neg r\}$ on $r$, and label the node $\{\neg p\}$, which is false under $p = 1$.
4. The root split on $p$.
   Resolve $\{p\}$ and $\{\neg p\}$ on $p$, and label the root $\square$.

The labels form a tree-like [[resolution refutation|6JSH907W5R]] of $F$.
It has $7$ clauses, one for each node of the search tree, and its width is $2$.

## Remarks

The same labeling works for every DPLL run that ends with "unsatisfiable".
The claim is that each node with partial assignment $\rho$ gets a clause $C$ that is false under $\rho$, and we prove it by induction from the leaves.
At a leaf, the claim holds by the choice of the clause.
At a node that splits on $x$, let $C_0$ and $C_1$ be the clauses of the children for $x = 0$ and $x = 1$.
If $x \notin C_0$, then $C_0$ is already false under $\rho$, so the node gets $C_0$, and the subtree of $C_1$ is dropped.
If $\neg x \notin C_1$, the node gets $C_1$ in the same way.
Otherwise $x \in C_0$ and $\neg x \in C_1$, and the node gets the resolvent on $x$, which is false under $\rho$.
At the root $\rho$ is empty, and the only clause that is false under the empty assignment is $\square$.

Unit propagation fits the same scheme, since it is a split in which one child is a leaf at once.
So every DPLL search tree has at least $S_T(F \vdash \square)$ nodes, and a lower bound for tree-like resolution is a lower bound on the running time of DPLL.
The converse also holds: a tree-like refutation, read from the root, is a search tree that splits on the pivots.

Watch out.
A CDCL solver learns clauses and uses them again in later branches.
Its runs give dag-like refutations, so lower bounds for tree-like resolution do not apply to CDCL, and only the weaker bounds for general resolution do.

## Explanations

### L1 human

A DPLL solver tries the values of the variables one by one, and it backs up when a clause fails.
For this formula it tries $p = 0$ and fails for both values of $q$, then tries $p = 1$ and fails for both values of $r$.
The record of these failures is a resolution proof.
Each failure gives a clause, and each backtrack combines two clauses into one.

### L2 human

We check the node $p = 0$ against the claim.
Its assignment is $\rho = \{p = 0\}$, and it splits on $q$.
The child $q = 0$ carries $C_0 = \{p, q\}$, which contains $q$, and the child $q = 1$ carries $C_1 = \{p, \neg q\}$, which contains $\neg q$.
So neither shortcut applies, and the node gets the resolvent on $q$:
$$\{p, q\}, \ \{p, \neg q\} \ \vdash \ \{p\}.$$
Check: $\{p\}$ is false under $p = 0$, as the claim says.
The typical use of the example is to turn a lower bound for tree-like resolution into a lower bound on DPLL running time, for example on the [[pigeonhole formulas|RJ571F7FF0]].
