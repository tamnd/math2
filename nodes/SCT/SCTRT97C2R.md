## Summary

In [[modern portfolio theory|ZBDA8W9D6V]], the efficient frontier is the set of portfolios that offer the highest expected return for each level of risk.
No portfolio on it can be improved in expected return without taking more risk.
In the plane of standard deviation and expected return it is the upper half of one branch of a [[hyperbola|0WN5G117YC]].
A rational mean–variance investor holds a portfolio on the efficient frontier.

## Explanations

### L1 human

Plot every possible portfolio as a point: how risky it is across, how much it earns on average up.
The points fill a region whose left edge curves like a bullet.
The upper half of that edge is the efficient frontier.
Any portfolio inside the region is beaten by one on the frontier that earns more for the same risk.
