## Example

Consider the following rule, which is not a rule of [[cutting planes|KKCX2HQP2K]].
From $\sum_i a_i x_i \geq \gamma$ and an integer $c \geq 2$, derive $\sum_i \floor{a_i / c} \, x_i \geq \ceil{\gamma / c}$, with no condition on the $a_i$.
We show that this rule is unsound.

1. Start from the line $x + 2y \geq 1$, which is the line of the clause $x \vee y$ with the coefficient of $y$ doubled. It holds at a $0$-$1$ point exactly when $x = 1$ or $y = 1$.
2. Take $c = 2$. The number $2$ does not divide the coefficient $1$ of $x$, so the cutting-planes division rule does not apply.
3. The rule above gives $\floor{1/2} x + \floor{2/2} y \geq \ceil{1/2}$, that is, $0 \cdot x + y \geq 1$, so $y \geq 1$.
4. The point $x = 1$, $y = 0$ satisfies the premise, since $1 + 0 = 1 \geq 1$.
5. The same point violates the conclusion, since $y = 0 < 1$.

So the rule derives a false line from a true one, and it is unsound.

## Remarks

The cutting-planes rule needs that $c$ divides every coefficient, because then the left side is an integer at every integer point.
Here $(1/2) x + y$ is not an integer at $x = 1$, $y = 0$, and the rounding of the right side up to $1$ is not justified.

Rounding the coefficients up instead of down gives a sound rule for $0$-$1$ points.
From $x + 2y \geq 1$ it gives $x + y \geq 1$, which holds exactly when $x = 1$ or $y = 1$.
The reason is that $\ceil{a_i/c} x_i \geq (a_i/c) x_i$ when $x_i \geq 0$, so the new left side is an integer that is at least $\gamma / c$.
This rule is a combination of the cutting-planes rules with the Boolean axioms: add $x \geq 0$ to $x + 2y \geq 1$ to get $2x + 2y \geq 1$, and divide by $2$.

## Explanations

### L1 human

Dividing an inequality by $2$ is safe, but throwing away the halves is not.
The statement "$x$ plus two times $y$ is at least $1$" is true when $x = 1$ and $y = 0$.
If we halve it and drop the half of $x$, we get "$y$ is at least $1$", which is false for the same values.

### L2 human

To test a proposed rule, look for a $0$-$1$ point that satisfies the premise and violates the conclusion.

1. The premise $x + 2y \geq 1$ holds at $(1, 0)$, $(0, 1)$ and $(1, 1)$.
2. The conclusion $y \geq 1$ holds only at $(0, 1)$ and $(1, 1)$.
3. The point $(1, 0)$ is a counterexample.

The correct way to divide $x + 2y \geq 1$ by $2$ is first to add the Boolean axiom $x \geq 0$, which makes every coefficient even.
A trap is to apply the division rule to a line in which only some coefficients are divisible by $c$.
