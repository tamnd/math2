## Example

Consider the following rule, which is not a rule of [[cutting planes|KKCX2HQP2K]].
From $\sum_i a_i x_i \geq \gamma$ and an integer $c \geq 2$, it derives $\sum_i \lfloor a_i / c \rfloor \, x_i \geq \lceil \gamma / c \rceil$, with no condition on the $a_i$.
We show that the rule is unsound with one line and one point.

1. Start from $x + 2y \geq 1$.
   At a $0$-$1$ point it holds exactly when $x = 1$ or $y = 1$, so it has the same solutions as the clause $x \vee y$.
2. Take $c = 2$.
   The number $2$ does not divide the coefficient $1$ of $x$, so the cutting-planes division rule does not apply.
3. The proposed rule gives the following line:
   $$\lfloor 1/2 \rfloor x + \lfloor 2/2 \rfloor y \geq \lceil 1/2 \rceil, \quad \text{that is,} \quad y \geq 1.$$
4. The point $x = 1$, $y = 0$ satisfies the premise, since $1 + 0 = 1 \geq 1$.
5. The same point violates the conclusion, since $y = 0 < 1$.

So the rule derives a false line from a true one, and a proof system with this rule would refute satisfiable formulas.

## Remarks

The divisibility condition is what makes the true rule sound.
When $c$ divides every coefficient, the left side is an integer at every integer point, so rounding the right side up loses no solution.
Here the honest quotient $(1/2) x + y$ equals $1/2$ at the point $(1, 0)$, and that value lies strictly between $0$ and $1$.
Rounding the right side up to $1$ is then not justified.

What changes if we round the coefficients up instead of down?
From $x + 2y \geq 1$ we then get $x + y \geq 1$, which is correct.
In general $\lceil a_i/c \rceil x_i \geq (a_i/c) x_i$ whenever $x_i \geq 0$, so the new left side is an integer that is at least $\gamma / c$.
This variant is not new: add the Boolean axiom $x \geq 0$ to $x + 2y \geq 1$ to get $2x + 2y \geq 1$, and divide by $2$.

## Explanations

### L1 human

Dividing an inequality by $2$ is safe, but throwing away the halves is not.
The statement "$x$ plus two times $y$ is at least $1$" is true when $x = 1$ and $y = 0$.
If we halve it and drop the half of $x$, we get "$y$ is at least $1$", which is false for the same values.

### L2 human

To test a proposed rule, look for a $0$-$1$ point that satisfies the premise and violates the conclusion.
The premise $x + 2y \geq 1$ holds at $(1, 0)$, $(0, 1)$ and $(1, 1)$.
The conclusion $y \geq 1$ holds only at $(0, 1)$ and $(1, 1)$, so $(1, 0)$ is a counterexample.
The correct way to divide $x + 2y \geq 1$ by $2$ is first to make every coefficient even, here by adding $x \geq 0$.
Watch out: a line in which only some coefficients are divisible by $c$ is not a premise of the division rule.
