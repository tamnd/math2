## Summary

Approximate counting measures the size of a set by maps instead of by listing its elements.
The even numbers below $16$ have size $8$, and a weak theory can see this without counting: the map $u \mapsto 2u$ sends $\{0, \dots, 7\}$ onto them, and $x \mapsto \lfloor x/2 \rfloor$ sends them back onto $\{0, \dots, 7\}$.
Emil Jeřábek built on this idea a way for theories of [[bounded arithmetic|A2CFPP8JMN]] to compare the sizes of sets given by [[Boolean circuits|SQXNFGVADX]].

In exact terms, let $X, Y \subseteq [0, 2^n)$ and $0 \le \varepsilon \le 1$, and identify a number $s$ with the interval $[0, s)$.
Write $v \times X$ for the set of pairs $(i, x)$ with $i < v$ and $x \in X$.
Then $X \preceq_\varepsilon Y$ means that there are a circuit $G$ and a number $v \ge 1$ such that every element of $v \times X$ is a value of $G$ on the set below:

$$v \times \big(Y \sqcup [0, \varepsilon 2^n)\big).$$

We write $X \approx_\varepsilon Y$ when $X \preceq_\varepsilon Y$ and $Y \preceq_\varepsilon X$.
The basic theory is $\mathsf{APC}_1 = \mathsf{PV}_1 + \mathrm{dWPHP}(\mathsf{PV})$: the first-order form of [[Cook's theory PV|FMM44KFZQT]] plus the dual weak [[pigeonhole principle|0HGVCWQGY3]] for polynomial-time functions.
In $\mathsf{APC}_1$, every set $X$ given by a circuit has an approximate size: for each $\varepsilon$ with $\varepsilon^{-1}$ of size polynomial in $n$, there is an $s$ with $X \approx_\varepsilon s$.

## Motivation

A circuit $C$ on $n = 100$ inputs defines a set of $100$-bit strings, and its exact size counts the satisfying assignments of $C$.
Computing that number is $\#\mathrm{P}$-hard, so a theory whose functions are polynomial-time cannot define it.
Yet the analysis of a [[randomized algorithm|2Y50S7GQTD]] needs only a probability, such as "at least $3/4$ of the random strings work", up to a small error.
Approximate counting gives weak theories exactly this kind of estimate.

The tool is the comparison by maps.
A map of $Y$ onto $X$ shows that $X$ is not larger than $Y$, and a polynomial-time map can be a term of the theory.
The dual weak pigeonhole principle guarantees that such comparisons never lie badly: no polynomial-time map sends a set onto a much larger set.
With this axiom Jeřábek formalized the classes [[BPP|PTD7E1PKV4]], $\mathrm{APP}$, $\mathrm{MA}$ and $\mathrm{AM}$ in weak theories.

## Notation

For a function $f$, $\mathrm{dWPHP}(f)$ says that for all $x > 0$ and $y$, some $v < x(\lvert y \rvert + 1)$ is not of the form $f(u)$ with $u < x \lvert y \rvert$.
It is also called the surjective weak pigeonhole principle, $\mathrm{sWPHP}$, and the schema over all polynomial-time $f$ is $\mathrm{dWPHP}(\mathsf{PV})$.
The injective version $\mathrm{iWPHP}$ forbids one-to-one maps of a large set into a small one, and the retraction version $\mathrm{rWPHP}$ is weaker than both.
The second standard theory is $\mathsf{APC}_2 = T^1_2 + \mathrm{dWPHP}(\mathsf{PV}_2)$, where $\mathsf{PV}_2$ means polynomial time with an $\mathrm{NP}$ oracle.
The error $\varepsilon$ in $\preceq_\varepsilon$ is measured against the whole interval $2^n$, not against $X$.

## Remarks

### A first comparison

Take $n = 4$, so the whole interval is $[0, 16)$, and let $X = \{3, 7, 11, 15\}$, the numbers whose last two binary digits are $11$.
To show $X \preceq_0 4$, take $v = 1$ and $G(u) = 4u + 3$:

$$G(0) = 3, \quad G(1) = 7, \quad G(2) = 11, \quad G(3) = 15.$$

To show $4 \preceq_0 X$, take $v = 1$ and $G(x) = \lfloor x/4 \rfloor$, which sends $3, 7, 11, 15$ to $0, 1, 2, 3$.
So $X \approx_0 4$, and a random number below $16$ lies in $X$ with probability $4/16 = 1/4$.
Check: $4u + 3 < 16$ exactly for $u \le 3$, so no value falls outside the interval.

The same two maps work for every $n$, and they are circuits of size polynomial in $n$.
Two more examples are on their own pages.
[[One instance of the dual principle|HBTQ8ZVSG6]] is checked with numbers, and [[a hard string|DRH5CFRPR7]] is obtained from the principle for a coding map of circuits.

### Why the principle is needed

Without an axiom, a comparison by maps could prove nonsense such as $2^n \preceq_0 2^{n-1}$.
In the standard numbers this cannot happen, but a weak theory cannot count to check it.
The principle $\mathrm{dWPHP}(\mathsf{PV})$ forbids exactly this: no polynomial-time map covers a set of size $2s$ from a set of size $s$.

From it Jeřábek derived that comparisons of numbers are sound.
If $s \preceq_0 t$ for $s, t \le 2^n$, then $s \le t + \delta 2^n$ for every $\delta$ with $\delta^{-1}$ of polynomial size.
This is why the approximate size $s$ of a set is unique up to the error.

### The rules you can use

Three rules hold already in $\mathsf{PV}_1$, and each has a one-line reason.
The relation $\preceq_\varepsilon$ is monotone in $\varepsilon$, because a larger padding interval only adds elements to the domain.
Inclusion $X \subseteq Y$ gives $X \preceq_0 Y$, by the identity map with $v = 1$.
If $X \preceq_\varepsilon Y$ and $Y \preceq_\delta Z$, then $X \preceq_{\varepsilon + \delta} Z$, by composing the two circuits.

In $\mathsf{APC}_1$ much more is true.
Every set given by a circuit has an approximate size, any two such sets are comparable, and the sizes satisfy inclusion and exclusion up to the errors.
By Wilkie's witnessing theorem, the $\forall \Sigma^b_1$ theorems of $S^1_2 + \mathrm{dWPHP}(\mathsf{PV})$ are witnessed by randomized polynomial-time algorithms.
$T^2_2$ proves $\mathrm{dWPHP}(\mathsf{PV})$, while neither $\mathsf{PV}_1$ nor $S^1_2$ is known to prove it.

### What it cannot do

Approximate counting cannot tell an empty set from a set with one element.
The set $\{x_0\}$ is covered from the padding $[0, \varepsilon 2^n)$ as soon as $\varepsilon 2^n \ge 1$, so $\{x_0\} \approx_\varepsilon 0$.
[[The single-element non-example|H8RF8WJHMA]] works out the maps, and it shows why the error must be relative to $2^n$.

Exact counting is also out of reach.
"The set $X$ has exactly $s$ elements" is not an approximate comparison, and $\mathsf{PV}_1$ cannot define the exact number for circuit-defined $X$.
Finally, a map given only by its full table is no witness: the table has about $2^n$ entries, and the theory need not have a number that codes it.

### Two theories and their uses

$\mathsf{APC}_1$ handles sets given by polynomial-size circuits, with additive error $\varepsilon 2^n$.
It suffices for the analysis of $\mathrm{BPP}$ algorithms and for the link between the dual principle and hard Boolean functions.

$\mathsf{APC}_2$ uses hashing, as in Sipser's proof that $\mathrm{BPP} \subseteq \Sigma^p_2$.
With its $\mathrm{NP}$ oracle it counts $\mathrm{NP}$ sets with an error that is a small fraction of the set itself.
Jeřábek used it to give a proof of the tournament principle in bounded arithmetic.

### History

Wilkie first connected $\mathrm{dWPHP}(\mathsf{PV})$ with randomized computation, and his witnessing theorem appears in Krajíček's book of 1995.
Krajíček studied $S^1_2 + \mathrm{dWPHP}(\mathsf{PV})$ under the name $\mathsf{BT}$.
In papers from 2004 to 2009, Jeřábek related the principle to hard Boolean functions, developed approximate counting in $\mathsf{PV}_1 + \mathrm{dWPHP}(\mathsf{PV})$, and then counting by hashing in $T^1_2$ plus the principle for $\mathsf{PV}_2$.

### Watch out

Do not read $X \approx_\varepsilon s$ as "$X$ has $s \pm \varepsilon \lvert X \rvert$ elements".
In $\mathsf{APC}_1$ the error is $\varepsilon 2^n$, so for $n = 10$ and $\varepsilon = 1/100$ the error is about $10$, even when $X$ has only $3$ elements.
Do not confuse the dual principle with the injective one either.
They are different schemas, and each of them implies the retraction version.

### Try it

1. Show that the odd numbers below $16$ satisfy $X \approx_0 8$.
   Answer: $u \mapsto 2u + 1$ covers them from $[0, 8)$, and $x \mapsto \lfloor x/2 \rfloor$ covers $[0, 8)$ from them.
2. With $n = 6$ and $\varepsilon = 1/8$, how large can a set be and still satisfy $X \approx_\varepsilon 0$ by the padding trick?
   Answer: the padding has $2^6/8 = 8$ elements, so a set with at most $8$ elements is covered by it.

## Explanations

### L1 human

Counting the elements of a large set one by one takes too long.
Often it is enough to know the size roughly, for example "about one half of all numbers below $1000$".
One way to compare sizes without counting is to pair elements: if every element of $X$ is hit from $Y$, then $X$ is not larger than $Y$.
Approximate counting builds a theory of sizes from such pairings.
The only extra axiom says that a small set cannot be mapped onto a much larger set.

### L2 human

Here is a typical estimate: what fraction of the $8$-bit numbers have last digit $0$ and second-to-last digit $1$?
These are the numbers $x < 256$ with $x \bmod 4 = 2$, so take $X = \{2, 6, 10, \dots, 254\}$.
The map $G(u) = 4u + 2$ covers $X$ from $[0, 64)$, and its largest value is $G(63) = 254$.
The map $x \mapsto \lfloor x/4 \rfloor$ covers $[0, 64)$ from $X$.
So $X \approx_0 64$, and the fraction is:

$$\frac{64}{256} = \frac{1}{4}.$$

Both maps are circuits of size polynomial in $n = 8$, so the theory sees them.
This is how a weak theory estimates the probability that a randomized algorithm succeeds.
Watch out for the copies $v \times X$: for sets with no simple structure a single map is too weak, and Jeřábek's definition needs the parameter $v$.

### L3 human

Approximate counting is the bounded-arithmetic form of the counting methods of complexity theory, such as Stockmeyer's approximate counting and Sipser's hashing.
Over $S^1_2$, $\mathrm{dWPHP}(\mathsf{PV})$ is equivalent to the existence of Boolean functions of exponential [[circuit complexity|4PGX7PHJCK]], a formal version of the theme of hardness versus randomness and [[pseudorandom generators|MD9THSA21A]].
So $\mathsf{APC}_1$ is a natural theory for reasoning about $\mathrm{BPP}$, and $\mathsf{APC}_2$ for approximate counting of $\mathrm{NP}$ sets.
The weak [[pigeonhole principles|NJ18EZ5JBC]] that these theories assume are among the principles studied in the [[separation problem|PEJQDHHX8E]] of bounded arithmetic.
