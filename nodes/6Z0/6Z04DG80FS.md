## Summary

The state-transition matrix $\Phi(t, t_0)$ of a linear system $x' = A(t) x$ is the matrix that maps the state at time $t_0$ to the state at time $t$.
It solves the homogeneous system for all initial states at once, and with it the forced system $x' = A(t) x + B(t) u$ is solved by an explicit integral.
For a constant matrix $A$ it is the [[matrix exponential|020M04FN1H]] $e^{A(t - t_0)}$.
It is the basic tool for linear time-varying systems in [[control theory|JXZ0GZXET1]].

## Explanations

### L1 human

Think of the state of a system as a point that moves with time.
For a linear system, where the point ends up depends linearly on where it started, so the move from time $t_0$ to time $t$ is given by a matrix.
That matrix is the state-transition matrix.
For the scalar equation $x' = a x$, it is the number $e^{a(t - t_0)}$, since $x(t) = e^{a(t - t_0)} x(t_0)$.
