## Summary

Binary search finds a target value in a sorted array.
It compares the target with the middle element of the remaining range and discards the half that cannot contain it.
On an array of $n$ elements it uses at most $\floor{\log_2 n} + 1$ comparisons with array elements.
It is the basic example of a logarithmic-time [[algorithm|9DMSG5HAQX]], and the same halving idea solves many search problems over monotone predicates.

## Explanations

### L1 human

This is the game "guess my number between $1$ and $100$" played well: always guess the middle, and the answer "higher" or "lower" removes half the candidates.
After $7$ guesses at most, the number is found, since $2^7 = 128 > 100$.
In a sorted list, look at the middle entry; if the target is larger, keep only the right half, otherwise the left half, and repeat.
