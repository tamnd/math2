## Definition

Let $n \ge 1$ and let $\oplus$ be the coordinatewise sum modulo $2$ on $\set{0,1}^n$.
The *one-time pad* of length $n$ is the [[cryptosystem|7YNRCX56CM]] with the following data.

1. The plaintexts, ciphertexts and keys are all the strings in $\set{0,1}^n$.
2. The key $k$ is chosen with the [[discrete uniform distribution|02MY6WZXEQ]] on $\set{0,1}^n$.
3. Encryption is $e_k(m) = m \oplus k$ and decryption is $d_k(c) = c \oplus k$.

Each key encrypts a single message.

## Remarks

Example: with $n = 4$, $m = 0110$ and $k = 1100$, the ciphertext is $c = 1010$.
Decryption gives $1010 \oplus 1100 = 0110 = m$, because $k \oplus k = 0$.

Non-example: encrypting two messages $m, m'$ with the same key $k$ breaks the last condition.
Then $c \oplus c' = m \oplus m'$, which reveals, for instance, whether $m = m'$.

The same construction works over any finite group $G$: keys are uniform in $G$, $e_k(m) = mk$ and $d_k(c) = ck^{-1}$.
The Vernam cipher is the binary case, and the case $G = (\Z/26\Z)^n$ acts on letters.
