## Example

Take the structure $(\mathbb{N}, <, \cdot)$, and read $\varepsilon$ by the [[choice function|0FWBQ53MPJ]] $\Phi$ with $\Phi(S) = \min S$ for nonempty $S \subseteq \mathbb{N}$ and $\Phi(\emptyset) = 0$.
We evaluate two terms of the [[epsilon calculus|TH5ZKCKN3W]] and check the critical formulas.

1. The set of $x$ with $3 < x$ is $\set{4, 5, 6, \dots}$. So $\varepsilon x \, (3 < x)$ denotes $\min \set{4, 5, \dots} = 4$.
2. The critical formula $3 < t \to 3 < \varepsilon x \, (3 < x)$ holds for every value of $t$, because its consequent $3 < 4$ is true.
3. The set of $x$ with $x \cdot x = 2$ is empty, since $1 \cdot 1 = 1$ and $2 \cdot 2 = 4$, and squares grow from there. So $\varepsilon x \, (x \cdot x = 2)$ denotes the default value $0$.
4. The critical formula $t \cdot t = 2 \to \varepsilon x \, (x \cdot x = 2) \cdot \varepsilon x \, (x \cdot x = 2) = 2$ holds for every value of $t$, because its antecedent is always false.
5. The formula $A(\varepsilon x \, A)$ for $A = (x \cdot x = 2)$ says $0 \cdot 0 = 2$, which is false. This matches $\exists x \, (x \cdot x = 2)$ being false.

So $\varepsilon$-terms always denote, and their critical formulas hold, also when no witness exists.

## Remarks

Another choice function gives other values: $\varepsilon x \, (3 < x)$ may denote any element of $\set{4, 5, \dots}$, for example $10$.
By the axiom of choice, every structure has a choice function on its nonempty subsets.
So every model of a first-order theory becomes a model of the epsilon calculus, which is the semantic reason for the second epsilon theorem.

## Explanations

### L1 human

The term $\varepsilon x \, (3 < x)$ means "some number bigger than $3$".
If the rule is "always take the smallest", it means $4$.
For "some number whose square is $2$", there is none, so the term gets an agreed default value, here $0$.

### L2 human

We compare with the description operator $\iota$.

1. The phrase "the number bigger than $3$" fails, since many numbers are bigger than $3$.
2. The phrase "the number whose square is $2$" fails, since there is none.
3. The term $\varepsilon x$ succeeds in both cases. It picks one number or a default.

The typical use is to have a term for every formula, without proving existence first.
A trap: the value of an $\varepsilon$-term depends on the choice function, so its exact value is not determined by the axioms.
