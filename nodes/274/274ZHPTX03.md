## Definition

Let $(V, \eta)$ be [[Minkowski space|G49G4R1K04]].
A *four-vector* is an element $A$ of $V$.
In an inertial frame, given by a basis $e_0, e_1, e_2, e_3$ in which $\eta = \operatorname{diag}(-1, 1, 1, 1)$, it has components $(A^0, A^1, A^2, A^3)$ with $A = \sum_\mu A^\mu e_\mu$.
If a second inertial frame has components $x'^\mu = \sum_\nu \Lambda^\mu{}_\nu x^\nu$ for a [[Lorentz transformation|WEVGN4C7PQ]] $\Lambda$, then the components of $A$ in it are
$$A'^\mu = \sum_{\nu = 0}^{3} \Lambda^\mu{}_\nu A^\nu.$$
Equivalently, a four-vector quantity assigns four components to each inertial frame.
The components in any two frames must be related in this way.

## Remarks

Example: the displacement $\Delta x = (c \Delta t, \Delta x^1, \Delta x^2, \Delta x^3)$ between two events is a four-vector, since coordinates of events change by $\Lambda$ followed by a translation and the translation cancels in differences.
Non-example: the quadruple $(c, u_x, u_y, u_z)$ built from the ordinary velocity $\mathbf{u}$ of a particle is not a four-vector.
In the rest frame of the particle it is $(c, 0, 0, 0)$.
The boost to a frame where the particle has velocity $v$ along $x$ turns this into $(\gamma c, \gamma v, 0, 0)$, which differs from $(c, v, 0, 0)$.
The number $\eta(A, B) = -A^0 B^0 + A^1 B^1 + A^2 B^2 + A^3 B^3$ is the same in every frame.
Indices are lowered with $\eta$: $A_\mu = \sum_\nu \eta_{\mu\nu} A^\nu$, so that $\eta(A, B) = \sum_\mu A_\mu B^\mu$.
