## Example

Let $\mathcal{L}$ be the [[infinitary logic|PQG7VAZ1R2]] $L_{\omega_1\omega}$ with countable signatures.
Its [[Hanf number|A9XBRF3A7Z]] is $\beth_{\omega_1}$, by Morley's argument.
Let $\varphi$ be a sentence of $L_{\omega_1\omega}$ with a model of size at least $\beth_{\omega_1}$.

1. Reduction. By the Remarks, there are a countable first-order theory $T_\varphi$ and a countable set $\Sigma$ of [[types|9V71Q3SD1G]] such that the models of $\varphi$ are the [[reducts|EY20BF96SJ]] of the models of $T_\varphi$ that omit $\Sigma$.
2. Skolemize $T_\varphi$ to a countable theory $T^*$ with [[Skolem functions|NKQY9NB955]]. Models of $T_\varphi$ that omit $\Sigma$ expand to models of $T^*$ that still omit $\Sigma$.
3. Families. For $p(\bar{y}) \in \Sigma$ and a tuple $\bar{t}(\bar{v})$ of Skolem terms, let $\Psi_{p, \bar{t}} = \set{\neg \sigma(\bar{t}(\bar{v})) : \sigma \in p}$. There are countably many such families.
4. Models. For $\alpha < \omega_1$, let $\mathcal{M}_\alpha \models T^*$ omit $\Sigma$, with $\abs{M_\alpha} \ge \beth_\alpha$ and any linear order. For increasing $\bar{a}$, the tuple $\bar{t}(\bar{a})$ does not realize $p$, so $\bar{a}$ satisfies some formula of $\Psi_{p, \bar{t}}$.
5. Indiscernibles. Morley's form of the [[existence of indiscernibles|RG6D2FAS14]] gives, for each infinite order $I$, an indiscernible sequence $(a_i)_{i \in I}$. For each family one formula holds at all increasing tuples.
6. The Skolem hull is the [[Ehrenfeucht-Mostowski model|TSGB29FJM0]] $\operatorname{EM}(I, \Phi)$. Each element tuple is $\bar{t}(\bar{a})$ for an increasing $\bar{a}$, so the model omits $\Sigma$, and its $L$-reduct satisfies $\varphi$.
7. Since $\abs{\operatorname{EM}(I, \Phi)} = \abs{I}$, $\varphi$ has models of every infinite size. So $h(L_{\omega_1\omega}) \le \beth_{\omega_1}$.
8. The sentences of [[this example|CGEPN90SDZ]] give the reverse inequality $h(L_{\omega_1\omega}) \ge \beth_{\omega_1}$.

## Remarks

### Chang's reduction

Let $F$ be a countable set of formulas of $L_{\omega_1\omega}$ that contains $\varphi$ and is closed under subformulas.
For each $\psi(\bar{x}) \in F$ take a new relation symbol $R_\psi$.
The theory $T_\varphi$ says that $R_\varphi$ holds, that $R_\psi \leftrightarrow \psi$ for atomic $\psi$, and that $R$ commutes with negation, finite conjunction and quantifiers.
For each $\bigwedge_n \psi_n$ in $F$ it also says $R_{\bigwedge_n \psi_n}(\bar{x}) \to R_{\psi_n}(\bar{x})$ for every $n$.
The type $p_{\bigwedge_n \psi_n} = \set{R_{\psi_n}(\bar{x}) : n \in \N} \cup \set{\neg R_{\bigwedge_n \psi_n}(\bar{x})}$ is put in $\Sigma$.
In a model that omits $\Sigma$, induction on $F$ shows that $R_\psi$ defines the set of tuples that satisfy $\psi$, so the reduct satisfies $\varphi$.
Conversely, interpreting $R_\psi$ as the set defined by $\psi$ expands each model of $\varphi$.

### Comments

- The same argument shows that the Hanf number for omitting a countable set of types in a countable first-order theory is $\beth_{\omega_1}$.
- The bound $\beth_\alpha$ for every $\alpha < \omega_1$ enters through the [[Erdős-Rado theorem|S1BHE358VX]] in the proof of Morley's form.
- Step 4 needs only a model of size at least $\beth_\alpha$ for each $\alpha < \omega_1$ separately. One model of size $\beth_{\omega_1}$ serves for all $\alpha$.

## Explanations

### L1 human

A sentence of this logic can say things that ordinary first-order sentences cannot, such as "every element is one of these constants".
So some sentences have only models below a certain size.
Morley showed that a sentence with a model of size $\beth_{\omega_1}$ has models of every infinite size.
The method replaces the large model by a model built from an ordered list of elements that all look alike.
Such a list can be stretched to any length, and the model stretches with it.

### L2 human

We check step 6 for one type $p(y) \in \Sigma$ in one variable and an element $t(a_{i_1}, a_{i_2})$ with $i_1 < i_2$.

1. Step 5 gives $\sigma \in p$ such that $\neg \sigma(t(v_1, v_2))$ holds at all increasing pairs of the sequence.
2. In particular $\neg \sigma(t(a_{i_1}, a_{i_2}))$ holds, so this element does not realize $p$.
3. An element $t(a_{i_2}, a_{i_1})$ is also covered, as it equals $t'(a_{i_1}, a_{i_2})$ for the term $t'(v_1, v_2) = t(v_2, v_1)$.

The typical use is as a size threshold: to show that a sentence of $L_{\omega_1\omega}$ has arbitrarily large models, it suffices to find models of size at least $\beth_\alpha$ for all $\alpha < \omega_1$.
The trap is to apply the ordinary existence of indiscernibles: it gives an indiscernible sequence, but its Skolem hull may realize the omitted types.
