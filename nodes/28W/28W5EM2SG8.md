## Example

Consider the lower bound
$$x^2 + 1 \ge 0 \quad \text{for all real } x.$$
We show that the bound is true, but that the constant $0$ is not [[sharp|KWQV0G0VJ3]].

1. The bound holds.
   For each real $x$ we have $x^2 \ge 0$, so $x^2 + 1 \ge 1 > 0$.
2. A larger lower bound holds.
   Step 1 already shows $x^2 + 1 \ge 1$ for every real $x$, and $1 > 0$.
   So the constant $0$ can be raised, and the bound with $0$ is not best possible.
3. The bound with $1$ is sharp.
   At $x = 0$ we get $x^2 + 1 = 1$.
   So for any $c > 1$ the claim $x^2 + 1 \ge c$ fails at $x = 0$.

So $0$ is a true lower bound but not the best one, and the sharp lower bound is $1$, attained at $x = 0$.

## Remarks

For a lower bound "sharp" means that no larger constant works.
The sharp lower bound is the infimum of $x^2 + 1$ over the real numbers, which is $1$.
Every constant $c \le 1$ gives a true bound $x^2 + 1 \ge c$, but only $c = 1$ is sharp.

The bound with $0$ is not attained either, but that is not the reason it fails to be sharp.
The bound $\frac{x}{1 + x} < 1$ for $x > 0$ is never attained and is still sharp.
What fails here is that a better constant exists.

If we change the function to $x^2 - 2x + 1 = (x - 1)^2$, the bound $\ge 0$ becomes sharp, since $x = 1$ gives $0$.
A bound that is true but not sharp is still useful when a proof needs only a weak fact, such as $x^2 + 1 \ne 0$, which shows that $\frac{1}{x^2 + 1}$ is defined for every real $x$.

## Explanations

### L1 human

The number $x^2 + 1$ is never negative.
But it is also never smaller than $1$.
So "at least $0$" is true, and "at least $1$" is true and better.
The value $x = 0$ gives exactly $1$, so "at least $1$" is the best bound of this kind.

### L2 human

To test whether a lower bound $f(x) \ge c$ is sharp, compute the infimum of $f$ and compare it with $c$.
Here $f(x) = x^2 + 1$, and $f(x) \ge 1$ with $f(0) = 1$, so
$$\inf_{x \in \mathbb{R}} f(x) = 1.$$
Since $c = 0 < 1$, the bound with $c = 0$ is not sharp.
The test works for any lower bound: the bound is sharp exactly when $c$ equals the infimum.
