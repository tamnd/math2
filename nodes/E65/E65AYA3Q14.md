## Example

Take the two-sorted language of [[vector spaces|Z8Z0HGXK6D]], with $+_V \colon V \times V \to V$ and $+_F \colon F \times F \to F$.
Let $a$ be a variable of sort $F$ and $v$ a variable of sort $V$.
We check that "$a + v$" is not a term of [[many-sorted logic|7TDHDN8P96]] in either reading of $+$.

1. In many-sorted logic, $f(t_1, \dots, t_n)$ is a [[term|6D3WA7N2W4]] only when $f \colon s_1 \times \dots \times s_n \to s$ and each $t_i$ is a term of sort $s_i$.
2. Read $+$ as $+_V$. Its first argument must have sort $V$, but $a$ has sort $F$. So $a +_V v$ is not a term.
3. Read $+$ as $+_F$. Its second argument must have sort $F$, but $v$ has sort $V$. So $a +_F v$ is not a term.
4. No other function symbol is written $+$, so "$a + v$" is not a term.

So the sort discipline rejects "scalar plus vector" at the level of syntax.

## Remarks

In the one-sorted relativization, $a + v$ is a term, and it has some value in every structure.
The axioms then say nothing about this value, so it is harmless but meaningless.
The many-sorted syntax removes such terms, which makes formulas closer to mathematical practice.
The well-sorted term $a \ast v +_V v$ is fine: $a \ast v$ has sort $V$.

## Explanations

### L1 human

One cannot add the number $2$ to the vector $(1, 3)$.
In two-sorted logic, this rule is part of the grammar.
The expression "$2 + (1, 3)$" is not a term at all, in the same way as "$x <$" is not a formula.

### L2 human

We sort-check three expressions.

1. $a \ast v$: $\ast$ needs sorts $F$ and $V$, and gets $a{:}F$ and $v{:}V$. A term of sort $V$.
2. $v \ast a$: $\ast$ gets $v{:}V$ first, but needs sort $F$ first. Not a term.
3. $(a \cdot_F a) \ast (v +_V v)$: both arguments have the right sorts. A term of sort $V$.

The typical use of the sort check is in proof assistants, where it is a type check.
A trap: in informal writing $v a$ and $a v$ both appear, but in a sorted signature the order of arguments is fixed.
