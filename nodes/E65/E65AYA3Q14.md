## Example

Take the two-sorted language of [[vector spaces|Z8Z0HGXK6D]], with sorts $F$ for scalars and $V$ for vectors.
It has two addition symbols, $+_V \colon V \times V \to V$ and $+_F \colon F \times F \to F$.
Let $a$ be a variable of sort $F$ and $v$ a variable of sort $V$.
We check that "$a + v$" is not a term of [[many-sorted logic|7TDHDN8P96]] in either reading of $+$.

1. The rule for terms: $f(t_1, \dots, t_n)$ is a [[term|6D3WA7N2W4]] only when $f \colon s_1 \times \dots \times s_n \to s$ and each $t_i$ is a term of sort $s_i$.
2. Read $+$ as $+_V$.
   Its first argument must have sort $V$, but $a$ has sort $F$, so $a +_V v$ is not a term.
3. Read $+$ as $+_F$.
   Its second argument must have sort $F$, but $v$ has sort $V$, so $a +_F v$ is not a term.
4. No other symbol of the signature is written $+$, so "$a + v$" is not a term at all.

So the sort rules reject "scalar plus vector" as a matter of grammar, before any structure is chosen.

## Remarks

Compare the one-sorted translation, where scalars and vectors share one domain.
There $a + v$ is a term, and it has some value in every structure, but the axioms say nothing about that value.
So the term is harmless and meaningless at once, and the many-sorted syntax simply removes it.

A small change gives a correct term.
With scalar multiplication $\ast \colon F \times V \to V$, the expression $a \ast v +_V v$ is a term of sort $V$, because $a \ast v$ already has sort $V$.

## Explanations

### L1 human

You cannot add the number $2$ to the arrow $(1, 3)$.
In two-sorted logic this rule is part of the grammar.
The expression "$2 + (1, 3)$" is not a term at all, in the same way as "$x <$" is not a formula.

### L2 human

We sort-check three expressions, with $\ast \colon F \times V \to V$ and $\cdot_F \colon F \times F \to F$.
The first is $a \ast v$: the symbol $\ast$ needs the sorts $F$ and $V$ and gets $a{:}F$ and $v{:}V$, so it is a term of sort $V$.
The second is $v \ast a$: the symbol $\ast$ gets $v{:}V$ in the first place, where it needs sort $F$, so it is not a term.
The third is $(a \cdot_F a) \ast (v +_V v)$: the arguments have sorts $F$ and $V$ in the right order, so it is a term of sort $V$.
The typical use of a sort check is in proof assistants, where it is the type check that runs before any proof.
Watch out: informal writing uses both $av$ and $va$, but in a sorted signature the order of arguments is fixed.
