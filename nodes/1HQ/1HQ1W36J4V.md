## Statement

Let $\varphi$ be a modal formula with variables $p_1, \dots, p_n$, and let $\mathrm{ST}_x$ be the [[standard translation|YW6YGBMVQY]].
Read a [[Kripke model|NGHWZ9Y7ZV]] $\mathfrak{M} = (W, R, V)$ as the first-order structure with domain $W$.
In this structure, $R$ interprets the relation symbol $R$, and $V(p_i)$ interprets the predicate $P_i$.

1. Variables. $\mathrm{ST}_x(\varphi)$ has no free variable other than $x$, and it contains no variable other than $x$ and $y$. The same holds for $\mathrm{ST}_y(\varphi)$ with $x$ and $y$ exchanged.
2. Local truth. For every $w \in W$, $\mathfrak{M}, w \models \varphi$ if and only if $\mathfrak{M} \models \mathrm{ST}_x(\varphi)[x \mapsto w]$.
3. Global truth. $\mathfrak{M} \models \varphi$ if and only if $\mathfrak{M} \models \forall x\, \mathrm{ST}_x(\varphi)$.
4. Frame validity. For a [[frame|6BQ71KQ6QT]] $\mathfrak{F} = (W, R)$, $\mathfrak{F} \models \varphi$ if and only if $\mathfrak{F} \models \forall P_1 \dots \forall P_n\, \forall x\, \mathrm{ST}_x(\varphi)$, a sentence of monadic [[second-order logic|G6X7SZSNC5]].

The proof is in [[the proof of correctness|EAK51TNH1M]].

## Remarks

### Why each hypothesis is needed

1. The structure must interpret $P_i$ as $V(p_i)$. With another interpretation, part 2 compares $\varphi$ with a different valuation, and it fails in general.
2. Part 4 needs the second-order quantifiers. Without them, $\forall x\, \mathrm{ST}_x(\varphi)$ is global truth in one model. For $\varphi = \square p \to \square\square p$, it can hold on a frame that is not transitive, see [[the axiom 4 example|NA6H3978PW]].
3. Part 1 depends on the reuse of variables in the definition. With a new variable for each box, the translation has as many variables as the modal depth plus one.

### Consequences

1. Modal logic over all models inherits compactness and the Löwenheim-Skolem theorem from [[first-order logic|086QKPF0A6]].
2. Each modal formula is equivalent to a formula of the two-variable fragment, which is decidable, so satisfiability over all models is decidable.
3. Frame validity of a modal formula is a $\Pi^1_1$ property. For many formulas it is first-order, see [[the second-order translation of T|KM2BKWZKW8]] and [[common modal axiom schemata|FDFQFWPM4X]].
4. Worked computations: [[the translation of a box and a diamond|ZWH6KH29YT]].

### Converse

Not every first-order formula in one free variable is equivalent to a translation, see [[the reflexive point|SB9HMACX5D]].
The exact image, up to equivalence, is the class of bisimulation-invariant formulas, by van Benthem's theorem in [[modal model theory|SPQVNPZDTB]].

### Generalizations

1. For several boxes, use one relation symbol $R_i$ for each box; the same proof works, see [[multimodal logic|ERG3KAQWYF]].
2. For temporal operators with the converse relation, $\mathrm{ST}_x(\mathrm{H}\varphi) = \forall y\,(R(y, x) \to \mathrm{ST}_y(\varphi))$.
3. For the universal modality, $\mathrm{ST}_x(\mathrm{A}\varphi) = \forall y\, \mathrm{ST}_y(\varphi)$.

## History

The translation was made systematic in van Benthem's dissertation of 1976.
The observation that two variables suffice is due to Gabbay, around 1981.

## Explanations

### L1 human

The translation is faithful.
A modal statement is true at a world exactly when its translation, read in ordinary logic, is true of that world.
A statement holds on a whole frame for every choice of facts exactly when a second-order sentence holds.

### L2 human

We check part 2 for $\varphi = \lozenge p$ on a small model.

1. Take $W = \set{a, b}$, $R = \set{(a, b)}$ and $V(p) = \set{b}$.
2. $\mathrm{ST}_x(\lozenge p)$ is equivalent to $\exists y\,(R(x, y) \wedge P(y))$.
3. At $x = a$: $y = b$ gives $R(a, b)$ and $P(b)$, so the translation holds. Modally, $a$ sees $b$, where $p$ is true, so $\lozenge p$ is true at $a$.
4. At $x = b$: no $y$ has $R(b, y)$, so the translation fails. Modally, $b$ has no successor, so $\lozenge p$ is false at $b$.

The typical use is to transfer a first-order theorem to modal logic.
A trap: part 2 is about one model; part 4, about frames, quantifies over all valuations.

### L3 human

Part 4 places frame validity at the level of $\Pi^1_1$, and this is optimal in general.
Thomason showed in 1975 that the consequence relation between modal formulas over frames is as complex as consequence in full second-order logic.
Part 1 places local truth in the two-variable fragment, whose satisfiability problem is NEXPTIME-complete.
But modal satisfiability is only PSPACE-complete, by [[the complexity theorem|1P2B0C7CQ4]].
The guarded fragment explains this gap better.
