## Summary

A **residue number system** or **residue numeral system** (**RNS**) is a numeral system representing [[integers|0C4JS9RF5M]] by their values modulo several pairwise coprime integers called the moduli. This representation is allowed by the [[Chinese remainder theorem|0FNN9B4W64]], which asserts that, if $M$ is the product of the moduli, there is, in an interval of length $M$, exactly one integer having any given set of modular values. Using a residue numeral system for arithmetic operations is also called **multi-modular arithmetic**.
