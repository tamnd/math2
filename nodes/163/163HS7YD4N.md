## Definition

Consider a [[stochastic program|2YW60J1GT6]] $\min_{x \in X} \mathbb{E}[F(x, \xi)]$, where $\xi$ is a random vector with values in $\Xi$.
Let $\xi^1, \dots, \xi^N$ be [[independent random vectors with the same distribution|00MRN0FARV]] as $\xi$.
The *sample average approximation* of the problem is
$$\min_{x \in X} \hat f_N(x), \qquad \hat f_N(x) = \frac{1}{N} \sum_{j=1}^{N} F(x, \xi^j).$$
Let $\hat v_N$ be its optimal value and $\hat S_N$ its set of minimizers.
They are the *SAA estimators* of the optimal value and of the solution set of the true problem.

## Remarks

For each fixed $x$, $\hat f_N(x) \to \mathbb{E}[F(x, \xi)]$ almost surely by the [[strong law of large numbers|0DFWHQ839T]].
Suppose $X$ is compact, $F(\cdot, \xi)$ is continuous for almost every $\xi$, and $\abs{F(x, \xi)}$ is bounded by an integrable function of $\xi$.
Then $\hat f_N$ converges uniformly on $X$ almost surely, so $\hat v_N$ tends to the true optimal value almost surely.
It is a [[Monte Carlo method|HWP11G3HTN]].

Example: the newsvendor objective $F(x, \xi) = c x - p \min(x, \xi)$ with $0 < c < p$.
Given demand samples $\xi^1, \dots, \xi^N$, the function $\hat f_N$ is piecewise linear, and its slope at $x$ is $c - p \cdot \#\set{j : \xi^j > x} / N$.
So $\hat f_N$ is minimized where the fraction of samples above $x$ drops below $c/p$, that is, at an empirical quantile of order $(p - c)/p$.

Non-example: solving $\min_{x \in X} F(x, \bar\xi)$ with one fixed value $\bar\xi$, such as the mean, is not a sample average approximation.
It does not use a sample of $\xi$ and does not converge to the stochastic program as $N$ grows.
