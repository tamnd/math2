## Example

Fix a real number $\varepsilon > 0$.
We show that the statement "$1/n < \varepsilon$" holds [[for all sufficiently large|FEQ7WATMHF]] positive integers $n$, and we find a threshold $N$.

1. Put $N = \lfloor 1/\varepsilon \rfloor + 1$, where $\lfloor x \rfloor$ is the largest integer at most $x$. Then $N > 1/\varepsilon$, and $N \geq 1$.
2. Let $n \geq N$. Then $n > 1/\varepsilon > 0$, so $1/n < \varepsilon$.
3. So "$1/n < \varepsilon$" holds for all $n \geq N$, and it holds eventually.
4. This $N$ is the least threshold. For $n = N - 1 = \lfloor 1/\varepsilon \rfloor$ with $n \geq 1$, we have $n \leq 1/\varepsilon$, so $1/n \geq \varepsilon$.
5. A numerical case: for $\varepsilon = 0.03$, we get $1/\varepsilon = 33.33\ldots$ and $N = 34$. We check $1/34 = 0.0294\ldots < 0.03$, while $1/33 = 0.0303\ldots > 0.03$.
6. A case with equality: for $\varepsilon = 0.25$, we get $1/\varepsilon = 4$ and $N = 5$. At $n = 4$ we have $1/4 = 0.25$, which is not less than $0.25$, so the $+1$ in the formula for $N$ is needed.

## Remarks

The threshold $N$ depends on $\varepsilon$: a smaller $\varepsilon$ needs a larger $N$.
Step 1 uses the [[Archimedean property|0A74SX55QP]] of the real numbers, which says that some integer is larger than $1/\varepsilon$.
Since the statement holds eventually for every $\varepsilon > 0$, the sequence $1/n$ converges to $0$, by the [[definition of the limit of a sequence|05M5SWSZZD]].
The [[order of quantifiers|0FYQMKFE77]] matters here: for each $\varepsilon$ there is an $N$, but no single $N$ works for every $\varepsilon$.

## Explanations

### L1 human

The fractions $1, \tfrac12, \tfrac13, \tfrac14, \ldots$ get as small as we want.
Pick any small target, say $0.03$.
The fractions are above the target at first, but from $1/34$ on they are all below it.
For a smaller target we must go further along the list, but some point always exists.

### L2 human

We compute the threshold for $\varepsilon = 10^{-3}$ and check it.

1. We have $1/\varepsilon = 1000$, so $N = \lfloor 1000 \rfloor + 1 = 1001$.
2. For $n = 1001$, $1/1001 < 1/1000$, so the statement is true.
3. For $n = 1000$, $1/1000 = \varepsilon$, so the strict inequality fails, and $1000$ is not a threshold.

The typical use is a proof that a sequence converges: we find, for each $\varepsilon$, a threshold that works.
A trap: the statement "eventually, $1/n < \varepsilon$ for every $\varepsilon > 0$" is false, because $1/n$ is never $0$.
