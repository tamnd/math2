## Summary

A **tree of primitive Pythagorean triples** is a [[mathematical tree|062D9KXJB1]] in which each node represents a primitive [[Pythagorean triple|01G1WY1GVX]] and each primitive Pythagorean triple is represented by exactly one node. In two of these trees, Berggren's tree and Price's tree, the root of the tree is the triple $(3, 4, 5)$, and each node has exactly three children, generated from it by linear transformations.
