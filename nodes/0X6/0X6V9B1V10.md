## Summary

A [[system of linear equations|0GT4WWGWH2]] over a field $F$ is consistent when it has at least one solution in $F^n$, and inconsistent when it has no solution.
The exact definition is in [[the definition node|04JAAVHDDM]].
Row reduction decides which case holds: the system is inconsistent exactly when an echelon form of the augmented matrix has a row $(0, \dots, 0 \mid c)$ with $c \ne 0$.
In terms of rank, $Ax = b$ is consistent exactly when $\rank A = \rank [A \mid b]$, which is the [[Rouché-Capelli theorem|0HV1SKWPMS]].
Consistency is the first question about any system, because the description of the solutions makes sense only when solutions exist.

## Motivation

A model of a real situation often gives more conditions than unknowns, and the conditions can contradict each other.
Before we look for a formula for the solutions, we must know whether any solution exists.
Geometrically, two parallel lines in the plane have no common point, and three planes can fail to meet even when each two of them meet.
Elimination detects such a contradiction mechanically: it produces the equation $0 = c$ with $c \ne 0$.

## Notation

Some books say "solvable" for consistent and "unsolvable" for inconsistent.
The word "consistent" also has a meaning in logic, where a set of axioms is consistent when it does not prove a contradiction; the two meanings agree in spirit.

## Remarks

### Examples

1. The system $x + y = 3$, $x - y = 1$ is consistent, with solution $(2, 1)$.
2. The system $x + y = 2$, $x - y = 0$, $x + 2y = 4$ is inconsistent, although any two of its equations are consistent, see [[the inconsistent triangle|XJX2NN45ED]].
3. Every homogeneous system $Ax = 0$ is consistent, because $x = 0$ is a solution.
4. The system $x + y + z = 1$, $x + 2y + 3z = 2$, $x + 3y + 5z = a$ is consistent exactly when $a = 3$, see [[the parameter example|2WB9Z90K4Y]].
5. The equation $2x = 1$ is consistent over $\mathbb{Q}$ and inconsistent over $\mathbb{F}_2$, see [[the field example|WT7RS59FGD]].

### Non-examples

1. The equation $2x + 4y = 1$ is consistent over $\mathbb{Q}$, so it is not an inconsistent system, even though it has no solution in integers, see [[the integer example|MME3Y9VCHR]].
2. The nonlinear equation $x^2 = -1$ has no real solution, but "inconsistent system" in this topic refers to linear systems only.

### Basic properties

1. A system is inconsistent if and only if some linear combination of its equations is the equation $0 = 1$.
2. Row operations do not change consistency, because they do not change the solution set, see [[the theorem on row operations|K41GT10YM6]].
3. If $Ax = b$ is consistent for one $b$, it need not be consistent for another $b$.
4. $Ax = b$ is consistent for every $b \in F^m$ if and only if $A$ has a pivot in every row, see [[the existence and uniqueness theorem|BKA191KD1S]] and [[the pivot criterion|HJTF7B36W9]].
5. A consistent system over a field $F$ stays consistent over every field that contains $F$, since the same solution works.

### History

The test by ranks is due to Kronecker, Rouché, Fontené, Frobenius and Capelli, in the 1860s to 1890s.
The word "inconsistent" for systems without solutions is standard in English textbooks such as Lay.

### Common errors

1. Thinking that a system with more equations than unknowns must be inconsistent. The system $x = 1$, $2x = 2$ is consistent.
2. Thinking that a zero row in the coefficient part means inconsistency. Only a row $(0, \dots, 0 \mid c)$ with $c \ne 0$ in the augmented matrix does.
3. Comparing the rank of $A$ with the number of unknowns to decide consistency. That comparison decides uniqueness, not existence.

## Explanations

### L1 human

A system is consistent when there is at least one way to make all the equations true together.
The equations $x + y = 1$ and $x + y = 2$ cannot both be true, because the same sum cannot be $1$ and $2$.
So that system is inconsistent.
In a picture, the two lines are parallel and never meet.
Elimination shows the problem directly: subtracting the equations gives $0 = 1$.

### L2 human

We decide whether $x + 2y = 3$, $2x + 4y = 7$ is consistent.

1. The augmented matrix is $\left[\begin{array}{rr|r} 1 & 2 & 3 \\ 2 & 4 & 7 \end{array}\right]$.
2. $R_2 \leftarrow R_2 - 2R_1$ gives $(0, 0 \mid 1)$.
3. This row says $0x + 0y = 1$, which no pair satisfies.
4. So the system is inconsistent.
5. With right-hand side $(3, 6)$ the same step gives $(0, 0 \mid 0)$, and the system is consistent, with solutions $(3 - 2t, t)$.

The typical use is to test whether a vector $b$ is a combination of given vectors.
A trap: the [[reduced row echelon form|0WF5AQYTW6]] of $A$ alone cannot show inconsistency; you must reduce $[A \mid b]$, see [[the trap example|HCYVBVXBF4]].

### L3 human

$Ax = b$ is consistent exactly when $b$ lies in the [[column space|03AJKXH1AV]] of $A$, see [[linear systems as vector equations|E7SAHXQEVC]].
Dually, it is inconsistent exactly when some $y$ with $y^T A = 0$ has $y^T b \ne 0$; this is the [[Fredholm alternative|4HH8C9V8JQ]] in finite dimension.
Over an ordered field, the analogue for inequalities is Farkas' lemma, which belongs to linear programming.
For inconsistent systems over $\R$, [[least squares|0BYTQ4X1HC]] gives the best approximate solution.
