## Example

Let $X = \set{0, 1}$ and $I = \set{1, 2}$, so an assignment is a pair $x = (x_1, x_2)$.
Let $A = \mathcal{P}(X^I)$, with $16$ elements.
Put $S(\tau) p = \set{x : x \circ \tau \in p}$ and $\exists(J) p = \set{x : \exists y \in p \text{ with } y_i = x_i \text{ for } i \notin J}$.
We check [[the definition|3GG2T69SSE]].

1. $S(\tau)$ is a Boolean endomorphism: preimages preserve unions, intersections and complements.
2. $\exists(J)$ is a quantifier: $\exists(J)\emptyset = \emptyset$, $p \subseteq \exists(J) p$, and $\exists(J) q$ depends only on the coordinates outside $J$, which gives the third law.
3. Clauses 1 to 3 are direct.
4. Clause 4: $x \in S(\sigma) S(\tau) p$ iff $x \circ \sigma \in S(\tau) p$ iff $x \circ \sigma \circ \tau \in p$ iff $x \in S(\sigma\tau) p$.
5. Clause 5: membership in $\exists(J) p$ depends only on the coordinates outside $J$, and $x \circ \sigma$, $x \circ \tau$ agree there.
6. Clause 6 for $J = \set{1}$ and the swap $\tau$, with $p = \set{(0, 1)}$: $S(\tau) p = \set{(1, 0)}$, so $\exists(\set{1}) S(\tau) p = \set{(0, 0), (1, 0)}$. And $\tau^{-1}\set{1} = \set{2}$, $\exists(\set{2}) p = \set{(0, 0), (0, 1)}$, $S(\tau)$ of it is $\set{x : x_2 = 0}$. The two sides agree.

So $A$ is a [[polyadic algebra|CQ9A86S3J4]] of degree $2$.

## Remarks

1. The general case of clause 6 follows the same pattern: given $z \in p$ that agrees with $x \circ \tau$ off $\tau^{-1} J$, injectivity lets one define $y$ with $y \circ \tau = z$ and $y = x$ off $J$.
2. Let $\tau$ send both variables to $1$. Then $S(\tau)\set{(0, 0)} = \set{x : x_1 = 0}$: the formula $\varphi(v_1, v_1)$.
3. $\exists(I) p = X^I$ for $p \ne \emptyset$, so the algebra is simple.

## Explanations

### L1 human

Each element is a set of pairs of bits.
Renaming variables moves or copies the coordinates.
"There exists $v_1$" forgets the first coordinate.

### L2 human

1. Take $p = \set{(0, 0), (1, 1)}$, the set of "$v_1 = v_2$".
2. $\exists(\set{1}) p = X^I$, since every second coordinate appears in $p$.
3. With the swap $\tau$, $S(\tau) p = p$, since "$v_2 = v_1$" is the same set.

The typical use: small functional algebras let one check the six laws by hand.
The trap: $S(\tau)$ is defined by preimage, so it reads the coordinates of $x$ through $\tau$.
