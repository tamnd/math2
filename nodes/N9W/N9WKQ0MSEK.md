## Summary

An almost periodic function on a group is a bounded continuous function whose translates form a relatively compact set for uniform convergence.
John von Neumann introduced the notion for arbitrary groups, extending Bohr's [[almost periodic functions|GZBSV8DYGS]] on the real line.
These functions are exactly the uniform limits of linear combinations of coefficients of finite-dimensional unitary representations.
They are the continuous functions on the [[Bohr compactification|G852FHZ3W1]] pulled back to the group.

## Explanations

### L1 human

A periodic function on $\R$ repeats exactly; an almost periodic function repeats up to a small error.
On a general group, "shifting" means multiplying the variable on the left or right by a group element.
A function is almost periodic when all its shifts stay close to a finite list of functions, for any tolerance.
On a compact group every continuous function has this property.
On a group such as $\mathrm{SL}(2, \R)$, only the constant functions have it.
