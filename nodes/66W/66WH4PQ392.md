## Statement

The following is a theorem of [[RCA0|DNXCKXZZ08]], with reals and continuous functions coded as on the page on [[RCA0|XQENB067R3]].
Let $f$ be a continuous function, given by a code, whose domain contains $[0, 1]$, and assume $f(0) < 0 < f(1)$.
Then there is a real $x$ with $0 \le x \le 1$ and $f(x) = 0$.

## Remarks

### Why each hypothesis is needed

- The code of $f$ is needed: it gives, for each rational $q$, a $\Sigma^0_1$ test for $f(q) < 0$ and one for $f(q) > 0$. A function given only by its values at points has no code in $L_2$.
- The domain must contain all of $[0, 1]$. If $f(m)$ is undefined at a midpoint $m$, the bisection cannot decide in which half to continue.
- The signs at the endpoints are needed: $f(x) = x + 1$ has no zero in $[0, 1]$. The version with $f(0) \le 0 \le f(1)$ also holds: an endpoint with value $0$ is a zero, and otherwise the signs are strict.

### Consequences

- The [[intermediate value theorem|00KAFBR32E]] needs no set existence beyond computable mathematics.
- Every polynomial of odd degree with real coefficients has a real root, provably in $\mathsf{RCA}_0$.
- The theorem holds in the $\omega$-model of computable sets: a computable continuous function with $f(0) < 0 < f(1)$ has a computable zero.

### Converse

The theorem is provable in the base theory, so no reversal is needed.
The zero cannot in general be found uniformly from $f$: the map from $f$ to a zero is not computable, although each computable $f$ has a computable zero.

### Generalizations

The same proof works for any interval $[a, b]$ with rational or real endpoints.
The Brouwer fixed point theorem in dimension $n \ge 2$ is not provable in $\mathsf{RCA}_0$; it is equivalent to $\mathsf{WKL}_0$.

## Explanations

### L1 human

The usual proof cuts the interval in half again and again.
At each step it keeps the half where the function changes sign.
The theorem says that this proof works in the theory of computable mathematics.
The only problem is a midpoint where the function is exactly $0$, and then that midpoint is the answer.

### L2 human

The proof splits into two cases that a computer cannot tell apart.
In the first case some rational point is a zero.
In the second case no rational is a zero, the sign of $f$ at each rational is decidable from the code, and bisection works.
A trap is to try to decide $f(q) = 0$: this is a $\Pi^0_1$ statement, and it is not decidable from the code.
