## Statement

Take $f(x) = x^2 - 1/2$ on $[0, 1]$, with $f(0) = -1/2 < 0$ and $f(1) = 1/2 > 0$.
Its zero is $1/\sqrt{2}$, and bisection finds it: the signs at $1/2$, $3/4$ and $5/8$ narrow the search to $[5/8, 3/4]$.
The theorem says that this argument works in [[RCA0|DNXCKXZZ08]] for every continuous function, with reals and functions coded as for [[RCA0|XQENB067R3]].

**Theorem.** The following is provable in $\mathsf{RCA}_0$.
Let $f$ be a continuous function, given by a code, whose domain contains $[0, 1]$, and assume $f(0) < 0 < f(1)$.
Then there is a real $x$ with $0 \le x \le 1$ and $f(x) = 0$.

## Remarks

### Why each hypothesis is needed

The code of $f$ is what the proof works with.
For each rational $q$, it gives a $\Sigma^0_1$ test for $f(q) < 0$ and another for $f(q) > 0$.
In $L_2$, a continuous function is nothing but such a code.

The domain must contain all of $[0, 1]$.
If $f$ is undefined at a midpoint, the bisection has no sign to look at there.

The signs at the endpoints are needed, since $f(x) = x + 1$ has no zero in $[0, 1]$.
The version with $f(0) \le 0 \le f(1)$ also holds.
An endpoint with value $0$ is a zero, and otherwise the signs are strict.

### What it gives you

The [[intermediate value theorem|00KAFBR32E]] needs no set existence beyond computable mathematics.
Every polynomial of odd degree with real coefficients has a real root, provably in $\mathsf{RCA}_0$.
The theorem holds in the $\omega$-model of the computable sets.
So a computable continuous function with $f(0) < 0 < f(1)$ has a computable zero.

### The converse

The theorem is provable in the base theory, so no reversal is needed.
Still, the zero cannot be found uniformly from $f$.
The map from codes of $f$ to zeros is not computable, although each computable $f$ has a computable zero.

### Generalizations

The same proof works for any interval $[a, b]$ with rational or real endpoints.
The Brouwer fixed point theorem in dimension $n \ge 2$ is not provable in $\mathsf{RCA}_0$, and it is equivalent to $\mathsf{WKL}_0$.
In dimension $1$ it follows from the intermediate value theorem, applied to $f(x) - x$.

### Try it

Run bisection on $f(x) = x^2 - 1/2$ for two more steps, starting from $[5/8, 3/4]$.
You should find $f(11/16) = -7/256 < 0$ and the interval $[11/16, 3/4]$, then $f(23/32) = 17/1024 > 0$ and the interval $[11/16, 23/32]$.

## Explanations

### L1 human

The usual proof cuts the interval in half again and again.
At each step it keeps the half where the function changes sign.
The theorem says that this proof works in the theory of computable mathematics.
The only problem is a midpoint where the function is exactly $0$, and then that midpoint is the answer.

### L2 human

The [[proof|NE6198A903]] splits into two cases that a computer cannot tell apart.
In the first case some rational point is a zero.
In the second case no rational is a zero, the sign of $f$ at each rational is decidable from the code, and bisection works.

Watch out: do not try to decide $f(q) = 0$.
This is a $\Pi^0_1$ statement, and the code does not decide it.
The proof never asks it, and only uses classical logic to split into the two cases.
