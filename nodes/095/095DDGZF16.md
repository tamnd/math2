## Definition

Row equivalence collects the matrices that row operations can reach from one another.
Let $F$ be a [[field|04C5ZBG1WT]] and let $A$ and $B$ be $m \times n$ matrices over $F$.
The matrix $A$ is *row equivalent* to $B$ when there is a finite sequence of [[elementary row operations|04XWH28452]] that changes $A$ into $B$.
The empty sequence is allowed, so every matrix is row equivalent to itself.

## Notation

We write $A \sim B$ when $A$ is row equivalent to $B$.

## Remarks

### Why it is a symmetric relation

The definition speaks of going from $A$ to $B$, but the direction does not matter.
Each elementary row operation has an inverse operation, so a sequence from $A$ to $B$ can be undone step by step, in the reverse order.
So row equivalence is an equivalence relation, by the [[theorem on row equivalence|E4GKK727ZM]].

### Other ways to say it

The matrices $A$ and $B$ are row equivalent if and only if $B = PA$ for an [[invertible|0EB9N0S33C]] $m \times m$ matrix $P$.
They are row equivalent if and only if they have the same [[reduced row echelon form|0WF5AQYTW6]].
Row equivalent matrices have the same [[row space|069MCGX635]] and the same [[null space|0PHDYNR24D]].

### Watch out

The definition allows only row operations.
A column swap does not give a row equivalent matrix in general: it turns $\begin{bmatrix} 1 & 0 \\ 0 & 0 \end{bmatrix}$ into $\begin{bmatrix} 0 & 1 \\ 0 & 0 \end{bmatrix}$, and these two have different null spaces.

## Explanations

### L1 human

Two matrices are row equivalent when row operations can turn one into the other.
If they are augmented matrices of two systems, then the two systems have the same solutions.
Row reduction replaces a matrix by a simpler row equivalent matrix.

### L2 human

The matrices $\begin{bmatrix} 1 & 1 \\ 0 & 1 \end{bmatrix}$ and $I_2$ are row equivalent.

1. The step $R_1 \leftarrow R_1 - R_2$ turns the first matrix into $I_2$.
2. The step $R_1 \leftarrow R_1 + R_2$ turns $I_2$ back into the first matrix.

So the relation holds in both directions, as it always does.
