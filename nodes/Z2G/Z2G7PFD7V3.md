## Summary

In mathematical logic, **positive set theory** is the name for a class of alternative set theories in which the axiom of comprehension holds for at least the **positive formulas** $\phi$ (the smallest class of formulas containing atomic membership and equality formulas and closed under conjunction, disjunction, existential and [[universal quantification|0GHS47PDAQ]]).
