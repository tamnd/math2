## Summary

A fundamental matrix of a homogeneous linear system $x' = A(t) x$ is a matrix function whose columns are $n$ linearly independent solutions.
It is the matrix form of a [[fundamental system of solutions|0DS2QFYJHE]]. See the [[definition|0MQ24RBG93]].
