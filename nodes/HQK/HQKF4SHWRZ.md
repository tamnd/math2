## Summary

The morphism *f* : *Y* → *X* is **locally of finite type** if $X$ may be covered by affine open sets $\text{Spec }B$ such that each inverse image $f^{-1}(\text{Spec }B)$ is covered by affine open sets $\text{Spec }A$ where each $A$ is finitely generated as a $B$-algebra.

The morphism *f* : *Y* → *X* is of finite type if $X$ may be covered by affine open sets $\text{Spec }B$ such that each inverse image $f^{-1}(\text{Spec }B)$ is covered by finitely many affine open sets $\text{Spec }A$ where each $A$ is finitely generated as a $B$-algebra.
