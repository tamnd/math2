## Definition

Let $\Lambda$ be a set of modal formulas.
We say that $\Lambda$ is *closed under the necessitation rule* when $\varphi \in \Lambda$ implies $\square\varphi \in \Lambda$, for every formula $\varphi$.

Let $S$ be a Hilbert system with theorem set $\operatorname{Thm}(S)$, and let $\varphi_1, \dots, \varphi_n \,/\, \psi$ be a [[rule of inference|QPD3X471Q1]].
The rule is *admissible* in $S$ when every substitution instance with premises in $\operatorname{Thm}(S)$ has its conclusion in $\operatorname{Thm}(S)$.
The rule is *derivable* in $S$ when $S$ derives $\psi$ from the hypotheses $\varphi_1, \dots, \varphi_n$, using its rules on the hypotheses as well.

Let $\Lambda$ be a normal logic and $\Gamma$ a set of formulas.
The *local consequence* relation $\Gamma \vdash_\Lambda \psi$ holds when $\Lambda \vdash (\gamma_1 \wedge \dots \wedge \gamma_n) \to \psi$ for some $\gamma_1, \dots, \gamma_n \in \Gamma$.
The *global consequence* relation $\Gamma \vdash^g_\Lambda \psi$ holds when $\psi$ lies in the smallest set that contains $\Lambda \cup \Gamma$ and is closed under modus ponens and necessitation.

## Notation

The rule is written $\varphi \,/\, \square\varphi$ and named Nec, RN or N.
Local consequence uses necessitation on theorems only, and global consequence uses it on hypotheses too.

## Remarks

The two consequence relations differ exactly in how they treat necessitation.

In the usual Hilbert system of [[normal modal logic K|JS8W7PA6JK]], necessitation is a primitive rule, so it is derivable in that system.
For local consequence it is not derivable, since $p \nvdash_{\mathsf{K}} \square p$; see [[the non-theorem p → □p|R2WWD2R5NV]].
For global consequence it is derivable, so $p \vdash^g_{\mathsf{K}} \square p$, and then the [[deduction theorem|9X08XK5RV2]] fails for $\vdash^g$; see [[the global consequence example|R6MA6TFN5K]].
Uniform substitution shows the same contrast; see [[uniform substitution is admissible but not derivable|DE0GD8BM4M]].

Local consequence has the deduction theorem by its definition: $\Gamma \cup \{ \varphi \} \vdash_\Lambda \psi$ if and only if $\Gamma \vdash_\Lambda \varphi \to \psi$.
The two relations have the same theorems, since $\Lambda$ is closed under both rules.
So $\varnothing \vdash_\Lambda \psi$ holds iff $\varnothing \vdash^g_\Lambda \psi$ holds iff $\psi \in \Lambda$.

## Explanations

### L1 human

A rule of a logic says which new laws we may write down from old ones.
Necessitation says that from a proved law we may write down "necessarily" in front of it.
The rule works for proved laws, and not for statements that we only assume.

### L2 human

We compare the two consequence relations on the hypothesis $p$.

1. Globally, $p$ is a hypothesis, so necessitation gives $\square p$, and $p \vdash^g_{\mathsf{K}} \square p$.
2. Locally, $p \vdash_{\mathsf{K}} \square p$ would need $\mathsf{K} \vdash p \to \square p$.
3. The model with $W = \{ 1, 2 \}$, $R = \{ (1, 2) \}$ and $V(p) = \{ 1 \}$ makes $p$ true and $\square p$ false at $1$.
4. By soundness, $\mathsf{K} \nvdash p \to \square p$, so $p \nvdash_{\mathsf{K}} \square p$.

The typical use of local consequence is completeness by [[canonical models|TVE4F04KME]], which concerns truth at one world.
Watch out: a derivation from hypotheses that uses necessitation on a hypothesis does not give an implication theorem.

### L3 human

Every derivable rule of a logic is admissible.
For some modal logics, such as $\mathsf{S4}$ and $\mathsf{GL}$, some admissible rules are not derivable, and Rybakov studied when admissibility is decidable.
The local and global relations match truth at a world and truth in a whole model.
The global one is the consequence relation of equations $\varphi = \top$ in modal algebras.
