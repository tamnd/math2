## Summary

Propositional dynamic logic ($\mathsf{PDL}$) is the [[modal logic|C3RZY20ETK]] with one box $[\alpha]$ for each program $\alpha$.
Programs and formulas are defined together from atomic programs $a \in A$ and propositional variables $p$:
$$\alpha ::= a \mid \alpha ; \alpha \mid \alpha \cup \alpha \mid \alpha^* \mid \varphi ? \qquad \varphi ::= p \mid \bot \mid \neg \varphi \mid \varphi \wedge \varphi \mid [\alpha] \varphi .$$
A model is a Kripke model $\mathfrak{M} = (W, (R_a)_{a \in A}, V)$, and each program gets a relation: $R_{\alpha ; \beta} = \set{(w, u) : w R_\alpha v \text{ and } v R_\beta u \text{ for some } v}$, $R_{\alpha \cup \beta} = R_\alpha \cup R_\beta$, $R_{\alpha^*}$ is the reflexive [[transitive closure|05J9NWX07X]] of $R_\alpha$, and $R_{\varphi ?} = \set{(w, w) : \mathfrak{M}, w \models \varphi}$.
Then $\mathfrak{M}, w \models [\alpha] \varphi$ holds when $\mathfrak{M}, v \models \varphi$ for every $v$ with $w R_\alpha v$, and $\langle \alpha \rangle \varphi$ is $\neg [\alpha] \neg \varphi$.
$\mathsf{PDL}$ matters because it is a logic of programs with a finite complete axiom system and a decidable validity problem, and it is the model of many later modal logics of actions.

## Motivation

A Hoare triple $\{\varphi\} \, \alpha \, \{\psi\}$ says: if $\varphi$ holds before $\alpha$ runs, then $\psi$ holds after every terminating run of $\alpha$.
Vaughan Pratt saw that this is a modal statement: $\varphi \to [\alpha] \psi$, where $[\alpha]$ quantifies over the end states of the runs of $\alpha$.
A program is built from basic steps by sequence, choice and iteration, which are the operations of [[regular expressions|4DMYF2PR4Q]].
Tests $\varphi ?$ let a program check a condition, so the conditional and the while loop become regular programs.
So one modal logic with a box for each regular program can state and prove properties of all such programs.

## Notation

1. $[\alpha] \varphi$ is read "after every run of $\alpha$, $\varphi$ holds", and $\langle \alpha \rangle \varphi$ is read "some run of $\alpha$ ends in a state where $\varphi$ holds".
2. The program $\alpha ; \beta$ runs $\alpha$ and then $\beta$. Some books write $\alpha \beta$, and some write $\alpha + \beta$ for $\alpha \cup \beta$.
3. Derived programs: $\mathbf{skip} = \top ?$, $\mathbf{if}\ \varphi\ \mathbf{then}\ \alpha\ \mathbf{else}\ \beta = (\varphi ? ; \alpha) \cup (\neg \varphi ? ; \beta)$, and $\mathbf{while}\ \varphi\ \mathbf{do}\ \alpha = (\varphi ? ; \alpha)^* ; \neg \varphi ?$.
4. $\mathrm{FL}(\varphi)$ is the Fischer-Ladner closure of $\varphi$, defined below.

## Remarks

### Examples

1. [[Evaluating a PDL formula with star and composition|58ZZBPW3WF]]: on a four-world model we compute $R_{(a ; b)^*}$ and the truth of $\langle (a ; b)^* \rangle p$ and $[a^*] q$ world by world.
2. [[A while program as a PDL program|DT8R2PB0P7]]: the program $\mathbf{while}\ p\ \mathbf{do}\ a$ is $(p ? ; a)^* ; \neg p ?$, and we check its relation on a small model.
3. Hoare triples: $\{\varphi\} \, \alpha \, \{\psi\}$ is valid exactly when $\varphi \to [\alpha] \psi$ is valid. So the rules of [[Hoare logic|H1M6RSBJ5H]] for propositional programs become theorems of $\mathsf{PDL}$.
4. Reachability: $\langle a^* \rangle p$ holds at $w$ when some finite sequence of $a$-steps from $w$, possibly empty, reaches a $p$-world.

### Non-examples

1. [[A star interpreted too large violates the PDL axioms|13HTANHBNW]]: a structure where $a^*$ gets a relation larger than the reflexive transitive closure of $R_a$ is not a $\mathsf{PDL}$ model, and the star axioms fail in it.
2. Intersection $\alpha \cap \beta$ is not a $\mathsf{PDL}$ program. The relation $R_\alpha \cap R_\beta$ is not given by the regular operations, and the logic with intersection is a different system.
3. The formula $[a] p \to [a^*] p$ is not valid: take $w R_a v$ with $p$ true at $v$ and false at $w$. Then $[a] p$ holds at $w$, and $[a^*] p$ fails at $w$, since $w R_{a^*} w$.

### Basic properties

1. Axioms. Segerberg's axiom system has all propositional tautologies, the axiom $\mathrm{K}$ for each $[\alpha]$, the rules modus ponens and [[necessitation|G989VP2NGP]] for each $[\alpha]$, and the axioms
$$[\alpha ; \beta] \varphi \leftrightarrow [\alpha][\beta] \varphi, \qquad [\alpha \cup \beta] \varphi \leftrightarrow [\alpha] \varphi \wedge [\beta] \varphi, \qquad [\psi ?] \varphi \leftrightarrow (\psi \to \varphi),$$
$$[\alpha^*] \varphi \leftrightarrow \varphi \wedge [\alpha][\alpha^*] \varphi, \qquad [\alpha^*](\varphi \to [\alpha] \varphi) \to (\varphi \to [\alpha^*] \varphi).$$
The fourth axiom unfolds the star once, and the fifth is the induction axiom.
2. Completeness. A formula is a theorem of Segerberg's system if and only if it is valid in all models. Dexter Kozen and Rohit Parikh gave a short proof in 1981, by a canonical model filtered through the Fischer-Ladner closure.
3. No compactness. The set $\{\langle a^* \rangle p\} \cup \{[a]^n \neg p : n \geq 0\}$, where $[a]^n$ is $n$ boxes in a row, is unsatisfiable, while each finite subset has a model. So $\mathsf{PDL}$ is not compact, and the completeness theorem holds only for single formulas.
4. Fischer-Ladner closure. $\mathrm{FL}(\varphi)$ is the smallest set that contains $\varphi$, is closed under subformulas, and satisfies: if $[\alpha ; \beta] \psi \in \mathrm{FL}(\varphi)$ then $[\alpha][\beta] \psi \in \mathrm{FL}(\varphi)$; if $[\alpha \cup \beta] \psi$ is in it then $[\alpha] \psi$ and $[\beta] \psi$ are; if $[\chi ?] \psi$ is in it then $\chi$ is; and if $[\alpha^*] \psi$ is in it then $[\alpha][\alpha^*] \psi$ is. Its size is at most linear in the length of $\varphi$.
5. Small models. If $\varphi$ is satisfiable, then it is satisfiable in a model with at most $2^{|\mathrm{FL}(\varphi)|}$ worlds, obtained by [[filtration|6ZZSHAKG5F]] through $\mathrm{FL}(\varphi)$. This gives decidability.
6. Complexity. Satisfiability of $\mathsf{PDL}$ is complete for [[EXPTIME|T9G5S33CA0]]. Fischer and Ladner proved the lower bound, and Pratt gave an algorithm in exponential time.
7. Translation. $\langle \alpha^* \rangle \varphi$ is equivalent to $\mu X . (\varphi \vee \langle \alpha \rangle X)$, so $\mathsf{PDL}$ translates into the [[modal mu-calculus|MZ0M2KR9S0]].

### History

Vaughan Pratt introduced dynamic logic in 1976, as a modal reading of Hoare logic.
Michael Fischer and Richard Ladner defined propositional dynamic logic in 1977 and proved its decidability with the closure that now has their name.
Krister Segerberg proposed the axiom system in 1977.
Completeness proofs were found by several authors, among them Parikh, Pratt, and Kozen and Parikh in 1981.

### Common errors

1. Reading $\alpha^*$ as "one or more runs". The star includes zero runs, so $R_{\alpha^*}$ is reflexive, and $[\alpha^*] \varphi \to \varphi$ is valid.
2. Reading $[\alpha] \varphi$ as total correctness. $[\alpha] \varphi$ is true when $\alpha$ has no terminating run; termination is expressed by $\langle \alpha \rangle \top$.
3. Expecting strong completeness. By the failure of compactness, a formula can follow from an infinite set of formulas without a derivation from them.

## Explanations

### L1 human

Propositional dynamic logic talks about programs and what is true after they run.
The formula $[\alpha] \varphi$ says "whatever way the program $\alpha$ runs, if it stops, then $\varphi$ is true afterwards".
Programs are built from basic steps: do one thing then another, choose one of two things, repeat something any number of times, or check a condition.
For example, if a counter starts at $0$ and the program adds $1$ any number of times, then afterwards the counter is at least $0$.

### L2 human

We check that the induction axiom $[\alpha^*](\varphi \to [\alpha] \varphi) \to (\varphi \to [\alpha^*] \varphi)$ is valid.

1. Fix a model and a world $w$. Assume $w \models [\alpha^*](\varphi \to [\alpha] \varphi)$ and $w \models \varphi$.
2. Let $w R_{\alpha^*} v$. By the definition of reflexive transitive closure, there are $n \geq 0$ and worlds $w = v_0, v_1, \dots, v_n = v$ with $v_i R_\alpha v_{i+1}$.
3. We show $v_i \models \varphi$ by induction on $i$. For $i = 0$ this is the assumption $w \models \varphi$.
4. If $v_i \models \varphi$, then $w R_{\alpha^*} v_i$ and step 1 give $v_i \models \varphi \to [\alpha] \varphi$, so $v_i \models [\alpha] \varphi$, and $v_{i+1} \models \varphi$.
5. So $v = v_n \models \varphi$, and $w \models [\alpha^*] \varphi$.

The typical use of the induction axiom is to prove an invariant of a loop: a property that holds at the start and is kept by each step.
A trap: the hypothesis must hold at every world reachable by $\alpha^*$, not only at $w$; otherwise the induction step 4 has nothing to use.

### L3 human

$\mathsf{PDL}$ is the modal logic of the algebra of binary relations with composition, union, reflexive transitive closure and tests, and its program part is closely related to Kleene algebra with tests.
Its completeness proof is the model for many later results: a canonical model, a filtration through a finite closure, and a check that the star program behaves correctly in the filtered model.
Common knowledge in epistemic logic is a star modality of this kind.
Extensions add converse programs, intersection, or first-order assignments, and the [[modal mu-calculus|MZ0M2KR9S0]] contains $\mathsf{PDL}$ as a fragment without alternation of fixed points.
