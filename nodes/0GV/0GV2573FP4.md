## Statement

Two finite sets have the same number of elements exactly when their elements can be matched one to one.

Let $A$ and $B$ be [[finite sets|0BBTH3YSZA]], and let $|A|$ and $|B|$ be their [[cardinalities|05099E1NMJ]].
Then $|A| = |B|$ if and only if there is a [[bijection|0SNQEF7Z53]] $f : A \to B$.

The direction "a bijection gives equal sizes" is the one used in counting.
To count a set $A$, we find a bijection from $A$ to a set $B$ whose size we already know, and then $|A| = |B|$.
A proof of this kind is a bijective proof, one of the two forms of a [[combinatorial proof|SS07J9ZAQ7]].
The [[proof|VD65RRN8P2]] proves both directions.

## Remarks

### A first use: subsets and binary words

How many subsets does $\{1, 2, 3\}$ have?
Match each subset $S$ with the word of length $3$ that has $1$ in position $i$ when $i \in S$ and $0$ otherwise.
For example, $\{1, 3\} \mapsto 101$ and $\varnothing \mapsto 000$.
The map is a bijection, because the word tells you exactly which elements are in $S$.
There are $2 \cdot 2 \cdot 2 = 8$ words, so there are $8$ subsets, and the same map shows that a set of $n$ elements has $2^n$ [[subsets|0C5RDJE73X]].

### Why each hypothesis is needed

A bijection is needed, and an injection is not enough.
The inclusion of $\{1\}$ into $\{1, 2\}$ is injective, but the sizes are $1$ and $2$, and an injection $A \to B$ gives only $|A| \le |B|$.
A surjection is not enough either: the map $\{1, 2\} \to \{1\}$ is surjective, and it gives only $|A| \geq |B|$.

The sets must be finite for $|A|$ to be a natural number.
For infinite sets a bijection still means "the same size", which is the definition of [[equinumerous sets|0B0KR7FH2Q]], but this notion has new features.
For example, $n \mapsto n + 1$ is a bijection from $\mathbb{N}$ to its proper subset $\mathbb{N} \setminus \{0\}$, as in [[Hilbert's hotel|0N3Y8G340X]].

### What it gives you

The map $S \mapsto X \setminus S$ is a bijection from the $k$-subsets to the $(n - k)$-subsets of an $n$-set $X$, which gives the [[symmetry of binomial coefficients|0R7JS3DP3W]].
In [[stars and bars|009TEMTQKH]], the solutions of $x_1 + \cdots + x_k = n$ in natural numbers match the words of $n$ stars and $k - 1$ bars.
For [[Cayley's formula|0M2SSGSYPE]], the [[Prüfer code|900KK0PPYM]] matches the trees on $\{1, \dots, n\}$, for $n \geq 2$, with the sequences of length $n - 2$ in $\{1, \dots, n\}$, so there are $n^{n-2}$ trees.
[[Dyck words|0R9JR0465V]] of length $2n$ match [[binary trees|02A8EMC83C]] with $n$ internal nodes, so the [[Catalan numbers|092DRBFKMG]] count both.
The relation "there is a bijection between $A$ and $B$" is [[symmetric|BJA08CW1XK]], so a bijection in either direction is enough.

### The converse

The statement is an "if and only if", so it contains its converse.
The direction "equal sizes give a bijection" holds because you can number both sets with $1, \dots, n$ and match equal numbers.
For finite sets of the same size, an injection $A \to B$ is already a bijection, and so is a surjection.
These facts fail for infinite sets: the map $n \mapsto 2n$ from $\mathbb{N}$ to $\mathbb{N}$ is injective but not surjective.

### Generalizations

Georg Cantor took the existence of a bijection as the definition of "the same size" for all sets, and this gives the theory of cardinal numbers.
The [[Schröder-Bernstein theorem|0A9V6RKQG6]] says that injections $A \to B$ and $B \to A$ give a bijection $A \to B$, and for finite sets the [[finite version|X5R6PJQQVD]] follows from the bijection principle and the bound $|A| \le |B|$ for an injection.
There is a weighted form: a bijection $f : A \to B$ with $w(f(a)) = v(a)$ for all $a$ gives $\sum_{a \in A} v(a) = \sum_{b \in B} w(b)$.
Bijections that keep a statistic, such as the number of parts of a partition, prove identities between generating functions.
The [[pigeonhole principle|0HGVCWQGY3]] is the injection bound in contrapositive form: when $|A| > |B|$, no map $A \to B$ is injective.

### Watch out

A map is not a bijection until you prove it.
The most common gap in a bijective proof is a map $f$ with no check that it is injective and surjective.
The easiest check is to write down the inverse map $g$ and verify $g \circ f = \mathrm{id}$ and $f \circ g = \mathrm{id}$.
For example, "send a $3$-subset of $\{1, \dots, 5\}$ to its largest element" is a map onto $\{3, 4, 5\}$, but it is not injective, since $\{1, 2, 5\}$ and $\{1, 3, 5\}$ both go to $5$.

### Try it

How many words of length $5$ in the letters $a$ and $b$ have exactly two $a$'s?
Match a word with the set of positions of its $a$'s, a $2$-subset of $\{1, \dots, 5\}$, so there are $\binom{5}{2} = 10$.

Show that $\{1, \dots, 2n\}$ has as many subsets of size $n$ that contain $1$ as subsets of size $n$ that do not contain $1$.
The map $S \mapsto \{1, \dots, 2n\} \setminus S$ sends one kind to the other and is its own inverse.

## Explanations

### L1 human

To show that two collections have the same size, we can pair each thing of the first collection with exactly one thing of the second, with nothing left over on either side.
For example, in a dance class each student of the first group dances with exactly one student of the second group, and nobody stands alone.
Then the two groups have the same size, and we did not need to count either group.
In the same way, the subsets of $\{1, 2, 3\}$ pair with the words of length $3$ in the letters $0$ and $1$.
There are $8$ such words, so there are $8$ subsets.

### L2 human

How many $3$-subsets of $\{1, \dots, 10\}$ contain no two consecutive numbers?
Let $A$ be the set of such subsets $\{a < b < c\}$, so $b \geq a + 2$ and $c \geq b + 2$.
Close the gaps with
$$f(\{a, b, c\}) = \{a, b - 1, c - 2\}.$$
Then $a < b - 1 < c - 2 \le 8$, so $f$ maps $A$ to the set $B$ of all $3$-subsets of $\{1, \dots, 8\}$.
The inverse opens the gaps again: $g(\{x < y < z\}) = \{x, y + 1, z + 2\}$, and $y + 1 \geq x + 2$, $z + 2 \geq y + 3$ and $z + 2 \le 10$ show that $g$ maps $B$ to $A$.
Each map undoes the other, so $f$ is a bijection, and
$$|A| = |B| = \binom{8}{3} = 56.$$
The typical use is to trade a set with a condition for a set with no condition, and the inverse map is the quickest proof that the trade is fair.

### L3 human

In category language, cardinality classifies finite sets up to isomorphism, and the bijection principle says exactly this.
So a bijective proof of $|A| = |B|$ is an isomorphism, and it often explains more than a numerical identity: it can keep extra structure, such as a statistic or a group action.
In Mathlib the direction "a bijection gives equal sizes" is `Fintype.card_congr`, which takes an equivalence `α ≃ β`.

Bijective combinatorics looks for explicit bijections behind identities that have algebraic proofs, for example the [[partition identities|EZF8KV8YM6]] of Euler and Glaisher.
Some identities have a [[double counting|0F8YBHF2W3]] proof but no known simple bijective proof, and finding such a bijection is a research problem.
For infinite sets the same definition of equal size leads to Cantor's theory of cardinals and to the [[diagonalization technique|V2H30SA654]].
