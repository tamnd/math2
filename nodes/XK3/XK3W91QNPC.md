## Summary

In descriptive set theory, the **Kleene–Brouwer order** or **Lusin–Sierpiński order** is a linear order on finite sequences over some linearly ordered set $(X, <)$, that differs from the more commonly used [[lexicographic order|0B68KNPGCG]] in how it handles the case when one sequence is a prefix of the other. In the Kleene–Brouwer order, the prefix is later than the longer sequence containing it, rather than earlier.
