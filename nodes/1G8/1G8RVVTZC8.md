## Statement

In algebraic number theory, the **Grunwald–Wang theorem** is a local-global principle stating that—except in some precisely defined cases—an element *x* in a number field *K* is an *n*th power in *K* if it is an *n*th power in the [[completion|08EWT7J0SC]] $K_{\mathfrak{p}}$ for all but finitely many primes $\mathfrak{p}$ of *K*. For example, a [[rational number|0NCJ5WXN6Z]] is a square of a rational number if it is a square of a *p*-adic number for almost all [[prime numbers|01826KMG2H]] *p*.
