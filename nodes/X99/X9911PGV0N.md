## Example

The tree that weak König's lemma uses to separate two sets is infinite but thin, so weak weak König's lemma does not apply to it.
Let $A$ and $B$ be disjoint [[computably enumerable|TN9G24VABN]] sets with $A \cup B$ infinite, and let $A_s$ and $B_s$ be the finite sets of elements enumerated by stage $s$.
The *separation tree* is the set $T$ of strings $\sigma$ such that, for every $m < \lvert \sigma \rvert$, $m \in A_{\lvert \sigma \rvert}$ implies $\sigma(m) = 1$ and $m \in B_{\lvert \sigma \rvert}$ implies $\sigma(m) = 0$.
We show that $T$ is an infinite tree that does not have positive measure in the sense of [[WWKL0|KPHM3025GW]].

### The tree and its levels

1. $T$ is computable, because the test for $\sigma$ runs the enumerations for $\lvert \sigma \rvert$ stages.
2. $T$ is a tree.
   Let $\rho \preceq \sigma$ with $\sigma \in T$, and let $m < \lvert \rho \rvert$ be in $A_{\lvert \rho \rvert}$.
   Then $m \in A_{\lvert \sigma \rvert}$, so $\rho(m) = \sigma(m) = 1$, and the same holds for $B$.
3. Fix $n$, and let $k_n$ be the number of elements of $(A_n \cup B_n) \cap \{0, \dots, n - 1\}$.
   A string of length $n$ is in $T$ if and only if its values at these $k_n$ places are the forced ones.
   The other $n - k_n$ places are free, so $\lvert T_n \rvert = 2^{n - k_n}$.
4. In particular $\lvert T_n \rvert \ge 1$ for every $n$, so $T$ is infinite.

### The ratios tend to zero

5. $k_n$ tends to infinity.
   Given $k$, pick $k$ elements of $A \cup B$ and a stage $s$ by which all of them are enumerated.
   For every $n \ge s$ that is larger than these $k$ elements, $k_n \ge k$.
6. So $\lvert T_n \rvert / 2^n = 2^{-k_n}$ tends to $0$.
   For a rational $q > 0$, choose $k$ with $2^{-k} < q$; then $\lvert T_n \rvert / 2^n < q$ for large $n$.
7. So no rational $q > 0$ bounds the ratio from below, and $T$ is not a tree of positive measure.

The paths of $T$ are the characteristic functions of the sets $S$ with $A \subseteq S$ and $S \cap B = \emptyset$.
[[Weak König's lemma|7W9EG02T79]] applies to $T$ and gives such a separating set, but [[weak weak König's lemma|BJQ77Y2QFX]] does not apply.

## Remarks

Take $A = \{e : \varphi_e(e) = 0\}$ and $B = \{e : \varphi_e(e) = 1\}$, where $\varphi_e$ is the $e$-th partial computable function.
These sets are computably inseparable, so $T$ has no [[computable|DN5G4NAF95]] path, and this is the standard proof that $\mathsf{RCA}_0$ does not prove $\mathrm{WKL}$.
The example shows the gap between the two principles: the separation tree has measure zero, while the trees of $\mathrm{WWKL}$ have positive measure.
A second, simpler non-example is the tree $\{0^n : n \in \mathbb{N}\}$, with $\lvert T_n \rvert = 1$ and ratio $2^{-n}$.
It has a path, but it does not meet the hypothesis of $\mathrm{WWKL}$.

## Explanations

### L1 human

Two lists of numbers grow over time, and no number is on both lists.
A string of $0$s and $1$s survives if it puts a $1$ on every number of the first list and a $0$ on every number of the second list seen so far.
Each listed number halves the number of surviving strings.
Since the lists keep growing, the surviving fraction shrinks to zero.
So the tree is infinite, but it is too thin for weak weak König's lemma.

### L2 human

Take $A$ the even numbers and $B$ the odd numbers, each enumerated so that $A_s$ and $B_s$ contain the numbers below $s$.

1. At length $n$, every place $m < n$ is forced, so $k_n = n$.
2. So $\lvert T_n \rvert = 1$, and the only string is $1, 0, 1, 0, \dots$ of length $n$.
3. The ratio is $2^{-n}$, which tends to $0$.

Check: at $n = 3$ the only string in $T$ is $101$, and $1/8$ of the strings survive.
The typical use: this tree shows why $\mathrm{WWKL}$ does not reach separation principles, which need $\mathrm{WKL}$.
The trap: the separation tree is infinite and may even have a computable path, as here, but positive measure is a different condition.

### L3 human

Measure zero is the general case for separation: each element of $A \cup B$ fixes one bit, and infinitely many fixed bits leave a null set.
This is the intuition behind the theorem of Yu and Simpson that $\mathsf{WKL}_0$, which proves the separation principle for $\Sigma^0_1$ sets, is strictly stronger than $\mathsf{WWKL}_0$.
Over $\mathsf{RCA}_0$, $\Sigma^0_1$ separation is one of the standard equivalents of [[weak König's lemma|7W9EG02T79]].
