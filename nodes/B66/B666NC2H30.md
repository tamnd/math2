## Summary

An entanglement witness is an observable whose expectation value is nonnegative on every [[separable state|7F386TSFRW]] but negative on some [[entangled|CHNXT8CCK7]] state.
A negative measured value therefore certifies entanglement.
Because the separable states form a closed [[convex set|02AS45T3H9]], every entangled state is detected by some witness.
Witnesses are useful in experiments, where one measures a few observables instead of reconstructing the full state.

## Explanations

### L1 human

Think of the separable states as a convex blob inside the set of all states.
An entanglement witness is a flat wall with the whole blob on one side.
If a state lies on the other side of the wall, it cannot be in the blob, so it must be entangled.
For two qubits, the swap operator is a witness: it gives $-1$ on the singlet state and a nonnegative value on every separable state.
