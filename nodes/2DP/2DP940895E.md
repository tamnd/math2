## Summary

The simply typed lambda calculus is the [[lambda calculus|BD756KR8FM]] in which every term carries a type built from base types with the function arrow $\to$.
It was introduced by Alonzo Church in 1940 as a typed version of his calculus.
Typing rules out self-application, so every typed term has a normal form and computation always ends.
It is the smallest serious [[type theory|Q48KGV33AH]], and through the [[Curry–Howard correspondence|A77FER1Q5H]] it matches the implication fragment of intuitionistic logic.

## Explanations

### L1 human

In the untyped lambda calculus any function can be applied to anything, even to itself.
The simply typed calculus attaches a label to each function, such as "takes a number and gives a number".
A function may only be applied to an argument with the matching label.
For example, $\lambda x{:}\mathsf{b}.\, x$ has type $\mathsf{b} \to \mathsf{b}$, and it accepts only arguments of type $\mathsf{b}$.
These labels block the loops of the untyped calculus, at the price of losing some programs.
