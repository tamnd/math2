## Summary

For a [[feedback|7NYES2D0Z4]] loop with loop transfer function $L$, the sensitivity function is $S = 1/(1 + L)$ and the complementary sensitivity function is $T = L/(1 + L)$.
The function $S$ is the transfer function from a disturbance at the output to the output.
It also measures how relative changes of the plant affect the closed loop.
The function $T$ is the [[closed-loop transfer function|RYTSV821V8]] from the reference to the output, and also from sensor noise to the output, up to sign.
Since $S + T = 1$, the two cannot both be small at the same frequency, which is a basic trade-off of feedback design.

## Explanations

### L1 human

A good feedback loop should reject disturbances, which needs $S$ small, and ignore sensor noise, which needs $T$ small.
Because $S$ and $T$ add up to $1$, no loop can do both at the same frequency.
In practice one makes $S$ small at low frequencies, where disturbances live, and $T$ small at high frequencies, where noise lives.
For $L(s) = 1/s$ one gets $S(s) = s/(s + 1)$, small for slow signals, and $T(s) = 1/(s + 1)$, small for fast ones.
