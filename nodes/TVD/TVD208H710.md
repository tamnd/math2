## Definition

A *nondeterministic Turing machine* is a tuple $M = (Q, \Gamma, \sqcup, \Sigma, \delta, q_0, q_{\mathrm{acc}}, q_{\mathrm{rej}})$ with the following parts.

1. $Q$ is a finite nonempty set of states, with an initial state $q_0$ and two distinct halting states $q_{\mathrm{acc}}$ and $q_{\mathrm{rej}}$.
2. $\Gamma$ is a finite set of tape symbols, $\sqcup \in \Gamma$ is the blank, and $\Sigma \subseteq \Gamma \setminus \set{\sqcup}$ is the input alphabet.
3. $\delta \colon (Q \setminus \set{q_{\mathrm{acc}}, q_{\mathrm{rej}}}) \times \Gamma \to \mathcal P(Q \times \Gamma \times \set{L, R})$ is the transition function, with values in the [[power set|00E0YZCERH]].

Configurations and the start on an input $w \in \Sigma^*$ are as for a [[Turing machine|W6ESDYBF8Z]].
A configuration with state $q$ and scanned symbol $a$ may step to each configuration obtained by one triple $(q', s, D) \in \delta(q, a)$, applied as for a deterministic machine.
The machine *accepts* $w$ if some finite sequence of steps from the start configuration on $w$ reaches the state $q_{\mathrm{acc}}$.
The [[language|5MFZ4VNY6D]] of $M$ is the set of inputs it accepts.
The machine *decides* its language if, in addition, every sequence of steps on every input is finite.
It runs in time $t(n)$ if every sequence of steps on every input of length $n$ has at most $t(n)$ steps.

## Remarks

A deterministic Turing machine is the case where every set $\delta(q, a)$ has at most one element.
Example: let $L$ be the set of binary numerals of composite numbers.
A machine on input $n$ writes a binary numeral $d$ no longer than the input by nondeterministic choices, checks $1 < d < n$ and $d \mid n$, and accepts if both hold.
Some run accepts exactly when $n$ is composite, and every run takes time polynomial in the length of the input.
Non-example: acceptance does not mean that every run accepts; a machine with one accepting and one rejecting run on $w$ still accepts $w$.
A deterministic machine can simulate a nondeterministic machine that runs in time $t(n)$ within time $2^{O(t(n))}$, by searching through all runs.
So both kinds recognise the same languages.
Whether polynomial time can always be kept is the P versus NP problem.
