## Statement

Let $(\Z, +)$ be the [[additive group of integers|0BSCJA5G53]].
For an integer $n$, write $n\Z = \set{nk : k \in \Z}$ for the set of multiples of $n$.
For integers $a$ and $b$, write $a\Z + b\Z = \set{ax + by : x, y \in \Z}$.

1. (Classification.) Let $H$ be a [[subgroup|0X1JXT47GA]] of $\Z$. Then there is exactly one integer $n \geq 0$ with $H = n\Z$. If $H \neq \set{0}$, then $n$ is the least positive element of $H$.
2. (Containment.) Let $m, n \geq 0$ be integers. Then $m\Z \subseteq n\Z$ if and only if $n$ [[divides|0PG2H7WKGG]] $m$.
3. (Sums.) Let $a$ and $b$ be integers that are not both $0$. Then $a\Z + b\Z = \gcd(a, b)\Z$, where $\gcd$ is the [[greatest common divisor|0C8WYW4KYQ]].
4. (Intersections.) Let $m, n \geq 1$ be integers. Then $m\Z \cap n\Z = \operatorname{lcm}(m, n)\Z$, where $\operatorname{lcm}$ is the [[least common multiple|007NPQX34K]].

## Remarks

### Why each hypothesis is needed

1. The set $H$ must be a subgroup in part 1. The set $\set{0, 1, 2, \ldots}$ is closed under addition, but it is not of the form $n\Z$, because it does not contain $-1$.
2. The condition $n \geq 0$ is needed for uniqueness in part 1. Without it, $n\Z = (-n)\Z$ gives two values of $n$ for each $H \neq \set{0}$.
3. The condition "not both $0$" in part 3 avoids $\gcd(0, 0)$. For $a = b = 0$, the sum is $\set{0} = 0\Z$, which agrees with the convention $\gcd(0, 0) = 0$.
4. The condition $m, n \geq 1$ in part 4 keeps the least common multiple positive. If $m = 0$, then $m\Z \cap n\Z = \set{0}$, which agrees with the convention $\operatorname{lcm}(0, n) = 0$.

### Consequences

1. [[Bézout's identity|0DQVHMYAGA]]: since $\gcd(a, b) \in a\Z + b\Z$ by part 3, there are integers $x, y$ with $\gcd(a, b) = ax + by$.
2. Every common divisor of $a$ and $b$ divides $\gcd(a, b)$, because it divides $ax + by$.
3. Every common multiple of $m$ and $n$ is a multiple of $\operatorname{lcm}(m, n)$, by part 4.
4. Each subgroup $n\Z$ with $n \geq 1$ is isomorphic to $\Z$ by $k \mapsto nk$. So every subgroup of $\Z$ other than $\set{0}$ is infinite cyclic.
5. Each subgroup of $\Z$ is closed under multiplication by every integer. So the subgroups of $\Z$ are the ideals of the ring $\Z$, and every ideal of $\Z$ is generated by one element.

### Converse

The converse of part 1 holds: each set $n\Z$ is a subgroup of $\Z$, because $nk - nl = n(k - l)$.
Parts 2, 3 and 4 are equalities or equivalences, so they are their own converses.

### Generalizations

1. Each subgroup of $\Z^r$ is isomorphic to $\Z^s$ for some $s \leq r$.
2. In the polynomial ring $F[x]$ over a field $F$, every ideal is generated by one polynomial. The same rules hold for $\gcd$ and $\operatorname{lcm}$ of polynomials.
3. Each subgroup of $(\mathbb{R}, +)$ is either cyclic, of the form $a\Z$, or dense in $\mathbb{R}$. For example, $\Z + \sqrt{2}\,\Z$ is dense.
4. The subgroups of $(\Q, +)$ are not all cyclic. For example, the set of fractions $k / 2^j$ with $k, j \in \Z$ and $j \geq 0$ is a subgroup that is not cyclic.

## Explanations

### L1 human

Every subgroup of the integers under addition is the set of multiples of one number.
For example, take all the numbers that we can make from $12$ and $18$ by adding and subtracting.
We get $18 - 12 = 6$, and every such number is a multiple of $6$.
So we get exactly the multiples of $6$, and $6$ is the greatest common divisor of $12$ and $18$.
The numbers that are multiples of both $12$ and $18$ are $36, 72, 108$ and so on.
They are the multiples of $36$, the least common multiple of $12$ and $18$.

### L2 human

We find the subgroups $12\Z + 18\Z$ and $12\Z \cap 18\Z$.

1. The set $12\Z + 18\Z$ is a subgroup, because $(12x + 18y) - (12x' + 18y') = 12(x - x') + 18(y - y')$.
2. It contains $6 = 12 \cdot (-1) + 18 \cdot 1$.
3. Each element is $12x + 18y = 6(2x + 3y)$, a multiple of $6$. So $6$ is the least positive element.
4. By part 1, $12\Z + 18\Z = 6\Z$, and $6 = \gcd(12, 18)$, as part 3 says.
5. The positive common multiples of $12$ and $18$ are $36, 72, 108, \ldots$. The least is $36$, so $12\Z \cap 18\Z = 36\Z$, as part 4 says.

The typical use is a proof that a set of integers is the set of multiples of one number.
We show that the set is a subgroup, and then we find its least positive element.
A trap: inclusion reverses the size of the numbers.
We have $12\Z \subseteq 6\Z$ because $6$ divides $12$, so the larger number gives the smaller subgroup.

### L3 human

The map $n \mapsto n\Z$ is a bijection from the integers $n \geq 0$ onto the subgroups of $\Z$.
By part 2 it reverses order: $n \mid m$ if and only if $m\Z \subseteq n\Z$.
So the [[lattice of subgroups|0B8BW4YWTF]] of $\Z$ is the set of integers $n \geq 0$ under divisibility, turned upside down.
The sum of two subgroups corresponds to the $\gcd$, and the intersection corresponds to the $\operatorname{lcm}$.

Part 1 says that $\Z$ is a principal ideal domain.
The proof uses only division with remainder, so it works in every [[Euclidean domain|0CHS7RBD39]].
By the [[correspondence theorem|0S9ZVZ34MD]], the subgroups of $\Z/n\Z$ match the subgroups $d\Z$ with $d \mid n$, and this gives the [[fundamental theorem of cyclic groups|0423TXR9AN]].
