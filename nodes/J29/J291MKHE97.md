## Example

Consider the system $x + y = 1$, $x - y = 0$ over $\mathbb{R}$.
We show that it is not homogeneous and that its solution set is not a subspace.

1. The constant term of the first equation is $1 \ne 0$, so the system is not [[homogeneous|04KGXJG1A2]].
2. The operation $R_2 - R_1$ gives $-2y = -1$, so $y = \tfrac12$, and then $x = \tfrac12$. Check: $\tfrac12 + \tfrac12 = 1$ and $\tfrac12 - \tfrac12 = 0$.
3. Double the solution to get $(1, 1)$. Then $1 + 1 = 2 \ne 1$, so $(1, 1)$ is not a solution.
4. The zero vector gives $0 + 0 \ne 1$, so it is not a solution either.
5. A [[linear subspace|00YC1D652K]] contains $0$ and is closed under scaling. So the solution set $\set{(\tfrac12, \tfrac12)}$ is not a subspace.

## Remarks

The associated homogeneous system $x + y = 0$, $x - y = 0$ has only the solution $(0, 0)$.
So the solution set is $(\tfrac12, \tfrac12) + \set{0}$, as the [[structure theorem|PDH3HKXWAZ]] predicts.
The same failure happens for every system with $b \ne 0$, because then $A0 = 0 \ne b$ and the zero vector is never a solution.
If you change the right side to $(0, 0)$, the system becomes homogeneous, and its solution set $\set{0}$ is a subspace.

## Explanations

### L1 human

A subspace must contain zero, and it must stay the same when you double its points.
The single point $(\tfrac12, \tfrac12)$ fails both tests.

### L2 human

Here is a quick test: the solution set of $Ax = b$ is a subspace exactly when $b = 0$.
If $b \ne 0$, then $A0 = 0 \ne b$, so $0$ is not a solution, and every subspace contains $0$.
Watch out: the solution set of a consistent non-homogeneous system is still flat.
It is a shifted copy of a subspace, a point, line or plane that misses the origin, but it is not a subspace itself.
