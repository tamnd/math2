## Summary

Two flows are dynamically similar when they have the same shape up to scale and the same values of all the relevant [[dimensionless numbers|T3R5FWV91P]].
Then their solutions, written in dimensionless variables, are the same.
This lets engineers test a small model in a wind tunnel or a towing tank.
The results then predict the behaviour of a full-size aircraft or ship.

## Explanations

### L1 human

A toy-sized airplane in a wind tunnel can tell you about a real airplane only if the air flows around both in the same pattern.
Making the model the same shape is not enough; the balance of the forces must also match.
Dynamic similarity asks that the dimensionless numbers, such as the [[Reynolds number|JH9EJ0HA0R]], take the same values for the model and for the real object.
For example, a model at one tenth of the size in the same fluid needs ten times the speed to have the same Reynolds number.
