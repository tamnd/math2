## Summary

This topic is a part of [[mathematical logic|DYJ0KGTPMR]], and it starts with one table entry.
In 1920 Łukasiewicz gave sentences about the open future a third value $\tfrac12$, and his implication gives $\tfrac12 \to \tfrac12 = 1$.
So "if $p$ then $p$" stays a law while "$p$ or not $p$" does not.

Other readings of the middle value followed.
Post studied $n$-valued logics in 1921 and found connectives that define every truth function.
Kleene read the third value as "undefined" in 1938, for computations that may never stop, and Bochvar read it as "meaningless" in the same year.
Belnap-Dunn logic, from Dunn in 1976 and Belnap in 1977, adds a fourth value for conflicting reports.
All of these are logics of a logical matrix: an algebra of values with some values designated as true.

Łukasiewicz's logic also has a version with every value in $[0, 1]$.
Rose and Rosser proved it complete in 1958, and Chang introduced MV-algebras in 1958 and gave an algebraic proof in 1959.
McNaughton had described in 1951 the functions its formulas define.

Fuzzy logic in the narrow sense grew from this.
A t-norm is a truth function for "and", and Hájek's basic logic of 1998 is the logic of all continuous t-norms, as Cignoli, Esteva, Godo and Torrens proved in 2000.
Esteva and Godo's MTL of 2001 does the same for the left-continuous t-norms, by the theorem of Jenei and Montagna of 2002.
The topic ends with graded consequence, the complexity of first-order fuzzy logic, a game with lies, probability logic and vector logic.

## Remarks

### Reading order

1. [[Many-valued logic|DWYCKAKXZD]]: truth values beyond true and false, and why they are useful.
2. [[Logical matrix|P7E926JK13]]: an algebra with designated values, the common frame of all the logics below.
3. [[Łukasiewicz three-valued logic|1CE2TGM6MQ]]: the first many-valued logic, where the entry $\tfrac12 \to \tfrac12 = 1$ keeps $p \to p$ a law.
4. [[Strong Kleene logic|SZHA10A9X7]]: a third value for "undefined", where $p \lor \neg p = \tfrac12$ and no formula is a law.
5. [[Weak Kleene logic|BCK5QXQXA6]]: a third value for "meaningless" that spreads to every compound formula.
6. [[First-degree entailment|KXTP4P3GHT]]: four values for true, false, neither and both, arranged as a bilattice.
7. [[Post's many-valued logics|YHYSGRE7JV]]: a functionally complete logic for each finite number of values.
8. [[Sheffer function|1K829SJG3K]]: one connective that defines all others in a finitely valued logic.

### Reading order, continued

9. [[Łukasiewicz infinite-valued logic|NFCEM44XYH]]: truth values in $[0, 1]$, where $0.7 \to 0.4 = 0.7$.
10. [[Chang's completeness theorem|QM0F33QE9P]]: completeness through MV-algebras.
11. [[McNaughton's theorem|E11A9H8Z7Q]]: the functions that Łukasiewicz formulas define are the piecewise linear ones with integer coefficients.
12. [[Fuzzy logic|8DH4QM6AX8]]: fuzzy logic as a logic with a consequence relation, and its other use in engineering.
13. [[Triangular norm|VR6D8JXX1W]]: the truth functions of conjunction, which at $(0.5, 0.5)$ give $0.5$, $0.25$ or $0$.
14. [[Hájek's basic logic BL|3AQ5GHTXA4]]: the logic of all continuous t-norms.
15. [[Monoidal t-norm based logic|PT5PHKJDYM]]: the logic of all left-continuous t-norms.
16. [[Product fuzzy logic|YTHRDT9PDR]]: the logic of the product t-norm.
17. [[First-order Gödel logics|H8C323CV3T]]: quantifiers over the minimum t-norm, where the set of truth values matters.
18. [[Pavelka logic|YG62F8YC0P]]: truth constants in the language and consequence that comes in degrees.
19. [[Arithmetical complexity of first-order Łukasiewicz logic|VAHH1505Z0]]: why no computable list of axioms is complete.
20. [[Rényi-Ulam game with one lie|402GXME26B]]: a search game with lies, described by Łukasiewicz values.
21. [[Probability logic|Z2WRGJDRQT]]: probabilities on formulas, which behave differently from truth values.
22. [[Vector logic|DJ41X602BJ]]: truth values as orthonormal vectors and connectives as matrices.

### Prerequisites

[[The propositional calculus|JDK63589SA]] supplies formulas, valuations, tautologies and Hilbert calculi.
[[Algebraic logic|QYA4H5Y7VR]] supplies Boolean algebras, lattices and the algebraic view of a logic.
Rows 17 and 19 also need first-order structures and the [[arithmetical hierarchy|7CVJCQKY41]].

### Notation

The notation for strong conjunction varies between sources: $\otimes$, $\&$ and, in the MV-algebra literature, $\odot$.
This topic writes $\odot$ for the strong conjunction of Łukasiewicz logic and $\oplus$ for its strong disjunction.
For general t-norm logics such as BL and MTL, it writes $\otimes$ for the strong conjunction and $*$ for a t-norm.
In [[vector logic|DJ41X602BJ]], $\otimes$ is the Kronecker product, which is a different operation.
