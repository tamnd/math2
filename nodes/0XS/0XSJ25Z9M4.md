## Definition

A linear isomorphism is a linear map that matches the vectors of two spaces one to one.

Let $F$ be a field and let $V$ and $W$ be vector spaces over $F$.
A *linear isomorphism* from $V$ to $W$ is a [[bijective|0SNQEF7Z53]] [[linear map|0RJF668P1T]] $T \colon V \to W$.
The spaces $V$ and $W$ are *isomorphic*, written $V \cong W$, when a linear isomorphism $V \to W$ exists.

## Notation

A linear isomorphism is also called an *invertible linear map* or an *isomorphism of vector spaces*.
A linear isomorphism $V \to V$ is called an *automorphism* of $V$.

## Remarks

The definition has two conditions, linearity and bijectivity, and neither implies the other.
The swap $T(a, b) = (b, a)$ on $\R^2$ is linear and is its own inverse, so it is an isomorphism.
The projection $(a, b) \mapsto (a, 0)$ is linear but sends $(0, 1)$ and $(0, 2)$ to the same vector, so it fails bijectivity.
The cube map $x \mapsto x^3$ on $\R$ is bijective but fails linearity.

An equivalent definition asks for a linear map $S \colon W \to V$ with $S \circ T = \id_V$ and $T \circ S = \id_W$.
The two definitions agree because the inverse of a bijective linear map is linear.
Mathlib uses this second form: `LinearEquiv` is a linear map together with an inverse map and the two inverse laws.
For an $n \times n$ matrix $A$, the map $x \mapsto Ax$ is an isomorphism of $F^n$ exactly when $A$ is [[invertible|0EB9N0S33C]].
The [[concept page|0B8T10CE7N]] has more examples and the main properties.

## Explanations

### L1 human

A linear isomorphism is a linear map that matches the vectors of two spaces one to one.
Each vector of $W$ is the image of exactly one vector of $V$.
So the map can be undone, and the undoing map is again linear.

### L2 human

For $T(a, b) = (a + 2b, \; b)$ on $\R^2$, solving $T(a, b) = (u, v)$ gives $b = v$ and $a = u - 2v$, so each $(u, v)$ has exactly one preimage.
So $T$ is a linear isomorphism, with inverse $(u, v) \mapsto (u - 2v, \; v)$.
Watch out: a linear map that is only injective, such as $x \mapsto (x, 0)$ from $\R$ to $\R^2$, is not an isomorphism.
