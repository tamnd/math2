## Definition

Let $F$ be a field and let $V$ and $W$ be vector spaces over $F$.
A *linear isomorphism* from $V$ to $W$ is a [[bijective|0SNQEF7Z53]] [[linear map|0RJF668P1T]] $T \colon V \to W$.
The spaces $V$ and $W$ are *isomorphic*, written $V \cong W$, when a linear isomorphism $V \to W$ exists.

## Notation

A linear isomorphism is also called an *invertible linear map* or an *isomorphism of vector spaces*.
A linear isomorphism $V \to V$ is called an *automorphism* of $V$.

## Remarks

- An equivalent definition asks for a linear map $S \colon W \to V$ with $S \circ T = \id_V$ and $T \circ S = \id_W$. The two definitions agree because the inverse of a bijective linear map is linear.
- Mathlib uses the second form: `LinearEquiv` is a linear map together with an inverse map and the two inverse laws.
- For an $n \times n$ matrix $A$, the map $x \mapsto Ax$ is an isomorphism of $F^n$ if and only if $A$ is [[invertible|0EB9N0S33C]].

## Explanations

### L1 human

A linear isomorphism is a linear map that matches the vectors of two spaces one to one.
Each vector of $W$ is the image of exactly one vector of $V$.

### L2 human

The map $T(a, b) = (b, a)$ on $\R^2$ is linear and is its own inverse, so it is an isomorphism.
The map $T(a, b) = (a, 0)$ is linear but sends $(0, 1)$ and $(0, 2)$ to the same vector, so it is not an isomorphism.
