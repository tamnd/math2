## Summary

In mathematics, the **continuum function** is the function $\kappa\mapsto 2^\kappa$ on [[cardinals|0EBACQFAZW]], i.e. raising 2 to the power of *κ* using cardinal exponentiation. Given a cardinal number, the cardinal function yields the cardinality of the [[power set|00E0YZCERH]] of a set of the given cardinality.
