## Example

For a real number $x$, the chain "$1 < x < 4$" means "$1 < x$ and $x < 4$".
With $p$ for "$1 < x$" and $q$ for "$x < 4$", the chain is the [[conjunction|025YZN3VJW]] $p \land q$.
We compute its truth value for three values of $x$ and then find all $x$ that satisfy it.

1. At $x = 2$, $1 < 2$ is T and $2 < 4$ is T.
   Both conjuncts are T, so $p \land q$ is T.
2. At $x = 0$, $1 < 0$ is F and $0 < 4$ is T.
   One conjunct is F, so $p \land q$ is F.
3. At $x = 5$, $1 < 5$ is T and $5 < 4$ is F.
   One conjunct is F, so $p \land q$ is F.
4. The row "$p$ F, $q$ F" would need $x \le 1$ and $x \ge 4$ at once.
   No real number satisfies both, so this row never occurs.
5. So $1 < x < 4$ is true exactly for the $x$ in the open interval $(1, 4)$.

## Remarks

A chain of inequalities is a conjunction, and its solution set is an [[intersection|0ZNMMA9TF5]]:
$$(1, \infty) \cap (-\infty, 4) = (1, 4).$$
The sentence "$x$ is greater than $1$ but less than $4$" has the same form, with "but" in place of "and".

Step 4 shows that the parts of a conjunction can be linked, so some rows of a truth table may never occur for a given meaning of $p$ and $q$.
The table still covers every case of the form $p \land q$.

Reverse the chain to "$4 < x < 1$" and it means "$4 < x$ and $x < 1$", which is false for every real $x$.
Such a chain is not wrong to write, but it describes the empty set.

## Explanations

### L1 human

"$x$ is between $1$ and $4$" packs two claims into one: $x$ is bigger than $1$, and $x$ is smaller than $4$.
For $x = 2$ both claims hold, so $2$ is between $1$ and $4$.
For $x = 5$ the second claim fails, so $5$ is not between them.
One failed claim is enough.

### L2 human

Find all integers $n$ with $-2 \le n < 3$ and $n^2 > 1$.
The condition is a conjunction of three parts.
The first two parts leave $n = -2, -1, 0, 1, 2$.
The squares are $4, 1, 0, 1, 4$, and only $4$ is greater than $1$.
So the integers that satisfy all three parts are $-2$ and $2$.
Each conjunct filters out the values that fail it, which is how a list of conditions works in practice.
Watch out: "$-2 \le n < 3$" includes $-2$ and excludes $3$, so read each inequality sign separately.
