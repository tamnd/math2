## Example

For a real number $x$, the chained inequality "$1 < x < 4$" means "$1 < x$ and $x < 4$".
Let $p$ be "$1 < x$" and $q$ be "$x < 4$", so the chain is the [[conjunction|025YZN3VJW]] $p \land q$.
We compute its truth value from the truth table of $\land$ for three values of $x$.

1. $x = 2$: $1 < 2$ is T and $2 < 4$ is T. Both conjuncts are T, so $p \land q$ is T.
2. $x = 0$: $1 < 0$ is F and $0 < 4$ is T. One conjunct is F, so $p \land q$ is F.
3. $x = 5$: $1 < 5$ is T and $5 < 4$ is F. One conjunct is F, so $p \land q$ is F.
4. The row "$p$ F, $q$ F" would need $x \leq 1$ and $x \geq 4$ at the same time. No real number satisfies both, so this row does not occur for any $x$.
5. So $1 < x < 4$ is true exactly for the $x$ in the open interval $(1, 4)$.

## Remarks

The example shows that a chain of inequalities is a conjunction, and that its set of solutions is an [[intersection|0ZNMMA9TF5]]: $(1, \infty) \cap (-\infty, 4) = (1, 4)$.
The sentence "$x$ is greater than $1$ but less than $4$" has the same form; "but" is a conjunction here.

Step 4 shows that the parts of a conjunction can be linked: some rows of the truth table may never occur for a given meaning of $p$ and $q$.
The truth table still covers every possible case of the form $p \land q$.

If we change the chain to "$4 < x < 1$", then it means "$4 < x$ and $x < 1$", which is false for every real $x$.
Such a chain is not wrong to write, but it describes the empty set.

## Explanations

### L1 human

"$x$ is between $1$ and $4$" packs two claims into one: $x$ is bigger than $1$, and $x$ is smaller than $4$.
For $x = 2$ both claims hold, so $2$ is between $1$ and $4$.
For $x = 5$ the second claim fails, so $5$ is not between them.
One failed claim is enough.

### L2 human

We find all integers $n$ with $-2 \leq n < 3$ and $n^2 > 1$.

1. The condition is a conjunction of three parts: $-2 \leq n$, $n < 3$ and $n^2 > 1$.
2. The first two parts give the integers $-2, -1, 0, 1, 2$.
3. The third part: $(-2)^2 = 4 > 1$, $(-1)^2 = 1$, $0^2 = 0$, $1^2 = 1$ and $2^2 = 4 > 1$.
4. So the integers that satisfy all three parts are $-2$ and $2$.

The typical use of a conjunction of conditions is this filtering: each conjunct removes the values that fail it.

A trap: "$-2 \leq n < 3$" includes $-2$ and excludes $3$, so each inequality sign must be read separately.
