## Definition

A *phase space* is a pair $(M, \bot)$ of a commutative [[monoid|0N6R902FG1]] $(M, \cdot, 1)$ and a subset $\bot \subseteq M$.
For $X \subseteq M$, put $X^{\perp} = \set{m \in M \mid m x \in \bot \text{ for all } x \in X}$.
A *fact* is a set $X \subseteq M$ with $X = X^{\perp\perp}$.

A *phase model* is a phase space with a fact $p^*$ for each atom $p$.
It gives a fact $A^*$ for each formula $A$ of MALL, the multiplicative-additive fragment of [[linear logic|H408H4WHBA]]:

1. $(p^{\perp})^* = (p^*)^{\perp}$;
2. $(A \otimes B)^* = (A^* B^*)^{\perp\perp}$ and $(A \mathbin{\wp} B)^* = ((A^*)^{\perp} (B^*)^{\perp})^{\perp}$;
3. $(A \mathbin{\&} B)^* = A^* \cap B^*$ and $(A \oplus B)^* = (A^* \cup B^*)^{\perp\perp}$;
4. $1^* = \set{1}^{\perp\perp}$, $\bot^* = \bot$, $\top^* = M$ and $0^* = M^{\perp}$.

A sequent $\vdash A_1, \ldots, A_n$ is *valid* in the model if $a_1 \cdots a_n \in \bot$ for all $a_1 \in (A_1^*)^{\perp}, \ldots, a_n \in (A_n^*)^{\perp}$.
For $n = 0$ this means $1 \in \bot$.
A sequent is *valid* if it is valid in every phase model.

## Notation

For a sequent $\Gamma = A_1, \ldots, A_n$ we write $V(\Gamma) = (A_1^*)^{\perp} \cdots (A_n^*)^{\perp}$, so $\Gamma$ is valid if and only if $V(\Gamma) \subseteq \bot$.
Some authors write a phase space as $(M, \bot)$ and others as $(M, \cdot, 1, \bot)$.

## Remarks

### Basic facts

These facts hold in every phase space, and the proofs below use only the definition and the commutativity of $M$.

1. $X \subseteq X^{\perp\perp}$: for $x \in X$ and $m \in X^{\perp}$, $x m = m x \in \bot$.
2. If $X \subseteq Y$, then $Y^{\perp} \subseteq X^{\perp}$, since the condition for $Y^{\perp}$ is stronger.
3. $X^{\perp\perp\perp} = X^{\perp}$: fact 1 for $X^{\perp}$ gives $\subseteq$, and fact 2 applied to fact 1 gives $\supseteq$.
4. $X Y \subseteq \bot$ if and only if $X \subseteq Y^{\perp}$, by the definition of $Y^{\perp}$.
5. $X Y \subseteq \bot$ if and only if $X^{\perp\perp} Y \subseteq \bot$: by fact 4, both say $Y \subseteq X^{\perp}$, and $X^{\perp} = X^{\perp\perp\perp}$ by fact 3.
6. $\bot = \set{1}^{\perp}$, so $\bot$ is a fact.
   An intersection of facts is a fact, since $\bigcap_i X_i^{\perp\perp} = (\bigcup_i X_i^{\perp})^{\perp}$.

By facts 3 and 6, every $A^*$ is a fact.
By fact 4, $\Gamma, A$ is valid if and only if $V(\Gamma) \subseteq (A^*)^{\perp\perp} = A^*$.
In particular, $\vdash A^{\perp}, B$ is valid if and only if $A^* \subseteq B^*$.

### Negation

By induction on $A$, $(A^{\perp})^* = (A^*)^{\perp}$ for every formula $A$.
For example, $((B \otimes C)^{\perp})^* = (B^{\perp} \mathbin{\wp} C^{\perp})^* = ((B^*)^{\perp\perp} (C^*)^{\perp\perp})^{\perp} = (B^* C^*)^{\perp}$, which is $((B \otimes C)^*)^{\perp}$ by fact 3.
For the exponentials, Girard's phase semantics adds a structure to the phase space; this node treats MALL only.

## Explanations

### L1 human

Take a set of things that can be combined, and pick some combinations as "good", the set $\bot$.
The negation of a set $X$ is the set of all things that make a good combination with every member of $X$.
Formulas are read as sets equal to the negation of their negation.

### L2 human

We find the facts of $M = \set{1, a}$ with $a a = a$, and $\bot = \set{a}$.

1. $\set{1}^{\perp} = \set{m \mid m \in \bot} = \set{a}$.
2. $\set{a}^{\perp} = \set{m \mid m a = a} = \set{1, a}$, since $1 a = a$ and $a a = a$.
3. $\emptyset^{\perp} = M$ and $M^{\perp} = \set{a}^{\perp} \cap \set{1}^{\perp} = \set{a}$.
4. So $\set{1}^{\perp\perp} = \set{a}^{\perp} = M$, and $\set{1}$ is not a fact.
   The facts are $\set{a}$ and $M$.
5. In this space $1^* = M$ and $\bot^* = \set{a}$.

The typical use of the definition is to build small models in which a given sequent is not valid.
A trap: here both elements satisfy $m m = m$, so $X \subseteq X X$ for every set $X$, and $\vdash A^{\perp}, A \otimes A$ is valid; a model that refutes it needs an element with $m m \neq m$.
