## Proof

**Part 1.** Assume $BA = I_n$.

1. Let $x \in F^n$ with $Ax = 0$, a solution of the [[homogeneous system|04KGXJG1A2]] with matrix $A$.
2. By [[associativity|073E4XC016]], $x = I_n x = (BA)x = B(Ax) = B \cdot 0 = 0$.
3. So $Ax = 0$ has only the trivial solution.
4. By [[invertibility and row reduction|1ZK55FS2BF]], a square matrix over a field for which $Ax = 0$ has only the trivial solution is invertible. So $A$ is invertible.
5. A left inverse and a right inverse of one matrix are equal, by the [[uniqueness of the inverse|FMCX4D7RD4]]. Here $B$ is a left inverse and $A^{-1}$ is a right inverse, so $B = A^{-1}$.
6. So $AB = AA^{-1} = I_n$.

**Part 2.** Assume $AB = I_n$.

7. Read with the roles exchanged, this says that $A$ is a left inverse of $B$.
8. By part 1 applied to the pair $(B, A)$, the matrix $B$ is invertible and $BA = I_n$.
9. So $A$ is the inverse of $B$. By the definition of the [[inverse|0TWTS88TWN]], $A$ is invertible with $A^{-1} = B$.

## Idea

A left inverse kills every nonzero solution of $Ax = 0$.
Elimination then finds a pivot in every column, so the reduced row echelon form is $I_n$, and $A$ is invertible.
