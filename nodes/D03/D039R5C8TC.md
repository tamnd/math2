## Statement

In the atomic formula $x \cdot y = y + 1$, both occurrences of $y$ and the one occurrence of $x$ are free, since nothing in the formula can bind them.
The proposition says that this holds for every atomic formula.

Let $\varphi$ be an [[atomic formula|MCZRXR3SVB]] over a signature $\sigma$, so $\varphi$ is $t_1 = t_2$ or $R(t_1, \dots, t_n)$ for [[terms|6D3WA7N2W4]] $t_i$.

1. Every occurrence of a variable in $\varphi$ is [[free|9CNGDRAMGC]].
2. The set $\operatorname{FV}(\varphi)$ of free variables is the set of variables that occur in $\varphi$, that is, $\operatorname{Var}(t_1) \cup \dots \cup \operatorname{Var}(t_n)$, and $\operatorname{BV}(\varphi) = \emptyset$.
3. The formula $\varphi$ is a [[sentence|DKFGQTRYZE]] exactly when every $t_i$ is a closed term.

## Remarks

### Why each hypothesis is needed

The formula must be atomic.
In $\exists y \, (x = y)$ the occurrence of $y$ in the equation is bound, so part 1 fails once a quantifier is present.
For quantifier-free formulas the three parts still hold, by the same proof, because only quantifiers bind variables.

### Consequences

The base case of every induction on formulas about free variables is immediate, because in an atomic formula the free variables and the occurring variables are the same.
The truth of an atomic formula in a structure depends only on the values of the variables that occur in it.
A signature without constant symbols has no atomic sentences, because it has no closed terms.
For example, the signature $\{ < \}$ has no atomic sentence, while $\{ 0, < \}$ has $0 < 0$ and $0 = 0$.

### The converse fails

A formula in which every variable occurrence is free need not be atomic.
The formula $\neg (x = y)$ is an example, and so is every quantifier-free formula with a connective.

### Watch out

Freedom is a property of an occurrence inside a given formula, not of a variable once and for all.
In $(x = 0 \land \forall x \, (x = x))$, the first occurrence of $x$ is free, and the occurrences inside $\forall x \, (x = x)$ are bound.
Inside the atomic subformula $x = x$ alone, the same occurrences are free.
So the proposition speaks about the atomic formula on its own, not about its place in a larger formula.

## History

Textbooks of first-order logic state this fact as the base case of the definition of free variables.
Enderton defines "$x$ occurs free in $\alpha$" for atomic $\alpha$ to mean that $x$ occurs in $\alpha$, so he takes this proposition as part of the definition.

## Explanations

### L1 human

A variable is bound when a "for all" or "there exists" on that variable covers it.
An atomic formula, such as $x + 1 = y$, has no "for all" and no "there exists".
So every variable in it is free, and the formula is a claim about the values of those variables.

### L2 human

We check the three parts for $\varphi = P(f(x), c, y)$, with a constant $c$, a unary function symbol $f$ and a ternary relation symbol $P$.
The variables that occur are $x$ and $y$, each once.
No quantifier occurs, so both occurrences are free.
We compute
$$\operatorname{FV}(\varphi) = \operatorname{Var}(f(x)) \cup \operatorname{Var}(c) \cup \operatorname{Var}(y) = \{ x \} \cup \emptyset \cup \{ y \} = \{ x, y \}.$$
The terms $f(x)$ and $y$ are not closed, so $\varphi$ is not a sentence.
By contrast, $P(f(c), c, c)$ has only closed terms, so it is a sentence.
The typical use of the proposition is the base case of a proof by induction on formulas.
Watch out: a variable that occurs in an atomic formula is free there, even when the same occurrence is bound in a larger formula that contains it.
