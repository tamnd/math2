## Statement

Let $\varphi$ be an [[atomic formula|MCZRXR3SVB]] over a signature $\sigma$, so $\varphi$ is $t_1 = t_2$ or $R(t_1, \dots, t_n)$ for [[terms|6D3WA7N2W4]] $t_i$.

1. Every occurrence of a variable in $\varphi$ is [[free|9CNGDRAMGC]].
2. $\operatorname{FV}(\varphi)$ is the set of variables that occur in $\varphi$, that is, $\operatorname{Var}(t_1) \cup \dots \cup \operatorname{Var}(t_n)$, and $\operatorname{BV}(\varphi) = \emptyset$.
3. $\varphi$ is a [[sentence|DKFGQTRYZE]] exactly when every $t_i$ is a closed term.

## Remarks

### Why each hypothesis is needed

The formula must be atomic.
In $\exists y \, (x = y)$ the occurrence of $y$ in the equation is bound, so part 1 fails for formulas with quantifiers.
For quantifier-free formulas the three parts still hold, by the same proof, because only quantifiers bind variables.

### Consequences

1. The base case of every induction on formulas about free variables is immediate: in an atomic formula, free and occurring variables agree.
2. The truth of an atomic formula in a structure depends only on the values of the variables that occur in it.
3. A signature without constant symbols has no atomic sentences, because it has no closed terms.

### Converse

The converse of part 1 is false: a formula in which every variable occurrence is free need not be atomic.
The formula $\neg (x = y)$ is an example.
Every quantifier-free formula has only free occurrences, and a formula with a quantifier $\forall x$ or $\exists x$ whose scope contains $x$ has a bound occurrence.

### Generalizations

A formula $\varphi$ has a bound occurrence of $x$ exactly when some subformula $\forall x \, \psi$ or $\exists x \, \psi$ of $\varphi$ has $x \in \operatorname{FV}(\psi)$.
For a quantifier-free formula there is no such subformula, so every occurrence is free.

## History

Textbooks of first-order logic state this fact as the base case of the definition of free variables.
Enderton defines "$x$ occurs free in $\varphi$" for atomic $\varphi$ as "$x$ occurs in $\varphi$", which is this proposition taken as a definition.

## Explanations

### L1 human

A variable is bound when a "for all" or "there exists" on that variable covers it.
An atomic formula, such as $x + 1 = y$, has no "for all" and no "there exists".
So every variable in it is free, and it is a claim about the values of those variables.

### L2 human

We check the three parts for $\varphi = P(f(x), c, y)$ with a constant $c$, a unary $f$ and a ternary $P$.

1. The variables that occur are $x$ and $y$, each once.
2. No quantifier occurs, so both occurrences are free.
3. $\operatorname{FV}(\varphi) = \operatorname{Var}(f(x)) \cup \operatorname{Var}(c) \cup \operatorname{Var}(y) = \set{x} \cup \emptyset \cup \set{y} = \set{x, y}$.
4. The terms $f(x)$ and $y$ are not closed, so $\varphi$ is not a sentence. The atomic formula $P(f(c), c, c)$ is a sentence.

The typical use of the proposition is the base case of a proof by induction on formulas.
A trap: a variable that occurs in a term of an atomic formula is free there, even when the same variable is bound elsewhere in a larger formula.
