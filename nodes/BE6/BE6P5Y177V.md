## Example

Let $R$ be a [[real closed field|DDY3Q3PJ6W]] that is not archimedean, in the signature $\set{+, \cdot, 0, 1, <}$.
For example, $R$ can be the real closure of the [[ordered field|0P3VCBDEE2]] $\mathbb{R}(t)$, with $0 < t < 1/n$ for every $n \ge 1$.
Write $x \approx y$ when $|x - y| < 1/n$ for every integer $n \ge 1$, and let $\mu = \set{x : x \approx 0}$ be the set of infinitesimals.

1. Type-definable. The relation $\approx$ is the set of solutions of the set of formulas $\set{-1/n < x - y < 1/n : n \ge 1}$, without parameters, since each $1/n$ is $\emptyset$-definable.
2. Equivalence relation. It is reflexive and symmetric. For transitivity, $|x - y| < 1/(2n)$ and $|y - z| < 1/(2n)$ give $|x - z| < 1/n$.
3. Bounded and nonempty. The set $\mu$ contains $t > 0$, and $1$ is an upper bound for $\mu$.
4. Definable sets have suprema. By [[Tarski's quantifier elimination|FSJ9NGRRPA]], each definable subset of $R$ is a finite union of points and intervals with endpoints in $R \cup \set{\pm\infty}$. So a nonempty definable subset with an upper bound in $R$ has a least upper bound in $R$.
5. $\mu$ has no supremum. Suppose $s = \sup \mu$, so $s \ge t > 0$. If $s \in \mu$, then $2 s \in \mu$ and $2 s > s$. If $s \notin \mu$, then $s \ge 1/n$ for some $n$, and $1/(2n) < s$ is a smaller upper bound.
6. So $\mu$ is not definable, even with parameters, and $\approx$ is not definable either, since $\mu = \set{x : x \approx 0}$.

Hence $\approx$ is not one of the relations $E$ that give the sorts of $R^{\mathrm{eq}}$, and the classes $x + \mu$ are not [[imaginary elements|120S3V3975]].
They are hyperimaginaries, the classes of a type-definable equivalence relation; see [[this definition|N1RV9VNCE8]].

## Remarks

The example shows that the definition of $M^{\mathrm{eq}}$ uses definable relations, and that compactness arguments often produce type-definable ones instead.

On the finite elements, those with $|x| < n$ for some $n$, the class of $x$ determines its [[standard part|1ZBY4W4E81]] in $\mathbb{R}$, and the quotient is the residue field $\mathbb{R}$ of the natural valuation.
The relation $\approx$ depends on the model only through the formulas $|x - y| < 1/n$, so it makes sense in every model of the theory of real closed fields, and it is equality in $\mathbb{R}$ itself.

## Explanations

### L1 human

In some number systems there are numbers that are positive but smaller than $1$, $\tfrac12$, $\tfrac13$ and every other fraction $1/n$.
Two numbers are "infinitely close" when their difference is such a tiny number.
We can describe this with infinitely many conditions, one for each $n$, but not with one formula.
The reason is that the tiny numbers have no largest member and no smallest upper bound, while every set given by one formula has one.

### L2 human

We check the failure of a supremum in $R$ on one candidate.

1. Try $s = t$ as a supremum of $\mu$.
2. Then $2 t$ is in $\mu$, since $2 t < 2/(2 n) = 1/n$ by $t < 1/(2n)$.
3. And $2 t > t$, so $t$ is not an upper bound.
4. Try instead $s = 1/1000$. Then $1/2000$ is a smaller upper bound, since every infinitesimal is below $1/2000$.

The typical use is to recognize type-definable relations, like "infinitely close", that arise from infinitely many conditions.
A trap is to replace them by one of the conditions: $|x - y| < 1/1000$ is definable, but it is not transitive.
