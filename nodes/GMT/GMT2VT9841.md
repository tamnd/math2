## Counterexample

The trace lets you rotate a product of three matrices, but swapping two of the factors can change it.
Claim: $\operatorname{tr}(ABC) = \operatorname{tr}(BAC)$ for all $n \times n$ matrices.
This claim is false.
Take
$$A = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}, \qquad B = \begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix}, \qquad C = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}.$$

1. The first order gives
$$AB = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}, \qquad ABC = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}, \qquad \operatorname{tr}(ABC) = 1.$$
2. The swapped order gives
$$BA = \begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix}, \qquad BAC = \begin{pmatrix} 0 & 0 \\ 0 & 0 \end{pmatrix}, \qquad \operatorname{tr}(BAC) = 0,$$
since $C$ keeps only the first column of $BA$, which is zero.
3. So $\operatorname{tr}(ABC) = 1 \neq 0 = \operatorname{tr}(BAC)$.
4. The cyclic shifts of $ABC$ agree, as the [[cyclic property|0Y4NF1DRKD]] says: $BCA = \begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix}$ and $CAB = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}$ both have trace $1$.

## Remarks

### Why it works

In [[matrix units|A4HTT7JFD1]], $A = E_{12}$, $B = E_{21}$ and $C = E_{11}$, and every product follows from $E_{ij} E_{kl} = \delta_{jk} E_{il}$.
The six orders split into the two cyclic classes $\{ABC, BCA, CAB\}$ and $\{BAC, ACB, CBA\}$.
The first class has trace $1$, and the second class has trace $0$, for example $ACB = E_{12} E_{11} E_{21} = 0$.

### When all orders agree

For three [[symmetric|0VR671PHE5]] matrices the trace is the same for all six orders.
The transpose does not change the trace, so
$$\operatorname{tr}(ABC) = \operatorname{tr}((ABC)^{\mathsf{T}}) = \operatorname{tr}(C^{\mathsf{T}} B^{\mathsf{T}} A^{\mathsf{T}}) = \operatorname{tr}(CBA),$$
and $CBA$ lies in the second cyclic class, which joins the two classes.
The matrices $A$ and $B$ above are not symmetric, since $A^{\mathsf{T}} = B$.

## Explanations

### L1 human

You may move the first factor to the end, but you may not swap two factors.
Swapping $A$ and $B$ here changes the trace from $1$ to $0$.

### L2 human

The cyclic property comes from $\operatorname{tr}(XY) = \operatorname{tr}(YX)$ with $X$ a single factor and $Y$ the rest.
Swapping two neighbors is not of this form, so nothing protects it.
For two factors the swap is a cyclic shift, which is why the problem starts with three.
