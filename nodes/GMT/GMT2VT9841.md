## Counterexample

Claim: $\operatorname{tr}(ABC) = \operatorname{tr}(BAC)$ for all $n \times n$ matrices.
This claim is false.
Take
$$A = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}, \qquad B = \begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix}, \qquad C = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}.$$

1. $AB = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}$, so $ABC = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}$ and $\operatorname{tr}(ABC) = 1$.
2. $BA = \begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix}$, so $BAC = \begin{pmatrix} 0 \cdot 1 & 0 \\ 1 \cdot 0 & 0 \end{pmatrix} = \begin{pmatrix} 0 & 0 \\ 0 & 0 \end{pmatrix}$ and $\operatorname{tr}(BAC) = 0$.
3. So $\operatorname{tr}(ABC) = 1 \neq 0 = \operatorname{tr}(BAC)$.
4. The cyclic shifts agree, as the [[cyclic property|0Y4NF1DRKD]] says. $BCA = \begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix}$ and $CAB = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}$ both have trace $1$.

## Remarks

In matrix units, $A = E_{12}$, $B = E_{21}$ and $C = E_{11}$, and the products follow from $E_{ij} E_{kl} = \delta_{jk} E_{il}$; see [[matrix units|A4HTT7JFD1]].
For three [[symmetric|0VR671PHE5]] matrices the trace is invariant under all six orders, because $\operatorname{tr}(ABC) = \operatorname{tr}((ABC)^{\mathsf{T}}) = \operatorname{tr}(CBA)$.

## Explanations

### L1 human

We may move the first factor to the end, but we may not swap two factors.
Swapping $A$ and $B$ here changes the trace from $1$ to $0$.

### L2 human

The cyclic property comes from $\operatorname{tr}(XY) = \operatorname{tr}(YX)$ with $X$ a single factor and $Y$ the rest.
A swap of two neighbours is not of this form, so nothing protects it.
