## Example

One player picks a number from $1$ to $4$, and the other asks yes-or-no questions to find it.
The first player may lie once.
Four questions are not enough, and five are.
The bookkeeping that proves both facts is the arithmetic of [[Łukasiewicz three-valued logic|1CE2TGM6MQ]].

In the *Rényi-Ulam game* the unknown $x$ lies in a finite set $U$ with $n$ elements.
Each question is a subset $Q \subseteq U$, read as "is $x \in Q$?", and at most one answer in the whole game is a lie.
We take $n = 2^m$ and ask for the least number $q$ of questions that always find $x$.

### The states as three-valued functions

After some answers, give each $y \in U$ the value $1$ if $y$ is consistent with all answers, $\tfrac12$ if it is inconsistent with exactly one, and $0$ otherwise.
This is a map $\sigma \colon U \to \{0, \tfrac12, 1\}$, and at the start $\sigma(y) = 1$ for all $y$.
An answer to $Q$ defines $a \colon U \to \{\tfrac12, 1\}$, with $a(y) = 1$ if $y$ agrees with the answer and $a(y) = \tfrac12$ if not.
The new state is $\sigma \odot a$, computed at each $y$ with the [[Łukasiewicz conjunction|F9NDCFY3GS]] $u \odot v = \max(0, u + v - 1)$.
Check: $1 \odot 1 = 1$, $1 \odot \tfrac12 = \tfrac12$ and $\tfrac12 \odot \tfrac12 = 0$.
So each inconsistency costs $\tfrac12$, and two of them give $0$.
The secret $x$ never reaches $0$, because at most one answer is a lie.
So the questioner has found $x$ exactly when only one element has a value above $0$.

### The volume bound

With $r$ questions still to ask, give a state the weight
$$W_r(\sigma) = (r + 1) \cdot \#\{y : \sigma(y) = 1\} + \#\{y : \sigma(y) = \tfrac12\}.$$

1. Let the state be $\sigma$, ask any $Q$, and let $\sigma_{\mathrm{yes}}$ and $\sigma_{\mathrm{no}}$ be the two next states.
2. An element with value $1$ keeps $1$ under one answer and gets $\tfrac12$ under the other, so it adds $r + 1$ to $W_{r-1}(\sigma_{\mathrm{yes}}) + W_{r-1}(\sigma_{\mathrm{no}})$, as it does to $W_r(\sigma)$.
3. An element with value $\tfrac12$ keeps $\tfrac12$ under one answer and gets $0$ under the other, so it adds $1$ to both sides.
4. So $W_{r-1}(\sigma_{\mathrm{yes}}) + W_{r-1}(\sigma_{\mathrm{no}}) = W_r(\sigma)$ for every question.
5. Let the answerer always give the answer with the larger next weight, so the weight at least halves at each step.
6. The answerer commits to no $x$ in advance; any $y$ with a value above $0$ at the end is a legal secret, since its answers contain at most one lie.
7. After $q$ questions the weight is at least $W_q(\text{start}) / 2^q = n (q + 1) / 2^q$.
8. With $r = 0$ the weight counts the elements with a value above $0$, so if $n (q + 1) > 2^q$, at least two remain, and the questioner cannot name $x$.
9. So every winning strategy has $2^q \ge 2^m (q + 1)$.

For $m = 2$ the bound gives $q \ge 5$.
Check: $q = 4$ fails, since $2^4 = 16 < 4 \cdot 5 = 20$, and $q = 5$ passes, since $32 \ge 4 \cdot 6 = 24$.

### Five questions for four elements

Let $U = \{1, 2, 3, 4\}$, with the code words $00000$, $11100$, $00111$ and $11011$.
Question $i$ asks whether bit $i$ of the code word of $x$ is $1$.
So $Q_1 = Q_2 = \{2, 4\}$, $Q_3 = \{2, 3\}$ and $Q_4 = Q_5 = \{3, 4\}$, all fixed in advance.
The [[Hamming distances|EP5HNGSXFA]] of the pairs $12, 13, 14, 23, 24, 34$ are $3, 3, 4, 4, 3, 3$, so any two code words differ in at least $3$ places.
The answers form the code word of $x$ with at most one bit changed.
That word differs from the code word of $x$ in at most $1$ place, and from every other code word in at least $3 - 1 = 2$ places.
So in the final state only $x$ has a value above $0$.

### A run

The secret is $x = 3$, and the answer to $Q_2$ is a lie, so the answers are no, yes, yes, yes, yes.
The states $(\sigma(1), \sigma(2), \sigma(3), \sigma(4))$ after each answer are $(1, \tfrac12, 1, \tfrac12)$, $(\tfrac12, \tfrac12, \tfrac12, \tfrac12)$, $(0, \tfrac12, \tfrac12, 0)$, $(0, 0, \tfrac12, 0)$ and $(0, 0, \tfrac12, 0)$.
Only element $3$ remains, with the value $\tfrac12$ that records the one lie.

## Remarks

With up to $e$ lies, the same bookkeeping uses the values $0, \tfrac{1}{e+1}, \dots, 1$, and an inconsistent answer gives the factor $\tfrac{e}{e+1}$ under $\odot$, which lowers a value by $\tfrac{1}{e+1}$.
These values form a finite subalgebra of [[infinite-valued Łukasiewicz logic|JQ713VVD0G]].

The bound changes with $m$.
For $m = 1$ it gives $q \ge 3$, and three equal questions with a majority vote reach it.
For $m = 3$ it gives $q \ge 6$, since $8 \cdot 6 = 48 > 32$ and $8 \cdot 7 = 56 \le 64$.
For $m = 20$, about one million elements, it gives $q \ge 25$, since $2^{24} = 16 \cdot 2^{20}$ is below $25 \cdot 2^{20}$.
The bound is only a lower bound, and this example does not show that it is reached for every $m$.

For strategies fixed in advance, the bound is the [[Hamming bound|RZEGDKR7C7]] for [[codes|TAE6K8NQ46]] that correct one error.
Adaptive questions may use earlier answers, but by step 9 they cannot beat the same count.

Rényi described the game in 1961, and Ulam posed it again in his 1976 autobiography, with one million objects and one lie.

## Explanations

### L1 human

With four numbers and four questions, count the cases.
There are $4$ numbers and $5$ cases for the lie: no lie, or a lie in one of the $4$ answers.
That makes $20$ cases, but $4$ answers give only $16$ patterns, so two cases look the same.
With five questions there are $4 \cdot 6 = 24$ cases and $32$ patterns, and the questions above tell the four numbers apart in every case.
The game is a model of error-correcting codes, where a lie is a bit that noise changed.

### L2 human

Write the state as a list of values in $\{0, \tfrac12, 1\}$, one for each candidate.
After each answer, lower each inconsistent candidate by $\tfrac12$, and stop at $0$.
With $r$ questions left, the two possible answers split the weight $W_r$ into two parts with the sum $W_r$, and a good question splits it as evenly as possible.
For eight elements and six questions, the start weight is $8 \cdot 7 = 56 \le 64 = 2^6$, so the bound allows six questions.
Watch out: the weight bound is necessary, but it does not prove that a strategy exists.
Each case needs a strategy, as with the five questions above.
