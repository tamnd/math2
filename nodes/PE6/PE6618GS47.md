## Example

Let $T$ be the theory of [[fields|04C5ZBG1WT]] in $L = \set{+, -, \cdot, 0, 1}$, so that the conditions of infinite forcing are the [[integral domains|0QVD7WBFGN]].
Let $\varphi$ be the sentence $\exists x \, (x \cdot x = 1 + 1)$.
We show that the field of [[rational numbers|0NCJ5WXN6Z]] is not infinitely generic.

1. Truth. There is no rational number $x$ with $x^2 = 2$, so $\Q \models \neg \varphi$.
2. An extension. The [[field extension|0EQWVHF3W5]] $F = \Q(\sqrt 2)$ is an integral domain that contains $\Q$.
3. Forcing in $F$. The atomic sentence $\sqrt 2 \cdot \sqrt 2 = 1 + 1$ is true in $F$, so $F \Vdash \sqrt 2 \cdot \sqrt 2 = 1 + 1$, and $F \Vdash \varphi$ by the existential clause.
4. Forcing in $\Q$. By the negation clause, $\Q \Vdash \neg \varphi$ would require that no integral domain containing $\Q$ forces $\varphi$. Step 3 gives one, so $\Q \not\Vdash \neg \varphi$.

So $\Q \models \neg \varphi$ but $\Q \not\Vdash \neg \varphi$, and $\Q$ is not infinitely generic.

## Remarks

The example shows the general reason: a generic model must already satisfy every existential sentence that some extension forces, so it is existentially closed.
This is the forcing form of the fact that [[the rational field is not existentially closed|DP933VYXJV]].

When the field changes, the result changes.
An algebraically closed field contains a square root of $2$, and in fact it is infinitely generic.
The real field $\R$ also contains $\sqrt 2$, but it fails in the same way for $\exists x \, (x \cdot x + 1 = 0)$, which the complex numbers force.

## Explanations

### L1 human

In the rational numbers, $2$ has no square root.
But a larger number system has one, so the rationals cannot claim that "$2$ has no square root" is settled forever.
Forcing only accepts a negative statement when no larger system can make it false.

### L2 human

We compare forcing and truth for $\varphi$ in three fields.

1. In $\Q$: $\varphi$ is false and not forced, and $\neg \varphi$ is true but not forced.
2. In $\Q(\sqrt 2)$: $\varphi$ is true and forced.
3. In $\R$: $\varphi$ is true and forced, but $\exists x \, (x^2 + 1 = 0)$ is false and its negation is not forced.

So neither $\Q$ nor $\R$ is infinitely generic.
The typical use of the example is to see the negation clause at work.
A trap is to think that "not forced" means "forced false": in $\Q$, neither $\varphi$ nor $\neg \varphi$ is forced.
