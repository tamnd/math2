## Example

For a number $a \in \R$, consider the system
$$x + y + z = 1, \qquad x + 2y + 3z = 2, \qquad x + 3y + 5z = a.$$
We decide for which $a$ it is consistent by the [[Rouché-Capelli theorem|0HV1SKWPMS]].

1. The augmented matrix is $\left[\begin{array}{rrr|r} 1 & 1 & 1 & 1 \\ 1 & 2 & 3 & 2 \\ 1 & 3 & 5 & a \end{array}\right]$.
2. $R_2 \leftarrow R_2 - R_1$ gives $(0, 1, 2 \mid 1)$.
3. $R_3 \leftarrow R_3 - R_1$ gives $(0, 2, 4 \mid a - 1)$.
4. $R_3 \leftarrow R_3 - 2R_2$ gives $(0, 0, 0 \mid a - 3)$.
5. The coefficient part has two pivots, so $\rank A = 2$.
6. If $a \neq 3$, the last column has a pivot, so $\rank [A \mid b] = 3$, and there is no solution.
7. If $a = 3$, then $\rank [A \mid b] = 2 = \rank A$, so the system is consistent.
8. For $a = 3$, put $z = t$; row 2 gives $y = 1 - 2t$, and row 1 gives $x = 1 - (1 - 2t) - t = t$.
9. So the solution set is $\set{(0, 1, 0) + t(1, -2, 1) : t \in \R}$, a line of dimension $3 - 2 = 1$.

Check for $a = 3$ and every $t$:

1. $t + (1 - 2t) + t = 1$.
2. $t + 2(1 - 2t) + 3t = 2$.
3. $t + 3(1 - 2t) + 5t = 3$.

## Remarks

The third row of $A$ is $2 \cdot (\text{row } 2) - (\text{row } 1)$, so the system is consistent only if $a = 2 \cdot 2 - 1 = 3$.
Geometrically, the three planes contain a common line for $a = 3$; for other $a$ the third plane is parallel to that line and misses it.

## Explanations

### L1 human

The third equation is a combination of the first two on the left side.
So its right side must be the same combination of the first two right sides.
This happens only for $a = 3$.

### L2 human

1. Row reduce with the letter $a$ in the right side.
2. Find the rows of zeros in the coefficient part.
3. Set their right sides to $0$; this gives the condition on $a$.
4. For the allowed value, solve and check.

The typical use is a system that depends on a parameter, as in physics or geometry problems.
A trap: dividing by an expression in $a$ during the reduction, which is wrong for the value of $a$ that makes it $0$.
