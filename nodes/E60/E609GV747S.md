## Definition

Let $T$ be an imaging system that maps object intensities $f \in L^1(\R^2)$ to image intensities $Tf$ on $\R^2$.
Assume that $T$ is linear and shift invariant: if $g(x) = f(x - a)$ for some $a \in \R^2$, then $(Tg)(x) = (Tf)(x - a)$.
A *point spread function* of $T$ is a function $h \in L^1(\R^2)$ such that
$$Tf = h * f \quad \text{for all } f \in L^1(\R^2),$$
where $*$ is the [[convolution|2Z29JN3VES]] on $\R^2$.

## Remarks

Formally, $h = T\delta$ is the image of a point source, the [[Dirac delta|0KPHENZ5S7]] at the origin.
For incoherent light $h \ge 0$, and one often normalises $h$ so that $\int h = 1$.
In coherent imaging the same definition is applied to complex amplitudes instead of intensities.
The result is the amplitude point spread function, and the incoherent one is its squared modulus.

Example: an aberration-free system with a circular pupil has, in suitable scaled coordinates,
$$h(x) = \left( \frac{2 J_1(\abs{x})}{\abs{x}} \right)^2,$$
where $J_1$ is the [[Bessel function of the first kind|CZCMRDWDYW]] of order $1$.
This is the Airy pattern; it is nonnegative and integrable, since it decays like $\abs{x}^{-3}$.

Non-example: a system whose blur grows from the centre of the field to the edge is not shift invariant, so no single function $h$ describes it.
