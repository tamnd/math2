## Example

We apply [[Herbrand analysis|MESZ87G9ET]] to the theorem of $\mathrm{I}\Sigma_1$
$$\forall x \, \exists y \, (x = 2y \lor x = 2y + 1),$$
"each natural number is even or odd".
Let $A(x)$ be the formula $\exists y \, (x = 2y \lor x = 2y + 1)$.
Its matrix is quantifier-free, so $A$ is $\Sigma_1$.

The proof in $\mathrm{I}\Sigma_1$ is an [[induction|0ASJVEFA9J]] on $A$, and as a sequent derivation it has three parts.

- The base: a derivation of $\Rightarrow A(0)$.
- The step: a derivation of $A(a) \Rightarrow A(a + 1)$, followed by the $\Sigma_1$-induction rule, which gives $A(0) \Rightarrow A(x)$.
- A cut on $A(0)$, which combines $\Rightarrow A(0)$ and $A(0) \Rightarrow A(x)$ into $\Rightarrow A(x)$.

The only cut formula is $A(0)$ and the only induction formula is $A$, and both are $\Sigma_1$.
So every formula in the derivation is $\Sigma_1$, and the witnessing step applies directly.

1. Base. The witness for $A(0)$ is $y = 0$, because $0 = 2 \cdot 0$.
2. Step, first case. Let $y$ be a witness for $A(a)$ with $a = 2y$. Then $a + 1 = 2y + 1$, so $y$ is a witness for $A(a + 1)$.
3. Step, second case. Let $y$ be a witness for $A(a)$ with $a = 2y + 1$. Then $a + 1 = 2y + 2 = 2(y + 1)$, so $y + 1$ is a witness for $A(a + 1)$.
4. The [[proof by cases|0WCP0PVET6]] in steps 2 and 3 becomes a definition by cases: $g(a, y) = y$ if $a = 2y$, and $g(a, y) = y + 1$ otherwise. The test $a = 2y$ is quantifier-free, so $g$ is primitive recursive. If $a \neq 2y$ and $y$ is a witness for $A(a)$, then $a = 2y + 1$, so the second branch is correct.
5. The induction rule becomes a definition by [[primitive recursion|0DSHAVH45F]]: $h(0) = 0$ and $h(a + 1) = g(a, h(a))$. So $h$ is a [[primitive recursive function|5NVA2JRHPV]].
6. The cut on $A(0)$ becomes a composition: the base witness $0$ is the start value of $h$. So $h(x)$ is a witness for $A(x)$, for each $x$.

We compute the first values of $h$.

1. $h(0) = 0$.
2. $h(1) = g(0, 0) = 0$, since $0 = 2 \cdot 0$.
3. $h(2) = g(1, 0) = 1$, since $1 \neq 2 \cdot 0$.
4. $h(3) = g(2, 1) = 1$, since $2 = 2 \cdot 1$.
5. $h(4) = g(3, 1) = 2$, since $3 \neq 2 \cdot 1$.
6. $h(5) = g(4, 2) = 2$, since $4 = 2 \cdot 2$.

So $h(0), \ldots, h(5)$ are $0, 0, 1, 1, 2, 2$, and $h(x) = \lfloor x/2 \rfloor$ for these values.
For each $x$, the property "$x = 2h(x)$ or $x = 2h(x) + 1$" holds, by induction on $x$ with steps 1 to 4 above.
A number $y$ with $x = 2y$ or $x = 2y + 1$ is unique and equals $\lfloor x/2 \rfloor$, so $h(x) = \lfloor x/2 \rfloor$ for all $x$.

## Remarks

The example shows the three translations of the method in one small proof: induction becomes recursion, cases become a definition by cases, and the cut becomes a composition.
The extracted program is the loop "start with $0$, and add $1$ after each odd number", which is the proof read as an algorithm.
PRA proves $x = 2h(x) \lor x = 2h(x) + 1$, a quantifier-free statement, so the $\Pi^0_2$ theorem of $\mathrm{I}\Sigma_1$ becomes a theorem of PRA, as in [[Parsons's theorem|2VYJXZZDGB]].

If we replace $2$ by $3$, the theorem $\forall x \, \exists y \, (x = 3y \lor x = 3y + 1 \lor x = 3y + 2)$ has a proof with three cases in the step.
The extracted function is $h_3(0) = 0$ and $h_3(a + 1) = h_3(a) + 1$ if $a = 3h_3(a) + 2$, and $h_3(a + 1) = h_3(a)$ otherwise, so $h_3(x) = \lfloor x/3 \rfloor$.

## Explanations

### L1 human

We know that each whole number is even or odd.
The usual proof goes up from $0$: $0$ is even, and if a number is even, the next one is odd, and if it is odd, the next one is even.
Herbrand analysis reads this proof as a recipe for half of a number, rounded down.
Start at $0$ with the answer $0$.
Each time we pass an odd number, the answer goes up by $1$.
For $x = 5$ we pass the odd numbers $1$ and $3$, so the answer is $2$, and indeed $5 = 2 \cdot 2 + 1$.

### L2 human

We run the extracted function $h$ on $x = 7$ and check the result.

1. From the table, $h(5) = 2$.
2. $h(6) = g(5, 2)$. Since $5 \neq 2 \cdot 2$, the second branch gives $h(6) = 3$.
3. $h(7) = g(6, 3)$. Since $6 = 2 \cdot 3$, the first branch gives $h(7) = 3$.
4. Check: $7 = 2 \cdot 3 + 1$, so $y = 3$ is a witness for $A(7)$.

The typical use is to read a program off a proof by induction without a search.
A trap is to forget the case test in $g$: the step of the proof needs to know which disjunct holds, and in a $\Sigma_1$ proof this test is quantifier-free and decidable.
