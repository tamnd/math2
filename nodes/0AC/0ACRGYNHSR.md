## Summary

The Dirac measure at a point $x$ gives a set the value $1$ if the set contains $x$, and the value $0$ if not.
It is the probability measure of a random quantity that always takes the value $x$. The node [[Dirac measure|099SXAG014]] gives the precise definition.
