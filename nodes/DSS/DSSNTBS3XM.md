## Example

Let $T$ be the full binary tree of finite $0$-$1$ sequences, and let $V(p)$ be the set of all nodes except the root.
We use the Beth clauses of [[Beth semantics|GPC8Y4ZCSA]] with this $V$.

1. $V(p)$ is an up-set: an extension of a nonempty sequence is nonempty.
2. $V(p)$ is not barred: $\set{0, 1}$ is a bar for the root and lies inside $V(p)$, but the root is not in $V(p)$.
3. The root forces $p \vee p$: the bar $\set{0, 1}$ consists of nodes that force $p$.
4. The root does not force $p$, since it is not in $V(p)$.
5. So the root does not force $p \vee p \to p$, which is a theorem of $\mathsf{IPC}$. Soundness fails for this structure.

## Remarks

The example shows why valuations are required to be barred: without it, a disjunction can be stronger than its disjuncts.
If we add the root to $V(p)$, the valuation becomes barred, and $p$ holds everywhere.
Every up-set $U$ has a smallest barred up-set above it: the set of nodes with a bar inside $U$.
Replacing $V(p)$ by this set gives a Beth model.

## Explanations

### L1 human

Suppose that on every branch of the future, $p$ becomes known after one step.
Then $p$ is in fact known now, since nothing can prevent it.
A valuation that says "$p$ is not known now" in this case is not a sensible state of knowledge.
Beth models rule it out.

### L2 human

1. Take $U = V(p)$, the set of nonempty sequences.
2. The set of nodes with a bar inside $U$ is the set of all nodes, since $\set{\sigma 0, \sigma 1}$ is a bar for each $\sigma$.
3. So the barred up-set generated by $U$ is the whole tree.

The typical use of this example is to check the conditions in a definition.
A trap: being an up-set is not enough in Beth semantics; Kripke models only need up-sets because their disjunction clause is local.
