## Definition

Let $N$ be a finite index set, possibly very large, and for each $j \in N$ let $a_j \in \R^m$ be a column and $c_j \in \R$ a cost.
Let $b \in \R^m$.
The *master problem* is the [[linear program|VNMXB0J2KA]]
$$\text{minimize } \sum_{j \in N} c_j x_j \quad \text{subject to} \quad \sum_{j \in N} a_j x_j = b, \quad x_j \ge 0 \ (j \in N).$$
For a subset $J \subseteq N$, the *restricted master problem* is the same program with $x_j = 0$ for all $j \notin J$.
For $y \in \R^m$, the *reduced cost* of column $j$ is $c_j - y^T a_j$.
*Column generation* is the following iteration, which starts with a set $J$ for which the restricted master problem is feasible.

1. Solve the restricted master problem on $J$, and obtain an optimal solution $x$ and an optimal solution $y$ of its [[dual|14VMJNXMDC]].
2. Solve the *pricing problem*: find $j \in N$ with the least reduced cost $c_j - y^T a_j$.
3. If this least reduced cost is negative, add $j$ to $J$ and go to step 1.
4. Otherwise stop: $x$, extended by zeros, is an optimal solution of the master problem.

## Remarks

The stopping rule is correct: if every reduced cost is nonnegative, then $y$ satisfies $y^T a_j \le c_j$ for all $j \in N$, so $y$ is feasible for the dual of the full master problem.
Its dual value $b^T y$ equals the value of $x$, so both are optimal by weak duality.

Example: in the [[cutting stock problem|1HX9ZFG783]], let $w_i$ be the piece widths and $W$ the roll width.
Each column is a cutting pattern, that is, a vector $a \in \Z_{\ge 0}^m$ of piece counts with $\sum_i w_i a_i \le W$.
All costs are $1$, so the pricing problem is to maximize $y^T a$ over the patterns, a [[knapsack problem|6G8WNXTJAN]].

Non-example: a program with a small fixed number of variables gives nothing to generate, and one solves it directly.
In practice the pricing problem is never solved by listing all of $N$; the method is useful exactly when it can be solved by a separate algorithm.
