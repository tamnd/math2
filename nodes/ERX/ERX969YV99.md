## Definition

Let $(A, \to)$ be an abstract [[rewriting system|Y83TQF6V6A]], and let $\to^*$ be the reflexive and [[transitive closure|05J9NWX07X]] of $\to$.
Two elements $b, c \in A$ are *joinable* if $b \to^* d$ and $c \to^* d$ for some $d \in A$.
The system is:

1. *confluent* if for all $a, b, c \in A$ with $a \to^* b$ and $a \to^* c$, the elements $b$ and $c$ are joinable;
2. *locally confluent* if for all $a, b, c \in A$ with $a \to b$ and $a \to c$, the elements $b$ and $c$ are joinable;
3. *convergent* if it is confluent and terminating.

## Remarks

Example: $A = \N$ with $n \to n - 1$ for $n \ge 1$; any two elements reachable from $a$ both reduce to $0$, so the system is confluent.
Non-example: $A = \set{a, b, c}$ with $a \to b$ and $a \to c$; here $b$ and $c$ are distinct normal forms, so they are not joinable and the system is not even locally confluent.
Every confluent system is locally confluent, but not conversely: with $b \to a$, $b \to c$, $c \to b$, $c \to d$, the system is locally confluent, yet $b \to^* a$ and $b \to^* d$ with $a$ and $d$ distinct normal forms.
Confluence is equivalent to the *Church–Rosser property*: $a \leftrightarrow^* b$ implies that $a$ and $b$ are joinable.
In a confluent system each element has at most one normal form.
