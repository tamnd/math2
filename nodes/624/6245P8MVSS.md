## Statement

Let $I$ be an interval. Let $P$ be a matrix-valued function on $I$ and let $f$ be a vector-valued function on $I$, so that $x' = P x + f$ is a [[system of linear differential equations|0A6QZ367GX]] for a vector-valued unknown $x$.
Let $x_p$ be one solution of this system on $I$.
Then a function $x$ on $I$ is a solution of the system if and only if $x = x_c + x_p$, where $x_c$ is a solution of the associated homogeneous system $x' = P x$ on $I$.

## Remarks

The associated homogeneous system is the one with the same matrix $P$ and with right side $0$.
If $x$ solves the full system, then $x - x_p$ solves the homogeneous system, because the difference removes $f$. Conversely, adding $x_p$ to a homogeneous solution gives a solution of the full system.
