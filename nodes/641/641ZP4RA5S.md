## Example

Solve $\sqrt{x + 2} = x$ over $\mathbb{R}$, where $\sqrt{\ }$ is the non-negative [[square root|0F7FQS6XY6]].
A student hands in this solution; one line is wrong, so find it before reading on.

1. $\sqrt{x + 2} = x$.
2. Square both sides: $x + 2 = x^2$.
3. So $x^2 - x - 2 = 0$, that is, $(x - 2)(x + 1) = 0$.
4. So $x = 2$ or $x = -1$, and the solutions are $2$ and $-1$.

Substitute to test: $\sqrt{4} = 2$, so $2$ works, but $\sqrt{1} = 1 \neq -1$, so $-1$ does not.
The wrong line is the final claim, and the cause is step 2.
Squaring is an implication: if $\sqrt{x + 2} = x$, then $x + 2 = x^2$.
It is not an equivalence, because [[squaring is not injective|Q07B3Q8Q5A]], and $x + 2 = x^2$ also holds when $\sqrt{x + 2} = -x$.
So step 4 lists the solutions of the squared equation, and $-1$ is an extraneous solution that the squaring added.
Claiming it is a [[mathematical fallacy|S2BW0FDHV8]]: an implication is used as if it were an equivalence.

The correct version makes step 2 a [[biconditional|0S6GMNJ62Y]] by recording what squaring forgets:
$$\sqrt{x + 2} = x \iff x \ge 0 \text{ and } x + 2 = x^2.$$
Steps 3 and 4 are equivalences, so the solutions are the roots $2$ and $-1$ with $x \ge 0$, and the only solution is $x = 2$.

## Remarks

### Implication and equivalence in a chain

A chain $E_1 \Rightarrow E_2 \Rightarrow \cdots \Rightarrow E_n$ proves that every solution of $E_1$ solves $E_n$.
So the solutions of $E_n$ are only candidates, and each one must be checked in $E_1$.
A chain of equivalences $E_1 \Leftrightarrow \cdots \Leftrightarrow E_n$ proves that $E_1$ and $E_n$ have the same solutions, and needs no check.
Reading "$\Rightarrow$" as "$\Leftrightarrow$" accepts the converse of an implication, the same logical slip as [[affirming the consequent|J7KFCFQRBT]].

### A second trap with logarithms

Solve $\ln x + \ln(x - 3) = \ln 4$ with the [[natural logarithm|04DXAFN2ES]].
The rule $\ln a + \ln b = \ln(ab)$ turns it into $\ln\big(x(x - 3)\big) = \ln 4$, so $x(x - 3) = 4$, so $(x - 4)(x + 1) = 0$.
The candidate $x = 4$ works, since $\ln 4 + \ln 1 = \ln 4$.
The candidate $x = -1$ does not, since $\ln(-1)$ is not defined over $\mathbb{R}$.
The logarithm rule needs $a > 0$ and $b > 0$, while $x(x - 3) > 0$ also holds for $x < 0$, so the rule widened the domain.
The equivalent form is: the equation holds exactly when $x > 3$ and $x(x - 3) = 4$, which gives $x = 4$ alone.

### Steps that cannot be reversed

1. Squaring both sides, or raising them to any even power; [[squaring both sides|FGS7ZJJYRK]] shows the same step "proving" a false identity.
2. Multiplying both sides by an expression that can be $0$: $x = 1$ has one solution, while $x(x - 2) = x - 2$ also has $x = 2$.
3. Using a rule for logarithms or roots that holds only on a smaller domain.
4. Replacing an equation by a consequence, such as "$a = b$, so $a^2 = b^2$".

Dividing by an expression that can be $0$ is the mirror error: it can lose solutions, as [[division by zero fallacies|V7601AG5G3]] shows.

### Two ways to repair

The first way keeps the chain of implications and checks each candidate in the original equation.
That check is a step of the proof, not a test of the arithmetic.
Without it, the argument proves only "if $x$ is a solution, then $x \in \{2, -1\}$", which does not even say that $2$ is a solution.
The second way makes each step an equivalence by adding its condition at the step where it enters, as in the corrected solution above.

### Try it

Solve $\sqrt{x} = -2$ by squaring.
Squaring gives $x = 4$, but $\sqrt{4} = 2 \neq -2$, so the equation has no solution at all.

Is "$x^2 = 4x$, so $x = 4$" an implication, an equivalence, or neither?
Neither: it divides by $x$, which loses the solution $x = 0$.

## Explanations

### L1 human

Squaring both sides of an equation can create new answers that do not work.
The equation $x = 3$ has one answer.
After squaring, $x^2 = 9$ has two answers, $3$ and $-3$.
The new answer $-3$ came from the squaring, not from the first equation.
So after squaring we put each answer back into the first equation and keep only the ones that work.

### L2 human

We solve $\sqrt{2x + 3} = x - 2$ in both ways.
Squaring gives $2x + 3 = x^2 - 4x + 4$, so $x^2 - 6x + 1 = 0$ and $x = 3 \pm 2\sqrt{2}$.
For $x = 3 + 2\sqrt{2}$, the right side $1 + 2\sqrt{2}$ is positive and $2x + 3 = 9 + 4\sqrt{2} = (1 + 2\sqrt{2})^2$, so this candidate is a solution.
For $x = 3 - 2\sqrt{2} \approx 0.17$, the right side is about $-1.83$, and a square root is never negative, so this candidate fails.
In the second way, the equation holds exactly when $x \ge 2$ and $2x + 3 = (x - 2)^2$, and the condition $x \ge 2$ keeps only $3 + 2\sqrt{2}$.

The typical use of the second way is to write each condition when it enters, so that no check is needed at the end.
Watch out for checking candidates with rounded decimals, which can accept a false candidate or reject a true one when the two sides are close.
