## Summary

The basic reproduction number $R_0$ is the expected number of new infections caused by one typical infectious host in a fully susceptible population.
It is the main threshold quantity of epidemiology: an outbreak can grow when $R_0 > 1$ and dies out when $R_0 < 1$.
It also fixes the [[herd immunity threshold|XS908PP9W5]] $1 - 1/R_0$ and the final size of an epidemic in simple models.

## Explanations

### L1 human

Drop one sick person into a town where nobody is immune, and count how many people catch the disease directly from that person.
The average of this count is $R_0$.
If $R_0 = 2$, one case leads to about $2$, then $4$, then $8$ cases, so the outbreak grows.
If $R_0 = 0.5$, each generation of cases is half the size of the previous one, so the chain of infections fades out.
