## Summary

In mathematics, **symmetrization** is a process that converts any [[function|0EPAT51DXQ]] in $n$ variables to a symmetric function in $n$ variables. Similarly, **antisymmetrization** converts any function in $n$ variables into an [[antisymmetric|01MGYYBB9R]] function.
