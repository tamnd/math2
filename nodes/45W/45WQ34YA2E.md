## Example

Let $\Sigma^{*}$ be the set of strings over the alphabet $\{a, b\}$, with concatenation as $\bullet$, the empty string $\varepsilon$ as $e$, and equality as the order.
This is a monoid, but it is not commutative, so it is not a resource model in the sense of [[the definition|F0R5WTBN8Y]].
If we use the clauses of the definition anyway, the law $p \ast q \vdash q \ast p$ fails.

1. $ab \neq ba$, so concatenation is not commutative.
2. Let $V(p) = \{a\}$ and $V(q) = \{b\}$.
3. $ab \models p \ast q$, with $s = a$ and $t = b$, since $a \bullet b = ab$.
4. $ab \models q \ast p$ would need $s = b$ and $t = a$ with $ba = ab$, which is false.
5. So $ab \models p \ast q$ but $ab \not\models q \ast p$.

## Remarks

In every resource model, $p \ast q$ entails $q \ast p$: if $s \models p$, $t \models q$ and $s \bullet t \sqsubseteq r$, then $t \bullet s = s \bullet t \sqsubseteq r$.
So the commutativity of the monoid is the semantic form of [[exchange|YAFD18WYJ8]] for $\ast$.
The Wikipedia article on residuated lattices states that the formal languages over an alphabet form a residuated lattice under concatenation; that lattice is not commutative.

## Explanations

### L1 human

When we write words, the order of the letters matters: "ab" is not "ba".
So a model built from words cannot treat $p \ast q$ and $q \ast p$ as the same.

### L2 human

We check that $\varepsilon$ is a unit and look at $I$.

1. $\varepsilon w = w \varepsilon = w$ for every string $w$.
2. With the clause for $I$, $w \models I$ if and only if $w = \varepsilon$.
3. Then $a \models p \ast I$, with $s = a$ and $t = \varepsilon$.

The typical use of this structure is to model a logic without exchange.
A trap: a split of a string into two parts fixes which part comes first, so steps 3 and 4 are different splits.
