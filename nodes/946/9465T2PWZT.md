## Summary

Dynamic epistemic logic adds to [[epistemic logic|EA34W4ERRE]] modalities for events that change what agents know.
The simplest event is a public announcement: $[!\varphi]\psi$ says "after the truthful public announcement of $\varphi$, $\psi$ holds".
Semantically the announcement deletes every world where $\varphi$ is false and keeps the agents' relations on the rest.
The resulting public announcement logic has reduction axioms that rewrite each formula into one without announcements, by [[the reduction theorem|MFGHDHGV1D]].
Action models, due to Baltag, Moss and Solecki, describe events that different agents perceive differently, and they update a model by a product construction.
Dynamic epistemic logic matters because it turns informal stories of communication, such as puzzles, protocols and games, into model transformations with a complete logic.

## Motivation

Epistemic logic describes a snapshot of what agents know.
Puzzles like the [[muddy children|BG9TYCJ7HP]] turn on how knowledge changes: each answer, even "no", tells the others something.
One wants to reason inside the logic about the effect of such events, as [[propositional dynamic logic|VJ78A0Q22R]] reasons about the effect of programs.
The worlds give a direct model of information: learning $\varphi$ means ruling out the worlds where $\varphi$ is false.
Private and partly observed events need more structure, which action models supply.

## Notation

1. $[!\varphi]\psi$: after announcing $\varphi$, $\psi$. The dual $\langle !\varphi \rangle\psi = \neg[!\varphi]\neg\psi$ says that $\varphi$ is true and $\psi$ holds after its announcement.
2. $M|\varphi$: the model $M$ restricted to the worlds where $\varphi$ is true.
3. An action model is $\mathsf{E} = (E, (\to_a)_a, \mathrm{pre})$, with events $E$, relations $\to_a$, and a precondition formula $\mathrm{pre}(e)$ for each event.
4. $M \otimes \mathsf{E}$: the product update. $[\mathsf{E}, e]\psi$: after event $e$ of $\mathsf{E}$, $\psi$.
5. $\mathsf{PAL}$: public announcement logic. $\mathsf{PAC}$: with common knowledge added.

## Remarks

### Examples

1. In a two-agent model, announcing $p$ makes $p$ common knowledge, see [[the announcement example|YDAHGYKQZN]].
2. Announcing the Moore sentence $p \wedge \neg K_a p$ makes it false, see [[the unsuccessful update|Z13C7EBPXB]].
3. A message read by one agent while the other only knows it was sent is an action model update, see [[the private reading example|SYVGPVYNCP]].
4. The reduction axioms rewrite $[!p]K_a q$ into $p \to K_a(p \to q)$, see [[the translation example|JRHH7Z42A4]].
5. Each round of the muddy children puzzle is a public announcement, see [[the muddy children puzzle|BG9TYCJ7HP]].

### Non-examples

1. A private message to agent $a$ is not a public announcement. Deleting worlds would tell every agent the content, see [[the private reading example|SYVGPVYNCP]].
2. Change of facts, such as flipping a coin, is not an announcement: announcements change no valuation. Ontic change needs postconditions in action models.

### Basic properties

1. The semantic clause: $M, w \models [!\varphi]\psi$ iff $M, w \models \varphi$ implies $M|\varphi, w \models \psi$.
2. Reduction axioms, valid by [[the reduction theorem|MFGHDHGV1D]]:
   - $[!\varphi]p \leftrightarrow (\varphi \to p)$;
   - $[!\varphi]\neg\psi \leftrightarrow (\varphi \to \neg[!\varphi]\psi)$;
   - $[!\varphi](\psi \wedge \chi) \leftrightarrow ([!\varphi]\psi \wedge [!\varphi]\chi)$;
   - $[!\varphi]K_a\psi \leftrightarrow (\varphi \to K_a[!\varphi]\psi)$.
3. Every $\mathsf{PAL}$ formula is equivalent to a formula of [[S5|VC3A2VWXND]]$_n$ without announcements. So $\mathsf{PAL}$ is complete and decidable.
4. With [[common knowledge|7BCMKF2P7X]], no reduction axiom for $[!\varphi]C_G\psi$ exists in the language with $C_G$ alone. One adds relativized common knowledge $C_G(\varphi, \psi)$ to restore reduction.
5. Action models also have reduction axioms, and the logic of action models without common knowledge is as expressive as epistemic logic.
6. Multi-agent epistemic planning with action models is undecidable: no algorithm decides whether some sequence of actions reaches a goal formula.

### History

Plaza introduced public announcement logic in "Logics of public communications" (1989), with the reduction axioms.
Gerbrandy and Groeneveld treated announcements in 1997, independently.
Baltag, Moss and Solecki introduced action models in 1998.
Bolander and Andersen proved the undecidability of multi-agent epistemic planning in 2011.
The textbook of van Ditmarsch, van der Hoek and Kooi (2007) collected the field.

### Common errors

1. Expecting an announced formula to stay true. The Moore sentence $p \wedge \neg K_a p$ is false after its own announcement.
2. Forgetting the precondition. $[!\varphi]\psi$ is true at worlds where $\varphi$ is false, since false announcements cannot be made.
3. Writing $[!\varphi]K_a\psi \leftrightarrow K_a[!\varphi]\psi$. The correct axiom is $[!\varphi]K_a\psi \leftrightarrow (\varphi \to K_a[!\varphi]\psi)$; without the antecedent it fails where $\varphi$ is false.

## Explanations

### L1 human

Dynamic epistemic logic is about how knowledge changes when something is said or done.
Think of all the ways the world might be.
When someone announces a fact to everyone, the ways in which it is false drop out.
After that, everyone knows the fact, and everyone knows that everyone knows it.
Secret messages are harder, since one person learns something while the others learn only that something happened.

### L2 human

We announce $p$ in a model with worlds $w$ ($p$ true) and $v$ ($p$ false), which agent $a$ cannot tell apart.

1. Before: $K_a p$ is false at $w$, since $a$ considers $v$ possible.
2. The announcement $!p$ is truthful at $w$, so we form $M|p$, which keeps only $w$.
3. After: $K_a p$ is true at $w$. So $[!p]K_a p$ is true at $w$.
4. At $v$, the announcement $!p$ cannot be made, so $[!p]K_a p$ is true there vacuously.

The typical use is to compute what agents know after a sequence of announcements.
A trap: the updated model is computed once from the whole model, not separately for each agent.

### L3 human

$\mathsf{PAL}$ is a logic of model transformers, closely related to [[PDL|VJ78A0Q22R]], with announcements as programs.
Its reduction axioms show that it has the expressive power of epistemic logic.
Lutz showed in 2006 that $\mathsf{PAL}$ can be exponentially more succinct.
By the same work, satisfiability of $\mathsf{PAL}$ is PSPACE-complete for two or more agents, as for $\mathsf{S5}_n$ in [[the complexity theorem|1P2B0C7CQ4]].
