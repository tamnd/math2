## Example

On $\mathbb{Q}^3$ let $B(x, y) = x^{\mathsf{T}} A y$ with
$$A = \begin{pmatrix} 0 & 1 & 0 \\ -1 & 0 & 1 \\ 0 & -1 & 0 \end{pmatrix},$$
so that $B(x, y) = x_1 y_2 - x_2 y_1 + x_2 y_3 - x_3 y_2$.
We show that $B$ is alternating and degenerate, and we bring its matrix to the normal form of the classification.

1. The matrix satisfies $A^{\mathsf{T}} = -A$ and its diagonal is zero, so $B$ is [[alternating|08ZQAKBKHF]].
2. The radical is the null space of $A$. The equations $Ax = 0$ read
$$x_2 = 0, \qquad -x_1 + x_3 = 0, \qquad -x_2 = 0,$$
so the radical is the line spanned by $w = (1, 0, 1)$.
Check: $Aw = (0,\ -1 + 1,\ 0) = (0, 0, 0)$.
3. The radical is not zero, so by the [[criteria for nondegeneracy|3ND2FNJ38Y]] the form is degenerate, and $\operatorname{rank} A = 3 - 1 = 2$.
4. The value $B(e_1, e_2) = A_{12} = 1$ is not zero, so $(e_1, e_2)$ is a hyperbolic pair: $B(e_1, e_2) = 1$ and $B(e_2, e_1) = -1$.
5. The vector $w$ is orthogonal to both: $B(e_1, w) = A_{11} + A_{13} = 0$ and $B(e_2, w) = A_{21} + A_{23} = -1 + 1 = 0$.
6. Let $P$ have the columns $e_1, e_2, w$. Then $AP$ has the columns $Ae_1 = (0, -1, 0)$, $Ae_2 = (1, 0, -1)$ and $Aw = 0$, and
$$P^{\mathsf{T}} A P = \begin{pmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \\ 1 & 0 & 1 \end{pmatrix} \begin{pmatrix} 0 & 1 & 0 \\ -1 & 0 & 0 \\ 0 & -1 & 0 \end{pmatrix} = \begin{pmatrix} 0 & 1 & 0 \\ -1 & 0 & 0 \\ 0 & 0 & 0 \end{pmatrix}.$$
So in the basis $(e_1, e_2, w)$ the matrix is $J \oplus 0$, with $J = \begin{pmatrix} 0 & 1 \\ -1 & 0 \end{pmatrix}$.

## Remarks

The rank $2$ is even, as the [[classification of alternating forms|V8KKHKXXB3]] says it must be.
That fact alone forces degeneracy here: an alternating form on a space of odd dimension has even rank, so its rank is less than the dimension.
The determinant agrees with the Pfaffian rule: $\det A = 0 = 0^2$ is a square.

What changes if we add a dimension?
On $\mathbb{Q}^4$, the form $x_1 y_2 - x_2 y_1 + x_3 y_4 - x_4 y_3$ has matrix $J \oplus J$, with determinant $1$, so it is nondegenerate.
An alternating $3 \times 3$ matrix can only have rank $0$ or $2$, while a $4 \times 4$ one can have rank $0$, $2$ or $4$.

## Explanations

### L1 human

An alternating form on a space of odd dimension always has an arrow that pairs to zero with every arrow.
Here that arrow is $(1, 0, 1)$, and we find it by solving three short equations.
On the plane of the first two coordinate arrows, the form is the signed area of the plane.

### L2 human

To find the radical of an alternating form $x^{\mathsf{T}} A y$, solve $Ax = 0$.
Since $A^{\mathsf{T}} = -A$, the system $A^{\mathsf{T}} x = 0$ has the same solutions, so the left and the right radical are equal.
Then pick any pair $u, v$ with $B(u, v) \ne 0$, scale $v$ so that $B(u, v) = 1$, and add a basis of the radical, as in steps 4 to 6.
Watch out: a $3 \times 3$ alternating matrix never has rank $1$ or $3$, so a rank computation that gives one of these numbers contains an error.
