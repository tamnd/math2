## Proof

We first treat one new symbol, so $L' = L \cup \{ R \}$ or $L' = L \cup \{ f \}$, and $T' = T \cup \{ \delta \}$ with the defining axiom $\delta$.
We use soundness and [[Gödel's completeness theorem|WQ1ZE255SF]] in this form: $\Gamma \vdash \varphi$ exactly when $\varphi$ is true in every model of $\Gamma$ under every assignment.

*Part 1, unique expansion.*

1. Let $M$ be a [[model|MVCH6N9SNW]] of $T$.
   For a relation symbol, let $R^{M'} = \{ \bar a \in M^n : M \models \psi_R(\bar a) \}$.
   The expansion $M'$ satisfies $\delta$ by the definition of $R^{M'}$.
2. Any expansion that satisfies $\delta$ must contain exactly the tuples $\bar a$ with $M \models \psi_R(\bar a)$, so it equals $M'$.
3. For a function symbol, $M \models \forall \bar x\, \exists ! y\, \psi_f(\bar x, y)$ by soundness, because $T$ proves this sentence.
   So for each $\bar a \in M^n$ there is exactly one $b \in M$ with $M \models \psi_f(\bar a, b)$.
4. Let $f^{M'}(\bar a)$ be this $b$.
   Then $f^{M'}(\bar a) = b'$ holds exactly when $M \models \psi_f(\bar a, b')$, so $M'$ satisfies $\delta$.
5. Any expansion that satisfies $\delta$ maps $\bar a$ to an element $b'$ with $M \models \psi_f(\bar a, b')$, and step 3 gives $b' = b$.
   So the expansion is unique.

*Part 2, conservativity.*

6. If $T \vdash \sigma$, then $T' \vdash \sigma$, because $T \subseteq T'$.
7. Let $\sigma$ be an $L$-sentence with $T' \vdash \sigma$, and let $M$ be a model of $T$.
   By part 1, $M$ has an expansion $M'$ that is a model of $T'$.
8. By soundness $M' \models \sigma$.
   The sentence $\sigma$ has no new symbol, so its truth depends only on the $L$-part, and $M \models \sigma$.
9. So $\sigma$ is true in every model of $T$, and the completeness theorem gives $T \vdash \sigma$.

*Part 3, eliminability.*

10. For a relation symbol, let $\varphi^*$ be the result of replacing each atomic subformula $R(t_1, \ldots, t_n)$ of $\varphi$ by $\psi_R(t_1, \ldots, t_n)$.
    Before the replacement, rename the bound variables of $\psi_R$ so that no variable of the terms $t_i$ is captured.
11. In each model $M'$ of $T'$ and under each assignment, $R(\bar t)$ and $\psi_R(\bar t)$ have the same truth value, by $\delta$.
    By [[structural induction|12MQ2NJ29A]] on $\varphi$, $\varphi$ and $\varphi^*$ have the same truth value.
12. For a function symbol, we use induction on the number $k$ of occurrences of $f$ in $\varphi$.
    If $k = 0$, let $\varphi^* = \varphi$.
13. If $k > 0$, choose an atomic subformula $\alpha$ of $\varphi$ and an occurrence $f(t_1, \ldots, t_n)$ in $\alpha$ such that the terms $t_i$ contain no $f$.
    Such an occurrence exists: take one of minimal length.
14. Let $y$ be a variable that occurs nowhere in $\varphi$ or $\psi_f$, and let $\alpha_y$ be $\alpha$ with this occurrence replaced by $y$.
    Let $\alpha' = \exists y\, (\psi_f(\bar t, y) \land \alpha_y)$, with the bound variables of $\psi_f$ renamed as in step 10.
15. Fix a model $M'$ of $T'$ and an assignment $s$.
    By $\delta$, the only $b$ with $M' \models \psi_f(\bar t, y)[s(y \mapsto b)]$ is the value of $f(\bar t)$.
    So $\alpha'$ is true exactly when $\alpha_y$ is true with $y$ equal to this value, that is, exactly when $\alpha$ is true.
16. Replace $\alpha$ by $\alpha'$ in $\varphi$.
    By structural induction as in step 11, the new formula has the same truth value as $\varphi$ in every model of $T'$ under every assignment.
17. The new formula has $k - 1$ occurrences of $f$, because $\alpha_y$ has one occurrence fewer than $\alpha$ and $\psi_f(\bar t, y)$ has none.
    The induction hypothesis gives an $L$-formula $\varphi^*$ with the same truth value.
18. In both cases $\forall \bar z\, (\varphi \leftrightarrow \varphi^*)$ is true in every model of $T'$, so the completeness theorem gives $T' \vdash \forall \bar z\, (\varphi \leftrightarrow \varphi^*)$.

*Several new symbols.*

19. Let the new symbols be $S_1, S_2, \ldots$ in the order of the statement.
    Let $T_0 = T$, and let $T_j$ add the defining axiom of $S_j$ to $T_{j-1}$.
    Each $T_j$ is an extension of $T_{j-1}$ by one definition.
20. Parts 1, 2 and 3 pass from $T_{j-1}$ to $T_j$ by steps 1 to 18.
    For parts 2 and 3 we compose the translations and use that conservativity is transitive, and for part 1 we compose the unique expansions.
21. Suppose there are infinitely many new symbols, and $T' \vdash \sigma$ for an $L$-sentence $\sigma$.
    The derivation uses only finitely many defining axioms, and all of them lie in some $T_j$.
    So $T_j \vdash \sigma$, and finitely many steps give $T \vdash \sigma$.
22. Part 3 holds in the infinite case because each formula has finitely many new symbols, so it is a formula of the language of some $T_j$.
23. Part 1 holds in the infinite case because steps 1 to 5 fix the reading of each $S_j$ in terms of the earlier ones.
    So the expansions fit together into one expansion.

This proves unique expansion, conservativity and eliminability.

## Idea

A definition leaves no freedom: in each model of $T$ the new symbol must be read as the set or function that its definiens describes.
So every model of $T$ is the $L$-part of a model of $T'$, and an $L$-sentence true in all models of $T'$ is true in all models of $T$.
For eliminability, we remove a term $f(\bar t)$ with a new bound variable, one occurrence at a time.

## Variants

The syntactic proof, as in Shoenfield's book, translates each derivation from $T'$ into a derivation from $T$, and it does not use the completeness theorem.
It gives a computable translation of proofs, so the result holds in weak metatheories.
