## Summary

Take the sentence $\exists x \, \exists y \, \neg (x = y)$.
It says "there are at least two elements", and it can say that only because the symbol $=$ has the same meaning in every structure.
First-order logic with equality makes this official: $=$ is a logical symbol, like $\neg$ and $\forall$, and not a symbol of the signature.

Exactly, in first-order logic with equality the binary symbol $=$ belongs to every language, so $t_1 = t_2$ is an [[atomic formula|MCZRXR3SVB]] for any two terms $t_1$ and $t_2$.
In every [[structure|983GZBQYT4]] $\mathcal{M}$ and under every assignment $s$, the formula $t_1 = t_2$ is true exactly when $t_1$ and $t_2$ have the same value in the domain.
A deductive calculus for this logic adds the equality axioms: reflexivity, $\forall x \, (x = x)$, and one substitution axiom for each function symbol and each relation symbol, including $=$ itself.

## Motivation

Mathematics is full of equations: $x \cdot e = x$, $f(x) = 0$, "there is exactly one solution".
Each of these needs a symbol for [[equality|E918704SKV]] whose meaning nobody can change.
You could add $=$ as one more relation symbol with some axioms.
But then a structure may read the symbol as any relation that obeys the axioms, for example "has the same parity", and the symbol no longer means "is the same element".

Making $=$ logical fixes its meaning once and for all.
The equality axioms then let a proof system reason with $=$, and the [[completeness theorem|WQ1ZE255SF]] still holds for this logic.
Almost every theory in the area uses equality: groups, rings, orders with "exactly one", and the counting sentences of model theory.

## Notation

Most books write $t_1 = t_2$, and some write $t_1 \approx t_2$ to keep the symbol of the object language apart from equality in the metalanguage.
The formula $\neg (t_1 = t_2)$ is written $t_1 \neq t_2$.
Logic with equality is also called logic with identity, and logic without equality is sometimes called pure first-order logic.
Mendelson calls a structure *normal* when it reads the equality symbol as identity.
In Mathlib, equality is built into `FirstOrder.Language.BoundedFormula` by the constructor `equal`, so it is not a relation symbol of the language `L`.

## Remarks

### The equality axioms

For a signature $\sigma$, the equality axioms are reflexivity and the substitution axioms.
For a function symbol $f$ of arity $n$, the substitution axiom is
$$\forall \bar{x} \, \forall \bar{y} \, \big( (x_1 = y_1 \land \dots \land x_n = y_n) \to f(x_1, \dots, x_n) = f(y_1, \dots, y_n) \big).$$
For a relation symbol $R$ of arity $n$, it is
$$\forall \bar{x} \, \forall \bar{y} \, \big( (x_1 = y_1 \land \dots \land x_n = y_n) \to (R(x_1, \dots, x_n) \to R(y_1, \dots, y_n)) \big).$$
A constant symbol has arity $0$, so its axiom is $c = c$, which reflexivity already gives.
For the signature of groups the full list has four sentences, worked out in [[the equality axioms for groups|79ND6CD7ND]].

Each axiom is true in every structure, because equal elements are the same element.
The axioms are needed anyway, because a proof system sees $=$ only as a string of symbols.

### Symmetry and transitivity come free

You do not need separate axioms for symmetry and transitivity.
Take the substitution axiom for $=$ itself, with $n = 2$:
$$(x_1 = y_1 \land x_2 = y_2) \to (x_1 = x_2 \to y_1 = y_2).$$
Put $x_1 := x$, $y_1 := y$, $x_2 := x$ and $y_2 := x$.
The result is $(x = y \land x = x) \to (x = x \to y = x)$, and reflexivity gives both copies of $x = x$, so $x = y \to y = x$.
For transitivity put $x_1 := x$, $y_1 := x$, $x_2 := y$ and $y_2 := z$.
The result is $(x = x \land y = z) \to (x = y \to x = z)$, which gives $x = y \land y = z \to x = z$.

### Counting with equality

Equality lets a single sentence fix the size of a structure.
The sentence $\exists x \, \exists y \, (x \neq y)$ says "at least two elements", and $\forall x \, \forall y \, (x = y)$ says "at most one".
"There is exactly one $x$ with $\varphi$" becomes
$$\exists x \, \big( \varphi \land \forall y \, (\varphi[y/x] \to y = x) \big),$$
with $y$ a new variable.
[[Counting sentences|GVBGZT47CY]] works these out and checks them in small groups.
In the same way the field axioms need $=$, for example $0 \neq 1$ and $\forall x \, (x \neq 0 \to \exists y \, (x \cdot y = 1))$.
A [[theory with identity|9T8WK38ZK8]] is any theory that contains $=$ with these axioms.

### What the axioms cannot do

The equality axioms do not force the symbol to mean identity.
Read $=$ on the integers as "has the same parity".
Then [[congruence modulo 2 satisfies every equality axiom|CGV3Z8SN55]] in the signature of rings, but $0$ and $2$ are "equal" without being the same number.
In general, a relation $E$ that satisfies the equality axioms is a [[congruence|DCSXXT4SER]] of the structure.
The [[quotient|0011MTQMR6]] by $E$ reads the symbol as true identity and satisfies the same sentences.
So the axioms fix $=$ up to congruence, and the quotient closes the gap; that is how completeness for logic with equality follows from completeness without it.

### Life without equality

If $=$ is not in the logic, some things become impossible to say.
[[Without equality no sentence says that there are two elements|92DFZ28TR7]]: copy every element of a structure twice, and no sentence without $=$ can tell the copy from the original.
In particular $\exists x \, \exists y \, (x \neq y)$ has no equivalent without $=$, so equality is not definable from the other symbols in general.

### Watch out

The first trap is to treat $=$ as one more relation symbol of the signature.
In logic with equality its meaning is fixed in every structure, so "a structure that reads $=$ as parity" is simply not a structure of this logic.
The second trap is to think that reflexivity and substitution for the function and relation symbols are enough.
Leave out the substitution axiom for $=$ itself, and take the empty signature.
Then "$\le$ on $\{ 0, 1 \}$" satisfies reflexivity, but $0 \le 1$ holds and $1 \le 0$ fails, so symmetry is not provable.

### History

Leibniz stated that two things are identical when each can replace the other without change of truth.
Whitehead and Russell's Principia Mathematica defined identity by this law, with a quantifier over properties.
Gödel's completeness theorem of 1930 covered the calculus with identity as well as the pure calculus.

### Try it

Write a sentence that says "there are exactly two elements".
One answer is $\exists x \, \exists y \, \big( x \neq y \land \forall z \, (z = x \lor z = y) \big)$.

Which substitution axiom does the signature $\{ < \}$ of orders add to reflexivity and the axiom for $=$?
It adds $\forall x_1 \, \forall x_2 \, \forall y_1 \, \forall y_2 \, \big( (x_1 = y_1 \land x_2 = y_2) \to (x_1 < x_2 \to y_1 < y_2) \big)$.

## Explanations

### L1 human

In school you write $2 + 3 = 5$ to say that two expressions name the same number.
First-order logic with equality has the symbol $=$ for exactly this, and it means "the same thing" in every structure.
Its rules say that equals can replace equals: if $x = y$, then $x + 1 = y + 1$.
With $=$ you can count, for example "there are at least two things" is "there are $x$ and $y$ that are not equal".

### L2 human

Here is a small proof with the equality axioms: from $x = y$ we derive $y \cdot y = x \cdot x$ in the signature of groups.
The substitution axiom for $\cdot$, with $x_1 := x$, $x_2 := x$, $y_1 := y$ and $y_2 := y$, gives
$$(x = y \land x = y) \to x \cdot x = y \cdot y.$$
From $x = y$ we get $x \cdot x = y \cdot y$.
Symmetry, proved above from the axiom for $=$, turns this into $y \cdot y = x \cdot x$.
Notice that every step used a named axiom and the instantiation of $\forall$; nothing used the meaning of $=$.
That is the typical use: the axioms let a proof system do what we do without thinking in algebra.
The trap is to forget that the substitution axioms are stated for variables, so each use needs an instance of $\forall$ for the terms at hand.

### L3 human

The semantics fixes $=$ as identity, while the axioms fix it only up to congruence, and the quotient construction joins the two views.
So completeness, compactness and the Löwenheim-Skolem theorems hold for logic with equality.
One real difference is size: with $=$ a sentence can bound the size of a model from above, and without $=$ no set of sentences can.
In a finite relational signature, a formula without $=$ can still say that $x$ and $y$ can replace each other in every argument place of every relation symbol.
That formula defines the largest congruence, so equality is definable up to congruence.
In second-order logic equality is definable outright, by $\forall P \, (P(x) \leftrightarrow P(y))$, which is Leibniz's law.
Resolution provers treat equality with special rules such as paramodulation instead of the axioms.
