## Statement

Consider short impartial [[combinatorial games|SHQ800E0J4]] under normal play.
For $n \ge 0$ let $*n$ be the [[Nim|HYQPVQF509]] heap of size $n$, the game whose options are $*0, \dots, *(n-1)$.
For a finite set $S$ of natural numbers, let $\operatorname{mex} S$ be the least natural number not in $S$.
The *Grundy value* of a game $G$ is defined recursively by $g(G) = \operatorname{mex} \set{g(G') : G' \text{ an option of } G}$.
Games $G$ and $H$ are *equivalent* if for every impartial game $K$, the same player (first or second) wins $G + K$ and $H + K$.
Let $\oplus$ denote addition of natural numbers in binary without carrying.
Then for all short impartial games $G$ and $H$:

1. $G$ is equivalent to $*g(G)$;
2. $g(G + H) = g(G) \oplus g(H)$;
3. the second player wins $G$ if and only if $g(G) = 0$.

## Remarks

Part 3 follows by induction: a game with Grundy value $0$ has only options with nonzero value, and a game with nonzero value has an option with value $0$.
Part 2 is proved by induction on the sum, using that every value below $g(G) \oplus g(H)$ is reached by a move in one component, while $g(G) \oplus g(H)$ itself is not.
Part 1 follows from parts 2 and 3, since $G + K$ and $*g(G) + K$ have the same Grundy value for every $K$.

Example: in the subtraction game where a move removes $1$ or $2$ tokens from a heap of $m$ tokens, the Grundy value is $m \bmod 3$.
So two heaps of sizes $4$ and $5$ have value $1 \oplus 2 = 3 \ne 0$, and the first player wins.

The theorem was found independently by Roland Sprague (1935) and Patrick Grundy (1939).
For impartial games with infinitely many positions but no infinite plays, the same holds with Grundy values that are ordinal numbers.

## Explanations

### L1 human

Every impartial game, no matter how complicated, is secretly a single Nim heap of some size.
That size, the Grundy value, can be computed by working backwards from the end positions.
To play a sum of games, you just compute each Grundy value and combine them as in Nim.
A position is lost for the player to move exactly when this combined value is zero.

### L2 human

The theorem reduces the analysis of sums of impartial games to arithmetic with the nim-sum $\oplus$.
It is the impartial case of Conway's theory of game values, where the nim heaps $*n$ form a group under addition isomorphic to the natural numbers with $\oplus$.
In practice one computes Grundy values of a single component by the mex rule and often finds a pattern, such as the periodic values of subtraction games and octal games.
Under misère play, where the last player to move loses, no such simple theory exists.
