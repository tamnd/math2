## Definition

Let $E, A \in \R^{n \times n}$, $B \in \R^{n \times m}$, $C \in \R^{p \times n}$ and $D \in \R^{p \times m}$, where $E$ may be singular.
The *descriptor system* with these matrices is
$$E x'(t) = A x(t) + B u(t), \qquad y(t) = C x(t) + D u(t),$$
with state $x(t) \in \R^n$, input $u(t) \in \R^m$ and output $y(t) \in \R^p$.
It is *regular* if the [[matrix pencil|KQ7V0J5CGG]] $sE - A$ is regular, that is, $\det(sE - A)$ is not the zero polynomial.
For a regular descriptor system, the [[transfer function|86JKV3TRFD]] is
$$G(s) = C (sE - A)^{-1} B + D.$$

## Remarks

If $E$ is invertible, multiplying by $E^{-1}$ gives an ordinary state-space system, so descriptor systems generalise state-space [[realizations|WDVJXWV3RF]].
If $E$ is singular, the system is a linear [[differential-algebraic system of equations|EY362KR0KB]], its initial states must satisfy constraints, and solutions may involve derivatives of $u$.
A regular system can be brought to the Weierstrass form, which splits it into an ordinary differential equation and a nilpotent algebraic part.

Example: $E = \begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix}$, $A = I_2$, $B = \begin{pmatrix} -1 \\ 0 \end{pmatrix}$, $C = (0, 1)$, $D = 0$ encodes $0 = x_1 - u$ and $x_1' = x_2$, so $y = x_2 = u'$.
Here $sE - A = \begin{pmatrix} -1 & 0 \\ s & -1 \end{pmatrix}$ has determinant $1$, so the system is regular.
Then $(sE - A)^{-1} B = \begin{pmatrix} -1 & 0 \\ -s & -1 \end{pmatrix} \begin{pmatrix} -1 \\ 0 \end{pmatrix} = \begin{pmatrix} 1 \\ s \end{pmatrix}$, and $G(s) = s$, which is not proper.

Non-example of regularity: $n = 1$, $E = 0$, $A = 0$ gives $\det(sE - A) = 0$ for all $s$.
The equation $0 = Bu$ then puts no condition on $x$, so solutions are not determined by their initial values.
