## Summary

Let $f$ be a function defined on an open interval $(a,b)$.

The function $f$ is increasing on $(a,b)$ when every pair of points $x_1 < x_2$ in $(a,b)$ gives $f(x_1) < f(x_2)$.

The function $f$ is decreasing on $(a,b)$ when every such pair gives $f(x_1) > f(x_2)$.

The inequalities are strict here, so a flat piece of the graph is not allowed. This is the notion in [[strictly monotone function|0TR9SR9FTB]], restricted to the interval $(a,b)$.
