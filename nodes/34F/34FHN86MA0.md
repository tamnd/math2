## Definition

Let $G = (N, \Sigma, P, S)$ be a [[context-free grammar|CTCY2R8Q77]] in [[Chomsky normal form|7TMGSPXKJ3]], and let $w = a_1 a_2 \cdots a_n$ with $n \ge 1$ and $a_i \in \Sigma$.
The *CYK algorithm* computes sets $T[i, j] \subseteq N$ for $1 \le i \le j \le n$, by increasing $j - i$:

1. $T[i, i] = \set{A \in N : (A \to a_i) \in P}$;
2. for $i < j$, $T[i, j]$ is the set of $A \in N$ such that $(A \to BC) \in P$ for some $B \in T[i, k]$ and $C \in T[k+1, j]$ with $i \le k < j$.

It answers that $w \in L(G)$ if $S \in T[1, n]$, and that $w \notin L(G)$ otherwise.

## Remarks

By induction on $j - i$, $T[i, j]$ is exactly the set of $A$ with $A \Rightarrow^* a_i \cdots a_j$, so the answer is correct.
The empty word is in $L(G)$ exactly when $S \to \varepsilon$ is a rule.
The running time is $O(n^3 \abs{P})$, see [[big O notation|0TGV80E6A4]]: there are $O(n^2)$ cells and each is filled by trying $O(n)$ split points and all rules.
Example: with rules $S \to AB$, $A \to a$, $B \to b$ and $w = ab$, one gets $T[1,1] = \set{A}$, $T[2,2] = \set{B}$, $T[1,2] = \set{S}$, so $ab \in L(G)$.
For $w = ba$ one gets $T[1,2] = \emptyset$, so $ba \notin L(G)$.
The method requires Chomsky normal form: rules with longer right sides, or unit rules $A \to B$, are not handled by clause 2.
It is an instance of [[dynamic programming|R3FXF08WBH]], since each cell is computed from cells for shorter substrings.
