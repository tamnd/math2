## Summary

The string "$\omega^2 + \omega \cdot 3 + 1$" is a finite name for an infinite ordinal, and a program can decide that it names something smaller than "$\omega^\omega$" by comparing the leading exponents $2$ and $\omega$.
An ordinal notation system is a scheme of such names: it lets a theory about natural numbers talk about countable ordinals.

Precisely, an [[ordinal notation system|3CNSYYX2HF]] is a computable set $A \subseteq \mathbb{N}$ of codes with a computable strict total order $\prec$ that has no infinite descending sequence.
So $(A, \prec)$ is a [[well-order|01CGSJ0GNQ]] of some countable [[ordinal|0YSCSX5YZC]] type $\alpha$.
Each element of $A$ names one ordinal below $\alpha$, and the order of two names can be computed.
In proof theory one asks that $A$ and $\prec$ be primitive recursive, and usually elementary.

## Motivation

[[Transfinite induction|0ZHQMQ2C1N]] is a statement about ordinals, but [[Peano arithmetic|0QFT7Z76N5]] speaks only about natural numbers.
To state "PA proves transfinite induction up to $\alpha$", we need the ordinals below $\alpha$ coded as natural numbers, with an order that PA can compute.
A notation system provides exactly this.

The [[Cantor normal form|6GD30FGYDZ]] gives the first such system, for the ordinals below [[epsilon nought|KT50SMH3EC]], and it is the system of Gentzen's analysis of PA.
Stronger theories have larger ordinals and need longer systems.
So the later pages build new systems from ordinal functions: the [[Veblen function|JQFAE9S2F4]] for $\Gamma_0$, and [[collapsing functions|8S6CT4TMB7]] beyond it.

## Notation

We write $\prec$ for the order on notations, to keep it apart from the order $<$ of the natural numbers that serve as codes.
For a notation $a$, $\lvert a \rvert$ is the ordinal that it denotes, and $\lvert \prec \rvert$ is the order type of the whole system.
Many books use one symbol for a term and its ordinal, such as $\omega^\omega$ for both, which is safe inside one fixed system.

## Remarks

### Three small systems

The natural numbers with $<$ form a system for $\omega$, in which each number names itself.
Finite non-increasing sequences of natural numbers, compared lexicographically with a proper initial segment below the longer sequence, form a system for $\omega^\omega$.
There $(n_1, \ldots, n_k)$ names $\omega^{n_1} + \cdots + \omega^{n_k}$.
The [[Cantor normal form notation|R3BJR7TM2Z]] allows the exponents themselves to be terms, and gives a system for $\varepsilon_0$.
Terms built from $0$, $+$ and the binary Veblen function $\varphi_\alpha(\beta)$ give a system for the [[Feferman-Schütte ordinal|CNN7BK5YAW]] $\Gamma_0$.

### A comparison worked out

Compare $(2, 2, 0)$ with $(2, 1, 1, 1)$ in the system for $\omega^\omega$.
The first sequence names $\omega^2 + \omega^2 + \omega^0 = \omega^2 \cdot 2 + 1$, and the second names $\omega^2 + \omega \cdot 3$.
The first entries agree, and at the second entry $2 > 1$, so $(2, 2, 0) \succ (2, 1, 1, 1)$.
Check with ordinals: $\omega^2 + \omega \cdot 3 < \omega^2 + \omega^2 \le \omega^2 \cdot 2 + 1$.
The program never needed the ordinals, only the entries, and the [[comparison of Cantor normal forms|DXKWBFWCE0]] proves that this works in general.

### What it is not

[[Kleene's O|BG4RCYXQZK]] is not a notation system in this sense: its set of notations is not computable, and its order is not total.
The integers with $<$ are decidable and total, but $-1 > -2 > -3 > \cdots$ descends for ever, so well-foundedness fails.
The rationals with $<$ fail in the same way.
The class of all countable ordinals is well-ordered, but it is uncountable, so it cannot be coded in $\mathbb{N}$.

### The rules you can use

The order types of computable well-orders are exactly the ordinals below the Church-Kleene ordinal $\omega_1^{\mathrm{CK}}$, so every notation system has a type below $\omega_1^{\mathrm{CK}}$.
In a system built from normal forms, comparing two terms reduces to comparing smaller terms, so comparison is a simple recursion.
Well-foundedness is a $\Pi^1_1$ statement, and it cannot be read off the program for $\prec$; each system needs its own proof.
Two systems for the same ordinal are isomorphic, but the isomorphism need not be computable, and a theory may prove induction along one and not the other.

### The problem of natural notation systems

[[An artificial system of type ω|PXMATF6B16]] is a primitive recursive well-order along which PA cannot prove transfinite induction.
So "PA proves induction up to $\alpha$" only has a clear meaning for a fixed, reasonable system.
The [[proof-theoretic ordinal|C72RBH0CDR]], defined as the supremum of the order types of provable well-orders, avoids this, because artificial systems only lower individual cases.

There is no accepted mathematical definition of a natural notation system.
In practice a system is called natural when ordinal functions with a normal form theorem generate it, its comparison is elementary, and its basic facts are provable in a weak theory.
Above $\varepsilon_0$ several systems from different ordinal functions are in use, so each page must fix the system it uses.

### Watch out

A computable order with no computable descending sequence need not be a well-order.
Some computable linear orders have no computable descending sequence, yet they have a non-computable one.
So "I cannot write a program that descends for ever" is no proof of well-foundedness.
Also keep a notation apart from its ordinal: equal ordinals in different systems can have very different codes.

### History

Cantor's normal form of the 1890s gave the first finite names for the ordinals below $\varepsilon_0$.
Veblen's fixed-point functions of 1908 gave names for larger ordinals.
Church and Kleene studied notations for the computable ordinals in the 1930s, and Kleene's system $\mathcal{O}$ comes from that work.
Gentzen's consistency proof of 1936 made the notation system for $\varepsilon_0$ a tool of proof theory.

### Try it

Which is larger, $\omega^\omega$ or $\omega^3 \cdot 5 + \omega^2$?
The leading exponents are $\omega$ and $3$, and $\omega > 3$, so $\omega^\omega$ is larger.

Name in the sequence system the ordinal $\omega^3 + \omega + 4$.
It is $(3, 1, 0, 0, 0, 0)$: one $\omega^3$, one $\omega^1$ and four copies of $\omega^0$.

## Explanations

### L1 human

Ordinals continue past all the natural numbers: $\omega$, $\omega + 1$, $\omega \cdot 2$, $\omega^2$, and much further.
An ordinal notation system is a finite naming scheme for some of them, like the decimal system for numbers.
A program can read two names and say which ordinal is smaller.
For example, $\omega^2$ is larger than $\omega \cdot 100 + 7$, because its first term $\omega^2$ beats the first term $\omega \cdot 100$.
Logicians use such names to measure how strong a list of axioms is.

### L2 human

How would we state "PA proves induction up to $\omega^\omega$"?
Fix the sequence system $(A, \prec)$ above, coded in $\mathbb{N}$ by a standard coding of finite sequences.
The relation $\prec$ is primitive recursive, so PA has a formula for it.
For a formula $\varphi$, the induction statement says: if $\varphi$ holds at $a$ whenever it holds at all $b \prec a$, then $\varphi$ holds at every $a \in A$.
PA proves this for every $\varphi$, by the [[transfinite induction theorem|ZE54ABPMJ0]] of the sub-area.
This is the typical use: a notation system turns a question about ordinals into a question about one formula of arithmetic.

### L3 human

A notation system is a computable presentation of a countable ordinal.
Kleene's $\mathcal{O}$ collects notations for all computable ordinals at once, but it pays with undecidability, and this is why proof theory works with single systems.
Every [[ordinal analysis|C5E5TG8PGP]] ends with a notation system and a proof of transfinite induction along its initial segments.
The strongest systems in use name countable ordinals with symbols for large cardinals, such as inaccessible, Mahlo or weakly compact cardinals; see [[Rathjen's psi function|M7D1HEJQVH]].
Their well-foundedness proofs need strong theories, even though the systems themselves are primitive recursive.
