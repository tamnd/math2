## Summary

An [[ordinal notation system|3CNSYYX2HF]] is a computable set $A \subseteq \N$ with a computable strict total order $\prec$ that has no infinite descending sequence.
So $(A, \prec)$ is a [[well-order|01CGSJ0GNQ]] of some countable [[ordinal|0YSCSX5YZC]] type $\alpha$.
Each element of $A$ is a finite name for one ordinal below $\alpha$, and the order of two names can be computed.
Notation systems let a theory of arithmetic speak about countable ordinals, and they are the measuring scale of ordinal analysis.

## Motivation

[[Transfinite induction|0ZHQMQ2C1N]] is a statement about ordinals, but [[Peano arithmetic|0QFT7Z76N5]] only speaks about natural numbers.
To state "PA proves transfinite induction up to $\alpha$", one needs the ordinals below $\alpha$ as natural numbers, with an order that PA can compute.
A notation system provides exactly this.
The [[Cantor normal form|6GD30FGYDZ]] gives the first such system, for the ordinals below [[epsilon nought|KT50SMH3EC]].
Stronger theories need longer systems, so the subject builds new notation systems from ordinal functions such as the [[Veblen function|JQFAE9S2F4]].

## Notation

The symbol $\prec$ is used for the order on notations, to separate it from the order $<$ of the natural numbers that are the codes.
For a notation $a$, $\abs{a}$ is the ordinal that it denotes, and $\abs{\prec}$ is the order type of the whole system.

## Remarks

### Examples

- The natural numbers with $<$: a system for $\omega$, in which each number names itself.
- [[The Cantor normal form notation for epsilon nought|R3BJR7TM2Z]]: terms $\omega^{a_1} + \cdots + \omega^{a_k}$ with $a_1 \succeq \cdots \succeq a_k$, compared lexicographically; a system for $\varepsilon_0$.
- Finite non-increasing sequences of natural numbers, compared lexicographically with a proper initial segment below: a system for $\omega^\omega$, since $(n_1, \ldots, n_k)$ names $\omega^{n_1} + \cdots + \omega^{n_k}$.
- Terms built from $0$, $+$ and the binary Veblen function $\varphi_\alpha(\beta)$: a system for the [[Feferman-Schütte ordinal|CNN7BK5YAW]] $\Gamma_0$.
- [[An artificial notation system of type ω|PXMATF6B16]]: a primitive recursive well-order of type $\omega$ along which PA does not prove transfinite induction.

### Non-examples

- [[Kleene's O is not an ordinal notation system|BG4RCYXQZK]] in the sense of this page: its set of notations is not computable, and its order is not total.
- The integers with $<$, coded in $\N$: decidable and total, but $-1 > -2 > -3 > \cdots$ descends for ever, so well-foundedness fails.
- The rational numbers with $<$: decidable and total, but not well-founded.
- The set of all countable ordinals: well-ordered, but not a set of natural numbers, since it is uncountable.

### Basic properties

- Every notation system is a system for an ordinal below the Church-Kleene ordinal $\omega_1^{\mathrm{CK}}$, and every ordinal below $\omega_1^{\mathrm{CK}}$ has a notation system.
- In a notation system built from normal forms, the comparison of two terms reduces to the comparison of smaller terms, as in the [[comparison of Cantor normal forms|DXKWBFWCE0]].
- The well-foundedness of a notation system is a $\Pi^1_1$ statement. It is not decided by inspecting the program for $\prec$, and each system needs its own proof.
- Different systems for the same ordinal are isomorphic as orders, but the isomorphism need not be computable. A theory may prove transfinite induction along one system and not along the other.

### The problem of natural notation systems

The [[proof-theoretic ordinal|C72RBH0CDR]] of a theory is defined through notation systems, and the value depends on which systems one allows.
[[The artificial system of type ω|PXMATF6B16]] shows that PA can fail to prove transfinite induction along a system for the ordinal $\omega$.
So the statement "the ordinal of PA is $\varepsilon_0$" is about the standard system of Cantor normal forms.
There is no accepted mathematical definition of a "natural" notation system.
In practice, a system is called natural when it is generated by ordinal functions with a normal form theorem and its comparison is elementary.
Its basic facts, such as linearity, the successor and limit cases and the arithmetic of terms, should also be provable in a weak theory.
For ordinals above $\varepsilon_0$ the choice matters more, because several systems from different ordinal functions are in use, and each page must fix its system.

### History

Georg Cantor's normal form of the 1890s gave the first finite names for the ordinals below $\varepsilon_0$.
Oswald Veblen's fixed-point functions of 1908 gave names for larger ordinals.
Alonzo Church and Stephen Kleene studied notations for the computable ordinals in the 1930s, and Kleene's system $\mathcal{O}$ dates from that work.
Gerhard Gentzen's consistency proof of 1936 made the notation system for $\varepsilon_0$ a tool of proof theory.

### Common errors

- Speaking of "the" ordinal of a theory without a fixed notation system. The value is only meaningful for natural systems.
- Thinking that a computable order is a well-order when it has no computable descending sequence. There are computable linear orders with no computable descending sequence that still have a non-computable one.
- Confusing a notation, which is a finite term or code, with the ordinal that it denotes. Equal ordinals in different systems can have very different codes.

## Explanations

### L1 human

Ordinals continue past all the natural numbers: $\omega$, $\omega + 1$, $\omega \cdot 2$, $\omega^2$, and much further.
An ordinal notation system is a finite naming scheme for some of them, like the decimal system for numbers.
A program can read two names and say which ordinal is smaller.
For example, the name $\omega^2$ is larger than the name $\omega \cdot 100 + 7$, because the first term wins.
Logicians use such names to measure how strong a set of axioms is.

### L2 human

We find the ordinal named by the sequence $(2, 2, 0)$ in the system of non-increasing sequences, and we compare it with $(2, 1, 1, 1)$.

1. The sequence $(2, 2, 0)$ names $\omega^2 + \omega^2 + \omega^0 = \omega^2 \cdot 2 + 1$.
2. The sequence $(2, 1, 1, 1)$ names $\omega^2 + \omega \cdot 3$.
3. The first entries are equal. At the second entry, $2 > 1$, so $(2, 2, 0) \succ (2, 1, 1, 1)$.
4. This agrees with the ordinals: $\omega^2 \cdot 2 + 1 > \omega^2 + \omega \cdot 3$, since $\omega^2 + \omega \cdot 3 < \omega^2 + \omega^2$.

The typical use is to state that a theory proves transfinite induction along an initial segment of a fixed system.
The trap: the length of the order does not measure the difficulty.
An order of type $\omega$ can be harder to prove well-founded than the standard order of type $\omega^\omega$.

### L3 human

A notation system is a computable presentation of a countable ordinal.
In the systems of proof theory, the ordinal functions are computable functions on terms.
Kleene's $\mathcal{O}$ collects notations for all computable ordinals at once, but at the cost of decidability; this is why proof theory works with single systems.
The search for natural systems connects ordinal analysis with the theory of large cardinals.
The strongest collapsing functions use names of large cardinals, such as inaccessible, Mahlo or weakly compact cardinals, to name countable ordinals.
