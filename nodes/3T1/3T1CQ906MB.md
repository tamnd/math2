## Summary

The Robinson–Foulds metric measures how different two [[phylogenetic trees|RK58WSHJSG]] on the same set of taxa are.
It counts the splits of the taxa, given by the edges, that occur in one tree but not in the other.
It is a [[metric|0VKD1TP7F3]] on the phylogenetic trees with these taxa as leaves.
It is easy to compute and is the most common way to compare the output of phylogenetic methods.

## Explanations

### L1 human

Cutting one edge of a tree on a set of species splits the species into two groups.
Each tree is described by the list of splits it makes.
Two trees are compared by counting the splits that one tree makes and the other does not.
For example, one tree groups $\set{a, b}$ against $\set{c, d}$, and another groups $\set{a, c}$ against $\set{b, d}$.
Each has one such split, and the two splits differ, so the distance is $2$.
