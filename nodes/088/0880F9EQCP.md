## Definition

Let $A$ be an $n \times n$ complex [[Hermitian matrix|0P17NGQQMQ]], so $A^* = A$.
The matrix $A$ is *positive semidefinite* when
$$x^* A x \ge 0 \qquad \text{for all } x \in \C^n.$$
A real [[symmetric matrix|0VR671PHE5]] $A$ is positive semidefinite when $x^T A x \ge 0$ for all $x \in \R^n$.

## Notation

We write $A \succeq 0$.
In Mathlib the predicate is `Matrix.PosSemidef A`, and it includes the condition that $A$ is Hermitian.

## Remarks

- Each [[positive definite|0QQCG3JWJ4]] matrix is positive semidefinite, since $> 0$ implies $\ge 0$ and $x = 0$ gives $0$.
- For a Hermitian $A$, the number $x^* A x$ is real, so the inequality makes sense.
- Over $\C$, the condition $x^* A x \ge 0$ for all $x$ already forces $A$ to be Hermitian. Over $\R$ it does not: the rotation $\begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}$ has $x^T A x = 0$ for all real $x$. So the real definition must ask for symmetry.
- Some books do not ask for symmetry in the real case. This page always asks for it.

## Explanations

### L1 human

A positive semidefinite matrix is a symmetric matrix that never gives a negative value of $x^T A x$.
It may give $0$ for some nonzero vectors.
For example, $\begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}$ gives $x_1^2$, which is $0$ at $x = (0, 1)$.

### L2 human

To check the definition, write $x^T A x$ as a sum of squares with nonnegative coefficients, or as $\norm{Bx}^2$ for a matrix $B$.
Then the value is never negative.
To show that a matrix is not positive semidefinite, it is enough to find one vector with $x^T A x < 0$.
A trap: a matrix with a negative diagonal entry $a_{ii}$ fails at $x = e_i$, but a matrix with a nonnegative diagonal can still fail.

### L3 human

The definition says that the Hermitian form $(x, y) \mapsto y^* A x$ is positive semidefinite.
Its kernel $\set{x : x^* A x = 0}$ equals the null space of $A$, by the Cauchy-Schwarz inequality for semidefinite forms.
So the form induces an inner product on $\C^n / \ker A$.
In Mathlib, `Matrix.PosSemidef` works over any star-ordered ring.
