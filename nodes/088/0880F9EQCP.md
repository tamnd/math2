## Definition

A positive semidefinite matrix is a Hermitian matrix whose form $x^* A x$ is never negative.
Let $A$ be an $n \times n$ complex [[Hermitian matrix|0EKZCX4K3P]], so that $A^* = A$, where $A^*$ is the [[conjugate transpose|0EX045E2BP]].
The matrix $A$ is *positive semidefinite* when
$$x^* A x \ge 0 \qquad \text{for all } x \in \C^n.$$
A real $n \times n$ matrix $A$ is *positive semidefinite* when it is [[symmetric|0N28QN4CYA]], $A^{\mathsf{T}} = A$, and $x^{\mathsf{T}} A x \ge 0$ for all $x \in \R^n$.

## Notation

We write $A \succeq 0$.
In Mathlib the predicate is `Matrix.PosSemidef A`, and it includes the condition that $A$ is Hermitian.

## Remarks

The Hermitian condition makes each number $x^* A x$ real, so the inequality has a meaning.
The inequality is not strict, so the form may vanish at nonzero vectors, and that is the only difference from the definition of a [[positive definite matrix|0QQCG3JWJ4]].
So each positive definite matrix is positive semidefinite, since $x^* A x > 0$ for $x \ne 0$ and $x^* A x = 0$ for $x = 0$.

Over $\C$, the inequality for every $x$ already forces $A$ to be Hermitian, because a complex matrix with $x^* A x$ real for every $x$ is Hermitian.
Over $\R$ it does not.
The rotation $R = \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}$ has
$$x^{\mathsf{T}} R x = x_1 (-x_2) + x_2 x_1 = 0 \qquad \text{for every } x \in \R^2,$$
so it satisfies the real inequality, but it is not symmetric and it is not a semidefinite matrix in our sense.
So the real definition must ask for symmetry, and books that drop it in the real case are using a different notion.

For a small example, $\operatorname{diag}(1, 0)$ is symmetric with form $x_1^2 \ge 0$, so it is positive semidefinite, and the form is $0$ at $(0, 1)$, so it is not definite.
The matrix $\operatorname{diag}(1, -1)$ is symmetric but fails the inequality at $(0, 1)$.
The [[concept page|01MMVW8CKC]] gives more examples and the tests.

## Explanations

### L1 human

A positive semidefinite matrix is a symmetric matrix that never gives a negative value of $x^{\mathsf{T}} A x$.
It may give $0$ for some nonzero vectors.
For example, $\begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}$ gives $x_1^2$, which is $0$ at $x = (0, 1)$.

### L2 human

To check the definition, write $x^{\mathsf{T}} A x$ as a sum of squares with nonnegative coefficients, or as $\norm{Bx}^2$ for some matrix $B$.
For example, $\begin{pmatrix} 1 & 2 \\ 2 & 4 \end{pmatrix}$ gives $x_1^2 + 4x_1 x_2 + 4x_2^2 = (x_1 + 2x_2)^2$.
To show that a matrix is not positive semidefinite, it is enough to find one vector with $x^{\mathsf{T}} A x < 0$.
Watch out: a negative diagonal entry $a_{ii}$ fails at $x = e_i$, but a matrix with a nonnegative diagonal can still fail, as $\begin{pmatrix} 1 & 2 \\ 2 & 1 \end{pmatrix}$ does at $(1, -1)$.

### L3 human

The definition says that the Hermitian form $(x, y) \mapsto y^* A x$ is positive semidefinite.
Its set of isotropic vectors $\{ x : x^* A x = 0 \}$ equals the null space of $A$, by the Cauchy-Schwarz inequality for semidefinite forms.
So the form induces an inner product on the quotient $\C^n / \ker A$.
In Mathlib, `Matrix.PosSemidef` works over any star-ordered ring.
