## Summary

The Bullen parameter $\eta$ measures how far the density profile of a planet departs from the [[Adams–Williamson equation|E4CX8RCSHF]].
It equals $1$ in a region of uniform composition with an adiabatic temperature profile.
Values different from $1$ point to changes of composition or phase, or to temperature gradients that are not adiabatic.
It is used to check and to construct radial Earth models.

## Explanations

### L1 human

The Adams–Williamson equation predicts how fast density should grow with depth if rock is only squeezed.
The Bullen parameter is the ratio of the true growth to this prediction.
A value of $1$ means "just squeezing".
A value below $1$ means density grows more slowly, for instance because the rock gets hotter faster than an adiabat.
A value above $1$ means extra densification, for instance from a change of mineral phase.
