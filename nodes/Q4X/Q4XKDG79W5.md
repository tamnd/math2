## Statement

Multiplication is a well defined operation on the [[integers|0C4JS9RF5M]] $\mathbb{Z}$. Any two integers have exactly one product, and it is again an integer.

Moreover, for all integers $x$, $y$ and $z$:

1. $xy = yx$;
2. $x(yz) = (xy)z$;
3. $x(y + z) = xy + xz$.
