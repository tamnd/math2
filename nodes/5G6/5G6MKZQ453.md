## Example

Let $W = \set{0, 1, 2}$ and $R = \set{(0,0), (1,1), (2,2), (0,1), (1,2)}$.
On the power set of $W$, put $\Box x = \set{w : v \in x \text{ for every } v \text{ with } w R v}$, as in [[Kripke semantics|NGHWZ9Y7ZV]].
We check which axioms of an [[interior operator|7X1HGZ6FK0]] hold.

1. $\Box W = W$, so $\Box 1 = 1$ holds.
2. $\Box x \subseteq x$ holds, because $R$ is reflexive: $w R w$ gives $w \in x$.
3. $\Box(x \cap y) = \Box x \cap \Box y$ holds, since "every successor lies in $x \cap y$" means "in $x$ and in $y$".
4. $\Box \Box x = \Box x$ fails at $x = \set{0, 1}$.
   The successors of $0$ are $0, 1$, so $\Box\set{0, 1} \ni 0$; the point $1$ sees $2$, and $2$ sees $2$, so $\Box\set{0, 1} = \set{0}$.
   Then $\Box\set{0} = \emptyset$, because $0$ sees $1 \notin \set{0}$.

So $(B, \Box)$ is not an interior algebra.

## Remarks

1. The failure comes from $0 R 1$, $1 R 2$ and not $0 R 2$; the relation is not transitive.
2. Adding the pair $(0, 2)$ makes $R$ a preorder, and then $\Box$ is an interior operator.
3. The open elements $\set{x : \Box x = x}$ are $\emptyset$, $\set{2}$, $\set{1, 2}$, $W$.
   For $x = \set{2}$, $\Box(\neg x \cup \emptyset) = \set{0}$ is not open, so the formula of the theorem on open elements fails here.
4. The algebra is a modal algebra of the logic T, not of S4.

## Explanations

### L1 human

Here each point sees itself and the next point, but $0$ does not see $2$.
"Necessarily" at a point means "true at every point it sees".
At $0$, "necessarily in $\set{0, 1}$" is true, because $0$ sees only $0$ and $1$.
But at $1$ it is false, because $1$ sees $2$.
So "necessarily necessarily" is weaker than "necessarily", and the interior rule $IIx = Ix$ breaks.

### L2 human

1. Successors: $0 \mapsto \set{0, 1}$, $1 \mapsto \set{1, 2}$, $2 \mapsto \set{2}$.
2. $\Box\set{0, 1} = \set{0}$, since only the successors of $0$ lie in $\set{0, 1}$.
3. $\Box\set{0} = \emptyset$, since the successors of $0$ include $1$.
4. So $\Box \Box \set{0, 1} = \emptyset \ne \set{0} = \Box \set{0, 1}$.

The typical use: this frame refutes the S4 axiom $\Box p \to \Box \Box p$ at the point $0$ with $p$ true at $0$ and $1$.
The trap: reflexivity gives $\Box x \le x$, but not $\Box \Box x = \Box x$; that needs transitivity.
