## Summary

Backstepping is a recursive method for building stabilizing feedback laws and [[control-Lyapunov functions|40ED6BYH7W]] for nonlinear systems in strict-feedback form.
In such a system each state variable acts as the input of the subsystem before it.
One first stabilizes the innermost subsystem with a virtual control.
Then one steps back through the chain of integrators, each time adding a quadratic penalty on the gap between a state and its desired value.
Unlike [[feedback linearization|1J2KTGXB34]], it need not cancel nonlinearities that already help stability, and it is a standard tool of [[nonlinear control|RZ94FKGZ5Z]].

## Explanations

### L1 human

Picture a chain: the control pushes the last link, which pulls the one before it, and so on up to the first link that one wants to steer.
Backstepping first decides how the second link should move to steer the first one, as if it could be moved directly.
Then it decides how the third link should move so that the second follows that plan, and so on back to the real control.
At each step it also builds an energy-like function that proves the whole chain settles down.
