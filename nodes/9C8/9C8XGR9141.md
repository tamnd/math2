## Definition

Let $n \ge 1$ and $0 \le p \le n$ be integers.
Let $A$ be a real $m \times n$ [[matrix|0VD9ZSWWJG]], let $b \in \R^m$ and let $c \in \R^n$.
The *mixed-integer linear program* given by $(A, b, c, p)$ is the problem
$$\text{maximize } c^T x \quad \text{subject to} \quad A x \le b, \quad x_1, \dots, x_p \in \Z, \quad x_{p+1}, \dots, x_n \in \R.$$
The variables $x_1, \dots, x_p$ are the *integer variables* and the others are the *continuous variables*.
A vector satisfying all the constraints is a *feasible solution*, and a feasible solution of largest objective value is *optimal*.

## Remarks

When $p = 0$ the program is a [[linear program|VNMXB0J2KA]], and when $p = n$ it is a pure integer program.

Example: maximize $x + 2y$ subject to $x \le 3y$, $x \le 2$, $x \ge 0$, $0 \le y \le 1$, $y \in \Z$, $x \in \R$.
For $y = 0$ the constraint $x \le 0$ forces $x = 0$ with value $0$.
For $y = 1$ the best choice is $x = 2$, with value $4$, so the optimal solution is $(x, y) = (2, 1)$.

Non-example: maximize $x y$ subject to $0 \le x \le 1$ and $y \in \set{0, 1}$ has mixed variables but a nonlinear objective, so it is a mixed-integer nonlinear program, not a mixed-integer linear program.

One often minimizes instead of maximizes, and uses equality constraints with nonnegative variables; these forms are equivalent to the one above.
