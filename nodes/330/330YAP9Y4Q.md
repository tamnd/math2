## Definition

Primitive recursive arithmetic $\mathsf{PRA}$ is the following formal system.

1. Function symbols, following the [[primitive recursive functions|XZV7BD3D66]].
   - The constant $0$ (arity $0$) and the successor $S$ (arity $1$) are function symbols.
   - For $1 \le i \le n$, the projection $\pi^n_i$ is a function symbol of arity $n$.
   - If $g$ has arity $m$ and $h_1, \ldots, h_m$ have arity $n$, then $\mathrm{Comp}(g, h_1, \ldots, h_m)$ is a function symbol of arity $n$.
   - If $g$ has arity $n$ and $h$ has arity $n + 2$, then $\mathrm{Rec}(g, h)$ is a function symbol of arity $n + 1$.
2. Terms are built from the variables $x_0, x_1, \ldots$ by the function symbols.
3. Formulas. An atomic formula is an equation $s = t$ between terms. The formulas are built from atomic formulas by $\neg$, $\land$, $\lor$ and $\to$ only, with no quantifiers.
4. Logical axioms. These are the substitution instances of propositional tautologies, and the equality axioms $x = x$, $x = y \to (x = z \to y = z)$, and $x = y \to f(\ldots, x, \ldots) = f(\ldots, y, \ldots)$ for each function symbol $f$ and each argument place.
5. Successor axioms. $\neg (Sx = 0)$ and $Sx = Sy \to x = y$.
6. Defining equations, with $\vec y = y_1, \ldots, y_n$:
   - $\pi^n_i(y_1, \ldots, y_n) = y_i$;
   - $\mathrm{Comp}(g, h_1, \ldots, h_m)(\vec y) = g(h_1(\vec y), \ldots, h_m(\vec y))$;
   - $\mathrm{Rec}(g, h)(0, \vec y) = g(\vec y)$ and $\mathrm{Rec}(g, h)(Sx, \vec y) = h(x, \mathrm{Rec}(g, h)(x, \vec y), \vec y)$.
7. Rules.
   - Modus ponens.
   - Substitution: from $\varphi(x)$ infer $\varphi(t)$, for every variable $x$ and every term $t$.
   - Induction rule: from $\varphi(0)$ and $\varphi(x) \to \varphi(Sx)$ infer $\varphi(x)$, for every formula $\varphi$.

A formula is a theorem of $\mathsf{PRA}$ when it is the last formula of a finite sequence in which every formula is an axiom or follows from earlier formulas by a rule.

## Notation

Every formula of $\mathsf{PRA}$ is quantifier-free, so the restriction "for quantifier-free $\varphi$" in the induction rule is automatic.
We give the symbols their usual names.
Let $R = \mathrm{Rec}(\pi^1_1, \mathrm{Comp}(S, \pi^3_2))$, so that $R(0, y) = y$ and $R(Sx, y) = S(R(x, y))$.
The symbol $x + y$ is $\mathrm{Comp}(R, \pi^2_2, \pi^2_1)(x, y) = R(y, x)$, so that $x + 0 = x$ and $x + Sy = S(x + y)$ are theorems.
In the same way $x \cdot y$ is defined from $+$ by $x \cdot 0 = 0$ and $x \cdot Sy = x \cdot y + x$.

## Remarks

A theorem $\varphi(x_1, \ldots, x_k)$ asserts that $\varphi(\overline{n_1}, \ldots, \overline{n_k})$ holds for all numbers $n_1, \ldots, n_k$.
The definition fixes one symbol for each definition, not for each function: the symbols $\mathrm{Comp}(\pi^1_1, S)$ and $S$ are different, but $\mathsf{PRA}$ proves that they agree on every argument.
The induction rule can be replaced by the axioms of the first-order induction schema for quantifier-free formulas when the system is formulated in first-order logic; the quantifier-free theorems stay the same.
The [[concept node|WCXH72T8D8]] discusses what $\mathsf{PRA}$ proves and why it is the standard formal model of finitism.

## Explanations

### L1 human

The definition lists the symbols, the starting facts and the allowed steps of a proof.
Each function symbol comes with equations that compute it, so every closed term can be evaluated by hand.
For example, $S0 + S0$ evaluates to $S(S0 + 0)$ and then to $SS0$, which is the number $2$.
The only way to prove a general law is the induction rule: prove it for $0$, and prove that it passes from $x$ to $x + 1$.

### L2 human

We evaluate $\overline{2} \cdot \overline{2}$ with the defining equations.

1. $SS0 \cdot SS0 = SS0 \cdot S0 + SS0$, by the second equation of $\cdot$.
2. $SS0 \cdot S0 = SS0 \cdot 0 + SS0$, by the same equation.
3. $SS0 \cdot 0 = 0$, by the first equation of $\cdot$.
4. $0 + SS0 = S(0 + S0) = SS(0 + 0) = SS0$, by the second equation of $+$ twice and the first once.
5. So $SS0 \cdot S0 = SS0$, by steps 2 to 4 and the equality axioms.
6. $SS0 + SS0 = S(SS0 + S0) = SS(SS0 + 0) = SSSS0$, in the same way.
7. So $\overline{2} \cdot \overline{2} = \overline{4}$, by steps 1, 5 and 6.

A trap is to use a law such as $0 + x = x$ for a variable $x$ before it is proved; for numerals the equations compute it, but for the variable it needs the induction rule.
