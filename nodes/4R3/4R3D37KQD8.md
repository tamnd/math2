## Example

Let the vocabulary be empty, so a structure is a nonempty set $M$.
The [[branching quantifier|KMNVEGS34N]] sentence is
$$\iota := \exists a \begin{pmatrix} \forall x_1 & \exists y_1 \\ \forall x_2 & \exists y_2 \end{pmatrix} \bigl( (x_1 = x_2 \leftrightarrow y_1 = y_2) \land y_1 \neq a \bigr).$$
We show that $M \models \iota$ if and only if $M$ is [[infinite|0PWE3BCHVJ]].

1. By the meaning of the Henkin quantifier, $M \models \iota$ if and only if there are $c \in M$ and functions $f, g : M \to M$ such that, for all $a_1, a_2 \in M$, we have $a_1 = a_2 \leftrightarrow f(a_1) = g(a_2)$ and $f(a_1) \neq c$.
2. Suppose that $c$, $f$ and $g$ exist. Take $a_1 = a_2 = a$. The left side of the biconditional is true, so $f(a) = g(a)$. This holds for every $a$, so $f = g$.
3. With $g = f$, the biconditional reads $a_1 = a_2 \leftrightarrow f(a_1) = f(a_2)$. So $f$ is [[injective|09NWETVTNY]].
4. The second conjunct says that $c$ is not a value of $f$. So $f$ is not [[surjective|01RVCMSN5N]].
5. If $M$ were finite, an injective map from $M$ to $M$ would be surjective, by the [[pigeonhole principle|0HGVCWQGY3]]. So $M$ is infinite.
6. Conversely, let $M$ be infinite. By the axiom of choice, $M$ has a [[countably infinite subset|0RWQ5VZ6VQ]], so there is an injective map $e : \mathbb{N} \to M$.
7. Define $h : M \to M$ by $h(e(n)) = e(n + 1)$ for $n \in \mathbb{N}$, and $h(m) = m$ for $m$ outside the image of $e$. Then $h$ is injective, and $e(0)$ is not a value of $h$.
8. Put $c = e(0)$ and $f = g = h$. The biconditional of step 1 holds because $h$ is injective, and $f(a_1) \neq c$ holds by step 7. So $M \models \iota$.

For example, on $M = \mathbb{N}$ the witnesses are $c = 0$ and $f(n) = g(n) = n + 1$.
On $M = \set{0, 1, 2}$ every injective $f$ is a bijection, so every $c$ is a value of $f$, and $\iota$ is false.

## Remarks

The sentence expresses Dedekind-infinity: some injective map of the domain to itself misses an element.
Steps 2 to 5 use no choice, so a structure that satisfies $\iota$ is always infinite.
Only step 6 uses the axiom of choice, and only to find a countably infinite subset.

The first conjunct does two jobs.
At $x_1 = x_2$ it forces the two players' functions to agree, and at $x_1 \neq x_2$ it forces injectivity.
Without the branching, $y_2$ could depend on $x_1$ and $y_1$, and the first job fails; the [[linear reading|V24R6JC19Y]] is true in every set with at least two elements.

The sentence relativizes to a formula $\varphi(x)$.
The sentence $\exists a\, Q_H x_1 x_2 y_1 y_2\, (\varphi(a) \land (x_1 = x_2 \leftrightarrow y_1 = y_2) \land (\varphi(x_1) \to (\varphi(y_1) \land y_1 \neq a)))$ says that infinitely many elements satisfy $\varphi$.
The proof is the same, with the injection mapping the set defined by $\varphi$ into itself and missing $a$.

In [[independence-friendly logic|DPMKT2KRB8]] the same sentence is written $\exists c\, \forall x \exists y \forall z (\exists w / \set{x, y})\, ((x = z \leftrightarrow y = w) \land y \neq c)$.
Its negation says that the domain is finite.
So first-order logic with the Henkin quantifier has no complete proof system, by the argument on the page on [[branching quantifiers|KMNVEGS34N]].

## Explanations

### L1 human

Two players sit in separate rooms.
A referee tells the first player a name $x_1$ from a list, and the first player answers with a name $y_1$; the second player gets $x_2$ and answers $y_2$ in the same way.
They win if equal questions get equal answers, different questions get different answers, and the first player never answers with one forbidden name.
To win for sure, the players must agree in advance on a rule that sends different names to different names and never uses the forbidden name.
With the list $0, 1, 2, 3, \ldots$ the rule "add one" works, and $0$ is the forbidden name.
With a list of three names, a rule that sends different names to different names uses all three names, so it uses the forbidden one.

### L2 human

We check the witnesses on $M = \mathbb{Z}$, where the infinite set has no "first" element.

1. Fix any $c$, say $c = 0$, and look for an injective $f$ that misses $0$.
2. The map $n \mapsto n + 1$ is a bijection of $\mathbb{Z}$, so it does not miss $0$.
3. Take instead $f(n) = 2n + 1$ for $n \geq 0$ and $f(n) = 2n$ for $n < 0$. Its values are the odd numbers $1, 3, 5, \ldots$ and the even numbers $-2, -4, \ldots$.
4. Two different arguments in the same case give different values. The first case gives positive odd values and the second gives negative even values, so $f$ is injective.
5. The value $0$ is neither positive nor negative, so $0$ is not a value of $f$, and $\iota$ holds with $c = 0$ and $g = f$.

The typical use of this sentence is to show that a logic with the Henkin quantifier can define the class of infinite structures.
A trap is step 2: a bijection never works, so the witness must be chosen to miss $c$.
