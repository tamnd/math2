## Definition

Strong Kleene logic is the logic of one three-valued matrix with negation, minimum and maximum, in which only the top value counts as true.

The *strong Kleene matrix* is the [[logical matrix|AJEJS6TFWP]] $\mathbf{K}_3 = \langle \{0, \tfrac12, 1\}, \neg, \land, \lor, \{1\} \rangle$ with the operations below.
$$\neg x = 1 - x, \qquad x \land y = \min(x, y), \qquad x \lor y = \max(x, y)$$
Implication is the abbreviation $\varphi \to \psi = \neg \varphi \lor \psi$, so $x \to y = \max(1 - x, y)$.
The only [[designated value|K6CVH3D7R8]] is $1$.
*Strong Kleene logic* $\mathsf{K}_3$ is the logic of this matrix: $\Gamma \models_{\mathsf{K}_3} \varphi$ iff every valuation that gives all members of $\Gamma$ the value $1$ gives $\varphi$ the value $1$.

The tables, with the row for $x$:

| $x$ | $\neg x$ | $x \land 0$ | $x \land \tfrac12$ | $x \land 1$ | $x \lor 0$ | $x \lor \tfrac12$ | $x \lor 1$ |
|---|---|---|---|---|---|---|---|
| $0$ | $1$ | $0$ | $0$ | $0$ | $0$ | $\tfrac12$ | $1$ |
| $\tfrac12$ | $\tfrac12$ | $0$ | $\tfrac12$ | $\tfrac12$ | $\tfrac12$ | $\tfrac12$ | $1$ |
| $1$ | $0$ | $0$ | $\tfrac12$ | $1$ | $1$ | $1$ | $1$ |

## Notation

Kleene wrote the values as $\mathbf{f}$, $\mathbf{u}$ and $\mathbf{t}$.
Some texts call the logic $\mathsf{K}_3$, some $\mathsf{SK}$, and some say "strong Kleene scheme" for the tables alone.

## Remarks

Each part of the definition has a reason.
On $\{0, 1\}$ the tables are the classical ones, so every valid inference of $\mathsf{K}_3$ is classically valid.
A classical value of one argument decides the result whenever it decides it classically: $0 \land y = 0$ and $1 \lor y = 1$ for every $y$, including $y = \tfrac12$.
The designated set $\{1\}$ makes $\tfrac12$ "not yet true", so a formula that can take the value $\tfrac12$ is not a law.

The implication table follows from $\max(1 - x, y)$.
For $x = 0$ it gives $1$ in every column, and for $x = 1$ it gives $y$.
For $x = \tfrac12$ it gives $\tfrac12$, $\tfrac12$ and $1$ in the columns $y = 0$, $\tfrac12$ and $1$.

Modus ponens is valid: if $p = 1$, then $p \to q = \max(0, q) = q$, so a designated $p \to q$ forces $q = 1$.
Excluded middle is not: the valuation $p = \tfrac12$ gives $p \lor \neg p$ the value $\tfrac12$.
With the designated set $\{\tfrac12, 1\}$, the same algebra gives Priest's logic $\mathsf{LP}$; see [[the comparison|BJMXHXJ7QQ]].
The [[Łukasiewicz three-valued matrix|F9NDCFY3GS]] has the same $\neg$, $\land$ and $\lor$ and a different implication, with $\tfrac12 \to \tfrac12 = 1$.
The [[concept page|SZHA10A9X7]] gives the motivation and the uses.

## Explanations

### L1 human

There are three values: false, undefined and true.
"Not" swaps false and true and keeps undefined.
"And" takes the smaller value and "or" takes the larger one.
An argument is valid when true premises always give a true conclusion.

### L2 human

To test $\Gamma \models_{\mathsf{K}_3} \varphi$, look only at the valuations that make every premise exactly $1$.
For example, $p \land q \models p$ holds: if $\min(x, y) = 1$, then $x = 1$.
The typical use is to check an inference by a short search for a counter-valuation.
Watch out: do not count $\tfrac12$ as good enough for the premises, because that gives $\mathsf{LP}$, a different logic.
