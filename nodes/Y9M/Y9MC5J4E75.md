## Definition

Let $N \ge 1$ and $0 \le K \le N - 1$ be integers.
For each site $i \in \set{1, \dots, N}$ choose a set $V_i$ of $K$ other sites.
For each $i$ and each $y \in \set{0, 1}^{K+1}$, draw a value $f_i(y)$ from the uniform [[distribution|0QB913WM5E]] on $[0, 1]$, all independently.
The *NK model* is the random [[fitness landscape|5R81AA6TG8]] on $\set{0, 1}^N$ with neighbours at Hamming distance $1$.
Its fitness is $F(x) = \frac1N \sum_{i=1}^N f_i\big(x_i, (x_j)_{j \in V_i}\big)$, with the sites of $V_i$ listed in increasing order.

## Remarks

Example: for $K = N - 1$, each $f_i$ depends on the whole string, so the values $F(x)$ for distinct $x$ are independent and identically distributed.
Then each $x$ is a local peak with probability $1/(N + 1)$, being the largest of $N + 1$ independent continuous values, and the expected number of local peaks is $2^N/(N + 1)$.
For $K = 0$, $F$ is additive, so with probability $1$ it has exactly one local peak.
Non-example: a landscape of the same form in which the sets $V_i$ have different sizes is not an NK model, since each $V_i$ must have exactly $K$ elements.
The choice of $V_i$ as the $K$ nearest sites on a ring is called the adjacent neighbourhood model.
