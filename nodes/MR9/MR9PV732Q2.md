## Summary

A binary decision diagram is a directed acyclic graph that represents a [[Boolean function|0X05GS525E]].
To evaluate the function, start at the root and read the variable named at each node.
Follow the edge for its value until a terminal node $0$ or $1$ is reached.
Fix the order in which the variables are tested and merge redundant nodes.
Then the reduced ordered diagram of a function is unique, so equality of functions becomes equality of diagrams.
This makes binary decision diagrams a basic tool in hardware verification and [[model checking|VNY0VXVZ53]].

## Explanations

### L1 human

A binary decision diagram is a flow chart of yes/no questions about the inputs.
Each box asks "is $x_i$ true?" and has two exits, one for no and one for yes; at the bottom are the answers $0$ and $1$.
Unlike a decision tree, boxes can be shared, so a large function can have a small diagram.
For $x_1 \wedge x_2$: ask about $x_1$; if no, answer $0$; if yes, ask about $x_2$ and answer its value.
The size of the diagram can depend strongly on the order in which the variables are asked.
