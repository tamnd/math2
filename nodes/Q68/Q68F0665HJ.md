## Example

The distance between two lines is a least value over all pairs of points, so one pair of points only gives an upper bound.
A common error takes the distance between the base points of the two equations as the [[distance|C6GAS92QHX]] between the lines.
Let $L_1 = (1, 0, 0) + t(1, 1, 0)$ and $L_2 = (0, 0, 2) + s(0, 1, 1)$.

1. The base points are $a = (1, 0, 0)$ and $b = (0, 0, 2)$.
2. Their [[distance|0NPPGHQNXQ]] is $\|b - a\| = \|(-1, 0, 2)\| = \sqrt{5} \approx 2.24$.
3. The true distance between the lines is $\tfrac{1}{\sqrt{3}} \approx 0.58$, by the [[skew lines example|GQY9X52ZPJ]].
4. Another base point changes the value: with $a' = a + d = (2, 1, 0)$, the distance to $b$ is $\|(-2, -1, 2)\| = 3$.
5. So the distance between base points depends on how the lines are written, and it is not a property of the lines.

## Remarks

The same error can hide in parallel lines.
For $t(1, 0, 0)$ and $(0, 1, 0) + s(1, 0, 0)$, the base points are $1$ apart, and the lines are also $1$ apart.
That agreement holds only because the segment between these base points happens to be perpendicular to the lines.
With the base point $(5, 1, 0)$ for the second line, the same method would give $\sqrt{26}$.
For parallel lines the skew formula does not apply, since $d \times e = 0$, and the point-to-line formula gives the distance.

## Explanations

### L1 human

Two wires pass each other in space.
Two marks on the wires can be far apart even when the wires nearly touch.
The distance between the wires is the shortest bridge, not the bridge between two marks.

### L2 human

Here is a test for the error: change the base point of one line and see whether the answer changes.
A correct distance between lines does not depend on how the lines are written.
Watch out: for parallel lines, the base points give the correct value only if the segment between them is perpendicular to the lines.
