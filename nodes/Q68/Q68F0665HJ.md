## Example

Let $L_1 = (1, 0, 0) + t(1, 1, 0)$ and $L_2 = (0, 0, 2) + s(0, 1, 1)$.
A common error takes the distance between the base points as the [[distance|C6GAS92QHX]] between the lines.

1. The base points are $a = (1, 0, 0)$ and $b = (0, 0, 2)$.
2. Their [[distance|0NPPGHQNXQ]] is $\|b - a\| = \|(-1, 0, 2)\| = \sqrt{5} \approx 2.24$.
3. The true distance is $\tfrac{1}{\sqrt{3}} \approx 0.58$, by the [[skew lines example|GQY9X52ZPJ]].
4. Other base points change the value: with $a' = a + d = (2, 1, 0)$, the distance to $b$ is $\|(-2, -1, 2)\| = 3$.
5. So the distance between base points depends on the chosen equations, and it is not a property of the lines.

## Remarks

The distance between two sets is the least value over all pairs of points, so any pair gives only an upper bound.
The same error appears for parallel lines: for $t(1, 0, 0)$ and $(0, 1, 0) + s(1, 0, 0)$, the base points have the distance $1$, which is correct only by chance.
For parallel lines the skew formula fails, since $d \times e = 0$; the point-to-line formula gives the distance.

## Explanations

### L1 human

Two wires pass each other in space.
Two marks on the wires can be far apart even when the wires nearly touch.
The distance between the wires is the shortest bridge, not the bridge between two marks.

### L2 human

A test for the error: change the base point of one line, and see if the answer changes.
A correct distance between lines does not depend on how the lines are written.
A trap: for parallel lines, the base points give the correct value only if the segment between them is perpendicular to the lines.
