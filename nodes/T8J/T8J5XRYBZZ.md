## Summary

A state function is a quantity whose value depends only on the current equilibrium [[state|TD4C13V3J6]] of a system, not on how the system reached it.
Pressure, volume, temperature, internal energy and entropy are state functions.
The change of a state function in a process depends only on the initial and final states.
This makes state functions the main bookkeeping tools of thermodynamics.

## Explanations

### L1 human

Think of the height of a hiker on a mountain.
Her height at the summit does not depend on which trail she took, so the change in height is the same on every trail.
Height is like a state function.
The distance she walked does depend on the trail, so it is not a state function.
In thermodynamics, the internal energy of a gas plays the role of height, while heat and work play the role of distance walked.
