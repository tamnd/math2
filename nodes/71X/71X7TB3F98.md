## Definition

A formula is true in a structure when every assignment of values to its variables satisfies it.

Let $\mathcal{M}$ be an $L$-[[structure|983GZBQYT4]] and let $\varphi$ be an $L$-[[formula|HYJ10AF6RT]].
The formula $\varphi$ is true in $\mathcal{M}$, written $\mathcal{M} \models \varphi$, when $\mathcal{M} \models \varphi[s]$ for every variable assignment $s$ in $\mathcal{M}$, in the sense of [[satisfaction|1WTCZB4DVB]].
A [[sentence|DKFGQTRYZE]] $\sigma$ is false in $\mathcal{M}$ when it is not true in $\mathcal{M}$.
The theory of $\mathcal{M}$ is the set of $L$-sentences that are true in $\mathcal{M}$:
$$\operatorname{Th}(\mathcal{M}) = \{ \sigma : \sigma \text{ is an } L\text{-sentence and } \mathcal{M} \models \sigma \}.$$

## Notation

$\mathcal{M} \models \sigma$ is read "$\sigma$ is true in $\mathcal{M}$" or "$\mathcal{M}$ satisfies $\sigma$".
Some books define $\mathcal{M} \models \varphi$ only for sentences, and for sentences the two conventions agree.
In Mathlib, truth of a sentence is `FirstOrder.Language.Sentence.Realize`.

## Remarks

The definition asks for every assignment, and for a sentence that demand is easy to meet.
By the [[coincidence lemma|FM580NZ9W6]], all assignments give the same answer on a formula with no free variables.
So $\mathcal{M} \models \sigma$ holds if and only if some assignment satisfies $\sigma$, and every sentence is true or false in $\mathcal{M}$.
This uses that the domain is nonempty, so that at least one assignment exists.

For a formula with free variables $x_1, \ldots, x_n$, truth of $\varphi$ is the truth of its universal closure $\forall x_1 \cdots \forall x_n \, \varphi$.
Then a formula can be neither true nor false: $x < 1$ in $(\mathbb{N}, <)$ holds at $x \mapsto 0$ and fails at $x \mapsto 5$, as the [[example on free variables|WVR5YXJBM3]] shows.
The [[concept page on truth|K7XDVK5854]] gives the properties of $\operatorname{Th}(\mathcal{M})$ and the link to elementary equivalence.

## Explanations

### L1 human

A sentence is true in a structure when it holds there, with no letters left to fill in.
For example, "every number has a bigger number" is true for the whole numbers.
A formula with letters left over counts as true only when it holds for every way of filling in the letters.

### L2 human

We check the definition on the formula $\varphi = (x + 0 = x)$ in $\mathcal{M} = (\mathbb{Z}, +, 0)$.
Let $s$ be any assignment, and let $a = s(x)$.
The two sides of the equation get the values
$$(x + 0)^{\mathcal{M}}[s] = a + 0 = a, \qquad x^{\mathcal{M}}[s] = a,$$
so $\mathcal{M} \models \varphi[s]$ by the clause for equality.
Since $s$ was arbitrary, $\mathcal{M} \models \varphi$, and equivalently $\mathcal{M} \models \forall x \, (x + 0 = x)$.

The typical use is to state that an axiom holds in a structure.
Watch out: testing one assignment is not enough, since $x + x = x$ is satisfied at $x \mapsto 0$ but is not true in $(\mathbb{Z}, +, 0)$, because $1 + 1 \neq 1$.
