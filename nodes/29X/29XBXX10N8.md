## Example

Let $a_{m,n}$ for integers $m, n \geq 0$ be the entries of an infinite table:
$$a_{m,m} = 1, \qquad a_{m,m+1} = -1, \qquad a_{m,n} = 0 \text{ otherwise}.$$
Row $m$ has the entry $1$ in column $m$ and the entry $-1$ in column $m + 1$.
We show that the sum by rows and the sum by columns give different results, so the swap that [[double counting|0F8YBHF2W3]] makes is not valid here.

1. Row sums.
   Row $m$ has exactly two nonzero entries, $1$ and $-1$, so each row sum is $0$, and $\sum_{m} \sum_{n} a_{m,n} = 0$.
2. Column $0$.
   The only nonzero entry is $a_{0,0} = 1$, because $a_{m,0} = -1$ would need $m + 1 = 0$, so the sum of column $0$ is $1$.
3. Column $n \geq 1$.
   The nonzero entries are $a_{n,n} = 1$ and $a_{n-1,n} = -1$, so the sum of column $n$ is $0$.
4. So the column sums give
   $$\sum_{n} \sum_{m} a_{m,n} = 1 + 0 + 0 + \cdots = 1.$$
5. The two orders of summation give $0$ and $1$, so the double counting identity fails.
6. The condition that fails is finiteness.
   Double counting adds up the entries of a finite table, or non-negative entries, and this table is infinite with entries $-1$.

## Remarks

For a finite square of the table the two counts agree, as double counting says.
Take the entries with $0 \le m, n \le N$.
Rows $0$ to $N - 1$ have sum $0$, and row $N$ keeps only $a_{N,N} = 1$, because column $N + 1$ is outside the square, so the total by rows is $1$.
By columns, column $0$ gives $1$ and the columns $1$ to $N$ give $0$, so the total by columns is also $1$.
In the infinite table the entry $1$ of the last row moves off to infinity, and the sum by rows loses it.

The example shows why the [[interchange of summation order|MZM1AFXY82]] for infinite tables needs a hypothesis.
If $\sum_{m} \sum_{n} |a_{m,n}|$ is finite, or if all entries are non-negative, the two orders give the same sum.
Here $\sum_{n} |a_{m,n}| = 2$ for each of the infinitely many rows, so the sum of the absolute values is infinite.

## Explanations

### L1 human

Fill an endless grid with numbers: $1$ on the diagonal, $-1$ just to the right of each $1$, and $0$ everywhere else.
Each row contains one $1$ and one $-1$, so each row adds up to $0$.
The first column contains only one $1$, and every other column contains one $1$ and one $-1$.
So the columns add up to $1$ in total, while the rows add up to $0$.
Counting in two ways gives equal answers only for a finite grid, or for a grid with no negative numbers.

### L2 human

Here is the finite square with $N = 2$.
Its rows are
$$(1, -1, 0), \qquad (0, 1, -1), \qquad (0, 0, 1).$$
The row sums are $0$, $0$ and $1$, with total $1$.
The column sums are $1$, $0$ and $0$, with total $1$.
Both totals are $1$, because the square is a finite table.
The typical use of the example is a warning before you swap two infinite sums.
Watch out for the argument "each row sums to $0$, so the whole table sums to $0$": every finite square of the table has total $1$.
