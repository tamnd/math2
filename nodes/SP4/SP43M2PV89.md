## Example

The statement "every $u \le n$ has some $v \le n$ with $R(u, v)$" becomes a formula in conjunctive normal form, one clause for each $u$.
Let $R$ be a new binary relation symbol, and let $A(x)$ be the formula below.

$$A(x) := (\forall u \le x)(\exists v \le x)\, R(u, v)$$

It is a [[$\Delta_0(R)$ formula|GE43CSZTS9]], and it says that $R$ is total on $\{0, \dots, x\}$.
We compute its [[Paris-Wilkie translation|ZVD982MVST]] at $x = n$, with one variable $p_{i, j}$ for each atom $R(i, j)$.

1. The instance is $A(n) = (\forall u \le n)(\exists v \le n)\, R(u, v)$, and the bound $n$ is a closed term with the value $n$.
2. The universal quantifier becomes a conjunction over $i = 0, \dots, n$ of the translations of $(\exists v \le n)\, R(i, v)$.
3. Each existential quantifier becomes a disjunction over $j = 0, \dots, n$ of the translations of $R(i, j)$.
4. The atom $R(i, j)$ has the closed terms $i$ and $j$, so it becomes $p_{i, j}$.
5. Putting the steps together gives the following formula.

$$A(n)^{\mathrm{PW}} = \bigwedge_{i = 0}^{n} \bigvee_{j = 0}^{n} p_{i, j}$$

6. Size and depth: there are $n + 1$ clauses with $n + 1$ variables each, so $(n + 1)^2$ occurrences of variables, and the depth is $2$.
7. Truth: an assignment is a relation $X \subseteq \{0, \dots, n\}^2$.
   The formula is true if and only if every $i \le n$ has some $j \le n$ with $(i, j) \in X$, which is what $A(n)$ says.

For $n = 1$ the translation is $(p_{0,0} \lor p_{0,1}) \land (p_{1,0} \lor p_{1,1})$.

## Remarks

The example shows the pattern of the translation: each bounded quantifier gives one level of $\bigwedge$ or $\bigvee$, and each atom with $R$ gives one variable.
The formula $A(n)^{\mathrm{PW}}$ is not a [[tautology|05006AJ7DZ]], since the assignment with all variables false makes it false.
This matches the fact that $\forall x \, A(x)$ fails when $R$ is empty, so the Paris-Wilkie theorem has nothing to say about it.

Changing the formula changes the shape in a predictable way.
If the quantifiers are exchanged, $(\exists v \le n)(\forall u \le n)\, R(u, v)$ translates to $\bigvee_{j} \bigwedge_{i} p_{i, j}$, a formula in disjunctive normal form.
If the bound $n$ on $v$ is replaced by $n \cdot n$, each clause gets $n^2 + 1$ variables, so the size becomes $(n + 1)(n^2 + 1)$, which is still polynomial in $n$.

Watch out: give $p_{i, j}$ and $p_{j, i}$ different names.
The atoms $R(0, 1)$ and $R(1, 0)$ are different, and merging them would translate a different statement.

## Explanations

### L1 human

Take three people $0$, $1$, $2$, and the statement "each person likes somebody among the three".
Written out in full, it says: "$0$ likes $0$, $1$ or $2$; and $1$ likes $0$, $1$ or $2$; and $2$ likes $0$, $1$ or $2$".
Each part "$i$ likes $j$" is a switch that is on or off, so there are $9$ switches.
The written-out statement is true exactly when each of the three groups has a switch that is on.

### L2 human

We translate the same formula at $n = 2$ and test two assignments.
The translation has three clauses of three variables each:

$$(p_{0,0} \lor p_{0,1} \lor p_{0,2}) \land (p_{1,0} \lor p_{1,1} \lor p_{1,2}) \land (p_{2,0} \lor p_{2,1} \lor p_{2,2}).$$

First take $X = \{(0, 1), (1, 1), (2, 0)\}$.
The variables $p_{0,1}$, $p_{1,1}$ and $p_{2,0}$ are true, one in each clause, so the formula is true.
Next take $X = \{(0, 1), (1, 2)\}$.
The third clause has no true variable, so the formula is false.
Check: in $\mathbb{N}$ with $R$ read as the second $X$, the number $2$ has no $v \le 2$ with $R(2, v)$, so $A(2)$ is false, as the translation says.
The problem shows the typical use: one reads off the depth and the size of the translations before one applies a lower bound for bounded-depth proofs.
