## Definition

Let $x' = f(x, u)$, $y = h(x, u)$ be a [[control system|ZPDTVZQN5K]] with state space $X = \R^n$, input set $U \subseteq \R^m$ and outputs in $\R^p$.
Let $w \colon U \times \R^p \to \R$ be a function, the *supply rate*.
The system is *dissipative* with respect to $w$ if there is a *storage function* $V \colon X \to [0, \infty)$ with the following property.
For all $t_0 \le t_1$, every admissible input $u$, and every trajectory $x$ on $[t_0, t_1]$ with output $y$,
$$V(x(t_1)) \le V(x(t_0)) + \int_{t_0}^{t_1} w(u(t), y(t)) \, dt.$$
This inequality is the *dissipation inequality*.

## Remarks

If $V$ is continuously differentiable and $f$, $h$, $w$ are continuous, the dissipation inequality is equivalent to $\nabla V(x) \cdot f(x, u) \le w(u, h(x, u))$ for all $x \in X$ and $u \in U$.
Example: $x' = -x + u$, $y = x$ with $w(u, y) = uy$ and $V(x) = x^2/2$; here $\nabla V \cdot f = x(-x + u) = -x^2 + uy \le uy$, so the system is dissipative.
Non-example: the system $x' = 0$, $y = -u$ on $X = \R$ with $w(u, y) = uy = -u^2$ is not dissipative.
The state stays constant, so for $u = 1$ on $[0, 1]$ the inequality would give $V(x_0) \le V(x_0) - 1$.
With $m = p$ and $w(u, y) = u^T y$, dissipativity is called passivity.
When $u = 0$ and $w(0, y) \le 0$, a storage function does not increase along trajectories, which links storage functions with [[Lyapunov functions|01REYCJ371]].
