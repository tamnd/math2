## Summary

A state observer is an auxiliary dynamical system that estimates the internal state of a system from its known inputs and its measured outputs.
Its estimate converges to the true state as time goes on, whatever the unknown initial state.
Observers are needed because [[full state feedback|AWDQ3ES2S3]] uses the whole state, while sensors measure only some of it.
For linear systems an observer exists exactly when the system is detectable, and the standard design is the [[Luenberger observer|N1NX5VFS56]].

## Explanations

### L1 human

A pilot cannot see every quantity of an aircraft directly, but sees some instruments and knows the controls.
An observer is a computer model that runs alongside the real system, is fed the same controls, and keeps correcting itself by comparing its predicted readings with the real ones.
After a while its internal state matches the real one.
For a cart whose position is measured, an observer can recover the speed without a speed sensor.
