## Summary

Let $U \subset \R^n$ be an open set with smooth boundary.
Fix a boundary point $p$, and let $r$ be a defining function for $\partial U$ at $p$ with $r < 0$ on $U$.
The set $U$ is convex at $p$ when the second derivatives of $r$ at $p$ give a quadratic form that is nonnegative on every tangent vector of $\partial U$ at $p$.
That is, for $X_p = \sum_k a_k \partial/\partial x_k|_p$ tangent to the boundary, $\sum_{k,\ell} a_k a_\ell \, \partial^2 r/\partial x_k \partial x_\ell(p) \ge 0$.
The [[Hessian matrix|0693Y2METT]] of $r$ is tested only on the tangent space, not on all of $\R^n$.

The set $U$ is strongly convex at $p$ when this quadratic form is strictly positive for every nonzero tangent vector at $p$.

A domain is convex if it is convex at each boundary point.
A bounded domain is strongly convex if it is strongly convex at each boundary point.
For unbounded domains the word strongly is delicate, so some authors say strictly convex instead.
This is the differential test for a [[convex set|02AS45T3H9]] with smooth boundary.
