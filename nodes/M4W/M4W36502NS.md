## Definition

Let $m, n \ge 1$, let $A$ be a real $m \times n$ [[matrix|0VD9ZSWWJG]] and let $b \in \R^m$ lie in the image of $A$.
For $x \in \R^n$ let $\norm{x}_1 = \sum_{j=1}^n \abs{x_j}$ be the $\ell^1$ [[norm|0V2WP9B1MF]].
*Basis pursuit* is the optimization problem
$$\text{minimize } \norm{x}_1 \quad \text{subject to } A x = b, \quad x \in \R^n.$$
A *basis pursuit solution* is a vector $x^\sharp$ with $A x^\sharp = b$ and $\norm{x^\sharp}_1 \le \norm{x}_1$ for every $x$ with $A x = b$.

## Remarks

A minimizer always exists, because the feasible set is nonempty and closed and the norm grows without bound.
Writing $x = u - v$ with $u, v \ge 0$ turns the problem into the [[linear program|VNMXB0J2KA]]: minimize $\sum_j (u_j + v_j)$ subject to $A(u - v) = b$, $u, v \ge 0$.

Example: let $A = (1 \;\; 1 \;\; 2)$ and $b = 2$.
For any $x$ with $x_1 + x_2 + 2x_3 = 2$, we have $\norm{x}_1 \ge \frac12 (\abs{x_1} + \abs{x_2} + 2\abs{x_3}) \ge \frac12 \abs{x_1 + x_2 + 2x_3} = 1$.
Equality forces $x_1 = x_2 = 0$, so the unique basis pursuit solution is $x^\sharp = (0, 0, 1)$, which is $1$-sparse.

Non-example: minimizing the Euclidean norm $\norm{x}_2$ instead of $\norm{x}_1$ under the same constraint gives the least-norm solution $x = A^T (A A^T)^{-1} b = (\frac13, \frac13, \frac23)$.
It is not a basis pursuit solution, since its $\ell^1$ norm is $\frac43 > 1$, and it has no zero entry.

The name and the method go back to Chen, Donoho and Saunders.
A variant for noisy data, basis pursuit denoising, minimizes $\frac12 \norm{Ax - b}_2^2 + \lambda \norm{x}_1$ with a parameter $\lambda > 0$.
