## Summary

The random oracle model is an idealized setting for security proofs, in which every party can query a truly random function.
In a real scheme this function is replaced by a concrete [[cryptographic hash function|XJ8F3NQMGN]], such as SHA-256.
Mihir Bellare and Phillip Rogaway proposed it as a paradigm in 1993.
Proofs in the model give strong evidence of good design, but they are not proofs about the real scheme.
Indeed, some schemes are secure in the model and insecure with every concrete hash function.

## Explanations

### L1 human

Imagine a box in the sky that answers every question with a fresh random string, and always gives the same answer to the same question.
Everyone, including the attacker, may ask the box questions, but nobody can predict an answer without asking.
Many cryptographic schemes are easy to prove secure if their hash function behaves like this box.
In practice the box is a hash function, and one hopes that it is random enough.
