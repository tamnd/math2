## Example

The property that makes $\mathbb{R}$ complete cannot be written in [[first-order logic|086QKPF0A6]] over the real numbers.
Take the signature $\sigma = \{ +, \cdot, -, 0, 1, < \}$ of [[ordered fields|0P3VCBDEE2]].
An ordered field $F$ has the least upper bound property when every nonempty subset of $F$ that is bounded above has a [[supremum|0R3H5PANRQ]] in $F$.
We show that this property is not first-order, first in its form and then in a stronger sense.

1. The property begins with "for every subset $A$ of $F$".
   That quantifier ranges over subsets of the domain, so it is a quantifier of [[second-order logic|G6X7SZSNC5]].
2. A first-order formula of $\sigma$ quantifies only over elements, so the natural form is not a first-order sentence.
3. The stronger claim is that no set $\Sigma$ of first-order $\sigma$-sentences has as its models exactly the ordered fields with the property.
   Suppose, for a contradiction, that such a $\Sigma$ exists.
4. Every ordered field with the least upper bound property is isomorphic to $\mathbb{R}$, so the models of $\Sigma$ are exactly the ordered fields isomorphic to $\mathbb{R}$.
5. The signature $\sigma$ is finite, so there are only [[countably many|01TQB88H4C]] $\sigma$-sentences, and $\Sigma$ is countable.
6. The set $\Sigma$ has the infinite model $\mathbb{R}$, so by the downward [[Löwenheim-Skolem theorem|484M0TZ1S7]] it has a countable model $\mathcal{M}$.
7. By step 4, $\mathcal{M}$ is isomorphic to $\mathbb{R}$.
   An isomorphism is a bijection, and $\mathbb{R}$ is uncountable, so this is a contradiction.

So no set of first-order sentences in the language of ordered fields expresses the least upper bound property.

## Remarks

In second-order logic the property is one sentence:
$$\forall A \, \Big( \big(\exists x \, A(x) \land \exists b \, \forall x \, (A(x) \to x \le b)\big) \to \exists s \, \forall c \, \big(\forall x \, (A(x) \to x \le c) \leftrightarrow s \le c\big) \Big),$$
where $A$ is a variable for unary relations and $u \le w$ is short for $u < w \lor u = w$.
The last part says that the upper bounds of $A$ are exactly the elements above $s$, so $s$ is the least upper bound.

The proof above uses only that $\sigma$ is countable and that $\mathbb{R}$ is uncountable.
The same argument shows that no set of sentences in a countable signature pins down an uncountable structure up to isomorphism.

In ZFC set theory the property becomes first-order again, because subsets of $\mathbb{R}$ are elements of the universe of sets.
That move changes the domain: the variables then range over all sets, not over real numbers.

## Explanations

### L1 human

The least upper bound property says that every bounded set of real numbers has a smallest upper bound.
It talks about all sets of numbers, not only about numbers.
First-order logic can say "for every number" but not "for every set of numbers".
So the property cannot be written as a first-order sentence about numbers.
For example, the fractions $x$ with $x^2 < 2$ have no smallest upper bound among the fractions, but they have one among the real numbers, namely $\sqrt{2}$.

### L2 human

The natural first-order attempt replaces "every subset" by "every subset defined by a formula".
For each formula $\varphi(x)$, one axiom says: if $\varphi$ defines a nonempty set that is bounded above, then that set has a supremum.
These infinitely many axioms are first-order, one for each $\varphi$, and they hold in $\mathbb{R}$, because every subset of $\mathbb{R}$, defined or not, has a supremum.
But by steps 5 and 6 of the example they also hold in a countable ordered field, which cannot be isomorphic to $\mathbb{R}$.
A concrete such field is the field $\mathbb{R}_{\mathrm{alg}}$ of real algebraic numbers.
By Tarski's theorem on real closed fields it satisfies the same first-order sentences as $\mathbb{R}$, and it is countable.
In $\mathbb{R}_{\mathrm{alg}}$ the set of $x$ with $x < \pi$ is bounded above and has no supremum, and no formula defines it there.
Watch out: the schema "for every formula" is weaker than "for every subset", because a countable language has countably many formulas and $\mathbb{R}$ has uncountably many subsets.
