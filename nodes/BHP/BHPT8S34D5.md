## Statement

In number theory, the **Chinese hypothesis** is a disproven conjecture stating that an [[integer|0C4JS9RF5M]] *n* is [[prime|01826KMG2H]] if and only if it satisfies the condition that $2^n-2$ is divisible by *n*—in other words, that an integer *n* is prime if and only if $2^n \equiv 2 \bmod{n}$. It is true that if *n* is prime, then $2^n \equiv 2 \bmod{n}$ (this is a special case of [[Fermat's little theorem|0M25PRN3WQ]]), however the [[converse|09A3N7ZN5G]] (if $2^n \equiv 2 \bmod{n}$ then *n* is prime) is false, and therefore the hypothesis as a whole is false. The smallest counterexample is *n* = 341 = 11×31. [[Composite numbers|008BH74D7R]] *n* for which $2^n-2$ is divisible by *n* are called Poulet numbers. They are a special class of Fermat pseudoprimes.
