## Summary

A Chebyshev set in a normed space is a set from which every point has exactly one [[best approximation|7N4988HN3P]].
On a Chebyshev set the map sending each point to its nearest point, the metric projection, is well defined.
Closed convex sets in Hilbert spaces are the main examples.
The question of which Chebyshev sets are convex is a classical problem of geometry of normed spaces.

## Explanations

### L1 human

Stand anywhere in the plane and look for the nearest point of a set.
If there is always exactly one nearest point, the set is a Chebyshev set.
A line, a filled disc or a filled square in the plane has this property.
A circle does not: from its centre all points of the circle are equally near.
