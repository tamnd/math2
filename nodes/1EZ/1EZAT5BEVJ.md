## Summary

In mathematics, a **cofinite** [[subset|0BJR9QR08E]] of a set $X$ is a subset $A$ whose [[complement|0RKF1ZT5JJ]] in $X$ is a [[finite set|070R982G4B]]. In other words, $A$ contains all but finitely many elements of $X.$ If the complement is not finite, but is countable, then one says the set is cocountable.
