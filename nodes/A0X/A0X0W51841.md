## Example

Let $\operatorname{Prf}(z, y)$ be the [[primitive recursive relation|QQQRJA90EP]] "$z$ codes a PA-proof of the formula with code $y$", and let $A(x)$ be $\neg \operatorname{Prf}(x, \ulcorner 0 = 1 \urcorner)$.
Then $\forall x \, A(x)$ is the [[consistency|VM8TQ70CVJ]] sentence $\operatorname{Con}(\mathrm{PA})$.
We check that PA proves every premise of an ω-rule for this formula but not its conclusion.

1. PA is consistent, so no $n$ codes a PA-proof of $0 = 1$, and each sentence $A(\bar n)$ is true.
2. Each $A(\bar n)$ is a closed instance of a primitive recursive relation.
   [[Peano arithmetic|0QFT7Z76N5]] proves every true closed instance of such a relation, by carrying out the computation of its value.
3. So PA proves $A(\bar 0)$, $A(\bar 1)$, $A(\bar 2)$, and so on.
4. PA does not prove $\forall x \, A(x)$, by [[Gödel's second incompleteness theorem|4PZM5GJTR5]].
5. So the premises of one application of the [[ω-rule|XAMKAB1BZM]] are PA-theorems, and its conclusion is not.

## Remarks

The example shows that the ω-rule is stronger than any finite proof system for arithmetic.
Closing PA under the ω-rule, even once for every formula, already gives sentences such as $\operatorname{Con}(\mathrm{PA})$.
Closing it under the rule as often as needed gives all true arithmetic sentences, and that set is not recursively axiomatizable.
So the ω-rule serves as a tool for analyzing PA from outside, not as a rule of PA.

The theory $\mathrm{PA} + \neg\operatorname{Con}(\mathrm{PA})$ goes one step further wrong.
It is consistent, and it proves every $A(\bar n)$, but it also proves $\exists x \, \neg A(x)$.
A theory of this kind is called ω-inconsistent.

## Explanations

### L1 human

For each number $n$, Peano arithmetic can check that $n$ is not the code of a proof of a contradiction.
It cannot prove the single statement that no number is such a code, by Gödel's theorem.
So in Peano arithmetic "true for each number separately" does not give "true for all numbers", and that step is exactly the ω-rule.

### L2 human

We follow one instance.
Take a number $n$, say $n = 1000$.
Since PA is consistent, $1000$ does not code a PA-proof of $0 = 1$.
PA evaluates $\operatorname{Prf}(\overline{1000}, \ulcorner 0 = 1 \urcorner)$ to false in finitely many steps, so it proves $A(\overline{1000})$.
The same works for every $n$, but each $n$ needs its own proof, and the proofs get longer as $n$ grows.

The typical use is to show that no consistent, recursively axiomatized theory that contains PA is closed under the ω-rule.
Watch out: the infinitely many proofs do not combine into one proof, since a proof is finite and must cover all $n$ by one argument.
