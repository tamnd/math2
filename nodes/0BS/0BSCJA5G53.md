## Example

Let $\mathbb{Z} = \{\ldots, -2, -1, 0, 1, 2, \ldots\}$ be the set of [[integers|0C4JS9RF5M]], with the usual addition $+$.
We check that $(\mathbb{Z}, +)$ is an [[abelian group|082GHNPJ53]], that it is [[cyclic|0KVGH0J5B3]], and we find its [[subgroups|0X1JXT47GA]].

1. Closure. The sum of two integers is an integer.
2. Associativity. $(a + b) + c = a + (b + c)$ for all integers, by the rules of arithmetic.
3. Identity. $n + 0 = 0 + n = n$ for each $n$, so $0$ is the identity element.
4. Inverses. $n + (-n) = (-n) + n = 0$, and $-n$ is an integer. So $-n$ is the inverse of $n$.
5. Commutativity. $m + n = n + m$ for all integers. So $(\mathbb{Z}, +)$ is abelian.
6. Cyclic. For $n > 0$, $n = 1 + \cdots + 1$ with $n$ terms. For $n < 0$, $n = -(1 + \cdots + 1)$ with $-n$ terms. Also $0 = 0 \cdot 1$. So $\mathbb{Z} = \langle 1 \rangle$.
7. Infinite. The multiples $1, 2, 3, \ldots$ of $1$ are all different, so $1$ has infinite [[order|0WE2NHZJ7B]], and $\mathbb{Z}$ is an [[infinite cyclic group|02B1T50JD1]].
8. Generators. If $\langle g \rangle = \mathbb{Z}$, then $1 = kg$ for some integer $k$. So $g$ divides $1$, and $g = 1$ or $g = -1$. Both of them generate $\mathbb{Z}$.

The subgroups of $\mathbb{Z}$ are the sets $n\mathbb{Z} = \{nk : k \in \mathbb{Z}\}$ for $n \geq 0$, by the [[classification of subgroups of the integers|0SRATCFF1W]].
Here is a sketch of the [[proof|BVTYBWDST2]].

9. Let $H$ be a subgroup. If $H = \{0\}$, then $H = 0\mathbb{Z}$.
10. Otherwise $H$ has an element $h \neq 0$. Then $h$ or $-h$ is positive, and both are in $H$. Let $n$ be the least positive element of $H$.
11. Each multiple $nk$ is in $H$, because $H$ is closed under addition and inverses. So $n\mathbb{Z} \subseteq H$.
12. Let $h \in H$. By the [[division algorithm|0CHQKZFK5S]], $h = qn + r$ with integers $q, r$ and $0 \leq r < n$.
13. Then $r = h - qn$ is in $H$. Since $r < n$ and $n$ is the least positive element of $H$, we get $r = 0$.
14. So $h = qn \in n\mathbb{Z}$, and $H = n\mathbb{Z}$.

## Remarks

For $n \neq 0$, the map $k \mapsto nk$ is an [[isomorphism|08MG7H8JW5]] from $\mathbb{Z}$ to $n\mathbb{Z}$.
It is a [[homomorphism|0JYTG5K9Y4]], because $n(k + l) = nk + nl$; it is injective, because $nk = nl$ gives $k = l$; and it is onto $n\mathbb{Z}$ by the definition of $n\mathbb{Z}$.
So each subgroup of $\mathbb{Z}$ other than $\{0\}$ is isomorphic to $\mathbb{Z}$.
The quotients $\mathbb{Z}/n\mathbb{Z}$ are the [[integers modulo n|0YJ3WRR9RY]].

The group $\mathbb{Z}$ is the [[free group|0KTW26C80J]] on one generator.
For each group $G$ and each $g \in G$, there is exactly one homomorphism $\varphi \colon \mathbb{Z} \to G$ with $\varphi(1) = g$, namely $\varphi(k) = g^k$.
The map is a homomorphism by the [[laws of exponents|00DRK90Z6K]], $g^{k + l} = g^k g^l$.
It is the only one, because a homomorphism with $\varphi(1) = g$ has $\varphi(k) = g^k$ for $k > 0$, $\varphi(0) = e$ and $\varphi(-k) = \varphi(k)^{-1}$.
So each infinite cyclic group is isomorphic to $\mathbb{Z}$.

Two related structures are not groups.
[[The natural numbers under addition are not a group|R68D2P175Z]], because $1$ has no inverse in $\mathbb{N} = \{0, 1, 2, \ldots\}$.
[[The integers under multiplication are not a group|NH7XE98CMF]], because $2$ has no inverse: $2k = 1$ has no integer solution $k$.

## Explanations

### L1 human

The integers with addition are the first example of a group for most students.
Adding is associative, $0$ changes nothing, and $-n$ undoes $n$.
Each integer is a sum of copies of $1$ or of $-1$, so the single number $1$ builds the whole group.
The whole numbers $0, 1, 2, \ldots$ alone do not form a group, because we cannot undo $+1$ without $-1$.

### L2 human

We find the subgroup generated by $4$ and $6$, the smallest subgroup that contains both.

1. The subgroup has the form $n\mathbb{Z}$, and $n$ is its least positive element.
2. It contains $6 - 4 = 2$, so $n \leq 2$.
3. The set of all sums $4a + 6b$ with $a, b \in \mathbb{Z}$ is a subgroup that contains $4$ and $6$. So the subgroup lies in this set.
4. Each sum $4a + 6b$ is even, so $1$ is not in the subgroup. Thus $n = 2$.

So the subgroup generated by $4$ and $6$ is $2\mathbb{Z}$, and $2 = \gcd(4, 6)$, the [[greatest common divisor|0C8WYW4KYQ]].
In general, the subgroup generated by $a$ and $b$ is $d\mathbb{Z}$ with $d = \gcd(a, b)$.
A trap is to think that $\mathbb{Z}$ has a finite subgroup other than $\{0\}$: each $n\mathbb{Z}$ with $n \neq 0$ is infinite.
