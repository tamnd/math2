## Example

The [[Fano plane|QQ8GW1ASZM]] has the $7$ points $1, 2, \dots, 7$ and the $7$ lines
$$\set{1,2,3},\ \set{1,4,5},\ \set{1,6,7},\ \set{2,4,6},\ \set{2,5,7},\ \set{3,4,7},\ \set{3,5,6}.$$
Each line has $3$ points, and each pair of distinct points lies on exactly one line.
We use [[double counting|0F8YBHF2W3]] twice to find the number of lines through each point, with no list of these lines.

1. Let $R$ be the set of pairs $(p, L)$ where $p$ is a point, $L$ is a line, and $p \in L$. These pairs are the incidences.
2. Count $R$ by lines. There are $7$ lines, and each line has $3$ points. So $|R| = 7 \cdot 3 = 21$.
3. Count $R$ by points. If $r_p$ is the number of lines through $p$, then $|R| = r_1 + r_2 + \cdots + r_7$.
4. So $r_1 + \cdots + r_7 = 21$, and the mean of the numbers $r_p$ is $3$. This count alone does not show that each $r_p$ equals $3$.
5. Fix a point $p$. Let $T$ be the set of pairs $(q, L)$ where $q \neq p$ is a point and $L$ is a line that contains both $p$ and $q$.
6. Count $T$ by points $q$. Each of the $6$ points $q \neq p$ lies on exactly one line with $p$. So $|T| = 6$.
7. Count $T$ by lines $L$. Each of the $r_p$ lines through $p$ has $3 - 1 = 2$ points other than $p$. So $|T| = 2 r_p$.
8. So $2 r_p = 6$, and $r_p = 3$ for each point $p$.
9. Check with the list: the point $1$ lies on $\set{1,2,3}$, $\set{1,4,5}$ and $\set{1,6,7}$, and the point $5$ lies on $\set{1,4,5}$, $\set{2,5,7}$ and $\set{3,5,6}$.

In the language of the [[incidence matrix|9DNFN8M83X]], the $7 \times 7$ matrix with rows for points and columns for lines has $21$ entries $1$, and each row sum and each column sum is $3$.

## Remarks

The example shows the two levels of the technique.
The first count gives only the mean of the numbers $r_p$.
The second count uses the rule "two points lie on one line", and it gives each $r_p$ exactly.

The same counts work with parameters.
Let a finite set of $v$ points carry $b$ lines with $k$ points each, such that each pair of distinct points lies on exactly $\lambda$ lines.
Steps 5 to 8 give $r(k - 1) = \lambda(v - 1)$ for the number $r$ of lines through each point, and steps 1 to 3 then give $bk = vr$.
These are the two basic identities of [[block designs|4JCSS2Z1BA]].
For the Fano plane, $v = b = 7$, $k = 3$ and $\lambda = 1$, so $r = 6/2 = 3$ and $b = 7 \cdot 3 / 3 = 7$.
If we change $k$ to $4$ with $\lambda = 1$, the identities need $3r = v - 1$ and $4b = vr$; for $v = 13$ they give $r = 4$ and $b = 13$, the projective plane of order $3$.

## Explanations

### L1 human

Seven points are joined by seven "lines", and each line passes through three points.
If we count, line by line, how many points lie on the lines, we get $7 \times 3 = 21$.
If we count the same thing point by point, we add up the number of lines through each point.
Both counts give the same total $21$.
So, on average, each of the $7$ points lies on $3$ lines.

### L2 human

We repeat the second count of the example for the point $p = 4$.

1. The points other than $4$ are $1, 2, 3, 5, 6, 7$.
2. The line through $4$ and $1$ is $\set{1,4,5}$, through $4$ and $2$ is $\set{2,4,6}$, and through $4$ and $3$ is $\set{3,4,7}$.
3. The points $5$, $6$ and $7$ are on these same lines: $\set{1,4,5}$, $\set{2,4,6}$ and $\set{3,4,7}$.
4. So the $6$ other points come in $3$ groups of $2$, one group for each line through $4$.
5. Hence $2 r_4 = 6$ and $r_4 = 3$.

The typical use of such counts is to find the parameters of a design before we try to build it.
If the identities give a value of $r$ or $b$ that is not an integer, no design with those parameters exists.
A trap is to read step 4 of the example as a proof that each point is on $3$ lines: a mean of $3$ allows the values $2$ and $4$.
