## Example

The [[normal modal logic|D1TJYZZDCY]] $\mathsf{K}$ has the formulas of classical propositional logic and one more connective $\Box$.
Its theorems are generated by all [[tautologies|05006AJ7DZ]], the axiom $\Box(p \to q) \to (\Box p \to \Box q)$, modus ponens, uniform substitution and necessitation (from $\varphi$ infer $\Box\varphi$).
We show that $\mathsf{K}$ is an [[extension|3JK7T9D6X1]] of classical logic: a formula $\varphi$ without $\Box$ is a theorem of $\mathsf{K}$ if and only if $\varphi$ is a tautology.
So $\mathsf{K}$ is a [[conservative extension|N238J43XNE]] of classical propositional logic.

1. If $\varphi$ is a tautology, then $\varphi$ is an axiom of $\mathsf{K}$, so it is a theorem.
2. Conversely, let $\varphi$ be a box-free theorem of $\mathsf{K}$. By the soundness of $\mathsf{K}$ for [[Kripke semantics|NGHWZ9Y7ZV]], $\varphi$ is true at every world of every Kripke model.
3. Let $v$ be any classical valuation. Build the model with one world $w$, the empty accessibility relation, and $p$ true at $w$ exactly when $v(p) = 1$.
4. For a box-free formula, truth at $w$ is computed by the classical truth tables, because the clauses for $\neg, \land, \lor, \to$ at one world are the classical clauses.
5. So $v(\varphi) = 1$ by steps 2 and 4. Since $v$ was arbitrary, $\varphi$ is a tautology.

The language has new formulas such as $\Box p$, and the new theorems such as $\Box(p \to p)$ all contain $\Box$.

## Remarks

The example shows the pattern of an extension: new vocabulary, new theorems about it, and no change on the old vocabulary.
The same proof works for every normal modal logic that has a one-world model, for example $\mathsf{T}$ and $\mathsf{S5}$ with the reflexive one-world frame.
It fails for a logic whose axioms force interaction with the old connectives, but such logics are not normal modal logics.

## Explanations

### L1 human

Modal logic adds the word "necessarily" to ordinary logic.
It does not change the meaning of "and", "or" and "not".
So every statement that uses only the old words keeps its old status: if it is always true in ordinary logic, it is a theorem of modal logic, and conversely.
The new theorems are about the new word, such as "necessarily, if it rains then it rains".

### L2 human

We check that the box-free formula $p \to (q \to p)$ is a theorem of $\mathsf{K}$ and that $p \to q$ is not.

1. The truth table of $p \to (q \to p)$ has value T in all four rows, so it is a tautology and an axiom of $\mathsf{K}$.
2. The formula $p \to q$ is false under the valuation $v(p) = 1$, $v(q) = 0$.
3. The one-world model of step 3 above with this valuation makes $p \to q$ false at $w$.
4. By soundness, $p \to q$ is not a theorem of $\mathsf{K}$.

The typical use is to check that a modal logic is a safe addition to classical logic.
A trap is to think that "extension" means "proves more formulas in the old language"; a conservative extension proves no new old-language formula.
