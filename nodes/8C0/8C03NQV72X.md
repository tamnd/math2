## Definition

Let $C$ be a [[linear code|E85KREWV60]] of length $n$ and dimension $k \ge 1$ over the finite field $\F_q$.
A *generator matrix* of $C$ is a $k \times n$ [[matrix|0VD9ZSWWJG]] $G$ with entries in $\F_q$ whose [[row space|069MCGX635]] is $C$.
Equivalently, the rows of $G$ form a basis of $C$, so $G$ has [[rank|0ZC9YTXZRY]] $k$ and
$$C = \set{mG : m \in \F_q^k}.$$

## Remarks

Example: over $\F_2$, the matrix
$$G = \begin{pmatrix} 1 & 0 & 1 \\ 0 & 1 & 1 \end{pmatrix}$$
has rank $2$, and its row space is $\set{000, 101, 011, 110}$, so $G$ is a generator matrix of this $[3, 2, 2]$ code.
Non-example: the matrix with rows $101$, $011$, $110$ spans the same code but is not a generator matrix.
Its $3$ rows are linearly dependent, while a generator matrix of a $2$-dimensional code has $2$ rows.
A code has many generator matrices: if $G$ is one, then the others are $AG$ with $A$ an invertible $k \times k$ matrix.
A generator matrix of the form $G = (I_k \mid P)$, with $I_k$ the identity matrix and $P$ a $k \times (n - k)$ matrix, is said to be in standard form.
After a permutation of the coordinates every linear code has a generator matrix in standard form, by Gaussian elimination.
