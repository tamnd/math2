## Example

Let $\mathrm{PA}^2$ be second-order Peano arithmetic over $\set{0, S}$, with the axioms (P1), (P2) and the induction axiom (P3) of the [[categoricity example|CKEG6B25AN]].
Write $\underline{n}$ for the term $S(S(\cdots S(0)))$ with $n$ copies of $S$.
We show that $\mathrm{PA}^2$ has a [[Henkin model|KWEJFK5943]] that is not isomorphic to $\mathbb{N}$.

1. Add a new constant $c$, and let $T = \set{\text{(P1)}, \text{(P2)}, \text{(P3)}} \cup \set{c \neq \underline{n} : n \in \mathbb{N}}$.
2. Let $T_0 \subseteq T$ be finite, and let $N$ be larger than every $n$ with $c \neq \underline{n} \in T_0$.
3. The full structure over $(\mathbb{N}, 0, n \mapsto n + 1)$, with $c$ read as $N$, satisfies (P1), (P2) and (P3), and it satisfies $c \neq \underline{n}$ for each $n < N$.
4. A full structure is a Henkin model, by the [[example on full structures|J5YH6PWPDX]]. So $T_0$ has a Henkin model.
5. Compactness holds for the Henkin semantics, as the [[definition page|KWEJFK5943]] explains. So $T$ has a Henkin model $\mathfrak{M} = (\mathcal{M}, (D_n))$.
6. Let $B = \set{\underline{n}^{\mathcal{M}} : n \in \mathbb{N}}$. Then $0^{\mathcal{M}} \in B$, and $B$ is closed under $S^{\mathcal{M}}$.
7. The element $c^{\mathcal{M}}$ is not in $B$, since $\mathfrak{M}$ satisfies $c \neq \underline{n}$ for every $n$.
8. If $B$ belonged to $D_1$, then (P3) with $X = B$ would give $B = M$, which contradicts step 7. So $B \notin D_1$.
9. In a structure isomorphic to $\mathbb{N}$, every element is the value of a term $\underline{n}$. Step 7 shows that this fails in $\mathcal{M}$, so $\mathcal{M}$ is not isomorphic to $\mathbb{N}$.

## Remarks

The model $\mathfrak{M}$ satisfies (P3), but (P3) only speaks about the sets in $D_1$.
The set $B$ of standard elements is missing from $D_1$, so induction cannot reach it.
This is the exact point where the categoricity proof for the full semantics breaks down.

By the Löwenheim-Skolem theorem for the Henkin semantics, we can take $M$ and each $D_n$ countable.
Then $D_1$ is a countable family of subsets of $M$, and it cannot be all of $\mathcal{P}(M)$, by Cantor's theorem.

When $T$ also contains the comprehension instances and the recursion equations for $+$ and $\cdot$, the same argument gives a non-standard model of the first-order theory [[second-order arithmetic|DC60FYCSPM]].
Its number part is then a [[non-standard model of arithmetic|1QWN5CV4CG]].

## Explanations

### L1 human

The second-order rule of induction says: every allowed set that contains $0$ and is closed under "add one" contains every number.
In the Henkin meaning, a model chooses which sets are allowed.
A model can contain an extra element $c$ that we never reach from $0$ by adding one.
It survives because the set of ordinary numbers $0, 1, 2, \ldots$ is not on its list of allowed sets.
So the rule of induction never applies to that set.

### L2 human

We check step 3 for the finite set $T_0 = \set{\text{(P1)}, \text{(P3)}, c \neq \underline{2}, c \neq \underline{5}}$.

1. Take $N = 6$, and read $c$ as $6$ in $\mathbb{N}$.
2. (P1) holds: $n + 1 \neq 0$ for every $n \in \mathbb{N}$.
3. (P3) holds in the full structure: a set $X \subseteq \mathbb{N}$ with $0 \in X$ and closed under $n \mapsto n + 1$ is $\mathbb{N}$, by induction in $\mathbb{N}$.
4. The term $\underline{2}$ has the value $2$, and $\underline{5}$ has the value $5$. Both differ from $6$.

The typical use of this example is to show that the Henkin semantics, unlike the full semantics, cannot fix the natural numbers up to isomorphism.
The trap is to think that $\mathfrak{M}$ fails induction: it satisfies (P3), because its family $D_1$ is smaller than $\mathcal{P}(M)$.
