## Example

A map can match the points of a space one to one and still fail to respect sums, and then it is not a linear isomorphism.
Let $f \colon \R \to \R$ be $f(x) = x^3$.

1. The map $f$ is [[bijective|0SNQEF7Z53]], since it is strictly increasing with inverse $y \mapsto \sqrt[3]{y}$.
2. It is not additive, since $f(1 + 1) = 8$ while $f(1) + f(1) = 2$.
3. It is not homogeneous, since $f(2 \cdot 1) = 8$ while $2 f(1) = 2$.
4. So $f$ is not a [[linear map|0RJF668P1T]], and it is not a [[linear isomorphism|0XSJ25Z9M4]].

## Remarks

A bijection between vector spaces is a linear isomorphism only if it is also linear.
The map $f$ does respect the zero vector and negatives, since $f(0) = 0$ and $f(-x) = -f(x)$, so these two tests do not detect the failure.
It is also a homeomorphism of $\R$, so it is an isomorphism of topological spaces, but not of vector spaces.

If we replace $x^3$ by $3x$, the map becomes linear and bijective, with inverse $y \mapsto y / 3$, and it is a linear isomorphism.

## Explanations

### L1 human

Cubing is a one-to-one matching of the real numbers with themselves.
But it does not respect sums, since $2^3 = 8$ and $1^3 + 1^3 = 2$.
So it is not a linear isomorphism.

### L2 human

The example separates the two parts of the definition: bijective and linear.
Both are needed, and neither implies the other.
Watch out: do not call every invertible map between vector spaces an isomorphism of vector spaces.
