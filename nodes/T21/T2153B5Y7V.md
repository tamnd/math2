## Proof

Let $A$ be an $n \times n$ matrix over a commutative ring $R$ in which $2$ is invertible.

1. Existence: put $S = \tfrac12 (A + A^{\mathsf{T}})$ and $K = \tfrac12 (A - A^{\mathsf{T}})$. These make sense because $\tfrac12 \in R$.
2. The [[transpose|0W809K6AW0]] is additive, commutes with scalars and satisfies $(A^{\mathsf{T}})^{\mathsf{T}} = A$. So $S^{\mathsf{T}} = \tfrac12 (A^{\mathsf{T}} + A) = S$, and $S$ is [[symmetric|0N28QN4CYA]].
3. By the same rules, $K^{\mathsf{T}} = \tfrac12 (A^{\mathsf{T}} - A) = -K$, so $K$ is [[skew-symmetric|03RNVFDEAN]].
4. Also $S + K = \tfrac12 A + \tfrac12 A^{\mathsf{T}} + \tfrac12 A - \tfrac12 A^{\mathsf{T}} = A$.
5. Uniqueness: suppose $A = S' + K'$ with $S'$ symmetric and $K'$ skew-symmetric.
6. Transposing gives $A^{\mathsf{T}} = S'^{\mathsf{T}} + K'^{\mathsf{T}} = S' - K'$.
7. Add the equations of steps 5 and 6: $A + A^{\mathsf{T}} = 2S'$. Since $2$ is invertible, $S' = \tfrac12 (A + A^{\mathsf{T}}) = S$.
8. Subtract them: $A - A^{\mathsf{T}} = 2K'$, so $K' = K$.
9. So the decomposition exists and is unique.

## Idea

Transposing $A = S + K$ gives $A^{\mathsf{T}} = S - K$.
These are two linear equations in $S$ and $K$, and we solve them by adding and subtracting.
The solution needs division by $2$.

## Variants

- Uniqueness is the statement $\operatorname{Sym}_n \cap \operatorname{Skew}_n = 0$. If $M^{\mathsf{T}} = M$ and $M^{\mathsf{T}} = -M$, then $2M = 0$, so $M = 0$.
