## Summary

A recursively enumerable language is a [[formal language|5MFZ4VNY6D]] whose members are exactly the inputs on which some [[Turing machine|758EYCN27B]] halts and accepts.
Such languages are also called Turing-recognizable or semi-decidable.
On inputs outside the language, the machine may reject or run forever.
Equivalently, some machine lists the members of the language one after another.
These languages are the top level of the Chomsky hierarchy, generated by unrestricted grammars, and they correspond to the [[computably enumerable sets|TN9G24VABN]] of natural numbers.

## Explanations

### L1 human

For a recursively enumerable language, a program confirms membership but may never confirm non-membership.
If the string belongs, the program eventually says yes.
If it does not, the program may say no, or may keep running, and one never knows whether a yes is still coming.
The set of programs that halt is the main example: run the program, and if it stops, say yes.
