## Statement

Consider the following decision problem.
Given an integer $m \times n$ matrix $A$ and an integer vector $b \in \Z^m$, decide whether there is a vector $x \in \set{0, 1}^n$ with $A x \le b$.
This problem is [[NP-complete|JGZWHWA8P8]].
Consequently, the problem of optimizing a linear function over the integer solutions of a system of linear inequalities is [[NP-hard|MHA48AWBXN]].

## Remarks

Idea of the proof.
The problem is in NP, since a vector $x \in \set{0, 1}^n$ is a certificate that can be checked in polynomial time.
For hardness, one reduces the [[Boolean satisfiability problem|3QKF32ZAKN]] in conjunctive normal form to it.
A clause such as $u_1 \lor \lnot u_2 \lor u_3$ becomes the inequality $x_1 + (1 - x_2) + x_3 \ge 1$, that is, $-x_1 + x_2 - x_3 \le 0$, and a formula is satisfiable exactly when the system of these inequalities has a $0$-$1$ solution.

Richard Karp included $0$-$1$ integer programming in his 1972 list of 21 NP-complete problems.
The feasibility problem with general integer variables, $x \in \Z^n$, is also NP-complete.
Its membership in NP is less obvious.
It rests on the fact that a system with an integer solution has one whose encoding length is polynomial in the encoding length of $(A, b)$.

In contrast, linear programming, without integrality, can be solved in polynomial time.
If the number $n$ of variables is fixed, integer programming is also solvable in polynomial time, by [[Lenstra's algorithm|6XV9EBX43B]].

## Explanations

### L1 human

The theorem says that integer programming is at least as hard as every problem whose solutions can be checked quickly.
Any logic puzzle of the satisfiability kind can be written as an integer program with $0$-$1$ variables.
So no fast method for all integer programs is expected, unless P equals NP.

### L2 human

The reduction from satisfiability shows that $0$-$1$ variables alone already carry the full difficulty.
It also explains why practical solvers rely on [[branch and bound|ZZ7C50WN56]] and [[cutting planes|PR7VMJN5BH]], whose worst-case running time is exponential.
Special classes are easy: when the constraint matrix is [[totally unimodular|VSD67A49XC]] and $b$ is integral, the [[linear programming relaxation|PYMHHM5Z6F]] already has an integral optimal vertex, by the [[Hoffman–Kruskal theorem|95TD9J5X3P]].
Many problems of [[combinatorial optimization|FJPER80BJC]] are proved NP-hard by writing hard instances as such integer programs or the reverse.
