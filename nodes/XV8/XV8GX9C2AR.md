## Example

Let $\mathcal{M}$ be an $L$-structure with domain $M$ and let $A \subseteq M$ be nonempty.
The *substructure generated by* $A$, written $\langle A \rangle$, is the intersection of all [[substructures|676H7EGTKJ]] of $\mathcal{M}$ whose domain contains $A$.
Its domain is the set of values $t^{\mathcal{M}}(a_1, \dots, a_n)$ of [[terms|6D3WA7N2W4]] $t(x_1, \dots, x_n)$ at elements $a_1, \dots, a_n \in A$.
We compute two cases.

First case: $\mathcal{M} = (\Z, +, -, 0)$ and $A = \set{4, 6}$.

1. The values of terms at $4$ and $6$ are the numbers $4a + 6b$ with $a, b \in \Z$, because each term is a sum and difference of copies of its variables and of $0$.
2. Each such number is even, since $4$ and $6$ are even.
3. The number $2 = 6 - 4$ is such a value, so every $2k$ is a value, by the term with $k$ copies of $x_2 - x_1$, or $-k$ copies of $x_1 - x_2$.
4. So $\langle A \rangle = 2\Z$.

Second case: $\mathcal{M} = (\R, +, -, \cdot, 0, 1)$, the real numbers in the signature of rings, and $A = \set{\sqrt{2}}$.

5. Let $S = \set{a + b\sqrt{2} : a, b \in \Z}$. It contains $0$, $1$ and $\sqrt{2}$.
6. $S$ is closed under $+$ and $-$, by adding or subtracting the coefficients.
7. $S$ is closed under $\cdot$, since $(a + b\sqrt{2})(c + d\sqrt{2}) = (ac + 2bd) + (ad + bc)\sqrt{2}$ with integer coefficients.
8. So $S$ is the domain of a substructure that contains $A$, and $\langle A \rangle \subseteq S$.
9. Each element $a + b\sqrt{2}$ of $S$ is the value of a term at $\sqrt{2}$, built from $1$, $x$, $+$ and $-$; so $S \subseteq \langle A \rangle$.
10. So $\langle \sqrt{2} \rangle = \Z[\sqrt{2}]$, the [[subring|0GNCRPYXYV]] of $\R$ generated by $\sqrt{2}$.

## Remarks

The second case shows again that the generated substructure depends on the signature.
The field $\Q(\sqrt{2}) = \set{a + b\sqrt{2} : a, b \in \Q}$ is not the answer, because the signature has no symbol for division.
If we add a unary symbol ${}^{-1}$ with $0^{-1} = 0$, then the generated substructure contains $2^{-1} = 1/2$, and it becomes the subfield $\Q(\sqrt{2})$.
For a signature without constant symbols, the empty set generates nothing: in textbooks $\langle \emptyset \rangle$ is not defined, while Mathlib gives the empty substructure.
In [[universal algebra|W82R6N0GM9]], the generated substructure is called the [[generated subalgebra|2TQD8NMG9P]].

## Explanations

### L1 human

Start with a few elements of a structure and apply the operations again and again.
All the elements that we can reach in this way form the generated substructure.
For example, start with $4$ and $6$ in the integers and allow adding and subtracting.
We get $6 - 4 = 2$, then $2 + 2 = 4$, $2 + 4 = 6$, and in the end all even numbers, and no odd number.

### L2 human

We find the substructure of $(\Q, +, -, 0)$ generated by $A = \set{1/2}$.

1. The values of terms at $1/2$ are the numbers $k \cdot (1/2)$ with $k \in \Z$.
2. So $\langle A \rangle = \set{k/2 : k \in \Z}$, the set of half-integers and integers.
3. This set does not contain $1/4$, because $1/4 = k/2$ gives $k = 1/2 \notin \Z$.

The typical use is to describe the smallest structure that contains given elements, as in the method of diagrams.
A trap is to include inverses or division that the signature does not have.
