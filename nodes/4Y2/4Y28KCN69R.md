## Definition

Let $n, m, p \ge 1$, and let $A \in \R^{n \times n}$, $B \in \R^{n \times m}$ and $C \in \R^{p \times n}$.
Consider the linear [[control system|ZPDTVZQN5K]] $x' = A x + B u$ with output $y = C x$ and control set $\R^m$.
The system is *output controllable* if the following holds for every initial state $x_0 \in \R^n$ and every $y_1 \in \R^p$.
There are a time $T > 0$ and an admissible control $u$ on $[0, T]$ whose trajectory with $x(0) = x_0$ satisfies $C x(T) = y_1$.

## Remarks

The system is output controllable if and only if the $p \times nm$ matrix
$$\begin{pmatrix} CB & CAB & CA^2 B & \cdots & CA^{n-1} B \end{pmatrix}$$
has [[rank|0ZC9YTXZRY]] $p$.
The reason is that the states reachable from $x_0$ at time $T$ form the affine space $e^{AT} x_0 + \operatorname{im} \mathcal{C}$, where $\mathcal{C} = (B, AB, \ldots, A^{n-1} B)$.
So the reachable outputs form $C e^{AT} x_0 + \operatorname{im}(C \mathcal{C})$, which is all of $\R^p$ exactly when $C \mathcal{C}$ has rank $p$.

Example: the double integrator with $A = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}$, $B = \begin{pmatrix} 0 \\ 1 \end{pmatrix}$ and $C = (1, 0)$ has $CB = 0$ and $CAB = 1$.
The matrix $(CB, CAB) = (0, 1)$ has rank $1 = p$, so the system is output controllable.

Non-example: $n = p = 1$, $A = -1$, $B = 0$, $C = 1$ gives $y(T) = e^{-T} x_0$.
From $x_0 = 0$ the output stays $0$, so the value $y_1 = 1$ is never reached.

If $C$ has rank $p$, then [[controllability|A9WFM77Z4P]] of $(A, B)$ implies output controllability.
The converse fails: the system $x_1' = u$, $x_2' = 0$ with output $y = x_1$ is not controllable, since $x_2$ never moves, but $CB = 1$, so it is output controllable.
For an output $y = C x + D u$ with a direct term and piecewise continuous controls, the usual rank test adds the block $D$ to the matrix above.
