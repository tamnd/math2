## Summary

Axiomatic **constructive set theory** is an approach to mathematical constructivism following the program of axiomatic set theory. The same [[first-order|086QKPF0A6]] language with "$=$" and "$\in$" of classical set theory is usually used, so this is not to be confused with a constructive types approach. On the other hand, some constructive theories are indeed motivated by their interpretability in type theories.
