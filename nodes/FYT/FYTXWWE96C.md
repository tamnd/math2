## Summary

In graph theory, a **mixed graph** $G = (V, E, A)$ is a [[graph|00C0BR7D7H]] consisting of a set of vertices $V$, a set of (undirected) edges $E$, and a set of [[directed|0KFYGSHHF5]] edges (or arcs) $A$.
