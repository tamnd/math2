## Counterexample

*System U* is the pure type system with sorts $*$, $\square$ and $\triangle$, axioms $* : \square$ and $\square : \triangle$, and rules $(*, *)$, $(\square, *)$, $(\square, \square)$, $(\triangle, *)$ and $(\triangle, \square)$.
It extends the higher-order form of [[System F|SVNYKTGQ48]] by allowing quantification over all kinds, such as $\forall \kappa{:}\square.\, \dots$.
*Girard's paradox* is the construction, in System U, of a closed term of type $\bot = \forall \alpha{:}{*}.\, \alpha$.
Applying this term to any type $\tau$ of sort $*$ gives a closed term of $\tau$.
So every proposition has a proof, and System U is inconsistent as a logic.
It follows that System U does not have the [[normalization property|GYMQHR3PXF]].
Indeed, a closed normal term of type $\forall \alpha{:}{*}.\, \alpha$ would have the form $\lambda \alpha{:}{*}.\, t$.
Here $t$ would be a normal term of type $\alpha$ whose only free variable is $\alpha$, and no such $t$ exists.

## Remarks

The construction is a type-theoretic form of the [[Burali-Forti paradox|CCNCGN3P59]].
It builds a type that behaves like the collection of all well-founded orders, and derives a contradiction from it.
Girard found the paradox in his 1972 thesis.
It also applies to any system with a type of all types, $* : *$, such as the first version of Martin-Löf's type theory.
Antonius Hurkens later gave a much shorter version.
The paradox shows that a [[type theory|Q48KGV33AH]] used as a logic cannot have a type of all types.
For this reason the [[calculus of constructions|TKMY3F6KSA]] has no sort above $\square$, so it cannot quantify over all kinds.
[[Martin-Löf type theory|ESVYD9CZ8C]] instead uses a hierarchy of universes, each in the next.

## Explanations

### L1 human

In naive set theory, a set of all sets leads to a contradiction.
Girard's paradox is the same lesson for type theory.
If a type of all types is allowed, or if one can quantify too freely over large types, then every statement can be proved.
Proof assistants avoid it by stacking types in levels, where each level only talks about the levels below it.
