## Statement

Hintikka's lemma says that every Hintikka set has a model, and that the model can be built from the closed terms of the language.

Let $L$ be a first-order language without the equality symbol, with at least one constant symbol, the connectives $\neg, \wedge, \vee, \to$ and the quantifiers $\forall, \exists$.
Let $T_L$ be the set of closed [[terms|6D3WA7N2W4]] of $L$, and let $H$ be a [[Hintikka set|RJNDEG07R1]] for $L$.
Define the $L$-[[structure|983GZBQYT4]] $\mathcal{M}_H$ as follows.

- The domain is $T_L$.
- Each constant symbol $c$ is interpreted as the term $c$ itself.
- Each $n$-ary function symbol $f$ is interpreted as the map that sends $(t_1, \dots, t_n)$ to the term $f(t_1, \dots, t_n)$.
- Each $n$-ary relation symbol $R$ is interpreted as the set of tuples $(t_1, \dots, t_n)$ with $R(t_1, \dots, t_n) \in H$.

Then $\mathcal{M}_H \models \varphi$ for every sentence $\varphi \in H$.
In particular, every Hintikka set is [[satisfiable|QN7M1JCGT9]].

## Remarks

### A first use

Take the language with the constant $c$ and the unary symbols $P, Q$, and the set
$$H = \{ \exists x\, Q(x),\ Q(c),\ \forall x(Q(x) \to P(x)),\ Q(c) \to P(c),\ P(c) \}.$$
It is a Hintikka set: there are no negated atoms, the $\beta$ sentence $Q(c) \to P(c)$ has the component $P(c)$, the $\gamma$ sentence has its instance for the only closed term $c$, and the $\delta$ sentence has the instance $Q(c)$.
The lemma gives the one-element structure on $\{ c \}$ with $P = \{ c \}$ and $Q = \{ c \}$.
Check from the short sentences up: $P(c)$ and $Q(c)$ are true, so $Q(c) \to P(c)$ is true, so the universal sentence is true, and $\exists x\, Q(x)$ has the witness $c$.

The structure $\mathcal{M}_H$ is the [[Herbrand structure|HKW429DSDK]] whose true atomic sentences are exactly the atomic members of $H$.
Atomic sentences outside $H$ are false in it, even when $H$ does not contain their negations.

### Why each hypothesis is needed

Each set below meets every condition except the one named, and it has no model.
The language has one constant $c$ and unary symbols $P, Q$ unless we say otherwise.

Without condition 1, the set $\{ P(c), \neg P(c) \}$ is a counterexample, since it has only literals.
Without condition 2, take $\{ P(c) \wedge Q(c), \neg P(c) \}$.
Without condition 3, take $\{ P(c) \vee Q(c), \neg P(c), \neg Q(c) \}$.
Without condition 4, take $\{ \forall x\, P(x), \neg P(c) \}$.
Without condition 5, take $\{ \exists x\, P(x), \forall x\, \neg P(x), \neg P(c) \}$, which meets condition 4 because $\neg P(c)$ is the only instance needed.

The constant symbol is needed too.
In the language with only $P$, the set $\{ \forall x\, P(x), \forall x\, \neg P(x) \}$ meets condition 4 vacuously, because there are no closed terms.
It has no model, since every structure has a nonempty domain.

The exclusion of equality is needed as well.
The set $\{ \neg(c = c) \}$ meets all five conditions, because $c = c$ is not in it, and no structure makes it true.
The set $\{ c = d, P(c), \neg P(d) \}$ fails in the same way.

### With equality

When $L$ has the equality symbol, we add two closure conditions.

- (E1) $(t = t) \in H$ for every closed term $t$.
- (E2) If $(s = t) \in H$, $\varphi$ is an atomic formula whose only free variable is $x$, and $\varphi[s/x] \in H$, then $\varphi[t/x] \in H$.

Define $s \sim t$ when $(s = t) \in H$.
(E1) makes $\sim$ reflexive, (E2) with $\varphi = (x = s)$ makes it symmetric, and (E2) with $\varphi = (r = x)$ makes it transitive.
(E2) with $\varphi = (f(t_1, \dots, t_i, \dots, t_n) = f(t_1, \dots, x, \dots, t_n))$, where $s = t_i$, shows that $\sim$ respects $f$.
With $\varphi = R(t_1, \dots, x, \dots, t_n)$ it shows that $\sim$ respects the relations that $H$ gives, so $\sim$ is a [[congruence relation|DCSXXT4SER]].
The model now has the classes $[t]$ as elements, and $R$ holds of $([t_1], \dots, [t_n])$ when $R(t_1, \dots, t_n) \in H$.
Then $s = t$ is true exactly when $(s = t) \in H$, and for $\neg(s = t) \in H$ condition 1 gives $[s] \neq [t]$.

### What it gives you

The lemma is the last step of the completeness proof for tableaux.
An open branch of a finished systematic tableau is a Hintikka set for $L^{+}$, so the set at its root is satisfiable; see [[semantic tableaux|WGWBBVE8GX]].
The model has domain $T_L$, so it is countable when $L$ is countable.
Through the tableau proof this gives a countable model for every satisfiable countable set, a case of the [[Löwenheim-Skolem theorem|484M0TZ1S7]].
Together with a construction of Hintikka sets, the lemma also yields the [[model existence theorem|G0DTR159RN]] and [[Gödel's completeness theorem|WQ1ZE255SF]].

### The converse

The converse "every satisfiable set is a Hintikka set" is false.
The set $\{ \exists x\, P(x) \}$ is satisfiable but fails condition 5, as the [[satisfiable non-Hintikka set|RV5VSDKNBX]] shows.

A weaker converse is true.
Let $\Gamma$ have a model $\mathcal{M}$, and add a new constant $\underline{a}$ for each element $a \in M$.
Then the set of sentences of the larger language that are true in $\mathcal{M}$, with $\underline{a}$ read as $a$, is a Hintikka set that contains $\Gamma$.
So a set is satisfiable exactly when it is a subset of a Hintikka set for some language.

### Generalizations

The propositional version takes $H$ to be a set of propositional formulas with conditions 1 to 3.
Its model is the valuation that makes a letter true exactly when the letter is in $H$.
The same lemma holds for many-sorted languages, and, with Kripke models in place of structures, for modal and intuitionistic logics.

## History

Jaakko Hintikka introduced model sets in 1955, as sets of sentences that describe a model.
Raymond Smullyan's book First-Order Logic (1968) gave the lemma in the uniform $\alpha, \beta, \gamma, \delta$ notation and used it for the completeness of analytic tableaux.

## Explanations

### L1 human

A Hintikka set is a list of facts in which each complicated fact is backed by simpler facts on the list.
The lemma says that such a list always describes a possible world.
To build the world, take the names on the list as the objects.
Then make each basic fact on the list true and every other basic fact false.
For example, the list "$P(c)$ and not $Q(c)$; $P(c)$; not $Q(c)$" gives the world with one object $c$ that has $P$ and lacks $Q$.
The backing of each fact by simpler facts then makes every fact on the list true.

### L2 human

We apply the lemma to $H = \{ P(0),\ \neg P(s(0)),\ \exists x\, \neg P(x) \}$ in the language with the constant $0$, a unary function symbol $s$ and a unary relation symbol $P$.

1. $H$ is a Hintikka set: $P(0)$ and $\neg P(s(0))$ do not clash, there is no $\gamma$ sentence, and the $\delta$ sentence has the instance $\neg P(s(0))$.
2. The domain of $\mathcal{M}_H$ is the infinite set $\{ 0, s(0), s(s(0)), \dots \}$, and $s$ sends each term $t$ to $s(t)$.
3. The relation $P$ holds only of $0$, because $P(0)$ is the only atom in $H$.
4. So $P(0)$ is true, $P(s(0))$ is false, and $\exists x\, \neg P(x)$ has the witness $s(0)$.

The typical use is the last step of a completeness proof for a tableau or sequent system.
Watch out for equality: with $=$ in the language, $\mathcal{M}_H$ would read $=$ as identity of terms, so $c = d \in H$ would be false, and the quotient of the remarks is needed.

### L3 human

The lemma is a cut-free form of model existence: the model is read off a set that is only closed downward, and no maximal consistent extension is needed.
The model is a [[Herbrand structure|HKW429DSDK]], and Herbrand's theorem uses the same structures in a finite form.
The proof is an induction on a rank that the instances $\gamma(t)$ and $\delta(t)$ lower, even though they are not subformulas.
The same pattern, an induction that carries truth up from the atomic level, returns in the truth lemma for canonical models in modal logic.
