## Statement

Let $s \colon \N \to \N$ be a space-constructible function with $s(n) \ge \log n$ for all large $n$.
Let $\mathrm{NSPACE}(s(n))$ be the class of languages decided by [[nondeterministic Turing machines|M7SDX137WE]] in space $O(s(n))$.
Here space is the number of work-tape cells used on inputs of length $n$, as in [[space complexity|FDNFGKEEJR]].
Then a language $L \subseteq \Sigma^*$ is in $\mathrm{NSPACE}(s(n))$ if and only if its complement $\Sigma^* \setminus L$ is in $\mathrm{NSPACE}(s(n))$.
In particular $\mathrm{NL} = \mathrm{co}\text{-}\mathrm{NL}$, where $\mathrm{NL}$ is the class [[NL|7RH189REV7]].

## Remarks

The proof is by *inductive counting*.
It is enough to show that non-reachability in a directed graph is in $\mathrm{NL}$.
This suffices because reachability is complete for $\mathrm{NL}$, and the general case applies the same method to the graph of configurations.
For $i = 0, 1, 2, \dots$ the machine computes the number $c_i$ of vertices reachable from the start in at most $i$ steps.
It checks each candidate count by guessing paths and verifying them one vertex at a time, using only counters of logarithmic size.
Once the exact number $c$ of reachable vertices is known, the machine proves that a target $t$ is unreachable by exhibiting $c$ reachable vertices, all different from $t$.
For $s(n) = n$ the theorem says that the [[context-sensitive languages|NYJ7PD4025]], which are the languages of [[linear bounded automata|KF2JADMJC0]], are closed under complement.

## Explanations

### L1 human

Nondeterministic machines are good at saying "yes": they guess a witness and check it.
Saying "no" seems harder, since one must rule out every possible witness.
This theorem shows that, when memory rather than time is the limit, saying "no" is no harder than saying "yes".
The trick is to count how many configurations can be reached, and then use this count to certify that the bad one is not among them.

### L2 human

The theorem was proved independently by Neil Immerman and Róbert Szelepcsényi.
It settled the second "LBA problem", whether the complement of a context-sensitive language is context-sensitive.
Compare it with time: whether $\mathrm{NP} = \mathrm{co}\text{-}\mathrm{NP}$ is still open.
Together with [[Savitch's theorem|PFKWV5SFF5]], $\mathrm{NSPACE}(s(n)) \subseteq \mathrm{DSPACE}(s(n)^2)$, it shows that nondeterminism changes space classes very little.
