## Example

Consider the system over $\mathbb{R}$
$$2y + x = 5, \qquad 3z - y = 1, \qquad x = 4z.$$
Each equation misses one unknown, and the unknowns come in a different order each time.
We find the [[coefficient matrix|0P7A2MJD24]] and then solve the system.

1. Fix the order $x, y, z$, move all unknowns to the left, and write a $0$ for each missing unknown:
$$x + 2y + 0z = 5, \qquad 0x - y + 3z = 1, \qquad x + 0y - 4z = 0.$$
2. Read off the rows. This gives
$$A = \begin{bmatrix} 1 & 2 & 0 \\ 0 & -1 & 3 \\ 1 & 0 & -4 \end{bmatrix}, \qquad b = \begin{pmatrix} 5 \\ 1 \\ 0 \end{pmatrix}.$$
3. Reduce the [[augmented matrix|0YCDZ7N8VD]] $[A \mid b]$. The operation $R_3 - R_1$ gives $(0, -2, -4 \mid -5)$, and then $R_3 - 2R_2$ gives $(0, 0, -10 \mid -7)$.
4. Back substitution gives $z = \tfrac{7}{10}$, then $y = 3z - 1 = \tfrac{11}{10}$ from row 2, then $x = 5 - 2y = \tfrac{14}{5}$ from row 1.
5. Check the original equations: $2 \cdot \tfrac{11}{10} + \tfrac{14}{5} = \tfrac{22}{10} + \tfrac{28}{10} = 5$, then $3 \cdot \tfrac{7}{10} - \tfrac{11}{10} = 1$, and $4 \cdot \tfrac{7}{10} = \tfrac{14}{5}$.

## Remarks

The zeros in $A$ come from the unknowns that are missing in each equation.
If you dropped them and wrote the rows as $(2, 1)$, $(3, -1)$ and $(1, -4)$, the matrix would have only two columns for three unknowns, and each column would mix different unknowns.
If the third equation were $x = 4z + y$ instead, only one entry would change: the third row would become $(1, -1, -4)$.

## Explanations

### L1 human

Before you make the table, write every equation in the same pattern: first $x$, then $y$, then $z$.
When an unknown is missing, write it with the number $0$ in front.
Then each column of the table belongs to one unknown.

### L2 human

Word problems often give equations in this untidy shape.
Fix the order of the unknowns, move all unknowns to the left side, and fill in zeros for the missing ones, and only then build the matrix.
Watch out in the equation $x = 4z$: after you move $4z$ to the left, the coefficient of $z$ is $-4$, not $4$.
