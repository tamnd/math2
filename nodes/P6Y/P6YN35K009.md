## Summary

In number theory, a **prime $k$-tuple** is a finite collection of values representing a repeatable pattern of differences between prime numbers. For a $k$-[[tuple|9HFER6N708]] $(a, b, \ldots)$, the positions where the $k$-tuple matches a pattern in the prime numbers are given by the set of integers $n$ for which all of the values $(n + a, n + b, \ldots)$ are prime. Typically the first value in the $k$-tuple is 0 and the rest are distinct positive even numbers.
