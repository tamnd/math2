## Summary

The Laplace transform is an integral transform. It sends a function $f$ of a real variable $t \ge 0$ to the function $F(s) = \int_0^\infty f(t) e^{-st}\, dt$ of a complex variable $s$.
It is named after Pierre-Simon Laplace. See the [[definition|05XT5AVJBK]].
