## Statement

Let $1 \le p \le \infty$ and let $L_p^q$ be the [[$L^p$ space|SASP14MA1Z]] of functions $[0, \infty) \to \R^q$.
For a function $x$ on $[0, \infty)$ and $\tau \ge 0$, let $x_\tau$ be its truncation: $x_\tau(t) = x(t)$ for $t \le \tau$ and $x_\tau(t) = 0$ for $t > \tau$.
Let $L_{pe}^q$ be the extended space of measurable $x$ with $x_\tau \in L_p^q$ for every $\tau \ge 0$.
Let $H_1 \colon L_{pe}^m \to L_{pe}^q$ and $H_2 \colon L_{pe}^q \to L_{pe}^m$ be maps with constants $\gamma_1, \gamma_2 \ge 0$ and $\beta_1, \beta_2 \ge 0$ such that, for all $\tau \ge 0$,
$$\norm{(H_1 e_1)_\tau}_p \le \gamma_1 \norm{(e_1)_\tau}_p + \beta_1, \qquad \norm{(H_2 e_2)_\tau}_p \le \gamma_2 \norm{(e_2)_\tau}_p + \beta_2$$
for all $e_1 \in L_{pe}^m$ and $e_2 \in L_{pe}^q$.
Consider the [[feedback|7NYES2D0Z4]] system
$$e_1 = u_1 - H_2 e_2, \qquad e_2 = u_2 + H_1 e_1,$$
and assume that it is well posed: for all inputs $u_1 \in L_{pe}^m$ and $u_2 \in L_{pe}^q$ it has a solution $e_1 \in L_{pe}^m$, $e_2 \in L_{pe}^q$.
If $\gamma_1 \gamma_2 < 1$, then for every solution and every $\tau \ge 0$,
$$\norm{(e_1)_\tau}_p \le \frac{\norm{(u_1)_\tau}_p + \gamma_2 \norm{(u_2)_\tau}_p + \beta_2 + \gamma_2 \beta_1}{1 - \gamma_1 \gamma_2},$$
$$\norm{(e_2)_\tau}_p \le \frac{\norm{(u_2)_\tau}_p + \gamma_1 \norm{(u_1)_\tau}_p + \beta_1 + \gamma_1 \beta_2}{1 - \gamma_1 \gamma_2}.$$
In particular, the closed loop is finite-gain $L_p$ stable: inputs in $L_p$ give $e_1, e_2$ in $L_p$, with norms bounded as above.

## Remarks

Truncating the loop equations at $\tau$ and using the triangle inequality gives $\norm{(e_1)_\tau} \le \norm{(u_1)_\tau} + \gamma_2 \norm{(e_2)_\tau} + \beta_2$ and $\norm{(e_2)_\tau} \le \norm{(u_2)_\tau} + \gamma_1 \norm{(e_1)_\tau} + \beta_1$.
Substituting the second bound into the first gives $(1 - \gamma_1 \gamma_2) \norm{(e_1)_\tau} \le \ldots$, and all quantities are finite because the signals lie in the extended space.
For $u_i \in L_p$, letting $\tau \to \infty$ gives the bound on the full norms.

Example: for stable linear time-invariant $H_1$ and $H_2$ and $p = 2$, the gains $\gamma_i$ can be taken as the peak values $\sup_\omega \abs{G_i(i\omega)}$ of the transfer functions.
So the loop is stable if $\sup_\omega \abs{G_1(i\omega)} \cdot \sup_\omega \abs{G_2(i\omega)} < 1$.

The strict inequality is needed.
Take $p = 2$, scalar signals, $H_1$ the identity and $H_2$ the linear system with transfer function $-1/(s + 1)$, so $\gamma_1 = \gamma_2 = 1$.
With $u_2 = 0$ the loop gives $e_1 = \frac{s + 1}{s} u_1$ in the Laplace domain.
For $u_1(t) = e^{-t}$ this is $e_1 = 1/s$, the unit step, which is not in $L_2$.

## Explanations

### L1 human

Put two systems in a loop, each feeding the other.
If going once around the loop always shrinks signals, then nothing can build up, and the loop is stable.
That is all the theorem says: the product of the two amplification factors must be less than $1$.

### L2 human

The theorem needs no linearity and no state description, only bounds on the gains, which makes it the basic tool of input-output stability.
In robust control, $H_1$ is a known stable system and $H_2$ an unknown perturbation with gain at most $\gamma_2$; the loop is stable for all such perturbations if $\gamma_1 \gamma_2 < 1$.
This is the basis of the $H_\infty$ approach to robustness.
It is conservative for a given loop, since it ignores phase; passivity theorems use phase information instead.
