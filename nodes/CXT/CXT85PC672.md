## Example

Let $L = \{P\}$ with one unary relation symbol $P$, and let $\tau$ be the sentence $\exists x \, P(x) \to \forall x \, P(x)$.
We show that $\tau$ is not [[valid|AMDZRKKT4J]], by a countermodel.
Let $\mathcal{M}$ have domain $\{0, 1\}$ and $P^{\mathcal{M}} = \{0\}$, and let $s$ be any assignment.

1. The variant $s[x \mapsto 0]$ satisfies $P(x)$, because $0 \in P^{\mathcal{M}}$.
   So $\mathcal{M} \models \exists x \, P(x)[s]$, by the clause for $\exists$ of [[satisfaction|1WTCZB4DVB]].
2. The variant $s[x \mapsto 1]$ does not satisfy $P(x)$, because $1 \notin P^{\mathcal{M}}$.
   So $\mathcal{M} \not\models \forall x \, P(x)[s]$, by the clause for $\forall$.
3. The antecedent of $\tau$ holds and the consequent fails, so $\mathcal{M} \not\models \tau[s]$, by the clause for $\to$.
4. So $\tau$ is false in $\mathcal{M}$, and $\tau$ is not valid.

The condition of validity that fails is truth in every structure.

## Remarks

One structure and one assignment are enough to refute validity, and this is the standard method.
The sentence $\tau$ is true in some structures: in every structure with one element, and in every structure where $P$ is empty or is the whole domain.
So $\tau$ is satisfiable but not valid.
It is the converse of the valid sentence $\forall x \, P(x) \to \exists x \, P(x)$, so the converse of a valid implication need not be valid.

## Explanations

### L1 human

"If something is red, then everything is red" is false in a world with one red ball and one blue ball.
One such world is enough to show that the sentence is not a law of logic.

### L2 human

We list all four structures on $\{0, 1\}$ and decide $\tau$ in each.

1. If $P = \emptyset$, the antecedent is false, so $\tau$ is true.
2. If $P = \{0\}$, the antecedent is true and the consequent is false, so $\tau$ is false.
3. If $P = \{1\}$, the same happens with $1$ in place of $0$, so $\tau$ is false.
4. If $P = \{0, 1\}$, the consequent is true, so $\tau$ is true.

The typical use is to show that a proposed inference rule is unsound.
Watch out: "not valid" does not mean "false", and $\tau$ is not valid, but it is true in cases 1 and 4.
