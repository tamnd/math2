## Statement

A function $f \colon \set{0,1}^* \to \N$ is in $\#\mathrm{P}$ if there is a polynomial-time [[nondeterministic Turing machine|M7SDX137WE]] $M$ of the following kind.
For every $x$, the number of accepting computation paths of $M$ on $x$ is $f(x)$.
A function $g$ is $\#\mathrm{P}$-hard if every $f \in \#\mathrm{P}$ is computed in polynomial time by a deterministic machine with an oracle for $g$.

For an $n \times n$ matrix $A = (a_{ij})$ with entries in $\set{0,1}$, its [[permanent|X9B1XETBPF]] is
$$\operatorname{perm}(A) = \sum_{\sigma \in S_n} \prod_{i=1}^n a_{i \sigma(i)}.$$
The function $A \mapsto \operatorname{perm}(A)$ is $\#\mathrm{P}$-complete: it is in $\#\mathrm{P}$ and it is $\#\mathrm{P}$-hard.

## Remarks

The permanent of a $0$-$1$ matrix $A$ is the number of perfect matchings of the bipartite graph with biadjacency matrix $A$.
So it lies in $\#\mathrm{P}$: a machine guesses a permutation $\sigma$ and accepts when all $a_{i\sigma(i)}$ equal $1$.
For hardness, Leslie Valiant first reduced the number of satisfying assignments of a formula to the permanent of an integer matrix.
His gadgets build a weighted graph whose cycle covers encode the assignments.
He then reduced integer entries to $0$-$1$ entries, using computations modulo a large number.

The [[determinant|00KDZRW4C0]] has the same formula with the signs $\sgn \sigma$, and it is computed in polynomial time by Gaussian elimination.
So a change of signs separates an easy function from a $\#\mathrm{P}$-complete one.
Deciding whether a bipartite graph has a perfect matching is in P, so the theorem gives a counting problem that is hard although its decision version is easy.

## Explanations

### L1 human

The permanent looks like the determinant without the minus signs.
The determinant is easy to compute, but Valiant showed in 1979 that the permanent is as hard as counting the solutions of any NP problem.
If the permanent could be computed in polynomial time, then $\mathrm{P} = \mathrm{NP}$, and much more would follow.

### L2 human

The theorem started the theory of counting complexity and the class $\#\mathrm{P}$.
Together with [[Toda's theorem|PDMBKJV6JQ]], it shows that an oracle for the permanent decides every problem in the polynomial hierarchy in polynomial time.
In algebraic complexity, Valiant's classes VP and VNP have the determinant and the permanent as their model problems.
The question whether they differ is an algebraic analogue of P versus NP.
The permanent of a matrix with nonnegative entries can still be approximated by a randomised algorithm, a result of Jerrum, Sinclair and Vigoda.
