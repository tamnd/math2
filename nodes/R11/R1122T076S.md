## Statement

In plain words: classical propositional logic does not prove everything, and adding any new law to it, for all instances, makes it prove everything.

The formulas are built from the variables $p_1, p_2, p_3, \ldots$ with the connectives $\lnot$ and $\to$.
Let $\mathsf{H}$ be the Hilbert system with the three axiom schemas
$$\varphi \to (\psi \to \varphi), \qquad (\varphi \to (\psi \to \chi)) \to ((\varphi \to \psi) \to (\varphi \to \chi)), \qquad (\lnot\varphi \to \lnot\psi) \to (\psi \to \varphi),$$
where $\varphi$, $\psi$, $\chi$ range over all formulas, and with modus ponens as the only rule.
For a formula $A$, let $\mathsf{H} + A$ be the system with the same rule whose axioms are those of $\mathsf{H}$ and all formulas $A\sigma$.
Here $\sigma$ ranges over the [[substitutions|NCDZ969V7X]] of formulas for variables.
Then the following hold.

1. $\mathsf{H}$ is [[Post consistent|WK2P0E82B4]]: the formula $p_1$ is not a theorem of $\mathsf{H}$.
2. $\mathsf{H}$ is Post complete: if $A$ is not a theorem of $\mathsf{H}$, then every formula is a theorem of $\mathsf{H} + A$.

## Remarks

### Why each hypothesis is needed

The hypothesis that $A$ is not a theorem of $\mathsf{H}$ is needed.
If $A$ is a theorem, for example $A = p_1 \to p_1$, then every instance $A\sigma$ is already a theorem of $\mathsf{H}$.
So $\mathsf{H} + A$ has the same theorems as $\mathsf{H}$, and $p_1$ is still not a theorem.

Adding $A$ as a schema, with all its instances, is needed.
Suppose only the formula $p_1$ itself is added as an axiom.
The valuation with $p_1$ true and all other variables false makes every axiom true, and modus ponens keeps truth under this valuation.
So $p_2$ is not a theorem, and the extended system is Post consistent.

The completeness of $\mathsf{H}$ for truth tables is needed.
The system with only the first two schemas and modus ponens does not prove the tautology $\lnot\lnot p_1 \to p_1$.
Adding that tautology as a schema gives a system that still proves only tautologies, so it is Post consistent, and the weaker system is not Post complete.

The classical semantics is needed.
[[Intuitionistic propositional logic is not Post complete|EBVDK5GCGV]], because adding the excluded middle gives classical logic.

### What it gives you

The theorems of $\mathsf{H}$ are exactly the [[tautologies|05006AJ7DZ]].
No logic in this language that is closed under substitution and modus ponens lies strictly between classical logic and the trivial logic.

A schema that is not a tautology cannot be added to classical propositional logic, even if it looks plausible in some reading.
The converse $(p \to q) \to (q \to p)$ is an example, and [[adding the converse schema|BH8WMN52AF]] shows the collapse in ten lines.

Classical propositional logic is still not negation complete: neither $p_1$ nor $\lnot p_1$ is a theorem.
The substitution in the definition of $\mathsf{H} + A$ is what separates Post completeness from negation completeness.

### Converse

The converse direction reads: if every non-theorem collapses $\mathsf{H}$, then $\mathsf{H}$ proves all tautologies.
This holds for every system $S$ in this language that is closed under substitution and modus ponens and proves only tautologies.
If a tautology $A$ were not a theorem of $S$, then $S + A$ would still prove only tautologies.
So $p_1$ would not be a theorem of $S + A$, and $S$ would not be Post complete.

### Generalizations

The same proof works for any functionally complete set of connectives.
For the implicational fragment, with $\to$ as the only connective, the result also holds, with a different substitution.
There no formula is false under every valuation, so the false variables of a falsifying row are replaced by one fixed variable $r$, and the instance then derives $r$.

In first-order logic the corresponding statement is about theories of sentences.
A consistent, deductively closed theory is maximal consistent exactly when it is negation complete.

## History

Emil Post proved in 1921 that the propositional calculus of *Principia Mathematica* is complete in two senses.
Every tautology is a theorem, and adding any non-theorem as a new law makes every formula provable.
His method used truth tables.
The second property is the one now called Post completeness, and it already appears in Hilbert's lectures on logic of 1917.

## Explanations

### L1 human

The laws of classical logic of "not" and "if then" are exactly the formulas that are true in every row of their truth table.
Suppose we try to add one more law, a formula that fails in some row.
A law holds for every way of filling in its letters.
So we may fill the letters with sentences that are always true or always false, copying the row where the formula fails.
The result is a sentence that is always false, but it is now a law.
A system that has an always false sentence as a law proves everything.

### L2 human

We run the proof on $A = p_1 \to p_2$.

1. $A$ is not a tautology: the valuation $p_1 = \mathsf{T}$, $p_2 = \mathsf{F}$ makes it false.
2. Let $\top$ be $p_1 \to p_1$ and let $\bot'$ be $\lnot(p_1 \to p_1)$.
   Every valuation makes $\top$ true and $\bot'$ false.
3. Substitute $\top$ for $p_1$ and $\bot'$ for $p_2$.
   The instance is $A^* = (p_1 \to p_1) \to \lnot(p_1 \to p_1)$.
4. Under every valuation, $A^*$ is $\mathsf{T} \to \mathsf{F} = \mathsf{F}$, so $\lnot A^*$ is a tautology and a theorem of $\mathsf{H}$.
5. In $\mathsf{H} + A$, both $A^*$ and $\lnot A^*$ are theorems, and every formula follows by explosion.

Here a shorter route also exists.
Put $\top$ for $p_1$ and any formula $B$ for $p_2$, and modus ponens with the theorem $\top$ gives $B$.
The typical use is to show that a proposed new logical law is either already a law or destroys the logic.
A trap is to substitute variables for variables.
The instance $p_3 \to p_4$ is still true under some valuations, so it gives nothing.

### L3 human

Algebraically, $\mathsf{H} + A$ is Post consistent exactly when the equation $A = 1$ holds in some nontrivial Boolean algebra.
Every nontrivial Boolean algebra contains the two-element algebra, in which a non-tautology fails.
So the equation fails everywhere, and the extension is trivial.
The theorem thus says that the variety of Boolean algebras is minimal among nontrivial varieties.
For intermediate logics, many-valued logics and modal logics the lattices of extensions are large, and their maximal elements are studied in [[algebraic logic|QYA4H5Y7VR]].
