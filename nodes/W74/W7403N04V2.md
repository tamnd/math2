## Statement

Let $m$, $n$ and $p$ be [[natural numbers|0MWKJ44V5A]], where $0$ counts as a natural number.
Use the [[order on the natural numbers|0HNATXFEV5]] and the [[addition of natural numbers|0S13V32CPB]].

If $m \le n$, then $m + p \le n + p$.

If $m < n$, then $m + p < n + p$.

## Remarks

Adding the same number to both sides keeps the order, and it keeps strict inequality as well.
