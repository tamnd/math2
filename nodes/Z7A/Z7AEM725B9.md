## Example

Let $q = \frac{1}{2}(1 + i + j + k)$, the [[quaternion|AM07TESJED]] with $a = b = c = d = \frac{1}{2}$.
We compute its matrix $U = \phi(q)$ from [[the quaternion theorem|A763JSEVW8]], check that $U$ lies in $SU(2)$, and find $U^3$.

1. The length is $\abs{q}^2 = 4 \cdot \frac{1}{4} = 1$, so $q$ is a unit quaternion.
2. The theorem uses $\alpha = a + bi = \frac{1 + i}{2}$ and $\beta = c + di = \frac{1 + i}{2}$, so
$$U = \begin{pmatrix} \alpha & \beta \\ -\overline{\beta} & \overline{\alpha} \end{pmatrix} = \frac{1}{2} \begin{pmatrix} 1 + i & 1 + i \\ -1 + i & 1 - i \end{pmatrix}.$$
3. The determinant uses $(1 + i)(1 - i) = 2$ and $(1 + i)(-1 + i) = -1 + i - i + i^2 = -2$:
$$\det U = \tfrac{1}{4}\big((1 + i)(1 - i) - (1 + i)(-1 + i)\big) = \tfrac{1}{4}(2 + 2) = 1.$$
4. The columns $\frac{1}{2}(1 + i, -1 + i)$ and $\frac{1}{2}(1 + i, 1 - i)$ both have squared length $\frac{1}{4}(2 + 2) = 1$.
5. Their inner product, with the conjugate on the second vector, is
$$\tfrac{1}{4}\big((1 + i)\overline{(1 + i)} + (-1 + i)\overline{(1 - i)}\big) = \tfrac{1}{4}\big(2 + (-1 + i)(1 + i)\big) = \tfrac{1}{4}(2 - 2) = 0.$$
6. So $U$ is unitary with determinant $1$, and $U \in SU(2)$.
7. The trace is $\tr U = \frac{1}{2}\big((1 + i) + (1 - i)\big) = 1$, so the characteristic polynomial is $t^2 - t + 1$. Its roots are $\frac{1 \pm i\sqrt{3}}{2} = e^{\pm i\pi/3}$.
8. Both roots satisfy $\lambda^3 = e^{\pm i\pi} = -1$. Since the roots differ, $U$ is diagonalizable, so $U^3 = -I_2$, and $q^3 = -1$ in the quaternions.

Check: put $u = i + j + k$, so that $u^2 = -3$, because the squares give $-1$ three times and the mixed products cancel in pairs.
Then $q = \frac{1}{2}(1 + u)$, and $q^2 = \frac{1}{4}(1 + 2u + u^2) = \frac{1}{2}(-1 + u)$.
So $q^3 = \frac{1}{4}(-1 + u)(1 + u) = \frac{1}{4}(-1 + u^2) = -1$.

## Remarks

The example runs [[the quaternion theorem|A763JSEVW8]] in both directions.
From $U$, the first row gives $\alpha = \frac{1 + i}{2}$ and $\beta = \frac{1 + i}{2}$, and these give back $a = b = c = d = \frac{1}{2}$.

The quaternion also turns space.
The map $v \mapsto q v \overline{q}$ on the pure quaternions sends $i \mapsto j$, $j \mapsto k$ and $k \mapsto i$.
This is the rotation by $\frac{2\pi}{3}$ about the axis through $(1, 1, 1)$, whose matrix is the [[cyclic permutation matrix|E6SGA0X325]].
The quaternion $-q$ gives the same rotation, but $\phi(-q) = -U$ is a different element of $SU(2)$, which shows the double cover of $SO(3)$ by $SU(2)$.

Since $q^3 = -1$, we get $q^6 = 1$, while $q^2 \ne 1$ and $q^3 \ne 1$.
So $q$ generates a cyclic subgroup of order $6$ in $SU(2)$, and its image in $SO(3)$ has order $3$.

## Explanations

### L1 human

A unit quaternion is a list of four numbers whose squares add up to $1$.
Here all four numbers are $\frac{1}{2}$, and $4 \cdot \frac{1}{4} = 1$.
The theorem turns this list into a $2 \times 2$ table of complex numbers.
The table keeps all lengths and has determinant $1$, and three copies of it multiply to minus the identity.

### L2 human

Here is the typical use: to combine rotations of space, multiply their unit quaternions, or their matrices in $SU(2)$.
The rotation of $q$ applied three times is the identity rotation, and in $SU(2)$ the product $U^3$ is $-I_2$, which maps to the identity rotation.
Watch out: $U^3 = -I_2$, not $I_2$, although three turns by $\frac{2\pi}{3}$ give the identity.
The sign is exactly the information that $SU(2)$ keeps and $SO(3)$ forgets.
