## Example

Let $f(x) = |x|$ be the [[absolute value|0FFXKTKKQC]] function on $\mathbb{R}$.
We check that $f$ fails to be differentiable only in the expected way, so it is not [[pathological|WMBZPYPN2D]].

1. For $x > 0$, $f(x) = x$, so $f'(x) = 1$.
2. For $x < 0$, $f(x) = -x$, so $f'(x) = -1$.
3. At $x = 0$, the difference quotient $(f(h) - f(0))/h = |h|/h$ equals $1$ for $h > 0$ and $-1$ for $h < 0$. So the limit as $h \to 0$ does not exist, and $f$ is not [[differentiable|0K57YG3BB8]] at $0$.
4. The function is [[continuous|0X3WGX95FE]] at every point, since $\big||x| - |a|\big| \le |x - a|$.

So $f$ is continuous everywhere and differentiable at every point except one.
Its graph is two straight half lines that meet at a corner, which is what a drawing shows.

## Remarks

The function $|x|$ is a standard counterexample to the converse of "differentiable implies continuous".
A counterexample is not always pathological: the word "pathological" asks for behaviour that defeats intuition, and a single corner does not.
Compare the Weierstrass function, which is continuous and differentiable at no point.

## Explanations

### L1 human

The graph of $|x|$ looks like the letter V.
It has one sharp corner at $0$, and it is a straight line on each side.
At the corner, the graph has no single slope.
Everyone expects this from the picture, so the function is not called pathological.

### L2 human

To decide whether a function is pathological, compare its behaviour with the picture of its graph.

1. The picture of $|x|$ has one corner, at $0$.
2. The analysis gives exactly one point of non-differentiability, at $0$.
3. The picture and the analysis agree, so the function is well-behaved in the informal sense.

A trap: "not differentiable at a point" does not make a function pathological.
