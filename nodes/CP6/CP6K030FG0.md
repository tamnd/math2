## Example

Let $f(x) = |x|$ be the [[absolute value|0FFXKTKKQC]] function on $\mathbb{R}$.
We check that $f$ fails to be differentiable only in the way its graph predicts, so it is not [[pathological|WMBZPYPN2D]].

1. For $x > 0$ we have $f(x) = x$ near $x$, so $f'(x) = 1$.
2. For $x < 0$ we have $f(x) = -x$ near $x$, so $f'(x) = -1$.
3. At $x = 0$ the difference quotient is
   $$\frac{f(h) - f(0)}{h} = \frac{|h|}{h} = \begin{cases} 1 & h > 0, \\ -1 & h < 0. \end{cases}$$
   The two one-sided limits differ, so the limit as $h \to 0$ does not exist, and $f$ is not [[differentiable|0K57YG3BB8]] at $0$.
4. The function is [[continuous|0X3WGX95FE]] at every point $a$, since $\big||x| - |a|\big| \le |x - a|$.

So $f$ is continuous everywhere and differentiable at every point except one.
Its graph is two straight half lines that meet at a corner, which is exactly what a drawing shows.

## Remarks

The function $|x|$ is the standard counterexample to the converse of "differentiable implies continuous".
So a counterexample is not always pathological: the word asks for behavior that defeats intuition, and a single visible corner does not.

What changes when the corners multiply?
The function $|x - 1| + |x - 2| + |x - 3|$ has three corners and is still well-behaved.
Even a function with corners at every integer, such as the distance from $x$ to the nearest integer, is not called pathological, because its graph is a saw tooth that you can draw.
The picture breaks only when infinitely many such teeth are stacked: with $s(x)$ the distance from $x$ to the nearest integer, the sum $\sum_{n \ge 0} 2^{-n} s(2^n x)$ is continuous and differentiable at no point.

## Explanations

### L1 human

The graph of $|x|$ looks like the letter V.
It has one sharp corner at $0$, and it is a straight line on each side.
At the corner the graph has no single slope.
Everyone expects this from the picture, so the function is not called pathological.

### L2 human

To decide whether a function is pathological, compare what analysis tells you with what the graph shows.
For $|x|$ the graph has one corner, at $0$, and step 3 finds exactly one point where the derivative fails, also at $0$.
The two agree, so the function is well-behaved in the informal sense.
For the Weierstrass function the graph you draw looks continuous and the analysis finds no derivative anywhere, and that mismatch is what the word "pathological" records.
