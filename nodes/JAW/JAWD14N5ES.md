## Summary

A left-invariant measure on a group is a measure that gives the same value to a set and to each of its left translates.
It is the case of an [[invariant measure|B232EZ1FMB]] where the maps are the left translations $x \mapsto gx$.
The [[Haar measure|VY0HXD3GC4]] of a locally compact group is a left-invariant measure that is also a nonzero Radon measure.
Left-invariant measures are the basic tool for integrating over a group without favouring any point.

## Explanations

### L1 human

Think of a measure as a way to weigh the subsets of a group.
It is left-invariant if moving a set by multiplying all its elements on the left by a fixed element never changes its weight.
On the real line under addition, the length of an interval does not change when the interval is shifted, so length is left-invariant.
A unit mass placed at the point $0$ is not left-invariant, because shifting the point $0$ to $1$ moves the set away from the mass.
