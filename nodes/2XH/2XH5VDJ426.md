## Statement

A *monotone circuit* is a [[Boolean circuit|SQXNFGVADX]] whose gates are AND and OR gates of fan-in two, with no NOT gates.
Let $n \ge 2$ and $2 \le k \le n$.
Take one variable $x_{\set{u,v}}$ for each pair of vertices $u \ne v$ in $\set{1, \ldots, n}$.
An assignment of these variables describes the graph with edge set $\set{\set{u,v} : x_{\set{u,v}} = 1}$.
Let $\mathrm{CLIQUE}_{k,n}$ be the Boolean function that is $1$ exactly when this graph contains a [[clique|0BYX1D7C2E]] with $k$ vertices.
Then there is a constant $\varepsilon > 0$ with the following property.
For all $n$ and all $k$ with $2 \le k \le n^{1/4}$, every monotone circuit for $\mathrm{CLIQUE}_{k,n}$ has at least $2^{\varepsilon \sqrt{k}}$ gates.

## Remarks

Alexander Razborov proved in 1985 the first superpolynomial lower bound for monotone circuits computing clique functions, and Alon and Boppana sharpened it to the exponential form above.
For $k = \floor{n^{1/4}}$ the bound is $2^{\varepsilon n^{1/8}}$, which is superpolynomial in the number of variables.
The proof is the method of approximations: each gate is replaced by an approximator, a small OR of "clique indicators", and the [[sunflower lemma|N6TH42TD7F]] keeps the approximators small.
Each replacement makes few errors on two test distributions, graphs consisting of one $k$-clique and complete $(k-1)$-partite graphs, but the final approximator must err on many of them.

The hypothesis of monotonicity is essential to the method.
Razborov also showed that perfect matching in bipartite graphs, which is in P, requires monotone circuits of size $n^{\Omega(\log n)}$.
So monotone circuit size can be much larger than general circuit size, and the result does not imply a lower bound for general circuits.

## Explanations

### L1 human

Deciding whether a graph has a large clique, a set of vertices all joined to each other, is an NP-complete problem.
If one is allowed only AND and OR gates, without negation, then any circuit for this problem must be exponentially large.
This was a breakthrough in the effort to prove that NP problems need large circuits.
It stops short of the goal because real circuits may use NOT gates.

### L2 human

Clique detection is a monotone function: adding edges never destroys a clique.
So it has monotone circuits, and monotone circuit size is a natural first target for lower bounds.
The approximation method and the sunflower lemma became standard tools of [[circuit complexity|4PGX7PHJCK]].
Later, Tardos gave a monotone function in P that needs exponential-size monotone circuits, which shows that the gap between monotone and general circuits can be exponential.
