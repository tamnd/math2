## Proof

We compare a structure with the truth assignment it induces, use propositional compactness to find one assignment that falsifies all instances, and turn that assignment into a structure built from closed terms.

Let $\sigma$ be a signature without equality that has at least one constant symbol.
Let $\psi$ be a quantifier-free formula whose free variables are among $x_1, \dots, x_n$.
We prove that $\exists \bar x \, \psi$ is valid if and only if some disjunction $\psi(\bar t_1) \lor \cdots \lor \psi(\bar t_k)$ with $k \ge 1$ and closed terms is a [[tautology|05006AJ7DZ]].

**Setup.**
Let $H$ be the set of closed [[terms|6D3WA7N2W4]] of $\sigma$, the [[Herbrand universe|2BVB7YDEV4]].
It is nonempty, because $\sigma$ has a constant symbol.
Let $\mathrm{At}$ be the set of atomic sentences $R\,s_1 \cdots s_m$ with $s_1, \dots, s_m \in H$.
A truth assignment is a map $v : \mathrm{At} \to \{ T, F \}$, and it extends to a map $\bar v$ on all quantifier-free sentences by the truth tables of $\neg$ and $\to$.
For a [[structure|983GZBQYT4]] $\mathcal{A}$, let $v_{\mathcal{A}}$ be the assignment with $v_{\mathcal{A}}(\alpha) = T$ if and only if $\mathcal{A} \models \alpha$.
We use the substitution lemma (see the [[soundness proof|Q2F1N068BV]]) in this form: for closed terms $\bar t$, $\mathcal{A} \models \psi(\bar t)$ if and only if $\mathcal{A} \models \psi[t_1^{\mathcal{A}}, \dots, t_n^{\mathcal{A}}]$.
This form holds because closed terms are substitutable for any variable, and replacing the $x_i$ one at a time by closed terms gives the simultaneous substitution.

**Lemma A.** For every structure $\mathcal{A}$ and every quantifier-free sentence $\chi$, $\mathcal{A} \models \chi$ if and only if $\bar v_{\mathcal{A}}(\chi) = T$.

1. We use [[structural induction|12MQ2NJ29A]] on $\chi$.
   For atomic $\chi$ the claim is the definition of $v_{\mathcal{A}}$.
2. For $\chi = \neg \alpha$, $\mathcal{A} \models \neg \alpha$ holds if and only if $\mathcal{A} \not\models \alpha$.
   By the induction hypothesis this holds if and only if $\bar v_{\mathcal{A}}(\alpha) = F$, that is, $\bar v_{\mathcal{A}}(\neg \alpha) = T$.
3. For $\chi = \alpha \to \beta$, $\mathcal{A} \not\models \alpha \to \beta$ holds if and only if $\mathcal{A} \models \alpha$ and $\mathcal{A} \not\models \beta$.
   By the induction hypothesis this holds if and only if $\bar v_{\mathcal{A}}(\alpha) = T$ and $\bar v_{\mathcal{A}}(\beta) = F$, that is, $\bar v_{\mathcal{A}}(\alpha \to \beta) = F$.

**The easy direction.**

4. Suppose that $\delta = \psi(\bar t_1) \lor \cdots \lor \psi(\bar t_k)$ is a tautology, and let $\mathcal{A}$ be any $\sigma$-structure.
5. A tautology is true under every assignment, so $\bar v_{\mathcal{A}}(\delta) = T$, and Lemma A gives $\mathcal{A} \models \delta$.
6. So $\mathcal{A} \models \psi(\bar t_i)$ for some $i$.
   By the substitution lemma, $\mathcal{A} \models \psi[\bar a]$ with $a_j = t_{i,j}^{\mathcal{A}}$, where $t_{i,j}$ is the $j$-th term of $\bar t_i$.
7. So $\mathcal{A} \models \exists \bar x \, \psi$.
   Since $\mathcal{A}$ was arbitrary, $\exists \bar x \, \psi$ is valid.

**The hard direction, by contraposition.**

8. Suppose that no disjunction $\psi(\bar t_1) \lor \cdots \lor \psi(\bar t_k)$ with $k \ge 1$ is a tautology.
   We build a structure in which $\exists \bar x \, \psi$ is false.
9. We read each member of $\mathrm{At}$ as a propositional variable, and we put $\Sigma = \{ \neg \psi(\bar t) : \bar t \in H^n \}$.
10. We claim that $\Sigma$ is finitely satisfiable.
    The empty subset is satisfied by any assignment, so let $\{ \neg \psi(\bar t_1), \dots, \neg \psi(\bar t_k) \}$ with $k \ge 1$ be a finite subset.
11. If no assignment made all $k$ formulas true, every assignment would make some $\psi(\bar t_i)$ true.
    Then $\psi(\bar t_1) \lor \cdots \lor \psi(\bar t_k)$ would be a tautology, against step 8.
12. By the [[compactness theorem for propositional logic|4X9126SEMM]], some assignment $v$ makes every member of $\Sigma$ true.
13. We define the [[Herbrand structure|HKW429DSDK]] $\mathcal{H}_v$ with universe $H$.
    A constant symbol $c$ denotes the term $c$, and an $m$-ary function symbol $f$ sends $(s_1, \dots, s_m)$ to the term $f s_1 \cdots s_m$.
14. An $m$-ary relation symbol $R$ holds of $(s_1, \dots, s_m)$ in $\mathcal{H}_v$ if and only if $v(R\,s_1 \cdots s_m) = T$.

**Lemma B.** For every closed term $t$, the value $t^{\mathcal{H}_v}$ is the term $t$ itself.

15. We use induction on $t$.
    For a constant symbol $c$, $c^{\mathcal{H}_v} = c$ by step 13.
16. For $t = f s_1 \cdots s_m$, the induction hypothesis gives $s_i^{\mathcal{H}_v} = s_i$.
    So $t^{\mathcal{H}_v} = f^{\mathcal{H}_v}(s_1, \dots, s_m) = f s_1 \cdots s_m = t$, by step 13.

**Lemma C.** For every quantifier-free sentence $\chi$, $\mathcal{H}_v \models \chi$ if and only if $\bar v(\chi) = T$.

17. By Lemma A, it is enough to show that $v_{\mathcal{H}_v} = v$ on $\mathrm{At}$.
18. Let $R\,s_1 \cdots s_m \in \mathrm{At}$.
    By Lemma B, $s_i^{\mathcal{H}_v} = s_i$, so $\mathcal{H}_v \models R\,s_1 \cdots s_m$ if and only if $(s_1, \dots, s_m) \in R^{\mathcal{H}_v}$, which holds if and only if $v(R\,s_1 \cdots s_m) = T$ by step 14.

**Lemma D.** Let $\mathcal{A}$ be a structure in which every element is $t^{\mathcal{A}}$ for some closed term $t$, and let $\theta$ have free variables among $\bar x$.
Then $\mathcal{A} \models \forall \bar x \, \theta$ if and only if $\mathcal{A} \models \theta(\bar t)$ for every $\bar t \in H^n$.

19. Suppose $\mathcal{A} \models \forall \bar x \, \theta$, and let $\bar t \in H^n$.
    Then $\mathcal{A} \models \theta[t_1^{\mathcal{A}}, \dots, t_n^{\mathcal{A}}]$, and the substitution lemma gives $\mathcal{A} \models \theta(\bar t)$.
20. Conversely, suppose that every closed instance is true, and let $a_1, \dots, a_n \in A$.
    By the hypothesis on $\mathcal{A}$, we choose closed terms $t_i$ with $t_i^{\mathcal{A}} = a_i$.
21. Then $\mathcal{A} \models \theta(\bar t)$, and the substitution lemma gives $\mathcal{A} \models \theta[a_1, \dots, a_n]$.
    Since the $a_i$ were arbitrary, $\mathcal{A} \models \forall \bar x \, \theta$.

**The end of the proof.**

22. By Lemma B, every element $s$ of $\mathcal{H}_v$ is the value of the closed term $s$, so Lemma D applies to $\mathcal{H}_v$.
23. For each $\bar t \in H^n$, $v$ makes $\neg \psi(\bar t)$ true by step 12, so $\mathcal{H}_v \models \neg \psi(\bar t)$ by Lemma C.
24. Lemma D with $\theta = \neg \psi$ gives $\mathcal{H}_v \models \forall \bar x \, \neg \psi$, so $\mathcal{H}_v \not\models \exists \bar x \, \psi$.
25. So $\exists \bar x \, \psi$ is not valid, which proves the contrapositive of the hard direction.

Steps 4 to 7 and steps 8 to 25 together prove Herbrand's theorem.

## Idea

A quantifier-free sentence has the same truth value in a structure as under the truth assignment that the structure induces.
If no finite disjunction of instances is a tautology, then the negations of all the instances are finitely satisfiable as propositional formulas.
Propositional compactness gives one assignment for all of them at once, and the Herbrand structure turns that assignment into a first-order structure.
In that structure every element is named by a closed term, so the truth of every instance of $\neg \psi$ gives the truth of $\forall \bar x \, \neg \psi$.
For $\exists x \, (P x \to P f x)$ there is no such assignment: it would need $P t$ true and $P f t$ false for every term $t$, and the terms $c$ and $fc$ already clash.

## Variants

The same proof works with a set $T$ of universal sentences as hypotheses.
We add all ground instances of members of $T$ to $\Sigma$ in step 9, and Lemma D then shows that $\mathcal{H}_v$ is a model of $T$.

We can also replace propositional compactness by the first-order [[compactness theorem|1NR3HAWG9D]], applied to the set of all ground instances of $\neg \psi$.
It gives a structure $\mathcal{A}$ in which all these instances are true.
The substructure of values of closed terms then satisfies $\forall \bar x \, \neg \psi$ by Lemma D, since quantifier-free sentences keep their truth values in substructures.

The [[proof by cut elimination|Y8PV0B46A6]] is constructive: it reads the terms $\bar t_i$ off a cut-free derivation, while the proof here only shows that some terms exist.
