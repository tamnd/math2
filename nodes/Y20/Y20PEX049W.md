## Example

Let $S_3$ be the [[symmetric group|0515A6D2Y1]] on $\{1, 2, 3\}$, with permutations composed from right to left.
It has order $3! = 6$.

1. The identity $e$ has [[order|0JPYSD5E0B]] $1$.
2. Each transposition $(1\,2)$, $(1\,3)$, $(2\,3)$ has order $2$. For example, $(1\,2)$ is not $e$, and $(1\,2)(1\,2) = e$, because swapping twice gives back each number.
3. Each $3$-cycle $(1\,2\,3)$, $(1\,3\,2)$ has order $3$. For $c = (1\,2\,3)$ we get $c^2 = (1\,3\,2) \neq e$ and $c^3 = e$, because $c$ moves each number one step around the cycle $1 \to 2 \to 3 \to 1$.
4. These are all $6$ elements: $1 + 3 + 2 = 6$.
5. The orders $1$, $2$ and $3$ all divide $6$, as the [[theorem on element orders|08V7JHS3QZ]] states.

## Remarks

No element has order $6$, so $S_3$ is not a [[cyclic group|0KVGH0J5B3]].
Thus the divisor $6$ of $|S_3|$ is not the order of an element, and the converse of the theorem fails.
The primes $2$ and $3$ do occur as orders, as Cauchy's theorem predicts.
For $S_4$, of order $24$, the element orders are $1, 2, 3, 4$, so the divisors $6$, $8$, $12$ and $24$ do not occur.

## Explanations

### L1 human

There are $6$ ways to put three books in a row.
A move that swaps two books, done twice, gives back the first row, so it has order $2$.
A move that sends each book one place to the right, with the last one going to the front, needs $3$ steps to come back.
No move needs $6$ steps, although there are $6$ arrangements.

### L2 human

We check that no element of $S_3$ has order $6$.

1. An element of order $6$ would generate a cyclic subgroup with $6$ elements, that is, all of $S_3$.
2. Then $S_3$ would be cyclic, and hence abelian.
3. But $(1\,2)(1\,3) = (1\,3\,2)$ and $(1\,3)(1\,2) = (1\,2\,3)$, so $S_3$ is not abelian.
4. Thus no element has order $6$, which agrees with steps 1 to 4 of the example.

The typical use is to find the possible element orders before a computation by hand.
A trap is to compose permutations in different orders in the same calculation, which changes the result.
