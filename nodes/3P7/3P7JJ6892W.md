## Definition

Let $A$ be a rational $m \times n$ matrix and let $b \in \Q^m$.
For $c \in \Z^n$ consider the [[linear program|VNMXB0J2KA]]
$$D(c): \quad \text{minimize } b^T y \quad \text{subject to} \quad A^T y = c, \quad y \ge 0.$$
The system $A x \le b$ is *totally dual integral* (TDI) if the following holds for every $c \in \Z^n$.
If $D(c)$ has an optimal solution, then it has an optimal solution $y \in \Z^m$.

## Remarks

The program in the definition is the [[dual|14VMJNXMDC]] of maximizing $c^T x$ subject to $A x \le b$.

Example: the one-variable system $x \le 1$ is TDI.
For $c \in \Z$ the dual is to minimize $y$ subject to $y = c$ and $y \ge 0$; it has an optimal solution exactly when $c \ge 0$, and then $y = c$ is an integer.

Non-example: the system $2 x \le 2$ describes the same [[polyhedron|0325SGSJAR]] $\set{x \le 1}$, but it is not TDI.
For $c = 1$ the dual is to minimize $2y$ subject to $2y = 1$ and $y \ge 0$, whose only feasible solution is $y = 1/2$.

Edmonds–Giles theorem: if $A x \le b$ is TDI and $b$ is integral, then every minimal nonempty face of $\set{x : A x \le b}$ contains an integer point.
In particular, if the polyhedron has vertices, they are all integral.
Every rational polyhedron has a TDI description with $A$ integral, and when the polyhedron is integral one can choose $b$ integral as well.
If $A$ is [[totally unimodular|VSD67A49XC]], then $A x \le b$ is TDI for every $b$.
