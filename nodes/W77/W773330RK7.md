## Example

Let $0 \le \varepsilon \le 1$.
The *binary symmetric channel* with crossover probability $\varepsilon$ has input and output alphabets $\set{0, 1}$ and transition probabilities
$$W(1 \mid 0) = W(0 \mid 1) = \varepsilon, \qquad W(0 \mid 0) = W(1 \mid 1) = 1 - \varepsilon.$$
Each row of $W$ is a probability vector, so this is a [[communication channel|B9C5RBFATB]].
Used $n$ times without memory, it flips each bit independently with probability $\varepsilon$.

Its [[capacity|J7MZ2XQP9M]] is $C = 1 - h(\varepsilon)$ bits, where $h$ is the [[binary entropy function|GW25TGD33J]].
The check: for any input law, the [[mutual information|A83CYGDXFG]] is $I(X; Y) = H(Y) - H(Y \mid X)$.
Given $X = x$, the output is $x$ or its flip with probabilities $1 - \varepsilon$ and $\varepsilon$, so $H(Y \mid X) = h(\varepsilon)$.
Since $H(Y) \le 1$, one gets $I(X; Y) \le 1 - h(\varepsilon)$.
The uniform input makes $Y$ uniform, so $H(Y) = 1$ and the bound is reached.

For $\varepsilon = 0.1$ this gives $C \approx 0.531$.
For $\varepsilon = 1/2$ the output is independent of the input and $C = 0$.
For $\varepsilon = 1$ the channel always flips, and $C = 1$, since the receiver can flip the bits back.

## Explanations

### L1 human

This is the standard model of a noisy line for bits: each bit arrives correctly with probability $1 - \varepsilon$ and flipped with probability $\varepsilon$, independently.
Its capacity $1 - h(\varepsilon)$ is the number of useful bits per bit sent, when good long codes are used.
The worst case is $\varepsilon = 1/2$, where the output is pure noise.
