## Definition

A *sealed-bid auction* of a single indivisible object among a finite set $N = \set{1, \dots, n}$ of bidders is given by:

1. an allocation rule, assigning to each bid profile $b = (b_1, \dots, b_n) \in [0, \infty)^n$ numbers $q_i(b) \ge 0$ with $\sum_i q_i(b) \le 1$, the probability that bidder $i$ gets the object;
2. a payment rule, assigning to each bid profile $b$ numbers $p_i(b) \in \R$, the payment of bidder $i$.

In the *independent private values model*, each bidder $i$ has a value $v_i \ge 0$ for the object, known only to her.
The values are independent random variables, and their distributions are known to all.
Bidder $i$ with value $v_i$ receives utility $v_i q_i(b) - p_i(b)$.
The auction and the distributions define a [[Bayesian game|2XQ7VWT8KJ]] in which a strategy of bidder $i$ is a bid function $\beta_i \colon [0, \infty) \to [0, \infty)$.

## Remarks

An auction is a [[mechanism|DTXJQKEHDP]] whose strategy sets are sets of bids.
Example: the second-price auction has $q_i(b) = 1$ and $p_i(b) = \max_{j \ne i} b_j$ when $b_i$ is the unique highest bid.
It has $q_i(b) = p_i(b) = 0$ when $b_i$ is below the highest bid, and ties are broken by a fixed rule.
Non-example: a rule that gives the object to every bidder with $q_i(b) = 1$ for all $i$ fails clause 1 when $n \ge 2$, since there is only one object.
Open auctions, such as the English ascending auction, are modelled as extensive-form games instead.
The *revenue* of an auction is the expected sum of the payments in a given equilibrium.

## Explanations

### L1 human

An auction format is specified by who gets the object and who pays what, for every possible set of bids.
Adding the bidders' private values turns it into a game of incomplete information, and auction theory studies its equilibria.
