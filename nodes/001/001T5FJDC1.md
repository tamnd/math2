## Summary

A block diagonal matrix is a square [[block matrix|0ASDFEQS6P]] whose diagonal blocks are square and whose other blocks are all zero.
The [[formal definition|0M0SNKZ482]] writes it as $\operatorname{diag}(A_1, \dots, A_k)$ or $A_1 \oplus \cdots \oplus A_k$, the direct sum of the blocks.
It generalizes the [[diagonal matrix|044JNC7ZAA]], whose blocks are $1 \times 1$.
Sums, products, powers and inverses of block diagonal matrices are computed block by block.

## Motivation

Suppose that $V = U_1 \oplus \cdots \oplus U_k$ and that a linear map $T$ sends each $U_i$ into itself.
In a basis made of bases of the $U_i$, the matrix of $T$ is block diagonal.
So a block diagonal matrix splits a problem into $k$ smaller independent problems.
Normal forms, such as the [[Jordan normal form|085HQ5G5TE]], are block diagonal for this reason.

## Notation

- $\operatorname{diag}(A_1, \dots, A_k)$, $A_1 \oplus \cdots \oplus A_k$ and $\bigoplus_i A_i$ are all common.
- In Mathlib, `Matrix.blockDiagonal` takes a family of blocks of one shape, indexed by a type `o`. Its rows are indexed by the product type `m × o`.
- `Matrix.blockDiagonal'` allows blocks of different sizes, and its rows are indexed by a sigma type.
- So a reindexing is needed to compare these matrices with a matrix indexed by `Fin n`.

## Remarks

### Examples

- [[Powers and the inverse of a block diagonal matrix|D5885TV9MW]].
- [[A rotation about an axis in R³|TZCTBFEM13]] is $\operatorname{diag}(R_\theta, 1)$.
- Each [[diagonal matrix|044JNC7ZAA]] is block diagonal with $1 \times 1$ blocks.

### Non-examples

- [[A block anti-diagonal matrix|PCAKQ72AW3]] is not block diagonal.
- A block upper triangular matrix with a nonzero block above the diagonal is not block diagonal.

### Basic properties

Let $A = \operatorname{diag}(A_1, \dots, A_k)$ and $B = \operatorname{diag}(B_1, \dots, B_k)$ with $A_i$ and $B_i$ of the same order $n_i$.

- $A + B = \operatorname{diag}(A_1 + B_1, \dots, A_k + B_k)$.
- $AB = \operatorname{diag}(A_1 B_1, \dots, A_k B_k)$, by the [[block multiplication rule|WR3RCF5PSQ]].
- So $A^m = \operatorname{diag}(A_1^m, \dots, A_k^m)$, and $p(A) = \operatorname{diag}(p(A_1), \dots, p(A_k))$ for each polynomial $p$.
- $A$ is [[invertible|0EB9N0S33C]] if and only if each $A_i$ is invertible, and then $A^{-1} = \operatorname{diag}(A_1^{-1}, \dots, A_k^{-1})$.
- $\operatorname{tr} A = \sum_i \operatorname{tr} A_i$, and over a commutative ring $\det A = \prod_i \det A_i$.
- $A^{\mathsf{T}} = \operatorname{diag}(A_1^{\mathsf{T}}, \dots, A_k^{\mathsf{T}})$.
- The subspaces spanned by the standard basis vectors of each block are [[invariant subspaces|0ACX5QT8TE]] of $A$.

### Common errors

- Allowing non-square diagonal blocks. Then the diagonal blocks do not lie on the main diagonal.
- Expecting block diagonal matrices to commute. $\operatorname{diag}(A_1, A_2)$ and $\operatorname{diag}(B_1, B_2)$ commute only when $A_1 B_1 = B_1 A_1$ and $A_2 B_2 = B_2 A_2$.

## Explanations

### L1 human

A block diagonal matrix has square blocks along the diagonal and zeros everywhere else.
Each block acts on its own group of coordinates and ignores the other coordinates.
So we can study each block separately.

### L2 human

The matrix of a map is block diagonal exactly when the basis splits into groups and the map keeps the span of each group.
The search for a basis that makes a matrix block diagonal with small blocks is the search for [[invariant subspaces|0ACX5QT8TE]].

### L3 human

The direct sum $A_1 \oplus A_2$ is the matrix of the direct sum of two modules over $R[x]$.
The structure theory of linear maps writes each matrix over a field as a direct sum of indecomposable blocks.
