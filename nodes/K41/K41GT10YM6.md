## Statement

Let $F$ be a [[field|04C5ZBG1WT]], let $M$ be an $m \times k$ matrix over $F$, and let $\rho$ be an [[elementary row operation|04XWH28452]] on $m$ rows.
Write $\rho(M)$ for the result of applying $\rho$ to $M$.

1. (Reversibility.) There is an elementary row operation $\rho'$ of the same type with $\rho'(\rho(M)) = M$ for every $m \times k$ matrix $M$.
2. (Matrix form.) Let $E = \rho(I_m)$. Then $\rho(M) = EM$ for every $m \times k$ matrix $M$, and $E$ is invertible with $E^{-1} = \rho'(I_m)$.
3. (Solution sets.) Let $A$ be $m \times n$, let $b \in F^m$, and let $[A' \mid b'] = \rho([A \mid b])$. Then the systems $Ax = b$ and $A'x = b'$ have the same solution set in $F^n$.

## Remarks

### Why each hypothesis is needed

1. Scaling needs $c \ne 0$. Scaling the equation $x - y = 1$ by $0$ gives $0 = 0$, and the system $x + y = 3$, $x - y = 1$ gains the solution $(3, 0)$, see [[the non-examples|EBR5JMWFAE]].
2. Row addition needs $i \ne j$. The step $R_1 \leftarrow R_1 + (-1) R_1$ turns $R_1$ into a zero row and can gain solutions.
3. Row operations must be applied one at a time. Replacing $R_1$ by $R_1 + R_2$ and $R_2$ by $R_2 + R_1$ at the same time is not a sequence of elementary operations, and it can gain solutions, see [[the non-examples|EBR5JMWFAE]].
4. $F$ must be a field, so that $c \ne 0$ has an inverse. Over the ring $\mathbb{Z}/4\mathbb{Z}$, scaling $x = 1$ by $2$ gives $2x = 2$, which has the extra solution $x = 3$.

### Consequences

1. Row equivalent systems have the same solution set, see [[row equivalence|006BHFWMAP]] and [[its properties|E4GKK727ZM]].
2. If $B$ comes from $A$ by a sequence of row operations, then $B = PA$ with $P$ an invertible product of [[elementary matrices|01REXW3WWE]].
3. Row operations on $[A \mid B]$ act on both blocks at once: $E[A \mid B] = [EA \mid EB]$.

### Converse

The converse "same solution set implies row equivalent augmented matrices" is false in general.
The systems $x = 0$, $x = 1$ and $0x = 1$, $0x = 0$ both have no solution, but their reduced forms $\left[\begin{array}{c|c} 1 & 0 \\ 0 & 1 \end{array}\right]$ and $\left[\begin{array}{c|c} 0 & 1 \\ 0 & 0 \end{array}\right]$ differ.
For consistent systems with the same number of equations, the converse is true; it follows from the [[uniqueness of the RREF|BF9SMZMJZE]].

## History

Elimination by adding multiples of one equation to another is the method of the "Fangcheng" chapter of the *Nine Chapters on the Mathematical Art*.
The description of the three operations by elementary matrices is standard in modern textbooks.

## Explanations

### L1 human

When we solve equations by hand, we swap equations, multiply an equation by a nonzero number, or add a multiple of one equation to another.
Each of these moves can be undone by a move of the same kind.
So the new equations are true exactly when the old ones are.
This is why elimination never loses a solution and never invents one.

### L2 human

We apply $R_2 \leftarrow R_2 - 3R_1$ to the system $x + 2y = 5$, $3x + 4y = 6$.

1. The new second equation is $(3x + 4y) - 3(x + 2y) = 6 - 15$, that is, $-2y = -9$.
2. A solution of the old system satisfies both old equations, so it satisfies their combination $-2y = -9$.
3. The inverse step $R_2 \leftarrow R_2 + 3R_1$ gives back $3x + 4y = 6$.
4. So a solution of the new system is a solution of the old one.
5. Both systems have the solution $(-4, \tfrac92)$: $-4 + 9 = 5$, $-12 + 18 = 6$ and $-2 \cdot \tfrac92 = -9$.

The typical use is to justify every step of [[Gaussian elimination|0JVJ2WCXZH]].
A trap: "multiply an equation by $x$" or "divide by an expression that can be $0$" is not an elementary row operation, and it can change the solution set.

### L3 human

Part 2 says that row operations are left multiplications by invertible matrices.
Since $EA x = Eb$ and $Ax = b$ are equivalent for any invertible $E$, part 3 holds for every invertible $E$, not only for elementary ones.
Over a field, every invertible matrix is a product of elementary matrices, so row equivalence means $B = PA$ with $P$ in the general linear group.
Over a ring, scaling is allowed only by units, and row operations give the orbits of $\mathrm{GL}_m$ on matrices; this leads to Hermite and Smith normal forms.
