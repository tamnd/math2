## Summary

There is a binary tree that a computer can list level by level, but that no computer can climb.
It has an element of every length, so it is infinite, and still no computable 0-1 sequence is an infinite branch through it.
$\mathsf{WKL}_0$ is the system that adds the missing branches.
Its axioms are those of [[RCA0|XQENB067R3]] together with weak König's lemma, which says that every infinite binary tree has a path, as in the [[formal definition|K5YPW1NTHZ]]:
$$\mathsf{WKL}_0 = \mathsf{RCA}_0 + \forall T \subseteq 2^{<\mathbb{N}}\, \big(T \text{ is an infinite tree} \to \exists f\, \forall n\, (f {\restriction} n \in T)\big).$$
It is the second of the big five systems of [[second-order arithmetic|DC60FYCSPM]], and it is the system of compactness arguments.

## Motivation

The computable sets form a model of $\mathsf{RCA}_0$, so every theorem of $\mathsf{RCA}_0$ is true in computable mathematics.
Many theorems of analysis fail there.
A computable continuous function on $[0, 1]$ can have no computable point where it reaches its maximum.
A computable sequence of open intervals can cover every computable real in $[0, 1]$ and still have no finite subsequence that does the same.
The classical proofs of these theorems use compactness, and compactness in its plainest form is a path through an infinite binary tree.

So $\mathsf{WKL}_0$ adds exactly this one principle, and the theorems that need it turn out to need nothing more.
The [[Heine-Borel theorem for the unit interval|KRS3VTWCHJ]] is equivalent to it, and so are the extreme value theorem, the Brouwer fixed point theorem and Gödel's completeness theorem for countable languages.
The system returns in the study of conservation, because it proves no new statements about numbers, and in [[partial realizations of Hilbert's program|Z26S516BKH]].

## Notation

We write $\mathrm{WKL}$ for the sentence of weak König's lemma and $\mathsf{WKL}_0 = \mathsf{RCA}_0 + \mathrm{WKL}$ for the system.
The subscript $0$ says that induction is restricted to $\Sigma^0_1$ formulas, as in $\mathsf{RCA}_0$.
Some books spell the name Kőnig, after Dénes Kőnig, and write $2^{<\mathbb{N}}$ as $\{0, 1\}^{<\omega}$ or $2^{<\omega}$.

## Remarks

### A computable tree with no computable path

Let $\varphi_e$ be the $e$-th program, and say that $\varphi_e(e)$ *halts by stage $s$* when it stops within $s$ steps.
Put a 0-1 sequence $\sigma$ in $T$ when, for each $e < \lvert \sigma \rvert$ such that $\varphi_e(e)$ halts by stage $\lvert \sigma \rvert$ with output $0$ or $1$, the entry $\sigma(e)$ differs from that output.
A machine decides membership in $T$ by running finitely many programs for finitely many steps.

Shortening $\sigma$ gives fewer entries and a smaller stage, so the conditions only get weaker and $T$ is a tree.
For each length $n$, the sequence with $\sigma(e) = 1$ when $\varphi_e(e)$ halts by stage $n$ with output $0$, and $\sigma(e) = 0$ otherwise, is in $T$.
So $T$ is infinite.

Now suppose that a total program $\varphi_d$ with values $0$ and $1$ computed a path $f$.
Then $\varphi_d(d)$ halts with output $f(d)$, and at a late enough level the tree forces $f(d) \ne \varphi_d(d) = f(d)$.
This is impossible, so $T$ has no computable path.
This tree is the [[separation tree|X9911PGV0N]], and it shows that the computable sets do not satisfy $\mathrm{WKL}$.

### Binary trees and finitely branching trees

König's lemma for finitely branching trees says that every infinite tree in which each node has finitely many children has a path.
Over $\mathsf{RCA}_0$ it is [[equivalent to ACA0|3P2J5NWCM1]], which is much stronger than $\mathsf{WKL}_0$.
The difference is the bound on the children.
In a binary tree we know in advance that each node has at most the two children $\sigma 0$ and $\sigma 1$.

In the reversal of König's lemma, the node $\sigma$ has the child $j + 1$ exactly when $f(j) = \lvert \sigma \rvert$ for a given one-to-one function $f$.
The tree is finitely branching, but a bound on the children of $\sigma$ requires knowing whether $\lvert \sigma \rvert$ is in the range of $f$, which is the halting problem in disguise.
When a bound is given as a function along with the tree, the principle is again equivalent to $\mathsf{WKL}_0$.

### Models that pass and models that fail

The [[computable sets|F5T3F7E0H1]] form a model of $\mathsf{RCA}_0$ but not of $\mathsf{WKL}_0$, by the tree above.
The [[sets computable from the halting set|7KCGVY6XJM]] fail too, because the same tree built with the halting set as oracle has no path computable from it.

On the other side, the [[arithmetical sets|9KPCZ6NA32]] form a model of $\mathsf{WKL}_0$, since they satisfy $\mathsf{ACA}_0$.
A smaller model comes from the low basis theorem: there is an [[ω-model of WKL0 in which every set is low|8B045KSKW5]].
The halting set is not low, so that model omits it, and $\mathsf{WKL}_0$ does not prove $\mathsf{ACA}_0$.

### What the system proves and what it adds

Over $\mathsf{RCA}_0$, weak König's lemma is equivalent to each of the following: the Heine-Borel theorem for $[0, 1]$, the boundedness and the maximum of continuous functions on $[0, 1]$, Gödel's completeness theorem for countable languages, the Brouwer fixed point theorem, the Hahn-Banach theorem for separable Banach spaces, and the existence of a prime ideal in every countable commutative ring.

Yet these new theorems say nothing new about numbers.
$\mathsf{WKL}_0$ is [[Π¹₁-conservative over RCA0|8G2GVRXWG5]], so both systems prove the same arithmetical sentences, and its first-order part is $\mathrm{I}\Sigma_1$.
It is also [[Π⁰₂-conservative over primitive recursive arithmetic|V609D9SZ05]], and its proof-theoretic ordinal is $\omega^\omega$, the same as that of $\mathsf{RCA}_0$.

### Watch out

Weak König's lemma does not say which path exists, and it does not say that a path can be computed from the tree.
A frequent wrong move in a proof is to take the set of nodes of $T$ that have extensions of every length, and then to climb inside that set.
That set is defined by a $\Pi^0_1$ formula, and it exists in $\mathsf{ACA}_0$ but in general not in $\mathsf{WKL}_0$.
For the separation tree above, that set tells us for each $e$ whether $\varphi_e(e)$ halts with output $0$ or $1$, and so it computes the halting set.
A proof that uses it has silently assumed $\mathsf{ACA}_0$.
The correct move is to apply $\mathrm{WKL}$ to the tree itself and accept the path it gives.

### History

Harvey Friedman introduced $\mathsf{WKL}_0$ in his first papers on reverse mathematics in the 1970s.
Leo Harrington proved its $\Pi^1_1$ conservativity over $\mathsf{RCA}_0$.
Stephen Simpson proposed in 1988 that $\mathsf{WKL}_0$ gives a partial realization of Hilbert's program.

### Try it

First, is the set of all 0-1 sequences with at most one entry equal to $1$ an infinite binary tree, and what are its paths?
Yes: deleting entries cannot add a $1$, and the all-zero sequences give every length.
Its paths are the constant function $0$ and the functions with exactly one value $1$.

Second, why does $\mathsf{RCA}_0$ already prove that the full binary tree $2^{<\mathbb{N}}$ has a path?
The constant function $0$ exists by $\Delta^0_1$ comprehension, and it is a path, so no use of $\mathrm{WKL}$ is needed.

## Explanations

### L1 human

Think of a tree of choices: at each step you choose $0$ or $1$, and some sequences of choices are forbidden.
If there are allowed sequences of every length, weak König's lemma says that there is an infinite sequence of choices all of whose beginnings are allowed.
A computer can check that the allowed sequences never run out, and still be unable to produce such an infinite sequence.
$\mathsf{WKL}_0$ is computable mathematics with this one extra promise.

### L2 human

Here is a typical proof in $\mathsf{WKL}_0$: two disjoint sets $A$ and $B$ that are enumerated by functions $a$ and $b$ have a separating set, that is, a set $S$ with $A \subseteq S$ and $S \cap B = \emptyset$.
Put $\sigma$ in $T$ when for every $i, j < \lvert \sigma \rvert$ with $a(i) < \lvert \sigma \rvert$ and $b(j) < \lvert \sigma \rvert$ we have $\sigma(a(i)) = 1$ and $\sigma(b(j)) = 0$.
This is a bounded condition, so $T$ exists by $\Delta^0_1$ comprehension, and shortening $\sigma$ weakens it, so $T$ is a tree.

For each $n$, the sequence of length $n$ with value $1$ at the points $a(i) < n$ with $i < n$, and $0$ elsewhere, is in $T$, because no point is both some $a(i)$ and some $b(j)$.
So $T$ is infinite, and $\mathrm{WKL}$ gives a path $f$.
The set $S = \{ m : f(m) = 1 \}$ contains each $a(i)$, by the condition at a level above $i$ and $a(i)$, and in the same way it misses each $b(j)$.
This shows the typical use: describe the wanted object by finite conditions, check that the conditions can be met at every length, and let $\mathrm{WKL}$ supply the infinite object.

### L3 human

A Turing degree computes a path through every infinite computable binary tree exactly when it is a PA degree, that is, when it computes a complete consistent extension of Peano arithmetic.
So the $\omega$-models of $\mathsf{WKL}_0$ are the Scott sets, which are also the standard systems of the countable nonstandard models of Peano arithmetic.
The weaker principle of [[weak weak König's lemma|BJQ77Y2QFX]], for trees of positive measure, connects the same circle of ideas to measure theory and algorithmic randomness.
In the [[reverse mathematics zoo|E3X5B175ZR]], many combinatorial principles are compared with $\mathsf{WKL}_0$, and [[Ramsey's theorem for pairs|ZT5KV6KJ3E]] is one that neither implies it nor follows from it.
