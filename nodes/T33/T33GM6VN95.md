## Statement

Let $n \ge 2$ and let $U \subseteq \C^n$ be a [[connected|0SPE8WNWFV]] [[open set|02BH3MCBQB]], that is, a domain.
Let $f$ be a [[holomorphic function|507C34W0ZT]] on $U$.
If $f$ has at least one zero in $U$, then the set $\set{z \in U : f(z) = 0}$ is not a [[compact set|0R6EWFKRCF]].

## Remarks

The result is a consequence of the phenomenon behind [[Hartogs's extension theorem|FSGES670AZ]]: a compact set of zeros would give a compact set of singularities of $1/f$, and such singularities can be removed when $n \ge 2$.

The hypothesis $n \ge 2$ is necessary. In $\C$ the function $f(z) = z$ has the compact zero set $\set{0}$.

The hypothesis that $U$ is connected is used. If $U$ is a disjoint union of two balls, then $f$ equal to $0$ on one ball and $1$ on the other has a compact zero set that is nonempty.

Example: the zero set of $z_1^2 + z_2^2 - 1$ in $\C^2$ is a closed unbounded set, not a compact one.
