## Summary

A proof checker reads a list of formulas and tests each line: is it an axiom, or does it follow from earlier lines by a rule?
Arithmetization of syntax shows that every one of these tests is a computation on numbers, and that a weak theory of arithmetic can prove the outcome of each computation.

The method has three stages.
First, a [[Gödel numbering|MFJXPAF0R0]] codes symbols, formulas and proofs by numbers.
Second, the syntactic relations, such as "$x$ codes a formula" and "$y$ codes a proof of $x$ in $T$", become [[primitive recursive|5NVA2JRHPV]] relations on codes, provided the axioms of $T$ form a primitive recursive set (for a decidable set of axioms, the proof relation is decidable).
Third, each such relation is represented in [[Robinson arithmetic|3K1AKGXF8A]] $\mathsf{Q}$ by a formula, which gives the proof predicate $\mathrm{Prf}_T(y, x)$.

## Motivation

The incompleteness theorems need a sentence that talks about its own provability.
A theory of arithmetic talks only about numbers.
So we must show that "$y$ is a proof of $x$ in $T$" is a property of numbers, that a formula expresses it, and that $T$ proves the true instances.
Arithmetization does this work once, for every theory whose axioms can be recognized by a program.

The idea is the same one that lets a computer check a proof written in Lean or Coq.
The proof is stored as data, and the checker is a program that runs on the data.
Arithmetization replaces the program by a formula of arithmetic, and it replaces running the program by proving the formula in $\mathsf{Q}$.
All of incompleteness theory, from the [[provability predicate|NB2BCZR40F]] to [[Löb's theorem|3HD30YG3DG]], rests on it.

## Notation

We write $\underline{n}$ for the numeral of $n$, and $\ulcorner \varphi \urcorner$ for the numeral of the code $\# \varphi$.
The usual names of the coded relations are $\mathrm{Form}(x)$ and $\mathrm{Sent}(x)$ for "$x$ codes a formula" and "a sentence", and $\mathrm{Ax}_T(x)$ for "$x$ codes an axiom of $T$".
The function $\mathrm{sub}(x, n)$ gives the code of the result of putting $\underline{n}$ for the free variable $v_0$ in the formula with code $x$.
$\mathrm{Prf}_T(y, x)$ says that $y$ codes a proof in $T$ of the formula with code $x$, and books use the same symbol for the relation and for the formula that represents it.
Some books put the arguments in the other order, $\mathrm{Prf}_T(x, y)$, so check which argument is the proof.

## Remarks

### Checking a proof by arithmetic

Suppose $y$ codes the list of formulas $\varphi_1, \ldots, \varphi_k$, so that $y = 2^{\# \varphi_1} 3^{\# \varphi_2} \cdots p_k^{\# \varphi_k}$.
The number of lines $k$ is the number of primes that divide $y$, and the code of line $i$ is the exponent of $p_i$ in $y$.
For each line, we test whether it is an axiom, with the test $\mathrm{Ax}_T$, or whether two earlier lines give it by modus ponens.
Last, we test whether the final line has code $x$.
Every test searches only below $y$, so $\mathrm{Prf}_T(y, x)$ is primitive recursive whenever $\mathrm{Ax}_T$ is.
[[The proof predicate of Peano arithmetic is decidable|QGR9FT4EHP]] carries this out for $\mathsf{PA}$, and [[concatenation of codes|YZHC2B7YT5]] shows one of the building blocks in full.

### The small functions that make it work

Two functions turn up again and again.
The numeral function $\mathrm{num}(n) = \# \underline{n}$ is primitive recursive, since $\mathrm{num}(0) = \# 0$ and $\mathrm{num}(n + 1)$ is the code of $S$ followed by the string with code $\mathrm{num}(n)$.
The diagonal function $d(n) = \mathrm{sub}(n, n)$ puts the numeral of the code of a formula into the formula itself.
It is primitive recursive as a composition, and it is the engine of the [[diagonal lemma|3PRW76471J]].

### What Q can prove about codes

Primitive recursive is a fact about $\mathbb{N}$, and we still need proofs inside a theory.
The representability theorem gives them.
For each [[computable|KZSB5E471K]] relation $R \subseteq \mathbb{N}^k$ there is a formula $\varphi_R(\vec{x})$ with two properties for all $\vec{n}$.
If $R(\vec{n})$ holds, then $\mathsf{Q} \vdash \varphi_R(\underline{\vec{n}})$, and if $R(\vec{n})$ fails, then $\mathsf{Q} \vdash \neg \varphi_R(\underline{\vec{n}})$.
For a primitive recursive relation, $\varphi_R$ can be chosen to be $\Sigma_1$, that is, an existential quantifier block in front of a formula with only bounded quantifiers.

A second fact is $\Sigma_1$-completeness: every $\Sigma_1$ sentence that is true in $\mathbb{N}$ is provable in $\mathsf{Q}$.
Every theory that proves the axioms of $\mathsf{Q}$ inherits both facts.
So once $\mathrm{Prf}_T$ is represented, a real proof with code $p$ of a formula $\varphi$ gives $T \vdash \mathrm{Prf}_T(\underline{p}, \ulcorner \varphi \urcorner)$.

### How the representation is built

The representability theorem is proved by induction on the definition of a recursive function, and [[its proof|4T3MSP1SPK]] gives it in full.
The zero function, the successor and the projections are represented by $y = 0$, $y = S x$ and $y = x_i$.
A composition is represented by an existential quantifier over the intermediate values.
A minimization $\mu z \, (g(\vec{x}, z) = 0)$ is represented by saying that $z = y$ works and that no $z < y$ works.
This uses two facts about $\mathsf{Q}$, that $z \le \underline{n}$ implies $z = 0 \vee \cdots \vee z = \underline{n}$, and that $z \le \underline{n} \vee \underline{n} \le z$.
Primitive recursion needs finite sequences, and [[Gödel's β-function lemma|BM6P0C2AC2]] codes them with addition and multiplication alone.

### Where the method stops

The axioms must form a decidable set.
The theory of all sentences true in $\mathbb{N}$ is consistent and contains $\mathsf{Q}$, but [[true arithmetic has no decidable axiom set|69TTX21TRJ]], so no proof predicate in this sense exists for it.
For an axiom set that is only computably enumerable, Craig's trick first replaces it by a decidable axiom set with the same theorems, and then the method applies.
A numbering that is not computable, such as [[coding sentences by their truth value|Y4VRPDEV6K]], gives no primitive recursive syntax at all.

### Watch out

Do not forget the hypothesis on the axioms.
Without a decidable $\mathrm{Ax}_T$, the proof relation need not be decidable, and nothing in the method goes through.
Second, representability does not need induction.
It holds in $\mathsf{Q}$, which has no induction axioms, and that is why the incompleteness theorems apply to such weak theories.
Third, "$\varphi$ represents $R$ in $\mathsf{Q}$" is stronger than "$\varphi$ defines $R$ in $\mathbb{N}$": it asks for a proof in $\mathsf{Q}$ of each true instance and of the negation of each false one.

### History

Gödel arithmetized syntax in his 1931 paper "Über formal unentscheidbare Sätze der Principia Mathematica und verwandter Systeme I".
He used prime-power codes and a long chain of primitive recursive definitions that ends with the proof relation.
His β-function let him express recursive definitions with addition and multiplication alone.
Raphael Robinson introduced the finite theory $\mathsf{Q}$ in 1950, and it became the standard base theory for representability.

### Try it

Why is "$x$ codes a formula" primitive recursive with prime-power codes?
A string is a formula when it is atomic or is built by one rule from shorter formulas, and the parts of a string have smaller codes, so a course-of-values recursion below $x$ decides it.

Is the set of theorems of $\mathsf{PA}$ decidable because $\mathrm{Prf}_{\mathsf{PA}}$ is?
No: the set of theorems is $\{ x : \exists y \, \mathrm{Prf}_{\mathsf{PA}}(y, x) \}$, and the search over $y$ has no bound.

## Explanations

### L1 human

A careful reader can check a written proof line by line, the way a computer checks a program.
Arithmetization shows that this checking is arithmetic: it uses only adding, multiplying and comparing numbers.
After coding, "this list of formulas is a proof of $0 = 0$" becomes a statement about two numbers.
Then arithmetic itself can state facts about proofs, and a theory can talk about what it can prove.

### L2 human

We check a short proof in $\mathsf{PA}$ by arithmetic.
Let $\varphi$ be the axiom $\forall v \, (v + 0 = v)$ and let $\psi$ be the logical axiom $\forall v \, (v + 0 = v) \to 0 + 0 = 0$.
Modus ponens gives $0 + 0 = 0$, so the proof is the list $\varphi, \psi, 0 + 0 = 0$, with code
$$y = 2^{\# \varphi} \cdot 3^{\# \psi} \cdot 5^{\#(0 + 0 = 0)}.$$
The test reads three exponents, finds that line $1$ is an axiom of $\mathsf{PA}$ and line $2$ a logical axiom, and checks that the exponent of $3$ is the code of line $1$, then $\to$, then line $3$, in parentheses.
So $\mathrm{Prf}_{\mathsf{PA}}(y, \ulcorner 0 + 0 = 0 \urcorner)$ is true, and by $\Sigma_1$-completeness $\mathsf{Q}$ proves it.
The proof checker became a theorem of arithmetic, and this step is how a theory comes to prove facts about its own proofs.

### L3 human

Arithmetization says that $\mathbb{N}$ with addition and multiplication can simulate every finite combinatorial structure: strings, trees and finite sequences.
The same simulation shows that the theory of $(\mathbb{N}, +, \cdot)$ is undecidable, while [[Presburger arithmetic|4W0E9G7PPV]], the theory of $(\mathbb{N}, +)$, is decidable.
In computability theory the same idea gives Kleene's $T$ predicate, which codes the runs of a machine.
Bounded arithmetic carries out arithmetization with codes of polynomial size, and the [[provability predicate|NB2BCZR40F]] and the [[derivability conditions|F6H4STF9RG]] are its direct products.
