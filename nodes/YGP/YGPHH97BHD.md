## Summary

Let $U \subset \C^n$ be open. Both notions are defined by restricting a function to complex lines $\xi \mapsto a + b\xi$ with $a, b \in \C^n$, on the open set of $\xi \in \C$ where the point lies in $U$.

A function $f \colon U \to \R$ of class $C^2$ is a [[pluriharmonic function|4A7VAXPG4F]] if each such restriction is [[harmonic|0DEB0JMN0W]]. In words, $f$ is harmonic on every complex line.

A function $f \colon U \to \R \cup \{-\infty\}$ is a [[plurisubharmonic function|FF2P7ER3QT]] if it is upper semicontinuous and each such restriction is [[subharmonic|Z1MHMGFNFW]]. The short names are psh and plush.
