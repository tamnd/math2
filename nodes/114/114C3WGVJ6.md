## Example

Take a moment $m$ with two histories, $H_m = \set{h_1, h_2}$, and two agents with the same partition:
$$\mathrm{Choice}^m_1 = \mathrm{Choice}^m_2 = \set{\set{h_1}, \set{h_2}}.$$
Let $p$ be true at $m/h_1$ and false at $m/h_2$.
We show that this is not a frame of [[STIT logic|WYY2JXWMYY]], and that the independence axiom fails on it.

1. Each $\mathrm{Choice}^m_i$ is a partition of $H_m$, so each agent alone is well modelled.
2. Pick the cell $\set{h_1}$ for agent 1 and the cell $\set{h_2}$ for agent 2.
3. Their intersection is $\emptyset$. So the independence condition of STIT frames fails.
4. At $m/h_1$, the cell of agent 1 is $\set{h_1}$, so $[1]p$ is true. Hence $\lozenge[1]p$ is true at $m/h_1$.
5. At $m/h_2$, the cell of agent 2 is $\set{h_2}$, so $[2]\neg p$ is true. Hence $\lozenge[2]\neg p$ is true at $m/h_1$.
6. At $m/h_1$, $[2]\neg p$ is false, since $p$ holds there. At $m/h_2$, $[1]p$ is false, since $p$ fails there.
7. So $[1]p \wedge [2]\neg p$ is false on both histories, and $\lozenge([1]p \wedge [2]\neg p)$ is false at $m/h_1$.
8. Hence $\lozenge[1]p \wedge \lozenge[2]\neg p \to \lozenge([1]p \wedge [2]\neg p)$ fails at $m/h_1$.

## Remarks

In this structure the choice of agent 1 decides the choice of agent 2, so the two agents do not act at the same time and independently.
The independence condition says that no agent can restrict the options of another agent at the same moment.
If agent 2 had the trivial partition $\set{H_m}$, independence would hold again, since each cell of agent 1 meets $H_m$.
A version of the example with a second moment, where agent 2 chooses after seeing the choice of agent 1, is a correct STIT model: the choices are then at different moments.

## Explanations

### L1 human

Two people are said to choose at the same time between "left" and "right".
But the model says: whenever the first picks left, the second also picks left.
Then the second person has no real choice of her own.
STIT logic forbids this, because choices at the same moment must be free of each other.

### L2 human

1. Form all pairs of cells, one cell for each agent: $(\set{h_1}, \set{h_1})$, $(\set{h_1}, \set{h_2})$, $(\set{h_2}, \set{h_1})$, $(\set{h_2}, \set{h_2})$.
2. Intersect each pair; two of the intersections are empty.
3. One empty intersection is enough to break independence.

The typical use of this check is to validate a model before computing group operators.
A trap: two agents may share a partition only when it is trivial.
Two different cells of one partition are disjoint, so a shared non-trivial partition always breaks independence.
