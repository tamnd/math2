## Statement

Let $n \ge 1$ and let $l_k \le u_k$ be real numbers for $k = 0, 1, \ldots, n$, with $0 \notin [l_n, u_n]$.
Consider the family $\mathcal{P}$ of all real [[polynomials|1G0B73WPX8]]
$$p(s) = a_0 + a_1 s + a_2 s^2 + \cdots + a_n s^n \quad \text{with } a_k \in [l_k, u_k] \text{ for each } k,$$
where $[l_k, u_k]$ is a closed [[interval|0Q1D85B8G6]].
Define the four Kharitonov polynomials
$$\begin{aligned}
K_1(s) &= l_0 + l_1 s + u_2 s^2 + u_3 s^3 + l_4 s^4 + l_5 s^5 + u_6 s^6 + \cdots, \\
K_2(s) &= u_0 + u_1 s + l_2 s^2 + l_3 s^3 + u_4 s^4 + u_5 s^5 + l_6 s^6 + \cdots, \\
K_3(s) &= l_0 + u_1 s + u_2 s^2 + l_3 s^3 + l_4 s^4 + u_5 s^5 + u_6 s^6 + \cdots, \\
K_4(s) &= u_0 + l_1 s + l_2 s^2 + u_3 s^3 + u_4 s^4 + l_5 s^5 + l_6 s^6 + \cdots,
\end{aligned}$$
each of degree $n$, where the pattern of lower and upper bounds repeats with period $4$.
Then every polynomial in $\mathcal{P}$ is a [[Hurwitz polynomial|Y631JTMMT5]] if and only if $K_1$, $K_2$, $K_3$ and $K_4$ are Hurwitz polynomials.

## Remarks

The condition is necessary, since the $K_i$ belong to $\mathcal{P}$.
For sufficiency, fix $\omega \ge 0$.
The real part of $p(i\omega)$ involves only the even coefficients, and the imaginary part only the odd ones.
So, as $p$ runs over $\mathcal{P}$, the values $p(i\omega)$ fill an axis-parallel rectangle with corners $K_1(i\omega), \ldots, K_4(i\omega)$.
If the four corners are Hurwitz, a zero-exclusion argument shows that the rectangle never contains $0$ as $\omega$ varies.
So no member of the family has a root on the imaginary axis, and by continuity of the roots no root can cross into the right half-plane.

Example: the family $a_0 + a_1 s + s^2$ with $a_0 \in [1, 2]$, $a_1 \in [1, 3]$ and $a_2 = 1$ is Hurwitz, since $K_1 = 1 + s + s^2$, $K_2 = 2 + 3s + s^2$, $K_3 = 1 + 3s + s^2$ and $K_4 = 2 + s + s^2$ all have positive coefficients and degree $2$.

The theorem uses that the coefficients vary independently in intervals.
For families where the coefficients depend on common parameters, the four vertex polynomials are not enough in general.
For polytopes of polynomials, the edge theorem asks for the stability of the edges instead.

## Explanations

### L1 human

Suppose the coefficients of a polynomial are only known to lie in some ranges, as for a system whose physical constants are uncertain.
There are infinitely many possible polynomials.
Kharitonov's theorem says that to know whether all of them are stable, it is enough to test four special ones built from the ends of the ranges.

### L2 human

The theorem is a basic result of robust stability: it turns a test over a continuum of systems into four [[Routh–Hurwitz|KJF8Y19BNV]] tests.
It applies to characteristic polynomials whose coefficients are uncertain independently, which is the main limitation in practice.
The proof is a frequency-domain argument on the value set $\set{p(i\omega) : p \in \mathcal{P}}$, which is a rectangle for each $\omega$.
