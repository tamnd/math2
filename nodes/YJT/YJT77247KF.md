## Summary

A locally decodable code is an [[error-correcting code|TAE6K8NQ46]] with a fast local decoder.
Any single symbol of the message can be recovered by reading only a few symbols of a corrupted codeword.
The decoder is a [[randomized algorithm|2Y50S7GQTD]] that chooses its few positions at random.
Such codes are used in complexity theory, in private information retrieval and in the study of probabilistically checkable proofs.
The main question is the trade-off between the number of queries and the length of the code.

## Explanations

### L1 human

An ordinary code protects a long message, but to read one bit of it you usually decode the whole codeword.
A locally decodable code lets you read one bit by looking at only two or three places, even if some places were damaged.
The price is redundancy: the codeword is much longer than the message.
The [[Hadamard code|HSXZD57ABX]] is the basic example.
It writes down every parity $\langle x, a \rangle$ of the message $x \in \set{0,1}^k$, so it has length $2^k$.
To read bit $i$, pick a random $a$ and add the two stored parities at $a$ and at $a + e_i$.
