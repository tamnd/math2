## Definition

A *discrete Bayesian search problem* consists of:

1. a finite set $\set{1, \dots, n}$ of cells, one of which contains a hidden object;
2. [[prior probabilities|00NBBSXRQS]] $p_1, \dots, p_n \ge 0$ with $\sum_i p_i = 1$, where $p_i$ is the probability that the object is in cell $i$;
3. detection probabilities $d_i \in (0, 1]$, where $d_i$ is the probability that one search of cell $i$ finds the object if it is there, independently of earlier searches;
4. costs $c_i > 0$ of one search of cell $i$.

*Bayesian search theory* chooses the searches by updating the probabilities with [[Bayes' theorem|0NM6E9VW04]].
After an unsuccessful search of cell $j$, the [[posterior probabilities|0KJ7ZS8AJA]] are
$$p_j' = \frac{p_j (1 - d_j)}{1 - p_j d_j}, \qquad p_i' = \frac{p_i}{1 - p_j d_j} \quad (i \ne j).$$
A search strategy is a sequence of cells to search until the object is found.
The aim is to minimize the expected total cost of the searches.

## Remarks

Example: two cells with $p = (0.6, 0.4)$, $d = (0.5, 0.9)$ and $c = (1, 1)$.
The success probabilities of a first search are $p_1 d_1 = 0.3$ and $p_2 d_2 = 0.36$, so cell $2$ is searched first; if it fails, the update gives $p' = (0.6, 0.04)/0.64 = (0.9375, 0.0625)$.
All four clauses hold.

Non-example: suppose a search of cell $i$ can also report the object when it is elsewhere, a false alarm.
This fails clause 3, and the update above must be replaced by one that accounts for false alarms.

For this model, the strategy that always searches next a cell maximizing $p_i d_i / c_i$, with the current probabilities $p_i$, minimizes the expected total cost.
