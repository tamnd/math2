## Summary

Let $X \subset \mathbb{R}^n$ be any subset, not necessarily open. A complex valued function on $X$ is called smooth if it is locally the restriction of a [[smooth function|0V33BNKZ9S]] defined on an open set of $\mathbb{R}^n$.

More exactly, $f \colon X \to \mathbb{C}$ is smooth if every point $p \in X$ has an open neighborhood $U$ in $\mathbb{R}^n$ and a smooth function $F \colon U \to \mathbb{C}$ with $F = f$ on $X \cap U$.

The same definition with "smooth" replaced by real-analytic (see [[analytic function|081WKEDK6C]]) gives the real-analytic functions on $X$. The extension $F$ may depend on the point $p$, and it need not be unique.

This notion is used for functions on real submanifolds and hypersurfaces, for example when one studies CR functions.
