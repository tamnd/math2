## Example

A real number is [[algebraic|0MNF0BYFQC]] if it is a root of a nonzero [[polynomial|N2EY1EVPRB]] with integer coefficients.
A real number that is not algebraic is [[transcendental|0VTQXTCR2G]].
We prove by a [[counting argument|1KVSS0KRZA]] that a real transcendental number exists.

1. Let $p(x) = a_0 + a_1 x + \cdots + a_d x^d$ have integer coefficients, degree $d \ge 1$ and $a_d \ne 0$.
2. Define the height of $p$ as
   $$h(p) = d + |a_0| + |a_1| + \cdots + |a_d|.$$
   It is a positive integer, at least $2$.
3. For a fixed integer $N$, a polynomial of height $N$ has $d \le N$ and $|a_i| \le N$ for each $i$.
   So there are only finitely many polynomials of height $N$.
4. Each such polynomial has at most $d$ real roots.
   Let $A_N$ be the finite set of all real roots of all the polynomials of height $N$.
5. Every real algebraic number lies in some $A_N$, because its polynomial has some height.
   So the set $A$ of real algebraic numbers is $A_2 \cup A_3 \cup A_4 \cup \cdots$.
6. List the elements of $A_2$ in increasing order, then the new elements of $A_3$ in increasing order, then those of $A_4$, and so on.
   Each algebraic number appears at a finite position in this list, so $A$ is countable.
7. The real numbers are [[uncountable|0518MM6BE1]].
   So $A \ne \mathbb{R}$, and some real number is not algebraic.

We check the first sets of the list.

1. Height $2$: only $x$ and $-x$, so $A_2 = \{0\}$.
2. Height $3$: the $8$ polynomials $\pm 2x$, $\pm x \pm 1$ and $\pm x^2$, so $A_3 = \{-1, 0, 1\}$.
3. Height $4$: $22$ polynomials, for example $2x - 1$, $x + 2$ and $x^2 - 1$.
   Their real roots give $A_4 = \{-2, -1, -\tfrac{1}{2}, 0, \tfrac{1}{2}, 1, 2\}$.
4. The number $\sqrt{2}$ is a root of $x^2 - 2$, which has height $2 + 2 + 0 + 1 = 5$, and it is not in $A_4$.
   So $\sqrt{2}$ first appears in $A_5$.

## Remarks

The counting argument proves existence and names no transcendental number.
It also proves more than existence.
Since $A$ is countable and $\mathbb{R}$ is uncountable, the set $\mathbb{R} \setminus A$ is uncountable, so in the sense of size most real numbers are transcendental.

Step 6 is an explicit list, so the proof needs no choice principle.
The general fact that a [[countable union of countable sets|0Z8FM54P86]] is countable uses the axiom of countable choice, but here the height and the order of the reals fix the list directly.
A proof that a specific number such as $e$ or $\pi$ is transcendental needs analysis, and it is much harder.
The count of 22 polynomials of height $4$ splits as $10$ of degree $1$, $10$ of degree $2$ and the $2$ polynomials $\pm x^3$.

## Explanations

### L1 human

Some numbers, like $\sqrt{2}$, are solutions of simple equations with whole-number coefficients.
You can write all these equations in one long list, in order of their size.
So you can also list all their solutions, one after another.
But Cantor proved that the real numbers cannot be put in one list.
So some real number is missing from the list, and it is not the solution of any such equation.

### L2 human

Where does $\tfrac{1}{3}$ first appear in the list?
It is a root of $3x - 1$, which has height
$$1 + |{-1}| + |3| = 1 + 1 + 3 = 5.$$
Can a polynomial of smaller height have the root $\tfrac{1}{3}$?
By Gauss's lemma, an integer polynomial $p$ with root $\tfrac{1}{3}$ factors as $(3x - 1) q(x)$ with $q$ an integer polynomial, so the leading coefficient of $p$ is a multiple of $3$.
The polynomial $p$ also has a second nonzero coefficient, because a single term $a x^d$ has only the root $0$.
So $h(p) \ge 1 + 3 + 1 = 5$, and $\tfrac{1}{3}$ first appears in $A_5$.

The typical use is the comparison "countable set inside an uncountable set".
Watch out: the argument does not find a transcendental number.
It shows only that the list of algebraic numbers cannot contain every real number.
