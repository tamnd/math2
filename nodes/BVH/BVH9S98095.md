## Definition

A *probabilistic Turing machine* is a tuple $M = (Q, \Gamma, \sqcup, \Sigma, \delta_0, \delta_1, q_0, q_{\mathrm{acc}}, q_{\mathrm{rej}})$ with the following parts.

1. $Q$, $\Gamma$, $\sqcup$, $\Sigma$, $q_0$, $q_{\mathrm{acc}}$ and $q_{\mathrm{rej}}$ are as for a [[Turing machine|W6ESDYBF8Z]] with accepting state $q_{\mathrm{acc}}$ and rejecting state $q_{\mathrm{rej}}$.
2. $\delta_0$ and $\delta_1$ are two transition functions from $(Q \setminus \set{q_{\mathrm{acc}}, q_{\mathrm{rej}}}) \times \Gamma$ to $Q \times \Gamma \times \set{L, R}$.

At each step the machine chooses $\delta_0$ or $\delta_1$ with probability $1/2$ each, independently of all earlier choices, and moves by the chosen function.
For an input $w$, the acceptance probability $\Pr[M \text{ accepts } w]$ is the [[probability|059TJN0NZ1]] that the run on $w$ reaches $q_{\mathrm{acc}}$.
For a [[language|5MFZ4VNY6D]] $L \subseteq \Sigma^*$, the machine *decides $L$ with bounded error* if, for every $w \in \Sigma^*$, the run halts with probability $1$ and
$$\Pr[M \text{ accepts } w] \ge 2/3 \text{ if } w \in L, \qquad \Pr[M \text{ accepts } w] \le 1/3 \text{ if } w \notin L.$$

## Remarks

Equivalently, the machine reads its random choices from an extra tape filled with independent fair random bits.
Example: if $\delta_0 = \delta_1$, the machine is deterministic.
If in addition it halts on every input, it decides its language with bounded error, with acceptance probabilities $0$ and $1$.
Non-example: a machine that flips one coin and accepts on heads accepts every input with probability $1/2$.
It does not decide any language with bounded error, since $1/2$ is neither at least $2/3$ nor at most $1/3$.
The constants $2/3$ and $1/3$ can be replaced by $1 - 2^{-k}$ and $2^{-k}$ by running the machine $O(k)$ times and taking the majority answer.
BPP is the class of languages decided with bounded error by a probabilistic machine whose runs all take polynomial time.
