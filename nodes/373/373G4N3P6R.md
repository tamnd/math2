## Example

One book says "$(\mathbb{N}, +)$ is a monoid", and another says "$(\mathbb{N}, +)$ has no identity element".
Both are right, because they use different [[conflicting conventions|CSFEP56A7D]] for $\mathbb{N}$.
Let reading A be $\mathbb{N} = \{0, 1, 2, \ldots\}$ and reading B be $\mathbb{N} = \{1, 2, 3, \ldots\}$, and compute the same things under both.

1. The set $S = \{n \in \mathbb{N} : n < 5\}$ is
   $$\{0, 1, 2, 3, 4\} \ \text{under A}, \qquad \{1, 2, 3, 4\} \ \text{under B}.$$
   So $|S| = 5$ under reading A and $|S| = 4$ under reading B.
2. The sentence "$(\mathbb{N}, +)$ has an identity element" is true under reading A, because $0 + n = n$ for every $n$.
3. Under reading B the same sentence is false.
   An identity $e$ would satisfy $e + 1 = 1$, so $e = 0$, and $0 \notin \mathbb{N}$ under reading B.
4. The sentence "every $n \in \mathbb{N}$ is the successor of some element of $\mathbb{N}$" is false under both readings.
   Under A the number $0$ fails, and under B the number $1$ fails.
5. The sentence "every $n \in \mathbb{N}$ satisfies $n^2 \ge n$" is true under both readings, since
   $$n^2 - n = n(n - 1) \ge 0 \quad \text{for every integer } n \ge 0.$$

## Remarks

One set-builder expression gives sets of different sizes, and one sentence changes its truth value, when the convention for $\mathbb{N}$ changes.
Steps 4 and 5 show that other sentences keep their truth value, so you cannot tell in advance without checking the extra element $0$.

This site uses reading A, which is also the choice of the standard ISO 80000-2 and of Mathlib.
For the positive integers it writes $\mathbb{Z}_{>0}$, which means the same set under every convention.
To tell which reading a book uses, look at its first induction proof or its list of notation: a symbol such as $\mathbb{N}_0$ for $\{0, 1, 2, \ldots\}$ signals reading B.

## Explanations

### L1 human

Some books start counting at $0$ and some start at $1$.
Ask "how many natural numbers are less than $5$?".
A book that starts at $0$ counts $0, 1, 2, 3, 4$ and answers $5$.
A book that starts at $1$ counts $1, 2, 3, 4$ and answers $4$.
Both answers are right for their own book.

### L2 human

Count the elements of $T = \{n \in \mathbb{N} : n \le m\}$ for a fixed integer $m \ge 1$.
Under reading A the set is $\{0, 1, \ldots, m\}$, and under reading B it is $\{1, 2, \ldots, m\}$, so
$$|T| = m + 1 \ \text{under A}, \qquad |T| = m \ \text{under B}.$$
For $m = 10$ the answers are $11$ and $10$.
In the notation of this site, the set of reading B is $\{n \in \mathbb{Z}_{>0} : n \le m\}$, and it has $m$ elements under every convention.
Counts like this one are the daily work of combinatorics, where an off-by-one error changes the answer.
Watch out: a counting formula copied from a book with reading B can be wrong by one for a reader who uses reading A.
