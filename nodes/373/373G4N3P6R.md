## Example

Let option A be $\mathbb{N} = \{0, 1, 2, \ldots\}$ and option B be $\mathbb{N} = \{1, 2, 3, \ldots\}$.
We compute the same expressions under both options.

1. The set $S = \{n \in \mathbb{N} : n < 5\}$ is $\{0, 1, 2, 3, 4\}$ under option A and $\{1, 2, 3, 4\}$ under option B.
2. So $|S| = 5$ under option A and $|S| = 4$ under option B.
3. The sentence "$(\mathbb{N}, +)$ has an identity element" is true under option A, because $0 + n = n$ for every $n$.
4. Under option B the same sentence is false: an identity $e$ would satisfy $e + 1 = 1$, so $e = 0$, and $0 \notin \mathbb{N}$.
5. The sentence "every $n \in \mathbb{N}$ is the successor of some element of $\mathbb{N}$" is false under option A, because of $n = 0$. Under option B it is false too, because of $n = 1$.
6. The sentence "every $n \in \mathbb{N}$ satisfies $n^2 \ge n$" is true under both options, since $n^2 - n = n(n - 1) \ge 0$ for every integer $n \ge 0$.

## Remarks

The example shows that one set-builder expression can give sets of different sizes, and one sentence can change its truth value, when the convention for $\mathbb{N}$ changes.
Step 5 and step 6 show that some sentences keep their truth value under both options.
This site uses option A, which is also the choice of the international standard ISO 80000-2 and of Mathlib.
For the positive integers this site writes $\mathbb{Z}_{>0}$, which has the same meaning under both options.

## Explanations

### L1 human

Some books start counting at $0$ and some start at $1$.
Ask "how many natural numbers are less than $5$?".
A book that starts at $0$ counts $0, 1, 2, 3, 4$ and answers $5$.
A book that starts at $1$ counts $1, 2, 3, 4$ and answers $4$.
Both answers are right for their own book.

### L2 human

We count the elements of $T = \{n \in \mathbb{N} : n \le m\}$ for a fixed $m \ge 1$.

1. Under option A, $T = \{0, 1, \ldots, m\}$, so $|T| = m + 1$.
2. Under option B, $T = \{1, 2, \ldots, m\}$, so $|T| = m$.
3. For $m = 10$ the answers are $11$ and $10$.
4. In the notation of this site, the set of option B is $\{n \in \mathbb{Z}_{>0} : n \le m\}$, and it has $m$ elements under every convention.

The typical use of this count is in combinatorics, where an off-by-one error changes the answer.
A trap: a formula copied from a book with option B can be wrong by one when the reader uses option A.
