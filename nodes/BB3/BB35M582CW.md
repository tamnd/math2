## Proof

We prove the two inclusions; for the hard one, we test $T$ against projections onto lines.

1. Scalars are central. Let $a \in F$ and $S \in \End(V)$. For $v \in V$, $S(av) = a\,S(v)$ by homogeneity.
2. So $(S \circ a\id_V)(v) = (a\id_V \circ S)(v)$, and $a \id_V$ lies in the [[centre|CQSZTPMSEP]].
3. If $V = \{0\}$, then $\End(V) = \{0\} = \{a \id_V\}$, and the theorem holds. From now on, let $V \ne \{0\}$.
4. Let $T$ commute with every $S \in \End(V)$. Fix $v \ne 0$ in $V$.
5. The set $\{v\}$ is [[linearly independent|0CRMGPAH83]]. By the [[extension theorem|0M4SXE5WW3]], it extends to a basis $B$ of $V$.
6. By the [[theorem on bases|0R8X9XA83A]], there is a linear $P_v \colon V \to V$ with $P_v(v) = v$ and $P_v(b) = 0$ for $b \in B$, $b \ne v$.
7. The image of $P_v$ is the line $Fv$. Since $T P_v = P_v T$, we get $T(v) = T(P_v(v)) = P_v(T(v)) \in Fv$.
8. So $T(v) = \lambda_v v$ for a scalar $\lambda_v \in F$. Since $v \ne 0$, $\lambda_v$ is unique.
9. Let $v, w$ be nonzero. Suppose first $w = cv$ with $c \ne 0$. Then $T(w) = c\,T(v) = \lambda_v w$, so $\lambda_w = \lambda_v$.
10. Suppose next that $v, w$ are linearly independent. Then $v + w \ne 0$, and $T(v + w) = \lambda_{v+w} v + \lambda_{v+w} w$.
11. Also $T(v + w) = T(v) + T(w) = \lambda_v v + \lambda_w w$.
12. Compare coefficients, using independence: $\lambda_v = \lambda_{v+w} = \lambda_w$.
13. So all $\lambda_v$ equal one scalar $\lambda$. Then $T(v) = \lambda v$ for each $v \ne 0$, and also $T(0) = 0 = \lambda \cdot 0$.
14. So $T = \lambda \id_V$. With step 2, the centre is exactly $\{a \id_V : a \in F\}$.
15. For $V \ne \{0\}$, $a \id_V = b \id_V$ forces $a = b$, applied at a vector $v \ne 0$. So $a \mapsto a \id_V$ is injective.
16. This map is also additive, multiplicative and sends $1$ to $\id_V$. So it is a ring isomorphism of $F$ onto the centre.

## Idea

A central endomorphism commutes with each projection onto a line.
So it sends each vector into its own line, and $T(v) = \lambda_v v$.
Linearity then forces all the scalars $\lambda_v$ to be equal.

## Variants

- For $\dim V = n$, choose a basis and use [[matrix units|4H93XF4RVH]]. If $A$ commutes with each $E_{ij}$, then $A$ is diagonal with equal diagonal entries. This is the [[matrix proof|TX4J5JR205]].
