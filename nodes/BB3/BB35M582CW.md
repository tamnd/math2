## Proof

We prove the two inclusions, and for the hard one we test $T$ against projections onto lines.

1. Let $a \in F$ and $S \in \End(V)$, and note that $S(av) = a\,S(v)$ for $v \in V$, by homogeneity.
2. So $(S \circ a\id_V)(v) = (a\id_V \circ S)(v)$, and $a \id_V$ lies in the [[center|CQSZTPMSEP]].
3. If $V = \{0\}$, then $\End(V) = \{0\} = \{a \id_V\}$, and the theorem holds, so from now on let $V \ne \{0\}$.
4. Let $T$ commute with every $S \in \End(V)$, and fix $v \ne 0$ in $V$.
5. The set $\{v\}$ is [[linearly independent|0CRMGPAH83]], so by the [[extension theorem|0M4SXE5WW3]] it extends to a basis $B$ of $V$.
6. By the [[theorem on bases|0R8X9XA83A]], there is a linear $P_v \colon V \to V$ with $P_v(v) = v$ and $P_v(b) = 0$ for $b \in B$ with $b \ne v$.
7. The image of $P_v$ is the line $Fv$, and since $T P_v = P_v T$, we get $T(v) = T(P_v(v)) = P_v(T(v)) \in Fv$.
8. So $T(v) = \lambda_v v$ for a scalar $\lambda_v \in F$, which is unique since $v \ne 0$.
9. Let $v, w$ be nonzero, and suppose first that $w = cv$ with $c \ne 0$, so that $T(w) = c\,T(v) = \lambda_v w$ and $\lambda_w = \lambda_v$.
10. Suppose next that $v, w$ are linearly independent, so that $v + w \ne 0$ and $T(v + w) = \lambda_{v+w} v + \lambda_{v+w} w$.
11. Also $T(v + w) = T(v) + T(w) = \lambda_v v + \lambda_w w$.
12. Comparing coefficients, using independence, gives $\lambda_v = \lambda_{v+w} = \lambda_w$.
13. So all $\lambda_v$ equal one scalar $\lambda$, and $T(v) = \lambda v$ for each $v \ne 0$, while also $T(0) = 0 = \lambda \cdot 0$.
14. So $T = \lambda \id_V$, and with step 2 the center is exactly $\{a \id_V : a \in F\}$.
15. For $V \ne \{0\}$, evaluating at a vector $v \ne 0$ shows that $a \id_V = b \id_V$ forces $a = b$, so $a \mapsto a \id_V$ is injective.
16. This map is also additive and multiplicative and sends $1$ to $\id_V$, so it is a ring isomorphism of $F$ onto the center.

## Idea

A central endomorphism commutes with each projection onto a line.
So it sends each vector into its own line, and $T(v) = \lambda_v v$.
Linearity then forces all the scalars $\lambda_v$ to be equal.

## Variants

For $\dim V = n$, one can choose a basis and use [[matrix units|4H93XF4RVH]] instead.
If a matrix $A$ commutes with each $E_{ij}$, then $A$ is diagonal with equal diagonal entries, and this is the [[matrix proof|TX4J5JR205]].
