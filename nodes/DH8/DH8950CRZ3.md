## Summary

A system is BIBO stable, for bounded-input bounded-output, if every bounded input signal produces a bounded output signal.
It is a notion of stability that looks only at the input-output map, not at the internal state.
For a [[linear time-invariant system|6J9MPVHSMF]] it holds exactly when the [[impulse response|3X3SYVM7R5]] is absolutely integrable.
For a proper rational [[transfer function|86JKV3TRFD]] in lowest terms, it holds exactly when every pole has negative real part.

## Explanations

### L1 human

Push a system with a signal that never gets larger than some fixed size.
If the response also never gets larger than some fixed size, whatever the push, the system is BIBO stable.
A bowl with a damped ball in it is BIBO stable: bounded shaking gives bounded motion.
An integrator is not: a constant push of size $1$ makes its output grow like $t$.
