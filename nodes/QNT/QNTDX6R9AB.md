## Definition

Let $\F_q$ be a [[finite field|0ZXZ82FTX2]], let $1 \le k \le n$, and let $\F_q((D))$ be the field of formal [[Laurent series|0GXMPDNYX3]] $\sum_{t \ge t_0} a_t D^t$ in the delay variable $D$.
Let $G(D)$ be a $k \times n$ matrix with entries in the [[polynomial ring|0SDC934R52]] $\F_q[D]$ and of rank $k$ over $\F_q((D))$.
The *convolutional code* generated by $G(D)$ is
$$C = \set{u(D)\, G(D) : u(D) \in \F_q((D))^k} \subseteq \F_q((D))^n.$$
Its rate is $k/n$, and its memory is the largest degree of an entry of $G(D)$.

## Remarks

Writing $u(D) = \sum_t u_t D^t$ with $u_t \in \F_q^k$ and $G(D) = \sum_{l=0}^{\mu} G_l D^l$, the output at time $t$ is $c_t = \sum_{l=0}^{\mu} u_{t-l} G_l$, a convolution of the input with the coefficient matrices; this is the shift-register description.
The free distance is the least number of nonzero symbols $c_t^{(j)}$ in a nonzero codeword with finitely many nonzero terms; it plays the role of the minimum distance.

Example: $q = 2$ and $G(D) = (1 + D + D^2, \ 1 + D^2)$, a rate $1/2$ code of memory $2$.
The input $u(D) = 1$ gives the codeword $(1 + D + D^2, 1 + D^2)$, with $5$ nonzero symbols, and the free distance of this code is $5$.

Non-example: the matrix with rows $(1, D)$ and $(D, D^2)$ has rank $1$, since the second row is $D$ times the first.
It does not generate a rate $2/2$ code: its image is the rate $1/2$ code generated by $(1, D)$ alone.
