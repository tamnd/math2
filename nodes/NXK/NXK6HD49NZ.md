## Summary

A generating function of a [[canonical transformation|AGA36YKX4F]] is a single function of half of the old and half of the new variables.
The whole transformation is obtained from it by partial derivatives.
It gives a convenient way to write down canonical transformations, since any nondegenerate function produces one.
There are four standard types, according to which variables it depends on.
The solution of the [[Hamilton–Jacobi equation|5TRXQKP7DY]] is a generating function that makes the new Hamiltonian zero.
See the [[definition|D4TRNRC45C]].

## Explanations

### L1 human

A canonical transformation involves $2n$ new functions that must fit together in a special way.
A generating function packs all of them into one function, and the fit is then automatic.
For one degree of freedom, the function $F = q Q$ produces $p = Q$ and $P = -q$, which swaps the roles of position and momentum.
The function $F = q P$ produces $p = P$ and $Q = q$, the identity.
Small changes of $F$ around $qP$ give canonical transformations close to the identity, which is how perturbation theory uses them.
