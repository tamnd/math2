## Statement

Let $V_1, V_2, \dots$ be [[i.i.d.|00MRN0FARV]] random variables with values in a finite set $\mathcal{V}$, with [[entropy|Y86E072V0V]] $H(V)$ in bits.
Let $(\mathcal{X}, W, \mathcal{Y})$ be a discrete memoryless [[channel|B9C5RBFATB]] with [[capacity|J7MZ2XQP9M]] $C$.
A *source–channel code* of length $n$ is a pair of maps $e \colon \mathcal{V}^n \to \mathcal{X}^n$ and $d \colon \mathcal{Y}^n \to \mathcal{V}^n$.
Its error probability is $P_e^{(n)} = \Pr(d(Y^n) \ne V^n)$, where $Y^n$ is the output of the channel for the input $e(V^n)$.

1. If $H(V) < C$, then there are source–channel codes with $P_e^{(n)} \to 0$ as $n \to \infty$.
2. If there are source–channel codes with $P_e^{(n)} \to 0$, then $H(V) \le C$.

## Remarks

For part 1, compress $V^n$ to about $n(H(V) + \delta)$ bits, as in [[Shannon's source coding theorem|PC8ASRWARE]], with $\delta > 0$ so small that $H(V) + \delta < C$.
Then send these bits with a channel code of rate below $C$, given by the [[noisy-channel coding theorem|PR3NJB0SKG]].
For part 2, Fano's inequality and the argument of the [[converse of the channel coding theorem|N3RD9BNKQA]] give $H(V) \le C + P_e^{(n)} \log_2 \abs{\mathcal{V}} + 1/n$.

Example: a source of fair bits, $H(V) = 1$, cannot be sent reliably at one bit per use over a binary channel that flips bits with probability $0.1$, since $C \approx 0.531 < 1$.

The scheme of part 1 designs the source code and the channel code separately, and part 2 shows that no joint design does better in this setting.
In many multi-user networks this separation is no longer optimal.

## Explanations

### L1 human

A source can be sent reliably over a channel exactly when its entropy is below the capacity, up to the boundary case.
Moreover, one can first compress the data as well as possible and then protect it against noise, as two independent steps.
This is why compression and error correction are designed as separate layers in practice.

### L2 human

The theorem joins the two halves of Shannon's theory: the entropy measures what must be sent, and the capacity measures what can be sent.
The same conclusion holds for stationary ergodic sources, with the entropy rate in place of $H(V)$.
For lossy transmission, the analogous statement compares the rate–distortion function with the capacity.
