## Example

Let $S$ be the sentence "$x > 3$", where $x$ is a real number and nothing else is said about $x$.
We show that $S$ is not a [[mathematical statement|S9MHMRAX88]].

1. A statement must have exactly one truth value.
2. For $x = 4$, the sentence says $4 > 3$, which is true.
3. For $x = 2$, the sentence says $2 > 3$, which is false.
4. So the truth value of $S$ depends on the value of $x$, and $S$ alone has no truth value.
5. So $S$ is not a statement. It is an open sentence, and in logic it is a [[predicate|0QHEWQD30B]] of $x$.

## Remarks

The example shows the condition of the definition that fails: the sentence must be true or false as it stands.
The free variable $x$ is the reason.

Three small changes turn $S$ into a statement.
The sentence "$x > 3$ for $x = 5$" is a true statement.
The sentence "there is a real $x$ with $x > 3$" is a true statement.
The sentence "every real $x$ satisfies $x > 3$" is a false statement, because $x = 0$ fails.

The context can also close the variable.
If an earlier line says "let $x = 10$", then $S$ means $10 > 3$, and it is a true statement in that context.
So whether a line of a proof is a statement depends on the lines before it.

## Explanations

### L1 human

"The number is bigger than three" does not say which number.
For four it is true, and for two it is false.
So we cannot call the sentence true or false.
It becomes a statement only when we say which number we mean, or when we say "every number" or "some number".

### L2 human

We sort the following sentences, all about a real number $x$.

1. "$x > 3$": an open sentence, by the steps above.
2. "$x^2 + 1 > 0$": an open sentence by its form. It is true for every real $x$, so in a theorem we read it with a hidden "for every $x$", and then it is a true statement.
3. "If $x > 3$, then $x > 2$": an open sentence by its form. With the hidden "for every real $x$", it is a true statement.

The typical use is to find the free variables before we decide the truth value of a line.

A trap: sentence 2 is true for every $x$, but the open sentence alone is still not a statement.
The quantifier, written or understood, makes it one.
