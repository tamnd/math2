## Example

Let $S$ be the sentence "$x > 3$", where $x$ is a real number and nothing else is said about $x$.
We show that $S$ is not a [[mathematical statement|S9MHMRAX88]].

1. A statement must have exactly one truth value as it stands.
2. For $x = 4$ the sentence says $4 > 3$, which is true.
3. For $x = 2$ the sentence says $2 > 3$, which is false.
4. So the truth value of $S$ depends on the value of $x$, and $S$ alone has no truth value.
5. So $S$ is not a statement.
   It is an open sentence, and in logic it is a [[predicate|0QHEWQD30B]] of $x$.

## Remarks

The condition of the definition that fails is "true or false as it stands", and the free variable $x$ is the reason.
Three small changes turn $S$ into a statement.
"$x > 3$ for $x = 5$" is a true statement.
"There is a real $x$ with $x > 3$" is a true statement.
"Every real $x$ satisfies $x > 3$" is a false statement, because $x = 0$ fails.

The context can also close the variable.
If an earlier line of a proof says "let $x = 10$", then $S$ means $10 > 3$, and in that context it is a true statement.
So whether a line of a proof is a statement depends on the lines before it.

## Explanations

### L1 human

"The number is bigger than three" does not say which number.
For four it is true, and for two it is false.
So we cannot call the sentence true or false.
It becomes a statement only when we say which number we mean, or when we say "every number" or "some number".

### L2 human

Sort three sentences about a real number $x$.
The first, "$x > 3$", is an open sentence, as the steps above show.
The second, "$x^2 + 1 > 0$", is an open sentence by its form.
It is true for every real $x$, since $x^2 \ge 0$ gives $x^2 + 1 \ge 1$, so in a theorem we read it with a hidden "for every $x$", and then it is a true statement.
The third, "if $x > 3$, then $x > 2$", is also open by its form, and with the hidden "for every real $x$" it is a true statement.

Watch out: the second sentence is true for every $x$, but the open sentence on its own is still not a statement.
The quantifier, written or understood, is what makes it one.
So before you decide whether a line is true, find its free variables.
