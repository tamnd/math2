## Example

Let $\mathrm{REC}$ be the family of [[computable sets|PPGD5KW8JC]], and let $\varphi_e$ be the $e$-th partial computable function.
We check three things: $(\mathbb{N}, \mathrm{REC})$ is the least $\omega$-model of [[RCA0|XQENB067R3]], it is not a model of [[WKL0|K5YPW1NTHZ]], and it is not a [[β-model|J0Z2GNJZ2W]].
The second check builds a computable binary tree with no computable path.

1. $\mathrm{REC}$ contains $\emptyset$, the join of two computable sets is computable, and a set [[Turing reducible|PA4PYQ1PZ0]] to a computable set is computable.
   So $\mathrm{REC}$ is a Turing ideal, and it is an $\omega$-model of $\mathsf{RCA}_0$ by the [[characterization of ω-models|Y6D27XJT3H]].
2. Every $\omega$-model of $\mathsf{RCA}_0$ is a Turing ideal, so it contains $\emptyset$ and every set computable from $\emptyset$.
   So $\mathrm{REC}$ is the least one.
3. Let $A = \{ e : \varphi_e(e) = 0 \}$ and $B = \{ e : \varphi_e(e) = 1 \}$, which are disjoint.
   No computable $C$ has $A \subseteq C$ and $C \cap B = \emptyset$.
   For such a $C$, take $e$ with $\varphi_e(x) = 1$ for $x \in C$ and $\varphi_e(x) = 0$ for $x \notin C$.
   If $e \in C$, then $\varphi_e(e) = 1$, so $e \in B$, which is disjoint from $C$; if $e \notin C$, then $\varphi_e(e) = 0$, so $e \in A \subseteq C$.
4. Let $T$ be the set of $\sigma \in 2^{<\mathbb{N}}$ that obey, for every $e < \lvert \sigma \rvert$, this rule: if $\varphi_e(e)$ halts within $\lvert \sigma \rvert$ steps, then $\sigma(e) = 1 - \varphi_e(e)$.
   Membership in $T$ is decided by running finitely many programs for finitely many steps, so $T$ is computable.
5. $T$ is closed under initial segments, because a computation that halts within $m$ steps also halts within $n \ge m$ steps.
   For each $n$, the string of length $n$ that follows the rule for the computations halting within $n$ steps, and has $0$ elsewhere, lies in $T$.
   So $T$ is an infinite binary tree in $\mathrm{REC}$.
6. Let $P$ be a path through $T$.
   If $\varphi_e(e) = 0$ in $s$ steps, then $P {\restriction} n \in T$ for $n > \max(e, s)$ gives $P(e) = 1$, and in the same way $\varphi_e(e) = 1$ gives $P(e) = 0$.
   So $\{ e : P(e) = 1 \}$ separates $A$ from $B$, and by step 3 it is not computable.
7. So $T$ has no path in $\mathrm{REC}$, and weak König's lemma fails in $(\mathbb{N}, \mathrm{REC})$.
8. The $\Sigma^1_1$ sentence "$T$ has a path" is true in $(\mathbb{N}, \mathcal{P}(\mathbb{N}))$, since every infinite binary tree has a path, and it is false in $(\mathbb{N}, \mathrm{REC})$.
   So this model is not a $\beta$-model.

## Remarks

The tree $T$ is often called a Kleene tree.
The example explains the name "theory of computable mathematics": the least $\omega$-model of $\mathsf{RCA}_0$ contains only computable sets.
The same argument gives a general test.
A theorem with a computable instance that has no computable solution is not provable in $\mathsf{RCA}_0$.

What changes when we add oracles?
Relativize the construction to a set $X$, and the tree becomes computable in $X$ with no path computable in $X$.
So no model of the form "all sets computable from $X$" satisfies $\mathsf{WKL}_0$.
The models of $\mathsf{WKL}_0$ must be closed under taking paths, and the low basis theorem builds such a model from low sets.

## Explanations

### L1 human

Keep only the sets that a computer can decide, and all the axioms of $\mathsf{RCA}_0$ still hold.
Some infinite binary trees that a computer can decide have no branch that a computer can follow forever.
The tree above forces each branch to disagree, at place $e$, with every program $e$ that outputs $0$ or $1$ on its own number, so no program can trace a branch.
So weak König's lemma is false in this world of computable sets.

### L2 human

Steps 3 to 7 build a computable instance of weak König's lemma with no computable solution.
This is the standard way to show that a principle is not provable in $\mathsf{RCA}_0$: find a computable instance, and show that no solution is computable.

Watch out: $T$ has paths, many of them.
Each path separates $A$ from $B$, but no path is computable.
The failure is in the model, not in the tree.
