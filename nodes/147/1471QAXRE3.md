## Proof

Let $N^k = 0$ and put $S = I + N + \cdots + N^{k-1}$.

1. By the distributive law for [[matrix products|076JGP6R3T]], $(I - N) S = (I + N + \cdots + N^{k-1}) - (N + N^2 + \cdots + N^{k})$.
2. All terms except $I$ and $-N^k$ cancel in pairs, so $(I - N) S = I - N^k$.
3. In the same way, $S (I - N) = (I + \cdots + N^{k-1}) - (N + \cdots + N^k) = I - N^k$. The two orders agree because every term is a power of $N$.
4. By hypothesis $N^k = 0$, so $(I - N) S = S (I - N) = I$.
5. So $I - N$ is [[invertible|0EB9N0S33C]], and its inverse is $S$.

## Idea

The telescoping identity $(1 - x)(1 + x + \cdots + x^{k-1}) = 1 - x^k$ uses only the ring axioms.
Nilpotency removes the last term.

## Variants

- By induction on $k$: for $k = 1$, $N = 0$ and $I - N = I$. In general, $(I - N)(I + N) = I - N^2$, and $N^2$ has a smaller index when $k \ge 2$, so $I - N^2$ is invertible and $(I - N)^{-1} = (I + N)(I - N^2)^{-1}$.
