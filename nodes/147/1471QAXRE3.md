## Proof

We multiply $I - N$ by the finite sum in both orders and watch the terms cancel.
Let $N^k = 0$ and put $S = I + N + \dots + N^{k-1}$.

1. By the distributive law of [[matrix multiplication|076JGP6R3T]], and since $I N^j = N^j$ and $N N^j = N^{j+1}$,
$$(I - N) S = (I + N + \dots + N^{k-1}) - (N + N^2 + \dots + N^k).$$
2. Each power $N^j$ with $1 \le j \le k - 1$ appears once with a plus sign and once with a minus sign, so these terms cancel, and
$$(I - N) S = I - N^k.$$
3. In the same way, $S (I - N) = (I + \dots + N^{k-1}) - (N + \dots + N^k) = I - N^k$, since $N^j N = N^{j+1}$.
4. By hypothesis $N^k = 0$, so $(I - N) S = I$ and $S (I - N) = I$.
5. So $S$ is a two-sided inverse of $I - N$, and $I - N$ is [[invertible|0EB9N0S33C]] with $(I - N)^{-1} = S$.

## Idea

The proof is the telescoping identity $(1 - x)(1 + x + \dots + x^{k-1}) = 1 - x^k$, which uses only the ring axioms.
We must check both orders of the product, because matrices need not commute, but here every factor is a polynomial in $N$, so the two orders give the same result.
Nilpotency then removes the last term $x^k$, and what is left is $1$.

## Variants

There is a proof by induction on $k$.
For $k = 1$ we have $N = 0$, and $I - N = I$ is its own inverse.
For $k \ge 2$, the matrix $N^2$ is nilpotent of smaller index, so $I - N^2$ is invertible by induction.
Since $(I - N)(I + N) = (I + N)(I - N) = I - N^2$, the matrix $(I + N)(I - N^2)^{-1}$ is an inverse of $I - N$; it commutes with $I - N$ because all factors are polynomials in $N$.
