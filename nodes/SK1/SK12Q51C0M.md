## Example

We use the [[revision theory|ZQ4TWM7K6E]] over the [[standard model|WP27CABPA4]], with the revision rule $\rho(h) = \{\ulcorner \varphi \urcorner : (\mathcal{N}, h) \models \varphi\}$.
Let $\lambda := \exists y\,(D(\underline{k}, y) \wedge \neg T(y))$ be the liar from the [[proof of the diagonal lemma|SFPSB6JPTC]].
Here $D(\underline{k}, m)$ is true in $\mathcal{N}$ only for $m = \ulcorner \lambda \urcorner$.
We show that the liar is unstable in every revision sequence.

1. For every hypothesis $h$: $(\mathcal{N}, h) \models \lambda$ if and only if $\ulcorner \lambda \urcorner \notin h$. The reason is that the only witness $y$ is $\ulcorner \lambda \urcorner$.
2. So $\ulcorner \lambda \urcorner \in \rho(h)$ if and only if $\ulcorner \lambda \urcorner \notin h$, by the definition of $\rho$.
3. Let $S$ be any revision sequence. For every ordinal $\zeta$, $S_{\zeta + 1} = \rho(S_\zeta)$, so step 2 gives: $\ulcorner \lambda \urcorner \in S_{\zeta + 1}$ if and only if $\ulcorner \lambda \urcorner \notin S_\zeta$.
4. Start from $S_0 = \emptyset$. The table gives the first stages, by step 3.

| stage | $0$ | $1$ | $2$ | $3$ | $4$ | $\dots$ |
|---|---|---|---|---|---|---|
| $\ulcorner \lambda \urcorner$ in the stage | no | yes | no | yes | no | $\dots$ |

5. By induction on $n$, $\ulcorner \lambda \urcorner \in S_n$ if and only if $n$ is odd.
6. At the limit $\omega$, the code $\ulcorner \lambda \urcorner$ is neither stably in nor stably out of $S|_\omega$, by step 5. So the limit rule lets $S_\omega$ contain it or not.
7. Both choices give revision sequences. After $\omega$, the value changes again at every successor, by step 3.
8. *Not stably true.* Suppose $\ulcorner \lambda \urcorner \in S_\zeta$ for all $\zeta \ge \theta$. Then $\ulcorner \lambda \urcorner \in S_\theta$ and $\ulcorner \lambda \urcorner \in S_{\theta + 1}$, which contradicts step 3.
9. *Not stably false.* The same argument with "not in" in place of "in" gives a contradiction.
10. *Not nearly stably true or false.* For every $\theta$ and $n$, step 3 shows that $S_{\theta + n}$ and $S_{\theta + n + 1}$ differ on $\ulcorner \lambda \urcorner$.
11. Steps 8 to 10 hold for every revision sequence. So $\lambda$ is valid neither in $\mathsf{T}^*$ nor in $\mathsf{T}^{\#}$, and the same holds for $\neg \lambda$.

## Remarks

The SEP entry gives a version of this example in a language with four names, one of which names the sentence $\neg T\lambda$.
There this liar sentence also changes its value at every revision.
The behavior of $\lambda$ is the formal form of the informal reasoning "if it is true, then it is not true, and conversely".
The tautology $T(\ulcorner \lambda \urcorner) \vee \neg T(\ulcorner \lambda \urcorner)$ is true at every stage, since each stage is a classical model.
So the revision theory keeps excluded middle for the liar, but it gives the liar no stable value.
Compare the [[truth-teller|RQNRNHSQQ0]], which is stable in every sequence.

## Explanations

### L1 human

Guess that the liar is not true.
Then what it says holds, so in the next round we call it true.
Then what it says fails, so in the next round we call it not true.
The value changes every round, and it never settles.

### L2 human

1. Stage $0$: $\ulcorner \lambda \urcorner \notin S_0$, so $\lambda$ holds in $(\mathcal{N}, S_0)$.
2. Stage $1$: $\ulcorner \lambda \urcorner \in S_1$, so $\lambda$ fails in $(\mathcal{N}, S_1)$.
3. Stage $2$: $\ulcorner \lambda \urcorner \notin S_2$, and the pattern repeats.
4. At stage $\omega$ the limit rule gives no value, so we may choose. The pattern repeats from there.

The typical use of the example is to separate pathological sentences, which never settle, from ordinary ones.
The trap is step 4: a choice at a limit does not make the liar stable, since the next stage changes it again.
