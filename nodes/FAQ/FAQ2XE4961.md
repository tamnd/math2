## Example

We use the [[revision theory|ZQ4TWM7K6E]] over $\mathcal{N}$, with the revision rule $\rho(h) = \{\ulcorner \varphi \urcorner : (\mathcal{N}, h) \models \varphi\}$.
Define a sequence $R$ of length $\omega \cdot 2$ by $R_n := \rho^n(\emptyset)$ and $R_{\omega + n} := \rho^n(\emptyset)$ for all $n < \omega$.
So $R$ restarts from the empty hypothesis at stage $\omega$.
We check that $R$ is not an initial segment of any revision sequence.

1. $R$ obeys the successor rule: $R_{\zeta + 1} = \rho(R_\zeta)$ for every $\zeta < \omega \cdot 2$, by the definition.
2. The sentence $0 = 0$ is true in $(\mathcal{N}, h)$ for every $h$. So $\ulcorner 0 = 0 \urcorner \in \rho(h)$ for every $h$.
3. Hence $\ulcorner 0 = 0 \urcorner \in R_n$ for every $n \ge 1$, by step 2.
4. So $\ulcorner 0 = 0 \urcorner$ is stably in $R|_\omega$, with starting stage $1$.
5. The limit rule requires $\ulcorner 0 = 0 \urcorner \in R_\omega$.
6. But $R_\omega = \emptyset$, so the limit rule fails at $\omega$.
7. So $R$ is not an initial segment of a revision sequence.

## Remarks

The limit rule is the only constraint at limit stages.
Without it, any sentence could change its value at a limit, and no sentence would be categorically true.
In $R$, the sentence $T(\ulcorner 0 = 0 \urcorner)$ is true at all stages $n \ge 1$, false at $\omega$, and true again from $\omega + 1$.
A correct sequence can choose $R'_\omega$ freely only on the unstable codes, such as the code of the [[liar|SK12Q51C0M]].

## Explanations

### L1 human

A revision sequence may forget nothing that has settled.
This sequence forgets everything at stage $\omega$ and starts again from nothing.
So it breaks the rule for infinite stages.

### L2 human

1. The code of $0 = 0$ enters at stage $1$ and stays in at every finite stage.
2. So it is stably in before $\omega$.
3. The limit rule then puts it into stage $\omega$, but $R_\omega$ is empty.

The typical use is to check a proposed sequence against both rules.
The trap is to check only the successor rule.
