## Definition

Consider a linear network with $n$ ports in sinusoidal steady state, as for a [[two-port network|CEM0TDK67M]].
Its complex port voltages and port currents are $V_k$ and $I_k$ for $k = 1, \dots, n$.
Fix a reference impedance $Z_0 > 0$.
The *incident* and *reflected waves* at port $k$ are
$$a_k = \frac{V_k + Z_0 I_k}{2\sqrt{Z_0}}, \qquad b_k = \frac{V_k - Z_0 I_k}{2\sqrt{Z_0}}.$$
Assume that for every $a \in \C^n$ there is exactly one possible state of the network with incident waves $a$.
The network has the *scattering matrix* $S \in \C^{n \times n}$ if the reflected waves of this state are $b = S a$ for every $a$.
The entries $S_{kl}$ are the *scattering parameters*, or S-parameters.

## Remarks

Let the network have an impedance matrix $Z$, so that $V = Z I$, and let $Z + Z_0 \mathbf{1}$ be invertible.
Then $S = (Z - Z_0 \mathbf{1})(Z + Z_0 \mathbf{1})^{-1}$, where $\mathbf{1}$ is the identity matrix.
Example: a one-port load with impedance $Z_L$ has $S = (Z_L - Z_0)/(Z_L + Z_0)$, the reflection coefficient.
The matched load $Z_L = Z_0$ gives $S = 0$; an open circuit ($I = 0$) gives $b = a$, so $S = 1$; a short circuit ($V = 0$) gives $S = -1$.
Non-example: the one-port with $V = -Z_0 I$, a negative resistance, has $a = 0$ in every state.
So not every incident wave occurs, and there is no scattering matrix.
Since $\abs{a_k}^2 - \abs{b_k}^2 = \operatorname{Re}(\overline{V_k} I_k)$, the sum over $k$ is proportional to the power absorbed by the network.
Hence a lossless network has a [[unitary|0AR68JTMDT]] scattering matrix, and a passive one has $\norm{S} \le 1$.
A reciprocal network has a symmetric scattering matrix.
Some texts use other normalizations, such as complex reference impedances or different reference impedances at different ports.
