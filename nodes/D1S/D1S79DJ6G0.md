## Definition

Let $M$ be a single-tape [[nondeterministic Turing machine|M7SDX137WE]] with input alphabet $\Sigma$.
Let $\triangleleft, \triangleright \notin \Sigma$ be two tape symbols, the left and right end markers.
Then $M$ is a *linear bounded automaton* if:

1. on input $w \in \Sigma^*$, the machine starts with $\triangleleft w \triangleright$ on its tape and its head on $\triangleleft$;
2. $M$ never moves its head to the left of $\triangleleft$ or to the right of $\triangleright$;
3. $M$ never overwrites $\triangleleft$ or $\triangleright$.

The language of $M$ is the set of $w \in \Sigma^*$ for which some computation of $M$ on $\triangleleft w \triangleright$ reaches an accepting state.

## Remarks

Example: consider a machine that first scans $\triangleleft w \triangleright$ to check that $w \in a^+ b^+ c^+$.
Then, in each pass, it replaces the first unmarked $a$, $b$ and $c$ by a mark symbol $x$.
It rejects if one of them is missing.
It accepts when, after a pass, no unmarked letter is left; this is a linear bounded automaton for $\set{a^n b^n c^n : n \ge 1}$.
It only rewrites cells between the markers, so clauses 2 and 3 hold.
Non-example: a [[Turing machine|758EYCN27B]] that copies its input to the right of $\triangleright$ violates clause 2.
A language is accepted by a linear bounded automaton if and only if it is [[context-sensitive|NYJ7PD4025]].
The same class arises if the machine may use $c \cdot n$ cells on inputs of length $n$, for a fixed constant $c$.
The reason is that a larger tape alphabet compresses $c$ cells into one.
