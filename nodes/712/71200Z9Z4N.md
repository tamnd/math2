## Proof

Let the set $P$ of variables be [[countable|01TQB88H4C]], listed as $p_0, p_1, p_2, \dots$ (the list may be finite).
Let $\Sigma$ be a finitely satisfiable set of [[formulas|TT7WT5HPN9]].
For a variable $p$ write $p^1 = p$ and $p^0 = \neg p$.

1. Claim: if $\Theta$ is finitely satisfiable and $p$ is a variable, then $\Theta \cup \set{p}$ or $\Theta \cup \set{\neg p}$ is finitely satisfiable. Suppose both fail.
2. Then there are finite sets $\Phi \subseteq \Theta \cup \set{p}$ and $\Psi \subseteq \Theta \cup \set{\neg p}$, and neither has a model.
3. The set $\Theta_0 = (\Phi \cup \Psi) \setminus \set{p, \neg p}$ is a finite subset of $\Theta$, so some [[truth assignment|H31CS3HK5P]] $w$ makes all of $\Theta_0$ true.
4. If $w(p) = 1$, then $w$ makes all of $\Phi \subseteq \Theta_0 \cup \set{p}$ true. If $w(p) = 0$, then $w$ makes all of $\Psi \subseteq \Theta_0 \cup \set{\neg p}$ true. Both cases contradict step 2, which proves the claim.
5. Define $\Sigma_0 = \Sigma$. Given $\Sigma_n$, put $\varepsilon_n = 1$ if $\Sigma_n \cup \set{p_n}$ is finitely satisfiable and $\varepsilon_n = 0$ otherwise, and put $\Sigma_{n+1} = \Sigma_n \cup \set{p_n^{\varepsilon_n}}$.
6. Each $\Sigma_n$ is finitely satisfiable, by [[induction|0ASJVEFA9J]] on $n$. The case $n = 0$ is the hypothesis, and step 1 gives the step from $n$ to $n + 1$.
7. Define the truth assignment $v$ by $v(p_n) = \varepsilon_n$ for every $n$.
8. Let $\varphi \in \Sigma$. A formula has finitely many variables, so the variables of $\varphi$ lie among $p_0, \dots, p_{m-1}$ for some $m$.
9. The finite set $\set{\varphi, p_0^{\varepsilon_0}, \dots, p_{m-1}^{\varepsilon_{m-1}}}$ is a subset of $\Sigma_m$. By step 6 it has a model $w$.
10. For $i < m$ we have $w(p_i^{\varepsilon_i}) = 1$, so $w(p_i) = \varepsilon_i = v(p_i)$.
11. The value of a formula depends only on the values of its variables (the coincidence property of the [[valuation|H31CS3HK5P]], proved by structural induction). Steps 8 and 10 give $v(\varphi) = w(\varphi) = 1$.
12. So $v$ makes every member of $\Sigma$ true, and $\Sigma$ is [[satisfiable|QN7M1JCGT9]].

## Idea

The proof decides the variables one at a time.
At each step it keeps the value of $p_n$ that leaves the set finitely satisfiable, and step 1 shows that one value always works.
A formula of $\Sigma$ only looks at finitely many variables, and these are all decided after finitely many steps.

## Variants

- König's lemma in disguise: the finite sequences $(\varepsilon_0, \dots, \varepsilon_{n-1})$ such that $\Sigma \cup \set{p_0^{\varepsilon_0}, \dots, p_{n-1}^{\varepsilon_{n-1}}}$ is finitely satisfiable form an infinite binary tree. Step 1 says that every vertex of this tree has a child, and steps 5 to 7 follow an infinite branch. This is the argument of König's lemma for binary trees.
- No choice: step 5 fixes the rule "take $1$ when it works", so the construction needs no form of the axiom of choice. It only uses the given list of $P$.
- A second tree: let $T_n$ be the set of assignments to $p_0, \dots, p_{n-1}$ that make true every formula of $\Sigma$ with variables among them. Up to logical equivalence there are finitely many such formulas, so finite satisfiability makes each $T_n$ nonempty. The sets $T_n$ form an infinite binary tree under restriction, and König's lemma gives an infinite branch, which is a model of $\Sigma$.
- For an arbitrary $P$, see the [[proof by Tychonoff's theorem|MAQEYCNFST]].
