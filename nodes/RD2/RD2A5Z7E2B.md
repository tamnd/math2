## Summary

A Post algebra of order $n$ is an algebra in the [[variety|AJNZJD8442]] generated by the $n$-element chain $\mathbf{P}_n$ with a cyclic negation; see [[the definition|G24036DJ5K]].
Post algebras are the algebras of [[Post's $n$-valued logic|YHYSGRE7JV]], in the same way as [[Boolean algebras|0XADJKM699]] are the algebras of classical logic.
The chain $\mathbf{P}_n$ is [[primal|XD01Y7B6XW]], so every Post algebra of order $n$ is a Boolean power of $\mathbf{P}_n$.
Each element is a join $\bigvee_i (b_i \land e_i)$ of a decreasing chain of complemented elements $b_i$ with the constants $e_i$.
For $n = 2$ the Post algebras are exactly the Boolean algebras.

## Motivation

Post's $n$-valued logic has the values $0 < 1 < \dots < n - 1$, the connectives $\max$ and $\min$, and a negation that moves each value one step up and the top value to $0$.
These connectives define every function on the values.
One wants the algebras that satisfy the same identities, as Boolean algebras do for two values.
The representation by chains of complemented elements shows that each Post algebra is a Boolean algebra "with $n$ levels".

## Notation

We write $\mathbf{P}_n = (\set{0, \dots, n - 1}, \lor, \land, ', 0, n - 1)$ and $\mathbf{Post}_n$ for the variety it generates.
The constant $e_i$ is the term $0$ followed by $i$ primes, so that $e_0 = 0$ and $e_{n - 1} = n - 1$ in $\mathbf{P}_n$.
For an algebra $A$ in $\mathbf{Post}_n$, $B(A)$ is the Boolean algebra of complemented elements of its lattice reduct.
Some texts use the lattice signature with constants $e_i$ and unary operations $D_i$ instead.

## Remarks

### Examples

1. [[The chain $\mathbf{P}_3$|P7MWSZ837M]], the generator of $\mathbf{Post}_3$.
2. [[The square $\mathbf{P}_3^2$|8YXQWBZJQW]], with its nine elements as the decreasing pairs of complemented elements.
3. Every Boolean algebra, as a Post algebra of order $2$ with $x' = \neg x$.
4. The power $\mathbf{P}_n^X$ for a set $X$, with the pointwise operations.
5. The continuous maps from a Stone space to the discrete $\mathbf{P}_n$, with the pointwise operations.

### Non-examples

1. [[The three-element Kleene chain|G8JCK81ASR]]: the negation $x' = 2 - x$ fails $x''' = x$.
2. The chain $\mathbf{P}_3$ is not a Post algebra of order $2$: the identity $x'' = x$ fails at $x = 0$, since $0'' = 2$.
3. The four-element chain with $x' = x + 1 \bmod 4$ is a Post algebra of order $4$ but not of order $3$, since $0''' = 3 \ne 0$.

### Basic properties

1. The lattice reduct of a Post algebra is a bounded distributive lattice.
2. Every operation on $\set{0, \dots, n - 1}$ is a term operation of $\mathbf{P}_n$, by Post's functional completeness result. So $\mathbf{P}_n$ is primal.
3. By [[Foster's theorem|TCD8SZW95Z]], every Post algebra of order $n$ is isomorphic to a Boolean power $\mathbf{P}_n[B]^*$. The map $A \mapsto B(A)$ is an equivalence between $\mathbf{Post}_n$ and Boolean algebras.
4. Representation: each $x \in A$ is uniquely $x = \bigvee_{i = 1}^{n - 1} (b_i \land e_i)$ with $b_1 \ge b_2 \ge \dots \ge b_{n - 1}$ in $B(A)$.
5. The variety $\mathbf{Post}_n$ is generated by one finite simple algebra with no proper subalgebras, so its subdirectly irreducible members are the copies of $\mathbf{P}_n$.

### History

Post introduced the $n$-valued systems in his 1921 paper on elementary propositions.
Rosenbloom defined Post algebras in 1942, in an axiomatic form.
Epstein gave a lattice theoretic treatment in 1960, with the representation by chains of complemented elements.

### Common errors

1. Taking the negation to be order-reversing. Post's negation is cyclic, and it is not monotone.
2. Thinking that Post algebras are chains. Only $\mathbf{P}_n$ and its copies are chains; the others are products or Boolean powers.
3. Mixing up $\mathbf{P}_3$ and the three-element Łukasiewicz algebra. They have the same universe, but different operations and different term operations.

## Explanations

### L1 human

Classical logic has two truth values, and Boolean algebras capture its laws.
Post's logic has $n$ truth values on a ladder, and a negation that moves each value one step up and the top back to the bottom.
A Post algebra is an algebra that obeys the same laws.
Each element is built from $n - 1$ ordinary yes or no answers, one for each step of the ladder.

### L2 human

1. In $\mathbf{P}_3$, the constants are $e_0 = 0$, $e_1 = 0' = 1$ and $e_2 = 0'' = 2$.
2. The complemented elements are $0$ and $2$.
3. The element $1$ is $(2 \land e_1) \lor (0 \land e_2) = 1$, with the chain $b_1 = 2 \ge b_2 = 0$.
4. The element $2$ uses $b_1 = b_2 = 2$, and $0$ uses $b_1 = b_2 = 0$.
5. So the three elements correspond to the three decreasing chains of length $2$ in $\set{0, 2}$.

The typical use: questions about Post algebras reduce to questions about their Boolean algebras $B(A)$.
The trap: $\mathbf{P}_n^2$ is a Post algebra, but it is not a chain.

### L3 human

Post algebras are the first case of the theory of varieties generated by a primal algebra.
Foster's theorem gives the categorical equivalence with Boolean algebras, and so a Stone duality with Boolean spaces.
The Boolean products of $\mathbf{P}_n$ over a Stone space give the same algebras.
Since $\mathbf{P}_n$ is primal, the logic of Post algebras of order $n$ is the $n$-valued logic in which every truth function is expressible.
