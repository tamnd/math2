## Summary

The infinite sites model is a mutation model for DNA sequences in which every mutation hits a site that has never mutated before.
So no site is hit twice, and each polymorphic site of a sample records exactly one mutation.
It is the basic model behind the [[Watterson estimator|XD14B1J3EQ]] and [[Tajima's D|F3P1C35630]].

## Explanations

### L1 human

Picture a DNA sequence so long that two mutations almost never land on the same letter.
Then each mutation leaves its own mark at its own position.
Counting the positions where the sampled sequences disagree counts the mutations in their shared history.
For example, if three sequences differ at four positions, the infinite sites model says that four mutations happened in their genealogy.
