## Example

We count the triples $(x, y, z)$ of nonnegative integers with $x + y + z = 10$.
Listing them is long and easy to get wrong, so we replace the count by an equivalent [[auxiliary problem|DYSJB93V11]] about rows of symbols.

1. Write a triple as a row of $10$ stars and $2$ bars: $x$ stars, a bar, $y$ stars, a bar, $z$ stars.
   For example, $(3, 0, 7)$ becomes `***||*******`.
2. Each triple gives a row of $12$ symbols with exactly $2$ bars, since the stars number $x + y + z = 10$.
3. Each row of $12$ symbols with exactly $2$ bars gives a triple.
   Count the stars before the first bar, between the bars and after the second bar; the three counts are nonnegative and add up to $10$.
4. The maps of steps 2 and 3 undo each other, so they are bijections, and the [[bijection principle|0GV2573FP4]] says that the two sets have the same size.
5. A row is fixed by the places of its $2$ bars among the $12$ places, so the number of rows is
   $$\binom{12}{2} = \frac{12 \cdot 11}{2} = 66.$$
6. So there are $66$ triples.

Check on a small case: for $x + y + z = 2$ the same argument gives $\binom{4}{2} = 6$.
The six triples are $(2, 0, 0)$, $(0, 2, 0)$, $(0, 0, 2)$, $(1, 1, 0)$, $(1, 0, 1)$ and $(0, 1, 1)$.

## Remarks

The auxiliary problem is equivalent to the given one, because the bijection loses no information in either direction.
That is the best kind of auxiliary problem: its answer is the answer you want, with no candidates to check.
The general result is [[stars and bars|009TEMTQKH]]: the equation $x_1 + \dots + x_k = n$ has $\binom{n + k - 1}{k - 1}$ solutions in nonnegative integers.

When the unknowns must be positive, a second auxiliary problem helps.
Put $x = x' + 1$, $y = y' + 1$ and $z = z' + 1$, so that $x' + y' + z' = 7$ with $x', y', z' \ge 0$.
The count is then $\binom{9}{2} = 36$.

The direct count by cases also gives $66$, as the sum $11 + 10 + \dots + 1$, but with more unknowns it turns into nested sums.
The row of symbols turns every such count into one binomial coefficient.

## Explanations

### L1 human

We want to share $10$ sweets among $3$ children, and a child may get none.
Put the $10$ sweets in a row and place $2$ sticks in the row to cut it into three parts.
Each way to place the sticks is one way to share the sweets.
So we only count the ways to choose $2$ places out of $12$ for the sticks, and there are $66$.

### L2 human

We count the nonnegative integer solutions of $x + y + z + w = 5$ in the same way.
A solution is now a row of $5$ stars and $3$ bars, which has $8$ symbols.
The bijection is the same as before: count the stars between the bars.
The number of rows is the number of ways to choose $3$ places of $8$ for the bars:
$$\binom{8}{3} = \frac{8 \cdot 7 \cdot 6}{6} = 56.$$
So the equation has $56$ solutions.

The equivalence rests on the bijection.
If two rows gave the same triple, the count of rows would be too large, so the check in steps 2 to 4 is part of the proof.
