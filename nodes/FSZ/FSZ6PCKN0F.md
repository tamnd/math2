## Definition

Let $A$ be a [[finite set|070R982G4B]] with at least two elements.
A set $F$ of finitary [[operations|EJ8YJVM9BW]] on $A$ is functionally complete if the [[clone|PTKR703G6A]] generated by $F$ contains every operation $A^n \to A$ for every $n \geq 1$.
For $A = \set{0, 1}$ the operations are the truth functions.
Then a set $C$ of connectives is functionally complete when every truth function $f : \set{0,1}^n \to \set{0,1}$ with $n \geq 1$ is the truth function of a formula built from the variables $p_1, \ldots, p_n$ with connectives from $C$ only.

## Notation

The clone generated by $F$ is written $[F]$ or $\operatorname{Clo}(F)$; it is the smallest set of operations that contains $F$ and all projections $(x_1, \ldots, x_n) \mapsto x_i$, and is closed under composition.
In logic texts a functionally complete set of connectives is also called adequate.

## Remarks

The two forms of the definition agree for $A = \set{0,1}$: the operations in $[F]$ are exactly the truth functions of the formulas over $F$, where a variable gives a projection and a connective applied to formulas gives a composition.
Example: $F = \set{\land, \neg}$ on $\set{0, 1}$ is functionally complete.
Check: every Boolean function of $n \geq 1$ variables has a disjunctive normal form, with the constant $0$ written as $x_1 \land \neg x_1$.
The disjunctions are removed with $x \lor y = \neg(\neg x \land \neg y)$.
Non-example: $F = \set{\land, \lor}$ on $\set{0, 1}$ is not functionally complete.
Every operation built from $\land$ and $\lor$ maps $(1, \ldots, 1)$ to $1$, so $\neg$ is not in the generated clone.
Some texts allow the constants as free extra operations; this changes which sets count as complete.
For example, $\set{\to}$ is not complete, but $\set{\to, 0}$ is, since $\neg x = x \to 0$.

## Explanations

### L1 human

A set of logic gates is complete when every truth table can be built as a circuit from these gates alone.
"And" together with "not" is complete, and so is the single gate NAND.
"And" together with "or" is not complete, because a circuit made from them always outputs "true" when all inputs are "true".

### L2 human

To prove that a set of connectives is complete, express the connectives of a known complete set, such as $\neg$, $\land$, $\lor$.

1. For $\set{\neg, \land}$, write $p \lor q$ as $\neg(\neg p \land \neg q)$.
2. Check this with a truth table: both sides are false only at $p = q = 0$.
3. So every formula over $\set{\neg, \land, \lor}$ can be rewritten over $\set{\neg, \land}$, with the same truth table.

A trap: the rewriting must apply inside every part of the formula, which is a proof by structural induction.

### L3 human

Functional completeness says that $F$ generates the top element of the lattice of clones on $A$.
Because this top clone is finitely generated, $F$ is complete exactly when it lies in no maximal clone.
For $A = \set{0,1}$ the five maximal clones give [[Post's functional completeness theorem|WGBR7JHBV4]].
