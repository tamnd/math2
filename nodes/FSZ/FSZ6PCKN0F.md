## Definition

We define when a set of operations, such as the logic gates AND and NOT, can build every operation.

Let $A$ be a [[finite set|070R982G4B]] with at least two elements.
A set $F$ of finitary [[operations|EJ8YJVM9BW]] on $A$ is *functionally complete* when the [[clone|PTKR703G6A]] generated by $F$ contains every operation $A^n \to A$ for every $n \geq 1$.

For $A = \{ 0, 1 \}$ the operations are the truth functions, and the definition reads as follows.
A set $C$ of connectives is functionally complete when every truth function $f : \{ 0, 1 \}^n \to \{ 0, 1 \}$ with $n \geq 1$ is the truth function of a formula built from the variables $p_1, \ldots, p_n$ with connectives from $C$ only.

## Notation

The clone generated by $F$ is written $[F]$ or $\operatorname{Clo}(F)$.
It is the smallest set of operations that contains $F$ and all projections $(x_1, \ldots, x_n) \mapsto x_i$ and is closed under composition.
In logic texts a functionally complete set of connectives is also called adequate.

## Remarks

The two forms of the definition agree for $A = \{ 0, 1 \}$.
The operations in $[F]$ are exactly the truth functions of the formulas over $F$, because a variable gives a projection and a connective applied to formulas gives a composition.

A first example is $F = \{ \land, \neg \}$ on $\{ 0, 1 \}$, which is functionally complete.
Every Boolean function of $n \geq 1$ variables that takes the value $1$ has a disjunctive normal form, and the constant $0$ is $x_1 \land \neg x_1$.
The disjunctions are then removed with $x \lor y = \neg(\neg x \land \neg y)$.
Check at $x = 1$, $y = 0$: $\neg x \land \neg y = 0 \land 1 = 0$, and its negation is $1$, which is $x \lor y$.

A first non-example is $F = \{ \land, \lor \}$ on $\{ 0, 1 \}$.
Every operation built from $\land$ and $\lor$ maps $(1, \ldots, 1)$ to $1$, so $\neg$ is not in the generated clone.

Watch out: the constants are not in $[F]$ unless $F$ produces them.
Some texts allow the constants as free extra operations, and this changes which sets count as complete.
For example, $\{ \to \}$ is not complete, but $\{ \to, 0 \}$ is, since $\neg x = x \to 0$.

## Explanations

### L1 human

A set of logic gates is complete when every truth table can be built as a circuit from these gates alone.
"And" together with "not" is complete, and so is the single gate NAND.
"And" together with "or" is not complete, because a circuit made from them always outputs "true" when all inputs are "true".

### L2 human

To prove that a set of connectives is complete, express the connectives of a known complete set, such as $\neg$, $\land$ and $\lor$.
For $\{ \neg, \land \}$, write $p \lor q$ as $\neg(\neg p \land \neg q)$.
A truth table checks this: both sides are false only at $p = q = 0$.
So every formula over $\{ \neg, \land, \lor \}$ can be rewritten over $\{ \neg, \land \}$ with the same truth table.
Watch out: the rewriting must apply inside every part of the formula, and the proof that it keeps the truth table is a structural induction.

### L3 human

Functional completeness says that $F$ generates the top element of the lattice of clones on $A$.
This top clone is finitely generated, so $F$ is complete exactly when it lies in no maximal clone.
For $A = \{ 0, 1 \}$ the five maximal clones give [[Post's functional completeness theorem|WGBR7JHBV4]].
