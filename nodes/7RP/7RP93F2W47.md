## Definition

Let $\Sigma$ be a countable alphabet whose symbols are listed effectively, and let $\Sigma^*$ be the set of finite strings over $\Sigma$.
A *Gödel numbering* of $\Sigma^*$ is a map $\# \colon \Sigma^* \to \N$ with these three properties.

1. The map $\#$ is injective.
2. The map $\#$ is [[computable|KZSB5E471K]].
3. The set of codes $\set{\# w : w \in \Sigma^*}$ is a [[computable set|PPGD5KW8JC]], and the inverse map from codes to strings is computable.

For a first-order language, a Gödel numbering of its [[formulas|HYJ10AF6RT]] is the restriction of a Gödel numbering of its strings of symbols.
A Gödel numbering of proofs is a Gödel numbering of finite sequences of formulas, built in the same way from the codes of the formulas.

## Notation

1. The code of a string $w$ is written $\# w$, $\mathrm{gn}(w)$ or $\ulcorner w \urcorner$.
2. In a theory of arithmetic, $\ulcorner \varphi \urcorner$ also denotes the [[numeral|VK6WWSDMXK]] $\underline{\# \varphi}$, a closed term.

## Remarks

The standard example uses prime powers.
Give each symbol $s$ an injective code $c(s) \ge 1$, and let $p_1 = 2, p_2 = 3, p_3 = 5, \ldots$ be the primes in increasing order.
Set $\# (s_1 s_2 \cdots s_n) = p_1^{c(s_1)} p_2^{c(s_2)} \cdots p_n^{c(s_n)}$.
By unique factorization the map is injective.
Trial division finds the exponents of a number, so the map and its inverse are computable, and all three clauses hold.

The map that sends each string to its length is computable, but it fails clause 1, because different strings of the same length get the same number.

Any two Gödel numberings $\#_1$ and $\#_2$ of $\Sigma^*$ are related by the computable bijection $\#_2 \circ \#_1^{-1}$ between their sets of codes.
For this reason the choice of numbering does not change which sets of formulas are computable or computably enumerable.

The main page of the idea, with examples, is the concept [[Gödel numbering|MFJXPAF0R0]].

## Explanations

### L1 human

A Gödel numbering is a rule that turns each piece of text into one whole number.
Different texts must get different numbers.
A computer must be able to go from the text to the number and back.
For example, if "0" has code 13 and "=" has code 7, then the text "0=0" can get the number $2^{13} \cdot 3^{7} \cdot 5^{13}$.

### L2 human

1. Take the alphabet $\set{a, b}$ with $c(a) = 1$ and $c(b) = 2$.
2. The string $ab$ gets $2^1 \cdot 3^2 = 18$, and the string $ba$ gets $2^2 \cdot 3^1 = 12$.
3. To decode $18$, divide by $2$ once and by $3$ twice, and read the exponents $1, 2$ as $a, b$.
4. The number $10 = 2 \cdot 5$ is not a code, because the prime $3$ is skipped.

The typical use is to replace a syntactic relation, such as "$x$ is the code of a formula", by a relation on numbers.
A trap: clause 3 matters, since an injective but not computable map does not let arithmetic describe syntax.
