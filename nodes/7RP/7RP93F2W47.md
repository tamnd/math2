## Definition

A Gödel numbering is a computable way to turn each string of symbols into a number, so that the string can be read back from the number.

Let $\Sigma$ be a countable alphabet whose symbols are listed effectively, and let $\Sigma^*$ be the set of finite strings over $\Sigma$.
A *Gödel numbering* of $\Sigma^*$ is a map $\# \colon \Sigma^* \to \mathbb{N}$ with these three properties.

1. The map $\#$ is injective.
2. The map $\#$ is [[computable|KZSB5E471K]].
3. The set of codes $\{ \# w : w \in \Sigma^* \}$ is a [[computable set|PPGD5KW8JC]], and the inverse map from codes to strings is computable.

For a first-order language, a Gödel numbering of its [[formulas|HYJ10AF6RT]] is the restriction of a Gödel numbering of its strings of symbols.
A Gödel numbering of proofs is a Gödel numbering of finite sequences of formulas, built in the same way from the codes of the formulas.

## Notation

The code of a string $w$ is written $\# w$, $\mathrm{gn}(w)$ or $\ulcorner w \urcorner$.
In a theory of arithmetic, $\ulcorner \varphi \urcorner$ also denotes the [[numeral|VK6WWSDMXK]] $\underline{\# \varphi}$, which is a closed term and not a number.

## Remarks

Each condition has a job.
Injectivity makes the code name one string only, so that a statement about the code is a statement about that string.
Computability of $\#$ means that we can find the code of a formula by a mechanical procedure.
The third condition is the reverse direction: given a number, we can decide whether it is a code and, if it is, recover the string.
Without it, arithmetic could not inspect a code to find, for example, the last formula of a proof.

The standard example uses prime powers.
Give each symbol $s$ a code $c(s) \ge 1$, with different symbols getting different codes, and let $p_1 = 2, p_2 = 3, p_3 = 5, \ldots$ be the primes.
Set
$$\#(s_1 s_2 \cdots s_n) = p_1^{c(s_1)} p_2^{c(s_2)} \cdots p_n^{c(s_n)}.$$
By unique factorization the map is injective.
Trial division finds the exponents of a number, so the map and its inverse are computable, and all three conditions hold.
For the alphabet $\{a, b\}$ with $c(a) = 1$ and $c(b) = 2$, the string $ab$ gets $2^1 \cdot 3^2 = 18$, and $ba$ gets $2^2 \cdot 3^1 = 12$.
The number $10 = 2 \cdot 5$ is not a code, because it skips the prime $3$.

The map that sends each string to its length is computable, but it fails condition 1, because $ab$ and $ba$ both get $2$.

Any two Gödel numberings $\#_1$ and $\#_2$ of $\Sigma^*$ are related by the computable bijection $\#_2 \circ \#_1^{-1}$ between their sets of codes.
For this reason the choice of numbering does not change which sets of formulas are computable or computably enumerable.
The concept page [[Gödel numbering|MFJXPAF0R0]] has the worked examples and the uses.

## Explanations

### L1 human

A Gödel numbering is a rule that turns each piece of text into one whole number.
Different texts must get different numbers.
A computer must be able to go from the text to the number and back.
For example, if "0" has code 13 and "=" has code 7, then the text "0=0" gets the number $2^{13} \cdot 3^{7} \cdot 5^{13}$.

### L2 human

We decode the number $18$ in the numbering of strings over $\{a, b\}$ above.
Divide by $2$: $18 = 2 \cdot 9$, and $9$ is odd, so the exponent of $2$ is $1$.
Divide by $3$: $9 = 3^2$, so the exponent of $3$ is $2$, and nothing is left.
The exponents $1, 2$ read as $a, b$, so $18$ is the code of $ab$.
The decoding used only division, which is why condition 3 holds.
This is how arithmetic reads a formula from its code, and the [[arithmetization of syntax|6M12VR1GT6]] builds on it.
