## Example

We take a real proof of $0 + 0 = 0$ and turn it into a proof of the sentence "$0 + 0 = 0$ is provable".
Let $\mathsf{Q}$ be [[Robinson arithmetic|TT8MXRTVBM]], with a Hilbert-style proof system whose rule is modus ponens.
Let $\mathrm{Prov}_{\mathsf{Q}}(x) := \exists y \, \mathrm{Prf}_{\mathsf{Q}}(y, x)$ be its [[provability predicate|NB2BCZR40F]].
We show that $\mathsf{Q} \vdash \mathrm{Prov}_{\mathsf{Q}}(\ulcorner 0 + 0 = 0 \urcorner)$.

1. Line 1 is $\forall x \, (x + 0 = x)$, which is an axiom of $\mathsf{Q}$.
2. Line 2 is $\forall x \, (x + 0 = x) \to 0 + 0 = 0$.
   It is a logical axiom, an instance of $\forall x \, \psi(x) \to \psi(t)$ with the closed term $t = 0$.
3. Line 3 is $0 + 0 = 0$, which follows from lines 1 and 2 by modus ponens.
4. Let $p = 2^{a_1} 3^{a_2} 5^{a_3}$, where $a_i$ is the code of line $i$.
   By steps 1 to 3, $p$ codes a proof in $\mathsf{Q}$ of $0 + 0 = 0$.
5. The relation "$y$ codes a proof in $\mathsf{Q}$ of the formula with code $x$" is decidable, by [[arithmetization of syntax|6M12VR1GT6]].
   It holds for $y = p$ and $x = \#(0 + 0 = 0)$.
6. The formula $\mathrm{Prf}_{\mathsf{Q}}$ represents this relation in $\mathsf{Q}$, so $\mathsf{Q} \vdash \mathrm{Prf}_{\mathsf{Q}}(\underline{p}, \ulcorner 0 + 0 = 0 \urcorner)$.
7. The logical rule from $\psi(t)$ to $\exists y \, \psi(y)$ gives $\mathsf{Q} \vdash \exists y \, \mathrm{Prf}_{\mathsf{Q}}(y, \ulcorner 0 + 0 = 0 \urcorner)$, which is $\mathrm{Prov}_{\mathsf{Q}}(\ulcorner 0 + 0 = 0 \urcorner)$.

## Remarks

The example is one instance of the first [[derivability condition|F6H4STF9RG]]: a proof in $T$ yields a proof in $T$ that $\mathrm{Prov}_T$ holds.
Nothing in the steps used the particular sentence except in steps 1 to 3, so the same recipe works for every theorem of every theory with a decidable axiom set.

The proof of step 6 is long.
The number $p$ is huge, and the numeral $\underline{p}$ is a term with $p$ symbols $S$.
Still, the proof exists, and existence is all that the incompleteness theorems need.

Now change the sentence to $\forall x \, (0 + x = x)$.
$\mathsf{Q}$ does not prove it, since some models of $\mathsf{Q}$ have an element $a$ with $0 + a \ne a$.
So no $p$ exists, the recipe has nothing to start from, and $\mathrm{Prov}_{\mathsf{Q}}$ of this code is false in $\mathbb{N}$.

Watch out: the recipe goes from a real proof to a formal statement, and not back.
A theory can prove $\mathrm{Prov}_T(\ulcorner \varphi \urcorner)$ without any real proof of $\varphi$, as [[non-standard proofs|JP0RVCPF38]] show.

## Explanations

### L1 human

The statement "zero plus zero is zero" has a three-line proof from the axioms.
That proof is a finite object, so it has a code number $p$.
Robinson arithmetic can check the claim "$p$ codes a proof of zero plus zero is zero" by calculation.
So Robinson arithmetic proves "there is a proof of zero plus zero is zero".

### L2 human

The whole example compresses into four moves.
Write the proof: the axiom $\forall x \, (x + 0 = x)$, its instance at $x = 0$, and modus ponens.
Code the three lines, and then the proof, by prime powers.
Representability turns the true statement "$p$ is a proof" into the theorem $\mathrm{Prf}_{\mathsf{Q}}(\underline{p}, \ulcorner 0 + 0 = 0 \urcorner)$ of $\mathsf{Q}$.
The rule for $\exists$ then hides the explicit number $p$.
These four moves are the first derivability condition, which the proofs of the [[second incompleteness theorem|4PZM5GJTR5]] and of [[Löb's theorem|3HD30YG3DG]] use in every application.
