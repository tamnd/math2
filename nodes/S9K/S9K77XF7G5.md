## Definition

Let $f \colon \R^n \to \R$ be continuously differentiable, with [[gradient|0ABK9V9Y64]] $\nabla f$.
Let $x \in \R^n$ and let $p$ be a descent direction at $x$, that is, $\nabla f(x)^T p < 0$.
Fix an initial step $\bar\alpha > 0$, a contraction factor $\rho \in (0, 1)$ and a constant $c \in (0, 1)$.
*Backtracking line search* returns the step length
$$\alpha = \bar\alpha \rho^{j},$$
where $j \ge 0$ is the least integer such that
$$f(x + \bar\alpha \rho^{j} p) \le f(x) + c \, \bar\alpha \rho^{j} \, \nabla f(x)^T p.$$

## Remarks

In words: start with $\alpha = \bar\alpha$, and replace $\alpha$ by $\rho \alpha$ as long as the Armijo condition, clause 1 of the [[Wolfe conditions|E1F970GGRC]], fails.
The integer $j$ exists: $(f(x + \alpha p) - f(x)) / \alpha \to \nabla f(x)^T p$ as $\alpha \to 0^+$, and $\nabla f(x)^T p < c \nabla f(x)^T p$.

Example: $f(x) = x^2$, $x = 1$, $p = -f'(1) = -2$, $\bar\alpha = 1$, $\rho = c = 1/2$.
The test reads $f(1 - 2\alpha) \le 1 - 2\alpha$.
For $j = 0$, $f(-1) = 1 > -1$, so the step is rejected.
For $j = 1$, $f(0) = 0 \le 0$, so $\alpha = 1/2$ is returned.

Non-example: if $p = 2$ is not a descent direction at $x = 1$, then $f(1 + 2\alpha) = 1 + 4\alpha + 4\alpha^2 > 1 + 4c\alpha$ for every $\alpha > 0$.
No integer $j$ works, and the procedure never stops.
