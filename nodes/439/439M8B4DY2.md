## Summary

A formal system $S$ has four parts.
The first part is an [[alphabet|RABRP2KG81]], a set of symbols.
The second part is a set of formation rules, which single out some finite [[strings|1P6EP01HZF]] over the alphabet as the formulas of $S$.
The third part is a set of formulas, the axioms of $S$.
The fourth part is a finite set of rules of inference; each rule has a fixed number of premises and says which formula may be written after given premises.
We require each part to be [[decidable|T62EJ749R5]]: a mechanical procedure tells whether a string is a formula, whether a formula is an axiom, and whether a rule leads from given premises to a given formula.
A derivation in $S$ is a finite sequence of formulas in which each formula is an axiom or follows from earlier formulas by a rule.
A theorem of $S$ is a formula that is the last formula of some derivation.
Formal systems matter because they make proofs into finite objects, so that questions about provability become mathematical questions.

## Motivation

A proof in a textbook leaves many small steps to the reader.
Two readers can disagree about whether such a proof is complete, and around 1900 the paradoxes of set theory, such as [[Russell's paradox|0HESMMSYEG]], made this a serious problem.
A formal system removes the disagreement: the allowed steps are listed, and each step only looks at the shape of strings.
Then a computer can check a derivation, and a mathematician can prove facts about all derivations at once.
[[Hilbert's program|P1RW6JWX73]] needed exactly this, because it asked for proofs that no derivation ends in a contradiction.

## Notation

We write $\vdash_S \varphi$ when $\varphi$ is a theorem of $S$, and $\vdash \varphi$ when $S$ is fixed.
For a set $\Gamma$ of formulas, $\Gamma \vdash_S \varphi$ means that some derivation ends with $\varphi$ when the members of $\Gamma$ may be used as extra axioms (hypotheses).
Other names in the literature are formal theory, deductive system, logistic system and calculus.
Some books allow a countably infinite alphabet, such as the propositional variables $p_0, p_1, p_2, \dots$; the alphabet must then be decidable.
Some books drop the decidability requirement and speak of an effective formal system when it holds.

On the pages of this sub-area a theory is any set of sentences, and its members are its axioms.
The set of all consequences of a theory is its deductive closure, and a theory that equals its deductive closure is deductively closed.
The word "complete" has three meanings, and each page says which one it uses.
A proof system is complete for a semantics when it derives every consequence of the semantics.
A theory is complete (negation complete) when it proves $\varphi$ or $\neg \varphi$ for each sentence $\varphi$.
A system is Post complete when each new axiom schema that is not already derivable makes it inconsistent, as on the page [[Post consistency|WK2P0E82B4]].

## Remarks

### Examples

- The [[MIU system|PMN32E37BW]] has the alphabet $\set{M, I, U}$, the single axiom $MI$ and four rules. The string $MU$ is not a theorem, because the number of letters $I$ in a theorem is never divisible by $3$.
- The [[pq-system|96BDP1YQMT]] has the alphabet $\set{p, q, -}$. Its theorems are exactly the strings that say $a + b = c$ in unary notation, with $a, b \geq 1$.
- A [[Hilbert system|1MGMQX43B8]] for propositional logic has the variables, $\neg$, $\to$ and parentheses as alphabet, three axiom schemas and the rule [[modus ponens|0Y0MQYST0M]]. Its theorems are exactly the [[tautologies|05006AJ7DZ]], by soundness and completeness.
- First-order arithmetic with the [[Peano axioms|0QFT7Z76N5]] is a formal system. The induction schema gives infinitely many axioms, but it is decidable whether a formula is one of them.
- [[Zermelo-Fraenkel set theory|0HE5WDQ9FJ]] is a formal system with the single non-logical symbol $\in$. Most of mathematics can be derived in it.
- A [[formal grammar|DP1HXZGPCM]] is a formal system: the start symbol is the axiom and the productions are rules with one premise.

### Non-examples

- [[True arithmetic taken as a set of axioms|9BW1F5B5GA]] fails the condition that the axioms form a decidable set. So no procedure can check its derivations.
- A system with the $\omega$-rule, "from $\varphi(0), \varphi(1), \varphi(2), \dots$ infer $\forall x\, \varphi(x)$", fails the condition that each rule has finitely many premises. It is not a [[finitary formal system|AP5F7FXTVM]].
- A [[mathematical proof|0B94TKFQJX]] written in ordinary language is not a derivation in a formal system. Its steps are not given by a fixed list of rules on strings, as the page on the [[axiomatic method|GD2JBXJV5Z]] explains.

### Basic properties

- It is decidable whether a finite sequence of formulas is a derivation. There are finitely many lines, finitely many rules, and each rule has a fixed number of premises, so each line needs finitely many decidable checks.
- The set of theorems is [[computably enumerable|TN9G24VABN]]: list all finite sequences of formulas, and keep the last line of each sequence that is a derivation.
- The set of theorems need not be decidable. For first-order logic it is not, by [[Church's theorem|VA6BNNY2YC]].
- Theorems are closed under the rules: if the premises of a rule are theorems, then the conclusion is a theorem. Write the derivations of the premises one after the other and add the conclusion.
- To show that every theorem has a property $P$, it suffices to show that each axiom has $P$ and that each rule keeps $P$. This is induction on the length of derivations, and it proves both that $MU$ is not a theorem of the MIU system and the [[soundness|4A84VHDTHV]] of proof systems.
- Derivability from hypotheses, $\Gamma \vdash_S \varphi$, is a [[consequence relation|J78Y1M4GND]].

### Syntax and semantics

The rules of a formal system act on strings, and they do not use any meaning of the symbols: this is the syntax of the system.
A semantics gives the formulas a meaning, usually by saying in which structures or under which valuations a formula is true.
For the pq-system, the reading "$p$ means plus and $q$ means equals" makes every theorem a true equation.
The same system has other readings, and the MIU system has no intended reading at all.
A proof system is sound for a semantics when every theorem is true in every interpretation, and complete for it when every formula true in every interpretation is a theorem.
For first-order logic both hold, by soundness and by [[Gödel's completeness theorem|WQ1ZE255SF]].
For arithmetic, the [[incompleteness theorems|X9WYNYE29C]] show that no consistent formal system with decidable axioms derives all sentences true in the natural numbers.
The difference between the formulas of $S$ and the statements that we make about $S$ is the subject of the page [[object language and metalanguage|D9G8M42GKC]].

### History

Gottlob Frege's *Begriffsschrift* of 1879 gave the first formal system for predicate logic, with explicit axioms and rules of inference.
In the 1920s David Hilbert and his school made formal systems themselves the object of mathematical study.
In 1931 Kurt Gödel proved his incompleteness theorems for formal systems of arithmetic, and in 1936 Alonzo Church and Alan Turing showed that the theorems of first-order logic form an undecidable set.
Douglas Hofstadter introduced the MIU system in his book *Gödel, Escher, Bach* of 1979.

### Common errors

- A theorem of $S$ is a formula with a derivation, not a true statement. Truth needs a semantics, and a theorem of an unsound system can be false.
- A decidable set of axioms does not make the set of theorems decidable. First-order logic has a decidable set of axioms and an undecidable set of theorems.
- The phrase "$S$ is complete" is ambiguous. State whether it means completeness for a semantics, negation completeness or Post completeness.

## Explanations

### L1 human

A formal system is a game with strings of symbols.
The rules say which string we start with and how we may change a string into a new one.
In the MIU game we start with the string MI.
One rule says that from M followed by any string we may write M followed by that string twice, so MI gives MII, and MII gives MIIII.
Another rule says that three I's in a row may be replaced by one U, so MIIII gives MUI.
Every string that we can reach is a theorem of the game.
The string MU can never be reached, because the number of I's is never a multiple of three.

### L2 human

We work in the Hilbert system $H$ for propositional logic.
Its formulas are built from variables $p, q, r, \dots$ with $\neg$, $\to$ and parentheses.
Its axioms are all instances of three schemas, where $\varphi, \psi, \chi$ stand for any formulas.

- A1: $\varphi \to (\psi \to \varphi)$.
- A2: $(\varphi \to (\psi \to \chi)) \to ((\varphi \to \psi) \to (\varphi \to \chi))$.
- A3: $(\neg \psi \to \neg \varphi) \to ((\neg \psi \to \varphi) \to \psi)$.

The only rule is modus ponens: from $\varphi$ and $\varphi \to \psi$ infer $\psi$.
We derive $p \to p$.

1. $(p \to ((p \to p) \to p)) \to ((p \to (p \to p)) \to (p \to p))$ is an instance of A2 with $\varphi = p$, $\psi = p \to p$, $\chi = p$.
2. $p \to ((p \to p) \to p)$ is an instance of A1 with $\varphi = p$ and $\psi = p \to p$.
3. $(p \to (p \to p)) \to (p \to p)$ follows from lines 2 and 1 by modus ponens.
4. $p \to (p \to p)$ is an instance of A1 with $\varphi = p$ and $\psi = p$.
5. $p \to p$ follows from lines 4 and 3 by modus ponens.

Each line is checked by matching shapes, without any idea of truth.
The typical use of a formal system is twofold: we find derivations to show that formulas are theorems, and we find invariants to show that formulas are not theorems.
A trap is to read "$p \to p$ is a theorem" as a formula of $H$.
It is a statement about $H$, made in the metalanguage, and the formula is only $p \to p$.

### L3 human

The theorems of a formal system form a computably enumerable set of strings.
Conversely, every computably enumerable set $X$ of strings is the set of theorems without an extra symbol of some formal system.
For this, add a symbol $\#$, take as axioms the strings $w \#^n$ such that an enumeration of $X$ lists $w$ at step $n$, and add the rule "from $w \# v$ infer $w$" when $v$ consists of $\#$ only.
So formal systems and computably enumerable sets are two views of one notion, as Post's canonical systems and the theory of [[rewriting systems|Y83TQF6V6A]] show.

Natural deduction and sequent calculi are formal systems in which derivations are trees and rules act on sequents rather than on single formulas; [[Proof systems for first-order logic|TTCRX3NFNY]] compares them.
The relation $\Gamma \vdash_S \varphi$ of any formal system is a finitary [[consequence relation|J78Y1M4GND]], and the study of [[abstract logical systems|RQXV7PM2WT]] starts from this observation.
The three senses of "complete" lead to the main theorems of the area: [[Gödel's completeness theorem|WQ1ZE255SF]] for proof systems, the [[incompleteness theorems|X9WYNYE29C]] for theories, and the Post completeness of classical propositional logic.
