## Example

Let $T \colon \R^2 \to \R^2$ be the map $T(v) = 2v$, with the dot product on $\R^2$.
We check the two conditions of a [[linear isometry|0717XXPWM6]] and find that the second one fails.

1. The map is linear, because $T(au + bv) = 2au + 2bv = aT(u) + bT(v)$.
2. The norm condition fails at $(1, 0)$, because $\norm{T(1, 0)} = \norm{(2, 0)} = 2$ while $\norm{(1, 0)} = 1$.
3. In fact $\norm{Tv} = 2\norm{v}$, so the condition fails for every $v \ne 0$.
4. For inner products, $\ip{Tu}{Tv} = \ip{2u}{2v} = 4\ip{u}{v}$, so $T^*T = 4I \ne I$.

## Remarks

The map keeps angles and right angles, since $\ip{Tu}{Tv} = 0$ exactly when $\ip{u}{v} = 0$.
So keeping orthogonality does not make a linear map an isometry.
Such maps, a positive multiple of an isometry, are called similarities or conformal linear maps.

Change the factor and see what happens.
The scaling $v \mapsto cv$ on a real space is a linear isometry exactly when $\abs{c} = 1$, that is, when $c = 1$ or $c = -1$.
The inverse map $v \mapsto \tfrac{1}{2}v$ halves every length, so it fails as well.
On $\C^n$ the scalings by every $c$ with $\abs{c} = 1$, such as $c = i$, are linear isometries.

## Explanations

### L1 human

A copier that doubles the size of a picture keeps the shape of the picture, but not its size.
A segment of length $3$ becomes a segment of length $6$.
An isometry must keep sizes, so doubling is not an isometry.

### L2 human

Take $v = (3, 4)$, which has length $5$.
Then $Tv = (6, 8)$, and its length is
$$\sqrt{36 + 64} = \sqrt{100} = 10.$$
So $\norm{Tv} \ne \norm{v}$, and $T$ is not a linear isometry.
Watch out: the matrix $2I$ has orthogonal columns $(2, 0)$ and $(0, 2)$, but they are not unit vectors, so $2I$ is not an [[orthogonal matrix|0W02QESPJQ]].
