## Example

We prove $\forall x\, Q(x)$ from the premises $\forall x\, (P(x) \to Q(x))$ and $\forall x\, P(x)$ in [[Fitch-style natural deduction|2B6XC7XJA8]].
```text
 1 │ ∀x (P(x) → Q(x))
 2 │ ∀x P(x)
   ├────────────────
 3 │ │ [c]
   │ ├────
 4 │ │ P(c) → Q(c)        ∀ Elim: 1
 5 │ │ P(c)               ∀ Elim: 2
 6 │ │ Q(c)               → Elim: 4, 5
 7 │ ∀x Q(x)              ∀ Intro: 3-6
```
We check each line.

1. Lines 1 and 2 are the premises, above the Fitch bar of the main proof.
2. Line 3 opens a box with the constant $c$. The constant $c$ does not occur in lines 1 and 2, so it is new.
3. Line 4 is ${\forall}$ Elim from line 1: $(P(x) \to Q(x))[c/x] = P(c) \to Q(c)$. Line 1 is in the main scope, which contains the box, so the citation is allowed.
4. Line 5 is ${\forall}$ Elim from line 2: $P(x)[c/x] = P(c)$.
5. Line 6 is ${\to}$ Elim from lines 4 and 5, both inside the same box.
6. Line 7 is ${\forall}$ Intro from the box of lines 3 to 6: the box starts with $\boxed{c}$ and ends with $Q(x)[c/x] = Q(c)$.
7. The constant $c$ does not occur in line 7 or outside the box, so the condition of ${\forall}$ Intro holds.
8. Line 7 is in the main scope, where only the premises are open. So the list is a proof of $\forall x\, Q(x)$ from the premises.

## Remarks

The proof is the Fitch form of the informal argument "let $c$ be arbitrary; then $P(c)$, and so $Q(c)$".
In the tree form of [[natural deduction|6KT3BJZ7D1]] the same proof has a variable $y$ in place of $c$ and no box.
If the second premise is changed to $P(a)$ for a constant $a$, the proof breaks: ${\forall}$ Intro on $a$ fails, because $a$ occurs outside the box.
With that premise only $Q(a)$ follows, by ${\forall}$ Elim with $a$ and ${\to}$ Elim.

## Explanations

### L1 human

The premises say "every $P$ is a $Q$" and "everything is a $P$".
The proof picks a new object $c$, with no special property.
It shows that $c$ is a $P$ and then that $c$ is a $Q$.
Because $c$ was a new name, the same steps work for every object, so everything is a $Q$.

### L2 human

To write a Fitch proof of a universal goal $\forall x\, Q(x)$, follow three steps.

1. Open a box with a constant that does not occur in the proof so far.
2. Inside the box, derive $Q(c)$, using lines from outside the box when needed.
3. Close the box and write $\forall x\, Q(x)$ in the outer scope.

A trap is to choose a constant that already occurs in a premise.
