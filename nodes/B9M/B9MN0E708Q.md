## Example

We prove $\forall x\, Q(x)$ from the premises $\forall x\, (P(x) \to Q(x))$ and $\forall x\, P(x)$ in [[Fitch-style natural deduction|2B6XC7XJA8]].
In words: if every $P$ is a $Q$ and everything is a $P$, then everything is a $Q$.
```text
 1 │ ∀x (P(x) → Q(x))
 2 │ ∀x P(x)
   ├────────────────
 3 │ │ [c]
   │ ├────
 4 │ │ P(c) → Q(c)        ∀ Elim: 1
 5 │ │ P(c)               ∀ Elim: 2
 6 │ │ Q(c)               → Elim: 4, 5
 7 │ ∀x Q(x)              ∀ Intro: 3-6
```
We check each line.

1. Lines 1 and 2 are the premises, above the Fitch bar of the main proof.
2. Line 3 opens a box with the constant $c$, which does not occur in lines 1 and 2, so it is new.
3. Line 4 follows by ${\forall}$ Elim from line 1, since $(P(x) \to Q(x))[c/x] = P(c) \to Q(c)$.
   Line 1 is in the main scope, which contains the box, so the citation is allowed.
4. Line 5 follows by ${\forall}$ Elim from line 2, since $P(x)[c/x] = P(c)$.
5. Line 6 follows by ${\to}$ Elim from lines 4 and 5, which lie in the same box.
6. Line 7 follows by ${\forall}$ Intro from the box of lines 3 to 6, which starts with $\boxed{c}$ and ends with $Q(x)[c/x] = Q(c)$.
7. The constant $c$ occurs neither in line 7 nor anywhere else outside the box, so the condition of ${\forall}$ Intro holds.
8. Line 7 stands in the main scope, where only the premises are open, so the list is a proof of $\forall x\, Q(x)$ from the premises.

## Remarks

### What the example shows

The proof is the Fitch form of the informal argument "let $c$ be arbitrary; then $P(c)$, and so $Q(c)$".
In the tree form of [[natural deduction|6KT3BJZ7D1]] the same proof has a variable $y$ in place of $c$ and no box.
The box has no assumption formula, only the constant: for ${\forall}$ Intro the constant itself is all that the box introduces.

### What changes with a named object

Replace the second premise by $P(a)$ for a constant $a$.
Then the proof breaks at line 7: to use $P(a)$ inside the box we would need the boxed constant to be $a$, but $a$ occurs in a premise, outside the box.
With that premise only $Q(a)$ follows, by ${\forall}$ Elim with $a$ and ${\to}$ Elim, and $\forall x\, Q(x)$ is not a consequence.
For example, in the domain $\{0, 1\}$ with $P$ and $Q$ true of $0$ only and $a = 0$, both premises hold and $\forall x\, Q(x)$ fails.

## Explanations

### L1 human

The premises say "every $P$ is a $Q$" and "everything is a $P$".
The proof picks a new object $c$ with no special property.
It shows that $c$ is a $P$ and then that $c$ is a $Q$.
Because $c$ was a new name, the same steps work for every object, so everything is a $Q$.

### L2 human

To write a Fitch proof of a universal goal $\forall x\, Q(x)$, follow three steps.

1. Open a box with a constant that does not occur in the proof so far.
2. Inside the box, derive $Q(c)$, and cite lines from outside the box when you need them.
3. Close the box and write $\forall x\, Q(x)$ in the outer scope.

The typical use is the step "let $c$ be arbitrary" of an informal proof.
Watch out: a constant that already occurs in a premise is not arbitrary, and a box with it cannot be closed by ${\forall}$ Intro.
