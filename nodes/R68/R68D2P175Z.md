## Example

Let $\mathbb{N} = \{0, 1, 2, \dots\}$ be the set of [[natural numbers|0MWKJ44V5A]], with the usual addition.
We check the group axioms and find the one that fails.

1. Closure holds: the sum of two natural numbers is a natural number.
2. Associativity holds: $(a + b) + c = a + (b + c)$ for all $a, b, c \in \mathbb{N}$.
3. An identity exists: $0 + a = a = a + 0$ for each $a \in \mathbb{N}$.
4. Inverses fail. An [[inverse|0ZNZH0EXFX]] of $1$ would be an $m \in \mathbb{N}$ with $1 + m = 0$. But $m \geq 0$, so $1 + m \geq 1$, and $1 + m \neq 0$.

Thus $(\mathbb{N}, +)$ is not a [[group|G5S1M9]].
It is a commutative [[monoid|0N6R902FG1]].

## Remarks

The same argument shows that each $n \geq 1$ has no inverse, because $n + m \geq n \geq 1$.
Only the element $0$ has an inverse, namely $0$ itself.
When we add the negative integers, each $n$ gets the inverse $-n$, and we get the [[additive group of integers|0BSCJA5G53]] $(\mathbb{Z}, +)$.
This is the smallest group that contains $(\mathbb{N}, +)$ in a natural way.
The monoid $(\mathbb{N}, +)$ satisfies both cancellation laws, because $a + b = a + c$ implies $b = c$.
So cancellation alone does not make an infinite monoid a group.

## Explanations

### L1 human

With the numbers $0, 1, 2, \ldots$ and addition, adding $0$ changes nothing.
To undo adding $1$, we would need a number that gives $0$ when we add it to $1$.
No number of the list does this, because adding a number never makes the result smaller.
So adding $1$ cannot be undone, and these numbers with addition are not a group.

### L2 human

We find all elements of $(\mathbb{N}, +)$ that have an inverse.

1. Let $a \in \mathbb{N}$ have an inverse $m \in \mathbb{N}$, so $a + m = 0$.
2. Both $a \geq 0$ and $m \geq 0$, so $a \leq a + m = 0$.
3. Thus $a = 0$, and then $m = 0$.

So $0$ is the only element with an inverse.
The typical use of this non-example is to show that the inverse axiom does not follow from the other axioms.
A trap is to say that $-1$ is the inverse of $1$; the inverse must lie in the set, and $-1 \notin \mathbb{N}$.
