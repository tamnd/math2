## Statement

A satisfiable formula with $50$ variables has a certificate of $50$ bits, one satisfying assignment, and you can check it in a moment.
The theorem says that every tautology has a certificate of polynomial size in some fixed proof system exactly when $\mathrm{NP} = \mathrm{coNP}$.

Let $\mathrm{TAUT}$ be the set of codes of propositional tautologies over a fixed finite alphabet.
A [[propositional proof system|3V24CYWDT6]] is a polynomial-time function onto $\mathrm{TAUT}$.
It is *polynomially bounded* if there is a polynomial $q$ such that every tautology $\tau$ has a proof of length at most $q(\lvert \tau \rvert)$.
Let [[NP|SBDQH0TJ5X]] and [[coNP|NBSD5FG7NY]] be the usual complexity classes.
Then the following two conditions are equivalent.

1. There is a polynomially bounded propositional proof system.
2. $\mathrm{NP} = \mathrm{coNP}$.

The measure is size, the number of symbols of a proof.

## Remarks

### Why each hypothesis is needed

The checker must run in polynomial time.
Without that condition, the map that sends each tautology to itself and every other string to $p \lor \neg p$ would count, with proofs of length $\lvert \tau \rvert$.
Then condition 1 would hold outright, and the theorem would assert $\mathrm{NP} = \mathrm{coNP}$, which no one knows.

The bound must be a polynomial in $\lvert \tau \rvert$.
Every tautology has some proof in every proof system, because of completeness, so the question is only how long the shortest proof is.
A bound such as $2^{\lvert \tau \rvert}$ holds in the [[truth-table proof system|67MYPBSHCJ]] and says nothing about $\mathrm{NP}$.

The image must be all of $\mathrm{TAUT}$.
A system that proves only some tautologies, all with short proofs, is easy to build, and it tells us nothing about the hard ones.

### What it gives you

The theorem turns a question about machines into a question about proofs.
To prove $\mathrm{NP} \ne \mathrm{coNP}$, it is enough to show that no proof system is polynomially bounded.
Cook's program attacks this one system at a time: [[resolution|6JSH907W5R]], [[bounded-depth Frege|41QJ1WEMJ3]], [[cutting planes|KKCX2HQP2K]], [[Frege|J2BAR09TPF]] and [[extended Frege|5YSE04SHFH]].

Here is the chain of implications, as a worked use.
If every proof system has a family of tautologies with superpolynomial size, then condition 1 fails.
So $\mathrm{NP} \ne \mathrm{coNP}$ by the theorem.
Since $\mathrm{P}$ is closed under complement, $\mathrm{P} = \mathrm{NP}$ would give $\mathrm{NP} = \mathrm{coNP}$, so also $\mathrm{P} \ne \mathrm{NP}$, which settles the [[P versus NP problem|MFN5GYZH5Z]].

### One system is not all systems

A lower bound for a single system does not give $\mathrm{NP} \ne \mathrm{coNP}$.
[[Haken's theorem|4PCEYEW3JG]] shows that resolution needs exponential size on the pigeonhole formulas, but Frege proves the same formulas in polynomial size.
So Haken's theorem rules out resolution as a polynomially bounded system, and nothing more.

### Generalizations

The same proof works for every nonempty language $L$.
A polynomially bounded proof system for $L$ exists if and only if $L \in \mathrm{NP}$.
For a coNP-complete $L$, such as the set of unsatisfiable CNFs, the condition $L \in \mathrm{NP}$ is equivalent to $\mathrm{NP} = \mathrm{coNP}$.

### Watch out

Students often read the theorem as "short proofs exist if and only if $\mathrm{P} = \mathrm{NP}$".
That is wrong in one direction.
$\mathrm{P} = \mathrm{NP}$ implies $\mathrm{NP} = \mathrm{coNP}$, so it would give a polynomially bounded system.
But $\mathrm{NP} = \mathrm{coNP}$ might hold while $\mathrm{P} \ne \mathrm{NP}$, and then short proofs would exist that are hard to find.

## History

Stephen Cook and Robert Reckhow published the theorem in 1979, in "The relative efficiency of propositional proof systems" in the Journal of Symbolic Logic.
The same paper gave the general definition of a propositional proof system and the notion of p-simulation.
Cook's 1975 work on the theory $\mathrm{PV}$ and the propositional translations of its theorems came before it; see [[bounded arithmetic|RA380RWEC0]].

## Explanations

### L1 human

To show that a formula can be true, you give one assignment that makes it true.
To show that a formula is always true, you give a proof.
The theorem says that short proofs for all such formulas exist exactly when a famous open problem has the answer "yes".
For a formula with $50$ letters, one assignment of $50$ values shows that it can be false, but no one knows a short proof that it never is.

### L2 human

Let us see why a polynomially bounded system would put $\mathrm{TAUT}$ in $\mathrm{NP}$.
Suppose that every tautology $\tau$ has a proof of length at most $\lvert \tau \rvert^3$ in a system $f$.
A nondeterministic machine on input $\tau$ guesses a string $w$ of length at most $\lvert \tau \rvert^3$, computes $f(w)$, and accepts if $f(w) = \tau$.
For a formula of length $100$, the guess has at most $10^6$ symbols, and computing $f(w)$ takes time polynomial in $10^6$.
The machine accepts exactly the tautologies, so $\mathrm{TAUT} \in \mathrm{NP}$, and coNP-completeness of $\mathrm{TAUT}$ gives $\mathrm{coNP} \subseteq \mathrm{NP}$.
The [[proof|1Y0JAEAP7M]] writes out both directions.

### L3 human

The theorem identifies polynomially bounded proof systems with NP certificates for a coNP-complete language.
It places proof complexity beside circuit complexity: circuit lower bounds approach $\mathrm{P} \ne \mathrm{NP}$, and proof lower bounds approach $\mathrm{NP} \ne \mathrm{coNP}$.
Through the correspondence with [[bounded arithmetic|RA380RWEC0]], lower bounds for strong systems link with the independence of complexity statements from weak theories of arithmetic.
The current frontier is [[lower bounds for Frege systems|ANSV13M4FS]], where no superpolynomial bound is known.
