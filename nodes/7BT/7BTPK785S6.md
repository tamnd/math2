## Definition

Let $C$ be a [[linear code|E85KREWV60]] over the finite field $\F_q$ with length $n$, dimension $k \ge 1$ and [[minimum distance|M2X88AXM17]] $d$.
The code $C$ is *maximum distance separable* (an *MDS code*) if
$$d = n - k + 1,$$
that is, if it meets the [[Singleton bound|RAKXDDYNAM]] with equality.

## Remarks

Example: the binary even-weight code of length $n$ has $k = n - 1$ and $d = 2 = n - (n - 1) + 1$, so it is MDS.
Non-example: the $[7, 4, 3]$ Hamming code is not MDS, since $n - k + 1 = 4 \ne 3$.
A linear $[n, k]$ code is MDS if and only if every $k$ columns of a [[generator matrix|8TXKFC5PRD]] are linearly independent.
The dual of an MDS code is again MDS.
The codes $\F_q^n$, the repetition codes $[n, 1, n]$ and the even-weight (zero-sum) codes $[n, n - 1, 2]$ are the trivial MDS codes.
Reed–Solomon codes are MDS codes of any length $n \le q$ and any dimension $k \le n$.
The definition extends to a nonlinear code with $M$ codewords over an alphabet with $q$ symbols: it is MDS if $M = q^{n - d + 1}$.
