## Example

Consider the array with first row $(1, 2)$ and second row $(3, 4, 5)$.
We check that it is not a [[matrix|0VD9ZSWWJG]].

1. A matrix of size $m \times n$ has an entry $a_{ij}$ for every pair $(i, j)$ with $1 \le i \le m$ and $1 \le j \le n$, by the [[definition|0N1MY1T0W9]].
2. The array has 2 rows, so $m$ would be $2$.
3. Row 2 has an entry in column 3, so $n$ would be at least $3$.
4. Then the pair $(1, 3)$ would need an entry, but row 1 has only 2 entries.
5. So no size $m \times n$ fits the array, and it is not a matrix.

## Remarks

Programs sometimes store ragged arrays, for example the rows of a lower triangle of different lengths.
If we fill the missing position with $0$, we get the $2 \times 3$ matrix $\begin{pmatrix} 1 & 2 & 0 \\ 3 & 4 & 5 \end{pmatrix}$.
This is a new matrix: the choice of $0$ is extra information.

## Explanations

### L1 human

In a matrix every row has the same length.
Here the first row is shorter, so there is a hole in the table.

### L2 human

The definition of a matrix asks for a value at every position of a rectangle.
A ragged array is a function on a set of positions that is not a rectangle.
