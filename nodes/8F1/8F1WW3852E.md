## Example

Consider the array with first row $(1, 2)$ and second row $(3, 4, 5)$.
We check that it is not a [[matrix|0VD9ZSWWJG]] of any size.

1. By the [[definition|0N1MY1T0W9]], a matrix of size $m \times n$ has an entry $a_{ij}$ for every pair $(i, j)$ with $1 \le i \le m$ and $1 \le j \le n$.
2. The array has 2 rows, so $m$ would have to be $2$.
3. Row 2 has an entry in column 3, so $n$ would have to be at least $3$.
4. Then the position $(1, 3)$ would need an entry, but row 1 has only 2 entries.
5. So no size $m \times n$ fits the array, and it is not a matrix.

## Remarks

The failure is a missing position, not a bad number.
If we fill the hole with $0$, we get the $2 \times 3$ matrix
$$\begin{pmatrix} 1 & 2 & 0 \\ 3 & 4 & 5 \end{pmatrix}.$$
This is a new object, because the choice of $0$ is extra information that the ragged array did not contain.
Filling with $9$ would give a different matrix just as well.

Programs often store ragged arrays, for example the rows of a lower triangle, which have lengths $1, 2, \dots, n$.
To do matrix algebra with such data, we first fill the missing positions with zeros and get a [[triangular matrix|0N4XY7Z3NN]].

## Explanations

### L1 human

In a matrix every row has the same length.
Here the first row is shorter than the second, so the table has a hole in its top right corner.
A table with a hole is not a matrix.

### L2 human

The definition asks for one value at every position of a rectangle of positions.
The positions of the ragged array are $(1, 1)$, $(1, 2)$, $(2, 1)$, $(2, 2)$ and $(2, 3)$, and these five positions do not form a rectangle.
Watch out: a matrix may contain zeros, but an empty place is not a zero.
