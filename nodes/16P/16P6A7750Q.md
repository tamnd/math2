## Example

In the [[Hilbert system|1MGMQX43B8]] L, we show that A3, $(\neg \psi \to \neg \varphi) \to ((\neg \psi \to \varphi) \to \psi)$, is not derivable from A1 and A2 with [[modus ponens|0Y0MQYST0M]].
We use the matrix method of [[independence of axioms|729RCBPAM3]].
The matrix has the values $0$ and $1$, the designated value $1$, the usual [[truth table|05RSK4Q657]] for $\to$, and $\neg$ read as the identity: $\neg 0 = 0$ and $\neg 1 = 1$.
An assignment of values to the variables extends to all formulas by these tables.

1. The schemas A1 and A2 are built from $\varphi$, $\psi$, $\chi$ with $\to$ only, and $\to$ has its usual table. So an instance takes the value of the schema at the values of $\varphi$, $\psi$, $\chi$, and this value is $1$, since the schemas are tautologies.
2. Modus ponens preserves the value $1$: if $a = 1$ and $a \to b = 1$, then $b = 1$ by the truth table of $\to$.
3. By induction on the length of a derivation, every formula derivable from A1 and A2 with modus ponens takes the value $1$ under every assignment.
4. Take the instance of A3 with $\varphi := p$ and $\psi := q$, and the assignment $p = 0$, $q = 0$.
5. Since $\neg$ is the identity, the instance has the value of $(q \to p) \to ((q \to p) \to q)$.
6. With $p = q = 0$, we get $q \to p = 1$, then $(q \to p) \to q = 1 \to 0 = 0$, and finally $1 \to 0 = 0$.
7. So this instance of A3 takes the value $0$, and by step 3 it is not derivable from A1 and A2.

## Remarks

The idea of the matrix is to erase the negation signs.
A formula derivable from A1 and A2 stays a tautology after all signs $\neg$ are erased, and A3 does not.
Any other reading of $\neg$ that makes A3 fail works as well.
For example, with $\neg$ read as the constant $1$, the instance of A3 above has the value of $(1 \to 1) \to ((1 \to p) \to q)$, which is $p \to q$, and it is $0$ at $p = 1$, $q = 0$.

The second matrix gives more information.
With $\neg$ read as the constant $1$, the formula $\neg \neg p \to p$ has the value $1 \to p$, which is $0$ at $p = 0$.
So the theorem T2 of the [[basic theorems of L|Y060MF2NZ7]] also needs A3.
The first matrix cannot show this, because erasing $\neg$ turns $\neg \neg p \to p$ into the tautology $p \to p$.

## Explanations

### L1 human

To show that a rule of a game cannot be replaced by the others, we can find a different way to score the game.
In the new scoring, every move that uses only the other rules keeps a perfect score, but the rule in question loses points.
Here we score formulas with truth tables, but we let "not" do nothing.
The first two axiom patterns still always score $1$, and modus ponens keeps the score $1$.
The third pattern scores $0$ in one case, so it cannot come from the first two.

### L2 human

We check one more instance of A3 in the matrix, with $\varphi := p \to p$ and $\psi := q$.

1. After erasing $\neg$, the instance has the value of $(q \to (p \to p)) \to ((q \to (p \to p)) \to q)$.
2. The formula $p \to p$ has the value $1$, so $q \to (p \to p)$ has the value $1$.
3. At $q = 0$, the value is $1 \to (1 \to 0) = 1 \to 0 = 0$.

The typical use of the method is to prove that an axiom list has no redundant member.
A trap is to forget step 2 of the example: the reading of the connectives must make every rule preserve the designated value, or the argument proves nothing.
