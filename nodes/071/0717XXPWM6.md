## Definition

A linear isometry is a linear map that keeps the norm of every vector.
Let $V$ and $W$ be [[normed spaces|00A0RPAQ8A]] over $\mathbb{K} = \R$ or $\C$.
A *linear isometry* from $V$ to $W$ is a [[linear map|0RJF668P1T]] $T \colon V \to W$ such that
$$\norm{Tv} = \norm{v} \qquad \text{for all } v \in V.$$

## Notation

We often write $Tv$ for $T(v)$.
When $V$ and $W$ are inner product spaces, the norms are the induced norms $\norm{v} = \sqrt{\ip{v}{v}}$.
Mathlib writes `LinearIsometry`, with the notation `E →ₗᵢ[𝕜] F`.
Its version allows semilinear maps and seminormed spaces, so it is a little more general than the definition above.

## Remarks

The definition has two conditions, and each one does its own job.
Linearity ties the map to the vector space structure, so that $T(u - v) = Tu - Tv$.
The norm condition then gives $\norm{Tu - Tv} = \norm{u - v}$, so the map keeps every distance and not only the lengths of vectors from $0$.
It also makes $T$ injective, because $Tv = 0$ gives $\norm{v} = \norm{Tv} = 0$.

For a small example, take $T(x, y) = (y, x)$ on $\R^2$ with the dot product.
Then $\norm{T(x, y)}^2 = y^2 + x^2 = \norm{(x, y)}^2$, so $T$ is a linear isometry, the reflection in the line $y = x$.
The map $S(x, y) = (x + y, 0)$ is linear and sends both $(1, 0)$ and $(0, 1)$ to $(1, 0)$, a vector of length $1$.
It still fails the norm condition, because $S(1, -1) = (0, 0)$ while $\norm{(1, -1)} = \sqrt 2$.
So the norm condition must be checked on all vectors, not only on a basis.
For inner product spaces, the [[equivalent conditions|95ST99SEW7]] say which finite checks do suffice.

Between inner product spaces, a linear isometry also keeps inner products, by [[polarization|0R7VXTYHYZ]].
Between spaces of the same finite dimension it is bijective, by the [[rank-nullity theorem|0W4FSW1TVB]].
The [[concept page|07SJXTWVQW]] gives more examples and non-examples.

## Explanations

### L1 human

A linear isometry is a linear map that keeps all lengths.
Turns of the plane about the origin and mirrors in lines through the origin are examples.
Such a map cannot squeeze a nonzero arrow down to the zero arrow, because the zero arrow has length $0$ and the first arrow does not.

### L2 human

To test the definition, write $\norm{Tv}^2$ for a general vector $v$ and compare it with $\norm{v}^2$.
For $T(x, y) = \tfrac{1}{2}(x + \sqrt 3\, y, \sqrt 3\, x - y)$ we expand:
$$\tfrac{1}{4}\left((x + \sqrt 3\, y)^2 + (\sqrt 3\, x - y)^2\right) = \tfrac{1}{4}\left(4x^2 + 4y^2\right) = x^2 + y^2,$$
because the cross terms $2\sqrt 3\, xy$ and $-2\sqrt 3\, xy$ cancel.
So $T$ is a linear isometry.
Check: $T(1, 0) = \tfrac{1}{2}(1, \sqrt 3)$ has length $\tfrac{1}{2}\sqrt{1 + 3} = 1$.
Watch out: the computation must hold for every $(x, y)$, and a check on one vector only rules a map out, never in.
