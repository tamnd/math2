## Definition

Let $V$ and $W$ be [[normed spaces|00A0RPAQ8A]] over $\mathbb{K} = \R$ or $\C$.
A *linear isometry* from $V$ to $W$ is a [[linear map|0RJF668P1T]] $T \colon V \to W$ such that
$$\norm{Tv} = \norm{v} \qquad \text{for all } v \in V.$$

## Notation

- We often write $Tv$ for $T(v)$.
- When $V$ and $W$ are inner product spaces, the norms are the induced norms $\norm{v} = \sqrt{\ip{v}{v}}$.
- Mathlib writes `LinearIsometry`, with the notation `E →ₗᵢ[𝕜] F`. Its version allows semilinear maps and seminormed spaces, so it is a little more general than this definition.

## Remarks

- A linear isometry is injective, because $Tv = 0$ gives $\norm{v} = \norm{Tv} = 0$.
- A linear isometry keeps distances, because $\norm{Tu - Tv} = \norm{T(u - v)} = \norm{u - v}$.
- Between inner product spaces, a linear isometry keeps inner products, by [[polarization|0R7VXTYHYZ]].
- For finite-dimensional inner product spaces, [[the equivalent conditions|~d0f0e2fd]] give other tests, for example $T^*T = I$.
- A linear isometry between spaces of the same finite dimension is bijective, by [[the rank-nullity theorem|0W4FSW1TVB]].
- Examples and non-examples are in the node on the [[concept|07SJXTWVQW]].

## Explanations

### L1 human

A linear isometry is a linear map that keeps all lengths.
Rotations of the plane about the origin and reflections in lines through the origin are examples.
A map that keeps lengths cannot squeeze a nonzero vector to zero, because the zero vector has length $0$.

### L2 human

To test the definition, compute $\norm{Tv}$ for a general vector $v$.
For $T(x, y) = (y, x)$ on $\R^2$: $\norm{T(x, y)}^2 = y^2 + x^2 = \norm{(x, y)}^2$, so $T$ is a linear isometry.
For $T(x, y) = (x, 0)$: $\norm{T(0, 1)} = 0 \neq 1$, so $T$ is not a linear isometry.
A trap: a map can keep the length of each vector of a basis and still fail.
The map $T(x, y) = (x + y, 0)$ sends $(1, 0)$ and $(0, 1)$ to $(1, 0)$, a vector of length $1$.
But $T(1, -1) = (0, 0)$, so $T$ is not a linear isometry.
