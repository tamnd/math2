## Proof

Part 1: row echelon form, by induction on the number $m$ of rows, for all $n$ at once.

1. Base case $m = 1$: a matrix with one row has no zero row above a nonzero row and no two consecutive nonzero rows. So it is in [[row echelon form|0F27PBRWD7]].
2. Induction step: let $m \ge 2$, and assume part 1 for all matrices with $m - 1$ rows.
3. If $A = 0$, then $A$ has no nonzero rows, so it is in row echelon form.
4. Otherwise let $j$ be the first column of $A$ with a nonzero entry, and let $a_{ij} \ne 0$.
5. If $i \ne 1$, swap $R_1$ and $R_i$. Now the entry in position $(1, j)$ is nonzero; call it $a$.
6. For each $i = 2, \dots, m$, apply $R_i \leftarrow R_i - (a_{ij}/a) R_1$, which uses $a \ne 0$ and the field $F$.
7. This makes the entry $(i, j)$ equal to $a_{ij} - (a_{ij}/a) a = 0$ for every $i \ge 2$.
8. Columns $1, \dots, j - 1$ were zero. Each row operation forms new entries of a column from entries of the same column, so these columns stay zero.
9. Let $A'$ be the matrix of rows $2, \dots, m$. By the induction hypothesis, a sequence of row operations takes $A'$ to a row echelon form $B'$.
10. Apply the same operations to rows $2, \dots, m$ of the whole matrix. They do not involve row $1$.
11. Columns $1, \dots, j$ of rows $2, \dots, m$ are zero before these operations, so they stay zero, as in step 8.
12. So every nonzero row of $B'$ has its leading entry in a column greater than $j$.
13. Let $B$ have row $1$ from step 5 and rows $2, \dots, m$ from $B'$. Row $1$ is nonzero with leading entry in column $j$.
14. Zero rows: row $1$ is nonzero, and in $B'$ the zero rows are below the nonzero rows. So all zero rows of $B$ are at the bottom.
15. Staircase: if row $2$ of $B$ is nonzero, its leading entry is right of column $j$ by step 12. Other consecutive pairs lie in $B'$.
16. So $B$ is in row echelon form, and $A$ is [[row equivalent|095DDGZF16]] to $B$.

Part 2: from row echelon form to reduced row echelon form.

17. Let $B$ be in row echelon form with nonzero rows $1, \dots, r$ and leading entries in columns $p_1 < p_2 < \dots < p_r$.
18. For each $i \le r$, apply $R_i \leftarrow (1/b_{i p_i}) R_i$. Scaling keeps the zero pattern, so the matrix stays in row echelon form with leading entries $1$.
19. Now take $i = r, r - 1, \dots, 1$ in turn. For each $k < i$, apply $R_k \leftarrow R_k - b_{k p_i} R_i$, with the current entry $b_{k p_i}$.
20. This makes the entry $(k, p_i)$ zero, since the entry $(i, p_i)$ is $1$.
21. Row $i$ is zero in all columns before $p_i$, and $p_k < p_i$. So row $k$ keeps its zeros before $p_k$ and its leading $1$ in column $p_k$.
22. Row $i$ is zero in each column $p_l$ with $l > i$, because those columns were cleared above row $l$ earlier. So no earlier zero is destroyed.
23. Entries below $(i, p_i)$ are zero by the row echelon form, and step 19 does not change rows below row $i$.
24. After the loop, each pivot column $p_i$ is the unit vector $e_i$, and the matrix is in row echelon form with leading entries $1$.
25. So it is in [[reduced row echelon form|0NNR68BFRY]].
26. By transitivity of row equivalence, see [[the theorem on row equivalence|E4GKK727ZM]], $A$ is row equivalent to this matrix.

## Idea

Find the first nonzero column, bring a nonzero entry to the top, and clear the column below it.
The rest of the matrix has one row fewer, so induction finishes the staircase.
Then scale each pivot to $1$ and clear the entries above the pivots, working from the bottom pivot up, which keeps the staircase.

## Variants

Induction on the number of columns also works: reduce the first $n - 1$ columns, then treat the last column.
One can also clear above and below each pivot in a single pass, which is the usual form of [[Gauss-Jordan elimination|098D6FQN3N]].
