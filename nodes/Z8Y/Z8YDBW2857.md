## Definition

Peano arithmetic is Robinson arithmetic together with one induction axiom for each formula of the language.
Let $L_A$ be the [[language of arithmetic|329ZG1Z0G5]].
For a formula $\varphi(x, y_1, \ldots, y_k)$ of $L_A$, whose free variables are among $x, y_1, \ldots, y_k$, the induction axiom $\mathrm{Ind}_\varphi$ is the sentence
$$\forall y_1 \cdots \forall y_k\, \Bigl( \bigl( \varphi(0, \vec{y}) \land \forall x\, (\varphi(x, \vec{y}) \to \varphi(S x, \vec{y})) \bigr) \to \forall x\, \varphi(x, \vec{y}) \Bigr).$$
*Peano arithmetic* $\mathsf{PA}$ is the first-order [[theory|FZRMYTQFRR]] in $L_A$ whose axioms are:

1. the eight axioms $\mathsf{Q}1$ to $\mathsf{Q}8$ of [[Robinson arithmetic|TT8MXRTVBM]];
2. the axiom $\mathrm{Ind}_\varphi$ for every formula $\varphi$ of $L_A$.

## Notation

The variables $y_1, \ldots, y_k$ are the parameters of the induction axiom, and $x$ is the induction variable.
The set of axioms in item 2 is the [[induction schema|G55NMADJ6G]].
For a class $\Gamma$ of formulas, $\mathsf{I}\Gamma$ is the theory whose item 2 is restricted to $\varphi \in \Gamma$.

## Remarks

Item 1 gives the rules of computation: what $S$, $+$ and $\cdot$ do, and what $<$ means.
Item 2 adds the power to prove general laws, and it is the only part with infinitely many axioms.
The parameters $\vec{y}$ are there because many inductions need fixed outside values.
For example, to prove $x + y = y + x$ by induction on $x$, we keep $y$ fixed as a parameter.

One axiom of item 1 is redundant.
$\mathsf{PA}$ proves $\mathsf{Q}3$ by induction on $\varphi(x) := x = 0 \lor \exists y\,(x = S y)$, because the step holds with witness $y = x$.
So many books list only $\mathsf{Q}1$, $\mathsf{Q}2$ and $\mathsf{Q}4$ to $\mathsf{Q}7$ with the schema, and define $<$ separately.

For the full schema the parameters can also be removed.
Apply parameter-free induction on $x$ to the formula
$$\forall \vec{y}\,\bigl((\varphi(0, \vec{y}) \land \forall u\,(\varphi(u, \vec{y}) \to \varphi(S u, \vec{y}))) \to \varphi(x, \vec{y})\bigr),$$
and the result is $\mathrm{Ind}_\varphi$.
For a restricted class $\Gamma$ this trick adds quantifiers, so parameter-free $\Gamma$-induction can be weaker.

The set of axioms is infinite but decidable, because an algorithm can check whether a string is an instance of the schema.
A structure that satisfies $\mathsf{Q}$ but fails one instance of the schema, such as [[this model of Q|PR8Z1YPJDK]], is not a model of $\mathsf{PA}$.
The [[concept page|HACXBCM7SS]] describes what $\mathsf{PA}$ proves and what its models look like.

## Explanations

### L1 human

Peano arithmetic is Robinson arithmetic plus one induction rule for each property that a formula can express.
The rule for a property says: if $0$ has it, and each number that has it passes it to the next number, then all numbers have it.
The extra letters $y_1, \ldots, y_k$ let the property depend on other fixed numbers.

### L2 human

We write out the induction axiom for $\varphi(x, y) := x + y = y + x$.
The parameter is $y$ and the induction variable is $x$.
The base $\varphi(0, y)$ is $0 + y = y + 0$, and the shifted formula $\varphi(S x, y)$ is $S x + y = y + S x$.
So the axiom reads
$$\forall y\,\bigl((0 + y = y + 0 \land \forall x\,(x + y = y + x \to S x + y = y + S x)) \to \forall x\,(x + y = y + x)\bigr).$$
The typical use of the definition is to write the exact instance before using it, as in [[the commutativity proof|DE8YZ5SDH3]].
The trap is to substitute $S x$ for an occurrence of $x$ that is bound inside $\varphi$, since substitution acts only on free occurrences.
