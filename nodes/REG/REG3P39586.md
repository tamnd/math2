## Proof

We expand $h(x + cy, x + cy)$ to get polarization, use polarization to compare $h$ with the form $\overline{h(y, x)}$, and then read the Hermitian condition on basis vectors.
Throughout, $h$ is linear in the first slot and conjugate-linear in the second, as in the [[definition of a sesquilinear form|0W44K2VNBD]].

Part 1.

1. Let $c \in \mathbb{C}$. Linearity in the first slot and conjugate-linearity in the second give
$$h(x + cy, x + cy) = h(x, x) + \bar c\, h(x, y) + c\, h(y, x) + c \bar c\, h(y, y).$$
2. Take $c = i^k$ for $k = 0, 1, 2, 3$. Then $c \bar c = 1$, and multiplying the expansion by $c$ gives
$$i^k\, h(x + i^k y, x + i^k y) = i^k\, h(x, x) + h(x, y) + i^{2k}\, h(y, x) + i^k\, h(y, y).$$
3. Add the four equations. The sums of the coefficients are
$$\sum_{k = 0}^{3} i^k = 1 + i - 1 - i = 0, \qquad \sum_{k = 0}^{3} i^{2k} = 1 - 1 + 1 - 1 = 0.$$
4. So the terms with $h(x, x)$, $h(y, x)$ and $h(y, y)$ cancel, and the term $h(x, y)$ appears four times. This is part 1.

Part 2.

5. Let $h$ be Hermitian. With $u = v$ the [[definition|8NJ7XY6F1S]] gives $h(v, v) = \overline{h(v, v)}$, and a number equal to its [[complex conjugate|0FTH2E9TAS]] is real.
6. Conversely, let $h(v, v) \in \mathbb{R}$ for all $v$. Define $g(x, y) = \overline{h(y, x)}$.
7. The map $g$ is sesquilinear. Since $h(y, x)$ is conjugate-linear in $x$, its conjugate is linear in $x$, and since $h(y, x)$ is linear in $y$, its conjugate is conjugate-linear in $y$.
8. On the diagonal, $g(v, v) = \overline{h(v, v)} = h(v, v)$, because $h(v, v)$ is real.
9. So $d = h - g$ is sesquilinear, being a difference of sesquilinear forms, and $d(v, v) = 0$ for all $v$.
10. Part 1 applied to $d$ gives $4\, d(x, y) = \sum_k i^k\, d(x + i^k y, x + i^k y) = 0$, so $d = 0$.
11. Hence $h(x, y) = g(x, y) = \overline{h(y, x)}$ for all $x, y$, and $h$ is Hermitian.

Part 3.

12. Let $h$ be Hermitian. Then $M_{ji} = h(e_j, e_i) = \overline{h(e_i, e_j)} = \overline{M_{ij}}$ for all $i, j$, so $M^* = M$.
13. Conversely, let $M^* = M$, that is, $M_{ji} = \overline{M_{ij}}$. Sesquilinearity gives $h(x, y) = \sum_{i, j} x_i M_{ij} \bar y_j$ for coordinate vectors $x$ and $y$.
14. Conjugate this sum and use $\overline{M_{ij}} = M_{ji}$:
$$\overline{h(x, y)} = \sum_{i, j} \bar x_i\, \overline{M_{ij}}\, y_j = \sum_{i, j} y_j M_{ji} \bar x_i = h(y, x).$$
15. So $h$ is Hermitian.

Part 4.

16. The Hermitian condition does not mention a basis. So, by part 3 applied in each basis, every matrix of a Hermitian form is a Hermitian matrix.
17. For a [[Hermitian matrix|0EKZCX4K3P]], $\bar M = M^{\mathsf{T}}$, and the determinant of a transpose equals the determinant. So $\overline{\det M} = \det \bar M = \det M^{\mathsf{T}} = \det M$, and $\det M$ is real.

This proves all four parts.

## Idea

Polarization writes $h(x, y)$ as a combination of four diagonal values $h(v, v)$, with the weights $1, i, -1, -i$.
If these values are real, then $h$ and the "swapped and conjugated" form $\overline{h(y, x)}$ agree on the diagonal.
Two sesquilinear forms that agree on the diagonal agree everywhere, by polarization again, and that is the Hermitian condition.
The matrix test is the same condition, read on pairs of basis vectors.

## Variants

Part 2 also follows from two direct expansions, without the full polarization identity.
Write $a = h(x, y)$ and $b = h(y, x)$, and assume all diagonal values are real.
The expansion of $h(x + y, x + y)$ shows that $a + b$ is real, so $\operatorname{Im} a = -\operatorname{Im} b$.
The expansion of $h(x + iy, x + iy)$ contains $-ia + ib = i(b - a)$, and this must be real, so $\operatorname{Re} a = \operatorname{Re} b$.
Together these say $b = \bar a$, which is the Hermitian condition.
