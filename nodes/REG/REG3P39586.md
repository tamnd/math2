## Proof

Part 1.

1. For $c \in \C$ with $\abs{c} = 1$, sesquilinearity gives $h(x + cy, x + cy) = h(x, x) + \bar c\,h(x, y) + c\,h(y, x) + c \bar c\,h(y, y)$.
2. With $c = i^k$, we have $c \bar c = 1$ and $\bar c = i^{-k}$.
3. Multiply by $i^k$ and sum over $k = 0, 1, 2, 3$. The terms give $\sum_k i^k\,h(x, x) + \sum_k h(x, y) + \sum_k i^{2k}\,h(y, x) + \sum_k i^k\,h(y, y)$.
4. $\sum_{k = 0}^{3} i^k = 1 + i - 1 - i = 0$ and $\sum_{k = 0}^{3} i^{2k} = 1 - 1 + 1 - 1 = 0$.
5. So the sum is $4\,h(x, y)$, which is part 1.

Part 2.

6. Let $h$ be Hermitian. With $u = v$ the [[definition|8NJ7XY6F1S]] gives $h(v, v) = \overline{h(v, v)}$, so $h(v, v)$ is real, by the properties of the [[complex conjugate|0FTH2E9TAS]].
7. Conversely, let $h(v, v) \in \R$ for all $v$. Define $g(x, y) = \overline{h(y, x)}$.
8. $g$ is sesquilinear: $h(y, x)$ is conjugate-linear in $x$, so its conjugate is linear in $x$; and $h(y, x)$ is linear in $y$, so its conjugate is conjugate-linear in $y$.
9. $g(v, v) = \overline{h(v, v)} = h(v, v)$, since $h(v, v)$ is real.
10. So $d = h - g$ is sesquilinear, and $d(v, v) = 0$ for all $v$.
11. Part 1 for $d$ gives $4\,d(x, y) = \sum_k i^k\,d(x + i^k y, x + i^k y) = 0$. So $d = 0$.
12. Hence $h(x, y) = g(x, y) = \overline{h(y, x)}$ for all $x, y$, and $h$ is Hermitian.

Part 3.

13. Let $h$ be Hermitian. Then $M_{ji} = h(e_j, e_i) = \overline{h(e_i, e_j)} = \overline{M_{ij}}$, so $M^* = M$.
14. Conversely, let $M^* = M$, that is, $M_{ji} = \overline{M_{ij}}$. By sesquilinearity, $h(x, y) = \sum_{i, j} x_i M_{ij} \bar y_j$.
15. Then $\overline{h(x, y)} = \sum_{i, j} \bar x_i\,\overline{M_{ij}}\,y_j = \sum_{i, j} y_j M_{ji} \bar x_i = h(y, x)$.
16. So $h$ is Hermitian.

Part 4.

17. Being Hermitian does not depend on a basis. So, by part 3 in each basis, every matrix of a Hermitian form is a Hermitian matrix.
18. For a Hermitian matrix, $\overline{\det M} = \det \bar M = \det M^T = \det M$, since $\bar M = M^T$ and the determinant of the transpose is the same. So $\det M$ is real.

This proves all four parts.

## Idea

Polarization writes $h(x, y)$ as a combination of four diagonal values $h(v, v)$.
If these values are real, then $h$ and the form $\overline{h(y, x)}$ agree on the diagonal, so they agree everywhere.
The matrix test is the Hermitian condition on pairs of basis vectors.

## Variants

Part 2 also follows from a direct computation with $v = x + y$ and $v = x + iy$.
The imaginary part of $h(x + y, x + y)$ is $\operatorname{Im}\bigl(h(x, y) + h(y, x)\bigr) = 0$, and the imaginary part of $h(x + iy, x + iy)$ gives $\operatorname{Re}\bigl(h(y, x) - h(x, y)\bigr) = 0$.
Together these say that $h(y, x) = \overline{h(x, y)}$.
