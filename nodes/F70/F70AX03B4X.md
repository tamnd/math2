## Example

We prove the [[sum of the first n odd numbers|9PESCNHE7Q]]: for every natural number $n$,
$$1 + 3 + 5 + \cdots + (2n - 1) = n^2.$$
The proof is by [[mathematical induction|0ASJVEFA9J]], and it starts at $n = 0$, since the site counts $0$ as a natural number.
The base case is [[trivial|Y0HXCJRB9B]] in the exact sense: an easy case that the proof must still check.

1. Base case $n = 0$.
   The left side is the sum of no terms, which is $0$ by the convention for an empty sum.
   The right side is $0^2 = 0$, so the statement holds for $n = 0$.
2. Inductive step.
   Assume that $1 + 3 + \cdots + (2n - 1) = n^2$ for some $n \in \mathbb{N}$.
3. The sum of the first $n + 1$ odd numbers adds the next odd number, $2n + 1$, so it equals $n^2 + (2n + 1)$.
4. Complete the square:
   $$n^2 + 2n + 1 = (n + 1)^2.$$
   So the statement holds for $n + 1$.
5. By induction, the statement holds for every $n \in \mathbb{N}$.

Check: for $n = 4$, $1 + 3 + 5 + 7 = 16 = 4^2$.
The base case took one line, and the inductive step did the work.

## Remarks

A "trivial case" is not a case to leave out.
Without step 1, steps 2 to 4 prove only that the statement passes from $n$ to $n + 1$.
The false statement $1 + 3 + \cdots + (2n - 1) = n^2 + 1$ passes from $n$ to $n + 1$ as well:
$$n^2 + 1 + (2n + 1) = (n + 1)^2 + 1.$$
It fails only at the base case, because $0 \neq 0^2 + 1$.
So the one-line check is what separates the true statement from the false one.
If the induction starts at $n = 1$ instead, the base case is $1 = 1^2$, which is also trivial and also needed.

## Explanations

### L1 human

Add the first few odd numbers: $1 = 1$, $1 + 3 = 4$, $1 + 3 + 5 = 9$, $1 + 3 + 5 + 7 = 16$.
The answers are the square numbers $1, 4, 9, 16$.
To prove this for every count, we check the first case and then show that each case leads to the next one.
The first case is so easy that mathematicians call it trivial, but the proof still has to say it.

### L2 human

Here is why the trivial case cannot be skipped.
Let $P(n)$ be the false statement "$1 + 3 + \cdots + (2n - 1) = n^2 + 1$".
If $P(n)$ holds, add $2n + 1$ to both sides:
$$1 + 3 + \cdots + (2n + 1) = n^2 + 1 + 2n + 1 = (n + 1)^2 + 1,$$
which is $P(n + 1)$.
So the inductive step works for $P$.
But $P(0)$ says $0 = 1$, which is false, so the induction never starts.
Watch out: a base case can fail even when it looks trivial, so a proof must compute it and not only call it trivial.
