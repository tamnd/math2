## Definition

Consider the while language, whose commands are $C ::= \mathsf{skip} \mid x := E \mid C; C \mid \mathsf{if}\ B\ \mathsf{then}\ C\ \mathsf{else}\ C \mid \mathsf{while}\ B\ \mathsf{do}\ C$, where $E$ ranges over integer expressions and $B$ over boolean expressions in the program variables.
Assertions $P, Q, R$ are formulas of first-order [[predicate logic|086QKPF0A6]] over the integers whose free variables may include the program variables.
A *Hoare triple* is an expression $\set{P}\, C\, \set{Q}$.
Runs of commands are given by the [[operational semantics|N8SGDCGJTW]] of the language.
The triple is *valid* if, for every state $s$ satisfying $P$, every terminating run of $C$ from $s$ ends in a state satisfying $Q$.
*Hoare logic* is the proof system whose derivable triples are generated by these rules.

1. Skip: $\set{P}\, \mathsf{skip}\, \set{P}$.
2. Assignment: $\set{Q[E/x]}\, x := E\, \set{Q}$, where $Q[E/x]$ is the [[substitution|NCDZ969V7X]] of $E$ for $x$ in $Q$.
3. Composition: from $\set{P}\, C_1\, \set{R}$ and $\set{R}\, C_2\, \set{Q}$ derive $\set{P}\, C_1; C_2\, \set{Q}$.
4. Conditional: from $\set{P \land B}\, C_1\, \set{Q}$ and $\set{P \land \lnot B}\, C_2\, \set{Q}$ derive $\set{P}\, \mathsf{if}\ B\ \mathsf{then}\ C_1\ \mathsf{else}\ C_2\, \set{Q}$.
5. While: from $\set{I \land B}\, C\, \set{I}$ derive $\set{I}\, \mathsf{while}\ B\ \mathsf{do}\ C\, \set{I \land \lnot B}$.
6. Consequence: from $P \Rightarrow P'$, $\set{P'}\, C\, \set{Q'}$ and $Q' \Rightarrow Q$, where the implications are true in the integers, derive $\set{P}\, C\, \set{Q}$.

## Remarks

Example: $\set{x = 1}\ x := x + 1\ \set{x = 2}$ is derivable.
Rule 2 gives $\set{x + 1 = 2}\ x := x + 1\ \set{x = 2}$, and rule 6 applies since $x = 1$ implies $x + 1 = 2$.

Non-example: $\set{\mathsf{true}}\ x := x + 1\ \set{x = 2}$ is not valid, since from the state $x = 5$ the command ends with $x = 6$.
It is not derivable either, because Hoare logic is [[sound|4A84VHDTHV]]: every derivable triple is valid.

The triples above express partial correctness: $\set{\mathsf{true}}\ \mathsf{while}\ \mathsf{true}\ \mathsf{do}\ \mathsf{skip}\ \set{\mathsf{false}}$ is valid, because the loop never terminates.
Total correctness, written $[P]\, C\, [Q]$, also requires termination, and its while rule needs a variant that decreases in a well-founded order.
Stephen Cook proved that the system is relatively complete: every valid triple is derivable if all true assertions of the integers may be used in rule 6.
