## Summary

An involutory matrix is a [[square matrix|0JXZKX526R]] $A$ with $A^2 = I$, so that $A$ is its own inverse; the [[formal definition|1GVCRBXQT8]] states it.
Reflections, such as the exchange of two coordinates, are the main examples.
Outside characteristic $2$, $A$ is involutory exactly when $P = \tfrac12 (I + A)$ is [[idempotent|0KCE8CG86P]], so involutions and projections correspond.

## Motivation

A map that undoes itself when applied twice is an involution.
Reflections in a line or a plane, the exchange of two coordinates and the change of sign are examples.
In coding and in cryptography, an involutory matrix is useful because the same matrix encodes and decodes.

## Notation

- An involutory matrix is also called an *involution*.
- In Mathlib the condition is written `A * A = 1`.

## Remarks

### Examples

- [[The matrix that exchanges two coordinates|28TDNCN9Z8]].
- [[The reflection diag(1, −1) and its projection (I + A)/2|8XT0ZBM0BN]].
- [[A family of involutory matrices with a free parameter|D20HHJ9CD6]].
- $I$ and $-I$ are involutory.

### Non-examples

- [[The rotation by a quarter turn|HH1JX5YNJ1]] has $R^2 = -I$, so it is not involutory.
- A [[nilpotent matrix|07BSPZPSMF]] is never involutory, because it is not invertible.

### Basic properties

Let $A$ be an involutory $n \times n$ matrix over a field $F$.

- $A$ is [[invertible|0EB9N0S33C]] with $A^{-1} = A$.
- $A^{\mathsf{T}}$, $-A$ and $P^{-1} A P$ are involutory for each invertible $P$.
- Every eigenvalue $\lambda$ satisfies $\lambda^2 = 1$, so $\lambda = \pm 1$. If $Av = \lambda v$ with $v \neq 0$, then $v = A^2 v = \lambda^2 v$.
- If $\operatorname{char} F \neq 2$, then $P = \tfrac12 (I + A)$ satisfies $P^2 = \tfrac14 (I + 2A + A^2) = \tfrac14 (2I + 2A) = P$.
- Conversely, if $\operatorname{char} F \neq 2$ and $P$ is idempotent, then $A = 2P - I$ satisfies $A^2 = 4P^2 - 4P + I = I$.
- So, outside characteristic $2$, $F^n$ is the direct sum of the $+1$ space $\operatorname{im} P$ and the $-1$ space $\ker P$.
- If $\operatorname{char} F = 2$, then $A$ is involutory if and only if $A = I + N$ with $N^2 = 0$. Indeed $(I + N)^2 = I + 2N + N^2 = I + N^2$ there.
- Two involutory matrices $A$ and $B$ have an involutory product $AB$ if and only if $AB = BA$.

### Common errors

- Confusing involutory ($A^2 = I$) with idempotent ($A^2 = A$).
- Using $\tfrac12 (I + A)$ in characteristic $2$, where $2$ has no inverse.

## Explanations

### L1 human

An involutory matrix undoes itself.
Doing it twice brings every vector back to where it started.
A mirror reflection is the picture to keep in mind.

### L2 human

Outside characteristic $2$, every vector $v$ splits as $\tfrac12 (v + Av) + \tfrac12 (v - Av)$.
The first part is fixed by $A$ and the second part changes sign.
So $A$ is a reflection through the $+1$ space along the $-1$ space.

### L3 human

The involutory matrices in $\mathrm{GL}_n(F)$ are the elements of order dividing $2$.
Over a field of characteristic $0$, two involutory matrices of the same size are similar if and only if they have the same trace.
The reason is that the trace is the number of $+1$ eigenvalues minus the number of $-1$ eigenvalues.
In characteristic $p > 2$ the trace is known only modulo $p$, so this test can fail.
