## Example

Let $L = \set{E}$ be the [[signature|WDVVEYD6AT]] with one binary relation symbol $E$ and no other symbols.
Let $M = \set{1, 2, 3}$ and let $E^{\mathcal{M}} = \set{(1, 2), (2, 3), (3, 1)}$.
We check that $\mathcal{M} = (M, E^{\mathcal{M}})$ is an $L$-[[structure|983GZBQYT4]].

1. The domain is nonempty, because $1 \in M$.
2. The signature has no constant symbols, so there is nothing to check for constants.
3. The signature has no function symbols, so there is nothing to check for functions.
4. The symbol $E$ is binary, so its interpretation must be a subset of $M^2$. Each of the pairs $(1, 2)$, $(2, 3)$ and $(3, 1)$ has both entries in $M$, so $E^{\mathcal{M}} \subseteq M^2$.

So $\mathcal{M}$ is an $L$-structure.
As a [[directed graph|0KFYGSHHF5]], it is the directed cycle $1 \to 2 \to 3 \to 1$.

## Remarks

The example shows that a directed graph with vertex set $V$ is the same thing as an $\set{E}$-structure with domain $V$: the vertices form the domain and the edges form the [[binary relation|05AVARPXA2]] $E^{\mathcal{M}}$.
On the domain $\set{1, 2, 3}$ there are $2^{3^2} = 2^9 = 512$ different $\set{E}$-structures, one for each subset of $M^2$.

The example changes as follows when one part changes.

- Every subset of $M^2$ is allowed, including the empty set (no edges) and all of $M^2$ (all edges and all loops).
- A simple undirected graph is the special case in which $E^{\mathcal{M}}$ is symmetric and irreflexive. These two conditions are sentences that the structure may or may not satisfy; they are not part of the definition of a structure.
- If we add the pair $(3, 4)$ to $E^{\mathcal{M}}$ but keep $M = \set{1, 2, 3}$, we no longer get a structure, because $4 \notin M$.

## Explanations

### L1 human

A directed graph is a set of dots with arrows between some of them.
To see it as a structure, take the dots as the domain and read the symbol $E(x, y)$ as "there is an arrow from $x$ to $y$".
Here the dots are $1$, $2$ and $3$, and the arrows go from $1$ to $2$, from $2$ to $3$ and from $3$ back to $1$.
Any choice of arrows between the three dots gives a structure, and there are $512$ such choices.

### L2 human

We use the structure to read a formula.
The formula $\forall x \, \exists y \, E(x, y)$ says "each vertex has an outgoing edge".

1. The vertex $1$ has the edge $(1, 2)$.
2. The vertex $2$ has the edge $(2, 3)$.
3. The vertex $3$ has the edge $(3, 1)$.

So the sentence is true in $\mathcal{M}$, by the clauses of [[satisfaction|2RBQPV02AS]].
If we remove the edge $(3, 1)$, the vertex $3$ has no outgoing edge, and the sentence becomes false.
The typical use is to express graph properties as first-order sentences in the signature $\set{E}$.
A trap is to read $E(x, y)$ as symmetric: in this graph $E(1, 2)$ holds, while $E(2, 1)$ does not.
