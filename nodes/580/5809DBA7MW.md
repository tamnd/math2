## Proof

We build Büchi automata for the connectives and quantifiers, and the hard step, complement, uses Ramsey's theorem to cut each infinite word into blocks of one type.
We use the notation of the [[statement|YPDXVTH5JR]].
For a word $\alpha$ and $i < j$ we write $\alpha[i, j)$ for the finite word $a_i a_{i+1} \cdots a_{j-1}$.
Parts A to C are about automata, Part D connects them with logic, and Parts E and F prove parts 4 and 5 of the theorem.

### Part A: union and letter maps

1. The disjoint union of two Büchi automata, with the union of the initial states, recognizes $L(A_1) \cup L(A_2)$, because each run stays inside one of the two automata.
2. Let $h \colon \Gamma \to \Delta$ be a map of alphabets, applied letter by letter to infinite words.
   For a Büchi automaton $A$ over $\Delta$, the automaton with the transitions $(p, b, q)$ for $(p, h(b), q)$ in $A$ recognizes $h^{-1}(L(A))$.
   The reason is that a run of the new automaton on $\beta$ is the same sequence of states as a run of $A$ on $h(\beta)$.
3. For a Büchi automaton $A$ over $\Gamma$, the automaton with the transitions $(p, h(b), q)$ for $(p, b, q)$ in $A$ recognizes $h(L(A))$.
   An accepting run on $\gamma$ chooses letters $b_i$ with $h(b_i) = \gamma_i$, so it is an accepting run of $A$ on $\beta = b_0 b_1 \cdots$ with $h(\beta) = \gamma$, and conversely.

### Part B: profiles of finite words

Let $A = (Q, \Sigma, \Delta, I, F)$.
For $u \in \Sigma^+$ and $p, q \in Q$, write $p \xrightarrow{u} q$ when some path of $A$ labeled $u$ leads from $p$ to $q$.
Write $p \overset{u}{\Longrightarrow} q$ when some such path visits a state of $F$, endpoints included.
The profile of $u$ is $\tau(u) = (R_u, R^F_u)$ with $R_u = \{ (p, q) : p \xrightarrow{u} q \}$ and $R^F_u = \{ (p, q) : p \overset{u}{\Longrightarrow} q \}$.
Let $T$ be the finite set of all pairs of relations on $Q$, and for $\tau \in T$ let $U_\tau = \{ u \in \Sigma^+ : \tau(u) = \tau \}$.

4. A path labeled $va$ splits at the state $s$ reached after $v$, and it visits $F$ exactly when its part on $v$ or its part on $a$ does, since $s$ belongs to both parts.
   So $R_{va} = R_v ; R_a$ and $R^F_{va} = (R^F_v ; R_a) \cup (R_v ; R^F_a)$, where $R ; R'$ is the composition "first $R$, then $R'$".
5. Hence a [[deterministic automaton|W65B6BKZRY]] with the states $T$ and one extra start state reaches $\tau(v)$ after it reads $v$.
   With accepting state $\tau$, it recognizes $U_\tau$, so each $U_\tau$ is regular.

### Part B: saturation

6. Let $\tau, \tau' \in T$, $U = U_\tau$ and $V = U_{\tau'}$.
   We claim that $U V^\omega$ is either contained in $L(A)$ or disjoint from it.
7. Let $\alpha = u v_1 v_2 \cdots$ and $\beta = u' v'_1 v'_2 \cdots$ with $u, u' \in U$ and all $v_i, v'_i \in V$, and let $\alpha \in L(A)$.
   Take an accepting run on $\alpha$, and let $s_0 \in I$, $s_1, s_2, \ldots$ be its states at the borders of the blocks $u, v_1, v_2, \ldots$.
8. Then $(s_0, s_1) \in R_u$ and $(s_i, s_{i+1}) \in R_{v_i}$ for $i \ge 1$.
   A state of $F$ occurs infinitely often and each block is finite, so $(s_i, s_{i+1}) \in R^F_{v_i}$ for infinitely many $i$.
9. The words $u, u'$ have the same profile, and so do all $v_i, v'_i$, so the same memberships hold for $u'$ and the $v'_i$.
   Choose paths of $A$ on $u'$ and on each $v'_i$ between these border states, visiting $F$ in the blocks found in step 8.
   Their concatenation is an accepting run on $\beta$, so $\beta \in L(A)$.

### Part B: Ramsey's theorem for pairs

10. Let each pair $i < j$ of numbers $\ge 1$ get one of finitely many colors.
    We show that some infinite set $H$ has all its pairs of the same color.
    This is the infinite form of [[Ramsey's theorem|00TQV3F5S4]], and we prove it in steps 11 and 12.
11. Put $H_0 = \{1, 2, 3, \ldots\}$, and given an infinite set $H_t$, let $h_t = \min H_t$.
    The numbers $j > h_t$ in $H_t$ fall into finitely many classes by the color of $(h_t, j)$, so one class is infinite.
    Call this class $H_{t+1}$ and call its color $d_t$.
12. For $t < t'$ we have $h_{t'} \in H_{t+1}$, so the pair $(h_t, h_{t'})$ has color $d_t$.
    Some color $d$ equals $d_t$ for infinitely many $t$, and $H = \{ h_t : d_t = d \}$ has all its pairs of color $d$.

### Part B: every word lies in a block language

13. Let $\alpha \in \Sigma^\omega$, and color the pair $i < j$ by $\tau(\alpha[i, j))$.
    Steps 11 and 12 give $h_0 < h_1 < \cdots$, all at least $1$, with $\tau(\alpha[h_t, h_{t'})) = \tau'$ for all $t < t'$.
14. Let $\tau = \tau(\alpha[0, h_0))$, where the prefix is nonempty since $h_0 \ge 1$.
    Then $\alpha = \alpha[0, h_0) \, \alpha[h_0, h_1) \, \alpha[h_1, h_2) \cdots$ lies in $U_\tau U_{\tau'}^\omega$.
15. So $\Sigma^\omega \setminus L(A)$ is the union of the sets $U_\tau U_{\tau'}^\omega$ that are disjoint from $L(A)$.
    These sets lie in the complement.
    Conversely, a word outside $L(A)$ lies in some $U_\tau U_{\tau'}^\omega$ by steps 13 and 14, and this set meets the complement, so it is disjoint from $L(A)$ by step 6.

### Part B: automata for block languages

16. Let $U, V \subseteq \Sigma^+$ be regular, and take a [[nondeterministic automaton|SFMYM96C1B]] for $V$ whose start state $p_0$ has no incoming transitions.
    Add a transition $(p, a, p_0)$ for each transition $(p, a, f)$ with $f$ accepting, and make $p_0$ the only accepting state.
17. Between two visits to $p_0$, a run reads a nonempty word of $V$, because it starts at $p_0$ and its last transition replaces a transition into an accepting state.
    Conversely, a factorization into words of $V$ gives a run through $p_0$ infinitely often, so this automaton recognizes $V^\omega$.
18. Put an automaton for $U$ in front, with a new transition $(p', a, p_0)$ for each transition $(p', a, f')$ into an accepting state of the $U$-automaton.
    A run must leave the $U$-part, once, to visit $p_0$ infinitely often, so the result recognizes $U V^\omega$.

### Part B: computing the complement

19. If $U_\tau$ or $U_{\tau'}$ is empty, so is $U_\tau U_{\tau'}^\omega$, and emptiness of the automata of step 5 is decidable.
    Otherwise pick $u \in U_\tau$ and $v \in U_{\tau'}$.
    By step 6, $U_\tau U_{\tau'}^\omega$ is disjoint from $L(A)$ exactly when $u v^\omega \notin L(A)$.
20. To test $u v^\omega \in L(A)$, run $A$ in parallel with a counter of the positions in the lasso $u v^\omega$.
    This is a Büchi automaton with states $Q \times \{0, \ldots, |u| + |v| - 1\}$, accepting when the $Q$-part is in $F$, and the emptiness test of Part C decides it.
21. By steps 1, 15 to 18 and 20, a Büchi automaton for $\Sigma^\omega \setminus L(A)$ is computed from $A$.
    This proves part 2 of the theorem.

### Part C: emptiness

22. Suppose $A$ has an accepting run.
    Since $F$ is finite, some $f \in F$ occurs infinitely often.
    Its first occurrence gives a path from an initial state to $f$, and two later occurrences give a nonempty path from $f$ to $f$.
23. Conversely, let a path labeled $u$ lead from an initial state to $f \in F$, and let a nonempty path labeled $v$ lead from $f$ to $f$.
    Following the first path and then the cycle forever is an accepting run on $u v^\omega$.
24. Reachability in a finite graph is decidable, so part 3 holds.

### Part D: from automata to sentences

25. Let $A$ be a Büchi automaton, and take set variables $X_q$ for $q \in Q$, read as "the state before position $i$ is $q$".
    Let $\varphi_A$ say four things: the $X_q$ partition $\mathbb{N}$, the first position lies in some $X_q$ with $q \in I$, every pair $x, y$ with $S(x, y)$ has some $(q, a, q') \in \Delta$ with $x \in X_q$, $P_a(x)$ and $y \in X_{q'}$, and some $q \in F$ gives $\forall x \, \exists y \, (x < y \wedge y \in X_q)$.
26. The relation $x < y$ is definable, as in the statement.
    The partitions that satisfy the first three clauses are exactly the runs of $A$, where $r_i$ is the unique $q$ with $i \in X_q$.
    The last clause says that the run is accepting, so $\varphi_A$ defines $L(A)$.

### Part D: from formulas to automata

27. Translate first-order variables into singleton set variables, as in steps 14 to 17 of the [[proof of the Büchi-Elgot-Trakhtenbrot theorem|NT5RAK54G3]], with $S(x, y)^* = \operatorname{Succ}(X_x, X_y)$.
    The set variables $X_1, \ldots, X_m$ become tracks: an infinite word over $\Sigma \times \{0, 1\}^m$ is the same as a word $\alpha \in \Sigma^\omega$ with sets $U_1, \ldots, U_m \subseteq \mathbb{N}$.
28. For $\operatorname{Sing}(X_j)$, take states $0$ and $1$ with $1$ accepting, let bit $0$ loop on both states, and let bit $1$ go from $0$ to $1$.
    For $X_i \subseteq X_j$, take one accepting state with no transition on bits $(1, 0)$, and treat $X_i \subseteq P_a$ in the same way.
    For $\operatorname{Succ}(X_i, X_j)$, take states $0, 1, 2$ with $2$ accepting, where bits $(0,0)$ loop on $0$ and $2$, bits $(1,0)$ go from $0$ to $1$, and bits $(0,1)$ go from $1$ to $2$.
29. In each case an infinite run exists exactly when the relation holds, and every such run stays in an accepting state from some point on.
30. Negation is complement by Part B, disjunction is union by step 1, and $\psi \wedge \chi$ is $\neg(\neg \psi \vee \neg \chi)$.
    For $\exists X_j \, \psi$, let $g_j$ set bit $j$ to $0$, and the language is $g_j^{-1}(g_j(L_\psi))$ by steps 2 and 3.
    No padding is needed, because all words are infinite.
31. By [[structural induction|12MQ2NJ29A]], every formula gets a Büchi automaton.
    For a sentence $\varphi$ over $\Sigma$, the language $\{ \alpha : \alpha \models \varphi \}$ is $e^{-1}(L_{\varphi^*})$ with $e(a) = (a, 0, \ldots, 0)$, and this proves part 1.

### Parts E and F: decidability and complexity

32. Let $\varphi$ be an S1S sentence, and use the alphabet $\{0,1\}^m$ of the tracks alone.
    The truth of a sentence does not depend on the sets, so $L_{\varphi^*}$ is either all infinite words or empty.
33. Part D computes the automaton for $L_{\varphi^*}$, and Part C decides whether its language is empty, so S1S is decidable.
34. Relativize each set quantifier of a WS1S sentence $\psi$ to finite sets: $\exists X$ becomes $\exists X \, (\operatorname{Fin}(X) \wedge \ldots)$ and $\forall X$ becomes $\forall X \, (\operatorname{Fin}(X) \to \ldots)$, with $\operatorname{Fin}(X) = \exists y \, \forall z \, (z \in X \to z < y)$.
35. The result $\psi'$ is true in $(\mathbb{N}, S)$ in the sense of S1S exactly when $\psi$ is true in the sense of WS1S, and the map $\psi \mapsto \psi'$ is computable in linear time.
36. Meyer proved that WS1S is not [[elementary recursive|RJ3MCAAZSV]], and we cite this result without proof.
    An elementary decision procedure for S1S, composed with step 35, would decide WS1S in elementary time, so S1S is not elementary recursive.

This proves parts 1 to 5 of Büchi's theorem, with part 5 resting on Meyer's cited lower bound.

## Idea

Formulas and automata translate into each other as for finite words: tracks for variables, union for disjunction, projection for set quantifiers.
The new problem is complement, because Büchi automata cannot be made deterministic.
Büchi's argument sorts finite words by a finite profile that records which states the automaton can connect, with or without a visit to $F$.
Ramsey's theorem then cuts every infinite word into a prefix and blocks of one profile, and the complement is a finite union of such block languages.
Emptiness reduces to finding a reachable accepting state on a cycle.

## Variants

The complement can also be built by determinization.
McNaughton's theorem gives a deterministic Muller automaton, whose complement is again a Muller automaton, and Safra's construction does this with $2^{O(n \log n)}$ states.
Another route, due to Kupferman and Vardi, uses ranking functions on the run graph of the automaton, and it avoids both Ramsey's theorem and determinization.
An algebraic route replaces automata by finite semigroups and $\omega$-semigroups, with the same Ramsey factorization at its core.
