## Summary

First-order logic is the logic of formulas built from a [[signature|WDVVEYD6AT]] of function, relation and constant symbols, with variables, the [[connectives|QS0XVAN9BG]] $\neg, \land, \lor, \to, \leftrightarrow$, equality, and the quantifiers $\forall x$ and $\exists x$.
The variables range over the elements of one domain, and a quantifier binds a variable for an element, never for a set of elements or for a relation.
A first-order logic has three parts: the syntax (the [[terms|6D3WA7N2W4]] and [[formulas|HYJ10AF6RT]]), the semantics ([[structures|983GZBQYT4]] and [[satisfaction|2RBQPV02AS]]), and a deductive calculus.
It matters because almost all of mathematics can be written as first-order theories, and because it is the strongest logic with a complete proof system and the compactness property.

## Motivation

[[Propositional logic|09K9MWD2QQ]] treats "every number has a larger number" as one atom $p$.
It cannot see the inner structure "for every $x$ there is a $y$ with $x < y$", so it cannot prove that this sentence implies "for $0$ there is a $y$ with $0 < y$".
Mathematical statements talk about elements, operations and relations, and they quantify over elements.
First-order logic adds exactly these features: symbols for operations and relations, variables for elements, and the quantifiers.
The restriction to quantification over elements is a choice.
It keeps the good metatheory: [[Gödel's completeness theorem|WQ1ZE255SF]], the [[compactness theorem|1NR3HAWG9D]] and the [[Löwenheim-Skolem theorem|484M0TZ1S7]].
Statements about all subsets, such as the least upper bound property, then need a detour through set theory.

## Notation

1. Other names are predicate logic, predicate calculus, quantification theory and elementary logic. "Elementary" here means "first-order", as in "elementary equivalence".
2. A first-order language is fixed by its signature $\sigma$. Books write $\mathcal{L}$, $L$, $\tau$ or $\sigma$ for it.
3. Books differ in the primitive symbols. Enderton takes $\neg$, $\to$ and $\forall$ as primitive and defines the rest. Other books take all five connectives and both quantifiers. This site takes all of them as primitive.
4. Some books write $\bigwedge x$ and $\bigvee x$, or $(x)$ for $\forall x$. Some write $\supset$ for $\to$ and $\equiv$ for $\leftrightarrow$.
5. In Mathlib a signature is `FirstOrder.Language`, and formulas are `FirstOrder.Language.BoundedFormula`.

2. Semantics: structures, assignments, satisfaction and truth, in the topic [[structures, satisfaction and truth|NJDME6F845]].
3. Deduction: Hilbert systems, natural deduction and sequent calculi, in the topic [[proof systems for first-order logic|TTCRX3NFNY]].
4. Metatheory: soundness, completeness and compactness, in the topic [[completeness, compactness and interpolation|FBWW4J1XWG]].

### Examples

1. [[Continuity of a real function|~948b6da6]] is a first-order formula in the language of ordered fields with one function symbol, because $\varepsilon$, $\delta$ and $y$ range over real numbers.
2. [[Every positive real number has a square root|~376488c3]] is a first-order sentence $\forall x \, (0 < x \to \exists y \, (y \cdot y = x))$.
3. The group axioms are first-order sentences in the signature $\set{\cdot, e, {}^{-1}}$, and together they form a [[first-order theory|92SWXST1ZM]].
4. First-order Peano arithmetic replaces the one induction axiom about all subsets by one axiom for each formula. Each of these axioms is first-order.
5. Zermelo-Fraenkel set theory is a first-order theory in the signature $\set{\in}$. Its variables range over sets, and sets are its elements.

### Non-examples

1. [[The least upper bound property|~4ea127ad]] quantifies over all subsets of the domain. It is a sentence of [[second-order logic|G6X7SZSNC5]], and no set of first-order sentences has exactly the complete ordered fields as models.
2. "The group is finite" is not expressed by any set of first-order sentences, by the compactness theorem: see [[finiteness of a group is not first-order|3J825EJ81F]].
3. The induction axiom of the second-order [[Peano axioms|0QFT7Z76N5]] begins with "for every set $P$ of numbers". The quantifier ranges over sets, so the axiom is second-order.
4. A formula with infinitely long conjunctions, such as $\bigvee_{n} (x = n)$ over all numerals, belongs to [[infinitary logic|PQG7VAZ1R2]], not to first-order logic.

### Basic properties

1. Each formula is a finite string, and it has exactly one reading as a formation tree, by [[unique readability|~62799b98]].
2. Over a countable signature there are only countably many formulas, since each formula is a finite string over a countable alphabet.
3. Soundness and [[Gödel's completeness theorem|WQ1ZE255SF]]: a sentence is provable from a theory exactly when it is true in every model of the theory.
4. The [[compactness theorem|1NR3HAWG9D]]: a set of sentences has a model when each finite subset has a model.
5. The [[Löwenheim-Skolem theorem|484M0TZ1S7]]: a countable theory with an infinite model has a model of each infinite cardinality.
6. [[Church's theorem|VA6BNNY2YC]]: validity in first-order logic is not decidable, when the signature has a relation symbol of arity at least $2$.
7. [[Lindström's theorem|FYZ3CJGZYV]]: first-order logic is a maximal logic with the compactness and the downward Löwenheim-Skolem properties.

### History

Frege's Begriffsschrift of 1879 gave the first formal logic with quantifiers, but it allowed quantification over concepts.
In 1922 Skolem proposed to read Zermelo's "definite properties" in set theory as first-order formulas.
Hilbert and Ackermann's book of 1928 isolated the first-order part as the "restricted functional calculus" and asked whether its proof system is complete.
Gödel answered yes in his thesis of 1929.

### Common errors

1. A student thinks that "first-order" forbids talk about sets. Set theory is first-order: its elements are the sets.
2. A student writes a quantifier over a property, such as "for every property $P$", inside a first-order formula. This is a second-order quantifier.
3. A student treats the signature as part of the logic. The connectives and quantifiers are fixed, and only the non-logical symbols change from one language to another.

## Explanations

### L1 human

First-order logic is a precise language for statements about objects.
It has names for objects, such as $0$, and symbols for operations and relations, such as $+$ and $<$.
It has variables such as $x$ and $y$, and the phrases "for all $x$" and "there is an $x$".
For example, "for all $x$ there is a $y$ with $x < y$" says that no number is the largest.
This is true for the whole numbers $0, 1, 2, \dots$, because $y = x + 1$ always works.
The words "for all" and "there is" talk only about objects, such as numbers, and never about collections of objects.

### L2 human

We write "between two different real numbers there is a third" in first-order logic.

1. The signature has one binary relation symbol $<$.
2. "$z$ lies between $x$ and $y$" is the formula $(x < z \land z < y)$.
3. "For all $x$ and $y$ with $x < y$, some $z$ lies between them" is $\forall x \, \forall y \, (x < y \to \exists z \, (x < z \land z < y))$.
4. The sentence has no free variables, so it is true or false in each ordered set.
5. It is true in $(\mathbb{Q}, <)$: take $z = (x + y)/2$.
6. It is false in $(\mathbb{Z}, <)$: for $x = 0$ and $y = 1$, no integer lies strictly between them.

The typical use is to write the axioms of a class of structures, here the dense orders, and then to study their models.
A trap: the restricted quantifier "for all $x > 0$" becomes $\forall x \, (0 < x \to \dots)$ with $\to$, but "there is an $x > 0$" becomes $\exists x \, (0 < x \land \dots)$ with $\land$.

### L3 human

First-order logic sits between propositional logic and second-order logic.
Second-order logic can characterize $\mathbb{N}$ and $\mathbb{R}$ up to isomorphism, but it loses completeness and compactness.
Lindström's theorem explains the choice of first-order logic as the standard: no proper extension keeps both compactness and the downward Löwenheim-Skolem property.
The price is that first-order theories with an infinite model have models of every infinite size, so they cannot pin down an infinite structure.
In model theory, the definable sets of a structure carry much of its geometry, as in o-minimality and stability.
In proof theory and in the foundations of mathematics, first-order theories such as Peano arithmetic and ZFC are the standard frames.
Many-sorted logic, logic without equality and the epsilon calculus are variants of the same syntax, treated later in this topic.
