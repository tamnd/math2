## Problem

Stock rolls all have the same width $W > 0$.
For $i = 1, \dots, m$, the order asks for $d_i$ pieces of width $w_i$, where $0 < w_i \le W$ and $d_i$ is a positive integer.
A *pattern* is a vector $a = (a_1, \dots, a_m)$ of nonnegative integers with $\sum_i a_i w_i \le W$: it cuts $a_i$ pieces of width $w_i$ from one roll.
Let $a^{(1)}, \dots, a^{(p)}$ be all the patterns.
Let $x_j$ be the number of rolls cut with pattern $a^{(j)}$.
The *cutting stock problem* asks for nonnegative integers $x_1, \dots, x_p$ that minimize $\sum_j x_j$.
The constraints are $\sum_j a^{(j)}_i x_j \ge d_i$ for every $i$.

## Remarks

This is an [[integer program|9GX3WH5EQF]], usually with a huge number $p$ of patterns.
When every $d_i = 1$ and the widths are rescaled so that $W = 1$, it is the [[bin packing problem|9F79A9Z5DD]], so it is NP-hard.
Gilmore and Gomory solved the linear programming relaxation by [[column generation|X8JZFMSYT1]].
Only a few patterns are kept, and a new improving pattern is found by solving a knapsack problem.
Rounding the fractional solution then gives good integer solutions in practice.
Variants allow rolls of different widths, minimize waste instead of rolls, or cut in two dimensions.

## Explanations

### L1 human

A paper mill makes long rolls of a fixed width, and customers order narrower rolls of various widths.
The mill must decide how to slice the big rolls so as to use as few of them as possible.
For example, from rolls of width $10$, an order for two pieces of width $6$ and two of width $4$ is met with two rolls, each cut as $6 + 4$.
The same question appears for steel bars, glass sheets and cloth.
