## Example

Let $L = \set{<}$ and let $\mathrm{DLO}$ be the set of axioms of [[dense linear orders without endpoints|2W4S2H4VYA]].
These say that $<$ is irreflexive, transitive and total, that between any two elements there is a third, that there is no least and no greatest element, and that there are at least two elements.
We check that the [[theory|X9HV9C6X4F]] $\operatorname{Th}(\Q, <)$ is the set of [[consequences|1HK0VYWTV7]] of $\mathrm{DLO}$.

1. $(\Q, <) \models \mathrm{DLO}$: between $a < b$ lies $(a + b)/2$, below $a$ lies $a - 1$, and above $a$ lies $a + 1$.
2. So every consequence of $\mathrm{DLO}$ is true in $(\Q, <)$, and lies in $\operatorname{Th}(\Q, <)$.
3. For the other inclusion, let $\tau \in \operatorname{Th}(\Q, <)$ and suppose that $\mathrm{DLO} \not\models \tau$. Then some model $\mathcal{N}$ of $\mathrm{DLO}$ satisfies $\neg\tau$.
4. $\mathcal{N}$ is infinite, since a finite nonempty linear order has a greatest element. By the downward [[Löwenheim-Skolem theorem|484M0TZ1S7]] there is a countable model $\mathcal{N}_0$ of $\mathrm{DLO} \cup \set{\neg\tau}$.
5. By [[Cantor's theorem|ABN5PTXEHY]], $\mathcal{N}_0 \cong (\Q, <)$. Isomorphic structures satisfy the same sentences, so $(\Q, <) \models \neg\tau$.
6. This contradicts $\tau \in \operatorname{Th}(\Q, <)$. So $\mathrm{DLO} \models \tau$.

So $\operatorname{Th}(\Q, <) = \set{\tau : \mathrm{DLO} \models \tau}$, and $\mathrm{DLO}$ is a finite axiomatization of the theory of the rational order.

## Remarks

Steps 3 to 6 are the [[Łoś-Vaught test|ZR7Y5C235P]] in the case $\kappa = \aleph_0$.
The same proof shows that $(\R, <)$, $(\Q \cap (0, 1), <)$ and every other dense linear order without endpoints have the same theory as $(\Q, <)$.
The theory $\operatorname{Th}(\Q, <)$ is decidable: to decide $\tau$, list the proofs from the finite set $\mathrm{DLO}$ until a proof of $\tau$ or of $\neg\tau$ appears.
By contrast, $\operatorname{Th}(\Z, <)$ contains $\forall x \, \exists y \, (x < y \land \neg\exists z \, (x < z \land z < y))$, which is false in $(\Q, <)$.

## Explanations

### L1 human

The rational numbers in their order have a few basic features: the order has no gaps between points, no first point and no last point.
Every true statement about the order of the rationals follows from these few features alone.
So a short list of axioms says everything that can be said in this language.

### L2 human

We check that the sentence $\tau = \forall x \, \exists y \, \exists z \, (y < x \land x < z)$ follows from $\mathrm{DLO}$.

1. Let $\mathcal{N} \models \mathrm{DLO}$ and $a \in N$.
2. Since $a$ is not the least element, there is $b < a$.
3. Since $a$ is not the greatest element, there is $c > a$.
4. So $\mathcal{N} \models \tau$.

The typical use of the example is as the first complete theory that one meets.
A trap is to apply Cantor's theorem to an uncountable model directly; the proof first passes to a countable model.
