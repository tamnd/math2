## Definition

Let $C \subseteq \Sigma^n$ be a [[block code|EFGYF9P0PN]] of length $n$ over a finite alphabet $\Sigma$, with at least two codewords.
The *minimum distance* of $C$ is
$$d(C) = \min \set{d(x, y) : x, y \in C,\ x \ne y},$$
where $d$ is the [[Hamming distance|K5287V64FH]].
A code of length $n$ with $M$ codewords and minimum distance $d$ is an $(n, M, d)$ code.

## Remarks

Example: the even-weight code $C = \set{000, 011, 101, 110}$ has $d(C) = 2$.
Any two distinct codewords differ in exactly two positions, for instance $d(011, 101) = 2$.

Non-example: a set with one codeword has no minimum distance, since the minimum would be over the empty set.

If $\Sigma = \F_q$ and $C$ is a linear subspace of $\F_q^n$, then $d(C)$ equals the least [[Hamming weight|K8ZHAQAK2B]] of a nonzero codeword.
Indeed $d(x, y) = \mathrm{wt}(x - y)$, and $x - y$ runs over the nonzero codewords as $x \ne y$ run over $C$.
A linear code of dimension $k$ and minimum distance $d$ is an $[n, k, d]$ code.
