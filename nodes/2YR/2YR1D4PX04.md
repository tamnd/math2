## Statement

Consider the second order homogeneous equation $a y'' + b y' + c y = 0$ with real constants $a \neq 0$, $b$, $c$. Let $r_1$ and $r_2$ be the roots of its [[characteristic equation|0GZWXM2DKE]] $a r^2 + b r + c = 0$.

If $r_1 \neq r_2$ and both are real, which happens when $b^2 - 4ac > 0$, then the [[general solution|0SKYFQAFYD]] is $y = C_1 e^{r_1 x} + C_2 e^{r_2 x}$, with arbitrary constants $C_1, C_2$.

If $r_1 = r_2$, which happens when $b^2 - 4ac = 0$, then the general solution is $y = (C_1 + C_2 x)\, e^{r_1 x}$.

## Remarks

In the first case the two exponentials are independent solutions. In the second case the single exponential is not enough, and the extra solution is $x e^{r_1 x}$.

Example: $y'' - 3y' + 2y = 0$ has roots $1$ and $2$, so $y = C_1 e^{x} + C_2 e^{2x}$. The equation $y'' - 2y' + y = 0$ has the double root $1$, so $y = (C_1 + C_2 x) e^{x}$.
