## Example

Let $f : \mathbb{R} \to \mathbb{R}$ be a function, and let $a \in \mathbb{R}$.
Consider two definitions of "$f$ is continuous at $a$".

- (D1) For each $\varepsilon > 0$ there is a $\delta > 0$ such that $\abs{x - a} < \delta$ implies $\abs{f(x) - f(a)} < \varepsilon$. This is the [[epsilon-delta definition|0W8YHHGCJG]].
- (D2) For each sequence $(x_n)$ with $x_n \to a$, the sequence $f(x_n)$ converges to $f(a)$. This is [[sequential continuity|055Z15H69G]].

We prove that D1 and D2 are [[equivalent definitions|NZ42PS2P1A]].

Proof that D1 implies D2.

1. Assume D1, and let $x_n \to a$. Let $\varepsilon > 0$.
2. D1 gives a $\delta > 0$ such that $\abs{x - a} < \delta$ implies $\abs{f(x) - f(a)} < \varepsilon$.
3. By the definition of the [[limit of a sequence|05M5SWSZZD]], there is an $N$ such that $\abs{x_n - a} < \delta$ for all $n \geq N$.
4. So $\abs{f(x_n) - f(a)} < \varepsilon$ for all $n \geq N$. This holds for each $\varepsilon > 0$, so $f(x_n) \to f(a)$.

Proof that D2 implies D1, by the [[contrapositive|0BB5TPGQ1N]].

1. Assume that D1 fails. Then there is an $\varepsilon > 0$ such that no $\delta > 0$ works.
2. For each $n \geq 1$, the value $\delta = 1/n$ does not work. So there is an $x_n$ with $\abs{x_n - a} < 1/n$ and $\abs{f(x_n) - f(a)} \geq \varepsilon$.
3. Then $x_n \to a$, because $1/n \to 0$.
4. But $f(x_n)$ does not converge to $f(a)$, because each term has distance at least $\varepsilon$ from $f(a)$.
5. So D2 fails. This proves D2 implies D1.

## Remarks

1. Step 2 of the second proof chooses one $x_n$ for each $n$. In general this needs the axiom of countable choice. For a function on $\mathbb{R}$ this use is standard and accepted.
2. The same proof works for functions between [[metric spaces|0VKD1TP7F3]]. It uses only the balls of radius $1/n$ around $a$.
3. For maps between general topological spaces, the open set definition is primary, and sequential continuity is weaker. The two agree when the domain is [[first-countable|0CP5NDD21C]].
4. D1 is better for estimates, and D2 is better for showing that a function is not continuous: one bad sequence is enough.

## Explanations

### L1 human

A function is continuous at a point when small changes of the input give small changes of the output.
There are two ways to make "small" exact.
One way says: for each allowed error in the output, some closeness of the input keeps the output within that error.
The other way says: when the inputs walk towards the point, the outputs walk towards the value at the point.
These two ways sound different, but they describe exactly the same functions.

### L2 human

We use D2 to show that the function $f(x) = 1$ for $x > 0$ and $f(x) = 0$ for $x \leq 0$ is not continuous at $0$.

1. Let $x_n = 1/n$. Then $x_n \to 0$.
2. For each $n$, $x_n > 0$, so $f(x_n) = 1$.
3. So $f(x_n) \to 1$, but $f(0) = 0$.
4. So D2 fails at $0$. By the theorem, D1 also fails, and $f$ is not continuous at $0$.

The typical use: one sequence disproves continuity, while D1 proves continuity by an estimate.
A trap is to test only one sequence to prove continuity.
D2 requires each sequence that converges to $a$.
