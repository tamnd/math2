## Example

Let $f \colon \mathbb{R} \to \mathbb{R}$ be a function and let $a \in \mathbb{R}$.
Compare two definitions of "$f$ is [[continuous|0X3WGX95FE]] at $a$".
The [[epsilon-delta definition|0W8YHHGCJG]] D1 says that for every $\varepsilon > 0$ there is a $\delta > 0$ such that $|x - a| < \delta$ implies $|f(x) - f(a)| < \varepsilon$.
The definition of [[sequential continuity|055Z15H69G]] D2 says that for every sequence $(x_n)$ with $x_n \to a$, the sequence $(f(x_n))$ converges to $f(a)$.
We prove that D1 and D2 are [[equivalent definitions|NZ42PS2P1A]].

First we show that D1 implies D2.

1. Assume D1, let $x_n \to a$, and let $\varepsilon > 0$.
2. D1 gives a $\delta > 0$ such that $|x - a| < \delta$ implies $|f(x) - f(a)| < \varepsilon$.
3. By the definition of the [[limit of a sequence|05M5SWSZZD]], there is an $N$ with $|x_n - a| < \delta$ for all $n \ge N$.
4. So $|f(x_n) - f(a)| < \varepsilon$ for all $n \ge N$.
   This holds for every $\varepsilon > 0$, so $f(x_n) \to f(a)$.

Next we show that D2 implies D1, by the [[contrapositive|0BB5TPGQ1N]].

1. Assume that D1 fails.
   Then there is an $\varepsilon > 0$ for which no $\delta > 0$ works.
2. For each $n \ge 1$ the value $\delta = 1/n$ does not work, so there is an $x_n$ with $|x_n - a| < 1/n$ and $|f(x_n) - f(a)| \ge \varepsilon$.
3. Then $x_n \to a$, because $1/n \to 0$.
4. But $(f(x_n))$ does not converge to $f(a)$, because every term has distance at least $\varepsilon$ from $f(a)$.
5. So D2 fails, and this proves that D2 implies D1.

## Remarks

Step 2 of the second proof chooses one $x_n$ for each $n$, and in general this uses the axiom of countable choice.
Ordinary analysis accepts that axiom, so the equivalence is a standard theorem.

The same proof works for functions between [[metric spaces|0VKD1TP7F3]], since it uses only balls of radius $1/n$ around $a$.
For maps between general topological spaces, the open set definition is primary and sequential continuity is weaker.
The two agree when the domain is [[first-countable|0CP5NDD21C]].

Each definition has its own job.
D1 is the natural tool for proving continuity by an estimate.
D2 is the natural tool for disproving it, since one bad sequence is enough.

## Explanations

### L1 human

A function is continuous at a point when small changes of the input give small changes of the output.
There are two ways to make "small" exact.
One way says that for every allowed error in the output, some closeness of the input keeps the output within that error.
The other way says that when the inputs walk towards the point, the outputs walk towards the value at the point.
The two ways sound different, but they describe exactly the same functions.

### L2 human

We use D2 to show that the step function with $f(x) = 1$ for $x > 0$ and $f(x) = 0$ for $x \le 0$ is not continuous at $0$.

1. Let $x_n = 1/n$, so $x_n \to 0$.
2. Each $x_n$ is positive, so $f(x_n) = 1$ for every $n$.
3. So $f(x_n) \to 1$, but $f(0) = 0$.
4. So D2 fails at $0$, and by the theorem D1 fails too.

To see D1 fail directly, take $\varepsilon = \tfrac{1}{2}$: every $\delta > 0$ allows $x = \delta/2$, and $|f(\delta/2) - f(0)| = 1 \ge \tfrac{1}{2}$.
One sequence disproves continuity, while a proof of continuity uses D1 and an estimate.
Watch out: a proof of continuity with D2 must handle every sequence that converges to $a$, and testing one sequence such as $x_n = -1/n$ proves nothing.
