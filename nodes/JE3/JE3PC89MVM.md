## Summary

A [[model of computation|YFHEG4GYHW]] or a programming system is Turing complete when it can simulate every [[Turing machine|758EYCN27B]].
It is Turing equivalent when, in addition, every one of its machines can be simulated by a Turing machine.
By the [[Church–Turing thesis|RWRNBS3Z7B]], a Turing equivalent system can carry out every algorithm.
Turing completeness of a system implies that questions such as whether a given program halts are undecidable for it.

## Explanations

### L1 human

A system is Turing complete if it can do anything a computer can do, given enough time and memory.
Most programming languages are Turing complete, and so are some very simple systems.
Examples are [[register machines|TGDKQY6S1T]] with two counters and the cellular automaton [[Rule 110|KT6HCJGJF7]].
A calculator that only adds and multiplies numbers is not Turing complete, because it has no loops or memory to reuse.
