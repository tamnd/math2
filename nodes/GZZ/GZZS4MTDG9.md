## Summary

A utility function assigns a real number to each alternative so that better alternatives get larger numbers.
It represents a [[preference relation|JGP0Q56FRY]] when one alternative is at least as good as another exactly when its number is at least as large.
Utility functions turn questions about choice into questions about maximizing a real function, which is the main tool of consumer theory.
In this ordinal sense only the order of the values matters, so any strictly increasing transformation of a utility function represents the same preferences.

## Explanations

### L1 human

A utility function is a score sheet for choices.
Instead of comparing alternatives two by two, one gives each alternative a score and compares the scores.
For example, if a person likes apples and pears equally and both more than plums, the scores $2, 2, 1$ represent this taste.
The scores $10, 10, 3$ represent the same taste, because only the order of the scores matters.
