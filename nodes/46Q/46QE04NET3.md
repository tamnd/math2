## Example

Let $X = \mathbb{R} \setminus \{1\}$, and define
$$f \colon X \to X, \qquad f(x) = \frac{x + 1}{x - 1}.$$
We prove that $f$ is a bijection in three ways, with the templates of [[proving injectivity and surjectivity|DD2P85Y8E9]].

1. The rule is defined on $X$, since $x - 1 \ne 0$ for $x \ne 1$.
2. The values lie in $X$.
   If $f(x) = 1$, then $x + 1 = x - 1$, so $1 = -1$, which is false.
3. Injectivity.
   Let $f(a) = f(b)$ and multiply by $(a - 1)(b - 1)$, which is not $0$:
   $$(a + 1)(b - 1) = (b + 1)(a - 1).$$
4. Expand both sides to get $ab - a + b - 1 = ab - b + a - 1$, so $2b = 2a$ and $a = b$.
   Hence $f$ is [[injective|09NWETVTNY]].
5. Surjectivity.
   Let $y \in X$, so $y \ne 1$, and solve $\frac{x + 1}{x - 1} = y$ for $x$:
   $$x + 1 = yx - y, \qquad x(y - 1) = y + 1, \qquad x = \frac{y + 1}{y - 1}.$$
6. This $x$ lies in $X$ by step 2 applied to $y$.
   Each step of 5 reverses, because $x - 1 \ne 0$ and $y - 1 \ne 0$, so $f(x) = y$ and $f$ is [[surjective|01RVCMSN5N]].
7. Inverse.
   The solution in step 5 is $x = f(y)$, which suggests checking $f(f(x)) = x$.
8. Compute $f(x) + 1 = \frac{2x}{x - 1}$ and $f(x) - 1 = \frac{2}{x - 1}$, so
   $$f(f(x)) = \frac{f(x) + 1}{f(x) - 1} = \frac{2x}{x - 1} \cdot \frac{x - 1}{2} = x.$$
9. So $f \circ f = \mathrm{id}_X$, and $f$ is a two-sided [[inverse|0J2WAR83WP]] of itself.
   By [[bijective iff it has a two-sided inverse|01VG2A0BHW]], $f$ is a bijection.

Check: $f(3) = 4/2 = 2$ and $f(2) = 3/1 = 3$, so $f(f(3)) = 3$.

## Remarks

Steps 7 to 9 prove the bijection on their own, and steps 3 to 6 reach the same conclusion by the two separate templates.
A function with $f \circ f = \mathrm{id}$ is an involution, and every involution is a bijection, because it is its own two-sided inverse.

The choice of $X$ on both sides matters.
With domain $\mathbb{R} \setminus \{1\}$ and codomain $\mathbb{R}$, the function is still injective but not surjective, because the value $1$ is never reached.
The function is a Möbius transformation $x \mapsto \frac{ax + b}{cx + d}$ with $a = b = c = 1$ and $d = -1$.
When $c \ne 0$ and $ad - bc \ne 0$, such a map is a bijection from $\mathbb{R} \setminus \{-d/c\}$ to $\mathbb{R} \setminus \{a/c\}$, and here both removed points are $1$.

## Explanations

### L1 human

The rule takes a number, adds $1$, and divides by the number minus $1$.
For $3$ it gives $4 \div 2 = 2$, and for $2$ it gives $3 \div 1 = 3$.
So applying the rule twice brings $3$ back to $3$, and the proof shows the same for every allowed number.
A rule that undoes itself can never send two numbers to the same place, and it reaches every allowed number.

### L2 human

We see why $1$ must be removed from both sides.

1. The input $1$ is not allowed, because the denominator $x - 1$ is $0$ there.
2. The output $1$ is never reached, by step 2 of the example.
3. If the codomain kept $1$, the equation $f(x) = 1$ would have no solution, and $f$ would not be surjective.
4. So the exact statement is that $f$ is a bijection from $\mathbb{R} \setminus \{1\}$ to $\mathbb{R} \setminus \{1\}$.

The inverse route fits any change of variables whose inverse has a formula.
Watch out: multiplying by $x - 1$ without the condition $x \ne 1$ can bring in a false solution.
