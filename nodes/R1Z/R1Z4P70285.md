## Summary

A flexible algebra is a [[nonassociative algebra|60W3THKGA7]] in which $(xy)x = x(yx)$ for all elements $x, y$.
So the expression $xyx$ has one meaning, whatever the bracketing.
All associative, all commutative and all anticommutative algebras are flexible, and so are all [[alternative algebras|N8K9SSVMRN]].
Flexibility is a weak replacement for associativity that still allows a good structure theory.

## Explanations

### L1 human

In a product of three factors where the first and the last are equal, a flexible algebra lets you ignore the brackets.
It does not ask this for three arbitrary factors.
The octonions are flexible but not associative.
Every Lie algebra is flexible, because both $(xy)x$ and $x(yx)$ equal $-x(xy)$ there.
