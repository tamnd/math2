## Example

For a formula $\varphi$, let $\Box \varphi$ be true when $\varphi$ is a [[tautology|05006AJ7DZ]], and false otherwise.
We show that $\Box$ is not a [[logical connective|QS0XVAN9BG]] with a truth function, as the [[definition|CA49F5KQGB]] requires.

1. Suppose that $\Box$ had a truth function $f$, so that the value of $\Box \varphi$ under an assignment is $f$ applied to the value of $\varphi$.
2. Fix the assignment $p = \mathsf{T}$.
3. The formula $\varphi_1 = p \lor \neg p$ has value $\mathsf{T}$ under this assignment. It is a tautology, because it is also true at $p = \mathsf{F}$. So $\Box \varphi_1$ is true.
4. The formula $\varphi_2 = p$ has value $\mathsf{T}$ under this assignment. It is not a tautology, because it is false at $p = \mathsf{F}$. So $\Box \varphi_2$ is false.
5. By step 1, $\Box \varphi_1$ and $\Box \varphi_2$ both have the value $f(\mathsf{T})$, so they are equal.
6. Steps 3 and 4 give different values, which contradicts step 5.

So no truth function $f$ exists, and "it is a tautology that" is not a truth-functional connective.

## Remarks

The example shows the difference between a connective and a statement about formulas.
The value of $\Box \varphi$ depends on the values of $\varphi$ under all assignments, not under one.
This is why the claim "$\varphi$ is a tautology" is written in the metalanguage as $\models \varphi$, and not as a connective inside a formula.

The same proof works for "it is provable that" and for "it is necessary that".
[[Modal logic|C3RZY20ETK]] adds such an operator $\Box$ to the language, and it gives $\Box$ a meaning through possible worlds instead of a truth function.
If $\Box$ is applied only to formulas without variables, such as $\top$ and $\bot$, then its value does depend only on the truth value, but this does not make it a connective on all formulas.

## Explanations

### L1 human

Compare "it rains or it does not rain" and "it rains" on a rainy day.
Both are true today.
The first is true on every day, so it is a law of logic.
The second is not true on every day.
So "is a law of logic" is not decided by today's truth value alone, and it is not a connective.

### L2 human

We test whether "$\varphi$ is satisfiable" is a truth-functional connective.

1. Fix the assignment $p = \mathsf{F}$.
2. The formula $p$ is false under it, but $p$ is satisfiable, because $p = \mathsf{T}$ makes it true.
3. The formula $p \land \neg p$ is false under it, and it is not satisfiable.
4. Two formulas with the same value $\mathsf{F}$ give different answers, so the operator is not truth-functional.

The typical use of this test is to separate properties of formulas, such as being a tautology or being [[satisfiable|QN7M1JCGT9]], from connectives inside formulas.
A trap: a property of formulas can look like a connective when it is written next to the formula, as in $\models \varphi$.
