## Example

The epsilon-delta definition of continuity is a formula of [[first-order logic|086QKPF0A6]], because every quantifier in it ranges over real numbers.
To write it, take the [[signature|WDVVEYD6AT]] of [[ordered fields|0P3VCBDEE2]] with one more unary function symbol $f$:
$$\sigma = \{ +, \cdot, -, 0, 1, <, f \},$$
where $+$ and $\cdot$ are binary function symbols, $-$ and $f$ are unary function symbols, $0$ and $1$ are constants, and $<$ is a binary relation symbol.
We write $u - w$ as short for the term $u + (-w)$.
Let $\mathrm{Cont}(a)$ be the formula
$$\forall \varepsilon \, \Big(0 < \varepsilon \to \exists \delta \, \big(0 < \delta \land \forall x \, ((-\delta < x - a \land x - a < \delta) \to (-\varepsilon < f(x) - f(a) \land f(x) - f(a) < \varepsilon))\big)\Big).$$
We check that it is a formula of $\sigma$ and that it says "$f$ is continuous at $a$".

1. The letters $\varepsilon$, $\delta$, $x$ and $a$ are variables, so each one stands for one element of the domain.
2. The expressions $x - a$, $f(x) - f(a)$, $-\delta$ and $-\varepsilon$ are [[terms|6D3WA7N2W4]], since they are built from variables by $+$, $-$ and $f$, each with the right number of arguments.
3. Each expression $u < w$ with terms $u$ and $w$ is an atomic formula, because $<$ is a binary relation symbol.
4. The connectives $\land$ and $\to$ and the quantifiers $\forall \varepsilon$, $\exists \delta$ and $\forall x$ then build a [[formula|HYJ10AF6RT]].
5. Each quantifier binds a variable for one element, so the formula is first-order.
6. The variables $\varepsilon$, $\delta$ and $x$ are bound, and $a$ is free, so $\mathrm{Cont}(a)$ is a property of the element $a$.
7. The absolute value is not a symbol of $\sigma$, so the formula writes $|x - a| < \delta$ as the pair $-\delta < x - a$ and $x - a < \delta$.
8. Read $f$ as a function $g \colon \mathbb{R} \to \mathbb{R}$ in the ordered field $\mathbb{R}$.
   By the clauses of satisfaction, $\mathrm{Cont}(a)$ holds at $a$ exactly when for each $\varepsilon > 0$ some $\delta > 0$ gives $|g(x) - g(a)| < \varepsilon$ whenever $|x - a| < \delta$, which is continuity of $g$ at $a$.

So "$f$ is continuous everywhere" is the first-order sentence $\forall a \, \mathrm{Cont}(a)$.

## Remarks

The order of the quantifiers carries the meaning.
If we move $\forall a$ inside, after $\exists \delta$, we get
$$\forall \varepsilon \, \big(0 < \varepsilon \to \exists \delta \, (0 < \delta \land \forall a \, \forall x \, (\cdots))\big),$$
and now one $\delta$ must work for every $a$.
That is uniform continuity, a stronger property: $g(x) = x^2$ on $\mathbb{R}$ is continuous but not uniformly continuous.

The same formula makes sense in every ordered field with a unary function, for example in $\mathbb{Q}$.
In $\mathbb{Q}$ let $g(x) = 1$ when $x^2 > 2$ and $g(x) = 0$ when $x^2 < 2$.
No rational number has square $2$, so each rational point has a small interval on which $g$ is constant, and $\forall a \, \mathrm{Cont}(a)$ holds.
Yet $g$ takes the values $0$ and $1$ and never $\tfrac{1}{2}$, so the intermediate value theorem fails in $\mathbb{Q}$.
That theorem needs the completeness of $\mathbb{R}$, and completeness is [[not a first-order property|3K03C8D8D8]].

## Explanations

### L1 human

A function is continuous at a point when small changes of the input give small changes of the output.
The precise version says: for each allowed error $\varepsilon$ there is a tolerance $\delta$.
All the phrases "for each" and "there is" here talk about numbers.
So the definition can be written with variables for numbers, the symbols $+$, $-$ and $<$, and a symbol $f$ for the function.
For example, for $g(x) = 2x$ and the error $\varepsilon = 0.1$, the tolerance $\delta = 0.05$ works at every point.

### L2 human

We check $\mathrm{Cont}(a)$ for $g(x) = 2x$ at every point $a$.
Let $\varepsilon > 0$ be given, and take $\delta = \varepsilon / 2$, so $0 < \delta$.
Now let $x$ satisfy $-\delta < x - a < \delta$.
Since $g(x) - g(a) = 2(x - a)$, multiplying the inequalities by $2$ gives
$$-2\delta < g(x) - g(a) < 2\delta, \quad \text{that is,} \quad -\varepsilon < g(x) - g(a) < \varepsilon.$$
Check: with $\varepsilon = 0.1$, $\delta = 0.05$, $a = 1$ and $x = 1.04$, we get $g(x) - g(a) = 0.08 < 0.1$.

The first-order form also lets us negate the definition by rule.
Push $\neg$ inward past each quantifier, swapping $\forall$ and $\exists$, and use $\neg (A \to B) \equiv A \land \neg B$:
$$\exists \varepsilon \, \big(0 < \varepsilon \land \forall \delta \, (0 < \delta \to \exists x \, (|x - a| < \delta \land \neg (|f(x) - f(a)| < \varepsilon)))\big),$$
where $|\cdot|$ is only shorthand for the two inequalities.
Watch out: inside the formula you cannot write $|x - a|$ unless the signature has a symbol for it.
