## Summary

A pushdown automaton is a finite automaton equipped with an unbounded stack.
At each move it reads at most one input letter and the top symbol of the stack.
Then it changes state and replaces the top symbol by a string.
Nondeterministic pushdown automata accept exactly the [[context-free languages|Q56EWEQYE2]].
They are the machine model behind parsers for programming languages.

## Explanations

### L1 human

Think of a [[finite automaton|SFMYM96C1B]] that also holds a stack of plates.
It may put plates on top or take the top plate off, but it can never look below the top plate.
The stack gives it unbounded memory used in a last-in, first-out way.
For example, to check $a^n b^n$, it pushes one plate for each $a$, pops one plate for each $b$, and accepts if the stack is empty exactly when the input ends.
