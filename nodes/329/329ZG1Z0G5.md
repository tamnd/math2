## Definition

1. The language of arithmetic $L_A$ is the first-order [[signature|PWHJZYBNEY]] with these non-logical symbols: the constant symbol $0$, the unary function symbol $S$, the binary function symbols $+$ and $\cdot$, and the binary relation symbol $<$. The logical symbols include equality $=$.
2. The terms and formulas of $L_A$ are the [[terms|BQQ0FPFZ67]] and [[well-formed formulas|2CHENV4DCC]] of first-order logic over this signature. We write $s + t$, $s \cdot t$ and $s < t$ in infix form.
3. For $n \in \N$, the numeral $\overline{n}$ is the closed term defined by $\overline{0} = 0$ and $\overline{n + 1} = S\,\overline{n}$.
4. The abbreviation $s \le t$ stands for $s < t \lor s = t$.
5. Let $t$ be a term and $x$ a variable that does not occur in $t$. The bounded quantifiers are the abbreviations $\forall x < t\, \varphi$ for $\forall x\,(x < t \to \varphi)$ and $\exists x < t\, \varphi$ for $\exists x\,(x < t \land \varphi)$. The forms $\forall x \le t\, \varphi$ and $\exists x \le t\, \varphi$ are defined in the same way with $\le$.
6. The standard model $\mathfrak{N}$ is the $L_A$-[[structure|Y6C40MHZZC]] with domain $\N = \set{0, 1, 2, \ldots}$, with $0^{\mathfrak{N}} = 0$, $S^{\mathfrak{N}}(n) = n + 1$, $+^{\mathfrak{N}}$ and $\cdot^{\mathfrak{N}}$ the usual addition and multiplication, and $<^{\mathfrak{N}} = \set{(m, n) : m < n}$.

## Notation

A sentence $\varphi$ of $L_A$ is called true when $\mathfrak{N} \models \varphi$.
A theory in $L_A$ that uses the symbol $<$ contains the defining axiom $\forall x\, \forall y\, (x < y \leftrightarrow \exists v\, (v + S x = y))$, unless it says otherwise.
Defined relations get names, for example $x \mid y$ for $\exists z \le y\, (z \cdot x = y)$; these names are abbreviations, not new symbols.

## Remarks

The condition in item 5 that $x$ does not occur in $t$ keeps the bound from depending on the quantified variable.
For example, $\forall x < x\, \varphi$ is not a bounded quantifier in this sense.
The value of the numeral $\overline{n}$ in $\mathfrak{N}$ is $n$, by induction on $n$: the value of $\overline{0}$ is $0$, and if the value of $\overline{n}$ is $n$, then the value of $S\,\overline{n}$ is $n + 1$.
In $\mathfrak{N}$ the defining axiom of $<$ is true: $m < n$ holds if and only if $n = v + (m + 1)$ for some $v \in \N$, namely $v = n - m - 1$.
The [[concept page|D8SD54M5PN]] lists the variants of this definition in the literature.

## Explanations

### L1 human

The definition lists the five signs of the language: zero, "next", plus, times and "less than".
It also gives names to the terms that stand for the numbers: $\overline{2}$ is "next of next of zero".
Finally it says what the signs mean in the ordinary numbers $0, 1, 2, \ldots$.

### L2 human

We compute the value of the term $S(\overline{1} \cdot \overline{2}) + \overline{3}$ in $\mathfrak{N}$.

1. The numerals $\overline{1}$, $\overline{2}$ and $\overline{3}$ have the values $1$, $2$ and $3$, by the remark on numerals.
2. The value of $\overline{1} \cdot \overline{2}$ is $1 \cdot 2 = 2$, by item 6.
3. The value of $S(\overline{1} \cdot \overline{2})$ is $2 + 1 = 3$.
4. The value of the whole term is $3 + 3 = 6$, the value of $\overline{6}$.

The typical use of the definition is to fix the symbols before a theory such as [[Robinson arithmetic|3K1AKGXF8A]] gives axioms for them.
A trap: the term in this computation is not the numeral $\overline{6}$; the two are different strings with the same value.
