## Summary

The Hindley–Milner type system is a typed lambda calculus with a restricted form of polymorphism.
In it, a name bound by $\mathsf{let}$ can be used at several types.
It was found by J. Roger Hindley for combinatory logic and independently by Robin Milner for the language ML.
Luis Damas proved the completeness of its inference algorithm.
Its key property is that [[type inference|6NY149HDKS]] is decidable and every typable term has a principal type, so programs need no type annotations.
It is the core of the type systems of ML, OCaml and Haskell.

## Explanations

### L1 human

Some functions work for every type: the identity $\lambda x.\, x$ returns its argument whatever it is.
Hindley–Milner gives such a function a type scheme $\forall \alpha.\, \alpha \to \alpha$ that can be used at each type separately.
In $\mathsf{let}\ \mathit{id} = \lambda x.\, x\ \mathsf{in}\ (\mathit{id}\ 3, \mathit{id}\ \mathsf{true})$, the same $\mathit{id}$ is used once on a number and once on a truth value.
The system is just weak enough that a computer can always find these types by itself.
