## Proof

Let $\varphi$ be [[Euler's totient function|0DAMHCT17R]].

Part 1, elements of each order.

1. Let $C = \langle c \rangle$ be a [[cyclic group|0KVGH0J5B3]] of order $n$, and let $x \in C$. By the [[order of a cyclic subgroup|031M8HX7DA]], $x$ has finite [[order|0WE2NHZJ7B]], and $\abs{\langle x \rangle}$ equals the order of $x$.
2. By the [[fundamental theorem of cyclic groups|0423TXR9AN]], part 2, the order of $\langle x \rangle$ divides $n$. So the order of each element of $C$ [[divides|0PG2H7WKGG]] $n$.
3. So if $d$ does not divide $n$, then $C$ has no element of order $d$.
4. Now let $d \mid n$. Put $h = c^{n/d}$ and $H = \langle h \rangle$. By the fundamental theorem, $H$ is the only subgroup of $C$ of order $d$.
5. Let $x \in C$ have order $d$. By step 1, $\langle x \rangle$ has order $d$. So $\langle x \rangle = H$ by step 4, and $x \in H$.
6. So the elements of order $d$ in $C$ are the elements of order $d$ in $H$.
7. By step 1 applied to $h$, the order of $h$ is $\abs{H} = d$. By the order of a cyclic subgroup, $h^0, h^1, \ldots, h^{d-1}$ are distinct, and they are all of $H$.
8. Since $h^d = e = h^0$, the elements $h^1, h^2, \ldots, h^d$ are also distinct, and they are all of $H$.
9. By the [[order of a power|0VVPQNVM8S]], $h^k$ has order $d / \gcd(d, k)$. This equals $d$ if and only if $\gcd(d, k) = 1$.
10. So the elements of order $d$ are the $h^k = c^{kn/d}$ with $1 \leq k \leq d$ and $\gcd(k, d) = 1$. By step 8 they are distinct, and by the definition of $\varphi$ there are $\varphi(d)$ of them.

Part 2, the totient sum.

11. Let $C = \Z/n$, the [[integers modulo n|03VFZ2WETT]] under addition. It is cyclic of order $n$, with generator $1$.
12. By step 2, each of the $n$ elements of $C$ has an order $d$ that divides $n$. So we can count the elements of $C$ by their orders.
13. By part 1, exactly $\varphi(d)$ elements have order $d$. So $n = \sum_{d \mid n} \varphi(d)$.

Part 3, the cyclicity criterion.

14. Let $G$ be a group of order $n$, with identity $e$. For $d \mid n$, put $S_d = \set{x \in G : x^d = e}$. Suppose that $S_d$ has at most $d$ elements for each $d \mid n$.
15. For $d \mid n$, let $a(d)$ be the number of elements of order $d$ in $G$. We show that $a(d) \leq \varphi(d)$.
16. If $a(d) = 0$, this holds. Otherwise, let $x \in G$ have order $d$. By the order of a cyclic subgroup, $\langle x \rangle$ has exactly $d$ elements.
17. Each element of $\langle x \rangle$ is $x^k$ for some $k$. By the [[laws of exponents|00DRK90Z6K]], $(x^k)^d = (x^d)^k = e$. So $\langle x \rangle \subseteq S_d$.
18. The set $S_d$ has at most $d$ elements by hypothesis, and $\langle x \rangle$ has $d$ elements. So $\langle x \rangle = S_d$.
19. Each element $y$ of order $d$ satisfies $y^d = e$, so $y \in S_d = \langle x \rangle$. So the elements of order $d$ in $G$ are the elements of order $d$ in $\langle x \rangle$.
20. The group $\langle x \rangle$ is cyclic of order $d$. By part 1, applied to $\langle x \rangle$ with $d$ in place of $n$, it has exactly $\varphi(d)$ elements of order $d$. So $a(d) = \varphi(d)$.
21. The [[order of an element divides the order of the group|08V7JHS3QZ]]. So each element of $G$ has an order $d$ with $d \mid n$, and $n = \sum_{d \mid n} a(d)$.
22. By steps 15 to 20 and part 2, $n = \sum_{d \mid n} a(d) \leq \sum_{d \mid n} \varphi(d) = n$.
23. Suppose that $a(d) < \varphi(d)$ for some $d \mid n$. Then the sum in step 22 is less than $n$, which is a contradiction. So $a(d) = \varphi(d)$ for each $d \mid n$.
24. In particular, $a(n) = \varphi(n) \geq 1$, because $k = 1$ satisfies $\gcd(1, n) = 1$. So $G$ has an element $g$ of order $n$.
25. By the order of a cyclic subgroup, $\langle g \rangle$ has $n$ elements. Since $\abs{G} = n$, we get $\langle g \rangle = G$, and $G$ is cyclic. $\blacksquare$

## Idea

In a cyclic group, every element of order $d$ generates the one subgroup of order $d$.
So the elements of order $d$ are the generators of a cyclic group of order $d$.
The order of a power shows that there are $\varphi(d)$ of them.
Sorting the elements of $\Z/n$ by order gives $\sum_{d \mid n} \varphi(d) = n$.
For the criterion, the bound on $x^d = e$ makes each count at most $\varphi(d)$, and the totient sum forces equality, so some element has order $n$.

## Variants

Part 1 can be proved without the fundamental theorem.
The element $c^k$ has order $n / \gcd(n, k)$, so it has order $d$ exactly when $\gcd(n, k) = n/d$.
Writing $k = (n/d)j$, this holds exactly when $\gcd(d, j) = 1$, and Bézout's identity proves this last step.
Part 2 also has a direct proof in number theory: sort the fractions $k/n$ with $1 \leq k \leq n$ by their denominators in lowest terms.
