## Summary

Let $T$ be a [[theory|92SWXST1ZM]] in the language $\set{0, S, +, \cdot}$, with [[numerals|VK6WWSDMXK]] $\underline{n}$.
$T$ is $\omega$-inconsistent when there is a formula $\varphi(x)$ with one free variable such that $T \vdash \exists x \, \varphi(x)$ and $T \vdash \neg \varphi(\underline{n})$ for every $n \in \N$.
$T$ is $\omega$-consistent when it is not $\omega$-inconsistent.
$T$ is $1$-consistent when the same holds for the formulas $\varphi(x)$ in $\Delta_0$, those with only bounded quantifiers.
Gödel used $\omega$-consistency in the second half of his first incompleteness theorem, to show that the negation of the Gödel sentence is unprovable.

## Motivation

An $\omega$-inconsistent theory proves "some number has property $\varphi$" and refutes "$n$ has property $\varphi$" for each single $n$.
Such a theory may still be [[consistent|VM8TQ70CVJ]], because no finite proof uses all the refutations at once.
But it cannot have $\N$ as a model, so it is false about the numbers.
Gödel needed a hypothesis between consistency and truth in $\N$ that is purely syntactic, and $\omega$-consistency is that hypothesis.

## Notation

1. $\omega$ denotes the set of natural numbers, and the prefix refers to the infinitely many instances $\varphi(\underline{0}), \varphi(\underline{1}), \ldots$.
2. $1$-consistency is also called $\Sigma_1$-soundness, by basic property 4.
3. Some books state the condition with $\forall$: there is no $\varphi$ with $T \vdash \varphi(\underline{n})$ for every $n$ and $T \vdash \neg \forall x \, \varphi(x)$. Replacing $\varphi$ by $\neg \varphi$ shows that this is the same notion.

## Remarks

### Examples

1. [[Peano arithmetic is ω-consistent|5JKPMRAXZP]], because its axioms are true in $\N$.
2. [[PA + Con(PA) is ω-consistent|RD3VPJH67B]], because $\mathrm{Con}(\mathsf{PA})$ is true.
3. [[Robinson arithmetic|3K1AKGXF8A]] $\mathsf{Q}$ is $\omega$-consistent, since $\N \models \mathsf{Q}$.
4. True arithmetic, the set of all sentences true in $\N$, is $\omega$-consistent.

### Non-examples

1. [[PA + ¬Con(PA) is consistent but ω-inconsistent|FK06QR6A44]]: it proves that a proof of $0 = S0$ exists, and it refutes each candidate.
2. An inconsistent theory is $\omega$-inconsistent: it proves $\exists x \, (x = x)$ and every $\neg (\underline{n} = \underline{n})$.
3. The theory $\mathsf{Q} + \exists x \, \neg (0 + x = x)$ is consistent, but it is $\omega$-inconsistent: $\mathsf{Q}$ proves $0 + \underline{n} = \underline{n}$ for each $n$.

### Basic properties

1. An $\omega$-consistent theory is consistent. If $T$ is inconsistent, the formula $x = x$ shows that $T$ is $\omega$-inconsistent.
2. An $\omega$-consistent theory is $1$-consistent, because the definition of $1$-consistency asks less.
3. If $\N$ is a model of $T$, then $T$ is $\omega$-consistent. If $T \vdash \exists x \, \varphi(x)$, some $\varphi(n)$ holds in $\N$, so $T$ cannot prove the false sentence $\neg \varphi(\underline{n})$.
4. For $T \supseteq \mathsf{Q}$, $T$ is $1$-consistent exactly when every $\Sigma_1$ sentence provable in $T$ is true in $\N$. The proof uses that $\mathsf{Q}$ decides every $\Delta_0$ sentence.
5. Every subtheory of an $\omega$-consistent theory, in the same language, is $\omega$-consistent, since it proves fewer sentences.
6. Gödel's first theorem shows that for an $\omega$-consistent c.e. $T \supseteq \mathsf{Q}$, the theory $T + \neg G_T$ is consistent but $\omega$-inconsistent.

### History

Gödel introduced $\omega$-consistency in his 1931 paper, as the hypothesis under which the negation of his sentence is unprovable.
Rosser showed in 1936 that plain consistency is enough for incompleteness, with a different sentence.
The notion of $1$-consistency, the restriction to $\Sigma_1$ statements, appears in later work on reflection principles.

### Common errors

1. A student thinks that $\omega$-consistency follows from consistency. The theory $\mathsf{PA} + \neg \mathrm{Con}(\mathsf{PA})$ is consistent and $\omega$-inconsistent.
2. A student thinks that an $\omega$-inconsistent theory proves a contradiction. It proves infinitely many sentences that together have no model with only standard numbers, but no single contradiction.
3. A student reads $\omega$-consistency as a semantic notion. It is defined by provability alone, although truth in $\N$ implies it.

## Explanations

### L1 human

A theory is $\omega$-inconsistent if it claims "there is a number with this property" but rules out $0$, $1$, $2$ and every other number one at a time.
This is strange but not a contradiction, since a proof can only use finitely many of the claims.
A model of such a theory must contain extra numbers beyond $0, 1, 2, \ldots$.
$\omega$-consistency forbids this behaviour.

### L2 human

1. Let $T := \mathsf{Q} + \exists x \, \neg (0 + x = x)$.
2. For each $n$, $\mathsf{Q}$ proves $0 + \underline{n} = \underline{n}$, by $n$ uses of axioms 4 and 5.
3. So $T$ refutes $\neg (0 + \underline{n} = \underline{n})$ for every $n$ and proves $\exists x \, \neg (0 + x = x)$.
4. So $T$ is $\omega$-inconsistent, although it has a model with two non-standard elements.

The typical use is the hypothesis of Gödel's form of the first incompleteness theorem.
A trap: the formula $\varphi$ has one free variable, and the $\omega$-rule asks for the numerals, not for all closed terms.

### L3 human

$\omega$-consistency says that $T$ is consistent with the $\omega$-rule: from $\varphi(\underline{n})$ for all $n$, infer $\forall x \, \varphi(x)$.
Restrictions to formulas of bounded complexity give a hierarchy of $n$-consistency notions between $1$-consistency and $\omega$-consistency, and they are related to uniform [[reflection principles|NB485KFXKV]].
In model theory, an $\omega$-consistent theory need not have a standard model; $\omega$-consistency is weaker than having $\N$ as a model.
