## Summary

The theory $\mathsf{PA} + \neg \mathrm{Con}(\mathsf{PA})$ proves "some number codes a proof of $0 = 1$", and it also proves "$0$ is not such a code", "$1$ is not such a code", and so on for every single number.
It never proves a contradiction, but it is plainly wrong about the numbers.
$\omega$-consistency is the condition that rules out this behavior.

Exactly, let $T$ be a [[theory|92SWXST1ZM]] in the language of arithmetic, with [[numerals|VK6WWSDMXK]] $\underline{n}$.
$T$ is $\omega$-inconsistent when there is a formula $\varphi(x)$ with one free variable such that
$$T \vdash \exists x \, \varphi(x) \quad \text{and} \quad T \vdash \neg \varphi(\underline{n}) \text{ for every } n \in \mathbb{N}.$$
$T$ is $\omega$-consistent when it is not $\omega$-inconsistent.
$T$ is $1$-consistent when no formula $\varphi(x)$ with only bounded quantifiers witnesses $\omega$-inconsistency.

## Motivation

Gödel's first incompleteness theorem has two halves.
The first half, "$T$ does not prove the Gödel sentence $G$", needs only consistency.
The second half, "$T$ does not prove $\neg G$", is harder, because $\neg G$ says "some number codes a proof of $G$", and a consistent theory might claim that without any real proof existing.
Gödel needed a hypothesis that forbids such empty existence claims.
Truth in $\mathbb{N}$ would do, but Gödel wanted a purely syntactic condition, defined by provability alone, and $\omega$-consistency is that condition.

Rosser later found a different sentence for which plain consistency suffices, so $\omega$-consistency is no longer needed for incompleteness.
It remains the natural hypothesis whenever a theory must not prove false existential statements, and it returns in the study of [[reflection principles|NB485KFXKV]].

## Notation

The letter $\omega$ denotes the set of natural numbers, and the prefix refers to the infinitely many instances $\varphi(\underline{0}), \varphi(\underline{1}), \ldots$.
$1$-consistency is also called $\Sigma_1$-soundness, for the reason given below.
Some books state the condition with $\forall$: no $\varphi$ has $T \vdash \varphi(\underline{n})$ for every $n$ together with $T \vdash \neg \forall x \, \varphi(x)$.
Replacing $\varphi$ by $\neg \varphi$ shows that this is the same notion.

## Remarks

### Theories that pass

[[Peano arithmetic is ω-consistent|5JKPMRAXZP]], because all its axioms are true in $\mathbb{N}$.
The argument is short.
If $T$ is true in $\mathbb{N}$ and $T \vdash \exists x \, \varphi(x)$, then some number $m$ satisfies $\varphi$ in $\mathbb{N}$.
So $\neg \varphi(\underline{m})$ is false, and $T$ cannot prove it.
The same argument covers [[Robinson arithmetic|3K1AKGXF8A]] $\mathsf{Q}$, true arithmetic, and [[PA + Con(PA)|RD3VPJH67B]], whose extra axiom is true.

### Theories that fail

[[PA + ¬Con(PA) is consistent but ω-inconsistent|FK06QR6A44]]: the formula "$y$ codes a proof of $0 = S0$" has a proved existential and a refuted instance at every numeral.
A smaller case is $\mathsf{Q} + \exists x \, \neg (0 + x = x)$.
It is consistent, since $\mathsf{Q}$ has a model with an element $a$ such that $0 + a \ne a$.
But $\mathsf{Q}$ proves $0 + \underline{n} = \underline{n}$ for each $n$, so the formula $\neg (0 + x = x)$ witnesses $\omega$-inconsistency.
An inconsistent theory also fails, since it proves $\exists x \, (x = x)$ and every $\neg (\underline{n} = \underline{n})$.

### How the notions are ordered

Truth in $\mathbb{N}$ implies $\omega$-consistency, by the argument above.
$\omega$-consistency implies $1$-consistency, because $1$-consistency asks the same thing for fewer formulas.
$1$-consistency implies consistency, because an inconsistent theory proves $\exists x \, (x = x)$ and refutes each $\underline{n} = \underline{n}$, and $x = x$ has no quantifiers.
The last arrow cannot be reversed: $\mathsf{PA} + \neg \mathrm{Con}(\mathsf{PA})$ is consistent but not $1$-consistent.
A subtheory in the same language keeps $\omega$-consistency, since it proves fewer sentences.

### Why it is called $\Sigma_1$-soundness

For $T \supseteq \mathsf{Q}$, $1$-consistency says that every $\Sigma_1$ sentence $\exists x \, \delta(x)$ that $T$ proves, with $\delta$ bounded, is true in $\mathbb{N}$.
Suppose $T$ proves such a sentence and it is false.
Then each $\delta(\underline{n})$ is a false bounded sentence, $\mathsf{Q}$ refutes it, and $\delta$ witnesses that $T$ is not $1$-consistent.
Conversely, a witness $\delta$ of $1$-inconsistency gives the provable sentence $\exists x \, \delta(x)$, which is false, since a true instance $\delta(\underline{m})$ would be proved by $\mathsf{Q}$ and $T$ would be inconsistent.

### Watch out

Consistency does not give $\omega$-consistency, and $\mathsf{PA} + \neg \mathrm{Con}(\mathsf{PA})$ is the standard counterexample.
An $\omega$-inconsistent theory need not prove a contradiction.
It proves infinitely many sentences that no model with only standard numbers satisfies, but each finite proof uses finitely many of them.
Last, $\omega$-consistency is defined by provability alone, even though truth in $\mathbb{N}$ implies it.

### History

Gödel introduced $\omega$-consistency in his 1931 paper, as the hypothesis under which the negation of his sentence is unprovable.
Rosser showed in 1936 that plain consistency is enough for incompleteness, with a different sentence.

### Try it

Let $T$ be $\omega$-consistent, computably axiomatized and contain $\mathsf{Q}$, and let $G$ be its Gödel sentence.
Is $T + \neg G$ $\omega$-consistent?
No: it proves $\exists y \, \mathrm{Prf}_T(y, \ulcorner G \urcorner)$, while $\mathsf{Q}$ refutes $\mathrm{Prf}_T(\underline{n}, \ulcorner G \urcorner)$ for each $n$, because $G$ has no proof in $T$.

## Explanations

### L1 human

A theory is $\omega$-inconsistent if it claims "there is a number with this property" but rules out $0$, $1$, $2$ and every other number, one at a time.
This is strange but not a contradiction, because a proof can only use finitely many of the claims.
A model of such a theory must contain extra numbers beyond $0, 1, 2, \ldots$, and the claimed number is one of them.
$\omega$-consistency forbids this behavior.

### L2 human

We check the case $T := \mathsf{Q} + \exists x \, \neg (0 + x = x)$ in detail.
For each $n$, $\mathsf{Q}$ proves $0 + \underline{n} = \underline{n}$ by induction on $n$ outside the theory.
The base is $0 + 0 = 0$, from the axiom $x + 0 = x$.
The step uses $0 + S \underline{n} = S(0 + \underline{n})$ and the previous case:
$$0 + \underline{n+1} = S(0 + \underline{n}) = S \underline{n} = \underline{n+1}.$$
So $T$ refutes $\neg (0 + \underline{n} = \underline{n})$ for every $n$, and also proves $\exists x \, \neg (0 + x = x)$.
This is the pattern of every $\omega$-inconsistency: each numeral is excluded by its own proof, but no single proof excludes them all.

### L3 human

The $\omega$-rule infers $\forall x \, \varphi(x)$ from the infinitely many premises $\varphi(\underline{n})$.
An $\omega$-consistent theory never refutes a conclusion of one application of this rule to its own theorems.
Restricting the formulas to $\Sigma_n$ gives the notions of $n$-consistency between $1$-consistency and $\omega$-consistency, and these are tied to the uniform [[reflection principles|NB485KFXKV]].
Truth in $\mathbb{N}$ implies all of these conditions, so they can be read as syntactic fragments of soundness, each strong enough for a particular argument.
