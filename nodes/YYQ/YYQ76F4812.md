## Proof

We read each hydra as an ordinal term with Buchholz's collapsing functions, cite the lemma that every rule lowers the term, and conclude by well-ordering.
This is an outline: the ordinal part needs the theory of the functions $\psi_\nu$, and we cite three lemmas without proof.
We use the rules 1 to 4 of the [[Buchholz hydra|9APRFM0G7F]].

### The hydras with labels 0 only

1. If every node other than the root has the label $0$, only rules 1 and 2 apply.
2. These are the rules of the [[Kirby-Paris hydra|C028FF4TWM]], with $n$ copies at step $n$.
3. So the [[proof by ordinal assignment|EDZN6B9AWQ]] below $\varepsilon_0$ proves part 1 for these hydras in full.

### The ordinal of a general hydra

1. Buchholz's functions $\psi_\nu$, for $\nu \le \omega$, map ordinals to ordinals below $\Omega_{\nu+1}$, with $\psi_0(0) = 1$ and $\psi_\nu(0) = \Omega_\nu$ for $\nu > 0$.
   Here $\Omega_\nu = \aleph_\nu$ for $\nu > 0$.
2. A node with label $\nu$ and children of values $\alpha_1, \dots, \alpha_j$ gets the value $\psi_\nu(\alpha_1 + \cdots + \alpha_j)$.
   The root gets the sum $\alpha_1 + \cdots + \alpha_j$.
3. For example, $+(0)$ has the value $\psi_0(0) = 1$, and $+(0(0))$ has the value $\psi_0(1) = \omega$.
   The hydra $+(0(1))$ has the value $\psi_0(\Omega_1) = \varepsilon_0$.
4. Every hydra has a value below the [[Takeuti-Feferman-Buchholz ordinal|S5FTQGHVKC]] $\psi_0(\varepsilon_{\Omega_\omega + 1})$.
   The values of the paths $R_x$ are $\psi_0(\psi_\omega(\psi_\omega(\cdots)))$, and they tend to this ordinal.

### Part 1: termination

1. **Cited lemma 1** (Buchholz 1987).
   Read with suitable normal forms, the value of a hydra strictly decreases at every step, for every choice of the head and of $n$.
2. The lemma checks each rule.
   Rule 4 replaces $\psi_\omega$ by $\psi_{n+1}$, rule 3 moves to an element of a fundamental sequence, and rule 2 is the step of the Kirby-Paris hydra.
3. Suppose that a battle never ends.
   Then its values form an infinite strictly decreasing sequence of ordinals, by lemma 1.
4. This contradicts the [[well-ordering|0F1D6PK9RZ]] of the ordinals, so every battle ends, which is part 1.

### Part 3: a proof in ZFC

1. The functions $\psi_\nu$ and the cardinals $\aleph_\nu$ are defined in $\mathsf{ZFC}$.
2. The ordinals are well-ordered in $\mathsf{ZFC}$.
   With lemma 1, the argument of part 1 is therefore a proof in $\mathsf{ZFC}$.

### Part 2: unprovability in the subsystem

1. We code the terms built from $0$, $+$ and $\psi_\nu$ with $\nu \le \omega$ by numbers.
   Their order is decidable, and on the terms in normal form it is a well-order of type $\psi_0(\varepsilon_{\Omega_\omega + 1})$.
2. **Cited lemma 2** (Buchholz 1987).
   The rules of the game follow the fundamental sequences of these terms.
   From this, $(\Pi^1_1\text{-}\mathsf{CA}) + \mathsf{BI}$ plus statement 1 proves [[transfinite induction|0ZHQMQ2C1N]] along the whole notation system.
3. **Cited lemma 3** (ordinal analysis).
   The [[proof-theoretic ordinal|C72RBH0CDR]] of $(\Pi^1_1\text{-}\mathsf{CA}) + \mathsf{BI}$ is $\psi_0(\varepsilon_{\Omega_\omega + 1})$, so this system does not prove transfinite induction along the whole notation system.
4. Suppose that $(\Pi^1_1\text{-}\mathsf{CA}) + \mathsf{BI}$ proves statement 1.
   Then lemma 2 gives a proof of transfinite induction along the whole notation system.
5. This contradicts lemma 3, so the system does not prove statement 1, which is part 2.

## Idea

Each hydra is the tree of an ordinal term, built from the collapsing functions $\psi_\nu$, and each rule of the game moves to a smaller term.
A label $\omega$ that becomes $n + 1$ is a jump down from $\Omega_\omega$ to $\Omega_{n+1}$, and a label $u$ that becomes $u - 1$ with a copied subtree is a step down a fundamental sequence.
The terms are well-ordered, so every battle ends.
Their order type is the proof-theoretic ordinal of $(\Pi^1_1\text{-}\mathsf{CA}) + \mathsf{BI}$, and a theory cannot prove the well-foundedness of its own ordinal, so the system cannot prove the theorem.

## Variants

Hamano and Okada gave a direct independence proof for the game on finite labeled trees.
With ordinals below $\varepsilon_0$ in place of the collapsing functions, the same scheme is the [[proof for the Kirby-Paris hydra|EDZN6B9AWQ]].
