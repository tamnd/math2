## Summary

A linear matrix inequality asks that a symmetric matrix depending affinely on some real unknowns be [[positive semidefinite|01MMVW8CKC]].
Its set of solutions is a [[convex set|02AS45T3H9]], so feasibility and optimization over it are convex problems that semidefinite programming solves efficiently.
In control theory many stability and performance questions, such as the existence of a quadratic [[Lyapunov function|01REYCJ371]], reduce to linear matrix inequalities.

## Explanations

### L1 human

An ordinary linear inequality says that one number, built linearly from the unknowns, is nonnegative.
A linear matrix inequality says the same for a whole symmetric matrix: the matrix built linearly from the unknowns must have no negative eigenvalue.
It packs infinitely many scalar inequalities into one condition, one for each direction $v$ in the form $v^T F v \ge 0$.
For example, the matrix $\begin{pmatrix} x & 1 \\ 1 & y \end{pmatrix}$ is positive semidefinite exactly when $x \ge 0$, $y \ge 0$ and $xy \ge 1$.
That region of the plane is convex, as for every linear matrix inequality.
