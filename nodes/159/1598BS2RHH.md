## Example

Take sequences of numbers, $\rho = \tau = 0$, and the [[bar recursion|8CCG6F2FAT]] with these data:

- $Y(\alpha) = \alpha(0)$;
- $G(s) = 0$ for every $s$;
- $H(s, f) = f(0) + 1$.

So $\Phi(s) = 0$ if $Y(\hat s) < |s|$, and $\Phi(s) = \Phi(s * 0) + 1$ otherwise.
We compute $\Phi$.

1. For $s = \langle \rangle$: $\hat s$ is the zero sequence, so $Y(\hat s) = 0$, and $0 < 0$ fails. So $\Phi(\langle \rangle) = \Phi(\langle 0 \rangle) + 1$.
2. For $s$ of length $k \ge 1$ with first entry $x$: $\hat s(0) = x$, so the recursion stops exactly when $x < k$.
3. For $s = \langle 0 \rangle$: $0 < 1$, so $\Phi(\langle 0 \rangle) = 0$, and step 1 gives $\Phi(\langle \rangle) = 1$.
4. For $s = \langle 3 \rangle$: the condition $3 < k$ fails for $k = 1, 2, 3$, so the recursion visits $\langle 3 \rangle$, $\langle 3, 0 \rangle$ and $\langle 3, 0, 0 \rangle$.
5. At $\langle 3, 0, 0, 0 \rangle$ the condition $3 < 4$ holds, so $\Phi$ is $0$ there.
6. Going back, $\Phi(\langle 3, 0, 0 \rangle) = 1$, $\Phi(\langle 3, 0 \rangle) = 2$ and $\Phi(\langle 3 \rangle) = 3$.
7. In general, by induction on $x - k$, the recursion from $\langle x \rangle$ stops at length $x + 1$, and $\Phi(\langle x \rangle) = x$.

## Remarks

The depth of the recursion from $\langle x \rangle$ is $x + 1$, so the depths have no common bound.
Along each single path the recursion stops, because $Y$ reads only one entry.
In this example $\Phi$ is also definable by [[primitive recursion|5NVA2JRHPV]], because the depth is computed from $x$ in advance.
In the applications, $Y$ is a variable of type 2, and the depth cannot be computed in advance from the data.

## Explanations

### L1 human

The judge $Y$ looks only at the first entry $x$ of the list.
The recursion keeps adding zeros until the list is longer than $x$.
A list that starts with $3$ needs $4$ entries; a list that starts with $1000$ needs $1001$ entries.
So each list stops, but no single number of steps works for all lists.

### L2 human

We compute $\Phi(\langle 1 \rangle)$ and $\Phi(\langle 2 \rangle)$.

1. $\langle 1 \rangle$: $1 < 1$ fails, so $\Phi(\langle 1 \rangle) = \Phi(\langle 1, 0 \rangle) + 1$.
2. $\langle 1, 0 \rangle$: $1 < 2$ holds, so $\Phi(\langle 1, 0 \rangle) = 0$ and $\Phi(\langle 1 \rangle) = 1$.
3. $\langle 2 \rangle$ and $\langle 2, 0 \rangle$ fail the condition, and $\langle 2, 0, 0 \rangle$ meets it, so $\Phi(\langle 2 \rangle) = 2$.

The typical use is to see that bar recursion is well-founded but not bounded.
A trap is step 1: the empty sequence does not stop, since its zero extension gives $Y = 0$ and $0 < 0$ fails.
