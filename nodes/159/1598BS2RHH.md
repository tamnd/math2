## Example

Take sequences of numbers, so $\rho = \tau = \mathbb{N}$, and take the [[bar recursion|8CCG6F2FAT]] with $Y(\alpha) = \alpha(0)$, $G(s) = 0$ for every $s$, and $H(s, f) = f(0) + 1$.
So $\Phi(s) = 0$ if $Y(\hat s) < \lvert s \rvert$, and $\Phi(s) = \Phi(s * 0) + 1$ otherwise.
We compute $\Phi$.

1. For $s = \langle \rangle$ the extension $\hat s$ is the zero sequence, so $Y(\hat s) = 0$, and $0 < 0$ fails.
   So $\Phi(\langle \rangle) = \Phi(\langle 0 \rangle) + 1$.
2. For $s$ of length $k \ge 1$ with first entry $x$ we have $\hat s(0) = x$, so the recursion stops exactly when $x < k$.
3. For $s = \langle 0 \rangle$ the test $0 < 1$ holds, so $\Phi(\langle 0 \rangle) = 0$, and step 1 gives $\Phi(\langle \rangle) = 1$.
4. For $s = \langle 3 \rangle$ the condition $3 < k$ fails for $k = 1, 2, 3$, so the recursion visits $\langle 3 \rangle$, $\langle 3, 0 \rangle$ and $\langle 3, 0, 0 \rangle$.
5. At $\langle 3, 0, 0, 0 \rangle$ the condition $3 < 4$ holds, so $\Phi$ is $0$ there.
6. Going back, $\Phi(\langle 3, 0, 0 \rangle) = 1$, $\Phi(\langle 3, 0 \rangle) = 2$ and $\Phi(\langle 3 \rangle) = 3$.
7. In general, by induction on $x + 1 - k$, a sequence of length $k \le x + 1$ that starts with $x$ and continues with zeros has $\Phi$ value $x + 1 - k$.
   For $k = 1$ this gives $\Phi(\langle x \rangle) = x$, and the recursion from $\langle x \rangle$ stops at length $x + 1$.

## Remarks

The recursion from $\langle x \rangle$ visits $x + 1$ sequences, so the depths have no common bound.
Along each single path the recursion stops, because $Y$ reads only one entry.

In this example $\Phi$ is also definable by [[primitive recursion|5NVA2JRHPV]], because the depth is computed from $x$ in advance.
In the applications $Y$ is a variable of type $(\mathbb{N} \to \mathbb{N}) \to \mathbb{N}$, and the depth cannot be computed in advance from the data.

## Explanations

### L1 human

The judge $Y$ looks only at the first entry $x$ of the list.
The recursion keeps adding zeros until the list is longer than $x$.
A list that starts with $3$ needs $4$ entries, and a list that starts with $1000$ needs $1001$ entries.
So each list stops, but no single number of steps works for all lists.

### L2 human

We compute $\Phi(\langle 1 \rangle)$ and $\Phi(\langle 2 \rangle)$.
At $\langle 1 \rangle$ the test $1 < 1$ fails, so $\Phi(\langle 1 \rangle) = \Phi(\langle 1, 0 \rangle) + 1$.
At $\langle 1, 0 \rangle$ the test $1 < 2$ holds, so $\Phi(\langle 1, 0 \rangle) = 0$ and $\Phi(\langle 1 \rangle) = 1$.
The sequences $\langle 2 \rangle$ and $\langle 2, 0 \rangle$ fail the test, and $\langle 2, 0, 0 \rangle$ meets it, so $\Phi(\langle 2 \rangle) = 2$.

The typical use is to see that bar recursion is well-founded but not bounded.
Watch out for step 1: the empty sequence does not stop, since its zero extension gives $Y = 0$ and $0 < 0$ fails.
