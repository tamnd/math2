## Proof

Let $G$ be a [[group|G5S1M9]] of order $p$, where $p$ is a [[prime number|0SN0MAEKYX]], and let $e$ be its identity.

Part 1.

1. Let $g \in G$ with $g \neq e$. Such an element exists, because $p \geq 2$.
2. By the [[theorem on element orders|08V7JHS3QZ]], the order of $g$ divides $p$. The only positive divisors of $p$ are $1$ and $p$.
3. Only the identity has order $1$, because $g^1 = g$. Since $g \neq e$, the order of $g$ is $p$.
4. So the [[cyclic subgroup|08ABT85339]] $\langle g \rangle$ has $p$ elements.
5. The set $\langle g \rangle$ is a subset of $G$ with as many elements as the finite set $G$. So $\langle g \rangle = G$.
6. Thus $g$ generates $G$, and $G$ is [[cyclic|0B85Q41RP6]].

Part 2.

7. Let $H$ be a subgroup of $G$. By [[Lagrange's theorem|3C53TD]], $|H|$ divides $p$, so $|H| = 1$ or $|H| = p$.
8. If $|H| = 1$, then $H = \{e\}$, because each subgroup contains $e$.
9. If $|H| = p$, then $H = G$, by the same argument as in step 5.
10. So the only [[normal subgroups|0CB0DX5BVV]] of $G$ are $\{e\}$ and $G$, because a normal subgroup is a subgroup.
11. The group $G$ is nontrivial, since $p \geq 2$. Thus $G$ is [[simple|0YMYMNQ0QZ]].

## Idea

A prime has only two positive divisors.
By Lagrange's theorem, each subgroup has order $1$ or $p$, and so it is trivial or the whole group.
The subgroup generated by an element other than $e$ is not trivial, so it is the whole group.

## Variants

Part 1 also follows from part 2: for $g \neq e$, the subgroup $\langle g \rangle$ is not $\{e\}$, so it is $G$.
Another proof uses [[Cauchy's theorem|0JM7PA288B]]: $G$ has an element of order $p$, and it generates $G$.
This uses a harder theorem than needed.
