## Summary

The typical set of a source is the set of sequences of length $n$ whose probability is close to $2^{-nH}$.
Here $H$ is the [[Shannon entropy|Y86E072V0V]] of the source.
By the [[asymptotic equipartition property|5P7AA5QR7T]], it has probability close to $1$ for large $n$, and it has about $2^{nH}$ elements.
It is usually a tiny part of all sequences, and coding only its elements gives optimal compression.
Typical sets are the main tool in the proofs of Shannon's coding theorems.

## Explanations

### L1 human

Toss a coin that lands heads with probability $0.9$ a thousand times.
The single most likely result is all heads, but you will almost never see it.
What you will see is a sequence with about $900$ heads, and there are many such sequences, each with about the same probability.
These sequences form the typical set.
There are far fewer of them than the $2^{1000}$ possible sequences, about $2^{469}$, so they can be numbered with about $469$ bits.
