## Summary

A Hopfield network is a recurrent network of binary threshold units with symmetric connections.
John Hopfield showed in 1982 that it has an energy function that never increases under asynchronous updates.
So every run ends in a stable state, and stored patterns can be made stable states, which makes the network a model of associative memory.
It links neural networks with the statistical mechanics of spin systems such as the [[Ising model|R0KGM32QN6]].

## Explanations

### L1 human

Picture a group of switches, each on or off, joined by wires of different strengths.
Each switch looks at its neighbours and flips to agree with the weighted vote it receives.
Because the wires work the same in both directions, the flips always go downhill on an energy landscape, and the network settles in a valley.
If the wires are set so that a stored picture sits at the bottom of a valley, then a noisy version of the picture slides down to the clean one.
This is how the network "remembers" a pattern from a partial cue.
