## Statement

Let $N \subseteq M$ be a [[subfactor|9RWS7TZHXH]] of type $\mathrm{II}_1$ factors with Jones index $[M:N] < \infty$.
Then
$$[M : N] \in \set{4 \cos^2(\pi / n) : n = 3, 4, 5, \dots} \cup [4, \infty).$$
Conversely, every number in this set is the index of a subfactor of the [[hyperfinite type II1 factor|NZ4NY8SK1C]] $R$.

## Remarks

The proof uses the basic construction: $M$ acts on $L^2(M)$, and adding the orthogonal projection $e_N$ onto $L^2(N)$ gives a larger factor $M_1 = \langle M, e_N \rangle$ with $[M_1 : M] = [M : N]$.
Iterating gives a tower $N \subseteq M \subseteq M_1 \subseteq M_2 \subseteq \cdots$ with projections $e_1, e_2, \dots$ that satisfy $e_i e_{i \pm 1} e_i = \lambda e_i$ with $\lambda = [M:N]^{-1}$ and $e_i e_j = e_j e_i$ for $\abs{i - j} \ge 2$.
The trace restricted to the algebras generated by $e_1, \dots, e_k$ must be positive, and this forces $\lambda^{-1}$ into the set above.
For the values below $4$, the construction of the converse uses these same projections inside $R$.

The first allowed values are $1$, $2$, $(3 + \sqrt 5)/2 \approx 2.618$ and $3$, for $n = 3, 4, 5, 6$.
So no subfactor has index strictly between $1$ and $2$, although the index need not be an integer.

## Explanations

### L1 human

The index of a subfactor measures how much bigger the large algebra is than the small one.
One might expect any number at least $1$ to be possible.
Jones found that below $4$ only a discrete list of values $4\cos^2(\pi/n)$ can occur, while every number from $4$ on can occur.

### L2 human

The relations among the projections $e_i$ are those of the Temperley–Lieb algebra.
Jones used representations of the braid group built from them to discover the Jones polynomial of knots.
Finer invariants of a subfactor, such as its principal graph and its standard invariant, lead to the classification of subfactors of small index.
For the fixed points $M^G$ of an outer action of a finite group $G$ on $M$, one has $[M : M^G] = \abs{G}$, so the index generalizes the index of a subgroup.
