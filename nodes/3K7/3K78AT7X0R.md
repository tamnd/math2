## Example

Claim: for every positive integer $n$, $2^n > n^2$.
A student checks the claim for $n = 1, 5, 6, 7$ and concludes that it is true for all $n$.
This is not a [[proof of a universal statement|CX38X989TB]].
We check the values.

| $n$ | $2^n$ | $n^2$ | $2^n > n^2$ |
|---|---|---|---|
| 1 | 2 | 1 | true |
| 2 | 4 | 4 | false |
| 3 | 8 | 9 | false |
| 4 | 16 | 16 | false |
| 5 | 32 | 25 | true |
| 6 | 64 | 36 | true |
| 7 | 128 | 49 | true |

1. The student's checks for $n = 1, 5, 6, 7$ are correct.
2. The checks do not use an arbitrary $n$. They are four separate facts about four numbers.
3. The claim is false for $n = 2$, since $2^n = 4$ and $n^2 = 4$ there, and $4 > 4$ is false. So $n = 2$ is a [[counterexample|0ED72CTBNP]].
4. The claim is also false for $n = 3$ ($8 < 9$) and $n = 4$ ($16 = 16$).

## Remarks

The true statement is: for every integer $n \geq 5$, $2^n > n^2$.
It has a proof by [[mathematical induction|0ASJVEFA9J]], and a generic argument alone does not give it.
The base case is $32 > 25$.
For the step, assume $2^n > n^2$ with $n \geq 5$.
Then $2^{n+1} = 2 \cdot 2^n > 2n^2$, and $2n^2 \geq (n + 1)^2$ because $n^2 - 2n - 1 = (n - 1)^2 - 2 \geq 14 > 0$ for $n \geq 5$.

The example shows two lessons.
Checks that happen to avoid the bad values can make a false claim look true.
And a true universal statement can need a hypothesis, here $n \geq 5$, that a few checks do not reveal.

## Explanations

### L1 human

Doubling grows fast: $2, 4, 8, 16, 32, 64, \ldots$
Squares grow more slowly at first: $1, 4, 9, 16, 25, 36, \ldots$
From the fifth term on, the doubling sequence is ahead.
But at the second, third and fourth terms it is not ahead: $4$ against $4$, $8$ against $9$, $16$ against $16$.
A person who checks only the first term and some large terms will miss this.

### L2 human

We find the exact set of positive integers $n$ with $2^n > n^2$.

1. Compute the table for $n = 1$ to $7$, as above.
2. The claim holds for $n = 1$ and fails for $n = 2, 3, 4$.
3. It holds for $n = 5$, and the induction in the remarks shows that it holds for each $n \geq 5$.
4. So the set is $\{1\} \cup \{n : n \geq 5\}$.

The typical use of such a table is to form a correct conjecture, which a proof must then confirm.

A trap: the student may "fix" the claim to "for all $n \geq 3$" after seeing $n = 2$ fail.
The value $n = 3$ is also a counterexample, so each new conjecture needs its own check and its own proof.
