## Summary

Let $V$ be a [[vector space|000AYPA9AJ]] over a field $F$.
A linear combination of vectors $v_1, \dots, v_k \in V$ is a vector $a_1 v_1 + \cdots + a_k v_k$ with scalars $a_1, \dots, a_k \in F$.
The precise form, also for infinite families, is in the [[definition|0JB3DP1BMF]].
Linear combinations are the only expressions that the two operations of a vector space can build, so they underlie span, independence, bases and coordinates.

## Motivation

In a vector space we can only add vectors and scale them.
Every expression that we build from given vectors with these operations reduces to one linear combination, by the axioms.
A linear system $Ax = b$ asks whether $b$ is a linear combination of the columns of $A$; see [[linear systems as vector equations|E7SAHXQEVC]].

## Notation

We write $\sum_{i=1}^k a_i v_i$, or $\sum_{i \in I} a_i v_i$ for a family with only finitely many nonzero $a_i$.
The scalars $a_i$ are the *coefficients*.
The *trivial* linear combination has all coefficients $0$, and its value is $0$.

## Remarks

### Examples

1. In $\R^2$: $(7, 2) = 3(1, 1) + 2(2, -1/2)$. Check: $3(1, 1) = (3, 3)$ and $2(2, -1/2) = (4, -1)$, so the sum is $(7, 2)$.
2. In $\R^2$: $(7, 2) = 7 e_1 + 2 e_2$, with $e_1 = (1, 0)$ and $e_2 = (0, 1)$.
3. In $P_2(\R)$: $3 - x + 4x^2 = 3 \cdot 1 + (-1) \cdot x + 4 \cdot x^2$.
4. The system $x_1 + 2x_2 = 5$, $3x_1 + 4x_2 = 6$ asks for $x_1, x_2$ with $x_1 (1, 3) + x_2 (2, 4) = (5, 6)$. The solution $x_1 = -4$, $x_2 = 9/2$ gives $(-4 + 9, -12 + 18) = (5, 6)$.
5. The empty linear combination, with $k = 0$, has value $0$.

### Non-examples

1. The vector $(1, 2, 3) \in \R^3$ is not a linear combination of $e_1 = (1, 0, 0)$ and $e_2 = (0, 1, 0)$: each $a e_1 + b e_2 = (a, b, 0)$ has third entry $0$, not $3$.
2. In $F[x]$, the expression $1 + x + x^2 + \cdots$ is not a linear combination of the monomials.
   It has infinitely many nonzero coefficients, and a linear combination must be a finite sum.
3. A product such as $v_1 v_2$ of two vectors is not a linear combination; a vector space has no multiplication of vectors.

### Basic properties

1. A linear combination of linear combinations of $v_1, \dots, v_k$ is again a linear combination of $v_1, \dots, v_k$, by the distributive and associative axioms.
2. The set of all linear combinations of a set $S$ is its [[span|0DTY8B9HMS]], the smallest subspace that contains $S$.
3. A subset $W$ is a [[subspace|00YC1D652K]] if and only if it is nonempty and contains each linear combination of its vectors.
4. The [[matrix-vector product|0PDVQEP0ZC]] $Ax$ is the linear combination of the columns of $A$ with the entries of $x$ as coefficients.
5. A linear combination with coefficient sum $1$ is an [[affine combination|0KJH6SRFZK]]; one with nonnegative coefficients of sum $1$ is a [[convex combination|21SXYJYC59]].

### History

Grassmann used linear combinations of his "extensive quantities" in 1844, together with the notion of linear dependence.
The phrase "linear combination" became standard in the twentieth century.

### Common errors

1. A linear combination is always a finite sum; infinite sums need a topology and belong to analysis.
2. The coefficients come from the field $F$.
   The vector $(1, \sqrt2) \in \R^2$ is a real combination of $(1, 0)$ and $(1, 1)$, but not a rational one, because $\sqrt2$ is [[irrational|0DZGSDHD92]].
3. Different coefficient lists can give the same vector when the vectors are dependent: $2(1, 0) + 0(2, 0) = 0(1, 0) + 1(2, 0)$.

## Explanations

### L1 human

A linear combination mixes some vectors: scale each one by a number, then add the results.
With the vectors $(1, 0)$ and $(0, 1)$ we can make every vector of the plane in this way.
Infinite sums are not allowed: only finitely many coefficients can be nonzero.

### L2 human

To decide whether $b$ is a linear combination of $v_1, \dots, v_k$ in $F^m$, put the $v_i$ as columns of a matrix $A$.
Then solve $Ax = b$ by [[Gaussian elimination|0JVJ2WCXZH]].
A solution $x$ gives the coefficients, and an inconsistent system shows that $b$ is not a combination.
Example: is $(1, 2, 3)$ a combination of $(1, 0, 1)$ and $(0, 1, 1)$?
The equations are $x_1 = 1$, $x_2 = 2$ and $x_1 + x_2 = 3$, and $x_1 = 1$, $x_2 = 2$ solves all three.
So $(1, 2, 3) = (1, 0, 1) + 2(0, 1, 1)$.

### L3 human

A family $(v_i)_{i \in I}$ in $V$ gives a linear map $F^{(I)} \to V$ that sends a finitely supported $a$ to $\sum_i a_i v_i$.
Its image is the span, and it is injective exactly when the family is independent.
In Mathlib, this map is `Finsupp.linearCombination`.
