## Definition

Let $S \subseteq \R^n$ be a closed set whose [[interior|0RZH6W98HK]] $\operatorname{int} S$ is nonempty.
A *barrier function* for $S$ is a function $B \colon \operatorname{int} S \to \R$ such that:

1. $B$ is [[continuous|0X3WGX95FE]] on $\operatorname{int} S$;
2. $B(x_k) \to +\infty$ for every sequence $(x_k)$ in $\operatorname{int} S$ that converges to a point of the [[boundary|05D5EGMFYV]] of $S$.

## Remarks

Example: let $S = \set{x \in \R^n : g_i(x) \le 0 \text{ for } i = 1, \dots, m}$, where each $g_i \colon \R^n \to \R$ is continuous and $\operatorname{int} S = \set{x : g_i(x) < 0 \text{ for all } i}$.
The *logarithmic barrier* $B(x) = -\sum_{i=1}^m \ln(-g_i(x))$ is continuous on $\operatorname{int} S$.
If $x_k \to \bar x$ with $\bar x$ on the boundary, then $g_i(x_k) \to 0^-$ for some $i$, so $-\ln(-g_i(x_k)) \to +\infty$ while the other terms stay bounded below near $\bar x$; hence $B(x_k) \to +\infty$.
The *inverse barrier* $B(x) = -\sum_{i=1}^m 1/g_i(x)$ works in the same way.

Non-example: for $S = [0, \infty)$, the function $P(x) = \min(0, x)^2$ is continuous, but it equals $0$ on $\operatorname{int} S$ and stays bounded near $0$, so clause 2 fails.
Such a function is a penalty, not a barrier.

In the barrier method one minimises $f(x) + \mu B(x)$ over $\operatorname{int} S$ for a parameter $\mu > 0$ and lets $\mu \to 0$.
