## Definition

A logical matrix is an algebra of truth values for the connectives together with a set of values that count as true, and it defines a consequence relation.

Fix a propositional language with a set $C$ of connectives, each with an arity, and let $\mathrm{Fm}$ be the algebra of [[formulas|TFDYXS3K1N]].
An *algebra of type $C$* is a nonempty set $A$ with an $n$-ary [[operation|EJ8YJVM9BW]] $c^{\mathbf{A}} \colon A^n \to A$ for each $n$-ary connective $c$.

1. A *logical matrix* is a pair $M = \langle \mathbf{A}, D \rangle$ of an algebra $\mathbf{A}$ of type $C$ and a subset $D \subseteq A$, the set of *designated values*.
2. A *valuation* in $M$ is a homomorphism $h \colon \mathrm{Fm} \to \mathbf{A}$, that is, a map with $h(c(\varphi_1, \dots, \varphi_n)) = c^{\mathbf{A}}(h(\varphi_1), \dots, h(\varphi_n))$ for every connective $c$.
3. *Matrix consequence*: $\Gamma \models_M \varphi$ iff every valuation $h$ with $h[\Gamma] \subseteq D$ has $h(\varphi) \in D$.
4. For a class $\mathcal{K}$ of matrices, $\Gamma \models_{\mathcal{K}} \varphi$ iff $\Gamma \models_M \varphi$ for every $M \in \mathcal{K}$.
5. A matrix $M$ is a *model* of a [[consequence relation|J78Y1M4GND]] $\vdash$ when $\Gamma \vdash \varphi$ implies $\Gamma \models_M \varphi$.
6. For a consequence relation $\vdash$ on $\mathrm{Fm}$ and a set $T$ closed under $\vdash$, the matrix $\langle \mathrm{Fm}, T \rangle$ is a *Lindenbaum matrix* of $\vdash$.

## Notation

Some authors require $\emptyset \neq D \neq A$, and call the matrices with $D = \emptyset$ or $D = A$ trivial.
The set of tautologies of $M$ is $\{\varphi : \emptyset \models_M \varphi\}$, also called the content of $M$.
The algebra is often written in bold, $\mathbf{A}$, and its universe in plain type, $A$.

## Remarks

Clause 1 separates the two jobs of a truth table: the algebra computes values, and $D$ says which values are true.
Clause 2 asks for a homomorphism because that is what truth-functionality means: the value of a compound depends only on the values of its parts.
A homomorphism from $\mathrm{Fm}$ is fixed by its values on the variables, since $\mathrm{Fm}$ is freely generated by them, so a valuation is just an assignment of values to variables.
Clause 3 reads "true premises give a true conclusion" with "true" replaced by "designated".

A small example: $\langle \{0, \tfrac12, 1\}, \{1\} \rangle$ with Kleene's operations is the matrix of [[strong Kleene logic|SZHA10A9X7]].
Here $p \land q \models p$ holds, because $\min(x, y) = 1$ forces $x = 1$.
The same algebra with $D = \{\tfrac12, 1\}$ is a different matrix, as [[the comparison with the logic of paradox|BJMXHXJ7QQ]] shows.
A [[Lindenbaum matrix|ZV4GTXRRCV]] is the case where the values are formulas.

A case that fails clause 2 is a probability function on formulas.
It assigns numbers in $[0, 1]$, but it is not a homomorphism into any algebra on $[0, 1]$, as [[the example on probability|EVW7FAWM68]] shows.

Two facts follow at once.
Each $\models_{\mathcal{K}}$ satisfies reflexivity, monotonicity and cut, by the argument for one matrix applied to each member of $\mathcal{K}$.
Each $\models_{\mathcal{K}}$ is structural: if $\sigma$ is a substitution and $h$ a valuation, then $h \circ \sigma$ is a valuation, so $\Gamma \models_M \varphi$ gives $\sigma[\Gamma] \models_M \sigma(\varphi)$.
A *many-valued matrix* in the sense of [[the definition of many-valued logic|66NMTCQNQV]] is a logical matrix with at least three values and $\emptyset \neq D \neq A$.
The [[concept page|P7E926JK13]] gives the uses.

## Explanations

### L1 human

A logical matrix has two parts.
The first part is a set of values with a table for each connective.
The second part is the set of values that count as true.
With these two parts you can compute the value of any formula and decide whether it counts as true.

### L2 human

We check structurality on one instance.
In classical logic $p \models p \lor q$.
Substitute $r \land s$ for $p$ and $\neg r$ for $q$, which gives the inference below.
$$r \land s \models (r \land s) \lor \neg r$$
Any valuation $h$ with $h(r \land s) = 1$ gives $h((r \land s) \lor \neg r) = 1$, since a disjunction with a true disjunct is true.
So the substituted inference is valid too, as the structurality of matrix consequence predicts.
Watch out: because matrix consequence is always structural, a non-structural relation, such as one with a special axiom about one variable, has no matrix semantics.
