## Definition

Let $q$ be a prime power and let $k, n$ be integers with $1 \le k \le n \le q$.
Let $a_1, \dots, a_n$ be distinct elements of the [[finite field|0ZXZ82FTX2]] $\F_q$, the evaluation points.
The *Reed–Solomon code* with these parameters is
$$\mathrm{RS}_k(a_1, \dots, a_n) = \set{(f(a_1), \dots, f(a_n)) : f \in \F_q[x], \ \deg f < k},$$
where the zero polynomial is included.

## Remarks

The code is a [[linear code|E85KREWV60]] of length $n$ and dimension $k$ over $\F_q$, since the evaluation map is linear and injective on polynomials of degree less than $k \le n$.
A nonzero $f$ of degree less than $k$ has at most $k - 1$ roots, so each nonzero codeword has weight at least $n - k + 1$.
With the [[Singleton bound|RAKXDDYNAM]], the [[minimum distance|M2X88AXM17]] is exactly $n - k + 1$.

In the classical case, $n = q - 1$ and $a_j = \alpha^{j}$ for $0 \le j \le n - 1$, where $\alpha$ is a primitive element of $\F_q$.
Then the code is cyclic, and it equals the narrow-sense [[BCH code|YY5ZM93GBY]] of length $q - 1$ over $\F_q$ with designed distance $n - k + 1$.
Its generator polynomial is $(x - \alpha)(x - \alpha^2) \cdots (x - \alpha^{n-k})$.

Example: $q = 5$, $k = 2$ and the points $0, 1, 2, 3, 4$.
The polynomial $f(x) = x$ gives the codeword $(0, 1, 2, 3, 4)$ of weight $4 = n - k + 1$.

Non-example: if the points are not distinct, say $(0, 0, 1, 2)$ over $\F_5$ with $k = 2$, the same formula gives a code whose codeword $(0, 0, 1, 2)$ from $f(x) = x$ has weight $2 < n - k + 1 = 3$.
