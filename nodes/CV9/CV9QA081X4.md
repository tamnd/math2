## Summary

In physics and mathematics, a **random field** is a random function over an arbitrary domain (usually a multi-dimensional space such as $\mathbb{R}^n$). That is, it is a function $f(x)$ that takes on a random value at each point $x \in \mathbb{R}^n$(or some other domain). It is also sometimes thought of as a synonym for a [[stochastic process|0QH5ENKZM1]] with some restriction on its index set. That is, by modern definitions, a random field is a generalization of a [[stochastic process|0QH5ENKZM1]] where the underlying parameter need no longer be real or [[integer|0C4JS9RF5M]] valued "time" but can instead take values that are multidimensional [[vectors|000AYPA9AJ]] or points on some manifold.
