## Summary

A deterministic context-free language is a language accepted by a deterministic [[pushdown automaton|8YEY51Q3B5]], one that never has a choice between moves.
These languages lie strictly between the [[regular languages|18WVBDCS38]] and the [[context-free languages|Q56EWEQYE2]].
They can be parsed in linear time, are generated by unambiguous grammars, and are closed under complement.
Most programming languages are designed so that their syntax is deterministic context-free.

## Explanations

### L1 human

A deterministic pushdown automaton reads the input once, from left to right, and at each moment knows exactly which move to make.
It never has to guess, so it can work fast and without backtracking.
The language of words $w c w^R$, where $w^R$ is $w$ written backwards, is deterministic: the middle marker $c$ tells the machine when to stop pushing and start popping.
Without the marker, as in the even palindromes $w w^R$, the machine would have to guess the middle, and no deterministic machine works.
