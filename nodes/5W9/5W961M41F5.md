## Example

In [[second-order arithmetic|DC60FYCSPM]] a function from $\mathbb{R}$ to $\mathbb{R}$ is not an object, so it is represented by a code, which is a set of numbers.
We recall the standard coding of [[RCA0|XQENB067R3]], and we show that no code represents the [[Heaviside function|09C4JP7Y0M]] $H$, with $H(x) = 1$ for $x > 0$ and $H(x) = 0$ for $x \le 0$.

A *code* is a set $\Phi$ of quadruples $(a, r, b, s)$ of rationals with $r, s > 0$, subject to closure conditions that keep it consistent.
The quadruple $(a, r, b, s) \in \Phi$ says that points at distance less than $r$ from $a$ go to points at distance at most $s$ from $b$.
The coded function $f$ is defined at $x$ if for every $\varepsilon > 0$ some $(a, r, b, s) \in \Phi$ has $\lvert x - a \rvert < r$ and $s < \varepsilon$.
Its value $f(x)$ is the real $y$ with $\lvert y - b \rvert \le s$ for all $(a, r, b, s) \in \Phi$ with $\lvert x - a \rvert < r$.
The argument uses only these two definitions.

1. Let $f$ be coded by $\Phi$ and defined at $x$.
   We show that $f$ is [[continuous|0X3WGX95FE]] at $x$ on its domain.
2. Let $\varepsilon > 0$.
   Since $f$ is defined at $x$, there is $(a, r, b, s) \in \Phi$ with $\lvert x - a \rvert < r$ and $s < \varepsilon / 2$.
3. Put $\delta = r - \lvert x - a \rvert > 0$.
   If $\lvert x' - x \rvert < \delta$, then $\lvert x' - a \rvert < r$ by the triangle inequality.
4. For such $x'$ in the domain of $f$, the definition of the value gives $\lvert f(x') - b \rvert \le s$, and it also gives $\lvert f(x) - b \rvert \le s$.
5. So $\lvert f(x') - f(x) \rvert \le 2s < \varepsilon$, and $f$ is continuous at $x$.
6. Now suppose that $\Phi$ codes $H$ on a domain that contains $0$ and all the points $2^{-k}$.
   Apply steps 2 to 5 at $x = 0$ with $\varepsilon = 1$, and let $\delta$ be the number of step 3.
7. Choose $k$ with $2^{-k} < \delta$.
   Step 5 gives $\lvert H(2^{-k}) - H(0) \rvert < 1$, but $H(2^{-k}) = 1$ and $H(0) = 0$.

This is a contradiction, so no code represents $H$.

## Remarks

Steps 1 to 5 show more than the example needs: every coded function is continuous at each point of its domain.
So in second-order reverse mathematics, a theorem about "functions from $\mathbb{R}$ to $\mathbb{R}$" is always a theorem about continuous functions.
A discontinuous function can enter $L_2$ only through a special code, such as a Borel code or a sequence of continuous approximations, and each choice of code gives its own version of a theorem.

The obstruction sits at the jump only.
The restriction of $H$ to $\mathbb{R} \setminus \{0\}$ is continuous on its domain, and it has a code.
In [[higher-order reverse mathematics|NPDRXTBW5W]], functions on the reals are objects of higher type.
There Kohlenbach showed that the existence of a discontinuous function from $\mathbb{R}$ to $\mathbb{R}$ is equivalent to Kleene's quantifier $(\exists^2)$ over $\mathsf{RCA}_0^\omega$.

## Explanations

### L1 human

In the usual framework, a function on the reals is described by a list of promises of the form "inputs near $a$ give outputs near $b$".
Every such list describes a function without jumps, because each promise holds on a whole interval.
The step function jumps from $0$ to $1$ at $0$.
A promise about the inputs near $0$ would have to keep both outputs $0$ and $1$ close to one value, and that is impossible with a small error.

### L2 human

We see the coding work for the identity function $f(x) = x$.
One code is the set of all $(a, r, a, r)$ with $a$ and $r > 0$ rational.
If $\lvert x - a \rvert < r$, then $\lvert f(x) - a \rvert = \lvert x - a \rvert < r$, so the value condition holds.
For $\varepsilon > 0$, a rational $a$ near $x$ and a rational $r < \varepsilon$ with $\lvert x - a \rvert < r$ show that $f$ is defined at $x$.

Now try the same for $H$ at $0$.
A quadruple $(a, r, b, s)$ with $\lvert a \rvert < r$ also covers the small positive points, so it needs both $\lvert 0 - b \rvert \le s$ and $\lvert 1 - b \rvert \le s$.
Adding the two gives $1 \le 2s$, so $s \ge \tfrac{1}{2}$, and $H$ is not defined at $0$ for any $\varepsilon \le \tfrac{1}{2}$.

The typical use of the argument is to explain the reading of analysis in $L_2$.
Watch out: the result does not say that $\mathsf{Z}_2$ refutes the existence of discontinuous functions, only that its language cannot name them by codes of this kind.
