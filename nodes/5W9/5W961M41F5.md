## Example

In [[second-order arithmetic|DC60FYCSPM]] a function $\R \to \R$ is not an object, so it is represented by a code, a set of numbers.
We recall the standard coding used in [[RCA0|XQENB067R3]], and show that no code represents the [[Heaviside function|09C4JP7Y0M]] $H$, with $H(x) = 1$ for $x > 0$ and $H(x) = 0$ for $x \le 0$.

A *code* is a set $\Phi$ of quadruples $(a, r, b, s)$ of rationals with $r, s > 0$, subject to three closure conditions that make it consistent.
The quadruple $(a, r, b, s) \in \Phi$ is read as "points at distance less than $r$ from $a$ are sent to points at distance at most $s$ from $b$".
The coded function $f$ is defined at $x$ if for every $\varepsilon > 0$ some $(a, r, b, s) \in \Phi$ has $\abs{x - a} < r$ and $s < \varepsilon$.
Its value $f(x)$ is the real $y$ with $\abs{y - b} \le s$ for all $(a, r, b, s) \in \Phi$ with $\abs{x - a} < r$.
The proof below uses only these two definitions, not the closure conditions.

1. Let $f$ be coded by $\Phi$ and defined at $x$. We show that $f$ is [[continuous|0X3WGX95FE]] at $x$ on its domain.
2. Let $\varepsilon > 0$. Since $f$ is defined at $x$, pick $(a, r, b, s) \in \Phi$ with $\abs{x - a} < r$ and $s < \varepsilon / 2$.
3. Put $\delta = r - \abs{x - a} > 0$. If $\abs{x' - x} < \delta$, then $\abs{x' - a} < r$ by the triangle inequality.
4. For such $x'$ in the domain of $f$, the definition of the value gives $\abs{f(x') - b} \le s$. It also gives $\abs{f(x) - b} \le s$.
5. So $\abs{f(x') - f(x)} \le 2s < \varepsilon$. This proves continuity at $x$.
6. Now suppose that $\Phi$ codes $H$ on a domain that contains $0$ and all the points $2^{-k}$.
7. Apply steps 2 to 5 at $x = 0$ with $\varepsilon = 1$, and let $\delta$ be the number of step 3.
8. Choose $k$ with $2^{-k} < \delta$. Then $\abs{H(2^{-k}) - H(0)} < 1$ by step 5.
9. But $H(2^{-k}) = 1$ and $H(0) = 0$, so $\abs{H(2^{-k}) - H(0)} = 1$. This is a contradiction, so no code represents $H$.

So second-order arithmetic cannot even state "the Heaviside function exists" in the usual way, and this is the gap that [[higher-order reverse mathematics|NPDRXTBW5W]] fills.

## Remarks

Every coded function is continuous at each point of its domain, by steps 1 to 5.
So statements about "all functions $\R \to \R$" in second-order reverse mathematics are really statements about continuous functions.
Discontinuous functions can be handled in second-order arithmetic only by ad hoc codes, for example a Borel code or a sequence of continuous approximations, and each choice of code gives its own version of a theorem.
In higher-order reverse mathematics $H$ is an object of type $1 \to 1$, and its existence is equivalent to $(\exists^2)$ over $\mathsf{RCA}_0^\omega$.

## Explanations

### L1 human

In the classical framework a function on the reals is described by a list of promises of the form "inputs near $a$ give outputs near $b$".
Every such list describes a function without jumps, because the promises hold on whole intervals.
The step function jumps from $0$ to $1$ at $0$.
Any promise about inputs near $0$ would have to cover both outputs $0$ and $1$ within a small error, which is impossible.
So the step function has no description of this kind.

### L2 human

We check step 4 on the identity function $f(x) = x$.

1. One code for $f$ is the set of all $(a, r, a, r)$ with $a$ rational and $r > 0$ rational.
2. If $\abs{x - a} < r$, then $\abs{f(x) - a} = \abs{x - a} < r$, so the value condition holds.
3. For $\varepsilon > 0$ and $x$, the quadruple $(a, r, a, r)$ with $r < \varepsilon / 2$ and $\abs{x - a} < r$ shows that $f$ is defined at $x$.
4. For the Heaviside function at $0$, a quadruple $(a, r, b, s)$ with $\abs{a} < r$ also covers small positive points $2^{-k}$, so it would need $\abs{0 - b} \le s$ and $\abs{1 - b} \le s$, so $s \ge \tfrac{1}{2}$. So the domain condition fails at $0$ for $\varepsilon \le \tfrac{1}{2}$.

The typical use: this argument explains why a theorem about all functions $\R \to \R$ must be read, in second-order arithmetic, as a theorem about continuous functions.
The trap: one can code $H$ restricted to $\R \setminus \set{0}$, which is continuous there; the obstruction is only at the jump.

### L3 human

The coding is designed so that $\mathsf{RCA}_0$ can work with continuous functions, and the restriction to them is not an accident.
A set of numbers carries only countable information.
A continuous function is determined by its values on the rationals, while an arbitrary function is not.
Higher types remove this restriction.
The price is that the conservation results for the base system no longer settle the strength of theorems about discontinuous functions, and new principles such as $(\exists^2)$ appear.
