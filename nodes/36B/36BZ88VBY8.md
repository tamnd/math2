## Summary

The unicity distance of a cipher is an estimate of the length of ciphertext an attacker needs before only one key gives a meaningful decryption.
Shannon defined it as the key entropy divided by the redundancy per character of the plaintext language.
Below this length a ciphertext-only attack with unlimited computing power cannot single out the key; above it, the key is in principle determined.
It says nothing about how hard it is to find the key in practice.

## Explanations

### L1 human

Try every key on a very short ciphertext, such as three letters.
Many keys give a real word, so the attacker cannot tell which key is right.
As the ciphertext grows, wrong keys produce gibberish, and the number of keys that give sensible text shrinks.
The unicity distance is roughly the length where only the true key is left.
For a simple substitution cipher on English text it is about $28$ letters.
