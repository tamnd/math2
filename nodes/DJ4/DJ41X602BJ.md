## Summary

**Vector logic** is an algebraic model of elementary logic based on [[matrix algebra|0VD9ZSWWJG]]. Vector logic assumes that the truth values map on [[vectors|0QN3D80AWP]], and that the monadic and dyadic operations are executed by matrix operators. "Vector logic" has also been used to refer to the representation of classical propositional logic as a [[vector space|000AYPA9AJ]], in which the unit vectors are propositional variables. Predicate logic can be represented as a vector space of the same type in which the axes represent the predicate letters $S$ and $P$. In the vector space for propositional logic the origin represents the false, F, and the infinite periphery represents the true, T, whereas in the space for predicate logic the origin represents "nothing" and the periphery represents the flight from nothing, or "something".
