## Summary

Write "true" as $s = (1, 0)^T$ and "false" as $n = (0, 1)^T$.
The matrix that swaps the two coordinates sends $s$ to $n$ and $n$ to $s$, so it computes "not":
$$N = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}, \qquad Ns = n, \qquad Nn = s.$$

*Vector logic* is this algebraic model of classical propositional logic, in which truth values are [[vectors|0QN3D80AWP]] and connectives are [[matrices|0VD9ZSWWJG]].
In general $s$ and $n$ are any two [[orthonormal|0S9GGTR0EX]] vectors in $\mathbb{R}^q$, with $q \ge 2$.
A connective with one argument is a $q \times q$ matrix, and a connective with two arguments is a $q \times q^2$ matrix that acts on the [[Kronecker product|0N7ENQRCXN]] $u \otimes v$ of the inputs.
Mixed inputs $\alpha s + (1 - \alpha) n$ with $\alpha \in [0, 1]$ give a [[many-valued|DWYCKAKXZD]] extension with the same matrices.

## Motivation

A truth table lists the output of a connective for each input.
A matrix can store the same list, since its column for an input holds the output vector.
Then the evaluation of a formula becomes a product of matrices, and two formulas are equivalent when their matrices are equal.
The same matrices act on mixtures of $s$ and $n$, so uncertain inputs need no new definitions.

## Notation

The vectors $s$ and $n$ are column vectors, and $u^T$ is the [[transpose|09DXWYRD43]] of $u$.
Here $\otimes$ is the Kronecker product of vectors and matrices; in other nodes of this topic it can denote a strong conjunction, which is a different operation.
The two rules used most are $(A \otimes B)(C \otimes D) = AC \otimes BD$ and $(A \otimes B)^T = A^T \otimes B^T$.
They give $(a \otimes b)^T (c \otimes d) = (a^T c)(b^T d)$ for column vectors $a, b, c, d$.

The basic matrices are as follows.

- Identity: $I = s s^T + n n^T$.
- Negation: $N = n s^T + s n^T$.
- Conjunction: $C = s (s \otimes s)^T + n (s \otimes n)^T + n (n \otimes s)^T + n (n \otimes n)^T$.
- Disjunction: $D = s (s \otimes s)^T + s (s \otimes n)^T + s (n \otimes s)^T + n (n \otimes n)^T$.
- Implication: $L = s (s \otimes s)^T + n (s \otimes n)^T + s (n \otimes s)^T + s (n \otimes n)^T$.
- Equivalence: $E = s (s \otimes s)^T + n (s \otimes n)^T + n (n \otimes s)^T + s (n \otimes n)^T$.
- Exclusive or: $X = n (s \otimes s)^T + s (s \otimes n)^T + s (n \otimes s)^T + n (n \otimes n)^T$.

Each term $w (a \otimes b)^T$ sends the input $a \otimes b$ to the output $w$, and the other three basic inputs to $0$.

## Remarks

### Four matrices for two dimensions

With $q = 2$, $s = (1, 0)^T$ and $n = (0, 1)^T$, the basic inputs $s \otimes s, s \otimes n, n \otimes s, n \otimes n$ are the standard basis vectors of $\mathbb{R}^4$, in this order.
So the columns of each matrix are its outputs for these four inputs:
$$C = \begin{pmatrix} 1 & 0 & 0 & 0 \\ 0 & 1 & 1 & 1 \end{pmatrix}, \quad D = \begin{pmatrix} 1 & 1 & 1 & 0 \\ 0 & 0 & 0 & 1 \end{pmatrix}, \quad L = \begin{pmatrix} 1 & 0 & 1 & 1 \\ 0 & 1 & 0 & 0 \end{pmatrix}.$$
Check: $s \otimes n = (0, 1, 0, 0)^T$, and $C (s \otimes n)$ is the second column of $C$, which is $n$, so "true and false" is false.

### The rules you can use

The identities $Is = s$, $In = n$, $Ns = n$, $Nn = s$ and $N^2 = I$ follow from $s^T s = n^T n = 1$ and $s^T n = 0$.
On inputs from $\{s, n\}$ the matrices $C, D, L, E, X$ give the classical truth tables of $\land$, $\lor$, $\to$, $\leftrightarrow$ and exclusive or.
Every one of the 16 classical connectives with two arguments has a matrix of the same form, one term per row of its truth table.
All these matrices vanish on vectors orthogonal to the basic inputs, so two such expressions are equal as matrices when they agree on the basic inputs.
So [[De Morgan's law and contraposition|ZPR591D9SC]] become the identities $C = N D (N \otimes N)$ and $L = D (N \otimes I)$.

### Mixed inputs

Put $u = \alpha s + (1 - \alpha) n$ and $v = \alpha' s + (1 - \alpha') n$.
Bilinearity gives $C (u \otimes v) = \alpha \alpha' s + (1 - \alpha \alpha') n$, again a mixture of $s$ and $n$.
So the [[scalar projection|A8Y386G318]] $s^T C (u \otimes v)$ is $\alpha \alpha'$, and $s^T N u$ is $1 - \alpha$.
Check with $u = (0.3, 0.7)^T$ and $v = (0.6, 0.4)^T$: $u \otimes v = (0.18, 0.12, 0.42, 0.28)^T$, and $C (u \otimes v) = (0.18, 0.82)^T$.

### What it is not

The projections are bilinear in $\alpha$ and $\alpha'$, so [[the Łukasiewicz implication is not a projection|8Q0HST6PC1]].
At $\alpha = \alpha' = \tfrac12$ every projection is the average of the four classical values, which is $\tfrac34$ for implication, while $\min(1, 1 - \tfrac12 + \tfrac12) = 1$.
Vectors $s$ and $n$ that are not orthogonal do not work either: if $s^T n \neq 0$, then $In = s (s^T n) + n \neq n$.

### Watch out

The symbol $\otimes$ is the Kronecker product of the input vectors, not a strong conjunction.
The dyadic matrices have $q$ rows and $q^2$ columns, because they map $\mathbb{R}^{q^2}$ to $\mathbb{R}^q$.
Projected values do not stay in $\{0, \tfrac12, 1\}$: the conjunction of two inputs with $\alpha = \alpha' = \tfrac12$ gives $\tfrac14$.

### History

Mizraji introduced vector logic in 1992, as a matrix-vector representation of the logical calculus.

### Try it

With $s = \tfrac{1}{\sqrt2}(1, 1)^T$ and $n = \tfrac{1}{\sqrt2}(1, -1)^T$, compute $N = n s^T + s n^T$.
The answer is $\begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix}$, since $n s^T = \tfrac12 \begin{pmatrix} 1 & 1 \\ -1 & -1 \end{pmatrix}$ and $s n^T = \tfrac12 \begin{pmatrix} 1 & -1 \\ 1 & -1 \end{pmatrix}$.

## Explanations

### L1 human

Write "true" as one arrow and "false" as another arrow at a right angle to it.
A logical operation becomes a table of numbers, a matrix, that turns input arrows into an output arrow.
"Not" swaps the two arrows, and "and" gives the "true" arrow only when both inputs are the "true" arrow.
A mixture of the two arrows, such as $70\%$ true and $30\%$ false, can express doubt.

### L2 human

To evaluate a formula, write each input as $s$ or $n$, form the Kronecker products, and multiply by the matrices from the inside out.
To prove an equivalence, show that the two matrix expressions agree on the four basic inputs.
With mixed inputs, the value $s^T G (u \otimes v)$ is the sum of the weights $\alpha \alpha'$, $\alpha (1 - \alpha')$, $(1 - \alpha) \alpha'$ and $(1 - \alpha)(1 - \alpha')$ of the basic inputs that $G$ sends to $s$.
Watch out: these values are those of probability for independent inputs, not those of [[Łukasiewicz logic|NFCEM44XYH]].

### L3 human

Let $W = \operatorname{span}\{s, n\}$.
The four vectors $a \otimes b$ with $a, b \in \{s, n\}$ form an orthonormal basis of $W \otimes W$.
Every dyadic matrix of vector logic has the form $\sum_{a, b} w_{ab} (a \otimes b)^T$ with $w_{ab} \in \{s, n\}$, and so vanishes on $(W \otimes W)^\perp$.
So the dyadic matrices correspond one to one to the functions $\{s, n\}^2 \to \{s, n\}$, that is, to the 16 classical connectives.
On mixed inputs, $s^T G (u \otimes v)$ is the bilinear extension of the truth table of $G$ from $\{0, 1\}^2$ to $[0, 1]^2$.
It is the probability that the connective is true when the inputs are true with independent probabilities $\alpha$ and $\alpha'$.
