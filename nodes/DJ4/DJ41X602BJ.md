## Summary

*Vector logic* is an algebraic model of classical propositional logic in which truth values are [[vectors|0QN3D80AWP]] and connectives are [[matrices|0VD9ZSWWJG]].
Fix $q \ge 2$ and two [[orthonormal|0S9GGTR0EX]] column vectors $s, n \in \mathbb{R}^q$, where $s$ stands for "true" and $n$ for "false".
A connective with one argument is a $q \times q$ matrix, and a connective with two arguments is a $q \times q^2$ matrix.
The matrix of a connective with two arguments acts on the [[Kronecker product|0N7ENQRCXN]] $u \otimes v$ of the two input vectors.
For example, negation is $N = n s^T + s n^T$, so $Ns = n$ and $Nn = s$.
Inputs of the form $\alpha s + (1 - \alpha) n$ with $\alpha \in [0, 1]$ give a [[many-valued|DWYCKAKXZD]] extension, with the same matrices.
The idea matters because logical laws become identities between matrices, which linear algebra can check.

## Motivation

A truth table lists the output of a connective for each input.
A matrix can store the same list: its column for an input holds the output vector.
Then evaluation of a formula becomes a product of matrices, and two formulas are equivalent when their matrices are equal.
The same matrices also act on mixtures of $s$ and $n$, so uncertain inputs need no new definitions.

## Notation

The vectors $s$ and $n$ are column vectors, and $u^T$ is the [[transpose|09DXWYRD43]] of $u$.
The symbol $\otimes$ is the Kronecker product of vectors and matrices in this node.
In other nodes of this topic, $\otimes$ can denote a strong conjunction, which is a different operation.
The two rules used most are the mixed product rule $(A \otimes B)(C \otimes D) = AC \otimes BD$ and the rule $(A \otimes B)^T = A^T \otimes B^T$.
They give $(a \otimes b)^T (c \otimes d) = (a^T c)(b^T d)$ for column vectors $a, b, c, d$.

The basic matrices are as follows.

- Identity: $I = s s^T + n n^T$.
- Negation: $N = n s^T + s n^T$.
- Conjunction: $C = s (s \otimes s)^T + n (s \otimes n)^T + n (n \otimes s)^T + n (n \otimes n)^T$.
- Disjunction: $D = s (s \otimes s)^T + s (s \otimes n)^T + s (n \otimes s)^T + n (n \otimes n)^T$.
- Implication: $L = s (s \otimes s)^T + n (s \otimes n)^T + s (n \otimes s)^T + s (n \otimes n)^T$.
- Equivalence: $E = s (s \otimes s)^T + n (s \otimes n)^T + n (n \otimes s)^T + s (n \otimes n)^T$.
- Exclusive or: $X = n (s \otimes s)^T + s (s \otimes n)^T + s (n \otimes s)^T + n (n \otimes n)^T$.

Each term $w (a \otimes b)^T$ sends the input $a \otimes b$ to the output $w$, and it sends the other three basic inputs to $0$.

## Remarks

### Examples

1. With $q = 2$, $s = (1, 0)^T$ and $n = (0, 1)^T$, the matrices are
$$N = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}, \quad C = \begin{pmatrix} 1 & 0 & 0 & 0 \\ 0 & 1 & 1 & 1 \end{pmatrix}, \quad D = \begin{pmatrix} 1 & 1 & 1 & 0 \\ 0 & 0 & 0 & 1 \end{pmatrix}, \quad L = \begin{pmatrix} 1 & 0 & 1 & 1 \\ 0 & 1 & 0 & 0 \end{pmatrix}.$$
The columns are the outputs for the inputs $s \otimes s, s \otimes n, n \otimes s, n \otimes n$ in this order.
2. With $q = 2$, $s = \tfrac{1}{\sqrt2}(1, 1)^T$ and $n = \tfrac{1}{\sqrt2}(1, -1)^T$, negation is $N = \begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix}$, and $I$ is the identity matrix.
3. [[De Morgan and contraposition as matrix identities|~4900304c]]: $C = N D (N \otimes N)$ and $L = D (N \otimes I)$, checked on all inputs.
4. [[Scalar projections of vector logic|~dbefcadb]]: for inputs $\alpha s + (1 - \alpha) n$ and $\alpha' s + (1 - \alpha') n$, the value $s^T C (u \otimes v)$ is $\alpha \alpha'$.

### Non-examples

1. [[Łukasiewicz implication is not a scalar projection|~ba43f5c6]]: no $1 \times 4$ matrix $G$ gives $\min(1, 1 - \alpha + \alpha')$ as $G (u \otimes v)$ for all inputs, so this connective of [[Łukasiewicz logic|~ca73eab3]] is outside the scheme.
2. Vectors $s$ and $n$ that are not orthogonal do not work. If $s^T n \ne 0$, then $I n = s (s^T n) + n \ne n$.
3. A $q \times q$ matrix can not represent a connective with two arguments, because it acts on one vector only.

### Basic properties

1. $I s = s$, $I n = n$, $N s = n$, $N n = s$, and $N^2 = I$. Each identity follows from $s^T s = n^T n = 1$ and $s^T n = 0$.
2. For $u, v \in \set{s, n}$, the matrices $C, D, L, E, X$ give the classical truth tables of $\land, \lor, \to, \leftrightarrow$ and exclusive or.
3. Every matrix above sends every vector orthogonal to $s$ and $n$ to $0$. So two such expressions are equal as matrices when they agree on the basic inputs.
4. Each of the 16 classical connectives with two arguments has a matrix of the same form, one term per row of its truth table.
5. If $u = \alpha s + (1 - \alpha) n$ and $v = \alpha' s + (1 - \alpha') n$, then $C (u \otimes v) = \alpha \alpha' s + (1 - \alpha \alpha') n$. The output is again a weighted sum of $s$ and $n$ with weights that add up to $1$.

### History

Wikipedia cites papers of Mizraji (1992, 1996, 2008) as the main sources of vector logic.
It relates earlier uses of linear algebra in logic to Peirce and Copilowish, and the approach to neural network models with large matrices.

### Common errors

1. Reading $\otimes$ as a strong conjunction. In vector logic it is the Kronecker product of the input vectors.
2. Writing the dyadic matrices as $q^2 \times q$. They have $q$ rows and $q^2$ columns, because they map $\mathbb{R}^{q^2}$ to $\mathbb{R}^q$.
3. Assuming that projected values stay in $\set{0, \tfrac12, 1}$. The conjunction gives $\tfrac12 \cdot \tfrac12 = \tfrac14$ for two inputs with $\alpha = \alpha' = \tfrac12$.

## Explanations

### L1 human

Write "true" as one arrow and "false" as another arrow at a right angle to it.
A logical operation becomes a table of numbers, a matrix, that turns input arrows into an output arrow.
"Not" swaps the two arrows.
"And" gives the "true" arrow only when both inputs are the "true" arrow.
A mixture of the two arrows, such as $70\%$ true and $30\%$ false, can express doubt.

### L2 human

1. Take $s = (1, 0)^T$ and $n = (0, 1)^T$.
2. Compute $s \otimes n = (0, 1, 0, 0)^T$.
3. Multiply by $C$ from Example 1: the result is the second column of $C$, which is $(0, 1)^T = n$. So "true and false" is false.
4. For the inputs $u = (0.3, 0.7)^T$ and $v = (0.6, 0.4)^T$, $u \otimes v = (0.18, 0.12, 0.42, 0.28)^T$ and $C (u \otimes v) = (0.18, 0.82)^T$.

The typical use is to turn a logical identity into a matrix identity, then check it by multiplication.
A trap: the projected values are those of probability for independent inputs, and not those of [[Łukasiewicz logic|~ca73eab3]].

### L3 human

Let $W = \operatorname{span}\set{s, n}$.
The four vectors $a \otimes b$ with $a, b \in \set{s, n}$ form an orthonormal basis of $W \otimes W$.
Every dyadic matrix of vector logic has the form $\sum_{a, b} w_{ab} (a \otimes b)^T$ with $w_{ab} \in \set{s, n}$, and so vanishes on $(W \otimes W)^\perp$.
So the dyadic matrices correspond one to one to the functions $\set{s, n}^2 \to \set{s, n}$, that is, to the 16 classical connectives.
On weighted inputs, $s^T G (u \otimes v)$ is the bilinear extension of the truth table of $G$ from $\set{0, 1}^2$ to $[0, 1]^2$.
This equals the probability that the connective is true when the inputs are true with independent probabilities $\alpha$ and $\alpha'$.
