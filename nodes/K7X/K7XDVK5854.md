## Summary

A sentence has no free variables, so once we fix a structure it is simply true or simply false there.
In $(\mathbb{Z}, <)$ the sentence $\forall x \, \exists y \, (x < y)$ is true, because $n + 1$ is above every integer $n$.
The sentence $\exists x \, \forall y \, (x \leq y)$, where $x \leq y$ abbreviates $x < y \vee x = y$, is false in $(\mathbb{Z}, <)$, because $a - 1$ is below every candidate $a$.
The same sentence is true in $(\mathbb{N}, <)$, with the witness $0$.
So truth belongs to a sentence and a structure together.

In exact terms, let $\mathcal{M}$ be a [[structure|983GZBQYT4]] for a signature $L$, and let $\sigma$ be an $L$-[[sentence|DKFGQTRYZE]].
Then $\sigma$ is true in $\mathcal{M}$, written $\mathcal{M} \models \sigma$, when every variable assignment in $\mathcal{M}$ [[satisfies|2RBQPV02AS]] $\sigma$.
Since $\sigma$ has no free variables, this holds exactly when some assignment satisfies $\sigma$.
Otherwise $\sigma$ is false in $\mathcal{M}$, and then $\mathcal{M} \models \neg \sigma$.
The theory of $\mathcal{M}$ collects the true sentences:
$$\operatorname{Th}(\mathcal{M}) = \{ \sigma : \sigma \text{ is an } L\text{-sentence and } \mathcal{M} \models \sigma \}.$$
The [[formal definition|71X7TB3F98]] also covers formulas with free variables.

## Motivation

Satisfaction $\mathcal{M} \models \varphi[s]$ depends on an assignment $s$.
The statements of mathematics, such as "every element has an inverse", have no free variables, and for them the assignment is a nuisance.
The [[coincidence lemma|FM580NZ9W6]] removes it: satisfaction of a formula depends only on the values of its free variables, and a sentence has none.
So each sentence gets one truth value in each structure.

This turns a familiar phrase into an exact one.
"The group $G$ is abelian" means that the sentence $\forall x \, \forall y \, (x \cdot y = y \cdot x)$ is true in $G$.
Collecting all true sentences into $\operatorname{Th}(\mathcal{M})$ lets us compare structures by what they make true, and ask which properties first-order logic can express.
The [[models of a theory|MVCH6N9SNW]] and [[validity|5SDS9T8E7J]] are both defined from truth.

## Notation

We write $\mathcal{M} \models \sigma$ for "$\sigma$ is true in $\mathcal{M}$", also read "$\mathcal{M}$ satisfies $\sigma$", and $\mathcal{M} \not\models \sigma$ for "$\sigma$ is false in $\mathcal{M}$".
For a formula $\varphi$ with free variables, Enderton and Mendelson write $\mathcal{M} \models \varphi$ when every assignment satisfies $\varphi$, which is the same as the truth of its universal closure.
Other books use $\mathcal{M} \models \varphi$ only for sentences.
We follow the first convention and say so whenever a formula has free variables.
In Mathlib, truth of a sentence is `FirstOrder.Language.Sentence.Realize`, with the notation `M ⊨ φ`, and the theory of a structure is `FirstOrder.Language.completeTheory`.

## Remarks

### One sentence, two structures

The [[sentence "every number has a larger one"|WK9J5ZTZGJ]], $\forall x \, \exists y \, (x < y)$, is true in $(\mathbb{N}, <)$ and false in $(\{0, 1, 2\}, <)$.
In $\mathbb{N}$, every value $n$ of $x$ has the witness $n + 1$.
In $\{0, 1, 2\}$, the value $2$ of $x$ has no witness, since none of $(2, 0)$, $(2, 1)$, $(2, 2)$ lies in the order.

A sentence can also separate two infinite structures.
The density sentence
$$\forall x \, \forall y \, (x < y \to \exists z \, (x < z \wedge z < y))$$
is true in $(\mathbb{Q}, <)$, with the witness $z = (x + y)/2$, and false in $(\mathbb{Z}, <)$, at $x \mapsto 0$, $y \mapsto 1$.
Since an isomorphism preserves truth, these two orders are not isomorphic.

### Sentences that count

Some sentences use only equality.
The [[sentence "there are at least three elements"|EWA6VT52BV]],
$$\exists x \, \exists y \, \exists z \, (\neg x = y \wedge \neg x = z \wedge \neg y = z),$$
is true exactly in the structures whose domain has at least three elements, whatever the signature.
In the same way, the sentence $\forall x \, \forall y \, (x \cdot y = y \cdot x)$ is true in the group $(\mathbb{Z}, +)$, read with $\cdot$ as $+$, and false in the symmetric group $S_3$.

### What is not true or false

A [[formula with a free variable is neither true nor false|WVR5YXJBM3]].
In $(\mathbb{N}, <)$ with a constant $1$, the formula $x < 1$ holds when $x \mapsto 0$ and fails when $x \mapsto 5$.
So neither $x < 1$ nor $\neg (x < 1)$ is true, and the condition that fails is that $x < 1$ is not a sentence.
A sentence can still be false, of course: the [[integers have no least element|73YT05DXRB]], so no assignment satisfies $\exists x \, \forall y \, (x \leq y)$ in $(\mathbb{Z}, <)$.

### The rules for true sentences

Bivalence holds for sentences: exactly one of $\mathcal{M} \models \sigma$ and $\mathcal{M} \models \neg \sigma$ holds.
The reason is that $\sigma$ is satisfied by all assignments or by none, and assignments exist because the domain is nonempty.
So $\operatorname{Th}(\mathcal{M})$ is complete: for each sentence $\sigma$ it contains $\sigma$ or $\neg \sigma$, and not both.
It is also closed under [[logical consequence|1HK0VYWTV7]], since a consequence of true sentences is true in every structure where they are true.

A structure $\mathcal{M}$ is a [[model|MVCH6N9SNW]] of a set $T$ of sentences exactly when $T \subseteq \operatorname{Th}(\mathcal{M})$.
If $\mathcal{M} \cong \mathcal{N}$, then $\operatorname{Th}(\mathcal{M}) = \operatorname{Th}(\mathcal{N})$, by [[isomorphism invariance of truth|NDTJ2E895C]].

### Same theory, different structures

Structures with the same theory are [[elementarily equivalent|P3B1V182N4]], written $\mathcal{M} \equiv \mathcal{N}$.
Isomorphic structures are elementarily equivalent, but the converse fails.
The orders $(\mathbb{Q}, <)$ and $(\mathbb{R}, <)$ satisfy exactly the same sentences, yet they are not isomorphic, since $\mathbb{Q}$ is countable and $\mathbb{R}$ is not.
The proof that they have the same theory belongs to model theory: both are dense linear orders without endpoints, and that theory is complete.
So elementary equivalence is a strictly weaker relation than isomorphism.

### Watch out

Do not confuse "not true" with "false" for formulas.
For a sentence, $\mathcal{M} \not\models \sigma$ gives $\mathcal{M} \models \neg \sigma$.
For the formula $x < 1$ in $(\mathbb{N}, <)$, both $x < 1$ and $\neg (x < 1)$ fail to be true.

Do not confuse truth in one structure with [[validity|5SDS9T8E7J]].
The sentence $\forall x \, \exists y \, (x < y)$ is true in $(\mathbb{N}, <)$ but not valid, since it fails in $(\{0\}, <)$.

### History

Alfred Tarski defined truth for formalized languages in his 1933 monograph, through the satisfaction of formulas by sequences of objects.
His adequacy condition, convention T, asks that a definition of truth imply each instance of "'snow is white' is true if and only if snow is white"; see the [[semantic conception of truth|8FBF0EFFC9]].
Truth relative to an arbitrary structure became the standard notion with the model theory of the 1950s.

### Try it

Is $\forall x \, \exists y \, (y < x)$ true in $(\mathbb{N}, <)$?
No: at $x \mapsto 0$ a witness would need $y < 0$, and no natural number is below $0$.

Is the density sentence above true in $(\{0\}, <)$?
Yes: its hypothesis $x < y$ fails for the only pair $(0, 0)$, so every instance of the implication holds.

## Explanations

### L1 human

A sentence is a complete statement in a formal language, with no unknown letters left over.
Once we fix a structure, such as the whole numbers with "less than", every sentence is either true or false there.
"For every number there is a bigger number" is true for the whole numbers $0, 1, 2, \ldots$.
The same sentence is false for the three numbers $0, 1, 2$ alone, because nothing is bigger than $2$.
The list of all sentences that are true in a structure is called its theory.

### L2 human

We decide the truth of $\forall x \, \exists y \, (y < x)$ in two structures.
In $(\mathbb{Z}, <)$, each value $a$ of $x$ has the witness $y \mapsto a - 1$, because $a - 1 < a$, so the sentence is true.
In $(\mathbb{N}, <)$, the value $x \mapsto 0$ needs some $b \in \mathbb{N}$ with $b < 0$, and there is none, so the sentence is false.
By bivalence, $(\mathbb{N}, <) \models \neg \forall x \, \exists y \, (y < x)$.

So the sentence lies in $\operatorname{Th}(\mathbb{Z}, <)$ and its negation lies in $\operatorname{Th}(\mathbb{N}, <)$.
This is the typical use: one sentence true in one structure and false in another proves that the two are not isomorphic.
Watch out: a formula with a free variable cannot do this job, because it can be satisfied in both structures by some assignments and fail in both by others.

### L3 human

The map $\mathcal{M} \mapsto \operatorname{Th}(\mathcal{M})$ sends structures to complete theories, and its fibers are the classes of elementarily equivalent structures.
By the [[completeness theorem|WQ1ZE255SF]], every complete consistent theory that is closed under consequence equals $\operatorname{Th}(\mathcal{M})$ for some $\mathcal{M}$.
A theory $\operatorname{Th}(\mathcal{M})$ can be decidable, as for the ordered field of real numbers, or undecidable, as for $(\mathbb{N}, +, \cdot)$.
Tarski's undefinability theorem says that $\operatorname{Th}(\mathbb{N}, +, \cdot)$, coded by numbers, is not definable in $(\mathbb{N}, +, \cdot)$ itself.
Other logics, such as second-order or infinitary logic, have their own truth relations, and these separate more structures than $\equiv$ does.
