## Summary

In graph theory, an **independent dominating set** for a [[graph|00C0BR7D7H]] $G = (V, E)$ is a [[subset|0BJR9QR08E]] $D \subseteq V$ that is both a dominating set and an [[independent set|08ANQHHG3P]]; equivalently, it is a maximal independent set.
