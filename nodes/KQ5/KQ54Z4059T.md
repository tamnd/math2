## Definition

Work in the setting of [[modern portfolio theory|ZBDA8W9D6V]]: $n$ risky assets with mean vector $m$ and positive definite covariance matrix $\Sigma$.
For a portfolio $w$, write $\mu(w) = w^T m$ and $\sigma(w) = \sqrt{w^T \Sigma w}$.
A portfolio $w$ is *efficient* if there is no portfolio $v$ with $\mu(v) \ge \mu(w)$ and $\sigma(v) \le \sigma(w)$, at least one inequality being strict.
The *efficient frontier* is the set of points $(\sigma(w), \mu(w))$ of efficient portfolios $w$.

## Remarks

Let $\mathbf{1} = (1, \dots, 1)$, $A = \mathbf{1}^T \Sigma^{-1} \mathbf{1}$, $B = \mathbf{1}^T \Sigma^{-1} m$ and $C = m^T \Sigma^{-1} m$, and assume that $m$ is not a multiple of $\mathbf{1}$, so that $D = AC - B^2 > 0$.
The minimum variance for a target mean $\mu$ is
$$\sigma^2(\mu) = \frac{A \mu^2 - 2 B \mu + C}{D}.$$
So the minimum-variance portfolios lie on a [[hyperbola|0WN5G117YC]] in the $(\sigma, \mu)$ plane.
The efficient frontier is the upper half of the branch with $\sigma > 0$, the part with $\mu \ge B/A$, which starts at the global minimum-variance portfolio.

Example: two uncorrelated assets with means $1, 2$ and variances $1, 1$.
The portfolio with mean $\mu$ is $w = (2 - \mu, \mu - 1)$, with variance $(2 - \mu)^2 + (\mu - 1)^2 = 2\mu^2 - 6\mu + 5$.
This agrees with the formula, since $A = 2$, $B = 3$, $C = 5$ and $D = 1$.
The frontier is the set of these points with $\mu \ge 3/2$.

Non-example: the portfolio $w = (1, 0)$ has $\mu = 1$ and $\sigma = 1$.
It is not efficient, because $w = (0, 1)$ has $\mu = 2$ and the same $\sigma = 1$.
