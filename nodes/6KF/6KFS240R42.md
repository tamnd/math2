## Definition

A Sheffer function is one operation on a finite set from which every other operation can be built.
Let $A$ be a finite set with at least two elements.
A set $F$ of finitary [[operations|EJ8YJVM9BW]] on $A$ is *functionally complete* if every operation $g \colon A^n \to A$ with $n \ge 1$ is a composition of operations in $F$ and projections.
An operation $f$ on $A$ is a *Sheffer function* if the set $\{f\}$ is functionally complete.
Equivalently, the [[clone|PTKR703G6A]] generated by $f$ contains every finitary operation on $A$.

## Notation

For $A = \{0, 1\}$ this is the usual [[functional completeness|TDZVCWYJ9F]] of a set of connectives.
A Sheffer function is often written $x \mid y$, and the two-valued ones are also written $x \uparrow y$ (NAND) and $x \downarrow y$ (NOR).

## Remarks

The condition $|A| \ge 2$ removes a degenerate case.
On a one-element set every operation is a projection, so every operation would count, and the notion says nothing.
The condition $n \ge 1$ means that constants count as constant functions of one variable, so a Sheffer function must produce them as such.
Projections are allowed in compositions so that variables can be repeated, permuted and ignored, as in $x \uparrow x$.

For an example, take NAND on $\{0, 1\}$, $x \uparrow y = \neg(x \wedge y)$.
Negation is $\neg x = x \uparrow x$, and conjunction is $x \wedge y = (x \uparrow y) \uparrow (x \uparrow y)$.
Check at $x = y = 1$: $1 \uparrow 1 = 0$ and $0 \uparrow 0 = 1 = 1 \wedge 1$.
Since $\{\wedge, \neg\}$ is functionally complete, so is $\{\uparrow\}$.
NOR is the only other binary Sheffer function on $\{0, 1\}$.

A case that fails is $\wedge$ on $\{0, 1\}$.
Every operation built from $\wedge$ sends $(0, \dots, 0)$ to $0$, so negation, which sends $0$ to $1$, is not built.
A unary operation also fails, since its compositions depend on one variable only, so a Sheffer function has arity at least $2$.

On $\{0, \dots, m - 1\}$ the operation $\max(x, y) + 1 \bmod m$ is a Sheffer function, by [[Webb's theorem|EPSBDVPKJP]].
The concept page [[Sheffer function|1K829SJG3K]] works this case and lists the general tests.

## Explanations

### L1 human

A Sheffer function is one operation that can build every other operation on a finite set of values.
NAND does this for true and false, which is why circuits can use NAND gates alone.
For three or more values, a single well-chosen operation can still do it.

### L2 human

To show that $f$ is a Sheffer function, write the members of a known complete set with $f$ alone.
To show that $f$ is not one, find a property that $f$ has and that some operation lacks.
Watch out: the property must survive composition.
"Sends $(0, \dots, 0)$ to $0$" survives, because a composition of such operations also sends $(0, \dots, 0)$ to $0$.
"Takes both values" does not survive: exclusive or takes both values, but $x \oplus x$ is the constant $0$.
