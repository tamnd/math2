## Definition

Let $A$ be a finite set with at least two elements.
A set $F$ of finitary [[operations|EJ8YJVM9BW]] on $A$ is *functionally complete* if every operation $g \colon A^n \to A$ with $n \ge 1$ is a composition of operations in $F$ and projections.
An operation $f$ on $A$ is a *Sheffer function* if the set $\set{f}$ is functionally complete.
That is, the [[clone|PTKR703G6A]] generated by $f$ contains every finitary operation on $A$.

## Notation

For $A = \set{0, 1}$ this is the usual [[functional completeness|TDZVCWYJ9F]] of a set of connectives.
A Sheffer function is often written $x \mid y$ or $x \uparrow y$.

## Remarks

1. Example: NAND, $x \uparrow y = \neg(x \wedge y)$ on $\set{0, 1}$, is a Sheffer function. Check: $\neg x = x \uparrow x$ and $x \wedge y = \neg(x \uparrow y)$, and $\set{\wedge, \neg}$ is functionally complete.
2. Non-example: $\wedge$ on $\set{0, 1}$ is not a Sheffer function. Every operation generated by $\wedge$ maps $(0, \dots, 0)$ to $0$, so $\neg$ is not generated.
3. NOR, $x \downarrow y = \neg(x \vee y)$, is the only other binary Sheffer function on $\set{0, 1}$.
4. A Sheffer function must have arity at least $2$, since a unary operation generates only operations that depend on one variable.
5. On $\set{0, \dots, m - 1}$, $\max(x, y) + 1 \bmod m$ is a Sheffer function, by [[Webb's theorem|EPSBDVPKJP]].

## Explanations

### L1 human

A Sheffer function is one operation that can build every other operation on a finite set of values.
NAND does this for true and false.
For more values, a single well-chosen operation can still do it.

### L2 human

To show that $f$ is a Sheffer function, write a known complete set with $f$ alone.
To show that $f$ is not, find a property that $f$ keeps and that some operation breaks, such as preserving a value.
A trap: generated operations include all compositions, so check that the property survives composition.
