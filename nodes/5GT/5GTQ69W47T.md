## Definition

An *intuitionistic Kripke frame* is a nonempty set $W$ with a [[partial order|0QV2JS9RJ3]] $\leq$.
The elements of $W$ are *worlds* or *nodes*.
An *intuitionistic Kripke model* is a triple $\mathfrak{M} = (W, \leq, V)$, where $(W, \leq)$ is a frame and $V$ assigns to each propositional variable $p$ an [[up-set|ETCE287E2R]] $V(p) \subseteq W$.
Up-set means: if $w \in V(p)$ and $w \leq v$, then $v \in V(p)$.

The forcing relation $w \Vdash \varphi$, for $w \in W$ and a formula $\varphi$ of [[intuitionistic logic|52XCYMK0WW]], is defined by [[structural induction|12MQ2NJ29A]].

1. $w \Vdash p$ if and only if $w \in V(p)$.
2. $w \nVdash \bot$.
3. $w \Vdash \varphi \wedge \psi$ if and only if $w \Vdash \varphi$ and $w \Vdash \psi$.
4. $w \Vdash \varphi \vee \psi$ if and only if $w \Vdash \varphi$ or $w \Vdash \psi$.
5. $w \Vdash \varphi \to \psi$ if and only if, for every $v \geq w$, $v \Vdash \varphi$ implies $v \Vdash \psi$.

A formula $\varphi$ is *valid in the model* if every world forces it, and *valid on the frame* if it is valid in every model on the frame.
For a set $\Gamma$ of formulas, $\Gamma \Vdash \varphi$ means: in every model, every world that forces all members of $\Gamma$ forces $\varphi$.

## Notation

$\mathfrak{M}, w \Vdash \varphi$ is also written $w \models \varphi$, and $[\![\varphi]\!] = \set{w : w \Vdash \varphi}$ is the truth set.
$\mathrm{Up}(W, \leq)$ is the set of up-sets of the frame.
Some authors use preorders instead of partial orders; this gives the same valid formulas.

## Remarks

1. The derived clause for negation is: $w \Vdash \neg\varphi$ if and only if no $v \geq w$ forces $\varphi$.
2. So $w \Vdash \neg\neg\varphi$ if and only if every $v \geq w$ has some $u \geq v$ with $u \Vdash \varphi$.
3. Persistence: if $w \Vdash \varphi$ and $w \leq v$, then $v \Vdash \varphi$. So every truth set is an up-set; the proof is step 1 of [[the soundness and completeness proof|GWK70Q7WR3]].
4. Truth sets form a Heyting algebra: $[\![\varphi \to \psi]\!]$ is the largest up-set $U$ with $U \cap [\![\varphi]\!] \subseteq [\![\psi]\!]$.
5. A frame is a model of "growing knowledge": $w \leq v$ means that $v$ is a possible later state of knowledge. Forced formulas stay forced.
6. Example: in the frame $u \leq v$ with $V(p) = \set{v}$, the world $u$ forces neither $p$ nor $\neg p$; see [[the two-point countermodel|8BKRJ0KPVD]].
7. Non-example: a valuation that is not an up-set breaks persistence; see [[a valuation that is not an up-set|KH72FWWF6A]].
8. Through the [[Gödel-McKinsey-Tarski translation|BXVNEN55MR]], an intuitionistic frame is an $\mathsf{S4}$ frame, and the clause for $\to$ is the clause for $\square(\varphi \to \psi)$.

## Explanations

### L1 human

Think of a scientist whose knowledge grows over time.
Each world is a state of knowledge, and a later world knows at least as much.
A fact once known stays known.
"$A$ or $B$" is known when one of them is known now.
"Not $A$" is known only when $A$ will never become known, in any later state.

### L2 human

We compute truth sets in the three-world frame $r \leq a$, $r \leq b$, with $a$ and $b$ incomparable, and $V(p) = \set{a}$.

1. $[\![p]\!] = \set{a}$.
2. $[\![\neg p]\!]$ is the set of worlds with no later world in $\set{a}$. This is $\set{b}$, since $r \leq a$.
3. $[\![\neg\neg p]\!]$ is the set of worlds with no later world in $\set{b}$. This is $\set{a}$.
4. $[\![\neg p \vee \neg\neg p]\!] = \set{a, b}$, which does not contain $r$.

The typical use of the definition is to refute a formula by a small model.
A trap: the clause for $\to$ looks at all later worlds, not only at the current world; checking the world alone gives the classical clause.
