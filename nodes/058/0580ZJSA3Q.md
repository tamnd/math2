## Definition

Let $S$ be a [[set|0BSJ7RQ9BW]].
A binary operation on $S$ is a [[function|0EPAT51DXQ]] $\ast \colon S \times S \to S$ from the [[Cartesian product|09CEDJYBKP]] $S \times S$ to $S$.
For $a, b \in S$, the image of the pair $(a, b)$ is written $a \ast b$.

## Notation

The symbols $a \ast b$, $a \cdot b$ and $ab$ are common for a general binary operation.
The symbol $a + b$ is used by convention only when the operation is [[commutative|099E72KTF8]].
In Mathlib, the class `Mul` gives a type a binary operation written $a * b$.

## Remarks

Addition, subtraction and multiplication are binary operations on the set $\mathbb{Z}$ of [[integers|0C4JS9RF5M]].
Subtraction is not a binary operation on the set $\mathbb{N} = \{0, 1, 2, \ldots\}$ of [[natural numbers|0MWKJ44V5A]], because $1 - 2$ is not in $\mathbb{N}$.
The condition that $a \ast b$ is in $S$ for all $a, b \in S$ is called closure.
The definition asks for a value at every pair, so a rule such as division on $\mathbb{Q}$, with no value at the pairs $(a, 0)$, is not a binary operation on $\mathbb{Q}$.
The concept page [[binary operation|0M418FE7BB]] gives the examples, the non-examples and the first properties.

## Explanations

### L1 human

A binary operation is a rule that takes two elements of a set, in order, and gives one element of the same set.
For example, addition takes $2$ and $3$ and gives $5$.
The order can matter: $2 - 3$ and $3 - 2$ are different.

### L2 human

To check that a rule is a binary operation on a set $S$, we check two things.

1. The rule gives a value for each ordered pair $(a, b)$ with $a, b \in S$.
2. Each value is an element of $S$.

For example, multiplication on the set $\{1, -1\}$ is a binary operation.
The four products are $1 \cdot 1 = 1$, $1 \cdot (-1) = -1$, $(-1) \cdot 1 = -1$ and $(-1) \cdot (-1) = 1$, and each of them is in $\{1, -1\}$.
Addition on the same set is not a binary operation, because $1 + 1 = 2$.
A trap is to forget that a binary operation can take the same element two times, as in the pair $(1, 1)$.
