## Summary

Give the natural number $n$ the truth degree $\tfrac{1}{n+1}$ for a predicate $P$.
Every object has a positive degree, yet $\forall x P(x)$ gets the infimum $0$, and no object attains it.
So the sentence "some $x$ has the least degree of $P$" fails, though it holds on every finite domain.

A *first-order Gödel logic* is the set of first-order sentences that get value $1$ in every structure with truth values in a set $V \subseteq [0, 1]$.
The connectives are those of [[Gödel-Dummett logic|474SGS2N0X]]: $\min$, $\max$, the Gödel implication, and $\neg x = x \to 0$.
The quantifiers $\forall$ and $\exists$ are the infimum and supremum over the domain.
For $V = [0, 1]$ this is the first-order Gödel logic $\mathrm{G}\forall$, which Horn axiomatized in 1969.
Unlike the propositional case, the first-order logic depends on the order type of $V$, not only on whether $V$ is finite.

## Motivation

In Gödel logic the value of a propositional formula depends only on the order of the values of its variables.
So all infinite subsets of $[0, 1]$ that contain $0$ and $1$ give the same propositional logic.
Quantifiers compute infima and suprema, and these depend on the order type of $V$.
They see whether a set of values has a least element, and whether $0$ is a limit of other values.
So first-order Gödel logics separate truth value sets that propositional logic cannot separate.

## Notation

Let $V \subseteq [0, 1]$ be closed, with $0, 1 \in V$.
A *$V$-structure* $\mathfrak{M}$ has a nonempty domain $M$ and, for each $n$-ary predicate $P$, a map $P^{\mathfrak{M}} \colon M^n \to V$.
Values of formulas are computed as in Mostowski's semantics, with the Gödel operations on $V$ and with $\inf$ and $\sup$ for $\forall$ and $\exists$.
We write $\mathrm{G}_V$ for the set of sentences with value $1$ in every $V$-structure.
Since $V$ is closed, all infima and suprema of subsets of $V$ lie in $V$.

## Remarks

### Valid sentences

The constant domain axiom $\forall x (p \lor Q(x)) \to (p \lor \forall x Q(x))$ has value $1$ for every $V$, as [[the constant domain example|KTWJZCFJXY]] proves.
The sentences $\neg \neg \forall x P(x) \to \forall x \neg \neg P(x)$ and $\forall x (P(x) \to \exists y P(y))$ are valid as well.
The first holds because $\neg \neg$ is monotone, so $\neg \neg$ of an infimum is at most each $\neg \neg P(d)$.
The propositional part of $\mathrm{G}_{[0, 1]}$ is the logic of [[the Gödel chain on the unit interval|BHR2YXEQZT]].

### A sentence that depends on V

The sentence $\exists x (P(x) \to \forall y P(y))$ is in $\mathrm{G}_V$ exactly when every nonempty subset of $V$ has a least element, as [[the separating example|5K8AMXXHT2]] proves.
With the degrees $\tfrac{1}{n+1}$ from the Summary its value is $\sup_n (\tfrac{1}{n+1} \to 0) = 0$.
If $V$ is finite with $n$ elements, $\mathrm{G}_V$ is the first-order logic of the $n$-element Gödel chain, and it contains this sentence.

### What is not a Gödel logic

[[Intuitionistic predicate logic|AXGTQ7091K]] is not a Gödel logic, since it refutes both prelinearity and the constant domain axiom.
Classical first-order logic is not $\mathrm{G}_{[0, 1]}$ either.
The sentence $\forall x \neg \neg P(x) \to \neg \neg \forall x P(x)$ is classically valid and not valid over $[0, 1]$.
Check: with $P(n) = \tfrac{1}{n+1}$ the antecedent is $1$, and the consequent is $\neg \neg 0 = 0$, so the value is $1 \to 0 = 0$.

### Axiomatizations

Every first-order Gödel logic extends [[intuitionistic predicate logic|MW0RVDRFTA]] by prelinearity and the constant domain axiom.
For $V = [0, 1]$ these extra axioms suffice, by Horn's theorem of 1969.
For other $V$ the answer depends on $V$, and Baaz, Preining and coauthors studied which $\mathrm{G}_V$ are recursively axiomatizable.

### Watch out

Do not assume that every infinite $V$ gives the same first-order logic, as in the propositional case, since the separating sentence refutes this.
Do not read $\forall$ as a minimum either.
Over an infinite domain the infimum need not be attained, and this is the source of the dependence on $V$.
Finally, the constant domain axiom is an extra law, so first-order Gödel logic is more than intuitionistic logic plus prelinearity.

### History

Mostowski proposed the lattice-valued semantics of quantifiers in 1961.
Horn gave an axiomatization of first-order Gödel logic over $[0, 1]$ in 1969.
Baaz and Preining surveyed the field of first-order Gödel logics in the Handbook of Mathematical Fuzzy Logic of 2011.

### Try it

Let $V = \{ 1 - \tfrac1n : n \ge 1 \} \cup \{ 1 \}$, which contains $0$ at $n = 1$.
Every nonempty subset has a least element, because $V$ is well ordered.
So $\exists x (P(x) \to \forall y P(y))$ is in $\mathrm{G}_V$, though it is not in $\mathrm{G}_{[0, 1]}$.

## Explanations

### L1 human

Gödel logic measures truth by degrees, and it cares only about which statement is truer.
"For all $x$" takes the lowest degree over all $x$, and "there is an $x$" takes the highest.
With infinitely many objects, the lowest degree may only be approached and never reached.
Then the choice of allowed degrees changes which sentences are always true.

### L2 human

To test a sentence in $\mathrm{G}_V$, build a structure whose atomic values form a set without a least element, if $V$ allows one.
A decreasing sequence such as $\tfrac{1}{n+1}$, approaching $0$, is the typical tool.
Watch out: in $V = \{ 1 - \tfrac1n : n \ge 1 \} \cup \{ 1 \}$ there is no infinite strictly decreasing sequence, so this tool is not available there.

### L3 human

A $V$-structure is a model over the complete Heyting chain $V$, so intuitionistic predicate logic is sound for it.
If $V$ and $V'$ are order isomorphic, then $\mathrm{G}_V = \mathrm{G}_{V'}$, since the Gödel operations, $\inf$ and $\sup$ are defined from the order alone.
