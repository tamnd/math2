## Example

Let $\vdash$ be [[first-degree entailment|KXTP4P3GHT]], the logic of the four-element [[De Morgan algebra|5Q53XWV0QN]] $\mathbf{DM}_4 = \set{\mathbf{F}, \mathbf{N}, \mathbf{B}, \mathbf{T}}$ with designated set $\set{\mathbf{T}, \mathbf{B}}$.
Here $\mathbf{N}$ and $\mathbf{B}$ are fixed by $\lnot$, and $\mathbf{F} < \mathbf{N}, \mathbf{B} < \mathbf{T}$.
We show that $\vdash$ is not protoalgebraic; see [[the Leibniz hierarchy|6JT3CMJT8F]].

1. $\vdash$ has no theorems. Send every variable to $\mathbf{N}$. The set $\set{\mathbf{N}}$ is closed under $\lnot$, $\land$ and $\lor$, so every formula takes the value $\mathbf{N}$, which is not designated.
2. $x \nvdash y$: send $x$ to $\mathbf{T}$ and $y$ to $\mathbf{F}$.
3. By step 1, the empty set is a theory, and $\Omega(\emptyset) = \mathrm{Fm} \times \mathrm{Fm}$, since every congruence is compatible with $\emptyset$.
4. Let $T$ be the theory of $\set{x}$. By step 2, $y \notin T$, so the pair $(x, y)$ is not compatible with $T$ and $\Omega(T) \ne \mathrm{Fm} \times \mathrm{Fm}$.
5. So $\emptyset \subseteq T$ but $\Omega(\emptyset) \not\subseteq \Omega(T)$: the Leibniz operator is not monotone, and $\vdash$ is not protoalgebraic.

## Remarks

1. The same conclusion follows from the syntactic test: a set $\Delta(x, y, \vec{z})$ with $\vdash \Delta(x, x, \vec{z})$ must be empty by step 1, and then $x, \Delta(x, y, \vec{z}) \vdash y$ fails by step 2.
2. The argument shows that every logic with no theorems, in which not every formula follows from every other, is not protoalgebraic.
3. First-degree entailment is studied instead with the general theory of Font and Jansana; its natural algebras are the De Morgan lattices.

## Explanations

### L1 human

First-degree entailment has no formula that is always true.
Without such formulas there is no way to say that two formulas are equivalent, and the logic falls below the lowest level of the Leibniz hierarchy.

### L2 human

1. Assign the value "neither true nor false" to every variable.
2. Then every formula built with "and", "or" and "not" has this value too.
3. So no formula is true under all assignments, and no formula can express equivalence.

The typical use: the empty theory and one nontrivial theory are enough to show that the Leibniz operator is not monotone.
The trap: first-degree entailment has a good class of algebras, the De Morgan lattices, but having algebras is not the same as being protoalgebraic.
