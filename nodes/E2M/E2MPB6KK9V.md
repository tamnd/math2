## Example

A student has met many functions in school: $f(x) = 2x + 1$, $g(x) = x^2$, $h(x) = \sin x$.
Each was given by one formula.
The student forms the [[concept image|C5S2X0WDJ8]]: "a function is a formula in $x$".
The concept definition of a [[function|0EPAT51DXQ]] from $\mathbb{R}$ to $\mathbb{R}$ is a rule that assigns to each real number $x$ exactly one real number $f(x)$.
We test the image on three examples.

1. $F(x) = x^2$ for $x \neq 0$, and $F(0) = 1$. Each $x$ has exactly one value, so $F$ is a function by the definition. The image hesitates, because $F$ is not given by one formula.
2. $G(x) = 5$ for all $x$. Each $x$ has exactly one value, so $G$ is a function. The image hesitates, because the formula has no $x$.
3. $H(x) = 1$ if $x$ is rational, and $H(x) = 0$ if $x$ is irrational. Each $x$ has exactly one value, so $H$ is a function. The image rejects it, because no formula of school type gives it.

In each case the definition accepts a function that the image rejects or doubts, so the image conflicts with the definition.

## Remarks

Shlomo Vinner (1983) studied concept images of function among students who had learned the set definition, and found that many judged examples by formulas and graphs.
The example $G$ shows that "a formula in $x$" is not the issue: a constant formula is still a formula, but it does not "use" $x$.
The image is useful in many calculations, and it fails when the student must decide whether an object is a function.

## Explanations

### L1 human

Most functions in school are given by a formula, like $x^2$ or $2x + 1$.
So students think that a function is the same thing as a formula.
But a function only needs to give one answer for each input.
"Give $1$ for rational numbers and $0$ for irrational numbers" is a function, even with no formula of the usual kind.

### L2 human

1. State the image: "a function is a formula".
2. State the definition: "exactly one output for each input".
3. Test objects that satisfy the definition but not the image: a function by cases, a constant function, a function with no formula.
4. Ask the student to decide by the definition.

A trap is to accept "it is a function because the teacher says so".
The aim is that the student checks the definition, and so adds the new examples to the image.
