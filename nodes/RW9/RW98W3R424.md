## Summary

Four-dimensional variational assimilation, or 4D-Var, is a method of [[data assimilation|TKT0QAPWW8]] that fits a model trajectory to all the observations made during a time window.
It chooses the initial state of the window that minimises a cost function.
The cost measures the misfit to a background estimate and to the observations along the trajectory.
The gradient of the cost function is computed by a backward integration of the adjoint model, which makes the method an [[optimal control|T3V6ZNAMDN]] problem.
It is used to produce the initial conditions of several major operational weather forecasting systems.

## Explanations

### L1 human

Observations of the atmosphere arrive at many different times, not all at once.
4D-Var asks: which starting state, run forward with the weather model, best passes through all of these observations, while staying close to the previous forecast?
Searching over millions of possible starting states needs to know which way to change each number.
The adjoint model provides this direction at the cost of about one extra model run.
The result is a starting state that is consistent with the model's physics and with the observations over the whole window.
