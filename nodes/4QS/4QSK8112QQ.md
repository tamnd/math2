## Example

Read a string over $k$ letters as a number in base $k$, but with the digits $1$ to $k$ instead of $0$ to $k - 1$.
Over $\{a, b\}$, with $a$ as the digit $1$ and $b$ as the digit $2$, the string $ab$ becomes $1 \cdot 2 + 2 = 4$.

In general, let $\Sigma = \{a_1, \ldots, a_k\}$ be a finite alphabet with $k \ge 2$ symbols.
For the language of arithmetic we can take the $12$ symbols $\neg, \to, \forall, =, (, ), 0, S, +, \cdot, v, '$ and write the variable $v_i$ as $v$ followed by $i$ primes.
Define
$$\#(a_{d_1} a_{d_2} \cdots a_{d_n}) = d_1 k^{n-1} + d_2 k^{n-2} + \cdots + d_n,$$
with each digit $d_j \in \{1, \ldots, k\}$, and give the empty string the code $0$.
We check that $\#$ is a [[Gödel numbering|MFJXPAF0R0]] whose set of codes is all of $\mathbb{N}$.

1. The sum is computed from the digits by $n$ multiplications and additions, so $\#$ is [[computable|KZSB5E471K]].
2. The last digit is determined by the code.
   We have $\#(w a_d) = k \cdot \#(w) + d$ with $1 \le d \le k$, so $d$ is the unique number in $\{1, \ldots, k\}$ with $d \equiv \#(w a_d) \pmod k$.
3. To decode $m \ge 1$, let $d$ be as in step 2 and set $m' = (m - d)/k$.
   Then $0 \le m' < m$, and $m$ is the code of the string for $m'$ followed by $a_d$.
4. Repeating step 3 reaches $0$ after finitely many steps, because the numbers decrease.
   The digits found, read backwards, give a string $w$ with $\#(w) = m$.
5. Step 4 gives a string for every $m \in \mathbb{N}$, so every number is a code, and the set of codes is $\mathbb{N}$, which is decidable.
6. The map is injective.
   By step 2, two strings with the same code have the same last digit and the same code without it, and induction on the length gives equal strings.
7. Steps 3 and 4 compute the inverse map, so all three conditions of a Gödel numbering hold.

## Remarks

For $k = 2$ the first codes are easy to list.
The empty string, $a$, $b$, $aa$, $ab$, $ba$, $bb$ and $aaa$ get the codes $0$ to $7$ in this order.
This is the length-lexicographic order: shorter strings first, and strings of the same length in dictionary order.

The numbering differs from the prime-power numbering in two ways.
It is a bijection, so every number names a string and no number is wasted.
Its codes are also much smaller: a string of length $n$ gets a code below $k^{n+1}$, while prime-power codes grow faster than any exponential in $n$.

Why not use the usual digits $0$ to $k - 1$?
Then $a_0$ and $a_0 a_0$ would both get the code $0$, just as $7$ and $007$ are the same number.
Leading zeros break injectivity, and the shift to the digits $1$ to $k$ repairs it.

## Explanations

### L1 human

Write the letters as the digits $1$ and $2$, and read a string as a number in a special base $2$.
The string $ab$ becomes $1 \cdot 2 + 2 = 4$.
The string $ba$ becomes $2 \cdot 2 + 1 = 5$.
Every whole number comes from exactly one string, so nothing is wasted.

### L2 human

We decode $m = 11$ with $k = 2$, $a$ as $1$ and $b$ as $2$.
Since $11$ is odd, its last digit is $1$, the letter $a$, and $(11 - 1)/2 = 5$.
Since $5$ is odd, the next digit is $1$, the letter $a$, and $(5 - 1)/2 = 2$.
Since $2$ is even, the next digit is $2$, the letter $b$, and $(2 - 2)/2 = 0$, so we stop.
Reading the digits backwards gives the string $baa$.
Check:
$$2 \cdot 2^2 + 1 \cdot 2 + 1 = 11.$$
The decoding needed only division with remainder, which is why the inverse of the numbering is computable.
