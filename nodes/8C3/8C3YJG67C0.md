## Definition

Let $\Sigma$ be a finite alphabet of character states, such as the four nucleotides, the twenty amino acids or the sense codons.
A *substitution model* on $\Sigma$ is a [[continuous-time Markov chain|TWQFE0FZZS]] with state space $\Sigma$, given by a rate matrix $Q = (q_{ij})_{i, j \in \Sigma}$.
The entries satisfy $q_{ij} \ge 0$ for $i \ne j$ and $\sum_{j} q_{ij} = 0$ for each $i$.
The probability that state $i$ has become state $j$ after time $t \ge 0$ is the entry $P_{ij}(t)$ of the [[matrix exponential|020M04FN1H]] $P(t) = e^{tQ}$.
Each site of a sequence evolves by this chain, independently of the other sites.

## Remarks

Most models used in practice are also assumed to have a [[stationary distribution|0KRH5157WP]] $\pi$ and to be time-reversible, that is, to satisfy [[detailed balance|CTGN6CK1ZS]] $\pi_i q_{ij} = \pi_j q_{ji}$.
The matrix is usually scaled so that $-\sum_i \pi_i q_{ii} = 1$; then time is measured in expected substitutions per site.
Example: on $\Sigma = \set{A, C, G, T}$, the matrix with $q_{ij} = 1/3$ for $i \ne j$ and $q_{ii} = -1$ is a rate matrix: off-diagonal entries are nonnegative and each row sums to $0$.
It is the Jukes–Cantor model, scaled to one substitution per site per unit time.
Non-example: a matrix with $q_{ii} = -1$ and $q_{ij} = 1/2$ for $i \ne j$ on four states has row sums $1/2 \ne 0$, so it is not a rate matrix.
