## Definition

A truth valuation gives every formula the value $0$ or $1$ in a way that respects the truth tables of the connectives.

Let $P$ be a set of propositional variables, and let $\mathrm{Form}$ be the set of [[propositional formulas|TT7WT5HPN9]] over $P$.

1. A truth assignment is a function $v \colon P \to \{ 0, 1 \}$.
2. A truth valuation is a function $V \colon \mathrm{Form} \to \{ 0, 1 \}$ such that, for all formulas $\varphi$ and $\psi$,
   $$V((\neg \varphi)) = 1 - V(\varphi), \qquad V((\varphi \land \psi)) = \min(V(\varphi), V(\psi)), \qquad V((\varphi \lor \psi)) = \max(V(\varphi), V(\psi)),$$
   $$V((\varphi \to \psi)) = \max(1 - V(\varphi), V(\psi)), \qquad V((\varphi \leftrightarrow \psi)) = \begin{cases} 1 & \text{if } V(\varphi) = V(\psi), \\ 0 & \text{otherwise.} \end{cases}$$
3. If the formulas include the constants $\top$ and $\bot$, a truth valuation also satisfies $V(\top) = 1$ and $V(\bot) = 0$.
4. For a truth assignment $v$, the valuation $\bar v$ is the unique truth valuation with $\bar v(p) = v(p)$ for each $p \in P$, and $\bar v(\varphi)$ is the truth value of $\varphi$ under $v$.

## Notation

The five clauses are the [[truth tables|05RSK4Q657]] of the connectives, written as arithmetic on $\{ 0, 1 \}$.
After the extension theorem we write $v(\varphi)$ for $\bar v(\varphi)$, and $v \models \varphi$ for $v(\varphi) = 1$.

## Remarks

### Reading the clauses

Each clause is one truth table in a single formula.
The clause for $\land$ takes the smaller value, so the conjunction is $1$ only when both parts are $1$.
The clause for $\to$ is $0$ only when $V(\varphi) = 1$ and $V(\psi) = 0$, as we can check row by row:
$$\max(0, 1) = 1, \qquad \max(0, 0) = 0, \qquad \max(1, 1) = 1, \qquad \max(1, 0) = 1,$$
for the rows $(1, 1)$, $(1, 0)$, $(0, 1)$ and $(0, 0)$.
The clauses must hold for all formulas $\varphi$ and $\psi$, not only for variables; that is what forces the value of a long formula.

### Why item 4 is a correct definition

Item 4 speaks of "the unique" valuation, so it needs a theorem: each assignment has exactly one extension.
The [[concept page|H31CS3HK5P]] proves this extension theorem, and the proof rests on the [[unique readability theorem|6KBJX91N7G]].
Item 2 defines valuations without any assignment, and the theorem then shows that restriction $V \mapsto V|_P$ is a bijection from valuations to assignments.

### A small example and a failure

The assignment $p = 1$, $q = 0$ extends to the valuation with $\bar v(p \lor q) = 1$, $\bar v(p \land q) = 0$ and $\bar v(\neg q) = 1$.
The map that gives $1$ to every formula fails the first clause, since $V(\neg p)$ would have to be $1 - 1 = 0$.
[[A map that is not a valuation|WZ0QZBR9ST]] gives a subtler failure, which agrees with an assignment on all variables.

### Fewer connectives

In the [[Hilbert system|1MGMQX43B8]] $L$, with only $\neg$ and $\to$ as primitive connectives, only the clauses for $\neg$ and $\to$ are needed.
The other connectives get their values through their definitions.
For example, $\varphi \lor \psi$ abbreviates $\neg \varphi \to \psi$, and
$$\max(1 - (1 - a), b) = \max(a, b)$$
is the table of $\lor$, as it should be.

## Explanations

### L1 human

A truth assignment says which letters are true.
A truth valuation says which formulas are true, and it must follow the tables of the connectives.
For example, if a valuation makes $p$ true, it must make "not $p$" false, and it must make "$p$ or $q$" true.

### L2 human

We find all valuations that make $\neg p \to q$ false.
By the clause for $\to$, we need $V(\neg p) = 1$ and $V(q) = 0$.
By the clause for $\neg$, $V(\neg p) = 1$ means $V(p) = 0$.
So exactly the valuations with $p = 0$ and $q = 0$ make the formula false.
Check: then $\max(1 - 1, 0) = 0$.
This is how we use the clauses in reverse, to find a countermodel.
