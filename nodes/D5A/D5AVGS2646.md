## Definition

Let $\varepsilon$ denote the empty [[string|1P6EP01HZF]].
An *$\varepsilon$-NFA* is a tuple $N = (Q, \Sigma, \Delta, q_0, F)$ where:

1. $Q$ is a nonempty finite set of states;
2. $\Sigma$ is an [[alphabet|RABRP2KG81]] with $\varepsilon \notin \Sigma$;
3. $\Delta \colon Q \times (\Sigma \cup \set{\varepsilon}) \to \mathcal{P}(Q)$ is the transition function, with values in the [[power set|00E0YZCERH]] of $Q$;
4. $q_0 \in Q$ is the initial state;
5. $F \subseteq Q$ is the set of accepting states.

The automaton $N$ *accepts* a string $w \in \Sigma^*$ when $w = y_1 y_2 \cdots y_m$ for some $y_1, \ldots, y_m \in \Sigma \cup \set{\varepsilon}$, and there are states $r_0, \ldots, r_m$ with $r_0 = q_0$, $r_i \in \Delta(r_{i-1}, y_i)$ for $1 \le i \le m$, and $r_m \in F$.
The *language of* $N$ is the [[formal language|5MFZ4VNY6D]] $L(N)$ of all strings that $N$ accepts.

## Remarks

Example: over $\Sigma = \set{a, b}$, let $Q = \set{0, 1, 2}$, $q_0 = 0$, $F = \set{1, 2}$, $\Delta(0, \varepsilon) = \set{1, 2}$, $\Delta(1, a) = \set{1}$, $\Delta(2, b) = \set{2}$, and $\Delta = \emptyset$ on all other pairs.
The word $aa$ is accepted with $y = (\varepsilon, a, a)$ and states $0, 1, 1, 1$, and $L(N) = \set{a^m : m \ge 0} \cup \set{b^n : n \ge 0}$.
Non-example: the word $ab$ is not accepted, since after reading $a$ every run is in state $1$, which has no $b$-move.
The *$\varepsilon$-closure* $E(q)$ of a state $q$ is the set of states reachable from $q$ by $\varepsilon$-moves alone.
Replacing $\Delta(q, a)$ by $\bigcup_{p \in E(q)} \bigcup_{r \in \Delta(p, a)} E(r)$ and making $q$ accepting when $E(q) \cap F \ne \emptyset$ removes the $\varepsilon$-moves without changing the language.
