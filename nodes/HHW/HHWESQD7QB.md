## Summary

The point spread function of an imaging system is the image it makes of a single point of light.
Take a linear system that acts the same way at every position.
Then the image of any object is the [[convolution|2Z29JN3VES]] of the object with the point spread function.
So this one function describes the whole blurring of the system.
For a perfect lens with a circular opening it is the [[Airy disk|DB435TBQJT]] pattern.

## Explanations

### L1 human

No lens makes a point of light into a perfect point.
It makes a small blob, and the shape of this blob is the point spread function.
An object is a sum of many points, so its image is a sum of many such blobs, one per point, each as bright as its point.
A star photographed with a telescope shows the point spread function almost directly.
A smaller blob means a sharper system.
