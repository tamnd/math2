## Example

### The two theories

Let PA be first-order [[Peano arithmetic|0QFT7Z76N5]] in the language with $0$, $S$, $+$ and $\cdot$.
Its axioms are the following sentences, and the schema (Ind) has one axiom for each formula $A(x, \bar y)$.

- (P1) $\forall x \, \lnot(S(x) = 0)$.
- (P2) $\forall x \, \forall y \, (S(x) = S(y) \to x = y)$.
- (P3) $\forall x \, (x + 0 = x)$ and (P4) $\forall x \, \forall y \, (x + S(y) = S(x + y))$.
- (P5) $\forall x \, (x \cdot 0 = 0)$ and (P6) $\forall x \, \forall y \, (x \cdot S(y) = x \cdot y + x)$.
- (Ind) $\forall \bar y \, \bigl(A(0, \bar y) \land \forall x \, (A(x, \bar y) \to A(S(x), \bar y)) \to \forall x \, A(x, \bar y)\bigr)$.

We give an [[interpretation|8H03GRMDYG]] $I$ of PA in [[Zermelo-Fraenkel set theory|0HE5WDQ9FJ]] ZF.
A set is *inductive* when it contains $\emptyset$ and contains $x \cup \{x\}$ for each of its elements $x$.
By the [[axiom of infinity|X0B4YT5FA7]] an inductive set exists.
By Separation, the elements of that set that lie in every inductive set form a set $\omega$.
So $\omega$ is the least inductive set, and ZF proves that it exists and is unique.

### The dictionary

The interpretation $I$ consists of the following formulas of set theory.

1. The domain is $\delta(x) := x \in \omega$.
2. The constant $0$ is the empty set: $\varphi_0(y) := \forall z \, (z \notin y)$.
3. The successor is $x \cup \{x\}$: $\varphi_S(x, y) := \forall z \, (z \in y \leftrightarrow (z \in x \lor z = x))$.
4. Addition is the formula "$a(x_1, x_2) = y$", where $a \colon \omega \times \omega \to \omega$ is the unique function with $a(m, \emptyset) = m$ and $a(m, n \cup \{n\}) = a(m, n) \cup \{a(m, n)\}$.
5. Multiplication is the formula "$g(x_1, x_2) = y$", where $g \colon \omega \times \omega \to \omega$ is the unique function with $g(m, \emptyset) = \emptyset$ and $g(m, n \cup \{n\}) = a(g(m, n), m)$.

The functions $a$ and $g$ exist and are unique by the recursion theorem on $\omega$, a theorem of ZF; see [[definition by recursion|0DSHAVH45F]].
Let $B$ be the set of functions from $\omega$ to $\omega$, which exists by Power set and Separation.
For $a$, the recursion theorem gives $H \colon \omega \to B$ with $H(\emptyset) = (m \mapsto m)$ and $H(n \cup \{n\}) = (m \mapsto H(n)(m) \cup \{H(n)(m)\})$, and we put $a(m, n) := H(n)(m)$.
For $g$, it gives $G \colon \omega \to B$ with $G(\emptyset) = (m \mapsto \emptyset)$ and $G(n \cup \{n\}) = (m \mapsto a(G(n)(m), m))$, and we put $g(m, n) := G(n)(m)$.
Uniqueness follows by induction on $n$, in the form of step 9 below.

### The conditions on the symbols

We check the conditions of an interpretation, one step for each condition, and each step is an argument in ZF.

1. The domain is not empty: $\emptyset \in \omega$, because $\omega$ is inductive.
2. The empty set exists and is unique by Extensionality, and it lies in $\omega$ by step 1.
3. The successor is a total function on $\omega$.
   For $x \in \omega$ the set $x \cup \{x\}$ exists by Pairing and Union, it is unique by Extensionality, and it lies in $\omega$ because $\omega$ is inductive.
4. Addition and multiplication are total functions on $\omega$.
   For $x_1, x_2 \in \omega$ the values $a(x_1, x_2)$ and $g(x_1, x_2)$ exist, are unique and lie in $\omega$, by the recursion theorem.

### The translated axioms

5. (P1) holds because $x \in x \cup \{x\}$, so $x \cup \{x\}$ is not empty and differs from $\emptyset$.
6. For (P2), let $x, y \in \omega$ with $x \cup \{x\} = y \cup \{y\}$, and suppose that $x \ne y$.
   Then $x \in y \cup \{y\}$ and $x \ne y$ give $x \in y$, and in the same way $y \in x$.
   So the set $\{x, y\}$ has no $\in$-minimal element, against the [[axiom of foundation|NFQ9FVCP31]], and hence $x = y$.
7. (P3) and (P4) are the equations that define $a$.
   The translation of (P4) first unnests the terms $S(y)$, $x + S(y)$ and $x + y$, and by steps 3 and 4 each of them has exactly one value in $\omega$.
8. (P5) and (P6) are the equations that define $g$.
9. For (Ind), fix parameters $\bar y$ in $\omega$ and assume the translated hypotheses: $A^I(\emptyset, \bar y)$, and $A^I(x, \bar y) \to A^I(x \cup \{x\}, \bar y)$ for each $x \in \omega$.
   By Separation, $X = \{n \in \omega : A^I(n, \bar y)\}$ is a set, and by the hypotheses it is inductive.
   Since $\omega$ is the least inductive set, $\omega \subseteq X$, so $A^I(n, \bar y)$ holds for each $n \in \omega$.

So $I$ is an interpretation, and $\mathsf{ZF} \rhd \mathsf{PA}$.

## Remarks

The example shows the standard pattern of an interpretation: a domain, explicit definitions of the symbols, and a proof in $S$ of each translated axiom.
The induction schema becomes one instance of Separation for each formula $A$, together with the minimality of $\omega$.
As a consequence, if ZF is consistent, then PA is consistent.

The proof uses only Extensionality, Empty set, Pairing, Union, Power set, Infinity, Separation and Foundation.
So Zermelo set theory with the axiom of foundation also interprets PA, and Replacement is not needed.
If we change the successor to $x \mapsto \{x\}$, and the domain to the least set that contains $\emptyset$ and is closed under $x \mapsto \{x\}$, we get Zermelo's numerals.
The same steps give a second interpretation, with (P2) following from Extensionality alone, since $\{x\} = \{y\}$ gives $x = y$.

ZF proves more than the translated axioms: it proves that $\omega$ is a model of PA, and so it proves the translation of $\mathrm{Con}(\mathsf{PA})$.
Hence ZF also interprets $\mathsf{PA} + \mathrm{Con}(\mathsf{PA})$, which PA itself does not, by the [[non-example|NN7696NJR6]].
Watch out: interpreting a theory is weaker than proving its consistency, since PA interprets PA but does not prove $\mathrm{Con}(\mathsf{PA})$.

## Explanations

### L1 human

Set theory knows only sets and the relation "is an element of".
It can still speak about numbers.
The number $0$ is the empty set, $1$ is the set $\{0\}$, $2$ is the set $\{0, 1\}$, and $3$ is the set $\{0, 1, 2\}$.
The next number after $n$ is the set that has the elements of $n$ and also $n$ itself.
Each rule of arithmetic, for example "$0$ is not the next number of any number", becomes a fact about sets that set theory can prove.

### L2 human

We compute $1 + 1$ and $2 \cdot 2$ in the interpretation, to see that the definitions give the usual values.
The first numbers are $0 = \emptyset$, $1 = \{\emptyset\}$, $2 = \{\emptyset, \{\emptyset\}\}$, $3 = 2 \cup \{2\}$ and $4 = 3 \cup \{3\}$.
Use the second equation for $a$ once, then the first:
$$a(1, 1) = a(1, 0) \cup \{a(1, 0)\} = 1 \cup \{1\} = 2.$$
For $2 \cdot 2$ we first need $g(2, 1) = a(g(2, 0), 2) = a(0, 2)$, and two uses of the second equation for $a$ give $a(0, 2) = 2$.
Then
$$g(2, 2) = a(g(2, 1), 2) = a(2, 2) = a(2, 1) \cup \{a(2, 1)\} = 3 \cup \{3\} = 4,$$
since $a(2, 1) = 2 \cup \{2\} = 3$.
Check: $4 = \{0, 1, 2, 3\}$ has four elements, as it should.

The typical use is a relative consistency proof, and the construction is the first step of arithmetic inside set theory.
Watch out: do not prove the induction schema with one set $X$ for all formulas at once; Separation gives one set for each formula $A$, and that is all that the schema needs.
