## Definition

Let $k \ge 1$ and $\ell \ge 1$ be integers, and let $\Omega$ be a [[probability distribution|0DVDCMA2DK]] on $\set{1, \dots, k}$, the degree distribution.
The input is a list of $k$ symbols $x_1, \dots, x_k \in \F_2^{\ell}$.
The *LT code* with degree distribution $\Omega$ produces a sequence of output symbols $y_1, y_2, \dots$; the $j$-th one is formed as follows, independently for each $j$.

1. Draw a degree $d_j$ from $\Omega$.
2. Draw a set $S_j \subseteq \set{1, \dots, k}$ of size $d_j$ uniformly among all such sets.
3. Output $y_j = \bigoplus_{i \in S_j} x_i$, the bitwise sum modulo $2$, together with the set $S_j$ or a seed from which the receiver can recompute it.

## Remarks

The receiver gets some of the output symbols, for instance after losses on an [[erasure channel|ESYMTB37YG]].
It decodes by peeling: while some received $y_j$ has exactly one unknown input in $S_j$, it solves for that input.
Then it substitutes the input into the other received symbols.
The ideal soliton distribution is $\rho(1) = 1/k$ and $\rho(d) = 1/(d(d - 1))$ for $2 \le d \le k$; it sums to $1$ since $\sum_{d=2}^{k} \big(\frac{1}{d-1} - \frac{1}{d}\big) = 1 - \frac{1}{k}$.
Luby's robust soliton distribution modifies it so that, for a failure probability $\delta$, $k + O\big(\sqrt{k} \ln^2 (k/\delta)\big)$ received symbols suffice for peeling to recover all inputs with probability at least $1 - \delta$.

Example: $k = 3$ with received symbols $y_1 = x_1$, $y_2 = x_1 \oplus x_2$ and $y_3 = x_2 \oplus x_3$.
Peeling gives $x_1 = y_1$, then $x_2 = y_2 \oplus x_1$, then $x_3 = y_3 \oplus x_2$.

Non-example: if $\Omega$ puts all its mass on degree $2$, the construction is still an LT code, but peeling never starts, since no received symbol has degree $1$.
A code that uses fixed sets $S_1, \dots, S_n$ chosen in advance is a fixed linear block code of length $n$, not a rateless LT code.
