## Statement

Every linear system has a least-squares solution, the closest point $A \hat x$ is always unique, and $\hat x$ itself is unique exactly when the columns of $A$ are independent.

Let $A$ be a real $m \times n$ matrix and let $b \in \R^m$.
Let $p$ be the [[orthogonal projection|0Q8HZTJC7G]] of $b$ onto the [[column space|0F0RPPJ2TT]] $\operatorname{Col}(A)$.
Then the following hold.

1. Existence: the system $Ax = b$ has at least one [[least-squares solution|0BYTQ4X1HC]].
2. A vector $\hat x \in \R^n$ is a least-squares solution if and only if $A \hat x = p$.
3. If $\hat x$ is one least-squares solution, then the set of all least-squares solutions is $\hat x + \operatorname{Nul}(A)$, where $\operatorname{Nul}(A)$ is the [[null space|0PQ2GGY1QV]] of $A$.
4. Uniqueness: the least-squares solution is unique if and only if the columns of $A$ are [[linearly independent|0CRMGPAH83]].

The [[proof|4XW9MXQYKZ]] applies the best approximation theorem to the subspace $\operatorname{Col}(A)$.

## Remarks

### Why each hypothesis is needed

Independence of the columns is exactly what uniqueness needs.
In [[the example with dependent columns|FM9VEAKSA7]], the second column is twice the first, and every $x$ with $x_1 + 2x_2 = 3$ is a least-squares solution.
The null space there is the line $\R(-2, 1)$, and part 3 says that the solutions fill a copy of that line.

The Euclidean norm is the hidden hypothesis behind part 2.
With the norm $\max_i \abs{y_i}$ the closest point of a subspace need not be unique.
Take the line $U = \R(1, 0)$ in $\R^2$ and $b = (0, 1)$.
The distance from $b$ to $(t, 0)$ in that norm is $\max(\abs{t}, 1)$, which equals $1$ for every $t$ with $\abs{t} \le 1$, so a whole segment of $U$ is closest.

### What it gives you

Part 2 says that the closest point $A \hat x = p$ is the same for every least-squares solution, even when $\hat x$ is not unique.
The [[normal equations|4D7MRG4D91]] turn part 2 into a square linear system that we can solve by hand.
When the columns are independent, that system has the unique solution
$$\hat x = (A^{\mathsf{T}} A)^{-1} A^{\mathsf{T}} b,$$
and this formula needs the independence, because only then is $A^{\mathsf{T}} A$ invertible.
When the columns are dependent, the [[minimum-norm solution|QM2Y84VDX8]] theorem, applied to the consistent system $Ax = p$, picks the shortest solution, which is the one in the row space.

### The converse

Part 4 is already an equivalence, so its converse is part of the statement.
There is also a link with exact solutions.
If $Ax = b$ is consistent, then $b$ lies in $\operatorname{Col}(A)$, so $p = b$, and part 2 says that the least-squares solutions are exactly the ordinary solutions.

### Generalizations

The same statement holds over $\C$, with the conjugate transpose in place of the transpose.
It holds for every linear map $T$ from a vector space into an inner product space whose image is finite-dimensional: the solutions form the coset $\hat x + \ker T$.

## Explanations

### L1 human

A linear system may have no exact answer, but it always has a best approximate answer.
The best approximate value of $Ax$ is always one definite vector, the closest point to $b$.
The recipe $x$ that produces it may not be unique: if two columns of $A$ point the same way, there are many ways to mix them and reach the same point.

### L2 human

Take
$$A = \begin{pmatrix} 1 & 0 \\ 0 & 1 \\ 0 & 0 \end{pmatrix}, \qquad b = \begin{pmatrix} 1 \\ 2 \\ 3 \end{pmatrix}.$$
The column space is the plane $x_3 = 0$ in $\R^3$, so the projection of $b$ is $p = (1, 2, 0)$.
The equation $A \hat x = p$ gives $\hat x = (1, 2)$.
The columns are independent, so part 4 says that no other least-squares solution exists.
The residual is $b - p = (0, 0, 3)$, and the least distance from $b$ to the column space is $3$.
The typical use of the theorem is to know in advance whether a fitting problem has one answer.
A common mistake is to think that dependent columns make the problem unsolvable, when they only make the answer non-unique.

### L3 human

The set of least-squares solutions is an affine subspace parallel to $\ker T$, so the problem is well posed only up to the kernel.
When the domain is also an inner product space of finite dimension, the [[Moore-Penrose pseudoinverse|0YY8VX28JR]] picks the point of this affine subspace that is closest to $0$.
In statistics, dependent columns of a design matrix are called collinear regressors, and then the parameters cannot be identified from the data, although the fitted values can.
