## Statement

Let $A$ be a real $m \times n$ matrix and let $b \in \R^m$.
Let $p$ be the [[orthogonal projection|0Q8HZTJC7G]] of $b$ onto the [[column space|0F0RPPJ2TT]] $\operatorname{Col}(A)$.
Then:

1. Existence: $Ax = b$ has at least one [[least-squares solution|0BYTQ4X1HC]].
2. A vector $\hat x$ is a least-squares solution if and only if $A \hat x = p$. So the closest point $A \hat x$ is the same for all least-squares solutions.
3. If $\hat x$ is one least-squares solution, then the set of all of them is $\hat x + \operatorname{Nul}(A)$, where $\operatorname{Nul}(A)$ is the [[null space|0PQ2GGY1QV]].
4. Uniqueness: the least-squares solution is unique if and only if the columns of $A$ are [[linearly independent|0CRMGPAH83]].

The [[proof|4XW9MXQYKZ]] applies the best approximation theorem to $U = \operatorname{Col}(A)$.

## Remarks

### Why each hypothesis is needed

- Independent columns are needed for uniqueness: for [[the example with dependent columns|FM9VEAKSA7]], every $x$ with $x_1 + 2 x_2 = 3$ is a least-squares solution.
- The Euclidean norm matters: for the norm $\max_i \abs{y_i}$, the closest point of a subspace need not be unique, and part 2 fails.

### Consequences

- Least-squares solutions are the solutions of the [[normal equations|4D7MRG4D91]].
- If $m \ge n$ and $A$ has rank $n$, then $\hat x = (A^{\mathsf{T}} A)^{-1} A^{\mathsf{T}} b$.
- If $A$ has dependent columns, the solution of smallest norm is the one in the row space of $A$, by the [[minimum-norm solution|QM2Y84VDX8]] theorem applied to $A x = p$.

### Converse

Part 4 is an equivalence.
If $Ax = b$ is consistent, then $p = b$, and part 2 says that the least-squares solutions are the exact solutions.

## Explanations

### L1 human

There is always a best approximate solution of a linear system.
It may not be unique: if two columns of $A$ point the same way, there are many ways to reach the same closest point.
The closest point itself is always unique.

### L2 human

For $A = \begin{pmatrix} 1 & 0 \\ 0 & 1 \\ 0 & 0 \end{pmatrix}$ and $b = (1, 2, 3)$:

1. $\operatorname{Col}(A)$ is the plane $x_3 = 0$, so $p = (1, 2, 0)$.
2. $A \hat x = p$ gives $\hat x = (1, 2)$, and the columns are independent, so it is unique.
3. The residual is $(0, 0, 3)$, and the least distance is $3$.

The typical use is to know in advance whether a least-squares problem has one answer.
The trap is to think that dependent columns make the problem unsolvable; they only make the answer non-unique.

### L3 human

The same statement holds over $\C$ with the conjugate transpose, and for any linear map $T$ from a vector space into an inner product space whose image is finite-dimensional.
The set of least-squares solutions is an affine subspace parallel to $\ker T$.
When the domain is also a finite-dimensional inner product space, the [[Moore-Penrose pseudoinverse|0YY8VX28JR]] picks the point of this set closest to $0$.
In statistics, dependent columns are called collinear regressors, and then the parameters cannot be identified from the data.
