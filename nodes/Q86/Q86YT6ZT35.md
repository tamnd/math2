## Definition

Let $X$ and $Y$ be real random variables with [[cumulative distribution functions|0H8H7ZTHW2]] $F$ and $G$.

1. $X$ dominates $Y$ in the *first order* if $F(t) \le G(t)$ for every $t \in \R$.
2. Assume that $X$ and $Y$ have finite [[expected values|0WQNRCNY3M]]. $X$ dominates $Y$ in the *second order* if $\int_{-\infty}^{t} F(s)\, ds \le \int_{-\infty}^{t} G(s)\, ds$ for every $t \in \R$.

## Remarks

Let $X$ be uniform on $[0, 2]$ and let $Y = 1$.
Then $Y$ dominates $X$ in the second order: for $0 \le t \le 2$, $\int_0^t F_X(s)\,ds - \int_0^t F_Y(s)\,ds = t^2/4 - \max(0, t - 1) = (t - 2)^2/4 \ge 0$ when $t \ge 1$, and $t^2/4 \ge 0$ when $t < 1$; for $t > 2$ both integrals equal $t - 1$.
Neither dominates the other in the first order: $F_X(1/2) = 1/4 > 0 = F_Y(1/2)$, while $F_Y(3/2) = 1 > 3/4 = F_X(3/2)$.
First-order dominance holds if and only if $\mathbb{E}[\varphi(X)] \ge \mathbb{E}[\varphi(Y)]$ for every nondecreasing function $\varphi$ for which both expectations exist; see [[monotone function|0A7KV2WB7A]].
Second-order dominance holds if and only if $\mathbb{E}[\varphi(X)] \ge \mathbb{E}[\varphi(Y)]$ for every nondecreasing [[concave|0GCM7B6PBK]] $\varphi$ for which both expectations exist.
First-order dominance implies second-order dominance.
