## Statement

A formula of [[intuitionistic predicate logic|MW0RVDRFTA]] is *monadic* if its predicate symbols are all unary, and it has no function symbols and no equality.

**Theorem (Kripke).** The set of monadic formulas provable in $\mathsf{IQC}$ is not decidable.
That is, no algorithm decides, for every monadic formula $\varphi$, whether $\mathsf{IQC} \vdash \varphi$.

The proof is in [[the proof by reduction from classical logic|JP8876HAAR]].

## Remarks

### Why each hypothesis is needed

1. The restriction to intuitionistic logic matters. The classical [[monadic predicate calculus|SERN6CRVWW]] is decidable, since a satisfiable monadic sentence has a model of bounded finite size.
2. Without quantifiers the fragment is propositional, and $\mathsf{IPC}$ is decidable by the finite model property.

### Consequences

1. The full predicate logic $\mathsf{IQC}$ is undecidable, which also follows from the [[Gödel-Gentzen translation|WC4TDGEWZR]] and [[Church's theorem|VA6BNNY2YC]].
2. Monadic intuitionistic logic does not have the finite model property, since a recursively axiomatized logic with this property is decidable.

### Converse

The set of monadic theorems is recursively enumerable, since $\mathsf{IQC}$ is recursively axiomatized.
So the set of monadic formulas that are not provable is not recursively enumerable.

### Generalizations

1. The one-variable fragment, with only one individual variable, is decidable. It corresponds to an intuitionistic analogue of the modal logic $\mathsf{S5}$.
2. Stronger forms are known: the monadic theorems of $\mathsf{IQC}$ and the monadic formulas valid on all finite Kripke frames form recursively inseparable sets.

## History

Kripke proved the theorem with his semantics for intuitionistic predicate logic.

## Explanations

### L1 human

In classical logic, statements about properties of single objects, such as "every $x$ that is red is round", can be checked mechanically.
In intuitionistic logic, the same kind of statement can not be checked by any algorithm.
The reason is that an intuitionistic model has many stages, and a pair of stages can play the role of a relation between two objects.

### L2 human

1. Suppose an algorithm $A$ decides monadic $\mathsf{IQC}$.
2. Use the cited translation $\tau$ from classical sentences with one binary predicate to monadic formulas.
3. Run $A$ on $\tau(\varphi)$; this decides classical validity of $\varphi$.
4. That contradicts the undecidability of classical logic with one binary predicate.

The typical use is as a contrast between classical and intuitionistic logic.
A trap: the one-variable fragment is decidable, so the proof needs formulas with several individual variables.

### L3 human

The one-variable fragment of intuitionistic predicate logic is the logic $\mathsf{MIPC}$ of Prior, which is decidable.
Recursive inseparability from the logic of finite frames shows that monadic $\mathsf{IQC}$ is not the logic of any recursive class of finite models.
