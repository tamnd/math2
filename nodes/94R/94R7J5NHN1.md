## Definition

Let $E$ be a finite set, and let $2^E$ be its [[power set|00E0YZCERH]].
A function $f \colon 2^E \to \R$ is *submodular* if
$$f(A) + f(B) \ge f(A \cup B) + f(A \cap B) \quad \text{for all } A, B \subseteq E.$$
It is *supermodular* if $-f$ is submodular, and *modular* if it is both.

## Remarks

Equivalent form, diminishing returns: $f$ is submodular if and only if
$$f(A \cup \set{x}) - f(A) \ge f(B \cup \set{x}) - f(B)$$
for all $A \subseteq B \subseteq E$ and $x \in E \setminus B$.

Example: let $G$ be a finite graph with vertex set $E$, and let $f(A)$ be the number of edges with exactly one end in $A$.
An edge with ends $u, v$ adds to $f(A) + f(B) - f(A \cup B) - f(A \cap B)$ an amount that is $0$ or $2$ in each case of the positions of $u$ and $v$.
So this cut function is submodular.
The [[rank function|SYRCTH853H]] of a matroid is submodular, and so is $f(A) = \abs{\bigcup_{i \in A} S_i}$ for fixed finite sets $S_i$.
The modular functions are the functions $f(A) = c + \sum_{a \in A} w(a)$, for a constant $c$ and weights $w \colon E \to \R$.

Non-example: on $E = \set{1, 2}$, let $f(A) = \abs{A}^2$.
For $A = \set{1}$ and $B = \set{2}$, the left side is $1 + 1 = 2$ and the right side is $4 + 0 = 4$, so the inequality fails.
In general $f(A) = g(\abs{A})$ is submodular exactly when $g$ is concave on $\set{0, 1, \dots, \abs{E}}$, in the sense that $g(k+1) - g(k)$ does not increase.
