## Proof

The plan: either some rational is a zero, or the sign of $f$ at rationals is decidable from the code and bisection runs.

Work in $\mathsf{RCA}_0$.
Let $\Phi$ be the code of $f$, with the notation $(a, r) \Phi (b, s)$ used for [[RCA0|XQENB067R3]].
### Two facts about the code

First we prove two facts about a real $z$ in the domain of $f$.

1. Fact F1: if $f(z) > 0$, then there is $(a, r) \Phi (b, s)$ with $\lvert z - a \rvert < r$ and with this property.
   Every $y$ in the domain with $\lvert y - a \rvert < r$ has $f(y) > 0$.
2. Proof of F1: the definition of the domain gives $(a, r) \Phi (b, s)$ with $\lvert z - a \rvert < r$ and $s < f(z)/3$.
3. Then $\lvert f(z) - b \rvert \le s$, so $b \ge f(z) - s > 2s$.
   For $y$ with $\lvert y - a \rvert < r$, we get $f(y) \ge b - s > s > 0$.
4. Fact F2: for a rational $q$ in the domain, $f(q) < 0$ holds exactly when there is $(a, r) \Phi (b, s)$ with $\lvert q - a \rvert < r$ and $b + s < 0$.
5. Proof of F2: if such a quintuple exists, then $f(q) \le b + s < 0$.
   Conversely, pick one with $s < -f(q)/3$, and then $b \le f(q) + s < -2s$, so $b + s < 0$.
   Likewise $f(q) > 0$ has a $\Sigma^0_1$ form.

### The case split and the bisection

6. Case A: some rational $q \in [0, 1]$ has $f(q) = 0$.
   Then $x = q$ is the required zero.
7. Case B: no rational $q \in [0, 1]$ has $f(q) = 0$.
   Then, for each such $q$, $f(q) < 0$ holds exactly when $f(q) > 0$ fails.
8. So, on the dyadic rationals of $[0, 1]$, the property $f(q) < 0$ has a $\Sigma^0_1$ form and a $\Pi^0_1$ form.
   $\Delta^0_1$ comprehension gives the set $N$ of dyadic $q \in [0, 1]$ with $f(q) < 0$.
9. Define $a_0 = 0$ and $b_0 = 1$.
   Given $a_n$ and $b_n$, let $m = (a_n + b_n)/2$.
   If $m \in N$, put $a_{n+1} = m$ and $b_{n+1} = b_n$, and otherwise put $a_{n+1} = a_n$ and $b_{n+1} = m$.
10. This is a primitive recursion with the parameter $N$, so $\mathsf{RCA}_0$ proves that the sequence $(a_n, b_n)_n$ exists.
11. By $\Sigma^0_0$ induction on $n$, with the parameters $N$ and $(a_n, b_n)_n$, we get four facts.
    They are $a_n \in N$, $b_n \notin N$, $a_n \le a_{n+1} \le b_{n+1} \le b_n$, and $b_n - a_n = 2^{-n}$.
12. The base case holds, since $f(0) < 0$ gives $0 \in N$ and $f(1) > 0$ gives $1 \notin N$.
13. For $k < l$, we have $0 \le a_l - a_k \le b_k - a_k = 2^{-k}$.
    So $x = (a_n)_n$ is a real, and $a_n \le x \le b_n$ for all $n$.

### The limit is a zero

14. Assume $f(x) > 0$.
    Take $(a, r) \Phi (b, s)$ as in F1 for $z = x$, and choose $n$ with $2^{-n} < r - \lvert x - a \rvert$.
15. Then $\lvert a_n - a \rvert \le \lvert a_n - x \rvert + \lvert x - a \rvert < r$, so $f(a_n) > 0$ by F1.
    This contradicts $a_n \in N$.
16. Assume $f(x) < 0$.
    The argument of steps 1 to 3 with the signs reversed, applied to $b_n$, gives $f(b_n) < 0$.
    So $b_n \in N$, a contradiction.
17. By trichotomy for reals, $f(x) = 0$.
    Also $0 \le x \le 1$, since $0 \le a_n \le 1$ for all $n$.

## Idea

The bisection method needs to decide the sign of $f$ at each midpoint.
The sign is decidable from the code when $f$ has no rational zero, and a rational zero ends the proof at once.
The law of excluded middle chooses between the two cases, so the proof is not uniform in $f$.

## Variants

The approximate version has a proof without the case split.
It says that for each rational $\varepsilon > 0$ there is a rational $q \in [0, 1]$ with $\lvert f(q) \rvert < \varepsilon$.
The proof searches the rationals for such a $q$, and the search ends by the theorem above, so it is computable uniformly in $f$ and $\varepsilon$.
The exact zero cannot be found uniformly, so the case split in step 6 is needed for the full theorem.
