## Example

We show that $\mathsf{RT}^2_2$ implies $\mathsf{CAC}$ over [[RCA0|XQENB067R3]], an arrow of the [[reverse mathematics zoo|E3X5B175ZR]].
$\mathsf{CAC}$ says that every infinite [[partial order|0QV2JS9RJ3]] $(P, \preceq)$ with $P \subseteq \N$ has an infinite chain or an infinite [[antichain|03HF498P1J]].
A *chain* is a set of pairwise comparable elements, and an *antichain* is a set of pairwise incomparable elements.
We argue in $\mathsf{RCA}_0 + \mathsf{RT}^2_2$.

1. Let $(P, \preceq)$ be a partial order with $P$ infinite. $\mathsf{RCA}_0$ proves that $P$ is the range of a strictly increasing function $p : \N \to \N$.
2. For $m < n$, put $c(\set{m, n}) = 0$ if $p(m) \preceq p(n)$ or $p(n) \preceq p(m)$, and $c(\set{m, n}) = 1$ otherwise.
3. The colouring $c$ exists by $\Delta^0_1$ comprehension. Its definition uses only $p$, $\preceq$ and no unbounded quantifier.
4. By $\mathsf{RT}^2_2$ there is an infinite set $H$ such that $c$ is constant on the pairs from $H$.
5. Let $G = \set{p(m) : m \in H}$. We have $y \in G$ if and only if some $m \le y$ has $m \in H$ and $p(m) = y$, because $p(m) \ge m$ for a strictly increasing $p$. So $G$ exists by $\Delta^0_1$ comprehension.
6. $G$ is infinite, because $p$ is one-to-one and $H$ is infinite.
7. If the constant colour is $0$, then any two elements $p(m), p(n)$ of $G$ with $m < n$ in $H$ are comparable. So $G$ is an infinite chain.
8. If the constant colour is $1$, then any two distinct elements of $G$ are incomparable. So $G$ is an infinite antichain.
9. Steps 7 and 8 cover both colours, so $(P, \preceq)$ has an infinite chain or an infinite antichain. This is $\mathsf{CAC}$.

## Remarks

The proof uses one application of $\mathsf{RT}^2_2$ and no induction beyond the $\Sigma^0_1$ induction of $\mathsf{RCA}_0$.
The converse fails: Hirschfeldt and Shore showed in 2007 that $\mathsf{CAC}$ does not imply $\mathsf{RT}^2_2$ over $\mathsf{RCA}_0$.
Hirschfeldt and Shore explain the gap this way: the colourings that come from orders are transitive in a certain sense, and a general colouring is not.
The same pattern, with the colour given by the order between $p(m)$ and $p(n)$, proves $\mathsf{RT}^2_2 \to \mathsf{ADS}$ directly.

## Explanations

### L1 human

Think of a large group of people, where some pairs can be ranked against each other and some pairs cannot.
Colour a pair red when the two can be ranked, and blue when they cannot.
Ramsey's theorem gives an endless group in which all pairs have the same colour.
If all pairs are red, everyone in the group can be ranked against everyone else: this is a chain.
If all pairs are blue, no two of them can be ranked: this is an antichain.

### L2 human

Take the partial order on $\set{1, 2, 3, \dots}$ given by divisibility.
The pair $\set{2, 4}$ gets colour $0$, because $2$ divides $4$, and the pair $\set{2, 3}$ gets colour $1$.
The set of powers of $2$ is homogeneous of colour $0$, and it is a chain.
The set of primes is homogeneous of colour $1$, and it is an antichain.
The typical use of this argument is to show that a combinatorial principle is at most as strong as $\mathsf{RT}^2_2$.
The trap: step 5 is needed, because the homogeneous set $H$ is a set of indices and not a set of elements of $P$.
