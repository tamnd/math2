## Example

Let $\mathbb{Z}/6\mathbb{Z} = \{0, 1, 2, 3, 4, 5\}$ be the [[integers modulo $6$|03VFZ2WETT]] with addition modulo $6$.
The identity element is $0$, and the group is written additively.
So the [[order|0WE2NHZJ7B]] of $a$ is the smallest positive integer $n$ with $n a \equiv 0 \pmod 6$.
We list the multiples $a, 2a, 3a, \ldots$ modulo $6$ until the first $0$.

1. The element $0$: $1 \cdot 0 = 0$. So $\ord(0) = 1$.
2. The element $1$: the multiples are $1, 2, 3, 4, 5, 0$. The first $0$ is $6 \cdot 1$, so $\ord(1) = 6$.
3. The element $2$: the multiples are $2, 4, 0$. The first $0$ is $3 \cdot 2 = 6$, so $\ord(2) = 3$.
4. The element $3$: the multiples are $3, 0$. The first $0$ is $2 \cdot 3 = 6$, so $\ord(3) = 2$.
5. The element $4$: the multiples are $4, 2, 0$, because $8 \equiv 2$ and $12 \equiv 0$. So $\ord(4) = 3$.
6. The element $5$: the multiples are $5, 4, 3, 2, 1, 0$, because $5k \equiv -k \pmod 6$. So $\ord(5) = 6$.

The orders are $1, 6, 3, 2, 3, 6$.
Each of them divides $|\mathbb{Z}/6\mathbb{Z}| = 6$, as the [[result on element orders|08V7JHS3QZ]] states.

## Remarks

In each case the order of $a$ is $6 / \gcd(6, a)$, as [[the order of a power|0VVPQNVM8S]] says, because $a = a \cdot 1$ is the $a$th multiple of the element $1$ of order $6$.
For example, $\ord(4) = 6 / \gcd(6, 4) = 6 / 2 = 3$.
The elements of order $6$ are $1$ and $5$, the residues coprime to $6$, and each of them generates the whole group.
The group is [[abelian|082GHNPJ53]], but not each element has order $6$.
The elements $2$ and $4$ are inverse to each other, and they have the same order, as [[the order of an inverse|0PMT9YJZVW]] says.
For $\mathbb{Z}/n\mathbb{Z}$ in general, the order of $a$ is $n / \gcd(n, a)$, so the orders are exactly the divisors of $n$.

## Explanations

### L1 human

Think of a clock with $6$ hours, numbered $0$ to $5$.
A step of $2$ hours brings the hand to $2$, then $4$, then back to $0$.
So the step of $2$ hours comes back after $3$ steps, and its order is $3$.
A step of $1$ hour needs $6$ steps, and a step of $3$ hours needs $2$ steps.

### L2 human

We use the table of orders to answer a question about subgroups.

1. The subgroup generated by $a$ has $\ord(a)$ elements, by [[the order of a cyclic subgroup|031M8HX7DA]].
2. The element $2$ generates $\{0, 2, 4\}$, with $3$ elements.
3. The element $3$ generates $\{0, 3\}$, with $2$ elements.
4. The elements $1$ and $5$ generate the whole group, with $6$ elements.

The typical use of such a table is to find all generators of a cyclic group: here they are the elements of order $6$.
A trap is to look for a power $2^n \equiv 1$ under multiplication.
The operation of this group is addition, so the order of $2$ asks for $n \cdot 2 \equiv 0$, and the identity is $0$, not $1$.
