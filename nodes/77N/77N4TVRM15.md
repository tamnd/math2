## Example

Let $\mathbb{Z}/6\mathbb{Z} = \{0, 1, 2, 3, 4, 5\}$ be the [[integers modulo $6$|03VFZ2WETT]] with addition.
The [[order|0JPYSD5E0B]] of $a$ is the least $k \geq 1$ with $k \cdot a \equiv 0 \pmod 6$.

1. The element $0$ has order $1$.
2. The element $1$ has order $6$. The multiples are $1, 2, 3, 4, 5, 0$.
3. The element $2$ has order $3$. The multiples are $2, 4, 0$.
4. The element $3$ has order $2$. The multiples are $3, 0$.
5. The element $4$ has order $3$. The multiples are $4, 2, 0$.
6. The element $5$ has order $6$. The multiples are $5, 4, 3, 2, 1, 0$.
7. The orders are $1, 6, 3, 2, 3, 6$. Each of them divides $6$, as the [[theorem on element orders|08V7JHS3QZ]] states.

## Remarks

The example shows that each divisor of $6$ occurs as an order in this group.
This holds in each [[cyclic group|0KVGH0J5B3]] of order $n$: for each divisor $d$ of $n$, the element $n/d$ of $\mathbb{Z}/n\mathbb{Z}$ has order $d$.
In general the order of $a$ in $\mathbb{Z}/n\mathbb{Z}$ is $n / \gcd(a, n)$.
For example, $\gcd(4, 6) = 2$ and $6 / 2 = 3$, which agrees with step 5.

## Explanations

### L1 human

Think of a clock with $6$ hours, numbered $0$ to $5$.
Start at $0$ and jump $2$ hours each time.
You visit $2$, $4$ and then $0$ again, after $3$ jumps.
So the order of $2$ is $3$, and $3$ divides $6$.

### L2 human

We find the order of $4$ by the formula and by direct computation.

1. By the formula, the order is $6 / \gcd(4, 6) = 6 / 2 = 3$.
2. Directly, $4 + 4 = 8 \equiv 2$, and $2 + 4 = 6 \equiv 0$. So $3 \cdot 4 \equiv 0$, and no smaller multiple is $0$.
3. Both methods give $3$.

The typical use of the theorem here is a check: an answer such as "order $4$" in a group of order $6$ must be wrong.
A trap is to think that in an abelian group each element has the same order as the group.
Here $3$ has order $2$, not $6$.
