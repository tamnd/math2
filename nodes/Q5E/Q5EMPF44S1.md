## Summary

A diversity index is a number that measures how many kinds a community contains and how evenly its individuals spread over them.
In ecology the kinds are species and the input is the list of relative abundances of the species.
The main examples are species richness, the Shannon index, the Simpson index and the Hill numbers.
These indices let ecologists compare communities and track changes in biodiversity with a single number.

## Explanations

### L1 human

Picture two forests, each with ten tree species.
In the first forest almost every tree belongs to one species, and the other nine species are rare.
In the second forest each species makes up one tenth of the trees.
Both forests have the same number of species, but the second one is more diverse, and a diversity index captures this.
For example, the Simpson index $\sum_i p_i^2$ is close to $1$ for the first forest and exactly $0.1$ for the second, so a smaller value means more diversity.
