## Statement

Let $F$ be a field, let $V$ be a vector space over $F$, and let $S \subseteq V$.

1. $\operatorname{span}(S)$ is a [[linear subspace|0EPTJA5QV4]] of $V$, and $S \subseteq \operatorname{span}(S)$.
2. If $W$ is a subspace of $V$ with $S \subseteq W$, then $\operatorname{span}(S) \subseteq W$.
3. Hence $\operatorname{span}(S)$ is the intersection of all subspaces of $V$ that contain $S$.
4. In particular, $\operatorname{span}(\varnothing) = \set{0}$.

## Remarks

### Why each hypothesis is needed

In part 2, $W$ must be a subspace: the set $S$ itself contains $S$, but it need not contain $\operatorname{span}(S)$.
The span uses finite combinations only; with infinite sums, part 1 would need a topology on $V$.

### Consequences

A subset $W$ is a subspace if and only if $\operatorname{span}(W) = W$.
If $S \subseteq T$, then $\operatorname{span}(S) \subseteq \operatorname{span}(T)$, and $\operatorname{span}(\operatorname{span}(S)) = \operatorname{span}(S)$.
To show that $S$ spans a subspace $W$, it is enough to show $S \subseteq W$ and that each vector of $W$ is a combination of $S$.

### Converse

If a subspace $Y$ contains $S$ and lies in every subspace that contains $S$, then $Y = \operatorname{span}(S)$.

### Generalizations

The same proof gives the submodule generated by a subset of a module, the subgroup generated by a subset of a group, and the ideal generated by a subset of a ring.

## Explanations

### L1 human

Any subspace that contains some vectors must contain all their combinations, by closure.
The combinations already form a subspace.
So the span is the smallest subspace that holds the vectors.

### L2 human

Example: the smallest subspace of $\R^3$ that contains $(1, 0, 0)$ and $(0, 1, 0)$.
Each such subspace contains $a(1, 0, 0) + b(0, 1, 0) = (a, b, 0)$.
The set of all $(a, b, 0)$ is a subspace, the plane $z = 0$.
So the plane $z = 0$ is the answer.
