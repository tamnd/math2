## Statement

The combinations of a set form a subspace, and no smaller subspace can hold the set.
Let $F$ be a field, let $V$ be a vector space over $F$, and let $S \subseteq V$.

1. The [[span|0HR573CHNM]] $\operatorname{span}(S)$ is a [[linear subspace|0EPTJA5QV4]] of $V$, and $S \subseteq \operatorname{span}(S)$.
2. If $W$ is a subspace of $V$ with $S \subseteq W$, then $\operatorname{span}(S) \subseteq W$.
3. Hence $\operatorname{span}(S)$ equals the intersection of all subspaces of $V$ that contain $S$.
4. In particular, $\operatorname{span}(\varnothing) = \{0\}$.

## Remarks

### A check in the plane

Let $S = \{(1, 0, 0), (0, 1, 0)\}$ in $\mathbb{R}^3$.
Every combination has the form $(a, b, 0)$, so the span is the plane $z = 0$, and this plane is a subspace, as part 1 says.
Any subspace $W$ that contains both vectors contains $a(1, 0, 0)$ and $b(0, 1, 0)$ by closure under scaling, and then their sum $(a, b, 0)$ by closure under addition.
So $W$ contains the whole plane, as part 2 says.
The plane $z = 0$ is therefore the smallest subspace that contains $S$.

### Why each hypothesis is needed

Part 2 needs $W$ to be a subspace, not just a set that contains $S$.
The set $S$ itself contains $S$, but in the example above it does not contain $\operatorname{span}(S)$, since $(1, 1, 0)$ is missing from it.
A set closed under addition but not under scaling fails too: the vectors $(a, b, 0)$ with integer $a$ and $b$ contain $S$, but not $(\tfrac12, 0, 0)$.

The span uses only finite combinations.
In a space with a topology one can also form infinite sums, but then part 1 needs the extra step of taking a closure, which belongs to analysis.

### What it gives you

A subset $W$ is a subspace if and only if $\operatorname{span}(W) = W$.
If $S \subseteq T$, then $\operatorname{span}(S) \subseteq \operatorname{span}(T)$, since $\operatorname{span}(T)$ is a subspace that contains $S$.
Taking the span twice changes nothing, since $\operatorname{span}(S)$ is already a subspace that contains itself.
To prove that $\operatorname{span}(S) \subseteq W$ for a subspace $W$, it is enough to check that each vector of $S$ lies in $W$; you never need to look at the combinations.

### The converse

The two properties in parts 1 and 2 pin the span down.
If a subspace $Y$ contains $S$ and lies inside every subspace that contains $S$, then $Y \subseteq \operatorname{span}(S)$ and $\operatorname{span}(S) \subseteq Y$, so $Y = \operatorname{span}(S)$.

### Generalizations

The same argument gives the submodule generated by a subset of a module, the subgroup generated by a subset of a group and the ideal generated by a subset of a ring.
In each case the generated object is both the set of finite expressions built from the subset and the intersection of all objects that contain it.

## Explanations

### L1 human

Any subspace that contains some vectors must contain every way of scaling and adding them.
Those combinations already form a subspace on their own.
So the span is the smallest subspace that holds the vectors.

### L2 human

The typical use is a short proof of containment.
Suppose you want to show that $\operatorname{span}((1, 1), (1, -1))$ is all of $\mathbb{R}^2$.
Apply part 2 with $W = \operatorname{span}((1, 1), (1, -1))$ and with the standard vectors as the set, so it is enough to put the standard vectors inside $W$:
$$(1, 0) = \tfrac12 (1, 1) + \tfrac12 (1, -1), \qquad (0, 1) = \tfrac12 (1, 1) - \tfrac12 (1, -1).$$
Then $W$ is a subspace that contains $(1, 0)$ and $(0, 1)$, so it contains their span, which is $\mathbb{R}^2$.

### L3 human

The theorem says that the span is a closure operator on the subsets of $V$, and that its closed sets are exactly the subspaces.
In the language of order theory, the subspaces form a complete lattice, with intersection as meet and span of the union as join.
Mathlib builds `Submodule.span` this way: as the infimum of the submodules that contain the set, with the description by combinations as a theorem.
