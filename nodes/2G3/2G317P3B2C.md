## Definition

A *cryptosystem* is a tuple $(\mathcal{P}, \mathcal{C}, \mathcal{K}, \mathcal{E}, \mathcal{D})$ with the following properties.

1. $\mathcal{P}$ is a [[set|0BSJ7RQ9BW]] of plaintexts, $\mathcal{C}$ is a set of ciphertexts and $\mathcal{K}$ is a set of keys.
2. For each key $k \in \mathcal{K}$ there is an encryption [[function|0XHDTE5YMZ]] $e_k \colon \mathcal{P} \to \mathcal{C}$ in $\mathcal{E}$ and a decryption function $d_k \colon \mathcal{C} \to \mathcal{P}$ in $\mathcal{D}$.
3. For each key $k$ and each plaintext $x \in \mathcal{P}$, $d_k(e_k(x)) = x$.

*Cryptography* is the study of cryptosystems and of other protocols, such as signatures and key exchange, that protect information against an adversary.

## Remarks

Example: the shift cipher has $\mathcal{P} = \mathcal{C} = \mathcal{K} = \Z/26\Z$, with $e_k(x) = x + k$ and $d_k(y) = y - k$.
Clause 3 holds because $(x + k) - k = x$ in $\Z/26\Z$.

Non-example: take $\mathcal{P} = \mathcal{C} = \mathcal{K} = \Z/26\Z$ and $e_k(x) = kx$.
For $k = 2$ the map $e_2$ sends $0$ and $13$ to $0$, so no $d_2$ can satisfy clause 3.

Clause 3 forces each $e_k$ to be injective.
In a *symmetric* cryptosystem the same secret key serves both maps.
In a public-key cryptosystem the key for $e_k$ is public, while the matching key for $d_k$ stays secret.
In modern definitions the maps are given by efficient, often randomized, algorithms.
