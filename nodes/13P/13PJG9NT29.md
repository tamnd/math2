## Example

Let $f \colon \mathbb{R} \to \mathbb{R}$ be the function $f(x) = 3x - 7$.
The claim is that $f$ is [[surjective|01RVCMSN5N]]: for every real $y$ there is a real $x$ with $f(x) = y$.
We find $x$ in scratch work, and then we write a final proof that does not show the search, as the method of [[scratch work and the final proof|E97XXFW9MV]] asks.

The scratch work treats $f(x) = y$ as an equation for the unknown $x$.

> We want $3x - 7 = y$.
> Adding $7$ gives $3x = y + 7$, and dividing by $3$ gives $x = \frac{y + 7}{3}$.

This tells us which $x$ to name.
It is not a proof of existence, because the solving started from the assumption that a solution exists.

The final proof reads as follows.

> Let $y$ be a real number, and let $x = \frac{y + 7}{3}$, which is a real number.
> Then $f(x) = 3 \cdot \frac{y + 7}{3} - 7 = (y + 7) - 7 = y$.
> Since $y$ was arbitrary, every real number is a value of $f$, so $f$ is surjective.
> $\square$

We check the final proof.

1. It starts with an arbitrary $y$, as the goal "for every $y$" requires.
2. It names $x$ by a formula in $y$ alone, which answers the goal "there is $x$".
3. It verifies $f(x) = y$ by a calculation that a reader can check in one line.
4. It solves no equation, since the solving belongs to the scratch work.

Check: for $y = 5$ we get $x = 4$ and $f(4) = 12 - 7 = 5$.

## Remarks

The scratch work runs from the goal $f(x) = y$ to a candidate $x$, and the proof runs from the candidate to the goal.
This is the usual pattern for [[proving surjectivity|DD2P85Y8E9]], and the final proof is shorter than the search because checking a candidate is easier than finding it.

The scratch work also shows where a claim fails.
For $g(x) = x^2$ on $\mathbb{R}$ the same search gives $x = \pm\sqrt{y}$, which needs $y \ge 0$, and so $y = -1$ has no preimage.
For $f(x) = 3x - 7$ on the integers, the search gives $x = \frac{y + 7}{3}$, which is not an integer for $y = 0$, so $f$ is not surjective onto $\mathbb{Z}$.

## Explanations

### L1 human

Think of a machine that takes a number, multiplies it by $3$ and subtracts $7$.
We want to show that every number can come out of the machine.
To find the input for the output $5$, we run the machine backward: add $7$ to get $12$, then divide by $3$ to get $4$.
In the written proof we only show that the input $\frac{y+7}{3}$ works for each output $y$.
How we found that input stays in the draft.

### L2 human

We repeat the method for $h \colon \mathbb{R} \setminus \{1\} \to \mathbb{R} \setminus \{2\}$ with $h(x) = \frac{2x}{x - 1}$.
In scratch work we solve $\frac{2x}{x - 1} = y$: this gives $2x = yx - y$, so $x(2 - y) = -y$ and $x = \frac{y}{y - 2}$.
The formula needs $y \ne 2$, which the codomain gives, and we must also check that $x \ne 1$.

Now the proof.
Let $y \ne 2$, and let $x = \frac{y}{y - 2}$.
If $x = 1$, then $y = y - 2$, which is false, so $x \ne 1$ and $x$ is in the domain.
We compute
$$x - 1 = \frac{y - (y - 2)}{y - 2} = \frac{2}{y - 2} \quad \text{and} \quad 2x = \frac{2y}{y - 2},$$
so $h(x) = \frac{2y}{y - 2} \cdot \frac{y - 2}{2} = y$, and $h$ is surjective.

Check: $y = 4$ gives $x = 2$ and $h(2) = \frac{4}{1} = 4$.
Watch out: the check that $x$ lies in the domain is part of the proof, and the scratch work does not do it for you.
