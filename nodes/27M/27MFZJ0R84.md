## Definition

Let $(M, g)$ be a time-oriented [[Lorentzian manifold|BY4QYYS788]], with timelike curves as in the [[causal structure|KZWG5F0TSB]].
A timelike curve is *inextendible* if it has no endpoint in $M$ in either direction.
So it cannot be extended to a longer timelike curve.
A *Cauchy surface* of $(M, g)$ is a subset $\Sigma \subseteq M$ such that every inextendible timelike curve in $M$ meets $\Sigma$ exactly once.

## Remarks

A Cauchy surface is achronal, since no timelike curve meets it twice, and it is a closed topological hypersurface of $M$.
Its domain of dependence, the set of points $p$ such that every inextendible causal curve through $p$ meets $\Sigma$, is all of $M$.
Some authors require in addition that $\Sigma$ be a smooth spacelike hypersurface; such Cauchy surfaces exist in every globally hyperbolic spacetime.

Example: in [[Minkowski space|G49G4R1K04]] with coordinates $(t, x)$, the hyperplane $\Sigma = \set{t = 0}$ is a Cauchy surface.
Indeed, along an inextendible timelike curve the coordinate $t$ is strictly increasing.
Since the speed is less than $1$, it takes every real value, so it equals $0$ exactly once.

Non-example: the hyperboloid $H = \set{t = \sqrt{1 + \abs{x}^2}}$ in Minkowski space is spacelike and achronal, but it is not a Cauchy surface.
The [[hyperbolic motion|HE6EP8V35W]] curve $s \mapsto (\sinh s, \cosh s, 0, 0)$ is an inextendible timelike curve with $x_1^2 - t^2 = 1$, while points of $H$ have $t^2 - \abs{x}^2 = 1$, so it never meets $H$.
