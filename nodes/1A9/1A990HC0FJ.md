## Statement

A CTL formula can be checked on a finite system with one linear-time pass over the system for each subformula.

Let $M = (S, R, L)$ be a finite [[Kripke structure|RFQ8DJZNQT]] with a total transition relation $R$, and let $\varphi$ be a formula of [[CTL|1DA0Y6KDF8]].
Let $\lvert\varphi\rvert$ be the number of subformulas of $\varphi$.
Then the set $[\![\varphi]\!]_M = \{s \in S : M, s \models \varphi\}$ can be computed in time
$$O\big(\lvert\varphi\rvert \cdot (\lvert S \rvert + \lvert R \rvert)\big).$$
In particular, the CTL [[model checking|VNY0VXVZ53]] problem "does $s$ satisfy $\varphi$?" is decidable in polynomial time.

## Remarks

### Why each hypothesis is needed

The structure $M$ is finite, so that the sets of states can be stored and the searches end.

The relation $R$ is total, so that every finite path extends to an infinite one.
The proof uses this when it turns a finite path to a $\psi_2$-state into a witness for $E[\psi_1 U \psi_2]$.
Without totality a dead-end state has no infinite path at all, and the clauses for $EG$ and $EU$ mean something else.

The shape of CTL matters most.
Each temporal operator sits directly under a path quantifier, so every subformula denotes a set of states, and the sets can be computed from the inside out.
For [[CTL*|Y4XZ94GRXV]], where this fails, model checking is PSPACE-complete, so no such bound is expected there.

### What it gives you

CTL model checking is in P, while LTL model checking is PSPACE-complete by [[the LTL theorem|RD9B213GJ5]].
When the property fails, the same search gives a witness path or a counterexample path for the outermost operator.
The bound is linear in $\lvert S \rvert$, but $\lvert S \rvert$ is often exponential in the size of a program text.
This is the state explosion problem, and symbolic methods attack it.

### Generalizations

Fairness constraints, given as $k$ sets of states that a path must visit infinitely often, can be added at a cost of a factor $k$ in the time.
Symbolic model checking, by Burch, Clarke, McMillan, Dill and Hwang (1990), computes the same fixpoints on binary decision diagrams.
The modal [[mu-calculus|MZ0M2KR9S0]] has the same inside-out method, with one fixpoint iteration for each fixpoint operator.

## History

Clarke and Emerson gave a polynomial-time algorithm for CTL in 1981.
Clarke, Emerson and Sistla published the algorithm with time linear in $\lvert M \rvert \cdot \lvert\varphi\rvert$ in ACM TOPLAS in 1986.

## Explanations

### L1 human

To check a CTL formula, a computer labels each state with the parts of the formula that hold there.
It starts with the smallest parts and works outward.
Each part needs one pass over the states and the moves.
So the work grows like the size of the system times the size of the formula.

### L2 human

Here is how the computer finds $[\![ E[p \, U \, q] ]\!]$.
It marks all $q$-states and puts them in a queue.
Then it takes a state from the queue, marks each unmarked $p$-state with an edge into it, and puts that state in the queue.
It stops when the queue is empty.
Each edge is looked at once, because we follow the edges backwards from each newly marked state only once.
On the arbiter with edges $i \to i$, $i \to w$, $w \to g$, $g \to i$, where $q$ holds at $g$ and $p$ holds at $i$ and $w$, the marks come in the order $g$, $w$, $i$.
Watch out: the bound counts edges as well as states, so a dense structure with $\lvert S \rvert^2$ edges costs about $\lvert S \rvert^2$ steps for each subformula.

### L3 human

The algorithm computes the least fixpoint for $EU$ by backward reachability, and the greatest fixpoint for $EG$ through strongly connected components.
In the [[mu-calculus|MZ0M2KR9S0]], CTL lies in the alternation-free fragment, and that whole fragment has model checking in linear time.
