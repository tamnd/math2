## Summary

The causal set programme is an approach to [[quantum gravity|M1VXRT5X56]] in which spacetime is fundamentally a discrete set of events with a causal order.
Mathematically a causal set is a [[locally finite poset|TV1V4JDRDD]], read as "event $x$ can influence event $y$".
The programme was proposed by Luca Bombelli, Joohan Lee, David Meyer and Rafael Sorkin in 1987, under the slogan "order + number = geometry".
The order recovers the [[causal structure|KZWG5F0TSB]] of a spacetime and counting elements recovers volume.

## Explanations

### L1 human

The causal structure of spacetime tells which events can affect which others, and it already determines most of the geometry.
What is missing is a scale, and counting supplies it if spacetime is made of discrete atoms.
So a causal set is a collection of spacetime atoms together with the relation "comes before".
The number of atoms in a region gives its volume, about one per Planck four-volume.
For example, dropping points at random into a region of Minkowski spacetime and remembering only which points lie in each other's future light cone gives a causal set.
