## Statement

The theorem says that monadic second-order logic on finite words and finite automata describe exactly the same languages, and that we can pass from one description to the other by an algorithm.

Let $\Sigma$ be a finite alphabet.
A nonempty word $w = a_0 a_1 \cdots a_{n-1} \in \Sigma^+$ is identified with the [[structure|983GZBQYT4]] whose domain is the set of positions, ordered as usual, with one unary predicate for each letter.
$$\underline{w} = (\{0, 1, \ldots, n-1\}, <, (P_a)_{a \in \Sigma}), \qquad P_a = \{ i : a_i = a \}.$$
Monadic second-order logic (MSO) over this signature is the fragment of [[second-order logic|G6X7SZSNC5]] with first-order variables $x, y, \ldots$ for positions and set variables $X, Y, \ldots$ for sets of positions.
Its atomic formulas are $x < y$, $x = y$, $P_a(x)$ and $x \in X$.
Formulas are built with $\neg$, $\wedge$, $\vee$, $\to$ and the quantifiers $\exists x$, $\forall x$, $\exists X$, $\forall X$, and a set quantifier ranges over all subsets of the domain.
A language $L \subseteq \Sigma^+$ is MSO-definable when some MSO sentence $\varphi$ gives $L = \{ w \in \Sigma^+ : \underline{w} \models \varphi \}$.

**Theorem.**

1. A language $L \subseteq \Sigma^+$ is MSO-definable if and only if $L$ is a [[regular language|18WVBDCS38]].
2. Both directions are effective: algorithms turn a finite automaton into an equivalent MSO sentence, and an MSO sentence into an equivalent finite automaton.
3. The set of MSO sentences that are true in some nonempty finite word is decidable, and so is the set of MSO sentences that are true in every nonempty finite word.
4. The weak monadic second-order theory of one successor, WS1S, is [[decidable|HWC687ES0Q]].
   It is the MSO theory of $(\mathbb{N}, S)$ with $S = \{ (i, i+1) : i \in \mathbb{N} \}$, where set variables range over the finite subsets of $\mathbb{N}$.

The [[proof|NT5RAK54G3]] proves all four parts.

## Remarks

### A first sentence and its automaton

Take the words over $\{a\}$ of even length.
A two-state automaton recognizes them: it moves between "even so far" and "odd so far" at each letter, and it accepts in "even so far".
An MSO sentence can describe the same words by guessing the set $X$ of even positions.
Write $\operatorname{first}(x)$ for $\neg \exists z \, (z < x)$, $\operatorname{last}(x)$ for $\neg \exists z \, (x < z)$, and $S(x, y)$ for $x < y \wedge \neg \exists z \, (x < z \wedge z < y)$.
The sentence is the following.
$$\exists X \, \bigl( \forall x \, (\operatorname{first}(x) \to x \in X) \wedge \forall x \, \forall y \, (S(x, y) \to (x \in X \leftrightarrow y \notin X)) \wedge \forall x \, (\operatorname{last}(x) \to x \notin X) \bigr)$$
The first two conjuncts force $X = \{0, 2, 4, \ldots\}$, and the third says that the last position $n - 1$ is odd, so the length $n$ is even.
Check: for $aaaa$ the last position $3$ is odd and the sentence holds, and for $aaa$ the last position $2$ is even and the sentence fails.
The set $X$ is the run of the automaton written along the word, and the proof turns this observation into a method for every automaton.

### Why the quantifiers must be monadic

If a sentence may also quantify over binary relations, languages that are not regular become definable.
The language $\{ a^m b^m : m \ge 1 \}$ is defined by three conditions: every $a$ comes before every $b$, both letters occur, and some binary relation is a bijection from the $a$-positions onto the $b$-positions.
This language is not regular, by the [[pumping lemma|CBR9WAGZGZ]].
So the word "monadic" in the theorem cannot be dropped.

### Why finite words and finite sets

On infinite words, finite automata must be replaced by [[Büchi automata|92DM43HQZT]], because an infinite run has no last state.
That case is [[Büchi's theorem on S1S|YPDXVTH5JR]].
In part 4 the set variables range over finite sets only.
With quantifiers over all subsets of $\mathbb{N}$ we get the theory S1S, which is still decidable, but its proof needs automata on infinite words.

### What it gives you

Regular languages get a description that mentions neither automata nor regular expressions.
The closure of regular languages under complement, intersection and projection becomes the closure of MSO under $\neg$, $\wedge$ and $\exists$.
MSO over the successor relation defines the same languages as MSO over $<$, because $x \le y$ holds exactly when every set that contains $x$ and is closed under successor contains $y$.

Part 4 decides arithmetic too.
In base $k$, a natural number is coded by $k - 1$ finite sets: the positions where its digit is $1$, the positions where it is $2$, and so on.
Addition with carry is then definable in WS1S, and so is the function $V_k$.
This gives the decidability of [[Presburger arithmetic|4W0E9G7PPV]] and of [[Büchi arithmetic|NSTECGT93D]].

### The price of the translation

Meyer proved that WS1S is not [[elementary recursive|RJ3MCAAZSV]]: no decision procedure runs in time bounded by a tower of exponentials of fixed height.
So the translation of part 2 from sentences to automata cannot run in elementary time in general.
In the proof, each negation can cost one exponential, because complement needs the powerset construction.

### First-order logic is weaker

The theorem is an equivalence, so its converse is a part of it.
The same equivalence fails for first-order logic over $<$, which defines a proper subclass of the regular languages.
The words over $\{a\}$ of even length form a regular language that no first-order sentence defines, while the MSO sentence above defines it.
The first-order definable languages are exactly the star-free languages (McNaughton and Papert, 1971).

### Generalizations

The same match between logic and automata holds on other structures.
On infinite words, MSO over $(\mathbb{N}, <)$ matches Büchi automata.
On finite labeled trees, MSO matches bottom-up [[tree automata|3VSFM7K70Z]], by work of Thatcher and Wright and of Doner, and this is the base of [[Courcelle's theorem|DD4JB8XJ5A]].
On the infinite binary tree, MSO matches automata on infinite trees, by [[Rabin's tree theorem|PXKKP038RG]].

### Watch out

Do not mix up WS1S and S1S.
The sentence $\exists X \, \forall x \, (x \in X)$ says that some set contains every number.
It is false in WS1S, because every finite set misses some number, and it is true in S1S, where $X = \mathbb{N}$ is allowed.
So the two theories differ, although both are decidable.

### Try it

Is the language "the number of $a$'s is a multiple of $3$" over $\{a, b\}$ MSO-definable?
Yes: a three-state automaton counts the $a$'s modulo $3$, and part 1 turns it into a sentence with three set variables.

Is $\{ a^m b^m : m \ge 1 \}$ MSO-definable?
No: it is not regular, and part 1 says that every MSO-definable language is regular.

## History

The theorem was proved independently by Julius Richard Büchi (1960), Calvin Elgot (1961) and Boris Trakhtenbrot, in work on the logic of finite automata.
Büchi used it to show that WS1S is decidable, and two years later he extended the method to infinite words and S1S.
Meyer's lower bound showed in the 1970s that no decision procedure for WS1S is elementary.

## Explanations

### L1 human

A word such as $abba$ has positions $0, 1, 2, 3$, and each position carries a letter.
A sentence of monadic second-order logic may say "there is a set of positions such that ..." and "for every position ...".
For example, "the word has even length" can be said by coloring every second position, starting with the first one, and asking that the last position is not colored.
The theorem says that such sentences express exactly the properties that a machine with a fixed finite memory can check while it reads the word once.
So every such sentence can be turned into a machine, and the machine can be tested.

### L2 human

We go from a sentence to an automaton on a small case.
Let $\Sigma = \{a, b\}$ and take the sentence $\exists x \, \exists y \, (x < y \wedge P_a(x) \wedge P_b(y))$, "some $a$ comes before some $b$".
An automaton with three states $0$, $1$, $2$ checks it.
In state $0$ it waits for an $a$ and then moves to $1$.
In state $1$ it waits for a $b$ and then moves to $2$.
State $2$ accepts and stays there on every letter.
Check: on $bab$ the states are $0, 0, 1, 2$, so the word is accepted, and on $bba$ they are $0, 0, 0, 1$, so it is rejected.
The two existential quantifiers became the two moments where the automaton changes state.
This is the typical use of the theorem: a property that is easy to say in logic is regular, and an automaton for it can be built step by step.
Watch out: the translation is not always this cheap, because each negation may force a powerset construction.

### L3 human

The theorem is the first case of the correspondence between logic and automata: definability in MSO equals recognizability by finite automata.
The same pattern holds for infinite words, finite and infinite trees, and graphs of bounded treewidth, and it is the source of the decidability results from [[Büchi arithmetic|NSTECGT93D]] to [[Rabin's tree theorem|PXKKP038RG]].
Algebraically, a language is regular exactly when a finite monoid recognizes it, and the first-order definable languages are those that an aperiodic finite monoid recognizes.
The non-elementary lower bound makes the correspondence effective but not efficient, and practical tools for WS1S work with minimized deterministic automata.
