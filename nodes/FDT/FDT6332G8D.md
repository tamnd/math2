## Example

A student writes the following text, which is a flawed example.

> **Claim.** If $m$ and $n$ are even integers, then $m - n$ is even.
>
> **Proof.** Since $m$ and $n$ are even, $m = 2k$ and $n = 2k$.
> So $m - n = 2k - 2k = 0 = 2 \cdot 0$, which is even.
> $\blacksquare$

The claim is true, but the text misuses the [[moves for each logical form|872K5XB580]].
We find the step that fails.

1. By the [[definition of an even integer|BV6E0ZG3YN]], the given "$m$ is even" says "there is an integer $k$ with $m = 2k$", which is an [[existential|0MSRQHCNN9]] given.
2. The move for an existential given is to introduce a new letter for the witness and to assume only what the given states.
3. The given "$n$ is even" is a second existential given, so its witness needs a second new letter, say $l$ with $n = 2l$.
4. The text uses $k$ for both witnesses, and so it adds the assumption $m = n$, which the hypotheses do not give.
5. So the text proves only the case $m = n$, and for $m = 6$ and $n = 2$ it says nothing.

The same error "proves" a false claim.

> **False claim.** If $m$ and $n$ are even integers, then $m = n$.
>
> **"Proof."** We have $m = 2k$ and $n = 2k$, so $m = n$.

The claim is false, since $m = 2$ and $n = 4$ are even and $2 \ne 4$.
Here is the correct proof of the true claim.

> Suppose that $m$ and $n$ are even.
> Then there are integers $k$ and $l$ with $m = 2k$ and $n = 2l$.
> So $m - n = 2k - 2l = 2(k - l)$, and $k - l$ is an integer.
> Hence $m - n$ is even.
> $\square$

Check: $m = 6$ and $n = 2$ give $k = 3$, $l = 1$ and $m - n = 4 = 2 \cdot 2$.

## Remarks

The rule is not about letters as such: the second witness may be called $k$ if the first is renamed.
The point is that two witnesses are two unknown numbers, and one letter makes them one number.
A universal given is different, because you may apply it many times, to the same value or to different values.

In Lean the two givens are used with `obtain ⟨k, hk⟩ := hm` and `obtain ⟨l, hl⟩ := hn`.
The system makes a new variable for each witness, so it does not allow the error.

## Explanations

### L1 human

"Six is even" means that six is two times some whole number, namely three.
"Two is even" means that two is two times some whole number, namely one.
The two "some numbers" are different.
The student's text calls both of them $k$, as if they were the same number.
That secretly assumes that the two even numbers are equal, and with that trick one could "prove" that $2 = 4$.

### L2 human

We repair a second text with the same error, for the claim "if $a \mid b$ and $a \mid c$, then $a \mid b - c$".
The faulty text says "$b = ak$ and $c = ak$, so $b - c = 0$, which $a$ divides".
The givens are two existential statements: there is an integer $s$ with $b = as$, and there is an integer $t$ with $c = at$.
With two letters the calculation reads
$$b - c = as - at = a(s - t),$$
and $s - t$ is an integer, so $a \mid b - c$.

Check: $a = 3$, $b = 12$ and $c = 6$ give $s = 4$, $t = 2$ and $b - c = 6 = 3 \cdot 2$.
Every proof that unpacks two existential hypotheses needs two letters.
Watch out also for a letter that the statement already uses: "$n = 2n$" confuses the number with its witness.
