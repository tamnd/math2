## Example

A student writes the following text.

> **Claim.** If $m$ and $n$ are even integers, then $m - n$ is even.
>
> **Proof.** Since $m$ and $n$ are even, $m = 2k$ and $n = 2k$.
> So $m - n = 2k - 2k = 0 = 2 \cdot 0$, which is even.
> $\blacksquare$

The claim is true, but the text is not a correct use of [[proof strategies by logical form|872K5XB580]].
We check the step that fails.

1. The given "$m$ is even" has the form "there is an integer $k$ with $m = 2k$", by the [[definition of an even integer|BV6E0ZG3YN]]. It is an [[existential|0MSRQHCNN9]] given.
2. The strategy for an existential given is: introduce a new letter for the witness, and assume only the property that the given states.
3. The given "$n$ is even" is a second existential given. Its witness needs a second new letter, say $l$, with $n = 2l$.
4. The text uses $k$ for both witnesses. This adds the assumption $m = n$, which the hypotheses do not give.
5. So the text proves only the case $m = n$. For $m = 6$ and $n = 2$, the text says nothing.

The same error "proves" a false claim.

> **False claim.** If $m$ and $n$ are even integers, then $m = n$.
>
> **"Proof."** We have $m = 2k$ and $n = 2k$, so $m = n$.

The claim is false: $m = 2$ and $n = 4$ are even, and $2 \ne 4$.

The correct proof of the true claim:

> Suppose that $m$ and $n$ are even.
> Then there are integers $k$ and $l$ with $m = 2k$ and $n = 2l$.
> So $m - n = 2k - 2l = 2(k - l)$, and $k - l$ is an integer.
> Hence $m - n$ is even.
> $\square$

## Remarks

1. In Lean the two givens are used with `obtain ⟨k, hk⟩ := hm` and `obtain ⟨l, hl⟩ := hn`. The system creates a new variable for each witness, so it does not allow the error of the text.
2. The rule is not about letters as such. The second witness may be called $k$ only if the first one is renamed; the point is that two witnesses are two unknown numbers.
3. A universal given can be used many times with the same or with different values. The rule of new letters applies only to existential givens.
4. For $m = 6$ and $n = 2$ the correct proof gives $k = 3$, $l = 1$ and $m - n = 4 = 2 \cdot 2$.

## Explanations

### L1 human

"Six is even" means that six is two times some whole number, namely three.
"Two is even" means that two is two times some whole number, namely one.
The two "some numbers" are different.
The student's text calls both of them $k$, as if they were the same number.
That secretly assumes that the two even numbers are equal, and with that trick one could "prove" that $2 = 4$.

### L2 human

We repair a second text with the same error, for the claim "if $a \mid b$ and $a \mid c$, then $a \mid b - c$".

1. Faulty text: "$b = ak$ and $c = ak$, so $b - c = 0$, which $a$ divides."
2. The givens are two existential statements: there is an integer $s$ with $b = as$, and there is an integer $t$ with $c = at$.
3. With two letters: $b - c = as - at = a(s - t)$.
4. The number $s - t$ is an integer, so $a \mid b - c$.
5. Check: $a = 3$, $b = 12$, $c = 6$ give $s = 4$, $t = 2$, and $b - c = 6 = 3 \cdot 2$.

The typical use of the rule of new letters is every proof that unpacks two existential hypotheses, such as parity and divisibility.
A trap is to reuse a letter that the statement already uses, for example $n = 2n$, which confuses the number with its witness.
