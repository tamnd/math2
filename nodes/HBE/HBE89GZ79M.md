## Definition

Let $L$ be a [[signature|WDVVEYD6AT]] and let $M$ be an $L$-[[structure|983GZBQYT4]].

1. An $L$-structure $A$ is *finitely generated* when $A$ is the smallest [[substructure|676H7EGTKJ]] of $A$ that contains some finite subset $X \subseteq A$.
2. The *age* of $M$, written $\operatorname{Age}(M)$, is the class of all finitely generated $L$-structures $A$ such that there is an [[embedding|SCRB74SWQN]] $A \to M$.
3. A class $\mathcal{K}$ of finitely generated $L$-structures, closed under isomorphism, has the *hereditary property* (HP) when $A \in \mathcal{K}$ and $B$ a finitely generated substructure of $A$ imply $B \in \mathcal{K}$.
4. Such a class has the *joint embedding property* (JEP) when for all $A, B \in \mathcal{K}$ there are $C \in \mathcal{K}$ and embeddings $A \to C$ and $B \to C$.

## Notation

The class $\operatorname{Age}(M)$ is closed under isomorphism, because the composite of an isomorphism and an embedding is an embedding.
When $L$ has no constant symbols, the empty set generates the empty substructure, and books that allow empty structures put it in every age.

## Remarks

Example: the age of $(\Q, <)$ is the class of finite linear orders, see [[this example|1B07YPD0SC]].
Non-example: the class of finite linear orders of even size is closed under isomorphism but has no HP, so it is the age of no structure; see [[this non-example|VDQCA78MNQ]].

## Explanations

### L1 human

The age of a structure lists every small piece of it that is built from finitely many elements.
Two structures can share an age when they have the same small pieces, even if they look different as a whole.

### L2 human

We check that the age of $(\N, +, 0)$ contains $(\N, +, 0)$ itself.

1. The structure $(\N, +, 0)$ is generated by $\set{1}$, because the smallest set that contains $0$ and $1$ and is closed under $+$ is $\N$.
2. So it is finitely generated, and the identity map embeds it into itself.

A trap is to think that a finitely generated structure must be finite; with a function symbol it can be infinite.
