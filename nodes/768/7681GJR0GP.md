## Example

The statement is: for every real number $x$, if $x \neq 0$, then $x^2 > 0$.
A student proposes $x = 0$ as a [[counterexample|0ED72CTBNP]], since $0^2 = 0$ is not greater than $0$.
A counterexample to an implication must satisfy three conditions, and we check each one.

1. It must be a real number.
   The number $0$ is real, so this condition holds.
2. It must satisfy the hypothesis $x \neq 0$.
   The number $0$ does not, so this condition fails.
3. It must fail the conclusion.
   Since $0^2 = 0$ is not greater than $0$, this condition holds.

Condition 2 fails, so $0$ is not a counterexample.
In fact the statement is true and has no counterexample at all.
If $x > 0$, then $x^2 = x \cdot x > 0$ as a product of two positive numbers.
If $x < 0$, then $x^2 = (-x)(-x) > 0$ for the same reason, since $-x > 0$.

## Remarks

The student's number is a counterexample to a different statement, "for every real number $x$, $x^2 > 0$", which drops the hypothesis.
So the number is useful: it shows that the hypothesis $x \neq 0$ cannot be removed.
It just does not refute the statement that was asked about.

A change of the number system changes the answer.
Over the complex numbers, $x = i$ satisfies $x \neq 0$, and $x^2 = -1$ is not greater than $0$.
So the statement fails over $\mathbb{C}$, and indeed $\mathbb{C}$ has no order that is compatible with multiplication.

## Explanations

### L1 human

The rule says: square any number except zero, and the result is positive.
The student squared zero and got zero, which is not positive.
But the rule never talked about zero, and it left zero out on purpose.
So zero cannot break the rule.
To break it, you would need a number other than zero whose square is not positive, and there is no such real number.

### L2 human

Here are two more proposals, both against the statement "for every real $x > 1$, $x^2 > x$".
The first is $x = \frac{1}{2}$, where indeed $\frac{1}{4} < \frac{1}{2}$, but the hypothesis $x > 1$ fails, so it is not a counterexample.
The second is $x = 1$, which fails the hypothesis as well, since $1 > 1$ is false.
In fact the statement is true, because multiplying $x > 1$ by the positive number $x$ gives $x^2 > x$.
So before you check the conclusion, check that the proposed object satisfies every hypothesis.
Watch out: boundary values such as $x = 1$ are common candidates, and whether the hypothesis uses $>$ or $\ge$ decides whether they are allowed.
