## Summary

The Viterbi algorithm finds the most likely sequence of hidden states of a [[hidden Markov model|HJVM390354]] given a sequence of observations.
It is a [[dynamic programming|R3FXF08WBH]] method: for each time and each state, it keeps only the best path that ends there.
Its cost grows linearly with the length of the sequence instead of exponentially.
Viterbi introduced it in 1967 to decode [[convolutional codes|JCFC831VS2]], where it performs maximum likelihood sequence decoding.
It is also used in speech recognition and bioinformatics.

## Explanations

### L1 human

Imagine a map of states at each time step, with arrows between consecutive times, each arrow carrying a score.
The best route through the whole map passes through some state at each time.
The part of it up to that state must itself be the best route to that state.
So it is enough to remember, for each state, the best route ending there and its score, and extend these step by step.
At the end, one picks the best final state and follows the stored back-pointers.
