## Proof

We list all proofs from the axioms and wait for a proof of $\sigma$ or of $\neg \sigma$, and completeness makes sure that one of them comes.

Let $L$, $A$ and $T = \operatorname{Cn}(A)$ be as in the [[statement|HZ7A7B2ERA]].
We fix a standard [[formal system|439M8B4DY2]] for first-order logic, for example a Hilbert system, in which a proof is a finite list of formulas.

### The algorithm

1. The set of $L$-sentences is computable, by the hypothesis on the coding of $L$.
   The map $\sigma \mapsto \neg \sigma$ on codes is computable, since it adds one symbol.
2. Whether a finite list of formulas is a proof from $A$ is decidable.
   Each line must be a logical axiom, a member of $A$, or follow from earlier lines by a rule.
   Each of these checks is computable, because $A$ is [[computable|PPGD5KW8JC]].
3. We list all finite lists of formulas as $p_0, p_1, p_2, \ldots$ in a computable order, for example by increasing code.
4. On input $\sigma$, the algorithm examines $p_0, p_1, \ldots$ in turn.
   If $p_n$ is a proof from $A$ with last line $\sigma$, it stops and answers "yes".
   If $p_n$ is a proof from $A$ with last line $\neg \sigma$, it stops and answers "no".

### The algorithm always stops

5. Since $T$ is [[complete|655K8Y7VS8]], $A \models \sigma$ or $A \models \neg \sigma$.
6. By [[Gödel's completeness theorem|WQ1ZE255SF]], $A \models \sigma$ implies $A \vdash \sigma$, and $A \models \neg \sigma$ implies $A \vdash \neg \sigma$.
   So some $p_n$ is a proof of $\sigma$ or of $\neg \sigma$ from $A$, and the search stops at step $n$ at the latest.

### The answers are correct

7. The answer "yes" is correct.
   If the algorithm finds a proof of $\sigma$ from $A$, then $A \models \sigma$ by [[soundness|4A84VHDTHV]], so $\sigma \in T$.
8. The answer "no" is correct.
   If the algorithm finds a proof of $\neg \sigma$, then $A \models \neg \sigma$ by soundness.
   By the definition of a complete theory, $T$ has a model $\mathcal{M}$.
   Then $\mathcal{M} \models A$ and $\mathcal{M} \models \neg \sigma$, so $\mathcal{M} \not\models \sigma$.
   Hence $A \not\models \sigma$, and $\sigma \notin T$.
9. By steps 5 to 8, the algorithm always stops, and it answers "yes" exactly when $\sigma \in T$.
   So $T$ is computable, that is, $T$ is decidable.

### Computably enumerable axioms

For a [[computably enumerable|TN9G24VABN]] set $A$, we change step 2 as follows.
Let $a_0, a_1, \ldots$ be a computable list of $A$.
At stage $n$, the algorithm examines $p_0, \ldots, p_n$, and it accepts only proofs whose non-logical axioms are among $a_0, \ldots, a_n$.
Each proof from $A$ uses finitely many axioms, so it is accepted at some stage, and steps 4 to 9 go through unchanged.

## Idea

Completeness of $T$ means that for every sentence, the sentence or its negation has a proof.
The proofs from a computable set of axioms can be listed by a machine.
So a search for a proof of $\sigma$ or of $\neg \sigma$ always ends.
The existence of a model guarantees that the search never finds both, so the first answer it finds is the right one.

## Variants

Craig's trick reduces the computably enumerable case to the computable case in another way.
If $a_0, a_1, \ldots$ lists $A$, the set of sentences $a_n \wedge \cdots \wedge a_n$ with $n + 1$ copies is computable and has the same consequences as $A$.

In the language of computability, $T$ and its complement in the set of sentences are both computably enumerable, because the complement is $\{ \sigma : \neg \sigma \in T \}$.
A set that is computably enumerable and has a computably enumerable complement is computable, and this gives the theorem in one line.

No bound on the running time follows from either proof.
For theories such as [[Presburger arithmetic|4W0E9G7PPV]], a quantifier elimination procedure gives an explicit algorithm with a known running time.
