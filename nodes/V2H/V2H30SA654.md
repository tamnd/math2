## Summary

Diagonalization builds an object that differs from every object of a given list, by making it differ from the object number $x$ at the place $x$.
It is the standard way to prove that a list, an enumeration or a class of machines is incomplete.

Here is a first problem.
Can a [[set|0SJ3RX9TXA]] $X$ be mapped onto its [[power set|00E0YZCERH]], so that every subset of $X$ is $f(x)$ for some $x$?
Given any [[function|0EPAT51DXQ]] $f \colon X \to \mathcal{P}(X)$, form the set
$$D = \{x \in X : x \notin f(x)\}.$$
For each $x$, the element $x$ lies in exactly one of $D$ and $f(x)$, so $D \ne f(x)$.
So $D$ is a subset that $f$ misses, and no map from $X$ onto $\mathcal{P}(X)$ exists; this is [[Cantor's theorem|0WTEMGYV2C]], and [[the three-element example|Z9Q8PGPQ1Y]] computes $D$ for one map.

The general form is short.
Let $Y$ be a set with at least two elements, and let $(f_x)_{x \in X}$ be a family of functions from $X$ to $Y$.
Choose a map $\sigma \colon Y \to Y$ with $\sigma(y) \ne y$ for every $y$, and define $d \colon X \to Y$ by
$$d(x) = \sigma(f_x(x)).$$
Then $d(x) \ne f_x(x)$ for every $x$, so $d$ differs from every $f_x$, and no family indexed by $X$ contains all functions from $X$ to $Y$.
For subsets, $Y = \{0, 1\}$, $f_x$ is the indicator of $f(x)$, $\sigma$ swaps $0$ and $1$, and $d$ is the indicator of $D$.

## Motivation

To prove that a list misses some object, a new object must differ from each listed object.
An infinite list has infinitely many objects, so we need infinitely many differences at once, one for each listed object.
The diagonal supplies them: the object with index $x$ is tested at the place $x$, and every index gets its own place.
If the listed objects are the rows of a table and the places are its columns, these places lie on the diagonal of the table, which gives the method its name.

The method runs through logic and computer science.
[[Cantor's diagonal argument|0XCH8QVDCQ]] shows that the real numbers are uncountable.
The [[undecidability of the halting problem|Z7TN2B35B0]], [[Gödel's incompleteness theorems|X9WYNYE29C]] and the [[time hierarchy theorem|A6D1D67GHA]] all use one diagonal step, applied to programs or to formulas.

## Notation

The value $f_x(x)$ is the diagonal entry of the table with rows $f_x$ and columns $x$.
For binary [[sequences|0G9EKM0E15]], $Y = \{0, 1\}$ and the usual change is $\sigma(y) = 1 - y$, the flip.
In logic and computation, $f_x(x)$ means "the object with code $x$ applied to its own code", and the diagonal step then appears as self-reference.

## Remarks

### The steps of a diagonal proof

1. Write the objects of the list as functions $f_x$ on the index set $X$ of the list.
2. Choose a change $\sigma$ of values with no fixed point.
3. Define the diagonal object by $d(x) = \sigma(f_x(x))$.
4. Check that $d$ belongs to the class of objects under study.
5. Conclude that $d \ne f_x$ for each $x$, because $d$ and $f_x$ differ at $x$.

Step 4 is where the real work lies, and it is the step that students forget.
For all binary sequences it is free, but for sets of a special kind, for computable functions or for sentences of arithmetic, it is the heart of the proof.

### Growth rates and programs

Take any sequence of functions $f_1, f_2, \ldots$ from $\mathbb{N}$ to $\mathbb{N}$, and define
$$g(n) = \max\{f_1(n), \ldots, f_n(n)\} + 1.$$
For $n \ge k$, the function $f_k$ appears in the maximum, so $g(n) > f_k(n)$: $g$ eventually exceeds each $f_k$.
For the powers $f_k(n) = n^k$ this gives $g(n) = n^n + 1$, as [[the growth-rate example|8JK4QVPVZ2]] shows, and the [[Ackermann function|N470JF7ZJX]] $n \mapsto A(n, n)$ is a diagonal of the same kind.

The halting problem uses the same move on programs.
Suppose a program $H$ decides, for every program $e$ and input $x$, whether $e$ halts on $x$.
Build the program $D$ that, on input $e$, asks $H$ about $e$ on input $e$ and does the opposite: it loops forever if $H$ says "halts", and halts otherwise.
Run $D$ on its own code $d$: it halts exactly when $H$ says it does not, a contradiction, so $H$ cannot exist.
Here the objects are [[Turing machines|758EYCN27B]], and step 4 is the check that $D$ is a program, which holds because $H$ is one.

### Gödel and the hierarchy theorems

In [[Gödel's incompleteness theorems|X9WYNYE29C]], the [[diagonal lemma|3PRW76471J]] gives a sentence that states its own unprovability, through the [[Gödel numbering|MFJXPAF0R0]] of formulas.
In the [[time hierarchy theorem|A6D1D67GHA]], a machine runs machine $i$ on input $i$ for a fixed time bound and then gives the opposite answer, so it decides a problem that no faster machine decides.
In each case the diagonal object differs from the object number $i$ on the input $i$.

### When the diagonal proves nothing

The diagonal of a list of all finitely supported binary sequences is the constant sequence $1, 1, 1, \ldots$.
That sequence is not finitely supported, so step 4 fails, and the set is still countable, as [[the finitely supported example|QB4ETWZHM6]] shows.

A diagonal also needs one place for each listed object.
A list of the $8$ binary strings of length $3$ has only $3$ places for $8$ strings.
The flipped diagonal of the first $3$ strings differs from those $3$, but it is one of the other $5$, and the list is complete.

And $\sigma$ must have no fixed point.
If $Y$ has one element, every map $\sigma \colon Y \to Y$ fixes it, and the only function $X \to Y$ lies in every nonempty list.

### Watch out

Decimal digits need care, because some real numbers have two names: $0.0999\ldots$ and $0.1000\ldots$ are the same number.
A flip that changes $9$ to $0$ can produce another name of a listed number.
The safe change sends every digit to $5$, except that $5$ goes to $6$, so the new expansion has no $0$ or $9$ and names exactly one number.

A second slip is to think that one diagonal proves uncountability.
It proves that one given list is incomplete, and the proof must work for every list, which it does because the construction applies to any list.

### History

Georg Cantor introduced the diagonal argument in 1891, to prove that the binary sequences are uncountable and that a set is smaller than its power set.
Kurt Gödel used a diagonal construction with codes of formulas in his incompleteness theorems of 1931.
Alan Turing proved the undecidability of the halting problem by diagonalization in 1936.
Juris Hartmanis and Richard Stearns proved the time hierarchy theorem by diagonalization in 1965.

### Try it

First, flip the diagonal of the list $s_1 = 0110\ldots$, $s_2 = 1100\ldots$, $s_3 = 0001\ldots$, $s_4 = 1010\ldots$.
The diagonal entries are $0, 1, 0, 0$, so the new sequence starts $1, 0, 1, 1$, and it differs from $s_n$ at place $n$ for $n = 1, 2, 3, 4$.

Second, let $X = \{a, b\}$ and $f(a) = \{a, b\}$, $f(b) = \{a\}$.
Find the set that $f$ misses by the diagonal rule.
Since $a \in f(a)$ and $b \notin f(b)$, the diagonal set is $D = \{b\}$, and indeed $D$ is neither $\{a, b\}$ nor $\{a\}$.

## Explanations

### L1 human

Suppose someone writes a list of words, and each word has as many letters as there are words in the list.
You want a new word that is not in the list.
Take the first letter of the first word and change it, then the second letter of the second word and change it, and so on.
Your new word differs from the first word in the first letter, from the second word in the second letter, and so on down the list.
So it differs from every word in the list.

### L2 human

Here is a typical problem: show that the set of all functions from $\mathbb{N}$ to $\mathbb{N}$ is uncountable.
Suppose $f_0, f_1, f_2, \ldots$ were a list of all of them.
Define a new function by changing each diagonal value,
$$d(n) = f_n(n) + 1.$$
Then $d$ is a function from $\mathbb{N}$ to $\mathbb{N}$, so it belongs to the class, which is step 4.
For every $n$, the value $d(n) = f_n(n) + 1$ differs from $f_n(n)$, so $d \ne f_n$.
So $d$ is missing from the list, and no list contains all the functions.

Check with a small start of a list: if $f_0(n) = 0$, $f_1(n) = n$ and $f_2(n) = n^2$, then $d(0) = 1$, $d(1) = 2$ and $d(2) = 5$, which differ from $f_0(0) = 0$, $f_1(1) = 1$ and $f_2(2) = 4$.
The problem shows the usual pattern: index the objects, change the diagonal, check membership, and read off the difference at each place.

### L3 human

[[Lawvere's fixed-point theorem|N84M16W19X]] puts the method in a general form: in a cartesian closed category, if some map $X \to Y^X$ is onto in the suitable sense, then every map $\sigma \colon Y \to Y$ has a fixed point.
Diagonalization is the contrapositive: a map $\sigma$ with no fixed point shows that no map $X \to Y^X$ is onto.
In this form, Cantor's theorem, [[Russell's paradox|0HESMMSYEG]], Gödel's diagonal lemma, Tarski's undefinability of truth and the halting problem are one argument, and they differ in the class of objects and in the work of step 4.

In computability and complexity, diagonalization gives the hierarchy theorems and the existence of undecidable problems.
It also has a known limit there.
A proof that only simulates machines and flips their answers works the same way relative to every oracle, and Baker, Gill and Solovay found oracles relative to which $\mathsf{P} = \mathsf{NP}$ and others relative to which $\mathsf{P} \ne \mathsf{NP}$.
So simulation and flipping alone cannot settle the $\mathsf{P}$ versus $\mathsf{NP}$ question.
In set theory, diagonalization proves König's theorem on cofinalities, and it is the sharpest form of the [[counting arguments for existence|1KVSS0KRZA]]: there are more objects than entries in any list.
