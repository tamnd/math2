## Summary

Diagonalization is a method to build an object that differs from each object in a given list.
Let $X$ be a [[set|0SJ3RX9TXA]], let $Y$ be a set with at least two elements, and let $(f_x)_{x \in X}$ be a family of [[functions|0EPAT51DXQ]] from $X$ to $Y$.
Choose a map $\sigma \colon Y \to Y$ with $\sigma(y) \ne y$ for every $y \in Y$.
Define $d \colon X \to Y$ by $d(x) = \sigma(f_x(x))$.
Then $d(x) \ne f_x(x)$ for every $x$, so $d$ is different from every $f_x$, and no family indexed by $X$ contains all functions from $X$ to $Y$.
The method matters because it is the standard way to prove that a list, an enumeration or a class of machines is incomplete.

## Motivation

To prove that a list misses some object, we must make a new object differ from each listed object.
An infinite list has infinitely many objects, and we need one difference for each of them.
The diagonal gives exactly one place for each listed object: the object with index $x$ is checked at the place $x$.
If the listed objects are rows of a table and the places are columns, these places lie on the diagonal of the table.
A change of every diagonal entry gives a row that is not in the table.

## Notation

The value $f_x(x)$ is the diagonal entry of the table with rows $f_x$ and columns $x$.
For binary sequences, $Y = \set{0, 1}$ and the usual change is $\sigma(y) = 1 - y$.
For sets, a family of subsets $f(x) \subseteq X$ is a family of indicator functions, and the diagonal set is $D = \set{x \in X : x \notin f(x)}$.
In logic and computation, $f_x(x)$ means "object $x$ applied to its own code", and the diagonal step is then self-reference.

## Remarks

### The steps

1. Write the objects of the list as functions $f_x$ on the index set $X$ of the list.
2. Choose a change $\sigma$ of values with no fixed point.
3. Define the diagonal object by $d(x) = \sigma(f_x(x))$.
4. Check that $d$ belongs to the class of objects under study.
5. Conclude that $d \ne f_x$ for each $x$, because $d$ and $f_x$ differ at $x$.

### Examples

- [[Cantor's diagonal argument|0XCH8QVDCQ]]: no [[sequence|0G9EKM0E15]] of binary sequences lists all binary sequences. So the set of binary sequences, and the set of [[real numbers|0518MM6BE1]], is uncountable.
- [[Cantor's theorem|0WTEMGYV2C]]: no map $f$ from a set $X$ onto its [[power set|00E0YZCERH]] exists, because $D = \set{x : x \notin f(x)}$ is not a value of $f$. [[This example|Z9Q8PGPQ1Y]] computes $D$ for a set with three elements. [[Russell's paradox|0HESMMSYEG]] is the same construction applied to all sets.
- Growth rates: for any sequence of functions $f_1, f_2, \ldots$ on $\N$, the function $g(n) = \max_{k \le n} f_k(n) + 1$ eventually exceeds each $f_k$, as [[this example|8JK4QVPVZ2]] shows. The [[Ackermann function|N470JF7ZJX]] $n \mapsto A(n, n)$ is a diagonal of this kind.
- The [[undecidability of the halting problem|Z7TN2B35B0]]: a program that does the opposite of what a claimed decider predicts for its own code gives a contradiction. The objects are [[Turing machines|758EYCN27B]], and the index is the code of a machine.
- [[Gödel's incompleteness theorems|X9WYNYE29C]]: the [[diagonal lemma|3PRW76471J]] gives a sentence that states its own unprovability. The diagonal step uses the [[Gödel numbering|MFJXPAF0R0]] of formulas.
- The [[time hierarchy theorem|A6D1D67GHA]]: a machine that runs machine $i$ on input $i$ for a time bound and then gives the opposite answer decides a problem that no faster machine decides.

### Non-examples

- The diagonal of a list of all finitely supported binary sequences is the constant sequence $1, 1, 1, \ldots$. It is not finitely supported, so step 4 fails and the set is still countable, as [[this example|QB4ETWZHM6]] shows.
- A diagonal needs one place for each listed object. A list of the $8$ binary strings of length $3$ has only $3$ places for $8$ strings. The flip of the diagonal of the first $3$ strings is one of the other $5$ strings, and the list is complete.

### Basic properties

- The diagonal object is explicit: for a given list, $d$ is defined from the list by one formula. The proof that the list is incomplete is direct, and it is often stated by [[contradiction|0J0XBKG64S]] only for style.
- The condition on $\sigma$ is essential: if $Y$ has one element, every map $\sigma \colon Y \to Y$ has a fixed point, and the only function $X \to Y$ is in every nonempty list.
- Lawvere's fixed point theorem is the abstract form. If some map $X \to Y^X$ is onto, then every map $\sigma \colon Y \to Y$ has a fixed point. Diagonalization is the contrapositive.
- The method proves more than one missing object. If a list of binary sequences missed only countably many sequences, the list and the missed sequences would form a new list of all binary sequences. But the diagonal of the new list is missing from it.

### When it fails

The method fails when the diagonal object is not in the class, as in the finitely supported non-example.
It needs care when objects have two names: $0.0999\ldots$ and $0.1000\ldots$ are the same real number.
In complexity theory, the method has a known limit: a proof that only simulates and flips works relative to every oracle.
Theodore Baker, John Gill and Robert Solovay found oracles relative to which $\mathsf{P} = \mathsf{NP}$, and others relative to which $\mathsf{P} \ne \mathsf{NP}$.
So simulation and flipping alone cannot settle the $\mathsf{P}$ versus $\mathsf{NP}$ question.

### History

Georg Cantor introduced the diagonal argument in 1891, to prove that the binary sequences are uncountable and that a set is smaller than its power set.
Kurt Gödel used a diagonal construction with codes of formulas in his incompleteness theorems of 1931.
Alan Turing proved the undecidability of the halting problem by diagonalization in 1936.
Juris Hartmanis and Richard Stearns proved the time hierarchy theorem by diagonalization in 1965.

### Common errors

- To forget step 4. The diagonal object must be in the class, or the argument proves nothing.
- To use decimal digits without care. The flip of $9$ to $0$ can give another name of a listed number; changing each digit to $5$ or $6$ avoids this.
- To think that one diagonal proves uncountability. It proves that one given list is incomplete, and the argument must work for every list.

## Explanations

### L1 human

Suppose someone writes a list of words, each with as many letters as there are words in the list.
We want a new word that is not in the list.
We take the first letter of the first word and change it, then the second letter of the second word and change it, and so on.
Our new word differs from the first word in the first letter, from the second word in the second letter, and so on.
So it differs from every word in the list.

### L2 human

We apply the method to a list of four binary sequences.
The list starts:

1. $s_1 = 0, 1, 1, 0, \ldots$
2. $s_2 = 1, 1, 0, 0, \ldots$
3. $s_3 = 0, 0, 0, 1, \ldots$
4. $s_4 = 1, 0, 1, 0, \ldots$

The diagonal entries are $s_1(1) = 0$, $s_2(2) = 1$, $s_3(3) = 0$ and $s_4(4) = 0$.

1. Flip each diagonal entry with $\sigma(y) = 1 - y$: $d = 1, 0, 1, 1, \ldots$
2. Then $d(1) = 1 \ne 0 = s_1(1)$, so $d \ne s_1$.
3. In the same way, $d$ differs from $s_2$, $s_3$ and $s_4$ at the places $2$, $3$ and $4$.
4. For an infinite list $s_1, s_2, \ldots$, the same rule defines all of $d$, and $d$ differs from every $s_n$ at the place $n$.

The typical use is to prove that a set is uncountable, or that a class of programs misses some problem.
A trap is the decimal form of real numbers, where two different digit strings can name the same number.

### L3 human

Lawvere's fixed point theorem puts the method in a general form, in any cartesian closed category.
In this form, Cantor's theorem, Russell's paradox, Gödel's diagonal lemma, Tarski's undefinability of truth and the halting problem are one argument.
The difference between the cases is the class of objects, and the main work in each case is step 4: to show that the diagonal object is a set, a sentence or a program.

In computability and complexity, diagonalization gives the hierarchy theorems, the existence of undecidable problems and the recursion theorem.
The relativization barrier shows that it does not separate $\mathsf{P}$ from $\mathsf{NP}$ alone.
In set theory, diagonalization gives the theorem of König on cofinalities and many constructions by transfinite recursion that meet a list of requirements.
Within this sub-area, it is the infinite form of the [[counting arguments for existence|1KVSS0KRZA]]: there are more objects than entries in any list.
