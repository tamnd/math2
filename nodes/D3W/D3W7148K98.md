## Definition

Let a monochromatic plane wave of wavelength $\lambda$ fall normally on a grating in the plane $z = 0$.
Let the transmission function $t(x)$ of the grating be periodic with period $d$.
Write $t(x) = \sum_{n \in \Z} c_n e^{2\pi i n x / d}$.
The *Talbot length* is $z_T = 2 d^2 / \lambda$.
Let $u(x, z)$ be the field behind the grating in the [[Fresnel approximation|4JZ84R10NJ]].
The *Talbot effect* is the identity
$$u(x, m z_T) = e^{i k m z_T} \, t(x)$$
for every positive integer $m$, where $k = 2\pi/\lambda$: the grating reappears as an exact image.

## Remarks

Check: in the Fresnel approximation the order $n$ is multiplied by $e^{ikz} e^{-i \pi \lambda z n^2 / d^2}$, so $u(x, z) = e^{ikz} \sum_n c_n e^{-i \pi \lambda z n^2 / d^2} e^{2\pi i n x / d}$.
At $z = z_T$ the extra phase is $e^{-2 \pi i n^2} = 1$ for every $n$, which gives the self-image.
At $z = z_T / 2$ it is $e^{-i\pi n^2} = (-1)^n$, so $u(x, z_T/2) = e^{ikz} t(x + d/2)$: the image is shifted by half a period.
Non-example: in exact wave optics the order $n$ propagates with the phase $z \sqrt{k^2 - (2\pi n / d)^2}$, which is not quadratic in $n$.
The self-images are then only approximate.
They are good when $d \gg \lambda$, which is where the [[paraxial approximation|N111BHFQ2H]] holds.

## Explanations

### L1 human

A periodic pattern splits light into a set of beams, one for each diffraction order.
As they travel, the beams slip out of step with each other at rates proportional to $n^2$.
At the Talbot distance all of them are back in step at once, so the original pattern is rebuilt.
