## Summary

An invariant is a quantity that no allowed move can change.
If the start and the target give it different values, then no sequence of moves, however long, leads from the start to the target.

Here is a problem that the method solves in a few lines.
An island has $13$ red, $15$ green and $17$ blue chameleons, and when two chameleons of different colors meet, both take the third color.
Can all the chameleons ever have one color?
Each meeting changes the difference of the red and green counts by $0$, $3$ or $-3$, so that difference never changes [[modulo|0WAY5WX8NY]] $3$, and the same holds for the other two differences.
At the start no difference is a multiple of $3$, but an island of one color has two counts equal to $0$, so one difference is $0$.
The answer is no, and the [[full example|XBVPYJ1NEB]] writes out every step.

In general, we have a set of states, a start state, a target state and a set of allowed moves, each of which changes one state into another.
An invariant is a function $I$ on the states such that
$$I(t) = I(s) \quad \text{whenever a move changes } s \text{ into } t.$$
The invariant principle says: if $I(\text{start}) \neq I(\text{target})$, then no finite sequence of moves leads from the start to the target.

## Motivation

Many puzzles and processes ask whether a state can be reached.
To show that a state is reachable, one sequence of moves is enough, and you can find it by search.
To show that a state is unreachable, you must rule out every sequence of moves, and there are infinitely many of them.
No search can do that, so we need a property that every reachable state shares and the target lacks.
A quantity that no move changes is the simplest such property.

The idea is old and wide.
In physics, energy and momentum are invariants of motion, and they rule out machines that create energy from nothing.
In computing, a loop invariant is a statement that each pass of a loop keeps, and it proves that a program returns the right result.
Two special forms of the invariant come later: [[parity arguments|H9JT1XNDKQ]] use a count modulo $2$, and [[coloring proofs|90Q4PK1CST]] use the counts of cells of each color.

## Notation

There is no standard symbol.
Many books write $I$ or $\Phi$ for the invariant and $s \to t$ for a move from $s$ to $t$.
The word "invariant" also has a wider meaning in mathematics: a quantity that a whole class of transformations does not change, as in [[classification and invariants|9HQ3TADPA8]].
Here it has the narrow meaning of a quantity that the allowed moves of one problem do not change.

## Remarks

### Why the method works

Suppose that a sequence of $k$ moves leads from $s$ to $t$.
We show $I(t) = I(s)$ by [[induction|0ASJVEFA9J]] on $k$.
For $k = 0$ the two states are equal.
For the step, the first $k - 1$ moves keep the value by the induction hypothesis, and the last move keeps it by the definition of an invariant.
So every state that you can reach from $s$ lies in the set
$$\{ t : I(t) = I(s) \}.$$
The argument is a [[proof by contradiction|0J0XBKG64S]] in its usual form: we suppose that the target is reached and compare the two values of $I$.

### Three more invariants

In the [[15 puzzle|RTSBC9NAD7]], each slide is a swap of the blank with one tile, so it changes the parity of the arrangement.
The same slide moves the blank by one cell, so it also changes the parity of the taxicab distance from the blank to its home corner.
The sum of the two parities, modulo $2$, never changes, and so the position with only $14$ and $15$ swapped cannot be solved.

The MU puzzle of Hofstadter starts with the word MI, and four rules rewrite words.
The number of letters I is never a multiple of $3$, because the rules keep it, double it or lower it by $3$.
The word MU has no letter I, so it cannot be reached; the L2 explanation below gives the details.

Three numbers $3, 4, 12$ stand on a board, and a move replaces two of them, $a$ and $b$, by $0.6a - 0.8b$ and $0.8a + 0.6b$.
Expand the squares to see that the sum of squares does not change:
$$(0.6a - 0.8b)^2 + (0.8a + 0.6b)^2 = 0.36a^2 + 0.64b^2 + 0.64a^2 + 0.36b^2 = a^2 + b^2.$$
The start gives $9 + 16 + 144 = 169$, and the triple $4, 6, 12$ gives $16 + 36 + 144 = 196$, so that triple cannot be reached.

### How to find an invariant

The search for an invariant follows a short routine.

1. Describe the states and the allowed moves exactly.
2. Compute simple quantities of a state: sums, sums of squares, counts of each kind, and their remainders modulo $2$, $3$ or $4$.
3. For each kind of move, check whether the quantity changes.
4. Keep a quantity that no move changes, and compute it at the start and at the target.
5. If the values differ, the target cannot be reached.

The numbers in the rules suggest the modulus.
A meeting of chameleons changes the counts by $-1$, $-1$ and $+2$, and these agree modulo $3$, so the differences are fixed modulo $3$.

### What an invariant cannot do

The converse of the principle is false: a state with the same value of $I$ may still be unreachable.
So an invariant proves impossibility, and a proof that a target is reachable needs a sequence of moves.

Some quantities look promising and fail.
In the game of chameleons, the total number of chameleons never changes, but it is $45$ at the start and at each state of one color, so it rules out nothing, as [[the non-example|4Y6AAEMN20]] shows.
In the 15 puzzle, the number of tiles in their home cells is not an invariant at all, since one slide can change it by $1$.
A quantity that falls at each move, such as the number of pairs out of order in a list, is a [[monovariant|TP3GC5J08D]]: it proves that a process stops, not that a target is unreachable.

### Finer and complete invariants

If $I$ and $J$ are invariants, then the pair $(I, J)$ is an invariant, and so is $f(I)$ for every function $f$.
A pair is finer than each part, so it rules out more targets.
An invariant is complete when equal values give exactly the reachable states.
The parity invariant of the 15 puzzle is complete, but that fact needs a separate proof by construction.

When a target passes every invariant you know, try to reach it.
With $13$ red, $16$ green and $17$ blue chameleons, the difference of the red and green counts is $-3$, a multiple of $3$.
Then $13$ red and green meetings, one green and blue meeting and two red and green meetings make all $46$ chameleons blue.

### Watch out

The common error is to check some moves and not all of them.
In the MU puzzle, rule R2 doubles the number $c$ of letters I, so $c$ itself is not an invariant, and a student who checks only rules R1 and R4 would wrongly keep $c$.
The correct invariant is the property "$c$ is not a multiple of $3$", and you must check it against all four rules.

A second error is to stop at a quantity that has the same value at the start and at the target, and to report that the target is reachable.
Equal values decide nothing, and you need either a finer invariant or a construction.

### History

In 1879 William Johnson and William Story used a parity invariant to show that half of the arrangements of the 15 puzzle cannot be solved.
Douglas Hofstadter introduced the MU puzzle in his book "Gödel, Escher, Bach" (1979).

### Try it

Write the numbers $1$ to $10$ on a board.
A move erases two numbers $a$ and $b$ and writes $a + b + 1$.
After nine moves one number is left; which one?
Each move raises the sum of the numbers by $1$ and lowers the count by $1$, so the sum plus the count is an invariant, equal to $55 + 10 = 65$.
At the end the count is $1$, so the last number is $65 - 1 = 64$.

A move on the triple $(a, b, c)$ replaces it by $(a + 1, b + 1, c)$, $(a + 1, b, c + 1)$ or $(a, b + 1, c + 1)$.
Can you reach $(5, 5, 5)$ from $(0, 0, 0)$?
Each move raises the sum by $2$, so the sum stays even, and $15$ is odd, so you cannot.

## Explanations

### L1 human

Some games have a hidden number that never changes, whatever moves you make.
If the start and the goal give different values of this number, then the goal can never be reached.
For example, put the numbers $1$ to $10$ on a board, and allow a move that erases two numbers and writes their sum.
The total of the numbers on the board is $55$ at the start, and no move changes it.
So the last number on the board must be $55$, and it can never be $56$.
The skill is to find the right hidden number for the game.

### L2 human

We solve the MU puzzle with an invariant.
The states are words in the letters M, I and U, and the start is the word MI.
Rule R1 lets a word $x$I become $x$IU.
Rule R2 lets a word M$x$ become M$xx$.
Rule R3 replaces three letters III in a row by U, and rule R4 deletes two letters UU in a row.
Can the word MU be reached?

Let $c(w)$ be the number of letters I in the word $w$.
Rules R1 and R4 add or remove the letter U, so they keep $c$.
Rule R2 doubles the part after M, so it changes $c$ into $2c$.
Rule R3 changes $c$ into $c - 3$.
If $3$ does not divide $c$, then $3$ does not divide $2c$, because $3$ is prime and does not divide $2$, and $3$ does not divide $c - 3$.
So the property "$c(w)$ is not a multiple of $3$" holds after every move whenever it held before.

At the start, MI has $c = 1$, and $1$ is not a multiple of $3$.
The target MU has $c = 0$, which is a multiple of $3$.
So MU cannot be reached from MI.
Notice that $c$ itself changes; the invariant is a property of $c$ modulo $3$, and the numbers $2$ and $3$ in the rules point to the modulus.

### L3 human

The states and moves form a directed graph, and the states that you can reach from $s$ form the forward closure of $s$.
An invariant is a function that is constant along the edges, so it is constant on each forward closure.
When the moves come from a [[group action|0WCY42EV9V]], the reachable sets are the [[orbits|0YQPZB5Q1G]], and an invariant is a function constant on the orbits.
A complete invariant separates the orbits, and that is the aim of [[classification|9HQ3TADPA8]] in algebra and topology; the [[Euler characteristic|RNDDWDAFJ5]] and the [[knot invariants|GZQ5ZE3X6G]] are invariants in this sense.

In dynamical systems, an invariant of a flow is a [[first integral|0262JP0NV9]], such as the energy of a mechanical system, and [[Noether's theorem|XHPDM5T2JG]] links such conserved quantities to symmetries.
The one-way version is a [[Lyapunov function|01REYCJ371]] or a [[monovariant|TP3GC5J08D]], which decreases along the motion and proves stability or termination.
Many proofs use both: an invariant fixes what stays the same, and a monovariant shows that the process ends.
