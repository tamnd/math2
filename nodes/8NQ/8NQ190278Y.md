## Summary

The invariant principle is a method of [[proof|0B94TKFQJX]] for problems about states and moves.
We have a set of states, a start state, a target state and a set of allowed moves, each of which changes one state into another.
An invariant is a function $I$ on the states such that $I(t) = I(s)$ whenever a move changes $s$ into $t$.
If $I(\text{start}) \neq I(\text{target})$, then no finite sequence of moves leads from the start to the target.
The method matters because it proves impossibility, a claim about all sequences of moves, by one computation on two states.

## Motivation

Many puzzles and processes ask whether a state can be reached.
A search can show that a state is reachable, because one sequence of moves is enough.
A search cannot show that a state is unreachable when there are infinitely many sequences of moves, or too many to list.
We need a property that every reachable state shares and the target lacks.
A quantity that no move changes is the simplest such property.
For example, in the [[15 puzzle|RTSBC9NAD7]] the moves can be made in any order for any time, but one parity is never changed by a move, and this rules out half of the arrangements.

## Notation

There is no standard symbol.
Many texts write $I$ or $\Phi$ for the invariant and $s \to t$ for a move from $s$ to $t$.
The word "invariant" has a wider meaning in mathematics: a quantity that does not change under a given class of transformations, as in [[classification and invariants|9HQ3TADPA8]].
This page uses the narrow meaning of a quantity that the allowed moves do not change.

## Remarks

### Examples

- The [[15 puzzle|RTSBC9NAD7]]: the parity of the arrangement of the $16$ cells plus the parity of the distance of the blank from its home corner does not change. So the position with only $14$ and $15$ swapped cannot be solved.
- A [[game of chameleons|XBVPYJ1NEB]] with $13$ red, $15$ green and $17$ blue: the differences of the three counts [[modulo|0WAY5WX8NY]] $3$ do not change. So the chameleons can never all have one colour.
- The MU puzzle of Hofstadter starts with the word MI and has four rewriting rules. The number of letters I is never a multiple of $3$, because the rules keep it, double it or subtract $3$ from it, and $1$ is not a multiple of $3$. So the word MU, with no letter I, cannot be reached.
- Three numbers $3, 4, 12$ are on a board. A move replaces two of them, $a$ and $b$, by $0.6a - 0.8b$ and $0.8a + 0.6b$. The sum of the squares does not change, since $(0.6a - 0.8b)^2 + (0.8a + 0.6b)^2 = a^2 + b^2$. The start has sum of squares $9 + 16 + 144 = 169$, so the triple $4, 6, 12$, with $16 + 36 + 144 = 196$, cannot be reached.
- The [[parity argument|H9JT1XNDKQ]] and the [[coloring proof|90Q4PK1CST]] use special invariants: a count modulo $2$, and a count of the cells of each colour.

### Non-examples

- In the 15 puzzle, the number of tiles in their home cells is not an invariant, because one move can change it by $1$. So it proves nothing about reachability.
- In the game of chameleons, the total number of chameleons is an invariant, but it has the same value at the start and at the target. So it does not rule out the target, as [[this example|4Y6AAEMN20]] shows.
- A quantity that only decreases, such as the number of inversions in a sort, is not an invariant. It is a [[monovariant|TP3GC5J08D]], and it proves termination instead of impossibility.

### Basic properties

- If $I$ is an invariant and the start state $s$ leads to a state $t$ by a finite sequence of moves, then $I(t) = I(s)$. The proof is by [[induction|0ASJVEFA9J]] on the number of moves: each move keeps the value.
- So the set of states that can be reached from $s$ lies in the set $\set{t : I(t) = I(s)}$.
- The converse is false in general: a state with the same value of $I$ can still be unreachable. A proof that a state is reachable needs a sequence of moves, or a separate argument.
- If $I$ and $J$ are invariants, then the pair $(I, J)$ and each function $f(I)$ of $I$ are invariants. A finer invariant rules out more states.
- An invariant is complete when its equal values give exactly the reachable states. The parity invariant of the 15 puzzle is complete, and this needs a separate proof.

### When it applies

The method applies when a problem gives a start, a set of moves and a target, and asks whether the target can be reached.
A typical signal is the word "never" or the question "is it possible?".
It also applies when the problem asks what the final state of a process must be, if the process ends.

### The steps

1. Describe the states and the allowed moves exactly.
2. Compute small quantities of the state: sums, sums modulo a small number, parities, counts of colours, sums of squares.
3. Check for each kind of move whether the quantity changes.
4. Keep a quantity that no move changes, and compare its values at the start and at the target.
5. If the values differ, conclude that the target cannot be reached.

### When it fails

The method gives no information when every candidate invariant has the same value at the start and at the target.
Then the target may be reachable, and a construction is the right tool.
In the game of chameleons with $13$ red, $16$ green and $17$ blue, the difference of the red and green counts is $0$ modulo $3$, and all chameleons can in fact become blue.

### Related methods

- A [[monovariant|TP3GC5J08D]] changes in one direction at each move, and it proves that a process stops.
- A [[parity argument|H9JT1XNDKQ]] and a [[coloring proof|90Q4PK1CST]] are invariants with values modulo $2$ or counts of colours.
- A [[proof by contradiction|0J0XBKG64S]] is the logical form: we suppose that the target is reached and compare the values of the invariant.

### History

In 1879 William Johnson and William Story used a parity invariant to show that half of the arrangements of the 15 puzzle cannot be solved.
Douglas Hofstadter introduced the MU puzzle in his book "Gödel, Escher, Bach" (1979).

### Common errors

- To check that a quantity is unchanged by some moves, but not by every kind of move. One unchecked move can break the argument.
- To conclude from equal values of the invariant that the target is reachable. Equal values only fail to rule it out.
- To choose an invariant that takes the same value at the start and at the target, and then to stop. A finer quantity may be needed.

## Explanations

### L1 human

Some games have a hidden number that never changes, whatever moves we make.
If the start and the goal give different values of this number, then the goal can never be reached.
For example, put the numbers $1$ to $10$ on a board and allow a move that erases two numbers and writes their sum.
The total of the numbers on the board is $55$ at the start, and no move changes it.
So the last number on the board must be $55$, and it can never be $56$.
The skill is to find the right hidden number for the game.

### L2 human

We solve the MU puzzle with an invariant.
The states are words in the letters M, I and U, and the start is the word MI.
The four rules are: (R1) a word $xI$ may become $xIU$; (R2) a word $Mx$ may become $Mxx$; (R3) three letters III in a row may become U; (R4) two letters UU in a row may be deleted.
The question is whether the word MU can be reached.

1. Let $c(w)$ be the number of letters I in the word $w$. We study $c(w)$ modulo $3$.
2. Rule R1 adds the letter U, so it keeps $c$.
3. Rule R2 doubles the part $x$ after the M, so it changes $c$ into $2c$.
4. Rule R3 removes three letters I, so it changes $c$ into $c - 3$.
5. Rule R4 removes two letters U, so it keeps $c$.
6. If $c$ is not divisible by $3$, then $2c$ is not divisible by $3$, because $3$ is prime and does not divide $2$. Also $c - 3$ is not divisible by $3$.
7. So the property "$c(w)$ is not a multiple of $3$" is kept by each of the four rules. This property is an invariant.
8. The start MI has $c = 1$, which is not a multiple of $3$.
9. The target MU has $c = 0$, which is a multiple of $3$. So MU cannot be reached from MI.

The typical use is the comparison of steps 8 and 9: compute the invariant at the start and at the target.
The trap is to stop at step 3 because $c$ itself changes.
The invariant is not $c$ but a property of $c$ modulo $3$, and the right modulus comes from the numbers $2$ and $3$ in the rules.

### L3 human

The states and moves form a directed graph, and the reachable states from $s$ form the forward closure of $s$.
An invariant is a function that is constant along the edges, so it is constant on each component of the graph when the moves can be undone.
When the moves come from a [[group action|0WCY42EV9V]], the reachable sets are the [[orbits|0YQPZB5Q1G]], and an invariant is a function constant on the orbits.
A complete invariant separates the orbits, which is the aim of [[classification|9HQ3TADPA8]] in algebra and topology: the [[Euler characteristic|RNDDWDAFJ5]] and the [[knot invariants|GZQ5ZE3X6G]] are invariants in this sense.

In dynamical systems an invariant of a flow is a [[first integral|0262JP0NV9]], such as the energy of a mechanical system.
[[Noether's theorem|XHPDM5T2JG]] links such conserved quantities to symmetries.
The one-way version is a [[Lyapunov function|01REYCJ371]] or a [[monovariant|TP3GC5J08D]], which decreases along the motion and proves stability or termination.
In computer science, a loop invariant is a property kept by each pass of a loop, and it proves the correctness of the result.
