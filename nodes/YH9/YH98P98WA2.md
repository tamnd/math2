## Example

Let $\sigma = \set{0, +}$, with a constant symbol $0$ and a binary function symbol $+$.
We turn two equations into [[sentences|DKFGQTRYZE]] by universal closure, and we check each step with the [[definition|Q85MMH5DEY]].

1. $\operatorname{FV}(x + 0 = x) = \operatorname{Var}(x + 0) \cup \operatorname{Var}(x) = \set{x}$, so the equation is not a sentence.
2. $\operatorname{FV}(\forall x \, (x + 0 = x)) = \set{x} \setminus \set{x} = \emptyset$, so $\forall x \, (x + 0 = x)$ is a sentence.
3. $\operatorname{FV}(x + y = y + x) = \set{x, y}$.
4. $\operatorname{FV}(\forall y \, (x + y = y + x)) = \set{x}$, so one quantifier is not enough.
5. $\operatorname{FV}(\forall x \, \forall y \, (x + y = y + x)) = \emptyset$, so the universal closure $\forall x \, \forall y \, (x + y = y + x)$ is a sentence.

In the structure $(\mathbb{N}, 0, +)$ both sentences are true, because $n + 0 = n$ and $m + n = n + m$ for all natural numbers $m, n$.

## Remarks

The example shows how an algebraic law, written with free variables, becomes an axiom of a first-order theory.
The order of the quantifiers in a universal closure does not matter: $\forall y \, \forall x \, (x + y = y + x)$ is logically equivalent to the sentence of step 5.
The commutative law can fail in another structure.
In the structure of words over $\set{a, b}$, with $0$ the empty word and $+$ concatenation, the first sentence is true and the second is false, since $ab \neq ba$.
The existential closure gives other sentences.
For the formula $x = 0$, the closure $\exists x \, (x = 0)$ is true in $\mathbb{N}$, and the closure $\forall x \, (x = 0)$ is false.

## Explanations

### L1 human

In school, "$x + 0 = x$" means "for every number $x$, adding $0$ to $x$ gives $x$".
The "for every" is silent there.
Logic writes it out: $\forall x \, (x + 0 = x)$.
With the "for every" written, the claim is complete, and we can check it: $5 + 0 = 5$, and the same works for each number.
A law with two letters, such as $x + y = y + x$, needs a "for every" for each letter.

### L2 human

We show that a formula holds under every assignment exactly when its closure is true, for $\varphi = (x + y = y + x)$ in a structure $\mathcal{M}$.

1. By the truth clause for $\forall$, $\mathcal{M} \models \forall x \, \forall y \, \varphi$ when for each $a \in M$ and each $b \in M$ the formula $\varphi$ holds with $x$ and $y$ sent to $a$ and $b$.
2. An assignment $s$ affects $\varphi$ only through the pair $(s(x), s(y))$, because $\operatorname{FV}(\varphi) = \set{x, y}$.
3. Every pair $(a, b)$ comes from some assignment, and every assignment gives some pair.
4. So both conditions say that $\varphi$ holds for every pair $(a, b)$, and they are equivalent.

The typical use is the translation of laws of algebra into axioms, as for the axioms of groups or rings.
The trap is to close only some variables: $\forall y \, (x + y = y + x)$ still depends on $x$.
