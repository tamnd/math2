## Example

Let $\sigma = \{ 0, + \}$, with a constant symbol $0$ and a binary function symbol $+$.
We turn two equations into [[sentences|DKFGQTRYZE]] by universal closure, and we check each step with the [[definition|Q85MMH5DEY]].

1. $\operatorname{FV}(x + 0 = x) = \operatorname{Var}(x + 0) \cup \operatorname{Var}(x) = \{ x \}$, so the equation is not a sentence.
2. $\operatorname{FV}(\forall x \, (x + 0 = x)) = \{ x \} \setminus \{ x \} = \emptyset$, so $\forall x \, (x + 0 = x)$ is a sentence.
3. $\operatorname{FV}(x + y = y + x) = \{ x, y \}$.
4. $\operatorname{FV}(\forall y \, (x + y = y + x)) = \{ x \}$, so one quantifier is not enough.
5. $\operatorname{FV}(\forall x \, \forall y \, (x + y = y + x)) = \emptyset$, so the universal closure $\forall x \, \forall y \, (x + y = y + x)$ is a sentence.

In the structure $(\mathbb{N}, 0, +)$ both sentences are true, because $n + 0 = n$ and $m + n = n + m$ for all natural numbers $m$ and $n$.

## Remarks

The example shows how an algebraic law, written with free variables, becomes an axiom of a first-order theory.
The order of the quantifiers in a universal closure does not matter: $\forall y \, \forall x \, (x + y = y + x)$ is logically equivalent to the sentence of step 5.

The commutative law can fail in another structure.
Take the words over $\{ a, b \}$, with $0$ the empty word and $+$ concatenation.
Then the first sentence is true, and the second is false, since $ab \neq ba$.

The existential closure gives a different sentence.
For the formula $x = 0$, the closure $\exists x \, (x = 0)$ is true in $\mathbb{N}$, while $\forall x \, (x = 0)$ is false.
So the choice of closure matters.

## Explanations

### L1 human

In school, "$x + 0 = x$" means "for every number $x$, adding $0$ to $x$ gives $x$".
The "for every" is silent there.
Logic writes it out: $\forall x \, (x + 0 = x)$.
With the "for every" written, the claim is complete, and we can check it: $5 + 0 = 5$, and the same works for each number.
A law with two letters, such as $x + y = y + x$, needs a "for every" for each letter.

### L2 human

We show that $\varphi = (x + y = y + x)$ holds in a structure $\mathcal{M}$ under every assignment exactly when its closure is true in $\mathcal{M}$.
By the truth clause for $\forall$, $\mathcal{M} \models \forall x \, \forall y \, \varphi$ means that $\varphi$ holds when $x$ and $y$ are sent to $a$ and $b$, for every $a, b \in M$.
An assignment $s$ affects $\varphi$ only through the pair $(s(x), s(y))$, because $\operatorname{FV}(\varphi) = \{ x, y \}$.
Every pair $(a, b)$ comes from some assignment, and every assignment gives some pair.
So both conditions say that $\varphi$ holds for every pair, and they are equivalent.
This is why textbooks may state laws with free variables: the universal reading is the closure.
