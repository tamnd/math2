## Example

Let $k \ge 1$ and let $m = (m_1, \dots, m_k) \in \F_2^k$ be a message of $k$ bits.
Its (even) *parity bit* is $p = m_1 + \cdots + m_k$ in $\F_2$, and the sent word is $(m_1, \dots, m_k, p)$.
For example, the message $1011$ has parity bit $1 + 0 + 1 + 1 = 1$, and the sent word is $10111$.
The sent words are exactly the words of $\F_2^{k+1}$ of even [[Hamming weight|K8ZHAQAK2B]].
They form a [[linear code|E85KREWV60]], the kernel of the map $x \mapsto x_1 + \cdots + x_{k+1}$, with dimension $k$.
Two distinct words of even weight differ in at least $2$ positions, and $110 \cdots 0$ shows that $2$ is reached.
So the [[minimum distance|M2X88AXM17]] is $2$, and this is a $[k + 1, k, 2]$ code.

## Remarks

Flipping one bit changes the parity of the weight, so the receiver detects any single error, and in fact any odd number of errors.
An even number of errors leaves the parity unchanged and is not detected.
With minimum distance $2$ the code [[detects one error but corrects none|NDQ8D2V5XY]]: the word $10110$ is at distance $1$ from both $10111$ and $10100$.

## Explanations

### L1 human

A parity bit is one extra bit added so that the total number of ones is even.
If one bit gets flipped in transit, the count becomes odd, and the receiver knows that something went wrong.
It cannot tell which bit was flipped, so it can only ask for the data again.
It is the cheapest error check and was long used in memory chips and serial links.
