## Example

Let $\mathsf{GL} = \mathsf{K} + \square(\square p \to p) \to \square p$ be the [[provability logic|WJK0YA4GP2]].
Its frames are the transitive frames with no infinite forward chain, as in [[Löb's axiom|QQ6PZFGGB3]].
We show that the canonical frame of $\mathsf{GL}$ has an infinite forward chain, so the [[canonical model|TVE4F04KME]] method fails for $\mathsf{GL}$.

The chain is forced by one consistent set of formulas:
$$\Gamma = \{ \lozenge p_0 \} \cup \{ \square(p_i \to \lozenge p_{i+1}) : i \in \mathbb{N} \}.$$

First we show that $\Gamma$ is $\mathsf{GL}$-consistent.
Fix $k \geq 1$ and the finite part $\Gamma_k = \{ \lozenge p_0 \} \cup \{ \square(p_i \to \lozenge p_{i+1}) : i \leq k - 1 \}$.
Take the chain $c_0, c_1, \dots, c_{k+1}$ with $c_i R c_j$ exactly when $i < j$, and put $V(p_i) = \{ c_{i+1} \}$.
This frame is finite, transitive and irreflexive, so it validates $\mathsf{GL}$.
At $c_0$, $\lozenge p_0$ is true because $c_0 R c_1$ and $p_0$ is true at $c_1$.
For $i \leq k - 1$, the only world where $p_i$ holds is $c_{i+1}$, and it sees $c_{i+2}$, where $p_{i+1}$ holds.
So $\square(p_i \to \lozenge p_{i+1})$ is true at $c_0$, and all of $\Gamma_k$ is true at $c_0$.
By [[soundness|E87G6ZTMTN]], no finite part of $\Gamma$ is refutable in $\mathsf{GL}$, so $\Gamma$ is consistent.

Now we build the chain in the canonical frame.
[[Lindenbaum's lemma|SC0BSJ3GT6]] gives a maximal consistent $\Delta_0 \supseteq \Gamma$.
$\mathsf{GL}$ proves axiom $\mathrm{4}$, so its canonical frame is transitive.
Since $\lozenge p_0 \in \Delta_0$, the existence lemma of the [[truth lemma page|NM4CB7QAYT]] gives $\Delta_1$ with $\Delta_0 R^c \Delta_1$ and $p_0 \in \Delta_1$.
Each $\square(p_i \to \lozenge p_{i+1})$ lies in $\Delta_0$, so $p_0 \to \lozenge p_1$ lies in $\Delta_1$, and by axiom $\mathrm{4}$ each $\square(p_i \to \lozenge p_{i+1})$ lies in $\Delta_1$ as well.
So $\lozenge p_1 \in \Delta_1$, and the same argument gives $\Delta_2$ with $\Delta_1 R^c \Delta_2$ and $p_1 \in \Delta_2$.
Repeating it gives $\Delta_0 R^c \Delta_1 R^c \Delta_2 R^c \cdots$ with $p_n \in \Delta_{n+1}$.

This chain goes on forever, so $R^c$ is not conversely [[well-founded|0DQPNJNPYK]], and Löb's axiom is not valid on the canonical frame.

Check with $k = 1$: $\Gamma_1 = \{ \lozenge p_0, \square(p_0 \to \lozenge p_1) \}$ on the chain $c_0, c_1, c_2$ with $V(p_0) = \{ c_1 \}$ and $V(p_1) = \{ c_2 \}$.
$\lozenge p_0$ holds at $c_0$ via $c_1$, and $p_0 \to \lozenge p_1$ holds at $c_1$ via $c_2$ and at $c_2$ because $p_0$ is false there.

## Remarks

### Truth in the model versus validity on the frame

The canonical model of a logic always makes the logic true, but its frame need not validate it.
Under the canonical valuation every theorem of $\mathsf{GL}$ is true at every world.
Other valuations on the same frame refute Löb's axiom, because the frame contains the infinite chain above.
So $\mathsf{GL}$ is not canonical, and its completeness needs another method: the [[Kripke completeness of GL|1DMFNR7FZT]] uses finite models.

### Strong completeness fails

The set $\Gamma$ also shows that $\mathsf{GL}$ is not strongly complete.
$\Gamma$ is consistent, but no world of a transitive frame without infinite forward chains satisfies all of $\Gamma$, because the argument above would build such a chain.

### What makes the example work

If we drop $\lozenge p_0$ from $\Gamma$, the rest is true at a world without successors, and no chain is forced.
The first diamond starts the chain, and the boxed implications keep it going.

### Watch out

$\Gamma$ is satisfiable in a model whose theorems are those of $\mathsf{GL}$, namely the canonical model.
It is not satisfiable on any frame of $\mathsf{GL}$.
This is the gap between truth in a model and validity on a frame.

## Explanations

### L1 human

The canonical model collects all consistent descriptions of a world into one model.
For most logics, the picture behind this model already obeys the rules of the logic.
For the logic of provability, the rules forbid a path of arrows that goes on forever.
But a consistent description can ask for such a path, one step at a time.
It says: "$p_0$ is possible, and wherever $p_0$ holds, $p_1$ is possible, and so on".
So the canonical picture contains an endless path, and it breaks the rules.

### L2 human

Each finite piece of the description can be met by a finite chain: the piece with $k$ conditions needs $k + 2$ worlds.
This is why every finite part is consistent.
The whole description needs an infinite chain, which a frame of $\mathsf{GL}$ cannot have, but the canonical frame can.
The typical use of this example is as the standard proof that a logic can be complete without being canonical.
