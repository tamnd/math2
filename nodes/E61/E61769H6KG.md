## Example

Let $\mathsf{GL} = \mathsf{K} + \square(\square p \to p) \to \square p$ be the [[provability logic|WJK0YA4GP2]].
We show that the canonical frame of $\mathsf{GL}$ does not validate $\mathsf{GL}$, so the [[canonical model|TVE4F04KME]] method fails for it.
Consider the set
$$\Gamma = \set{\lozenge p_0} \cup \set{\square(p_i \to \lozenge p_{i+1}) : i \in \N}.$$

1. Fix $k \geq 1$ and the finite part $\Gamma_k = \set{\lozenge p_0} \cup \set{\square(p_i \to \lozenge p_{i+1}) : i \leq k - 1}$.
2. Take the chain $c_0, c_1, \dots, c_{k+1}$ with $c_i R c_j$ exactly when $i < j$, and $V(p_i) = \set{c_{i+1}}$.
3. This frame is finite, transitive and irreflexive, so it validates $\mathsf{GL}$ by part 3 of [[Löb's axiom in provability logic|QQ6PZFGGB3]].
4. At $c_0$, $\lozenge p_0$ is true, since $c_0 R c_1$ and $p_0$ is true at $c_1$.
5. Let $i \leq k - 1$ and $c_0 R c_j$. If $p_i$ is true at $c_j$, then $j = i + 1$, and $c_{i+2}$ exists since $i + 2 \leq k + 1$.
6. Then $c_{i+1} R c_{i+2}$ and $p_{i+1}$ is true at $c_{i+2}$, so $\lozenge p_{i+1}$ is true at $c_j$. So $\square(p_i \to \lozenge p_{i+1})$ is true at $c_0$.
7. So $\Gamma_k$ is true at $c_0$. By [[soundness|E87G6ZTMTN]], no finite part of $\Gamma$ is refutable in $\mathsf{GL}$, so $\Gamma$ is $\mathsf{GL}$-consistent.
8. [[Lindenbaum's lemma|SC0BSJ3GT6]] gives a maximal consistent $\Delta_0 \supseteq \Gamma$. By the [[truth lemma|NM4CB7QAYT]], $\Gamma$ is true at $\Delta_0$ in the canonical model.
9. $\mathsf{GL}$ proves $\mathrm{4}$ (part 1 of the same page), and the canonical frame of a logic with $\mathrm{4}$ is transitive. So the canonical frame is transitive.
10. Since $\lozenge p_0$ holds at $\Delta_0$, there is $\Delta_1$ with $\Delta_0 R^c \Delta_1$ and $p_0 \in \Delta_1$.
11. Each $\square(p_i \to \lozenge p_{i+1})$ holds at $\Delta_0$, so $p_0 \to \lozenge p_1$ and, by axiom $\mathrm{4}$, each $\square(p_i \to \lozenge p_{i+1})$ hold at $\Delta_1$. So $\lozenge p_1$ holds at $\Delta_1$.
12. Repeating step 11 gives $\Delta_0 R^c \Delta_1 R^c \Delta_2 R^c \cdots$ with $p_n \in \Delta_{n+1}$.
13. The set $\set{\Delta_n : n \in \N}$ has no $R^c$-maximal element, so $R^c$ is not conversely [[well-founded|0DQPNJNPYK]].
14. By part 3 of the same page, Löb's axiom is not valid on the canonical frame.

## Remarks

The example shows that the canonical model of a logic always satisfies the logic, but its frame need not validate it.
The canonical model makes every theorem of $\mathsf{GL}$ true under its own valuation, while other valuations on the same frame refute Löb's axiom.
So $\mathsf{GL}$ is not canonical, and its completeness needs another method: the [[Kripke completeness of GL|1DMFNR7FZT]] uses finite models.
The set $\Gamma$ also shows that $\mathsf{GL}$ is not strongly complete: no world of a transitive conversely well-founded frame satisfies all of $\Gamma$.
If we drop $\lozenge p_0$ from $\Gamma$, the set is true at a world without successors, and no infinite chain is forced.

## Explanations

### L1 human

The canonical model collects all consistent descriptions of a world into one model.
For most logics, the picture behind this model already obeys the rules of the logic.
For the logic of provability, the rules forbid an infinite path that goes on forever.
But a consistent description can ask for such a path, step by step.
It says: "$p_0$ is possible, and wherever $p_0$ holds, $p_1$ is possible, and so on".
So the canonical picture contains an infinite path, and it breaks the rules.

### L2 human

1. For $k = 1$, $\Gamma_1 = \set{\lozenge p_0, \square(p_0 \to \lozenge p_1)}$.
2. The chain is $c_0, c_1, c_2$ with $V(p_0) = \set{c_1}$ and $V(p_1) = \set{c_2}$.
3. $\lozenge p_0$ holds at $c_0$ via $c_1$, and $p_0 \to \lozenge p_1$ holds at $c_1$ via $c_2$ and at $c_2$ since $p_0$ is false there.
4. So $\Gamma_1$ is true at $c_0$, with a chain of length 2.

The typical use of this example is as the standard proof that a logic can be complete without being canonical.
A trap: $\Gamma$ is satisfiable in a model of $\mathsf{GL}$, the canonical model, but not on any frame of $\mathsf{GL}$.
