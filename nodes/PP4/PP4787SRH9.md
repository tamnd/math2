## Example

Given: a triangle $ABC$ with $AB = AC$, and the [[midpoint|0S706JBZBG]] $M$ of $BC$.

Prove: the segment $AM$ is perpendicular to $BC$.

A student hands in this table, which is a flawed example.

| # | Statements | Reasons |
|---|---|---|
| 1 | $AB = AC$ | given |
| 2 | $BM = CM$ | definition of midpoint |
| 3 | $\angle AMB = \angle AMC$ | from the diagram |
| 4 | $\angle AMB + \angle AMC = 180^\circ$ | angles on a straight line |
| 5 | $\angle AMB = 90^\circ$ | rows 3 and 4 |
| 6 | $AM$ is perpendicular to $BC$ | definition of perpendicular lines |

Every statement in the table is true, but the table is not a [[two-column proof|P8PCGFASP8]].
The reasons in rows 1, 2, 4, 5 and 6 are of the allowed kinds: a given fact, a definition, the straight angle, and arithmetic on earlier rows.
The flaw is row 3.
A diagram is one drawing, and it can look the same for a triangle in which the statement is false.

Row 3 is also the only row that would need the hypothesis $AB = AC$, and no row cites row 1.
So the table would "prove" the claim for every triangle.
The claim is false without $AB = AC$: take $A = (1, 3)$, $B = (0, 0)$ and $C = (4, 0)$, so that $M = (2, 0)$.
The vectors $\vec{MA} = (-1, 3)$ and $\vec{MC} = (2, 0)$ have dot product $-2 \ne 0$, so $AM$ is not perpendicular to $BC$.

The repair replaces row 3 by three rows.

| # | Statements | Reasons |
|---|---|---|
| 3a | $AM = AM$ | a segment is equal to itself |
| 3b | triangle $ABM$ is congruent to triangle $ACM$, with $A \mapsto A$, $B \mapsto C$, $M \mapsto M$ | side-side-side (1, 2, 3a) |
| 3c | $\angle AMB = \angle AMC$ | corresponding parts of congruent triangles are equal (3b) |

Now row 3c uses row 1, through the side-side-side criterion of the [[congruence criteria for triangles|5NEJPXA6N4]].
Rows 4 to 6 stay the same, and the table is a two-column proof.

## Remarks

A two-column proof is more than a list of true facts: each reason must be a given fact, a definition, a postulate or a theorem.
Checking that each hypothesis is cited somewhere is a quick test.
A hypothesis that no row uses signals either a gap or a hypothesis that the theorem does not need.

In the triangle $A = (1, 3)$, $B = (0, 0)$, $C = (4, 0)$, the angle $\angle AMB$ has cosine
$$\frac{\vec{MA} \cdot \vec{MB}}{\lvert \vec{MA} \rvert \lvert \vec{MB} \rvert} = \frac{2}{\sqrt{10} \cdot 2} = \frac{1}{\sqrt{10}},$$
so $\angle AMB$ is about $71.6^\circ$ and $\angle AMC$ is about $108.4^\circ$.
A careless sketch could still make them look equal.

A diagram is still useful.
It suggests which facts to prove and which triangles to compare, but each fact needs a reason that holds for every figure that meets the "Given" line.

## Explanations

### L1 human

A drawing can fool the eye.
Two angles can look equal in a picture and differ by a few degrees.
Here the student wrote "from the diagram" as the reason why two angles are equal, and never used the fact that two sides of the triangle are equal.
So the same table would work for any triangle, and for some triangles the claim is false.
The repair uses congruent triangles to give a real reason.

### L2 human

We check the repaired table on the isosceles triangle $A = (0, 4)$, $B = (-3, 0)$ and $C = (3, 0)$.
The midpoint of $BC$ is $M = (0, 0)$.
For row 3b, $AB = AC = 5$, $BM = CM = 3$ and $AM = 4$, so the triangles $ABM$ and $ACM$ have the same three sides.
For row 3c, both angles at $M$ lie between the vector $(0, 4)$ and a horizontal vector, so both are $90^\circ$.
For row 6, $AM$ lies on the line $x = 0$ and $BC$ on the line $y = 0$, so they are perpendicular.

To read a table, ask of each reason whether it would hold for every figure that meets the "Given" line.
Watch out: a true statement does not make its reason acceptable, and a true statement with a missing reason is still a gap.
