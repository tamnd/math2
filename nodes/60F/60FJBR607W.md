## Definition

Let $H_A$ and $H_B$ be finite-dimensional complex Hilbert spaces, and let $\rho$ be a [[density matrix|V1JTB52E8C]] on the [[tensor product|EY0X2NKA3S]] $H_A \otimes H_B$.
The state $\rho$ is *separable* if, for finitely many indices $i$, there are weights $p_i \ge 0$ with $\sum_i p_i = 1$ and states $\rho_i^A$, $\rho_i^B$ such that
$$\rho = \sum_i p_i \, \rho_i^A \otimes \rho_i^B.$$
Here each $\rho_i^A$ is a density matrix on $H_A$ and each $\rho_i^B$ is a density matrix on $H_B$.

## Remarks

Example: on $\C^2 \otimes \C^2$, the state $\sigma = \tfrac12 (|00\rangle\langle 00| + |11\rangle\langle 11|)$ is separable.
Indeed $\sigma = \tfrac12 |0\rangle\langle 0| \otimes |0\rangle\langle 0| + \tfrac12 |1\rangle\langle 1| \otimes |1\rangle\langle 1|$, with weights $\tfrac12, \tfrac12$.
The maximally mixed state $\tfrac14 I = \tfrac12 I \otimes \tfrac12 I$ is separable with a single term.

Non-example: let $\psi = (|00\rangle + |11\rangle)/\sqrt{2}$.
A pure state $|\psi\rangle\langle\psi|$ is an extreme point of the set of states, so in any decomposition as above every term with $p_i > 0$ equals $|\psi\rangle\langle\psi|$.
Then $|\psi\rangle\langle\psi|$ would be a product $\rho^A \otimes \rho^B$, which forces $\psi$ to be a product vector, and it is not one.

Equivalently, the separable states form the [[convex hull|0FQSDC2EQ2]] of the pure product states $|a\rangle\langle a| \otimes |b\rangle\langle b|$.
By Carathéodory's theorem, at most $(d_A d_B)^2$ terms are needed, where $d_A = \dim H_A$ and $d_B = \dim H_B$.
In infinite dimension, one takes the closure of this convex hull in the trace norm.
