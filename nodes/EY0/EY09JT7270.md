## Summary

The ultraproduct method builds a model of a set $T$ of [[sentences|DKFGQTRYZE]] from models of its finite subsets.
Let $I$ be the set of finite subsets of $T$, and for each $\Delta \in I$ let $\mathcal{M}_\Delta$ be a model of $\Delta$.
For $\varphi \in T$ let $A_\varphi = \set{\Delta \in I : \varphi \in \Delta}$.
The sets $A_\varphi$ have the finite intersection property, since $\set{\varphi_1, \dots, \varphi_n}$ lies in $A_{\varphi_1} \cap \dots \cap A_{\varphi_n}$.
By the [[ultrafilter lemma|3MKZST79MK]] some ultrafilter $\mathcal{U}$ on $I$ contains every $A_\varphi$.
For $\varphi \in T$, the truth set of $\varphi$ contains $A_\varphi$, so [[Łoś's theorem|AGYBSTD7BG]] gives $\prod_{\Delta \in I} \mathcal{M}_\Delta / \mathcal{U} \models \varphi$.
This proves the [[compactness theorem|1NR3HAWG9D]] with no proof system, and the same pattern turns "finitely many conditions can be met" into "all conditions can be met at once".

## Motivation

The compactness theorem is a statement about truth, with no mention of proofs.
The classical route goes through the completeness theorem: a finitely satisfiable set is consistent, because a proof uses finitely many premises, and a consistent set has a model by Henkin's construction.
That route needs a full deductive calculus and its soundness and completeness.
The ultraproduct route stays inside semantics: it takes the models that exist for the finite parts and averages them.
The same averaging solves many problems where each finite part has a solution, as in combinatorics and algebra.

## Notation

The index set is often written $\mathcal{P}_{\mathrm{fin}}(T)$ or $[T]^{<\omega}$.
An ultrafilter on $\mathcal{P}_{\mathrm{fin}}(T)$ that contains every $A_\varphi$ is called *fine*.
The model obtained is $\prod_{\Delta} \mathcal{M}_\Delta / \mathcal{U}$, or $\prod_{\mathcal{U}} \mathcal{M}_\Delta$.

## Remarks

### Examples

- The [[proof of the compactness theorem by ultraproducts|22TWAHBVWT]] is the method applied to an arbitrary finitely satisfiable set of sentences.
- A theory with arbitrarily large finite models has an infinite model; see [[this example|NWC4594R42]].
- A graph is $k$-colorable when each finite subgraph is; see [[this example|QGFVNSRD06]].
- A nonprincipal ultrapower of $\N$ realizes the set of formulas $\set{x > n : n \in \N}$; see [[this example|5B6GQKKDMG]].
- The proof of [[Frayne's theorem|QPX9HG9BH4]] uses the same index set, with the finite parts of an elementary diagram.

### Non-examples

- For second-order sentences the method fails, since Łoś's theorem fails: an ultraproduct of finite sets is infinite. See [[this non-example|V4090YNR6F]].
- An arbitrary nonprincipal ultrafilter on $I$ does not work. It must contain every $A_\varphi$, or the truth set of some $\varphi$ may lie outside $\mathcal{U}$.
- A model for each single sentence is not enough: $\set{p, \neg p}$ has a model for each member, but no model.

### Basic properties

- The method uses the ultrafilter lemma to get $\mathcal{U}$ and the axiom of choice in the proof of Łoś's theorem.
- The language may be of any size, and no well-order of the sentences is needed.
- If each $\mathcal{M}_\Delta$ is a model of a theory $S$, the ultraproduct is also a model of $S$; so a set $T$ is satisfiable together with $S$ when each finite part is.
- The model is often large: over a countable infinite $I$ with a nonprincipal $\mathcal{U}$, an infinite ultraproduct has at least $2^{\aleph_0}$ elements.

### History

Gödel derived compactness for countable languages from his completeness theorem in 1930, and Maltsev extended it to all languages in 1936.
Both proofs go through a proof system or a direct construction of models from syntax.
The ultraproduct proof became possible with Łoś's theorem of 1955.

### Common errors

- To index the ultraproduct by the sentences of $T$ instead of the finite subsets of $T$.
- To use the [[Fréchet filter|QN98V7NMCD]] or another filter that is not an ultrafilter; then negation and disjunction are lost.
- To expect a countable model. Henkin's proof gives a model of size at most $\abs{L} + \aleph_0$, and the ultraproduct does not.

## Explanations

### L1 human

Suppose we have a long list of wishes for a structure, and for each short part of the list we can build a structure that meets it.
We cannot always see how to meet all the wishes at once.
The ultraproduct takes all these structures together and forms a kind of average.
Each wish is met by most of the structures, so it is met by the average.

### L2 human

Let $T$ consist of the field axioms and, for each prime $q$, the sentence $\chi_q$ that says $q \cdot 1 \neq 0$.
We build a model of $T$ from finite fields, which never satisfy all of $T$.

1. Let $I$ be the set of finite subsets $\Delta$ of $T$.
2. For $\Delta \in I$, let $p_\Delta$ be a prime larger than every $q$ with $\chi_q \in \Delta$, and let $\mathcal{M}_\Delta = \F_{p_\Delta}$. Then $\mathcal{M}_\Delta \models \Delta$.
3. Any finite intersection $A_{\varphi_1} \cap \dots \cap A_{\varphi_n}$ contains $\set{\varphi_1, \dots, \varphi_n}$, so the sets $A_\varphi$ have the finite intersection property.
4. The ultrafilter lemma gives an ultrafilter $\mathcal{U}$ on $I$ that contains every $A_\varphi$.
5. For $\varphi \in T$, the truth set of $\varphi$ contains $A_\varphi$ by step 2. Łoś's theorem gives $\varphi$ in the ultraproduct.

So the ultraproduct is a field of characteristic $0$ built from finite fields.
The typical use is to prove that a property holds in some infinite or nonstandard model.
The trap is the choice of the ultrafilter: it must contain the sets $A_\varphi$.

### L3 human

In topological terms, the method shows that the space of complete theories, the Stone space of the Lindenbaum algebra, is compact.
The sets $A_\varphi$ say that $\Delta$ grows, and a fine ultrafilter is a way to let $\Delta$ tend to all of $T$; the ultraproduct plays the part of the limit of the net $(\mathcal{M}_\Delta)$.
The same method gives compactness for continuous logic, where a complete proof system is harder to set up, and for logics where Łoś's theorem holds.
More generally, every logic whose sentences satisfy Łoś's theorem for all ultraproducts is compact, by the same argument.
