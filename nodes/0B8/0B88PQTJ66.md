## Definition

Let $D$ be a set, the domain of discourse, and let $P(x)$ be a [[predicate|0T3DPBG981]] on $D$.
The universal quantification of $P$ over $D$ is the [[proposition|0ZGC7ZESYN]] $\forall x \, P(x)$, read "for all $x$, $P(x)$".

1. $\forall x \, P(x)$ is true when $P(a)$ is true for every $a \in D$.
2. $\forall x \, P(x)$ is false when there is at least one $a \in D$ with $P(a)$ false.

The variable $x$ is bound by the quantifier $\forall x$.
If $P$ has further free variables, as in $P(x, y)$, then $\forall x \, P(x, y)$ is a predicate in $y$, and its value at $b \in D$ is $\forall x \, P(x, b)$.
For a subset $A \subseteq D$, the restricted universal quantification is the abbreviation
$$\forall x \in A \; P(x) \quad :\Longleftrightarrow \quad \forall x \, (x \in A \to P(x)),$$
where $\to$ is the [[material implication|0NMG7W7Q11]].

## Notation

Other forms are $\forall x \colon P(x)$, $\forall x, \, P(x)$, $(\forall x) \, P(x)$ and the older $(x) \, P(x)$.
The restricted form is also written $(\forall x \in A) \, P(x)$, and conditions other than membership are used in the same way: $\forall \varepsilon > 0 \; P(\varepsilon)$ means $\forall \varepsilon \, (\varepsilon > 0 \to P(\varepsilon))$.

## Remarks

When $A = \varnothing$, the statement $\forall x \in A \; P(x)$ is true for each $P$, because each instance has a false antecedent; this is a case of [[vacuous truth|0V4QXPGJQK]].
Classical first-order logic requires $D \neq \varnothing$, while the restricted form allows an empty $A$.
For a finite domain $D = \{a_1, \dots, a_n\}$, the statement $\forall x \, P(x)$ is equivalent to $P(a_1) \land \dots \land P(a_n)$.
An element $a$ with $P(a)$ false is a [[counterexample|0ED72CTBNP]], and one counterexample makes the statement false.
The concept page [[universal quantifier|0GHS47PDAQ]] gives the examples, the non-examples, the first properties and the methods of proof.

## Explanations

### L1 human

"For all $x$ in a set, $P(x)$" says that every member of the set passes the test $P$.
One member that fails the test makes the statement false.
For example, "every number in $\{2, 4, 6\}$ is even" is true, and "every number in $\{2, 4, 7\}$ is even" is false because of $7$.

### L2 human

We unfold $\forall x \in \mathbb{Z} \; (x^2 \ge x)$ with the definition, on the domain $D = \mathbb{R}$.

1. By the definition of the restricted form, the statement is $\forall x \, (x \in \mathbb{Z} \to x^2 \ge x)$.
2. For $x = \frac{1}{2}$, the antecedent is false, so the instance is true; for this non-integer, $x^2 = \frac{1}{4} < x$, but the implication does not ask about it.
3. For an integer $x \le 0$, we have $x^2 \ge 0 \ge x$. For an integer $x \ge 1$, we have $x^2 = x \cdot x \ge 1 \cdot x = x$.
4. So every instance is true, and the restricted statement is true.

A trap is to drop the restriction: $\forall x \in \mathbb{R} \; (x^2 \ge x)$ is false, and $x = \frac{1}{2}$ is a counterexample.
