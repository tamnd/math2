## Summary

Let $G$ be a [[group|G5S1M9]].
The order of $G$ is the [[cardinality|0G0ASKNA6Z]] of the set of elements of $G$, and it is written $|G|$.
When this set is [[finite|070R982G4B]], the group $G$ is a finite group, and $|G|$ is the number of its elements.
When this set is infinite, the group $G$ is an infinite group, and we say that $G$ has infinite order.
The order is the first number that we attach to a group, and many theorems on finite groups, such as [[Lagrange's theorem|3C53TD]], are statements about orders.

## Motivation

To compare two groups, the first question is how many elements each group has.
An [[isomorphism|08MG7H8JW5]] is a bijection, so two isomorphic groups have the same number of elements.
Thus the order is a quick test: groups of different orders are never isomorphic.
For finite groups the order also controls the structure.
For example, the order of each subgroup divides the order of the group, and a group of prime order is [[cyclic|0KVGH0J5B3]].
These facts make the order the starting point of the theory of finite groups.

## Notation

The most common notation is $|G|$.
Some books write $\#G$, $o(G)$ or $\operatorname{card}(G)$.
The word "order" has two meanings in group theory.
It means the order $|G|$ of a group, and it also means the [[order of an element|0WE2NHZJ7B]] $g$, written $\ord(g)$.
The two meanings are linked: the order of $g$ equals the order of the [[cyclic subgroup|031M8HX7DA]] $\langle g \rangle$ that $g$ generates.
In math2 the word "order" has both meanings, and the object (a group or an element) shows which meaning is used.

## Remarks

### Examples

1. The [[trivial group|0BNPC9850Y]] $\{e\}$ has order $1$, because it has one element.
2. The [[integers modulo $n$|03VFZ2WETT]] with addition form a group $\mathbb{Z}/n\mathbb{Z}$ of order $n$, because there are $n$ residue classes $0, 1, \ldots, n - 1$.
3. The [[symmetric group|0515A6D2Y1]] $S_3$ has order $3! = 6$, because there are $6$ permutations of three objects.
4. [[The general linear group of 2 by 2 matrices over the integers modulo 2 has order 6|M170X47PG4]]: exactly $6$ of the $16$ matrices have determinant $1$.
5. [[The additive group of rational numbers has countably infinite order|RCPSH0CW5W]], and the additive group of real numbers has an uncountable order.
6. The [[group of $n$th roots of unity|0WX11EA3F3]] has order $n$, because $z^n = 1$ has exactly $n$ complex solutions.

### Non-examples

1. [[The nonzero residues modulo 6 do not form a group of order 5|QWD5T5RX62]]: the set has $5$ elements, but it is not closed under multiplication, because $2 \cdot 3 \equiv 0 \pmod 6$.
2. [[The natural numbers under addition are not a group|R68D2P175Z]], so the infinite set $\mathbb{N}$ with addition has no order as a group: the element $1$ has no inverse.

### Basic properties

1. Each group has order at least $1$, because it contains its identity element $e$. A group of order $1$ is the trivial group.
2. Isomorphic groups have the same order, because an isomorphism is a bijection between their sets of elements.
3. The converse of property 2 is false. The groups $\mathbb{Z}/4\mathbb{Z}$ and the [[Klein four-group|0PMRQJVTME]] both have order $4$. They are not isomorphic, because $\mathbb{Z}/4\mathbb{Z}$ has an element of order $4$ and the Klein four-group has none.
4. The [[direct product|00HF4RJ5QN]] $G \times H$ of finite groups has order $|G| \cdot |H|$, because its set is the Cartesian product of the two sets.
5. By [[Lagrange's theorem|3C53TD]], the order of each subgroup of a finite group $G$ divides $|G|$.
6. In a finite group $G$, the [[order of each element divides the order of the group|08V7JHS3QZ]], and so $g^{|G|} = e$ for each $g \in G$, by [[this result|0ZEPNS9BXK]].

### History

Questions about the order of a group first came from groups of permutations, in the study of the roots of polynomial equations.
In 1872 Ludwig Sylow proved his theorems on the subgroups of a finite group whose order is the largest power of a prime that divides the order of the group.
These theorems, and Lagrange's theorem, made the order the main tool of the theory of finite groups.

### Common errors

1. The order of the group is mixed with the order of an element. A group of order $6$ need not have an element of order $6$: no element of $S_3$ has order $6$.
2. The order is taken to fix the group. Two groups of the same order can be different, as $\mathbb{Z}/4\mathbb{Z}$ and the Klein four-group show.
3. The elements of a set are counted before the group axioms are checked. A set with $5$ elements and an operation is a group of order $5$ only when the operation satisfies the group axioms.

## Explanations

### L1 human

The order of a group is the number of its elements.
For example, the rotations that move a square onto itself are the turns by $0$, $90$, $180$ and $270$ degrees.
These four rotations form a group, so this group has order $4$.
Some groups have infinitely many elements, for example the whole numbers $\ldots, -2, -1, 0, 1, 2, \ldots$ with addition.
Such a group has infinite order.
Take care: the same word "order" is also used for single elements of a group, with a different meaning.

### L2 human

We compute the order of the group $U(12)$ of units of $\mathbb{Z}/12\mathbb{Z}$, the [[group of units|0F8X8ZRQ53]] under multiplication modulo $12$.

1. The ring $\mathbb{Z}/12\mathbb{Z}$ has the $12$ residues $0, 1, \ldots, 11$.
2. A residue $a$ is a unit if and only if $\gcd(a, 12) = 1$, by [[this criterion|0GXNHEHQNA]].
3. The residues with $\gcd(a, 12) = 1$ are $1, 5, 7$ and $11$.
4. Thus $U(12) = \{1, 5, 7, 11\}$, and $|U(12)| = 4$.
5. We check one product: $5 \cdot 7 = 35 = 2 \cdot 12 + 11$, so $5 \cdot 7 \equiv 11 \pmod{12}$, and $11$ is again in the set.

The order $4$ alone does not tell us which group of order $4$ this is.
We have $5^2 = 25 \equiv 1$, $7^2 = 49 \equiv 1$ and $11^2 = 121 \equiv 1 \pmod{12}$, so no element has order $4$.
Thus $U(12)$ is not cyclic, and it is isomorphic to the Klein four-group.
The typical use of the order is with Lagrange's theorem: a subgroup of $U(12)$ can only have order $1$, $2$ or $4$.
A trap is to compare infinite groups only by the word "infinite".
The groups $(\mathbb{Z}, +)$ and $(\mathbb{R}, +)$ are both infinite, but their orders are different cardinal numbers, so they are not isomorphic.

### L3 human

For an infinite group the order is a [[cardinal number|0EBACQFAZW]].
Two infinite groups of the same cardinality can still be very different: $(\mathbb{Z}, +)$ and $(\mathbb{Q}, +)$ are both countable, but only the first is cyclic.
For finite groups the order is a strong constraint.
The number of groups of order $n$ up to isomorphism depends on the prime factorization of $n$: for example, there are $5$ groups of order $8$ and $14$ groups of order $16$.
Each group of prime order $p$ is cyclic, so it is isomorphic to $\mathbb{Z}/p\mathbb{Z}$.
The later sub-areas use the order in each step.
The sub-area on [[cosets and Lagrange's theorem|1VHQWXC64D]] divides $|G|$ by the order of a subgroup.
The [[Cauchy and Sylow theorems|STDBRYKADM]] find subgroups whose order is a prime power.
The [[arithmetic properties of finite groups|G87AMJC5CF]] tell which numbers $n$ have only cyclic or only abelian groups of order $n$.
For [[profinite groups|FPGHSQYSYX]] the order is a supernatural number, a formal product of prime powers with exponents that can be infinite.
