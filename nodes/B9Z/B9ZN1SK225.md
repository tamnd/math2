## Example

Consider the [[integers modulo 7|03VFZ2WETT]], with multiplication of classes: $[a][b] = [ab]$.
The identity element for this multiplication is $[1]$.
We find an inverse for each nonzero class $[1], [2], \ldots, [6]$.

1. $1 \cdot 1 = 1$, so $[1]^{-1} = [1]$.
2. $2 \cdot 4 = 8 = 7 + 1$, so $[2][4] = [1]$, and $[2]^{-1} = [4]$, $[4]^{-1} = [2]$.
3. $3 \cdot 5 = 15 = 2 \cdot 7 + 1$, so $[3][5] = [1]$, and $[3]^{-1} = [5]$, $[5]^{-1} = [3]$.
4. $6 \cdot 6 = 36 = 5 \cdot 7 + 1$, so $[6]^{-1} = [6]$.
5. Multiplication of classes is commutative, because multiplication of integers is commutative. So each equation $[a][b] = [1]$ above also gives $[b][a] = [1]$, and each $[b]$ is a two-sided inverse.

The class $[0]$ has no inverse, because $[0][b] = [0] \neq [1]$ for each $b$.

## Remarks

So the six nonzero classes modulo $7$ form a group under multiplication, the [[group of units|0F8X8ZRQ53]] of $\mathbb{Z}/7\mathbb{Z}$.
The same holds modulo each prime number.
For a modulus that is not prime, some nonzero classes have no inverse.
Modulo $6$, the class $[2]$ has no inverse, because $2b$ is even, so $2b - 1$ is odd and is not a multiple of $6$.
In general, $[a]$ has an inverse modulo $n$ exactly when $a$ and $n$ have no common divisor greater than $1$.

## Explanations

### L1 human

On a clock with $7$ hours, numbered $0$ to $6$, we multiply and then keep only the remainder after division by $7$.
For example, $3 \times 5 = 15$, and $15$ has the remainder $1$.
So $5$ undoes $3$ for this multiplication.
Each of the numbers $1$ to $6$ has such a partner.

### L2 human

To find the inverse of $[a]$ modulo $n$, look for $b$ with $ab - 1$ a multiple of $n$.
For small $n$, try $b = 1, 2, \ldots, n - 1$.
For large $n$, the Euclidean algorithm finds integers $b$ and $k$ with $ab + kn = 1$.
A trap is to expect an inverse for every nonzero class modulo every $n$, as the class $[2]$ modulo $6$ shows.
