## Summary

The order on the integers is the relation $\le$ on $\mathbb{Z}$ that puts the integers in the sequence $\dots < -2 < -1 < 0 < 1 < 2 < \dots$.
It is a total order that agrees with addition and with multiplication by positive integers.
