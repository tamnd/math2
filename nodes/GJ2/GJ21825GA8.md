## Summary

The recursive least squares (RLS) filter is an adaptive filter.
With each new data point, it updates the coefficients that minimize a weighted sum of squared errors over all past data.
It gives the exact solution of a (lightly regularized) [[weighted least squares|H5CGZHBR58]] problem at every step.
Yet it never solves a full linear system: it corrects the previous solution by a rank-one update.
A forgetting factor discounts old data, so the filter can track parameters that change slowly.
It typically converges much faster than the [[least mean squares filter|17RASDZEBS]], at a higher cost per step.

## Explanations

### L1 human

Suppose data points arrive one at a time and you want, after each one, the best-fitting line through all points seen so far.
Recomputing the fit from scratch each time is wasteful.
RLS keeps a small summary of the past, a matrix and the current coefficients, and corrects both when a new point arrives.
The correction is large when the new point is surprising and small when it agrees with the current fit.
In the simplest case, fitting a constant to numbers $d_1, d_2, \dots$ without forgetting or regularization, the RLS estimate is just the running average, updated by $w_k = w_{k-1} + (d_k - w_{k-1})/k$.
