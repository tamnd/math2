## Example

A set $X$ is [[low|DKQG0X84D9]] when its [[Turing jump|60P2XWY5QX]] satisfies $X' \le_T \emptyset'$.
We build an $\omega$-model of [[WKL0|K5YPW1NTHZ]] all of whose sets are low, and check that it is not a model of $\mathsf{ACA}_0$.
We use the [[low basis theorem|G8WRRVC0Z3]] relativized to a set $X$: every infinite binary tree computable from $X$ has a path $P$ with $(X \oplus P)' \le_T X'$.

1. For a set $X$ and a number $e$, let $T^X_e$ be the set of $\sigma \in 2^{<\N}$ such that no $\tau \subseteq \sigma$ makes the oracle program $e$ with oracle $X$ halt with output $0$ within $\abs{\sigma}$ steps. It is computable from $X$, and it is a binary tree, since a shorter $\sigma$ allows fewer steps.
2. Let $T \le_T X$ be a binary tree, and let $e$ compute its characteristic function from $X$. Then $T \subseteq T^X_e$. If $g {\restriction} k \notin T$, the program gives $0$ on $g {\restriction} k$ in some $s$ steps, and $g {\restriction} m \notin T^X_e$ for $m \ge \max(k, s)$. So every path through $T^X_e$ is a path through $T$.
3. Let $X_0 = \emptyset$. For $n = \langle i, e \rangle$, with $i \le n$, define $X_{n+1}$ from $X_n$ as follows.
4. If $T^{X_i}_e$ is infinite, it is computable from $X_n$, since $X_i \le_T X_n$. Let $P_n$ be a path with $(X_n \oplus P_n)' \le_T X_n'$, and put $X_{n+1} = X_n \oplus P_n$.
5. If $T^{X_i}_e$ is finite, put $X_{n+1} = X_n \oplus \emptyset$.
6. By induction on $n$, $X_n' \le_T \emptyset'$: the case $n = 0$ is clear, and step 4 gives $X_{n+1}' \le_T X_n' \le_T \emptyset'$.
7. Let $\mathcal{S} = \set{Z : Z \le_T X_n \text{ for some } n}$. Since $X_m \le_T X_n$ for $m \le n$, $\mathcal{S}$ is closed under join and downward under $\le_T$.
8. So $\mathcal{S}$ is a Turing ideal, and $(\N, \mathcal{S})$ is a model of $\mathsf{RCA}_0$ by the [[characterization of ω-models|Y6D27XJT3H]].
9. Let $T \in \mathcal{S}$ be an infinite binary tree. Then $T \le_T X_i$ for some $i$. Take $e$ as in step 2, so $T^{X_i}_e \supseteq T$ is infinite.
10. At stage $n = \langle i, e \rangle$, step 4 put a path $P_n$ through $T^{X_i}_e$ into $X_{n+1}$. By step 2, $P_n$ is a path through $T$, and $P_n \in \mathcal{S}$. So $(\N, \mathcal{S})$ is a model of $\mathsf{WKL}_0$.
11. Each $Z \in \mathcal{S}$ is low: $Z \le_T X_n$ gives $Z' \le_T X_n' \le_T \emptyset'$.
12. The halting set $\emptyset'$ is not low, since $\emptyset'' \not\le_T \emptyset'$. So $\emptyset' \notin \mathcal{S}$.
13. The jump of $\emptyset \in \mathcal{S}$ is missing, so [[the existence of jumps|10NR4PGXHW]] fails, and $(\N, \mathcal{S})$ is not a model of $\mathsf{ACA}_0$.

## Remarks

The model shows that $\mathsf{WKL}_0$ does not prove arithmetical comprehension.
The pairing $\langle i, e \rangle = (i + e)^2 + i$ satisfies $\langle i, e \rangle \ge i$, which step 3 uses.
The sequence $(X_n)$ is defined in the metatheory; it does not need to be uniform for the conclusions above.

## Explanations

### L1 human

The low basis theorem gives a path through a computable tree that is not much more complicated than a computable set.
Adding such paths one tree at a time, forever, gives a family of sets where every infinite tree has a path.
All sets in the family stay low, so the halting problem never enters.

### L2 human

The construction is a standard way to separate two principles by an $\omega$-model.
One closes a Turing ideal under one principle with a basis theorem that keeps the sets simple, and then shows that a set needed by the other principle is too complex.
A trap is to take the family of all low sets: it is not closed under join, since two low sets can have a join of the degree of $\emptyset'$.
