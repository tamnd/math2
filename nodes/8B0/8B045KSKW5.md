## Example

A set $X$ is [[low|DKQG0X84D9]] when its [[Turing jump|60P2XWY5QX]] is no harder than the halting set: $X' \le_T \emptyset'$.
We build a family $\mathcal{S}$ of low sets such that $(\mathbb{N}, \mathcal{S})$ is an $\omega$-model of [[WKL0|K5YPW1NTHZ]], and we check that it is not a model of $\mathsf{ACA}_0$.
The tool is the [[low basis theorem|G8WRRVC0Z3]] relative to a set $X$: every infinite binary tree computable from $X$ has a path $P$ with $(X \oplus P)' \le_T X'$.

### A list of all trees

First we make a list of trees that catches every tree computable from $X$.

1. Fix a set $X$ and a number $e$, and let $T^X_e$ be the set of strings $\sigma \in 2^{<\mathbb{N}}$ with the following property.
   No initial segment $\tau$ of $\sigma$ makes program $e$ with oracle $X$ halt with output $0$ on input $\tau$ within $\lvert \sigma \rvert$ steps.
   It is computable from $X$, and it is a binary tree, because a shorter $\sigma$ has fewer initial segments and allows fewer steps.
2. Let $T \le_T X$ be a binary tree, and let program $e$ compute its characteristic function from $X$.
   Then every element of $T$ is in $T^X_e$, because the program never gives $0$ on an initial segment of an element of $T$.
3. Every path $g$ through $T^X_e$ is a path through $T$.
   If $g {\restriction} k \notin T$, the program gives $0$ on $g {\restriction} k$ within some $s$ steps, and then $g {\restriction} m \notin T^X_e$ for $m \ge \max(k, s)$.

### The construction

Next we build the model in stages, with the pairing $\langle i, e \rangle = (i + e)^2 + i$, which satisfies $\langle i, e \rangle \ge i$.

4. Let $X_0 = \emptyset$.
   At stage $n = \langle i, e \rangle$ we have $i \le n$, so $X_i$ is already defined and $X_i \le_T X_n$.
5. If $T^{X_i}_e$ is infinite, it is computable from $X_n$, and the low basis theorem gives a path $P_n$ with $(X_n \oplus P_n)' \le_T X_n'$.
   Put $X_{n+1} = X_n \oplus P_n$.
6. If $T^{X_i}_e$ is finite, put $X_{n+1} = X_n$.
7. By induction on $n$, $X_n' \le_T \emptyset'$.
   For $n = 0$ the jump of $\emptyset$ is $\emptyset'$, and step 5 gives $X_{n+1}' \le_T X_n' \le_T \emptyset'$.
8. Let $\mathcal{S} = \{ Z : Z \le_T X_n \text{ for some } n \}$.

### Checking the model

Now we check the axioms and the failure of $\mathsf{ACA}_0$.

9. Since $X_m \le_T X_n$ for $m \le n$, the family $\mathcal{S}$ is closed under $\oplus$ and downward under $\le_T$.
   So it is a Turing ideal, and $(\mathbb{N}, \mathcal{S})$ is a model of $\mathsf{RCA}_0$ by the [[characterization of ω-models|Y6D27XJT3H]].
10. Let $T \in \mathcal{S}$ be an infinite binary tree, so $T \le_T X_i$ for some $i$, and take $e$ as in step 2.
    Then $T^{X_i}_e$ contains $T$ and is infinite, so at stage $n = \langle i, e \rangle$ step 5 added a path $P_n \in \mathcal{S}$, which is a path through $T$ by step 3.
11. Each $Z \in \mathcal{S}$ is low, because $Z \le_T X_n$ gives $Z' \le_T X_n' \le_T \emptyset'$.
12. The halting set is not low, since $\emptyset'' \not\le_T \emptyset'$, so $\emptyset' \notin \mathcal{S}$.
    The jump of $\emptyset \in \mathcal{S}$ is missing, so [[the existence of jumps|10NR4PGXHW]] fails and $(\mathbb{N}, \mathcal{S})$ is not a model of $\mathsf{ACA}_0$.

## Remarks

The model shows that $\mathsf{WKL}_0$ does not prove arithmetical comprehension.
It shows the standard way to separate two principles by an $\omega$-model.
Close a Turing ideal under the weaker principle with a basis theorem that keeps every set simple.
Then show that a set needed by the stronger principle is too complex.

The trees $T^X_e$ matter because "program $e$ computes a tree" is not decidable.
Every $e$ gives some tree $T^X_e$, so the construction can run through all $e$ without asking which programs are total.

Watch out: the family of all low sets is not a Turing ideal.
There are two low sets whose join computes $\emptyset'$, so that family is not closed under $\oplus$.
This is why the construction adds one path at a time to a single increasing sequence $X_0 \le_T X_1 \le_T \cdots$.

If we replace the low basis theorem by the hyperimmune-free basis theorem, the same construction gives an $\omega$-model of $\mathsf{WKL}_0$ in which every set is hyperimmune-free.

## Explanations

### L1 human

The low basis theorem says that a computable tree with infinitely many nodes has a branch that is only a little more complicated than a computable set.
We add such branches one tree at a time, forever, and keep everything that the added branches compute.
In the end every infinite tree in the family has a branch in the family.
All sets in the family stay simple, so the halting problem never enters.

### L2 human

Follow the first stages.
Stage $0 = \langle 0, 0 \rangle$ looks at $T^{\emptyset}_0$, a computable tree, and adds a low path if the tree is infinite.
Stage $2 = \langle 1, 0 \rangle$ looks at the tree $T^{X_1}_0$ computed from the new set $X_1$, which may be a tree that did not exist before.
Each later stage looks at trees from earlier sets, and the pairing makes sure that every pair $(i, e)$ is visited.
The trap is to stop after the computable trees: a path through a computable tree can compute new trees, and those need paths too.
