## Example

Seven short axioms about $0$, successor, addition and multiplication already give a theory that no program can decide.
From these axioms you can prove $2 + 2 = 4$ by a few steps of computation.
You cannot prove $\forall x \, (0 + x = x)$, and you cannot refute it either.
Yet the failure is deeper than one hard sentence: no algorithm sorts all sentences into theorems and non-theorems.

The signature has a constant $0$, a unary function symbol $S$ and binary function symbols $+$ and $\cdot$.
[[Robinson arithmetic|3K1AKGXF8A]] $\mathsf{Q}$ is the theory axiomatized by these seven sentences.

1. $\forall x \, (S x \neq 0)$.
2. $\forall x \, \forall y \, (S x = S y \to x = y)$.
3. $\forall x \, (x \neq 0 \to \exists y \, (x = S y))$.
4. $\forall x \, (x + 0 = x)$.
5. $\forall x \, \forall y \, (x + S y = S (x + y))$.
6. $\forall x \, (x \cdot 0 = 0)$.
7. $\forall x \, \forall y \, (x \cdot S y = x \cdot y + x)$.

We check that $\mathsf{Q}$ is not a [[decidable theory|HWC687ES0Q]].

1. The set of axioms is finite, hence computable.
   So the set of consequences of $\mathsf{Q}$ is computably enumerable.
2. $\mathsf{Q}$ is consistent, because the standard structure $(\mathbb{N}, 0, S, +, \cdot)$ satisfies the seven axioms.
3. $\mathsf{Q}$ is [[essentially undecidable|9JDDFN8PT7]]: every consistent theory in the same signature that contains $\mathsf{Q}$ is undecidable, by [[the essential undecidability of Robinson arithmetic|RZ42PP37MD]].
4. $\mathsf{Q}$ is itself a consistent theory that contains $\mathsf{Q}$, so by step 3 it is undecidable.

So the condition of decidability fails: no algorithm decides, for each sentence $\sigma$, whether $\mathsf{Q} \models \sigma$.

## Remarks

### What the example shows

A finite set of axioms does not make a theory decidable.
The route through completeness does not apply, because $\mathsf{Q}$ is not complete.
For example, $\mathsf{Q}$ does not prove $\forall x \, \forall y \, (x + y = y + x)$, since a nonstandard model of $\mathsf{Q}$ violates this law.

### A route to Church's theorem

Let $\alpha$ be the conjunction of the seven axioms.
Then $\mathsf{Q} \models \sigma$ holds exactly when $\alpha \to \sigma$ is valid.
So a decision procedure for validity would decide $\mathsf{Q}$, which is impossible.
This gives a proof of [[Church's theorem|VA6BNNY2YC]].

### What changes with the axioms

Without multiplication the picture changes.
The complete theory of the structure $(\mathbb{N}, 0, S, +)$ is decidable, by [[Presburger arithmetic|4W0E9G7PPV]].
In the other direction, more axioms do not help.
If you add, for example, the induction axioms of Peano arithmetic, the theory stays undecidable, as long as it is consistent.

## Explanations

### L1 human

Robinson arithmetic is a short list of seven basic rules about counting, adding and multiplying whole numbers.
A computer can list everything that follows from these seven rules, one result after another.
But no computer program can take any statement and decide, after finite time, whether it follows from the rules.
So a short list of rules can still produce a theory that is too complex for any algorithm.

### L2 human

We see why proof search gets stuck on the sentence $\sigma = \forall x \, (0 + x = x)$.
For each numeral $\bar{n}$, $\mathsf{Q}$ proves $0 + \bar{n} = \bar{n}$, by $n$ uses of axiom 5 and one use of axiom 4.
For $n = 2$ the computation reads as follows:
$$0 + SS0 = S(0 + S0) = SS(0 + 0) = SS0.$$
But $\sigma$ itself is not provable in $\mathsf{Q}$, because some models of $\mathsf{Q}$ have extra elements $a$ with $0 + a \neq a$.
Its negation is not provable either, since $\sigma$ is true in $\mathbb{N}$.
So a search for a proof of $\sigma$ or of $\neg \sigma$ runs forever.

The typical use of $\mathsf{Q}$ is as the base theory for undecidability: a theory that interprets $\mathsf{Q}$ in a suitable way is undecidable.
Watch out: undecidability of $\mathsf{Q}$ does not follow from this one stuck search.
One sentence on which a search fails does not exclude a cleverer algorithm, and the proof needs essential undecidability.
