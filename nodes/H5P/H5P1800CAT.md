## Definition

A *discrete channel* is a triple $(\mathcal{X}, W, \mathcal{Y})$ with the following parts.

1. $\mathcal{X}$ is a finite set, the *input [[alphabet|RABRP2KG81]]*.
2. $\mathcal{Y}$ is a finite set, the *output alphabet*.
3. $W$ assigns to each $x \in \mathcal{X}$ a [[probability mass function|0D6J4B671D]] $W(\cdot \mid x)$ on $\mathcal{Y}$, the *transition probabilities*.

The channel is *memoryless* when $n$ uses of it act independently.
That is, the probability of receiving $y^n = (y_1, \dots, y_n)$ when $x^n = (x_1, \dots, x_n)$ is sent is
$$W^n(y^n \mid x^n) = \prod_{i=1}^{n} W(y_i \mid x_i).$$

## Remarks

Equivalently, $W$ is a [[Markov kernel|2AVNDP8BJP]] from $\mathcal{X}$ to $\mathcal{Y}$, or a stochastic matrix with rows indexed by $\mathcal{X}$ and columns by $\mathcal{Y}$.
Channels with infinite alphabets, such as $\mathcal{X} = \mathcal{Y} = \R$, are defined in the same way with a Markov kernel.
Example: $\mathcal{X} = \mathcal{Y} = \set{0, 1}$ with $W(1 \mid 0) = W(0 \mid 1) = 0.1$ and $W(0 \mid 0) = W(1 \mid 1) = 0.9$.
Each row sums to $1$, so this is a channel; it flips each bit with probability $0.1$.
Non-example: $W(0 \mid 0) = 0.9$ and $W(1 \mid 0) = 0.2$ does not define a channel, since these probabilities sum to $1.1$.
