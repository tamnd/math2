## Example

Take the frame $(\mathbb{N}, <)$: the worlds are the natural numbers, and $m R n$ means $m < n$.
We check the properties of this [[accessibility relation|XBCYFDPS2F]], and then we test the axioms of [[common modal axiom schemata|FDFQFWPM4X]].

1. It is serial, because every $n$ has the successor $n + 1$.
2. It is [[transitive|0GJZW9JFZQ]], because $l < m$ and $m < n$ give $l < n$.
3. It is not [[reflexive|0X8NMST0J2]], because $0 < 0$ fails.
4. It is not [[symmetric|061J5VGSPT]], because $0 < 1$ holds and $1 < 0$ fails.
5. It is not Euclidean, because $0 < 1$ and $0 < 2$ hold but $2 < 1$ fails.
6. So the axioms $\mathrm{D}$ and $\mathrm{4}$ are valid on $(\mathbb{N}, <)$, by the correspondences for serial and transitive frames.
7. The axiom $\mathrm{T}$ fails with $V(p) = \{ n : n \geq 1 \}$.
   At $0$ every successor has $p$, so $\square p$ is true, while $p$ is false.
8. The axiom $\mathrm{B}$, $p \to \square\lozenge p$, fails with $V(p) = \{ 0 \}$.
   At $1$ all successors are at least $2$ and lack $p$, so $\lozenge p$ is false at $1$.
   Then $\square\lozenge p$ is false at $0$, while $p$ is true at $0$.
9. The axiom $\mathrm{5}$, $\lozenge p \to \square\lozenge p$, fails with $V(p) = \{ 2 \}$.
   At $1$ the successor $2$ has $p$, so $\lozenge p$ is true.
   At $2$ all successors exceed $2$, so $\lozenge p$ is false there, and $\square\lozenge p$ is false at $1$.

Now read $\square p$ as "$p$ at all later times", and take $V(p) = \{ n : n \text{ even} \}$.

10. $[\![ \lozenge p ]\!] = \mathbb{N}$, since after each $n$ there is a later even number.
11. $[\![ \square p ]\!] = \varnothing$, since one of $n + 1$ and $n + 2$ is odd.
12. $[\![ \square\lozenge p ]\!] = \mathbb{N}$, since $\lozenge p$ holds everywhere.

## Remarks

The frame validates the logic $\mathsf{KD4}$, and $\mathrm{T}$, $\mathrm{B}$ and $\mathrm{5}$ fail on it.

In the temporal reading, $\square\lozenge p$ says "$p$ holds infinitely often", and $\lozenge\square p$ says "from some time on, $p$ holds forever".
With $V(p)$ the even numbers, $\lozenge\square p$ is false everywhere, because $\square p$ is false everywhere.
So the two notions differ, although they sound alike.

What changes with $\leq$ in place of $<$?
The frame becomes reflexive, so $\mathrm{T}$ becomes valid.
The order $\leq$ is still not symmetric, and $\mathrm{B}$ still fails with $V(p) = \{ 0 \}$ at $0$, since $1$ sees no world with $p$.
What changes with a finite chain $\{ 0, \dots, k \}$ in place of $\mathbb{N}$?
The last world $k$ has no successor, so $\square\bot$ is true at $k$ and $\mathrm{D}$ fails there.

## Explanations

### L1 human

Read the numbers $0, 1, 2, \dots$ as days, and "box $p$" as "$p$ on every later day".
"Diamond $p$" means "$p$ on some later day".
If it rains on every even day, then on each day there is a later rainy day.
But on no day is it true that it rains on all later days.
Every day has a next day, so "box $p$" always gives "diamond $p$".

### L2 human

Take $V(p) = \{ 3, 4, 5, \dots \}$ and compute $[\![ \lozenge\square p ]\!]$.
At $n \geq 2$ every later day is at least $3$, so $\square p$ is true.
At $0$ and $1$ the later day $2$ lacks $p$, so $\square p$ is false.
Every day has a later day that is at least $2$, so $\lozenge\square p$ holds everywhere:
$$[\![ \square p ]\!] = \{ 2, 3, \dots \}, \qquad [\![ \lozenge\square p ]\!] = \mathbb{N}.$$
The typical use of $(\mathbb{N}, <)$ is as a frame for the logic of the strict future, and as an infinite test frame for $\mathsf{KD4}$.
Watch out: the frame is transitive and irreflexive, but it does not validate [[Löb's axiom|QQ6PZFGGB3]], because it has an infinite increasing chain.
