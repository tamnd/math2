## Definition

A matrix is a rectangular array of elements of a ring, with an entry at every position.
Let $R$ be a [[ring|0B1261B5ED]], for example a field, and let $m, n \ge 0$ be integers.
An $m \times n$ *matrix* over $R$ is a function
$$A \colon \{1, \dots, m\} \times \{1, \dots, n\} \to R,$$
and we write $a_{ij}$ for its value $A(i, j)$.
The element $a_{ij}$ is the *entry* of $A$ in row $i$ and column $j$.
Row $i$ of $A$ is the list $(a_{i1}, \dots, a_{in})$, and column $j$ is the list $(a_{1j}, \dots, a_{mj})$.
The pair $m \times n$ is the *size* of $A$, and we display $A$ as an array with $m$ rows and $n$ columns:
$$A = \begin{pmatrix} a_{11} & \cdots & a_{1n} \\ \vdots & \ddots & \vdots \\ a_{m1} & \cdots & a_{mn} \end{pmatrix}.$$
The set of all $m \times n$ matrices over $R$ is written $M_{m \times n}(R)$ or $R^{m \times n}$.
Two matrices $A$ and $B$ are *equal* when they have the same size and $a_{ij} = b_{ij}$ for all $i$ and $j$.

## Notation

A $1 \times n$ matrix is a *row vector*, and an $m \times 1$ matrix is a *column vector*.
When $m = n$ the matrix is [[square|0JXZKX526R]], and $M_n(R)$ means $M_{n \times n}(R)$.
The notation $A = (a_{ij})_{1 \le i \le m,\, 1 \le j \le n}$ shows the ranges of the indices when they are not clear from the context.

## Remarks

The definition has three parts, and each one has a job.
The ring $R$ says where the entries live, and it must have an addition and a multiplication so that matrices can later be added and multiplied.
The function on the full rectangle of positions says that every position has exactly one entry, so the array has no holes.
The equality rule includes the size, because two functions with different domains are different functions.

For example, the rule $a_{ij} = i + j$ on $2$ rows and $2$ columns gives the matrix with rows $(2, 3)$ and $(3, 4)$.
In contrast, the array with rows $(1, 2)$ and $(3, 4, 5)$ fails the second part, since the position $(1, 3)$ has no entry; see [[the ragged array|8F1WW3852E]].
The concept page on [[matrices|0VD9ZSWWJG]] shows where matrices come from and what they are used for.

The case $m = 0$ or $n = 0$ is allowed, and then there is exactly one matrix of that size, the empty function.
The Mathlib declaration `Matrix m n α` is the type `m → n → α` for arbitrary index types `m` and `n`, which is why the match is recorded as a variant.
Mathlib needs `Fintype` instances on the index types for products, traces and determinants, and with `Fin m` as the index type the first entry is `A 0 0`.

## Explanations

### L1 human

A matrix is a table of numbers with a fixed number of rows and columns, and no empty places.
The matrix $\begin{pmatrix} 1 & 2 & 3 \\ 4 & 5 & 6 \end{pmatrix}$ has 2 rows and 3 columns, so it is a $2 \times 3$ matrix.
We name an entry by its row first and then its column, so $a_{21} = 4$.

### L2 human

Thinking of a matrix as a function on positions makes equality precise.
The row $\begin{pmatrix} 1 & 2 & 3 \end{pmatrix}$ is a function on the positions $(1, 1)$, $(1, 2)$, $(1, 3)$, and the column with the same entries is a function on $(1, 1)$, $(2, 1)$, $(3, 1)$.
The domains differ, so the two matrices are different.
Watch out: entry by entry comparison makes sense only after you check that the sizes agree.
