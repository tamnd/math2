## Example

Let $\Sigma = \set{(, )}$.
The *Dyck language* $D_1 \subseteq \Sigma^*$ is the set of balanced strings of brackets.
In such a string $w$, every prefix has at least as many $($ as $)$.
The string $w$ itself has as many $($ as $)$.
Its elements are the [[Dyck words|0YTJ3RN3GE]], for example $\varepsilon$, $(\,)$, $(\,)(\,)$ and $((\,))$.
More generally, $D_n$ is the language of balanced strings over $n$ kinds of bracket pairs.
In $D_n$, each closing bracket must match the kind of the last unmatched opening bracket.

$D_1$ is a [[context-free language|Q56EWEQYE2]]: it is generated by the [[context-free grammar|CTCY2R8Q77]] with rules $S \to SS$, $S \to (S)$ and $S \to \varepsilon$.
To check this, note that each rule keeps the strings balanced.
Conversely, a nonempty balanced string either splits into two shorter nonempty balanced strings or has the form $(u)$ with $u$ balanced.

$D_1$ is not a [[regular language|18WVBDCS38]].
Let $p$ be the pumping length of the [[pumping lemma for regular languages|CBR9WAGZGZ]].
The word $(^p\,)^p$ can only be pumped inside its first block, which unbalances it.

## Remarks

$D_1$ is even a [[deterministic context-free language|5BN419NP56]]: a pushdown automaton pushes on $($, pops on $)$, and never needs to guess.
The number of Dyck words of length $2n$ is the Catalan number $\frac{1}{n+1}\binom{2n}{n}$, see [[Dyck words are counted by Catalan numbers|017SRZ7NE9]].
The languages $D_n$ play a central role in the Chomsky–Schützenberger representation theorem.

## Explanations

### L1 human

The Dyck language is the language of correctly nested brackets, as in a well-written formula.
Reading left to right, one never closes more brackets than one has opened, and at the end everything is closed.
A finite automaton cannot recognise it, because it would need to remember how many brackets are still open, which can be any number.
A stack solves this, which makes the Dyck language the model example of a context-free language.
