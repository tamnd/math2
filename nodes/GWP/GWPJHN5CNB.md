## Proof

We find two properties that every Kleene formula has and that Łukasiewicz implication lacks, and then we verify the two definitions of item 3.
We use the notation of [[the statement|729J1FD1GZ]].

First, item 1.

1. We claim that every formula $\varphi(p, q)$ in $\neg$, $\land$ and $\lor$ has the value $\tfrac12$ at $p = q = \tfrac12$, and we use [[structural induction|12MQ2NJ29A]] on $\varphi$.
2. If $\varphi$ is $p$ or $q$, its value is $\tfrac12$.
3. If $\varphi = \neg \psi$ and $\psi$ has the value $\tfrac12$, then $\varphi$ has the value $1 - \tfrac12 = \tfrac12$.
4. If $\varphi$ is $\psi \land \chi$ or $\psi \lor \chi$, with both parts of value $\tfrac12$, then its value is $\min(\tfrac12, \tfrac12) = \max(\tfrac12, \tfrac12) = \tfrac12$.
5. But $\tfrac12 \to_{Ł} \tfrac12 = \min(1, 1) = 1 \neq \tfrac12$, so no such $\varphi$ defines $\to_{Ł}$.

### Item 2: an order that the Kleene connectives respect

6. Order $V$ by information: $u \sqsubseteq w$ iff $u = w$ or $u = \tfrac12$.
7. Negation is monotone for $\sqsubseteq$, because it fixes $\tfrac12$ and swaps $0$ and $1$.
8. Minimum is monotone; let $x \sqsubseteq x'$ and $y \sqsubseteq y'$.
   If $\min(x, y) = 0$, then $x$ or $y$ is $0$, so $x'$ or $y'$ is $0$, and $\min(x', y') = 0$.
   If $\min(x, y) = 1$, then $x = y = 1$, so $x' = y' = 1$; and if $\min(x, y) = \tfrac12$, it lies below every value.
9. Maximum is monotone by the same argument with $0$ and $1$ exchanged, and the constants $0$ and $1$ are monotone.
10. By structural induction, every formula in $\neg$, $\land$, $\lor$, $0$ and $1$ defines a function that is monotone for $\sqsubseteq$ in each argument.
11. We have $(\tfrac12, \tfrac12) \sqsubseteq (1, \tfrac12)$ coordinate by coordinate.
    But $\tfrac12 \to_{Ł} \tfrac12 = 1$ and $1 \to_{Ł} \tfrac12 = \tfrac12$, and $1 \not\sqsubseteq \tfrac12$.
12. So $\to_{Ł}$ is not monotone, and step 10 shows that no such formula defines it.

### Item 3: the two definitions

13. If $x \le y$, then $x \to_{Ł} y = 1$ and $1 \to_{Ł} y = y = \max(x, y)$.
14. If $x > y$, then $x \to_{Ł} y = 1 - x + y$, and $(1 - x + y) \to_{Ł} y = \min(1, x) = x = \max(x, y)$.
15. De Morgan gives $\neg(\neg x \lor \neg y) = 1 - \max(1 - x, 1 - y) = \min(x, y)$.

This proves the three items.

## Idea

To show that something is not definable, find a property that all the building blocks keep and the target breaks.
The value $\tfrac12$ at the all-$\tfrac12$ input is kept by the Kleene operations, and so is the information order, in which $\tfrac12$ means "not yet known".
The single entry $\tfrac12 \to_{Ł} \tfrac12 = 1$ breaks both, because it produces knowledge out of no knowledge.

## Variants

Steps 6 to 12 alone also prove item 1, since a formula without constants is a special case of step 10.
The same invariant method works for any finite set of operations on a finite set.
An operation lies in the [[clone|PTKR703G6A]] generated by the set iff it preserves every relation that the set preserves, so non-definability always has a witness of this kind.
