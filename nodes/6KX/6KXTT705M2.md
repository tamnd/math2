## Example

A group of students computes $f(n) = n^2 + n + 41$ for $n = 0, 1, 2, 3, 4, 5$ and gets $41, 43, 47, 53, 61, 71$.
They check that each value is prime.
One of them says: "So $n^2 + n + 41$ is probably prime for all $n$, unless we find a value where it is not."
We lay out the argument in the [[Toulmin model|RVZCSFDB2Y]].

1. Claim $C$: for each natural number $n$, the number $n^2 + n + 41$ is prime.
2. Data $D$: the six values above, each checked to be prime.
   For example, $71$ has no prime divisor $p$ with $p^2 \le 71$, since none of $2, 3, 5, 7$ divides it.
3. Warrant $W$: a pattern that holds in all checked cases probably holds in general, which is an inductive warrant.
4. Backing $B$: the students' experience that patterns in small cases often continue.
5. Qualifier $Q$: "probably", stated by the student.
6. Rebuttal $R$: "unless we find a value where it is not", also stated by the student.
7. The rebuttal applies at $n = 40$:
   $$f(40) = 1600 + 40 + 41 = 1681 = 41^2,$$
   which is not prime, so the claim is false.

## Remarks

The example uses all six parts of the model, including the qualifier and the rebuttal, which a deductive proof does not need.
The student's argument is a good [[conjecture|WMEMMHZ3BH]] with an honest qualifier, and the layout records that the student never claimed certainty.
[[Forty prime values of n^2 + n + 41 do not prove a statement|H75AB4EJT5]] gives the full computation for $n = 0$ to $39$.

Once the rebuttal has fired, the class can make a new claim with a deductive warrant.
At $n = 41$ every term has the factor $41$:
$$f(41) = 41^2 + 41 + 41 = 41 \cdot (41 + 1 + 1) = 41 \cdot 43 = 1763.$$
Here the data are the factorization, the warrant is the definition of a prime, and the qualifier is "certainly".

## Explanations

### L1 human

The students try six numbers and get a prime each time.
They guess that this always happens, and they say "probably", which is honest.
They also say what would prove them wrong: one number where the result is not prime.
Such a number exists, since for $n = 40$ the result is $1681 = 41 \cdot 41$.
The Toulmin model has a place for "probably" and for "unless", so it describes this argument well.

### L2 human

Read the layout from left to right.
The claim is that every value is prime, and the data are six prime values.
The warrant is the inductive rule "what holds in the cases checked holds always", and the student supplied both the qualifier and the rebuttal.
Testing the rebuttal is the natural next step, and $n = 40$ gives $41^2$.
Watch out: calling the student's argument a wrong proof misreads it, since the student did not claim a proof and the layout shows a conjecture with a correct qualifier.
