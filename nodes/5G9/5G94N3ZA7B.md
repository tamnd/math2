## Definition

Let $i < j$.
The comparator $[i:j]$ exchanges the entries in positions $i$ and $j$ of a sequence when the entry in position $i$ is larger.
Let $m = 2^j$ with $j \ge 0$.
The *odd–even merging network* $M_m$ takes two sorted sequences $a_1, \dots, a_m$ and $b_1, \dots, b_m$ and is defined recursively.

1. If $m = 1$, then $M_1$ is the single comparator applied to $(a_1, b_1)$.
2. If $m \ge 2$, apply $M_{m/2}$ to the odd-indexed sequences $a_1, a_3, \dots, a_{m-1}$ and $b_1, b_3, \dots, b_{m-1}$, giving $c_1, \dots, c_m$.
3. In parallel, apply $M_{m/2}$ to the even-indexed sequences $a_2, a_4, \dots, a_m$ and $b_2, b_4, \dots, b_m$, giving $d_1, \dots, d_m$.
4. Output the sequence $c_1, \min(d_1, c_2), \max(d_1, c_2), \dots, \min(d_{m-1}, c_m), \max(d_{m-1}, c_m), d_m$, that is, apply the $m - 1$ comparators to the pairs $(d_i, c_{i+1})$ for $1 \le i \le m - 1$.

Let $n = 2^k$ with $k \ge 0$.
The *Batcher odd–even mergesort* network $S_n$ on $n$ inputs is defined recursively.
The network $S_1$ has no comparator.
For $n \ge 2$, $S_n$ applies $S_{n/2}$ to each half of the input in parallel.
Then it applies $M_{n/2}$ to the two sorted halves.

## Remarks

The network $S_n$ is a [[sorting network|G854V12EC7]]: it sorts every input sequence of length $n$.
It has depth $k(k+1)/2$ and uses $(k^2 - k + 4)\,2^{k-2} - 1$ comparators.

Example: for $n = 4$, the network is $[1:2]$, $[3:4]$, then $[1:3]$, $[2:4]$, then $[2:3]$.
That is $5$ comparators in $3$ layers, which agrees with the formula for $k = 2$.
On the input $(3, 1, 4, 2)$ the layers give $(1, 3, 2, 4)$, then $(1, 3, 2, 4)$, then $(1, 2, 3, 4)$.

Non-example: the network $[1:2]$, $[3:4]$, $[1:3]$, $[2:4]$ without the last comparator $[2:3]$ omits the final step of $M_2$.
It does not sort: the input $(1, 3, 2, 4)$ passes through unchanged.

The construction is usually stated for $n$ a power of $2$; other sizes are handled by padding with large values or by pruning comparators.
