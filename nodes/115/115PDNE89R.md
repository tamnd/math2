## Summary

The relative degree of a single-input single-output nonlinear system counts how often the output must be differentiated in time before the input appears.
It is defined with [[Lie derivatives|PJWK0PKN6Q]] of the output function along the vector fields of the system.
It fixes the size of the linear part in input-output [[feedback linearization|1J2KTGXB34]], and what remains is the [[zero dynamics|W3N8APDEB9]].
For a linear system it equals the difference between the degrees of the denominator and the numerator of the [[transfer function|86JKV3TRFD]].

## Explanations

### L1 human

Push on a cart and watch its position.
The push changes the acceleration at once, but the velocity only after a while and the position even later.
So one must differentiate the position twice to see the push: the relative degree is $2$.
In general the relative degree counts how many integrations lie between the input and the output.
