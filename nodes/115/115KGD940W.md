## Definition

Fix a countable set of variables.
The *SKI terms* are defined by these rules.

1. Every variable and each of the constants $\mathbf{S}$, $\mathbf{K}$, $\mathbf{I}$ is a term.
2. If $M$ and $N$ are terms, then $(M\, N)$ is a term.

Application associates to the left, so $M\, N\, P$ means $((M\, N)\, P)$.
*Weak reduction* $\to_w$ is the least relation on terms with two properties.
First, it contains the rules
$$\mathbf{I}\, M \to_w M, \qquad \mathbf{K}\, M\, N \to_w M, \qquad \mathbf{S}\, M\, N\, P \to_w M\, P\, (N\, P)$$
for all terms $M, N, P$.
Second, if $M \to_w M'$ then $M\, N \to_w M'\, N$ and $N\, M \to_w N\, M'$.
The *SKI combinator calculus* is the set of SKI terms with weak reduction, a [[rewriting system|Y83TQF6V6A]].

## Remarks

Example: $\mathbf{S}\, \mathbf{K}\, \mathbf{K}$ behaves like $\mathbf{I}$.
For every term $M$, $\mathbf{S}\, \mathbf{K}\, \mathbf{K}\, M \to_w \mathbf{K}\, M\, (\mathbf{K}\, M) \to_w M$.

Non-example: $\mathbf{K}\, M$ alone is not a redex.
The rule for $\mathbf{K}$ needs two arguments, so $\mathbf{K}\, M$ is in normal form whenever $M$ is.

Combinatory completeness: for each term $M$ and variable $x$ there is a term $[x]M$ without $x$ such that $([x]M)\, N \twoheadrightarrow_w M[x := N]$ for all $N$.
One can take $[x]x = \mathbf{I}$, $[x]M = \mathbf{K}\, M$ if $x$ does not occur in $M$, and $[x](M\, N) = \mathbf{S}\, ([x]M)\, ([x]N)$ otherwise.
This translates every term of the [[lambda calculus|BD756KR8FM]] into an SKI term with the same behavior on arguments.
