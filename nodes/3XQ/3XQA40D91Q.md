## Summary

Full waveform inversion is [[seismic tomography|JRN1693EHB]] that fits entire recorded seismograms, not only picked arrival times.
It simulates the waves in a trial Earth model by solving the [[wave equation|5EHD2XBQDG]] and measures the misfit to the data.
It then updates the model by local optimisation, with gradients from the [[adjoint state method|YD8SA6WS01]].
Since it uses amplitudes and phases of all arrivals, it can resolve structures down to about half a wavelength, much finer than travel-time tomography.
Its main difficulty is that the misfit has many local minima, so it needs a good starting model and low frequencies.

## Explanations

### L1 human

Instead of noting only when each wave arrives, full waveform inversion tries to reproduce every wiggle of the recordings.
A computer simulates the waves in a guessed Earth, compares the simulated and the real recordings, and adjusts the guess to make them more alike, again and again.
If the first guess is too far off, the simulated wiggles line up with the wrong real wiggles and the method gets stuck.
For a wave that repeats every second, a starting model that predicts arrivals more than half a second wrong can lead to this mismatch.
